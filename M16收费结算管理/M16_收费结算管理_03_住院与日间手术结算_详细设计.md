## 1. 模块概述

### 1.1 模块定位

住院结算回答的问题与门诊完全不同：

| 维度 | 门诊收费（M16-02） | **住院结算（M16-03）** |
|---|---|---|
| 核心问题 | 这笔钱现在收 | **这个患者住了 N 天，最后要结多少** |
| 结算时点 | 诊疗前 | 出院时 |
| 资金模型 | 直接付 | **先交预交金，出院多退少补** |
| 记账次数 | 一次 | **每天、每次开单都记账** |
| 金额确定性 | 收钱时确定 | **出院那一刻才确定** |

```
┌────────────────────────────────────────────────────────────────┐
│                      住院资金流全景                              │
│                                                                  │
│  入院                                                             │
│   │  ① 交预交金 10,000                                            │
│   ▼                                                               │
│  ┌──────────────┐                                                │
│  │  预交金池     │ 10,000.00                                       │
│  │ m16_deposit   │                                                │
│  └──────┬───────┘                                                │
│         │  ② 每日医嘱记账（不扣预交金，只累计）                     │
│         │     ③ 预交金不足预警                                    │
│         ▼                                                         │
│  ┌──────────────┐                                                │
│  │  住院费用账    │ 累计 12,800.00                                  │
│  │ m16_inpatient │                                                │
│  │   _charge     │                                                │
│  └──────┬───────┘                                                │
│         │  ④ 出院结算                                             │
│         ▼                                                         │
│  应收 12,800 − 预交 10,000 = 补交 2,800                            │
│         │                                                         │
│         ├── 补交 2,800 → 调 M16-02/M16-05 收款                    │
│         └── 或多退 2,000 → 调 M16-08 退费（退到原支付方式）         │
│         ▼                                                         │
│  出院                                                        │
└────────────────────────────────────────────────────────────────┘
```

### 1.2 为什么预交金与费用记账必须分离

**朴素做法（错误）：** 每开一条医嘱就从预交金里扣钱。

**为什么错：**

| 问题 | 说明 |
|---|---|
| 无法"记账后改价" | 医保回款比例、物价调整可能在出院时才确定 |
| 无法"费用分类统计" | 预交金池只有一个数，看不到药品/检查/手术各花多少 |
| 无法"多退少补" | 出院时算不清该补还是该退 |
| 无法"中途结算" | 长期住院患者中途结算一次，需要冻结当前账期 |

**正确做法：**

```
预交金池（只增不减，除退还）
    ↕ 出院结算时对账
住院费用账（只增不减，除冲销）
```

**预交金是"患者交了多少"，费用账是"花了多少"，两者在出院时才相遇。**

### 1.4 概念辨析：门诊结算 vs 住院结算 vs 日间手术结算

| 概念 | 定义 | 生命周期 | 预交金 | 典型金额 |
|---|---|---|---|---|
| 门诊结算 | 一次就诊的所有费用，先付后诊疗 | 分钟级 | 无 | 100~3,000 元 |
| **日间手术结算** | 当日入院、当日手术、当日或次日出院 | 小时级（≤24h） | **可选**（可先交后结） | 2,000~15,000 元 |
| **住院结算** | 多日住院，出院时一次结清 | 天级（3~30 天） | **必须** | 5,000~80,000 元 |

**日间手术是"门诊与住院之间"的灰区：**

| 场景 | 走哪个流程 |
|---|---|
| 白内障日间手术（当天出院） | **日间手术结算**（M16-03），可用预交金也可不用 |
| 玻璃体切割术后观察 2 天 | 住院结算（M16-03） |
| 门诊小手术（胬肉切除） | 门诊结算（M16-02） |
| 屈光手术（SMILE/FS-LASIK） | 视光销售结算（M16-04） |

### 1.5 模块目标

| 目标 | 指标 |
|---|---|
| 预交金准确 | 余额 = 累计充值 − 累计退还 − 累计结算占用，误差 = 0 |
| 记账不丢 | 每条医嘱必须记账且**只记一次** |
| 出院算得清 | 出院结算金额可完整追溯到每一条明细 |
| 中途可结算 | 长期住院可分段结算，账期清晰 |
| 预警及时 | 预交金不足当日预警 |

### 2.4 医保结算的预留说明

**二级眼科医院通常接入当地医保。医保结算会彻底改变多退少补的计算：**

```
无医保：
  应收 12,800  预交 10,000  →  患者补交 2,800

有医保（职工医保住院报销 85%）：
  应收 12,800
  医保统筹支付 9,860   ← 医保基金出
  个人自付 2,940       ← 患者出
  预交 10,000
  → 患者退 7,060
```

**M16-03 的预留设计：**

| 预留点 | 说明 |
|---|---|
| `m16_inpatient_settlement.insurance_amount` | 医保统筹支付金额（预留字段） |
| `m16_inpatient_settlement.self_pay_amount` | 个人自付金额（预留字段） |
| `m16_inpatient_settlement.settle_mode` | `SELF_PAY` 自费 / `INSURANCE` 医保 / `COMMERCIAL` 商保 |
| 接口 `POST /internal/v1/m16/inpatient/insurance-settle` | 医保结算入账（待 M21 接入） |

**当前实现：** 仅实现 `SELF_PAY`，其他模式返回 54876 `医保结算暂未开通`。

## 3. 业务模型

### 3.1 预交金池模型

```
┌────────────────────────────────────────────────────────────────┐
│  预交金账户（一个住院号一个账户）                                  │
│                                                                  │
│  住院号 ZY20261021001  患者 王五                                   │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │  累计充值    10,000.00                                     │  │
│  │  累计退还     2,000.00                                     │  │
│  │  冻结金额         0.00                                     │  │
│  │  ─────────────────────────────                             │  │
│  │  可用余额     8,000.00                                     │  │
│  └──────────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────────┘

余额计算：
  available_balance = total_deposit - total_refund - frozen_amount
```

**为什么要冻结：**

| 场景 | 处理 |
|---|---|
| 出院结算进行中 | 冻结全部余额，防止另一个窗口同时退还 |
| 转科结算 | 冻结，结算完成解冻 |
| 预交金异常审查 | 主管冻结，需授权解冻 |

### 3.2 预交金状态机

```
    ┌─────────┐  充值   ┌─────────┐  出院退余额  ┌──────────┐
    │  NONE   ├────────►│ ACTIVE  ├─────────────►│  CLOSED  │
    │ 无账户   │         │ 正常    │              │ 已结清    │
    └─────────┘         └────┬────┘              └──────────┘
                             │
                       冻结（结算中/审查）
                             │
                             ▼
                        ┌──────────┐
                        │  FROZEN  │
                        │ 已冻结    │
                        └────┬─────┘
                             │ 解冻
                             ▼
                        ┌─────────┐
                        │ ACTIVE  │
                        └─────────┘
```

### 3.3 住院费用记账模型

**核心原则：一条医嘱 = 一条记账（幂等）。**

```
M05 医嘱执行完成
      │
      ▼
POST /internal/v1/m16/inpatient/charge
{
  "admission_id": 88001,
  "source_type": "ORDER",
  "source_id": 55021,          ← 医嘱ID，幂等键
  "charge_item_code": "310101",
  "charge_item_name": "床位费（三等）",
  "quantity": 1,
  "unit_price": 45.00,
  "charge_date": "2026-10-21"
}
      │
      ▼
┌─────────────────────────────────────────┐
│ 幂等检查：source_type + source_id 是否已记账？│
│   已记账 → 返回原记录（幂等）              │
│   未记账 → 写入 m16_inpatient_charge       │
└─────────────────────────────────────────┘
      │
      ▼
返回 charge_id, charge_no, cumulative_amount
```

**记账幂等键：** `uk_m16_inpcharge_source (source_type, source_id) WHERE status = 'NORMAL'`

**为什么必须幂等：** M05 可能重试、网络可能超时、MQ 可能重复投递。**重复记账 = 多收患者钱 = 医患纠纷。**

### 3.4 费用冲销模型

```
原记账：charge_id=1001, 金额 260.00, status=NORMAL
   │
   │  M05 作废医嘱
   ▼
冲销：创建 charge_id=1050, 金额 -260.00, status=REVERSAL,
      reversal_of_charge_id=1001
   │
   ▼
原记录：charge_id=1001, status=REVERSED
```

**为什么用"红冲"而不是"删除"：**

| 原因 | 说明 |
|---|---|
| 审计要求 | 住院费用必须可追溯，任何变动留痕 |
| 对账要求 | 财务需要看到"记了多少、冲了多少" |
| 法规要求 | 《医疗机构财务会计制度》要求费用变动留痕 |

### 3.5 住院结算模型

```
出院结算 = 
    住院费用累计（NORMAL − REVERSAL）
  − 预交金累计充值
  + 预交金累计退还
  
  结果 > 0  →  患者补交
  结果 < 0  →  患者退还
  结果 = 0  →  结清
```

### 3.6 中途结算模型

**场景：** 患者住院 45 天，医院要求每 30 天结算一次（或医保要求）。

```
账期 1：2026-10-01 ~ 2026-10-30  费用 8,200  预交 10,000  → 无需补交
账期 2：2026-10-31 ~ 2026-11-14  费用 4,600  预交金余额 1,800 → 补交 2,800
```

**实现：**

| 字段 | 说明 |
|---|---|
| `settle_type` | `DISCHARGE` 出院 / `INTERIM` 中途 / `TRANSFER` 转科 |
| `period_start` / `period_end` | 账期区间 |
| `period_no` | 第几期 |
| 费用归属 | 按 `charge_date` 落在账期内 |

**中途结算后：** 已结算的费用标记 `settled_settlement_id`，后续结算不再重复计入。

### 3.7 日间手术结算模型（骨架）

**日间手术特点：** 当天入院、当天手术、当天或次日出院，流程快，金额确定。

```
术前：门诊确定手术方式与费用 → 患者知情
   │
   ▼
当日入院
   │
   ├── 方式 A：先交预交金（与住院一致）
   └── 方式 B：不交预交金，术后直接结算
   │
   ▼
手术完成 → 费用记账
   │
   ▼
当日/次日出院 → 结算 → 多退少补
```

**M06 需要提供的：**

| 编号 | 内容 | 状态 |
|---|---|---|
| S-01 | 日间手术预约 ID（`day_surgery_id`） | ⏳ 待 M06 |
| S-02 | 手术方式对应的费用套餐 | ⏳ 待 M06/M01-07 |
| S-03 | 是否采用预交金模式 | ⏳ 待 M06 参数 |
| S-04 | 结算完成回调 | ⏳ 待 M06 |

**当前实现：** 复用住院结算的全部结构与接口，仅通过 `admission_type = 'DAY_SURGERY'` 区分。不额外造表。

### 3.8 预交金预警模型

```
预交金余额 < 已发生费用 × 预警比例（默认 20%）
   →  触发预警
   →  推送病区护士站（M08）与住院医生
```

**预警分级：**

| 级别 | 条件 | 处理 |
|---|---|---|
| 提示 | 余额 < 费用 × 20% | 护士站提示 |
| 催缴 | 余额 ≤ 0 | 短信通知患者家属 + 病区催缴 |
| 停药 | 余额 < −2,000（可配） | 仅提示，医生决定是否停药 |

> **注意：不得因欠费停止抢救与必要治疗。** 系统只做提示，不做强制停药。

### 3.9 结算与收付款的关系

```
出院结算（M16-03）
      │
      ├── 需要补交 → 调 M16-02 收银台（或 M16-05 直连）
      │                  → 支付成功 → M16-01 on-paid → M16-03 确认结算
      │
      └── 需要退还 → 调 M16-08 退费
                         → 退费成功 → M16-03 确认结算
```

**关键：结算动作本身不产生现金流，现金流由 M16-02/M16-08 产生。M16-03 只负责"算清楚"和"记账"。**

```python
# app/services/m16/deposit_service.py
"""预交金服务：充值 / 退还 / 冻结 / 余额"""
from datetime import date, datetime
from decimal import Decimal, ROUND_HALF_UP
from typing import Optional, List

from sqlalchemy import select, func
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.m16.inpatient import (
    M16DepositAccount, M16Deposit, M16InpatientCharge,
)
from app.core.exceptions import BizException
from app.core.redis import redis_client
from app.clients.m03_client import M03Client


CENT = Decimal("0.01")
MAX_SINGLE_DEPOSIT = Decimal("50000.00")
MAX_TOTAL_DEPOSIT = Decimal("200000.00")
DEFAULT_WARN_RATIO = Decimal("0.20")


def money(value) -> Decimal:
    return Decimal(str(value)).quantize(CENT, rounding=ROUND_HALF_UP)


class DepositService:
    """预交金池管理"""

    def __init__(self, db: AsyncSession):
        self.db = db
        self.m03 = M03Client()

    # ---------- 收取预交金 ----------
    async def create_deposit(self, payload, user,
                             trace_id: str = "") -> dict:
        """收预交金

        流程：
          ① 校验金额上限
          ② 锁定账户（SELECT FOR UPDATE）
          ③ 校验账户状态
          ④ 建预交金记录
          ⑤ 更新账户累计
          ⑥ 调用支付通道（M16-05）
          ⑦ 打印收据
        """
        amount = money(payload.amount)

        if amount <= 0:
            raise BizException(54867, "充值金额必须大于 0")

        if amount > MAX_SINGLE_DEPOSIT:
            raise BizException(
                54868,
                f"单次充值金额不得超过 {MAX_SINGLE_DEPOSIT} 元")

        account = await self._lock_account(payload.admission_id)

        if account.status == "CLOSED":
            raise BizException(54870, "预交金账户已结清，不可继续充值")

        if account.status == "FROZEN":
            raise BizException(
                54871, f"预交金账户已冻结：{account.frozen_reason or '未知原因'}")

        new_total = money(account.total_deposit + amount)

        if new_total > MAX_TOTAL_DEPOSIT:
            raise BizException(
                54869,
                f"累计预交金不得超过 {MAX_TOTAL_DEPOSIT} 元，"
                f"当前已交 {account.total_deposit} 元")

        deposit_no = await self._next_deposit_no()

        deposit = M16Deposit(
            deposit_no=deposit_no,
            admission_id=payload.admission_id,
            admission_no=payload.admission_no,
            patient_id=payload.patient_id,
            deposit_type="DEPOSIT",
            amount=amount,
            balance_before=money(
                account.total_deposit - account.total_refund
                - account.frozen_amount),
            balance_after=money(
                account.total_deposit - account.total_refund
                - account.frozen_amount + amount),
            payment_method=payload.payment_method,
            pay_status="SUCCESS",
            cashier_id=user.staff_id,
            cashier_name=user.real_name,
            received_at=datetime.now(),
            remark=payload.remark,
            trace_id=trace_id,
        )
        self.db.add(deposit)
        await self.db.flush()

        # 更新账户（原子加）
        account.total_deposit = new_total
        account.available_balance = money(
            new_total - account.total_refund - account.frozen_amount)
        account.last_deposit_at = deposit.received_at
        await self.db.flush()

        return {
            "deposit_id": deposit.id,
            "deposit_no": deposit_no,
            "admission_id": payload.admission_id,
            "admission_no": payload.admission_no,
            "amount": float(amount),
            "payment_method": payload.payment_method,
            "received_at": deposit.received_at.isoformat(),
            "receipt_no": await self._next_receipt_no(),
            "account": self._account_dict(account),
        }

    # ---------- 退还预交金 ----------
    async def refund(self, deposit_id: int, payload, user,
                     trace_id: str = "") -> dict:
        """退还预交金

        只允许退还「可用余额」范围内的金额。
        退还本身走 M16-08 的退费通道（原路退回）。
        """
        amount = money(payload.amount)

        if amount <= 0:
            raise BizException(54867, "退还金额必须大于 0")

        original = (await self.db.execute(
            select(M16Deposit).where(M16Deposit.id == deposit_id)
        )).scalar_one_or_none()

        if not original:
            raise BizException(40001, "预交金记录不存在")

        account = await self._lock_account(original.admission_id)

        if account.status == "FROZEN":
            raise BizException(54871, "预交金账户已冻结，不可退还")

        if amount > account.available_balance:
            raise BizException(
                54872,
                f"退还金额 {amount} 元超过可用余额 "
                f"{account.available_balance} 元")

        # 退还审批（走 M16-08）
        if not payload.approval_id:
            raise BizException(54873, "预交金退还必须经过审批")

        deposit_no = await self._next_deposit_no()

        refund = M16Deposit(
            deposit_no=deposit_no,
            admission_id=original.admission_id,
            admission_no=original.admission_no,
            patient_id=original.patient_id,
            deposit_type="REFUND",
            amount=-amount,
            balance_before=account.available_balance,
            balance_after=money(account.available_balance - amount),
            refund_of_deposit_id=original.id,
            payment_method=original.payment_method,
            refund_channel=payload.refund_channel,
            pay_status="SUCCESS",
            cashier_id=user.staff_id,
            cashier_name=user.real_name,
            received_at=datetime.now(),
            remark=payload.reason,
            approval_id=payload.approval_id,
            trace_id=trace_id,
        )
        self.db.add(refund)
        await self.db.flush()

        account.total_refund = money(account.total_refund + amount)
        account.available_balance = money(
            account.total_deposit - account.total_refund
            - account.frozen_amount)
        await self.db.flush()

        return {
            "refund_id": refund.id,
            "refund_no": deposit_no,
            "deposit_id": deposit_id,
            "amount": float(amount),
            "refund_channel": payload.refund_channel,
            "refund_status": "SUCCESS",
            "refunded_at": refund.received_at.isoformat(),
            "account": self._account_dict(account),
        }

    # ---------- 账户锁定 ----------
    async def _lock_account(self, admission_id: int) -> M16DepositAccount:
        """锁定账户行（SELECT FOR UPDATE）

        必须加行锁，否则两个窗口同时充值/退还时，
        total_deposit 会丢更新。
        """
        account = (await self.db.execute(
            select(M16DepositAccount)
            .where(M16DepositAccount.admission_id == admission_id)
            .with_for_update()
        )).scalar_one_or_none()

        if account:
            return account

        # 首次充值，自动建账户
        account = M16DepositAccount(
            admission_id=admission_id,
            status="ACTIVE",
            total_deposit=Decimal("0.00"),
            total_refund=Decimal("0.00"),
            frozen_amount=Decimal("0.00"),
            available_balance=Decimal("0.00"),
            accumulated_charge=Decimal("0.00"),
        )
        self.db.add(account)
        await self.db.flush()
        return account

    # ---------- 余额查询 ----------
    async def balance(self, admission_id: int) -> dict:
        """预交金余额（内部契约 API-20）"""
        account = (await self.db.execute(
            select(M16DepositAccount)
            .where(M16DepositAccount.admission_id == admission_id)
        )).scalar_one_or_none()

        if not account:
            return {
                "admission_id": admission_id,
                "total_deposit": 0.0,
                "total_refund": 0.0,
                "frozen_amount": 0.0,
                "available_balance": 0.0,
                "accumulated_charge": 0.0,
                "balance_gap": 0.0,
                "balance_status": "NONE",
                "need_warn": False,
            }

        gap = money(account.available_balance - account.accumulated_charge)
        warn_threshold = money(account.accumulated_charge * DEFAULT_WARN_RATIO)

        if account.available_balance <= 0:
            status = "INSUFFICIENT"
        elif account.available_balance < warn_threshold:
            status = "WARNING"
        else:
            status = "SUFFICIENT"

        return {
            "admission_id": admission_id,
            "admission_no": account.admission_no,
            "patient_id": account.patient_id,
            "total_deposit": float(account.total_deposit),
            "total_refund": float(account.total_refund),
            "frozen_amount": float(account.frozen_amount),
            "available_balance": float(account.available_balance),
            "accumulated_charge": float(account.accumulated_charge),
            "balance_gap": float(gap),
            "balance_status": status,
            "warn_threshold": float(warn_threshold),
            "need_warn": status in ("INSUFFICIENT", "WARNING"),
        }

    # ---------- 编号 ----------
    async def _next_deposit_no(self) -> str:
        day = date.today().strftime("%Y%m%d")
        key = f"m16:inpatient:depseq:{day}"
        seq = await redis_client.incr(key)

        if seq == 1:
            await redis_client.expire(key, 86400 * 3)

        return f"YJ{day}{seq:04d}"

    async def _next_receipt_no(self) -> str:
        day = date.today().strftime("%Y%m%d")
        key = f"m16:inpatient:rcptseq:{day}"
        seq = await redis_client.incr(key)

        if seq == 1:
            await redis_client.expire(key, 86400 * 3)

        return f"YJQ{day}{seq:04d}"

    @staticmethod
    def _account_dict(account: M16DepositAccount) -> dict:
        return {
            "total_deposit": float(account.total_deposit),
            "total_refund": float(account.total_refund),
            "frozen_amount": float(account.frozen_amount),
            "available_balance": float(account.available_balance),
        }
```

```python
class InpatientService:
    """住院费用记账"""

    def __init__(self, db: AsyncSession):
        self.db = db
        self.m05 = M05Client()

    # ---------- 记账（核心） ----------
    async def charge(self, payload, trace_id: str = "") -> dict:
        """住院费用记账（内部契约 API-18）

        幂等键：source_type + source_id
          · M05 重试、MQ 重复投递都可能重复调用

        # ① 幂等检查
        existing = (await self.db.execute(
            select(M16InpatientCharge).where(
                M16InpatientCharge.source_type == payload.source_type,
                M16InpatientCharge.source_id == payload.source_id,
                M16InpatientCharge.status == "NORMAL",
                M16InpatientCharge.is_deleted == False,
            )
        )).scalar_one_or_none()

        if existing:
            account = await self._get_account(payload.admission_id)
            return {
                "charge_id": existing.id,
                "charge_no": existing.charge_no,
                "admission_id": existing.admission_id,
                "amount": float(existing.amount),
                "status": existing.status,
                "cumulative_amount": float(
                    account.accumulated_charge if account else 0),
                "deposit_balance": float(
                    account.available_balance if account else 0),
                "is_idempotent": True,
                "charged_at": existing.charged_at.isoformat(),
            }

        # ② 校验住院存在（M05 可用时；不可用则降级）
        try:
            admission = await self.m05.get_admission(payload.admission_id)
            if not admission:
                raise BizException(54887, "住院号不存在")
        except BizException:
            raise
        except Exception:
            # M05 未就绪：记录告警但不阻断
            pass

        # ③ 计算金额（行级先舍入）
        amount = money(
            Decimal(str(payload.unit_price)) * Decimal(str(payload.quantity)))

        if amount <= 0:
            raise BizException(40001, "记账金额必须大于 0")

        charge_no = await self._next_charge_no()

        charge = M16InpatientCharge(
            charge_no=charge_no,
            admission_id=payload.admission_id,
            admission_no=payload.admission_no,
            patient_id=payload.patient_id,
            source_type=payload.source_type,
            source_id=payload.source_id,
            charge_item_code=payload.charge_item_code,
            charge_item_name=payload.charge_item_name,
            charge_item_spec=payload.charge_item_spec,
            charge_category=payload.charge_category,
            quantity=Decimal(str(payload.quantity)),
            unit_price=Decimal(str(payload.unit_price)),
            amount=amount,
            charge_date=payload.charge_date,
            dept_id=payload.dept_id,
            exec_dept_id=payload.exec_dept_id,
            status="NORMAL",
            charged_at=datetime.now(),
            operator_id=payload.operator_id,
            operator_name=payload.operator_name,
            remark=payload.remark,
            trace_id=trace_id,
        )
        self.db.add(charge)
        await self.db.flush()

        # ④ 更新账户累计费用（行锁）
        account = await self._lock_account(payload.admission_id)

        if account:
            account.accumulated_charge = money(
                account.accumulated_charge + amount)

        await self.db.flush()

        return {
            "charge_id": charge.id,
            "charge_no": charge_no,
            "admission_id": payload.admission_id,
            "amount": float(amount),
            "status": "NORMAL",
            "cumulative_amount": float(
                account.accumulated_charge if account else amount),
            "deposit_balance": float(
                account.available_balance if account else 0),
            "is_idempotent": False,
            "charged_at": charge.charged_at.isoformat(),
        }

    # ---------- 冲销 ----------
    async def reverse(self, payload, trace_id: str = "") -> dict:
        """费用冲销：红冲而非删除"""
        original = (await self.db.execute(
            select(M16InpatientCharge)
            .where(M16InpatientCharge.id == payload.charge_id)
            .with_for_update()
        )).scalar_one_or_none()

        if not original:
            raise BizException(54889, "记账记录不存在")

        if original.status == "REVERSED":
            raise BizException(54888, "该记账记录已冲销，不可重复冲销")

        if original.status == "REVERSAL":
            raise BizException(40001, "冲销记录本身不可被冲销")

        charge_no = await self._next_charge_no()

        reversal = M16InpatientCharge(
            charge_no=charge_no,
            admission_id=original.admission_id,
            admission_no=original.admission_no,
            patient_id=original.patient_id,
            source_type=original.source_type,
            source_id=original.source_id,
            charge_item_code=original.charge_item_code,
            charge_item_name=original.charge_item_name,
            charge_item_spec=original.charge_item_spec,
            charge_category=original.charge_category,
            quantity=-original.quantity,
            unit_price=original.unit_price,
            amount=-original.amount,
            charge_date=original.charge_date,
            dept_id=original.dept_id,
            exec_dept_id=original.exec_dept_id,
            status="REVERSAL",
            reversal_of_charge_id=original.id,
            charged_at=datetime.now(),
            operator_id=payload.operator_id,
            operator_name=payload.operator_name,
            remark=payload.reverse_reason,
            trace_id=trace_id,
        )
        self.db.add(reversal)

        original.status = "REVERSED"
        original.reversed_at = datetime.now()
        original.reversed_by = payload.operator_id
        await self.db.flush()

        account = await self._lock_account(original.admission_id)

        if account:
            account.accumulated_charge = money(
                account.accumulated_charge - original.amount)

        await self.db.flush()

        return {
            "reversal_charge_id": reversal.id,
            "reversal_charge_no": charge_no,
            "original_charge_id": original.id,
            "original_status": "REVERSED",
            "reversal_amount": float(-original.amount),
            "cumulative_amount": float(
                account.accumulated_charge if account else 0),
            "deposit_balance": float(
                account.available_balance if account else 0),
        }

    # ---------- 费用汇总 ----------
    async def charge_summary(self, admission_id: int,
                             date_from: Optional[str] = None,
                             date_to: Optional[str] = None) -> dict:
        """按费用类别汇总（含冲销）"""
        stmt = select(
            M16InpatientCharge.charge_category,
            func.coalesce(func.sum(M16InpatientCharge.amount), 0),
            func.count(M16InpatientCharge.id),
        ).where(
            M16InpatientCharge.admission_id == admission_id,
            M16InpatientCharge.is_deleted == False,
        )

        if date_from:
            stmt = stmt.where(M16InpatientCharge.charge_date >= date_from)

        if date_to:
            stmt = stmt.where(M16InpatientCharge.charge_date <= date_to)

        rows = (await self.db.execute(
            stmt.group_by(M16InpatientCharge.charge_category)
        )).all()

        net_total = sum(Decimal(str(r[1])) for r in rows)
        by_category = []

        for category, amount, cnt in rows:
            amt = money(amount)
            by_category.append({
                "category": category,
                "category_name": self._category_name(category),
                "amount": float(amt),
                "count": cnt,
                "percentage": round(
                    float(amt / net_total * 100) if net_total else 0, 2),
            })

        gross = money(sum(
            r[1] for r in rows if Decimal(str(r[1])) > 0))
        reversal = money(abs(sum(
            r[1] for r in rows if Decimal(str(r[1])) < 0)))

        return {
            "admission_id": admission_id,
            "total_amount": float(gross),
            "reversal_amount": float(reversal),
            "net_amount": float(net_total),
            "by_category": by_category,
        }

    # ---------- 账户 ----------
    async def _get_account(self, admission_id: int):
        return (await self.db.execute(
            select(M16DepositAccount)
            .where(M16DepositAccount.admission_id == admission_id)
        )).scalar_one_or_none()

    async def _lock_account(self, admission_id: int):
        return (await self.db.execute(
            select(M16DepositAccount)
            .where(M16DepositAccount.admission_id == admission_id)
            .with_for_update()
        )).scalar_one_or_none()

    # ---------- 编号 ----------
    async def _next_charge_no(self) -> str:
        day = date.today().strftime("%Y%m%d")
        key = f"m16:inpatient:chargeseq:{day}"
        seq = await redis_client.incr(key)

        if seq == 1:
            await redis_client.expire(key, 86400 * 3)

        return f"ZYJL{day}{seq:04d}"

    @staticmethod
    def _category_name(category: str) -> str:
        return {
            "BED": "床位费",
            "CLINIC": "诊查费",
            "NURSING": "护理费",
            "EXAM": "检查费",
            "LAB": "检验费",

            "ANESTHESIA": "麻醉费",
            "DRUG": "西药费",

            "TREATMENT": "治疗费",

        }.get(category, category)
```

```python
from datetime import datetime

from typing import Optional

from sqlalchemy import select, func

CENT = Decimal("0.01")


def money(value) -> Decimal:
    return Decimal(str(value)).quantize(CENT, rounding=ROUND_HALF_UP)


class InpatientSettleService:
    """出院结算：算清楚，然后交给收付款通道"""

    def __init__(self, db: AsyncSession):
        self.db = db
        self.charge_svc = InpatientService(db)
        self.deposit_svc = DepositService(db)

    # ---------- 试算 ----------
    async def preview(self, payload) -> dict:
        """试算：不落库，只算差额"""
        summary = await self.charge_svc.charge_summary(
            payload.admission_id, payload.period_start, payload.period_end)
        account = await self.deposit_svc.balance(payload.admission_id)

        net = Decimal(str(summary["net_amount"]))
        available = Decimal(str(account["available_balance"]))
        settle_amount = money(net - available)

        if settle_amount > 0:
            direction = "PAYABLE"
            direction_text = "患者应补交"
        elif settle_amount < 0:
            direction = "REFUNDABLE"
            direction_text = "患者应退还"
        else:
            direction = "EVEN"
            direction_text = "无需补退"

        warnings = []

        if summary["reversal_amount"] > 0:
            warnings.append({
                "code": "W-01",
                "message": f"本期存在冲销记录，冲销金额 "
                           f"{summary['reversal_amount']} 元",
            })

        if net <= 0:
            raise BizException(54884, "账期内无费用，无需结算")

        return {
            "admission_id": payload.admission_id,
            "settle_type": payload.settle_type,
            "period_start": payload.period_start,
            "period_end": payload.period_end,
            "total_amount": summary["total_amount"],
            "reversal_amount": summary["reversal_amount"],
            "net_amount": float(net),
            "deposit_total": account["total_deposit"],
            "deposit_refund": account["total_refund"],
            "deposit_available": float(available),
            "settle_amount": float(abs(settle_amount)),
            "settle_signed_amount": float(settle_amount),
            "settle_direction": direction,
            "settle_direction_text": direction_text,
            "by_category": summary["by_category"],
            "warnings": warnings,
        }

    # ---------- 执行结算 ----------
    async def execute(self, payload, user, trace_id: str = "") -> dict:
        """执行结算

        顺序：
          ① 幂等检查（同一住院同一账期只能结算一次）
          ② 试算
          ③ 冻结预交金
          ④ 建结算单（M16-01）
          ⑤ 处理补交/退还
          ⑥ 更新结算记录为 SETTLED
          ⑦ 解冻 + 回写 M05
        """
        existing = (await self.db.execute(
            select(M16InpatientSettlement).where(
                M16InpatientSettlement.admission_id == payload.admission_id,
                M16InpatientSettlement.settle_type == payload.settle_type,
                M16InpatientSettlement.period_start == payload.period_start,
                M16InpatientSettlement.period_end == payload.period_end,
                M16InpatientSettlement.is_deleted == False,
            )
        )).scalar_one_or_none()

        if existing:
            if existing.status == "SETTLED":
                raise BizException(
                    54878,
                    f"该账期已结算（结算单 {existing.settlement_no}），不可重复结算")

        preview = await self.preview(payload)

        settle_amount = Decimal(str(preview["settle_amount"]))
        direction = preview["settle_direction"]

        # 冻结预交金（防止另一窗口同时退还）
        account = (await self.db.execute(
            select(M16DepositAccount)
            .where(M16DepositAccount.admission_id == payload.admission_id)
            .with_for_update()
        )).scalar_one_or_none()

        if account:
            if account.status == "FROZEN":
                raise BizException(54871, "预交金账户已冻结，不可结算")

            account.frozen_amount = money(
                account.frozen_amount + account.available_balance)
            account.available_balance = Decimal("0.00")
            account.status = "FROZEN"
            account.frozen_reason = f"结算中：账期 {payload.period_start} ~ {payload.period_end}"
            await self.db.flush()

        try:
            settlement_no = await self._next_settlement_no()

            settlement = M16InpatientSettlement(
                settlement_no=settlement_no,
                admission_id=payload.admission_id,
                admission_no=preview.get("admission_no", ""),
                patient_id=payload.patient_id,
                settle_type=payload.settle_type,
                period_no=await self._next_period_no(payload.admission_id),
                period_start=payload.period_start,
                period_end=payload.period_end,
                total_amount=Decimal(str(preview["net_amount"])),
                reversal_amount=Decimal(str(preview["reversal_amount"])),
                net_amount=Decimal(str(preview["net_amount"])),
                deposit_amount=Decimal(str(preview["deposit_available"])),
                settle_amount=settle_amount,
                settle_direction=direction,
                status="SETTLING",
                created_by=user.staff_id,
                trace_id=trace_id,
            )
            self.db.add(settlement)
            await self.db.flush()

            # 处理补交：需要收钱
            paid_amount = Decimal("0.00")
            refund_amount = Decimal("0.00")

            if direction == "PAYABLE":
                received = money(payload.received_amount or 0)

                if received < settle_amount:
                    raise BizException(
                        54879,
                        f"应补交 {settle_amount} 元，实收 {received} 元，尚未收齐")

                paid_amount = settle_amount
                settlement.payment_method = payload.payment_method
                settlement.payment_no = await self._create_payment(
                    payload, settle_amount, direction)

            elif direction == "REFUNDABLE":
                refund_amount = money(abs(settle_amount))
                settlement.refund_no = await self._create_refund(
                    payload, refund_amount)

            settlement.paid_amount = paid_amount
            settlement.refund_amount = refund_amount
            settlement.status = "SETTLED"
            settlement.settled_at = datetime.now()
            settlement.settled_by = user.staff_id
            settlement.settled_by_name = user.real_name
            await self.db.flush()

            # 解冻
            if account:
                account.frozen_amount = Decimal("0.00")
                account.available_balance = money(
                    account.total_deposit - account.total_refund)

                if payload.settle_type == "DISCHARGE":
                    account.status = "CLOSED"
                    account.closed_at = datetime.now()

                await self.db.flush()

            return {
                "settlement_id": settlement.id,
                "settlement_no": settlement_no,
                "admission_id": payload.admission_id,
                "settle_type": payload.settle_type,
                "period_no": settlement.period_no,
                "total_amount": float(settlement.net_amount),
                "deposit_amount": float(settlement.deposit_amount),
                "settle_amount": float(abs(settle_amount)),
                "settle_direction": direction,
                "paid_amount": float(paid_amount),
                "refund_amount": float(refund_amount),
                "status": "SETTLED",
                "settled_at": settlement.settled_at.isoformat(),
                "account": {
                    "total_deposit": float(account.total_deposit),
                    "total_refund": float(account.total_refund),
                    "frozen_amount": float(account.frozen_amount),
                    "available_balance": float(account.available_balance),
                } if account else None,
                "rewrites": [],
            }
        except Exception:
            # 结算失败，解冻
            if account:
                account.frozen_amount = Decimal("0.00")
                account.available_balance = money(
                    account.total_deposit - account.total_refund)
                account.status = "ACTIVE"
                await self.db.flush()

            raise
```

```python
                            "patient_name": acc.patient_name or "",
                            "admission_no": acc.admission_no or "",
                            "gap": abs(info["balance_gap"]),

                    })
                except Exception:
                    pass

    return {"warned": warned, "critical": critical}


@shared_task
def monthly_inpatient_report_task(year_month: str = None):
    """住院收入月报（每月 1 日 02:30）"""
    import asyncio
    return asyncio.run(_monthly_report(year_month))


async def _monthly_report(year_month: str = None):
    from datetime import date
    from sqlalchemy import select, func
    from app.core.database import AsyncSessionLocal
    from app.models.m16.inpatient import (
        M16InpatientCharge, M16InpatientSummary,
    )

    today = date.today()

    if year_month:
        y, m = year_month.split("-")
        first = date(int(y), int(m), 1)
    else:
        first = today.replace(day=1)

    if first.month == 12:
        next_first = date(first.year + 1, 1, 1)
    else:
        next_first = date(first.year, first.month + 1, 1)

    async with AsyncSessionLocal() as db:
        rows = (await db.execute(
            select(
                M16InpatientCharge.charge_category,
                M16InpatientCharge.dept_id,
                func.count(M16InpatientCharge.id),
                func.sum(M16InpatientCharge.amount),
            )
            .where(
                M16InpatientCharge.charge_date >= first,
                M16InpatientCharge.charge_date < next_first,
                M16InpatientCharge.is_deleted == False,
            )
            .group_by(M16InpatientCharge.charge_category,
                      M16InpatientCharge.dept_id)
        )).all()

        for category, dept_id, cnt, amount in rows:
            db.add(M16InpatientSummary(
                stat_month=first,
                dept_id=dept_id,
                charge_category=category,
                charge_count=cnt,
                amount=amount,
            ))

        await db.commit()

    return {"month": str(first), "rows": len(rows)}
```

```python
@shared_task
def reconcile_deposit_balance_task():
    """每日核对预交金账户余额

    账户表的 available_balance 是累加出来的，万一某次事务失败
    会导致账面不平。这个任务每天重算一遍，发现不一致就修正并告警。
    """
    import asyncio
    return asyncio.run(_reconcile())


async def _reconcile():
    from datetime import datetime
    from decimal import Decimal
    from sqlalchemy import select, func
    from app.core.database import AsyncSessionLocal
    from app.models.m16.inpatient import M16DepositAccount, M16Deposit

    fixed = 0
    mismatched = []

    async with AsyncSessionLocal() as db:
        accounts = (await db.execute(
            select(M16DepositAccount).where(
                M16DepositAccount.is_deleted == False)
        )).scalars().all()

        for acc in accounts:
            row = (await db.execute(
                select(func.coalesce(func.sum(M16Deposit.amount), 0))
                .where(
                    M16Deposit.admission_id == acc.admission_id,
                    M16Deposit.pay_status == "SUCCESS",
                    M16Deposit.is_deleted == False,
                )
            )).scalar()

            real = Decimal(str(row or 0))
            computed = Decimal(str(acc.total_deposit)) - Decimal(
                str(acc.total_refund))
            expected_available = computed - Decimal(str(acc.frozen_amount))

            if expected_available != acc.available_balance:
                mismatched.append({
                    "admission_id": acc.admission_id,
                    "account_balance": float(acc.available_balance),
                    "computed_balance": float(expected_available),
                    "delta": float(
                        expected_available - acc.available_balance),
                })
                acc.available_balance = expected_available
                acc.last_reconciled_at = datetime.now()
                fixed += 1

        await db.commit()

    return {"checked": len(accounts), "fixed": fixed,
            "mismatches": mismatched[:50]}
```
