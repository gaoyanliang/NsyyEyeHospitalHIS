## 1. 模块概述

### 1.1 模块定位

M16-07 负责把「收到的钱」变成「合法的税务凭证」。它处在资金流的末端、税务数据的源头。

```
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│  M16-01  │   │  M16-02  │   │  M16-05  │   │  M16-08  │
│ 结算单   │   │ 收银     │   │ 支付     │   │ 退费     │
└────┬─────┘   └────┬─────┘   └────┬─────┘   └────┬─────┘
     │ 已收款        │ 实收和找零    │ 交易流水号    │ 退费单
     └──────────────┴──────┬───────┴──────────────┘
                           ▼
                 ┌─────────────────────┐
                 │    M16-07 发票       │
                 │  ┌───────────────┐  │
                 │  │ 开票判定       │  │
                 │  │ 号码分配       │  │
                 │  │ 税控/平台开具  │  │
                 │  │ 版式文件/打印  │  │
                 │  │ 红冲/换开      │  │
                 │  │ 交付与查验     │  │
                 │  └───────────────┘  │
                 └──────────┬──────────┘
                            │
         ┌──────────────────┼──────────────────┐
         ▼                  ▼                  ▼
  ┌────────────┐    ┌────────────┐    ┌────────────┐
  │  电子发票   │    │  纸质发票   │    │  票据台账   │
  │  PDF/OFD   │    │ 打印/重打   │    │ 领用/核销   │
  └────────────┘    └────────────┘    └────────────┘
                            │
                            ▼
                     ┌────────────┐
                     │   M17 财务  │
                     │  税务申报   │
                     └────────────┘
```

**一句话定位：** M16-07 只管「这张钱该开什么票、票开出来了没有、开错了怎么改、纸质票用到哪了」，至于「收了多少钱」归 M16-02，「钱到没到账」归 M16-05，「钱退不退」归 M16-08。

### 1.2 为什么独立成子模块

| 若并入其他子模块 | 产生的问题 |
|---|---|
| 并入 M16-02 收银 | 收银是「一人一窗口一时刻」的，发票是「跨窗口、跨班次、跨天、甚至跨月」的。电子发票「今天收钱、三天后患者扫码开票」是常态，收银员早已交班。发票生命周期必须独立于收银员会话 |
| 并入 M16-05 支付 | 支付管「钱」，发票管「票」。现金支付不需要第三方通道，但必须开票；微信支付成功了但发票可以是「暂不开、后补开」。混在一起会让支付状态机被发票状态污染 |
| 并入 M16-08 退费 | 退费只产生红冲需求，红冲是发票的动作。且正常业务里 90% 的发票与退费无关 |
| 并入 M01-06 主数据 | M01-06 定义「税率多少、票种有几种、号码段范围」这类规则，是**静态配置**；M16-07 是**动态业务**——每一张票都有号码、有状态、有税控回执、有交付记录 |
| 不独立、散落各处 | 税务稽查要「某日全部开票记录」，散落在收银、住院结算、视光三个地方就查不全。发票号一旦重复或跳号，税务上是重大问题 |

**核心判断：发票是法律凭证，不是业务附属品。** 它的生命周期、状态机、号码管理、留痕要求都由税法而非业务流程决定，因此必须有自己的边界。

### 1.4 概念辨析

**发票 vs 收据 vs 小票**

| 概念 | 定义 | 法律效力 | 归属 |
|---|---|---|---|
| 发票 | 税务机关监制的税务凭证，有发票代码与发票号码 | 可报销、可抵扣、可入账 | M16-07 |
| 收费票据（财政票据） | 非营利性医疗机构使用的财政监制票据 | 可报销、不可抵扣 | M16-07（票种 `FINANCE`） |
| 收据 | 医院自制的收款证明，无税务/财政监制 | 仅供内部核对 | M16-02（小票） |
| 小票 | 收银机打的交易明细条 | 无 | M16-02 |

> 二级眼科医院通常已转为企业主体，开具**医疗收费电子发票**（增值税普通发票，医疗服务免税）。少数仍保留非营利性执照的院区使用财政票据。M16-07 两种都支持，由 `md_invoice_config.invoice_type` 决定。

**蓝票 vs 红票**

| 概念 | 方向 | 产生原因 | 是否冲减收入 |
|---|---|---|---|
| 蓝票（正常票） | 正数 | 收款 | 否（增加） |
| 红票（红字发票） | 负数 | 退费、开票有误、折扣后开票、销售折让 | 是 |

**作废 vs 红冲 —— 本子模块最容易混淆的一对概念**

| 维度 | 作废（VOID） | 红冲（RED_FLUSH） |
|---|---|---|
| 适用时点 | **当月内**且未交付患者、未上传税务 | **跨月**、已交付、已上传税务 |
| 号码处理 | 号码保留但标记作废，**不得复用** | 原蓝票保持有效，另开一张红票 |
| 收入影响 | 原票不产生收入 | 红票冲减原票金额 |
| 税务影响 | 需向税局报送作废 | 需向税局报送红字发票 |
| 是否留痕 | 是（作废记录表） | 是（红票与原票双向关联） |
| 不可逆性 | 作废后不可恢复 | 红票可用蓝票「重新开票」抵消 |

> **一句话记住：** 电子发票几乎不能作废（一旦开具即上传税务），只能红冲；纸质发票当月未交付可以作废。M16-07 强制检查：电子发票一律不允许作废，只能红冲。

### 1.5 模块目标

| 目标 | 指标 | 说明 |
|---|---|---|
| 开票不重复 | 100% | 同一结算单同一票种的蓝票唯一 |
| 号码不重号不跳号 | 100% | 号码段按序使用，作废票占号不复用 |
| 红冲准确 | 100% | 红票金额 ≤ 原票金额，累计红冲 ≤ 原票 |
| 电子发票及时送达 | ≥ 99.5% | 开票成功 5 分钟内交付 |
| 开票成功率 | ≥ 99.9% | 税控/平台失败自动重试 3 次 |
| 纸质票可追溯 | 100% | 每张纸质票都能追到领用人与使用人 |
| 查验回写及时 | ≥ 99% | 患者查验后 24 小时内回写状态 |
| 开票响应 | P95 ≤ 300ms | 电子发票异步开具，接口返回受理即成功 |

## 3. 业务模型

### 3.1 发票主状态机

```
                    ┌──────────┐
                    │  PENDING │  待开票（已受理，未取号）
                    └────┬─────┘
                         │ 分配号码
                         ▼
                    ┌──────────┐
                    │  ISSUING │  开票中（已取号，调税控）
                    └────┬─────┘
              ┌──────────┴──────────┐
         成功 │                     │ 失败
              ▼                     ▼
        ┌──────────┐          ┌──────────┐
        │  ISSUED  │          │  FAILED  │
        │  已开具   │          │ 开具失败  │
        └────┬─────┘          └────┬─────┘
             │                     │ 重试成功
             │                     └──────► ISSUING
             │ 交付
             ▼
        ┌──────────┐
        │DELIVERED │  已交付（患者已收到）
        └────┬─────┘
             │
     ┌───────┴────────┬──────────────┐
     │红冲             │作废（仅纸质） │ 查验
     ▼                ▼              ▼
┌──────────┐    ┌──────────┐   ┌──────────────┐
│RED_FLUSH │    │  VOIDED  │   │VERIFIED/     │
│ 已红冲   │    │  已作废   │   │VERIFY_FAILED │
└──────────┘    └──────────┘   └──────────────┘
```

**状态说明**

| 状态 | 名称 | 终态 | 可转 |
|---|---|---|---|
| `PENDING` | 待开票 | 否 | ISSUING / CANCELLED |
| `ISSUING` | 开票中 | 否 | ISSUED / FAILED |
| `ISSUED` | 已开具 | 否 | DELIVERED / VOIDED / RED_FLUSHED |
| `DELIVERED` | 已交付 | 否 | VOIDED / RED_FLUSHED |
| `FAILED` | 开具失败 | 否 | ISSUING（重试） / CANCELLED |
| `VOIDED` | 已作废 | ✅ | — |
| `RED_FLUSHED` | 已全额红冲 | ✅ | — |
| `PARTIAL_RED` | 部分红冲 | 否 | RED_FLUSHED |
| `CANCELLED` | 已取消 | ✅ | — |

> **注意 `PARTIAL_RED`：** 一张 1,000 元发票退了 300 元，开 300 元红票后原票仍是有效的（余额 700）。只有退到 0 才变 `RED_FLUSHED`。

### 3.2 开票判定模型

开票不是「有钱就开」，需要过五道判定：

```
① 结算单状态？── PAID 及以上 ──┐
                              │
② 是否已有有效蓝票？── 无 ─────┤
                              │
③ 票种与金额？── 医疗服务免税 / 商品 13% ──┤
                              │
④ 抬头信息完整？── 单位需税号 ──┤
                              │
⑤ 开票点限额内？── 当日号码段足够 ──┤
                              │
                              ▼
                         允许开票
```

**判定表**

| 条件 | 不满足时 | 错误码 |
|---|---|---|
| 结算单 `status IN ('PAID','SETTLED')` | 拒绝 | 54976 |
| 该结算单在该票种下无 `status NOT IN ('VOIDED','CANCELLED','RED_FLUSHED')` 的蓝票 | 拒绝（已有票则提示去查看） | 54979 |
| `amount > 0` | 拒绝（负数应走红冲） | 54973 |
| 单位抬头必须有 `tax_no` 且 15~20 位 | 拒绝 | 54980 |
| 手机号/邮箱至少一个（电子票） | 拒绝 | 54981 |
| 号码段剩余 ≥ 1（纸质票） | 拒绝 | 54987 |

### 3.3 税种与税率模型

| 收费大类 | 税率 | 说明 |
|---|---|---|
| 医疗服务（挂号/诊查/检查/检验/治疗/手术） | 免税 | `is_tax_free=TRUE`，税率 0 |
| 药品 | 免税（医疗） / 13%（零售） | 按 `md_charge_item.charge_class` 决定 |
| 卫生材料 | 免税（医疗） / 13%（零售） | 同上 |
| 视光商品（镜片/镜架/隐形眼镜） | 13% | 商品销售 |
| 视光服务（验光/加工） | 6% | 现代服务 |
| 会员卡工本费 | 6% | 现代服务 |

> **同一张发票混合计税：** 医院实际业务中，「检查 200 元（免税）+ 眼药水 50 元（免税）+ 镜片 800 元（13%）」可能出现在同一张票上。M16-07 支持按 `tax_rate` 分组，生成多行税额明细。
>
> **免税金额与应税金额在同一张票上分开列示**，这是增值税发票的规范要求。

**税额计算**

```
免税行：
  tax_rate = 0
  tax_amount = 0

应税行（价税合计已知）：
  amount_without_tax = ROUND(amount_with_tax / (1 + tax_rate), 2)
  tax_amount = amount_with_tax - amount_without_tax
```

> **先算不含税再倒算税额**（而不是「含税 × 税率」），保证 `不含税 + 税额 = 含税` 恒等，避免 1 分差额导致发票校验失败。

### 3.4 号码管理模型

**三种号码来源**

| 来源 | 票种 | 分配方式 | 谁负责 |
|---|---|---|---|
| 税务平台 | 电子发票 | 由平台返回 `invoice_no` | M16-07 只记录 |
| 号码段顺序分配 | 纸质发票、财政票据 | 从 `md_invoice_number_segment` 顺序取 | M16-07 |
| 手工录入 | 手工票/补录 | 收费员输入 | M16-07 校验唯一 |

**纸质票取号算法（并发安全）**

```sql
-- 1. 取号（行锁，避免并发重号）
SELECT id, config_id, prefix, start_no, end_no, current_no
  FROM md_invoice_number_segment
 WHERE invoice_point = $1
   AND invoice_type = $2
   AND status = 'ACTIVE'
   AND current_no < end_no
 ORDER BY start_no
   FOR UPDATE SKIP LOCKED
 LIMIT 1;
-- 2. current_no += 1，used_count += 1
-- 3. current_no = end_no 时置 status='EXHAUSTED'
```

> **`FOR UPDATE SKIP LOCKED`** 而不是 `FOR UPDATE`：三台收银机同时取号时，不应排队等同一段，而是各取一段。这样 P95 从「排队 200ms」降到「<5ms」。

**号码段预警**

| 阈值 | 动作 |
|---|---|
| 剩余 < 100 张 | 每日 08:00 邮件通知票据管理员 |
| 剩余 < 20 张 | 当日每 2 小时提醒 + 收费台横幅 |
| 剩余 = 0 | 该开票点禁止开具纸质票，报 54987 |

**废票占号规则**

作废的纸质票**号码不复用**。作废时：

1. `m16_invoice` 记录 `status='VOIDED'`，保留 `invoice_no`
2. 同时写入 `m16_invoice_void`、`m16_invoice_assign_log`（动作 `VOID`）
3. 纸质票打「作废」戳，归档保存 5 年

> 税务要求：作废发票必须**全联次保存**，不得销毁。M16-07 的作废流程会打印作废标签，提示收费员保留废票。

### 3.5 红冲模型

**红冲的四种触发场景**

| 场景 | 发起方 | 红冲金额 | 是否需审批 |
|---|---|---|---|
| 全额退费 | M16-08 退费单 | = 原票金额 | 是（财务主管） |
| 部分退费 | M16-08 退费单 | = 退费额 | 是（财务主管） |
| 开票有误（抬头/金额） | 收费员发起换开 | = 原票全额 | 是（收费主管） |
| 销售折让（视光打折后开票） | 收费员发起 | = 折让额 | 是（收费主管） |

**红冲校验清单**

```
① 原票存在且 status IN ('ISSUED','DELIVERED','PARTIAL_RED')
② 红冲金额 > 0 且 ≤ 原票金额 − 已红冲额
③ 跨月（开票月 ≠ 当前月）必须有财务主管审批
④ 电子票一律不允许作废，只能红冲
⑤ 红票需在税控系统做「红字确认单」关联（数电票规范）
```

**累计红冲约束**

```
已红冲额 = SUM(red_invoice.amount WHERE original_id = 原票 ID AND status <> 'VOIDED')
剩余可红冲 = 原票金额 − 已红冲额
```

数据库层用部分唯一索引 + 触发器双重保障，见 4.4 节。

### 3.6 换开模型

换开是「先红后蓝」的两步原子动作。用户视角只点一次「换开」，系统内部执行：

```
┌──────────────────────────────────────────────┐
│ 换开请求                                      │
│  原票 #20260001 金额 500（抬头错误）           │
└────────────────────┬─────────────────────────┘
                     ▼
        ① 校验原票状态允许换开
                     ▼
        ② 生成红票（关联原票，-500）
           └─ 调税控平台开具红字发票
                     ▼
        ③ 生成新蓝票（新抬头，+500）
           └─ 调税控平台开具蓝字发票
                     ▼
        ④ 原子提交：任何一步失败则回滚
           └─ 红票成功、蓝票失败 → 红票暂停（status='SUSPENDED'）
              等待重开蓝票，不允许只留红票
```

> **为什么需要 `SUSPENDED` 状态：** 红票已开、蓝票失败时，若直接回滚会让税控系统的红票变成「无处核销」的孤儿。M16-07 的做法是保留红票，标记为挂起，并生成一个待重开的蓝票任务，财务可人工介入。这与税务实践一致。

### 3.7 纸质票生命周期

```
┌────────┐  领用  ┌────────┐  发放  ┌────────┐  使用  ┌────────┐  核销  ┌────────┐
│ 税局   │──────►│ 票据库 │──────►│ 开票点 │──────►│ 患者   │──────►│ 归档   │
│ 领用   │       │ 管理员 │       │ 收费员 │       │        │       │        │
└────────┘       └────────┘       └────────┘       └────────┘       └────────┘
                     │                 │
                     │ 报废             │ 作废
                     ▼                 ▼
                 ┌────────┐       ┌────────┐
                 │ 废票库 │       │ 废票库 │
                 └────────┘       └────────┘
```

**核销规则**

| 场景 | 核销动作 |
|---|---|
| 正常开出 | 号码段 `used_count+1`，无需单独核销 |
| 作废 | 记录作废原因，废票必须归档 |
| 打印失败（卡纸/空号） | 记录为废票，不允许复用号码 |
| 整段作废 | 号码段 `status='VOID'`，需院长审批 |

**月度核销报表**

每月 1 日生成上月「号码段使用台账」：

- 期初号码、期末号码
- 本期使用数、作废数、废票数
- 结存数
- 与税控系统申报数对账

### 3.8 交付模型

**电子发票四种交付方式**

| 方式 | 触发 | 记录字段 | 失败降级 |
|---|---|---|---|
| 二维码 | 开票成功立即展示 | `deliver_type='QR'` | — |
| 短信 | 患者留手机号 | `deliver_type='SMS'` | 改二维码 |
| 邮件 | 患者留邮箱 | `deliver_type='EMAIL'` | 改二维码 |
| 微信卡包 | 患者通过微信支付 | `deliver_type='WECHAT'` | 改二维码 |

**交付状态机**

```
PENDING ──► SENDING ──► SUCCESS
                │
                └──► FAILED ──► 重试（3 次）──► FAILED（终态，人工处理）
```

**二维码内容**

不是发票链接，而是一个**短令牌**：

```
https://fapiao.hospital.local/i/{token}
token = 32 位随机串，Redis 存储 TTL 7 天
Redis value = {invoice_id, patient_id, expire_at}
```

> **为什么用令牌而不是直接给发票 ID：** 发票 ID 是顺序数字。如果 URL 是 `/invoice/12345`，攻击者改一个数字就能看别人的发票——包含姓名、金额、疾病信息。令牌方案让枚举不可行（32 位随机串，2^128 空间），且可随时吊销。

### 3.9 查验回写模型

患者拿到电子发票后可能在税务平台（如「全国增值税发票查验平台」）查验。M16-07 支持两种回写：

| 方式 | 说明 | 频率 |
|---|---|---|
| 主动查验 | M16-07 定时调税务查验接口，比对状态 | 每日 02:00 |
| 被动上报 | 税务平台/服务商推送查验结果到 M16-07 | 实时 |

查验结果枚举：

| 结果 | 含义 | 处理 |
|---|---|---|
| `VERIFIED` | 查验通过 | 更新 `last_verified_at` |
| `VERIFY_FAILED` | 查验不通过（票面信息与税务不一致） | 🔴 严重告警，冻结该票，人工排查 |
| `NOT_FOUND` | 税务平台查不到 | 🟡 告警，可能是平台延迟，次日重查 |

```python
# app/services/m16/invoice_service.py
import hashlib
import secrets
from datetime import datetime, date
from decimal import Decimal, ROUND_HALF_UP
from typing import Optional

from sqlalchemy import select, and_, func
from sqlalchemy.ext.asyncio import AsyncSession

CENT = Decimal("0.01")
MAX_DELIVER_PER_DAY = 5
MAX_REPRINT_FREE = 1
MAX_REPRINT_TOTAL = 3
LARGE_AMOUNT = Decimal("1000.00")


def money(v: Decimal) -> Decimal:
    return Decimal(v).quantize(CENT, rounding=ROUND_HALF_UP)


class InvoiceService:
    """发票开具、交付、红冲、换开、作废"""

    def __init__(self, db: AsyncSession, redis, tax_client, storage, msg):
        self.db = db
        self.redis = redis
        self.tax = tax_client
        self.storage = storage
        self.msg = msg

    # ---------- 开票 ----------

    async def issue(self, req, user):
        settle = await self._load_settlement(req.settlement_no)
        await self._check_issuable(settle, req.invoice_type)
        config = await self._load_config(
            settle.invoice_point, req.invoice_type)

        items = await self._build_items(settle, config)
        total = money(sum(i["amount"] for i in items))
        tax_total = money(sum(i["tax_amount"] for i in items))

        inv = M16Invoice(
            settlement_id=settle.id,
            settlement_no=settle.settlement_no,
            patient_id=settle.patient_id,
            patient_name=settle.patient_name,
            invoice_type=req.invoice_type,
            invoice_point=settle.invoice_point,
            title_type=req.title_type,
            title=req.title.strip(),
            tax_no=req.tax_no,
            mobile=req.mobile,
            email=req.email,
            amount=total,
            tax_amount=tax_total,
            amount_without_tax=money(total - tax_total),
            is_tax_free=(tax_total == Decimal("0")),
            tax_rate=config.tax_rate,
            status="PENDING",
            remark=req.remark,
            issued_by=user.id,
            issued_by_name=user.name,
            created_by=user.id,
        )
        self.db.add(inv)
        await self.db.flush()

        inv.invoice_no = await self._allocate_number(inv, config)
        inv.status = "ISSUING"
        await self.db.flush()

        try:
            result = await self._call_tax_platform(inv, items)
        except TaxPlatformError as exc:
            inv.status = "FAILED"
            inv.fail_reason = str(exc)[:500]
            await self.db.commit()
            await self._log(inv, "ISSUE", "ERROR", str(exc))
            raise BizError(54983, "开票平台调用失败：" + str(exc))

        inv.invoice_code = result["invoice_code"]
        inv.status = "ISSUED"
        inv.issued_at = datetime.now()
        inv.issue_date = inv.issued_at.date()
        inv.qr_token = secrets.token_hex(16)

        files = await self._store_files(inv, result)
        inv.pdf_file_id = files.get("PDF")
        inv.ofd_file_id = files.get("OFD")
        inv.xml_file_id = files.get("XML")
        if not inv.pdf_file_id and req.invoice_type == "ELECTRONIC":
            inv.status = "FAILED"
            inv.fail_reason = "版式文件存储失败"
            await self.db.commit()
            raise BizError(54984, "版式文件存储失败")

        await self._store_qr_token(inv)
        await self.db.flush()

        await self._write_items(inv, items)
        await self._log(inv, "ISSUE", "SUCCESS", None)
        await self.db.commit()

        if req.invoice_type == "ELECTRONIC":
            await self._deliver_auto(inv)
        await self._callback_settlement(inv)
        return await self._detail_dict(inv)

    async def _check_issuable(self, settle, invoice_type):
        if settle.status not in ("PAID", "SETTLED"):
            raise BizError(54976, "结算单状态不允许开票")
        if money(settle.payable_amount) <= Decimal("0"):
            raise BizError(54979, "结算单金额为 0 或负数")

        # 关键：已开票检查，红冲后的原票允许重新开
        stmt = select(func.count()).select_from(M16Invoice).where(
            M16Invoice.settlement_id == settle.id,
            M16Invoice.invoice_type == invoice_type,
            M16Invoice.is_red_invoice == False,
            M16Invoice.status.notin_(
                ["VOIDED", "CANCELLED", "RED_FLUSHED"]),
            M16Invoice.is_deleted == False,
        )
        exists = (await self.db.execute(stmt)).scalar_one()
        if exists:
            raise BizError(54978, "该结算单已开具同类发票")

    async def _allocate_number(self, inv, config):
        if inv.invoice_type == "ELECTRONIC":
            return None  # 由税务平台返回
        seg = await self._next_segment(
            inv.invoice_point, inv.invoice_type)
        if seg is None:
            raise BizError(54987, "纸质发票号码段已用尽")
        return seg["invoice_no"]

    async def _next_segment(self, point, inv_type):
        row = await self.db.execute(
            select(MdInvoiceNumberSegment).where(
                MdInvoiceNumberSegment.invoice_point == point,
                MdInvoiceNumberSegment.invoice_type == inv_type,
                MdInvoiceNumberSegment.status == "ACTIVE",
                MdInvoiceNumberSegment.current_no
                < MdInvoiceNumberSegment.end_no,
                MdInvoiceNumberSegment.deleted == False,
            ).order_by(MdInvoiceNumberSegment.start_no)
            .with_for_update(skip_locked=True).limit(1)
        )
        seg = row.scalar_one_or_none()
        if seg is None:
            return None
        seg.current_no = seg.current_no + 1
        seg.used_count = seg.used_count + 1
        if seg.current_no >= seg.end_no:
            seg.status = "EXHAUSTED"
        prefix = seg.prefix or ""
        return {"invoice_no": prefix + str(seg.current_no).zfill(8),
                "segment_id": seg.id}

    async def _build_items(self, settle, config):
        """按税率分组生成发票明细"""
        rows = await self._load_settle_items(settle.id)
        out = []
        for r in rows:
            if money(r.amount) <= Decimal("0"):
                continue
            rate = self._resolve_tax_rate(r, config)
            amt = money(r.amount)
            if rate == Decimal("0"):
                out.append({
                    "item_code": r.item_code,
                    "item_name": r.item_name,
                    "spec": r.spec,
                    "unit": r.unit,
                    "quantity": r.quantity,
                    "amount": amt,
                    "tax_rate": Decimal("0.0000"),
                    "tax_amount": Decimal("0.00"),
                })
            else:
                without = money(amt / (Decimal("1") + rate))
                out.append({
                    "item_code": r.item_code,
                    "item_name": r.item_name,
                    "spec": r.spec,
                    "unit": r.unit,
                    "quantity": r.quantity,
                    "amount": amt,
                    "tax_rate": rate,
                    "tax_amount": money(amt - without),
                })
        if not out:
            raise BizError(54979, "无可开票明细")
        return out

    def _resolve_tax_rate(self, row, config):
        if config.is_tax_free:
            return Decimal("0.0000")
        by_class = config.taxrate_by_class or {}
        if row.charge_class in by_class:
            return Decimal(str(by_class[row.charge_class]))
        return Decimal(str(config.tax_rate or 0))


    # ---------- 交付 ----------

    async def _deliver_auto(self, inv):
        if inv.mobile:
            await self._try_deliver(inv, "SMS", inv.mobile)
        elif inv.email:
            await self._try_deliver(inv, "EMAIL", inv.email)

    async def deliver(self, invoice_id, body, user):
        inv = await self._get(invoice_id)
        if inv.invoice_type != "ELECTRONIC":
            raise BizError(40001, "纸质发票不支持电子交付")
        if inv.status not in ("ISSUED", "DELIVERED", "PARTIAL_RED"):
            raise BizError(54990, "发票状态不允许交付")

        cnt = await self._today_deliver_count(inv.id)
        if cnt >= MAX_DELIVER_PER_DAY:
            raise BizError(54985, "今日交付次数已达上限")
        return await self._try_deliver(inv, body.deliver_type,
                                       body.receiver, user)

    async def _try_deliver(self, inv, dtype, receiver, user=None):
        rec = M16InvoiceDelivery(
            invoice_id=inv.id,
            deliver_type=dtype,
            receiver=receiver,
            status="SENDING",
            operator_id=getattr(user, "id", None),
            created_at=datetime.now(),
        )
        self.db.add(rec)
        await self.db.flush()
        try:
            if dtype == "SMS":
                await self.msg.send_sms(
                    receiver,
                    "您在本院的电子发票已开具，"
                    "点击查看：https://fapiao.hospital.local/i/"
                    + (inv.qr_token or ""))
            elif dtype == "EMAIL":
                await self.msg.send_email(
                    receiver, "电子发票",
                    await self._file_bytes(inv.id, "PDF"))
            rec.status = "SUCCESS"
            rec.delivered_at = datetime.now()
            if inv.status == "ISSUED":
                inv.status = "DELIVERED"
        except Exception as exc:
            rec.status = "FAILED"
            rec.fail_reason = str(exc)[:500]
            await self.db.commit()
            await self._log(inv, "DELIVER", "ERROR", str(exc))
            raise BizError(54983, "交付失败：" + str(exc))
        await self.db.commit()
        return {"delivery_id": rec.id, "status": rec.status}


    # ---------- 红冲 ----------

    async def red_flush(self, invoice_id, body, user):
        orig = await self._get(invoice_id)
        await self._check_red_flushable(orig)

        amt = money(body.amount)
        remaining = await self._remaining_red_amount(orig)
        if amt <= Decimal("0") or amt > remaining:
            raise BizError(54991, "红冲金额超出可红冲额度")

        if body.reason in ("WRONG_TITLE", "ALLOWANCE") \
                and not body.attachment_ids:
            raise BizError(54992, "红冲证明材料未上传")

        cross_month = orig.issue_date.month != date.today().month \
            or orig.issue_date.year != date.today().year
        if cross_month and not body.approval_id:
            raise BizError(54993, "跨月红冲需财务主管审批")

        red = M16Invoice(
            settlement_id=orig.settlement_id,
            settlement_no=orig.settlement_no,
            patient_id=orig.patient_id,
            patient_name=orig.patient_name,
            invoice_type=orig.invoice_type,
            invoice_point=orig.invoice_point,
            title_type=orig.title_type,
            title=orig.title,
            tax_no=orig.tax_no,
            amount=money(-amt),
            tax_amount=money(-amt),
            is_tax_free=orig.is_tax_free,
            tax_rate=orig.tax_rate,
            status="ISSUING",
            is_red_invoice=True,
            original_invoice_id=orig.id,
            red_reason=body.reason,
            red_description=body.description,
            refund_no=body.refund_no,
            issued_by=user.id,
            issued_by_name=user.name,
            created_by=user.id,
        )
        self.db.add(red)
        await self.db.flush()

        red.invoice_no = await self._allocate_number(red, None)
        try:
            result = await self.tax.red_flush(orig, red)
        except TaxPlatformError as exc:
            red.status = "FAILED"
            red.fail_reason = str(exc)[:500]
            await self.db.commit()
            raise BizError(54983, "红冲失败：" + str(exc))

        red.invoice_code = result["invoice_code"]
        red.status = "ISSUED"
        red.issued_at = datetime.now()
        red.issue_date = red.issued_at.date()
        red.qr_token = secrets.token_hex(16)

        new_remaining = remaining - amt
        if new_remaining <= Decimal("0"):
            orig.status = "RED_FLUSHED"
        else:
            orig.status = "PARTIAL_RED"
        orig.red_amount = money(orig.red_amount + amt)

        await self.db.flush()
        await self._log(red, "RED_FLUSH", "SUCCESS", None,
                        ref_no=orig.invoice_no)
        await self.db.commit()
        return {
            "red_invoice_id": red.id,
            "red_invoice_no": red.invoice_no,
            "original_id": orig.id,
            "original_no": orig.invoice_no,
            "red_amount": str(red.amount),
            "original_amount": str(orig.amount),
            "remaining_red_amount": str(new_remaining),
            "original_status": orig.status,
            "status": red.status,
        }

    async def _remaining_red_amount(self, orig):
        stmt = select(func.coalesce(func.sum(M16Invoice.amount),
                                    Decimal("0"))).where(
            M16Invoice.original_invoice_id == orig.id,
            M16Invoice.status.notin_(["FAILED", "CANCELLED", "VOIDED"]),
            M16Invoice.is_deleted == False,
        )
        used = (await self.db.execute(stmt)).scalar_one()
        return money(abs(Decimal(str(used))) * -1 * -1) \
            if used else money(orig.amount)

    async def _check_red_flushable(self, inv):
        if inv.is_red_invoice:
            raise BizError(54990, "红字发票不可再红冲")
        if inv.status not in ("ISSUED", "DELIVERED", "PARTIAL_RED"):
            raise BizError(54990, "发票状态不允许红冲")

    # ---------- 换开 ----------

    async def reissue(self, invoice_id, body, user):
        orig = await self._get(invoice_id)
        await self._check_red_flushable(orig)
        if money(orig.amount) <= Decimal("0"):
            raise BizError(54994, "红字发票不可换开")

        red_res = await self.red_flush(invoice_id, RedFlushRequest(
            amount=orig.amount,
            reason="WRONG_TITLE",
            description=body.description,
            attachment_ids=body.attachment_ids,
            approval_id=body.approval_id,
        ), user)

        try:
            new_inv = await self.issue(IssueRequest(
                settlement_no=orig.settlement_no,
                invoice_type=orig.invoice_type,
                title_type=body.new_title_type,
                title=body.new_title,
                tax_no=body.new_tax_no,
                mobile=body.new_mobile,
                email=body.new_email,
                remark="换开自 " + str(orig.invoice_no),
            ), user)
        except BizError as exc:
            await self._suspend_red(red_res["red_invoice_id"], str(exc))
            raise BizError(54983,
                           "红票已开具但蓝票失败：" + str(exc))

        return {
            "red_invoice_id": red_res["red_invoice_id"],
            "red_invoice_no": red_res["red_invoice_no"],
            "red_status": "ISSUED",
            "new_invoice_id": new_inv["invoice_id"],
            "new_invoice_no": new_inv["invoice_no"],
            "new_status": new_inv["status"],
            "original_status": "RED_FLUSHED",
        }

    async def _suspend_red(self, red_id, reason):
        red = await self._get(red_id)
        red.status = "SUSPENDED"
        red.fail_reason = ("蓝票开具失败：" + reason)[:500]
        await self.db.commit()
        await self._alert("RED_SUSPENDED", red_id, reason)

    # ---------- 作废 ----------

    async def void(self, invoice_id, body, user):
        inv = await self._get(invoice_id)
        if inv.invoice_type == "ELECTRONIC":
            raise BizError(54988, "电子发票不可作废，请使用红冲")
        if inv.status not in ("ISSUED", "DELIVERED"):
            raise BizError(54989, "该发票当前状态不允许作废")
        if not body.returned_original:
            raise BizError(40001, "必须收回纸质发票原件")
        if inv.issue_date.month != date.today().month \
                or inv.issue_date.year != date.today().year:
            raise BizError(54989, "跨月发票不可作废")
        if inv.amount >= Decimal("500.00"):
            await self._require_approval(inv, "VOID", user)

        old = inv.status
        inv.status = "VOIDED"
        inv.voided_at = datetime.now()
        inv.voided_by = user.id
        inv.void_reason = body.reason
        await self.db.flush()
        await self._log(inv, "VOID", "SUCCESS",
                        body.description, ref_no=inv.invoice_no)
        await self.db.commit()
        return {
            "invoice_id": inv.id,
            "invoice_no": inv.invoice_no,
            "old_status": old,
            "new_status": "VOIDED",
            "number_reusable": False,
            "archive_required": True,
        }

    # ---------- 工具 ----------

    async def _get(self, invoice_id):
        inv = await self.db.get(M16Invoice, invoice_id)
        if inv is None or inv.is_deleted:
            raise BizError(40001, "发票不存在")
        return inv

    async def _store_qr_token(self, inv):
        key = "m16:invoice:qr:" + (inv.qr_token or "")
        await self.redis.set(key, str(inv.id), ex=7 * 86400)

    async def _today_deliver_count(self, invoice_id):
        today = datetime.now().replace(hour=0, minute=0, second=0,
                                       microsecond=0)
        stmt = select(func.count()).select_from(M16InvoiceDelivery).where(
            M16InvoiceDelivery.invoice_id == invoice_id,
            M16InvoiceDelivery.created_at >= today,
        )
        return (await self.db.execute(stmt)).scalar_one()

    async def _log(self, inv, action, result, detail, ref_no=None):
        self.db.add(M16InvoiceLog(
            invoice_id=inv.id,
            invoice_no=inv.invoice_no,
            settlement_no=inv.settlement_no,
            action=action,
            result=result,
            detail=(detail or "")[:2000] if detail else None,
            ref_no=ref_no,
            created_at=datetime.now(),
        ))

    async def _alert(self, kind, ref_id, reason):
        await self.redis.publish(
            "m16:alert", kind + "|" + str(ref_id) + "|" + (reason or ""))
```

### 6.7 号码段服务实现

```python
# app/services/m16/invoice_segment_service.py
from datetime import datetime
from decimal import Decimal

from sqlalchemy import select, and_, or_, func


class InvoiceSegmentService:
    """纸质票号码段领用、警告、核销"""

    ALERT_REMAINING = 100
    URGENT_REMAINING = 20
    MAX_SEGMENT_SIZE = 10000

    def __init__(self, db, redis):
        self.db = db
        self.redis = redis

    async def create(self, body, user):
        if body.end_no < body.start_no:
            raise BizError(40001, "终止号必须大于等于起始号")
        size = body.end_no - body.start_no + 1
        if size > self.MAX_SEGMENT_SIZE:
            raise BizError(40001, "单个号码段数量不得超过 10000")

        overlap = await self._find_overlap(
            body.invoice_point, body.invoice_type,
            body.prefix, body.start_no, body.end_no)
        if overlap is not None:
            raise BizError(54995,
                           "号码段与已有段重叠：" + str(overlap.segment_no))

        seg = MdInvoiceNumberSegment(
            invoice_point=body.invoice_point,
            invoice_type=body.invoice_type,
            prefix=body.prefix,
            start_no=body.start_no,
            end_no=body.end_no,
            current_no=0,
            used_count=0,
            total_count=size,
            assign_date=body.assign_date or datetime.now().date(),
            writer_name=body.writer_name,
            status="ACTIVE",
            remark=body.tax_bureau_record_no,
            created_by=user.id,
        )
        self.db.add(seg)
        await self.db.commit()
        await self.redis.delete(
            "m16:invoice:segments:" + body.invoice_point)
        return self._dict(seg)

    async def _find_overlap(self, point, inv_type, prefix, start, end):
        stmt = select(MdInvoiceNumberSegment).where(
            MdInvoiceNumberSegment.invoice_point == point,
            MdInvoiceNumberSegment.invoice_type == inv_type,
            MdInvoiceNumberSegment.deleted == False,
            MdInvoiceNumberSegment.status != "VOID",
            or_(
                and_(MdInvoiceNumberSegment.start_no <= start,
                     MdInvoiceNumberSegment.end_no >= start),
                and_(MdInvoiceNumberSegment.start_no <= end,
                     MdInvoiceNumberSegment.end_no >= end),
                and_(MdInvoiceNumberSegment.start_no >= start,
                     MdInvoiceNumberSegment.end_no <= end),
            ),
        ).limit(1)
        return (await self.db.execute(stmt)).scalar_one_or_none()

    async def verify(self, segment_id, body, user):
        seg = await self.db.get(MdInvoiceNumberSegment, segment_id)
        if seg is None:
            raise BizError(40001, "号码段不存在")

        used = await self._count_used(seg)
        voided = await self._count_voided(seg)
        remain = seg.total_count - used - voided

        if body.tax_declared_used is not None \
                and body.tax_declared_used != used:
            if not body.diff_reason:
                raise BizError(54996,
                               "号码段核销与税控申报数不一致："
                               + "本院 " + str(used)
                               + " / 税控 " + str(body.tax_declared_used))

        seg.status = "VERIFIED"
        self.db.add(M16InvoiceSegmentLog(
            segment_id=seg.id,
            action="VERIFY",
            used_count=used,
            void_count=voided,
            remain_count=remain,
            tax_declared_used=body.tax_declared_used,
            diff_reason=body.diff_reason,
            operator_id=user.id,
            created_at=datetime.now(),
        ))
        await self.db.commit()
        return {"segment_id": seg.id, "used": used, "voided": voided,
                "remain": remain, "status": seg.status}

    async def _count_used(self, seg):
        stmt = select(func.count()).select_from(M16Invoice).where(
            M16Invoice.number_segment_id == seg.id,
            M16Invoice.status.notin_(["CANCELLED"]),
        )
        return (await self.db.execute(stmt)).scalar_one()

    async def _count_voided(self, seg):
        stmt = select(func.count()).select_from(M16Invoice).where(
            M16Invoice.number_segment_id == seg.id,
            M16Invoice.status == "VOIDED",
        )
        return (await self.db.execute(stmt)).scalar_one()

    async def check_remaining(self):
        """定时任务：号码段余量预警"""
        stmt = select(MdInvoiceNumberSegment).where(
            MdInvoiceNumberSegment.status == "ACTIVE")
        rows = (await self.db.execute(stmt)).scalars().all()
        alerts = []
        for seg in rows:
            remain = seg.total_count - seg.used_count
            if remain <= self.URGENT_REMAINING:
                alerts.append({"level": "URGENT",
                               "segment": seg.prefix + str(seg.current_no),
                               "remain": remain})
            elif remain <= self.ALERT_REMAINING:
                alerts.append({"level": "WARN",
                               "segment": seg.prefix + str(seg.current_no),
                               "remain": remain})
        return alerts
```

```python
# app/tasks/m16/invoice_tasks.py
import asyncio
from celery import shared_task
from datetime import datetime, timedelta


@shared_task(name="m16.invoice.issue_async", max_retries=3,
             default_retry_delay=5)
def issue_invoice_async(self, invoice_id):
    """异步开票：受理后立即返回，后台调税控"""
    async def _run():
        from app.db.session import async_session
        from app.services.m16.invoice_service import InvoiceService
        async with async_session() as db:
            svc = InvoiceService(db, redis(), tax_client(), storage(), msg())
            return await svc.issue_async_worker(invoice_id)
    try:
        return asyncio.run(_run())
    except Exception as exc:
        raise self.retry(exc=exc)


@shared_task(name="m16.invoice.retry_failed")
def retry_failed_invoices():
    """每 2 分钟扫一次失败发票，重试"""
    async def _run():
        from app.db.session import async_session
        async with async_session() as db:
            rows = await load_invoices(
                db,
                status="FAILED",
                fail_reason_like="税控",
                retry_count_lt=3,
                created_after=datetime.now() - timedelta(hours=2),
            )
            out = []
            for inv in rows:
                out.append({"id": inv.id, "retried": True})
            return out
    return asyncio.run(_run())


@shared_task(name="m16.invoice.check_segment")
def check_segment_remaining():
    """每日 08:00 检查号码段余量"""
    async def _run():
        from app.db.session import async_session
        from app.services.m16.invoice_segment_service import (
            InvoiceSegmentService,
        )
        async with async_session() as db:
            svc = InvoiceSegmentService(db, redis())
            alerts = await svc.check_remaining()
            if alerts:
                await notify_admin("纸质发票号码段余量预警", alerts)
            return {"alert_count": len(alerts)}
    return asyncio.run(_run())


@shared_task(name="m16.invoice.check_segment_hourly")
def check_segment_hourly():
    """紧急余量每小时提醒"""
    async def _run():
        from app.db.session import async_session
        from app.services.m16.invoice_segment_service import (
            InvoiceSegmentService,
        )
        async with async_session() as db:
            svc = InvoiceSegmentService(db, redis())
            alerts = [a for a in await svc.check_remaining()
                      if a["level"] == "URGENT"]
            if alerts:
                await notify_admin("纸质发票号码段即将用尽", alerts)
            return {"urgent": len(alerts)}
    return asyncio.run(_run())


@shared_task(name="m16.invoice.deliver_retry")
def retry_delivery():
    """每 5 分钟重试交付失败的发票"""
    async def _run():
        from app.db.session import async_session
        async with async_session() as db:
            rows = await load_deliveries(
                db, status="FAILED", retry_count_lt=3,
                created_after=datetime.now() - timedelta(hours=24))
            return [{"id": r.id} for r in rows]
    return asyncio.run(_run())


@shared_task(name="m16.invoice.verify_daily")
def verify_daily():
    """每日 02:00 调税务查验接口，回写状态"""
    async def _run():
        from app.db.session import async_session
        async with async_session() as db:
            targets = await load_invoices_to_verify(
                db, issued_after=datetime.now() - timedelta(days=7))
            ok = 0
            fail = 0
            for inv in targets:
                r = await verify_one(inv)
                if r["status"] == "VERIFIED":
                    ok += 1
                else:
                    fail += 1
            return {"verified": ok, "failed": fail}
    return asyncio.run(_run())
```

## 11. 异常处理与日志

### 11.1 异常分类

| 类别 | 示例 | 处理 |
|---|---|---|
| 参数错误 | 抬头为空、税号格式错 | 直接拒绝，40001 |
| 业务拒绝 | 已开票、金额超限 | 拒绝并给明确原因 |
| 配置缺失 | 无发票配置、号码段用尽 | 拒绝，报警给管理员 |
| 外部失败 | 税控超时、平台 5xx | 重试 3 次（1s/5s/15s）；失败标 FAILED |
| 存储失败 | 对象存储不可用 | 拒绝，回滚整个开票事务 |
| 并发冲突 | 同时打印同一张票 | Redis 锁，第 2 个返回「正在打印」 |
| 数据不一致 | 查验不通过 | 严重告警，冻结发票 |
