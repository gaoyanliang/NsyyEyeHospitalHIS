## 1. 模块概述

### 1.1 模块定位

视光销售结算回答的问题：

> **一个患者配了一副眼镜/一个 OK 镜/一套隐形眼镜，钱怎么收、分几次收、退的时候怎么退。**

它与门诊收费（M16-02）的关键差异：

| 维度 | 门诊收费（M16-02） | **视光销售（M16-04）** |
|---|---|---|
| 商品性质 | 医疗服务项目 | **实物商品 + 加工服务** |
| 库存 | 无 | **有，且可能缺货** |
| 交付时点 | 即时（服务做完） | **可能延后（定制片需加工 3~7 天）** |
| 收款节奏 | 一次付清 | **常分定金 + 尾款** |
| 退换 | 几乎不退 | **可能有退换货** |
| 顾客身份 | 一定是患者 | **可能是"顾客"（不挂号也可配镜）** |
| 金额构成 | 项目价 × 数量 | **镜架 + 镜片 + 加工费 + 配件 + 折扣** |

```
┌────────────────────────────────────────────────────────────────────┐
│                     视光销售全流程                                   │
│                                                                      │
│  ①到店（可不挂号）                                                    │
│      │                                                               │
│      ▼                                                               │
│  ┌──────────────┐   ②验光/选品                                         │
│  │ 视光销售单    │   ├─ 镜架 A  ¥680                                       │
│  │ OPTICAL_ORDER│   ├─ 镜片 B  ¥1,200（定制，加工 5 天）                  │
│  │              │   └─ 加工费    ¥80                                      │
│  └──────┬───────┘   合计 ¥1,960                                       │
│         │                                                            │
│         ├── ③全额付 → 直接等货 → 取镜                                   │
│         │                                                             │
│         └── ④付定金 30%（¥588）→ 等货 → 取镜时付尾款（¥1,372）           │
│                          │                                            │
│                          ▼                                            │
│                   ┌──────────────────┐                                │
│                   │ 加工/备货 3~7 天   │                                │
│                   └────────┬─────────┘                                │
│                            │ 到货通知（M03-05 短信）                    │
│                            ▼                                          │
│                     ⑤取镜 / 付尾款 / 交镜片质保卡                        │
│                            │                                          │
│                            ▼                                          │
│                     ⑥退换（15 天内未加工可退，已加工不退）                 │
└────────────────────────────────────────────────────────────────────┘
```

### 1.2 为什么视光销售必须独立成子模块

| 方案 | 问题 |
|---|---|
| 用 M16-02 门诊收费直接收 | 门诊收费以"挂号/就诊"为锚点，视光顾客可能没有就诊记录；且不支持定金、欠款、分次收款 |
| 用 M16-03 住院结算 | 住院是"先交预交金后结算"，视光是"先定货后收款"，方向反的 |
| 直接不当费用管，只当零售 | 无法追溯镜片批次、质保期；财务上镜片销售与医疗服务收入需要分账 |

**独立的价值：**

1. **支持"无就诊记录的顾客"**（`patient_id` 可空，用 `customer_name` + 手机号）
2. **支持定金 + 尾款**（`m16_optical_payment` 允许多次）
3. **支持定制加工等待期**（`expected_ready_date`）
4. **支持镜片质保追溯**（`lens_batch_no` + `warranty_months`）
5. **支持退换货分级**（未加工可退、已加工不可退、质量问题可换）

### 1.4 概念辨析：销售单 / 结算单 / 支付单 / 发票

| 概念 | 定义 | 数量关系 | 归属 |
|---|---|---|---|
| **销售单**（Optical Order） | 一次配镜交易的业务单据 | 1 | M16-04 |
| **结算单**（Settlement） | 一次收费的金额凭据 | 1 销售单 → N 结算单（定金、尾款各一张） | M16-01 |
| **支付单**（Payment） | 一次实际的钱款进出 | 1 结算单 → N 支付单（可混合支付） | M16-02/M16-05 |
| **发票**（Invoice） | 税务凭据 | 1 销售单 → 1 发票（可分次开） | M16-07 |

```
销售单 SO20261021001  总额 1,960
   ├── 结算单 BL20261021003   ¥588   （定金 30%）
   │      └── 支付单 PAY...   ¥588  微信
   └── 结算单 BL20261026011  ¥1,372 （尾款）
          └── 支付单 PAY...   ¥1,372 支付宝
```

### 1.5 模块目标

| 目标 | 指标 |
|---|---|
| 开单快速 | 选品到出单 ≤ 60 秒 |
| 定金率准确 | 定金比例强制校验，不得低于配置值 |
| 尾款可催 | 到货 3 天未取镜自动提醒 |
| 退换可判 | 未加工/已加工/质量问题三档判定自动化 |
| 质保可查 | 任一镜片可回溯批次与质保期 |

### 1.6 关键业务角色

| 角色 | 职责 | 权限 |
|---|---|---|
| 视光师 | 验光、推荐、开销售单 | `m16:optical:*` |
| 视光收银员 | 收定金/尾款、退换 | `m16:optical:pay` |
| 视光主管 | 折扣审批、退换审批 | `m16:optical:manage` |

| 财务 | 视光收入对账 | 只读 |

## 3. 业务模型

### 3.1 销售单生命周期

```
    ┌────────┐  开单  ┌────────┐ 收定金 ┌─────────┐ 收齐  ┌─────────┐
    │ 新建    ├───────►│ 草稿    ├───────►│ 已付定金 ├──────►│ 已付清   │
    │        │        │ DRAFT  │        │ PARTIAL │      │  PAID   │
    └────────┘        └───┬────┘        └────┬────┘      └────┬────┘
                          │                  │                │
                      作废│              全款│            取镜 │
                          ▼                  │                ▼
                     ┌────────┐              │          ┌──────────┐
                     │ 已作废  │              │          │ 已交付    │
                     │CANCELLED│              │          │DELIVERED │
                     └────────┘              │          └────┬─────┘
                                             │               │
                                             │           退换 │
                                             │               ▼
                                             │          ┌──────────┐
                                             │          │ 已退换    │
                                             │          │ RETURNED │
                                             │          └──────────┘
                                             │
                                   定金付后全款付清
                                             └──► PAID
```

**状态定义：**

| 状态 | 含义 | 可否收钱 | 可否退换 |
|---|---|---|---|
| `DRAFT` | 已开单未付款 | 可 | 可（直接作废） |
| `PARTIAL` | 已付定金 | 可（收尾款） | 可（扣违约金后退） |
| `PAID` | 已付清未取镜 | 否 | 可（按加工状态判定） |
| `DELIVERED` | 已取镜 | 否 | 可（按质保判定） |
| `RETURNED` | 已退换 | 否 | 否 |
| `CANCELLED` | 已作废 | 否 | 否 |

### 3.2 定金模型

```
定金比例 = 配置的默认比例（如 30%）
定金金额 = ROUND(订单总额 × 定金比例, 2)
```

**规则：**

| 场景 | 处理 |
|---|---|
| 定制镜片（`processing_days > 0`） | **必须收定金**，默认 30% |
| 现货（`processing_days = 0`） | 可不收定金，直接全款 |
| 单笔 ≥ 5,000 元 | 定金比例提升至 50%（可配） |
| OK 镜（`is_custom=TRUE` 且 `category='LENS'`） | 定金比例 50%（可配） |

### 3.3 退换货判定模型

**核心：三个问题决定能不能退。**

```
① 是否已加工？
   ├── 未加工 → 可退（扣 0~10% 手续费）
   └── 已加工 → 进②
       
② 是否质量问题？
   ├── 是 → 可换/可退（全额）
   └── 否 → 进③

③ 是否在质保期内？
   ├── 是 → 可免费维修/更换
   └── 否 → 不可退，仅可付费维修
```

**判定矩阵：**

| 加工状态 | 质量问题 | 时限 | 结论 | 退款比例 |
|---|---|---|---|---|
| 未加工 | — | 下单 15 天内 | `FULL_REFUND` 全额退 | 100% |
| 未加工 | — | 下单 > 15 天 | `REFUND_WITH_FEE` 扣手续费 | 90% |
| 已加工未取镜 | 是 | — | `FULL_REFUND` 全额退 | 100% |
| 已加工未取镜 | 否 | — | `REFUSE` 拒绝 | 0% |
| 已取镜 | 是 | 质保期内 | `EXCHANGE_OR_REFUND` 换新或退 | 100% |
| 已取镜 | 是 | 超质保期 | `REPAIR_ONLY` 仅维修 | 0% |
| 已取镜 | 否 | 7 天内 | `REFUSE` 拒绝（定制片） | 0% |
| 已取镜 | 否 | — | `REFUSE` 拒绝 | 0% |

**特殊：框架眼镜（非定制）**

| 场景 | 结论 |
|---|---|
| 未加工 | 全额退 |
| 已加工，7 天内，无损坏 | 扣 20% 加工费后退 |
| 已加工，超 7 天 | 拒绝 |

### 3.4 金额构成模型

```
销售单总额 = Σ 商品金额 + Σ 服务金额 − 折扣金额

商品金额 = Σ (retail_price × quantity)
服务金额 = Σ (charge_item_price × quantity)   例：加工费、验光费
折扣金额 = 会员折扣 + 优惠券 + 手动折扣（走 M16-06 或本模块内置）

应付金额 = 总额 − 定金已付
尾款金额 = ROUND(总额 × (1 − 定金比例), 2)
```

> **行级舍入：** 同 M16-01，`line_amount = ROUND(unit_price × quantity, 2)` 后再累加。

**示例：**

```
镜架 A        ¥680.00 × 1 = ¥680.00
镜片 B（定制） ¥1,200.00 × 2 = ¥2,400.00   （双眼）
加工费        ¥40.00 × 2    = ¥80.00
配件（镜盒）   ¥30.00 × 1    = ¥30.00
──────────────────────────────────
小计                          ¥3,190.00
会员折扣 9折                  −¥319.00
──────────────────────────────────
总额                          ¥2,871.00

定金 30%                       ¥861.30
尾款                          ¥2,009.70
```

### 3.5 加工进度模型

```
PENDING（待加工）
   │ 加工师接单
   ▼
PROCESSING（加工中）
   │ 加工完成，等待到店
   ▼
READY（已到货待取）
   │ 顾客取镜
   ▼
DELIVERED（已交付）
```

**外协加工：** 若镜片外送加工，额外状态 `OUTSOURCING`（外协中）。

### 3.6 销售单与结算单的关系

```
m16_optical_order（销售单）
   │ order_no = SO20261021001, total_amount = 2,871.00
   │
   ├── m16_optical_settlement_rel（关联表，一单多结算）
   │     ├── settlement_id=1001, settle_stage='DEPOSIT', amount=861.30
   │     └── settlement_id=1002, settle_stage='FINAL',   amount=2,009.70
   │
   └── m16_optical_item（明细）
         ├─ 镜架 A      680.00 × 1
         ├─ 镜片 B    1,200.00 × 2
         ├─ 加工费       40.00 × 2
         └─ 镜盒         30.00 × 1
```

**为什么用关联表而不是在销售单上挂 `settlement_id`：** 因为一张销售单对应多个结算单（定金 + 尾款），且可能因退换产生冲红结算单。

### 3.7 顾客（无就诊记录）模型

```
有就诊记录：
  patient_id = 10021, customer_name = NULL
  （从 M03-01 取姓名、手机、性别、年龄）

无就诊记录：
  patient_id = NULL, customer_name = "张女士", customer_phone = "138****1234"
  （仅用于配镜，不建档；如需建档调 M03-01 ensure）
```

**规则：**

| 场景 | 处理 |
|---|---|
| 顾客要求开票 | **必须**有 `patient_id`（发票需要抬头与税号，可现场补建档案） |
| 顾客要求退换 | 必须有手机号，用于核验 |
| 顾客是会员 | 必须有 `patient_id`（会员挂在患者上） |
| 单纯买镜盒 | 可以不建档 |

    async def create_order(self, payload, user, trace_id: str = "") -> dict:
        """创建销售单

        流程：
          ① 校验顾客信息
          ② 逐行取商品档案，校验上下架与最低折扣
          ③ 行级算价（先舍入）
          ④ 判断定金比例
          ⑤ 计算预计取镜日
          ⑥ 落库
        """
        self._check_customer(payload.patient_id, payload.customer_name,
                             payload.customer_phone)

        if not payload.items:
            raise BizException("1604001", "销售单明细不能为空")

        if len(payload.items) > MAX_ORDER_ITEMS:
            raise BizException(40001,
                               f"单张销售单明细不得超过 {MAX_ORDER_ITEMS} 行")

        items = []
        gross = Decimal("0.00")
        discount = Decimal("0.00")
        max_processing_days = 0
        has_custom = False

        for idx, raw in enumerate(payload.items, start=1):
            line = await self._build_item(idx, raw)
            items.append(line)
            gross += line["gross_amount"]
            discount += line["discount_amount"]
            max_processing_days = max(max_processing_days,
                                      line["processing_days"])
            if line["is_custom"]:
                has_custom = True

        total = money(gross - discount)

        if total <= 0:
            raise BizException("1604007", "应收总额必须大于 0")

        # 定金比例
        ratio = self._resolve_deposit_ratio(
            payload.deposit_ratio, total, has_custom)

        if ratio < MIN_DEPOSIT_RATIO or ratio > MAX_DEPOSIT_RATIO:
            raise BizException("1604008", "定金比例超出允许范围")

        deposit_amount = money(total * ratio)
        expected_ready = None

        if max_processing_days > 0:
            expected_ready = date.today() + timedelta(days=max_processing_days)

        order_no = await self._next_order_no()

        order = M16OpticalOrder(
            order_no=order_no,
            patient_id=payload.patient_id,
            customer_name=payload.customer_name,
            customer_phone=payload.customer_phone,
            optometry_no=payload.optometry_no,
            prescription_id=payload.prescription_id,
            seller_id=payload.seller_id or (user.staff_id if user else None),
            seller_name=user.real_name if user else None,
            gross_amount=money(gross),
            discount_amount=money(discount),
            total_amount=total,
            deposit_ratio=ratio,
            deposit_amount=deposit_amount,
            paid_amount=Decimal("0.00"),
            status="DRAFT",
            expected_ready_date=expected_ready,
            processing_status="PENDING" if max_processing_days > 0 else "NONE",
            remark=payload.remark,
            trace_id=trace_id,
        )
        self.db.add(order)
        await self.db.flush()

        for line in items:
            self.db.add(M16OpticalItem(
                order_id=order.id,
                line_no=line["line_no"],
                product_type=line["product_type"],
                product_code=line["product_code"],
                product_name=line["product_name"],
                brand=line["brand"],
                spec=line["spec"],
                quantity=line["quantity"],
                eye_side=line["eye_side"],
                unit_price=line["unit_price"],

                discount_amount=line["discount_amount"],

        return self._order_dict(order, items)

    async def _build_item(self, line_no: int, raw) -> dict:
        """构造一行明细：取商品档案 + 算价 + 校验"""
        if raw.quantity <= 0:
            raise BizException("1604002", "商品数量必须大于 0")

        product = await self.mdm.get_optical_product(raw.product_code)

        if not product:
            raise BizException(40001,
                               f"商品 {raw.product_code} 不存在")

        if product.get("status") != "ON_SALE":
            raise BizException(
                "1604009", f"商品 {product.get('product_name')} 已下架，不可销售")

        # 定制镜片数量校验
        qty = Decimal(str(raw.quantity))

        if product.get("is_custom") and product.get("category") == "LENS":
            if raw.eye_side == "OU" and qty != 2:
                raise BizException("1604003",
                                   "双眼定制镜片数量必须为 2 片")
            if raw.eye_side in ("OD", "OS") and qty != 1:
                raise BizException("1604003",
                                   "单眼定制镜片数量必须为 1 片")

        # 验配要求
        if product.get("require_optometry") and not raw.optometry_no:
            raise BizException(
                "1604005",
                f"商品 {product.get('product_name')} 需要验光数据，请先完成验光")

        if product.get("is_prescription") and not raw.prescription_id:
            raise BizException(
                "1604006",
                f"商品 {product.get('product_name')} 为处方类商品，请先录入处方")

        unit_price = money(raw.unit_price)
        rate = Decimal(str(raw.discount_rate))

        # 最低折扣校验
        min_rate = Decimal(str(product.get("min_discount_rate") or 0))

        if min_rate and rate < min_rate:
            raise BizException(
                "1604004",
                f"商品 {product.get('product_name')} 成交折扣 {rate} "
                f"低于最低折扣 {min_rate}，请申请审批")

        gross = money(unit_price * qty)
        amount = money(gross * rate)
        discount_amount = money(gross - amount)

        return {
            "line_no": line_no,
            "product_type": product.get("category", "OTHER"),
            "product_code": product["product_code"],
            "product_name": product["product_name"],
            "brand": product.get("brand"),
            "spec": product.get("spec"),
            "quantity": qty,
            "eye_side": raw.eye_side,
            "unit_price": unit_price,
            "discount_rate": rate,
            "gross_amount": gross,
            "amount": amount,
            "discount_amount": discount_amount,
            "is_custom": bool(product.get("is_custom")),
            "processing_days": int(product.get("processing_days") or 0),
            "warranty_months": int(product.get("warranty_months") or 0),
        }

    def _resolve_deposit_ratio(self, requested, total: Decimal,
                               has_custom: bool) -> Decimal:
        """决定定金比例

        规则：
          · 定制商品必须收定金（最低默认比例）
          · 高价值订单提升比例
          · 用户传了就用用户的（但要 ≥ 各类下限）
        """
        ratio = (Decimal(str(requested)) if requested is not None
                 else DEFAULT_DEPOSIT_RATIO)

        floor = Decimal("0")

        if has_custom:
            floor = DEFAULT_DEPOSIT_RATIO

        if total >= HIGH_VALUE_THRESHOLD:
            floor = max(floor, HIGH_VALUE_DEPOSIT_RATIO)

        if ratio < floor:
            if has_custom:
                raise BizException(
                    "1604008",
                    f"含定制商品的销售单定金比例不得低于 {floor}")
            raise BizException("1604008", f"定金比例不得低于 {floor}")

        return ratio

    @staticmethod
    def _check_customer(patient_id, name, phone):
        """顾客信息：要么有 patient_id，要么有姓名+手机"""
        if patient_id:

        if not name or not phone:
            raise BizException(
                "1604027", "无患者档案时，请同时填写顾客姓名与手机号")

    # ---------- 收款 ----------
    async def pay(self, order_id: int, stage: str, payload, user,

        payable = money(order.total_amount - order.paid_amount)

            raise BizException("1604014", "该销售单已付清，无需再收款")

        expected = (order.deposit_amount if stage == "DEPOSIT"

                "1604015",
                f"收款金额 {amount} 与应付金额 {expected} 不一致")

        # 建结算单（M16-01）
        settlement = await self.settle_svc.create(
            source_type="OPTICAL",
            source_id=order.id,

                "charge_item_code": "OPTICAL_SALE",

            }],

        )

        payment = await self.settle_svc.pay(

        )

            order_id=order.id,
            settlement_id=settlement["settlement_id"],
            settlement_no=settlement["settlement_no"],
            settle_stage=stage,
            payment_id=payment.get("payment_id"),
            payment_no=payment.get("payment_no"),

            cashier_name=user.real_name if user else None,
            paid_at=datetime.now(),
            trace_id=trace_id,
        ))

        order.paid_amount = money(order.paid_amount + amount)

        if order.paid_amount >= order.total_amount:
            order.status = "PAID"
            order.paid_at = datetime.now()
        else:

            "order_status": order.status,

        }

            raise BizException("1604018", "存在未到货商品，不可取镜")

        if order.processing_status in ("PROCESSING", "OUTSOURCING",
                                       "PENDING"):
            raise BizException("1604019", "加工未完成，不可取镜")

        if not payload.confirm_items_ok or not payload.confirm_notice_given:
            raise BizException("1604020", "请先完成顾客确认项")

        order.status = "DELIVERED"
        order.delivered_at = datetime.now()
        order.delivered_by = user.staff_id if user else None
        order.delivered_by_name = user.real_name if user else None
        order.warranty_card_no = await self._next_warranty_no()

        lens_until = self._add_months(datetime.now().date(), 12)

        order.lens_warranty_until = lens_until
        order.frame_warranty_until = frame_until
        order.lens_batch_no = payload.lens_batch_no
        order.signature = payload.signature

        await self.db.flush()

        return {
            "order_id": order.id,
            "order_no": order.order_no,
            "status": order.status,
            "status_text": self._status_text(order.status),
            "delivered_at": order.delivered_at.isoformat(),
            "warranty": {
                "lens_warranty_months": 12,
                "lens_warranty_until": str(lens_until),
                "frame_warranty_months": 6,
                "frame_warranty_until": str(frame_until),
            },
            "warranty_card_no": order.warranty_card_no,
        }

    # ---------- 加工进度 ----------
    async def on_processing(self, payload, trace_id: str = "") -> dict:
        """加工进度回写（M10 内部契约）"""
        order = (await self.db.execute(
            select(M16OpticalOrder)
            .where(M16OpticalOrder.order_no == payload.order_no)
            .with_for_update()
        )).scalar_one_or_none()

        if not order:
            raise BizException("1604013", "销售单不存在或已作废")

        old = order.processing_status
        allowed = {
            "PENDING": ("PROCESSING", "OUTSOURCING", "CANCELLED"),
            "PROCESSING": ("READY", "OUTSOURCING", "CANCELLED"),
            "OUTSOURCING": ("PROCESSING", "READY", "CANCELLED"),
            "READY": ("DELIVERED",),
            "NONE": (),
            "DELIVERED": (),
        }

        if payload.status not in allowed.get(old, ()):
            raise BizException(
                "1604016", f"加工状态不能从 {old} 流转到 {payload.status}")

        order.processing_status = payload.status

        if payload.status == "READY":
            order.arrived_at = (payload.arrived_at
                                or datetime.now())
            order.lens_batch_no = payload.lens_batch_no

        await self.db.flush()

        return {
            "order_no": order.order_no,
            "old_status": old,
            "new_status": payload.status,
            "updated": True,
        }

    # ---------- 查询 ----------
    async def _get_order_for_update(self, order_id: int):
        order = (await self.db.execute(
            select(M16OpticalOrder)
            .where(M16OpticalOrder.id == order_id,
                   M16OpticalOrder.is_deleted == False)
            .with_for_update()
        )).scalar_one_or_none()

        if not order:
            raise BizException("1604013", "销售单不存在或已作废")

        return order

    # ---------- 编号 ----------
    async def _next_order_no(self) -> str:
        day = date.today().strftime("%Y%m%d")
        key = f"m16:optical:ordseq:{day}"
        seq = await redis_client.incr(key)

        if seq == 1:
            await redis_client.expire(key, 86400 * 3)

        return f"SO{day}{seq:04d}"

    async def _next_warranty_no(self) -> str:
        day = date.today().strftime("%Y%m%d")
        key = f"m16:optical:warseq:{day}"
        seq = await redis_client.incr(key)

        if seq == 1:
            await redis_client.expire(key, 86400 * 3)

        return f"WK{day}{seq:04d}"

    @staticmethod
    def _add_months(d: date, months: int) -> date:
        """加月份，处理月末（1月31日 + 1 月 → 2月28日）"""
        import calendar
        year = d.year + (d.month - 1 + months) // 12
        month = (d.month - 1 + months) % 12 + 1
        day = min(d.day, calendar.monthrange(year, month)[1])
        return date(year, month, day)

    @staticmethod
    def _status_text(status: str) -> str:
        return {
            "DRAFT": "草稿",
            "PARTIAL": "已付定金",
            "PAID": "已付清",
            "DELIVERED": "已交付",
            "RETURNED": "已退换",
            "CANCELLED": "已作废",
        }.get(status, status)

"""视光退换货判定与处理"""
from datetime import date, datetime

from typing import Optional

FRAME_RETURN_DAYS = 7          # 框架已加工退货天数
FRAME_RETURN_FEE_RATE = Decimal("0.20")
OVERTIME_FEE_RATE = Decimal("0.10")

class OpticalReturnService:

    # ---------- 判定 ----------
    async def preview(self, order_id: int, payload) -> dict:
        """退换判定预览：不落库"""
        order = await self._get_order(order_id)
        items = await self._get_items(order_id, payload.item_ids)

        if not items:
            raise BizException(40001, "请选择要退换的商品")

        decision, text, allowed = self._decide(
            order, payload.is_processed, payload.is_quality_issue)

        if decision == "REFUSE":
            return {
                "order_no": order.order_no,
                "order_status": order.status,
                "decision": decision,
                "decision_text": text,
                "allowed_actions": [],
                "refund_base_amount": 0.0,
                "refund_fee_rate": 0.0,
                "refund_amount": 0.0,
                "in_warranty": self._in_warranty(order, items[0]),
                "require_approval": False,
                "approval_reason": None,
                "messages": [
                    {"level": "ERROR", "text": text},
                ],
            }

        base = money(sum(Decimal(str(i.amount)) for i in items))
        fee_rate = self._fee_rate(order, payload.is_processed,
                                  payload.is_quality_issue)
        refund = money(base * (Decimal("1") - fee_rate))

        require_approval = refund >= APPROVAL_THRESHOLD
        approval_reason = None

        if require_approval:
            approval_reason = (
                f"退款金额 {refund} 元 ≥ {APPROVAL_THRESHOLD} 元，需主管审批")

        days_since_order = (date.today() - order.created_at.date()).days
        days_since_delivery = (
            (date.today() - order.delivered_at.date()).days
            if order.delivered_at else None)

        messages = []

        if self._in_warranty(order, items[0]):
            messages.append({
                "level": "INFO",
                "text": "在质保期内，可免费换新或全额退款",
            })
        elif payload.is_quality_issue:
            messages.append({
                "level": "WARN",
                "text": "已超出质保期，仅可付费维修",
            })

        return {
            "order_no": order.order_no,
            "order_status": order.status,
            "decision": decision,
            "decision_text": text,
            "allowed_actions": allowed,
            "refund_base_amount": float(base),
            "refund_fee_rate": float(fee_rate),
            "refund_amount": float(refund),
            "in_warranty": self._in_warranty(order, items[0]),
            "warranty_until": (str(order.lens_warranty_until)
                               if order.lens_warranty_until else None),
            "require_approval": require_approval,
            "approval_reason": approval_reason,
            "days_since_order": days_since_order,
            "days_since_delivery": days_since_delivery,
            "messages": messages,
        }

    def _decide(self, order, is_processed: bool,
                is_quality_issue: bool):
        """三问判定矩阵

        ① 是否已加工
        ② 是否质量问题
        ③ 是否在质保期
        """
        days = (date.today() - order.created_at.date()).days

        # 未加工
        if not is_processed:
            if days <= FREE_RETURN_DAYS:
                return ("FULL_REFUND", "未加工且在 15 天内，可全额退款",
                        ["FULL_REFUND"])
            return ("REFUND_WITH_FEE",
                    f"未加工但已超过 {FREE_RETURN_DAYS} 天，扣 10% 手续费后退款",
                    ["PARTIAL_REFUND"])

        # 已加工，质量问题
        if is_quality_issue:
            if self._in_warranty(order, None):
                return ("EXCHANGE_OR_REFUND",
                        "已加工但属质量问题且在质保期内，可换新或全额退款",
                        ["EXCHANGE", "PARTIAL_REFUND", "FULL_REFUND"])
            return ("REPAIR_ONLY", "已加工且属质量问题但超出质保期，仅可付费维修",
                    [])

        # 已加工，非质量问题
        if order.status == "PAID" and order.processing_status == "READY":
            return ("REFUSE", "定制商品已加工完成，非质量问题不可退货",
                    [])

        if order.status == "DELIVERED" and days <= FRAME_RETURN_DAYS:
            return ("REFUND_WITH_FEE",
                    f"已取镜 {days} 天内且非质量问题，扣 20% 加工费后退款",
                    ["PARTIAL_REFUND"])

        return ("REFUSE", "已加工交付且非质量问题，不可退货", [])

    def _fee_rate(self, order, is_processed: bool,
                  is_quality_issue: bool) -> Decimal:
        if not is_processed:
            days = (date.today() - order.created_at.date()).days

            if days <= FREE_RETURN_DAYS:
                return Decimal("0.00")

            return OVERTIME_FEE_RATE

        if is_quality_issue:
            if self._in_warranty(order, None):
                return Decimal("0.00")
            return Decimal("1.00")

        if order.status == "DELIVERED":
            return FRAME_RETURN_FEE_RATE

        return Decimal("1.00")

    @staticmethod
    def _in_warranty(order, item) -> bool:
        if order.lens_warranty_until:
            return date.today() <= order.lens_warranty_until

        if order.frame_warranty_until:
            return date.today() <= order.frame_warranty_until

        return False

    # ---------- 提交 ----------
    async def submit(self, order_id: int, payload, user,
                     trace_id: str = "") -> dict:
        """提交退换：建退换单 + 触发退款（M16-08）"""
        order = (await self.db.execute(
            select(M16OpticalOrder)
            .where(M16OpticalOrder.id == order_id)
            .with_for_update()
        )).scalar_one_or_none()

        if not order:
            raise BizException("1604013", "销售单不存在或已作废")

        if order.status == "RETURNED":
            raise BizException("1604021", "该销售单已退换，不可重复退换")

        if order.status == "CANCELLED":
            raise BizException("1604022", "已作废的销售单不可退换")

        preview = await self.preview(order_id, payload)
        decision = preview["decision"]

        if decision == "REFUSE":
            raise BizException("1604024", preview["decision_text"])

        refund_amount = money(preview["refund_amount"])

        if refund_amount > order.paid_amount:
            raise BizException(
                "1604023",
                f"退款金额 {refund_amount} 超过该单实付 {order.paid_amount}")

        if payload.action == "PARTIAL_REFUND" and not payload.approval_id:
            raise BizException("1604026", "部分退款必须经过审批")

        return_no = await self._next_return_no()

        record = M16OpticalReturn(
            return_no=return_no,
            order_id=order.id,
            order_no=order.order_no,
            item_ids=payload.item_ids,
            action=payload.action,
            decision=decision,
            is_processed=payload.is_processed,
            is_quality_issue=payload.is_quality_issue,
            issue_desc=payload.issue_desc,
            refund_base_amount=Decimal(str(preview["refund_base_amount"])),
            refund_fee_rate=Decimal(str(preview["refund_fee_rate"])),
            refund_amount=refund_amount,
            status="APPROVING" if preview["require_approval"] else "APPROVED",
            approval_id=payload.approval_id,
            operator_id=user.staff_id if user else None,
            operator_name=user.real_name if user else None,
            trace_id=trace_id,
        )
        self.db.add(record)

        if preview["require_approval"] and not payload.approval_id:
            await self.db.flush()
            return self._return_dict(record, "待审批")

        # 退款走 M16-08
        order.status = "RETURNED"
        order.returned_at = datetime.now()
        record.status = "COMPLETED"
        record.completed_at = datetime.now()

        await self.db.flush()

        return self._return_dict(record, "已完成")

    # ---------- 查询 ----------
    async def _get_order(self, order_id: int) -> M16OpticalOrder:
        order = (await self.db.execute(
            select(M16OpticalOrder)
            .where(M16OpticalOrder.id == order_id,
                   M16OpticalOrder.is_deleted == False)
        )).scalar_one_or_none()

        if not order:
            raise BizException("1604013", "销售单不存在或已作废")

        return order

    async def _get_items(self, order_id: int, item_ids) -> list:
        stmt = select(M16OpticalItem).where(
            M16OpticalItem.order_id == order_id,
            M16OpticalItem.is_deleted == False,
        )

        if item_ids:
            stmt = stmt.where(M16OpticalItem.id.in_(item_ids))

        return list((await self.db.execute(stmt)).scalars().all())

    async def _next_return_no(self) -> str:
        from app.core.redis import redis_client
        day = date.today().strftime("%Y%m%d")
        key = f"m16:optical:retseq:{day}"
        seq = await redis_client.incr(key)

        if seq == 1:
            await redis_client.expire(key, 86400 * 3)

        return f"OTR{day}{seq:04d}"

    @staticmethod
    def _return_dict(record, status_text: str) -> dict:
        return {
            "return_id": record.id,
            "return_no": record.return_no,
            "order_no": record.order_no,
            "action": record.action,
            "decision": record.decision,
            "refund_amount": float(record.refund_amount),
            "status": record.status,
            "status_text": status_text,
            "created_at": record.created_at.isoformat()
            if record.created_at else None,
        }

async def _daily_report(biz_date: str = None):
    from datetime import date
    from sqlalchemy import select, func
    from app.core.database import AsyncSessionLocal
    from app.models.m16.optical import (
        M16OpticalOrder, M16OpticalDailySummary,
    )

    day = date.fromisoformat(biz_date) if biz_date else date.today()

    async with AsyncSessionLocal() as db:
        rows = (await db.execute(
            select(
                M16OpticalOrder.seller_id,
                M16OpticalOrder.seller_name,
                func.count(M16OpticalOrder.id),
                func.sum(M16OpticalOrder.total_amount),
                func.sum(M16OpticalOrder.paid_amount),
            ).where(
                func.date(M16OpticalOrder.created_at) == day,
                M16OpticalOrder.status != "CANCELLED",
                M16OpticalOrder.is_deleted == False,
            ).group_by(M16OpticalOrder.seller_id,
                       M16OpticalOrder.seller_name)
        )).all()

        for seller_id, seller_name, cnt, total, paid in rows:
            db.add(M16OpticalDailySummary(
                stat_date=day,
                seller_id=seller_id,
                seller_name=seller_name,
                order_count=cnt,
                total_amount=total or 0,
                paid_amount=paid or 0,
                unpaid_amount=(total or 0) - (paid or 0),
            ))

        await db.commit()

    return {"date": str(day), "rows": len(rows)}
