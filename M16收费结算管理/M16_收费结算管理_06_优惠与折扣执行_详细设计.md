## 1. 模块概述

### 1.1 模块定位

优惠与折扣执行（下称 M16-06）负责「这笔钱该不该打折、打几折、为什么要打、谁批的、打了之后怎么退」的**判定与执行**。它是 M16 计费链路中**唯一会改变应付金额**的环节，也是唯一会留下「为什么少收了钱」证据的环节。

```
                     ┌──────────────────────────────┐
   M01-06 主数据      │  优惠方案档案                 │
   md_discount_policy │  P01 满减 / 折扣 / 套餐 / 赠送  │
   md_charge_item     └──────────────┬───────────────┘
                                     │ 只读消费
                     ┌───────────────▼──────────────┐
   M03-03 会员等级    │  M16-06 优惠与折扣执行        │
   患者标签           │                              │
   M04-06 特殊身份    │  ①匹配可用方案               │
   （优抚/残疾/军人） │  ②逐级计算（等级→方案→手动）  │
                     │  ③审批（超阈值走流程）        │
                     │  ④落账（写优惠明细+审批单）    │
                     │  ⑤回退（结算单作废时）        │
                     └───────────────┬──────────────┘
                                     │ 提供优惠结果
                     ┌───────────────▼──────────────┐
                     │  M16-01 结算单与计费引擎      │
                     │  payable = total - discount  │
                     └───────────────┬──────────────┘
                                     │
                     ┌───────────────▼──────────────┐
                     │  M16-02 门诊收费 / M16-08 退费 │
                     └──────────────────────────────┘
```

**M16-06 回答的三个问题：**

1. **能不能打？** —— 这个患者有哪些可用优惠？为什么这个方案不可用（门槛未满、限次已用完、不在有效期、不适用这个科室）？
2. **打多少？** —— 多个优惠叠加时的顺序与精度，会员等级折扣与外院合作折扣冲突时谁优先。
3. **谁负责？** —— 超出医师/收费员权限的折扣谁批的、凭什么批的、审批链在哪。

### 1.2 为什么独立成子模块

| 维度 | 并入 M16-01 计费引擎 | 并入 M16-02 门诊收费 | 独立为 M16-06 |
|---|---|---|---|
| 优惠计算复杂度 | 计费引擎已管价格/数量/眼别，再塞优惠会变成 800 行以上的巨型方法 | 收银台只关心「收多少钱」，不该关心「为什么打折」 | ✅ 独立的匹配 + 叠加 + 审批链路 |
| 审批流 | 计费引擎不该有审批 | 收银员无审批权限 | ✅ 折扣审批是独立的流程实体 |
| 优惠核销 | 核销次数与会话无关 | 与收银台次强相关 | ✅ 券码/权益核销需要自己的状态机 |
| 审计要求 | 混合在计费日志里 | 混合在收费日志里 | ✅ 折扣是「少收钱」，审计必须单独立账 |
| 复用面 | 门诊、住院、视光都要用 | 只有门诊收费用 | ✅ 三场景共用同一套引擎 |

**核心理由：折扣是一个「会引发腐败风险」的操作。** 一个收费员如果能随意把 300 元的检查改成 30 元，没有任何留痕，这家医院的钱就是漏的。M16-06 存在的最大价值不是算得准，而是**每一分少收的钱都能追溯到「依据什么方案/谁批的/什么时间/为什么」**。

### 1.3 与相邻子模块分工

| 事项 | M16-06 | M16-01 计费引擎 | M16-02 门诊收费 | M03-03 会员 | M01-06 收费主数据 |
|---|---|---|---|---|---|
| 优惠方案建档（满减 100 减 20） | ❌ 只读 | ❌ | ❌ | ❌ | ✅ 唯一责任 `md_discount_policy` |
| 会员等级与等级折扣率 | ❌ 只读 | ❌ | ❌ | ✅ 唯一责任 | ❌ |
| 判断「这个患者能享受哪些优惠」 | ✅ 唯一责任 | ❌ | ❌ | ❌ | ❌ |
| 计算优惠金额、叠加顺序 | ✅ 唯一责任 | ❌ 只接收结果 | ❌ | ❌ | ❌ |
| 折扣审批（超权限折扣） | ✅ 唯一责任 | ❌ | ❌ 只发起 | ❌ | 提供审批规则 |
| 优惠券核销次数扣减 | ✅ 唯一责任 | ❌ | ❌ | ❌ | 提供总配额 |
| 应收金额 = 总额 − 优惠 | ❌ | ✅ 唯一责任 | ❌ | ❌ | ❌ |
| 收银员手工减免录入 | ❌ 只校验 | ❌ | ✅ 唯一责任（录入动作） | ❌ | 提供 `max_discount_rate` |
| 退费时优惠如何回退 | ✅ 提供回退计算 | ❌ | ❌ | ❌ | 提供 `allow_refund` |
| 优惠后的实收记账 | ❌ | ✅ | ✅ | ❌ | ❌ |

> **✅ 标注的是唯一责任方**，其余方只能消费，不得自行计算。

### 1.4 概念辨析

| 概念 | 定义 | 举例 | 归属 |
|---|---|---|---|
| **折扣率（discount_rate）** | 按比例减少的系数，0.85 表示 85 折 | 会员金卡 85 折 | 方案属性 |
| **满减（full_reduce）** | 达到门槛后减固定金额 | 满 200 减 30 | 方案属性 |
| **套餐价（package_price）** | 一组项目的整体价格 | 术前检查套餐 380 元 | 方案属性 |
| **赠送（gift）** | 免费送项目，不减金额但免收该部分 | 满 500 赠一次裂隙灯检查 | 方案属性 |
| **优惠方案（policy）** | 一份完整的优惠规则定义 | 「教师节教师检查 8 折」 | M01-06 `md_discount_policy` |
| **权益券（voucher）** | 患者持有的、可核销一次的优惠凭证 | 患者 A 持有一张「满 300 减 50」券 | M16-06 `m16_discount_apply` |
| **优惠明细（apply）** | 某次结算应用了哪个方案、减了多少钱 | 结算单 S001 应用了教师节 8 折，减 42 元 | M16-06 `m16_discount_apply` |
| **手动折扣（manual）** | 无方案依据、由人指定的减免 | 科主任批准给困难患者减 100 元 | M16-06 `m16_discount_approval` |
| **审批（approval）** | 超阈值折扣的批准记录 | 医务科李主任批准减免 800 元 | M16-06 `m16_discount_approval` |
| **优惠叠加（stacking）** | 多个优惠同时应用 | 会员 9 折 + 满 200 减 30 | 方案属性 `allow_stack` |
| **最优组合（best combo）** | 在所有合法叠加中选减免最多的组合 | 试算 3 种组合，选减 105 元那个 | 算法结果 |

**容易混淆的两组：**

- **折扣 vs 优惠**：折扣是「打几折」，是比率；优惠是所有减少应收的手段（含满减、套餐、赠送、折扣）。本文档统一叫「优惠」，折扣是其子集。
- **优惠明细 vs 审批单**：优惠明细是「发生了优惠」的结果；审批单是「允许发生优惠」的许可。有方案依据的优惠（如会员 9 折）不需要审批单；无方案依据的手动折扣必须有审批单。

### 1.5 模块目标

| 编号 | 目标 | 指标 | 验收方式 |
|---|---|---|---|
| G-01 | 优惠计算准确 | 计算错误率 < 0.01% | 每日对账校验 |
| G-02 | 优惠匹配快 | 可用方案查询 P95 ≤ 100ms | 性能压测 |
| G-03 | 试算快 | 单次试算（3 个方案）P95 ≤ 150ms | 性能压测 |
| G-04 | 审批时效 | 超阈值折扣平均审批时长 ≤ 10 分钟 | 月度统计 |
| G-05 | 全量留痕 | 折扣留痕率 100%，无审批单的手动折扣为 0 | 每日巡检 |
| G-06 | 降级可用 | 方案服务不可用时收费不中断 | 故障演练 |
| G-07 | 核销准确 | 核销超用率 0 | 每日巡检 |
| G-08 | 回退可算 | 结算单作废后优惠回退准确率 100% | 场景测试 |

**G-06 降级要求的具体含义：** 如果 M01-06 的方案主数据服务不可达，M16-06 必须能在 200ms 内返回「无可用优惠」，让收费继续，而不是让患者排队等。宁可少收优惠，不可堵住收费窗口——这是本模块与「准确性」并列的第一原则。

## 3. 业务模型

### 3.1 优惠类型模型

M16-06 支持四类优惠（方案属性 `policy_type` 由 M01-06 定义）：

| policy_type | 中文 | 计算方式 | 例子 |
|---|---|---|---|
| `DISCOUNT` | 比例折扣 | `reduce = ROUND(base × (1 - discount_rate), 2)` | 9 折：base × 0.10 |
| `FULL_REDUCE` | 满减 | `base >= full_amount` 时 `reduce = reduce_amount` | 满 200 减 30 |
| `PACKAGE` | 套餐价 | `reduce = original_amount - package_amount` | 三项检查原价 500，套餐 380 |
| `GIFT` | 赠送 | `reduce = 被赠项目金额`（该项目应收归零） | 满 500 赠裂隙灯（40 元） |

### 3.2 优惠叠加模型

M01-06 方案上有 `allow_stack`（是否允许叠加）与 `stack_priority`（叠加优先级，值小优先）。

**叠加顺序（从先到后）：**

```
① 会员等级折扣（M03-03 提供等级折扣率）
        │
        ▼
② 身份优惠（优抚/残疾/军人，M04-06 提供）
        │
        ▼
③ 方案优惠（md_discount_policy，按 stack_priority 升序）
   ├── allow_stack = FALSE 的方案一旦应用，结束后续方案匹配
   └── allow_stack = TRUE 的方案继续叠加
        │
        ▼
④ 手动折扣（人工录入，必须有审批或阈值内）
```

**两种减法模式（M01-06 §3.5 定义，M16-06 执行）：**

| 模式 | 公式 | 举例（原价 200，9 折，满 200 减 30） |
|---|---|---|
| `RATE_FIRST`（先折后减，默认） | `payable = ROUND(total × rate, 2) - reduce_amount` | 200×0.9=180，再减 30 → **150** |
| `REDUCE_FIRST`（先减后折） | `payable = ROUND((total - reduce_amount) × rate, 2)` | 200-30=170，再乘 0.9 → **153** |

> **模式存在总金额字段 `m16_settlement.discount_mode` 上，一张结算单只能用一种模式。** 混合模式会导致「先折后减」和「先减后折」对同一张单产生不同的结果，无法对账。

### 3.3 最优组合选择算法

当一个结算单有 N 个可选方案，且并非所有方案都允许互相叠加时，需要在合法的叠加组合中选出减免最多的。

**问题规模：** 单张结算单可用的方案通常 ≤ 8 个（会员折扣 1 + 身份优惠 1 + 常规方案 3~5 + 手动 1）。

**算法：** 由于 N ≤ 8，直接暴力枚举所有子集（2^8 = 256 种），对每个子集验证叠加合法性，取减免最大值。复杂度 256 × O(项目数)，项目数通常 ≤ 30，完全可以接受。

```
候选方案集合 P = [p1, p2, ..., pn]   n ≤ MAX_CANDIDATE(8)
best = (reduce=0, combo=[])
for each subset S of P:                 # 2^n 个子集
    if not is_stackable(S): continue     # 检查 allow_stack 冲突
    if not meets_conflict(S): continue   # 检查互斥规则
    result = compute(S)                  # 按叠加顺序计算
    if result.reduce > best.reduce:
        best = result
return best
```

**为什么不用动态规划：** 折扣是乘法、满减是减法、赠送是赋值，三者混合后不满足最优子结构，DP 不适用。

**`is_stackable` 判定：** 子集 S 若包含任何一个 `allow_stack=FALSE` 的方案，则 S 只能是单元素集合；否则全部允许。

**`meets_conflict` 判定：** 检查 `md_discount_policy` 上的 `apply_charge_classes` 与 `apply_dept_ids` 是否与本次项目冲突，以及互斥规则表（见 §3.7）。

### 3.4 优惠计算模型

#### 3.4.1 计算基准（base）的确定

优惠不是针对「结算单总额」算的，而是针对**可优惠金额**算的：

```
base = Σ (允许参与优惠的明细行金额)
```

一行明细允许参与优惠的条件：

| 条件 | 来源 | 说明 |
|---|---|---|
| `md_charge_item.allow_discount = TRUE` | M01-06 | 项目级开关 |
| 该行状态不是 `REVERSED` | M16-01 | 红冲行不参与 |
| 该行不是赠送行 | M16-06 | `is_gift=TRUE` 的行已被优惠过，不再参与 |
| 该行 `bill_quantity > 0` | M16-01 | 负数行（冲销）不参与 |

**举例：** 结算单含「裂隙灯检查 40 元（可优惠）」「药品费 100 元（不可优惠）」，则 base = 40，满 200 减 30 不成立。

#### 3.4.2 行级先舍入

```
line_base = ROUND(unit_price × bill_quantity, 2)
base = Σ line_base
reduce = ROUND(base × (1 - rate), 2)
payable_after = base - reduce
```

**为什么行级先舍入：** 若先累加再舍入，明细行数不同会导致同一批项目在不同组合下算出差 1 分的结果，退费时对不上账。

#### 3.4.3 优惠金额不得超过 base

`reduce = min(reduce, base)`，且 `payable_after >= 0`。若算法得出 `reduce > base`（例如满 500 减 600），截断为 `reduce = base`，并记 `discount_capped=TRUE`，产生 `LOW` 级告警日志（说明方案配置有问题）。

### 3.5 优惠券（权益券）核销模型

**券的来源：** M01-06 方案上的 `total_quota` / `limit_per_person` 定义配额；M03 会员权益发放券码；M19 营销发放券码。M16-06 只做核销。

**券码结构：** `V{14位日期}{4位序号}{4位校验码}`，共 22 位。

**核销状态机：**

```
ISSUED（已发放）──► LOCKED（锁定中，30 分钟内不可他用）──► USED（已核销，终态）
      │                        │
      │                        └──► ISSUED（锁定超时自动释放）
      └──► EXPIRED（已过期）
      └──► VOIDED（已作废）
```

**锁定机制：** 收费员选券后，Redis `SET m16:discount:voucher:{code} LOCK <port> NX EX 1800` 锁定 30 分钟，防止同一张券在两个窗口同时使用。结算单作废或收银员取消时主动释放。

### 3.6 手动折扣与审批模型

**手动折扣的下限：** 由三层决定，取最严格的一个：

```
min_rate = MAX(
    md_charge_item.min_discount_rate,        # 项目级下限（M01-06）
    md_discount_policy.min_discount_rate,    # 方案级下限（M01-06）
    system_param M16.DISCOUNT.MIN_RATE,      # 系统级下限（本条）
    1 - (医师/收费员个人授权额度)             # 个人权限下限
)
```

**审批阈值与审批层级：**

| 折扣率区间 | 需审批 | 审批人 | 时限 |
|---|---|---|---|
| rate ≥ `AUTO_LIMIT`（默认 0.95） | 不需要 | — | — |
| `DIRECTOR_LIMIT` ≤ rate < `AUTO_LIMIT`（默认 0.90） | 需要 | 科主任 | 30 分钟 |
| `MEDICAL_LIMIT` ≤ rate < `DIRECTOR_LIMIT`（默认 0.80） | 需要 | 医务科 | 60 分钟 |
| rate < `MEDICAL_LIMIT` | 需要 | 医务科 + 财务主管（双签） | 120 分钟 |

**折扣金额也参与判断：** 除了折扣率，减免金额也是触发条件。

```
needs_approval = (rate < AUTO_LIMIT) OR (reduce_amount >= AMOUNT_THRESHOLD)
```

`AMOUNT_THRESHOLD` 默认 300 元。降低 1 分钱不是问题，减 300 元就必须有人负责。

**审批状态机：**

```
DRAFT ──► PENDING ──► APPROVED ──► APPLIED（已写入优惠明细）
             │            │
             │            └──► VOIDED（结算单作废，优惠撤销）
             ├──► REJECTED（终态）
             └──► TIMEOUT（超时未批，自动 REJECTED）
```

**审批期间的锁定：** 从 `PENDING` 开始，结算单进入「待审批锁定」，不能收费、不能修改明细、不能作废。锁定由 `m16_settlement.locked_by_approval` 标记。**否则会出现「审批期间金额被改」的漏洞。**

### 3.7 互斥与冲突规则

| 冲突类型 | 规则 | 错误码 |
|---|---|---|
| 同类型方案互斥 | 同一 `policy_type` 的两个方案不可同时应用（两个满减不能叠加） | 54959 |
| 指定互斥 | 方案 A 的 `exclusive_with` 列表含方案 B，则二者不可同时应用 | 54959 |
| 套餐互斥 | 套餐价方案与单项目的比例折扣不可同时应用（套餐内项目不再打折） | 54959 |
| 赠送互斥 | 同一被赠项目不能同时出现在两个赠送方案里 | 54959 |
| 身份互斥 | 优抚、残疾、军人身份三者只能取其一（取折扣最大的） | 不报错，自动取优 |
| 会员与身份 | 会员折扣与身份折扣可叠加，取 `allow_stack` 判定 | — |

### 3.8 优惠回退模型

结算单作废或部分退费时，已应用的优惠必须相应回退。

**全额作废：** 所有优惠明细置 `status='REVOKED'`，券码恢复 `ISSUED`（若未过期），审批单置 `VOIDED`，配额返还。

**部分退费：** 按退费行占原单 base 的比例分摊优惠。

```
refund_discount_share = ROUND(apply.reduce_amount × (refund_base / total_base), 2)
```

**举例：** 原单 base 400 元，应用满 200 减 30。退费行 base 100 元（25%），则优惠按比例回退 30 × 0.25 = 7.5 元，实际退给患者 `100 - 7.5 = 92.5` 元。

> **这是医院最容易扯皮的地方。** 患者会说「我退了 1/4，为什么只退 92.5 不是 100？」所以收银台必须在小票上打印「原价 100 元，优惠分摊 7.5 元，实退 92.5 元」。

### 3.9 优惠降级模型

**降级原则：先收上钱比优惠准确更重要。**

| 降级场景 | 降级动作 | 标记 |
|---|---|---|
| M01-06 方案服务超时（> 200ms） | 返回空优惠列表 | `discount_degraded=TRUE` |
| M03-03 会员服务超时 | 按普通患者计（无等级折扣） | `member_degraded=TRUE` |
| M04-06 身份服务超时 | 不应用身份优惠 | `benefits_degraded=TRUE` |
| 最优组合计算超时（> 500ms） | 只应用会员折扣，不应用方案优惠 | `combo_degraded=TRUE` |
| M01-11 审批服务不可用 | **不降级**，拒绝超阈值折扣，报 54958 | — |

**降级后的补偿：** 降级产生的少收优惠，允许在 24 小时内通过「优惠补录」接口补做（`POST /api/v1/m16/discount/supplement`），补录需财务主管权限。补录不改变已收金额，只修正账务记录。

| 可优惠基数 | 参与优惠的明细金额合计（§3.4.1） |
| 折扣模式 | `RATE_FIRST` / `REDUCE_FIRST`，由系统参数决定，界面只读 |
| 组合 | 一个合法的方案子集 |
| 减免 | 该组合的总减免额 |
| 最优 | 减免最大的组合，加星标 |
| 明细分摊 | 按行 base 比例分摊优惠（行级先舍入，尾差调到最后一行） |

**尾差处理：** 分摊后各行优惠之和若不等于总减免，差额（±1~2 分）调整到 base 最大的那一行。

**交互说明**

| 编号 | 操作 | 效果 |
|---|---|---|
| I-01 | 切换折扣模式 | 仅财务主管可切换，切换后重算全部组合 |
| I-02 | 选择组合 | 高亮，弹出明细分摊预览 |
| I-03 | 确认应用 | 调 `POST /internal/v1/m16/discount/apply`，成功后返回收银台 |
| I-04 | 组合含身份优惠 | 弹出身份核验证件号输入框 |

**校验规则**

| 编号 | 规则 | 错误码 |
|---|---|---|
| V-01 | 组合含 `allow_stack=FALSE` 的方案且不止一个 | 54959 方案不可叠加 |
| V-02 | 减免额 > 基数 | 截断并记 `discount_capped` |
| V-03 | 结算单已收费 | 54956 结算单状态不允许应用优惠 |
| V-04 | 结算单已应用过优惠 | 幂等返回（不重复应用） |
| V-05 | 试算超时 500ms | 降级为只应用会员折扣，提示重试 |

```python
# app/services/m16/discount_service.py
"""M16-06 优惠与折扣执行 核心服务"""
from __future__ import annotations

import asyncio
import itertools
from datetime import datetime, date, timedelta
from decimal import Decimal, ROUND_HALF_UP
from typing import Optional

import structlog
from sqlalchemy import select, update, func, and_, or_
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.m16.discount import (
    M16DiscountApply, M16DiscountItem, M16DiscountVoucher,
    M16DiscountApproval, M16DiscountLog, M16DiscountConfig,
)
from app.services.m16.errors import M16Error


logger = structlog.get_logger(__name__)

CENT = Decimal("0.01")
MAX_CANDIDATE = 8
TRIAL_TIMEOUT_MS = 500
AVAILABLE_TIMEOUT_MS = 200


def money(v) -> Decimal:
    """金额统一保留 2 位小数，四舍五入"""
    return Decimal(str(v)).quantize(CENT, rounding=ROUND_HALF_UP)


class DiscountService:
    """优惠查询、试算、应用、撤销"""

    def __init__(self, db: AsyncSession):
        self.db = db

    # ---------------- 查询可用优惠 ----------------

    async def query_available(
        self,
        patient_id: int,
        settlement_no: Optional[str],
        dept_id: Optional[int],
    ) -> dict:
        """查询患者可用的优惠方案（带降级）"""
        base = await self._load_base(settlement_no) if settlement_no else None
        if base is None:
            raise M16Error(54952, "项目清单为空，无可用优惠")

        member = await self._load_member_safe(patient_id)
        benefits = await self._load_benefits_safe(patient_id)

        try:
            policies = await asyncio.wait_for(
                self._load_policies(base, dept_id),
                timeout=AVAILABLE_TIMEOUT_MS / 1000)
        except asyncio.TimeoutError:
            logger.warning("discount.policy_timeout",
                           patient_id=patient_id, trace="degraded")
            return {
                "patient_id": patient_id,
                "member_level_code": member.get("level_code") if member else None,
                "member_level_name": member.get("level_name") if member else None,
                "base_amount": str(base["amount"]),
                "item_count": base["item_count"],
                "candidates": [],
                "degraded": True,
                "degrade_reason": "方案服务超时",
            }

        candidates = []
        for p in policies:
            ok, reason = self._check_policy(p, base, member, benefits)
            candidates.append({
                "policy_code": p["code"],
                "policy_name": p["name"],
                "policy_type": p["type"],
                "discount_rate": p.get("rate"),
                "reduce_amount": str(self._policy_reduce(p, base)) if ok else "0.00",
                "available": ok,
                "unavailable_reason": reason,
                "allow_stack": p["allow_stack"],
                "stack_priority": p["stack_priority"],
                "valid_from": p.get("valid_from"),
                "valid_to": p.get("valid_to"),
                "limit_per_person": p.get("limit_per_person"),
                "used_by_patient": p.get("used_by_patient", 0),
            })

        candidates.sort(key=lambda x: (not x["available"], x["stack_priority"]))
        return {
            "patient_id": patient_id,
            "member_level_code": member.get("level_code") if member else None,
            "member_level_name": member.get("level_name") if member else None,
            "base_amount": str(base["amount"]),
            "item_count": base["item_count"],
            "candidates": candidates,
            "degraded": False,
        }

    def _check_policy(self, p: dict, base: dict, member, benefits) -> tuple:
        """判断单个方案是否可用，返回 (可用, 不可用原因)"""
        today = date.today()
        if p.get("valid_from") and today < p["valid_from"]:
            return False, "活动未开始（%s）" % p["valid_from"]
        if p.get("valid_to") and today > p["valid_to"]:
            return False, "活动已结束（%s）" % p["valid_to"]
        if p.get("status") != "ACTIVE":
            return False, "方案已停用"
        if p["type"] == "FULL_REDUCE" and base["amount"] < p["full_amount"]:
            return False, "未达门槛（差 ¥%s）" % money(
                p["full_amount"] - base["amount"])
        if p["type"] == "PACKAGE" and base["item_count"] < p.get("min_items", 1):
            return False, "需要 %d 项，当前 %d 项" % (
                p["min_items"], base["item_count"])
        if p.get("require_identity") and not benefits.get(p["require_identity"]):
            return False, "患者非%s对象" % p["require_identity_text"]
        if p.get("limit_per_person"):
            if p.get("used_by_patient", 0) >= p["limit_per_person"]:
                return False, "已达个人限次（%d/%d）" % (
                    p["used_by_patient"], p["limit_per_person"])
        if p.get("apply_dept_ids") and base.get("dept_id"):
            if base["dept_id"] not in p["apply_dept_ids"]:
                return False, "不适用当前科室"
        return True, None

    def _policy_reduce(self, p: dict, base: dict) -> Decimal:
        """单个方案的减免额"""
        b = base["amount"]
        if p["type"] == "DISCOUNT":
            r = money(b * (Decimal("1") - Decimal(str(p["rate"]))))
        elif p["type"] == "FULL_REDUCE":
            r = money(p["reduce_amount"]) if b >= p["full_amount"] \
                else Decimal("0.00")
        elif p["type"] == "PACKAGE":
            r = money(p["original_amount"] - p["package_amount"])
        elif p["type"] == "GIFT":
            r = money(p.get("gift_amount") or 0)
        else:
            r = Decimal("0.00")
        if p.get("max_reduce_amount"):
            r = min(r, money(p["max_reduce_amount"]))
        return min(r, b)

    # ---------------- 试算 ----------------

    async def trial(
        self,
        settlement_no: str,
        policy_codes: list,
        discount_mode: str,
        top_n: int,
    ) -> dict:
        """试算并返回前 top_n 个最优组合"""
        base = await self._load_base(settlement_no)
        if base is None:
            raise M16Error(54952, "项目清单为空，无可用优惠")
        if len(policy_codes) > MAX_CANDIDATE:
            raise M16Error(54974, "候选方案超过 %d 个" % MAX_CANDIDATE)

        policies = await self._load_policies_by_codes(policy_codes)
        policy_map = {p["code"]: p for p in policies}

        started = datetime.now()
        combos = []
        for r in range(1, len(policies) + 1):
            for subset in itertools.combinations(policies, r):
                if datetime.now() - started > timedelta(
                        milliseconds=TRIAL_TIMEOUT_MS):
                    logger.warning("discount.trial_timeout",
                                   settlement_no=settlement_no)
                    break
                if not self._is_stackable(subset):
                    continue
                if not self._meets_conflict(subset):
                    continue
                combos.append(self._compute_combo(subset, base, discount_mode))

        combos.sort(key=lambda c: c["reduce_amount"], reverse=True)
        top = combos[:top_n]
        for i, c in enumerate(top):
            c["is_best"] = (i == 0)

        return {
            "base_amount": str(base["amount"]),
            "discount_mode": discount_mode,
            "combos": top,
            "excluded": self._excluded_note(policy_codes, policies, base),
            "elapsed_ms": int((datetime.now() - started).total_seconds() * 1000),
        }

    @staticmethod
    def _is_stackable(subset) -> bool:
        """子集是否可叠加：含任一 allow_stack=FALSE 时只能单元素"""
        if len(subset) <= 1:
            return True
        return all(p["allow_stack"] for p in subset)

    @staticmethod
    def _meets_conflict(subset) -> bool:
        """检查互斥：同类型互斥 + 显式互斥表"""
        types = [p["type"] for p in subset if p["type"] in (
            "DISCOUNT", "FULL_REDUCE", "PACKAGE")]
        if len(types) != len(set(types)):
            return False
        codes = {p["code"] for p in subset}
        for p in subset:
            if codes & set(p.get("exclusive_with") or []):
                return False
        return True

    def _compute_combo(self, subset, base, mode) -> dict:
        """按叠加顺序计算一个组合的最终减免与分摊"""
        total = base["amount"]

        # ① 会员折扣
        rate = Decimal("1")
        for p in subset:
            if p.get("is_member"):
                rate = min(rate, Decimal(str(p["rate"])))

        # ② 身份优惠
        for p in subset:
            if p.get("is_identity") and p["type"] == "DISCOUNT":
                rate = min(rate, Decimal(str(p["rate"])))

        # ③ 方案优惠（非会员非身份）
        ratio_ps = [p for p in subset
                    if not p.get("is_member") and not p.get("is_identity")
                    and p["type"] == "DISCOUNT"]
        for p in ratio_ps:
            rate = min(rate, Decimal(str(p["rate"])))

        reduce_sum = sum(
            money(p["reduce_amount"]) for p in subset
            if not p.get("is_member") and not p.get("is_identity")
            and p["type"] in ("FULL_REDUCE", "PACKAGE", "GIFT"))

        if mode == "RATE_FIRST":
            after = money(total * rate) - reduce_sum
        else:  # REDUCE_FIRST
            after = money((total - reduce_sum) * rate)

        after = max(after, Decimal("0.00"))
        reduce_total = total - after
        capped = False
        if reduce_total > total:
            reduce_total = total
            after = Decimal("0.00")
            capped = True

        items = self._allocate(base, reduce_total)
        return {
            "policy_codes": [p["code"] for p in subset],
            "reduce_amount": str(reduce_total),
            "payable_amount": str(after),
            "effective_rate": str(money(after / total)) if total else "0.00",
            "requires_identity_check": [
                p["require_identity"] for p in subset if p.get("require_identity")],
            "items": items,
            "discount_capped": capped,
        }

    @staticmethod
    def _allocate(base: dict, reduce_total: Decimal) -> list:
        """把总减免分摊到明细行，尾差调到最大行"""
        lines = base["lines"]
        total = base["amount"]
        out = []
        acc = Decimal("0.00")
        max_idx = 0
        max_amt = Decimal("-1")
        for i, ln in enumerate(lines):
            share = money(reduce_total * (ln["base_amount"] / total)) \
                if total else Decimal("0.00")
            if i == 0:
                pass
            acc += share
            if ln["base_amount"] > max_amt:
                max_amt = ln["base_amount"]
                max_idx = i
            out.append({
                "settlement_item_id": ln["item_id"],
                "item_code": ln["item_code"],
                "base_amount": str(ln["base_amount"]),
                "reduce_amount": share,
                "payable": str(money(ln["base_amount"] - share)),
            })
        diff = reduce_total - acc
        if diff != Decimal("0.00"):
            out[max_idx]["reduce_amount"] += diff
            out[max_idx]["payable"] = str(money(
                Decimal(out[max_idx]["base_amount"])
                - out[max_idx]["reduce_amount"]))
        for o in out:
            o["reduce_amount"] = str(o["reduce_amount"])
        return out

    # ---------------- 应用 ----------------

    async def apply(
        self,
        settlement_no: str,
        policy_codes: list,
        discount_mode: str,
        voucher_code: Optional[str],
        operator_id: int,
        operator_name: str,
        ip: Optional[str],
    ) -> dict:
        """把优惠结果写入结算单"""
        # ① 结算单状态校验（FOR UPDATE 防并发）
        settle = await self._lock_settlement(settlement_no)
        if settle is None:
            raise M16Error(54972, "结算单不存在")
        if settle.status not in ("DRAFT", "PENDING"):
            raise M16Error(54972, "结算单状态 %s 不允许应用优惠" % settle.status)

        # ② 幂等：已应用过相同方案则直接返回
        existing = await self._find_applies(settlement_no)
        if existing and {a.policy_code for a in existing} == set(policy_codes):
            return self._apply_result(settle, existing, idempotent=True)

        # ③ 试算并应用
        trial = await self.trial(settlement_no, policy_codes,
                                 discount_mode, top_n=1)
        best = trial["combos"][0]

        # ④ 写优惠主表与明细
        applies = []
        for code in best["policy_codes"]:
            apply = M16DiscountApply(
                settlement_id=settle.id,
                settlement_no=settlement_no,
                policy_code=code,
                policy_type=self._type_of(code, best),
                reduce_amount=self._reduce_of(code, best),
                discount_mode=discount_mode,
                status="ACTIVE",
                voucher_code=voucher_code if code == "VOUCHER" else None,
                operator_id=operator_id,
                operator_name=operator_name,
                applied_at=datetime.now(),
            )
            self.db.add(apply)
            await self.db.flush()
            applies.append(apply)

            for ln in best["items"]:
                self.db.add(M16DiscountItem(
                    apply_id=apply.id,
                    settlement_item_id=ln["settlement_item_id"],
                    item_code=ln["item_code"],
                    base_amount=Decimal(ln["base_amount"]),
                    reduce_amount=Decimal(ln["reduce_amount"]),
                ))

        # ⑤ 更新结算单优惠合计
        await self.db.execute(
            update(type(settle)).where(type(settle).id == settle.id).values(
                discount_amount=Decimal(best["reduce_amount"]),
                payable_amount=Decimal(best["payable_amount"]),
                discount_mode=discount_mode,
            ))

        # ⑥ 幂等：占用券码、扣减个人次数
        if voucher_code:
            await self._consume_voucher(voucher_code, settlement_no)

        await self.db.commit()
        logger.info("discount.applied", settlement_no=settlement_no,
                    codes=best["policy_codes"],
                    reduce=str(best["reduce_amount"]),
                    operator=operator_name, ip=ip)
        return self._apply_result(settle, applies, idempotent=False)

    async def revoke(self, apply_id: int, operator_id: int,
                     operator_name: str) -> dict:
        """撤销单条优惠（结算单作废或人工撤销）"""
        apply = await self.db.get(M16DiscountApply, apply_id)
        if apply is None:
            raise M16Error(54972, "优惠记录不存在")
        if apply.status != "ACTIVE":
            return {"apply_id": apply_id, "status": apply.status,
                    "message": "非 ACTIVE 状态，无需撤销"}
        apply.status = "REVOKED"
        apply.revoked_at = datetime.now()
        apply.revoked_by = operator_id
        apply.revoked_reason = "人工撤销"
        await self._release_voucher(apply.voucher_code)
        await self.db.commit()
        logger.info("discount.revoked", apply_id=apply_id,
                    operator=operator_name)
        return {"apply_id": apply_id, "status": "REVOKED"}

    async def revoke_by_settlement(self, settlement_no: str,
                                   reason: str) -> dict:
        """按结算单批量撤销（M16-01 作废结算单时调用）"""
        rows = await self._find_applies(settlement_no)
        count = 0
        for a in rows:
            if a.status != "ACTIVE":
                continue
            a.status = "REVOKED"
            a.revoked_at = datetime.now()
            a.revoked_reason = reason
            await self._release_voucher(a.voucher_code)
            count += 1
        await self.db.commit()
        return {"settlement_no": settlement_no,
                "revoked": count, "reason": reason}

    # ---------------- 退费优惠分摊 ----------------

    async def refundable_share(self, settlement_no: str,
                               refund_item_ids: list) -> dict:
        """计算退费时应回退的优惠分摊（供 M16-08 使用）"""
        applies = await self._find_applies(settlement_no)
        if not applies:
            return {"settlement_no": settlement_no,
                    "discount_share": "0.00", "detail": []}

        total_base = Decimal("0.00")
        refund_base = Decimal("0.00")
        detail = []
        for a in applies:
            items = await self._find_items(a.id)
            for it in items:
                total_base += it.base_amount
                if it.settlement_item_id in refund_item_ids:
                    refund_base += it.base_amount

        if total_base == 0:
            return {"settlement_no": settlement_no,
                    "discount_share": "0.00", "detail": []}

        ratio = refund_base / total_base
        share_total = Decimal("0.00")
        for a in applies:
            share = money(a.reduce_amount * ratio)
            share_total += share
            detail.append({
                "apply_id": a.id,
                "policy_code": a.policy_code,
                "original_reduce": str(a.reduce_amount),
                "refund_share": str(share),
            })

        return {
            "settlement_no": settlement_no,
            "total_base": str(total_base),
            "refund_base": str(refund_base),
            "ratio": str(money(ratio)),
            "discount_share": str(share_total),
            "detail": detail,
        }

    # ---------------- 降级补录 ----------------

    async def supplement(self, settlement_no: str, policy_codes: list,
                         reason: str, operator_id: int) -> dict:
        """降级后补录优惠（不改变已收金额，只修正账务）"""
        settle = await self._lock_settlement(settlement_no)
        if settle is None:
            raise M16Error(54972, "结算单不存在")
        trial = await self.trial(settlement_no, policy_codes, "RATE_FIRST", 1)
        best = trial["combos"][0] if trial["combos"] else None
        if best is None:
            raise M16Error(54952, "无可应用的优惠方案")

        before = settle.payable_amount
        for code in best["policy_codes"]:
            self.db.add(M16DiscountApply(
                settlement_id=settle.id,
                settlement_no=settlement_no,
                policy_code=code,
                policy_type="SUPPLEMENT",
                reduce_amount=self._reduce_of(code, best),
                discount_mode="RATE_FIRST",
                status="ACTIVE",
                is_supplement=True,
                supplement_reason=reason,
                operator_id=operator_id,
                operator_name="SYSTEM",
                applied_at=datetime.now(),
            ))
        await self.db.commit()
        logger.info("discount.supplemented", settlement_no=settlement_no,
                    reduce=str(best["reduce_amount"]), reason=reason)
        return {
            "settlement_no": settlement_no,
            "previous_degraded": True,
            "supplemented_reduce": best["reduce_amount"],
            "payable_before": str(before),
            "payable_after": best["payable_amount"],
            "note": "已收金额不变，仅修正账务记录，差额记入结算单差额调整",
        }

    # ---------------- 私有工具 ----------------

    async def _load_base(self, settlement_no: str) -> Optional[dict]:
        """加载可优惠基数与明细行"""
        from app.models.m16.settlement import M16Settlement, M16SettlementItem
        stmt = select(M16Settlement).where(
            M16Settlement.settlement_no == settlement_no,
            M16Settlement.is_deleted.is_(False))
        settle = (await self.db.execute(stmt)).scalar_one_or_none()
        if settle is None:
            return None
        sitems = (await self.db.execute(
            select(M16SettlementItem).where(
                M16SettlementItem.settlement_id == settle.id,
                M16SettlementItem.is_deleted.is_(False))
        )).scalars().all()

        lines = []
        total = Decimal("0.00")
        for it in sitems:
            if getattr(it, "allow_discount", True) is False:
                continue
            if getattr(it, "is_gift", False):
                continue
            if (it.bill_quantity or 0) <= 0:
                continue
            amt = money(it.unit_price * it.bill_quantity)
            total += amt
            lines.append({
                "item_id": it.id,
                "item_code": it.charge_item_code,
                "base_amount": amt,
            })
        if not lines:
            return None
        return {
            "settlement_id": settle.id,
            "dept_id": getattr(settle, "dept_id", None),
            "amount": total,
            "item_count": len(lines),
            "lines": lines,
        }

    async def _load_member_safe(self, patient_id: int) -> dict:
        """读会员信息，失败返回空 dict（降级）"""
        try:
            return await self._call_m03_member(patient_id)
        except Exception as exc:  # noqa: BLE001
            logger.warning("discount.member_degraded",
                           patient_id=patient_id, error=str(exc)[:200])
            return {}

    async def _load_benefits_safe(self, patient_id: int) -> dict:
        """读特殊身份，失败返回空 dict（降级）"""
        try:
            return await self._call_m04_benefits(patient_id)
        except Exception as exc:  # noqa: BLE001
            logger.warning("discount.benefits_degraded",
                           patient_id=patient_id, error=str(exc)[:200])
            return {}

    async def _load_policies(self, base: dict, dept_id) -> list:
        """从 M01-06 拉取候选方案（走 Redis 缓存）"""
        return await self._call_m01_policies(base, dept_id)

    async def _consume_voucher(self, code: str, settlement_no: str) -> None:
        """核销券：置 USED 并释放锁定"""
        stmt = select(M16DiscountVoucher).where(
            M16DiscountVoucher.voucher_code == code)
        v = (await self.db.execute(stmt)).scalar_one_or_none()
        if v is not None:
            v.status = "USED"
            v.used_at = datetime.now()
            v.used_settlement_no = settlement_no

    async def _release_voucher(self, code: Optional[str]) -> None:
        """结算作废时释放券"""
        if not code:
            return
        stmt = select(M16DiscountVoucher).where(
            M16DiscountVoucher.voucher_code == code)
        v = (await self.db.execute(stmt)).scalar_one_or_none()
        if v is not None and v.status == "USED":
            v.status = "ISSUED"
            v.used_at = None
            v.used_settlement_no = None

    def _apply_result(self, settle, applies, idempotent: bool) -> dict:
        return {
            "settlement_no": settle.settlement_no,
            "apply_count": len(applies),
            "total_reduce": str(sum(a.reduce_amount for a in applies)),
            "new_payable": str(settle.payable_amount),
            "applies": [
                {"id": a.id, "policy_code": a.policy_code,
                 "reduce_amount": str(a.reduce_amount),
                 "status": a.status,
                 "applied_at": a.applied_at.isoformat()}
                for a in applies
            ],
            "is_idempotent": idempotent,
        }
```

```python
# app/services/m16/discount_approval.py
"""M16-06 折扣审批服务"""
from datetime import datetime, timedelta
from decimal import Decimal, ROUND_HALF_UP
from typing import Optional

import structlog

from app.services.m16.errors import M16Error

logger = structlog.get_logger(__name__)
CENT = Decimal("0.01")

# 折扣率档位 → (审批角色链, 时限分钟)
APPROVAL_TIERS = [
    (Decimal("0.90"), Decimal("0.95"),
     [("DEPT_DIRECTOR", "科主任")], 30),
    (Decimal("0.80"), Decimal("0.90"),
     [("MEDICAL_AFFAIRS", "医务科")], 60),
    (Decimal("0.00"), Decimal("0.80"),
     [("MEDICAL_AFFAIRS", "医务科"),
      ("FINANCE_MANAGER", "财务主管")], 120),
]

AUTO_LIMIT = Decimal("0.95")
AMOUNT_THRESHOLD = Decimal("300.00")
MIN_REASON_LEN = 10


class ApprovalService:
    """手动折扣校验与审批流"""

    def __init__(self, db):
        self.db = db

    async def submit_manual(
        self,
        settlement_no: str,
        discount_rate: Decimal,
        reason: str,
        evidence_files: list,
        identity_cert_no: Optional[str],
        operator_id: int,
        operator_name: str,
        ip: Optional[str],
    ) -> dict:
        # ① 折扣率合理区间
        if discount_rate <= 0 or discount_rate >= 1:
            raise M16Error(54953, "折扣率必须在 0 和 1 之间")

        # ② 原因长度
        if len((reason or "").strip()) < MIN_REASON_LEN:
            raise M16Error(54954, "折扣原因至少 %d 个字" % MIN_REASON_LEN)

        # ③ 结算单加载 + 加锁
        settle = await self._lock_settlement(settlement_no)
        if settle is None:
            raise M16Error(54972, "结算单不存在")
        if settle.status not in ("DRAFT", "PENDING"):
            raise M16Error(54972, "结算单状态不允许修改折扣")

        # ④ 同一结算单不能有多个待审批
        pending = await self._find_pending(settlement_no)
        if pending:
            raise M16Error(54957, "该结算单已有待审批折扣（%s）"
                           % pending.approval_no)

        total = settle.total_amount
        reduce = (total * (Decimal("1") - discount_rate)).quantize(
            CENT, rounding=ROUND_HALF_UP)

        # ⑤ 证明材料要求
        need_evidence = discount_rate < Decimal("0.90") \
            or reduce >= AMOUNT_THRESHOLD
        if need_evidence and not evidence_files:
            raise M16Error(54955, "折扣率低于 0.90 或减免超 300 元必须上传证明材料")

        # ⑥ 是否需要审批
        tiers = self._resolve_tiers(discount_rate, reduce)
        if not tiers:
            # 阈值内，直接落优惠
            return await self._apply_direct(
                settle, discount_rate, reduce, reason, operator_id)

        # ⑦ 调 M01-11 通用审批（强依赖，不可降级）
        try:
            approval_id = await self._call_m01_approval_submit(
                business_type="M16_DISCOUNT",
                business_no=settlement_no,
                payload={
                    "settlement_no": settlement_no,
                    "discount_rate": str(discount_rate),
                    "reduce_amount": str(reduce),
                    "reason": reason,
                    "evidence_files": evidence_files,
                },
                tiers=tiers,
            )
        except Exception as exc:  # noqa: BLE001
            logger.error("discount.approval_unavailable",
                         settlement_no=settlement_no, error=str(exc)[:200])
            raise M16Error(54958, "审批服务不可用，请稍后重试或联系管理人员")

        # ⑧ 锁定结算单
        deadline = datetime.now() + timedelta(minutes=tiers[0][2])
        approval = self.db.M16DiscountApproval(
            approval_no=await self._next_approval_no(),
            settlement_id=settle.id,
            settlement_no=settlement_no,
            discount_rate=discount_rate,
            reduce_amount=reduce,
            reason=reason,
            evidence_files=evidence_files,
            status="PENDING",
            current_seq=1,
            approval_chain=[{"seq": i + 1, "role": r, "title": t,
                             "deadline_at": (datetime.now() + timedelta(
                                 minutes=m)).isoformat()}
                            for i, (r, t, m) in enumerate(tiers)],
            need_multi_sign=len(tiers) > 1,
            deadline_at=deadline,
            submitted_by=operator_id,
            submitted_by_name=operator_name,
            submitted_at=datetime.now(),
            version=1,
        )
        self.db.add(approval)
        await self.db.flush()
        await self._lock_settlement_for_approval(settle, approval.id)
        await self.db.commit()

        logger.info("discount.approval_submitted",
                    approval_no=approval.approval_no,
                    settlement_no=settlement_no,
                    rate=str(discount_rate), reduce=str(reduce),
                    operator=operator_name, ip=ip)
        return {
            "approval_id": approval.id,
            "approval_no": approval.approval_no,
            "status": "PENDING",
            "discount_rate": str(discount_rate),
            "reduce_amount": str(reduce),
            "approval_chain": approval.approval_chain,
            "need_multi_sign": approval.need_multi_sign,
            "settlement_locked": True,
            "message": "已提交审批，审批完成前该结算单不可收费",
        }

    def _resolve_tiers(self, rate: Decimal, reduce: Decimal) -> list:
        """根据折扣率与减免额确定审批链"""
        if rate >= AUTO_LIMIT and reduce < AMOUNT_THRESHOLD:
            return []
        for lo, hi, chain, minutes in APPROVAL_TIERS:
            if lo <= rate < hi:
                # 金额超阈值时至少升一级
                if reduce >= AMOUNT_THRESHOLD and len(chain) == 1:
                    idx = APPROVAL_TIERS.index((lo, hi, chain, minutes))
                    if idx > 0:
                        nxt = APPROVAL_TIERS[idx - 1]
                        return [(r, t, nxt[3]) for r, t in nxt[2]]
                return [(r, t, minutes) for r, t in chain]
        return [(r, t, 120) for r, t in APPROVAL_TIERS[-1][2]]

    async def approve(self, approval_id: int, comment: str,
                      version: int, user) -> dict:
        approval = await self.db.get(self.db.M16DiscountApproval, approval_id)
        if approval is None:
            raise M16Error(54962, "审批单不存在")
        if approval.version != version:
            raise M16Error(54962, "审批单状态已变更，请刷新后重试")
        if approval.status != "PENDING":
            raise M16Error(54962, "审批单当前状态 %s 不可审批"
                           % approval.status)
        if approval.submitted_by == user.id:
            raise M16Error(54960, "不能审批自己发起的折扣")
        if datetime.now() > approval.deadline_at:
            raise M16Error(54963, "审批已超时自动驳回")

        chain = approval.approval_chain
        seq = approval.current_seq
        if seq > len(chain):
            raise M16Error(54962, "审批链已走完")
        expected_role = chain[seq - 1]["role"]
        if expected_role not in (user.roles or []):
            raise M16Error(54961, "无该档位审批权限（需 %s）" % expected_role)

        chain[seq - 1]["approved_by"] = user.id
        chain[seq - 1]["approved_by_name"] = user.name
        chain[seq - 1]["approved_at"] = datetime.now().isoformat()
        chain[seq - 1]["comment"] = comment
        approval.approval_chain = chain
        approval.current_seq = seq + 1
        approval.version += 1

        more = seq < len(chain)
        if not more:
            approval.status = "APPROVED"
            approval.approved_at = datetime.now()
            await self._unlock_and_apply(approval)
        else:
            nxt = chain[seq]
            approval.deadline_at = datetime.fromisoformat(nxt["deadline_at"])

        await self.db.commit()
        logger.info("discount.approval_approved",
                    approval_no=approval.approval_no, seq=seq,
                    approver=user.name, more=more)
        return {
            "approval_no": approval.approval_no,
            "status": approval.status,
            "current_seq": approval.current_seq,
            "need_more_sign": more,
            "next_approver_role": chain[seq]["role"] if more else None,
            "settlement_unlocked": not more,
            "reduce_amount": str(approval.reduce_amount),
            "new_payable": str(approval.new_payable or Decimal("0")),
        }

    async def reject(self, approval_id: int, comment: str,
                     version: int, user) -> dict:
        approval = await self.db.get(self.db.M16DiscountApproval, approval_id)
        if approval is None:
            raise M16Error(54962, "审批单不存在")
        if approval.version != version:
            raise M16Error(54962, "审批单状态已变更，请刷新后重试")
        if approval.status != "PENDING":
            raise M16Error(54962, "审批单当前状态不可驳回")
        if approval.submitted_by == user.id:
            raise M16Error(54960, "不能审批自己发起的折扣")

        approval.status = "REJECTED"
        approval.rejected_at = datetime.now()
        approval.rejected_by = user.id
        approval.rejected_reason = comment
        approval.version += 1
        await self._unlock_settlement(approval.settlement_id)
        await self.db.commit()
        logger.info("discount.approval_rejected",
                    approval_no=approval.approval_no, approver=user.name)
        return {"approval_no": approval.approval_no,
                "status": "REJECTED",
                "settlement_unlocked": True,
                "comment": comment}

    async def _apply_direct(self, settle, rate, reduce, reason, operator_id):
        """阈值内直接应用，不进审批流"""
        settle.discount_amount = reduce
        settle.payable_amount = settle.total_amount - reduce
        await self.db.commit()
        logger.info("discount.manual_auto_applied",
                    settlement_no=settle.settlement_no,
                    rate=str(rate), reduce=str(reduce))
        return {"approval_id": None, "status": "AUTO_APPROVED",
                "discount_rate": str(rate), "reduce_amount": str(reduce),
                "settlement_locked": False}

    async def _next_approval_no(self) -> str:
        day = datetime.now().strftime("%Y%m%d")
        seq = await self.db.scalar(
            self.db.text(
                "SELECT COALESCE(MAX(CAST(RIGHT(approval_no, 4) AS INTEGER)), 0) + 1 "
                "FROM m16_discount_approval WHERE approval_no LIKE :p"),
            {"p": "DA" + day + "%"})
        return "DA" + day + "%04d" % seq
```

```python
async def _approval_timeout_scan():
    from app.db.session import async_session_factory
    from app.models.m16.discount import M16DiscountApproval
    from app.services.m16.notify import notify_role

    now = datetime.now()
    escalated = 0
    rejected = 0
    async with async_session_factory() as db:
        rows = (await db.execute(
            select(M16DiscountApproval).where(
                M16DiscountApproval.status == "PENDING",
                M16DiscountApproval.deadline_at < now,
            ).with_for_update(skip_locked=True)
        )).scalars().all()

        for a in rows:
            chain = a.approval_chain or []
            seq = a.current_seq
            if seq < len(chain):

                a.version += 1

                a.deadline_at = datetime.fromisoformat(nxt["deadline_at"])
                escalated += 1
                await notify_role(nxt["role"], a.approval_no,
                                  "折扣审批已升级至您，请尽快处理")
            else:
                # 最后一级也超时 → 自动驳回
                a.status = "TIMEOUT"
                a.rejected_at = now
                a.rejected_reason = "超时未审批，系统自动驳回"
                a.version += 1
                rejected += 1
                await _unlock_settlement(db, a.settlement_id)
        await db.commit()

    logger.info("discount.approval_timeout_scan",
                escalated=escalated, rejected=rejected)

async def _consistency_check():

    async with async_session_factory() as db:
```
