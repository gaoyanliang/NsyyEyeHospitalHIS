## 1. 模块概述

### 1.1 模块定位

M16-08 退费与冲红负责「**钱怎么退回去，退回去之后业务单据怎么办**」。

```
                退费请求来源
  ┌──────────┬──────────┬──────────┬──────────┐
  │ M04 退号 │ M07 退医嘱│ M16-04   │ M16-02   │
  │ 挂号退费 │ 药品/检查 │ 视光退换 │ 收费员发起│
  └────┬─────┴────┬─────┴────┬─────┴────┬─────┘
       │          │          │          │
       └──────────┴────┬─────┴──────────┘
                       ▼
        ┌──────────────────────────────┐
        │  M16-08 退费与冲红            │
        │  ① 退费资格判定（能不能退）    │
        │  ② 退费金额计算（退多少）      │
        │  ③ 审批（谁批的）              │
        │  ④ 冲红发票（票怎么办）        │
        │  ⑤ 资金退回（钱怎么回）        │
        │  ⑥ 业务单据回滚（单怎么解）    │
        └──┬───────┬────────┬──────────┘
           │       │        │
           ▼       ▼        ▼
      M16-05    M16-07   M16-01
      资金原路   发票红冲  结算单置
      退回               REFUNDED
           │
           ▼
       上游回写（M04 退号 / M07 退医嘱 / M16-04 退换）
```

**一句话定义：** M16-08 保证「每一分退出去的钱，都能对应到一笔收进来的钱，并能说清为什么退」。

### 1.2 为什么独立成子模块

| 维度 | 若并入其他子模块 | 独立成 M16-08 |
|---|---|---|
| **反向流程归属** | 退门诊费写在 M16-02、退住院写在 M16-03、退视光写在 M16-04 → 三份重复代码，口径漂移 | 一份判定引擎、一份金额算法 |
| **资金链路** | 各场景自行调支付渠道 → 退款单号冲突、原路退回规则不一致 | 统一由 M16-05 执行，M16-08 只管「退多少、退给谁」 |
| **票务联动** | 退费与红冲在不同模块 → 出现「钱退了票没红」 | 冲红是退费的必经步骤，同一事务边界内推进 |
| **审核口径** | 各场景自有审批 → 无法回答「本月退了多少、谁批的、为什么」 | 单一台账，单一审批链 |
| **风控** | 无法集中识别「同一患者高频退费」「同一收费员大额退费」 | 集中风控规则 |

**核心判断：退费是收费的逆运算，但比收费复杂得多。** 收费只要「钱到账 + 单据置位」，退费要同时处理「钱原路退回 + 发票红冲 + 结算单回滚 + 上游单据回滚 + 库存回补」。把它拆出去，M16-02/03/04 才能保持「只做正向」的简单性。

### 1.3 与相邻子模块分工

| 能力 | M16-01 结算单 | M16-02 门诊收费 | M16-05 支付 | M16-07 发票 | **M16-08 退费** |
|---|---|---|---|---|---|
| 判定「能不能退」 | ❌ | ❌ | ❌ | ❌ | ✅ **唯一责任** |
| 计算退多少（含优惠分摊） | ❌ | ❌ | ❌ | ❌ | ✅ **唯一责任** |
| 审批链与风控 | ❌ | ❌ | ❌ | 红冲审批 | ✅ **退费审批** |
| 结算单状态回滚 | ✅ 被调方 | ❌ | ❌ | ❌ | ✅ 发起方 |
| 发票红冲执行 | ❌ | ❌ | ❌ | ✅ 执行方 | ✅ 触发方 |
| 资金原路退回 | ❌ | ❌ | ✅ **唯一责任人** | ❌ | ✅ 调用方 |
| 上游单据回滚 | 部分（回写队列） | ❌ | ❌ | ❌ | ✅ 编排方 |
| 退费台账与统计 | ❌ | ❌ | ❌ | ❌ | ✅ **唯一责任** |

### 1.4 概念辨析

**退费（Refund） vs 冲红（Red Flush） vs 红冲（Reversal）**

| 概念 | 定义 | 处理对象 | 谁触发 |
|---|---|---|---|
| **退费** | 把钱退还给患者 | 资金 | M16-08 |
| **冲红 / 红冲** | 开具负数发票冲抵原发票 | 税务凭证 | M16-07（由 M16-08 触发） |
| **反向记账** | 在住院费用账上记一笔负数冲销 | 费用账 | M16-03 |

三者常被混用。本设计明确：

- 门诊退费：**必须**红冲发票（若已开票）
- 住院退费（出院后）：**必须**红冲发票
- 住院费用冲销（出院前记账错误）：**不涉及**发票，因为还没开票
- 退费 ≠ 作废：作废是「这笔没发生过」（M16-07 的当月未交付场景），退费是「发生过了但现在不做了」

**全额退 vs 部分退**

| 类型 | 定义 | 资金 | 发票 | 结算单 |
|---|---|---|---|---|
| **全额退** | 退还该结算单全部实收金额 | 一次性退完 | 整张红冲 | `REFUNDED` |
| **部分退** | 只退其中部分项目或部分金额 | 可多次退 | 按金额部分红冲（累计不超原票） | `PARTIAL_REFUNDED` |

**净额退款原则：** 退给患者的钱 = 患者实际支付的净额（扣掉优惠），不是项目原价。

例：检查费原价 800，八折实收 640，退这项检查 → 退 **640**，不是 800。优惠不返还给患者，也不返还给医院——这笔优惠本来就没收。

### 1.5 模块目标

| 指标 | 目标 | 说明 |
|---|---|---|
| 退费成功率 | ≥ 99.5% | 不含患者主动放弃 |
| 退费平均时长 | ≤ 3 分钟 | 从提交到资金到账 |
| 原路退回率 | ≥ 98% | 现金退现金、微信退微信 |
| 退费率（退费额/收费额） | ≤ 5% | 超阈值月度分析 |
| 红冲及时率 | 100% | 退费成功 5 分钟内完成红冲 |
| 退费差错率 | ≤ 0.1% | 金额错误、退错人 |
| 审批超时率 | ≤ 5% | 超时自动升级 |

### 1.6 关键业务角色

| 角色 | 职责 | 权限 |
|---|---|---|
| 收费员 | 发起退费、现金退还、打印退费单 | `m16:refund:apply` |
| 收费主管 | 审批中等金额退费、监管退费率 | `m16:refund:approve` |
| 财务主管 | 审批大额退费、跨月退费 | `m16:refund:approve_large` |
| 财务专员 | 对账、退费报表、异常追查 | `m16:refund:report` |

| 患者 | 申请自助退费（限未就诊挂号费） | 无 M16 权限，通过 M03-06 发起 |

## 3. 业务模型

### 3.1 退费场景与来源

| 场景码 | 场景 | 来源 | 可退范围 | 典型金额 |
|---|---|---|---|---|
| `REG_CANCEL` | 退号 | M04-03 | 挂号费全额 | 20~50 |
| `ORDER_DRUG` | 退药品 | M07-03 / M16-02 | 未发药医嘱全额 | 50~500 |
| `ORDER_EXAM` | 退检查 | M07-03 / M16-02 | 未执行检查全额 | 100~600 |
| `ORDER_LAB` | 退检验 | M07-03 / M16-02 | 未执行检验全额 | 50~300 |
| `ORDER_TREAT` | 退治疗 | M07-03 / M16-02 | 未执行治疗全额 | 30~200 |
| `OPTICAL_RETURN` | 视光退换 | M16-04 | 按退换判定矩阵 | 300~8000 |
| `MANUAL_ADJUST` | 人工调整 | M16-02 收费员 | 部分金额 | 不定 |

**场景决定规则：** 每个场景有不同的可退时间窗、不同的审批阈值、不同的上游回写目标。

### 3.2 退费单模型

一个退费单 = 一次资金退出动作。

```
m16_refund_order（退费单）
├── 对应 1 个结算单（settlement_no）
├── 只能退这个结算单里「还没退过」的明细
├── 可以含多条明细（re_refund_item）
├── 退款方式：ORIGINAL / CASH / STORED / MANUAL
└── 状态：DRAFT → PENDING_APPROVAL → APPROVED → EXECUTING
                  → SUCCESS / FAILED / ABNORMAL
```

**为什么一个退费单只能对应一个结算单：**

结算单是「一次交易」的原子单位。跨结算单合并退费会导致：
- 红冲时搞不清要红冲哪张票（一张票对应一个结算单）
- 部分退费时无法计算「这张结算单还剩多少可退」
- 审批阈值判定混乱

**部分退费的行选择：**

用户勾选「退哪几行」，每行填「退多少数量」。可退数量 = 原数量 − 已退数量。

```
结算明细：检查费 800 × 1（已退 0）→ 可退 1
结算明细：药品 A 45 × 3（已退 1）→ 可退 2
结算明细：药品 B 32 × 2（已退 0）→ 可退 2
```

### 3.3 退费金额计算模型

**四层计算，缺一不可：**

```
第 1 层：原始行金额
  line_gross = unit_price × quantity

第 2 层：优惠分摊
  line_discount_share = discount_apply.reduce_amount × (line_base / total_base)
  line_net = line_gross − line_discount_share

第 3 层：本次退费数量
  refund_ratio = refund_qty / original_qty
  refund_amount = ROUND(line_net × refund_ratio, 2)

第 4 层：尾差修正（最后一次退费）
  若本次退后 remaining_qty = 0：
      refund_amount = line_net − line_already_refunded
```

**为什么第 4 层必须有尾差修正：**

假设净额 100 元，分 3 次各退 1/3：
- 33.33 + 33.33 + 33.33 = 99.99，差 1 分钱

这 1 分钱在账上就是「钱多收了」。所以最后一次必须用「剩余额 = 净额 − 已退额」直接算出，而不是再乘比例。

**优惠分摊比例的分母必须一致：**

`total_base` 是**可优惠基数**（M16-06 定义），不是结算单总额。若结算单总额 1,000、可优惠基数 800、优惠 80：
- 正确：行优惠 = 80 × (行基数 / 800)
- 错误：行优惠 = 80 × (行金额 / 1000)

第二种算法会让优惠分摊总和 ≠ 80，账对不上。

### 3.4 退费状态机

```
   ┌─────────┐
   │  DRAFT  │  收费员录入选退项目
   └────┬────┘
        │ 提交
        ▼
┌──────────────────┐  无需审批（小额）
│ PENDING_APPROVAL │────────────┐
└────────┬─────────┘            │
         │ 审批通过              │
         ▼                      ▼
   ┌───────────┐          ┌──────────┐
   │ APPROVED  │◄─────────│ APPROVED │
   └─────┬─────┘          └──────────┘
         │ 执行
         ▼
   ┌───────────┐
   │ EXECUTING │  冲红 → 退款 → 回滚 → 回写
   └─────┬─────┘
    ┌────┴─────┬──────────┐
    ▼          ▼          ▼
┌────────┐ ┌────────┐ ┌──────────┐
│SUCCESS │ │ FAILED │ │ ABNORMAL │
└────────┘ └───┬────┘ └────┬─────┘
               │重试        │人工处理
               └──►EXECUTING└──►SUCCESS

旁支：DRAFT / PENDING_APPROVAL ──► REJECTED（驳回）
      DRAFT ──► CANCELLED（作废）
```

**各状态语义：**

| 状态 | 含义 | 资金 | 可编辑 |
|---|---|---|---|
| `DRAFT` | 草稿 | 未动 | ✅ |
| `PENDING_APPROVAL` | 待审批 | 未动 | ❌ |
| `APPROVED` | 已批准待执行 | 未动 | ❌ |
| `EXECUTING` | 执行中（锁定） | 可能已部分执行 | ❌ |
| `SUCCESS` | 退费成功 | 已退出 | ❌ |
| `FAILED` | 执行失败可重试 | 未退出 | ❌ |
| `ABNORMAL` | 异常需人工 | 不确定 | ❌ |
| `REJECTED` | 审批驳回 | 未动 | ❌ |
| `CANCELLED` | 主动作废 | 未动 | ❌ |

**`ABNORMAL` 的必要性：**

真实存在「渠道退款的请求发出去了，但响应超时」的窗口。此时钱可能已经退也可能没退，既不能判成功也不能判失败。如果乐观标 `SUCCESS`，可能重复退款；如果标 `FAILED` 让用户重试，也会重复退款。

没有 ABNORMAL 状态，这类情况必然演变成「退两次」或「该退没退」的纠纷。

### 3.5 审批模型

| 档位 | 触发条件 | 审批人 | 时限 | 超时动作 |
|---|---|---|---|---|
| T1 免审 | 金额 < 100 且 场景 ∈ {REG_CANCEL} | — | — | — |
| T2 初级 | 金额 < 500 | 收费主管 | 30 min | 升级 T3 |
| T3 中级 | 500 ≤ 金额 < 5000 | 财务主管 | 60 min | 升级 T4 |
| T4 高级 | 金额 ≥ 5000 或 跨月退费 或 现金退费 >1000 | 财务主管 + 院长 | 120 min | 通知医务科 + 冻结 |

**跨月退费为什么升级：**

当月退费只影响当月的日结与月结；跨月退费要动已封账的月份，需要做会计调整分录。这不是风控问题，是财务规范问题。

**现金退费为什么单独升级：**

现金没有渠道流水可追溯，是退费舞弊的高发点。`现金退费 > 1000` 必须双人。

### 3.6 退款方式决策

```
                   是否有原支付流水？
                    ┌──────┴──────┐
                   有              无（组合支付部分失败等）
                    │              │
          原渠道是否支持退款？       ▼
            ┌─────┴─────┐       CASH 现金
          支持         不支持
            │            │
   原渠道是否在有效期？  ▼
     ┌────┴────┐    STORED 退储值
    在        超期
     │          │
  ORIGINAL   CASH（需审批）

```

| 方式 | 代码 | 条件 | 到账 |
|---|---|---|---|
| 原路退回 | `ORIGINAL` | 渠道支持且未超期 | 实时~3 工作日 |
| 现金 | `CASH` | 原渠道不可退、超期、或患者要求 | 即时 |
| 退储值 | `STORED` | 患者为会员且有储值账户 | 即时 |
| 人工转账 | `MANUAL` | 大额、企业对公 | 1~3 工作日 |

**渠道退款期限（继承 M16-05）：**

| 渠道 | 期限 |
|---|---|
| 微信 | 365 天 |
| 支付宝 | 365 天 |
| 云闪付 | 365 天 |
| POS | 180 天 |
| 储值 | 无期限 |

**超期退费必须审批：** 超期只能退现金，且金额 ≥ 500 要 T3 审批。

### 3.7 红冲的不可降级性

其他附加动作（上游回写、积分回退）可以进队列重试，**红冲不行**。

原因：
- 发票是税务凭证。钱退了票不红，患者拿着有效发票去报销，医院面临虚开风险
- 税务稽查时「收入台账有这笔，退费台账有这笔，发票台账没有红票」是明确的疑点
- 红冲有时间窗（通常 3 年内），过期无法红冲

**因此执行顺序是：先红冲，再退款。** 红冲失败则整个退费单停在 `FAILED`，不退款。

**红冲在退款之后的场景：**

部分退费可能先退小额再退大额。每次退费都要红冲对应金额。若某次红冲失败但前一次已退款，退费单进 `ABNORMAL`，由财务人工处理——此时已有资金流出，不能简单回滚。

### 3.8 执行编排

```
 ┌──────────────────────────────────────────────────────────┐
 │ RefundService.execute(refund_id)                          │
 └──────────────────────────┬───────────────────────────────┘
                            ▼
 ① 加锁 m16:refund:exec:{id}     防并发重复执行
                            ▼
 ② 状态机检查：须为 APPROVED 或 FAILED
                            ▼
 ③ 幂等检查：已 SUCCESS 直接返回
                            ▼
 ④ 置 EXECUTING，记录 executing_at
                            ▼
 ⑤ 重算金额（防审批期间被改数据）
                            ▼
 ⑥ 红冲（若已开票）──────► 失败 → FAILED，记录红冲失败原因
                            ▼
 ⑦ 资金退回 ─────────────► 超时 → ABNORMAL
                            ▼
 ⑧ 结算单回滚（M16-01 on-refunded）
                            ▼
 ⑨ 上游回写（M04 / M07 / M16-04）──► 失败 → 进回写队列
                            ▼
 ⑩ 会员权益回退 ─────────────► 失败 → 进回退队列
                            ▼
 ⑪ 置 SUCCESS，记 completed_at
```

**第 ⑤ 步重算的必要性：**

审批可能耗时几小时。期间如果发票被红冲过、结算单被改过，按旧金额退款就错了。每次执行都重算，且重算结果必须与审批时的金额一致（差额 > 0.01 则拒绝执行，报 55003 `金额已变化`）。

### 3.9 退费风控规则

| 规则 | 条件 | 动作 |
|---|---|---|
| R-01 | 同一患者 30 天内退费 ≥ 3 次 | WARN 提示 |
| R-02 | 同一患者 30 天内退费 ≥ 5 次 | 阻断，需主管审批 |
| R-03 | 同一收费员日退费额 ≥ 5000 | WARN |
| R-04 | 同一收费员日现金退费 ≥ 3 笔 | 强制复核 |
| R-05 | 同一结算单 24 小时内退费 ≥ 2 次 | WARN |
| R-06 | 退费金额 = 结算单全额 且 距收费 < 10 分钟 | WARN（冲正交易） |
| R-07 | 红费率日超 8% | 推送财务主管 |
| R-08 | 退费后立即重新收费（同一患者 5 分钟内） | WARN（换单嫌疑） |

R-06 的解释：收费后 10 分钟内全额退是典型的「收费员录错患者」场景，本身无害，但若某收费员频繁出现则要检查操作规范。

"""M16-08 退费与冲红 服务层"""
import hashlib
import logging
from datetime import datetime, timedelta
from decimal import ROUND_HALF_UP, Decimal

from sqlalchemy import select, text, update
from sqlalchemy.ext.asyncio import AsyncSession

logger = logging.getLogger(__name__)

CENT = Decimal("0.01")


def money(value):
    """金额统一两位小数，四舍五入"""
    return Decimal(str(value)).quantize(CENT, rounding=ROUND_HALF_UP)


# 场景配置：可退时间窗（天）与审批基数
SCENE_CONFIG = {
    "REG_CANCEL": {"window_days": 1, "base_tier": "T1"},
    "ORDER_DRUG": {"window_days": 7, "base_tier": "T2"},

}

# 审批档位：金额阈值与审批角色
APPROVAL_TIERS = [
    {"tier": "T1", "max_amount": Decimal("100.00"),
     "role": None, "timeout": 0},
    {"tier": "T2", "max_amount": Decimal("500.00"),
     "role": "收费主管", "timeout": 30},
    {"tier": "T3", "max_amount": Decimal("5000.00"),
     "role": "财务主管", "timeout": 60},
    {"tier": "T4", "max_amount": None,
     "role": "财务主管+院长", "timeout": 120},
]

# 渠道退款期限（天），继承 M16-05
ORIGINAL_REFUND_DAYS = {
    "WECHAT": 365, "ALIPAY": 365, "UNIONPAY": 365,
    "POS": 180, "CASH": 0, "STORED": 99999,
}


class RefundService:
    """退费单：创建、执行、回调"""

    def __init__(self, db: AsyncSession):
        self.db = db

    # ---------- 可退查询 ----------

    async def get_refundable(self, settlement_no: str, user):
        """查询可退项目与金额"""
        settle = await self._load_settlement(settlement_no)
        if settle is None:
            raise BizError(55002, "结算单不存在")
        if settle.status not in ("PAID", "SETTLED", "PARTIAL_REFUNDED"):
            raise BizError(55002, "结算单状态不允许退费")

        items = await self._load_items(settle.id)
        total_base = sum(
            (Decimal(str(i["base_amount"])) for i in items
             if Decimal(str(i["base_amount"])) > 0),
            Decimal("0.00"),
        ) or Decimal("0.01")
        discount_total = await self._load_discount_total(settle.id)

        out_items, out_unrefundable = [], []
        for it in items:
            refundable_qty = (
                Decimal(str(it["quantity"]))
                - Decimal(str(it["refunded_qty"]))
            )
            if refundable_qty <= 0 or not it["allow_refund"]:
                out_unrefundable.append({
                    "item_id": it["id"],
                    "line_no": it["line_no"],
                    "item_name": it["item_name"],
                    "amount": str(it["net_amount"]),
                    "reason_code": (
                        "ALREADY_REFUNDED" if refundable_qty <= 0
                        else "NOT_REFUNDABLE"
                    ),
                    "reason": (
                        "该项目已全部退费" if refundable_qty <= 0
                        else "该项目不支持退费"
                    ),
                })
                continue
            base = Decimal(str(it["base_amount"]))
            share = money(discount_total * base / total_base) \
                if base > 0 else Decimal("0.00")
            net = money(Decimal(str(it["gross_amount"])) - share)
            out_items.append({
                "item_id": it["id"],
                "line_no": it["line_no"],
                "item_code": it["item_code"],
                "item_name": it["item_name"],
                "spec": it["spec"],
                "unit": it["unit"],
                "unit_price": str(it["unit_price"]),
                "quantity": str(it["quantity"]),
                "original_qty": str(it["quantity"]),
                "refunded_qty": str(it["refunded_qty"]),
                "refundable_qty": str(refundable_qty),
                "gross_amount": str(it["gross_amount"]),
                "discount_share": str(share),
                "net_amount": str(net),
                "refunded_amount": str(it["refunded_amount"]),
                "refundable_amount": str(
                    money(net - Decimal(str(it["refunded_amount"])))),
                "refundable": True,
                "refund_reason_code": None,
            })

        window = SCENE_CONFIG["ORDER_EXAM"]
        paid_at = settle.paid_at
        end_at = paid_at + timedelta(days=window["window_days"])
        now = datetime.now()
        return {
            "settlement_no": settlement_no,
            "patient_name": settle.patient_name,
            "paid_at": paid_at.isoformat(),
            "total_amount": str(settle.total_amount),
            "paid_amount": str(settle.paid_amount),
            "refunded_amount": str(settle.refunded_amount),
            "refundable_amount": str(
                money(Decimal(str(settle.paid_amount))
                      - Decimal(str(settle.refunded_amount)))),
            "settlement_status": settle.status,
            "invoice": await self._load_invoice_brief(settle.id),
            "window_settings": {
                "start_at": paid_at.isoformat(),
                "end_at": end_at.isoformat(),
                "in_window": now <= end_at,
                "remain_seconds": max(
                    0, int((end_at - now).total_seconds())),
            },
            "items": out_items,
            "unrefundable_items": out_unrefundable,
            "payment_methods": await self._load_payments(settle.id),

    # ---------- 金额计算 ----------

    async def _calc_amount(self, settle, items):
        """计算退费金额（四层模型）"""
        item_ids = [i["item_id"] if isinstance(i, dict) else i.item_id
                    for i in items]
        rows = await self._load_items_by_ids(settle.id, item_ids)
        if len(rows) != len(item_ids):
            raise BizError(55002, "退费项目不属于该结算单")

        total_base = await self._load_total_base(settle.id)
        discount_total = await self._load_discount_total(settle.id)

        lines = []
        gross_sum = Decimal("0.00")
        share_sum = Decimal("0.00")
        refunded_sum = Decimal("0.00")

        for req, row in zip(items, rows):
            req_qty = (Decimal(str(req["refund_qty"]))
                       if isinstance(req, dict)
                       else Decimal(str(req.refund_qty)))
            avail = (Decimal(str(row["quantity"]))
                     - Decimal(str(row["refunded_qty"])))
            if req_qty <= 0 or req_qty > avail:
                raise BizError(54998, "退费数量非法")

            gross = money(Decimal(str(row["unit_price"])) * req_qty)
            base = Decimal(str(row["base_amount"]))
            share = money(discount_total * base / total_base) \
                if total_base > 0 else Decimal("0.00")
            share_for_qty = money(share * req_qty
                                  / Decimal(str(row["quantity"])))
            net = money(gross - share_for_qty)

            is_tail = (req_qty == avail)
            if is_tail:
                # 尾差修正：剩余净额 = 该行净额 − 已退额
                row_net = money(
                    Decimal(str(row["gross_amount"])) - share)
                refund_amt = money(
                    row_net - Decimal(str(row["refunded_amount"])))
            else:
                refund_amt = net

            lines.append({
                "item_id": row["id"],
                "line_no": row["line_no"],
                "item_code": row["item_code"],
                "item_name": row["item_name"],
                "unit_price": str(row["unit_price"]),
                "refund_qty": str(req_qty),
                "original_qty": str(row["quantity"]),
                "refunded_qty_before": str(row["refunded_qty"]),
                "gross_amount": str(gross),
                "discount_share": str(share_for_qty),
                "refund_amount": str(refund_amt),
                "is_tail_adjust": is_tail,
            })
            gross_sum += gross
            share_sum += share_for_qty
            refunded_sum += Decimal(str(row["refunded_amount"]))

        return {
            "gross_amount": str(money(gross_sum)),
            "discount_share": str(money(share_sum)),
            "net_amount": str(money(gross_sum - share_sum)),
            "refunded_before": str(money(refunded_sum)),
            "refund_amount": str(money(gross_sum - share_sum)),
            "lines": lines,
        }

    # ---------- 执行 ----------

    async def execute(self, refund_id: int, payload, user,
                      client_ip: str = None):
        """执行退费"""
        lock_key = "m16:refund:exec:%d" % refund_id
        if not await self._try_lock(lock_key, 60):
            raise BizError(55008, "该退费单正在执行中")
        try:
            refund = await self._get_for_update(refund_id)
            if refund.status == "SUCCESS":
                return self._dict(refund)
            if refund.status not in ("APPROVED", "FAILED"):
                raise BizError(55008, "退费单状态不允许执行")

            # 金额一致性校验
            if payload.confirmed_amount is not None:
                if money(payload.confirmed_amount) != \
                        money(refund.refund_amount):
                    raise BizError(55003, "金额已变化，请重新提交")

            refund.status = "EXECUTING"
            refund.executing_at = datetime.now()
            await self.db.flush()

            steps = []
            try:
                # ① 重算
                settle = await self._load_settlement(refund.settlement_no)
                items = await self._load_refund_items(refund.id)
                recalc = await self._calc_amount(settle, [
                    {"item_id": i.settlement_item_id,
                     "refund_qty": i.refund_qty} for i in items])
                if abs(Decimal(recalc["refund_amount"])
                       - Decimal(str(refund.refund_amount))) > CENT:
                    raise BizError(55003, "金额已变化，需重新提交")
                steps.append(self._step(1, "RECALC", "金额重算",
                                        "SUCCESS", "与审批金额一致"))

                # ② 红冲
                red = None
                invoice = await self._get_invoice(settle.id)
                if invoice and Decimal(str(invoice.red_amount)) \
                        < Decimal(str(invoice.amount)):
                    red = await self._red_flush(
                        invoice, refund, settle)
                    steps.append(self._step(
                        2, "RED_FLUSH", "发票红冲", "SUCCESS",
                        "红票 %s ¥-%s" % (red["invoice_no"],
                                          refund.refund_amount)))
                else:
                    steps.append(self._step(2, "RED_FLUSH", "发票红冲",
                                            "SKIPPED", "无有效发票"))

                # ③ 资金退回
                pay = await self._pay_refund(refund, settle)
                refund.channel_refund_no = pay.get("refund_no")
                steps.append(self._step(
                    3, "PAY_REFUND", "资金退回", "SUCCESS",
                    "%s %s" % (pay.get("channel", ""),
                               pay.get("refund_no", ""))))

                # ④ 结算单回滚
                await self._rollback_settlement(refund, settle)
                steps.append(self._step(4, "SETTLE_ROLLBACK", "结算单回滚",
                                        "SUCCESS", settle.settlement_no))

                # ⑤ 上游回写（异步）
                await self._enqueue_upstream(refund)
                steps.append(self._step(5, "UPSTREAM_WRITEBACK", "上游回写",
                                        "QUEUED", refund.source_module))

                # ⑥ 会员权益（异步）
                if settle.patient_id:
                    await self._enqueue_member_revert(refund)
                    steps.append(self._step(6, "MEMBER_REVERT",
                                            "会员权益", "QUEUED", "积分回退"))
                else:
                    steps.append(self._step(6, "MEMBER_REVERT",
                                            "会员权益", "SKIPPED", "非会员"))

                refund.status = "SUCCESS"
                refund.completed_at = datetime.now()
                await self._log(refund, "EXECUTE", "SUCCESS", user)
                await self.db.commit()
                result = self._dict(refund)
                result["steps"] = steps
                result["red_invoice"] = red
                result["payment"] = pay
                return result

            except BizError as exc:
                await self.db.rollback()
                refund = await self._get_for_update(refund_id)
                if exc.code == 55003:
                    refund.status = "FAILED"
                    refund.fail_reason = exc.message
                    await self._log(refund, "EXECUTE", "ERROR", user,
                                    detail=exc.message)
                    await self.db.commit()
                    raise
                await self._mark_abnormal(refund, exc)
                raise

            except Exception as exc:
                logger.exception("退费执行异常 refund_id=%s", refund_id)
                await self.db.rollback()
                refund = await self._get_for_update(refund_id)
                await self._mark_abnormal(refund, exc)
                raise

        finally:
            await self._unlock(lock_key)

    async def _red_flush(self, invoice, refund, settle):
        """调 M16-07 红冲"""
        from app.services.m16.invoice import InvoiceService
        svc = InvoiceService(self.db)
        return await svc.red_flush(
            invoice.id,
            {
                "amount": str(refund.refund_amount),
                "reason": "REFUND",
                "description": "退费单 %s 红冲" % refund.refund_no,
                "refund_no": refund.refund_no,
            },
        )

    async def _pay_refund(self, refund, settle):
        """调 M16-05 退款"""
        from app.services.m16.pay import RefundService as PayRefundService
        svc = PayRefundService(self.db)
        return await svc.create(
            {
                "settlement_no": settle.settlement_no,
                "refund_amount": str(refund.refund_amount),
                "refund_method": refund.refund_method,
                "pay_method": refund.pay_channel,
                "biz_refund_no": refund.refund_no,
                "reason": refund.reason_desc or refund.reason_code,
            },
            operator_id=refund.created_by,
        )

    async def _rollback_settlement(self, refund, settle):
        """调 M16-01 回滚结算单"""
        remaining = money(
            Decimal(str(settle.paid_amount))
            - Decimal(str(settle.refunded_amount))
            - Decimal(str(refund.refund_amount)))
        new_status = "REFUNDED" if remaining <= Decimal("0.00") \
            else "PARTIAL_REFUNDED"
        settle.refunded_amount = money(
            Decimal(str(settle.refunded_amount))
            + Decimal(str(refund.refund_amount)))
        settle.status = new_status
        await self.db.flush()

    # ---------- 审批 ----------

    def _resolve_tier(self, amount, scene):
        """判定审批档位"""
        amt = money(amount)
        cfg = SCENE_CONFIG.get(scene, {"base_tier": "T2"})
        # 场景本身的要求档位（取较高者）
        base_tier = cfg["base_tier"]
        tier = None
        for t in APPROVAL_TIERS:
            if t["max_amount"] is None or amt < t["max_amount"]:
                tier = t
                break
        if base_tier == "T3" and tier["tier"] in ("T1", "T2"):
            tier = next(t for t in APPROVAL_TIERS if t["tier"] == "T3")
        required = tier["tier"] != "T1"
        return {
            "required": required,
            "tier": tier["tier"],
            "tier_name": {
                "T1": "免审", "T2": "初级审批",
                "T3": "中级审批", "T4": "高级审批",
            }[tier["tier"]],
            "approver_role": tier["role"],
            "timeout_minutes": tier["timeout"],
        }

    # ---------- 风控 ----------

    async def _risk_check(self, settle, amount, user):
        """退费风控规则"""
        hits = []
        patient_count = await self.db.scalar(
            text("SELECT COUNT(*) FROM m16_refund_order "
                 "WHERE patient_id = :pid "
                 "  AND created_at >= NOW() - INTERVAL '30 days' "
                 "  AND status IN ('SUCCESS','EXECUTING','APPROVED')"),
            {"pid": settle.patient_id},
        )
        if patient_count >= 5:
            hits.append({"rule": "R-02", "level": "BLOCK",
                         "message": "该患者 30 天内退费已达 %d 次"
                                    % patient_count})
        elif patient_count >= 3:
            hits.append({"rule": "R-01", "level": "WARN",
                         "message": "该患者 30 天内退费 %d 次"
                                    % patient_count})

        settle_count = await self.db.scalar(
            text("SELECT COUNT(*) FROM m16_refund_order "
                 "WHERE settlement_id = :sid "
                 "  AND created_at >= NOW() - INTERVAL '24 hours' "
                 "  AND status <> 'CANCELLED'"),
            {"sid": settle.id},
        )
        if settle_count >= 2:
            hits.append({"rule": "R-05", "level": "WARN",
                         "message": "该结算单 24 小时内已退费 %d 次"
                                    % settle_count})

        cashier_total = await self.db.scalar(
            text("SELECT COALESCE(SUM(refund_amount), 0) "
                 "FROM m16_refund_order "
                 "WHERE created_by = :uid AND refund_method = 'CASH' "
                 "  AND created_at >= CURRENT_DATE "
                 "  AND status IN ('SUCCESS','EXECUTING')"),
            {"uid": user.id},
        )
        if Decimal(str(cashier_total)) >= Decimal("5000.00"):
            hits.append({"rule": "R-03", "level": "WARN",
                         "message": "今日现金退费已累计 ¥%s"
                                    % cashier_total})

        if any(h["level"] == "BLOCK" for h in hits):
            raise BizError(55004, "触发退费风控阻断，需主管审批")
        return hits

    # ---------- 工具 ----------

    async def _next_refund_no(self):
        """RF + YYMMDD + 4 位序号"""
        seq = await self.db.scalar(text(
            "SELECT nextval('seq_m16_refund_no')"))
        return "RF%s%04d" % (datetime.now().strftime("%y%m%d"), seq % 10000)

    @staticmethod
    def _step(seq, code, name, status, detail):
        return {"seq": seq, "code": code, "name": name,
                "status": status, "detail": detail}


class RefundApprovalService:
    """退费审批"""

    def __init__(self, db: AsyncSession):
        self.db = db

    async def approve(self, refund_id, payload, user):
        refund = await self._get_for_update(refund_id)
        if refund.status != "PENDING_APPROVAL":
            raise BizError(55008, "退费单状态已变更")
        if refund.created_by == user.id:
            raise BizError(55006, "不能审批自己提交的退费单")
        if not await self._has_tier_permission(user, refund.approval_tier):
            raise BizError(55007, "审批权限不足该档位")
        if refund.approval_deadline and \
                datetime.now() > refund.approval_deadline:
            raise BizError(55010, "审批已超时")

        # 重算一致性
        settle = await self._load_settlement(refund.settlement_no)
        items = await self._load_refund_items(refund.id)
        svc = RefundService(self.db)
        recalc = await svc._calc_amount(settle, [
            {"item_id": i.settlement_item_id, "refund_qty": i.refund_qty}
            for i in items])
        if abs(Decimal(recalc["refund_amount"])
               - Decimal(str(refund.refund_amount))) > CENT:
            raise BizError(55003, "结算单金额已变化，请驳回后重新提交")

        refund.status = "APPROVED"
        refund.approved_by = user.id
        refund.approved_by_name = user.name
        refund.approved_at = datetime.now()
        refund.approval_comment = payload.comment
        await self.db.commit()

        if payload.auto_execute:
            return await svc.execute(
                refund_id, {"confirmed_amount": refund.refund_amount},
                user)
        return svc._dict(refund)

    async def reject(self, refund_id, payload, user):
        if not payload.comment or len(payload.comment.strip()) < 2:
            raise BizError(55009, "驳回必须填写意见")
        refund = await self._get_for_update(refund_id)
        if refund.status != "PENDING_APPROVAL":
            raise BizError(55008, "退费单状态已变更")
        refund.status = "REJECTED"
        refund.rejected_by = user.id
        refund.rejected_at = datetime.now()
        refund.approval_comment = payload.comment
        await self.db.commit()
        return RefundService(self.db)._dict(refund)


class RefundQueryService:
    """退费台账查询与导出"""

    QUERY_DAYS_LIMIT = 92
    EXPORT_ROWS_LIMIT = 50000

    def __init__(self, db: AsyncSession):
        self.db = db

    async def list(self, date_from, date_to, status, scene, refund_method,
                   cashier_id, keyword, page, page_size, user):
        df, dt = self._parse_dates(date_from, date_to)
        if (dt - df).days > self.QUERY_DAYS_LIMIT:
            raise BizError(55013, "查询跨度不得超过 %d 天"
                           % self.QUERY_DAYS_LIMIT)
        where = ["created_at >= :df", "created_at < :dt",
                 "is_deleted = FALSE"]
        params = {"df": df, "dt": dt}
        if status:
            where.append("status = :status")
            params["status"] = status
        if scene:
            where.append("scene = :scene")
            params["scene"] = scene
        if refund_method:
            where.append("refund_method = :rm")
            params["rm"] = refund_method
        if cashier_id:
            where.append("created_by = :cid")
            params["cid"] = cashier_id
        if keyword:
            where.append(
                "(patient_name ILIKE :kw OR refund_no ILIKE :kw "
                " OR settlement_no ILIKE :kw)")
            params["kw"] = "%%%s%%" % keyword

        where_sql = " AND ".join(where)
        total = await self.db.scalar(text(
            "SELECT COUNT(*) FROM m16_refund_order WHERE " + where_sql),
            params)
        rows = (await self.db.execute(text(
            "SELECT * FROM m16_refund_order WHERE " + where_sql
            + " ORDER BY created_at DESC LIMIT :lim OFFSET :off"),
            dict(params, lim=page_size, off=(page - 1) * page_size),
        )).mappings().all()

### 6.7 退费编排专题实现

```python
# app/services/m16/refund_orchestrator.py
"""退费执行编排：六步链路的容错与补偿"""
import asyncio
import logging
from datetime import datetime, timedelta
from decimal import Decimal

logger = logging.getLogger(__name__)

# 每步的重试策略：次数与间隔（秒）
STEP_RETRY_POLICY = {
    "RED_FLUSH": {"max_retry": 3, "intervals": [5, 30, 120]},
    "PAY_REFUND": {"max_retry": 0, "intervals": []},
    "SETTLE_ROLLBACK": {"max_retry": 3, "intervals": [2, 10, 30]},
    "UPSTREAM_WRITEBACK": {"max_retry": 10,
                           "intervals": [60, 120, 240, 480, 960]},
    "MEMBER_REVERT": {"max_retry": 10,
                      "intervals": [60, 120, 240, 480, 960]},
}


class RefundOrchestrator:
    """退费执行编排器"""

    def __init__(self, db):
        self.db = db

    async def run(self, refund):
        """按固定顺序执行，任一步失败按策略处理"""
        # ① 红冲：失败则不退款
        try:
            await self._run_with_retry(refund, "RED_FLUSH")
        except Exception as exc:
            logger.error("红冲失败 refund=%s err=%s",
                         refund.refund_no, exc)
            await self._set_failed(refund, "RED_FLUSH", exc)
            return

        # ② 资金退回：超时进 ABNORMAL，不重试
        try:
            await self._run_pay(refund)
        except PayTimeoutError as exc:
            await self._set_abnormal(refund, "PAY_REFUND", exc)
            return
        except Exception as exc:
            await self._set_failed(refund, "PAY_REFUND", exc)
            return

        # ③ 结算单回滚：失败重试，但不阻断后续（钱已退）
        await self._safe_run(refund, "SETTLE_ROLLBACK")

        # ④⑤ 上游回写与会员权益：进队列
        await self._safe_run(refund, "UPSTREAM_WRITEBACK")
        await self._safe_run(refund, "MEMBER_REVERT")

        refund.status = "SUCCESS"
        refund.completed_at = datetime.now()
        await self.db.commit()

    async def _run_with_retry(self, refund, step_code):
        policy = STEP_RETRY_POLICY[step_code]
        last_exc = None
        for attempt in range(policy["max_retry"] + 1):
            try:
                return await self._dispatch(refund, step_code)
            except Exception as exc:
                last_exc = exc
                if attempt < policy["max_retry"]:
                    await asyncio.sleep(
                        policy["intervals"][min(
                            attempt, len(policy["intervals"]) - 1)])
        raise last_exc

    async def _safe_run(self, refund, step_code):
        """失败不抛异常，只记队列"""
        try:
            await self._run_with_retry(refund, step_code)
        except Exception as exc:
            logger.warning("退费步骤 %s 失败已入队 refund=%s err=%s",
                           step_code, refund.refund_no, exc)
            await self._enqueue_compensation(refund, step_code, exc)

    async def _dispatch(self, refund, step_code):
        """按步骤码分发到具体实现"""
        if step_code == "RED_FLUSH":
            return await self._do_red_flush(refund)
        if step_code == "SETTLE_ROLLBACK":
            return await self._do_settle_rollback(refund)
        if step_code == "UPSTREAM_WRITEBACK":
            return await self._do_upstream(refund)
        if step_code == "MEMBER_REVERT":
            return await self._do_member_revert(refund)
        raise ValueError("未知步骤 %s" % step_code)

    async def _set_failed(self, refund, step_code, exc):
        refund.status = "FAILED"
        refund.fail_step = step_code
        refund.fail_reason = str(exc)[:500]
        refund.retry_count = (refund.retry_count or 0) + 1
        await self.db.commit()

    async def _set_abnormal(self, refund, step_code, exc):
        refund.status = "ABNORMAL"
        refund.fail_step = step_code
        refund.fail_reason = ("资金退回结果未知：%s" % exc)[:500]
        await self.db.commit()
        await self._alert_finance(refund)

    async def _alert_finance(self, refund):
        """通知财务主管处理异常"""
        from app.services.m03.message import MessageService
        svc = MessageService(self.db)
        await svc.send(
            template_code="M16_REFUND_ABNORMAL",
            receivers=["role:财务主管"],
            params={"refund_no": refund.refund_no,
                    "amount": str(refund.refund_amount),
                    "reason": refund.fail_reason},
        )


class PayTimeoutError(Exception):
    """渠道退款响应超时"""
```

**编排器设计要点：**

1. **红冲必须先于退款** —— `_run_with_retry` 抛异常直接 `return`，不执行后续步骤
2. **退款超时进 ABNORMAL 不重试** —— 重试会导致重复退款
3. **回滚与回写失败不阻断** —— 钱已经退出了，不能因为回写失败就回滚退款
4. **补偿队列兜底** —— `_safe_run` 失败全部入队，由 Celery 重试

## 11. 异常处理与日志

### 11.1 异常分类

| 类别 | 场景 | 处理策略 |
|---|---|---|
| **业务校验异常** | 资格不符、金额超限 | 直接返回错误码 |
| **并发冲突** | 重复执行 | Redis 锁 + 状态机 |
| **依赖超时** | M16-05 退款超时 | 置 `ABNORMAL`，不重试 |
| **依赖失败** | 红冲失败 | 置 `FAILED`，可重试 3 次 |
| **回写失败** | 上游回写失败 | 补偿队列，不影响主流程 |
| **数据不一致** | 金额重算不一致 | 拒绝执行，报 55003 |
| **系统异常** | 数据库/网络 | 事务回滚，置 `FAILED` |
