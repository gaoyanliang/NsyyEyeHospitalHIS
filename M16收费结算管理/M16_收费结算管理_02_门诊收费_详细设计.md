## 1. 模块概述

### 1.1 模块定位

门诊收费是**收银员每天对着的那个界面**。它回答："**收谁的钱、怎么收、钱进了哪个抽屉？**"

```
┌──────────────────────────────────────────────────────────────┐
│  M16-01 计费引擎已经在 UNPAID 结算单里写死了金额                │
│  "这张单应收 399.00 元，一分不能多一分不能少"                    │
└────────────────────────┬─────────────────────────────────────┘
                         │
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M16-02 门诊收费（本文档）★ 收银员操作界面                      │
│  · 扫就诊码 / 输门诊号，调出待收费结算单                        │
│  · 选支付方式（现金/扫码/POS/储值），可混合                       │
│  · 调 M16-05 实际扣款                                          │
│  · 现金找零                                                    │
│  · 打印小票                                                    │
│  · 记录班次（谁在哪个窗口、开了多少钱）                          │
└────────────────────────┬─────────────────────────────────────┘
                         │ 支付成功
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M16-01 接管：结算单 UNPAID → PAID，回写 M07/M04               │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 为什么门诊收费要独立成子模块

M16-01 的计费引擎是**纯计算、无界面、可被任何调用方触发**（挂号自动建单、医嘱自动建单、患者自助缴费）。

但**有人坐在窗口收钱**这件事，有完全不同的关注点：

| 关注点 | M16-01 计费引擎 | M16-02 门诊收费 |
|---|---|---|
| 谁在收钱 | 不关心 | **必须记录班次与收费员** |
| 钱进了哪个抽屉 | 不关心 | **必须能日结对账** |
| 患者站在窗口等 | 不关心 | **必须快（P95 ≤ 1.5 秒）** |
| 打印小票 | 不关心 | **必须打** |
| 找了多少钱 | 不关心 | **必须记找零** |
| 网络断了怎么办 | 不关心 | **必须能离线** |

**如果合在 M16-01：** 计费引擎会变成一个背着班次、小票、找零、离线队列的怪物，且无法被自助机、公众号复用。

### 1.3 与相邻子模块的分工

| 事项 | M16-01 | **M16-02** | M16-05 | M16-07 |
|---|---|---|---|---|
| 算金额 | ✅ | ❌ 只读 | ❌ | ❌ |
| 刷卡/扫码扣款 | ❌ | ❌ | ✅ **唯一责任** | ❌ |
| **选支付方式、拆多笔支付** | ❌ | ✅ **唯一责任** | 执行扣款 | ❌ |
| **现金找零** | ❌ | ✅ **唯一责任** | ❌ | ❌ |
| **收费员班次与现金箱** | ❌ | ✅ **唯一责任** | ❌ | ❌ |
| **打印小票** | ❌ | ✅ **唯一责任** | ❌ | ❌ |
| 开正式发票 | ❌ | 发起请求 | ❌ | ✅ **唯一责任** |
| 结算单状态改 PAID | 接收回调 | 触发回调 | ❌ | ❌ |
| 回写 M07/M04 | ✅ **唯一责任** | ❌ | ❌ | ❌ |

**关键约定：M16-02 只负责"收款这个动作"，钱进入系统之后的一切（状态、回写、记账）都由 M16-01 和下游承担。**

### 1.4 门诊收费与住院结算的区别

| 维度 | 门诊收费 | 住院结算（M16-03） |
|---|---|---|
| 结算时点 | 先付费后诊疗 | 预交金 → 出院结算 |
| 是否现结 | 是 | 否（有预交金池） |
| 单笔金额 | 几十 ~ 几千 | 几千 ~ 几万 |
| 是否需要预交 | 否 | 是 |
| 退费 | 原路退回 | 从预交金池或原路 |
| 状态 | 一次收清 | 多次记账，最后一次结清 |

### 1.5 模块目标

| 目标 | 指标 |
|---|---|
| 收银要快 | 从扫码到收据打印 P95 ≤ 1.5 秒 |
| 一分不差 | 班次现金对账误差 = 0（可查每一笔） |
| 不断网 | 网络中断仍可现金收费，恢复后自动补传 |
| 不重复收 | 同一结算单不可能被收两次 |
| 可追溯 | 每笔钱的收银员、窗口、班次、时间、找零全部可查 |

### 1.6 关键业务角色

| 角色 | 职责 | 权限 |
|---|---|---|
| 收费员 | 收银、找零、打印小票、开票 | `m16:cashier:*` |
| 收费处主管 | 开班审核、班次对账、长短款处理 | `m16:cashier:manage` |
| 财务科 | 查班次日报、核对现金 | 只读 |
| 患者 | 被动缴费 | 无（自助端走 M03-06） |

## 3. 业务模型

### 3.1 收银主流程

```
① 患者到窗口
      │
      ▼
② 收费员扫就诊码 / 输门诊号 / 输结算单号
      │
      ▼
③ 系统调出该患者的待收费结算单列表
      │
      ▼
④ 收费员勾选要收的单
      │
      ▼
⑤ 系统显示应收金额（来自 M16-01，不可改）
      │
      ▼
⑥ 收费员选支付方式
      ├─ 现金   → 输实收 → 自动算找零
      ├─ 扫码   → 调 M16-05 生成二维码 → 患者扫码 → 等待回调
      ├─ POS    → 调 M16-05 发起刷卡 → 等待结果
      └─ 储值   → 调 M16-05 扣余额 → 可能需患者输入密码
      │
      ▼
⑦ 支付成功
      │
      ▼
⑧ 回调 M16-01：结算单 UNPAID → PAID，回写 M07/M04
      │
      ▼
⑨ 打印小票
      │
      ▼
⑩ 记录班次流水（m16_cashier_record）
```

### 3.2 收费员班次模型（核心）

**问题：** 收费员交班时，抽屉里的现金必须和系统记录一致。差一分钱都要能查出来。

```
班次（m16_cashier_session）
  ├─ 开班：收费员 + 窗口 + 备用金（如 500 元零钞）
  ├─ 期间：每一笔收费都记一笔流水（m16_cashier_record）
  │    ├─ 现金收费 +399.00   → 抽屉 +399.00
  │    ├─ 现金收费 +120.00   → 抽屉 +120.00
  │    └─ 现金退费 -80.00    → 抽屉 -80.00
  └─ 交班：
       ├─ 系统算：应有现金 = 备用金 + Σ现金收 − Σ现金退
       ├─ 收费员点钞：实有现金 = 数出来的数
       └─ 差异 = 实有 − 应有
            ├─ 差异 = 0    → 正常交班
            ├─ 差异 > 0    → 长款（多钱了）
            └─ 差异 < 0    → 短款（少钱了）
```

**为什么要备用金：** 早上抽屉里本来就有 500 元零钱，交班时数出来 2,300 元，不能把 2,300 全算营业额。`应有现金 = 备用金 + 本期现金收入 − 本期现金支出`。

**长款短款都必须填说明：** 短款 50 元，要写"找零时多找给患者"。这是财务制度要求。

### 3.3 支付方式模型

**支付方式来自 M01-06 `md_payment_method`，M16-02 按 `pay_category` 决定交互：**

| `pay_category` | 示例 | 交互 | 是否需找零 | 是否三方 |
|---|---|---|---|---|
| `CASH` | 现金 | 输实收，自动算找零 | ✅ | ❌ |
| `CARD` | 银行卡 POS | 发起刷卡，等待结果 | ❌ | ✅ |
| `SCAN` | 微信/支付宝/云闪付 | 生成二维码，等回调 | ❌ | ✅ |
| `STORED` | 会员储值 | 扣余额（可能需密码） | ❌ | ❌ |
| `INSURANCE` | 商保直付 | 预留 | ❌ | ✅ |
| `OTHER` | 转账/支票/减免 | 手工登记 | ❌ | ❌ |

**关键：** M16-02 **不硬编码任何支付方式**，全部读 `md_payment_method`。新增"数字人民币"只需 M01-06 加一条主数据。

### 3.4 混合支付模型

**场景：** 患者储值余额只有 100 元，应收 399 元。

```
结算单 BL20261021001  应收 399.00
   ├─ 支付 1：会员储值  100.00  （成功）
   └─ 支付 2：微信扫码  299.00  （成功）
   ────────────────────────────────
   合计 399.00  ✓ 收齐
```

**规则：**

| 规则 | 说明 |
|---|---|
| 最小支付笔数 1 | 单一方式即可 |
| 最大支付笔数 | 默认 3（参数 `M16.CASHIER.MAX_SPLIT`） |
| 部分成功处理 | 前一笔成功、后一笔失败 → 结算单仍 `UNPAID`，已成功的支付挂起待处理 |
| 合计必须等于应收 | 差 1 分钱都不许结账 |
| 支付顺序 | 建议先储值/优惠券，再现金，最后扫码（减少找零） |

**部分成功的处理（关键）：**

```
支付1 储值 100.00 成功
支付2 微信 299.00 失败
      ↓
不能只算 100 收了，因为结算单要 399
      ↓
结算单保持 UNPAID，但记录「已收 100.00，待收 299.00」
状态：UNPAID + partially_paid=TRUE + partial_paid_amount=100.00
      ↓
患者下次来，只需补收 299.00
      ↓
或者：作废本次，退掉那 100
```

### 3.5 现金找零模型

```
应收金额   = 399.00
实收现金   = 500.00   （患者给的）
找零金额   = 500.00 − 399.00 = 101.00
```

**规则：**

| 规则 | 说明 | 错误码 |
|---|---|---|
| 实收 ≥ 应收 | 不足不允许确认 | 54850 |
| 找零自动算 | 不可手改 | — |
| 常用面额快捷键 | 100/200/500/1000 | — |
| 大额找零提示 | 找零 > 100 弹提示确认 | 警告 |
| 找零金额入流水 | `m16_cashier_record.change_amount` | — |

### 3.6 小票模型（≠ 发票）

**必须区分清楚：**

| 项 | 小票（M16-02） | 发票（M16-07） |
|---|---|---|
| 凭证性质 | 收款凭证 | 法定税前扣除凭证 |
| 谁开 | 收费员即可 | 需税控/电子发票平台 |
| 是否可报销 | 一般不可（部分单位认可） | ✅ |
| 号码 | 小票流水号 | 发票号码（税控分配） |
| 是否必须 | 每次都打 | 患者主动要求才开 |
| 作废 | 可与结算单一起作废 | 需红冲原票 |

**小票内容：**

### 3.7 离线收费模型

**场景：** 医院网络或服务器故障，窗口后面排了 30 个患者。

**策略：**

```
断网检测
   ↓
M16-05 不可用 + M16-01 不可用
   ↓
┌─────────────────────────────────────────┐
│ 进入「离线模式」（需主管授权一次）         │
│ · 仅允许现金收费                         │
│ · 结算单数据来自浏览器本地缓存            │
│ · 每笔写入 IndexedDB，带设备指纹          │
│ · 打印离线小票（标记「离线」字样）         │
└─────────────────────────────────────────┘
   ↓ 网络恢复
补传队列
   ↓
逐笔调用 M16-01 生成结算单 + 标记已收
   ↓
冲突检测：若该结算单在线已被收过 → 标记冲突，人工处理（退线下那笔）
```

**离线收费的硬约束：**

| 约束 | 说明 |
|---|---|
| 只允许现金 | 扫码/POS 必须联网 |
| 必须有主管授权 | 收费员无权自行开启 |
| 必须记录设备指纹 | 防冒用 |
| 离线单独立编号 | `OFF` 前缀，与在线单区分 |
| 必须当日补传 | 超过 24 小时需主管处理 |

### 3.8 收费与挂号的关系

```
场景 A：窗口挂号并立即收费
   M04-03 创建挂号（REGISTERED）
      ↓
   M16-01 生成挂号费结算单（UNPAID）
      ↓
   M16-02 收款
      ↓
   M16-01 on-paid → 回写 M04（on-payment）
      ↓
   挂号状态 REGISTERED → PAID

场景 B：预约已在线缴费
   M04-02 预约 → M16-01 建单 → M03-06 自助支付
      ↓
   到院后直接凭预约记录取号（无需再收费）
      ↓
   M04-03 取号时检查已支付，直接置 PAID
```

### 3.9 收费员权限与窗口绑定

```
收费员登录
   ↓
绑定窗口（workstation_id）
   ↓
开班（m16_cashier_session）
   ↓
收银
   ↓
交班（现金对账）
```

**规则：**

| 规则 | 说明 | 错误码 |
|---|---|---|

|---|---|
| 点钞录入 | 每种面额输入张数，自动算金额 |
| 差异非 0 | 必须填写说明才能交班 |
| 确认交班 | 班次状态 → `CLOSED`，不可再收银 |

**校验规则：**

| 规则 | 错误码 |
|---|---|
| 有未完成支付不可交班 | 54854 |
| 差异非 0 未填说明 | 54862 |
| 非本人班次不可交班 | 54863 |

```python
    # ---------- 班次校验 ----------
    async def _require_open_session(self, operator_id: int):
        """必须有进行中的班次才能收银"""
        session = (await self.db.execute(
            select(M16CashierSession).where(
                M16CashierSession.operator_id == operator_id,
                M16CashierSession.status == "OPEN",
            )
        )).scalar_one_or_none()

        if not session:
            raise BizException("1602004", "当前未开班，请先开班后再收费")

        return session

    # ---------- 应收汇总 ----------
    async def _sum_payable(self, settlement_ids: List[int]):
        """汇总本次应收，并校验状态"""
        if not settlement_ids:
            raise BizException("1602002", "未选择任何待收费结算单")

        settlements = (await self.db.execute(
            select(M16Settlement)
            .where(
                M16Settlement.id.in_(settlement_ids),
                M16Settlement.is_deleted == False,
            )
            .order_by(M16Settlement.id)
            .with_for_update()
        )).scalars().all()

        if len(settlements) != len(settlement_ids):
            raise BizException("1602001", "部分结算单不存在或已删除")

        patient_ids = set(s.patient_id for s in settlements)

        if len(patient_ids) > 1:
            raise BizException("1602008", "合并收款的结算单必须属于同一患者")

        total = Decimal("0.00")

        for s in settlements:
            if s.status == "PAID":
                raise BizException(
                    54838, f"结算单 {s.settlement_no} 已支付，不可重复收费")

            if s.status == "CANCELLED":
                raise BizException(
                    54838, f"结算单 {s.settlement_no} 已作废")

            already = await self._partial_paid_amount(s.id)
            total += s.payable_amount - already

        return settlements, money(total)

    async def _partial_paid_amount(self, settlement_id: int) -> Decimal:
        """已部分支付的金额（混合支付场景）"""
        row = (await self.db.execute(
            select(func.coalesce(func.sum(M16Payment.pay_amount), 0))
            .where(
                M16Payment.status == "SUCCESS",
                M16Payment.settlement_ids.contains([settlement_id]),
            )
        )).scalar()

        paid = Decimal(str(row or 0))

        # 减去已退
        refunded = (await self.db.execute(
            select(func.coalesce(func.sum(M16Settlement.refunded_amount), 0))
            .where(M16Settlement.id == settlement_id)
        )).scalar()

        return money(paid - Decimal(str(refunded or 0)))

    # ---------- 编号 ----------
    async def _next_payment_no(self) -> str:
        day = date.today().strftime("%Y%m%d")
        key = f"m16:cashier:payseq:{day}"
        seq = await redis_client.incr(key)

        if seq == 1:
            await redis_client.expire(key, 86400 * 2)

        return f"PAY{day}{seq:04d}"

    async def _next_receipt_no(self) -> str:
        day = date.today().strftime("%Y%m%d")
        key = f"m16:cashier:rcptseq:{day}"
        seq = await redis_client.incr(key)

        if seq == 1:
            await redis_client.expire(key, 86400 * 2)

        return f"TK{day}{seq:04d}"

    async def _next_record_no(self, session_id: int) -> str:
        key = f"m16:cashier:recseq:{session_id}"
        seq = await redis_client.incr(key)

        if seq == 1:
            await redis_client.expire(key, 86400 * 7)

        return seq

    @staticmethod
    def _source_desc(s: M16Settlement) -> str:
        return {
            "ENCOUNTER": "就诊医嘱",
            "REGISTRATION": "挂号",
            "OPTICAL": "视光销售",
            "INPATIENT": "住院结算",
        }.get(s.source_type, s.source_type)
```

```python
"""收费员班次服务"""
from datetime import date, datetime
from decimal import Decimal, ROUND_HALF_UP
from typing import Optional

def money(value) -> Decimal:
    return Decimal(str(value)).quantize(CENT, rounding=ROUND_HALF_UP)


class CashierSessionService:
    """班次：开班 → 期间收银 → 交班对账"""

    # 点钞面额（元）
    DENOMINATIONS = [100, 50, 20, 10, 5, 1, 0.5, 0.1]

    def __init__(self, db: AsyncSession):
        self.db = db

    # ---------- 开班 ----------
    async def open(self, payload, user, trace_id: str = "") -> dict:
        """开班：绑定收费员 + 窗口 + 备用金"""
        # 已有进行中班次
        existing = (await self.db.execute(
            select(M16CashierSession).where(
                M16CashierSession.operator_id == user.staff_id,
                M16CashierSession.status == "OPEN",
            )
        )).scalar_one_or_none()

        if existing:
            raise BizException(
                "1602006",
                f"您已在窗口「{existing.workstation_name}」开班（{existing.session_no}），"
                f"请先交班")

        # 窗口被占
        occupied = (await self.db.execute(
            select(M16CashierSession).where(
                M16CashierSession.workstation_id == payload.workstation_id,
                M16CashierSession.status == "OPEN",
            )
        )).scalar_one_or_none()

        if occupied:
            raise BizException(
                "1602005",
                f"窗口「{payload.workstation_name}」已由 {occupied.operator_name} 在岗")

        opening_float = money(payload.opening_float)

        if opening_float < 0:
            raise BizException(40001, "备用金不可为负数")

        session_no = await self._next_session_no()

        session = M16CashierSession(
            session_no=session_no,
            operator_id=user.staff_id,
            operator_name=user.real_name,
            workstation_id=payload.workstation_id,
            workstation_name=payload.workstation_name,
            business_date=date.today(),
            opening_float=opening_float,
            expected_cash=opening_float,
            status="OPEN",
            opened_at=datetime.now(),
            remark=payload.remark,
            trace_id=trace_id,
        )
        self.db.add(session)
        await self.db.commit()

        return {
            "session_id": session.id,
            "session_no": session_no,
            "operator_id": user.staff_id,
            "operator_name": user.real_name,
            "workstation_id": payload.workstation_id,
            "workstation_name": payload.workstation_name,
            "opening_float": float(opening_float),
            "status": "OPEN",
            "opened_at": session.opened_at.isoformat(),
        }

    # ---------- 交班 ----------
    async def close(self, payload, user, trace_id: str = "") -> dict:
        """交班：汇总 + 点钞 + 差异计算"""
        session = (await self.db.execute(
            select(M16CashierSession)
            .where(M16CashierSession.id == payload.session_id)
            .with_for_update()
        )).scalar_one_or_none()

        if not session:
            raise BizException(40001, "班次不存在")

        if session.status == "CLOSED":
            raise BizException("1602018", "班次已关闭")

        if session.operator_id != user.staff_id and not user.has_permission(
                "m16:cashier:manage"):
            raise BizException("1602016", "非本人班次不可交班")

        # 未完成支付拦截
        pending = (await self.db.execute(
            select(func.count(M16Payment.id)).where(
                M16Payment.cashier_session_id == session.id,
                M16Payment.status == "PENDING",
            )
        )).scalar()

        if pending:
            raise BizException(
                "1602007", f"存在 {pending} 笔未完成的支付，请先处理后再交班")

        # 汇总
        summary = await self._summarize(session.id)

        # 点钞
        actual_cash = Decimal("0.00")

        for d in payload.denomination_counts:
            if d.count < 0:
                raise BizException(40001, "钞票张数不可为负")

            actual_cash += Decimal(str(d.denom)) * d.count

        actual_cash = money(actual_cash)
        expected_cash = summary["expected_cash"]
        difference = money(actual_cash - expected_cash)

        if difference != 0 and not payload.shortage_reason:
            raise BizException(
                "1602015",
                f"现金差异 {difference} 元，必须填写长短款说明")

        if difference > 0:
            difference_type = "OVER"     # 长款
        elif difference < 0:
            difference_type = "SHORT"    # 短款
        else:
            difference_type = "EVEN"

        session.status = "CLOSED"
        session.closed_at = datetime.now()
        session.cash_income = summary["cash_income"]
        session.cash_expense = summary["cash_expense"]
        session.expected_cash = expected_cash
        session.actual_cash = actual_cash
        session.difference = difference
        session.difference_type = difference_type
        session.shortage_reason = payload.shortage_reason
        session.non_cash_amount = summary["non_cash_total"]
        session.settle_count = summary["settle_count"]
        session.refund_count = summary["refund_count"]
        session.total_income = summary["total_income"]
        session.total_refund = summary["total_refund"]

        await self.db.commit()

        return {
            "session_id": session.id,
            "session_no": session.session_no,
            "status": "CLOSED",
            "closed_at": session.closed_at.isoformat(),
            "opening_float": float(session.opening_float),
            "cash_income": float(summary["cash_income"]),
            "cash_expense": float(summary["cash_expense"]),
            "expected_cash": float(expected_cash),
            "actual_cash": float(actual_cash),
            "difference": float(difference),
            "difference_type": difference_type,
            "non_cash_summary": summary["non_cash"],
            "total_income": float(summary["total_income"]),
            "total_refund": float(summary["total_refund"]),
            "net_income": float(money(
                summary["total_income"] - summary["total_refund"])),
            "settle_count": summary["settle_count"],
            "refund_count": summary["refund_count"],
        }

    # ---------- 汇总 ----------
    async def _summarize(self, session_id: int) -> dict:
        """按支付方式汇总班次期间所有流水"""
        rows = (await self.db.execute(
            select(
                M16CashierRecord.pay_method,
                M16CashierRecord.record_type,
                func.count(M16CashierRecord.id),
                func.sum(M16CashierRecord.pay_amount),
                func.sum(M16CashierRecord.cash_effect),
            )
            .where(M16CashierRecord.session_id == session_id)
            .group_by(M16CashierRecord.pay_method,
                      M16CashierRecord.record_type)
        )).all()

        cash_income = Decimal("0.00")
        cash_expense = Decimal("0.00")
        total_income = Decimal("0.00")
        total_refund = Decimal("0.00")
        non_cash = {}
        settle_count = 0
        refund_count = 0

        for method, rtype, cnt, amount, cash in rows:
            amount = money(amount or 0)
            cash = money(cash or 0)

            if rtype == "PAY":
                total_income += amount
                settle_count += cnt
                cash_income += cash
            else:   # REFUND
                total_refund += abs(amount)
                refund_count += cnt
                cash_expense += abs(cash)

            if method != "CASH":
                non_cash[method] = float(
                    non_cash.get(method, 0) + (amount if rtype == "PAY" else -amount))

        session = (await self.db.execute(
            select(M16CashierSession)
            .where(M16CashierSession.id == session_id)
        )).scalar_one()

        expected_cash = money(
            session.opening_float + cash_income - cash_expense)

        non_cash_total = money(sum(Decimal(str(v)) for v in non_cash.values()))

        return {
            "cash_income": cash_income,
            "cash_expense": cash_expense,
            "expected_cash": expected_cash,
            "total_income": total_income,
            "total_refund": total_refund,
            "non_cash": non_cash,
            "non_cash_total": non_cash_total,
            "settle_count": settle_count,
            "refund_count": refund_count,
        }

    # ---------- 编号 ----------
    async def _next_session_no(self) -> str:
        from app.core.redis import redis_client
        day = date.today().strftime("%Y%m%d")
        key = f"m16:cashier:sessseq:{day}"
        seq = await redis_client.incr(key)

        if seq == 1:
            await redis_client.expire(key, 86400 * 2)

        return f"B{day}{seq:04d}"
```

### 6.6 混合支付实现示例

```python
# app/services/m16/mixed_payment_service.py
"""混合支付：一笔结算单拆成多种方式"""
from decimal import Decimal, ROUND_HALF_UP
from typing import List

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.m16.payment import M16Payment
from app.models.m16.settlement import M16Settlement
from app.core.exceptions import BizException
from app.clients.m16_payment_client import PaymentClient


CENT = Decimal("0.01")


def money(value) -> Decimal:
    return Decimal(str(value)).quantize(CENT, rounding=ROUND_HALF_UP)


class MixedPaymentService:
    """混合支付编排

    关键难点：任何一笔失败都不能把结算单置为 PAID。
    只有合计收齐了才回调 M16-01。
    """

    MAX_SPLIT = 3   # 最多拆 3 笔

    def __init__(self, db: AsyncSession):
        self.db = db
        self.client = PaymentClient()

    async def execute(self, settlement_ids: List[int], splits: List[dict],
                      user, trace_id: str = "") -> dict:
        """按 splits 顺序执行支付

        splits: [
          {"method": "STORED", "amount": 100.00},
          {"method": "WECHAT", "amount": 299.00}
        ]
        """
        if len(splits) > self.MAX_SPLIT:
            raise BizException(
                40001, f"最多拆分为 {self.MAX_SPLIT} 笔支付")

        if len(splits) < 2:
            raise BizException(40001, "混合支付至少需要 2 笔")

        settlements = (await self.db.execute(
            select(M16Settlement)
            .where(M16Settlement.id.in_(settlement_ids))
            .with_for_update()
        )).scalars().all()

        payable = money(sum(s.payable_amount for s in settlements))
        total = money(sum(Decimal(str(x["amount"])) for x in splits))

        if total != payable:
            raise BizException(
                "1602014",
                f"分笔合计 {total} 元与应收 {payable} 元不一致")

        # 逐笔执行
        executed = []
        failed_at = None

        for idx, split in enumerate(splits, start=1):
            payment_no = f"PAY{await self._seq()}"
            payment = M16Payment(
                payment_no=payment_no,
                settlement_ids=settlement_ids,
                patient_id=settlements[0].patient_id,
                pay_method=split["method"],
                pay_amount=money(split["amount"]),
                received_amount=money(split["amount"]),
                change_amount=Decimal("0.00"),
                status="PENDING",
                source_channel="CASHIER",
                split_index=idx,
                split_count=len(splits),
                cashier_id=user.staff_id,
                cashier_name=user.real_name,
                trace_id=trace_id,
            )
            self.db.add(payment)
            await self.db.flush()

            try:
                result = await self.client.pay({
                    "payment_no": payment_no,
                    "amount": float(split["amount"]),
                    "method": split["method"],
                })

                if result["status"] == "SUCCESS":
                    payment.status = "SUCCESS"
                    payment.transaction_no = result.get("transaction_no")
                    executed.append(payment_no)
                else:
                    payment.status = "FAILED"
                    payment.fail_reason = result.get("fail_reason")
                    failed_at = idx
                    break
            except Exception as e:
                payment.status = "FAILED"
                payment.fail_reason = str(e)[:500]
                failed_at = idx
                break

        await self.db.commit()

        if failed_at is not None:
            # 部分成功：不回滚已成功的，也不改结算单状态
            return {
                "status": "PARTIAL_FAILED",
                "executed": executed,
                "failed_at": failed_at,
                "succeeded_amount": float(money(sum(
                    Decimal(str(splits[i]["amount"]))
                    for i in range(failed_at - 1)))),
                "payable": float(payable),
                "message": (
                    f"第 {failed_at} 笔支付失败。已成功收款部分保留，"
                    f"可稍后补收剩余金额，或整单取消后退还已收部分。"),
            }

        # 全部成功 → 回调 M16-01
        from app.services.m16.settlement_service import SettlementService
        settle_svc = SettlementService(self.db)
        rewrites = []

        for s in settlements:
            result = await settle_svc.on_paid(s.id, {
                "payment_id": 0,
                "payment_no": ",".join(executed),
                "paid_amount": float(s.payable_amount),
                "payment_method": "MIXED",
                "paid_at": datetime.now().isoformat(),
                "operator_id": user.staff_id,
                "operator_name": user.real_name,
            }, trace_id=trace_id)
            rewrites.extend(result.get("rewrites", []))

        await self.db.commit()

        return {
            "status": "SUCCESS",
            "executed": executed,
            "succeeded_amount": float(payable),
            "payable": float(payable),
            "rewrites": rewrites,
        }
```

| `m16:cashier:lock:settle:{id}` | String | 10s | 结算单收款锁（防重复点击） |

**容量估算：** 计数器约 20 个 key，缓存类约 5 MB。可用内存 < 8 MB。

**防重复收款锁：**

```python
async def acquire_pay_lock(settlement_ids: list) -> bool:
    """同一结算单同一时刻只允许一个收银员在收

    这是防「两个窗口同时收同一张单」的最后一道闸门。
    数据库的 SELECT FOR UPDATE 也能防，但那是在事务内；
    这里在业务入口就拦住，避免用户看到两边的金额都对。
    """
    keys = [f"m16:cashier:lock:settle:{sid}" for sid in settlement_ids]
    got = []

    for key in keys:
        ok = await redis_client.set(key, "1", nx=True, ex=10)

        if not ok:
            # 回滚已获取的
            for k in got:
                await redis_client.delete(k)

            return False

        got.append(key)

    return True
```

```python
    为什么要主动关：
      患者扫了码但没付，或者付了但回调丢了。
```

| 金额只读 | 前端展示的金额来自后端，提交时后端重新汇总，**忽略前端传的金额** |
| 支付锁 | 同一结算单同一时刻只能被收一次 |
| 班次强绑定 | 未开班无法收银，收费员离职后班次需强制关闭 |
| 操作留痕 | 每笔收费写 `m16_cashier_record` + `m16_payment` + M02 审计 |
| 离线需授权 | 仅主管可开启，且记录设备指纹 |
| 大额提醒 | 单笔超 5000 提示主管确认（可配） |
| 长短款留痕 | 差异与说明永久保存 |

## 11. 异常处理与日志

### 11.1 异常分类

| 类型 | 示例 | 处理 |
|---|---|---|
| 未开班 | 收费员直接点收银 | 54851，引导开班 |
| 无待收费 | 患者没开单就来缴费 | 54848，提示去医生处开单 |
| 现金不足 | 实收 < 应收 | 54850，显示差额 |
| 支付超时 | 扫码 120s 未付 | 关闭订单，返回 P03 |
| 渠道故障 | 微信接口 500 | 54864，建议用现金 |
| 部分支付失败 | 混合支付第 2 笔失败 | 保留第 1 笔，提示补收或整单退 |
| 回写失败 | M07 不可用 | 已收钱，写补偿队列，前台照常打印小票 |
| 打印失败 | 打印机离线 | 降级电子小票，不阻断 |
| 网络中断 | 全部超时 | 引导离线模式（需主管授权） |
