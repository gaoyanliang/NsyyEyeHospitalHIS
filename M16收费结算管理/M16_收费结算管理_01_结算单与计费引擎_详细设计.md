## 1. 模块概述

### 1.1 模块定位

结算单与计费引擎是 M16 收费结算管理的**地基**。它回答："**这次该收多少钱、每一分钱是怎么算出来的？**"

```
┌──────────────────────────────────────────────────────────────┐
│  M07-03 医嘱（ISSUED）/ M04-03 挂号 / M10 视光订单             │
│  "我要做这些事"                                                │
└────────────────────────┬─────────────────────────────────────┘
                         │ 计费请求
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M16-01 结算单与计费引擎（本文档）★ 钱的来源                   │
│  · 把业务动作翻译成账单行                                       │
│  · 从 M01 价表取价、打价格快照                                  │
│  · 调 M16-06 算优惠                                            │
│  · 算出应收金额                                                │
└────────────────────────┬─────────────────────────────────────┘
                         │ 应收金额
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M16-05 支付与聚合收单                                         │
│  "钱确实收到了"                                                │
└────────────────────────┬─────────────────────────────────────┘
                         │ 支付成功
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M16-01 回写上游（on-paid）★ 闭环                              │
│  M07 医嘱 ISSUED → PAID                                       │
│  M04 挂号 REGISTERED → PAID                                   │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 为什么"算钱"要独立成子模块

**核心矛盾：** 算钱是**纯计算**，收钱是**外部副作用**。两者的失败处理完全不同。

| 维度 | 算钱（M16-01） | 收钱（M16-05） |
|---|---|---|
| 是否可重算 | ✅ 随时可以重算 | ❌ 调了微信就是调了 |
| 失败后果 | 重算即可 | 可能"钱扣了但系统不知道" |
| 事务边界 | 本地事务 | 需要分布式事务 + 补偿 |
| 幂等要求 | 弱（重算结果一致即可） | 强（幂等键必须唯一） |
| 变更频率 | 规则变更、版本迭代 | 几乎不变 |

**如果合并在一起：** 会出现"算到一半发现价格不对，但钱已经扣了"这种无法回滚的困境。

**分开后：** 计费引擎先算出**确定的金额**并冻结成结算单，支付环节只做"照单收钱"。金额一旦冻结，就不可再变。

### 1.3 与相邻子模块的分工

| 事项 | M16-01 计费引擎 | M16-02 门诊收费 | M16-05 支付 |
|---|---|---|---|
| 取价、算金额 | ✅ **唯一责任** | ❌ | ❌ |
| 建结算单 | ✅ **唯一责任** | 发起调用 | ❌ |
| 结算单状态推进到 PAID | ❌ | ✅ | ❌ |
| 调用支付渠道 | ❌ | ❌ | ✅ **唯一责任** |
| 回写上游（on-paid） | ✅ **唯一责任** | ❌ | ❌ |
| 打印小票 | ❌ | ✅ | ❌ |

**关键约定：回写上游只由 M16-01 做。** 因为它是唯一知道"这笔钱对应哪些业务单据"的子模块。

### 1.4 结算与"账单"的区别

```
结算单（Settlement）= 一次收钱的完整记录
   ├─ 结算单头（谁、什么时候、收了多少、状态）
   └─ 结算明细（每一行是什么项目、多少数量、单价、金额）

账单（Bill）在这个系统里不是一个独立对象
   患者说"我的账单"  → 其实是多个结算单的集合
   所以查询接口叫 unpaid/by-patient，返回结算单列表
```

**为什么这样设计：** 一次就诊可能产生多个结算单（挂号一次、检查一次、开药一次），把它们合成一个"账单"会让退费变得极其复杂（一个账单里部分退）。**保持"一单一结"最简单、最不容易错。**

### 1.5 模块目标

| 目标 | 指标 |
|---|---|
| 计费绝对准确 | 金额误差 = 0（精确到分，不四舍五入丢失） |
| 价格可追溯 | 每一行都能查到当时用的哪张价表、哪条价 |
| 计费可重算 | 未支付的结算单可重新计费，结果一致 |
| 回写不丢单 | 支付成功但回写失败，必须能补偿 |
| 计费快 | 单次计费 P95 ≤ 150ms |

### 1.6 关键业务角色

| 角色 | 在 M16-01 中的职责 | 权限 |
|---|---|---|
| 系统（自动） | 医嘱下达后自动建结算单 | 无界面 |
| 收费员 | 查看结算单、重新计费、作废结算单 | `m16:settle:*` |
| 收费处主管 | 作废已部分支付的结算单、重新计费授权 | 全部 |
| 财务科 | 查价快照、追溯计价依据 | 只读 |
| 审计员 | 查计费日志 | 只读 |

## 3. 业务模型

### 3.1 结算单来源模型

```
┌─────────────────────────────────────────────────────────────────┐
│ 三种结算单来源（settle_source）                                   │
├─────────────────────────────────────────────────────────────────┤
│ ① ENCOUNTER  就诊医嘱结算                                        │
│     来源：M07-03 医嘱（ISSUED 状态）                              │
│     场景：医生开完单，患者去缴费                                  │
│     回写：POST /internal/v1/m07/orders/on-paid → 医嘱 PAID        │
│                                                                 │
│ ② REGISTRATION 挂号费结算                                        │
│     来源：M04-03 挂号（REGISTERED 状态）                          │
│     场景：患者挂号时付挂号费                                      │
│     回写：POST /internal/v1/m04/registration/on-payment          │
│                                                                 │
│ ③ OPTICAL  视光销售结算（预留）                                   │
│     来源：M10 视光销售订单                                        │
│     场景：配镜销售                                                │
│     回写：M10 订单状态                                            │
└─────────────────────────────────────────────────────────────────┘
```

**注意：** 住院结算（`INPATIENT`）不在本子模块实现，见 M16-03 的接口预留说明。

### 3.2 结算单状态机（核心契约）

```
                          ┌─────────────────┐
                          │     UNPAID      │  待支付
                          │  （已计费冻结）   │
                          └────┬───────┬────┘
                               │       │
                  pay（M16-05）│       │ cancel（M16-01）
                               │       │
                               ▼       ▼
                     ┌─────────────┐ ┌─────────────┐
                     │    PAID     │ │  CANCELLED  │  已作废
                     │  （已支付）   │ └─────────────┘
                     └──┬───────┬──┘
                        │       │
        refund_partial  │       │  refund_full（M16-08）
                        │       │
                        ▼       ▼
              ┌──────────────┐ ┌─────────────┐
              │PART_REFUNDED │ │  REFUNDED   │  已全额退费
              │ （部分退费）   │ └─────────────┘
              └──────┬───────┘
                     │ refund_rest
                     ▼
              ┌─────────────┐
              │  REFUNDED   │
              └─────────────┘
```

**状态说明：**

| 状态 | 代码 | 含义 | 可变性 |
|---|---|---|---|
| 待支付 | `UNPAID` | 已计费，金额已冻结 | 金额**不可再改**，只能重算（重算后仍 UNPAID） |
| 已支付 | `PAID` | 已完成收款 | 金额不可改，明细不可改 |
| 部分退费 | `PART_REFUNDED` | 已退了一部分 | 剩余可继续退 |
| 已退费 | `REFUNDED` | 全额退回 | 终态，不可再变 |
| 已作废 | `CANCELLED` | 未支付时作废 | 终态，不可再变 |

**状态流转权责：**

| 变更 | 允许方 | 接口 |
|---|---|---|
| `UNPAID → PAID` | **仅 M16-05**（支付成功回调） | `POST /internal/v1/m16/settlements/{id}/on-paid` |
| `UNPAID → CANCELLED` | M16-01（本子模块） | `POST /api/v1/m16/settlements/{id}/cancel` |
| `PAID → PART_REFUNDED` | **仅 M16-08** | `POST /internal/v1/m16/settlements/{id}/on-refunded` |
| `PAID/PART_REFUNDED → REFUNDED` | **仅 M16-08** | 同上 |

**铁律：M16-01 自己绝不把结算单置为 `PAID` 或 `REFUNDED`。** 这两个状态必须由 M16-05/M16-08 在钱真正进出后回写。这条规则与 M07 医嘱的"M07 不直接置 PAID"完全同构。

### 3.3 计费计算模型（核心）

```
应收总额 = Σ 明细应收

单行明细：
  line_amount = unit_price × quantity × eye_multiplier
  discount_amount = f(line_amount, 优惠规则)
  payable_amount = line_amount - discount_amount

结算单：
  total_amount    = Σ line_amount       原价合计
  discount_amount = Σ discount_amount   优惠合计
  payable_amount  = total_amount - discount_amount   应收（实收）
```

**数量与眼别：**

| 条件 | quantity 含义 | eye_multiplier |
|---|---|---|
| `charge_by_eye = FALSE` | 用户输入数量 | 1 |
| `charge_by_eye = TRUE` 且 `eye_side = OD/OS` | 用户输入数量（单眼） | 1 |
| `charge_by_eye = TRUE` 且 `eye_side = OU` | 用户输入数量（单眼） | **2** |

**举例：**

```
项目：眼底照相  单价 80.00  按眼别计价
患者：双眼都要做

录入：eye_side = OU, quantity = 1
计算：unit_price=80.00, quantity=1, eye_multiplier=2
      line_amount = 80.00 × 1 × 2 = 160.00

如果患者只做右眼：
录入：eye_side = OD, quantity = 1
计算：line_amount = 80.00 × 1 × 1 = 80.00
```

### 3.4 价格快照模型（核心）

**问题：** 如果结算单只存 `charge_item_id`，三个月后查这张单收了多少钱，就得到价表里查——但价表已经变了。

**解决：计费时把价格完整复制一份存起来。**

```
m16_price_snapshot（价格快照）
  ├─ price_list_code    用的哪张价表（如 PRICE_OUTPATIENT_v12）
  ├─ price_item_id      M01 价表明细 ID
  ├─ original_price     价表原价
  ├─ price              价表执行价（可能有加价率）
  ├─ max_discount_rate  该项目的最大折扣率
  ├─ is_current         计价当时该价是否有效
  └─ snapshot_at        快照时间

用途：
  ① 查账：随时还原"当时为什么是这个价"
  ② 退费：按原价退（不是按现在的价退）
  ③ 稽核：价格调整后，前后单据对比
```

**快照的原则：** 计费之后，价表怎么变都不影响已生成的结算单。

### 3.5 组合套餐展开模型

```
M01 的收费组合（md_charge_combo）
  ├─ 白内障术前套餐  combo_no = CB0001
  │    ├─ 明细 1：视力检查
  │    ├─ 明细 2：眼压测量
  │    └─ 明细 3：角膜内皮计数
  └─ 套餐价：200.00（原价合计 240.00）

M16-01 展开逻辑：
  ① 取 md_charge_combo_detail 全部明细
  ② 每条明细生成一个结算明细行
  ③ 套餐价与明细合计的差额 → 作为「套餐优惠」
  ④ 明细行上标记 combo_id、combo_no
```

**关键：套餐不是一行，是多行。** 因为退费时要能部分退（比如只退角膜内皮）。

### 3.6 计费来源映射模型

| 来源类型 | 取什么 | 数量来源 | 眼别来源 | 关联键 |
|---|---|---|---|---|
| `ORDER` | `m07_order` 记录 | `order.quantity` | `order.eye_side` | `order_id`, `order_no` |
| `REGISTRATION` | `m04_registration` 记录 | 固定 1 | `NA` | `registration_id`, `registration_no` |
| `OPTICAL` | M10 订单明细 | 订单数量 | `NA` | `optical_order_id` |

**为什么结算明细要存来源 ID：** 支付成功后要按来源 ID 精确回写。存 `order_ids = [94001, 94002]`，M07 才能只把这两条置为 PAID。

### 3.7 拆单模型

**场景：** 患者开了一张检查单、一张化验单、一张处方。想分开缴费（比如只交得起检查）。

```
原：一个会话有 5 条待收费医嘱

拆单策略（可配置 merge_strategy）：

① BY_NONE     全部合成一张（默认）
   结算单 1：5 条医嘱，共 386.50 元

② BY_GROUP    按医嘱类型分组拆
   结算单 1：检查 2 条，160.00 元
   结算单 2：检验 1 条，56.50 元
   结算单 3：药品 2 条，170.00 元

③ BY_DEPT     按执行科室拆（跨科室时各自结算）
```

**系统参数：** `M16.SETTLE.MERGE_STRATEGY`，默认 `BY_NONE`。

### 3.8 计费计算规则细节

**金额精度：**

```
单价：NUMERIC(12,4)   最多 4 位小数（药品可能按每片 0.0250 计价）
数量：NUMERIC(12,4)   最多 4 位小数
行金额：NUMERIC(12,2) 保留 2 位，四舍五入（ROUND_HALF_UP）

计算顺序（关键）：
  ① line_amount = ROUND(unit_price × quantity × eye_mult, 2)
  ② discount_amount = ROUND(f(line_amount), 2)
  ③ payable = line_amount - discount_amount

禁止的做法：
  ✗ 先算总价再打折，因为各项目的折扣规则只适用于自己
  ✗ 对 4 位小数金额做展示，患者只能看到 2 位
```

**为什么行级先舍入：** 如果先累加再舍入，当明细很多时误差会累积到几毛钱，退费时对不上账。

### 3.9 计费与优惠的关系

```
M16-01 计费引擎                M16-06 优惠执行
      │                              │
      │ ① 算出原始行金额             │
      │    line_amount = 160.00      │
      │                              │
      ├─── 请求优惠计算 ────────────►│
```

```python
"""计费引擎：把业务动作翻译成金额"""
from datetime import date, datetime
from decimal import Decimal, ROUND_HALF_UP
from typing import Optional, List

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.m16.settlement import (

CENT = Decimal("0.01")


def money(value) -> Decimal:
    """统一金额舍入：2 位小数，四舍五入"""
    return Decimal(str(value)).quantize(CENT, rounding=ROUND_HALF_UP)


class ChargingService:
    """计费引擎（纯计算，不产生外部副作用）"""

    # 眼别倍数
    EYE_MULTIPLIER = {"OD": 1, "OS": 1, "OU": 2, "NA": 1}

    def __init__(self, db: AsyncSession):
        self.db = db
        self.mdm = MdmClient()
        self.m07 = M07Client()
        self.discount = DiscountClient()

    # ---------- 取价 ----------
    async def get_effective_price(
            self, charge_item_code: str,
            dept_id: Optional[int] = None) -> dict:
        """取当前有效价（带缓存）"""
        price = await self.mdm.get_charge_price(charge_item_code, dept_id)

        if not price:
            raise BizException(
                54840,
                f"收费项目 {charge_item_code} 无有效价格，请联系物价管理员",
                data={"charge_item_code": charge_item_code})

        return price

    # ---------- 单行计费 ----------
    async def calc_line(
            self, charge_item: dict, price: dict,
            eye_side: str, quantity: Decimal,
            patient_id: int, encounter_id: Optional[int],
            member_level: Optional[str] = None) -> dict:
        """计算一行明细的金额"""
        # ① 眼别倍数
        if charge_item["charge_by_eye"]:
            if eye_side not in ("OD", "OS", "OU"):
                raise BizException(
                    54842,
                    f"项目「{charge_item['name']}」按眼别计价，必须指定眼别")

            multiplier = self.EYE_MULTIPLIER[eye_side]
        else:
            multiplier = 1

        # ② 行金额
        unit_price = Decimal(str(price["price"]))
        line_amount = money(unit_price * Decimal(str(quantity)) * multiplier)

        # ③ 优惠（失败降级）
        discount_amount = Decimal("0.00")
        degraded = False

        try:
            disc = await self.discount.calculate(
                charge_item_code=charge_item["code"],
                line_amount=line_amount,
                patient_id=patient_id,
                encounter_id=encounter_id,
                member_level=member_level,
                allow_discount=charge_item["allow_discount"],
                max_discount_rate=charge_item.get("max_discount_rate"),
            )
            discount_amount = money(disc["discount_amount"])
        except Exception:
            degraded = True

        payable = money(line_amount - discount_amount)

        return {
            "unit_price": unit_price,
            "quantity": quantity,
            "eye_multiplier": multiplier,
            "line_amount": line_amount,
            "discount_amount": discount_amount,
            "payable_amount": payable,
            "discount_degraded": degraded,
            "price_list_code": price["price_list_code"],
            "price_item_id": price["id"],
            "original_price": Decimal(str(price["original_price"])),
        }

    # ---------- 套餐展开 ----------
    async def expand_combo(self, combo_code: str) -> List[dict]:
        """把套餐展开成明细列表"""
        combo = await self.mdm.get_charge_combo(combo_code)

        if not combo:
            raise BizException(54835, f"套餐 {combo_code} 不存在")

        details = await self.mdm.get_combo_details(combo_code)

        if not details:
            raise BizException(54835, f"套餐 {combo_code} 无明细")

        lines = []

        for d in details:
            lines.append({
                "charge_item_code": d["charge_item_code"],
                "charge_item_name": d["charge_item_name"],
                "quantity": Decimal(str(d["default_qty"])),
                "combo_id": combo["id"],
                "combo_code": combo_code,
                "is_optional": d["is_optional"],
                "group_name": d.get("group_name"),
            })

        return lines

    # ---------- 会话计费试算 ----------
    async def preview(self, payload, user) -> dict:
        """计费试算：不落库，只算"""
        orders = await self.m07.get_orders(payload.order_ids or [],
                                           payload.encounter_id)

        if not orders:
            raise BizException(54835, "结算单不包含任何可收费项目")

        # 校验所有医嘱可收费
        for o in orders:
            if o["status"] != "ISSUED":
                raise BizException(
                    54843,
                    f"医嘱 {o['order_no']} 状态为 {o['status']}，不可计费",
                    data={"order_no": o["order_no"], "status": o["status"]})

        # 取患者会员等级（失败不影响主流程）
        member_level = None

        try:
            member_level = await self.mdm.get_member_level(
                orders[0]["patient_id"])
        except Exception:
            pass

        items = []
        total = Decimal("0.00")
        discount_total = Decimal("0.00")
        any_degraded = False

        for o in orders:
            charge_item = await self.mdm.get_charge_item(o["charge_item_code"])

            if not charge_item:
                raise BizException(
                    54835, f"医嘱 {o['order_no']} 无对应收费项目")

            price = await self.get_effective_price(
                o["charge_item_code"], o.get("dept_id"))

            line = await self.calc_line(
                charge_item=charge_item,
                price=price,
                eye_side=o.get("eye_side") or "NA",
                quantity=Decimal(str(o["quantity"])),
                patient_id=o["patient_id"],
                encounter_id=o["encounter_id"],
                member_level=member_level,
            )

            items.append({
                "charge_item_code": o["charge_item_code"],
                "charge_item_name": o["item_name"],
                "order_id": o["order_id"],
                "order_no": o["order_no"],
                "eye_side": o.get("eye_side") or "NA",
                "quantity": line["quantity"],
                "eye_multiplier": line["eye_multiplier"],
                "unit_price": line["unit_price"],
                "line_amount": line["line_amount"],
                "discount_amount": line["discount_amount"],
                "payable_amount": line["payable_amount"],
                "price_list_code": line["price_list_code"],
            })

            total += line["line_amount"]
            discount_total += line["discount_amount"]

            if line["discount_degraded"]:
                any_degraded = True

        return {
            "total_amount": money(total),
            "discount_amount": money(discount_total),
            "payable_amount": money(total - discount_total),
            "discount_degraded": any_degraded,
            "items": items,
        }

    # ---------- 挂号费计算 ----------
    async def calc_registration_fee(
            self, registration_level_id: int, patient_id: int,
            dept_id: Optional[int]) -> dict:
        """计算挂号费（挂号级别 → 收费项目）"""
        level = await self.mdm.get_registration_level(registration_level_id)

        if not level:
            raise BizException(40001, "挂号级别不存在")

        items = []
        total = Decimal("0.00")

        # 挂号费 + 诊查费
        for code_key in ("registration_charge_item", "diagnosis_charge_item"):
            code = level.get(code_key)

            if not code:
                continue

            price = await self.get_effective_price(code, dept_id)
            charge_item = await self.mdm.get_charge_item(code)
            unit_price = Decimal(str(price["price"]))
            line = money(unit_price)

            items.append({
                "charge_item_code": code,
                "charge_item_name": charge_item["name"],
                "unit_price": unit_price,
                "quantity": 1,
                "line_amount": line,
            })
            total += line

        # 挂号费优惠（如减免政策）
        discount = Decimal("0.00")

        try:
            disc = await self.discount.calculate(
                charge_item_code="__REGISTRATION__",
                line_amount=money(total),
                patient_id=patient_id,
                encounter_id=None,
                member_level=None,
                allow_discount=True,
                max_discount_rate=None,
            )
            discount = money(disc["discount_amount"])
        except Exception:
            pass

        return {
            "registration_fee": items[0]["line_amount"] if items else Decimal("0"),
            "diagnosis_fee": items[1]["line_amount"] if len(items) > 1 else Decimal("0"),
            "total_amount": money(total),
            "discount_amount": discount,
            "payable_amount": money(total - discount),
            "items": items,
        }
```

```python
# app/services/m16/settlement_service.py
"""结算单主流程"""
import uuid

class SettlementService:
    """结算单主流程"""

    def __init__(self, db: AsyncSession):
        self.db = db
        self.charging = ChargingService(db)
        self.m07 = M07Client()
        self.m04 = M04Client()

    # ---------- 编号生成 ----------
    async def _next_no(self, prefix: str) -> str:
        """生成结算单号：BL + 日期 + 4 位流水"""
        day = date.today().strftime("%Y%m%d")
        key = f"m16:settle:seq:{prefix}:{day}"
        seq = await redis_client.incr(key)

        if seq == 1:
            await redis_client.expire(key, 86400 * 2)

        return f"{prefix}{day}{seq:04d}"

    # ---------- 生成结算单 ----------
    async def create(self, payload, user, trace_id: str = "") -> dict:
        """生成结算单（幂等）"""
        # 幂等键检查
        if getattr(payload, "idempotency_key", None):
            existing = await self._find_by_idem_key(
                payload.source_type, payload.idempotency_key)

            if existing:
                return self._to_dict(existing, idempotent_replay=True)

        # 计费
        calc = await self.charging.preview(payload, user)

        if calc["payable_amount"] <= 0:
            raise BizException(54835, "结算单不包含任何可收费项目")

        # 金额上限
        limit = await self._get_config("MAX_SETTLE_AMOUNT", 50000)

        if calc["payable_amount"] > Decimal(str(limit)):
            raise BizException(
                54844,
                f"结算单金额 {calc['payable_amount']} 超过上限 {limit}，需主管授权")

        # 建单
        settlement_no = await self._next_no("BL")

        settlement = M16Settlement(
            settlement_no=settlement_no,
            source_type=payload.source_type,
            encounter_id=payload.encounter_id,
            patient_id=calc["items"][0].get("patient_id") or payload.patient_id,
            total_amount=calc["total_amount"],
            discount_amount=calc["discount_amount"],
            payable_amount=calc["payable_amount"],
            paid_amount=Decimal("0.00"),
            refunded_amount=Decimal("0.00"),
            status="UNPAID",
            discount_degraded=calc["discount_degraded"],
            idempotency_key=getattr(payload, "idempotency_key", None),
            expire_at=datetime.now() + timedelta(hours=24),
            created_by=user.staff_id,
            created_by_name=user.real_name,
            trace_id=trace_id,
        )
        self.db.add(settlement)
        await self.db.flush()

        # 建明细 + 价格快照
        for idx, item in enumerate(calc["items"], start=1):
            settlement_item = M16SettlementItem(
                settlement_id=settlement.id,
                item_no=idx,
                charge_item_code=item["charge_item_code"],
                charge_item_name=item["charge_item_name"],
                order_id=item.get("order_id"),
                order_no=item.get("order_no"),
                eye_side=item.get("eye_side") or "NA",
                quantity=item["quantity"],
                eye_multiplier=item["eye_multiplier"],
                unit_price=item["unit_price"],
                line_amount=item["line_amount"],
                discount_amount=item["discount_amount"],
                payable_amount=item["payable_amount"],
            )
            self.db.add(settlement_item)
            await self.db.flush()

            self.db.add(M16PriceSnapshot(
                settlement_id=settlement.id,
                settlement_item_id=settlement_item.id,
                charge_item_code=item["charge_item_code"],
                price_list_code=item.get("price_list_code"),
                unit_price=item["unit_price"],
                snapshot_at=datetime.now(),
            ))

        self.db.add(M16SettlementLog(
            settlement_id=settlement.id,
            settlement_no=settlement_no,
            action="CREATE",
            after_json={
                "status": "UNPAID",
                "payable_amount": str(settlement.payable_amount),
                "item_count": len(calc["items"]),
            },
            operator_id=user.staff_id,
            operator_name=user.real_name,
            trace_id=trace_id,
        ))
        await self.db.commit()

        return self._to_dict(settlement)

    # ---------- 支付回写 ----------
    async def on_paid(self, settlement_id: int, payload: dict,
                      trace_id: str = "") -> dict:
        """★ M16-05 支付成功后调用：UNPAID → PAID + 回写上游"""
        # 行锁防并发
        settlement = (await self.db.execute(
            select(M16Settlement)
            .where(M16Settlement.id == settlement_id)
            .with_for_update()
        )).scalar_one_or_none()

        if not settlement:
            raise BizException(54833, "结算单不存在")

        paid_amount = Decimal(str(payload["paid_amount"]))

        # 幂等：已支付且金额一致
        if settlement.status == "PAID":
            if settlement.paid_amount == paid_amount:
                return {
                    "settlement_no": settlement.settlement_no,
                    "old_status": "PAID",
                    "new_status": "PAID",
                    "updated": False,
                    "rewrites": [],
                }
            raise BizException(54838, "结算单已是支付状态且金额不一致")

        if settlement.status != "UNPAID":
            raise BizException(
                54838,
                f"结算单状态 {settlement.status} 不允许支付")

        old_status = settlement.status
        settlement.status = "PAID"
        settlement.paid_amount = paid_amount
        settlement.paid_at = datetime.now()
        settlement.paid_method = payload.get("payment_method")
        settlement.payment_id = payload.get("payment_id")
        settlement.transaction_no = payload.get("transaction_no")

        self.db.add(M16SettlementLog(
            settlement_id=settlement.id,
            settlement_no=settlement.settlement_no,
            action="PAID",
            before_json={"status": old_status},
            after_json={"status": "PAID", "paid_amount": str(paid_amount)},
            operator_id=payload.get("operator_id"),
            operator_name=payload.get("operator_name"),
            trace_id=trace_id,
        ))
        await self.db.commit()

        # ★ 回写上游（失败不回滚支付，写入补偿队列）
        rewrites = await self._rewrite_upstream(settlement, "PAID")

        return {
            "settlement_no": settlement.settlement_no,
            "old_status": old_status,
            "new_status": "PAID",
            "paid_amount": float(paid_amount),
            "rewrites": rewrites,
            "updated": True,
        }

    # ---------- 回写上游（核心） ----------
    async def _rewrite_upstream(self, settlement, new_status: str) -> List[dict]:
        """按结算单来源回写对应上游模块"""
        results = []

        items = (await self.db.execute(
            select(M16SettlementItem)
            .where(M16SettlementItem.settlement_id == settlement.id)
        )).scalars().all()

        if settlement.source_type == "ENCOUNTER":
            order_ids = [i.order_id for i in items if i.order_id]

            if not order_ids:
                return results

            if new_status == "PAID":
                try:
                    resp = await self.m07.on_paid(settlement.encounter_id, {
                        "billing_no": settlement.settlement_no,
                        "encounter_id": settlement.encounter_id,
                        "order_ids": order_ids,
                        "paid_at": settlement.paid_at.isoformat(),
                        "total_amount": float(settlement.paid_amount),
                        "payment_method": settlement.paid_method,
                    })
                    results.append({
                        "target": "M07",
                        "interface": "/internal/v1/m07/orders/on-paid",
                        "success": True,
                        "affected": resp.get("updated", len(order_ids)),
                    })
                except Exception as e:
                    await self._enqueue_rewrite(settlement, "M07", order_ids, e)
                    results.append({
                        "target": "M07",
                        "interface": "/internal/v1/m07/orders/on-paid",
                        "success": False,
                        "error": str(e)[:200],
                    })

        elif settlement.source_type == "REGISTRATION":
            registration_id = settlement.registration_id

            if new_status == "PAID":
                try:
                    resp = await self.m04.on_payment({
                        "billing_no": settlement.settlement_no,
                        "registration_no": settlement.registration_no,
                        "paid_amount": float(settlement.paid_amount),
                        "pay_method": settlement.paid_method,
                        "paid_at": settlement.paid_at.isoformat(),
                        "transaction_no": settlement.transaction_no,
                    })
                    results.append({
                        "target": "M04",
                        "interface": "/internal/v1/m04/registration/on-payment",
                        "success": True,
                        "affected": 1,
                    })
                except Exception as e:
                    await self._enqueue_rewrite(
                        settlement, "M04", [registration_id], e)
                    results.append({
                        "target": "M04",
                        "interface": "/internal/v1/m04/registration/on-payment",
                        "success": False,
                        "error": str(e)[:200],
                    })

        return results

    # ---------- 重算 ----------
    async def recalculate(self, settlement_id: int, payload,
                          user, trace_id: str = "") -> dict:
        """重算：仅 UNPAID 状态"""
        settlement = (await self.db.execute(
            select(M16Settlement)
            .where(M16Settlement.id == settlement_id)
            .with_for_update()
        )).scalar_one_or_none()

        if not settlement:
            raise BizException(54833, "结算单不存在")

        if settlement.status != "UNPAID":
            raise BizException(
                54838,
                f"结算单状态为 {SETTLE_STATUS_LABELS.get(settlement.status)}，仅待支付可重算")

        if not payload.reason:
            raise BizException(54839, "重算原因必填")

        old_total = settlement.total_amount
        old_payable = settlement.payable_amount

        # 重算
        preview_payload = type("P", (), {
            "encounter_id": settlement.encounter_id,
            "order_ids": None,
            "patient_id": settlement.patient_id,
            "source_type": settlement.source_type,
        })()
        calc = await self.charging.preview(preview_payload, user)

        # 删除旧明细与快照
        from sqlalchemy import delete
        await self.db.execute(
            delete(M16SettlementItem)
            .where(M16SettlementItem.settlement_id == settlement_id))
        await self.db.execute(
            delete(M16PriceSnapshot)
            .where(M16PriceSnapshot.settlement_id == settlement_id))

        # 重建
        settlement.total_amount = calc["total_amount"]
        settlement.discount_amount = calc["discount_amount"]
        settlement.payable_amount = calc["payable_amount"]
        settlement.recalc_count = settlement.recalc_count + 1
        settlement.last_recalc_at = datetime.now()

        for idx, item in enumerate(calc["items"], start=1):
            self.db.add(M16SettlementItem(
                settlement_id=settlement.id,
                item_no=idx,
                charge_item_code=item["charge_item_code"],
                charge_item_name=item["charge_item_name"],
                order_id=item.get("order_id"),

                eye_side=item.get("eye_side") or "NA",
                quantity=item["quantity"],
                eye_multiplier=item["eye_multiplier"],
                unit_price=item["unit_price"],
                line_amount=item["line_amount"],
                discount_amount=item["discount_amount"],
                payable_amount=item["payable_amount"],
            ))

        self.db.add(M16SettlementLog(
            settlement_id=settlement.id,

    # ---------- 作废 ----------
    async def cancel(self, settlement_id: int, payload,
                     user, trace_id: str = "") -> dict:

            operator_id=user.staff_id,
            operator_name=user.real_name,
            trace_id=trace_id,
```

### 6.6 状态机实现示例

```python
# app/services/m16/settlement_state.py
"""结算单状态机（唯一的状态变更入口）"""
from app.core.exceptions import BizException


class SettlementStateMachine:
    """结算单状态机

    铁律：
      - M16-01 自己只能做 UNPAID → CANCELLED
      - PAID 只能由 M16-05 通过 on-paid 触发
      - REFUNDED / PART_REFUNDED 只能由 M16-08 通过 on-refunded 触发
    """

    # 允许的流转：{来源状态: {目标状态: 允许方}}
    TRANSITIONS = {
        "UNPAID": {
            "PAID": "M16-05",
            "CANCELLED": "M16-01",
        },
        "PAID": {
            "PART_REFUNDED": "M16-08",
            "REFUNDED": "M16-08",
        },
        "PART_REFUNDED": {
            "REFUNDED": "M16-08",
        },
        "REFUNDED": {},
        "CANCELLED": {},
    }

    STATUS_LABELS = {
        "UNPAID": "待支付",
        "PAID": "已支付",
        "PART_REFUNDED": "部分退费",
        "REFUNDED": "已退费",
        "CANCELLED": "已作废",
    }

    @classmethod
    def check(cls, from_status: str, to_status: str, caller: str) -> None:
        """校验流转是否合法，不合法抛 54838"""
        allowed = cls.TRANSITIONS.get(from_status, {})

        if to_status not in allowed:
            raise BizException(
                54838,
                f"结算单不可从「{cls.STATUS_LABELS.get(from_status, from_status)}」"
                f"变为「{cls.STATUS_LABELS.get(to_status, to_status)}」")

        expected_caller = allowed[to_status]

        if caller != expected_caller:
            raise BizException(
                40301,
                f"结算单状态变更「{from_status} → {to_status}」"
                f"只能由 {expected_caller} 触发，当前调用方为 {caller}")
```

```python
# app/tasks/m16/settlement_tasks.py
"""M16-01 异步任务"""
from celery import shared_task


@shared_task
def rewrite_retry_task():
    """回写上游失败重试（每 2 分钟）"""
    import asyncio
    return asyncio.run(_rewrite_retry())


async def _rewrite_retry():
    """重试回写失败的上游回调

    关键设计：支付已经成功，回写失败绝不能回滚支付。
    而是把「回写」当成一个独立可重试的任务。
    """
    from datetime import datetime, timedelta
    from sqlalchemy import select
    from app.core.database import AsyncSessionLocal
    from app.models.m16.settlement import M16RewriteQueue
    from app.clients.m07_client import M07Client
    from app.clients.m04_client import M04Client

    m07 = M07Client()
    m04 = M04Client()
    done = 0

    async with AsyncSessionLocal() as db:
        rows = (await db.execute(
            select(M16RewriteQueue).where(
                M16RewriteQueue.status == "PENDING",
                M16RewriteQueue.retry_count < 10,
                M16RewriteQueue.next_retry_at <= datetime.now(),
            ).order_by(M16RewriteQueue.id).limit(50)
        )).scalars().all()

        for row in rows:
            try:
                if row.target_module == "M07":
                    await m07.on_paid(
                        row.encounter_id, row.payload_json)
                elif row.target_module == "M04":
                    await m04.on_payment(row.payload_json)

                row.status = "SUCCESS"
                row.resolved_at = datetime.now()
                done += 1
            except Exception as e:
                row.retry_count = row.retry_count + 1
                row.last_error = str(e)[:500]
                # 指数退避：2^n 分钟，最长 512 分钟
                row.next_retry_at = datetime.now() + timedelta(
                    minutes=min(2 ** row.retry_count, 512))

                if row.retry_count >= 10:
                    row.status = "FAILED"

        await db.commit()

    return {"resolved": done, "total": len(rows)}


@shared_task
def expire_unpaid_task():
    """超时未支付的结算单自动作废（每小时）"""
    import asyncio
    return asyncio.run(_expire_unpaid())


async def _expire_unpaid():
    """作废超过 expire_at 的待支付结算单

    注意：只作废结算单，不动上游医嘱。
    上游医嘱由 M07-03 自己的定时任务按 ISSUED 超时处理。
    """
    from datetime import datetime
    from sqlalchemy import select, update
    from app.core.database import AsyncSessionLocal
    from app.models.m16.settlement import M16Settlement, M16SettlementLog

    async with AsyncSessionLocal() as db:
        rows = (await db.execute(
            select(M16Settlement).where(
                M16Settlement.status == "UNPAID",
                M16Settlement.expire_at < datetime.now(),
                M16Settlement.is_deleted == False,
            ).limit(500)
        )).scalars().all()

        for s in rows:
            s.status = "CANCELLED"
            s.cancelled_at = datetime.now()
            s.cancel_reason = "超时未支付，系统自动作废"

            db.add(M16SettlementLog(
                settlement_id=s.id,
                settlement_no=s.settlement_no,
                action="AUTO_EXPIRE",
                before_json={"status": "UNPAID"},
                after_json={"status": "CANCELLED"},
                detail="超时未支付",
                operator_name="系统",
            ))

        await db.commit()

    return {"expired": len(rows)}


@shared_task
def daily_settlement_summary_task(stat_date: str = None):
    """日结算汇总（每日 01:00，供 M16-09 与 M17 使用）"""
    import asyncio
    return asyncio.run(_daily_summary(stat_date))


async def _daily_summary(stat_date: str = None):
    """把当日结算单按科室/来源/状态汇总"""
    from datetime import date
    from decimal import Decimal
    from sqlalchemy import select, func
    from app.core.database import AsyncSessionLocal
    from app.models.m16.settlement import M16Settlement, M16DailySummary

    day = date.fromisoformat(stat_date) if stat_date else date.today()

    async with AsyncSessionLocal() as db:
        rows = (await db.execute(
            select(
                M16Settlement.dept_id,
                M16Settlement.source_type,
                func.count(M16Settlement.id),
                func.sum(M16Settlement.total_amount),
                func.sum(M16Settlement.discount_amount),
                func.sum(M16Settlement.payable_amount),
            )
            .where(
                func.date(M16Settlement.created_at) == day,
                M16Settlement.is_deleted == False,
            )
            .group_by(M16Settlement.dept_id, M16Settlement.source_type)
        )).all()

        for dept_id, source_type, cnt, total, disc, payable in rows:
            db.add(M16DailySummary(
                stat_date=day,
                dept_id=dept_id,
                source_type=source_type,
                settle_count=cnt,
                total_amount=total or Decimal("0"),
                discount_amount=disc or Decimal("0"),
                payable_amount=payable or Decimal("0"),
            ))

        await db.commit()

    return {"date": str(day), "groups": len(rows)}
```
