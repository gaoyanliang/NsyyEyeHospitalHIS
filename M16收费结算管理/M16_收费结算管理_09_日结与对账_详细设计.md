## 1. 模块概述

### 1.1 模块定位

M16-09 日结与对账负责「**今天收了多少钱，跟系统里记的、跟银行/渠道里说的，能不能对上**」。

```
                   一天中的全部资金动作
  ┌──────────┬──────────┬──────────┬──────────┬──────────┐
  │ M16-02   │ M16-03   │ M16-04   │ M16-06   │ M16-08   │
  │ 门诊收费 │ 住院预交 │ 视光销售 │ 优惠核销 │ 退费冲红 │
  └────┬─────┴────┬─────┴────┬─────┴────┬─────┴────┬─────┘
       │          │          │          │          │
       └──────────┴────┬─────┴──────────┴──────────┘
                       ▼
        ┌──────────────────────────────────────┐
        │      M16-09 日结与对账                │
        │                                       │
        │  ① 收费员交班（钱箱对不对）            │
        │  ② 收费点日结（窗口账对不对）          │
        │  ③ 科室日结（科室账对不对）            │
        │  ④ 全站日结（全院账对不对）            │
        │  ⑤ 账实核对（现金 vs 点钞）            │
        │  ⑥ 账账核对（系统 vs 渠道/银行）       │
        │  ⑦ 差异处理（差了怎么办）              │
        │  ⑧ 封账（之后不能再改）                │
        └──────────────┬───────────────────────┘
                       │
          ┌────────────┼────────────┐
          ▼            ▼            ▼
      M17 财务      M16-05        M22 报表
      核算凭证       渠道账单       管理报表
```

**一句话定义：** M16-09 是 M16 的终点——所有前 8 个子模块产生的钱，最终都在这里汇总成「可以交给财务的一张表」，并且这张表必须能被证明是对的。

### 1.2 为什么独立成子模块

**理由一：日结是「时间点上的快照」，不是「流水上的增量」。**

前面 8 个子模块都是记流水：一笔收费、一笔退费、一笔支付。日结完全不同——它要回答「截至今天 24:00，这个窗口收了多少钱」，而这个问题必须在一个**冻结的时刻**回答。如果边收费边日结，结果永远不一致。日结需要一个「封账时刻」的概念，这个语义在流水模块里没有。

**理由二：对账是「两个来源的比对」，不属于任何一方。**

系统里记的 12,580 元，渠道账单说 12,560 元。这个差异既不是收费模块的错，也不是支付模块的错，而是**两个来源之间**的事。只有独立出第三方子模块，才能中立地记录「双方各是多少、差多少、差在哪、谁的责任」。

**理由三：日结是唯一需要「人在回路」的环节。**

交班对账时，收费员点出一沓现金，系统显示应收 8,530 元，实际点出 8,520 元。这个 10 元钱去哪了？系统不知道，必须由人填原因。而「填原因」这件事本身就是一个独立的业务动作，有审批、有留痕、有统计。把它挂在收费模块里会让收费模块的状态机变得极其复杂。

**对比表**

| 维度 | 流水模块（M16-02~08） | 日结与对账（M16-09） |
|---|---|---|
| 数据性质 | 增量（每笔一条） | 快照（每日一条） |
| 更新方式 | 追加 | UPSERT + 封账后只读 |
| 触发 | 业务动作 | 时间点 + 人工确认 |
| 可重算 | 否 | 是（封账前） |
| 人工干预 | 极少 | 必然（差异处理） |
| 输出 | 单据 | 汇总表 + 差异清单 |
| 下游 | 业务状态 | 财务凭证 |

**理由四：跨模块聚合不可避免。**

门诊收费、住院预交金、视光销售分散在三个子模块，但财务要的「今日现金收入」只有一个数。这个数只能由独立的汇总层来算。

### 1.3 与相邻子模块分工

| 能力 | M16-02 门诊收费 | M16-05 支付收单 | M16-09 日结对账 | 说明 |
|---|---|---|---|---|
| 记录每一笔收款 | ✅ | ✅（渠道侧） | ❌ | 流水归流水 |
| 收费员开班/关班 | ✅ | ❌ | ❌ | M16-02 管班次 |
| 钱箱点钞与长短款 | ❌ | ❌ | ✅ | **日结唯一责任** |
| 收费员当日汇总 | ❌ | ❌ | ✅ | 日结汇总 |
| 收费点/科室/全院汇总 | ❌ | ❌ | ✅ | 日结汇总 |
| 渠道账单下载 | ❌ | ✅ | ❌ | M16-05 下载 |
| 三方对账（渠道↔流水↔结算） | ❌ | ✅ | ❌ | M16-05 做单渠道对账 |
| 全渠道汇总对账 | ❌ | ❌ | ✅ | **日结唯一责任** |
| 现金账实核对 | ❌ | ❌ | ✅ | **日结唯一责任** |
| 差异复核与调账 | ❌ | ❌ | ✅ | 日结流转 |
| 封账 | ❌ | ❌ | ✅ | 日结封账 |
| 财务凭证生成 | ❌ | ❌ | ❌ | 归 M17 |

**关键边界：** M16-05 的「对账」是**单渠道技术对账**（这个渠道的账单跟我系统对得上吗）。M16-09 的「对账」是**全院资金对账**（全院收了多少钱、多少现金、多少扫码、多少刷卡，最后落一张总表）。两者不是重复，是层次不同——M16-05 是医生的化验单，M16-09 是出院小结。

### 1.4 概念辨析

**日结 ≠ 交班 ≠ 关账 ≠ 封账**

| 概念 | 英文 | 谁做 | 粒度 | 频次 | 能否撤回 |
|---|---|---|---|---|---|
| 交班 | Shift Handover | 收费员 | 收费员 × 班次 | 每班一次 | 可（重新开） |
| 日结 | Daily Closing | 收费主管 | 收费点 / 科室 / 全院 | 每日一次 | 封账前可重算 |
| 关账 | Period Close | 财务 | 会计期间（月） | 每月一次 | 否 |
| 封账 | Freeze | 财务 | 已日结的数据 | 日结后 | 否（需解封审批） |

**账实核对 ≠ 账账核对**

| 概念 | 比什么 | 差异叫什么 | 谁负责 |
|---|---|---|---|
| 账实核对 | 系统记录的收入 vs 实际点出的现金 | 长短款 | 收费员 |
| 账账核对 | 系统流水 vs 渠道账单 / 银行流水 | 对账差异 | 财务 |

医院最常见的错误是把这两个混为一谈。现金少了 10 元是**账实差异**（钱箱里的钱和系统对不上）；微信账单少 10 元是**账账差异**（渠道说收了多少跟我系统记的不一致）。前者收费员自己查，后者找渠道客服。

**日结 ≠ 日报**

日结是一个**动作**（把今天的数据冻结并核对）。日报是一张**报表**（把日结结果排版成表）。M16-09 做日结，日报模板归 M22 报表中心——但日结结果必须持久化，否则 M22 做报表时要重新汇总，而那时数据可能已被后续调账改变。

### 1.5 模块目标

| 编号 | 目标 | 指标 |
|---|---|---|
| G-01 | 日结覆盖率 | 收费点 100%，科室 100%，全院 100% |
| G-02 | 日结及时率 | 次日前完成率 ≥ 99% |
| G-03 | 现金长短款率 | 长短款笔数 / 总班次 ≤ 2% |
| G-04 | 对账差异率 | 差异金额 / 总收入 ≤ 0.05% |
| G-05 | 差异结案周期 | 平均 ≤ 3 个工作日 |
| G-06 | 封账准确率 | 封账后无回退需求 ≥ 99.5% |
| G-07 | 日结生成耗时 | 单收费点 ≤ 5 秒；全院 ≤ 60 秒 |
| G-08 | 数据可追溯 | 任一日结数字可下钻到流水明细 ≤ 3 次点击 |

**指标说明：**

- **G-03 为什么是 2%**：现金找零本身就是手工操作，正常误差在几元以内。以每日 60 个班次、每班次约 15 笔现金计，2% 意味着每天约 1.2 个班次出现长短款，符合行业经验。超过 2% 说明流程或人员有问题。
- **G-04 为什么是 0.05%**：渠道对账差异通常源于「跨日到账」（23:59 支付，00:01 回调）和「手续费四舍五入」。0.05% 意味着日收入 5 万元的医院一天差异不超过 25 元，符合实际。
- **G-05 为什么是 3 个工作日**：跨日到账的差异要等次日的账单才能确认，加上周末，3 个工作日是合理上限。

### 1.6 关键业务角色

| 角色 | 编码 | 主要职责 | 可见范围 |
|---|---|---|---|
| 收费员 | `CASHIER` | 交班、核对钱箱、申报长短款 | 自己班次 |
| 收费主管 | `CASHIER_SUPERVISOR` | 审核交班、日结收费点、处理长短款 | 本收费点全部班次 |
| 财务主管 | `FINANCE_MANAGER` | 全院日结、对账差异复核、封账/解封 | 全站 |
| 财务专员 | `FINANCE_STAFF` | 下载渠道账单、发起对账、处理差异 | 全站只读 + 对账操作 |
| 财务总监 | `FINANCE_DIRECTOR` | 大额差异审批、封账/解封审批 | 全站 |
| 审计员 | `AUDITOR` | 只读查阅全部交班与日结记录 | 全站只读 |

**职责分离要求：**

- 收费员不能审核自己的交班
- 财务专员不能封账（封账需财务主管或总监）
- 财务主管不能独自解封（需总监审批）
- 任何时候，同一笔现金不能既由 A 申报长短款又由 A 审批

### 2.3 依赖清单

| 编号 | 依赖 | 类型 | 失败影响 | 降级策略 |
|---|---|---|---|---|
| D-01 | `m16_payment`（M16-05） | 数据库表 | 无法汇总非现金收入 | 阻断日结 |
| D-02 | `m16_cashier_session`（M16-02） | 数据库表 | 无班次可汇总 | 允许无班次日结（标 `no_session=TRUE`） |
| D-03 | `m16_settlement`（M16-01） | 数据库表 | 无法按业务类型拆解 | 降级为只按支付方式汇总 |
| D-04 | `m16_refund_order`（M16-08） | 数据库表 | 退款不计入 → 日结偏大 | 阻断日结（退款必须计入） |
| D-05 | `m16_reconcile_task`（M16-05） | 数据库表 | 无渠道对账结果 | 全站对账标 `channel_data_missing=TRUE` |
| D-06 | `md_payment_method`（M01-06） | 内部接口 | 无法翻译支付方式名称 | 用 `pay_method` 原码，缓存 1 小时 |
| D-07 | `mdm_department`（M01-01） | 内部接口 | 无法按科室汇总 | 降级为「未知科室」 |
| D-08 | `mpi_patient`（M03-01） | 数据库表 | 无法统计人次 | 人次留空 |
| D-09 | M17 凭证接口 | 内部接口 | 无法推送凭证 | 入补偿队列重试 |

**关键降级原则：**

**现金与退款不能降级。** 现金少了就是少了，退款没算进去就是算错了。这两项数据缺失时，日结必须阻断并报错，不能出一个「大概对」的数字。其他维度（科室、人次、支付方式名称）都可以降级——一张缺了科室列的日结表仍然能核对总金额。

### 2.4 与 M16-05 对账的衔接

```
M16-05（02:00 自动对账）
  │  渠道账单下载 → 单渠道比对 → 生成 m16_reconcile_task / diff
  ▼
M16-09（02:30 全站对账）
  │  读取 M16-05 的对账结果 → 汇总各渠道 → 与本院日结合计比对
  ▼
M16-09 差异单
    ├── 渠道侧差异（M16-05 已识别）→ 直接引用
    └── 系统侧差异（本院内部对不上）→ 新建
```

**衔接规则：**

1. M16-09 不重复做单渠道比对，直接复用 M16-05 的 `m16_reconcile_task` 结果
2. M16-09 只做「全院汇总层」的校验：`Σ各渠道渠道金额 = Σ各渠道系统金额`，以及 `全院日结合计 = Σ各子模块汇总`
3. 若 M16-05 对账任务未完成，M16-09 标 `channel_data_missing=TRUE` 并只做现金对账，次日补做

## 3. 业务模型

### 3.1 五个层级的日结

```
┌─────────────────────────────────────────────────────────────┐
│ L4 全院日结  m16_daily_close(close_level='HOSPITAL')        │
│    每日 00:30 自动生成 + 财务主管确认                         │
└───────────────────────────┬─────────────────────────────────┘
                            │ 汇总
┌───────────────────────────▼─────────────────────────────────┐
│ L3 科室日结  m16_daily_close(close_level='DEPT')            │
│    每日 00:30 自动生成，覆盖全院所有有收入的科室               │
└───────────────────────────┬─────────────────────────────────┘
                            │ 汇总
┌───────────────────────────▼─────────────────────────────────┐
│ L2 收费点日结  m16_daily_close(close_level='POINT')         │
│    收费点关闭时或每日 00:30 生成                              │
└───────────────────────────┬─────────────────────────────────┘
                            │ 汇总
┌───────────────────────────▼─────────────────────────────────┐
│ L1 交班  m16_shift_close                                    │
│    收费员点「交班」时生成，主管审核后生效                      │
└───────────────────────────┬─────────────────────────────────┘
                            │ 引用
┌───────────────────────────▼─────────────────────────────────┐
│ L0 流水  m16_payment / m16_refund_order / m16_settlement    │
│    其他子模块写入，日结只读                                   │
└─────────────────────────────────────────────────────────────┘
```

**为什么要有五个层级：**

- **L0 流水**回答「这一笔是怎么回事」
- **L1 交班**回答「这个人这一班对不对」——出问题能追到人
- **L2 收费点**回答「这个窗口对不对」——出问题能关窗口
- **L3 科室**回答「这个科室贡献多少」——用于科室核算
- **L4 全院**回答「今天医院收了多少」——用于财务记账

少任何一层都会有人问不到的问题。比如只有全院日结，收费员 A 出了长短款就找不到；只有交班没有科室汇总，科主任拿不到收入数。

### 3.2 交班模型

**交班 = 一个收费员在一个工作站上的一段连续工作时段。**

```
开班                  正常交班                    审核
 │                      │                          │
 ▼                      ▼                          ▼
OPEN ──────────► PENDING_AUDIT ──────────► CLOSED
 │                      │
 │ 作废                  │ 驳回
 ▼                      ▼
VOID ◄────────────── REJECTED ──► OPEN（重新交班）
```

**交班的六个数字**

| 数字 | 含义 | 计算 |
|---|---|---|
| `opening_float` | 备用金 | 开班时钱箱里的起始现金 |
| `cash_income` | 现金收入 | 班次内现金收款合计 |
| `cash_expense` | 现金支出 | 班次内现金退款合计 |
| `expected_cash` | 应有现金 | `opening_float + cash_income − cash_expense` |
| `actual_cash` | 实际点钞 | 收费员一张张点出来的 |
| `difference` | 长短款 | `actual_cash − expected_cash` |

**长短款判定**

| `difference` | `difference_type` | 名称 | 处理 |
|---|---|---|---|
| = 0 | `EVEN` | 平账 | 直接通过 |
| > 0 | `OVER` | 长款 | 需填原因 + 主管审核 |
| < 0 | `SHORT` | 短款 | 需填原因 + 主管审核 + 超过阈值需财务复核 |

**为什么长款也要审核：**

短款（钱少了）显然要查。长款（钱多了）看似无害，实际更危险——收多了钱通常意味着「多找了零」「收错了患者」「本该找零没找」，背后是服务差错甚至患者投诉。医院如果对长款放任不管，会积累成系统性的服务问题。

**备用金为什么必须固定：**

如果备用金可以随便定，交班时长短款就能被「调整备用金」掩盖。系统强制：同一工作站的备用金由主管统一设定，收费员开班时不能改。这保证了长短款只能如实暴露。

### 3.3 日结模型

**日结 = 把一个时间段内的资金动作冻结成快照，并验证快照自洽。**

```
    流水持续写入               日结窗口             封账
        │                        │                   │
 ───────┼────────────────────────┼───────────────────┼──────► 时间
     00:00                    23:59:59            T+1 确认
                                 │                   │
                                 ▼                   ▼
                         m16_daily_close       is_frozen=TRUE
                         status='DRAFT'        status='FROZEN'
```

**日结状态机**

```
        ┌──────────┐
        │  DRAFT   │ 自动生成或手动重算
        └────┬─────┘
             │ 主管核对无差异
             ▼
        ┌──────────┐
        │ PENDING  │ 已提交待确认
        └────┬─────┘
             │ 财务主管确认
             ▼
        ┌──────────┐
        │ CONFIRMED│ 已确认（可继续处理未结差异）
        └────┬─────┘
             │ 差异全部结案 + 财务主管封账
             ▼
        ┌──────────┐
        │  FROZEN  │ 已封账（只读，不可重算）
        └────┬─────┘
             │ 财务总监审批解封
             ▼
        ┌──────────┐
        │ UNFROZEN │ 已解封（可重算，需填原因）
        └────┬─────┘
             │ 重新封账
             ▼
          FROZEN
```

**为什么允许解封：**

封账后发现原数据有错（比如某笔收费录错了科室），是真实场景。如果完全禁止解封，错误就永久固化。但解封必须有严格条件：

1. 必须有充足理由（≥ 20 字）
2. 必须财务总监审批
3. 解封次数计入风控，同一日结解封超过 2 次触发审计
4. 解封后重算，所有数字变化写入 `m16_daily_close_log`
5. 原封账数据保留在 `m16_daily_close_snapshot`，可对比前后差异

### 3.4 日结的核算口径

**核心恒等式（日结必须满足）：**

```
总收入 = 现金收入 + 非现金收入
       = 现金收入 + (扫码 + 刷卡 + 储值 + 其他)
```

```
净收款 = 收款合计 − 退款合计
```

```
收费点日结合计 = Σ(该收费点当日全部班次)
科室日结合计   = Σ(该科室当日全部收入)
全院日结合计   = Σ(全部收费点日结) = Σ(全部科室日结)
```

**最后一条是日结自检的核心。** 如果「按收费点汇总」和「按科室汇总」算出来的全院总额不等，说明有收入既没有归属收费点也没有归属科室——这在 M16 里是不应该出现的，一定是数据问题。系统每次日结都会做这个交叉校验。

**业务类型口径**

| 业务类型 | `biz_type` | 来源 | 计入时间 |
|---|---|---|---|
| 门诊挂号 | `REGISTRATION` | M04-03 | 挂号收费成功时间 |
| 门诊医嘱 | `OUTPATIENT_ORDER` | M07-03 | 医嘱缴费成功时间 |
| 住院预交金 | `INPATIENT_DEPOSIT` | M16-03 | 预交金入账时间 |
| 住院结算 | `INPATIENT_SETTLE` | M16-03 | 出院结算完成时间 |
| 视光销售 | `OPTICAL_SALE` | M16-04 | 销售单收款时间 |
| 其他 | `OTHER` | M16-02 | 收费时间 |

**计入时间是「钱到账时间」而非「单据创建时间」。** 这是财务的通用原则——权责发生制看业务发生，但资金日报看资金到账。一笔 23:58 创建、00:02 支付成功的订单，计入次日。

### 3.5 对账模型

**对账 = 两个独立来源的记录，逐项比对，差异必须被解释。**

```
   来源 A（系统）              来源 B（外部）
   ┌──────────────┐          ┌──────────────┐
   │ m16_payment  │          │ 支付宝账单    │
   │ 12,580.00    │  ◄────►  │ 12,560.00    │
   └──────────────┘          └──────────────┘
              │                      │
              └──────────┬───────────┘
                         ▼
                  ┌─────────────┐
                  │ 差异 20.00  │
                  └──────┬──────┘
                         │ 逐笔定位
                         ▼
              ┌──────────────────────┐
              │ 差异 1: 渠道有系统无  │  ← 长款（系统漏记）
              │ 差异 2: 系统有渠道无  │  ← 短款（渠道漏记/跨日）
              │ 差异 3: 金额不一致    │  ← 手续费未扣
              │ 差异 4: 状态不一致    │  ← 系统成功渠道退款
              │ 差异 5: 手续费差异    │  ← 费率变更未生效
              └──────────────────────┘
```

**五类差异的定责与处理**

| 类型 | 代码 | 含义 | 责任方 | 处理动作 |
|---|---|---|---|---|
| 渠道独有 | `CHANNEL_ONLY` | 渠道有、系统无 | 系统（漏记） | 补单 `SUPPLEMENT` |
| 系统独有 | `LOCAL_ONLY` | 系统有、渠道无 | 渠道（漏记/跨日） | 撤销 `REVERSE` 或 等待 `WAIT` |
| 金额不一致 | `AMOUNT_MISMATCH` | 都有但金额不同 | 双方核查 | 调账 `ADJUST` |
| 状态不一致 | `STATUS_MISMATCH` | 都有但状态不同 | 双方核查 | 调账 `ADJUST` |
| 手续费差异 | `FEE_MISMATCH` | 手续费算错 | 系统 | 调账 `ADJUST` |

**差异金额的符号约定**

```
amount_diff = channel_amount − local_amount
```

- `amount_diff > 0`：渠道比我多 → 系统少记了（对我们有利，但要查）
- `amount_diff < 0`：渠道比我少 → 系统多记了（对我们不利，必须查）

**为什么用「渠道 − 本地」而不是反过来：**

因为对账的视角是「外部说我有多少钱」。正数意味着外部认为我比系统记的多，这是需要补记的方向，与「补单」动作方向一致，不容易搞反。

### 3.6 差异结案模型

```
     ┌────────────┐
     │  DETECTED  │ 自动识别
     └─────┬──────┘
           │ 分配处理人
           ▼
     ┌────────────┐
     │  ASSIGNED  │ 已分配
     └─────┬──────┘
           │ 开始处理
           ▼
     ┌────────────┐
     │ PROCESSING │ 处理中
     └──┬──────┬──┘
        │      │
   ┌────▼──┐ ┌─▼────────┐
   │RESOLVED│ │ESCALATED │  超时未结案
   │已结案   │ │已升级    │
   └────────┘ └──────────┘
        │
        ▼
   ┌──────────┐
   │  CLOSED  │ 归档
   └──────────┘
```

**差异结案时限**

| 差异金额 | 时限 | 超时处理 |
|---|---|---|
| ≤ 100 元 | 5 个工作日 | 提醒 |
| 100 ~ 1,000 元 | 3 个工作日 | 升级财务主管 |
| > 1,000 元 | 1 个工作日 | 升级财务总监 + 强制上报 |

**结案必须附证据。** 不允许「感觉没问题了就结案」。每笔结案的 `resolution_note` 至少 10 个字，且金额 ≥ 1,000 元的必须上传附件（渠道账单截图、银行回单、调账凭证）。

### 3.7 封账模型

**封账 = 把某个日结的数据冻结为不可修改。**

封账影响的范围：

| 对象 | 封账前 | 封账后 |
|---|---|---|
| `m16_daily_close` 本行 | 可重算 | 不可重算 |
| 当日的 `m16_payment` | 可补单/撤销 | 不可补单，需先解封 |
| 当日的 `m16_refund_order` | 可执行 | 不可执行，需先解封 |
| 当日的 `m16_settlement` | 可改 | 不可改 |
| 当日的 `m16_cashier_session` | 可关班 | 不可再开关班 |

**封账的锁粒度：** 按 `close_date + close_level + scope_id` 分别封。门诊收费点 A 封账不影响收费点 B，也不影响科室日结。

**封账前置条件（全部满足才能封）：**

| 编号 | 条件 | 不满足 |
|---|---|---|
| C-01 | 日结状态为 `CONFIRMED` | 报 "1609008" |
| C-02 | 该日结下所有班次已 `CLOSED` | 报 "1609009" |
| C-03 | 该日结下无 `PENDING` 差异（金额 ≥ 100 元的） | 报 "1609010" |
| C-04 | 该日结的交叉校验通过（收费点合计 = 科室合计） | 报 "1609011" |
| C-05 | 该日结无 `EXECUTING` 状态的退费单 | 报 "1609012" |
| C-06 | 操作人具备 `m16:daily:freeze` 权限 | 报 "1609015" |

### 3.8 重算模型

**重算 = 在封账前，因为底层数据变化，重新计算日结数字。**

**重算触发场景：**

| 场景 | 触发方 | 是否自动 |
|---|---|---|
| 深夜补录收费 | M16-02 手工补录 | 否，需手动重算 |
| 退费执行完成（跨日） | M16-08 跨日退费 | 是（Celery 检测） |
| 渠道账单晚到 | M16-05 账单下载 | 是 |
| 差异调账 | M16-09 自身 | 是 |
| 数据修正 | 财务手工 | 否，需手动 |

**重算必须记录前后差异：**

```sql
-- 重算前
INSERT INTO m16_daily_close_snapshot
SELECT * FROM m16_daily_close WHERE id = :id;

-- 重算后
UPDATE m16_daily_close SET total_income = :new, version = version + 1
 WHERE id = :id;

-- 记日志
INSERT INTO m16_daily_close_log (...) VALUES (...);
```

**重算的幂等性：** 同一日结的重算结果必须确定。日结的所有数字来自固定的时间窗口 `[close_date 00:00:00, close_date 23:59:59]` 和固定的过滤条件，只要底层流水不变，重算结果必然相同。这让重算可以安全地被执行无数次。

### 3.9 数据流

```
            日结数据从哪里来
  ┌────────────────────────────────────────────────┐
  │ m16_payment（M16-05）                          │
  │   status='SUCCESS' AND paid_at BETWEEN 窗口     │──┐
  ├────────────────────────────────────────────────┤  │
  │ m16_refund_order（M16-08）                     │  │

  │   status='PAID' AND paid_at BETWEEN            │──┤
  ├────────────────────────────────────────────────┤  │
  │ m16_deposit（M16-03）                          │  │
  │   type='RECHARGE' AND created_at BETWEEN       │──┘
  ├────────────────────────────────────────────────┤
  │ m16_optical_payment（M16-04）                  │
  │   status='SUCCESS' AND paid_at BETWEEN         │
  └────────────────────────────────────────────────┘
                        │
                        ▼
        ┌───────────────────────────────┐
        │ 统一为 DailyFlow 视图          │
        │ (pay_method, biz_type,        │

# app/services/m16/daily_service.py
"""M16-09 日结与对账 Service"""
import json
import logging
from datetime import date, datetime, time, timedelta
from decimal import Decimal
from typing import Any, Optional

from sqlalchemy import func, select, text, update
from sqlalchemy.ext.asyncio import AsyncSession

from app.core.exceptions import BizError
from app.core.redis import redis_client
from app.models.m16.daily import (
    M16DailyClose, M16DailyCloseLog, M16DailyCloseSnapshot,
    M16DailyDiff, M16ShiftDiff, M16ShiftClose,
)
from app.models.m16.payment import M16Payment
from app.services.m16.base import M16BaseService

logger = logging.getLogger(__name__)

CENT = Decimal("0.01")
ZERO = Decimal("0.00")

# 面额清单（分）
DENOMINATIONS = [
    Decimal("100"), Decimal("50"), Decimal("20"), Decimal("10"),
    Decimal("5"), Decimal("1"), Decimal("0.5"), Decimal("0.1"),
]

# 交班状态机
SHIFT_TRANSITIONS = {
    "OPEN": {"PENDING_AUDIT", "VOID"},
    "PENDING_AUDIT": {"CLOSED", "REJECTED"},
    "REJECTED": {"OPEN"},
    "CLOSED": set(),
    "VOID": set(),
}

# 日结状态机
CLOSE_TRANSITIONS = {
    "DRAFT": {"PENDING", "DRAFT"},
    "PENDING": {"CONFIRMED", "DRAFT"},
    "CONFIRMED": {"FROZEN", "PENDING"},
    "FROZEN": {"UNFROZEN"},
    "UNFROZEN": {"DRAFT", "PENDING"},
}

# 差异类型
DIFF_TYPES = ("CHANNEL_ONLY", "LOCAL_ONLY", "AMOUNT_MISMATCH",
              "STATUS_MISMATCH", "FEE_MISMATCH")

# 差异处理动作
RESOLVE_ACTIONS = ("SUPPLEMENT", "REVERSE", "WAIT", "ADJUST", "IGNORE")


def money(value: Any) -> Decimal:
    """统一金额精度"""
    return Decimal(str(value)).quantize(CENT)


class ShiftService(M16BaseService):
    """交班服务"""

    # ---------- 查询 ----------

    async def get_current(
        self, workstation_id: int, user: Any,
    ) -> dict:
        shift = await self._find_open_shift(
            user.user_id, workstation_id)
        if shift is None:
            raise BizError(55017, "当前无未关闭班次")
        if shift.opening_float is None:
            raise BizError(55047, "备用金配置缺失，请联系收费主管")
        summary = await self._summarize(shift)
        pending = await self._count_pending_refunds(shift)
        unknown = await self._count_unknown_payments(shift)
        return {
            **self._shift_dict(shift),
            "summary": summary,
            "cash_check": self._cash_check(shift, summary),
            "pending_refunds": pending,
            "unknown_payments": unknown,
        }

    async def list_shifts(self, q: Any, user: Any) -> dict:
        stmt = select(M16ShiftClose)
        if q.business_date:
            stmt = stmt.where(
                M16ShiftClose.business_date == q.business_date)
        if q.workstation_id:
            stmt = stmt.where(
                M16ShiftClose.workstation_id == q.workstation_id)
        if q.operator_id:
            stmt = stmt.where(
                M16ShiftClose.operator_id == q.operator_id)
        if q.status:
            stmt = stmt.where(M16ShiftClose.status == q.status)
        # 数据权限：收费员只看自己
        if not self._can_view_all(user):
            stmt = stmt.where(M16ShiftClose.operator_id == user.user_id)
        total = await self._count(stmt)
        stmt = (stmt.order_by(M16ShiftClose.business_date.desc(),
                              M16ShiftClose.opened_at.desc())
                .offset((q.page - 1) * q.page_size)
                .limit(q.page_size))
        rows = (await self.db.execute(stmt)).scalars().all()
        return {
            "items": [self._shift_dict(r) for r in rows],
            "total": total, "page": q.page,
            "page_size": q.page_size,
            "pages": (total + q.page_size - 1) // q.page_size,
        }

    async def get_detail(self, shift_id: int, user: Any) -> dict:
        shift = await self._get(shift_id)
        if not self._can_view(user, shift):
            raise BizError(55031, "无权查看该班次")
        summary = await self._summarize(shift)
        return {
            **self._shift_dict(shift),
            "summary": summary,
            "cash_check": self._cash_check(shift, summary),
            "denominations": shift.denomination_json or [],
            "diff": self._diff_dict(shift),
        }

    async def by_operator(
        self, operator_id: int, business_date: Optional[date],
    ) -> list[dict]:
        stmt = select(M16ShiftClose).where(
            M16ShiftClose.operator_id == operator_id)
        if business_date:
            stmt = stmt.where(
                M16ShiftClose.business_date == business_date)
        rows = (await self.db.execute(
            stmt.order_by(M16ShiftClose.opened_at.desc())
            .limit(30)
        )).scalars().all()
        return [self._shift_dict(r) for r in rows]

    # ---------- 点钞 ----------

    async def cash_count(
        self, shift_id: int, payload: Any, user: Any,
    ) -> dict:
        shift = await self._get_for_update(shift_id)
        if not self._can_view(user, shift):
            raise BizError(55031, "无权操作该班次")
        if shift.status not in ("OPEN", "REJECTED"):
            raise BizError(55018, "班次状态不允许点钞")

        # 1. 校验面额
        total = ZERO
        denoms = []
        for item in payload.denominations:
            fv = money(item.face_value)
            if fv not in DENOMINATIONS:
                raise BizError(55019, "面额 %s 非法" % fv)
            if item.count < 0:
                raise BizError(55019, "张数必须为非负整数")
            subtotal = money(fv * item.count)
            total = money(total + subtotal)
            denoms.append({
                "face_value": str(fv), "count": item.count,
                "subtotal": str(subtotal),
            })
        if total <= ZERO:
            raise BizError(55019, "点钞金额不能为 0")

        # 2. 与客户端申报金额比对（防篡改）
        declared = money(payload.actual_cash)
        if declared != total:
            raise BizError(
                55049,
                "分面额合计 %s 与申报金额 %s 不一致"
                % (total, declared))

        summary = await self._summarize(shift)
        expected = self._expected_cash(shift, summary)
        difference = money(total - expected)

        # 3. 长短款校验
        if difference != ZERO:
            if not payload.reason_code:
                raise BizError(55020, "存在长短款，请填写原因")
            if len(payload.reason_desc or "") < 20:
                raise BizError(55021, "长短款说明至少 20 个字")
            diff_type = "OVER" if difference > ZERO else "SHORT"
            if payload.difference_type != diff_type:
                raise BizError(
                    55020,
                    "差异类型与金额符号不符：差额 %s" % difference)
            if difference <= Decimal("-500") and not payload.attachment_ids:
                raise BizError(
                    55022, "短款超过 500 元，请上传证明材料")

        # 4. 落库
        shift.denomination_json = denoms
        shift.actual_cash = total
        shift.expected_cash = expected
        shift.difference = difference
        shift.difference_type = self._diff_type(difference)
        shift.diff_reason_code = payload.reason_code
        shift.diff_reason_desc = payload.reason_desc
        shift.diff_attachment_ids = payload.attachment_ids or []
        shift.diff_handle_mode = payload.handle_suggestion
        shift.updated_at = datetime.now()
        shift.updated_by = user.user_id
        await self.db.commit()

        logger.info(
            "shift cash counted",
            extra={
                "shift_no": shift.shift_no,
                "expected": str(expected),
                "actual": str(total),
                "difference": str(difference),
            },
        )
        return {
            "shift_no": shift.shift_no,
            "actual_cash": total,
            "expected_cash": expected,
            "difference": difference,
            "difference_type": shift.difference_type,
            "denomination_total": total,
            "match": difference == ZERO,
        }

    # ---------- 提交与审核 ----------

    async def submit(
        self, shift_id: int, payload: Any, user: Any,
    ) -> dict:
        shift = await self._get_for_update(shift_id)
        if not self._can_view(user, shift):
            raise BizError(55031, "无权操作该班次")
        self._check_transition(shift.status, "PENDING_AUDIT",
                               SHIFT_TRANSITIONS, 55018)

        # 执行中的退费单阻断
        pending = await self._count_pending_refunds(shift)
        if pending > 0:
            raise BizError(
                55018,
                "本班次有 %d 笔退费正在执行，请稍后再交班" % pending)

        if shift.actual_cash is None:
            raise BizError(55018, "请先录入实点现金")

        old = shift.status
        shift.status = "PENDING_AUDIT"
        shift.submitted_at = datetime.now()
        shift.updated_by = user.user_id
        await self._log_shift(shift, "SUBMIT", old,
                              "PENDING_AUDIT", user, payload.remark)
        await self.db.commit()
        return {**self._shift_dict(shift),
                "old_status": old,
                "new_status": shift.status}

    async def audit(
        self, shift_id: int, payload: Any, user: Any,
    ) -> dict:
        shift = await self._get_for_update(shift_id)
        if shift.operator_id == user.user_id:
            raise BizError(55023, "不能审核自己的交班")
        if shift.status != "PENDING_AUDIT":
            raise BizError(55018, "该班次状态已变更，请刷新")

        comment = payload.comment or ""
        diff = shift.difference or ZERO
        if diff > Decimal("500") and not comment:
            raise BizError(55023, "长款超 500 元，请填写审核意见")
        if diff <= Decimal("-200"):
            # 短款 > 200 需财务复核
            if not self._has_role(user, "FINANCE_MANAGER"):
                raise BizError(
                    55023, "短款超过 200 元，需财务复核后才能通过")

        mode = payload.handle_mode or shift.diff_handle_mode or "HOLD"
        if mode not in ("HOLD", "TURN_IN", "COMPENSATE"):
            raise BizError(55018, "处理方式非法")

        shift.status = "CLOSED"
        shift.audited_by = user.user_id
        shift.audited_at = datetime.now()
        shift.handle_mode = mode
        shift.audit_comment = comment
        shift.closed_at = datetime.now()
        shift.updated_by = user.user_id

        diff_id = None
        if diff != ZERO:
            rec = await self._create_shift_diff(shift, mode, user)
            diff_id = rec.id

        await self._log_shift(shift, "AUDIT", "PENDING_AUDIT",
                              "CLOSED", user, comment)
        await self.db.commit()

        logger.info(
            "shift audited",
            extra={"shift_no": shift.shift_no,
                   "mode": mode, "difference": str(diff)},
        )
        return {
            "shift_no": shift.shift_no,
            "old_status": "PENDING_AUDIT",
            "new_status": "CLOSED",
            "difference": diff,
            "handle_mode": mode,
            "diff_record_id": diff_id,
            "audited_by": user.user_id,
            "audited_at": shift.audited_at,
        }

    async def reject(
        self, shift_id: int, payload: Any, user: Any,
    ) -> dict:
        shift = await self._get_for_update(shift_id)
        if shift.operator_id == user.user_id:
            raise BizError(55023, "不能审核自己的交班")
        if shift.status != "PENDING_AUDIT":
            raise BizError(55018, "该班次状态已变更，请刷新")
        if len(payload.comment or "") < 10:
            raise BizError(55023, "驳回意见至少 10 个字")

        shift.status = "REJECTED"
        shift.rejected_by = user.user_id
        shift.rejected_at = datetime.now()
        shift.audit_comment = payload.comment
        shift.updated_by = user.user_id
        await self._log_shift(shift, "REJECT", "PENDING_AUDIT",
                              "REJECTED", user, payload.comment)
        await self.db.commit()
        return {
            "shift_no": shift.shift_no,
            "old_status": "PENDING_AUDIT",
            "new_status": "REJECTED",
            "difference": shift.difference,
            "handle_mode": None,
            "diff_record_id": None,
            "audited_by": user.user_id,
            "audited_at": shift.rejected_at,
        }

    async def batch_audit(self, payload: Any, user: Any) -> list:
        results = []
        for sid in payload.shift_ids:
            try:
                if payload.result == "APPROVED":
                    r = await self.audit(sid, payload, user)
                else:
                    r = await self.reject(sid, payload, user)
                results.append(r)
            except BizError as exc:
                results.append({
                    "shift_id": sid, "error": exc.message,
                    "code": exc.code})
        return results

    # ---------- 内部工具 ----------

    async def _summarize(self, shift: Any) -> dict:
        """按支付方式汇总本班次流水"""
        rows = (await self.db.execute(text("""
            SELECT pay_method, pay_method_name,
                   COUNT(*) FILTER (WHERE direction = 'IN')  AS in_cnt,
                   COUNT(*) FILTER (WHERE direction = 'OUT') AS out_cnt,
                   COALESCE(SUM(amount) FILTER (WHERE direction = 'IN'), 0)
                       AS income,
                   COALESCE(SUM(amount) FILTER (WHERE direction = 'OUT'), 0)
                       AS refund
              FROM v_m16_shift_flow
             WHERE shift_id = :sid AND status = 'SUCCESS'
             GROUP BY pay_method, pay_method_name
             ORDER BY pay_method
        """), {"sid": shift.id})).mappings().all()

        methods = []
        total_in = total_out = ZERO
        for r in rows:
            inc = money(r["income"])
            ref = money(r["refund"])
            total_in = money(total_in + inc)
            total_out = money(total_out + ref)
            methods.append({
                "pay_method": r["pay_method"],
                "pay_method_name": r["pay_method_name"],
                "count": r["in_cnt"] + r["out_cnt"],
                "income": inc, "refund": ref,
                "net": money(inc - ref),
            })
        return {
            "pay_methods": methods,
            "total_count": sum(m["count"] for m in methods),
            "total_income": total_in,
            "total_refund": total_out,
            "total_net": money(total_in - total_out),
        }

    def _expected_cash(self, shift: Any, summary: dict) -> Decimal:
        cash = next(
            (m for m in summary["pay_methods"]
             if m["pay_method"] == "CASH"),
            None)
        opening = money(shift.opening_float or ZERO)
        inc = cash["income"] if cash else ZERO
        ref = cash["refund"] if cash else ZERO
        return money(opening + inc - ref)

    def _cash_check(self, shift: Any, summary: dict) -> dict:
        expected = self._expected_cash(shift, summary)
        actual = (money(shift.actual_cash)
                  if shift.actual_cash is not None else None)
        diff = money(actual - expected) if actual is not None else None
        return {
            "opening_float": money(shift.opening_float or ZERO),
            "cash_income": self._cash_part(summary, "income"),
            "cash_refund": self._cash_part(summary, "refund"),
            "expected_cash": expected,
            "actual_cash": actual,
            "difference": diff,
            "difference_type": self._diff_type(diff),
        }

    def _cash_part(self, summary: dict, key: str) -> Decimal:
        cash = next(
            (m for m in summary["pay_methods"]
             if m["pay_method"] == "CASH"), None)
        return cash[key] if cash else ZERO

    @staticmethod
    def _diff_type(diff: Optional[Decimal]) -> Optional[str]:
        if diff is None:
            return None
        if diff == ZERO:
            return "EVEN"
        return "OVER" if diff > ZERO else "SHORT"

    def _check_transition(self, cur: str, nxt: str,
                          table: dict, code: int) -> None:
        if nxt not in table.get(cur, set()):
            raise BizError(code, "状态 %s 不能转为 %s" % (cur, nxt))

    async def _find_open_shift(self, operator_id: int,
                               workstation_id: int):
        return (await self.db.execute(
            select(M16ShiftClose).where(
                M16ShiftClose.operator_id == operator_id,
                M16ShiftClose.workstation_id == workstation_id,
                M16ShiftClose.status.in_(
                    ("OPEN", "REJECTED")))
        )).scalars().first()

    async def _count_pending_refunds(self, shift: Any) -> int:
        r = await self.db.execute(text("""
            SELECT COUNT(*) FROM m16_refund_order
             WHERE cashier_session_id = :sid
               AND status IN ('EXECUTING', 'APPROVED')
        """), {"sid": shift.id})
        return int(r.scalar() or 0)

    async def _count_unknown_payments(self, shift: Any) -> int:
        r = await self.db.execute(text("""
            SELECT COUNT(*) FROM m16_payment
             WHERE cashier_session_id = :sid AND status = 'UNKNOWN'
        """), {"sid": shift.id})
        return int(r.scalar() or 0)

    def _shift_dict(self, s: Any) -> dict:
        return {
            "session_id": s.id,
            "session_no": s.shift_no,
            "operator_id": s.operator_id,
            "operator_name": s.operator_name,
            "workstation_id": s.workstation_id,
            "workstation_name": s.workstation_name,
            "business_date": s.business_date,
            "opened_at": s.opened_at,
            "closed_at": s.closed_at,
            "opening_float": s.opening_float,
            "expected_cash": s.expected_cash,
            "actual_cash": s.actual_cash,
            "difference": s.difference,
            "difference_type": s.difference_type,
            "status": s.status,
        }

    def _diff_dict(self, s: Any) -> Optional[dict]:
        if not s.difference or s.difference == ZERO:
            return None
        return {
            "difference": s.difference,
            "type": s.difference_type,
            "reason_code": s.diff_reason_code,
            "reason_desc": s.diff_reason_desc,
            "handle_mode": s.handle_mode,
            "audit_comment": s.audit_comment,
        }


class DailyCloseService(M16BaseService):
    """日结服务"""

    # ---------- 生成 / 重算 ----------

    async def generate(
        self, close_date: date, close_level: str,
        scope_id: Optional[int] = None,
    ) -> dict:
        """生成或刷新一个日结（幂等 UPSERT）"""
        lock = "m16:daily:close:lock:%s:%s:%s" % (
            close_date, close_level, scope_id or 0)
        if not await redis_client.set(lock, "1", nx=True, ex=300):
            raise BizError(55024, "该日结正在生成中，请稍后")

        try:
            metrics = await self._aggregate(
                close_date, close_level, scope_id)
            row = await self._upsert(close_date, close_level,
                                     scope_id, metrics)
            return row
        finally:
            await redis_client.delete(lock)

    async def recalc(
        self, close_date: date, close_level: str,
        scope_id: Optional[int], reason: str, cascade: bool,
        user: Any,
    ) -> dict:
        row = await self._get_by_key(close_date, close_level, scope_id)
        if row is None:
            raise BizError(55024, "日结不存在，请先生成")
        if row.status == "FROZEN":
            raise BizError(55032, "已封账，如需重算请先申请解封")
        if row.status not in ("DRAFT", "PENDING", "UNFROZEN"):
            raise BizError(55024, "当前状态不允许重算")

        # 快照留底
        await self._snapshot(row, reason, user)

        before = self._metrics_of(row)
        fresh = await self._aggregate(close_date, close_level, scope_id)
        self._apply_metrics(row, fresh)
        row.version += 1
        row.status = "DRAFT"
        row.updated_at = datetime.now()
        row.updated_by = user.user_id

        await self._log_daily(row, "RECALC", reason, user,
                              before=before,
                              after=self._metrics_of(row))
        await self.db.commit()

        # 级联重算上级与下级
        if cascade:
            await self._cascade_recalc(close_date, close_level,
                                       scope_id, reason, user)

        logger.info(
            "daily close recalculated",
            extra={"close_date": str(close_date),
                   "level": close_level, "scope_id": scope_id,
                   "reason": reason})
        return await self.get_detail(close_date, close_level, scope_id)

    async def _cascade_recalc(
        self, close_date: date, close_level: str,
        scope_id: Optional[int], reason: str, user: Any,
    ) -> None:
        levels = ["POINT", "DEPT", "HOSPITAL"]
        idx = levels.index(close_level)
        # 向下：若重算科室，则其下收费点也重算没有意义（收费点不隶属科室）
        # 向上：始终重算更高层级
        for lv in levels[idx + 1:]:
            try:
                await self._recalc_silent(close_date, lv, None,
                                          reason, user)
            except BizError:
                logger.warning("cascade recalc skipped level=%s", lv)
        # 收费点重算需要重算全部科室与全院
        if close_level == "POINT":
            for lv, sid in [("DEPT", None), ("HOSPITAL", None)]:
                try:
                    await self._recalc_silent(close_date, lv, sid,
                                              reason, user)
                except BizError:
                    logger.warning("cascade recalc skipped level=%s", lv)

    async def _recalc_silent(
        self, close_date: date, level: str,
        scope_id: Optional[int], reason: str, user: Any,
    ) -> None:
        row = await self._get_by_key(close_date, level, scope_id)
        if row is None or row.status in ("FROZEN", "CONFIRMED"):
            return
        fresh = await self._aggregate(close_date, level, scope_id)
        self._apply_metrics(row, fresh)
        row.version += 1
        row.status = "DRAFT"
        row.updated_at = datetime.now()

    # ---------- 聚合核心 ----------

    async def _aggregate(
        self, close_date: date, close_level: str,
        scope_id: Optional[int],
    ) -> dict:
        start = datetime.combine(close_date, time(0, 0, 0))
        end = start + timedelta(days=1)
        params = {"start": start, "end": end}

        # 维度过滤
        where = ""
        if close_level == "POINT" and scope_id:
            where = " AND point_id = :scope_id"
            params["scope_id"] = scope_id
        elif close_level == "DEPT" and scope_id:
            where = " AND dept_id = :scope_id"
            params["scope_id"] = scope_id

        sql = text("""
            WITH f AS (
                SELECT pay_method, pay_method_name, biz_type,
                       CASE WHEN direction = 'IN' THEN amount
                            ELSE 0 END AS inc,
                       CASE WHEN direction = 'OUT' THEN amount
                            ELSE 0 END AS ref,
                       dept_id, point_id, patient_id, direction
                  FROM v_m16_daily_flow
                 WHERE occurred_at >= :start
                   AND occurred_at <  :end
                   AND status = 'SUCCESS'
                   """ + where + """
            )
            SELECT
                pay_method, pay_method_name,
                COUNT(*) FILTER (WHERE direction = 'IN')  AS in_cnt,
                COUNT(*) FILTER (WHERE direction = 'OUT') AS out_cnt,
                COALESCE(SUM(inc), 0) AS income,
                COALESCE(SUM(ref), 0) AS refund,
                SUM(inc) AS s_inc
              FROM f
             GROUP BY pay_method, pay_method_name
        """)
        pay_rows = (await self.db.execute(
            sql, params)).mappings().all()

        by_pay = []
        total_income = total_refund = ZERO
        for r in pay_rows:
            inc = money(r["income"])
            ref = money(r["refund"])
            total_income = money(total_income + inc)
            total_refund = money(total_refund + ref)
            by_pay.append({
                "pay_method": r["pay_method"],
                "pay_method_name": r["pay_method_name"],
                "count": (r["in_cnt"] or 0) + (r["out_cnt"] or 0),
                "income": inc, "refund": ref,
                "net": money(inc - ref),
            })
        net_income = money(total_income - total_refund)

        # 业务类型
        biz_sql = text("""
            SELECT biz_type,
                   SUM(CASE WHEN direction = 'IN' THEN amount
                            ELSE -amount END) AS amount,
                   COUNT(DISTINCT patient_id) AS cnt
              FROM v_m16_daily_flow
             WHERE occurred_at >= :start AND occurred_at < :end
               AND status = 'SUCCESS' """ + where + """
             GROUP BY biz_type
             ORDER BY amount DESC
        """)
        by_biz = [
            {"biz_type": r["biz_type"],
             "amount": money(r["amount"]),
             "count": r["cnt"]}
            for r in (await self.db.execute(
                biz_sql, params)).mappings().all()
        ]

        # 收费点（仅 POINT 以上）
        by_point = []
        if close_level in ("POINT", "HOSPITAL"):
            pt_sql = text("""
                SELECT point_id,
                       COUNT(DISTINCT shift_id) AS session_count,
                       SUM(CASE WHEN direction = 'IN' THEN amount
                                ELSE 0 END) AS income,
                       SUM(CASE WHEN direction = 'OUT' THEN amount
                                ELSE 0 END) AS refund
                  FROM v_m16_daily_flow
                 WHERE occurred_at >= :start
                   AND occurred_at <  :end
                   AND status = 'SUCCESS'
                 GROUP BY point_id
            """)
            by_point = [
                {"point_id": r["point_id"],
                 "session_count": r["session_count"],
                 "income": money(r["income"]),
                 "refund": money(r["refund"])}
                for r in (await self.db.execute(
                    pt_sql, params)).mappings().all()
            ]

        # 科室
        by_dept = []
        if close_level in ("DEPT", "HOSPITAL"):
            dp_sql = text("""
                SELECT dept_id,
                       SUM(CASE WHEN direction = 'IN' THEN amount
                                ELSE -amount END) AS amount
                  FROM v_m16_daily_flow
                 WHERE occurred_at >= :start
                   AND occurred_at <  :end
                   AND status = 'SUCCESS'
                 GROUP BY dept_id
                 ORDER BY amount DESC
            """)
            by_dept = [
                {"dept_id": r["dept_id"],
                 "amount": money(r["amount"])}
                for r in (await self.db.execute(
                    dp_sql, params)).mappings().all()
            ]

        # 人次
        pc = await self.db.execute(text("""
            SELECT COUNT(DISTINCT patient_id)
              FROM v_m16_daily_flow
             WHERE occurred_at >= :start AND occurred_at < :end
               AND status = 'SUCCESS'
               AND biz_type = 'REGISTRATION'
        """), params)
        patient_count = int(pc.scalar() or 0)

        # 长短款
        cash_diff = await self._cash_diff(close_date)

        return {
            "by_pay_method": by_pay,
            "by_biz_type": by_biz,
            "by_point": by_point,
            "by_dept": by_dept,
            "total_income": total_income,
            "total_refund": total_refund,
            "net_income": net_income,
            "patient_count": patient_count,
            "cash_diff": cash_diff,
        }

    async def _cash_diff(self, close_date: date) -> dict:
        r = await self.db.execute(text("""
            SELECT COUNT(*) FILTER (WHERE difference_type = 'OVER')  AS o_cnt,
                   COUNT(*) FILTER (WHERE difference_type = 'SHORT') AS s_cnt,
                   COALESCE(SUM(difference)
                       FILTER (WHERE difference_type = 'OVER'), 0)  AS o_amt,
                   COALESCE(SUM(difference)
                       FILTER (WHERE difference_type = 'SHORT'), 0) AS s_amt
              FROM m16_shift_close
             WHERE business_date = :d AND status = 'CLOSED'
        """), {"d": close_date}).mappings().first()
        over_amt = money(r["o_amt"] or 0)
        short_amt = money(r["s_amt"] or 0)
        return {
            "total_count": (r["o_cnt"] or 0) + (r["s_cnt"] or 0),
            "over_amount": over_amt,
            "short_amount": short_amt,
            "net_amount": money(over_amt + short_amt),
            "short_over_threshold": await self._short_over(
                close_date),
        }

    async def _short_over(self, close_date: date) -> int:
        r = await self.db.execute(text("""
            SELECT COUNT(*) FROM m16_shift_close
             WHERE business_date = :d AND status = 'CLOSED'
               AND difference < -200
        """), {"d": close_date})
        return int(r.scalar() or 0)

    # ---------- 自检 ----------

    async def run_checks(self, close_id: int) -> list:
        row = await self._get(close_id)
        by_pay = self._json_list(row.by_pay_method)
        by_pt = self._json_list(row.by_point)
        by_dept = self._json_list(row.by_dept)
        net = money(row.net_income)

        checks = []

        # C1 支付方式合计
        s1 = money(sum(money(m["net"]) for m in by_pay))
        checks.append({
            "code": "CROSS_PAY_METHOD",
            "name": "支付方式合计 = 汇总总额",
            "result": "PASS" if s1 == net else "FAIL",
            "detail": "支付方式合计 %s，汇总总额 %s" % (s1, net),
        })

        # C2 收费点合计 = 科室合计（仅全院）
        if row.close_level == "HOSPITAL":
            s_pt = money(sum(
                money(p["income"]) - money(p["refund"])
                for p in by_pt))
            s_dept = money(sum(money(d["amount"]) for d in by_dept))
            ok = s_pt == s_dept == net
            checks.append({
                "code": "CROSS_POINT_DEPT",
                "name": "收费点合计 = 科室合计",
                "result": "PASS" if ok else "FAIL",
                "detail": "收费点 %s，科室 %s，总额 %s"
                          % (s_pt, s_dept, net),
            })

        # C3 业务类型合计
        by_biz = self._json_list(row.by_biz_type)
        s3 = money(sum(money(b["amount"]) for b in by_biz))
        checks.append({
            "code": "CROSS_BIZ_TYPE",
            "name": "业务类型合计 = 汇总总额",
            "result": "PASS" if s3 == net else "FAIL",
            "detail": "业务类型合计 %s，汇总总额 %s" % (s3, net),
        })

        # C4 长短款
        cd = row.cash_diff or {}
        cd_net = money(cd.get("net_amount") or 0)
        checks.append({
            "code": "CASH_DIFF",
            "name": "长短款检查",
            "result": "PASS" if cd_net == ZERO else "WARN",
            "detail": "存在 %d 笔长短款，净额 %s"
                      % (cd.get("total_count", 0), cd_net),
        })

        # C5 未交班
        r = await self.db.execute(text("""
            SELECT COUNT(*) FROM m16_shift_close
             WHERE business_date = :d
               AND status IN ('OPEN', 'PENDING_AUDIT', 'REJECTED')
        """), {"d": row.close_date})
        open_cnt = int(r.scalar() or 0)
        checks.append({
            "code": "OPEN_SHIFT",
            "name": "班次全部已关闭",
            "result": "PASS" if open_cnt == 0 else "FAIL",
            "detail": "未关闭班次 %d 个" % open_cnt,
        })

        # C6 执行中退费
        r = await self.db.execute(text("""
            SELECT COUNT(*) FROM m16_refund_order
             WHERE DATE(created_at) = :d AND status = 'EXECUTING'
        """), {"d": row.close_date})
        exec_cnt = int(r.scalar() or 0)
        checks.append({
            "code": "EXECUTING_REFUND",
            "name": "无执行中退费",
            "result": "PASS" if exec_cnt == 0 else "FAIL",
            "detail": "执行中退费 %d 笔" % exec_cnt,
        })

        return checks

    # ---------- 封账 ----------

    async def check_freeze(
        self, close_date: date, close_level: str,
        scope_id: Optional[int] = None,
    ) -> dict:
        row = await self._get_by_key(close_date, close_level, scope_id)
        items = []

        # C-01 状态
        ok1 = row is not None and row.status == "CONFIRMED"
        items.append({
            "code": "C-01", "name": "日结状态为 CONFIRMED",
            "result": "PASS" if ok1 else "FAIL",
            "detail": row.status if row else "日结不存在",
        })

        # C-02 班次已关闭
        r = await self.db.execute(text("""
            SELECT COUNT(*) FROM m16_shift_close
             WHERE business_date = :d
               AND status NOT IN ('CLOSED', 'VOID')
        """), {"d": close_date})
        c2 = int(r.scalar() or 0)
        items.append({
            "code": "C-02", "name": "全部班次已关闭",
            "result": "PASS" if c2 == 0 else "FAIL",
            "detail": "未关闭 %d 个" % c2,
        })

        # C-03 无未结差异
        r = await self.db.execute(text("""
            SELECT COUNT(*), COALESCE(SUM(amount_diff), 0)
              FROM m16_daily_diff
             WHERE bill_date = :d
               AND status IN ('DETECTED', 'ASSIGNED', 'PROCESSING',
                              'ESCALATED')
               AND ABS(amount_diff) >= 100
        """), {"d": close_date})
        row3 = r.mappings().first()
        c3 = int(row3["count"] or 0)
        items.append({
            "code": "C-03", "name": "无未结差异（≥100 元）",
            "result": "PASS" if c3 == 0 else "WARN",
            "detail": "未结 %d 笔，合计 %s"
                      % (c3, money(row3["sum"] or 0)),
        })

        # C-04 交叉校验
        if row is not None:
            checks = await self.run_checks(row.id)
            fails = [c for c in checks if c["result"] == "FAIL"]
            items.append({
                "code": "C-04", "name": "交叉校验通过",
                "result": "PASS" if not fails else "FAIL",
                "detail": "; ".join(
                    "%s: %s" % (f["name"], f["detail"])
                    for f in fails) or "全部通过",
            })
        else:
            items.append({
                "code": "C-04", "name": "交叉校验通过",
                "result": "FAIL", "detail": "日结不存在",
            })

        # C-05 无执行中退费
        r = await self.db.execute(text("""
            SELECT COUNT(*) FROM m16_refund_order
             WHERE DATE(created_at) = :d AND status = 'EXECUTING'
        """), {"d": close_date})
        c5 = int(r.scalar() or 0)
        items.append({
            "code": "C-05", "name": "无执行中退费",
            "result": "PASS" if c5 == 0 else "FAIL",
            "detail": "执行中 %d 笔" % c5,
        })

        has_fail = any(i["result"] == "FAIL" for i in items)
        has_warn = any(i["result"] == "WARN" for i in items)
        conclusion = ("FAIL" if has_fail
                      else ("WARN" if has_warn else "PASS"))
        return {
            "close_date": close_date,
            "close_level": close_level,
            "items": items,
            "conclusion": conclusion,
            "can_freeze": not has_fail,
            "need_approval": has_warn and not has_fail,
        }

    async def freeze(
        self, close_id: int, payload: Any, user: Any,
    ) -> dict:
        row = await self._get_for_update(close_id)
        check = await self.check_freeze(
            row.close_date, row.close_level, row.scope_id)
        if check["conclusion"] == "FAIL":
            fails = [i for i in check["items"]
                     if i["result"] == "FAIL"]
            code_map = {"C-02": 55025, "C-03": 55026,
                        "C-04": 55027, "C-05": 55028,
                        "C-01": 55024}
            first = fails[0]
            raise BizError(
                code_map.get(first["code"], 55024),
                "%s：%s" % (first["name"], first["detail"]))

        if len(payload.note or "") < 10:
            raise BizError(55030, "封账说明至少 10 个字")

        if check["conclusion"] == "WARN":
            if not payload.force:
                raise BizError(55026, "存在未结差异，请先处理或强制封账")
            if not self._has_role(user, "FINANCE_DIRECTOR"):
                raise BizError(55029, "强制封账需财务总监审批")

        row.status = "FROZEN"
        row.frozen_at = datetime.now()
        row.frozen_by = user.user_id
        row.frozen_by_name = user.real_name
        row.freeze_note = payload.note
        row.updated_at = datetime.now()
        await self._log_daily(row, "FREEZE", payload.note, user)
        await self.db.commit()

        # 清缓存
        await redis_client.delete(
            "m16:daily:close:%s:%s:%s"
            % (row.close_date, row.close_level, row.scope_id or 0))

        logger.info(
            "daily closed frozen",
            extra={"close_id": close_id,
                   "close_date": str(row.close_date),
                   "level": row.close_level,
                   "force": check["conclusion"] == "WARN"})
        return {
            "close_id": row.id,
            "close_date": row.close_date,
            "close_level": row.close_level,
            "status": row.status,
            "frozen_at": row.frozen_at,
            "frozen_by_name": row.frozen_by_name,
            "forced": check["conclusion"] == "WARN",
        }

    async def apply_unfreeze(
        self, close_id: int, payload: Any, user: Any,
    ) -> dict:
        row = await self._get_for_update(close_id)
        if row.status != "FROZEN":
            raise BizError(55024, "仅已封账的日结可申请解封")
        if len(payload.reason or "") < 20:
            raise BizError(55033, "解封原因至少 20 个字")
        if await self._period_closed(row.close_date):
            raise BizError(55035, "所属会计期间已关账，不可解封")

        apply_no = await self._next_no("UNF")
        affected = await self._affected_scope(
            row.close_date, row.close_level, row.scope_id)
        count = (row.unfreeze_count or 0) + 1
        row.unfreeze_apply_no = apply_no
        row.unfreeze_reason = payload.reason
        row.unfreeze_count = count
        row.updated_at = datetime.now()
        await self._log_daily(row, "UNFREEZE_APPLY",
                              payload.reason, user)
        await self.db.commit()

        return {
            "apply_no": apply_no,
            "close_id": row.id,
            "status": "PENDING_APPROVAL",
            "approver_role": "FINANCE_DIRECTOR",
            "affected": affected,
            "unfreeze_count": count,
            "audit_flagged": count > 2,
            "expires_at": datetime.now() + timedelta(hours=24),
        }

    async def approve_unfreeze(
        self, close_id: int, payload: Any, user: Any,
    ) -> dict:
        row = await self._get_for_update(close_id)
        if row.status != "FROZEN":
            raise BizError(55024, "该日结状态已变更")
        if not self._has_role(user, "FINANCE_DIRECTOR"):
            raise BizError(55034, "解封需财务总监审批")

        if not payload.approved:
            await self._log_daily(row, "UNFREEZE_REJECT",
                                  payload.comment or "", user)
            await self.db.commit()
            return {"close_id": row.id, "status": row.status,
                    "approved": False}

        row.status = "UNFROZEN"
        row.unfrozen_at = datetime.now()
        row.unfrozen_by = user.user_id
        row.updated_at = datetime.now()
        await self._log_daily(row, "UNFREEZE_APPROVE",
                              payload.comment or "", user)
        await self.db.commit()

        logger.warning(
            "daily close unfrozen",
            extra={"close_id": close_id,
                   "close_date": str(row.close_date),
                   "count": row.unfreeze_count,
                   "approver": user.user_id})
        return {
            "close_id": row.id,
            "close_date": row.close_date,
            "close_level": row.close_level,
            "status": row.status,
            "frozen_at": None,
            "frozen_by_name": None,
            "forced": False,
        }

    async def _affected_scope(self, close_date: date, level: str,
                              scope_id: Optional[int]) -> dict:
        r = await self.db.execute(text("""
            SELECT COUNT(*) FROM m16_daily_close
             WHERE close_date = :d
        """), {"d": close_date})
        total = int(r.scalar() or 0)
        r2 = await self.db.execute(text("""
            SELECT COUNT(*) FROM m16_daily_close
             WHERE close_date = :d AND close_level = 'POINT'
        """), {"d": close_date})
        points = int(r2.scalar() or 0)
        r3 = await self.db.execute(text("""
            SELECT COUNT(*) FROM m16_daily_close
             WHERE close_date = :d AND close_level = 'DEPT'
        """), {"d": close_date})
        depts = int(r3.scalar() or 0)
        return {
            "hospital": 1,
            "points": points,
            "depts": depts,
            "total_records": total,
            "total_amount": ZERO,
        }

    async def _period_closed(self, close_date: date) -> bool:
        r = await self.db.execute(text("""
            SELECT 1 FROM m16_period_close
             WHERE period_start <= :d AND period_end >= :d
               AND status = 'CLOSED'
             LIMIT 1
        """), {"d": close_date})
        return r.first() is not None

    async def submit(self, close_id: int, user: Any) -> dict:
        row = await self._get_for_update(close_id)
        self._check_transition(row.status, "PENDING",
                               CLOSE_TRANSITIONS, 55024)
        checks = await self.run_checks(row.id)
        fails = [c for c in checks if c["result"] == "FAIL"]
        if fails:
            raise BizError(
                55027,
                "交叉校验未通过：%s" % fails[0]["detail"])
        old = row.status
        row.status = "PENDING"
        row.submitted_at = datetime.now()
        row.updated_at = datetime.now()
        await self._log_daily(row, "SUBMIT", "", user,
                              old_status=old)
        await self.db.commit()
        return await self.get_detail(
            row.close_date, row.close_level, row.scope_id)

    async def get_detail(
        self, close_date: date, close_level: str,
        scope_id: Optional[int],
    ) -> dict:
        key = "m16:daily:close:%s:%s:%s" % (
            close_date, close_level, scope_id or 0)
        cached = await redis_client.get(key)
        if cached:
            return json.loads(cached)

        row = await self._get_by_key(close_date, close_level, scope_id)
        if row is None:
            raise BizError(55046, "该日结尚未生成")
        data = await self._detail_dict(row)
        await redis_client.setex(
            key, 60, json.dumps(data, default=str))
        return data

    async def _detail_dict(self, row: Any) -> dict:
        net = money(row.net_income)
        metrics = {
            "total_income": money(row.total_income),
            "total_refund": money(row.total_refund),
            "net_income": net,
            "patient_count": row.patient_count or 0,
            "cash_ratio": self._ratio(
                self._sum_by(row.by_pay_method, "CASH"), net),
            "scan_ratio": self._ratio(
                self._sum_by(row.by_pay_method, "CASH",
                             exclude=True), net),
            "avg_amount": (money(net / row.patient_count)
                           if row.patient_count else ZERO),
            "refund_rate": self._ratio(
                money(row.total_refund),
                money(row.total_income)),
        }
        return {
            "id": row.id,
            "close_date": row.close_date,
            "close_level": row.close_level,
            "scope_id": row.scope_id,
            "scope_name": row.scope_name or "全院",
            "status": row.status,
            "version": row.version,
            "generated_at": row.generated_at,
            "confirmed_at": row.confirmed_at,
            "confirmed_by_name": row.confirmed_by_name,
            "metrics": metrics,
            "by_pay_method": self._with_ratio(
                self._json_list(row.by_pay_method), net),
            "by_biz_type": self._with_ratio(
                self._json_list(row.by_biz_type), net),
            "by_point": self._with_ratio(
                self._json_list(row.by_point), net),
            "by_dept": self._with_ratio(
                self._json_list(row.by_dept), net),
            "reconcile": row.reconcile_json or {
                "channel_data_missing": True, "channels": []},
            "cash_diff": row.cash_diff or {},
            "checks": await self.run_checks(row.id),
            "frozen_at": row.frozen_at,
            "unfreeze_count": row.unfreeze_count or 0,
        }

    async def list_closes(self, q: Any, user: Any) -> dict:
        stmt = select(M16DailyClose).where(
            M16DailyClose.close_date >= q.date_from,
            M16DailyClose.close_date <= q.date_to)
        if q.close_level:
            stmt = stmt.where(
                M16DailyClose.close_level == q.close_level)
        if q.scope_id is not None:
            stmt = stmt.where(M16DailyClose.scope_id == q.scope_id)
        if q.status:
            stmt = stmt.where(M16DailyClose.status == q.status)
        total = await self._count(stmt)
        rows = (await self.db.execute(
            stmt.order_by(M16DailyClose.close_date.desc(),
                          M16DailyClose.close_level)
            .offset((q.page - 1) * q.page_size)
            .limit(q.page_size)
        )).scalars().all()
        return {
            "items": [{
                "id": r.id, "close_date": r.close_date,
                "close_level": r.close_level,
                "scope_id": r.scope_id, "scope_name": r.scope_name,
                "status": r.status,
                "total_income": money(r.total_income),
                "total_refund": money(r.total_refund),
                "net_income": money(r.net_income),
            } for r in rows],
            "total": total, "page": q.page,
            "page_size": q.page_size,
            "pages": (total + q.page_size - 1) // q.page_size,
        }

    async def on_transaction(self, payload: Any) -> dict:
        """资金事务回调：写入日结流水缓冲表"""
        exists = await self.db.execute(text("""
            SELECT 1 FROM m16_daily_transaction
             WHERE transaction_id = :tid
             LIMIT 1
        """), {"tid": payload.transaction_id})
        if exists.first():
            return {
                "transaction_id": payload.transaction_id,
                "biz_date": payload.biz_date,
                "accepted": True,
                "is_idempotent": True,
                "frozen": await self._is_frozen(
                    payload.biz_date, payload.point_id),
            }

        frozen = await self._is_frozen(
            payload.biz_date, payload.point_id)
        if frozen:
            raise BizError(55031, "该日期已封账，不接受新的资金事务")

        await self.db.execute(text("""
            INSERT INTO m16_daily_transaction
                (transaction_id, transaction_type, biz_date,
                 pay_method, biz_type, amount, direction,
                 dept_id, operator_id, point_id, occurred_at,
                 status, created_at)
            VALUES (:tid, :ttype, :bdate, :pm, :bt, :amt, :dir,
                    :dept, :op, :pt, :occ, 'SUCCESS', NOW())
        """), {
            "tid": payload.transaction_id,
            "ttype": payload.transaction_type,
            "bdate": payload.biz_date,
            "pm": payload.pay_method,
            "bt": payload.biz_type,
            "amt": payload.amount,
            "dir": payload.direction,
            "dept": payload.dept_id,
            "op": payload.operator_id,
            "pt": payload.point_id,
            "occ": payload.occurred_at,
        })
        await self.db.commit()
        return {
            "transaction_id": payload.transaction_id,
            "biz_date": payload.biz_date,
            "accepted": True,
            "is_idempotent": False,
            "frozen": False,
        }

    async def _is_frozen(self, biz_date: date,
                         point_id: Optional[int]) -> bool:
        if point_id:
            row = await self._get_by_key(biz_date, "POINT", point_id)
            if row and row.status == "FROZEN":
                return True
        row = await self._get_by_key(biz_date, "HOSPITAL", None)
        return bool(row and row.status == "FROZEN")

    async def _upsert(self, close_date: date, level: str,
                      scope_id: Optional[int],
                      m: dict) -> Any:
        row = await self._get_by_key(close_date, level, scope_id)
        if row is None:
            row = M16DailyClose(
                close_date=close_date, close_level=level,
                scope_id=scope_id,
                scope_name=await self._scope_name(level, scope_id),
                status="DRAFT", version=1,
                generated_at=datetime.now())
            self.db.add(row)
        self._apply_metrics(row, m)
        await self.db.commit()
        return row

    def _apply_metrics(self, row: Any, m: dict) -> None:
        row.total_income = m["total_income"]
        row.total_refund = m["total_refund"]
        row.net_income = m["net_income"]
        row.patient_count = m["patient_count"]
        row.by_pay_method = self._serialize(m["by_pay_method"])
        row.by_biz_type = self._serialize(m["by_biz_type"])
        row.by_point = self._serialize(m["by_point"])
        row.by_dept = self._serialize(m["by_dept"])
        row.cash_diff = self._serialize(m["cash_diff"])
        row.generated_at = datetime.now()

    @staticmethod
    def _serialize(items: Any) -> Any:
        if isinstance(items, dict):
            return {k: str(v) if isinstance(v, Decimal) else v
                    for k, v in items.items()}
        return [
            {k: (str(v) if isinstance(v, Decimal) else v)
             for k, v in it.items()} for it in items
        ]

    async def _snapshot(self, row: Any, reason: str,
                        user: Any) -> None:
        snap = M16DailyCloseSnapshot(
            close_id=row.id, close_date=row.close_date,
            close_level=row.close_level, scope_id=row.scope_id,
            version=row.version,
            payload=self._metrics_of(row),
            reason=reason, created_by=user.user_id,
            created_at=datetime.now())
        self.db.add(snap)

    def _metrics_of(self, row: Any) -> dict:
        return self._serialize({
            "total_income": money(row.total_income),
            "total_refund": money(row.total_refund),
            "net_income": money(row.net_income),
            "patient_count": row.patient_count or 0,
            "by_pay_method": self._json_list(row.by_pay_method),
            "by_biz_type": self._json_list(row.by_biz_type),
            "by_point": self._json_list(row.by_point),
            "by_dept": self._json_list(row.by_dept),
        })

    async def export(self, payload: Any, user: Any) -> dict:
        span = (payload.date_to - payload.date_from).days

    async def run(self, payload: Any, user: Any) -> dict:
        lock = "m16:daily:reconcile:lock"
        if not await redis_client.set(lock, "1", nx=True, ex=600):
            raise BizError(55036, "对账任务正在运行")

        try:
            channels = payload.channels or [
                "WECHAT", "ALIPAY", "UNIONPAY", "POS"]
            tasks = []
            for ch in channels:
                task = await self._sync_channel(payload.bill_date, ch)
                if task is None:
                    raise BizError(
                        55037, "渠道 %s 的账单缺失" % ch)
                tasks.append(task)
            diffs = await self._load_diffs(payload.bill_date, channels)
            total_diff = money(sum(
                money(d["amount_diff"]) for d in diffs))
            return {
                "bill_date": payload.bill_date,
                "channels": tasks,
                "diff_count": len(diffs),
                "diff_amount": total_diff,
                "status": "FINISHED",
            }
        finally:
            await redis_client.delete(lock)

    def _infer(self, row: Any) -> list:
        """根据差异类型与时间推断 Top 2 可能原因"""
        out = []
        if row.diff_type == "LOCAL_ONLY":
            if row.local_paid_at and row.local_paid_at.hour >= 23:
                out.append({
                    "probability": "HIGH",
                    "reason": "跨日到账：支付时间接近 24:00，渠道账单"
                              "若按 T+1 计入，应在次日账单中出现"})
            out.append({
                "probability": "MEDIUM",
                "reason": "渠道侧订单缺失，需联系渠道客服核查"})
        elif row.diff_type == "CHANNEL_ONLY":
            out.append({
                "probability": "HIGH",
                "reason": "系统漏记：存在支付成功但回调或查询未落库"})
            out.append({
                "probability": "MEDIUM",
                "reason": "渠道重复推送或账单重复计入"})
        elif row.diff_type == "AMOUNT_MISMATCH":
            out.append({
                "probability": "HIGH",
                "reason": "手续费未扣或重复扣减"})
            out.append({
                "probability": "MEDIUM",
                "reason": "部分退款导致金额不同步"})
        elif row.diff_type == "STATUS_MISMATCH":
            out.append({
                "probability": "HIGH",
                "reason": "本地已退款但渠道未处理完成"})
            out.append({
                "probability": "MEDIUM",
                "reason": "渠道侧订单关闭而本地仍为成功"})
        else:
            out.append({
                "probability": "MEDIUM",
                "reason": "费率变更未生效或商户号配置差异"})
        return out[:2]

    async def resolve(self, diff_id: int, payload: Any,
                      user: Any) -> dict:
        row = await self._get_diff_for_update(diff_id)
        if row.status in ("RESOLVED", "CLOSED"):
            raise BizError(55038, "该差异已结案")
        if payload.action not in RESOLVE_ACTIONS:
            raise BizError(55038, "处理动作非法")
        if len(payload.note or "") < 10:
            raise BizError(55042, "处理说明至少 10 字")

        amt = money(row.amount_diff)
        if payload.action == "SUPPLEMENT" and abs(amt) > Decimal("5000"):
            raise BizError(55039, "补单金额超 5000 元，需财务总监审批")
        if payload.action == "ADJUST" and not payload.attachment_ids:
            raise BizError(55040, "调账必须上传凭证")
        if payload.action == "IGNORE" and abs(amt) > Decimal("1"):
            raise BizError(55041, "单笔超过 1 元不允许直接忽略")

        old = row.status
        row.resolved_action = payload.action
        row.responsible_party = payload.responsible_party
        row.resolution_note = payload.note
        row.attachment_ids = payload.attachment_ids or []

        if payload.action == "WAIT":
            days = max(1, min(payload.wait_days or 1, 7))
            row.status = "PROCESSING"
            row.wait_until = datetime.now() + timedelta(days=days)
            resolved = False
        else:
            row.status = "RESOLVED"
            row.resolved_at = datetime.now()
            row.resolved_by = user.user_id
            resolved = True

        row.updated_at = datetime.now()
        await self.db.commit()

        logger.info(
            "reconcile diff resolved",
            extra={"diff_no": row.diff_no, "action": payload.action,
                   "amount": str(amt), "operator": user.user_id})
        return {
            "diff_id": row.id, "diff_no": row.diff_no,
            "old_status": old, "new_status": row.status,
            "action": payload.action,
            "wait_until": row.wait_until,
            "resolved": resolved,
        }

    async def escalate(self, diff_id: int, reason: str,

        if row.status == "ESCALATED":

        await self.db.commit()
        return self._diff_dict(row)

-- 统一资金流水视图：把五个子模块的流水拍平成统一形态
CREATE OR REPLACE VIEW v_m16_daily_flow AS
-- 门诊收费（M16-02）与支付流水（M16-05）
SELECT
    p.payment_no              AS transaction_id,
    'PAYMENT'                 AS transaction_type,
    p.paid_at                 AS occurred_at,
    p.patient_id, p.patient_name,
    p.pay_method, p.pay_method_name,
    COALESCE(s.biz_type, 'OTHER') AS biz_type,
    p.pay_amount              AS amount,
    'IN'                      AS direction,
    p.cashier_id              AS operator_id,
    p.cashier_name            AS operator_name,
    p.cashier_session_id      AS shift_id,
    COALESCE(s.exec_point_id, p.workstation_id) AS point_id,
    s.exec_dept_id            AS dept_id,
    p.status
  FROM m16_payment p
  LEFT JOIN LATERAL (
      SELECT si.biz_type, si.exec_dept_id, si.exec_point_id
        FROM m16_settlement s2
        JOIN m16_settlement_item si ON si.settlement_id = s2.id
       WHERE s2.id = ANY (
           SELECT jsonb_array_elements_text(p.settlement_ids)::bigint)
       LIMIT 1
  ) s ON TRUE
 WHERE p.status = 'SUCCESS'

UNION ALL
-- 退费（M16-08）：direction = OUT
SELECT
    r.refund_no               AS transaction_id,
    'REFUND'                  AS transaction_type,
    r.completed_at            AS occurred_at,
    r.patient_id, r.patient_name,
    r.pay_channel             AS pay_method,
    r.pay_channel             AS pay_method_name,
    'REFUND'                  AS biz_type,
    r.actual_refund_amount    AS amount,
    'OUT'                     AS direction,
    r.created_by              AS operator_id,
    r.created_by_name         AS operator_name,
    r.cashier_session_id      AS shift_id,
    NULL::bigint              AS point_id,
    NULL::bigint              AS dept_id,
    'SUCCESS'                 AS status
  FROM m16_refund_order r
 WHERE r.status = 'SUCCESS'

UNION ALL
-- 住院预交金（M16-03）
SELECT
    d.deposit_no, 'DEPOSIT', d.created_at,
    d.patient_id, d.patient_name,
    d.pay_method, d.pay_method_name,
    'INPATIENT_DEPOSIT', d.amount,
    CASE WHEN d.type = 'REFUND' THEN 'OUT' ELSE 'IN' END,
    d.operator_id, d.operator_name,
    NULL::bigint, NULL::bigint, NULL::bigint,
    'SUCCESS'
  FROM m16_deposit d
 WHERE d.status = 'SUCCESS'

UNION ALL
-- 视光销售（M16-04）
SELECT
    o.payment_no, 'OPTICAL_PAY', o.paid_at,
    o.patient_id, o.customer_name,
    o.payment_method, o.payment_method,
    'OPTICAL_SALE', o.amount,
    CASE WHEN o.amount < 0 THEN 'OUT' ELSE 'IN' END,
    o.cashier_id, o.cashier_name,
    NULL::bigint, NULL::bigint, NULL::bigint,
    'SUCCESS'
  FROM m16_optical_payment o
 WHERE o.status = 'SUCCESS';

COMMENT ON VIEW v_m16_daily_flow
    IS 'M16-09 统一资金流水视图：五个子模块收支拍平，日结唯一数据源';

-- 班次流水视图
CREATE OR REPLACE VIEW v_m16_shift_flow AS
SELECT shift_id, transaction_id, occurred_at, pay_method,
       pay_method_name, biz_type, amount, direction, status
  FROM v_m16_daily_flow
 WHERE shift_id IS NOT NULL;

COMMENT ON VIEW v_m16_shift_flow
    IS 'M16-09 班次流水视图：交班汇总用';
```

**视图设计的三个要点：**

1. **`direction` 统一**：所有收入为 `IN`，所有支出为 `OUT`。这比在各处判断「是收款还是退款」更不容易出错。
2. **`biz_type` 统一**：门诊收费的 `biz_type` 来自结算单明细，退费固定为 `REFUND`，住院固定为 `INPATIENT_DEPOSIT`。日结按这个字段分组。
3. **`point_id` / `dept_id` 可空**：某些流水（如视光现货销售）可能没有就诊科室。这些收入在科室日结里归入 `dept_id = 0` 的「其他」科目。这保证了「科室合计 = 全院合计」恒成立。

## 7. 缓存与异步任务设计

### 7.1 Redis 缓存

| Key 模式 | 类型 | TTL | 说明 |
|---|---|---|---|
| `m16:daily:config` | Hash | 600s | 参数缓存 |
| `m16:daily:close:{date}:{level}:{scope}` | String | 60s | 日结详情缓存 |
| `m16:daily:close:lock:{date}:{level}:{scope}` | String | 300s | 日结生成锁 |
| `m16:daily:reconcile:lock` | String | 600s | 对账任务锁 |
| `m16:daily:shift:cur:{op}:{ws}` | String | 60s | 当前班次汇总 |
| `m16:daily:freeze:check:{date}:{level}` | String | 120s | 封账前置检查缓存 |
| `m16:daily:stat:{date}` | String | 1800s | 统计缓存 |
| `m16:daily:export:{task_id}` | String | 86400s | 导出任务进度 |
| `m16:daily:short_over` | ZSet | — | 短款超阈值待办（score=时间戳） |

**容量估算**

| Key 模式 | 数量 | 单条大小 | 合计 |
|---|---|---|---|
| config | 1 | 6 KB | 6 KB |
| close 详情 | ≤ 500 | 8 KB | 4 MB |
| close 生成锁 | ≤ 30 | 100 B | 3 KB |
| reconcile 锁 | 1 | 60 B | 60 B |
| shift 当前 | ≤ 100 | 4 KB | 400 KB |
| freeze check | ≤ 30 | 2 KB | 60 KB |
| stat | 90 | 3 KB | 270 KB |
| export | ≤ 50 | 300 B | 15 KB |
| short_over | ≤ 500 | 60 B | 30 KB |
| **合计** | | | **约 4.8 MB** |

**日结详情缓存的失效策略**

日结详情一旦被缓存，任何底层数据变化都可能让缓存过期。失效触发点：

| 事件 | 失效范围 |
|---|---|
| 日结重算 | 该日结 + 上级日结 |
| 封账/解封 | 该日结 |
| 差异结案 | 该日记账 + 全院 |
| 班次审核完成 | 该收费点日结 + 全院 |
| 资金事务回调 | 该日结 |

缓存 TTL 只有 60 秒，即使漏了某个失效点，最多 60 秒后自愈。

| `job_m16_daily_wait_retry` | `0 */2 * * *` | 每 2 小时重试等待中的差异 |
| `job_m16_daily_remind_shift` | `0 21 * * *` | 每日 21:00 提醒未交班 |
| `job_m16_daily_cleanup` | `0 4 * * *` | 每日 04:00 清理缓存 |
| `job_m16_daily_warmup` | `0 7 * * *` | 每日 07:00 预热前一日结缓存 |

**调度顺序的必要性：**

```
00:30  生成日结 ──┐
                   ├── 依赖：M16-02 班次已关、M16-05 支付已定稿
02:30  全站对账 ──┘   依赖：M16-05 单渠道对账已完成（02:00）
07:00  预热缓存        依赖：日结数据已就绪
08:00  异常检查        依赖：财务上班前推送到位
21:00  交班提醒        依赖：营业结束前提醒
```

M16-05 的 `auto_reconcile_task` 在 02:00 运行，M16-09 的 `reconcile_all_task` 在 02:30 运行，中间留 30 分钟给 M16-05 完成。若 M16-05 超时，M16-09 的 `reconcile_all_task` 会把缺失渠道记录到日志，并只生成现金对账部分的日结。

**R-02 的实现方式**

```sql
-- 工作站级唯一：一个工作站同时只能有一个 OPEN 班次
CREATE UNIQUE INDEX uk_m16_shift_ws_open
    ON m16_shift_close (workstation_id)
 WHERE status IN ('OPEN', 'REJECTED') AND is_deleted = FALSE;
```

用部分唯一索引而非应用层校验，是因为应用层的「先查后插」在并发下必然漏。两台收银机同时开着，同一个工作站被同时开班时，数据库会直接拒绝第二个。

### 8.2 日结规则

| 编号 | 规则 | 错误码 | 级别 |
|---|---|---|---|
| R-20 | 不能对今日或未来日期日结 | 55024 | 阻断 |
| R-21 | 日结状态只能按状态机流转 | 55024 | 阻断 |
| R-22 | 已封账不可重算 | 55032 | 阻断 |
| R-23 | 提交前交叉校验必须通过 | 55027 | 阻断 |
| R-24 | 存在未关闭班次不允许提交 | 55025 | 阻断 |
| R-25 | 重算必须填原因 ≥ 10 字 | 55024 | 阻断 |
| R-26 | 重算必须留快照 | 55024 | 强制 |
| R-27 | 重算级联上级日结 | — | 强制 |
| R-28 | 已 CONFIRMED 的日结重算需降级为 DRAFT | 55024 | 阻断 |

**R-27 级联规则**

重算某个日结时，所有依赖它的上级日结也必须重算，否则会出现「科室说收了 8 万，全院说收了 8 万零 5 块」这种自相矛盾。

```
重算 POINT  → 重算 DEPT → 重算 HOSPITAL
重算 DEPT   → 重算 HOSPITAL
重算 HOSPITAL → 无需级联
```

级联遇到 `FROZEN` 的上级时跳过并记日志——因为上级已封账意味着更大的范围已经定稿，下级的变化应该走「申请解封上级」流程，而不是自动改。

### 8.3 封账规则

| 编号 | 规则 | 错误码 | 级别 |
|---|---|---|---|
| R-30 | 封账前 6 项检查必须全部通过 | 55024~55028 | 阻断 |
| R-31 | 有未结差异可强制封账但需总监权限 | 55029 | 阻断 |
| R-32 | 封账说明 ≥ 10 字 | 55030 | 阻断 |
| R-33 | 解封需填原因 ≥ 20 字 | 55033 | 阻断 |
| R-34 | 解封需财务总监审批 | 55034 | 阻断 |
| R-35 | 所属会计期间已关账不可解封 | 55035 | 阻断 |
| R-36 | 解封超过 2 次触发审计标记 | — | 警告 |
| R-37 | 封账后当日资金事务回调被拒绝 | 55031 | 阻断 |

**R-37 的意义**

封账之后如果还允许写入流水，日结数字就不再代表「封账时刻的真实情况」。这条规则让封账成为一个真正的时间断点：

```python
async def _is_frozen(biz_date, point_id) -> bool:
    # 任一上级封账则视为已封
    point = await self._get_by_key(biz_date, "POINT", point_id)
    if point and point.status == "FROZEN":
        return True
    hospital = await self._get_by_key(biz_date, "HOSPITAL", None)
    return bool(hospital and hospital.status == "FROZEN")
```

注意判断顺序：先查细粒度（收费点），再查粗粒度（全院）。任一为 FROZEN 都算已封。

**R-62 是日结最核心的自检**

```python
if row.close_level == "HOSPITAL":
    s_pt = sum(income - refund for p in by_point)
    s_dept = sum(amount for d in by_dept)
    ok = (s_pt == s_dept == net_income)
```

这三个数必须完全相等（不是「接近」）。因为：

- 每个流水必然属于某个收费点（`point_id` 可空但有默认值）
- 每个流水必然属于某个科室（`dept_id` 可空但归 0）
- 每个流水必然属于某种支付方式
- 三个维度切的是同一批流水，只是分组方式不同

只要三者不等，说明有一批流水在某个维度上「消失了」——多半是视图的 JOIN 丢了行（比如 `LEFT JOIN LATERAL` 没兜住）。这个检查每天跑一次，等于给视图做了一次完整性体检。

**R-65 为什么按退费完成日计入**

患者 10-21 交了 320 元检查费，10-25 才来退。这笔钱：

- 收款计入 10-21（那时钱进账）
- 退款计入 10-25（那时钱出账）

如果退款回写到 10-21，10-21 的日结就要改，而 10-21 可能早已封账。财务的通用做法是「资金日报按资金实际发生日」，这样每个日结一旦封账就永久成立。

**S-07 的实现**

```python
# 错误做法：信任前端传来的 actual_cash
# total = payload.actual_cash

# 正确做法：由分面额重新计算，再与申报值比对
total = ZERO
for item in payload.denominations:
    total = money(total + money(item.face_value * item.count))
declared = money(payload.actual_cash)
if declared != total:
    raise BizError(55049, "分面额合计与申报金额不一致")
```

前端可以同时传 `denominations` 和 `actual_cash`，后端只用 `denominations` 算，`actual_cash` 只用于一致性校验。这样即使有人篡改请求，也只能改出「不一致」而不能改出「一个假的正确值」。

**重算的防抖**

一次批量收费会发出几十个 `m16.payment.success`，如果每条都触发重算，数据库会被打爆。所以用 Redis 做防抖：

```python
async def on_payment_success(event: dict) -> None:
    key = "m16:daily:recalc:pending:%s" % event["biz_date"]
    await redis_client.sadd(key, event["transaction_id"])
    await redis_client.expire(key, 300)
    # 延迟 60 秒后统一重算（Celery countdown）
    recalc_pending_task.apply_async(
        args=[event["biz_date"]], countdown=60)
```

60 秒内的所有事件合并成一次重算。

**并发冲突的重试策略**

```python
import asyncio

async def with_lock_retry(fn, max_retry=3):
    for i in range(max_retry):
        try:
            return await fn()
        except OperationalError as exc:
            if "could not obtain lock" not in str(exc):
                raise
            if i == max_retry - 1:
                raise BizError(55018, "操作繁忙，请稍后重试")
            await asyncio.sleep(0.2 * (i + 1))
    raise BizError(55018, "操作繁忙，请稍后重试")
```

| 账实核对 | Cash Verification | 系统记录与实际点钞比对 |
| 账账核对 | Reconciliation | 系统流水与外部账单比对 |
| 长款 | Over | 实际现金多于应有 |
| 短款 | Short | 实际现金少于应有 |
| 备用金 | Opening Float | 开班时钱箱里的起始现金 |
| 差异 | Diff | 两个来源之间的不一致 |
| 补单 | Supplement | 系统漏记时补录一条支付 |
| 调账 | Adjust | 通过凭证调整账面数字 |
| 跨日到账 | Cross-day Settlement | 23:59 支付、次日到账 |
| 交叉校验 | Cross Check | 多维度汇总结果互相验证 |
