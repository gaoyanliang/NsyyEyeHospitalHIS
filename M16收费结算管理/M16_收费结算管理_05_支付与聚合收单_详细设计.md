## 1. 模块概述

### 1.1 模块定位

支付与聚合收单回答的问题：

> **患者掏出来的钱，怎么安全地变成医院账上的"已收"。**

它不是收银界面（那是 M16-02），而是**渠道适配层 + 状态机 + 对账数据源**：

```
┌───────────────────────────────────────────────────────────────────────────┐
│                         M16-05 在系统中位置                                 │
│                                                                             │
│   M16-02 收银台      M03-06 自助机      M16-04 视光        M16-03 住院       │
│   （点了"扫码支付"）  （患者自己扫）      （定金/尾款）       （预交金）        │
│        │                  │                 │                 │            │
│        └──────────────────┴────────┬────────┴─────────────────┘            │
│                                    ▼                                        │
│                    ┌────────────────────────────────┐                       │

│                    │  │ ② 渠道适配（微信/支付宝…）  │  │                       │
```

### 1.2 为什么支付必须独立成子模块

| 方案 | 问题 |
|---|---|
| 在 M16-02 收银台里直接调微信 | 自助机（M03-06）、公众号、视光、住院四个入口都要重写一遍对接逻辑，四份代码四套 BUG |
| 把支付流水和收银流水合成一张表 | 收银有班次（谁收的钱），支付有渠道（钱从哪来）；合表后自助缴费（无班次）与窗口缴费混在一起，班次对不平 |
| 支付成功直接置结算单 PAID | 丢回调时钱到了但账没记；重复回调时账记两次。必须有独立的状态机与幂等层做缓冲 |

**独立的价值：**

1. **渠道无关的统一抽象**——上游只说"收 399 元，扫码"，不知道是微信还是支付宝
2. **回调幂等是刚需**——微信最多重试 8 次（4m/10m/10m/1h/2h/6h/15h），支付宝重试 25 小时，没有幂等就会重复入账
3. **主动查询是兜底**——回调可能永远不来（网络、医院内网、证书换），必须能主动查
4. **退款通道独立**——退款比收款更容易失败（余额不足、超过可退期），需要独立重试队列
5. **对账数据源**——渠道账单与本地流水必须能逐笔勾对，差异要能定位

### 1.4 概念辨析：支付单 / 渠道单 / 结算单 / 退款单

| 概念 | 定义 | 谁创建 | 生命周期 |
|---|---|---|---|
| **结算单**（Settlement） | 患者"应该付多少" | M16-01 | `UNPAID → PAID → PART_REFUNDED / REFUNDED` |
| **支付单**（Payment） | 患者"这一次付了多少、用什么付" | **M16-05** | `CREATED → PAYING → SUCCESS / FAILED / CLOSED / EXPIRED` |
| **渠道单**（Channel Order） | 渠道那边认的订单 | **M16-05** 向渠道申请 | 渠道侧状态，本地只存快照 |
| **交易号**（Transaction No） | 渠道认的"钱到账了"的唯一凭证 | 渠道返回 | 不可变 |
| **退款单**（Refund） | 退多少、退到哪 | M16-08 发起，M16-05 执行 | `CREATED → PROCESSING → SUCCESS / FAILED / ABNORMAL` |

```
结算单 BL20261021001  ¥399.00  （应该付）
     │
     ├── 支付单 PAY20261021001  ¥399.00  微信
     │       └── 渠道单 wx042000123420261021xxxx  微信侧
     │               └── 交易号 4200001234202610211234567890  （钱到了）
     │
     └── 退款单 RF20261021001  ¥152.00 （部分退）
             └── 渠道退款单 503000123420261022xxxx
```

**关键区别：支付单可能有多张对应一张结算单。**

```
结算单 ¥399
   ├── 支付单 1  ¥200  微信   ← 患者先付 200
   ├── 支付单 2  ¥199  现金   ← 再付 199（混合）
   └── 两张都成功 → 结算单才 PAID
```

## 3. 业务模型

### 3.1 支付单状态机

```
                        ┌──────────┐
             创建支付单  │ CREATED  │  已生成，未向渠道下单
                        └────┬─────┘
                             │ 向渠道下单成功
                             ▼
                        ┌──────────┐
                        │  PAYING  │  等待用户付款
                        └──┬────┬──┘
              渠道回调成功  │    │  渠道回调失败/用户取消
                           ▼    ▼
                      ┌─────────┐ ┌────────┐
                      │ SUCCESS │ │ FAILED │
                      └────┬────┘ └────────┘
                           │ 超时未支付
                           ▼
                      ┌─────────┐
                      │ EXPIRED │
                      └─────────┘

              任意未成功状态 ──关单──► CLOSED
```

**状态定义：**

| 状态 | 含义 | 是否可以再变更 | 触发方 |
|---|---|---|---|
| `CREATED` | 支付单已建，未调渠道 | 可以 | M16-05 内部 |
| `PAYING` | 已向渠道下单，拿到二维码/交易号 | 可以（等结果） | M16-05 内部 |
| `SUCCESS` | 渠道确认收到钱 | **不可逆** | 渠道回调 / 主动查询 |
| `FAILED` | 渠道明确失败（余额不足、银行卡拒绝） | 不可逆 | 渠道回调 / 主动查询 |
| `EXPIRED` | 超时未支付（默认 120 秒） | 不可逆 | 定时任务 |
| `CLOSED` | 人工或系统关闭 | 不可逆 | 关单接口 |
| `UNKNOWN` | 超时后仍不知结果（单边账） | **可以转 SUCCESS** | 定时任务标记，人工或自动查询出口 |

> **`UNKNOWN` 是必要的状态。** 真实场景里存在"渠道扣钱了但我们没收到回调、主动查询也超时"的窗口。这时候既不能判失败（钱可能已经收了），也不能判成功（没凭证）。`UNKNOWN` 让这笔钱进入人工/对账流程，而不是被草率地标成任何一边。

> **铁律：`SUCCESS` 是终态，任何操作都不能把它改回非成功。** 钱已经到账，改状态只会制造账实不符。

### 3.2 支付结果四问

每一次支付结果判定，都要回答四个问题：

```
① 这笔钱到了吗？           → 决定 SUCCESS / FAILED / UNKNOWN
② 这是同一个支付单吗？      → 幂等（payment_no 唯一 + 状态比对）
③ 这个交易号用过了吗？      → 防重复入账（transaction_no 全局唯一）
④ 结算单该置成什么状态？    → 调 M16-01（它决定是否 PAID）
```

**四问的具体实现：**

| 问 | 手段 | 失败后果 |
|---|---|---|
| ① 钱到了吗 | 渠道签名验签 + `trade_state` 字段 | 假回调导致虚假入账 |
| ② 同一支付单吗 | `payment_no` 唯一索引 + `SELECT FOR UPDATE` | 重复回调重复记账 |
| ③ 交易号用过吗 | `uk_m16_payment_txn` 部分唯一索引 | 一笔交易记两次 |
| ④ 结算单状态 | 调 M16-01 `on-paid`，由它判断是否付清 | 部分支付被误判为已付清 |

### 3.3 渠道抽象模型

**所有渠道统一成 6 个动作：**

| 动作 | 微信 | 支付宝 | 云闪付 | POS | 储值 | 统一接口 |
|---|---|---|---|---|---|---|
| 下单 | `/v3/pay/transactions/native` | `alipay.trade.precreate` | `/v1/netpay/qrcode` | POS 前置下单 | M03 扣款 | `pay()` |
| 查询 | `/v3/pay/transactions/out-trade-no/{no}` | `alipay.trade.query` | `/v1/netpay/query` | POS 查询 | M03 查流水 | `query()` |
| 关单 | `/v3/pay/transactions/out-trade-no/{no}/close` | `alipay.trade.close` | `/v1/netpay/void` | POS 撤销 | M03 冲正 | `close()` |
| 退款 | `/v3/refund/domestic/refunds` | `alipay.trade.refund` | `/v1/netpay/refund` | POS 退货 | M03 退还 | `refund()` |
| 退款查询 | `/v3/refund/domestic/refunds/{no}` | `alipay.trade.fastpay.refund.query` | `/v1/netpay/refund-query` | POS 查询 | M03 查流水 | `refund_query()` |
| 对账 | `/v3/bill/tradebill` | `alipay.data.dataservice.bill.downloadurl.query` | 商户平台下载 | POS 日结单 | M03 流水导出 | `download_bill()` |

**渠道适配器基类：**

```python

    每个渠道实现 6 个动作，上层只依赖这个接口。

    channel_code: str = ""          # WECHAT / ALIPAY / UNIONPAY / POS / STORED

        """向渠道下单，返回二维码/交易号/过期时间"""
        raise NotImplementedError

    async def query(self, order: PaymentOrder) -> QueryResult:
        """主动查询支付状态"""
        raise NotImplementedError

    async def close(self, order: PaymentOrder) -> bool:
        """关闭渠道订单"""
        raise NotImplementedError

    async def refund(self, refund: RefundOrder) -> RefundResult:
        """发起退款"""
        raise NotImplementedError

    async def refund_query(self, refund: RefundOrder) -> RefundResult:
        """查询退款"""
        raise NotImplementedError

    async def download_bill(self, bill_date: date) -> str:
        """下载对账文件，返回本地路径"""
        raise NotImplementedError
```

### 3.4 幂等模型

**三层幂等，任何一层命中都直接返回成功。**

```
第 1 层：Redis 幂等键（快，防并发）
    key = m16:pay:idem:{idempotency_key}
    value = payment_no
    TTL = 86400s

第 2 层：数据库唯一索引（准，防重复落库）
    uk_m16_payment_no      ON (payment_no)
    uk_m16_payment_txn     ON (transaction_no) WHERE NOT NULL
    uk_m16_payment_req     ON (channel_code, out_trade_no)

第 3 层：业务状态比对（稳，防重复副作用）
    支付单已是 SUCCESS 且金额一致 → 不再调 M16-01
```

**幂等键的生成规则：**

| 场景 | 幂等键 |
|---|---|
| 收银台扫码 | `CASHIER:{cashier_id}:{settlement_nos_hash}:{amount}` |
| 自助机 | `SELF:{device_id}:{settlement_nos_hash}:{amount}` |
| 视光 | `OPTICAL:{order_no}:{stage}` |
| 住院预交金 | `INPATIENT:{admission_id}:{stage}:{amount}` |
| 退款 | `REFUND:{refund_no}` |

> **注意：** 幂等键不能只用"结算单号"，因为一张结算单可能被分两次付（混合支付）。必须带金额与来源，否则第二次支付会被误判为重复。

### 3.5 回调安全模型

```
     微信服务器                医院网关                 M16-05
         │                       │                       │
         │ ① POST 回调报文        │                       │
         ├──────────────────────►│                       │
         │                       │ ② IP 白名单校验         │
         │                       │ ③ 报文大小限制(1MB)     │
         │                       ├──────────────────────►│
         │                       │                       │ ④ 验签
         │                       │                       │    (平台证书/APIv3key)
         │                       │                       │ ⑤ 解密 resource
         │                       │                       │ ⑥ 幂等检查
         │                       │                       │ ⑦ 更新状态
         │                       │                       │ ⑧ 回调 M16-01
         │                       │◄──────────────────────┤
         │◄── ⑨ {"code":"SUCCESS"} ──────────────────────┤
```

**回调必须做到 7 件事：**

| # | 动作 | 说明 |
|---|---|---|
| 1 | IP 白名单 | 微信/支付宝官方 IP 段，防止伪造源 |
| 2 | 报文限流 | 单 IP 500 QPS，防打挂 |
| 3 | 验签 | 微信 APIv3 用平台证书验 `Wechatpay-Signature`；支付宝用 RSA2 |
| 4 | 解密 | 微信回调用 APIv3 密钥 AES-GCM 解密 `resource` |
| 5 | 幂等 | 见 3.4 |
| 6 | 状态机 | 只允许合法流转（见 3.1） |
| 7 | 幂等应答 | 处理成功必须返回渠道要求的成功应答，否则渠道会重试 |

**渠道重试策略（决定了幂等的重要性）：**

| 渠道 | 重试 | 间隔 |
|---|---|---|
| 微信支付 | ≤ 8 次 | 4m / 10m / 10m / 1h / 2h / 6h / 15h |
| 支付宝 | 25 小时 | 4m / 10m / 10m / 1h / 2h / 6h / 15h（共 7 次） |
| 云闪付 | 5 次 | 5m / 15m / 30m / 1h / 2h |

### 3.6 主动查询补偿模型

**回调是"推"，查询是"拉"。真实系统必须两者都有。**

```
每 30 秒扫描一次：
  status IN ('PAYING', 'UNKNOWN')
  AND created_at <= NOW() - INTERVAL '60 秒'
  AND retry_count < 10
        │
        ▼
  调渠道 query()
        │
        ├── SUCCESS → 更新状态 → 回调 M16-01
        ├── FAILED  → 更新状态
        ├── PAYING  → 不做处理，retry_count + 1
        └── 超过 10 次仍 PAYING → 标记 UNKNOWN，进人工队列
```

**查询退避：**

| 次数 | 间隔 |
|---|---|
| 1~5 | 60 秒 |
| 6~10 | 5 分钟 |
| 11+ | 停止自动查询，进人工 |

### 3.7 退款模型

```
     M16-08 发起退款
           │
           ▼
    ┌──────────────┐
    │ CREATED      │  退款单已建
    └──────┬───────┘
           │ 调渠道 refund()
           ▼
    ┌──────────────┐
    │ PROCESSING   │  渠道已受理（微信返回 PROCESSING）
    └──┬────────┬──┘
       │        │
   成功│        │失败
       ▼        ▼
 ┌─────────┐ ┌──────────┐
 │ SUCCESS │ │  FAILED  │
 └─────────┘ └────┬─────┘
                  │ 余额不足/超期
                  ▼
            ┌──────────┐
            │ ABNORMAL │  退款异常，转人工
            └──────────┘
```

**退款渠道选择（`refund_method`）：**

| 值 | 含义 | 适用 |
|---|---|---|
| `ORIGINAL` | 原路退回（推荐） | 微信/支付宝/云闪付/银行卡 |
| `CASH` | 现金退 | 储值、或原渠道超过可退期 |
| `STORED` | 退到会员储值 | 患者同意 |
| `ANY` | 任选 | 由操作员决定 |

**退款约束：**

| 约束 | 说明 |
|---|---|
| 可退金额 | `settlement.paid_amount - sum(已成功退款)` |
| 退款期限 | 微信 1 年、支付宝 1 年、银行卡 180 天（超期只能现金） |
| 部分退款 | 微信支持多次部分退（累计不超总额） |
| 退款到账 | 微信实时到账；银行卡 T+1~T+7 |
| 退款失败重试 | 自动 3 次，间隔 1m/5m/15m，之后转人工 |

### 3.8 对账模型

**三方对账：** 渠道账单 ↔ 本地支付流水 ↔ 结算单。

```
 渠道账单（微信下发的 CSV/API）
     │ 每行：交易号、商户单号、金额、状态、时间
     │
     ▼ 逐笔比对（按 transaction_no 或 out_trade_no）
 ┌────────────────────────────────────────────────────┐
 │ ① 渠道有、本地无       → 长款（医院多收）  ❗严重    │
 │ ② 本地有、渠道无       → 短款（医院少收）  ❗严重    │
 │ ③ 双有，金额不同       → 金额不符          ❗严重    │
 │ ④ 双有，状态不同       → 状态不符          ⚠️严重   │
 │ ⑤ 双有，完全一致       → 平账（成功）              │
 └────────────────────────────────────────────────────┘
     │
     ▼ 差异写 m16_reconcile_diff
     │
     ▼ M16-09 汇总日结
```

**差异类型与处理：**

| 类型 | 代码 | 含义 | 处理 |
|---|---|---|---|
| 长款 | `CHANNEL_ONLY` | 渠道账单有、本地无 | 排查是否其他系统收款；确认后手工补录 |
| 短款 | `LOCAL_ONLY` | 本地有、渠道无 | 排查假成功；确认后冲正 |
| 金额不符 | `AMOUNT_MISMATCH` | 双有但金额不同 | 一般是对账文件解析错误，需人工核对 |
| 状态不符 | `STATUS_MISMATCH` | 本地 SUCCESS 渠道失败，或反之 | 严重，需立即处理 |
| 手续费不符 | `FEE_MISMATCH` | 手续费与费率算的不一致 | 进 M16-09 费用核算 |

> **对账文件格式差异极大：** 微信是 CSV+GZIP，支付宝是 ZIP+CSV+CSV 汇总，云闪付是 XML，POS 是银行定制的 TXT。所以对账必须有**按渠道可配置的列映射**，不能写死。

### 3.9 单边账与人工处理

**单边账 = 钱动了但一边没记录。** 真实业务里无法完全避免，只能发现 + 收敛。

**三类单边账：**

| 类型 | 现象 | 典型原因 | 处理 |
|---|---|---|---|
| 钱到账、账未记 | 渠道有交易，本地 UNKNOWN | 回调丢失 + 主动查询全超时 | 对账发现 → 人工补单（补录支付单并回写结算单） |
| 账记了、钱没到 | 本地 SUCCESS，渠道无 | 假回调 / 测试数据混入 | 对账发现 → 人工冲正（撤销支付单并回滚结算单） |
| 钱退多了 | 退款合计 > 收款 | 并发退款 | 数据库约束 + 业务校验双重拦截，发现即告警 |

**人工处理入口：** P05 支付异常处理页面，所有操作留痕。

### 6.5 Service 层核心逻辑

```python
# app/services/m16/pay_service.py
"""支付服务：下单 / 查单 / 关单 / 回调 / 补单"""
import hashlib
import json
from datetime import datetime, timedelta
from decimal import Decimal, ROUND_HALF_UP
from typing import Optional

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from app.channels.registry import get_adapter
from app.core.exceptions import BizException
from app.core.redis import redis_client
from app.models.m16.pay import (
    M16Payment, M16PaymentTrace, M16PayChannel,
)
from app.services.m16.settlement_client import SettlementClient


CENT = Decimal("0.01")
IDEM_TTL = 86400
MAX_QUERY_RETRY = 10
DEFAULT_EXPIRE = 120
CASH_CHANNEL = "CASH"
STORED_CHANNEL = "STORED"


def money(value) -> Decimal:
    return Decimal(str(value)).quantize(CENT, rounding=ROUND_HALF_UP)


class PayService:
    """支付单全生命周期"""

    def __init__(self, db: AsyncSession):
        self.db = db
        self.settle = SettlementClient()

    # ---------- 下单 ----------
    async def create(self, payload, user, trace_id: str = "") -> dict:
        """创建支付单并下单

        流程：
          ① 幂等检查（Redis → DB）
          ② 取渠道配置
          ③ 校验金额与结算单
          ④ 建支付单（CREATED）
          ⑤ 渠道下单
          ⑥ 更新为 PAYING
        """
        idem_key = payload.idempotency_key
        redis_key = f"m16:pay:idem:{idem_key}"

        # ① 幂等：Redis 快查
        cached = await redis_client.get(redis_key)

        if cached:
            return await self._idempotent_result(cached, payload)

        # ① 幂等：数据库兜底
        existing = await self._find_by_idem(idem_key)

        if existing:
            await redis_client.setex(redis_key, IDEM_TTL, existing.payment_no)
            return await self._idempotent_result(
                existing.payment_no, payload)

        # ② 渠道
        channel = await self._get_channel(payload.channel_code)

        if not channel or not channel.is_enabled:
            raise BizException(
                "1605003", f"支付渠道 {payload.channel_code} 未启用")

        # ③ 金额校验
        amount = money(payload.amount)

        if amount <= 0:
            raise BizException(40001, "支付金额必须大于 0")

        if payload.settlement_nos:
            await self._verify_settlement(
                payload.settlement_nos, amount)

        # ④ 建支付单
        payment_no = await self._next_payment_no()
        out_trade_no = f"HIS-{payment_no}"
        expire_at = datetime.now() + timedelta(
            seconds=payload.expire_seconds or DEFAULT_EXPIRE)

        payment = M16Payment(
            payment_no=payment_no,
            settlement_ids=payload.settlement_ids or [],
            settlement_nos=payload.settlement_nos or [],
            patient_id=payload.patient_id,
            patient_name=payload.patient_name,
            pay_method=payload.channel_code,
            pay_method_name=channel.channel_name,
            pay_category=channel.pay_category,
            pay_amount=amount,
            received_amount=amount,
            change_amount=Decimal("0.00"),
            status="CREATED",
            source_channel=payload.source_channel or "CASHIER",
            channel_code=payload.channel_code,
            channel_order_no=out_trade_no,
            idempotency_key=idem_key,
            cashier_id=user.staff_id if user else None,
            cashier_name=user.real_name if user else None,
            cashier_session_id=(payload.cashier_session_id
                                if payload.source_channel in
                                ("CASHIER", "REGISTRATION") else None),
            workstation_id=payload.workstation_id,
            expire_at=expire_at,
            trace_id=trace_id,
        )
        self.db.add(payment)
        await self.db.flush()

        # ⑤ 渠道下单
        if payload.channel_code == STORED_CHANNEL:
            result = await self._pay_by_stored(payment, payload, user,
                                               trace_id)
        elif payload.channel_code == CASH_CHANNEL:
            result = {"status": "SUCCESS", "transaction_no": None,
                      "paid_at": datetime.now()}
        else:
            adapter = get_adapter(payload.channel_code)
            order = {
                "out_trade_no": out_trade_no,
                "amount": amount,
                "description": payload.description or "医疗服务费",
                "expire_at": expire_at,
                "pay_scene": payload.pay_scene or "NATIVE",
                "patient_id": payload.patient_id,
            }

            try:
                result = await adapter.pay(order)
            except Exception as exc:
                payment.status = "FAILED"
                payment.fail_code = "CHANNEL_ERROR"
                payment.fail_reason = str(exc)[:500]
                await self._trace(payment, "pay", "ERROR", str(exc))
                await self.db.flush()
                raise BizException(
                    "1605021", f"渠道调用失败：{str(exc)[:80]}") from exc

        await self._trace(payment, "pay", "SUCCESS",
                          json.dumps(result, ensure_ascii=False,
                                     default=str))

        # ⑥ 状态推进
        if result.get("status") == "SUCCESS":
            await self._mark_success(payment, result, user, trace_id)
        elif result.get("status") == "PAYING":
            payment.status = "PAYING"
            payment.qr_code_url = result.get("qr_code_url")
            payment.qr_token = result.get("qr_token")
            payment.transaction_no = result.get("transaction_no")
        else:
            payment.status = "FAILED"
            payment.fail_code = result.get("fail_code")
            payment.fail_reason = result.get("fail_reason")

        await self.db.flush()

        # 写幂等键
        await redis_client.setex(redis_key, IDEM_TTL, payment_no)

        return self._dict(payment)

            select(M16Payment).where(M16Payment.payment_no == payment_no)

        if not payment:
            raise BizException("1605023", f"支付单 {payment_no} 不存在")

        if money(payment.pay_amount) != money(payload.amount):
            raise BizException(
                "1605005",
                f"幂等键冲突，已存在不同参数的支付单 {payment_no}")

        data = self._dict(payment)
        data["is_idempotent"] = True
        return data

    async def _verify_settlement(self, settlement_nos, amount: Decimal):
        """校验结算单可付金额"""
        total = Decimal("0.00")

        for no in settlement_nos:
            info = await self.settle.get(no)

            if not info:
                raise BizException(40001, f"结算单 {no} 不存在")

            if info["status"] not in ("UNPAID", "PART_PAID"):
                raise BizException(
                    40001, f"结算单 {no} 状态为 {info['status']}，不可支付")

            total += money(info["payable_amount"])

        if amount > total:
            raise BizException(
                "1605004",
                f"支付金额 {amount} 超过应付金额 {total}")

        m03 = M03Client()
        result = await m03.deduct_stored({
            "patient_id": payload.patient_id,
            "amount": float(payment.pay_amount),
            "biz_no": payment.payment_no,
            "password_token": payload.stored_password_token,
            "operator_id": user.staff_id if user else None,
        })

        if not result or not result.get("success"):
            reason = (result or {}).get("message", "储值扣款失败")

            if (result or {}).get("code") == "BALANCE_NOT_ENOUGH":
                raise BizException("1605024", f"会员储值余额不足：{reason}")

            return {"status": "FAILED", "fail_code": "STORED_FAILED",
                    "fail_reason": reason[:500]}

        return {
            "status": "SUCCESS",
            "transaction_no": result.get("stored_txn_no"),
            "paid_at": datetime.now(),
        }

    # ---------- 成功处理 ----------
    async def _mark_success(self, payment: M16Payment, result: dict,
                            user, trace_id: str) -> None:
        """支付成功：幂等 + 状态 + 回写结算单"""
        if payment.status == "SUCCESS":
            return

        txn = result.get("transaction_no")

        # 交易号唯一性（数据库唯一索引兜底，这里先查一次给友好报错）
        if txn:
            dup = (await self.db.execute(
                select(M16Payment).where(
                    M16Payment.transaction_no == txn,
                    M16Payment.id != payment.id,
                    M16Payment.is_deleted == False,
                )
            )).scalar_one_or_none()

            if dup:
                raise BizException(
                    "1605013",
                    f"交易号 {txn} 已被支付单 {dup.payment_no} 使用")

        payment.status = "SUCCESS"
        payment.transaction_no = txn
        payment.paid_at = (result.get("paid_at")
                           or datetime.now())
        payment.notified_at = datetime.now()
        await self.db.flush()

        await self._trace(payment, "notify", "SUCCESS",
                          f"transaction_no={txn}")

        # 回写结算单（M16-01 负责是否 PAID）
        rewrites = []

        for sid in (payment.settlement_ids or []):
            try:
                resp = await self.settle.on_paid(sid, {
                    "payment_id": payment.id,
                    "payment_no": payment.payment_no,
                    "paid_amount": float(payment.pay_amount),
                    "payment_method": payment.pay_method,
                    "paid_at": payment.paid_at.isoformat(),
                    "transaction_no": txn,
                    "operator_id": user.staff_id if user else None,
                    "operator_name": user.real_name if user else None,
                })
                rewrites.append({
                    "settlement_id": sid,
                    "success": True,
                    "new_status": resp.get("new_status"),
                })
            except Exception as exc:  # noqa: BLE001
                rewrites.append({
                    "settlement_id": sid,
                    "success": False,
                    "error": str(exc)[:200],
                })
                await self._trace(
                    payment, "settle", "ERROR",
                    f"settlement_id={sid} err={str(exc)[:200]}")

        payment.settlement_rewrites = rewrites
        payment.notified_at = datetime.now()
        await self.db.flush()

    # ---------- 回调 ----------
    async def handle_notify(self, channel_code: str, headers_or_form,
                            raw_body: bytes,
                            trace_id: str = "") -> dict:
        """渠道异步回调

        步骤：
          ① 渠道适配器验签解密
          ② 提取 out_trade_no / transaction_no / amount / trade_state
          ③ 幂等：支付单已 SUCCESS 直接应答成功
          ④ 金额校验（防伪造）
          ⑤ 更新状态 + 回写结算单
        """
        adapter = get_adapter(channel_code)
        parsed = await adapter.verify_notify(headers_or_form, raw_body)

        out_trade_no = parsed["out_trade_no"]
        payment_no = (out_trade_no.replace("HIS-", "")
                      if out_trade_no.startswith("HIS-") else out_trade_no)

        payment = (await self.db.execute(
            select(M16Payment)
            .where(M16Payment.payment_no == payment_no)
            .with_for_update()
        )).scalar_one_or_none()

        if not payment:
            # 找不到也要应答成功，否则渠道会一直重试
            return {"code": "SUCCESS", "message": "ignored"}

        # 已成功：幂等应答
        if payment.status == "SUCCESS":
            return {"code": "SUCCESS", "message": "duplicate"}

        trade_state = parsed.get("trade_state", "")

        if trade_state in ("SUCCESS", "TRADE_SUCCESS", "FINISHED"):
            # 金额校验
            if money(parsed["amount"]) != money(payment.pay_amount):
                await self._trace(
                    payment, "notify", "ERROR",
                    f"金额不符 渠道={parsed['amount']} "
                    f"本地={payment.pay_amount}")
                raise BizException("1605012", "回调金额与支付单金额不一致")

            await self._mark_success(payment, {
                "transaction_no": parsed["transaction_no"],
                "paid_at": parsed.get("paid_at"),
            }, None, trace_id)
        elif trade_state in ("CLOSED", "REVOKED", "PAYERROR"):
            if payment.status not in ("CREATED", "PAYING", "UNKNOWN"):
                return {"code": "SUCCESS", "message": "state-locked"}

            payment.status = "FAILED"
            payment.fail_code = trade_state
            payment.fail_reason = parsed.get("fail_reason") or trade_state
            await self.db.flush()

        await self._trace(payment, "notify", "SUCCESS",
                          json.dumps(parsed, ensure_ascii=False,
                                     default=str))

        return {"code": "SUCCESS", "message": "ok"}

    # ---------- 查单 ----------
    async def query_channel(self, payment_no: str, user,
                            trace_id: str = "") -> dict:
        """主动向渠道查单"""
        payment = await self._get_for_update(payment_no)

        if payment.status not in ("CREATED", "PAYING", "UNKNOWN"):
            raise BizException(
                "1605006", f"当前状态 {payment.status} 不支持主动查单")

        adapter = get_adapter(payment.channel_code)
        result = await adapter.query({
            "out_trade_no": payment.channel_order_no,
            "transaction_no": payment.transaction_no,
        })

        await self._trace(payment, "query", "SUCCESS",
                          json.dumps(result, ensure_ascii=False,
                                     default=str))

        if result.get("status") == "SUCCESS":
            await self._mark_success(payment, result, user, trace_id)
        elif result.get("status") == "FAILED":
            payment.status = "FAILED"
            payment.fail_code = result.get("fail_code")
            payment.fail_reason = result.get("fail_reason")

        payment.retry_count = (payment.retry_count or 0) + 1

        if (payment.status == "PAYING"
                and payment.retry_count >= MAX_QUERY_RETRY):
            payment.status = "UNKNOWN"
            payment.fail_reason = "主动查询超过上限仍未确定结果"

        await self.db.flush()
        return self._dict(payment)

    # ---------- 关单 ----------
    async def close(self, payment_no: str, payload, user,
                    trace_id: str = "") -> dict:
        """关闭支付单：先关渠道，再关本地"""
        payment = await self._get_for_update(payment_no)

        if payment.status not in ("CREATED", "PAYING"):
            raise BizException(
                "1605007", f"当前状态 {payment.status} 不支持关闭")

            "out_trade_no": payment.channel_order_no,
        })

        if not channel_result.get("closed"):

            if channel_result.get("paid"):
                await self.query_channel(payment_no, user, trace_id)
                raise BizException(
                    "1605007", "渠道显示该订单已支付，无法关闭，已刷新状态")

        old = payment.status
        payment.status = "CLOSED"
        payment.fail_reason = payload.reason
        await self._trace(payment, "close", "SUCCESS", payload.reason)
        await self.db.flush()

        return {
            "payment_no": payment_no,
            "old_status": old,
            "new_status": "CLOSED",
            "channel_closed": bool(channel_result.get("closed")),
            "closed_at": datetime.now().isoformat(),
        }
```

```python
"""退款服务：发起 / 查询 / 重试"""
from datetime import datetime, timedelta
from decimal import Decimal, ROUND_HALF_UP
from typing import Optional

from sqlalchemy import select, func
from sqlalchemy.ext.asyncio import AsyncSession

from app.channels.registry import get_adapter

from app.core.redis import redis_client
from app.models.m16.pay import M16Payment, M16Refund, M16PaymentTrace


CENT = Decimal("0.01")
MAX_AUTO_RETRY = 3
ORIGINAL_REFUND_DAYS = {
    "WECHAT": 365,
    "ALIPAY": 365,
    "UNIONPAY": 365,
    "POS": 180,
}


def money(value) -> Decimal:
    return Decimal(str(value)).quantize(CENT, rounding=ROUND_HALF_UP)


class RefundService:
    """退款单全生命周期"""

    def __init__(self, db: AsyncSession):
        self.db = db

    async def create(self, payload, user, trace_id: str = "") -> dict:
        """发起退款"""
        if payload.refund_no:
            exist = (await self.db.execute(
                select(M16Refund).where(
                    M16Refund.refund_no == payload.refund_no)
            )).scalar_one_or_none()

            if exist:
                data = self._dict(exist)
                data["is_idempotent"] = True
                return data

        payment = (await self.db.execute(
            select(M16Payment)
            .where(M16Payment.payment_no == payload.payment_no)
            .with_for_update()
        )).scalar_one_or_none()

        if not payment:
            raise BizException("1605023", f"支付单 {payload.payment_no} 不存在")

        if payment.status != "SUCCESS":
            raise BizException(
                40001, f"支付单状态 {payment.status} 不可退款")

        refundable = await self._refundable(payment)
        amount = money(payload.refund_amount)

        if amount <= 0:
            raise BizException(40001, "退款金额必须大于 0")

        if amount > refundable:
            raise BizException(
                "1605008",
                f"退款金额 {amount} 超过可退金额 {refundable}")

        method = payload.refund_method or "ORIGINAL"

        if method == "ORIGINAL":
            days = ORIGINAL_REFUND_DAYS.get(payment.channel_code, 180)
            elapsed = (datetime.now() - payment.paid_at).days

            if elapsed > days:
                raise BizException(
                    "1605009",
                    f"原渠道已超过 {days} 天可退期（已过 {elapsed} 天），"
                    f"请改用现金或储值退款")

        refund_no = payload.refund_no or await self._next_refund_no()

        refund = M16Refund(
            refund_no=refund_no,
            payment_id=payment.id,
            payment_no=payment.payment_no,
            transaction_no=payment.transaction_no,
            channel_code=payment.channel_code,
            refund_amount=amount,
            refund_method=method,
            refund_reason=payload.refund_reason,
            status="CREATED",
            operator_id=user.staff_id if user else None,
            operator_name=user.real_name if user else None,
            trace_id=trace_id,
        )
        self.db.add(refund)
        await self.db.flush()

        await self._execute(refund, user)
        return self._dict(refund)

    async def _execute(self, refund: M16Refund, user) -> None:
        """执行退款：按方式分派"""
        if refund.refund_method == "CASH":
            refund.status = "SUCCESS"
            refund.refunded_at = datetime.now()
            await self.db.flush()
            return

        if refund.refund_method == "STORED":
            from app.clients.m03_client import M03Client
            m03 = M03Client()
            resp = await m03.add_stored({
                "patient_id": refund.patient_id,
                "amount": float(refund.refund_amount),
                "biz_no": refund.refund_no,
            })
            refund.status = "SUCCESS" if resp and resp.get("success") \
                else "ABNORMAL"
            refund.refunded_at = datetime.now()
            await self.db.flush()
            return

        # 原路退回
        adapter = get_adapter(refund.channel_code)

        try:
            result = await adapter.refund({
                "out_trade_no": refund.payment_no,
                "transaction_no": refund.transaction_no,
                "out_refund_no": refund.refund_no,
                "refund_amount": refund.refund_amount,
                "reason": refund.refund_reason,
            })
        except Exception as exc:  # noqa: BLE001
            refund.status = "ABNORMAL"
            refund.fail_reason = str(exc)[:500]
            await self.db.flush()
            return

        refund.channel_refund_no = result.get("refund_id")
        refund.status = {
            "SUCCESS": "SUCCESS",
            "PROCESSING": "PROCESSING",
            "FAILED": "FAILED",
        }.get(result.get("status"), "PROCESSING")

        if refund.status == "FAILED":
            refund.fail_code = result.get("fail_code")
            refund.fail_reason = result.get("fail_reason")

        if refund.status == "SUCCESS":
            refund.refunded_at = datetime.now()

        await self.db.flush()

    async def _refundable(self, payment: M16Payment) -> Decimal:
        """可退金额 = 支付金额 - 已成功退款"""
        refunded = (await self.db.execute(
            select(func.coalesce(func.sum(M16Refund.refund_amount), 0))
            .where(
                M16Refund.payment_id == payment.id,
                M16Refund.status.in_(["SUCCESS", "PROCESSING"]),
                M16Refund.is_deleted == False,
            )
        )).scalar() or 0

        return money(Decimal(str(payment.pay_amount))
                     - Decimal(str(refunded)))

    async def retry(self, refund_no: str, user,
                    trace_id: str = "") -> dict:
        """退款重试"""
        refund = (await self.db.execute(
            select(M16Refund)
            .where(M16Refund.refund_no == refund_no)
            .with_for_update()
        )).scalar_one_or_none()

        if not refund:
            raise BizException(40001, f"退款单 {refund_no} 不存在")

        if refund.status not in ("FAILED", "ABNORMAL"):
            raise BizException(
                40001, f"退款单状态 {refund.status} 不支持重试")

        refund.retry_count = (refund.retry_count or 0) + 1
        refund.status = "CREATED"
        await self._execute(refund, user)
        return self._dict(refund)

    async def _next_refund_no(self) -> str:
        day = datetime.now().strftime("%Y%m%d")
        key = f"m16:refund:seq:{day}"
        seq = await redis_client.incr(key)

        if seq == 1:
            await redis_client.expire(key, 86400 * 3)

        return f"RF{day}{seq:04d}"

    @staticmethod
    def _dict(refund: M16Refund) -> dict:
        return {

            "payment_no": refund.payment_no,
            "channel_code": refund.channel_code,
            "refund_amount": float(refund.refund_amount),

            "status": refund.status,
            "status_text": RefundService._status_text(refund.status),
            "channel_refund_no": refund.channel_refund_no,
            "fail_reason": refund.fail_reason,
            "retry_count": refund.retry_count or 0,
            "refunded_at": (refund.refunded_at.isoformat()
                            if refund.refunded_at else None),
            "created_at": refund.created_at.isoformat(),
        }

    @staticmethod
```

```python
CENT = Decimal("0.01")
DIFF_TYPES = ("CHANNEL_ONLY", "LOCAL_ONLY", "AMOUNT_MISMATCH",
              "STATUS_MISMATCH", "FEE_MISMATCH")


def money(value) -> Decimal:
    return Decimal(str(value)).quantize(CENT, rounding=ROUND_HALF_UP)


class ReconcileService:
    """渠道对账"""

    def __init__(self, db: AsyncSession):
        self.db = db

    async def run(self, payload, user, trace_id: str = "") -> dict:
        """执行对账"""
        bill_date = date.fromisoformat(payload.bill_date)

        if bill_date > date.today():
            raise BizException("1605016", "对账日期不能是未来日期")

        running = (await self.db.execute(
            select(M16ReconcileTask).where(
                M16ReconcileTask.bill_date == bill_date,
                M16ReconcileTask.channel_code == payload.channel_code,
                M16ReconcileTask.status == "RUNNING",
            )
        )).scalar_one_or_none()

        if running:
            raise BizException("1605025", "对账任务正在执行中，请稍后")

        bill = (await self.db.execute(
            select(M16ReconcileTask).where(
                M16ReconcileTask.bill_date == bill_date,
                M16ReconcileTask.channel_code == payload.channel_code,
                M16ReconcileTask.bill_file_path.isnot(None),
            ).order_by(M16ReconcileTask.id.desc()).limit(1)
        )).scalar_one_or_none()

        if not bill:
            raise BizException("1605017", "渠道账单未下载，无法对账")

        task = M16ReconcileTask(
            bill_date=bill_date,
            channel_code=payload.channel_code,
            status="RUNNING",
            bill_file_path=bill.bill_file_path,
            started_at=datetime.now(),
            trace_id=trace_id,
        )
        self.db.add(task)
        await self.db.flush()

        try:
            await self._compare(task, bill.bill_file_path)
            task.status = "FINISHED"
        except Exception as exc:  # noqa: BLE001
            task.status = "FAILED"
            task.fail_reason = str(exc)[:500]

        task.finished_at = datetime.now()
        await self.db.flush()

        return {
            "task_id": task.id,
            "bill_date": str(bill_date),
            "channel_code": payload.channel_code,
            "status": task.status,
            "estimated_seconds": 30,
        }

    async def _compare(self, task, file_path: str) -> None:
        """逐笔比对：渠道账单 ↔ 本地支付流水"""
        adapter = get_adapter(task.channel_code)
        channel_rows = await adapter.parse_bill(file_path)

        channel_map = {}
        channel_amount = Decimal("0.00")
        channel_fee = Decimal("0.00")

        for row in channel_rows:
            key = row["transaction_no"]
            channel_map[key] = row
            channel_amount += money(row["amount"])
            channel_fee += money(row.get("fee") or 0)

        local_rows = (await self.db.execute(
            select(M16Payment).where(
                M16Payment.channel_code == task.channel_code,
                M16Payment.status == "SUCCESS",
                M16Payment.paid_at >= task.bill_date,
                M16Payment.paid_at < task.bill_date,
            )
        )).scalars().all()

        local_map = {p.transaction_no: p for p in local_rows if p.transaction_no}
        local_amount = sum((money(p.pay_amount) for p in local_rows),
                           Decimal("0.00"))

        matched = 0
        diffs = []

        # 遍历渠道账单
        for txn, row in channel_map.items():
            local = local_map.get(txn)

            if not local:
                diffs.append({
                    "diff_type": "CHANNEL_ONLY",
                    "transaction_no": txn,
                    "local_payment_no": None,
                    "channel_amount": money(row["amount"]),
                    "local_amount": Decimal("0.00"),
                    "remark": "渠道有交易，本地无流水（长款）",
                })
                continue

            if money(row["amount"]) != money(local.pay_amount):
                diffs.append({
                    "diff_type": "AMOUNT_MISMATCH",
                    "transaction_no": txn,
                    "local_payment_no": local.payment_no,
                    "channel_amount": money(row["amount"]),
                    "local_amount": money(local.pay_amount),
                    "remark": "金额不符",
                })
                continue

            matched += 1

        # 遍历本地（找短款）
        for txn, local in local_map.items():
            if txn not in channel_map:
                diffs.append({
                    "diff_type": "LOCAL_ONLY",
                    "transaction_no": txn,
                    "local_payment_no": local.payment_no,
                    "channel_amount": Decimal("0.00"),
                    "local_amount": money(local.pay_amount),
                    "remark": "本地成功，渠道无记录（短款）",
                })

        # 汇总写回
        task.channel_count = len(channel_rows)
        task.local_count = len(local_rows)
        task.matched_count = matched
        task.diff_count = len(diffs)
        task.channel_amount = channel_amount
        task.local_amount = local_amount
        task.amount_diff = channel_amount - local_amount
        task.channel_fee = channel_fee
        task.is_balanced = (len(diffs) == 0)

        for d in diffs:
            self.db.add(M16ReconcileDiff(
                task_id=task.id,
                bill_date=task.bill_date,
                channel_code=task.channel_code,
                **d,
            ))

        await self.db.flush()

    async def download(self, bill_date: str, channel_code: str,
```

```python
"""微信支付 API v3 适配器"""
import base64
import json
import time
import uuid
from datetime import date, datetime
from decimal import Decimal

import httpx
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import padding
from cryptography.hazmat.primitives.ciphers.aead import AESGCM

from app.channels.base import BaseChannelAdapter


WECHAT_BASE = "https://api.mch.weixin.qq.com"


class WechatAdapter(BaseChannelAdapter):
    """微信支付 v3

    关键点：
      · 请求用商户私钥 RSA-SHA256 签名
      · 回调用 APIv3 密钥 AES-GCM 解密 resource
      · 回调用平台证书验 Wechatpay-Signature
    """

    channel_code = "WECHAT"

    def __init__(self, config: dict):
        self.mch_id = config["mch_id"]
        self.serial_no = config["cert_serial_no"]
        self.private_key = serialization.load_pem_private_key(
            config["private_key"].encode(), password=None)
        self.api_v3_key = config["api_v3_key"].encode()
        self.platform_certs = config.get("platform_certs", {})

    # ---------- 签名 ----------
    def _sign(self, message: str) -> str:
        signature = self.private_key.sign(
            message.encode(),
            padding.PKCS1v15(),
            hashes.SHA256(),
        )
        return base64.b64encode(signature).decode()

    def _auth_header(self, method: str, url_path: str,
                     body: str) -> str:
        ts = str(int(time.time()))
        nonce = uuid.uuid4().hex
        message = f"{method}\n{url_path}\n{ts}\n{nonce}\n{body}\n"
        sig = self._sign(message)
        return (f'WECHATPAY2-SHA256-RSA2048 mchid="{self.mch_id}",'
                f'nonce_str="{nonce}",signature="{sig}",'
                f'timestamp="{ts}",serial_no="{self.serial_no}"')

    # ---------- 下单 ----------
    async def pay(self, order: dict) -> dict:
        path = "/v3/pay/transactions/native"
        body = json.dumps({
            "mchid": self.mch_id,
            "out_trade_no": order["out_trade_no"],
            "description": order["description"][:127],
            "notify_url": order.get("notify_url", ""),
            "amount": {
                "total": int(Decimal(str(order["amount"])) * 100),
                "currency": "CNY",
            },
            "time_expire": order["expire_at"].isoformat() + "+08:00",
        }, ensure_ascii=False, separators=(",", ":"))

        headers = {
            "Authorization": self._auth_header("POST", path, body),
            "Content-Type": "application/json",
            "Accept": "application/json",
        }

        async with httpx.AsyncClient(timeout=5.0) as client:
            resp = await client.post(WECHAT_BASE + path,
                                     content=body, headers=headers)

        if resp.status_code != 200:
            return {
                "status": "FAILED",
                "fail_code": f"HTTP_{resp.status_code}",
                "fail_reason": resp.text[:500],
            }

        data = resp.json()
        return {
            "status": "PAYING",
            "qr_code_url": data.get("code_url"),
            "qr_token": uuid.uuid4().hex,
        }

    # ---------- 验签解密 ----------
    async def verify_notify(self, headers: dict, raw_body: bytes) -> dict:
        """验签 + 解密 + 提取关键字段"""
        signature = headers.get("wechatpay-signature", "")
        timestamp = headers.get("wechatpay-timestamp", "")
        nonce = headers.get("wechatpay-nonce", "")
        serial = headers.get("wechatpay-serial", "")

        # 防重放：时间戳偏差 ≤ 5 分钟
        if abs(time.time() - int(timestamp)) > 300:
            raise ValueError("回调时间戳超出允许范围")

        message = (f"{timestamp}\n{nonce}\n"
                   f"{raw_body.decode('utf-8')}\n")

        cert_pem = self.platform_certs.get(serial)

        if not cert_pem:
            raise ValueError(f"未知平台证书序列号 {serial}")

        from cryptography import x509
        cert = x509.load_pem_x509_certificate(cert_pem.encode())
        cert.public_key().verify(
            base64.b64decode(signature),
            message.encode(),
            padding.PKCS1v15(),
            hashes.SHA256(),
        )

        # 解密
        payload = json.loads(raw_body)
        resource = payload["resource"]
        aesgcm = AESGCM(self.api_v3_key)
        plaintext = aesgcm.decrypt(
            resource["nonce"].encode(),
            base64.b64decode(resource["ciphertext"]),
            resource.get("associated_data", "").encode() or None,
        )
        data = json.loads(plaintext)

        return {
            "out_trade_no": data["out_trade_no"],
            "transaction_no": data.get("transaction_id"),
            "amount": Decimal(data["amount"]["total"]) / 100,
            "trade_state": data.get("trade_state", "SUCCESS"),
            "paid_at": data.get("success_time"),
            "buyer_id": data.get("payer", {}).get("openid"),
        }

    # ---------- 已有 M16-02 依赖的辅助方法 ----------

        数据行以反引号包裹。金额单位是元。

        with gzip.open(file_path, "rt", encoding="utf-8") as fp:
            content = fp.read()

        # 微信账单每行以 ` 开头，去掉后按逗号切
        for line in content.splitlines():
            if not line.startswith("`"):
                continue
            parts = [p.strip("`").strip() for p in line.split(",")]
            if len(parts) < 20 or not parts[6]:
                continue
            rows.append({
                "transaction_no": parts[6],
                "out_trade_no": parts[7],
                "amount": Decimal(parts[13] or "0"),
                "fee": Decimal(parts[19] or "0"),
                "trade_time": parts[0],
            })

        return rows
```

```python
@shared_task
def poll_pending_payments_task():

async def _poll_pending():
    from datetime import datetime, timedelta
    from sqlalchemy import select
    from app.core.database import AsyncSessionLocal
    from app.models.m16.pay import M16Payment
    from app.services.m16.pay_service import PayService

    cutoff = datetime.now() - timedelta(seconds=60)

    resolved = 0

    async with AsyncSessionLocal() as db:
        rows = (await db.execute(
            select(M16Payment).where(
                M16Payment.status.in_(["PAYING", "UNKNOWN"]),
                M16Payment.created_at <= cutoff,

        )).scalars().all()

                checked += 1

                if p.status == "SUCCESS":
                    resolved += 1
            except Exception:
                p.retry_count = (p.retry_count or 0) + 1

        await db.commit()

    from app.channels.registry import get_adapter

    expired = 0

        )).scalars().all()

        for p in rows:
            # 先查一次再判过期，防止"刚好已付"被误关
            try:
                adapter = get_adapter(p.channel_code)
                q = await adapter.query(
                    {"out_trade_no": p.channel_order_no})

                if q.get("status") == "SUCCESS":
                    continue

                await adapter.close({"out_trade_no": p.channel_order_no})
                p.status = "EXPIRED"
                p.fail_reason = "支付超时未完成"
                expired += 1
            except Exception:
                pass

        await db.commit()

    return {"expired": expired}

async def _health():
    from sqlalchemy import select, func
    from datetime import datetime, timedelta
    from app.core.database import AsyncSessionLocal
    from app.core.redis import redis_client
    from app.models.m16.pay import M16Payment
    import json as jsonmod

    since = datetime.now() - timedelta(minutes=5)
    health = {}

    async with AsyncSessionLocal() as db:
        rows = (await db.execute(
            select(
                M16Payment.channel_code,
                func.count(M16Payment.id),
                func.sum(
                    func.case((M16Payment.status == "SUCCESS", 1), else_=0)),
            ).where(
                M16Payment.created_at >= since,
            ).group_by(M16Payment.channel_code)
        )).all()

        for code, total, success in rows:
            rate = (success or 0) / total if total else 1.0
            status = "NORMAL" if rate >= 0.98 else (
                "SLOW" if rate >= 0.95 else "DOWN")
            health[code] = {"total": total, "success": success or 0,
                            "rate": round(rate, 4), "status": status}
            await redis_client.setex(
                f"m16:pay:health:{code}", 300,
                jsonmod.dumps(health[code]))

    return health
```

### 8.6 并发控制

```sql
-- 支付单号唯一
CREATE UNIQUE INDEX uk_m16_payment_no ON m16_payment (payment_no);

-- 幂等键唯一（同一业务不能建两张支付单）
CREATE UNIQUE INDEX uk_m16_payment_idem
    ON m16_payment (idempotency_key)
    WHERE idempotency_key IS NOT NULL AND is_deleted = FALSE;

-- 交易号全局唯一（防一笔钱记两次）
CREATE UNIQUE INDEX uk_m16_payment_txn
    ON m16_payment (transaction_no)
    WHERE transaction_no IS NOT NULL;

-- 渠道单号唯一
CREATE UNIQUE INDEX uk_m16_payment_out_trade
    ON m16_payment (channel_code, channel_order_no)
    WHERE channel_order_no IS NOT NULL;

-- 退款单号唯一
CREATE UNIQUE INDEX uk_m16_refund_no ON m16_refund (refund_no);

-- 同渠道退款单号唯一
CREATE UNIQUE INDEX uk_m16_refund_channel_no
    ON m16_refund (channel_code, channel_refund_no)
    WHERE channel_refund_no IS NOT NULL;
```

> **`uk_m16_payment_txn` 是资金安全的最后一道防线。** 即使应用层所有幂等逻辑都失效（代码 BUG、并发竞态、人工误操作），数据库也会拒绝第二个使用同一交易号的记录。这条索引的价值不在"正常运行"，而在"出事那年"。

## 11. 异常处理与日志

### 11.1 异常分类

| 类型 | 示例 | 处理 |
|---|---|---|
| 渠道未配置 | 微信商户号为空 | 54928，引导配置 |
| 渠道超时 | 微信 5 秒无响应 | 54946，`UNKNOWN`，进查询队列 |
| 渠道返回失败 | 用户余额不足 | 置 `FAILED`，提示患者换方式 |
| 回调验签失败 | 伪造回调 | 54940，记 CRITICAL，告警 |
| 回调金额不符 | 伪造或串单 | 54937，拒绝入账，告警 |
| 交易号重复 | 重复回调 / 补单冲突 | 54938，幂等返回 |
| 结算单回写失败 | M16-01 挂了 | 进 `m16_rewrite_queue`，Celery 重试 |
| 退款超期 | 原渠道 >365 天 | 54934，改现金 |
| 退款余额不足 | 微信商户余额不够 | `ABNORMAL`，通知财务充值 |
| 对账差异 | 长款/短款 | 写差异表，告警财务 |
| 会员储值不足 | 余额不够 | 54949，提示充值 |
| 丢回调 | 渠道没发/没收到 | 主动查询自愈；超 10 次 `UNKNOWN` |

### 11.2 日志规范

```python
logger.info(
    "m16.pay.success",
    extra={
        "payment_no": payment_no,
        "channel_code": channel_code,
        "amount": str(amount),
        "transaction_no": txn,
        "settlement_nos": settlement_nos,
        "source_channel": source_channel,
        "elapsed_ms": elapsed,
        "is_manual": is_manual,
        "trace_id": trace_id,
    },
)
```

**日志级别：**

| 级别 | 场景 |
|---|---|
| INFO | 下单、回调、查单、支付成功、退款、对账完成 |
| WARNING | 渠道耗时 > 3s、查询重试、幂等命中、余额不足 |
| ERROR | 渠道调用失败、回写结算单失败、退款失败、对账有差异 |
| CRITICAL | **验签失败、金额不符、交易号重复、长款/短款、单边账** |

> **验签失败与金额不符必须记 CRITICAL 并实时告警。** 这两类不是"业务失败"，是"可能有人攻击"或"系统有严重 BUG"。
