## 1. 模块概述

### 1.1 模块定位

文书签署与打印是医生工作站的**法定输出层**。它回答："**这些数据怎么变成有法律效力的纸？谁负责？**"

```
┌──────────────────────────────────────────────────────────────┐
│  数据层（前 5 个子模块产出的结构化数据）                         │
│  01 会话  │ 02 诊断 │ 03 医嘱 │ 04 报告 │ 05 处方              │
└────────────────────────┬─────────────────────────────────────┘
                         │ 渲染 + 签名
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M07-06 文书签署与打印（本文档）★法定输出                       │
│  ① 病历签名    ② 处方打印   ③ 检查检验申请单                    │
│  ④ 诊断证明书  ⑤ 病假条     ⑥ 手术同意书                      │
│  ⑦ 打印留痕    ⑧ 补打重打                                      │
└────────────────────────┬─────────────────────────────────────┘
                         │
        ┌────────────────┼────────────────┬────────────────┐
        ▼                ▼                ▼                ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ 纸质交付      │ │ M18 病历归档  │ │ M16 收费      │ │ 患者/单位     │
└──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘
```

### 1.2 为什么文书要独立成子模块

| 理由 | 说明 |
|---|---|
| **法律效力** | 病历、处方、诊断证明是法定医疗文书，需签名、留痕、防篡改 |
| **格式规范** | 处方笺颜色、诊断证明书格式有法规要求 |
| **打印留痕** | 谁在什么时间打印了几份，必须可追溯（防伪造） |
| **补打重打** | 患者丢单、报销需要，需控制重打次数并留痕 |
| **模板管理** | 不同科室/文书有不同模板 |
| **电子签名** | 符合《电子签名法》，需 CA 证书 + 摘要 |

### 1.3 与前 5 个子模块的分工

| 数据 | 产出方 | 本模块职责 |
|---|---|---|
| 就诊信息 | M07-01 | 取数填入文书 |
| 诊断 | M07-02 | 取数填入文书 |
| 医嘱 | M07-03 | 生成检查检验申请单 |
| 报告 | M07-04 | 生成报告纸 |
| **处方** | **M07-05** | **生成处方笺（M07-05 只负责签名，本模块负责排版打印）** |
| **病历正文** | **M18** | **本模块负责签名与打印，不含书写** |

> **边界一句话：** 本模块**不写内容**（内容来自其他模块或 M18），只负责**渲染、签名、打印、留痕**。

### 1.5 模块目标

- **合规**：文书格式符合法规，签名合法有效。
- **防篡改**：文书生成后内容锁定，改动必须重签。
- **可追溯**：每次打印留痕（谁、何时、第几份、打印机）。
- **快**：单份文书生成 + 打印 ≤ 2 秒。
- **防滥用**：重打需授权并记录原因。
- **可补打**：患者丢失可补打，有次数限制。

### 1.6 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 门诊医生 | 签名、打印 | 签名、打印文书 |
| 护士 | 打印 | 打印病历、指导单 |
| 医务科 | 监管 | 文书模板维护、重打授权 |
| 患者 | 接收 | 领取纸质文书 |

## 3. 业务模型

### 3.1 文书模型

#### 3.1.1 文书生命周期

```
        ┌──────────┐
        │  DRAFT   │  草稿（数据未就绪）
        └────┬─────┘
             │ 生成
             ▼
        ┌──────────┐
        │GENERATED │  已生成（待签名）
        └────┬─────┘
             │ 签名
             ▼
        ┌──────────┐
        │  SIGNED  │  已签名（法律效力生效）
        └────┬─────┘
             │ 打印
             ▼
        ┌──────────┐
        │ PRINTED  │  已打印
        └────┬─────┘
             │
    ┌────────┼──────────────┬──────────────┐
    │ 补打    │ 作废          │ 重新生成      │
    ▼        ▼              ▼              ▼
（PRINTED  CANCELLED      GENERATED
  保持）                     │
                            └──► 重签
```

#### 3.1.2 文书状态

| 状态 | 说明 | 可打印 | 可作废 |
|---|---|---|---|
| `DRAFT` | 草稿，数据未就绪 | ❌ | ✅ |
| `GENERATED` | 已生成，待签名 | ❌ | ✅ |
| `SIGNED` | 已签名 | ✅ | ✅ |
| `PRINTED` | 已打印 | ✅（补打） | ✅ |
| `CANCELLED` | 已作废 | ❌ | ❌ |

#### 3.1.3 文书与数据的关系

**核心原则：文书是数据的快照，不是引用。**

```
文书生成时：
  数据 → 渲染 → m07_document.content_snapshot (JSONB)
  同时：   data_hash = SHA256(规范化内容)

签名时：
  signature_hash = SHA256(content_snapshot + 签名人 + 时间)
  → 任何后续改动都会导致 hash 不匹配

出示时：
  重新计算 hash → 与 signature_hash 比对 → 一致则有效
```

**为什么存快照：**

| 理由 | 说明 |
|---|---|
| 防篡改 | 源数据变了，文书内容不变 |
| 法律效力 | 文书代表当时的诊疗事实 |
| 可重现 | 任何时候打印结果一致 |
| 审计需要 | 可追溯文书生成时的数据状态 |

### 3.3 电子签名模型

#### 3.3.1 签名要素

```
签名信息 = 
  ① 签名人身份（医生 ID + 姓名 + 职称）
  ② 签名时间（精确到秒）
  ③ 文书内容摘要（SHA256）
  ④ 数字证书（CA 颁发）
  ⑤ 签名值（用私钥加密摘要）

验证：
  用证书公钥解密签名值 → 得到摘要 A
  重新计算文书摘要 → 得到摘要 B
  A == B → 签名有效且内容未篡改
```

#### 3.3.2 签名方式

| 方式 | 代码 | 说明 | 法律效力 |
|---|---|---|---|
| CA 电子签名 | `CA` | 第三方 CA 证书 | 等同于手写签名 |
| 手写签名图 | `HANDWRITE` | 签名图片 + 时间戳 | 需配合其他证据 |
| 密码确认 | `PASSWORD` | 仅密码验证 | 内部使用，法律效力弱 |

#### 3.3.3 签名范围

| 文书 | 必须签名的人 |
|---|---|
| 门诊病历 | 接诊医生 |
| 处方 | 开方医生 + 审核药师 |
| 检查检验申请单 | 开单医生 |
| 诊断证明书 | 医生 + 医院（章） |
| 病假条 | 医生 + 医院（章） |
| 手术同意书 | 医生 + 患者/家属 |
| 出院小结 | 主治医师 |

### 3.4 打印模型

#### 3.4.1 打印流程

```
生成 PDF（内存）
   ↓
记录打印任务（m07_document_print）
   ↓
调用打印服务（本地/网络打印机）
   ↓
返回打印结果
   ↓
更新文书状态 PRINTED
   ↓
记录打印留痕（份数、打印机、IP、操作人）
```

#### 3.4.2 打印留痕要素

| 要素 | 说明 |
|---|---|
| 文书 ID / 编号 | 哪份文书 |
| 打印人 | 谁打的 |
| 打印时间 | 何时 |
| 打印份数 | 第几份 |
| 打印类型 | 首次/补打/重打 |
| 打印机 | 哪台设备 |
| 打印原因 | 补打/重打必填 |
| IP 地址 | 防追溯 |

#### 3.4.3 打印次数控制

| 打印类型 | 代码 | 次数限制 | 需授权 |
|---|---|---|---|
| 首次打印 | `FIRST` | 1 | ❌ |
| 补打 | `REPRINT` | 3 | ❌（超 3 次需授权） |
| 重打（内容变更后） | `REGENERATE` | 不限 | ✅ |
| 行政补打 | `ADMIN` | 不限 | ✅ 医务科 |

```
补打超过 3 次：
  → 提示"该文书已补打 3 次，如需继续请申请医务科授权"
  → 医务科授权后打印类型变为 ADMIN
```

class DocumentService:
    """文书生成、签名、验签"""

    STATUS_LABELS = {
        "DRAFT": "草稿", "GENERATED": "待签名", "SIGNED": "已签名",
        "PRINTED": "已打印", "CANCELLED": "已作废",
    }

    def __init__(self, db: AsyncSession):
        self.db = db
        self.m07 = M07InternalClient()
        self.m01 = M01Client()

    # ---------- 生成 ----------
    async def generate(self, payload, user) -> dict:
        """生成文书"""
        encounter = await self._get_encounter(payload.encounter_id)

        # 获取模板
        template = await self._resolve_template(
            payload.doc_type, payload.template_id)

        # 收集数据
        data = await self._collect_data(
            encounter, payload.doc_type, payload.source_type,
            payload.source_id)

        # 合并附加字段
        if payload.extra_fields:
            data.update(payload.extra_fields)

        # 必填字段校验
        missing = self._check_required(payload.doc_type, data)

        if missing:
            raise BizException("0706006", "必填字段缺失",
                data={
                    "doc_type": payload.doc_type,
                    "missing_fields": missing,
                    "suggestion": ("请先完成"
                                    f"{', '.join(m['label'] for m in missing)}"
                                    "的填写"),
                    "can_generate": False,
                })

        # 内容快照
        snapshot = self._build_snapshot(
            template, encounter, data)
        content_hash = self._hash_content(snapshot)

        document_no = (f"DOC{datetime.now().strftime('%Y%m%d')}"
                        f"{uuid.uuid4().hex[:4].upper()}")

        doc = M07Document(
            document_no=document_no,
            doc_type=payload.doc_type,
            doc_type_text=DOC_TYPE_LABELS.get(payload.doc_type, ""),
            template_id=template.id,
            template_name=template.template_name,
            template_version=template.version,

            encounter_id=payload.encounter_id,
            encounter_no=encounter.encounter_no,
            patient_id=encounter.patient_id,
            patient_name=encounter.patient_name,
            patient_gender=encounter.patient_gender,
            patient_age=encounter.patient_age,
            empi_no=encounter.empi_no,
            doctor_id=encounter.doctor_id,
            doctor_name=encounter.doctor_name,
            dept_id=encounter.dept_id,

            source_type=payload.source_type,
            source_id=payload.source_id,

            content_snapshot=snapshot,
            content_hash=content_hash,
            field_count=len(snapshot.get("fields", {})),

            status="GENERATED",
            print_count=0,
            reprint_count=0,
        )
        self.db.add(doc)
        await self.db.flush()

        self.db.add(M07DocumentLog(
            document_id=doc.id,
            document_no=document_no,
            encounter_id=doc.encounter_id,
            action="GENERATE",
            after_json={
                "doc_type": payload.doc_type,
                "template": template.template_name,
                "version": template.version,
            },
            operator_id=getattr(user, "id", None),
            operator_name=getattr(user, "name", None),
        ))

        await self.db.commit()

        return {
            "document_id": doc.id,
            "document_no": document_no,
            "doc_type": doc.doc_type,
            "doc_type_text": doc.doc_type_text,
            "template_id": template.id,
            "template_name": template.template_name,
            "template_version": template.version,
            "patient": {
                "patient_id": doc.patient_id,
                "patient_name": doc.patient_name,
                "patient_gender": doc.patient_gender,
                "patient_age": doc.patient_age,
                "empi_no": doc.empi_no,
            },
            "encounter": {
                "encounter_id": doc.encounter_id,
                "visit_no": doc.encounter_no,
                "dept_name": getattr(encounter, "dept_name", None),
                "doctor_name": doc.doctor_name,
            },
            "status": "GENERATED",
            "status_text": "待签名",
            "content_hash": content_hash,
            "field_count": doc.field_count,
            "missing_fields": [],
            "generated_at": datetime.now().isoformat(),
            "preview_url": f"/api/v1/m07/documents/{doc.id}/pdf",
            "can_sign": True,
            "next_step": "请签名后打印",
        }

    # ---------- 数据收集 ----------
    async def _collect_data(self, encounter, doc_type,
                              source_type, source_id) -> dict:
        """按文书类型收集数据"""
        data = {
            "patient_name": encounter.patient_name,
            "gender": encounter.patient_gender,
            "age": encounter.patient_age,
            "empi_no": encounter.empi_no,
            "visit_no": encounter.encounter_no,
            "visit_date": (encounter.encounter_date.isoformat()
                            if encounter.encounter_date else ""),
            "dept_name": getattr(encounter, "dept_name", ""),
            "doctor_name": encounter.doctor_name,
            "hospital_name": await self._get_hospital_name(),
        }

        # 诊断
        diagnoses = await self._get_diagnoses(encounter.id)

        if diagnoses:
            data["diagnosis"] = self._format_diagnosis(diagnoses)
            data["diagnosis_list"] = diagnoses

        # 按类型补充
        if doc_type == "MEDICAL_RECORD":
            emr = await self._get_emr(encounter.id, source_id)
            if emr:
                data.update(emr)

        elif doc_type in ("EXAM_REQUEST", "LAB_REQUEST"):
            orders = await self._get_orders(
                encounter.id,
                "EXAM" if doc_type == "EXAM_REQUEST" else "LAB")
            data["items"] = orders

        elif doc_type == "PRESCRIPTION":
            rxs = await self._get_prescriptions(encounter.id)
            data["items"] = rxs

        elif doc_type in ("SURGERY_CONSENT", "SPECIAL_CONSENT"):
            orders = await self._get_orders(encounter.id, "OPERATION")
            data["items"] = orders
            data["risks"] = self._get_consent_risks(doc_type)

        return data

    async def _get_diagnoses(self, encounter_id: int) -> List[dict]:
        from app.models.m07.diagnosis import M07Diagnosis

        rows = (await self.db.execute(

    async def sign(self, document_id: int, payload, user) -> dict:

        if doc.status not in ("GENERATED", "DRAFT"):

    async def verify(self, document_id: int) -> dict:

        if not doc.signed_at:
            return {
                "document_id": doc.id,

                "document_no": doc.document_no,
                "is_signed": True,
                "signature_valid": True,
                "verify_result": "VALID",

                "hash_match": True,
                "cert_info": {
                    "subject": f"CN={doc.signer_name}",
                    "is_valid_period": True,
                },
            }

        # 篡改
        return {
            "document_id": doc.id,
            "document_no": doc.document_no,
            "is_signed": True,

            "verify_result": "TAMPERED",

    async def print_document(self, document_id: int, payload,
                               user) -> dict:
        """打印文书"""
        doc = await self._get(document_id)

        # 状态校验
        if doc.status == "CANCELLED":
            raise BizException("0706005", "文书已作废，不可打印")

        if doc.status in ("DRAFT", "GENERATED"):
            raise BizException("0706013", "文书未签名不可打印",
                data={
                    "document_id": doc.id,
                    "document_no": doc.document_no,
                    "status": doc.status,
                    "status_text": "待签名",
                    "suggestion": "请先完成文书签名后再打印",
                })

        # 份数
        if not (1 <= payload.copies <= self.MAX_COPIES):
            raise BizException("0706029",
                f"打印份数超出限制（1~{self.MAX_COPIES}）")

        # 类型判定
        attempt = doc.print_count or 0
        is_first = attempt == 0

        if is_first:
            actual_type = "FIRST"
        else:
            actual_type = payload.print_type or "REPRINT"

        # 补打上限
        if actual_type == "REPRINT":
            if (doc.reprint_count or 0) >= self.MAX_REPRINT:
                raise BizException("0706016", "补打次数已达上限",
                    data={
                        "document_id": doc.id,
                        "document_no": doc.document_no,
                        "reprint_count": doc.reprint_count,
                        "max_reprint": self.MAX_REPRINT,
                        "suggestion": ("请联系医务科授权后打印"
                                        "（授权后打印类型变为行政补打）"),
                        "action": "REQUEST_AUTH",
                        "auth_required_role": "MEDICAL_AFFAIRS",
                    })

            if not payload.reason:
                raise BizException("0706017", "重打原因必填")

        # 防并发锁
        lock_key = f"m07:doc:print:lock:{document_id}"
        if not await redis_client.set(
                lock_key, "1", nx=True, ex=self.LOCK_TTL):
            raise BizException("0706030", "该文书已被锁定（正在打印）")

        try:
            # 调用打印服务
            print_ok = await self._submit_to_printer(
                doc, payload.printer_name, payload.copies)

            print_seq = attempt + 1

            rec = M07DocumentPrint(
                document_id=doc.id,
                document_no=doc.document_no,
                doc_type=doc.doc_type,
                patient_id=doc.patient_id,
                print_type=actual_type,

                printed_by_name=getattr(user, "name", None),
            )

            doc.last_printed_at = datetime.now()

            if actual_type == "FIRST":
                doc.status = "PRINTED"
                doc.first_printed_at = datetime.now()
            elif actual_type == "REPRINT":
                doc.reprint_count = (doc.reprint_count or 0) + 1
                doc.status = "PRINTED"
            elif actual_type == "ADMIN":
                doc.admin_print_count = (
                    doc.admin_print_count or 0) + 1
                doc.status = "PRINTED"

            await self.db.flush()

            .join(M07Document,
                   M07Document.id == M07DocumentPrint.document_id)
            .where(and_(*conds))
        )).one()

        total = row.total or 0

        by_type = (await self.db.execute(
            select(
                M07DocumentPrint.doc_type,
                func.count().label("cnt"),
            ).select_from(M07DocumentPrint)
            .join(M07Document,
                   M07Document.id == M07DocumentPrint.document_id)
            .where(and_(*conds))
            .group_by(M07DocumentPrint.doc_type)
            .order_by(func.count().desc())
        )).all()

        reasons = (await self.db.execute(
            select(
                M07DocumentPrint.reason,
                func.count().label("cnt"),
            ).select_from(M07DocumentPrint)
            .join(M07Document,
                   M07Document.id == M07DocumentPrint.document_id)
            .where(and_(*conds,
                         M07DocumentPrint.print_type == "REPRINT"))
            .group_by(M07DocumentPrint.reason)
        )).all()

        reprint_total = row.reprint or 0

        return {
            "start_date": start_date.isoformat(),
            "end_date": end_date.isoformat(),
            "dept_id": dept_id,
            "summary": {
                "total_prints": total,
                "first_prints": row.first or 0,
                "reprints": reprint_total,
                "admin_prints": row.admin or 0,
                "reprint_rate": (round(reprint_total / total * 100, 1)
                                  if total else 0),
                "admin_rate": (round((row.admin or 0) / total * 100, 1)
                                if total else 0),
            },
            "by_type": [
                {
                    "doc_type": r[0],
                    "doc_type_text": {
                        "MEDICAL_RECORD": "门诊病历",
                        "PRESCRIPTION": "处方笺",
                        "EXAM_REQUEST": "检查申请单",
                        "LAB_REQUEST": "检验申请单",
                        "DIAGNOSIS_CERT": "诊断证明书",
                        "SICK_LEAVE": "病假条",
                    }.get(r[0], r[0]),
                    "count": r[1],
                }
                for r in by_type
            ],
            "reprint_reasons": [
                {
                    "reason": r[0] or "OTHER",
                    "reason_text": self.REASON_LABELS.get(
                        r[0] or "OTHER", "其他"),
                    "count": r[1],
                    "rate": (round(r[1] / reprint_total * 100, 1)
                              if reprint_total else 0),
                }
                for r in reasons
            ],
            "suggestions": self._build_suggestions(
                total, reprint_total, row.admin or 0),
        }

    @staticmethod
    def _build_suggestions(total, reprint, admin) -> List[str]:
        """生成改进建议"""
        tips = []

        if not total:
            return tips

        rate = reprint / total * 100
        if rate > 20:
            tips.append(
                f"补打率 {rate:.1f}% 偏高，建议加强患者告知"
                "（首次交付时提醒保管）")
        if admin > 0:
            tips.append(
                f"存在 {admin} 次行政补打，建议医务科抽查原因")

        return tips

    async def _get(self, document_id: int) -> M07Document:
        doc = (await self.db.execute(
            select(M07Document).where(
                M07Document.id == document_id,
                M07Document.is_deleted == False,
            )
        )).scalar_one_or_none()

        if not doc:
            raise BizException("0706001", "文书不存在")

        return doc

async def _verify_integrity():
    """抽查已签名文书的 hash 是否一致"""
    import hashlib
    import json
    from datetime import date, timedelta
    from sqlalchemy import select
    from app.core.database import AsyncSessionLocal
    from app.models.m07.document import M07Document

    bad = []

    async with AsyncSessionLocal() as db:
        since = date.today() - timedelta(days=7)

        rows = (await db.execute(
            select(M07Document).where(
                M07Document.signed_at >= since,
                M07Document.status.in_(("SIGNED", "PRINTED")),
                M07Document.is_deleted == False,
            ).limit(1000)
        )).scalars().all()

        for doc in rows:
            canonical = json.dumps(
                doc.content_snapshot, ensure_ascii=False,
                sort_keys=True, separators=(",", ":"), default=str)
            actual = hashlib.sha256(canonical.encode("utf-8")).hexdigest()

            if actual != doc.content_hash:
                bad.append({
                    "document_id": doc.id,
                    "document_no": doc.document_no,
                    "saved": doc.content_hash[:16],
                    "actual": actual[:16],
                })

            try:
                from app.clients.mpi_message_client import MpiMessageClient
                await MpiMessageClient().send(
                    biz_type="DOCUMENT_TAMPERED",
                    receivers=[],
                    params={"items": bad[:10], "count": len(bad)})
            except Exception:
                pass

        return {"checked": len(rows), "tampered": len(bad),
                "detail": bad}
