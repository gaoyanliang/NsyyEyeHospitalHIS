## 1. 模块概述

### 1.1 模块定位

医嘱下达是医生工作站的**核心产出**。它回答："**给这个患者安排什么治疗？谁去执行？执行到哪一步了？**"

```
┌──────────────────────────────────────────────────────────────┐
│  M07-01 就诊会话 + M07-02 诊断                                 │
└────────────────────────┬─────────────────────────────────────┘
                         │
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M07-03 医嘱下达（本文档）★全部下游的契约源                     │
│  药品 / 检查 / 检验 / 治疗 / 手术                               │
│  下达 → 收费 → 执行 → 完成                                     │
└────────────────────────┬─────────────────────────────────────┘
                         │ 医嘱流转
        ┌────────┬───────┼────────┬────────┬────────┐
        ▼        ▼       ▼        ▼        ▼        ▼
┌────────┐┌────────┐┌────────┐┌────────┐┌────────┐┌────────┐
│ M16    ││ M12    ││ M13    ││ M08    ││ M14    ││ M09    │
│ 收费   ││ 检查   ││ 检验   ││ 护理   ││ 药房   ││ 手术   │
└────────┘└────────┘└────────┘└────────┘└────────┘└────────┘
```

### 1.2 为什么医嘱要独立成子模块

| 理由 | 说明 |
|---|---|
| **统一契约** | M12/M13/M14/M09 都按同一套医嘱状态机回写 |
| **生命周期** | 下达→收费→执行→完成→退费，状态复杂 |
| **五类同构** | 药品/检查/检验/治疗/手术结构相似，可统一建模 |
| **防止丢失** | 医嘱一旦下达不可删除，只能作废 |
| **可追溯** | 谁下的、什么时候下的、什么时候执行的 |
| **套餐复用** | 白内障术前一套 8 项检查，需一键带出 |

### 1.3 与相邻模块的分工

| 能力 | 归属 |
|---|---|
| 诊断字典 | M01-09 |
| 药品/耗材/收费项目主数据 | M01-03/04/06 |
| 手术项目 | M01-07 |
| **医嘱录入与生命周期** | **M07-03 本子模块** |
| **医嘱套餐** | **M07-03 本子模块** |
| 处方明细与频次 | M07-05（药品类医嘱的深化） |
| 检查执行与报告 | M12 |
| 检验执行与报告 | M13 |
| 药品调剂发药 | M14 |
| 治疗执行 | M08 |
| 手术排程执行 | M09 |
| 收费 | M16 |
| 护士站医嘱执行 | M08 |

> **边界一句话：** 本子模块只管"**医嘱的开具与生命周期**"；药品处方的**用法用量深化**归 M07-05，**执行与报告**归各执行模块。

### 1.4 医嘱与处方的区别

| 维度 | 医嘱（Order） | 处方（Prescription） |
|---|---|---|
| 粒度 | 一条诊疗安排 | 一张处方单（含多条药品） |
| 涵盖 | 药品+检查+检验+治疗+手术 | **仅药品** |
| 用途 | 全流程管理 | **药事法规要求**（签名、审核、发药凭证） |
| 归属 | M07-03 | M07-05 |
| 关系 | 1 个药品医嘱 → 归属 1 张处方 | 1 张处方 → 1~N 条药品医嘱 |

```
本次就诊
├── 药品医嘱1 吡诺克辛钠滴眼液 ─┐
├── 药品医嘱2 拉坦前列素滴眼液 ─┴─► 处方P001（医生签名 → 药师审核 → 发药）
├── 检查医嘱1 眼科B超
├── 检验医嘱1 血糖
└── 治疗医嘱1 结膜囊冲洗
```

### 1.5 模块目标

- **快**：单条医嘱录入 ≤ 15 秒，套餐一键带出。
- **准**：项目编码来自 M01，不手工输入。
- **全**：五类医嘱统一建模，下游一致。
- **可追溯**：医嘱不可删除，只能作废。
- **防错**：重复医嘱、配伍禁忌、资质校验。

### 1.6 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 门诊医生 | 下达医嘱 | 开单、套餐、作废 |
| 护士 | 执行 | 查看医嘱、回写执行 |
| 药师 | 审方 | 处方审核（M07-05） |
| 收费员 | 收费 | 收费（M16） |
| 科主任 | 质量 | 查看医嘱合理性 |

## 3. 业务模型

### 3.1 医嘱类型模型（五类）

| 类型 | 代码 | 项目来源 | 下游执行方 | 特有字段 |
|---|---|---|---|---|
| **药品** | `DRUG` | `md_drug` | M14 药房 | 剂量、频次、途径（M07-05） |
| **检查** | `EXAM` | `md_exam_item` | M12 检查 | 部位、眼别、造影剂 |
| **检验** | `LAB` | `md_lab_item` / `md_lab_combo` | M13 检验 | 标本、加急 |
| **治疗** | `TREATMENT` | `md_charge_item`（治疗类） | M08 护理 | 次数、部位、眼别 |
| **手术** | `OPERATION` | `md_operation` | M09 手术 | 眼别、择期/日间、麻醉 |

### 3.2 医嘱状态机（核心契约）

```
        ┌──────────┐
        │  DRAFT   │  草稿（未提交）
        └────┬─────┘
             │ 提交
             ▼
        ┌──────────┐
        │  ISSUED  │  已下达（待缴费）
        └────┬─────┘
             │
    ┌────────┼────────────┬──────────────┬──────────────┐
    │ 已收费  │ 作废        │ 医师停止       │ 系统取消       │
    ▼        ▼            ▼              ▼              ▼
┌──────────┐┌──────────┐┌──────────┐  ┌──────────┐  ┌──────────┐
│  PAID    ││CANCELLED ││ STOPPED  │  │ ABANDONED│  │ REJECTED │
└────┬─────┘└──────────┘└──────────┘  └──────────┘  └──────────┘
     │
     │ 开始执行
     ▼
┌──────────┐
│ EXECUTING│  执行中
└────┬─────┘
     │
     ├──── 完成 ────► ┌──────────┐
     │                │COMPLETED │
     │                └──────────┘
     │
     └──── 退费 ────► ┌──────────┐
                      │ REFUNDED │
                      └──────────┘
```

**状态说明：**

| 状态 | 说明 | 可编辑 | 所属方 |
|---|---|---|---|
| `DRAFT` | 草稿，未提交 | ✅ | M07 |
| `ISSUED` | 已下达，待缴费 | ✅ | M07 |
| `PAID` | 已缴费，待执行 | ❌ | M16 回写 |
| `EXECUTING` | 执行中 | ❌ | 执行方回写 |
| `COMPLETED` | 已完成 | ❌ | 执行方回写 |
| `STOPPED` | 医生停止 | ❌ | M07 |
| `CANCELLED` | 作废 | ❌ | M07 |
| `REFUNDED` | 已退费 | ❌ | M16 回写 |
| `REJECTED` | 被拒（如药师拒审） | ❌ | 执行方回写 |
| `ABANDONED` | 系统取消（超时未缴费） | ❌ | 系统 |

### 3.3 医嘱状态流转权责

**关键原则：谁能改哪个状态**

| 状态变更 | 触发方 | 接口 |
|---|---|---|
| `DRAFT → ISSUED` | M07 医生 | `POST /orders/{id}/issue` |
| `ISSUED → PAID` | **M16** | `POST /internal/v1/m07/orders/on-paid` |
| `PAID → EXECUTING` | **执行方** | `POST /internal/v1/m07/orders/on-executing` |
| `EXECUTING → COMPLETED` | **执行方** | `POST /internal/v1/m07/orders/on-completed` |
| `PAID/EXECUTING → REFUNDED` | **M16** | `POST /internal/v1/m07/orders/on-refunded` |
| `ISSUED/PAID → CANCELLED` | M07 医生 | `POST /orders/{id}/cancel` |
| `ISSUED/PAID → STOPPED` | M07 医生 | `POST /orders/{id}/stop` |
| 任意 → `REJECTED` | 执行方 | `POST /internal/v1/m07/orders/on-rejected` |

> **铁律：** M07 **不直接**把医嘱置为 `PAID`/`COMPLETED`，**必须**由下游回写。

### 3.4 医嘱项目模型

#### 3.4.1 项目来源映射

```
医嘱类型 → 主数据表 → 收费项目
DRUG        md_drug              → md_charge_item（药品类）
EXAM        md_exam_item         → md_charge_item（检查类）
LAB         md_lab_item/combo    → md_charge_item（检验类）
TREATMENT   md_charge_item       → 自身（治疗类）
OPERATION   md_operation         → md_charge_item（手术类）
```

#### 3.4.2 多项目映射

**一个医嘱可能对应多个收费项：**

```
检验组合"肝功能"：
  → 收费项目 "肝功能检查"（打包价）
  或
  → 收费项目 "ALT + AST + TBIL + DBIL..."（逐项计价）

检查"OCT黄斑"：
  → 收费项目 "OCT检查" × 1（单眼）
  → 收费项目 "OCT检查" × 2（双眼，charge_by_eye = TRUE）
```

**设计：** 医嘱表存 `charge_item_code`，实际计费由 M16 根据 `md_exam_charge_rel` / `md_operation_charge_rel` 展开。

### 3.5 眼别在医嘱中的应用

**眼科医嘱大量按眼别计价/执行：**

| 场景 | 眼别处理 |
|---|---|
| 检查（OCT、眼压） | 单眼 1 次，双眼 2 次 |
| 滴眼液 | 按眼别（左/右/双） |
| 手术 | **必须指定单眼** |
| 治疗（结膜囊冲洗） | 可双 |
| 检验（血糖） | 不适用 |

```
收费项目 charge_by_eye = TRUE：
  眼别 OD → 数量 1
  眼别 OS → 数量 1
  眼别 OU → 数量 2  ← 自动翻倍
```

套餐名：白内障术前检查

  · 眼科 B 超          EXAM
  · 眼压检查           EXAM
  · 角膜内皮计数        EXAM

  · 血常规             LAB

#### 3.6.2 套餐来源

|---|---|---|
| 个人套餐 | 医生自建 | 本人 |
| 科室套餐 | 科主任维护 | 全科 |

### 3.7 医嘱合理性校验模型

#### 3.7.1 校验类型

| 类型 | 说明 | 级别 |
|---|---|---|
| **重复校验** | 同一患者同日同项目重复 | 警告 |
| **冲突校验** | 检查与检验互斥（如需空腹的检验与已进食） | 警告 |
| **配伍校验** | 药品配伍禁忌 | **阻断**（M07-05） |
| **过敏校验** | 药品过敏 | **阻断**（M07-05） |
| **资质校验** | 手术级别 > 医生授权 | **阻断** |
| **频次校验** | 超出单次最大数量 | 警告 |
| **适应症校验** | 诊断与项目不符 | 提示 |
| **库存校验** | 药品库存不足 | 提示 |

#### 3.7.2 校验结果分级

| 级别 | 行为 | 提示色 |
|---|---|---|
| `BLOCK` | 禁止提交 | 红 |
| `WARN` | 提示，可确认继续 | 橙 |
| `INFO` | 仅提示 | 蓝 |

### 3.8 医嘱与收费的关系

```
医嘱下达（ISSUED）
   ↓ 医生完成就诊 / 患者去缴费
M16 收费
   ↓ 回写
医嘱 PAID
   ↓ 执行方执行
医嘱 EXECUTING → COMPLETED
```

**关键规则：**

- **未缴费不可执行**（除紧急抢救，走欠费流程）
- **退费需先退回医嘱**（若已执行则不可退）
- **医嘱金额在收费时确定**（不存医嘱表，避免价格变动）

### 3.9 医嘱与诊断的关系

```
诊断：糖尿病视网膜病变 H36.001（双眼）
   ↓
医嘱：眼底照相、OCT、FFA  ← 合理
医嘱：白内障手术          ← 提示"与诊断不符"
```

**用途：**

1. 合理用药审核依据
2. 医保/商保报销依据
3. 医嘱合理性考核

**约束：** 医嘱可关联 1 个主诊断（可空）。

        "REFUNDED": "已退费", "REJECTED": "已拒绝",

    # ---------- 下达医嘱 ----------
    async def create(self, payload, user) -> dict:
        """下达医嘱"""
        encounter = await self._get_encounter(payload.encounter_id)

        if encounter.status in ("CLOSED", "TRANSFERRED", "CANCELLED"):
            raise BizException("0703020", "就诊已完成，不可开立医嘱")

        # 项目校验
        item = await self._resolve_item(payload.order_type, payload.item_code)

        if not item:
            raise BizException("0703003", "项目编码不存在或已停用")

        # 眼别校验
        eye_side, quantity = self._resolve_eye_side(
            item, payload.eye_side, payload.quantity)

        # 数量校验
        if quantity <= 0:
            raise BizException("0703034", "医嘱数量必须为正数")

        max_qty = item.get("max_qty")
        if max_qty and quantity > max_qty:
            raise BizException("0703014",
                f"数量超出单次上限（最大 {max_qty}）")

        # 合理性校验
        from app.services.m07.order_validate_service import OrderValidateService
        validator = OrderValidateService(self.db)
        validation = await validator.validate_single(
            encounter, payload, item, eye_side, quantity, user)

        if validation["blocks"]:
            raise BizException("0703022", "合理性校验未通过",
                data={
                    "blocks": validation["blocks"],
                    "warnings": validation["warnings"],
                })

        # 创建
        order_no = f"OR{datetime.now().strftime('%Y%m%d')}" \
                   f"{uuid.uuid4().hex[:4].upper()}"

        unit_price = Decimal(str(item.get("price", 0)))
        total_amount = unit_price * quantity

            order_no=order_no,
            encounter_id=payload.encounter_id,
            encounter_no=encounter.encounter_no,
            patient_id=encounter.patient_id,
            patient_name=encounter.patient_name,
            dept_id=encounter.dept_id,
            doctor_id=getattr(user, "id", None),
            doctor_name=getattr(user, "name", None),
            order_date=encounter.encounter_date,
            order_type=payload.order_type,
            item_code=payload.item_code,
            item_name=item.get("name"),
            spec=item.get("spec"),
            charge_item_code=item.get("charge_item_code"),
            eye_side=eye_side,
            eye_side_text=self.EYE_SIDE_LABELS.get(eye_side, ""),
            quantity=Decimal(str(quantity)),
            unit=item.get("unit"),
            unit_price=unit_price,
            total_amount=total_amount,
            diagnosis_id=payload.diagnosis_id,
            remark=payload.remark,
            need_appointment=payload.need_appointment,
            need_fasting=payload.need_fasting,
            sample_type=item.get("sample_type"),
            is_urgent=payload.is_urgent or False,
            status="ISSUED" if payload.auto_issue else "DRAFT",
            issued_at=datetime.now() if payload.auto_issue else None,
        )
        self.db.add(order)
        await self.db.flush()

        # 日志
        self.db.add(M07OrderLog(
            order_id=order.id,
            order_no=order_no,
            encounter_id=payload.encounter_id,
            action="CREATE" if payload.auto_issue else "DRAFT",

                "qty": float(quantity),
                "status": order.status,

            operator_name=getattr(user, "name", None),
        ))

        await self._update_encounter_summary(payload.encounter_id)

        await self._record_common(payload.order_type, payload.item_code,

            "validation": validation,

    # ---------- 项目解析 ----------
    async def _resolve_item(self, order_type: str,
                              item_code: str) -> Optional[dict]:
        """按类型解析项目主数据"""
        if order_type == "DRUG":
            return await self.mdm.get_drug(item_code)
        if order_type == "EXAM":
            return await self.mdm.get_exam_item(item_code)
        if order_type == "LAB":
            item = await self.mdm.get_lab_item(item_code)
            if not item:
                item = await self.mdm.get_lab_combo(item_code)
            return item
        if order_type == "TREATMENT":
            return await self.mdm.get_charge_item(item_code)
        if order_type == "OPERATION":
            return await self.mdm.get_operation(item_code)
        return None

    # ---------- 眼别与数量 ----------
    def _resolve_eye_side(self, item: dict, eye_side: Optional[str],
                            quantity) -> tuple:
        """眼别与数量的联动计算"""
        charge_by_eye = item.get("charge_by_eye", False)
        is_ophthalmic = item.get("is_ophthalmic", charge_by_eye)

        # 眼科项目必须选眼别
        if charge_by_eye:
            if not eye_side or eye_side == "NA":
                raise BizException("0703013",
                    "眼别必填（该项目按眼别计价）",
                    data={
                        "item_code": item.get("code"),
                        "item_name": item.get("name"),
                        "charge_by_eye": True,
                        "allowed_eye_sides": ["OD", "OS", "OU"],
                        "suggestion": "请选择右眼、左眼或双眼；"
                                       "选择双眼时数量将自动翻倍",
                    })

            # 双眼自动翻倍
            if eye_side == "OU":
                quantity = Decimal(str(quantity)) * 2

            return eye_side, quantity

        # 手术必须单眼
        if item.get("order_type") == "OPERATION":
            if eye_side not in ("OD", "OS"):
                raise BizException("0703007", "手术必须指定单眼（右眼或左眼）")

            return eye_side, quantity

        return eye_side or "NA", quantity

    # ---------- 作废 ----------
    async def cancel(self, order_id: int, payload, user) -> dict:
        """作废医嘱"""
        order = await self._get(order_id)

        if order.status not in self.CANCELLABLE:
            if order.status in ("EXECUTING", "COMPLETED"):
                raise BizException("0703005",
                    f"该医嘱已{self.STATUS_LABELS.get(order.status)}，不可作废",
                    data={
                        "order_id": order.id,
                        "item_name": order.item_name,
                        "status": order.status,
                        "executed_at": (order.executed_at.isoformat()
                                         if order.executed_at else None),
                    })
            raise BizException("0703002",
                f"当前状态 {self.STATUS_LABELS.get(order.status)} 不可作废")

        # 已缴费需退费
        need_refund = order.status == "PAID"

        if need_refund and not payload.reason_detail:
            raise BizException("0703006", "已缴费医嘱作废需填写原因")

        if not payload.reason_type:
            raise BizException(40001, "作废原因必选")

        before_status = order.status
        order.status = "CANCELLED"
        order.cancelled_at = datetime.now()
        order.cancel_reason_type = payload.reason_type
        order.cancel_reason = payload.reason_detail
        order.cancelled_by = getattr(user, "id", None)
        order.cancelled_by_name = getattr(user, "name", None)

        self.db.add(M07OrderLog(
            order_id=order.id,
            order_no=order.order_no,
            encounter_id=order.encounter_id,
            action="CANCEL",
            before_json={"status": before_status},
            after_json={"status": "CANCELLED",
                         "need_refund": need_refund},
            reason=payload.reason_type,
            detail=payload.reason_detail,
            operator_id=getattr(user, "id", None),
            operator_name=getattr(user, "name", None),
        ))

        await self._update_encounter_summary(order.encounter_id)
        await self.db.commit()

        # 已缴费触发退费
        refund_info = None
        if need_refund:
            refund_info = {
                "needed": True,
                "amount": float(order.total_amount),
                "billing_no": order.billing_no,
                "status": "PENDING",
                "message": "已提交退费申请，等待 M16 处理",
            }

        return {
            "order_id": order.id,
            "order_no": order.order_no,
            "status": "CANCELLED",
            "status_text": "已作废",
            "cancelled_at": order.cancelled_at.isoformat(),
            "reason_type": payload.reason_type,
            "reason_detail": payload.reason_detail,
            "refund": refund_info,
            "encounter_summary": await self._get_summary(
                order.encounter_id),
        }

    async def _update_encounter_summary(self, encounter_id: int) -> None:
        """更新会话的医嘱计数"""
        cnt = (await self.db.execute(
            select(func.count()).select_from(M07Order).where(
                M07Order.encounter_id == encounter_id,
                M07Order.status.notin_(("CANCELLED", "ABANDONED")),
                M07Order.is_deleted == False,
            )
        )).scalar_one()

        await self.db.execute(
            M07Encounter.__table__.update()
            .where(M07Encounter.id == encounter_id)
            .values(order_count=cnt)
        )

    async def _get_summary(self, encounter_id: int) -> dict:
        """获取医嘱摘要"""
        rows = (await self.db.execute(
            select(
                M07Order.status,
                func.count().label("cnt"),
                func.coalesce(func.sum(M07Order.total_amount), 0).label("amt"),
            ).where(
                M07Order.encounter_id == encounter_id,
                M07Order.is_deleted == False,
            ).group_by(M07Order.status)
        )).all()

        by_status = {r[0]: r[1] for r in rows}
        total_amt = sum(float(r[2]) for r in rows)

        return {
            "order_count": sum(by_status.values()),
            "unpaid_count": by_status.get("ISSUED", 0),
            "paid_count": by_status.get("PAID", 0),
            "executing_count": by_status.get("EXECUTING", 0),
            "completed_count": by_status.get("COMPLETED", 0),
            "cancelled_count": by_status.get("CANCELLED", 0),
            "total_amount": round(total_amt, 2),
        }

# app/services/m07/order_callback_service.py
"""医嘱回调服务（下游回写的唯一入口）"""
from datetime import datetime
from typing import Optional

from sqlalchemy import select, func
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.m07.order import M07Order, M07OrderLog
from app.core.exceptions import BizException
from app.core.redis import redis_client


class OrderCallbackService:
    """下游回写医嘱状态（核心契约）"""

    STATUS_LABELS = {
        "PAID": "已缴费", "EXECUTING": "执行中",
        "COMPLETED": "已完成", "REFUNDED": "已退费",
        "REJECTED": "已拒绝",
    }

    def __init__(self, db: AsyncSession):
        self.db = db

    # ---------- 收费回写 ----------
    async def on_paid(self, payload: dict) -> dict:
        """M16 收费成功后回写"""
        order_ids = payload.get("order_ids") or []
        billing_no = payload.get("billing_no")

        if not order_ids:
            return {"updated": 0, "message": "无医嘱需要更新"}

        updated = 0
        failed = []

        for oid in order_ids:
            order = await self._get(oid)

            if not order:
                failed.append({"order_id": oid, "reason": "医嘱不存在"})
                continue

            # 幂等：已缴费跳过
            if order.status == "PAID":
                updated += 1
                continue

            if order.status != "ISSUED":
                failed.append({
                    "order_id": oid,
                    "reason": f"状态 {order.status} 不可缴费",
                })
                continue

            order.status = "PAID"
            order.billing_no = billing_no
            order.paid_at = datetime.now()
            order.paid_amount = order.total_amount

            self.db.add(M07OrderLog(
                order_id=order.id,
                order_no=order.order_no,
                encounter_id=order.encounter_id,
                action="PAY",
                after_json={
                    "status": "PAID",
                    "billing_no": billing_no,
                },
                operator_name="收费系统",
            ))

            updated += 1

        await self.db.commit()

        return {
            "billing_no": billing_no,
            "updated": updated,
            "failed": len(failed),
            "failures": failed,
            "message": f"已更新 {updated} 条医嘱",
        }

    # ---------- 执行开始 ----------
    async def on_executing(self, payload: dict) -> dict:
        """执行方开始执行"""
        order = await self._get(payload.get("order_id"))

        if not order:
            raise BizException("0703001", "医嘱不存在")

        if order.status == "EXECUTING":
            return self._result(order, "幂等：已执行中")

        if order.status != "PAID":
            raise BizException("0703002",
                f"医嘱状态 {order.status} 不可执行（未缴费）")

        order.status = "EXECUTING"
        order.executing_at = datetime.now()
        order.executor_module = payload.get("executor_module")

        self.db.add(M07OrderLog(
            order_id=order.id,
            order_no=order.order_no,
            encounter_id=order.encounter_id,
            action="EXECUTE_START",
            after_json={
                "status": "EXECUTING",
                "module": payload.get("executor_module"),
            },
            operator_name=payload.get("executor_module"),
        ))

        await self.db.commit()

        return self._result(order, "执行已开始")

    # ---------- 执行完成 ----------
    async def on_completed(self, payload: dict) -> dict:
        """执行方完成执行"""
        order = await self._get(payload.get("order_id"))

        if not order:
            raise BizException("0703001", "医嘱不存在")

        # 幂等
        if order.status == "COMPLETED":
            return self._result(order, "幂等：已完成")

        if order.status not in ("PAID", "EXECUTING"):
            raise BizException("0703002",
                f"医嘱状态 {order.status} 不可完成")

        order.status = "COMPLETED"
        order.executed_at = datetime.now()
        order.executor_module = payload.get("executor_module")

        result_ref = payload.get("result_ref") or {}
        order.result_ref = result_ref
        order.report_ready = result_ref.get("has_report", False)
        order.has_critical_value = result_ref.get(
            "has_critical_value", False)

        self.db.add(M07OrderLog(
            order_id=order.id,
            order_no=order.order_no,
            encounter_id=order.encounter_id,
            action="EXECUTE_COMPLETE",
            after_json={
                "status": "COMPLETED",
                "module": payload.get("executor_module"),
                "result_ref": result_ref,
            },
            operator_name=payload.get("executor_module"),
        ))

        await self.db.commit()

        # 危急值告警
        if order.has_critical_value:
            try:
                from app.clients.mpi_message_client import MpiMessageClient
                await MpiMessageClient().send(
                    biz_type="CRITICAL_VALUE",
                    receivers=[order.doctor_id],
                    params={
                        "order_no": order.order_no,
                        "item_name": order.item_name,
                        "patient_name": order.patient_name,
                    })
            except Exception:
                pass

        return self._result(order, "执行已完成")

    # ---------- 退费回写 ----------
    async def on_refunded(self, payload: dict) -> dict:
        """M16 退费成功后回写"""
        order = await self._get(payload.get("order_id"))

        if not order:
            raise BizException("0703001", "医嘱不存在")

        if order.status == "REFUNDED":
            return self._result(order, "幂等：已退费")

        # 已执行不可退
        if order.status in ("EXECUTING", "COMPLETED"):
            raise BizException("0703005", "该医嘱已执行，不可退费",
                data={
                    "order_id": order.id,
                    "item_name": order.item_name,
                    "status": order.status,
                    "executed_at": (order.executed_at.isoformat()
                                     if order.executed_at else None),
                    "suggestion": "已执行的检查不可退费",
                })

        order.status = "REFUNDED"
        order.refunded_at = datetime.now()
        order.refund_amount = payload.get("refund_amount")
        order.refund_no = payload.get("refund_no")
        order.refund_reason = payload.get("reason")

        self.db.add(M07OrderLog(
            order_id=order.id,
            order_no=order.order_no,
            encounter_id=order.encounter_id,
            action="REFUND",
            after_json={
                "status": "REFUNDED",
                "refund_no": payload.get("refund_no"),
                "amount": payload.get("refund_amount"),
            },
            detail=payload.get("reason"),
            operator_name="收费系统",
        ))

        await self.db.commit()

        return self._result(order, "医嘱已退回")

    # ---------- 拒绝 ----------
    async def on_rejected(self, payload: dict) -> dict:
        """执行方拒绝（如药师拒审）"""
        order = await self._get(payload.get("order_id"))

        if not order:
            raise BizException("0703001", "医嘱不存在")

        if not payload.get("reason"):
            raise BizException("0703028", "退回原因必填")

        order.status = "REJECTED"
        order.rejected_at = datetime.now()
        order.reject_reason = payload.get("reason")
        order.reject_by_module = payload.get("reject_by_module")
        order.reject_by_name = payload.get("reject_by_name")

        self.db.add(M07OrderLog(
            order_id=order.id,
            order_no=order.order_no,
            encounter_id=order.encounter_id,
            action="REJECT",
            after_json={"status": "REJECTED"},
            detail=payload.get("reason"),
            operator_name=payload.get("reject_by_name"),
        ))

        await self.db.commit()

        return self._result(order, "医嘱已被拒绝")

    # ---------- 辅助 ----------
    async def _get(self, order_id) -> Optional[M07Order]:
        if not order_id:
            return None

        return (await self.db.execute(
            select(M07Order).where(
                M07Order.id == order_id,
                M07Order.is_deleted == False,
            )
        )).scalar_one_or_none()

    def _result(self, order: M07Order, message: str) -> dict:
        return {
            "order_id": order.id,
            "order_no": order.order_no,
            "status": order.status,
            "status_text": self.STATUS_LABELS.get(order.status, order.status),
            "executed_at": (order.executed_at.isoformat()
                             if order.executed_at else None),
            "executed_by_module": order.executor_module,
            "report_ready": order.report_ready,
            "message": message,
        }

# app/services/m07/order_validate_service.py
"""医嘱合理性校验服务"""
from datetime import date, datetime
from decimal import Decimal
from typing import Optional, List

from sqlalchemy import select, func
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.m07.order import M07Order
from app.core.exceptions import BizException
from app.clients.mdm_client import MdmClient


class OrderValidateService:
    """医嘱合理性校验（8 类）"""

    def __init__(self, db: AsyncSession):
        self.db = db
        self.mdm = MdmClient()

    async def validate(self, payload, user) -> dict:
        """批量校验"""
        encounter = await self._get_encounter(payload.encounter_id)

        blocks = []
        warnings = []
        infos = []

        for idx, item in enumerate(payload.orders or []):
            result = await self._validate_one(
                encounter, item, idx, user)

            blocks.extend(result["blocks"])
            warnings.extend(result["warnings"])
            infos.extend(result["infos"])

        return {
            "passed": len(blocks) == 0,
            "blocks": blocks,
            "warnings": warnings,
            "infos": infos,
        }

    async def validate_single(self, encounter, payload, item: dict,
                                eye_side: str, quantity,
                                user) -> dict:
        """单条校验（创建时调用）"""
        return await self._validate_one(
            encounter,
            {
                "order_type": payload.order_type,
                "item_code": payload.item_code,
                "eye_side": eye_side,
                "quantity": float(quantity),
            },
            0, user, resolved_item=item)

    async def _validate_one(self, encounter, item: dict, idx: int,
                              user, resolved_item: Optional[dict] = None) -> dict:
        """单条医嘱校验"""
        blocks = []
        warnings = []
        infos = []

        order_type = item.get("order_type")
        item_code = item.get("item_code")
        eye_side = item.get("eye_side") or "NA"
        quantity = Decimal(str(item.get("quantity", 1)))

        master = resolved_item or await self._resolve(item_code, order_type)

        if not master:
            blocks.append({
                "code": "V-ITEM",
                "type": "ITEM",
                "level": "BLOCK",
                "index": idx,
                "message": "项目不存在或已停用",
                "detail": f"编码 {item_code}",
            })
            return {"blocks": blocks, "warnings": warnings, "infos": infos}

        # ---------- 1. 重复校验 ----------
        dup = await self._check_duplicate(
            encounter.id, item_code, eye_side)

        if dup:
            warnings.append({
                "code": "V-DUP",
                "type": "DUPLICATE",
                "level": "WARN",
                "index": idx,
                "message": "重复医嘱",
                "detail": f"今日已开立相同项目（{dup.order_no}）",
                "existing_order": {
                    "order_id": dup.id,
                    "order_no": dup.order_no,
                    "issued_at": (dup.issued_at.isoformat()
                                   if dup.issued_at else None),
                    "status": dup.status,
                },
                "can_force": True,
            })

        # ---------- 2. 手术资质校验 ----------
        if order_type == "OPERATION":
            auth = await self._check_operation_auth(
                master, user)

            if not auth["passed"]:
                blocks.append({
                    "code": "V-AUTH",
                    "type": "QUALIFICATION",
                    "level": "BLOCK",
                    "index": idx,
                    "message": "医生不具备该手术授权级别",
                    "detail": (f"手术级别 {master.get('surgery_level')}，"
                                f"医生授权 {auth['authorized_level']}"),
                    "action": "请指定具有授权的医师主刀",
                    "authorized_doctors": auth.get("authorized_doctors", []),
                })

            # ---------- 3. 术前准备校验 ----------
            prep = await self._check_operation_prepare(
                encounter.id, master.get("code"))

            if prep["missing"]:
                blocks.append({
                    "code": "V-PREOP",
                    "type": "PREPARATION",
                    "level": "BLOCK",
                    "index": idx,
                    "message": "术前检查未完成",
                    "detail": "缺少：" + "、".join(prep["missing"]),
                    "action": "请先开立缺失的术前检查",
                    "missing_items": prep["missing_codes"],
                })

        # ---------- 4. 眼别校验 ----------
        if master.get("charge_by_eye") and order_type != "OPERATION":
            if eye_side == "NA":
                blocks.append({
                    "code": "V-EYE",
                    "type": "EYE_SIDE",
                    "level": "BLOCK",
                    "index": idx,
                    "message": "眼别必填",
                    "detail": "该项目按眼别计价",
                })

        if order_type == "OPERATION" and eye_side not in ("OD", "OS"):
            blocks.append({
                "code": "V-EYE-OP",
                "type": "EYE_SIDE",
                "level": "BLOCK",
                "index": idx,
                "message": "手术必须指定单眼",
                "detail": "请选择右眼或左眼",
            })

        # ---------- 5. 数量校验 ----------
        max_qty = master.get("max_qty")
        if max_qty and quantity > Decimal(str(max_qty)):
            warnings.append({
                "code": "V-QTY",
                "type": "QUANTITY",
                "level": "WARN",
                "index": idx,
                "message": "数量超出常规",
                "detail": f"常规上限 {max_qty}，本次 {quantity}",
                "can_force": True,
            })

        # ---------- 6. 库存校验（药品） ----------
        if order_type == "DRUG":
            stock = master.get("stock_quantity", 0)
            if stock < quantity:
                infos.append({
                    "code": "V-STOCK",
                    "type": "STOCK",
                    "level": "INFO",
                    "index": idx,
                    "message": "库存不足",
                    "detail": f"库存 {stock}，需求 {quantity}",
                })

        # ---------- 7. 适应症校验 ----------
        diag = await self._get_primary_diagnosis(encounter.id)
        if diag and master.get("indication_codes"):
            indications = (master.get("indication_codes") or "").split(",")
            if (diag["diagnosis_code"] not in indications
                    and master.get("is_ophthalmic")):
                warnings.append({
                    "code": "V-DIAG",
                    "type": "INDICATION",
                    "level": "WARN",
                    "index": idx,
                    "message": "医嘱与诊断关联度较低",
                    "detail": (f"主诊断 {diag['diagnosis_code']} "
                                f"不在该项目的适应症列表"),
                    "can_force": True,
                })

        # ---------- 8. 空腹校验 ----------
        if item.get("need_fasting"):
            last_meal = encounter.last_meal_at
            if last_meal:
                from datetime import timedelta
                if datetime.now() - last_meal < timedelta(hours=8):
                    warnings.append({
                        "code": "V-FASTING",
                        "type": "PREPARATION",
                        "level": "WARN",
                        "index": idx,
                        "message": "检验需空腹",
                        "detail": f"最后进食 {last_meal.strftime('%H:%M')}，"
                                   f"未满 8 小时",
                        "can_force": True,
                    })

        return {"blocks": blocks, "warnings": warnings, "infos": infos}

    # ---------- 重复校验 ----------
    async def _check_duplicate(self, encounter_id: int, code: str,
                                 eye_side: str) -> Optional[M07Order]:
        """检查今日是否已开立相同项目"""
        return (await self.db.execute(
            select(M07Order).where(
                M07Order.encounter_id == encounter_id,
                M07Order.item_code == code,
                M07Order.eye_side == eye_side,
                M07Order.status.notin_(("CANCELLED", "REFUNDED", "ABANDONED")),
                M07Order.is_deleted == False,
            ).limit(1)
        )).scalar_one_or_none()

    # ---------- 手术资质 ----------
    async def _check_operation_auth(self, operation: dict, user) -> dict:
        """校验医生手术授权"""
        doctor_level = await self.mdm.get_doctor_surgery_level(
            getattr(user, "id", None))

        surgery_level = operation.get("surgery_level")

        if not surgery_level:
            return {"passed": True, "authorized_level": None}

        level_order = {"一级": 1, "二级": 2, "三级": 3, "四级": 4}
        required = level_order.get(surgery_level, 0)
        authorized = level_order.get(doctor_level, 0)

        if required <= authorized:
            return {
                "passed": True,
                "authorized_level": doctor_level,
            }

        # 找有资质的医生
        authorized_doctors = await self.mdm.get_doctors_by_surgery_level(
            surgery_level, dept_id=None)

        return {
            "passed": False,
            "authorized_level": doctor_level,
            "required_level": surgery_level,
            "authorized_doctors": authorized_doctors or [],
        }

    # ---------- 术前准备 ----------
    async def _check_operation_prepare(self, encounter_id: int,
                                          operation_code: str) -> dict:
        """检查术前准备项是否已完成"""
        required = await self.mdm.get_operation_prepare_items(
            operation_code)

        if not required:
            return {"missing": [], "missing_codes": []}

        # 已开立的检查检验
        existing = (await self.db.execute(
            select(M07Order.item_code).where(
                M07Order.encounter_id == encounter_id,
                M07Order.order_type.in_(("EXAM", "LAB")),
                M07Order.status.notin_(("CANCELLED", "REFUNDED", "ABANDONED")),
                M07Order.is_deleted == False,
            )
        )).all()

        existing_codes = {r[0] for r in existing}

        missing = []
        missing_codes = []

        for item in required:
            if item["item_code"] not in existing_codes:
                missing.append(item["item_name"])
                missing_codes.append(item["item_code"])

        return {"missing": missing, "missing_codes": missing_codes}

    # ---------- 主诊断 ----------
    async def _get_primary_diagnosis(self, encounter_id: int) -> Optional[dict]:
        from app.models.m07.diagnosis import M07Diagnosis

        d = (await self.db.execute(
            select(M07Diagnosis).where(
                M07Diagnosis.encounter_id == encounter_id,
                M07Diagnosis.diagnosis_type == "PRIMARY",
                M07Diagnosis.status == "ACTIVE",
                M07Diagnosis.is_deleted == False,
            )
        )).scalar_one_or_none()

        if not d:
            return None

        return {
            "diagnosis_code": d.diagnosis_code,
            "diagnosis_name": d.diagnosis_name,
        }

    async def _resolve(self, code: str, order_type: str) -> Optional[dict]:
        if order_type == "DRUG":
            return await self.mdm.get_drug(code)
        if order_type == "EXAM":
            return await self.mdm.get_exam_item(code)
        if order_type == "LAB":
            return await self.mdm.get_lab_item(code)
        if order_type == "TREATMENT":
            return await self.mdm.get_charge_item(code)
        if order_type == "OPERATION":
            return await self.mdm.get_operation(code)
        return None

    async def _get_encounter(self, encounter_id: int):
        from app.models.m07.encounter import M07Encounter

        e = (await self.db.execute(
            select(M07Encounter).where(M07Encounter.id == encounter_id)
        )).scalar_one_or_none()

        if not e:
            raise BizException(54701, "就诊会话不存在")

        return e
