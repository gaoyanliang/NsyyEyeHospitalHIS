## 1. 模块概述

### 1.1 模块定位

处方与用药是**药品医嘱的深化层**。它回答："**这个药怎么用？一天几次？滴哪只眼？用几天？谁能开？**"

```
┌──────────────────────────────────────────────────────────────┐
│  M07-03 医嘱下达（药品医嘱 ISSUED）                            │
│  · 开了什么药：吡诺克辛钠滴眼液 × 1 支                           │
│  · 只说"要这个药"                                              │
└────────────────────────┬─────────────────────────────────────┘
                         │ 深化
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M07-05 处方与用药（本文档）★药事法规载体                       │
│  · 怎么用：滴眼，每次 1 滴，每日 4 次，右眼                      │
│  · 用多久：7 天                                                │
│  · 谁能开：抗菌药物分级                                        │
│  · 合不合理：配伍禁忌、重复用药、超剂量                          │
│  · 谁签的：医生签名（法定凭证）                                  │
└────────────────────────┬─────────────────────────────────────┘
                         │ 审核通过
        ┌────────────────┼────────────────┬────────────────┐
        ▼                ▼                ▼                ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ M14 药房调剂 │ │ M16 收费     │ │ 06 文书签署   │ │ M19 随访     │
└──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘
```

### 1.2 为什么处方要独立成子模块

| 理由 | 说明 |
|---|---|
| **法定凭证** | 处方是《处方管理办法》规定的法定医疗文书，须签名、编号、留存 |
| **药事管理** | 抗菌药物分级、麻醉药品、贵重药品有专门管控要求 |
| **合理用药** | 配伍禁忌、重复用药、超剂量需要审核拦截 |
| **眼科特殊** | 滴眼液用法独特（"每次 1 滴"、眼别、频次），通用处方模型不适用 |
| **审核闭环** | 药师审核 → 通过/退回 → 医生改方，是完整工作流 |
| **数据上报** | 抗菌药物使用率、处方合格率是医院考核指标 |

### 1.3 与 M07-03 医嘱下达的分工

| 维度 | M07-03 医嘱下达 | M07-05 处方与用药 |
|---|---|---|
| 粒度 | 一条药品医嘱 | 一张处方（含 1~5 条药品） |
| 关注点 | **开了什么药、几支、多少钱** | **怎么用、合不合理、谁签字** |
| 数据表 | `m07_order` | `m07_prescription` + `m07_prescription_item` |
| 用法用量 | 不存（仅备注） | **完整存储**（剂量/频次/途径/疗程/眼别） |
| 审核 | 无 | **药师审核** |
| 签名 | 无 | **法定签名** |
| 生命周期 | 缴费→执行→完成 | 开具→审核→调配→发药 |

```
一条药品医嘱在两张表里的对应关系：

m07_order
├── order_type = 'DRUG'
├── item_code  = 'DRUG_PIRENOXINE'
├── quantity   = 1
├── unit       = '支'
└── prescription_item_id ──┐  关联
                            ▼
m07_prescription_item
├── drug_code    = 'DRUG_PIRENOXINE'
├── single_dose  = 1
├── dose_unit    = '滴'          ← 眼科特有
├── frequency    = 'QID'
├── route        = 'TOPICAL_EYE' ← 眼科特有
├── eye_side     = 'OD'
├── duration_days= 7
└── quantity     = 1
```

> **边界一句话：** M07-03 管**开单与收费**，M07-05 管**用法与合规**；两者通过 `prescription_item_id` 关联，不重复存储。

### 1.4 眼科处方的特殊性

#### 1.4.1 滴眼液的用法模型

**通用处方模型（不适用于眼科）：**

```
阿莫西林胶囊 0.5g × 24 粒
用法：口服，每次 0.5g，每日 3 次
```

**眼科滴眼液模型：**

```
左氧氟沙星滴眼液 5ml × 1 支
用法：滴眼，每次 1 滴，每日 4 次，右眼
疗程：7 天

关键差异：
· 剂量单位是"滴"不是"片/粒/ml"
· 途径是"滴眼"（TOPICAL_EYE）
· 必须指定眼别（OD/OS/OU）
· 频次常用 QID/TID/BID/QD/Q2H（每 2 小时）
· 疗程按天计算，不是按数量
```

#### 1.4.2 眼科常见用药途径

| 途径 | 代码 | 说明 | 示例 |
|---|---|---|---|
| **滴眼** | `TOPICAL_EYE` | 眼药水 | 左氧氟沙星滴眼液 |
| **涂眼** | `TOPICAL_EYE_OINTMENT` | 眼膏 | 红霉素眼膏 |
| **结膜下注射** | `SUBCONJUNCTIVAL` | 结膜下给药 | 地塞米松 |
| **球后注射** | `RETROBULBAR` | 球后给药 | 曲安奈德 |
| **玻璃体腔注射** | `INTRAVITREAL` | 眼内给药 | 雷珠单抗、康柏西普 |
| **前房冲洗** | `INTRAOCULAR_IRRIGATION` | 术中冲洗 | 万古霉素 |
| 口服 | `ORAL` | 全身用药 | 头孢克肟 |
| 静脉滴注 | `IV_DRIP` | 全身用药 | 甘露醇 |
| 肌肉注射 | `IM` | 全身用药 | 维生素 B12 |

#### 1.4.3 眼科滴眼液频次

| 代码 | 名称 | 间隔 | 常见用途 |
|---|---|---|---|
| `QD` | 每日 1 次 | 24h | 前列腺素类（晚间） |
| `BID` | 每日 2 次 | 12h | 抗生素预防 |
| `TID` | 每日 3 次 | 8h | 抗炎 |
| `QID` | 每日 4 次 | 6h | 抗生素治疗 |
| `Q6H` | 每 6 小时 | 6h | 重症感染 |
| `Q4H` | 每 4 小时 | 4h | 急性炎症 |
| `Q2H` | 每 2 小时 | 2h | 急性角膜炎 |
| `Q1H` | 每小时 | 1h | 化脓性角膜炎 |
| `PRN` | 必要时 | — | 人工泪液 |
| `QN` | 每晚 1 次 | 24h | 眼膏睡前 |
| `QOD` | 隔日 1 次 | 48h | 递减用药 |

#### 1.4.4 眼科特殊用药

| 药品类别 | 特殊要求 |
|---|---|
| **糖皮质激素滴眼液** | 需监测眼压，长期使用需签知情同意 |
| **前列腺素类** | 孕妇禁用，可致虹膜色素沉着 |
| **抗 VEGF 药物** | 玻璃体腔注射，需签手术同意书 |
| **阿托品** | 儿童验光用，需注明"散瞳后 6 小时视物模糊" |
| **散瞳剂** | 青光眼患者禁用（需拦截） |
| **麻醉药品** | 需专用处方（红处方） |

### 1.5 抗菌药物分级管理

| 级别 | 代码 | 处方权限 | 眼科示例 |
|---|---|---|---|
| **非限制使用** | `NON_RESTRICTED` | 所有执业医师 | 左氧氟沙星滴眼液、红霉素眼膏 |
| **限制使用** | `RESTRICTED` | 主治及以上 | 莫西沙星滴眼液、夫西地酸 |
| **特殊使用** | `SPECIAL` | 副主任及以上 + 会诊 | 万古霉素（玻璃体腔）、头孢他啶 |

**管控要点：**

| 指标 | 要求 | 说明 |
|---|---|---|
| 处方权限 | 按职称分级 | 越级需上级医师签名 |
| 微生物送检率 | 特殊使用 ≥80% | 使用前需送检 |
| 会诊要求 | 特殊使用需会诊 | 记录会诊意见 |
| 使用率考核 | 眼科目标 ≤20% | 全院指标分解 |

### 1.6 模块目标

- **合规**：符合《处方管理办法》，处方可追溯、可打印、可审计。
- **准确**：用法用量结构化，不用自由文本。
- **安全**：合理用药审核，阻断级问题不可提交。
- **适配**：眼科特有的滴眼、眼别、频次。
- **高效**：常用处方模板，一键带出。
- **可量化**：抗菌药物使用率、处方合格率可统计。

### 1.7 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 门诊医生 | 开方 | 开处方、签名、改方 |
| 药师 | 审方 | 审核、退回、发药 |
| 科主任 | 管理 | 抗菌药物审批、处方点评 |
| 医务科 | 监管 | 处方合格率、抗菌药物指标 |
| 收费员 | 收费 | 按处方收费 |

## 3. 业务模型

### 3.1 处方模型

#### 3.1.1 处方组成

```
处方 P202610200015（普通处方，白笺）
├── 患者：王五 男 82岁
├── 诊断：H25.901 老年性白内障（右）
├── 处方医生：张明华 主任医师
│
├── 药品1 吡诺克辛钠滴眼液 0.75mg:15ml × 1 支
│   滴眼，每次 1 滴，每日 4 次，右眼，7 天
├── 药品2 左氧氟沙星滴眼液 0.5%:5ml × 1 支
│   滴眼，每次 1 滴，每日 4 次，右眼，7 天
└── 药品3 双氯芬酸钠滴眼液 0.1%:5ml × 1 支
    滴眼，每次 1 滴，每日 3 次，右眼，7 天

处方金额：¥86.40
医生签名：张明华（电子签名）
处方审核：李药师 ✅通过
```

#### 3.1.2 处方类型

| 类型 | 代码 | 颜色 | 权限 | 说明 |
|---|---|---|---|---|
| **普通处方** | `NORMAL` | 白 | 执业医师 | 常规用药 |
| **儿科处方** | `PEDIATRIC` | 绿 | 执业医师 | ≤14 岁 |
| **急诊处方** | `EMERGENCY` | 黄 | 执业医师 | 急诊用药 |
| **麻精处方** | `NARCOTIC` | 红 | 需专门授权 | 麻醉/精神药品 |

**自动判定规则：**

```
患者年龄 ≤ 14 岁 → 儿科处方（绿）
处方含麻精药品 → 麻精处方（红，需授权）
就诊类型 = 急诊   → 急诊处方（黄）
其他              → 普通处方（白）
```

#### 3.1.3 处方状态机

```

        │  DRAFT   │  草稿
        └────┬─────┘
             │ 医生签名
             ▼

             │
    ┌────────┼──────────────┬──────────────┐
    │ 审核通过 │ 审核退回       │ 医生作废      │
    ▼        ▼              ▼              ▼
┌──────────┐┌──────────┐┌──────────┐
│ REVIEWED ││ RETURNED ││CANCELLED │
└────┬─────┘└────┬─────┘└──────────┘
     │            │ 医生修改
     │            └──────────► DRAFT
```

**状态说明：**

| 状态 | 说明 | 可编辑 | 可作废 |
|---|---|---|---|
| `DRAFT` | 草稿 | ✅ | ✅ |
| `SIGNED` | 已签名，待审核 | ❌ | ✅ |
| `REVIEWED` | 药师审核通过 | ❌ | ⚠️ 需退费 |
| `RETURNED` | 药师退回 | ✅ | ✅ |
| `DISPENSED` | 已发药 | ❌ | ❌ |
| `CANCELLED` | 已作废 | ❌ | ❌ |

### 3.2 用法用量模型（核心）

#### 3.2.1 结构化字段

| 字段 | 说明 | 眼科示例 | 通用科示例 |
|---|---|---|---|
| `route` | 用药途径 | `TOPICAL_EYE` 滴眼 | `ORAL` 口服 |
| `single_dose` | 单次剂量 | `1` | `0.5` |
| `dose_unit` | 剂量单位 | `滴` | `g` |
| `frequency` | 频次 | `QID` 每日4次 | `TID` 每日3次 |
| `eye_side` | 用药眼别 | `OD` 右眼 | `NA` |
| `duration_days` | 疗程天数 | `7` | `5` |
| `total_quantity` | 总数量 | `1` 支 | `24` 粒 |
| `usage_text` | 用法治文本 | 自动生成 | 自动生成 |

#### 3.2.2 use 文本自动生成

```python
def build_usage_text(route, single_dose, dose_unit,
                      frequency, eye_side, duration_days):
    """生成规范用法文本"""
    route_text = ROUTE_LABELS[route]        # "滴眼"
    freq_text = FREQ_LABELS[frequency]      # "每日4次"
    eye_text = EYE_LABELS.get(eye_side, "") # "右眼"

    parts = [route_text]
    if eye_text:
        parts.append(eye_text)
    parts.append(f"每次 {single_dose}{dose_unit}")
    parts.append(freq_text)
    if duration_days:
        parts.append(f"共 {duration_days} 天")

    return "，".join(parts)

# 输出："滴眼，右眼，每次 1滴，每日4次，共 7 天"
```

#### 3.2.3 疗程与数量换算

**关键规则：总数量必须覆盖疗程所需。**

```
滴眼液用量估算：
  每日 4 次 × 7 天 = 28 滴
  1 支 5ml 滴眼液 ≈ 100~120 滴
  → 1 支足够

校验公式：
  required_drops = frequency_per_day × duration_days
  available_drops = total_quantity × drops_per_unit
  if available_drops < required_drops → 警告
```

| 场景 | 处理 |
|---|---|
| 主治开非限制级 | ✅ 允许 |
| 住院医师开限制级 | ❌ 阻断（54831） |

| 紧急情况越级 | ⚠️ 允许 + 24 小时内上级补签 |

### 3.4 合理用药审核模型

#### 3.4.1 审核类型与级别

| 类型 | 说明 | 级别 | 眼科示例 |
|---|---|---|---|
| **过敏** | 患者过敏史含该药 | **BLOCK** | 青霉素过敏开阿莫西林 |
| **配伍禁忌** | 两药同用有禁忌 | **BLOCK** | 见 3.4.2 |
| **重复用药** | 同类药重复 | WARN | 两种喹诺酮滴眼液 |
| **超剂量** | 超过最大剂量 | WARN | 阿托品超浓度 |
| **超疗程** | 超过最长疗程 | WARN | 激素滴眼液 >4 周 |
| **适应症** | 与诊断不符 | WARN | 无感染开抗生素 |
| **禁忌症** | 患者有禁忌 | **BLOCK** | 青光眼开散瞳剂 |
| **特殊人群** | 儿童/孕妇/老年 | WARN | 孕妇用前列腺素类 |
| **相互作用** | 药物相互作用 | WARN | — |

#### 3.4.2 眼科常见配伍禁忌

| 药物 A | 药物 B | 后果 | 处理 |
|---|---|---|---|
| **两种滴眼液** | 同时滴（间隔 <5min） | 后药冲走前药 | 需间隔 5~10 分钟 |
| 毛果芸香碱 | 阿托品 | 作用拮抗 | 禁止同用 |
| 噻吗洛尔 | 维拉帕米（口服） | 加重心动过缓 | 监测心率 |
| 激素滴眼液 | 抗病毒药 | 病毒扩散 | 需抗病毒覆盖 |
| 荧光素钠 | — | 过敏 | 需皮试 |
| 阿托品 | 青光眼患者 | 眼压升高 | **禁止** |

**眼科特有的"滴眼间隔"规则：**

```
同一眼别多种滴眼液：
  必须间隔 ≥5 分钟
  → 系统提示"已有 2 种滴眼液，请告知患者间隔 5 分钟使用"

原因：后滴的药液会冲走先滴的药液，降低疗效
```

#### 3.4.3 审核结果分级

| 级别 | 行为 | 提示色 | 可否继续 |
|---|---|---|---|
| `BLOCK` | 禁止提交 | 红 | ❌ |
| `WARN` | 提示 + 需填理由 | 橙 | ✅ 填理由 |
| `INFO` | 仅提示 | 蓝 | ✅ |

### 3.5 处方模板模型

```
模板："白内障术后常规用药"
├── 左氧氟沙星滴眼液 0.5%:5ml × 1 支
│   QID，右眼，7 天
├── 双氯芬酸钠滴眼液 0.1%:3ml × 1 支
│   TID，右眼，14 天
├── 氟米龙滴眼液 0.1%:5ml × 1 支
│   QID，右眼，14 天（递减）
└── 玻璃酸钠滴眼液 0.1%:0.4ml × 30 支
    QID，右眼，30 天

模板变量：
  · 眼别：{OD/OS} → 按实际手术眼自动填充
  · 疗程：可按医生习惯微调
```

### 3.6 处方与医嘱的同步

```
开处方：
  医生开药品 → M07-03 生成医嘱（ISSUED）
             → M07-05 生成处方明细（DRAFT）
             → 医生填用法
             → 医生签名（SIGNED）
             → 药师审核（REVIEWED）
             → 收费（医嘱 PAID）
             → 发药（DISPENSED）

关键点：
· 医嘱金额由 M16 按 M01 价格计算
· 处方不存金额（只存数量）
· 处方作废需同步作废医嘱
```

### 3.7 处方与诊断的强关联

| 规则 | 说明 |
|---|---|
| 处方必须有诊断 | 无诊断不可签名（54807） |
| 抗菌药物需感染诊断 | 无感染诊断开抗菌药 → WARN |
| 诊断来自 M07-02 | 取主诊断 + 次诊断 |
| 医保报销依据 | 处方诊断与用药需匹配 |

```python
    # ---------- 用法文本 ----------
    def _build_usage_text(self, route, eye_side, single_dose,
                            dose_unit, frequency, duration_days) -> str:
        """生成规范用法文本"""
        parts = [self.ROUTE_LABELS.get(route, route)]

        eye_text = self.EYE_LABELS.get(eye_side or "", "")
        if eye_text:
            parts.append(eye_text)

        if single_dose:
            dose = float(single_dose)
            dose_str = (f"{dose:.0f}" if dose == int(dose) else f"{dose:g}")
            parts.append(f"每次 {dose_str}{dose_unit or ''}")

        freq_text = self.FREQ_LABELS.get(frequency or "", "")
        if freq_text:
            parts.append(freq_text)

        if duration_days:
            parts.append(f"共 {duration_days} 天")

        return "，".join(parts)

    def _is_ocular_route(self, route: str) -> bool:
        return route in (
            "TOPICAL_EYE", "TOPICAL_EYE_OINTMENT",
            "SUBCONJUNCTIVAL", "RETROBULBAR",
            "INTRAVITREAL", "INTRAOCULAR_IRRIGATION")

    # ---------- 剂量校验 ----------
    def _check_dosage(self, item) -> dict:
        """疗程用量 vs 数量是否足够"""
        if not self._is_ocular_route(item.route or ""):
            return {"sufficient": True}

        per_day = self.FREQ_PER_DAY.get(item.frequency or "", 0)

        if per_day <= 0 or not item.duration_days:
            return {"sufficient": True, "skip": True}

        required = per_day * item.duration_days * float(
            item.single_dose or 1)
        available = float(item.quantity or 0) * self.DROPS_PER_UNIT

        if available >= required:
            return {
                "sufficient": True,
                "required_drops": int(required),
                "available_drops": int(available),
            }

        need_qty = int(
            (required / self.DROPS_PER_UNIT) + 0.999)

        return {
            "sufficient": False,
            "required_drops": int(required),
            "available_drops": int(available),
            "required_quantity": need_qty,
            "current_quantity": float(item.quantity or 0),
            "message": (f"按每日 {per_day:g} 次 × "
                         f"{item.duration_days} 天计算需 "
                         f"{int(required)} 滴，当前数量不足"),
        }

    async def sign(self, prescription_id: int, payload, user) -> dict:
        """处方签名"""

        if rx.status not in self.EDITABLE:
            raise BizException("0705002",
                f"当前状态 {self.STATUS_LABELS.get(rx.status)} 不可签名")

        # 确认项

                     payload.confirm_usage,
                     payload.confirm_check_result)):
            raise BizException(40001, "请确认所有签署前核对项")

        # CA 签名
        if payload.sign_method == "CA" and not payload.ca_signature:
            raise BizException("0705026", "电子签名证书无效")

        # 重新审核
        items = await self._get_items(rx.id)
        encounter = await self._get_encounter(rx.encounter_id)

        from app.services.m07.medication_check_service import (
            MedicationCheckService,
        )
        checker = MedicationCheckService(self.db)
        check = await checker.check_prescription(
            rx, [self._item_to_dict(i) for i in items],
            encounter, user)

        if check["blocks"]:
            raise BizException("0705023", "必须处理阻断级问题",
                data={
                    "prescription_id": rx.id,
                    "blocks": check["blocks"],
                    "suggestion": ("请删除或更换存在阻断问题的药品"
                                    "后重新签名"),
                })

        # 抗菌药物权限
        from app.services.m07.antibiotic_service import AntibioticService
        abx = AntibioticService(self.db)
        perm = await abx.check_permission(rx, items, user)

        if not perm["passed"]:
            raise BizException(perm["error_code"], perm["message"],
                data=perm)

        # 必须提醒
        if check["warnings"] and not any(
                w.get("reason") for w in check["warnings"]):
            blocking_warn = [
                w for w in check["warnings"] if w.get("require_reason")]
            if blocking_warn and not payload.warn_reasons:
                raise BizException("0705024", "警告级问题需填写理由",
                    data={"warnings": blocking_warn})

        # 签名
        rx.status = "SIGNED"
        rx.signed_at = datetime.now()
        rx.signer_id = getattr(user, "id", None)
        rx.signer_name = getattr(user, "name", None)
        rx.signer_title = getattr(user, "title", None)
        rx.sign_method = payload.sign_method
        rx.signature_sn = payload.ca_cert_sn
        rx.signature_hash = self._sign_hash(rx, payload)
        rx.warn_reasons = payload.warn_reasons

        self.db.add(self._log(rx, "SIGN", user, {
            "sign_method": payload.sign_method,
            "signature_sn": payload.ca_cert_sn,
        }))

        await self.db.commit()

        return {
            "prescription_id": rx.id,
            "prescription_no": rx.prescription_no,
            "status": "SIGNED",
            "status_text": "已签名",
            "signed_at": rx.signed_at.isoformat(),
            "signer_name": rx.signer_name,
            "signer_title": rx.signer_title,
            "sign_method": rx.sign_method,
            "signature_sn": rx.signature_sn,
```

```python
            M07Prescription.doctor_id == doctor_id,
            M07Prescription.created_at >= datetime.combine(
                start, datetime.min.time()),
            M07Prescription.status.notin_(("CANCELLED",)),
```

```python
def aggregate_prescription_stats_task(stat_date: str = None):

    import asyncio
    return asyncio.run(_aggregate(stat_date))


async def _aggregate(stat_date: str = None):
    from datetime import date, timedelta
    from sqlalchemy import select, func
    from app.core.database import AsyncSessionLocal
    from app.models.m07.prescription import M07Prescription

    d = (date.fromisoformat(stat_date) if stat_date
         else date.today() - timedelta(days=1))

    async with AsyncSessionLocal() as db:
        rows = (await db.execute(
            select(
                M07Prescription.dept_id,
                M07Prescription.doctor_id,
                func.count().label("total"),
                func.count().filter(
                    M07Prescription.status == "RETURNED").label("returned"),
                func.count().filter(
                    M07Prescription.has_antibiotic == True).label("abx"),
            ).where(
                func.date(M07Prescription.created_at) == d,
                M07Prescription.is_deleted == False,
            ).group_by(
                M07Prescription.dept_id, M07Prescription.doctor_id)
        )).all()

        return {
            "date": d.isoformat(),
            "groups": [
                {
                    "dept_id": r[0],
                    "doctor_id": r[1],
                    "total": r[2],
                    "returned": r[3],
                    "abx": r[4],
                    "abx_rate": round(r[4] / r[2] * 100, 1) if r[2] else 0,
                }
                for r in rows
            ],
        }

async def _remind_culture():
    from sqlalchemy import select
    from app.core.database import AsyncSessionLocal
    from app.models.m07.prescription import M07AntibioticConsult
    from app.clients.mpi_message_client import MpiMessageClient

    async with AsyncSessionLocal() as db:
        rows = (await db.execute(
            select(M07AntibioticConsult).where(
                M07AntibioticConsult.status == "APPROVED",
                M07AntibioticConsult.culture_done == False,
            )
        )).scalars().all()

        sent = 0
        by_doctor = {}
        for r in rows:
            by_doctor.setdefault(r.applicant_id, []).append(
                r.consult_no)

        for doctor_id, consults in by_doctor.items():
            try:
                await MpiMessageClient().send(
                    biz_type="CULTURE_RESULT_MISSING",
                    receivers=[doctor_id],
                    params={"count": len(consults),
                             "consults": consults[:5]})
                sent += 1
            except Exception:
                continue

        return {"notified": sent, "pending_count": len(rows)}
```
