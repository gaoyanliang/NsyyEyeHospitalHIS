**设计说明：**

- `m07_report` 是**医生侧报告副本**，来自 M12/M13 推送，不反向修改
- **报告与图像拆分**：一份报告可能有多张图（OCT 横截面+地形图+正视图）
- **`m07_critical_value` 独立成表**：危急值需闭环管理（确认→处置→升级），比报告字段更复杂
- **`m07_report_trend` 是读模型**：把结构化字段拍平，避免每次对比都解析 JSONB
- **报告不可删除**：只可标记（`is_deleted` 仅用于撤回场景）
- **阅读记录独立**：一次报告可被多人查看（本人/科主任/质控），需完整留痕

**约束说明**

```sql
ALTER TABLE m07_report
    ADD CONSTRAINT ck_m07_report_type
    CHECK (report_type IN ('EXAM', 'LAB'));

ALTER TABLE m07_report
    ADD CONSTRAINT ck_m07_report_status
    CHECK (status IN ('DRAFT', 'PRELIMINARY', 'FINAL',
                       'AMENDED', 'RETRACTED'));

ALTER TABLE m07_report
    ADD CONSTRAINT ck_m07_report_read
    CHECK (read_status IN ('UNREAD', 'READ', 'MARKED'));

ALTER TABLE m07_report
    ADD CONSTRAINT ck_m07_report_eye
    CHECK (eye_side IN ('OD', 'OS', 'OU', 'NA'));

ALTER TABLE m07_report
    ADD CONSTRAINT ck_m07_report_structured
    CHECK (has_structured = FALSE OR structured_data IS NOT NULL);

ALTER TABLE m07_report
    ADD CONSTRAINT ck_m07_report_critical
    CHECK (has_critical = FALSE
           OR critical_handled IS NOT NULL);

ALTER TABLE m07_report
    ADD CONSTRAINT ck_m07_report_count CHECK (image_count >= 0);

-- 源报告幂等唯一
CREATE UNIQUE INDEX uk_m07_report_src
    ON m07_report (report_type, report_id);

-- 未阅查询
CREATE INDEX idx_m07_report_unread
    ON m07_report (doctor_id, reported_at DESC)
    WHERE read_status = 'UNREAD'
      AND status IN ('FINAL', 'AMENDED')
      AND is_deleted = FALSE;

-- 危急值未处置
CREATE INDEX idx_m07_report_critical
    ON m07_report (doctor_id, reported_at DESC)
    WHERE has_critical = TRUE AND critical_handled = FALSE;
```

**状态机**

```
        ┌──────────┐
        │  DRAFT   │  草稿（M12/M13 内部）
        └────┬─────┘
             │ 初审
             ▼
        ┌──────────────┐
        │ PRELIMINARY  │  初步
        └──────┬───────┘
               │ 终审
               ▼
        ┌──────────┐        修正        ┌──────────┐
        │  FINAL   │ ────────────────► │ AMENDED  │
        └────┬─────┘                    └────┬─────┘
             │ 撤回                          │ 撤回
             ▼                               ▼
        ┌──────────────┐
        │  RETRACTED   │  已撤回（医生不可见）
        └──────────────┘
```

            code = f.get("field_code")

                d[code] = f.get("value")
        return d

    @staticmethod

        lo = f.get("ref_min")
        hi = f.get("ref_max")
        if lo is None and hi is None:
            return ""
        if lo is not None and hi is not None:
            return f"{lo}~{hi}"
        if lo is not None:
            return f"≥{lo}"
        return f"≤{hi}"

    def missing_reference(self) -> bool:
        """是否缺参考区间（检验用）"""
        if self.report_type != "LAB":
            return False
        fields = self.structured_fields()
        return bool(fields) and all(
            f.get("ref_min") is None and f.get("ref_max") is None
            for f in fields)

        """相对上次是否改善（None 表示无法判定）"""
        if self.metric_value is None or prev_value is None:
            return None
        cur = float(self.metric_value)
        prev = float(prev_value)
        direction = self.TREND_DIRECTION.get(self.metric_code, "RANGE")

        if direction == "HIGHER_BETTER":
            return cur > prev
        if direction == "LOWER_BETTER":
            return cur < prev
        if direction == "RANGE":
            if self.ref_min is None or self.ref_max is None:
                return None
            lo = float(self.ref_min)
            hi = float(self.ref_max)
            return (abs(cur - (lo + hi) / 2)
                    < abs(prev - (lo + hi) / 2))
        return None
