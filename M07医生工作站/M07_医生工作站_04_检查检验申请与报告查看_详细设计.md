## 1. 模块概述

### 1.1 模块定位

检查检验申请与报告查看是医生工作站的**临床反馈回路**。它回答："**我开的检查做了吗？结果是什么？要不要改方案？**"

```
┌──────────────────────────────────────────────────────────────┐
│  M07-03 医嘱下达（检查/检验医嘱 ISSUED）                       │
└────────────────────────┬─────────────────────────────────────┘
                         │ 缴费后
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M12 检查执行 / M13 检验执行                                  │
│  预约 → 执行 → 出报告                                        │
└────────────────────────┬─────────────────────────────────────┘
                         │ 报告推送
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M07-04 检查检验申请与报告查看（本文档）                       │
│  申请单管理 → 报告接收 → 结果解读 → 危急值处置 → 历史对比        │
└────────────────────────┬─────────────────────────────────────┘
                         │ 临床决策依据
        ┌────────────────┼────────────────┬────────────────┐
        ▼                ▼                ▼                ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ 02 诊断修正  │ │ 03 追加医嘱  │ │ 05 调整处方  │ │ 06 诊断证明书 │
└──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘
```

### 1.2 为什么本模块要独立

| 理由 | 说明 |
|---|---|
| **闭环最后一环** | 医生开单后，必须能看到结果才能形成决策闭环 |
| **眼科报告特殊** | OCT/视野/FFA 是图像型报告，需影像查看器 |
| **危急值处置** | 危急值必须在医生侧确认并处置，否则存在医疗风险 |
| **历史趋势** | 眼压、视力、轴向、屈光度需要纵向对比 |
| **结构化报告** | 眼科检查（OCT 黄斑厚度、视野 MD）有结构化数值 |
| **报告解读留痕** | 医生是否看过、如何处置必须记录 |

### 1.3 与相邻模块的分工

| 能力 | 归属 |
|---|---|
| 检查检验项目主数据 | M01-09 |
| 检查检验医嘱下达 | M07-03 |
| **检查检验申请单（医生侧视图）** | **M07-04 本子模块** |
| **报告接收与存储（医生侧副本）** | **M07-04 本子模块** |
| **报告查看与解读** | **M07-04 本子模块** |
| **危急值确认与处置** | **M07-04 本子模块** |
| **结果与历史对比** | **M07-04 本子模块** |
| 检查预约与执行 | M12 |

> **边界一句话：** 本子模块是**患者检查与检验数据的唯一医生视图**，负责"看结果、做决策"；**不做**报告书写（M12/M13）、**不做**影像存储（PACS）。

### 1.4 检查与检验的差异

| 维度 | 检查（EXAM） | 检验（LAB） |
|---|---|---|
| 产出 | **图像 + 文字报告** | **数值结果 + 参考区间** |
| 数据形态 | 非结构化/结构化文字 | 结构化表格 |
| 查看方式 | 图像查看器 | 表格 + 趋势图 |
| 眼科示例 | OCT、视野、FFA、B 超 | 房水检测、血糖 |
| 异常判定 | 结论 + 危急值标记 | 数值与参考区间比较 |
| 历史对比 | 图像并排对比 | 数值趋势图 |
| 关联 | 图像存储于 PACS | 结果直接入库 |

### 1.5 模块目标

- **快**：报告首屏 ≤ 2 秒（含缩略图）。
- **全**：图像、结构化数值、文字结论一屏呈现。
- **准**：异常值高亮，危急值红色告警。
- **安全**：危急值必须确认处置，否则不能完成就诊。
- **对比**：一键与历次结果并排对比。
- **可追溯**：医生查看报告的时间、解读留痕。

### 1.6 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 门诊医生 | 查看报告、处置危急值 | 查看、对比、确认、处置 |
| 科主任 | 质控 | 查看危急值处置率 |
| 医务科 | 质量监管 | 危急值闭环统计 |
| 护士 | 协助 | 提醒医生有危急值 |

## 3. 业务模型

### 3.1 申请单模型

#### 3.1.1 申请单 vs 医嘱

| 维度 | 医嘱（M07-03） | 申请单（本模块） |
|---|---|---|
| 粒度 | 一条诊疗安排 | 一张申请单（可含多条检查） |
| 用途 | 全流程管理 | 医生侧视图 + 报告挂载点 |
| 关系 | 1 个检查医嘱 → 1 张申请单 | 1 张申请单 → 1~N 条检查医嘱 |

```
检查申请单 AP202610200015
├── OCT 黄斑（右眼）      → 医嘱 OR...0156
├── 眼科 B 超（双眼）     → 医嘱 OR...0157
└── 眼压检查（双眼）      → 医嘱 OR...0158
```

**说明：** 申请单是**逻辑分组**，不改变医嘱的独立性。同一就诊同一天同类型的医嘱可归为一张申请单。

#### 3.1.2 申请单状态

```
        ┌──────────┐
        │  CREATED │  已创建（待缴费）
        └────┬─────┘
             │ 缴费
             ▼
        ┌──────────┐
        │  PENDING │  待执行
        └────┬─────┘
             │
    ┌────────┼────────────┬──────────────┐
    │ 开始    │ 撤销        │ 全部取消       │
    ▼        ▼            ▼              ▼
┌──────────┐┌──────────┐┌──────────┐
│EXECUTING ││REVOKED   ││CANCELLED │
└────┬─────┘└──────────┘└──────────┘
     │ 全部完成
     ▼
┌──────────┐
│COMPLETED │
└──────────┘
```

### 3.2 报告模型

#### 3.2.1 报告类型

| 类型 | 来源 | 形态 | 示例 |
|---|---|---|---|
| **检查报告（图像型）** | M12 | 图像 + 文字 | OCT、眼底照相 |
| **检查报告（数值型）** | M12 | 数值 + 文字 | 眼压、视力、角膜内皮 |
| **检查报告（结构化）** | M12 | 结构化字段 + 文字 | 视野（MD、PSD）、角膜地形图 |
| **检验报告** | M13 | 数值表格 + 参考区间 | 血常规、房水检测 |

#### 3.2.2 报告状态

| 状态 | 说明 | 医生可见 |
|---|---|---|
| `DRAFT` | 报告草稿 | ❌ |
| `PRELIMINARY` | 初步报告 | ⚠️ 标记 |
| `FINAL` | 最终报告 | ✅ |
| `AMENDED` | 已修正 | ✅ 标记修正 |
| `RETRACTED` | 已撤回 | ❌ |

#### 3.2.3 报告接收方式

```
主链路：M12/M13 报告审核通过 → MQ 推送 → M07-04 落库
兜底：  定时任务每 5 分钟拉取 FINAL 报告（防 MQ 丢失）
```

### 3.3 危急值模型（医疗安全核心）

#### 3.3.1 危急值定义

| 眼科常见危急值 | 阈值示例 |
|---|---|
| 眼压 | > 40 mmHg 或 < 5 mmHg |
| 视力 | 骤降至 0.05 以下 |
| 视网膜中央动脉阻塞 | 报告结论含"动脉阻塞" |
| 视网膜脱离 | 报告结论含"视网膜脱离" |
| 眼内炎 | 报告结论含"眼内炎" |
| 房水/玻璃体液培养阳性 | 阳性 |
| 血糖 | > 25 mmol/L 或 < 2.8 mmol/L |
| 血钾 | > 6.5 或 < 2.5 mmol/L |

#### 3.3.2 危急值处置状态机

```
        ┌──────────────┐
        │   DETECTED   │  已识别（报告返回）
        └──────┬───────┘
               │ 通知医生
               ▼
        ┌──────────────┐
        │  NOTIFIED    │  已通知
        └──────┬───────┘
               │ 医生确认已阅
               ▼
        ┌──────────────┐
        │ ACKNOWLEDGED │  已确认
        └──────┬───────┘
               │ 记录处置措施
               ▼
        ┌──────────────┐
        │   HANDLED    │  已处置
        └──────────────┘
```

#### 3.3.3 危急值强制规则

| 规则 | 说明 |
|---|---|
| **未处置不可完成就诊** | M07-01 完成校验 `V-08` |
| **超时升级** | 15 分钟未确认 → 通知科主任 |
| **30 分钟未处置** | 通知医务科 |
| **全量留痕** | 识别、通知、确认、处置全程记录 |
| **处置措施必填** | ≥5 字 |

### 3.4 报告解读模型

#### 3.4.1 解读内容

| 内容 | 说明 |
|---|---|
| 已阅标记 | 医生点击"已阅" |
| 解读意见 | 医生对结果的判断 |
| 异常说明 | 对异常项的说明 |
| 后续安排 | 追加检查、调整方案、转诊 |
| 是否关联诊断 | 作为诊断依据 |

#### 3.4.2 解读与诊断的联动

```
报告：OCT 示黄斑水肿
   ↓ 医生解读
   · 标记为诊断依据 → 写入 M07-02 诊断依据
   · 关联诊断：H35.401 黄斑水肿
   ↓
诊断更新
```

### 3.5 历史对比模型

#### 3.5.1 对比维度

| 类型 | 对比方式 |
|---|---|
| 图像型（OCT） | 并排显示最近 3 次 |
| 数值型（眼压） | 趋势折线图 |
| 表格型（视野） | 关键指标趋势（MD、PSD） |
| 检验 | 数值 + 趋势 |

#### 3.5.2 眼科关键对比指标

| 指标 | 来源 | 临床意义 |
|---|---|---|
| **视力**（裸眼/矫正） | 视力检查 | 功能变化 |
| **眼压** | 眼压检查 | 青光眼控制 |
| **黄斑中心厚度（CMT）** | OCT | 黄斑水肿 |
| **视网膜神经纤维层（RNFL）** | OCT | 青光眼进展 |
| **视野 MD/PSD** | 视野 | 视野缺损 |
| **角膜内皮细胞密度** | 角膜内皮 | 术前评估 |
| **眼轴长度** | A 超 | 屈光手术 |
| **屈光度** | 验光 | 屈光变化 |

### 3.6 报告推送与实时性

```
M12/M13 出报告
   ↓
MQ 推送（主链路）
   ├─ WebSocket 推送到医生工作站
   └─ 落库 m07_report
   ↓ 若 5 分钟内未收到
定时任务兜底拉取
```

**实时提醒：**

| 场景 | 提醒方式 |
|---|---|
| 普通报告就绪 | 站内消息 + 列表角标 |
| **危急值** | **弹窗 + 声音 + 站内信** |
| 本诊室患者报告 | 顶部横幅提示 |

### 3.7 报告与图像的关系

```
检查报告（m07_report）
├── 文字结论
├── 结构化字段（JSONB）
└── 图像列表（m07_report_image）
     ├── 缩略图 URL
     ├── 原图 URL（PACS 鉴权）
     └── DICOM 序列号

图像调阅：
  医生点击缩略图 → 请求 M07-04 换取带时限的 PACS 令牌 → 打开 PACS 查看器
```

**安全：** 图像 URL **不可长期有效**，必须换取**一次性令牌**（5 分钟）。

from datetime import datetime, timedelta

    """危急值闭环管理"""

            select(M07Report).where(M07Report.id == report_id)
        )).scalar_one_or_none()

        if not report:

        cv = M07CriticalValue(
            report_id=report_id,
            report_no=report.report_no,
            order_id=report.order_id,

    # ---------- 处置 ----------
    async def handle(self, critical_id: int, payload, user) -> dict:
        """处置危急值"""
        cv = await self._get(critical_id)

        if cv.status == "HANDLED":
            raise BizException(54813, "该危急值已处置")

        # 必须先确认
        if not payload.acknowledge:
            raise BizException(54814, "危急值未确认不可处置",
                data={
                    "critical_id": cv.id,
                    "acknowledge": False,
                    "suggestion": "请先勾选「我已阅读该危急值结果」",
                    "required_field": "acknowledge",
                })

        # 处置措施必填
        measure = (payload.handle_measure or "").strip()
        if len(measure) < 5:
            raise BizException(54815, "危急值处置措施必填",
                data={
                    "critical_id": cv.id,
                    "handle_measure_length": len(measure),
                    "min_length": 5,
                    "suggestion": "请详细填写处置措施，至少 5 个字",
                })

        now = datetime.now()

        if not cv.acknowledged_at:
            cv.acknowledged_at = now
            cv.acknowledged_by = getattr(user, "id", None)
            cv.acknowledged_by_name = getattr(user, "name", None)
            cv.ack_minutes = round(
                (now - cv.detected_at).total_seconds() / 60, 1)

        cv.status = "HANDLED"
        cv.handled_at = now
        cv.handle_type = payload.handle_type
        cv.handle_measure = measure
        cv.handle_note = payload.note
        cv.handled_by = getattr(user, "id", None)
        cv.handled_by_name = getattr(user, "name", None)
        cv.handle_minutes = round(
            (now - cv.detected_at).total_seconds() / 60, 1)
        cv.is_within_limit = (
            cv.handle_minutes <= self.HANDLE_LIMIT_MINUTES)
        cv.reported_to_medical_affairs = bool(
            payload.report_to_medical_affairs)

        # 追加医嘱
        created_orders = await self._create_follow_up_orders(
            cv, payload.follow_up_orders, user)

        # 更新报告
        report = (await self.db.execute(
            select(M07Report).where(M07Report.id == cv.report_id)
        )).scalar_one_or_none()

        if report:
            report.critical_handled = True

        await self.db.commit()

        pending = await self._count_pending(cv.encounter_id)

        if payload.notify_patient:
            try:
                from app.clients.mpi_message_client import MpiMessageClient
                await MpiMessageClient().send(
                    biz_type="CRITICAL_PATIENT_NOTIFY",
                    receivers=[cv.patient_id],
                    params={"item_name": cv.item_name})
            except Exception:
                pass

        return {
            "critical_id": cv.id,
            "patient_name": cv.patient_name,
            "item_name": cv.item_name,
            "detected_value": cv.detected_value,
            "status": "HANDLED",
            "status_text": "已处置",
            "acknowledged_at": cv.acknowledged_at.isoformat(),
            "handled_at": cv.handled_at.isoformat(),
            "handle_type": cv.handle_type,
            "handle_type_text": self.HANDLE_TYPE_LABELS.get(
                cv.handle_type, ""),
            "handle_measure": cv.handle_measure,
            "handled_by_name": cv.handled_by_name,
            "handling_minutes": float(cv.handle_minutes or 0),
            "is_within_limit": cv.is_within_limit,
            "created_orders": created_orders,
            "patient_notified": payload.notify_patient,
            "encounter_can_complete": pending == 0,
            "remaining_critical_count": pending,
            "message": ("危急值已处置，本次就诊可正常完成"
                         if pending == 0
                         else f"危急值已处置，仍有 {pending} 项未处置"),
        }

        now = datetime.now()

                return {
                    "report_id": existing.id,
                    "saved": False,
                    "is_duplicate": True,
                    "message": "报告已存在（幂等）",

            existing.status = new_status
            existing.conclusion = payload.get("conclusion")
            existing.findings = payload.get("findings")
            existing.recommendation = payload.get("recommendation")
            existing.structured_data = payload.get("structured_data")
            existing.reported_at = self._parse_dt(payload.get("reported_at"))

            await self.db.commit()

            return {
                "report_id": existing.id,
                "saved": True,
                "is_duplicate": False,
                "updated": True,
                "message": "报告状态已更新",
            }

            order_info = {}

            report_sub_type=payload.get("report_sub_type"),

            patient_name=order_info.get("patient_name"),

            patient_age=order_info.get("patient_age"),

            doctor_id=order_info.get("doctor_id"),
            doctor_name=order_info.get("doctor_name"),
            dept_id=order_info.get("dept_id"),

            item_code=payload.get("item_code"),
            item_name=payload.get("item_name"),
            eye_side=payload.get("eye_side", "NA"),

            status=payload.get("status", "FINAL"),
            conclusion=payload.get("conclusion"),
            findings=payload.get("findings"),
            recommendation=payload.get("recommendation"),
            structured_data=payload.get("structured_data"),

            executed_at=self._parse_dt(payload.get("executed_at")),
            reported_at=self._parse_dt(payload.get("reported_at")),
            reporter_name=payload.get("reporter_name"),
            reviewer_name=payload.get("reviewer_name"),

    # ---------- 兜底拉取 ----------
    async def pull_missing(self, payload: dict) -> dict:
        """兜底拉取缺失报告（防 MQ 丢失）"""
        from datetime import date, timedelta

        start = payload.get("start_date") or (
            date.today() - timedelta(days=1)).isoformat()
        end = payload.get("end_date") or date.today().isoformat()

        pulled = []
        errors = []

        try:
            from app.clients.m12_client import M12Client
            from app.clients.m13_client import M13Client

            for client, mod in ((M12Client(), "M12"), (M13Client(), "M13")):
                try:
                    reports = await client.list_reports(start, end)
                    for rpt in (reports or {}).get("items", []):
                        try:
                            result = await self.on_report_ready({
                                **rpt,
                                "source_module": mod,
                            })
                            if result.get("saved"):
                                pulled.append({
                                    "report_id": result["report_id"],
                                    "module": mod,
                                })
                        except Exception as e:
                            errors.append({
                                "report_id": rpt.get("report_id"),
                                "error": str(e)[:100],
                            })
                except Exception as e:
                    errors.append({"module": mod, "error": str(e)[:100]})

        except Exception as e:
            return {
                "pulled": 0,
                "errors": [{"error": str(e)[:200]}],
                "message": "拉取失败",
            }

        return {
            "start_date": start,
            "end_date": end,
            "pulled": len(pulled),
            "errors": len(errors),
            "detail": pulled[:20],
            "message": f"兜底拉取完成，新增 {len(pulled)} 份报告",
        }

    @staticmethod
    def _parse_dt(v) -> Optional[datetime]:
        if not v:
            return None
        if isinstance(v, datetime):
            return v
        try:
            return datetime.fromisoformat(str(v))
        except ValueError:
            return None

# app/tasks/m07/report_tasks.py
"""报告异步任务"""
from celery import shared_task


@shared_task
def escalate_critical_values_task():
    """危急值升级（每分钟）"""
    import asyncio
    return asyncio.run(_escalate())


async def _escalate():
    """未确认/未处置的危急值逐级升级"""
    from datetime import datetime, timedelta
    from sqlalchemy import select
    from app.core.database import AsyncSessionLocal
    from app.core.redis import redis_client
    from app.models.m07.report import M07CriticalValue
    from app.clients.mpi_message_client import MpiMessageClient

    if not await redis_client.set(
            "m07:critical:escalate:lock", "1", nx=True, ex=300):
        return {"skipped": True}

    try:
        async with AsyncSessionLocal() as db:
            now = datetime.now()
            escalated = []

            rows = (await db.execute(
                select(M07CriticalValue).where(
                    M07CriticalValue.status != "HANDLED",
                    M07CriticalValue.escalation_scheduled_at <= now,
                )
            )).scalars().all()

            for cv in rows:
                cv.escalation_level = (cv.escalation_level or 0) + 1
                level = cv.escalation_level

                if level == 1:
                    cv.escalation_target = "科主任"
                    cv.escalation_scheduled_at = now + timedelta(minutes=15)
                elif level == 2:
                    cv.escalation_target = "医务科"
                    cv.escalation_scheduled_at = now + timedelta(minutes=30)
                else:
                    cv.escalation_target = "院领导"
                    cv.escalation_scheduled_at = now + timedelta(hours=2)

                cv.escalated_at = now

                escalated.append({
                    "critical_id": cv.id,
                    "level": level,
                    "target": cv.escalation_target,
                    "patient_name": cv.patient_name,
                    "item_name": cv.item_name,
                })

            await db.commit()

            if escalated:
                try:
                    await MpiMessageClient().send(
                        biz_type="CRITICAL_ESCALATION",
                        receivers=[],
                        params={"items": escalated})
                except Exception:
                    pass

            return {"escalated": len(escalated), "detail": escalated}
    finally:
        await redis_client.delete("m07:critical:escalate:lock")


@shared_task
def pull_missing_reports_task():

async def _pull_missing():

@shared_task
def notify_unread_reports_task():
    """未阅报告提醒（每日 12:00 / 17:00）"""
    import asyncio
    return asyncio.run(_notify_unread())


async def _notify_unread():
    from datetime import date
    from sqlalchemy import select, func
    from app.core.database import AsyncSessionLocal
    from app.models.m07.report import M07Report
    from app.clients.mpi_message_client import MpiMessageClient

    async with AsyncSessionLocal() as db:
        rows = (await db.execute(
            select(
                M07Report.doctor_id,
                func.count().label("cnt"),
            ).where(
                M07Report.reported_at >= date.today(),
                M07Report.read_status == "UNREAD",
                M07Report.status.in_(("FINAL", "AMENDED")),
                M07Report.is_deleted == False,
            ).group_by(M07Report.doctor_id)
        )).all()

        sent = 0
        for doctor_id, cnt in rows:
            if not doctor_id:
                continue
            try:
                await MpiMessageClient().send(
                    biz_type="UNREAD_REPORT_REMIND",
                    receivers=[doctor_id],
                    params={"count": cnt})
                sent += 1
            except Exception:
                continue

        return {"notified": sent}

    """清理过期缩略图缓存（每日 04:00）"""
    import asyncio
    return asyncio.run(_cleanup_images())


async def _cleanup_images():
    from app.core.redis import redis_client

    deleted = 0
    async for key in redis_client.scan_iter("m07:report:thumb:*"):
        ttl = await redis_client.ttl(key)
        if ttl < 0:
            await redis_client.delete(key)
            deleted += 1

    return {"deleted": deleted}
