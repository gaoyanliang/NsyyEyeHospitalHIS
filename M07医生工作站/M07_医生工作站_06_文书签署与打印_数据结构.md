**设计说明：**

- `m07_document` 是**文书主表**，所有类型共用
- **`content_snapshot` 是核心** —— 存的是生成时的数据副本（JSONB），不是引用。源数据变了文书不变，保证法律效力
- **`content_hash` 防篡改** —— SHA256(规范化快照)，任何改动都能检出
- **`m07_document_print` 独立成表** —— 一份文书可打印多次，每次留痕
- **`m07_certificate` 是证明类扩展** —— 诊断证明/病假条/疾病证明有额外字段（休息天数、用途、盖章），拆表避免主表膨胀
- **`m07_reprint_auth` 独立成表** —— 超次数补打需医务科审批，是独立流程

**约束说明**

```sql
ALTER TABLE m07_document
    ADD CONSTRAINT ck_m07_doc_no
    CHECK (document_no ~ '^DOC[0-9]{8}[A-Z0-9]{4}$');

ALTER TABLE m07_document
    ADD CONSTRAINT ck_m07_doc_type
    CHECK (doc_type IN (
        'MEDICAL_RECORD', 'PRESCRIPTION', 'EXAM_REQUEST',
        'LAB_REQUEST', 'DIAGNOSIS_CERT', 'SICK_LEAVE',
        'SURGERY_CONSENT', 'ANESTHESIA_CONSENT',
        'SPECIAL_CONSENT', 'DISCHARGE_SUMMARY',
        'DISEASE_CERT', 'REFERRAL'));

ALTER TABLE m07_document
    ADD CONSTRAINT ck_m07_doc_status
    CHECK (status IN ('DRAFT', 'GENERATED', 'SIGNED',
                       'PRINTED', 'CANCELLED'));

ALTER TABLE m07_document
    ADD CONSTRAINT ck_m07_doc_sign_method
    CHECK (sign_method IS NULL
           OR sign_method IN ('CA', 'HANDWRITE', 'PASSWORD'));

ALTER TABLE m07_document
    ADD CONSTRAINT ck_m07_doc_auth_status
    CHECK (reprint_auth_status IS NULL
           OR reprint_auth_status IN ('PENDING', 'APPROVED',
                                       'REJECTED'));

ALTER TABLE m07_document
    ADD CONSTRAINT ck_m07_doc_counts
    CHECK (print_count >= 0 AND reprint_count >= 0
           AND admin_print_count >= 0 AND field_count >= 0);

-- 内容快照与摘要必填
ALTER TABLE m07_document
    ADD CONSTRAINT ck_m07_doc_snapshot
    CHECK (content_snapshot IS NOT NULL
           AND length(content_hash) = 64);

-- 已签名必须有完整签名信息
ALTER TABLE m07_document
    ADD CONSTRAINT ck_m07_doc_signed
    CHECK (status NOT IN ('SIGNED', 'PRINTED')
           OR (signed_at IS NOT NULL
               AND signer_name IS NOT NULL
               AND signature_hash IS NOT NULL
               AND sign_method IS NOT NULL));

-- 已打印必须有打印时间
ALTER TABLE m07_document
    ADD CONSTRAINT ck_m07_doc_printed
    CHECK (status <> 'PRINTED'
           OR (first_printed_at IS NOT NULL AND print_count > 0));

-- 已作废必须有原因
ALTER TABLE m07_document
    ADD CONSTRAINT ck_m07_doc_cancelled
    CHECK (status <> 'CANCELLED' OR cancel_reason IS NOT NULL);

-- 待签文书（M07-01 完成就诊校验）
CREATE INDEX idx_m07_doc_pending
    ON m07_document (encounter_id, doc_type)
    WHERE status IN ('DRAFT', 'GENERATED')
      AND is_deleted = FALSE;
```

        """剩余补打次数"""
        return max(0, max_reprint - (self.reprint_count or 0))

        return self.reprint_remaining(max_reprint) > 0

    def verify_content_hash(self) -> bool:
        """校验内容 hash 是否一致"""
        if not self.content_snapshot:
            return False
        canonical = json.dumps(
            self.content_snapshot, ensure_ascii=False,
            sort_keys=True, separators=(",", ":"), default=str)
        actual = hashlib.sha256(canonical.encode("utf-8")).hexdigest()
        return actual == self.content_hash

    def compute_content_hash(self) -> str:
        """计算内容摘要"""
        canonical = json.dumps(
            self.content_snapshot or {}, ensure_ascii=False,
            sort_keys=True, separators=(",", ":"), default=str)
        return hashlib.sha256(canonical.encode("utf-8")).hexdigest()

        """快照字段"""
        return (self.content_snapshot or {}).get("fields", {})

        """取快照字段"""
        return self.snapshot_fields().get(name, default)

        if not self.print_count:

        if self.admin_print_count:
            parts.append(f"行政{self.admin_print_count}次")
        return "，".join(parts)
