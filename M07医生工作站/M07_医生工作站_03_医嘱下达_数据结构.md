**设计说明：**

- `m07_order` 是医嘱**主表**，五类医嘱共用
- 各类型的**特有字段**拆到扩展表（`_exam_ext` / `_lab_ext` / `_operation_ext` / 药品扩展在 M07-05）
- 用**扩展表**而非 JSONB 的原因：需要按部位、标本等字段查询
- `m07_order_set` + `m07_order_set_item` 实现套餐
- **状态流转权责**：M07 只能改 `DRAFT`/`ISSUED`/`STOPPED`/`CANCELLED`；`PAID`/`EXECUTING`/`COMPLETED`/`REFUNDED` 由下游回写

**约束说明**

```sql
ALTER TABLE m07_order
    ADD CONSTRAINT ck_m07_order_no
    CHECK (order_no ~ '^OR[0-9]{8}[A-Z0-9]{4}$');

ALTER TABLE m07_order
    ADD CONSTRAINT ck_m07_order_type
    CHECK (order_type IN ('DRUG', 'EXAM', 'LAB',
                           'TREATMENT', 'OPERATION'));

ALTER TABLE m07_order
    ADD CONSTRAINT ck_m07_order_status
    CHECK (status IN ('DRAFT', 'ISSUED', 'PAID', 'EXECUTING',
                       'COMPLETED', 'STOPPED', 'CANCELLED',
                       'REFUNDED', 'REJECTED', 'ABANDONED'));

ALTER TABLE m07_order
    ADD CONSTRAINT ck_m07_order_eye
    CHECK (eye_side IN ('OD', 'OS', 'OU', 'NA'));

ALTER TABLE m07_order
    ADD CONSTRAINT ck_m07_order_qty
    CHECK (quantity > 0);

ALTER TABLE m07_order
    ADD CONSTRAINT ck_m07_order_price
    CHECK (unit_price >= 0 AND total_amount >= 0);

-- 已缴费必须有收费单号
ALTER TABLE m07_order
    ADD CONSTRAINT ck_m07_order_paid
    CHECK (status NOT IN ('PAID', 'EXECUTING', 'COMPLETED')
           OR (paid_at IS NOT NULL AND billing_no IS NOT NULL));

-- 已完成必须有执行时间
ALTER TABLE m07_order
    ADD CONSTRAINT ck_m07_order_completed
    CHECK (status <> 'COMPLETED' OR executed_at IS NOT NULL);

-- 已作废必须有原因
ALTER TABLE m07_order
    ADD CONSTRAINT ck_m07_order_cancelled
    CHECK (status <> 'CANCELLED' OR cancel_reason IS NOT NULL);

-- 手术必须单眼
ALTER TABLE m07_order
    ADD CONSTRAINT ck_m07_order_operation_eye
    CHECK (order_type <> 'OPERATION' OR eye_side IN ('OD', 'OS'));

-- 待收费查询
CREATE INDEX idx_m07_order_pending
    ON m07_order (encounter_id, issued_at)
    WHERE status = 'ISSUED' AND is_deleted = FALSE;
```

**状态机**

```
        ┌──────────┐
        │  DRAFT   │  草稿
        └────┬─────┘
             │ issue
             ▼
        ┌──────────┐
        │  ISSUED  │  已下达（待缴费）
        └────┬─────┘
             │
    ┌────────┼────────────┬──────────────┬──────────────┐
    │ on_paid│ cancel      │ stop          │ abandon      │
    ▼        ▼            ▼              ▼              ▼
┌──────────┐┌──────────┐┌──────────┐  ┌──────────┐  ┌──────────┐
│  PAID    ││CANCELLED ││ STOPPED  │  │ABANDONED │  │ REJECTED │
└────┬─────┘└──────────┘└──────────┘  └──────────┘  └──────────┘
     │
     ├── on_executing ──► ┌──────────┐
     │                     │ EXECUTING│
     │                     └────┬─────┘
     │                          │ on_completed
     │                          ▼
     ├── on_completed ───► ┌──────────┐

     │                     └──────────┘
```
