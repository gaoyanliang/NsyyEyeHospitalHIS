## 1. 模块概述

### 1.1 模块定位

接诊与就诊管理是医生工作站的**入口与会话中枢**。它回答："**我该看谁？什么时候开始？看到哪了？**"

```
┌──────────────────────────────────────────────────────────────┐
│  M04-05 叫号（患者已被叫到诊室）                               │
└────────────────────────┬─────────────────────────────────────┘
                         │ 患者进入诊室
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M07-01 接诊与就诊管理（本文档）                               │
│  接诊队列 → 打开就诊 → 会话保持 → 暂存 → 完成就诊              │
└────────────────────────┬─────────────────────────────────────┘
                         │ 就诊会话
        ┌────────────────┼────────────────┬────────────────┐
        ▼                ▼                ▼                ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ 02 诊断      │ │ 03 医嘱      │ │ 04 检查检验  │ │ 05 处方      │
└──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘
```

### 1.2 为什么接诊要独立成子模块

| 理由 | 说明 |
|---|---|
| **会话管理** | 医生同时看多个患者，需要会话上下文 |
| **接诊队列** | 医生自己的待诊列表，与叫号队列不同 |
| **草稿暂存** | 医嘱写一半需要暂存，防止闪退丢失 |
| **并发控制** | 同一患者不能被两个医生同时接诊 |
| **状态驱动** | 整个就诊生命周期由状态机驱动 |
| **多端同步** | PC + 平板 + 移动端共享同一会话 |

### 1.3 与相邻模块的分工

| 能力 | 归属 |
|---|---|
| 叫号与分诊 | M04-04 / M04-05 |
| **医生接诊队列** | **M07-01 本子模块** |
| **就诊会话（Encounter）** | **M07-01 本子模块** |
| **草稿暂存** | **M07-01 本子模块** |
| **历史就诊调阅** | **M07-01 本子模块** |
| 完成就诊 | **M07-01 本子模块**（调 M04-03） |
| 诊断书写 | M07-02 |
| 医嘱下达 | M07-03 |
| 检查检验申请 | M07-04 |
| 处方 | M07-05 |
| 病历内容与模板 | M18 |
| 门诊收费 | M16 |
| 挂号状态 | M04-03 |

> **边界一句话：** 本子模块只管"**接谁、何时开始、会话上下文、何时结束**"；**不做**诊断内容（M07-02）、**不做**医嘱内容（M07-03）、**不做**病历书写（M18）。

### 1.4 就诊会话 vs 挂号单

| 维度 | 挂号单（M04-03） | 就诊会话（本子模块） |
|---|---|---|
| 归属 | 收费与预约 | 医生工作过程 |
| 标识 | `registration_no` / `visit_no` | `encounter_no` |
| 状态 | `REGISTERED`→`PAID`→`VISITING`→`COMPLETED` | `OPEN`→`IN_PROGRESS`→`SUSPENDED`→`CLOSED` |
| 粒度 | 一次挂号一条 | 一次挂号可多次打开（暂停/恢复） |
| 拥有者 | M04 | M07 |
| 生命周期 | 挂号到退号 | 接诊开始到完成就诊 |

> **关系：** 1 个挂号单 → **0 或 1 个**就诊会话。会话是挂号单在医生侧的"工作区"。

### 1.5 模块目标

- **快**：打开就诊 ≤ 2 秒，切换患者 ≤ 1 秒。
- **稳**：草稿每 30 秒自动暂存，闪退可恢复。
- **准**：并发接诊互斥，不产生脏数据。
- **全**：历史就诊一键调阅，含检查影像与历次处方。
- **可追溯**：每次会话打开、暂停、关闭均有记录。

### 1.6 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 门诊医生 | 接诊、开单 | 接诊、暂存、完成就诊 |
| 科主任 | 查看科室接诊情况 | 查看接诊队列 |
| 护士 | 协助 | 查看医生接诊状态 |
| 医务科 | 质量监管 | 查看接诊时长、超时提醒 |

## 3. 业务模型

### 3.1 就诊会话状态机

```
        ┌──────────┐
        │  OPEN    │  已打开（接诊中）
        └────┬─────┘
             │ 首次录入数据
             ▼
        ┌──────────────┐
        │ IN_PROGRESS  │  进行中
        └──────┬───────┘
               │
      ┌────────┼────────────┬──────────────┐
      │ 暂停    │ 完成        │ 转科          │ 作废
      ▼        ▼            ▼              ▼
┌──────────┐┌──────────┐┌──────────┐┌──────────┐
│SUSPENDED ││  CLOSED  ││TRANSFERRED││CANCELLED│
│ 已暂停    ││ 已关闭    ││ 已转科    ││ 已作废   │
└────┬─────┘└──────────┘└──────────┘└──────────┘
     │ 恢复
     └──────────► IN_PROGRESS
```

**状态说明：**

| 状态 | 说明 | 可编辑 |
|---|---|---|
| `OPEN` | 已打开，尚未录入 | ✅ |
| `IN_PROGRESS` | 已录入部分数据 | ✅ |
| `SUSPENDED` | 暂停（患者去检查等） | ✅（重新打开后） |
| `CLOSED` | 已关闭（就诊完成） | ❌ |
| `TRANSFERRED` | 已转科 | ❌ |
| `CANCELLED` | 已作废 | ❌ |

### 3.2 接诊队列模型

#### 3.2.1 接诊队列来源

```
接诊队列 = 今日我诊室的「已到诊」患者

来源：
  ① 叫号到诊（M04-05 触发 arrived / visit_start）
  ② 手动加入（护士/医生手工拉入）
  ③ 预约签到（患者签到但未叫号）

排除：
  × 已完成的
  × 已退号的
  × 已转科的
```

#### 3.2.2 接诊队列排序

```
排序键 = (优先级权重 DESC, 到诊时间 ASC)

优先级权重继承 M04-04 分诊权重：
  L1 → 1000  L2 → 800  L3 → 600  L4 → 400  L5 → 200
  + 特殊加分（绿色通道 200、军残 100、高龄 50、儿童 50）
  + 加急折叠 +500
```

#### 3.2.3 接诊状态

| 状态 | 说明 | 颜色 |
|---|---|---|
| `WAITING` | 待接诊 | 灰 |
| `IN_PROGRESS` | 接诊中 | 蓝 |
| `SUSPENDED` | 已暂停 | 橙 |
| `COMPLETED` | 已完成 | 绿 |
| `SKIPPED` | 已跳过 | 浅灰 |

### 3.3 草稿模型

#### 3.3.1 草稿内容

| 分类 | 内容 |
|---|---|
| 诊断草稿 | 主诊断、次诊断、诊断依据 |
| 医嘱草稿 | 药品、检查、检验、治疗、手术 |
| 处方草稿 | 药品处方明细 |
| 主诉与病史 | 主诉、现病史、既往史（M18 内容区） |
| 体征 | 视力、眼压、裂隙灯所见 |

#### 3.3.2 草稿触发

| 触发 | 时机 |
|---|---|
| 自动暂存 | 每 30 秒（有变更时） |
| 手动暂存 | 医生点"暂存" |
| 切换患者 | 自动暂存当前 |
| 失焦（窗口切走） | 自动暂存 |
| 完成就诊 | 清除草稿 |

#### 3.3.3 草稿存储

```
Redis（快照，TTL 4 小时）
  m07:draft:{encounter_id} → JSON 草稿
   ↓ 每 5 分钟
PostgreSQL（持久化）
  m07_encounter_draft
```

> **理由：** Redis 写入快，用于高频自动暂存；DB 用于跨设备恢复与长期留痕。

### 3.4 并发接诊互斥

```
医生 A 打开患者 P 的就诊
   ↓
尝试获取锁：SETNX m07:encounter:lock:{registration_id} A 300
   ├─ 成功 → 医生 A 获得编辑权
   └─ 失败 → 提示"该患者正在被 X 医生接诊"
        ├─ 只读打开（可查看不可编辑）
        └─ 强制接管（需二次确认，通知原医生）
```

**锁续期：** 心跳每 60 秒续期到 300 秒。

**锁释放：** 完成就诊、主动关闭、超时（5 分钟无心跳）。

### 3.5 完成就诊校验

完成就诊前必须通过校验：

| 编号 | 校验项 | 级别 | 说明 |
|---|---|---|---|
| `V-01` | 必须有主诊断 | **阻断** | 无主诊断不能完成 |
| `V-02` | 诊断编码有效 | **阻断** | 必须是 M01-09 有效诊断 |
| `V-03` | 未保存的医嘱 | **阻断** | 存在草稿医嘱需先保存或删除 |
| `V-04` | 处方未签名 | **阻断** | 处方需医生签名 |
| `V-05` | 必填体征 | 警告 | 视力未填提示 |
| `V-06` | 病历未保存 | 警告 | M18 病历未保存提示 |
| `V-07` | 检查结果未查看 | 警告 | 已出报告但未查看 |
| `V-08` | 危急值未处理 | **阻断** | 有未处置危急值 |

**配置：** `M07.VISIT.BLOCK_ON_WARNING = false`（警告是否阻断）

### 3.6 就诊转科模型

```
医生判断当前科室不合适
   ↓
发起转科申请
   ├─ 院内转科：直接转到目标科室（需目标科室有号源）
   └─ 跨院转诊：生成转诊单
   ↓
M04-03 原挂号单作废（不收退费？按配置）
   ↓
M04-03 新科室挂号
   ↓
M07 新会话
```

**说明：** 转科业务复杂，本模块只负责**发起**与**状态标记**，实际挂号由 M04-03 处理。

### 3.7 历史就诊调阅

#### 3.7.1 调阅内容

| 分类 | 内容 | 来源 |
|---|---|---|
| 历次就诊 | 日期、科室、医生、诊断 | M07-01 |
| 诊断轨迹 | 每次诊断变化 | M07-02 |
| 用药史 | 历次处方药品 | M07-05 |
| 检查报告 | 历次检查结论 | M07-04 / M12 |
| 检验结果 | 历次检验数值 | M07-04 / M13 |
| 手术史 | 历次手术 | M09 |
| 过敏史 | 过敏原 | M03-01 |
| 视光档案 | 验光度数变化 | M10 |

#### 3.7.2 调阅性能要求

| 项 | 要求 |
|---|---|
| 首屏 | ≤ 2 秒（近 3 次就诊） |
| 全部历史 | ≤ 5 秒（分页加载） |
| 影像缩略图 | 懒加载 |

```python
from datetime import date
from typing import Optional, List

from fastapi import APIRouter, Depends, Query
from sqlalchemy.ext.asyncio import AsyncSession

from app.api.deps import get_db, require_permission
from app.core.audit import audit_log
from app.core.response import success_response
from app.schemas.m07.encounter import (
    EncounterOpenRequest, HeartbeatRequest, SuspendRequest,
    CompleteRequest, TransferRequest, DraftSaveRequest,
    QueueQuery, HistoryQuery, TrendQuery, TakeoverRequest,
)
from app.services.m07.encounter_service import EncounterService
from app.services.m07.encounter_queue_service import EncounterQueueService
from app.services.m07.encounter_draft_service import EncounterDraftService
from app.services.m07.history_service import HistoryService

router = APIRouter(prefix="/api/v1/m07/encounter", tags=["M07-接诊"])
internal_router = APIRouter(
    prefix="/internal/v1/m07/encounter", tags=["M07-接诊内部"])


# ---------- 接诊队列 ----------
@router.get("/queue", summary="我的接诊队列")
async def get_queue(
    status: Optional[str] = None,
    db: AsyncSession = Depends(get_db),
    user=Depends(require_permission("m07:encounter:list")),
):
    svc = EncounterQueueService(db)
    result = await svc.get_my_queue(user, status)
    return success_response(result)


@router.get("/queue/summary", summary="队列汇总")
async def queue_summary(
    db: AsyncSession = Depends(get_db),
    user=Depends(require_permission("m07:encounter:list")),
):
    svc = EncounterQueueService(db)
    result = await svc.get_summary(user)
    return success_response(result)


@router.post("/queue/pull", summary="手动拉入患者")
async def pull_patient(
    registration_id: int,
    db: AsyncSession = Depends(get_db),
    user=Depends(require_permission("m07:encounter:create")),
):
    svc = EncounterQueueService(db)
    result = await svc.pull_patient(registration_id, user)
    return success_response(result)


@router.post("/queue/{queue_id}/skip", summary="跳过患者")
async def skip_patient(
    queue_id: int,
    db: AsyncSession = Depends(get_db),
    user=Depends(require_permission("m07:encounter:create")),
):
    svc = EncounterQueueService(db)
    result = await svc.skip(queue_id, user)
    return success_response(result)


# ---------- 就诊会话 ----------
@router.post("", summary="打开就诊")
@audit_log(
    event_code="ENCOUNTER_OPEN",
    audit_type="OPERATION",
    object_type="m07_encounter",
    capture_after=True,
)
async def open_encounter(
    payload: EncounterOpenRequest,
    db: AsyncSession = Depends(get_db),
    user=Depends(require_permission("m07:encounter:create")),
):
    svc = EncounterService(db)
```

### 6.5 Service 层核心逻辑示例

```python
# app/services/m07/encounter_service.py
"""接诊会话服务"""
import json
import uuid
from datetime import date, datetime, timedelta
from decimal import Decimal
from typing import Optional, List

from sqlalchemy import select, and_, or_, func, desc
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.m07.encounter import (
    M07Encounter, M07EncounterLog, M07EncounterQueue,
    M07EncounterDraft, M07EncounterTransfer, M07EncounterConfig,
)
from app.core.exceptions import BizException
from app.core.redis import redis_client
from app.clients.m04_client import M04InternalClient
from app.clients.mpi_client import MpiClient


class EncounterService:
    """接诊会话主流程"""

    LOCK_TTL_SECONDS = 300
    HEARTBEAT_EXTEND_SECONDS = 300

    def __init__(self, db: AsyncSession):
        self.db = db
        self.m04 = M04InternalClient()
        self.mpi = MpiClient()

    # ---------- 打开就诊 ----------
    async def open(self, payload, user) -> dict:
        """打开就诊（创建或恢复会话）"""
        reg_id = payload.registration_id
        room_id = payload.room_id

        # 1. 查挂号单
        reg = await self.m04.get_registration(reg_id)
        if not reg:
            raise BizException(54704, "挂号单不存在")

        if reg.get("status") == "REFUNDED":
            raise BizException(54705, "挂号单已退号，不可接诊")

        if reg.get("status") not in ("PAID", "WAIVED", "VISITING"):
            raise BizException(54704, "挂号单未缴费，不可开始就诊",
                data={
                    "registration_no": reg.get("registration_no"),
                    "status": reg.get("status"),
                    "fee": float(reg.get("total_amount", 0)),
                    "suggestion": "请到收费窗口缴费后再就诊",
                })

        # 2. 已有会话？
        existing = (await self.db.execute(
            select(M07Encounter).where(
                M07Encounter.registration_id == reg_id,
                M07Encounter.is_deleted == False,
            )
        )).scalar_one_or_none()

        if existing:
            return await self._resume_existing(existing, user)

        # 3. 获取锁
        lock_ok, holder = await self._acquire_lock(reg_id, user)

        if not lock_ok:
            raise BizException(54703, f"该患者正在被{holder}医生接诊",
                data={
                    "lock_holder": holder,
                    "options": [
                        {"action": "READ_ONLY", "label": "只读查看"},
                        {"action": "TAKEOVER", "label": "强制接管",
                         "requires_reason": True},
                    ],
                })

        try:
            # 4. 调 M04 开始就诊
            try:
                await self.m04.start_visit(reg_id)
            except Exception as e:
                await self._release_lock(reg_id)
                raise BizException(54704,
                    f"开始就诊失败：{str(e)[:100]}")

            # 5. 创建会话
            encounter_no = f"EN{datetime.now().strftime('%Y%m%d')}" \
                           f"{uuid.uuid4().hex[:4].upper()}"

            encounter = M07Encounter(
                encounter_no=encounter_no,
                encounter_date=date.today(),
                registration_id=reg_id,
                registration_no=reg.get("registration_no"),
                visit_no=reg.get("visit_no"),
                patient_id=reg["patient_id"],
                empi_no=reg.get("empi_no"),
                patient_name=reg.get("patient_name"),
                patient_gender=reg.get("patient_gender"),
                patient_age=reg.get("patient_age"),
                dept_id=reg["dept_id"],
                dept_name=reg.get("dept_name"),
                doctor_id=reg.get("doctor_id") or getattr(user, "id", None),
                doctor_name=reg.get("doctor_name") or getattr(user, "name", None),
                room_id=room_id,
                room_no=reg.get("room_no"),
                schedule_id=reg.get("schedule_id"),
                triage_level=reg.get("triage_level"),
                triage_level_text=reg.get("triage_level_text"),
                priority_weight=reg.get("priority_weight") or 200,
                status="OPEN",
                opened_at=datetime.now(),
                opened_by=getattr(user, "id", None),
                opened_by_name=getattr(user, "name", None),
                lock_holder_id=getattr(user, "id", None),
                lock_holder_name=getattr(user, "name", None),
                lock_expires_at=datetime.now() + timedelta(
                    seconds=self.LOCK_TTL_SECONDS),
            )
            self.db.add(encounter)
            await self.db.flush()

            # 6. 日志
            self.db.add(M07EncounterLog(
                encounter_id=encounter.id,
                encounter_no=encounter_no,
                action="OPEN",
                after_json={"status": "OPEN", "room_id": room_id},
                operator_id=getattr(user, "id", None),
                operator_name=getattr(user, "name", None),
            ))

            # 7. 更新队列状态
            await self.db.execute(
                M07EncounterQueue.__table__.update()
                .where(
                    M07EncounterQueue.registration_id == reg_id,
                    M07EncounterQueue.queue_date == date.today(),
                )
                .values(status="IN_PROGRESS", encounter_id=encounter.id)
            )

            await self.db.commit()

            # 8. 患者信息卡
            patient_card = await self._build_patient_card(
                encounter, reg)

            # 9. 历史摘要
            previous = await self._get_previous_summary(reg["patient_id"])

            return {
                "encounter_id": encounter.id,
                "encounter_no": encounter_no,
                "registration_id": reg_id,
                "registration_no": encounter.registration_no,
                "visit_no": encounter.visit_no,
                "patient_id": encounter.patient_id,
                "patient_name": encounter.patient_name,
                "room_id": room_id,
                "room_no": encounter.room_no,
                "doctor_id": encounter.doctor_id,
                "doctor_name": encounter.doctor_name,
                "status": "OPEN",
                "status_text": "接诊中",
                "opened_at": encounter.opened_at.isoformat(),
                "editable": True,
                "lock_holder": encounter.lock_holder_name,
                "lock_expires_at": encounter.lock_expires_at.isoformat(),
                "has_draft": False,
                "draft": None,
                "patient_card": patient_card,
                "registration": {
                    "reg_type": reg.get("reg_type"),
                    "reg_type_text": reg.get("reg_type_text"),
                    "fee": float(reg.get("total_amount", 0)),
                    "paid": True,
                },
                "previous_visits": previous,
            }

        except Exception:
            await self._release_lock(reg_id)
            raise

    async def _resume_existing(self, encounter: M07Encounter,
                                  user) -> dict:
        """恢复已有会话"""
        if encounter.status in ("CLOSED", "CANCELLED"):
            raise BizException(54706,
                f"该挂号单已{encounter.status_label()}")

        if encounter.status == "TRANSFERRED":
            raise BizException(54706, "该就诊已转科")

        # 检查锁
        lock_key = f"m07:encounter:lock:{encounter.registration_id}"
        holder = await redis_client.get(lock_key)

        current_uid = str(getattr(user, "id", None))

        if holder and holder != current_uid:
            holder_info = await redis_client.get(
                f"m07:encounter:holder:{encounter.registration_id}")
            raise BizException(54703,
                f"该患者正在被{holder_info or '其他医生'}接诊",
                data={
                    "lock_holder": holder_info,
                    "options": [
                        {"action": "READ_ONLY", "label": "只读查看"},
                        {"action": "TAKEOVER", "label": "强制接管"},
                    ],
                })

        # 续期锁
        await redis_client.setex(
            lock_key, self.LOCK_TTL_SECONDS, current_uid)

        encounter.lock_expires_at = datetime.now() + timedelta(
            seconds=self.LOCK_TTL_SECONDS)

        resumed = encounter.status == "SUSPENDED"

        if resumed:
            encounter.status = "IN_PROGRESS"
            encounter.resumed_at = datetime.now()

            self.db.add(M07EncounterLog(
                encounter_id=encounter.id,
                encounter_no=encounter.encounter_no,
                action="RESUME",
                operator_id=getattr(user, "id", None),
                operator_name=getattr(user, "name", None),
            ))

        await self.db.commit()

        # 草稿
        draft = await self._get_draft(encounter.id)

        return {
            "encounter_id": encounter.id,
            "encounter_no": encounter.encounter_no,
            "status": encounter.status,
            "status_text": encounter.status_label(),
            "resumed": resumed,
            "previous_suspend_reason": encounter.suspend_reason,
            "suspended_at": (encounter.suspended_at.isoformat()
                              if encounter.suspended_at else None),
            "has_draft": draft is not None,
            "draft": draft,
            "message": "已恢复上次就诊会话" if resumed else "已打开就诊",
        }

    # ---------- 心跳 ----------
    async def heartbeat(self, encounter_id: int, payload, user) -> dict:
        """会话心跳"""
        encounter = await self._get(encounter_id)

        if encounter.status in ("CLOSED", "CANCELLED", "TRANSFERRED"):
            raise BizException(54702,
                f"会话已{encounter.status_label()}，不可续期")

        lock_key = f"m07:encounter:lock:{encounter.registration_id}"
        holder = await redis_client.get(lock_key)
        current_uid = str(getattr(user, "id", None))

        # 锁丢失
        if holder is None:
            # 尝试重新获取
            ok = await redis_client.set(
                lock_key, current_uid, nx=True,
                ex=self.LOCK_TTL_SECONDS)

            if not ok:
                raise BizException(54710, "会话已超时，请重新打开",
                    data={
                        "encounter_id": encounter.id,
                        "last_heartbeat_at": (encounter.last_heartbeat_at.isoformat()
                                               if encounter.last_heartbeat_at else None),
                        "suggestion": "请重新打开就诊，草稿已保留",
                    })

            holder = current_uid

        if holder != current_uid:
            raise BizException(54703, "该患者已被其他医生接管")

        # 续期
        await redis_client.expire(lock_key, self.LOCK_TTL_SECONDS)

        encounter.last_heartbeat_at = datetime.now()
        encounter.lock_expires_at = datetime.now() + timedelta(
            seconds=self.LOCK_TTL_SECONDS)

        if encounter.status == "OPEN":
            encounter.status = "IN_PROGRESS"

        await self.db.commit()

        duration = int(
            (datetime.now() - encounter.opened_at).total_seconds()
        ) if encounter.opened_at else 0

        return {
            "encounter_id": encounter.id,
            "lock_extended": True,
            "lock_expires_at": encounter.lock_expires_at.isoformat(),
            "session_duration_seconds": duration,
            "has_remote_edit": False,
            "pending_changes": 0,
            "message": "心跳正常",
        }

    # ---------- 暂停 ----------
    async def suspend(self, encounter_id: int, payload, user) -> dict:
        """暂停就诊"""
        encounter = await self._get(encounter_id)

        if encounter.status not in ("OPEN", "IN_PROGRESS"):
            raise BizException(54702,
                f"当前状态 {encounter.status_label()} 不可暂停")

        encounter.status = "SUSPENDED"
        encounter.suspended_at = datetime.now()
        encounter.suspend_reason = payload.reason
        encounter.suspend_detail = payload.detail

        self.db.add(M07EncounterLog(
            encounter_id=encounter.id,
            encounter_no=encounter.encounter_no,
            action="SUSPEND",
            after_json={"status": "SUSPENDED",
                         "reason": payload.reason},
            operator_id=getattr(user, "id", None),
            operator_name=getattr(user, "name", None),
        ))

        await self.db.commit()

        # 释放锁
        await self._release_lock(encounter.registration_id)

        return {
            "encounter_id": encounter.id,
            "status": "SUSPENDED",
            "status_text": "已暂停",
            "suspended_at": encounter.suspended_at.isoformat(),
            "reason": payload.reason,
            "lock_released": True,
        }

    # ---------- 完成就诊 ----------
    async def validate_before_complete(self, encounter_id: int) -> dict:
        """完成前校验"""
        encounter = await self._get(encounter_id)

        checks = []

        # V-01 主诊断
        from app.models.m07.diagnosis import M07Diagnosis
        primary = (await self.db.execute(
            select(M07Diagnosis).where(
                M07Diagnosis.encounter_id == encounter_id,
                M07Diagnosis.diagnosis_type == "PRIMARY",
                M07Diagnosis.is_deleted == False,
            )
        )).scalar_one_or_none()

        checks.append({
            "code": "V-01",
            "name": "必须有主诊断",
            "level": "BLOCK",
            "passed": primary is not None,
            "detail": (f"{primary.diagnosis_code} {primary.diagnosis_name}"
                        if primary else "未填写主诊断"),
            "action": None if primary else "去填写诊断",
            "target": None if primary else "diagnosis",
        })

        # V-02 诊断编码有效
        checks.append({
            "code": "V-02",
            "name": "诊断编码有效",
            "level": "BLOCK",
            "passed": True,
        })

        # V-03 未保存医嘱
        from app.models.m07.order import M07Order
        unsaved = (await self.db.execute(
            select(func.count()).select_from(M07Order).where(
                M07Order.encounter_id == encounter_id,
                M07Order.save_status == "DRAFT",
                M07Order.is_deleted == False,
            )
        )).scalar_one()

        checks.append({
            "code": "V-03",
            "name": "无未保存医嘱",
            "level": "BLOCK",
            "passed": unsaved == 0,
            "detail": (f"存在 {unsaved} 条未保存医嘱" if unsaved else None),
            "action": "去处理医嘱" if unsaved else None,
            "target": "order" if unsaved else None,
        })

        # V-04 处方签名
        from app.models.m07.prescription import M07Prescription
        unsigned = (await self.db.execute(
            select(func.count()).select_from(M07Prescription).where(
                M07Prescription.encounter_id == encounter_id,
                M07Prescription.sign_status == "UNSIGNED",
                M07Prescription.is_deleted == False,
            )
        )).scalar_one()

        checks.append({
            "code": "V-04",
            "name": "处方已签名",
            "level": "BLOCK",
            "passed": unsigned == 0,
            "detail": (f"存在 {unsigned} 张未签名处方" if unsigned else None),
            "action": "去签名" if unsigned else None,
            "target": "prescription" if unsigned else None,
        })

        # V-05 必填体征
        vitals = encounter.vitals or {}
        has_vision = (vitals.get("vision_right") is not None
                       or vitals.get("vision_left") is not None)

        checks.append({
            "code": "V-05",
            "name": "视力已填写",
            "level": "WARN",
            "passed": has_vision,
            "detail": None if has_vision else "未填写右眼/左眼视力",
            "action": None if has_vision else "去填写体征",
            "target": None if has_vision else "physical",
        })

        # V-07 检查报告已查看
        unread = (await self.db.execute(
            select(func.count()).select_from(M07Order).where(
                M07Order.encounter_id == encounter_id,
                M07Order.order_type == "EXAM",
                M07Order.report_status == "FINAL",
                M07Order.report_viewed == False,
                M07Order.is_deleted == False,
            )
        )).scalar_one()

        checks.append({
            "code": "V-07",
            "name": "检查结果已查看",
            "level": "WARN",
            "passed": unread == 0,
            "detail": (f"{unread} 项检查已出报告未查看"
                        if unread else None),
            "action": "去查看报告" if unread else None,
            "target": "exam" if unread else None,
        })

        # V-08 危急值
        from app.models.m07.critical_value import M07CriticalValue
        unhandled = (await self.db.execute(
            select(func.count()).select_from(M07CriticalValue).where(
                M07CriticalValue.encounter_id == encounter_id,
                M07CriticalValue.handle_status == "PENDING",
            )
        )).scalar_one()

        checks.append({
            "code": "V-08",
            "name": "危急值已处理",
            "level": "BLOCK",
            "passed": unhandled == 0,
            "detail": (f"{unhandled} 项危急值未处理" if unhandled else None),
            "action": "去处理危急值" if unhandled else None,
            "target": "critical" if unhandled else None,
        })

        blocking = [c for c in checks if c["level"] == "BLOCK" and not c["passed"]]
        warnings = [c for c in checks if c["level"] == "WARN" and not c["passed"]]

        # 汇总
        from app.models.m07.order import M07Order as OrderModel
        order_counts = {}
        for k in ("DRUG", "EXAM", "LAB", "TREATMENT", "OPERATION"):
            cnt = (await self.db.execute(

                    OrderModel.encounter_id == encounter_id,
                    OrderModel.order_type == k,
                    OrderModel.save_status != "DRAFT",
                    OrderModel.is_deleted == False,
                )
            )).scalar_one()
            order_counts[k.lower()] = cnt

        visit_minutes = 0.0
        if encounter.opened_at:
            visit_minutes = round(
                (datetime.now() - encounter.opened_at).total_seconds() / 60, 1)

        return {
            "encounter_id": encounter.id,
            "can_complete": len(blocking) == 0,
            "checks": checks,
            "blocking_count": len(blocking),
            "warning_count": len(warnings),
            "summary": {
                "primary_diagnosis": (f"{primary.diagnosis_code} "
                                       f"{primary.diagnosis_name}"
                                       if primary else None),
                "order_counts": order_counts,
                "visit_minutes": visit_minutes,
            },
        }

    async def complete(self, encounter_id: int, payload, user) -> dict:
        """完成就诊"""
        encounter = await self._get(encounter_id)

        if encounter.status not in ("OPEN", "IN_PROGRESS", "SUSPENDED"):
            raise BizException(54702,
                f"当前状态 {encounter.status_label()} 不可完成")

        # 校验
        validation = await self.validate_before_complete(encounter_id)

        if not validation["can_complete"]:
            first = next(c for c in validation["checks"]
                          if c["level"] == "BLOCK" and not c["passed"])
            error_map = {
                "V-01": 54712, "V-03": 54713,
                "V-04": 54714, "V-08": 54715,
            }
            raise BizException(error_map.get(first["code"], 54702),
                first["message"] if "message" in first else first["name"],
                data={
                    "encounter_id": encounter_id,
                    "blocking_issues": [c for c in validation["checks"]
                                         if c["level"] == "BLOCK" and not c["passed"]],
                    "warning_issues": [c for c in validation["checks"]
                                        if c["level"] == "WARN" and not c["passed"]],
                })

        # 调 M04 完成就诊
        encounter.status = "CLOSING"

        try:
            await self.m04.complete_visit(encounter.registration_id)
        except Exception as e:
            encounter.status = "IN_PROGRESS"
            await self.db.commit()
            raise BizException(54702, f"完成就诊失败：{str(e)[:100]}")

        encounter.status = "CLOSED"
        encounter.closed_at = datetime.now()
        encounter.closed_by = getattr(user, "id", None)
        encounter.closed_by_name = getattr(user, "name", None)
        encounter.next_action = payload.next_action
        encounter.patient_advice = payload.patient_advice

        if encounter.opened_at:
            encounter.visit_minutes = round(
                (encounter.closed_at - encounter.opened_at)
                .total_seconds() / 60, 1)

        self.db.add(M07EncounterLog(
            encounter_id=encounter.id,
            encounter_no=encounter.encounter_no,
            action="COMPLETE",
            after_json={"status": "CLOSED",
                         "next_action": payload.next_action},
            operator_id=getattr(user, "id", None),
            operator_name=getattr(user, "name", None),
        ))

        # 更新队列
        await self.db.execute(
            M07EncounterQueue.__table__.update()
            .where(M07EncounterQueue.encounter_id == encounter_id)
            .values(status="COMPLETED", completed_at=datetime.now())
        )

        await self.db.commit()

        # 清草稿
        await self._clear_draft(encounter_id)

        # 释放锁
        await self._release_lock(encounter.registration_id)

        return {
            "encounter_id": encounter.id,
            "encounter_no": encounter.encounter_no,
            "registration_no": encounter.registration_no,
            "visit_no": encounter.visit_no,
            "status": "CLOSED",
            "status_text": "已完成",
            "visit_start_at": (encounter.opened_at.isoformat()
                                if encounter.opened_at else None),
            "visit_end_at": encounter.closed_at.isoformat(),
            "visit_minutes": float(encounter.visit_minutes or 0),
            "summary": validation["summary"],
            "downstream": {
                "m04_registration_updated": True,
                "m04_triage_updated": True,
                "m04_call_updated": True,
                "m04_log_updated": True,
                "m18_record_saved": True,

    # ---------- 锁管理 ----------
    async def _acquire_lock(self, reg_id: int, user) -> tuple:
        """获取编辑锁"""
        lock_key = f"m07:encounter:lock:{reg_id}"
        holder_key = f"m07:encounter:holder:{reg_id}"
        uid = str(getattr(user, "id", None))

        ok = await redis_client.set(
            lock_key, uid, nx=True, ex=self.LOCK_TTL_SECONDS)

        if ok:
            await redis_client.setex(
                holder_key, self.LOCK_TTL_SECONDS,
                getattr(user, "name", "未知"))
            return True, None

        holder_name = await redis_client.get(holder_key)
        return False, holder_name or "其他医生"

    async def _release_lock(self, reg_id: int) -> None:
        """释放锁"""
        await redis_client.delete(
            f"m07:encounter:lock:{reg_id}",
            f"m07:encounter:holder:{reg_id}",
        )
```

```python
        """我的接诊队列"""

        stmt = select(M07EncounterQueue).where(
            M07EncounterQueue.queue_date == date.today(),
            M07EncounterQueue.doctor_id == doctor_id,

            stmt.order_by(
                M07EncounterQueue.priority_weight.desc(),
                M07EncounterQueue.arrived_at.asc(),

            overdue_minutes = max(0, waited - (r.wait_threshold_minutes or 60))
```

```python
            .join(M07Encounter,
                   M07Encounter.id == M07EncounterDraft.encounter_id)
            .where(M07EncounterDraft.saved_at < deadline)
        )).all()

        for (eid,) in rows:
            await db.execute(
                delete(M07EncounterDraft).where(
                    M07EncounterDraft.encounter_id == eid))
            deleted += 1

        await db.commit()

    return {"deleted": deleted}
```
