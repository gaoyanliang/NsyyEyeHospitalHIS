## 4. 数据结构设计

### 4.1 ER 关系图

```
┌──────────────────────────────────────────────────────────────────────┐
│ 数据来源（业务明细表，只读汇总）                                        │
│  m07_encounter（01）  m07_order（03）  m07_prescription（05）         │
│  m07_report（04）     m07_document（06）  m07_critical_value（04）    │
│  mdm_employee（M01）  mdm_department（M01）                           │
└──────────────────────────────┬───────────────────────────────────────┘
                               │ 每日 02:00 聚合
                               ▼
┌───────────────────────────────────┐
│ m07_workload_daily ★核心           │
│  · 粒度：医生 × 日期                │
│  · 接诊量 / 诊时 / 开单 / 质量      │
│  · 三项得分 + 综合评分              │
└───┬───────────────────┬───────────┘
    │ 每月聚合            │ 同步汇总
    ▼                    ▼
┌──────────────────┐  ┌────────────────────────┐
│workload_monthly  │  │workload_dept_daily     │
│（医生 × 月）       │  │（科室 × 日期）           │
└──────────────────┘  └────────────────────────┘

支撑表：
┌──────────────────────────┐  ┌──────────────────────────┐
│workload_recalc_log       │  │workload_score_config     │
│（重算留痕）                │  │（评分权重配置）            │
└──────────────────────────┘  └──────────────────────────┘
```

**设计说明：**

- **预聚合是性能关键** —— 明细表年 61 万行，报表扫明细需 3~8 秒；汇总表只有 7,300 行/年
- **三张汇总表粒度不同** —— 医生日/医生月/科室日，各服务于不同查询
- **汇总表可重建** —— 删除重算即可，不丢数据（源数据才是真相）
- **评分在汇总时算好** —— 避免查询时重算，也保证历史评分不变
- **重算留痕独立成表** —— 数据修正必须可追溯
- **权重配置成表** —— 各院政策不同，可调整

**约束说明**

```sql
ALTER TABLE m07_workload_daily
    ADD CONSTRAINT ck_m07_wl_daily_counts CHECK (
        visit_count >= 0 AND first_visit_count >= 0
        AND exam_count >= 0 AND lab_count >= 0
        AND drug_count >= 0 AND treatment_count >= 0
        AND operation_count >= 0 AND prescription_count >= 0
        AND document_count >= 0);

ALTER TABLE m07_workload_daily
    ADD CONSTRAINT ck_m07_wl_daily_amount CHECK (
        order_amount >= 0 AND drug_amount >= 0
        AND exam_amount >= 0 AND lab_amount >= 0
        AND treatment_amount >= 0 AND operation_amount >= 0);

ALTER TABLE m07_workload_daily
    ADD CONSTRAINT ck_m07_wl_daily_time CHECK (
        total_duration_minutes >= 0
        AND total_wait_minutes >= 0
        AND work_minutes >= 0
        AND max_wait_minutes >= 0);

-- 初诊不能超过接诊量
ALTER TABLE m07_workload_daily
    ADD CONSTRAINT ck_m07_wl_daily_first
    CHECK (first_visit_count <= visit_count);

-- 百分比范围
ALTER TABLE m07_workload_daily
    ADD CONSTRAINT ck_m07_wl_daily_rates CHECK (
        diagnosis_completeness BETWEEN 0 AND 100
        AND prescription_pass_rate BETWEEN 0 AND 100
        AND antibiotic_rate BETWEEN 0 AND 100
        AND document_timeliness BETWEEN 0 AND 100
        AND critical_handle_rate BETWEEN 0 AND 100
        AND report_unread_rate BETWEEN 0 AND 100);

-- 得分范围
ALTER TABLE m07_workload_daily
    ADD CONSTRAINT ck_m07_wl_daily_scores CHECK (
        workload_score BETWEEN 0 AND 120
        AND efficiency_score BETWEEN 0 AND 120
        AND quality_score BETWEEN 0 AND 120
        AND composite_score BETWEEN 0 AND 120);

-- 金额合计一致性（容差 0.01）
ALTER TABLE m07_workload_daily
    ADD CONSTRAINT ck_m07_wl_daily_amount_sum CHECK (
        abs(order_amount - (drug_amount + exam_amount
            + lab_amount + treatment_amount
            + operation_amount)) <= 0.01);

CREATE UNIQUE INDEX uk_m07_wl_daily
    ON m07_workload_daily (doctor_id, work_date);

CREATE INDEX idx_m07_wl_daily_doctor
    ON m07_workload_daily (doctor_id, work_date DESC);

CREATE INDEX idx_m07_wl_daily_score
    ON m07_workload_daily (dept_id, work_date, composite_score DESC);
```

**幂等保证：**

```sql
-- 聚合任务使用 UPSERT（幂等，重跑安全）
INSERT INTO m07_workload_daily (
    doctor_id, work_date, visit_count, ...
) VALUES (...)
ON CONFLICT (doctor_id, work_date)
DO UPDATE SET
    visit_count = EXCLUDED.visit_count,
    ...
    generated_at = NOW();
```

**量级估算：**

| 项 | 数值 |
|---|---|
| 医生数 | 20 |
| 单行大小 | ≈350 B |
| 年行数 | 20 × 365 = 7,300 |
| 年存储 | ≈2.5 MB |

**保留期：** **10 年**（统计数据可不分区，数据量小）。

**定稿机制：**

```
月度汇总生成 → is_finalized = FALSE（可重算）
绩效办确认     → is_finalized = TRUE （不可重算，需解冻）

作用：
· 防止绩效计算后数据变动
· 提供审计基线
```

        """质量指标达标状态"""
        target_info = self.QUALITY_TARGETS.get(metric)
        if not target_info:
            return "UNKNOWN"

        _, target, op = target_info
        value = float(getattr(self, metric, 0) or 0)

        if op == "GTE":
            return "PASS" if value >= target else "FAIL"
        return "PASS" if value <= target else "FAIL"

        out = []

            out.append({
                "metric": code,
                "name": name,
                "value": float(getattr(self, code, 0) or 0),
                "target": target,
                "target_op": op,
                "status": self.quality_status(code),

        Integer, default=15, nullable=False)
    score_cap: Mapped[Decimal] = mapped_column(
        Numeric(6, 1), default=Decimal("120.0"), nullable=False)

    quality_weight_diagnosis: Mapped[Decimal] = mapped_column(
        Numeric(4, 2), default=Decimal("0.40"), nullable=False)
    quality_weight_prescription: Mapped[Decimal] = mapped_column(
        Numeric(4, 2), default=Decimal("0.30"), nullable=False)
    quality_weight_document: Mapped[Decimal] = mapped_column(
        Numeric(4, 2), default=Decimal("0.30"), nullable=False)

    low_score_threshold: Mapped[Decimal] = mapped_column(
        Numeric(6, 1), default=Decimal("85.0"), nullable=False)

    is_active: Mapped[bool] = mapped_column(
        Boolean, default=True, nullable=False)
    effective_date: Mapped[Optional[date]] = mapped_column(Date)
    remark: Mapped[Optional[str]] = mapped_column(String(500))

    created_by: Mapped[Optional[int]] = mapped_column(BigInteger)
    created_by_name: Mapped[Optional[str]] = mapped_column(String(64))
    created_at: Mapped[datetime] = mapped_column(
        DateTime, server_default=func.now())
    updated_at: Mapped[Optional[datetime]] = mapped_column(
        DateTime, server_default=func.now(), onupdate=func.now())

        UniqueConstraint("config_version", name="uk_m07_wl_cfg_version"),
        Index("uk_m07_wl_cfg_active", "is_active", unique=True,
              postgresql_where="is_active = TRUE"),
        {"comment": "评分权重配置"},
    )

    def weights(self) -> dict:
        return {
            "workload": float(self.weight_workload),
            "efficiency": float(self.weight_efficiency),
            "quality": float(self.weight_quality),
        }

    def quality_weights(self) -> dict:
        return {
            "diagnosis": float(self.quality_weight_diagnosis),
            "prescription": float(self.quality_weight_prescription),
            "document": float(self.quality_weight_document),
        }

    def calc_workload_score(self, visit_count: int) -> float:
        """工作量得分"""
        if not self.workload_base:
            return 0.0
        score = visit_count / self.workload_base * 100
        return round(min(float(self.score_cap), score), 1)

    def calc_efficiency_score(self, total_minutes: float,
                                visit_count: int,
                                timeout_count: int) -> float:
        """效率得分（诊时 70% + 超时 30%）"""
        if not visit_count:
            return 0.0

        avg = total_minutes / visit_count
        ideal = float(self.ideal_duration)

        if avg and avg > 0:
            duration_score = min(float(self.score_cap), ideal / avg * 100)
        else:
            duration_score = float(self.score_cap)

        timeout_rate = timeout_count / visit_count * 100
        timeout_score = max(0.0, 100.0 - timeout_rate)

        return round(duration_score * 0.7 + timeout_score * 0.3, 1)

    def calc_quality_score(self, diagnosis_rate: float,
                             prescription_rate: float,
                             document_rate: float) -> float:
        """质量得分"""
        return round(
            diagnosis_rate * float(self.quality_weight_diagnosis)
            + prescription_rate * float(
                self.quality_weight_prescription)
            + document_rate * float(self.quality_weight_document), 1)

    def calc_composite(self, workload_score: float,
                         efficiency_score: float,
                         quality_score: float) -> float:
        """综合评分"""
        return round(
            workload_score * float(self.weight_workload)
            + efficiency_score * float(self.weight_efficiency)
            + quality_score * float(self.weight_quality), 1)

    def summary_text(self) -> str:
        return (f"工作量 {float(self.weight_workload):.0%} / "
                f"效率 {float(self.weight_efficiency):.0%} / "
                f"质量 {float(self.weight_quality):.0%}")
