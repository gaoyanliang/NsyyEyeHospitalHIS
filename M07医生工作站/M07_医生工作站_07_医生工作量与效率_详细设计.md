## 1. 模块概述

### 1.1 模块定位

医生工作量与效率是医生工作站的**度量层**。它回答："**这个医生干了多少活？效率怎么样？贡献多大？**"

```
┌──────────────────────────────────────────────────────────────┐
│  业务数据层（前 6 个子模块产生的痕迹）                          │
│  01 会话  │ 02 诊断 │ 03 医嘱 │ 04 报告 │ 05 处方 │ 06 文书    │
└────────────────────────┬─────────────────────────────────────┘
                         │ 只读汇总（不改数据）
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M07-07 医生工作量与效率（本文档）★度量层                       │
│  ① 接诊量    ② 诊时效率   ③ 开单量                           │
│  ④ 收入贡献  ⑤ 质量指标   ⑥ 排名与对比                        │
└────────────────────────┬─────────────────────────────────────┘
                         │
        ┌────────────────┼────────────────┬────────────────┐
        ▼                ▼                ▼                ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ 医生自查      │ │ 科主任考核    │ │ 医务科质控    │ │ M17 绩效      │
└──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘
```

### 1.2 为什么工作量统计要独立成子模块

| 理由 | 说明 |
|---|---|
| **数据分散** | 接诊量在 01、开单在 03、处方在 05、文书在 06 |
| **口径复杂** | "接诊量"算初诊还是复诊？退号的算不算？ |
| **性能敏感** | 全量明细表聚合会拖慢业务库 |
| **预聚合** | 需要按日/科室/医生预聚合，避免每次扫明细 |
| **绩效依据** | 数据要经得起质询，口径必须固化 |
| **多维度** | 日/周/月/季/年，个人/科室/全院 |

### 1.3 与前 6 个子模块的分工

| 数据 | 产出方 | 本模块职责 |
|---|---|---|
| 接诊会话、诊时 | M07-01 | 汇总计数与时长 |
| 诊断数 | M07-02 | 汇总 |
| 医嘱量与金额 | M07-03 | 汇总 |
| 报告阅片数 | M07-04 | 汇总 |
| **处方与抗菌药** | **M07-05** | **汇总使用率** |
| 文书签署与打印 | M07-06 | 汇总 |
| **统计口径与预聚合** | **M07-07 本子模块** | — |
| **排名与绩效考核** | **M07-07 本子模块** | — |

> **边界一句话：** 本模块**只读不写业务数据**，只做汇总、计算、排名；**不改变**任何诊疗记录。

### 1.4 统计维度矩阵

```
维度一：时间
  · 日 / 周 / 月 / 季 / 年 / 自定义区间

维度二：对象
  · 医生个人 / 科室 / 全院

维度三：指标
  · 工作量：接诊量、初诊/复诊、开单数、处方数、手术台次
  · 效率：平均诊时、平均等待、超时率、翻台率
  · 质量：诊断完整率、处方合格率、抗菌药使用率、文书及时率
  · 经济：开单金额、药品占比、检查占比、人均费用
```

### 1.5 模块目标

- **准**：口径固化，可追溯，经得起质询。
- **快**：常用报表 ≤ 1 秒（靠预聚合）。
- **全**：工作量、效率、质量、经济四个维度。
- **公平**：同类可比（同科室、同职称）。
- **自动**：每日自动汇总，无需人工触发。
- **可下钻**：从科室到医生到患者明细。

### 1.6 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 门诊医生 | 自查 | 查看本人工作量 |
| 科主任 | 考核 | 查看本科室排名、对比 |
| 医务科 | 质控 | 全院质控指标 |
| 院领导 | 决策 | 全院趋势 |
| 绩效办 | 绩效 | 导出绩效数据 |

## 3. 业务模型

### 3.1 统计口径定义（**核心：必须固化**）

#### 3.1.1 接诊量口径

| 术语 | 定义 | 说明 |
|---|---|---|
| **接诊量** | 状态为 `COMPLETED` 的会话数 | 已完成就诊 |
| **挂号量** | 状态非 `CANCELLED`/`REFUNDED` 的挂号数 | 含未就诊 |
| **实际接诊** | `started_at` 非空的会话数 | 医生实际开始 |
| **初诊** | 患者首次在本院就诊 | 按 EMPI 判断 |
| **复诊** | 非首次 | — |
| **退号** | 状态为 `REFUNDED`/`CANCELLED` | **不计入接诊量** |

**关键规则：**

```
接诊量 = COUNT(会话 WHERE status = 'COMPLETED' AND date = ?)

排除：
· 已取消（CANCELLED）
· 已退号（REFUNDED）
· 已转诊（TRANSFERRED）
· 未开始就结束（started_at IS NULL）→ 单独统计为"异常结束"
```

#### 3.1.2 诊时口径

| 术语 | 计算 | 说明 |
|---|---|---|
| **接诊时长** | `ended_at - started_at` | 单次会话 |
| **有效诊时** | 接诊时长 - 暂停时长 | 扣除暂停 |
| **等待时长** | `started_at - queue_time` | 患者等待 |
| **平均诊时** | Σ有效诊时 / 接诊量 | — |
| **诊时中位数** | 排序取中位 | 抗极端值 |
| **超时率** | 诊时 > 阈值 / 接诊量 | 阈值可配 |

**诊时计算（扣除暂停）：**

```
若会话有多次暂停：
  有效诊时 = (ended_at - started_at) - Σ(每个暂停区间的时长)

示例：
  09:00 开始 → 09:05 暂停 → 09:12 恢复 → 09:20 结束
  总时长 = 20 分钟
  暂停 = 7 分钟
  有效诊时 = 13 分钟
```

#### 3.1.3 开单量口径

| 指标 | 计算 | 说明 |
|---|---|---|
| **医嘱总数** | 状态非 `CANCELLED` 的医嘱数 | 已下达 |
| **检查数** | `order_type='EXAM'` 且状态有效 | — |
| **检验数** | `order_type='LAB'` | — |
| **药品数** | `order_type='DRUG'` | — |
| **治疗数** | `order_type='TREATMENT'` | — |
| **手术台次** | `order_type='OPERATION'` 且已执行 | 主刀 + 助手分开 |
| **开单金额** | Σ `total_amount` | 医嘱金额 |
| **药品占比** | 药品金额 / 总金额 | 合理用药指标 |
| **检查占比** | 检查金额 / 总金额 | — |

#### 3.1.4 质量指标口径

| 指标 | 计算 | 目标 |
|---|---|---|
| **诊断完整率** | 有主诊断的会话 / 总会话 | ≥99% |
| **处方合格率** | 未退回处方 / 总处方 | ≥95% |
| **抗菌药使用率** | 含抗菌药处方 / 总处方 | ≤20% |
| **文书及时率** | 就诊后 24h 内签名的文书 / 总文书 | ≥95% |
| **危急值处置率** | 已处置 / 发现危急值 | 100% |
| **报告未阅率** | 未阅报告 / 已出报告 | ≤30% |

#### 3.1.5 效率指标口径

| 指标 | 计算 | 说明 |
|---|---|---|
| **翻台率** | 接诊量 / 出诊时长（小时） | 每小时接诊人数 |
| **出诊时长** | 首个会话开始 → 末个会话结束 | 实际工作时段 |
| **超时率** | 诊时 > 15 分钟 / 接诊量 | 阈值可配 |
| **平均等待** | Σ等待时长 / 接诊量 | 患者体验 |
| **最长等待** | MAX(等待时长) | 极端值 |

### 3.2 预聚合模型（性能关键）

#### 3.2.1 为什么要预聚合

```
❌ 实时聚合（不可行）：
  接诊量 = SELECT COUNT(*) FROM m07_encounter WHERE ...  -- 61 万行/年
  每次看报表都要扫一遍 → 3~8 秒

✅ 预聚合：
  每日 02:00 汇总昨日数据 → m07_workload_daily
  报表查询只扫汇总表（365 行/医生/年）→ 50ms
```

#### 3.2.2 预聚合粒度

| 表 | 粒度 | 行数估算 | 用途 |
|---|---|---|---|
| `m07_workload_daily` | 医生 × 日期 | 20 × 365 = 7,300/年 | 日统计 |
| `m07_workload_monthly` | 医生 × 月份 | 20 × 12 = 240/年 | 月统计 |
| `m07_workload_dept_daily` | 科室 × 日期 | 12 × 365 = 4,380/年 | 科室统计 |

#### 3.2.3 汇总链路

```
业务明细表
   ↓ 每日 02:00 汇总（Celery）
m07_workload_daily（日汇总）
   ↓ 每月 1 日 03:00 汇总
m07_workload_monthly（月汇总）
   ↓
报表查询（< 100ms）
```

**重算机制：** 若历史数据修正，可指定日期重算（幂等 upsert）。

### 3.3 排名模型

#### 3.3.1 排名维度

| 排名类型 | 排序依据 | 范围 |
|---|---|---|
| 接诊量排名 | `visit_count` DESC | 科室/全院 |
| 开单额排名 | `order_amount` DESC | 科室/全院 |
| 效率排名 | `avg_duration` ASC | 科室/全院 |
| 质量排名 | 综合评分 | 科室/全院 |

#### 3.3.2 综合评分模型

```
综合评分 = 工作量(40%) + 效率(30%) + 质量(30%)

工作量分 = (本人接诊量 / 科室平均接诊量) × 100，上限 120
效率分   = (科室平均诊时 / 本人诊时) × 100，上限 120
质量分   = 诊断完整率×40 + 处方合格率×30 + 文书及时率×30

最终 = 0.4×工作量分 + 0.3×效率分 + 0.3×质量分
```

**说明：** 评分模型**可配置**（权重存在系统参数），各院可按政策调整。

### 3.4 对比模型

#### 3.4.1 对比维度

| 对比类型 | 说明 |
|---|---|
| **同期对比** | 本月 vs 去年同月 |
| **环比** | 本月 vs 上月 |
| **同类对比** | 同科室同职称平均 |
| **全院对比** | 全院平均 |

#### 3.4.2 趋势分析

```
近 12 个月接诊量趋势
近 30 天日均诊时趋势
近 7 天工作量趋势
```

### 3.5 数据来源与归属

| 指标 | 主数据源 | 归属判定 |
|---|---|---|
| 接诊量 | `m07_encounter` | `doctor_id` + `encounter_date` |
| 初诊/复诊 | `m07_encounter.visit_type` | — |
| 诊时 | `m07_encounter` 时间字段 | — |
| 医嘱量 | `m07_order` | `doctor_id` + `order_date` |
| 处方量 | `m07_prescription` | `doctor_id` + `created_at` |
| 手术台次 | `m07_order_operation_ext` | `surgeon_id` |
| 文书 | `m07_document` | `doctor_id` + `signed_at` |
| 抗菌药 | `m07_prescription.has_antibiotic` | — |

**归属原则：** 以**开单医生**为归属人，不以执行医生；手术以**主刀**为主、助手记为 0.5 台次。

### 3.6 数据修正模型

```
场景：某医生昨天的数据录错了

处理：
  1. 修正源数据（业务模块）
  2. 手动触发重算：POST /workload/recalculate?date=2026-10-19
  3. 系统删除该日汇总 → 重新聚合
  4. 不影响其他日期

约束：
  · 重算需医务科权限
  · 全量重算需审批
  · 重算留痕
```

    def _aggregate_rows(self, rows) -> dict:

                "visit_count"] * 100

            elif g <= -10:
                tips.append(
                    f"本月接诊量较上月下降 {abs(g):.1f}%，建议关注")

        abx = agg.get("antibiotic_rate", 0)
        if abx >= 18:
            tips.append(
                f"抗菌药使用率 {abx}%，接近 20% 目标上限，建议关注")

        crit = agg.get("critical_handle_rate", 100)
        if crit < 100:
            tips.append(f"危急值处置率 {crit}%，仍有未闭环项")

        return tips

    # ---------- 趋势 ----------
    async def get_trend(self, doctor_id: Optional[int], metric: str,
                          granularity: str, days: int) -> dict:
        """趋势数据"""
        if metric not in METRIC_META:
            raise BizException(40001, f"未知指标：{metric}")

        end = date.today() - timedelta(days=1)
        start = end - timedelta(days=days - 1)

        if granularity == "month":
            rows = (await self.db.execute(
                select(M07WorkloadMonthly).where(
                    M07WorkloadMonthly.doctor_id == doctor_id,
                    M07WorkloadMonthly.work_month >= start.replace(day=1),
                    M07WorkloadMonthly.work_month <= end,
                ).order_by(M07WorkloadMonthly.work_month)
            )).scalars().all()

            points = [
                {"date": r.work_month.isoformat(),
                 "value": getattr(r, metric) or 0}
                for r in rows
            ]
        else:
            rows = (await self.db.execute(
                select(M07WorkloadDaily).where(
                    M07WorkloadDaily.doctor_id == doctor_id,
                    M07WorkloadDaily.work_date >= start,
                    M07WorkloadDaily.work_date <= end,
                ).order_by(M07WorkloadDaily.work_date)
            )).scalars().all()

            points = [
                {"date": r.work_date.isoformat(),
                 "value": getattr(r, metric) or 0,
                 "is_workday": r.work_date.weekday() < 5}
                for r in rows
            ]

        values = [p["value"] for p in points if p["value"]]
        name, unit, _ = METRIC_META[metric]

        stats = {}
        if values:
            sorted_vals = sorted(values)
            stats = {
                "total": sum(values),
                "avg": round(sum(values) / len(values), 1),
                "max": max(values),
                "min": min(values),
                "median": sorted_vals[len(sorted_vals) // 2],
            }

        return {
            "doctor_id": doctor_id,
            "metric": metric,
            "metric_name": name,
            "unit": unit,
            "granularity": granularity,
            "points": points,
            "statistics": stats,
        }

    # ---------- 科室看板 ----------
    async def get_dept_workload(self, dept_id: int,
                                  start_date: date,
                                  end_date: date) -> dict:
        """科室看板"""
        self._validate_range(start_date, end_date)

                M07WorkloadDeptDaily.dept_id == dept_id,

        if not rows:
            raise BizException(54900, "汇总数据不存在")

        visits = sum(r.visit_count or 0 for r in rows)
        days = len(rows)
        total_min = sum(
            float(r.total_duration_minutes or 0) for r in rows)

        # 医生维度
        doctor_rows = (await self.db.execute(
            select(M07WorkloadDaily).where(
                M07WorkloadDaily.dept_id == dept_id,
                M07WorkloadDaily.work_date >= start_date,
                M07WorkloadDaily.work_date <= end_date,
            )
        )).scalars().all()

        by_doctor = {}
        for r in doctor_rows:
            d = by_doctor.setdefault(r.doctor_id, {
                "doctor_id": r.doctor_id,
                "doctor_name": r.doctor_name,
                "doctor_title": r.doctor_title,
                "visit_count": 0,
                "total_duration": 0.0,
            })
            d["visit_count"] += r.visit_count or 0
            d["total_duration"] += float(
                r.total_duration_minutes or 0)

        doctors = []
        for d in by_doctor.values():
            avg = (round(d["total_duration"] / d["visit_count"], 1)
                    if d["visit_count"] else 0)
            doctors.append({
                "doctor_id": d["doctor_id"],
                "doctor_name": d["doctor_name"],
                "doctor_title": d["doctor_title"],
                "visit_count": d["visit_count"],
                "avg_duration": avg,
                "is_on_duty": d["visit_count"] > 0,
            })

        doctors.sort(key=lambda x: x["visit_count"], reverse=True)

        return {
            "dept": {
                "dept_id": dept_id,
                "dept_name": rows[0].dept_name,
            },
            "period": {
                "start_date": start_date.isoformat(),

                                  if visits else 0),
                "order_amount": float(sum(
                    (r.order_amount or 0) for r in rows)),
                "antibiotic_rate": self._avg(rows, "antibiotic_rate"),
                "composite_score": self._avg(rows, "composite_score"),
            },
            "doctors": doctors,
            "dept_compare": await self._dept_rank_all(
                start_date, end_date),
            "alerts": self._dept_alerts(rows, doctors),

    @staticmethod
    def _dept_alerts(rows, doctors) -> List[str]:
        alerts = []
        total_wait = sum(r.visit_count or 0 for r in rows)

        high_wait = [d for d in doctors
                      if d.get("waiting_count", 0) > 15]
        if high_wait:
            alerts.append(
                f"候诊 {sum(d['waiting_count'] for d in high_wait)} 人，"
                "建议加开诊室")

        return alerts

    async def _dept_rank_all(self, start_date: date,
                               end_date: date) -> List[dict]:
        """全院科室排名"""
        rows = (await self.db.execute(
            select(
                M07WorkloadDeptDaily.dept_id,
                M07WorkloadDeptDaily.dept_name,
                func.sum(M07WorkloadDeptDaily.visit_count).label("cnt"),
            ).where(
                M07WorkloadDeptDaily.work_date >= start_date,
                M07WorkloadDeptDaily.work_date <= end_date,
            ).group_by(
                M07WorkloadDeptDaily.dept_id,
                M07WorkloadDeptDaily.dept_name,
            ).order_by(func.sum(
                M07WorkloadDeptDaily.visit_count).desc())
        )).all()

        return [
            {
                "dept_id": r[0],
                "dept_name": r[1],
                "visit_total": int(r[2] or 0),
                "rank": i + 1,
            }
            for i, r in enumerate(rows)
        ]

    # ---------- 排名 ----------
    async def get_rank(self, dept_id: Optional[int], start_date: date,
                         end_date: date, rank_by: str) -> dict:
        """医生排名"""
        self._validate_range(start_date, end_date)

        sort_field = {
            "composite": M07WorkloadDaily.composite_score,
            "visit_count": M07WorkloadDaily.visit_count,
            "order_amount": M07WorkloadDaily.order_amount,
            "efficiency": M07WorkloadDaily.avg_duration,
        }.get(rank_by)

        if sort_field is None:
            raise BizException(54908, f"排名参数无效：{rank_by}")

        conds = [
            M07WorkloadDaily.work_date >= start_date,
            M07WorkloadDaily.work_date <= end_date,
        ]
        if dept_id:
            conds.append(M07WorkloadDaily.dept_id == dept_id)

        rows = (await self.db.execute(
            select(
                M07WorkloadDaily.doctor_id,
                M07WorkloadDaily.doctor_name,
                M07WorkloadDaily.doctor_title,
                M07WorkloadDaily.dept_id,
                M07WorkloadDaily.dept_name,
                func.sum(M07WorkloadDaily.visit_count).label("visits"),
                func.sum(M07WorkloadDaily.order_amount).label("amount"),
                func.sum(M07WorkloadDaily.total_duration_minutes).label(
                    "minutes"),
                func.avg(M07WorkloadDaily.composite_score).label("score"),
                func.avg(M07WorkloadDaily.workload_score).label("wl"),
                func.avg(M07WorkloadDaily.efficiency_score).label("eff"),
                func.avg(M07WorkloadDaily.quality_score).label("ql"),
            ).where(and_(*conds))
            .group_by(
                M07WorkloadDaily.doctor_id,
                M07WorkloadDaily.doctor_name,
                M07WorkloadDaily.doctor_title,
                M07WorkloadDaily.dept_id,
                M07WorkloadDaily.dept_name,
            )
        )).all()

        items = []
        for r in rows:
            visits = int(r.visits or 0)
            minutes = float(r.minutes or 0)
            items.append({
                "doctor_id": r[0],
                "doctor_name": r[1],
                "doctor_title": r[2],
                "dept_id": r[3],
                "dept_name": r[4],
                "visit_count": visits,
                "order_amount": round(float(r.amount or 0), 2),
                "avg_duration": (round(minutes / visits, 1)
                                  if visits else 0),
                "composite_score": round(float(r.score or 0), 1),
                "score_breakdown": {
                    "workload_score": round(float(r.wl or 0), 1),
                    "efficiency_score": round(float(r.eff or 0), 1),
                    "quality_score": round(float(r.ql or 0), 1),

        # 排序
        if rank_by == "efficiency":

        elif rank_by == "visit_count":

        elif rank_by == "order_amount":
            items.sort(key=lambda x: x["order_amount"], reverse=True)
        else:
            items.sort(key=lambda x: x["composite_score"], reverse=True)

        for i, it in enumerate(items, 1):
            it["rank"] = i

        # 按职称分组
        by_title = {}
        for it in items:

                "doctor_id": it["doctor_id"],

                "composite_score": it["composite_score"],
            })

        return {

            }.get(rank_by, rank_by),

    @staticmethod

class WorkloadAggregateService:
    """每日/每月汇总"""

    LOCK_KEY = "m07:wl:aggregate:lock"
    SCORE_WEIGHT = {"workload": 0.4, "efficiency": 0.3,
                     "quality": 0.3}
    TIMEOUT_MINUTES = 15

    def __init__(self, db: AsyncSession):
        self.db = db

    # ---------- 每日汇总 ----------
    async def aggregate_by_date(self, payload: dict) -> dict:
        """按日期汇总（幂等）"""
        work_date = payload.get("work_date")

        if not work_date:
            work_date = (date.today() - timedelta(days=1)).isoformat()

        d = date.fromisoformat(work_date)
        return await self.aggregate_daily(d)

    async def aggregate_daily(self, d: date) -> dict:
        """汇总某日全部医生"""
        if not await redis_client.set(
                self.LOCK_KEY, "1", nx=True, ex=1800):
            raise BizException(54904, "重算正在执行中")

        try:
            # 1. 取当日会话
            encounters = (await self.db.execute(
                select(M07Encounter).where(
                    M07Encounter.encounter_date == d,
                    M07Encounter.is_deleted == False,
                )
            )).scalars().all()

            if not encounters:
                return {"work_date": d.isoformat(),
                        "doctors": 0, "message": "当日无接诊数据"}

            by_doctor = {}
            for e in encounters:
                if not e.doctor_id:
                    continue
                by_doctor.setdefault(e.doctor_id, []).append(e)

            # 2. 删除当日汇总（重算）
            await self.db.execute(
                delete(M07WorkloadDaily).where(
                    M07WorkloadDaily.work_date == d))

            results = []
            for doctor_id, encs in by_doctor.items():
                stat = await self._build_daily_stat(
                    doctor_id, d, encs)
                self.db.add(stat)
                results.append(stat)

            # 3. 科室汇总
            await self._aggregate_dept(d, results)

            await self.db.commit()

            return {
                "work_date": d.isoformat(),
                "doctors": len(results),
                "total_visits": sum(r.visit_count for r in results),
                "message": "每日汇总完成",
            }

        except Exception as exc:
            await self.db.rollback()
            raise exc
        finally:
            await redis_client.delete(self.LOCK_KEY)

    async def _build_daily_stat(self, doctor_id: int, d: date,
                                  encounters) -> M07WorkloadDaily:
        """构建单个医生的日汇总"""
        first = encounters[0]

        # 接诊量：已完成
        completed = [e for e in encounters
                      if e.status == "COMPLETED"]
        visit_count = len(completed)
        first_visit = len([e for e in completed
                            if e.visit_type == "FIRST"])

        # 时长
        durations = []
        waits = []
        work_start = None
        work_end = None

        for e in completed:
            if not (e.started_at and e.ended_at):
                continue

            span = (e.ended_at - e.started_at).total_seconds() / 60
            pause = float(getattr(e, "total_pause_minutes", 0) or 0)
            durations.append(max(0.0, span - pause))

            if e.queue_time:
                waits.append(
                    (e.started_at - e.queue_time).total_seconds() / 60)

            if work_start is None or e.started_at < work_start:
                work_start = e.started_at
            if work_end is None or e.ended_at > work_end:
                work_end = e.ended_at

        total_duration = sum(durations)
        total_wait = sum(waits)
        timeout = len([x for x in durations
                        if x > self.TIMEOUT_MINUTES])

        work_minutes = 0.0
        if work_start and work_end:
            work_minutes = (work_end - work_start).total_seconds() / 60

        # 医嘱
        order_stats = await self._get_order_stats(doctor_id, d)

        # 处方
        rx_stats = await self._get_prescription_stats(doctor_id, d)

        # 文书
        doc_stats = await self._get_document_stats(doctor_id, d)

        # 质量
        quality = await self._get_quality_stats(
            doctor_id, d, visit_count, rx_stats, doc_stats)

        # 评分
        workload_score = self._calc_workload_score(visit_count)
        efficiency_score = self._calc_efficiency_score(
            total_duration, visit_count, timeout)
        quality_score = self._calc_quality_score(quality)

        composite = round(
            self.SCORE_WEIGHT["workload"] * workload_score
            + self.SCORE_WEIGHT["efficiency"] * efficiency_score
            + self.SCORE_WEIGHT["quality"] * quality_score, 1)

        return M07WorkloadDaily(
            doctor_id=doctor_id,
            doctor_name=first.doctor_name,
            doctor_title=getattr(first, "doctor_title", None),
            dept_id=first.dept_id,
            dept_name=getattr(first, "dept_name", None),
            work_date=d,

            visit_count=visit_count,
            first_visit_count=first_visit,
            completed_count=visit_count,

            exam_count=order_stats["exam"],
            lab_count=order_stats["lab"],
            drug_count=order_stats["drug"],
            treatment_count=order_stats["treatment"],
            operation_count=order_stats["operation"],

            prescription_count=rx_stats["count"],
            document_count=doc_stats["count"],

            order_amount=Decimal(str(order_stats["amount"])),
            drug_amount=Decimal(str(order_stats["drug_amount"])),
            exam_amount=Decimal(str(order_stats["exam_amount"])),
            lab_amount=Decimal(str(order_stats["lab_amount"])),
            treatment_amount=Decimal(
                str(order_stats["treatment_amount"])),
            operation_amount=Decimal(
                str(order_stats["operation_amount"])),

            total_duration_minutes=Decimal(str(round(total_duration, 2))),
            total_wait_minutes=Decimal(str(round(total_wait, 2))),
            max_wait_minutes=int(max(waits)) if waits else 0,
            work_minutes=Decimal(str(round(work_minutes, 2))),
            timeout_count=timeout,

            diagnosis_completeness=Decimal(
                str(quality["diagnosis_completeness"])),
            prescription_pass_rate=Decimal(
                str(quality["prescription_pass_rate"])),
            antibiotic_rate=Decimal(str(quality["antibiotic_rate"])),
            document_timeliness=Decimal(
                str(quality["document_timeliness"])),
            critical_handle_rate=Decimal(
                str(quality["critical_handle_rate"])),
            report_unread_rate=Decimal(
                str(quality["report_unread_rate"])),

            workload_score=Decimal(str(workload_score)),
            efficiency_score=Decimal(str(efficiency_score)),
            quality_score=Decimal(str(quality_score)),
            composite_score=Decimal(str(composite)),

            generated_at=datetime.now(),
        )

    async def _get_order_stats(self, doctor_id: int, d: date) -> dict:
        """医嘱统计"""
        rows = (await self.db.execute(
            select(
                M07Order.order_type,
                func.count().label("cnt"),
                func.coalesce(func.sum(M07Order.total_amount), 0).label(

            "TREATMENT": "treatment", "OPERATION": "operation",

        for order_type, cnt, amount in rows:
            key = key_map.get(order_type)
            if not key:
                continue
            out[key] = int(cnt or 0)
            out[f"{key}_amount"] = float(amount or 0)

    async def _get_prescription_stats(self, doctor_id: int,

    async def _get_quality_stats(self, doctor_id: int, d: date,
                                    visit_count: int, rx: dict,
                                    doc: dict) -> dict:
        """质量指标"""
        # 诊断完整率
        from app.models.m07.diagnosis import M07Diagnosis

        with_diag = (await self.db.execute(
            select(func.count(func.distinct(M07Diagnosis.encounter_id)))
            .where(
                M07Diagnosis.doctor_id == doctor_id,
                func.date(M07Diagnosis.created_at) == d,
                M07Diagnosis.diagnosis_type == "PRIMARY",
                M07Diagnosis.status == "ACTIVE",
                M07Diagnosis.is_deleted == False,
            )
        )).scalar_one()

        diag_rate = (round(with_diag / visit_count * 100, 4)
                      if visit_count else 100.0)
        diag_rate = min(100.0, float(diag_rate))

        # 处方合格率
        rx_total = rx["count"] or 1
        rx_pass = rx_total - rx["returned_count"]
        rx_rate = round(rx_pass / rx_total * 100, 4)

        # 抗菌药使用率
        abx_rate = round(rx["antibiotic_count"] / rx_total * 100, 4)

        # 文书及时率
        doc_total = doc["count"] or 1
        doc_rate = (round(doc["timely_count"] / doc_total * 100, 4)
                     if doc["count"] else 100.0)

        # 危急值处置率
        from app.models.m07.report import M07CriticalValue

        cv_total = (await self.db.execute(
            select(func.count()).select_from(M07CriticalValue).where(
                M07CriticalValue.notified_doctor_id == doctor_id,
                func.date(M07CriticalValue.detected_at) == d,
            )
        )).scalar_one()

        cv_handled = (await self.db.execute(
            select(func.count()).select_from(M07CriticalValue).where(
                M07CriticalValue.notified_doctor_id == doctor_id,
                func.date(M07CriticalValue.detected_at) == d,
                M07CriticalValue.status == "HANDLED",
            )
        )).scalar_one()

        cv_rate = (round(cv_handled / cv_total * 100, 4)
                    if cv_total else 100.0)

        # 报告未阅率
        from app.models.m07.report import M07Report

        rp_total = (await self.db.execute(
            select(func.count()).select_from(M07Report).where(
                M07Report.doctor_id == doctor_id,
                func.date(M07Report.reported_at) == d,
                M07Report.status.in_(("FINAL", "AMENDED")),
                M07Report.is_deleted == False,
            )
        )).scalar_one()

        rp_unread = (await self.db.execute(
            select(func.count()).select_from(M07Report).where(
                M07Report.doctor_id == doctor_id,
                func.date(M07Report.reported_at) == d,
                M07Report.status.in_(("FINAL", "AMENDED")),
                M07Report.read_status == "UNREAD",
                M07Report.is_deleted == False,
            )
        )).scalar_one()

        unread_rate = (round(rp_unread / rp_total * 100, 4)
                        if rp_total else 0.0)

        return {
            "diagnosis_completeness": diag_rate,
            "prescription_pass_rate": rx_rate,
            "antibiotic_rate": abx_rate,
            "document_timeliness": doc_rate,
            "critical_handle_rate": cv_rate,
            "report_unread_rate": unread_rate,
        }

    def _calc_workload_score(self, visit_count: int) -> float:
        """工作量分（相对 25 人/日为基准）"""
        base = 25
        return round(min(120.0, visit_count / base * 100), 1)

    def _calc_efficiency_score(self, total_minutes: float,
                                 visit_count: int,
                                 timeout: int) -> float:
        """效率分"""
        if not visit_count:
            return 0.0

        avg = total_minutes / visit_count
        # 理想诊时 8 分钟，超过按比例扣分
        ideal = 8.0
        duration_score = min(120.0, ideal / avg * 100) if avg else 120.0
        timeout_score = max(0.0, 100.0 - timeout / visit_count * 100)

        return round(duration_score * 0.7 + timeout_score * 0.3, 1)

    def _calc_quality_score(self, q: dict) -> float:
        """质量分"""
        return round(
            q["diagnosis_completeness"] * 0.4
            + q["prescription_pass_rate"] * 0.3
            + q["document_timeliness"] * 0.3, 1)

    async def _aggregate_dept(self, d: date, doctors) -> None:
        """科室汇总"""
        by_dept = {}
        for s in doctors:

                M07WorkloadDeptDaily.work_date == d))

        for dept_id, items in by_dept.items():
            visits = sum(i.visit_count for i in items)
            work_mins = sum(float(i.work_minutes or 0) for i in items)

            self.db.add(M07WorkloadDeptDaily(
                dept_id=dept_id,
                dept_name=items[0].dept_name,

                doctor_count=len(items),
                visit_count=visits,
                total_duration_minutes=Decimal(str(round(
                    sum(float(i.total_duration_minutes or 0)

                total_wait_minutes=Decimal(str(round(
                    sum(float(i.total_wait_minutes or 0)
                         for i in items), 2))),
                max_wait_minutes=max(
                    (i.max_wait_minutes or 0 for i in items),
                    default=0),
                work_minutes=Decimal(str(round(work_mins, 2))),
                timeout_count=sum(i.timeout_count for i in items),
                order_amount=Decimal(str(round(
                    sum(float(i.order_amount or 0) for i in items), 2))),
                antibiotic_rate=Decimal(str(round(
                    sum(float(i.antibiotic_rate or 0)
                         for i in items) / len(items), 4))),
                composite_score=Decimal(str(round(
                    sum(float(i.composite_score or 0)
                         for i in items) / len(items), 1))),
                generated_at=datetime.now(),
            ))

    async def aggregate_monthly(self, year: int, month: int) -> dict:
        """月度汇总（每月 1 日执行）"""
        first_day = date(year, month, 1)

        if month == 12:
            last_day = date(year + 1, 1, 1)
        else:
            last_day = date(year, month + 1, 1)

        rows = (await self.db.execute(
            select(M07WorkloadDaily).where(
                M07WorkloadDaily.work_date >= first_day,
                M07WorkloadDaily.work_date < last_day,
            )
        )).scalars().all()

        if not rows:
            return {"year": year, "month": month, "doctors": 0}

        by_doctor = {}
        for r in rows:
            by_doctor.setdefault(r.doctor_id, []).append(r)

        await self.db.execute(
            delete(M07WorkloadMonthly).where(
                M07WorkloadMonthly.work_month == first_day))

        for doctor_id, items in by_doctor.items():
            f = items[0]
            visits = sum(i.visit_count or 0 for i in items)
            minutes = sum(
                float(i.total_duration_minutes or 0) for i in items)

            self.db.add(M07WorkloadMonthly(
                doctor_id=doctor_id,
                doctor_name=f.doctor_name,
                doctor_title=f.doctor_title,
                dept_id=f.dept_id,
                dept_name=f.dept_name,
                work_month=first_day,
                work_days=len(items),
                visit_count=visits,
                first_visit_count=sum(
                    i.first_visit_count or 0 for i in items),
                order_amount=Decimal(str(round(sum(
                    float(i.order_amount or 0) for i in items), 2))),
                total_duration_minutes=Decimal(str(round(minutes, 2))),
                avg_duration=Decimal(str(round(
                    minutes / visits, 1) if visits else 0)),
                antibiotic_rate=Decimal(str(round(
                    sum(float(i.antibiotic_rate or 0)
                         for i in items) / len(items), 4))),
                composite_score=Decimal(str(round(
                    sum(float(i.composite_score or 0)
                         for i in items) / len(items), 1))),
                generated_at=datetime.now(),
            ))

        await self.db.commit()

        return {
            "year": year,
            "month": month,
            "doctors": len(by_doctor),
            "message": "月度汇总完成",
        }

    # ---------- 手动重算 ----------
    async def recalculate(self, payload, user) -> dict:
        """手动重算（指定日期范围）"""
        start = payload.start_date
        end = payload.end_date
        today = date.today()

        if end > today:
            raise BizException(54902, "重算日期不可为未来",
                data={"start_date": start.isoformat(),
                       "today": today.isoformat(),
                       "suggestion": "重算日期必须在今天之前"})

        if start > end:
            raise BizException(54903, "重算范围无效")

        if (end - start).days > 90:
            raise BizException(54903, "重算范围无效",
                data={"max_days": 90,
                       "suggestion": "单次重算不超过 90 天"})

        import uuid
        task_id = (f"RC{datetime.now().strftime('%Y%m%d%H%M')}"
                    f"{uuid.uuid4().hex[:3].upper()}")

        executed_at = datetime.now()
        deleted = 0
        created = 0

        d = start
        while d <= end:
            r = (await self.db.execute(
                select(func.count()).select_from(M07WorkloadDaily).where(
                    M07WorkloadDaily.work_date == d)
            )).scalar_one()
            deleted += r

            result = await self.aggregate_daily(d)
            created += result.get("doctors", 0)

            d += timedelta(days=1)

        return {
            "task_id": task_id,
            "start_date": start.isoformat(),
            "end_date": end.isoformat(),
            "scope": getattr(payload, "scope", "ALL"),
            "scope_text": {
                "DOCTOR": "单医生", "DEPT": "单科室",
                "ALL": "全院",
            }.get(getattr(payload, "scope", "ALL"), "全院"),
            "doctor_id": getattr(payload, "doctor_id", None),
            "reason": payload.reason,
            "status": "COMPLETED",
            "status_text": "已完成",
            "records_deleted": deleted,
            "records_created": created,
            "duration_ms": int(
                (datetime.now() - executed_at).total_seconds() * 1000),
            "executed_at": executed_at.isoformat(),
            "executed_by": getattr(user, "name", None),
            "message": (f"重算完成，已更新 {created} 条汇总记录"),
        }

                    biz_type="WORKLOAD_AGGREGATION_MISSING",
