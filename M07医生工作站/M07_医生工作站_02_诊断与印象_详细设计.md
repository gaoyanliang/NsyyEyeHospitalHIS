## 1. 模块概述

### 1.1 模块定位

诊断与印象是医疗行为的**核心结论**。它回答："**这个患者得了什么病？哪只眼？依据是什么？**"

```
┌──────────────────────────────────────────────────────────────┐
│  M07-01 就诊会话（已打开）                                     │
└────────────────────────┬─────────────────────────────────────┘
                         │
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M07-02 诊断与印象（本文档）                                   │
│  检索诊断 → 眼别标注 → 主次排序 → 填依据 → 保存                │
└────────────────────────┬─────────────────────────────────────┘
                         │ 诊断结论
        ┌────────────────┼────────────────┬────────────────┐
        ▼                ▼                ▼                ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ 03 医嘱      │ │ 05 处方      │ │ 06 文书      │ │ M18 病历     │
│ 依据诊断开单  │ │ 依据诊断用药  │ │ 诊断证明书    │ │ 诊断写入病历  │
└──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘
```

### 1.2 为什么诊断要独立成子模块

| 理由 | 说明 |
|---|---|
| **眼科特殊性** | 诊断必须标注**眼别**（OD/OS/OU），这是眼科核心 |
| **主次之分** | 主诊断唯一，决定 DRG/DIP 与统计口径 |
| **多诊断** | 一个患者常有 3~5 个诊断（白内障 + 青光眼 + 糖尿病视网膜病变） |
| **诊断依据** | 需记录支持该诊断的检查发现（医疗质量要求） |
| **模板复用** | 常见组合（如"白内障+老视"）需一键带出 |
| **准确率考核** | 与最终诊断对比，评估门诊诊断准确性 |

### 1.3 与相邻模块的分工

| 能力 | 归属 |
|---|---|
| 诊断字典维护 | M01-09 |
| **诊断录入与眼别标注** | **M07-02 本子模块** |
| **主次诊断排序** | **M07-02 本子模块** |
| **诊断依据** | **M07-02 本子模块** |
| **诊断模板** | **M07-02 本子模块** |
| **诊断修正与作废** | **M07-02 本子模块** |
| 病历文本呈现 | M18 |
| 诊断证明书 | M07-06 |
| DRG/DIP 分组 | M17（本模块提供诊断） |
| 诊断质控 | M17 / M19 |

> **边界一句话：** 本子模块只管"**诊断结论的结构化表达**"；**不做**诊断字典维护（M01-09）、**不做**病历文本（M18）、**不做**诊断证明书排版（M07-06）。

### 1.4 眼别模型（眼科核心）

| 代码 | 名称 | 说明 | 显示 |
|---|---|---|---|
| `OD` | 右眼 | Oculus Dexter | 右 |
| `OS` | 左眼 | Oculus Sinister | 左 |
| `OU` | 双眼 | Oculus Uterque | 双 |
| `NA` | 不适用 | 全身性疾病 | — |

**规则：**

- 眼科诊断（`is_ophthalmic = TRUE`）**必须**标注眼别
- 非眼科诊断（如"高血压"）眼别固定为 `NA`
- 眼别影响统计：白内障手术量按眼别分别计算

### 1.5 主次诊断规则

```
主诊断（PRIMARY）：有且仅有 1 条
  · 必须是 is_primary_allowed = TRUE 的诊断
  · 通常是本次就诊的主要问题
  · 决定 DRG/DIP 分组

次诊断（SECONDARY）：0~N 条
  · 合并症、并发症、其他问题

疑似诊断（SUSPECTED）：0~N 条
  · 尚未确诊，需进一步检查
  · 不计入确诊统计

鉴别诊断（DIFFERENTIAL）：0~N 条
  · 需排除的其他可能
  · 仅作记录，不计入统计
```

### 1.6 模块目标

- **快**：拼音码检索 3 键内命中，录入 ≤ 10 秒。
- **准**：编码来自 M01-09，不手工输入。
- **全**：眼别、依据、部位完整。
- **智**：常用诊断、上次诊断一键带出。
- **可追溯**：诊断修正留痕。

### 1.7 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 门诊医生 | 下诊断 | 检索、录入、排序、修正 |
| 科主任 | 质控 | 查看科室诊断分布 |
| 病案室 | 编码质控 | 查看诊断编码准确性 |
| 医务科 | 质量监管 | 诊断准确率考核 |

## 3. 业务模型

### 3.1 诊断记录状态机

```
        ┌──────────┐
        │  DRAFT   │  草稿（未提交）
        └────┬─────┘
             │ 保存
             ▼
        ┌──────────┐
        │  ACTIVE  │  有效
        └────┬─────┘
             │
    ┌────────┼────────────┬──────────────┐
    │ 修正    │ 作废        │ 会话完成      │
    ▼        ▼            ▼              ▼
┌──────────┐┌──────────┐┌──────────┐┌──────────┐
│ (更新)   ││CANCELLED ││ LOCKED   ││  ARCHIVED│
└──────────┘└──────────┘└──────────┘└──────────┘
```

**状态说明：**

| 状态 | 说明 | 可编辑 |
|---|---|---|
| `DRAFT` | 草稿 | ✅ |
| `ACTIVE` | 有效 | ✅（需修正记录） |
| `LOCKED` | 已锁定（就诊完成） | ❌ |
| `ARCHIVED` | 已归档 | ❌ |
| `CANCELLED` | 已作废 | ❌ |

### 3.2 诊断层级模型

```
本次就诊诊断集合
│
├── 主诊断（PRIMARY）★唯一
│    · 白内障 H25.901 OD
│    · 依据：晶状体混浊，视力 0.3
│
├── 次诊断（SECONDARY）×N
│    · 青光眼 H40.101 OD
│    · 老视 H52.401 OU
│
├── 疑似诊断（SUSPECTED）×N
│    · 视网膜脱离 H33.001 OS（待 OCT 确认）
│
└── 鉴别诊断（DIFFERENTIAL）×N
     · 黄斑变性 H35.301 OD（已排除）
```

### 3.3 眼别与诊断的矩阵

| 诊断类型 | 眼别要求 | 示例 |
|---|---|---|
| 眼科疾病（单眼） | **必填** OD/OS | 白内障（右） |
| 眼科疾病（双眼） | **必填** OU | 干眼症（双眼） |
| 眼科疾病（双单眼不同） | **拆两条** | 白内障 OD + 白内障 OS |
| 全身疾病 | 固定 NA | 高血压 |
| 全身疾病眼部表现 | **必填** OD/OS/OU | 糖尿病视网膜病变（双眼） |

**关键规则：**

```
双眼都有白内障：
  ✅ 正确：H25.901 OD（白内障右）+ H25.901 OS（白内障左）→ 2 条
  ❌ 错误：H25.901 OU（白内障双）→ 手术量统计会出错
```

> **例外：** 某些诊断天然是双（如"屈光不正"），可用 OU。

### 3.4 诊断依据模型

#### 3.4.1 依据类型

| 类型 | 说明 | 示例 |
|---|---|---|
| `SYMPTOM` | 症状 | 视物模糊 3 个月 |
| `SIGN` | 体征 | 晶状体混浊，视力 0.3 |
| `EXAM` | 检查结果 | OCT 示黄斑水肿 |
| `LAB` | 检验结果 | 空腹血糖 12.5 mmol/L |
| `HISTORY` | 病史 | 糖尿病 10 年 |
| `FREE_TEXT` | 自由文本 | 综合判断 |

#### 3.4.2 结构化依据

```
诊断：糖尿病视网膜病变（双眼）E11.301 + H36.001
依据：
  · [LAB] 空腹血糖 12.5 mmol/L（2026-10-20）
  · [HISTORY] 糖尿病史 10 年
  · [EXAM] 眼底照相示双眼视网膜散在出血点
  · [SIGN] 视力 OD 0.4 / OS 0.3
```

### 3.5 诊断检索模型

#### 3.5.1 检索方式

| 方式 | 输入 | 示例 |
|---|---|---|
| **拼音首字母** | `bnz` | → 白内障 |
| **拼音全拼** | `baineizhang` | → 白内障 |
| **中文名称** | `白内障` | → 白内障相关 |
| **ICD-10 编码** | `H25` | → H25.xxx |
| **院内编码** | `H25.901` | → 精确 |
| **别名** | `老年性白内障` | → 白内障 |
| **模糊搜索** | `视网膜` | → 所有含"视网膜"的 |

#### 3.5.2 排序规则

```
排序 = (is_common DESC, 使用频次 DESC, 匹配度 DESC, sort_no ASC)

1. 本次医生常用（个人高频）
2. 科室常用
3. 全院常用（is_common）
4. 匹配度高的
```

#### 3.5.3 眼科诊断优先

```
眼科诊断（is_ophthalmic = TRUE）默认置顶
可在搜索框旁切换"全部 / 仅眼科 / 仅全身"
```

### 3.6 诊断模板模型

#### 3.6.1 模板内容

```
模板名：白内障术后复查
诊断组合：
  1. H25.901 老年性白内障（右）PRIMARY OD
  2. Z98.801 白内障术后状态（右）SECONDARY OD
关联医嘱：视力检查、眼压检查
```

#### 3.6.2 模板来源

| 来源 | 说明 |
|---|---|
| 个人模板 | 医生自建 |
| 科室模板 | 科主任维护，全科共享 |
| 全院模板 | 医务科维护 |
| 系统模板 | 从历史诊断高频组合自动生成 |

### 3.7 诊断修正模型

```
原诊断：H25.901 老年性白内障（右）
   ↓ 修正
新诊断：H25.001 老年性白内障（右）+ H40.101 青光眼（右）

记录：
  · 修正时间：09:55
  · 修正原因：补充青光眼诊断
  · 修正人：张明华
  · 原诊断快照：保留
```

**规则：**

- 就诊完成前可自由修正
- 就诊完成后需"诊断修正"流程（留痕）
- 已开立医嘱引用的诊断不可删除（只能修正）

### 3.8 诊断准确率模型

```
门诊诊断（初诊）  vs  最终诊断（复诊/出院）
   ↓
一致 → 准确
提级 → 门诊漏诊（严重）
降级 → 门诊过度诊断

准确率 = 一致数 / 总数 × 100%
```

**考核指标：**

| 指标 | 目标 |
|---|---|
| 诊断一致率 | ≥ 85% |
| 漏诊率 | ≤ 5% |
| 过度诊断率 | ≤ 10% |

### 6.5 Service 层核心逻辑示例

```python
# app/services/m07/diagnosis_service.py
"""诊断服务"""
from datetime import date, datetime
from typing import Optional, List

from sqlalchemy import select, and_, or_, func, desc
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.m07.encounter import M07Encounter
from app.models.m07.diagnosis import (
    M07Diagnosis, M07DiagnosisBasis, M07DiagnosisLog,
    M07DiagnosisTemplate, M07DiagnosisCommon,
)
from app.core.exceptions import BizException
from app.core.redis import redis_client
from app.clients.mdm_client import MdmClient
from app.clients.mpi_client import MpiClient


class DiagnosisService:
    """诊断主流程"""

    TYPE_NAMES = {
        "PRIMARY": "主诊断",
        "SECONDARY": "次诊断",
        "SUSPECTED": "疑似诊断",
        "DIFFERENTIAL": "鉴别诊断",
    }
    EYE_SIDE_NAMES = {
        "OD": "右眼", "OS": "左眼", "OU": "双眼", "NA": "不适用",
    }

    def __init__(self, db: AsyncSession):
        self.db = db
        self.mdm = MdmClient()
        self.mpi = MpiClient()

    # ---------- 检索 ----------
    async def search(self, keyword: str, scope: str,
                       chapter_id: Optional[int], limit: int,
                       user) -> dict:
        """诊断检索"""
        if len(keyword.strip()) < 2:
            raise BizException(54752, "检索关键词过短，请输入至少 2 个字符",
                data={
                    "keyword": keyword,
                    "min_length": 2,
                    "suggestion": "可输入拼音首字母（如 bnz）、中文名称或 ICD-10 编码",
                })

        keyword = keyword.strip()

        # 判断匹配类型
        if keyword.isascii() and keyword.isalpha():
            match_type = "PINYIN_SHORT" if len(keyword) <= 6 else "PINYIN_FULL"
        elif keyword.isascii():
            match_type = "CODE"
        else:
            match_type = "CHINESE"

        # 调 M01-09 检索
        try:
            items = await self.mdm.search_diagnosis(
                keyword=keyword,
                scope=scope,
                chapter_id=chapter_id,
                limit=limit * 2,
            )
        except Exception as e:
            raise BizException(54751, f"诊断检索服务不可用：{str(e)[:100]}")

        if not items:
            return {
                "keyword": keyword,
                "matched_type": match_type,
                "scope": scope,
                "total": 0,
                "items": [],
                "by_chapter": [],
                "suggestion": {
                    "type": "NO_RESULT",
                    "message": "未找到匹配诊断，请尝试其他关键词",
                },
            }

        # 获取常用标记
        uid = getattr(user, "id", None)
        dept_id = getattr(user, "dept_id", None)

        my_common = await self._get_my_common_codes(uid)
        dept_common = await self._get_dept_common_codes(dept_id)

        # 排序：常用优先 + 使用频次
        def sort_key(item):
            is_mine = item["diagnosis_code"] in my_common
            is_dept = item["diagnosis_code"] in dept_common
            is_common = item.get("is_common", False)
            return (
                0 if is_mine else (1 if is_dept else (2 if is_common else 3)),
                -item.get("usage_count", 0),
                -item.get("match_score", 0),
            )

        items.sort(key=sort_key)
        items = items[:limit]

        # 补充标记
        for item in items:
            item["is_my_common"] = item["diagnosis_code"] in my_common
            item["is_dept_common"] = item["diagnosis_code"] in dept_common

        # 章节统计
        chapters = {}
        for item in items:
            ch = item.get("chapter_code")
            if ch:
                chapters.setdefault(ch, {
                    "chapter_code": ch,
                    "chapter_name": item.get("chapter_name"),
                    "count": 0,
                })
                chapters[ch]["count"] += 1

        return {
            "keyword": keyword,
            "matched_type": match_type,
            "scope": scope,
            "total": len(items),
            "items": items,
            "by_chapter": list(chapters.values()),
            "suggestion": {
                "type": "COMMON_FIRST",
                "message": "已按使用频次排序，常用诊断优先显示",
            },
        }

    async def _get_my_common_codes(self, doctor_id) -> set:
        """我的常用诊断编码"""
        if not doctor_id:
            return set()

        cached = await redis_client.get(
            f"m07:diag:common:{doctor_id}")
        if cached:
            return set(cached.split(","))

        rows = (await self.db.execute(
            select(M07DiagnosisCommon.diagnosis_code).where(
                M07DiagnosisCommon.doctor_id == doctor_id,
                M07DiagnosisCommon.scope == "PERSONAL",
            ).order_by(desc(M07DiagnosisCommon.usage_count)).limit(50)
        )).all()

        codes = {r[0] for r in rows}
        await redis_client.setex(
            f"m07:diag:common:{doctor_id}", 600, ",".join(codes))
        return codes

    async def _get_dept_common_codes(self, dept_id) -> set:
        """科室常用诊断编码"""
        if not dept_id:
            return set()

        rows = (await self.db.execute(
            select(M07DiagnosisCommon.diagnosis_code).where(
                M07DiagnosisCommon.dept_id == dept_id,
                M07DiagnosisCommon.scope == "DEPT",
            ).order_by(desc(M07DiagnosisCommon.usage_count)).limit(50)
        )).all()

        return {r[0] for r in rows}

    # ---------- 添加诊断 ----------
    async def create(self, payload, user) -> dict:
        """添加诊断"""
        encounter = await self._get_encounter(payload.encounter_id)

        # 状态校验
        if encounter.status in ("CLOSED", "TRANSFERRED", "CANCELLED"):
            raise BizException(54748, "就诊已完成，诊断已锁定")

        # 诊断字典校验
        dx = await self.mdm.get_diagnosis(payload.diagnosis_code)

        if not dx:
            raise BizException(54733, "诊断编码不存在或已停用")

        if dx.get("merged_to_id"):
            raise BizException(54757,
                f"诊断编码已合并，请使用新编码 {dx.get('merged_code')}")

        # 眼别校验
        eye_side = self._validate_eye_side(
            dx, payload.eye_side, payload.laterality_note)

        # 主诊断校验
        if payload.diagnosis_type == "PRIMARY":
            if not dx.get("is_primary_allowed", True):
                raise BizException(54734, "该诊断不可作主诊断")

            if payload.diagnosis_type in ("SUSPECTED", "DIFFERENTIAL"):
                raise BizException(54754, "疑似/鉴别诊断不可作为主诊断")

            existing_primary = (await self.db.execute(
                select(M07Diagnosis).where(
                    M07Diagnosis.encounter_id == payload.encounter_id,
                    M07Diagnosis.diagnosis_type == "PRIMARY",
                    M07Diagnosis.status == "ACTIVE",
                    M07Diagnosis.is_deleted == False,
                )
            )).scalar_one_or_none()

            if existing_primary:
                raise BizException(54735, "主诊断已存在，请先取消原主诊断",
                    data={
                        "existing_primary": {
                            "diagnosis_id": existing_primary.id,
                            "diagnosis_code": existing_primary.diagnosis_code,
                            "diagnosis_name": existing_primary.diagnosis_name,
                            "eye_side_text": existing_primary.eye_side_text,
                        },
                        "options": [
                            {"action": "SET_SECONDARY", "label": "设为次诊断"},
                            {"action": "REPLACE_PRIMARY", "label": "替换原主诊断"},
                        ],
                    })

        # 重复校验
        dup = (await self.db.execute(
            select(M07Diagnosis).where(
                M07Diagnosis.encounter_id == payload.encounter_id,
                M07Diagnosis.diagnosis_code == payload.diagnosis_code,
                M07Diagnosis.eye_side == eye_side,
                M07Diagnosis.status == "ACTIVE",
                M07Diagnosis.is_deleted == False,
            )
        )).scalar_one_or_none()

        if dup:
            raise BizException(54741,
                f"该诊断已添加（{dup.display_text()}）")

        # 年龄/性别校验
        patient = await self.mpi.get_patient(encounter.patient_id) or {}
        self._validate_applicability(dx, patient)

        # 排序号
        if payload.sort_no is None:
            max_sort = (await self.db.execute(
                select(func.coalesce(func.max(M07Diagnosis.sort_no), 0))
                .where(
                    M07Diagnosis.encounter_id == payload.encounter_id,
                    M07Diagnosis.is_deleted == False,
                )
            )).scalar_one()
            sort_no = max_sort + 1
        else:
            sort_no = payload.sort_no

        # 创建
        diagnosis = M07Diagnosis(
            encounter_id=payload.encounter_id,
            encounter_no=encounter.encounter_no,
            patient_id=encounter.patient_id,
            patient_name=encounter.patient_name,
            diagnosis_code=payload.diagnosis_code,
            icd10_code=dx.get("icd10_code"),
            diagnosis_name=dx.get("diagnosis_name"),
            diagnosis_name_en=dx.get("english_name"),
            diagnosis_category=dx.get("diagnosis_category"),
            display_text=self._build_display_text(
                payload.diagnosis_code, dx.get("diagnosis_name"), eye_side),
            diagnosis_type=payload.diagnosis_type,
            eye_side=eye_side,
            eye_side_text=self.EYE_SIDE_NAMES.get(eye_side, ""),
            laterality_note=payload.laterality_note,
            basis=payload.basis,
            is_suspected=payload.diagnosis_type in ("SUSPECTED", "DIFFERENTIAL"),
            is_ophthalmic=dx.get("is_ophthalmic", False),
            is_chronic=dx.get("is_chronic", False),
            is_infectious=dx.get("is_infectious", False),
            sort_no=sort_no,
            status="ACTIVE",
            record_date=encounter.encounter_date,
            record_by=getattr(user, "id", None),
            record_by_name=getattr(user, "name", None),
            dept_id=encounter.dept_id,
        )
        self.db.add(diagnosis)
        await self.db.flush()

        # 记录常用
        await self._record_common(
            payload.diagnosis_code, dx.get("diagnosis_name"),
            user, encounter.dept_id)

        # 会话冗余更新
        await self._update_encounter_summary(payload.encounter_id)

        # 日志
        self.db.add(M07DiagnosisLog(
            encounter_id=payload.encounter_id,
            diagnosis_id=diagnosis.id,
            action="CREATE",
            after_json={
                "code": payload.diagnosis_code,
                "type": payload.diagnosis_type,
                "eye": eye_side,
            },
            operator_id=getattr(user, "id", None),
            operator_name=getattr(user, "name", None),
        ))

        await self.db.commit()

        summary = await self._get_summary(payload.encounter_id)

        return {
            "diagnosis_id": diagnosis.id,
            "encounter_id": diagnosis.encounter_id,
            "diagnosis_code": diagnosis.diagnosis_code,
            "icd10_code": diagnosis.icd10_code,
            "diagnosis_name": diagnosis.diagnosis_name,
            "diagnosis_type": diagnosis.diagnosis_type,
            "diagnosis_type_text": self.TYPE_NAMES.get(
                diagnosis.diagnosis_type, ""),
            "eye_side": diagnosis.eye_side,
            "eye_side_text": diagnosis.eye_side_text,
            "display_text": diagnosis.display_text,
            "status": diagnosis.status,
            "status_text": "有效",
            "sort_no": diagnosis.sort_no,
            "basis": diagnosis.basis,
            "basis_count": 0,
            "is_suspected": diagnosis.is_suspected,
            "created_at": datetime.now().isoformat(),
            "encounter_summary": summary,
        }

    # ---------- 眼别校验 ----------
    def _validate_eye_side(self, dx: dict, eye_side: Optional[str],
                             note: Optional[str]) -> str:
        """校验并规范化眼别"""
        is_ophthalmic = dx.get("is_ophthalmic", False)

        if is_ophthalmic:
            if not eye_side or eye_side == "NA":
                raise BizException(54736, "眼科诊断必须标注眼别",
                    data={
                        "diagnosis_code": dx.get("diagnosis_code"),
                        "diagnosis_name": dx.get("diagnosis_name"),
                        "is_ophthalmic": True,
                        "allowed_eye_sides": ["OD", "OS", "OU"],
                        "suggestion": "请选择右眼（OD）、左眼（OS）或双眼（OU）",
                    })
            if eye_side not in ("OD", "OS", "OU"):
                raise BizException(40001,
                    f"眼别无效：{eye_side}，应为 OD/OS/OU")
            return eye_side

        # 非眼科诊断：固定 NA
        if eye_side and eye_side != "NA":
            # 全身疾病但有眼部表现（如糖尿病视网膜病变）
            if dx.get("has_ocular_manifestation"):
                return eye_side
            raise BizException(54737, "非眼科诊断眼别必须为不适用",
                data={
                    "diagnosis_code": dx.get("diagnosis_code"),
                    "diagnosis_name": dx.get("diagnosis_name"),
                    "is_ophthalmic": False,
                    "suggestion": "该诊断眼别应设为「不适用」",
                })

        return "NA"

    # ---------- 适用性校验 ----------
    def _validate_applicability(self, dx: dict, patient: dict) -> None:
        """年龄与性别适用性校验"""
        age = patient.get("age")
        gender = patient.get("gender")

        age_min = dx.get("age_min")
        age_max = dx.get("age_max")

        if age is not None and age_min is not None and age < age_min:
            raise BizException(54738, "患者年龄不符合该诊断适用范围",
                data={
                    "diagnosis_code": dx.get("diagnosis_code"),
                    "diagnosis_name": dx.get("diagnosis_name"),
                    "age_min": age_min,
                    "age_max": age_max,
                    "patient_age": age,
                    "suggestion": f"该诊断适用于 {age_min}~{age_max or '∞'} 岁患者",
                    "can_force": True,
                })

        if age is not None and age_max is not None and age > age_max:
            raise BizException(54738, "患者年龄不符合该诊断适用范围",
                data={
                    "diagnosis_code": dx.get("diagnosis_code"),
                    "diagnosis_name": dx.get("diagnosis_name"),
                    "age_min": age_min,
                    "age_max": age_max,
                    "patient_age": age,
                    "suggestion": f"该诊断适用于 {age_min or 0}~{age_max} 岁患者",
                    "can_force": True,
                })

        gender_limit = dx.get("gender_limit")
        if gender_limit and gender_limit != "ALL" and gender != gender_limit:
            raise BizException(54739, "患者性别不符合该诊断适用范围",
                data={
                    "diagnosis_code": dx.get("diagnosis_code"),
                    "diagnosis_name": dx.get("diagnosis_name"),
                    "gender_limit": gender_limit,
                    "patient_gender": gender,
                })

    @staticmethod
    def _build_display_text(code: str, name: str,
                              eye_side: str) -> str:
        """构建显示文本"""
        if eye_side == "NA":
            return f"{code} {name}"
        eye_text = {"OD": "右", "OS": "左", "OU": "双"}.get(eye_side, "")
        return f"{code} {name}（{eye_text}）"

    # ---------- 批量保存 ----------
    async def batch_save(self, payload, user) -> dict:
        """批量保存诊断"""
        encounter = await self._get_encounter(payload.encounter_id)

        if encounter.status in ("CLOSED", "TRANSFERRED", "CANCELLED"):
            raise BizException(54748, "就诊已完成，诊断已锁定")

        # 校验主诊断唯一
        primaries = [d for d in payload.diagnoses
                      if d.diagnosis_type == "PRIMARY"]
        if len(primaries) > 1:
            raise BizException(54735, "只能有一个主诊断")

        mode = payload.mode or "REPLACE"
        created = updated = deleted = 0
        deleted_codes = []

        if mode == "REPLACE":
            # 删除不在列表中的
            existing = (await self.db.execute(
                select(M07Diagnosis).where(
                    M07Diagnosis.encounter_id == payload.encounter_id,
                    M07Diagnosis.status == "ACTIVE",
                    M07Diagnosis.is_deleted == False,
                )
            )).scalars().all()

            new_keys = {(d.diagnosis_code, d.eye_side or "NA")
                         for d in payload.diagnoses}

            for old in existing:
                key = (old.diagnosis_code, old.eye_side or "NA")
                if key in new_keys:
                    continue

                # 引用校验
                if await self._is_referenced_by_order(old.id):
                    raise BizException(54740,
                        f"诊断 {old.display_text()} 已被医嘱引用，不可删除")

                old.is_deleted = True
                old.status = "CANCELLED"
                deleted += 1
                deleted_codes.append(old.diagnosis_code)

        # 逐个处理
        results = []
        for idx, d in enumerate(payload.diagnoses, 1):
            dx = await self.mdm.get_diagnosis(d.diagnosis_code)
            if not dx:
                raise BizException(54733,
                    f"诊断编码不存在：{d.diagnosis_code}")

            eye_side = self._validate_eye_side(dx, d.eye_side, None)

            existing = (await self.db.execute(
                select(M07Diagnosis).where(
                    M07Diagnosis.encounter_id == payload.encounter_id,
                    M07Diagnosis.diagnosis_code == d.diagnosis_code,
                    M07Diagnosis.eye_side == eye_side,
                    M07Diagnosis.status == "ACTIVE",
                    M07Diagnosis.is_deleted == False,
                )
            )).scalar_one_or_none()

            if existing:
                existing.diagnosis_type = d.diagnosis_type
                existing.basis = d.basis or existing.basis
                existing.sort_no = d.sort_no or idx
                updated += 1
                results.append(existing)
            else:
                new_dx = M07Diagnosis(
                    encounter_id=payload.encounter_id,
                    encounter_no=encounter.encounter_no,
                    patient_id=encounter.patient_id,
                    patient_name=encounter.patient_name,
                    diagnosis_code=d.diagnosis_code,
                    icd10_code=dx.get("icd10_code"),
                    diagnosis_name=dx.get("diagnosis_name"),
                    display_text=self._build_display_text(
                        d.diagnosis_code, dx.get("diagnosis_name"), eye_side),
                    diagnosis_type=d.diagnosis_type,
                    eye_side=eye_side,
                    eye_side_text=self.EYE_SIDE_NAMES.get(eye_side, ""),
                    basis=d.basis,
                    is_suspected=d.diagnosis_type in ("SUSPECTED", "DIFFERENTIAL"),
                    is_ophthalmic=dx.get("is_ophthalmic", False),
                    sort_no=d.sort_no or idx,
                    status="ACTIVE",
                    record_date=encounter.encounter_date,
                    record_by=getattr(user, "id", None),
                    record_by_name=getattr(user, "name", None),
                    dept_id=encounter.dept_id,
                )
                self.db.add(new_dx)
                await self.db.flush()
                created += 1
                results.append(new_dx)

        await self._update_encounter_summary(payload.encounter_id)

        self.db.add(M07DiagnosisLog(
            encounter_id=payload.encounter_id,
            diagnosis_id=results[0].id if results else 0,
            action="BATCH_SAVE",
            after_json={
                "mode": mode,
                "created": created,
                "updated": updated,
                "deleted": deleted,
            },
            operator_id=getattr(user, "id", None),
            operator_name=getattr(user, "name", None),
        ))

        await self.db.commit()

        summary = await self._get_summary(payload.encounter_id)

        return {
            "encounter_id": payload.encounter_id,
            "mode": mode,
            "total": len(payload.diagnoses),
            "created": created,
            "updated": updated,
            "deleted": deleted,
            "deleted_codes": deleted_codes,
            "items": [
                {
                    "diagnosis_id": r.id,
                    "diagnosis_code": r.diagnosis_code,
                    "diagnosis_type": r.diagnosis_type,
                    "eye_side": r.eye_side,
                    "display_text": r.display_text,
                    "sort_no": r.sort_no,
                }
                for r in sorted(results, key=lambda x: x.sort_no or 0)
            ],
            "encounter_summary": summary,
        }

    async def _is_referenced_by_order(self, diagnosis_id: int) -> bool:
        """诊断是否被医嘱引用"""
        from app.models.m07.order import M07Order

        cnt = (await self.db.execute(
            select(func.count()).select_from(M07Order).where(
                M07Order.diagnosis_id == diagnosis_id,
                M07Order.is_deleted == False,
            )
        )).scalar_one()

        return cnt > 0

    # ---------- 设为主诊断 ----------
    async def set_primary(self, diagnosis_id: int, user) -> dict:
        """设为主诊断"""
        diagnosis = await self._get(diagnosis_id)

        if diagnosis.status != "ACTIVE":
            raise BizException(54732, "仅有效诊断可设为主诊断")

        if diagnosis.is_suspected:
            raise BizException(54754, "疑似诊断不可作为主诊断")

        if not diagnosis.is_ophthalmic and diagnosis.eye_side != "NA":
            pass

        # 原主诊断降为次
        old_primary = (await self.db.execute(
            select(M07Diagnosis).where(
                M07Diagnosis.encounter_id == diagnosis.encounter_id,
                M07Diagnosis.diagnosis_type == "PRIMARY",
                M07Diagnosis.status == "ACTIVE",
                M07Diagnosis.id != diagnosis_id,
                M07Diagnosis.is_deleted == False,
            )
        )).scalar_one_or_none()

        old_primary_info = None
        if old_primary:
            old_primary.diagnosis_type = "SECONDARY"
            old_primary_info = {
                "diagnosis_id": old_primary.id,
                "display_text": old_primary.display_text,
            }

        diagnosis.diagnosis_type = "PRIMARY"
        diagnosis.sort_no = 1

        await self._update_encounter_summary(diagnosis.encounter_id)
        await self.db.commit()

        return {
            "diagnosis_id": diagnosis.id,
            "display_text": diagnosis.display_text,
            "diagnosis_type": "PRIMARY",
            "previous_primary": old_primary_info,
            "message": "已设为主诊断",
        }

    # ---------- 更新会话摘要 ----------
    async def _update_encounter_summary(self, encounter_id: int) -> None:
        """更新会话的诊断摘要"""
        from app.models.m07.encounter import M07Encounter

        diagnoses = (await self.db.execute(
            select(M07Diagnosis).where(
                M07Diagnosis.encounter_id == encounter_id,
                M07Diagnosis.status == "ACTIVE",
                M07Diagnosis.is_deleted == False,
            ).order_by(M07Diagnosis.sort_no)
        )).scalars().all()

        primary = next((d for d in diagnoses
                         if d.diagnosis_type == "PRIMARY"), None)

        await self.db.execute(
            M07Encounter.__table__.update()
            .where(M07Encounter.id == encounter_id)
            .values(
                primary_diagnosis=(primary.display_text if primary else None),
                diagnosis_count=len(diagnoses),
            )
        )

    async def _get_summary(self, encounter_id: int) -> dict:
        """获取诊断摘要"""
        counts = (await self.db.execute(
            select(
                M07Diagnosis.diagnosis_type,
                func.count().label("cnt"),
            ).where(
                M07Diagnosis.encounter_id == encounter_id,
                M07Diagnosis.status == "ACTIVE",
                M07Diagnosis.is_deleted == False,
            ).group_by(M07Diagnosis.diagnosis_type)
        )).all()

        by_type = {r[0]: r[1] for r in counts}

        primary = (await self.db.execute(
            select(M07Diagnosis).where(
                M07Diagnosis.encounter_id == encounter_id,
                M07Diagnosis.diagnosis_type == "PRIMARY",
                M07Diagnosis.status == "ACTIVE",
                M07Diagnosis.is_deleted == False,
            )
        )).scalar_one_or_none()

        return {
            "total": sum(by_type.values()),
            "primary_count": by_type.get("PRIMARY", 0),
            "secondary_count": by_type.get("SECONDARY", 0),
            "suspected_count": by_type.get("SUSPECTED", 0),
            "differential_count": by_type.get("DIFFERENTIAL", 0),
            "has_primary": primary is not None,
            "primary_diagnosis": primary.display_text if primary else None,
        }

    # ---------- 常用诊断记录 ----------
    async def _record_common(self, code: str, name: str,
                               user, dept_id) -> None:
        """记录常用诊断（UPSERT）"""
        uid = getattr(user, "id", None)

        for scope, key_field, key_val in [
            ("PERSONAL", "doctor_id", uid),
            ("DEPT", "dept_id", dept_id),
        ]:
            if not key_val:
                continue

            row = (await self.db.execute(
                select(M07DiagnosisCommon).where(
                    M07DiagnosisCommon.scope == scope,
                    M07DiagnosisCommon.diagnosis_code == code,
                    getattr(M07DiagnosisCommon, key_field) == key_val,
                )
            )).scalar_one_or_none()

            if row:
                row.usage_count = (row.usage_count or 0) + 1
                row.last_used_at = datetime.now()
            else:
                self.db.add(M07DiagnosisCommon(
                    scope=scope,
                    doctor_id=(uid if scope == "PERSONAL" else None),
                    dept_id=(dept_id if scope == "DEPT" else None),
                    diagnosis_code=code,
                    diagnosis_name=name,
                    usage_count=1,
                    last_used_at=datetime.now(),
                ))

    # ---------- 辅助 ----------
    async def _get_encounter(self, encounter_id: int) -> M07Encounter:
        e = (await self.db.execute(
            select(M07Encounter).where(
                M07Encounter.id == encounter_id,
                M07Encounter.is_deleted == False,
            )
        )).scalar_one_or_none()

        if not e:
            raise BizException(54701, "就诊会话不存在")

        return e

    async def _get(self, diagnosis_id: int) -> M07Diagnosis:
        d = (await self.db.execute(
            select(M07Diagnosis).where(
                M07Diagnosis.id == diagnosis_id,
                M07Diagnosis.is_deleted == False,
            )
        )).scalar_one_or_none()

        if not d:
            raise BizException(54731, "诊断记录不存在")

        return d
```

### 8.1 诊断录入规则

|---|---|---|
| 会话必须可编辑 | 未锁定 | 54748 |

| 场景 | 处理 |
