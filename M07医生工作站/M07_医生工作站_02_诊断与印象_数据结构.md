## 4. 数据结构设计

### 4.1 ER 关系图

```
┌──────────────────────────────────────────────────────────────────────┐
│ 上游（引用，不建物理外键）                                             │
│  m07_encounter（M07-01）、md_diagnosis（M01-09）                      │
│  mpi_patient（M03-01）、mdm_employee（M01）                           │
└──────────────────────────────┬───────────────────────────────────────┘
                               │ 诊断录入
                               ▼
┌──────────────────────────────────┐
│ m07_diagnosis（诊断记录）★核心     │
│  · encounter_id                  │
│  · diagnosis_code（引用字典）      │
│  · eye_side（OD/OS/OU/NA）       │
│  · diagnosis_type（主/次/疑似/鉴别）│
│  · status / sort_no              │
└───┬──────────────┬───────────────┴────────────────┐
    │ 1:N          │ 1:N                            │
    ▼              ▼                                ▼
┌──────────────┐ ┌──────────────┐          ┌──────────────────┐
│m07_diagnosis_│ │m07_diagnosis_│          │m07_diagnosis_    │
│basis（依据）  │ │log（操作日志） │          │accuracy（准确率） │
│  · basis_type│ │  · action    │          │（独立统计）       │
│  · content   │ │  · before/after│        └──────────────────┘
│  · exam_ref  │ └──────────────┘
└──────────────┘

支撑表：
┌──────────────────────────┐  ┌──────────────────────────┐
│m07_diagnosis_template    │  │m07_diagnosis_common      │
│（诊断模板）                │  │（常用诊断）               │
│  · template_name         │  │  · scope（个人/科室/全院） │
│  · diagnoses（JSONB）     │  │  · usage_count           │
└──────────────────────────┘  └──────────────────────────┘
```

**设计说明：**

- `m07_diagnosis` 与 `m07_encounter` 是 **1:N**（一个就诊可有多条诊断）
- **主诊断唯一**由部分唯一索引保证：`(encounter_id) WHERE diagnosis_type='PRIMARY'`
- `diagnosis_code` 引用 M01-09 字典，**不建物理外键**，但冗余 `diagnosis_name`/`icd10_code`
- **眼别**是眼科核心字段，眼科诊断必填 OD/OS/OU
- `m07_diagnosis_template` 的 `diagnoses` 用 JSONB 存组合
- `m07_diagnosis_common` 支撑"我的常用/科室常用"，用 `usage_count` 排序

**索引设计**

| 索引名 | 类型 | 字段 | 说明 |
|---|---|---|---|
| pk_m07_diagnosis | PRIMARY | id | 主键 |
| **idx_m07_diag_encounter** | **NORMAL** | **encounter_id, status, sort_no** | **按会话查（核心）** |
| **uk_m07_diag_primary** | **UNIQUE（部分）** | **encounter_id** | **主诊断唯一（核心）** |
| uk_m07_diag_unique | UNIQUE（部分） | encounter_id, diagnosis_code, eye_side | 同诊断同眼别唯一 |
| idx_m07_diag_code | NORMAL | diagnosis_code, record_date | 病种统计 |
| idx_m07_diag_patient | NORMAL | patient_id, record_date | 患者诊断史 |
| idx_m07_diag_date | NORMAL | record_date, dept_id | 科室统计 |
| idx_m07_diag_eye | NORMAL | eye_side, record_date | 眼别统计 |
| idx_m07_diag_name | NORMAL | diagnosis_name gin_trgm_ops | 名称模糊搜索（GIN） |

**约束说明**

```sql
ALTER TABLE m07_diagnosis
    ADD CONSTRAINT ck_m07_diag_type
    CHECK (diagnosis_type IN ('PRIMARY', 'SECONDARY',
                               'SUSPECTED', 'DIFFERENTIAL'));

ALTER TABLE m07_diagnosis
    ADD CONSTRAINT ck_m07_diag_eye
    CHECK (eye_side IN ('OD', 'OS', 'OU', 'NA'));

ALTER TABLE m07_diagnosis
    ADD CONSTRAINT ck_m07_diag_status
    CHECK (status IN ('DRAFT', 'ACTIVE', 'LOCKED',
                       'ARCHIVED', 'CANCELLED'));

-- 眼科诊断眼别不可为 NA
ALTER TABLE m07_diagnosis
    ADD CONSTRAINT ck_m07_diag_ophthalmic_eye
    CHECK (is_ophthalmic = FALSE OR eye_side <> 'NA');

-- 非眼科诊断眼别必须为 NA
ALTER TABLE m07_diagnosis
    ADD CONSTRAINT ck_m07_diag_systemic_eye
    CHECK (is_ophthalmic = TRUE OR eye_side = 'NA');

-- 疑似/鉴别诊断不可为主诊断
ALTER TABLE m07_diagnosis
    ADD CONSTRAINT ck_m07_diag_primary
    CHECK (diagnosis_type = 'PRIMARY'
           OR diagnosis_type IN ('SECONDARY', 'SUSPECTED', 'DIFFERENTIAL'));

ALTER TABLE m07_diagnosis
    ADD CONSTRAINT ck_m07_diag_sort CHECK (sort_no >= 0);

-- 已作废必须有原因
ALTER TABLE m07_diagnosis
    ADD CONSTRAINT ck_m07_diag_cancelled
    CHECK (status <> 'CANCELLED' OR cancel_reason IS NOT NULL);

-- 核心：一就诊一个主诊断
CREATE UNIQUE INDEX uk_m07_diag_primary
    ON m07_diagnosis (encounter_id)
    WHERE diagnosis_type = 'PRIMARY'
      AND status = 'ACTIVE'
      AND is_deleted = FALSE;

-- 同一就诊同一诊断同一眼别不可重复
CREATE UNIQUE INDEX uk_m07_diag_unique
    ON m07_diagnosis (encounter_id, diagnosis_code, eye_side)
    WHERE status = 'ACTIVE' AND is_deleted = FALSE;

-- 名称模糊搜索
CREATE EXTENSION IF NOT EXISTS pg_trgm;
CREATE INDEX idx_m07_diag_name
    ON m07_diagnosis USING gin (diagnosis_name gin_trgm_ops);
```

**状态机**

```
        ┌──────────┐
        │  DRAFT   │  草稿
        └────┬─────┘
             │ 保存
             ▼
        ┌──────────┐
        │  ACTIVE  │  有效
        └────┬─────┘
             │
    ┌────────┼────────────┬──────────────┐
    │ 修正    │ 作废        │ 就诊完成      │
    ▼        ▼            ▼              ▼
(更新)  ┌──────────┐  ┌──────────┐  ┌──────────┐
        │CANCELLED │  │  LOCKED  │  │ ARCHIVED │
        └──────────┘  └──────────┘  └──────────┘
```

**display_text 生成规则**

```
眼科诊断：{code} {name}（{eye_text}）
  例：H25.901 老年性白内障（右）
眼别文字：OD→右，OS→左，OU→双

非眼科诊断：{code} {name}
  例：I10 原发性高血压
```

**量级估算：**

| 项 | 数值 |
|---|---|
| 单会话平均诊断数 | 2.4 条 |
| 日诊断数 | ≈720 条 |
| 年诊断数 | ≈26 万条 |
| 单行大小 | ≈500 B |
| 年存储 | ≈130 MB |

**分区：** 按 `record_date` 年度分区，保留 **15 年**。

**约束说明**

```sql
ALTER TABLE m07_diagnosis_template
    ADD CONSTRAINT ck_m07_tpl_scope
    CHECK (scope IN ('PERSONAL', 'DEPT', 'HOSPITAL'));

-- 个人模板必须有 owner_id
ALTER TABLE m07_diagnosis_template
    ADD CONSTRAINT ck_m07_tpl_owner
    CHECK (scope <> 'PERSONAL' OR owner_id IS NOT NULL);

-- 科室模板必须有 dept_id
ALTER TABLE m07_diagnosis_template
    ADD CONSTRAINT ck_m07_tpl_dept
    CHECK (scope <> 'DEPT' OR dept_id IS NOT NULL);

-- 诊断组合必须为非空数组
ALTER TABLE m07_diagnosis_template
    ADD CONSTRAINT ck_m07_tpl_diagnoses
    CHECK (jsonb_typeof(diagnoses) = 'array'
       AND jsonb_array_length(diagnoses) > 0);

-- 同 scope 内模板名唯一
CREATE UNIQUE INDEX uk_m07_tpl_name
    ON m07_diagnosis_template (
        scope,
        COALESCE(owner_id, 0),
        COALESCE(dept_id, 0),
        template_name
    )
    WHERE is_deleted = FALSE;
```

**约束说明**

```sql
ALTER TABLE m07_diagnosis_accuracy
    ADD CONSTRAINT ck_m07_accuracy_eval
    CHECK (evaluation IS NULL
           OR evaluation IN ('EXCELLENT', 'GOOD',
                              'NEEDS_IMPROVEMENT', 'POOR'));

ALTER TABLE m07_diagnosis_accuracy
    ADD CONSTRAINT ck_m07_accuracy_counts
    CHECK (compared_count >= 0
       AND consistent_count >= 0
       AND miss_count >= 0
       AND over_count >= 0
       AND consistent_count + miss_count + over_count <= compared_count);

CREATE UNIQUE INDEX uk_m07_accuracy
    ON m07_diagnosis_accuracy (
        stat_date,
        COALESCE(dept_id, 0),
        COALESCE(doctor_id, 0)
    );

            return

        total = Decimal(self.compared_count)
        self.consistent_rate = round(
            Decimal(self.consistent_count) / total * 100, 2)
        self.miss_rate = round(Decimal(self.miss_count) / total * 100, 2)
        self.over_rate = round(Decimal(self.over_count) / total * 100, 2)

        rate = float(self.consistent_rate)
        if rate >= 90:
            self.evaluation = "EXCELLENT"
        elif rate >= 85:
            self.evaluation = "GOOD"
        elif rate >= 75:
            self.evaluation = "NEEDS_IMPROVEMENT"
        else:
            self.evaluation = "POOR"
```
