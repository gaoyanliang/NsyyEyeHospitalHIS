
### 0.3 三条铁律（违反即返工）

| # | 铁律 | 原因 |
|---|---|---|
| **1** | **数量口径三处一致**：页面总览树 `P0x` = 第 5 章 `### 5.x P0x` 标题 = 附录 A 页面清单；表清单 = `### 4.x 表：` 标题；接口总览 `API-01` 起连续无断号 | 全仓 95 个子模块统一标准，交叉引用依赖编号稳定 |
| **2** | **钱与库存都不自己算**：金额计算一律调 M16；库存数量一律以 M15 为权威源，M10 只做「销售可用量」视图与预占 | M05/M16/M15 已各有一套引擎，重复实现必然对不上账 |
| **3** | **技术栈 PostgreSQL 16**：不得出现 `AUTO_INCREMENT` / `TINYINT` / `DATETIME` / `ENGINE=` / `VARCHAR2` | 全仓已统一 PostgreSQL，MySQL 语法是硬错误 |

## 1. M10 模块定位与九子模块划分

### 1.1 一句话定位

> **M10 回答「这个患者的眼睛现在是什么状态（验光结果）、他该配什么（配镜处方）、我们卖了他什么、什么时候能把眼镜交到他手上」。**

M10 是眼科医院**唯一的、不依赖医保、现金流即时**的收入来源（占收入 25%~40%），承接总体设计第 5.3 节的**视光闭环**：

```
验光 → 配镜处方 → 选品 → 订单 → 收费 → 加工 → 取镜 → 复查 → 会员积分
 M10-01  M10-02   M10-05 M10-06  M16-04  M10-08  M10-06  M10-09  M03-03/M19
```

### 1.2 与 M01-08 / M16-04 的边界（最容易搞错的三方分工）

读懂这三句话，M10 就设计对了：

| 问题 | 权威方 | 说明 |
|---|---|---|
| **「我们卖哪些镜片、每档度数能不能做、多少钱、几道工序」** | **M01-08 视光产品** | M10 **只读**，不新建商品；下单必调 M01-08 的 `specs/lookup` 与 `pricing` |
| **「这个顾客买了什么、收了多少钱、退了多少钱、发票」** | **M16-04 视光销售结算** | 收款、定金、尾款、退换退款、发票全在 M16，M10 **不碰钱** |
| **「这个患者的验光结果是什么、该配什么镜片、配了多少副、加工到哪一步、什么时候复查」** | **M10（本模块）** | 验光、处方、订单业务档案、加工、复查 |

> **一句话记忆：** M01 定义「货」，M16 定义「钱」，M10 定义「人和货的关系」。

### 2.4 时间与金额

| 项 | 规范 |
|---|---|
| 时间 | ISO 8601 带时区 `2026-10-31T09:15:22+08:00`；数据库 `TIMESTAMP`（无时区，服务统一 `Asia/Shanghai`） |
| 日期 | `2026-10-31`，数据库 `DATE` |
| 单价 | `NUMERIC(12,4)`（视光商品度数加价精度高） |
| 金额 | `NUMERIC(14,2)` |
| 光圈（度） | `NUMERIC(6,2)`，如 `-4.25` |
| 弧曲率（mm） | `NUMERIC(5,2)`，如 `8.60` |
| 轴位（°） | `SMALLINT`，1~180 |
| 瞳距（mm） | `NUMERIC(5,2)`，如 `32.50` |
| 舍入 | `ROUND_HALF_UP`，金额到分；角度到 0.25D |

### 2.5 幂等与并发

| 场景 | 机制 |
|---|---|
| 创建订单 / 创建复诊预约 / 建加工单 | 请求头 `Idempotency-Key`，Redis 键 `m10:idem:{biz}:{key}` TTL 24h |
| 订单修改、处方修改 | 乐观锁 `version` 字段，冲突 → `"40900"` |
| 验光单编辑 | Redis 编辑锁 `m10:lock:optometry:{id}` TTL 60s |
| 加工单领取 | `SELECT ... FOR UPDATE SKIP LOCKED`（订单行锁 TTL 10s）+ 加工单状态机 |
| 库存预占 | `m10_stock_reserve` 唯一索引 `(sku_key, order_id, status='ACTIVE')` |

### 2.6 数据库硬规范

| 规范 | 说明 |
|---|---|
| 主键 | `BIGINT GENERATED BY DEFAULT AS IDENTITY`（SQLAlchemy 写 `Identity()`） |
| 布尔 | `BOOLEAN`，默认 `FALSE`/`TRUE` |
| 时间 | `TIMESTAMP`；创建/更新时间用 `CURRENT_TIMESTAMP` + 触发器维护 `updated_at` |
| JSON | `JSONB` |
| 枚举 | `VARCHAR(16/24/32)` + `CHECK` 约束，**不用 PostgreSQL ENUM 类型** |
| 外键 | **不建物理外键**，应用层校验 + 每日对账 |
| 逻辑删除 | `is_deleted BOOLEAN NOT NULL DEFAULT FALSE`（新模块用 `is_deleted`；M01 老表用 `deleted`，只读引用时不改） |
| 索引命名 | `pk_` / `uk_` / `idx_` / `ft_` |
| 约束命名 | `ck_{表缩略}_{规则}` |
| 中文检索 | `pg_trgm` + `GIN (col gin_trgm_ops)` |
| 分区 | 日志类表按 `created_at` 月度 `RANGE` 分区，保留 12~24 个月 |

### 4.x 补充硬要求

1. **每张表**：字段定义表 + 索引设计表 + 约束 SQL（至少状态 CHECK 与 1 条业务 CHECK），日志类表加分区策略。
2. **字段说明列**必须写清枚举取值与单位（如 `度（D）`、`mm`、`元`），不得写「见上」「同上」。
3. **只读引用上游的字段**：在字段说明里标注来源表，如 `patient_id BIGINT | N | — | 患者 ID（M03 \`mpi_patient.id\`，只读引用）`。
4. **SQLAlchemy 模型**：一张表一个 class，保留 `__table_args__` 的索引与 CHECK 声明，注释用中文 docstring。
5. **Pydantic**：至少包含 3 个请求体（Create/Update/Query）+ 3 个响应体（List/Detail/Brief），带 `Field(..., description="…")`。
6. **所有 `python` 代码块必须 `ast.parse` 通过**；**所有 `json` 代码块必须 `json.loads` 通过**。
7. **附录 E 建表顺序**必须写明本子模块表依赖的外部表（M01/M03/M15/M16）先于本表创建。

```python
    for i, line in enumerate(t.split("\n"), 1):
        if line.startswith("|"):
            if not buf:
                start = i
            buf.append(line)
        elif buf:
            out.append((start, "\n".join(buf)))
            buf = []
    if buf:
        out.append((start, "\n".join(buf)))
    return out


def validate(fp: Path) -> list:
    t = fp.read_text(encoding="utf-8")
    issues = []
    is_struct = fp.name.endswith("_数据结构.md")
    tag = "STRUCT" if is_struct else "DESIGN"

    # 1. 围栏配对
    if t.count(FENCE) % 2:
        issues.append((tag, 0, "代码围栏未配对"))

    # 2. Python 语法
    for i, b in enumerate(re.findall(FENCE + r"python\n(.*?)" + FENCE, t, re.S), 1):
        try:
            ast.parse(b)
        except SyntaxError as e:
            issues.append((tag, 0, "Python 块 #%d 语法错误: %s" % (i, e.msg)))

    # 3. JSON 语法
    for i, j in enumerate(re.findall(FENCE + r"json\n(.*?)" + FENCE, t, re.S), 1):
        try:
            json.loads(j)
        except Exception as e:  # noqa: BLE001
            issues.append((tag, 0, "JSON 块 #%d 解析失败: %s" % (i, e)))

    # 4. 表格列数
    for ln, tb in split_table(t):
        lines = tb.split("\n")
        if len(lines) >= 2 and len({x.count("|") for x in lines}) > 1:
            issues.append((tag, ln, "表格列数不一致（起始行 %d）" % ln))

    # 5. 乱码 / 占位词 / MySQL 残留
    if chr(0xFFFD) in t:
        issues.append((tag, 0, "存在乱码字符 U+FFFD"))
    for kw in BAD_SQL:
        if kw in t:
            issues.append((tag, 0, "MySQL 残留语法: %s" % kw))
    for kw in PLACEHOLDERS[:3]:
        if kw in t:
            issues.append((tag, 0, "存在占位词: %s" % kw))

    # 6. 详细设计专项
    if not is_struct:
        if re.search(r"^### 4\.\d+ 表：", t, re.M):
            issues.append((tag, 0, "第 4 章残留表定义（应为指引块）"))

        pages_tree = re.findall(r"├── (P\d\d)", t) + re.findall(r"└── (P\d\d)", t)
        pages_h5 = re.findall(r"^### 5\.\d+ (P\d\d)", t, re.M)
        s_tree, s_h5 = set(pages_tree), set(pages_h5)
        if s_tree != s_h5:
            issues.append((tag, 0, "页面总览与第 5 章不一致: 仅总览=%s 仅详述=%s"
                           % (sorted(s_tree - s_h5), sorted(s_h5 - s_tree))))

        apis = [int(x) for x in re.findall(r"^\| API-(\d+) \|", t, re.M)]
        if apis:
            expect = list(range(1, max(apis) + 1))
            if sorted(set(apis)) != expect:
                miss = sorted(set(expect) - set(apis))
                issues.append((tag, 0, "接口编号不连续，缺失: %s" % miss))

        for c in sorted(set(re.findall(r'"(\d{7})"', t))):
            if not c.startswith("10") or len(c) != 7:
                issues.append((tag, 0, "错误码格式异常: %s" % c))

    # 7. 数据结构专项
    if is_struct:
        tables = re.findall(r"^### 4\.\d+ 表：`(\w+)`", t, re.M)
        for tb in tables:
            if not tb.startswith("m10_"):
                issues.append((tag, 0, "表名前缀错误: %s" % tb))
        if len(tables) != len(set(tables)):
            issues.append((tag, 0, "表定义重复"))
        if "SQLAlchemy 2.0 模型定义" not in t:
            issues.append((tag, 0, "缺少 SQLAlchemy 模型章节"))
        if "Pydantic Schema 定义" not in t:
            issues.append((tag, 0, "缺少 Pydantic Schema 章节"))

    return issues


def main() -> int:
    """入口。"""
    root = Path(sys.argv[1] if len(sys.argv) > 1 else ".")
    fails = 0
    for fp in sorted(root.glob("M10_*.md")):
        issues = validate(fp)
        if issues:
            fails += 1
            print("✗ %s" % fp.name)
            for tag, ln, msg in issues:
                print("    [%s] L%s %s" % (tag, ln, msg))
    print("✓ 全部通过" if fails == 0 else "✗ %d 个文件存在问题" % fails)
    return 0 if fails == 0 else 1


if __name__ == "__main__":
    sys.exit(main())
```
