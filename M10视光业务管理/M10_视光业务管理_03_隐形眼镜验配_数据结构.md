### 4.2 表：`m10_contact_fitting`（隐形眼镜验配单主表）

**用途：** 记录「一次隐形眼镜验配」的完整档案。它是 M10-03 的**根实体**，也是对外契约 **P-08** 的唯一数据源。写入方为 M10-03 验配师工作站；只读方为 M10-06（下单取参数）、M16-04（销售单关联校验、处方合规）、M10-09（复查计划引用）。

**一次验配一条记录**，与患者、处方、验光单一对多关联：同一患者一年内可以验配 3 次（换品牌、换周期、度数变化），产生 3 条 `m10_contact_fitting`。

**为什么主表要冗余存放「验配结论」的汇总字段：** P-08 是 M16-04 收钱前的合规校验接口，要求 P95 ≤ 100 ms 且**不能有 N+1 查询**。因此把「拟配产品编码、验配结论、处方有效期、禁忌症筛查结论、验配师签名」这 5 组字段直接冗余在主表上，P-08 单表即可返回 90% 的必要信息。

| 状态 | 中文 | 进入条件 | 可编辑 | 可打印 | 可下单 |
|---|---|---|---|---|---|
| `DRAFT` | 草稿 | 新建验配申请 | 全部字段 | ✗ | ✗ |
| `PENDING_TRIAL` | 待试戴 | 提交且 `trial_needed = TRUE`，已借出试戴片 | 检查/试戴字段 | ✗ | ✗ |
| `TRIAL` | 试戴中 | 首次配适评估记录写入 | 配适/试戴字段 | ✗ | ✗ |
| `FITTED` | 已验配 | 填 `fitting_result` + 验配师签名 + 试戴片归还 | 仅备注 | 预览 | ✗ |

| `COMPLETED` | 已完成 | 已下单（`order_no` 回填） | ✗ | ✓ | ✗（已下） |

| `REJECTED` | 已驳回 | 审核驳回 | 可以修改后重新提交 | ✗ | ✗ |

### 4.3 表：`m10_contact_fitting_eye`（验配单眼别明细表）

**用途：** 按眼别（OD/OS）逐只记录隐形眼镜的**验配参数与配适结论**。这是全子模块**专业度最高的表**：软镜的基弧换算、直径选择、散光片的轴位稳定评估（旋转度、LARS 换算）、RGP 的荧光素染色四区评估与顶点距离换算，全部落在这里。

**为什么必须拆成独立表而不是塞进主表：** 一只眼有一套完整的 30+ 参数（角膜曲率、BC、DIA、度数、轴位、旋转度、配适评级、荧光素评估…），双眼各一套就是 60+ 字段。如果扁平化到主表，字段量翻倍且半数恒为 NULL，索引与统计都难写。拆分后每行语义清晰、可加唯一约束 `(fitting_id, eye_side)`。

**写入方：** M10-03（P03 软镜验配页、P04 散光片轴位评估页、P05 RGP 验配页）。**只读方：** M10-06 / M16-04（通过 P-08 契约返回）。

### 4.4 表：`m10_contact_trial_use`（试戴片借用登记表）

**用途：** 试戴片（Trial Lens）是**验配用的样品镜片**，在 M01-08 中以 `mdm_optical_product.is_trial_lens = TRUE` 标记，**只供验配试戴、不得销售**。本表记录每一片试戴片的**入库、借出、消毒、归还、报损**全过程，是《医疗器械使用质量管理规范》要求的使用追溯记录。

**为什么必须有独立表而不是在主表上记一个"借了几片"：**
1. **一物一码追溯**：试戴片有独立序列号（`trial_serial_no`），同一型号的 20 片必须能查到每一片给谁用过、何时消毒、是否报损；
2. **交叉污染防控**：隐形眼镜是接触角膜的三类器械，试戴片在两次使用之间必须消毒并留痕，无记录即视为违规；
3. **不销售合规**：M01-08 规定 `is_trial_lens = TRUE` 不可售；本表的 `borrowed_product_code` 与 `m10_contact_fitting.product_code` 必须不同（见 4.2 约束 `ck_m10_contact_fitting_trial_diff`），形成双向防错。

### 4.5 表：`m10_contact_care_plan`（护理指导与随访计划表）

**用途：** 记录验配后的**护理与戴镜指导**以及**随访/复查计划**。隐形眼镜事故中超过 60% 与护理不当或超时戴镜有关（睡眠戴镜、自来水冲洗镜片、护理液超期使用），因此本表是"患者教育留痕 + 复查依从性追踪"的载体。

### 4.6 表：`m10_contact_adaptation_log`（配适评估日志表）

**用途：** 记录**每一次配适评估**（试戴评估、复查评估、换片评估）的结构化结果。这是一个**只追加（append-only）**的过程表，不更新不删除，用于还原「这个患者试戴了哪几种镜片、每次评估的旋转度/荧光素表现如何、最终为什么选这个参数」的完整决策链。

**为什么与 4.3 眼别明细分开：** 4.3 是**当前生效方案的最终值**（一只眼一行）；本表是**评估过程的每一次读数**（一只眼 N 行）。举例：某散光患者试戴了 3 个品牌的散光片，每片评估 2 次（15 分钟、50 次眨眼后），共 6 条评估记录 → 4.3 只有 1 行最终采用方案。若合并，最终值会被历史读数覆盖，无法复盘，也无法做「不同品牌旋转稳定性」的质量分析。

### 4.7 表：`m10_contact_log`（操作审计日志表）

**用途：** 记录隐形眼镜验配全流程的**每一次关键操作**（状态流转、参数修改、试戴片借还、打印、导出、作废），满足三类医疗器械使用的可追溯要求与 HIS 审计要求。本表**只追加、不修改、不删除**。

**为什么必须单独一张日志表而不是只靠主表的 `updated_at`/`updated_by`：**
1. **状态机审计**：验配单从 `DRAFT` 到 `COMPLETED` 最多 6 次状态流转，每次的「谁、何时、因为什么」都必须可查；
2. **参数变更留痕**：验配参数（基弧、度数、轴位）是医疗器械处方参数，事后修改必须能看出改前改后（如轴位从 170° 改成 180°），否则无法界定医疗责任；
3. **试戴片追溯**：试戴片借还本身已在 4.4 有记录，但「借出时谁批的、归还核对谁做的」仍需操作级日志兜底。

**分区：** 按 `created_at` 月度 RANGE 分区，保留 **36 个月**（三类医疗器械追溯期要求 ≥ 产品有效期后 2 年，隐形眼镜验配记录按 3 年保守设计）。

CREATE TABLE m10_contact_log_y2026m12 PARTITION OF m10_contact_log

-- 分区自动创建函数（APScheduler 每月 25 日调用）
CREATE OR REPLACE FUNCTION fn_m10_contact_log_create_partition(p_month DATE)
RETURNS TEXT
LANGUAGE plpgsql
AS $$
DECLARE
    v_start DATE := date_trunc('month', p_month)::DATE;
    v_end   DATE := (date_trunc('month', p_month) + INTERVAL '1 month')::DATE;
    v_name  TEXT := 'm10_contact_log_y' || to_char(v_start, 'YYYY') || 'm'
                     || to_char(v_start, 'MM');
BEGIN
    EXECUTE format('CREATE TABLE IF NOT EXISTS %I PARTITION OF m10_contact_log '
                   'FOR VALUES FROM (%L) TO (%L)', v_name, v_start, v_end);
    RETURN v_name;
END;
$$;

-- 归档：保留 36 个月，超期分区先导出 JSONL 再 DETACH 删除
CREATE OR REPLACE FUNCTION fn_m10_contact_log_drop_expired(p_keep_months INT DEFAULT 36)
RETURNS INT
LANGUAGE plpgsql
AS $$
DECLARE
    v_rec  RECORD;
    v_cnt  INT := 0;
    v_cut  DATE := (date_trunc('month', CURRENT_DATE)
                    - make_interval(months => p_keep_months))::DATE;
BEGIN
    FOR v_rec IN
        SELECT c.relname AS part_name,
               substring(c.relname FROM 'y(\d{4})m(\d{2})') AS ym
        FROM pg_class c
        JOIN pg_inherits i ON i.inhrelid = c.oid
        JOIN pg_class p ON p.oid = i.inhparent
        WHERE p.relname = 'm10_contact_log'
          AND c.relname ~ '^m10_contact_log_y\d{4}m\d{2}$'
    LOOP
        IF to_date(v_rec.ym, 'YYYYMM') < v_cut THEN
            EXECUTE format('ALTER TABLE m10_contact_log DETACH PARTITION %I',
                           v_rec.part_name);
            EXECUTE format('DROP TABLE IF EXISTS %I', v_rec.part_name);
            v_cnt := v_cnt + 1;
        END IF;
    END LOOP;
    RETURN v_cnt;
END;
$$;

### 4.9 表：`m10_contact_stat`（验配工作量与质量统计表）

**用途：** 按 **`stat_date` + `org_id` + `fitter_id` + `fitting_type`** 维度日汇总验配工作量与质量指标，支撑 P08「隐形验配统计」页与月度科室报表，避免每次打开统计页都扫全表。

**为什么预汇总而不是实时聚合：** 验配单 + 眼别 + 评估日志三表关联聚合，单日数据量 10 万级，若每次打开统计页实时算 P95 会超过 3 秒。日汇总后统计页只需查 1 张表 + 30 行。

**计算方式：** APScheduler 每日 02:30 重算 T-1 日数据（幂等 UPSERT），支持「重算指定日期」补数。

       AND fit_cancelled >= 0 AND eye_total >= 0

       AND followup_due >= 0 AND followup_completed >= 0

ALTER TABLE m10_contact_stat
    ADD CONSTRAINT ck_m10_contact_stat_total
    CHECK (fit_success + fit_failed + fit_refer <= fit_total
       AND fit_completed <= fit_total
       AND fit_cancelled <= fit_total
       AND toric_rotation_gt10 <= toric_total
       AND rgp_decentration <= rgp_total
       AND followup_completed <= followup_due

        """旋转度绝对值（用于阈值判定）。"""
        return abs(self.rotation_degree or 0)

    def needs_axis_compensation(self, threshold: int = 10) -> bool:
        """是否需要做 LARS 轴位等效换算。"""
        return self.rotation_abs > threshold

    @staticmethod
    def compensate_axis_by_lars(refraction_axis: int, rotation: int) -> int:
        """LARS 法则换算下单轴位。

        LARS = Left Add, Right Subtract：
          - 镜片向"右"（顺时针，正旋转）偏 → 轴位需"减"旋转度；
          - 镜片向"左"（逆时针，负旋转）偏 → 轴位需"加"旋转度绝对值。
        结果归一化到 1~180。

        >>> M10ContactFittingEye.compensate_axis_by_lars(180, 15)
        175
        >>> M10ContactFittingEye.compensate_axis_by_lars(10, -15)
        25
        """
        axis = int(refraction_axis) - int(rotation)
        while axis < 1:
            axis += 180
        while axis > 180:
            axis -= 180
        return axis

    @staticmethod
    def vertex_convert(frame_power: Decimal, distance_mm: Decimal = Decimal("12")) -> Decimal:
        """顶点距离换算：Fc = Ff / (1 - d * Ff)，结果按 0.25D 舍入。

        约定 distance_mm 转米；框架镜度数绝对值 ≤ 4.00D 时换算量 < 0.25D，可按临床惯例不换算。
        """
        d = Decimal(distance_mm) / Decimal(1000)
        denom = Decimal(1) - d * Decimal(frame_power)
        if denom == 0:
            raise ValueError("顶点距离换算分母为零")
        fc = Decimal(frame_power) / denom
        return (fc * 4).quantize(Decimal("1")) / Decimal(4)

    @staticmethod
    def recommend_base_curve(k_avg_mm: Decimal, flat_factor: Decimal = Decimal("0.8")) -> Decimal:
        """软镜基弧推荐：BC = 平均 K 曲率半径（mm）+ 平坦化系数（默认 0.8mm）。"""
        return Decimal(k_avg_mm) + Decimal(flat_factor)

        """按复查节点推算下一次复查日期。"""
        base = from_date or date.today()
        nodes = self.followup_nodes or self.default_followup_nodes

            candidate = base.fromordinal(base.toordinal() + node)
            if self.next_followup_date is None or candidate <= self.next_followup_date:
                return candidate
        return None

    @staticmethod
    def rate(numerator: int, denominator: int, digits: int = 2) -> Decimal:
        """安全的百分比计算（分母为 0 返回 0.00）。"""
        if not denominator:
            return Decimal("0.00")
        value = Decimal(numerator) * Decimal(100) / Decimal(denominator)
        return value.quantize(Decimal(1).scaleb(-digits))

def _check_step_025(value: Optional[Decimal], field_name: str) -> Optional[Decimal]:
    """校验度数是否为 0.25 的整数倍。"""
    if value is None:
        return value
    scaled = Decimal(value) * 4
    if scaled != scaled.to_integral_value():
        raise ValueError(f"{field_name} 必须为 0.25 的整数倍，当前 {value}")
    return Decimal(value)


def _check_axis(axis: Optional[int], cylinder: Optional[Decimal]) -> Optional[int]:
    """柱镜为 0 时不得填轴位；柱镜非 0 时轴位必填。"""
    if not cylinder:
        if axis is not None:
            raise ValueError("柱镜为 0 时不可填写轴位")
        return axis
    if axis is None:
        raise ValueError("柱镜不为 0 时必须填写轴位")
    if not (1 <= int(axis) <= 180):
        raise ValueError("轴位必须在 1~180 之间")
    return int(axis)
