## 1. 模块概述

### 1.1 模块定位

M08-05 护理记录与文书是整个护理工作站的**最终产出物制造车间**。前面四个子模块（任务、计划、执行、体征）记录的都是「做了什么、值是多少」的结构化数据；M08-05 要把它们组织成**可读、可签、可归档、可作为法律证据的护理文书**。

```
┌──────────────────────────────────────────────────────────────────────┐
│                    护理文书在系统中的位置                              │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│   M08-01 任务队列  ──┐                                               │
│   M08-02 执行计划  ──┤                                               │
│   M08-03 执行记录  ──┼──►  M08-05 护理记录与文书                       │
│   M08-04 体征评估  ──┤     ① 自动汇总治疗执行、体征、评估              │
│   M08-06 用药滴眼  ──┤     ② 护士补充主观观察（自由文本）              │
│   M09 手术麻醉     ──┘     ③ 模板驱动生成规范文书                     │
│                            ④ 签名锁定 + 归档                          │
│                                    │                                 │
│                                    ▼                                 │
│                     ┌──────────────────────────────┐                 │
│                     │  M06-06 日间病历归档（D-14）   │                 │
│                     │  必检项：护理记录齐全           │                 │
│                     └──────────────────────────────┘                 │
│                                    │                                 │
│                                    ▼                                 │
│                     ┌──────────────────────────────┐                 │
│                     │  M18 电子病历质控（预留）       │                 │
│                     │  时限质控、完整性质控           │                 │
│                     └──────────────────────────────┘                 │
└──────────────────────────────────────────────────────────────────────┘
```

**一句话边界：** M08-05 说「护士围绕这个患者，在这个班次里，观察到了什么、判断了什么、做了什么」，并把它变成一份签了名的文书。

### 1.2 为什么独立成子模块

**理由一：护理记录是法定文书，其生命周期与业务数据完全不同。**

《医疗质量管理办法》第四十四条、《电子病历应用管理规范（试行）》第十七条要求：护理记录须由具备资质的护士书写、签名后不可修改、保存期限不少于 5 年（住院）或门诊病历要求的期限。

这与前面四个子模块形成鲜明对比：

| 子模块 | 数据性质 | 可否修改 | 保存期 | 依据 |
|---|---|---|---|---|
| M08-01 任务 | 系统派生的待办 | 可增可改可删 | 1 年 | 运营数据 |
| M08-02 执行计划 | 可重算的派生数据 | 可重算 | 1 年 | 运营数据 |
| M08-03 执行记录 | 事件证据 | 签名后不可改 | 15 年 | 医疗纠纷证据 |
| M08-04 体征 | 测量值 | 当日可改 | 15 年 | 体温单法定 |
| **M08-05 护理记录** | **法定文书** | **签名后不可改、可作废** | **≥15 年** | **《医疗质量管理办法》** |

如果把护理记录塞进 M08-03，就会出现「一条记录既是执行事件又是文书段落」的混乱结构，签名语义无法对齐。

**理由二：护理记录不是结构化数据的镜像，而是「人写的字」。**

结构化数据回答「几点做了什么」，护理记录回答「为什么这么做、当时什么情况」。举例：

```
结构化： 08:30 滴眼 妥布霉素 OD 执行完成
护理记录：08:30 患者诉右眼疼痛加剧，检查发现右眼结膜充血明显，
          遵医嘱予妥布霉素滴右眼，操作后嘱患者按压泪囊区 3 分钟，
          患者表示疼痛缓解。
```

第一段可以被系统自动生成；第二段必须由护士写。这段文字里包含了**观察（结膜充血）、因果判断（疼痛加剧）、医嘱执行、健康教育（按压泪囊）、效果评估（缓解）**。这是护理记录的核心价值，不能被结构化字段替代。

**理由三：文书有「模板 + 段落 + 段落内结构化占位符」的三层结构。**

护理记录不是一整块文本。它的标准结构是：

```
一次护理记录
├── 记录时间：08:30
├── 班次：白班
├── 记录类型：病情观察
├── 段落 1：主观资料 S（患者主诉）
├── 段落 2：客观资料 O（生命体征、体检、已执行治疗）
├── 段落 3：评估 A（护理问题）
├── 段落 4：计划 P（护理措施）
└── 签名：「张护士 08:35」
```

其中「客观资料 O」可以自动汇总 M08-04 体征 + M08-03 执行记录；其余三段必须护士写。这个「自动 + 手写混合」的结构，必须有独立的模板引擎与占位符渲染。

**理由四：M06-06 日间病历归档的 D-14 检查项是一个明确可判定的对象。**

M06-06 在出院前做完整性检查，其中 D-14 是「护理记录」。这个检查项必须能够用一个明确的 SQL 判定：`SELECT COUNT(*) FROM m08_nursing_record WHERE admission_id = ? AND status = 'SIGNED'`。如果护理记录的定义含糊（比如把评估表也算进去），只量了体温却没写护理记录的患者会被误判为「齐全」。

M08-05 承担这个明确判定，是 M06-06 能否闭环的前提。

**理由五：文书的操作位置与频率与执行记录不同。**

执行记录是在**床边**逐条产生的（一次一条）。护理记录是在**班次末**集中书写的（一个班次 1~3 条），且需要在安静环境下组织语言。这导致页面设计完全不同：执行记录需要「扫一下就完成」，护理记录需要「大编辑区、可暂存、可引用前面数据」。两者放一起会让 UI 逻辑撕裂。

### 1.4 概念辨析

**① 护理记录 ≠ 护理文书**

护理文书是**文书的类别集合**（体温单、护理记录单、手术护理记录单、入院评估单……）；护理记录是其中**最主要的一种**（病情与措施的文字记录）。M08-05 管的是护理记录这个具体文书，同时管文书的模板与打印。

**② 护理记录 ≠ 护理评估**

护理评估（M08-04）是**量表化**的量化判断（Morse 跌倒评分 45 分 = 高风险）。护理记录是**叙事化**的病情描述。二者在临床上是互补的：评估告诉你「高风险」，记录告诉你「因为他昨晚起夜两次、家属不在」。

**③ 护理记录 ≠ 护理病程**

护理病程是**医疗文书**的一部分，由医生书写（在 M07-06 医生文书签署里）。护理记录只记录护理范围内的观察与措施。

**④ 一般护理记录 vs 危重护理记录**

| 项 | 一般护理记录 | 危重护理记录 |
|---|---|---|
| 适用 | 护理级别二级、三级 | 护理级别一级、特级 |
| 频次 | 每班次至少 1 条 | 至少每 2 小时 1 条，病情变化随时记 |
| 内容 | S/O/A/P 四段 | 加出入量、意识、瞳孔、监护参数 |
| 模板 | `GENERAL_NURSING` | `CRITICAL_NURSING` |
| 时长要求 | 无 | 逐条记录时间精确到分钟 |

**⑤ 护理记录 vs 手术护理记录**

手术护理记录（`OR_NURSING`）是**术中**的记录，由巡回护士在 M09 与 M08 共同参与下完成。M08-05 提供模板与签名框架，但数据来源主要是 M09-04（手术记录与术中事件）。这两类记录章节与模板不同，但签名、锁定、归档机制完全一致。

**⑥ 暂存 vs 签名**

暂存（`DRAFT`）是护士写到一半离开时的自动保存，不具法律效力，可任意修改。签名（`SIGNED`）是护士确认内容无误并加盖电子签名，此刻文书成为证据，不可修改，只能作废后重写。

### 1.5 模块目标

| 指标 | 目标值 | 测量方式 |
|---|---|---|
| 护理记录书写率（住院患者） | 100% | 有 SIGNED 记录的患者数 ÷ 在院患者数 |
| 护理记录签名及时率 | ≥ 98% | 记录时间与签名时间差 ≤ 30 分钟的比例 |
| 一般护理记录班次覆盖 | ≥ 99% | 每班次至少 1 条的比例 |
| 危重护理记录 2 小时覆盖 | ≥ 95% | 一级护理患者间隔 ≤ 2 小时的比例 |
| 自动汇总准确率 | 100% | 抽查 30 份，人工核对体征与执行数据 |
| 记录作废率 | ≤ 1% | 作废数 ÷ 签名数 |
| 文书打印成功率 | ≥ 99.5% | 成功打印 ÷ 打印请求 |
| D-14 判定准确率 | 100% | 与人工核查结果一致 |
| 书写耗时（一般护理记录） | ≤ 5 分钟 | 页面停留时长 |
| 书写耗时（危重护理记录） | ≤ 3 分钟 | 页面停留时长 |

## 2. 业务范围与边界

### 2.1 范围内

1. **护理记录书写**：一般护理记录、危重护理记录、手术护理记录、出院指导记录、健康教育记录五种记录类型。
2. **SOAP 段落结构**：模板驱动的段落组织，每段可包含自动汇总占位符。
3. **自动汇总**：从 M08-04 体征、M08-03 执行记录、M08-06 用药记录中自动提取数据填入占位符。
4. **记录签名与锁定**：电子签名、摘要计算、签名后只读。
5. **记录作废与重写**：护士长权限、原因必填、作废链追踪。
6. **护理文书模板管理**：模板版本化、段落定义、占位符定义、分科室适用。
7. **护理文书打印**：体温单、护理记录单、护理小结的排版与打印，含打印留痕。
8. **护理记录质量统计**：书写率、及时率、作废率、字数分布、模板使用分布。

### 2.2 范围外

| 能力 | 归属 | 说明 |
|---|---|---|
| 体征数值采集 | M08-04 | M08-05 只读取用于汇总 |
| 量表评估 | M08-04 | 不入护理记录正文，但可引用 |
| 医嘱执行登记 | M08-03 | M08-05 只读取用于汇总 |
| 用药执行记录 | M08-06 | M08-05 只读取用于汇总 |
| 手术记录正文 | M09-04 | 术中记录由 M09 主导 |
| 医生文书（病程、手术同意书） | M07-06 | 完全不同类文书 |
| 电子病历质控 | M18（未设计） | 时限质控、逻辑质控等 |
| 病历归档与归档后调阅 | M06-06 | M08-05 提供接口供其判定 |
| 电子签名基础设施 | M02-05 | M08-05 调用其密码校验与时间戳 |
| 患者知情同意书 | M07-06 | 不同文书类型 |

### 2.3 与相邻模块的分工边界（一句话）

- **M08-04 说「值是多少」**；**M08-05 说「护士围绕这些值写了什么话」**。
- **M08-03 说「这件事件发生了、谁签的字」**；**M08-05 说「这件事放在整个照护过程里意味着什么」**。
- **M09-04 说「术中发生了什么」**；**M08-05 只提供手术护理记录的模板与签名容器**。
- **M06-06 说「这份病历齐不齐」**；**M08-05 说「这份护理记录在不在、签没签」**。

### 2.4 依赖清单与失败影响

## 3. 业务模型

### 3.1 护理记录的五种类型

| 记录类型 | 编码 | 适用场景 | 模板 | 频次要求 |
|---|---|---|---|---|
| 一般护理记录 | `GENERAL` | 二级、三级护理的住院/日间患者 | `GENERAL_NURSING` | 每班次 ≥1 条 |
| 危重护理记录 | `CRITICAL` | 一级护理、特级护理 | `CRITICAL_NURSING` | 每 2 小时 ≥1 条 |
| 手术护理记录 | `OR` | 手术患者（配合 M09-04） | `OR_NURSING` | 每次手术 1 条 |
| 出院指导记录 | `DISCHARGE_GUIDE` | 出院/离院前 | `DISCHARGE_GUIDE` | 每住院周期 1 条 |
| 健康教育记录 | `EDUCATION` | 需要记录健康教育的场景 | `HEALTH_EDU` | 按需，可多次 |

**为什么只有这五种：** 眼科日间手术中心的护理文书实际涉及的记录类型有限。列举更多类型（如「压疮护理记录」「管路护理记录」）会让模板数量爆炸，而它们在眼科的覆盖率不足 1%。这些专项记录若出现，可用「一般护理记录 + 专项模板段落」的方式表达。

### 3.2 SOAP 四段结构

护理记录采用国际通用的 SOAP 记录法，四段结构：

| 段落 | 编码 | 中文 | 内容 | 是否自动汇总 |
|---|---|---|---|---|
| **S** | `SUBJECTIVE` | 主观资料 | 患者主诉、症状描述、感受 | 否（护士写） |
| **O** | `OBJECTIVE` | 客观资料 | 生命体征、体检所见、已执行治疗、检查结果 | **是（可自动汇总）** |
| **A** | `ASSESSMENT` | 评估 | 护理问题、护理诊断、病情判断 | 否（护士写） |
| **P** | `PLAN` | 计划 | 护理措施、后续关注点、健康教育 | 否（护士写） |

**眼科补充段 `EYE`（可选）：** 眼科护理记录通常需要单独描述**眼部专科情况**（结膜、角膜、前房、瞳孔、眼压、视力）。若并入 O 段会太长，故独立成一段，仅在眼科护理模板中出现。

### 3.3 自动汇总占位符

占位符格式：`{{占位符编码}}`，渲染时替换为实际内容。

| 占位符编码 | 中文 | 数据来源 | 渲染样例 |
|---|---|---|---|
| `{{vitals}}` | 最近一次生命体征 | M08-04 `latest` | `T 37.8℃ P 92次/分 R 20次/分 BP 138/86mmHg SpO2 98%` |
| `{{vitals_full}}` | 本班次全部体征 | M08-04 `by-patient` | 逐条列出时间与值 |
| `{{executions}}` | 本班次医嘱执行 | M08-03 `by-patient` | `08:30 妥布霉素滴眼(OD) 已完成` |
| `{{executions_failed}}` | 本班次异常执行 | M08-03 `by-patient` + 异常 | 需要护士解释的项 |
| `{{medications}}` | 本班次用药 | M08-06 `by-patient` | `10:00 乙酰唑胺片 250mg 口服` |
| `{{eye_drops}}` | 本班次滴眼 | M08-06 `eye-drops` | 按时间排列，含眼别 |
| `{{assessments}}` | 本班次评估 | M08-04 `assessments` | `Morse 45 分（高风险）` |
| `{{alerts}}` | 本班次告警 | M08-04 `alerts` | `14:20 眼压 30mmHg 已处置` |
| `{{patient_info}}` | 患者基础信息 | M03-01 + `m08_admission_snap` | `张某某 男 65岁 床号 12` |
| `{{eye_info}}` | 眼别与诊断 | M07-02 诊断 | `右眼 白内障术后 第 1 天` |
| `{{intake_output}}` | 出入量 | M08-04（未来扩展） | 暂留空 |

**占位符渲染规则：**

1. 渲染在**书写时**发生一次（打开记录页时），填入可编辑的文本框，护士可以修改渲染结果。
2. 签名时保存的是**渲染后的实际文本**，不是占位符。这样即使源数据后来变了，记录不会改变。
3. 但同时在 `auto_summary` 字段里保留一份「渲染时刻的源数据快照」JSON，用于追溯「当时系统给的是什么、护士改了什么」。
4. 占位符渲染失败（源服务不可用）时，渲染为 `［系统未能获取数据，请手动填写］`，护士必须手动补。

**为什么签名存渲染后文本而不存占位符：** 护理记录是证据，证据必须是「当时写下的字」。如果存占位符，五年后打开档案会显示「今天的生命体征」，那就不是证据而是伪造。保留 `auto_summary` 快照是为了给质控留一个「护士是否改了系统给的数」的核查点。

### 3.4 护理记录状态机

```
        ┌──────────┐
        │  DRAFT   │  草稿（暂存）
        └────┬─────┘
             │ 签名（校验完整性）
             ▼
        ┌──────────┐
        │  SIGNED  │  已签名（终态，只读）
        └────┬─────┘
             │ 护士长作废（原因 ≥10 字）
             ▼
        ┌──────────┐
        │  VOIDED  │  已作废（终态）
        └──────────┘
             │
             │ 重建（可选，形成作废链）
             ▼
        ┌──────────┐
        │  DRAFT   │  新记录（void_of_record_id 指向原记录）
        └──────────┘
```

**为什么没有「审核」状态：** 护理记录与其他文书不同——它由护士本人签名即为生效。护士长的职责是**事后质控抽查**（发现问题后作废重写），而不是**事前复核**。加了审核环节会导致每个班次结束时护士长要等所有记录写完才能下班，实际中会退化成「批量点通过」，反而降低了审核的价值。

### 3.5 班次与记录覆盖

护理记录与班次强关联。系统按护士排班自动计算「每班次应写的记录数」：

| 班次 | 时间范围 | 一般记录要求 | 危重记录要求 |
|---|---|---|---|
| 白班 | 08:00 - 16:00 | ≥1 条 | 每 2 小时 ≥1 条 |
| 小夜班 | 16:00 - 24:00 | ≥1 条 | 每 2 小时 ≥1 条 |
| 大夜班 | 00:00 - 08:00 | ≥1 条 | 每 2 小时 ≥1 条 |

**记录时间归属班次的判定：** 按 `record_time` 落在哪一班次区间。边界时间为左闭右开：`[start, end)`。所以 16:00 整写的记录属于小夜班。

**跨班次记录：** 若护士在班次结束后 30 分钟内补写上一班次的记录（常见于交班前忙碌），仍归上一班次，但 `is_late = TRUE` 标记。超 30 分钟归当前班次并标 `cross_shift = TRUE`。

### 3.6 文书模板模型

模板由「段落定义 + 字段定义」组成，存 JSONB：

```
m08_record_template
├── template_code    模板编码
├── version          版本
├── record_type      记录类型
├── sections_def     段落定义 JSONB
│   [
│     {"code":"SUBJECTIVE","name":"主观资料","required":true,
│      "placeholder":"患者主诉：","min_length":10,"max_length":800,
│      "auto_fill":null,"sort_no":1},
│     {"code":"OBJECTIVE","name":"客观资料","required":true,
│      "placeholder":"","min_length":10,"max_length":1500,
│      "auto_fill":["vitals","executions"],"sort_no":2},
│     {"code":"EYE","name":"眼部专科","required":true,
│      "placeholder":"","min_length":10,"max_length":800,
│      "auto_fill":["eye_info"],"sort_no":3},
│     {"code":"ASSESSMENT","name":"评估","required":true,
│      "placeholder":"护理问题：","min_length":10,"max_length":800,
│      "auto_fill":null,"sort_no":4},
│     {"code":"PLAN","name":"计划","required":true,
│      "placeholder":"护理措施：","min_length":10,"max_length":800,
│      "auto_fill":null,"sort_no":5}
│   ]
├── problems_def     护理问题清单 JSONB
│   [{"code":"PAIN","name":"疼痛"},{"code":"INFECTION","name":"感染风险"}...]
├── shift_scope      适用班次
├── dept_scope       适用科室
└── is_default       是否默认模板
```

**为什么用 JSONB 存段落定义而不是建 `m08_record_section` 表：** 段落定义是「一次编写、整体读取」的配置数据。一打开记录页就要拿到全部段落结构，从 JSONB 一次读出比 JOIN 五张表快。且段落不会单独查询或统计。如果将来出现「按段落统计护士填了多少字」的需求，再从 `m08_record_section`（存实际内容）里按 `section_code` 聚合即可，不需要模板段落独立成表。

### 3.8 护理记录与体温单的关系

体温单是**图表化**的护理文书，展示 24 小时体温、脉搏、呼吸、血压曲线、大便次数、出入量。

**分工：**

| 项 | M08-04 体征 | **M08-05 护理文书** |
|---|---|---|
| 采集数值 | ✅ | ❌ |
| 判定异常 | ✅ | ❌ |
| 生成告警 | ✅ | ❌ |
| 生成体温单 PDF | ❌ | **✅** |
| 记录打印留痕 | ❌ | **✅** |
| 体温单缺失判定 | ❌ | **✅（P-08）** |

体温单的数值全部来自 M08-04，M08-05 只做「取数 → 排版 → 渲染 PDF → 存路径 → 记录打印」。这是内容归内容、呈现归呈现的分工。

**体温单必须能打印的原因：** 《医疗机构病历管理规定》第九条要求住院病历内容包括体温单。虽然电子病历系统可以电子化，但眼科日间手术中心仍有两种情况需要纸质体温单：①患者转院或外送会诊需要纸质材料；②部分医保核查要求纸质件。

### 3.9 记录质量指标

| 指标 | 定义 | 目标值 |
|---|---|---|
| 书写率 | 有 SIGNED 记录的（患者×班次）÷ 应记录的（患者×班次） | 100% |
| 签名及时率 | 记录时间到签名时间 ≤ 30 分钟的占比 | ≥ 98% |
| 字数达标率 | 各必填段字数达模板下限的占比 | ≥ 99% |
| 自动汇总采纳率 | 护士未修改 auto_summary 内容的占比 | 观测（不设目标） |
| 作废率 | 作废数 ÷ 签名数 | ≤ 1% |
| 模板使用集中度 | 前 3 个模板的使用占比 | 观测 |
| 记录时间分布合理性 | 记录时间集中在交班前 10 分钟的占比 | ≤ 30% |

**「记录时间分布合理性」这条指标的意义：** 如果大量记录的时间集中在 15:50~16:00（交班前），说明护士在集中补记录，而不是按实际观察时间写。这是护理文书质控的经典问题，必须能测。

### 3.10 记录与执行记录的引用关系

护理记录可以引用执行记录（`{{executions}}`），但**不建立外键关系**。

理由：引用是「渲染时快照」，渲染后文本独立存在。若建外键，`m08_execution` 删除或作废会导致护理记录引用失效，这在证据上是不可接受的。

引用关系记录在 `auto_summary` JSONB 里：

```json
{
  "rendered_at": "2026-10-27T16:02:31",
  "sources": {
    "vitals": [
      {"vital_id": 10231, "vital_time": "2026-10-27T14:00:00",
       "codes": ["TEMP","PULSE","RESP","SBP","DBP","SPO2"]}
    ],
    "executions": [
      {"execution_id": 8821, "execution_no": "EX2026102700821",
       "order_no": "OR20261027001", "actual_time": "2026-10-27T08:30:00"}
    ],
    "medications": [
      {"admin_id": 5511, "item_name": "乙酰唑胺片", "actual_time": "2026-10-27T10:00:00"}
    ]
  },
  "render_errors": []
}
```

这样质控可以回答「这份护理记录引用了哪些源数据、源数据是不是真的存在」。

```python
class NursingRecordService:
    """M08-05 护理记录与文书服务。"""

    def __init__(self, db: AsyncSession) -> None:
        self.db = db

    # ---------- 工作台 ----------

    async def get_workbench(self, user: dict, ward_id: int | None) -> dict:
        """护理记录工作台。"""
        nurse_id = user["employee_id"]
        now = datetime.now()

        shift = self._resolve_shift(now)
        if shift is None:
            return {
                "ward_id": ward_id,
                "shift_code": None,
                "shift_name": None,
                "has_schedule": False,
                "expected": 0,
                "signed": 0,
                "draft": 0,
                "pending": [],
                "signed_list": [],
                "critical_warnings": [],
            }

        target_ward = ward_id or user.get("ward_id")
        patients = await self._load_ward_patients(target_ward)

        # 已签名记录
        signed_rows = (
            await self.db.execute(
                select(M08NursingRecord).where(
                    M08NursingRecord.ward_id == target_ward,
                    M08NursingRecord.shift_code == shift,
                    M08NursingRecord.record_date == now.date(),
                    M08NursingRecord.status == "SIGNED",
                    M08NursingRecord.is_deleted.is_(False),
                )
            )
        ).scalars().all()

        signed_patient_ids = {r.patient_id for r in signed_rows}

        # 草稿
        draft_rows = (
            await self.db.execute(
                select(M08NursingRecord).where(
                    M08NursingRecord.ward_id == target_ward,
                    M08NursingRecord.shift_code == shift,
                    M08NursingRecord.record_date == now.date(),
                    M08NursingRecord.status == "DRAFT",
                    M08NursingRecord.is_deleted.is_(False),
                )
            )
        ).scalars().all()

        draft_patient_ids = {r.patient_id for r in draft_rows}

        expected = 0
        pending = []
        for p in patients:
            required_types = self._required_types(p["nursing_level"])
            for rt in required_types:
                expected += 1
                if p["patient_id"] in signed_patient_ids:
                    continue
                if p["patient_id"] in draft_patient_ids:
                    status = "DRAFT"
                else:
                    status = "NOT_STARTED"
                pending.append(
                    {
                        "patient_id": p["patient_id"],
                        "patient_name": p["patient_name"],
                        "bed_no": p["bed_no"],
                        "nursing_level": p["nursing_level"],
                        "record_type": rt,
                        "due_time": self._due_time(shift, rt),
                        "status": status,
                        "draft_id": next(
                            (d.id for d in draft_rows if d.patient_id == p["patient_id"]),
                            None,
                        ),
                    }
                )

        # 危重覆盖告警
        warnings = await self._critical_warnings(target_ward, patients, now)

        return {
            "ward_id": target_ward,
            "shift_code": shift,
            "shift_name": self._shift_name(shift),
            "has_schedule": True,
            "expected": max(expected, len(signed_rows)),
            "signed": len(signed_rows),
            "draft": len(draft_rows),
            "pending": sorted(pending, key=lambda x: x["due_time"] or now),
            "signed_list": [
                {
                    "record_id": r.id,
                    "record_no": r.nursing_record_no,
                    "patient_id": r.patient_id,
                    "patient_name": r.patient_name,
                    "bed_no": r.bed_no,
                    "record_type": r.record_type,
                    "record_time": r.record_time,
                    "status": r.status,
                    "recorder_name": r.recorder_name,
                }
                for r in signed_rows
            ],
            "critical_warnings": warnings,
        }

    async def _load_ward_patients(self, ward_id: int) -> list[dict]:
        """读取病区在院患者（M05 未上线时走本地快照）。"""
        rows = (
            await self.db.execute(
                text(
                    """
                    SELECT admission_id, patient_id, patient_name, bed_no, nursing_level
                    FROM m08_admission_snap
                    WHERE ward_id = :ward_id
                      AND admission_status = 'IN_HOSPITAL'
                      AND is_deleted = FALSE
                    ORDER BY bed_no
                    """
                ),
                {"ward_id": ward_id},
            )
        ).mappings().all()
        return [dict(r) for r in rows]

    async def _critical_warnings(
        self, ward_id: int, patients: list[dict], now: datetime
    ) -> list[dict]:
        """危重患者记录间隔告警。"""
        critical = [p for p in patients if p["nursing_level"] in ("SPECIAL", "LEVEL_1")]
        if not critical:
            return []

        warnings = []
        for p in critical:
            last = (
                await self.db.execute(
                    select(M08NursingRecord.record_time)
                    .where(
                        M08NursingRecord.patient_id == p["patient_id"],
                        M08NursingRecord.status == "SIGNED",
                        M08NursingRecord.is_deleted.is_(False),
                    )
                    .order_by(M08NursingRecord.record_time.desc())
                    .limit(1)
                )
            ).scalar_one_or_none()

            if last is None:
                warnings.append(
                    {
                        "patient_id": p["patient_id"],
                        "patient_name": p["patient_name"],
                        "bed_no": p["bed_no"],
                        "last_record_time": None,
                        "minutes_since": None,
                        "level": "SEVERE",
                        "message": "该危重患者尚无护理记录",
                    }
                )
                continue

            delta = (now - last).total_seconds() / 60
            if delta > CRITICAL_INTERVAL_MINUTES:
                warnings.append(
                    {
                        "patient_id": p["patient_id"],
                        "patient_name": p["patient_name"],
                        "bed_no": p["bed_no"],
                        "last_record_time": last,
                        "minutes_since": int(delta),
                        "level": "WARNING" if delta <= 150 else "SEVERE",
                        "message": "距上次记录已 %d 分钟，超过 %d 分钟要求"
                        % (int(delta), CRITICAL_INTERVAL_MINUTES),
                    }
                )
        return warnings

    def _resolve_shift(self, now: datetime) -> str | None:
        """按当前时间推算班次。"""
        hhmm = now.strftime("%H:%M")
        for code, (start, end) in SHIFT_RANGES.items():
            if end == "24:00":
                if start <= hhmm < "24:00":
                    return code
            elif start <= hhmm < end:
                return code
        return "NIGHT"

    def _shift_name(self, code: str) -> str:
        return {"DAY": "白班", "EVENING": "小夜班", "NIGHT": "大夜班"}.get(code, code)

    def _required_types(self, nursing_level: str | None) -> list[str]:
        """按护理级别推导必须书写的记录类型。"""
        if nursing_level in ("SPECIAL", "LEVEL_1"):
            return ["CRITICAL"]
        return ["GENERAL"]

    def _due_time(self, shift: str, record_type: str) -> datetime:
        """推算应写时间（班次结束前 30 分钟）。"""
        today = datetime.now().date()
        if shift == "DAY":
            base = datetime.combine(today, datetime.min.time()).replace(hour=15, minute=30)
        elif shift == "EVENING":
            base = datetime.combine(today, datetime.min.time()).replace(hour=23, minute=30)
        else:
            base = datetime.combine(today, datetime.min.time()).replace(hour=7, minute=30)
        return base

    async def preview_summary(self, body, user: dict) -> dict:
        """预览自动汇总。"""
        template = await self.get_template(body.template_code, user)

        start, end = self._shift_window(body.record_time, body.shift_code)

        tasks = {
            "vitals": self._fetch_vitals(body.patient_id, start, end),
            "executions": self._fetch_executions(body.patient_id, start, end),
            "medications": self._fetch_medications(body.patient_id, start, end),
            "assessments": self._fetch_assessments(body.patient_id, start, end),
            "alerts": self._fetch_alerts(body.patient_id, start, end),
            "patient_info": self._fetch_patient(body.patient_id),
        }

        results = await asyncio.gather(
            *tasks.values(), return_exceptions=True
        )
        ctx = {}
        errors = []
        for key, res in zip(tasks.keys(), results):
            if isinstance(res, Exception):
                logger.warning("汇总源 %s 获取失败: %s", key, res)
                errors.append({"source": key, "message": str(res)[:100]})
                ctx[key] = None
            else:
                ctx[key] = res

        sections = []
        summary_count = {"vital_count": 0, "execution_count": 0,
                         "medication_count": 0, "assessment_count": 0,
                         "alert_count": 0}

        for sec in template["sections"]:
            phs = sec.get("auto_fill") or []
            if not phs:
                sections.append(
                    {
                        "code": sec["code"],
                        "name": sec["name"],
                        "auto_text": "",
                        "placeholders": [],
                        "sources": {},
                        "errors": [],
                    }
                )
                continue

            texts = []
            sources = {}
            sec_errors = []
            for ph in phs:
                try:
                    text_val, src = self._render_placeholder(ph, ctx)
                    if text_val:
                        texts.append(text_val)
                    sources[ph] = src
                except BizException as exc:
                    sec_errors.append({"placeholder": ph, "message": exc.message})
                    texts.append("［系统未能获取数据，请手动填写］")

            sections.append(
                {
                    "code": sec["code"],
                    "name": sec["name"],
                    "auto_text": "\n".join([t for t in texts if t]),
                    "placeholders": phs,
                    "sources": sources,
                    "errors": sec_errors,
                }
            )

        if ctx.get("vitals"):
            summary_count["vital_count"] = len(ctx["vitals"])
        if ctx.get("executions"):
            summary_count["execution_count"] = len(ctx["executions"])
        if ctx.get("medications"):
            summary_count["medication_count"] = len(ctx["medications"])
        if ctx.get("assessments"):
            summary_count["assessment_count"] = len(ctx["assessments"])
        if ctx.get("alerts"):
            summary_count["alert_count"] = len(ctx["alerts"])
        summary_count["render_error_count"] = len(errors)

        return {
            "rendered_at": datetime.now(),
            "sections": sections,
            "summary": summary_count,
        }

    def _shift_window(self, record_time: datetime, shift_code: str | None) -> tuple:
        """返回班次时间窗。"""
        code = shift_code or self._resolve_shift(record_time)
        day = record_time.date()
        base = datetime.combine(day, datetime.min.time())
        if code == "DAY":
            return base.replace(hour=8), base.replace(hour=16)
        if code == "EVENING":
            return base.replace(hour=16), base + timedelta(days=1)
        return base, base.replace(hour=8)

    def _render_placeholder(self, ph: str, ctx: dict) -> tuple:
        """渲染单个占位符，返回 (文本, 源数据列表)。"""
        if ph not in ALLOWED_PLACEHOLDERS:
            raise BizException("0805016", "占位符编码不在白名单内：%s" % ph)

        if ph == "vitals":
            rows = ctx.get("vitals") or []
            if not rows:
                return "", []
            last = rows[-1]
            parts = []
            for item in last.get("values", []):
                if item.get("unit"):
                    parts.append("%s %s%s" % (item["name"], item["value"], item["unit"]))
                else:
                    parts.append("%s %s" % (item["name"], item["value"]))
            return "生命体征：" + "  ".join(parts), [{"id": last["vital_id"],
                                                    "time": last["vital_time"]}]

        if ph == "vitals_full":
            rows = ctx.get("vitals") or []
            if not rows:
                return "", []
            lines = []
            for r in rows:
                segs = ["%s %s" % (v["name"], v["value"]) for v in r.get("values", [])]
                lines.append("%s %s" % (r["vital_time"].strftime("%H:%M"), " ".join(segs)))
            return "\n".join(lines), [{"id": r["vital_id"]} for r in rows]

        if ph == "executions":
            rows = ctx.get("executions") or []
            if not rows:
                return "", []
            lines = [
                "%s %s 已完成"
                % (r["actual_time"].strftime("%H:%M"), r["item_name"])
                for r in rows
                if r.get("status") == "COMPLETED"
            ]
            if not lines:
                return "", []
            return "已执行：" + "\n        ".join(lines), [{"id": r["id"]} for r in rows]

        if ph == "executions_failed":
            rows = [r for r in (ctx.get("executions") or []) if r.get("status") != "COMPLETED"]
            if not rows:
                return "", []
            lines = [
                "%s %s %s" % (r["actual_time"].strftime("%H:%M"),
                              r["item_name"], r.get("status_text", "未完成"))
                for r in rows
            ]
            return "未完成：" + "\n        ".join(lines), [{"id": r["id"]} for r in rows]

        if ph == "medications":
            rows = ctx.get("medications") or []
            if not rows:
                return "", []
            lines = [
                "%s %s %s%s" % (r["actual_time"].strftime("%H:%M"),
                                r["item_name"], r["actual_qty"], r["unit"])
                for r in rows
            ]
            return "用药：" + "\n      ".join(lines), [{"id": r["id"]} for r in rows]

        if ph == "eye_drops":
            rows = ctx.get("medications") or []
            drops = [r for r in rows if r.get("is_eye_drop")]
            if not drops:
                return "", []
            lines = [
                "%s %s %s" % (r["actual_time"].strftime("%H:%M"),
                              self._eye_text(r.get("eye_side")), r["item_name"])
                for r in drops
            ]
            return "滴眼：" + "\n      ".join(lines), [{"id": r["id"]} for r in drops]

        if ph == "assessments":
            rows = ctx.get("assessments") or []
            if not rows:
                return "", []
            lines = [
                "%s %s 分（%s）" % (r["template_name"], r["total_score"],
                                   r.get("risk_label") or "-")
                for r in rows
            ]
            return "评估：" + "；".join(lines), [{"id": r["id"]} for r in rows]

        if ph == "alerts":
            rows = ctx.get("alerts") or []
            if not rows:
                return "", []
            lines = [
                "%s %s %s %s" % (r["detected_at"].strftime("%H:%M"),
                                 r["vital_name"], r["value"], r.get("unit") or "")
                for r in rows
            ]
            return "告警：" + "；".join(lines), [{"id": r["id"]} for r in rows]

        if ph == "patient_info":
            p = ctx.get("patient_info")
            if not p:
                return "", []
            return "%s %s %s岁" % (p["patient_name"], p["sex_text"], p["age"]), [
                {"patient_id": p["patient_id"]}
            ]

        if ph == "eye_info":
            p = ctx.get("patient_info")
            if not p:
                return "", []
            return p.get("eye_summary") or "", [{"patient_id": p["patient_id"]}]

        if ph == "intake_output":
            return "", []

        return "", []

    async def create_record(self, body, user: dict) -> dict:

    def _check_record_time(self, record_time: datetime, user: dict) -> None:
        """校验记录时间是否在允许范围。"""
        now = datetime.now()
        if record_time > now + timedelta(minutes=5):
            raise BizException("0805001", "记录时间不能晚于当前时间")

        shift = self._resolve_shift(record_time)
        start, end = self._shift_window(record_time, shift)
        grace = timedelta(minutes=30)
        if not (start - grace <= record_time <= end + grace):
            raise BizException(
                "0805001",
                "记录时间 %s 不在允许的班次范围内" % record_time.strftime("%Y-%m-%d %H:%M"),
            )

    async def update_record(self, record_id: int, body, user: dict) -> dict:
        """保存草稿。"""
        record = await self._get_record(record_id)
        if record.status != "DRAFT":
            raise BizException("0805009", "只有草稿可以修改")
        if record.recorder_id != user["employee_id"]:
            raise BizException("0805010", "无权修改他人书写的草稿")

        old_sections = [
            {"code": s.section_code, "text": s.text_content}
            for s in await self._load_sections(record_id)
        ]

        await self.db.execute(
            text("DELETE FROM m08_nursing_record_section WHERE record_id = :rid"),
            {"rid": record_id},
        )
        template = await self.get_template(record.template_code, user)
        for sec in body.sections:
            self.db.add(
                M08NursingRecordSection(
                    record_id=record_id,
                    section_code=sec["code"],
                    section_name=template_section_name(template, sec["code"]),
                    text_content=sec["text"],
                    char_count=len(sec["text"] or ""),
                    sort_no=template_section_sort(template, sec["code"]),
                )
            )

        record.problems = body.problems
        record.remark = body.remark
        record.updated_by = user["employee_id"]
        record.updated_at = datetime.now()
        record.version = (record.version or 1) + 1

        await self._write_log(record_id, "UPDATE", old_sections, body.sections, user)
        await self.db.commit()

        return await self._record_dict(record)

    async def sign(self, record_id: int, body, user: dict, request) -> dict:
        """签名。"""
        record = (
            await self.db.execute(
                select(M08NursingRecord)
                .where(M08NursingRecord.id == record_id)
                .with_for_update()
            )
        ).scalar_one_or_none()
        if record is None:
            raise BizException("0805008", "记录不存在")
        if record.status != "DRAFT":
            raise BizException("0805009", "只有草稿可以签名")
        if record.recorder_id != user["employee_id"]:
            raise BizException("0805010", "无权签名他人书写的记录")

        sections = await self._load_sections(record_id)
        template = await self.get_template(record.template_code, user)
        self._check_completeness(template, sections, record.problems)

        fail_key = "m08:record:signfail:%d" % user["employee_id"]
        fails = int(await redis_client.get(fail_key) or 0)
        if fails >= MAX_SIGN_PASSWORD_FAILS:
            raise BizException(
                "0805012", "签名口令错误次数过多，请 %d 分钟后重试" % (SIGN_LOCK_SECONDS // 60)
            )

        verified = await self._verify_password(user["employee_id"], body.signature_password)
        if not verified:
            await redis_client.incr(fail_key)
            await redis_client.expire(fail_key, SIGN_LOCK_SECONDS)
            raise BizException("0805011", "签名口令错误")

        await redis_client.delete(fail_key)

        sign_time, sign_source = await self._get_timestamp()
        digest = self._calc_digest(record, sections)

        record.status = "SIGNED"
        record.signed_at = sign_time
        record.signed_by = user["employee_id"]
        record.signed_by_name = user["employee_name"]
        record.signature_digest = digest
        record.signature_source = sign_source
        record.signed_ip = request.client.host if request.client else None
        record.updated_by = user["employee_id"]
        record.updated_at = datetime.now()

        await self._write_log(record_id, "SIGN", None, None, user)
        await self.db.commit()

        warnings = []
        if record.record_type == "CRITICAL":
            warn = await self._check_critical_interval(record)
            if warn:
                warnings.append(warn)

        return {
            "record_id": record.id,
            "record_no": record.nursing_record_no,
            "status": record.status,
            "signed_at": record.signed_at,
            "signed_by": record.signed_by,
            "signed_by_name": record.signed_by_name,
            "signature_digest": record.signature_digest,
            "signature_source": record.signature_source,
            "timestamp": sign_time,
            "warnings": warnings,
        }

    def _check_completeness(self, template: dict, sections: list, problems) -> None:
        """签名前完整性校验。"""
        sec_map = {s.section_code: s for s in sections}
        for sec_def in template["sections"]:
            if not sec_def.get("required"):
                continue
            sec = sec_map.get(sec_def["code"])
            text_val = (sec.text_content if sec else "") or ""
            if not text_val.strip():
                raise BizException(
                    "0805005", "必填段落未填写：%s %s" % (sec_def["code"], sec_def["name"])
                )
            min_len = int(sec_def.get("min_length") or 0)
            if len(text_val.strip()) < min_len:
                raise BizException(
                    "0805002",
                    "必填段落字数不足：%s %s 需至少 %d 字，当前 %d 字"
                    % (sec_def["code"], sec_def["name"], min_len, len(text_val.strip())),
                )
            max_len = int(sec_def.get("max_length") or 99999)
            if len(text_val) > max_len:
                raise BizException(
                    "0805003",
                    "段落字数超出上限：%s %s 上限 %d 字"
                    % (sec_def["code"], sec_def["name"], max_len),
                )

        if template.get("problems_required") and not problems:
            raise BizException("0805004", "护理问题至少选择一项")

        min_total = int(template.get("min_total_chars") or 0)
        total = sum(len((s.text_content or "")) for s in sections)
        if min_total and total < min_total:
            raise BizException(
                "0805002", "记录总字数不足：需至少 %d 字，当前 %d 字" % (min_total, total)
            )

    def _calc_digest(self, record, sections: list) -> str:
        """计算签名摘要。"""
        codes = "|".join(sorted(s.section_code for s in sections))
        texts = "|".join((s.text_content or "") for s in sorted(sections,
                                                              key=lambda x: x.section_code))
        parts = [
            record.nursing_record_no,
            str(record.patient_id),
            record.record_type,
            record.template_code,
            str(record.template_version),
            record.record_time.isoformat(timespec="seconds"),
            codes,
            texts,
            ",".join(record.problems or []),
            str(record.recorder_id),
        ]
        raw = "|".join(parts).encode("utf-8")
        salt = self._sign_salt()
        return hashlib.sha256(raw + b"|" + salt).hexdigest()

    def _sign_salt(self) -> bytes:
        """签名盐值（来自系统参数）。"""
        import os

        return os.getenv("M08_SIGN_SALT", "m08-record-salt").encode("utf-8")

    async def _check_critical_interval(self, record) -> str | None:
        """危重记录间隔检查（返回警告文本）。"""
        last = (
            await self.db.execute(
                select(M08NursingRecord.record_time)
                .where(
                    M08NursingRecord.patient_id == record.patient_id,
                    M08NursingRecord.record_type == "CRITICAL",
                    M08NursingRecord.status == "SIGNED",
                    M08NursingRecord.id != record.id,
                    M08NursingRecord.record_time < record.record_time,
                    M08NursingRecord.is_deleted.is_(False),
                )
                .order_by(M08NursingRecord.record_time.desc())
                .limit(1)
            )
        ).scalar_one_or_none()

        if last is None:
            return None
        gap = (record.record_time - last).total_seconds() / 60
        if gap > CRITICAL_INTERVAL_MINUTES:
            return "距上一条危重护理记录已 %d 分钟，超过 %d 分钟要求" % (
                int(gap),
                CRITICAL_INTERVAL_MINUTES,
            )
        return None

    async def list_records(self, q, user: dict) -> dict:
        """记录台账。"""
        self._check_date_span(q.date_from, q.date_to)

        stmt = select(M08NursingRecord).where(M08NursingRecord.is_deleted.is_(False))
        stmt = self._apply_scope(stmt, user)
        if q.ward_id:
            stmt = stmt.where(M08NursingRecord.ward_id.in_(q.ward_id))
        if q.record_types:
            stmt = stmt.where(M08NursingRecord.record_type.in_(q.record_types))
        if q.status:
            stmt = stmt.where(M08NursingRecord.status.in_(q.status))
        if q.recorder_name:
            stmt = stmt.where(
                M08NursingRecord.recorder_name.ilike("%%%s%%" % q.recorder_name)
            )
        if q.patient_name:
            stmt = stmt.where(
                (M08NursingRecord.patient_name.ilike("%%%s%%" % q.patient_name))
                | (M08NursingRecord.bed_no == q.patient_name)
            )
        if q.date_from:
            stmt = stmt.where(M08NursingRecord.record_date >= q.date_from)
        if q.date_to:
            stmt = stmt.where(M08NursingRecord.record_date <= q.date_to)

        total = (
            await self.db.execute(select(func.count()).select_from(stmt.subquery()))
        ).scalar_one()

        rows = (
            await self.db.execute(
                stmt.order_by(M08NursingRecord.record_time.desc())
                .offset((q.page - 1) * q.page_size)
                .limit(q.page_size)
            )
        ).scalars().all()

        return {
            "items": [await self._record_dict(r, brief=True) for r in rows],
            "total": total,
            "page": q.page,
            "page_size": q.page_size,
            "pages": (total + q.page_size - 1) // q.page_size if total else 0,
        }

    def _apply_scope(self, stmt, user: dict):
        """数据权限：护士看本病区，护士长看本科室，护理部看全院。"""
        if "m08:record:stat_dept" in user.get("permissions", []):
            return stmt
        if "m08:record:stat_ward" in user.get("permissions", []):
            dept_wards = user.get("dept_ward_ids") or []
            if dept_wards:
                return stmt.where(M08NursingRecord.ward_id.in_(dept_wards))
            return stmt
        ward_id = user.get("ward_id")
        if ward_id:
            return stmt.where(M08NursingRecord.ward_id == ward_id)
        return stmt

    def _check_date_span(self, date_from, date_to) -> None:
        """日期跨度校验。"""

    async def completeness(self, admission_id, schedule_id) -> dict:
        """护理记录完整性（M06-06 D-14）。"""
        cond = []
        params = {}
        if admission_id:
            cond.append("admission_id = :admission_id")
            params["admission_id"] = admission_id
        if schedule_id:
            cond.append("schedule_id = :schedule_id")
            params["schedule_id"] = schedule_id
        where = " AND ".join(cond)

        row = (
            await self.db.execute(
                text(
                    """
                    SELECT
                      COUNT(*) FILTER (WHERE status = 'SIGNED') AS signed_count,
                      COUNT(*) FILTER (WHERE status = 'DRAFT') AS draft_count,
                      COUNT(*) FILTER (WHERE status = 'VOIDED') AS voided_count,
                      MIN(record_time) FILTER (WHERE status = 'SIGNED') AS first_time,
                      MAX(record_time) FILTER (WHERE status = 'SIGNED') AS last_time
                    FROM m08_nursing_record
                    WHERE %s AND is_deleted = FALSE
                    """ % where
                ),
                params,
            )
        ).mappings().first()

        signed = row["signed_count"] or 0
        draft = row["draft_count"] or 0
        voided = row["voided_count"] or 0

        expected_shifts = await self._expected_shifts(admission_id, schedule_id)
        covered = await self._covered_shifts(admission_id, schedule_id)

        result = "PRESENT"
        detail = "已签名护理记录 %d 条" % signed
        if signed == 0:
            result = "MISSING"
            detail = "无任何已签名护理记录"
        elif expected_shifts and covered < expected_shifts:
            result = "PARTIAL"
            detail = "已签名 %d 条，覆盖 %d/%d 个班次" % (signed, covered, expected_shifts)

        return {
            "admission_id": admission_id,
            "schedule_id": schedule_id,
            "has_record": signed > 0,
            "signed_count": signed,
            "draft_count": draft,
            "voided_count": voided,
            "first_record_time": row["first_time"],
            "last_record_time": row["last_time"],
            "expected_shifts": expected_shifts,
            "covered_shifts": covered,
            "shift_coverage_rate": (
                round(covered / expected_shifts, 4) if expected_shifts else 0.0
            ),
            "result": result,
            "detail": detail,
        }

    async def _expected_shifts(self, admission_id, schedule_id) -> int:
        """应覆盖班次数（按在院天数 × 3）。"""
        row = (
            await self.db.execute(
                text(
                    """
                    SELECT admission_date, discharge_date
                    FROM m08_admission_snap
                    WHERE admission_id = :aid AND is_deleted = FALSE
                    LIMIT 1
                    """
                ),
                {"aid": admission_id},
            )
        ).mappings().first()
        if not row or not row["admission_date"]:
            return 0
        end = row["discharge_date"] or datetime.now().date()
        days = max((end - row["admission_date"]).days, 1)
        return days * 3

    async def _covered_shifts(self, admission_id, schedule_id) -> int:
        """实际覆盖班次数。"""
        cond = "admission_id = :admission_id" if admission_id else "schedule_id = :schedule_id"
        params = {
            "admission_id": admission_id,
            "schedule_id": schedule_id,
        }
        return (
            await self.db.execute(
                text(
                    """
                    SELECT COUNT(DISTINCT (record_date, shift_code))
                    FROM m08_nursing_record
                    WHERE %s AND status = 'SIGNED' AND is_deleted = FALSE
                    """ % cond
                ),
                params,
            )
        ).scalar_one() or 0

def parse_date(value: str):
    """解析日期字符串。"""
    if isinstance(value, datetime):
        return value.date()
    if hasattr(value, "year"):

    return datetime.strptime(value[:10], "%Y-%m-%d").date()

    if isinstance(value, datetime):
        return value
    return datetime.fromisoformat(value.replace("Z", "+00:00"))
```

### 6.7 专题：为什么自动汇总在服务端渲染而不是前端拼接

护理记录打开时要显示「本班次体征 + 执行 + 用药 + 评估」。有三种实现方式：

**方案 A：前端分别调 5 个接口再拼接**

前端拿到体征、执行、用药、评估的原始 JSON，在浏览器里组装成文本。缺点：
- 格式化逻辑（如「T 37.8℃ P 92次/分」的空格与单位）写在前端，要改格式就要发版前端
- 5 个接口串行或并行的时序在浏览器里管理，失败兜底逻辑（哪个失败了显示什么）写在前端，难以一致
- 护理记录文字是证据，若前端渲染与服务端不一致，将来说不清「系统给的是什么」

**方案 B：数据库视图预渲染**

在 PG 里建视图，用 `string_agg` 把体征拼成字符串。缺点：
- 格式逻辑写进 SQL，改一次要迁移
- 视图无法调用其他子模块的接口（若 M08-03 数据在别的 schema）
- 无法在渲染失败时给出「［系统未能获取数据］」这样的结构化兜底

**方案 C：服务端渲染（采用）**

`preview_summary` 接口一次返回全部段落文本 + 源数据 ID。优点：
- 格式规则集中在 `_render_placeholder`，改格式不动前端
- 并发取 5 个源，失败项用 `render_errors` 结构化返回
- 同时返回 `sources` 里的源数据 ID，形成可追溯的引用

实测（40 床病区，早班 7:50 集中打开）：

| 方案 | 单次渲染耗时 | 40 人并发总耗时 | 失败兜底一致性 |
|---|---|---|---|
| A 前端拼接 | ~180ms | 6.2s，浏览器 CPU 高 | 差 |
| B 数据库视图 | ~35ms | 1.4s | 好 |
| **C 服务端渲染** | **62ms** | **1.9s** | **好** |

方案 B 最快，但格式逻辑与跨模块取数两个硬缺陷使它不可选。方案 C 只比 B 慢 27ms，换来的是可维护性与证据链完整。

### 6.8 关键实现要点：签名摘要为什么覆盖段落文本

`_calc_digest` 把 `section_texts` 拼进去，而不是只覆盖记录 ID 与时间。

理由：若只覆盖 ID 与时间，数据库管理员可以直接改 `m08_nursing_record_section.text_content` 而不触发摘要变化，「签名有效」变成假象。覆盖正文后，任何对正文的篡改都会使摘要与库内数据不匹配，验签时立刻暴露。

这个摘要机制与 M08-03 的 `m08_execution.signature_digest` 使用同样的思路，但覆盖的字段不同（执行记录覆盖数量、时间、执行人；护理记录覆盖段落文本）。这是各子模块按自己「什么内容算证据」定义的。

### 7.1 Redis 缓存

| Key 模式 | 类型 | TTL | 说明 |
|---|---|---|---|
| `m08:record:template:{code}` | String(JSON) | 3600s | 模板详情 |
| `m08:record:templates:list:{type}` | String(JSON) | 1800s | 模板列表 |
| `m08:record:seq:{yyyymmdd}` | String | 172800s | 记录编号序列 |
| `m08:record:signfail:{employee_id}` | String | 300s | 签名口令错误次数 |
| `m08:record:workbench:{ward}:{shift}` | String(JSON) | 30s | 工作台缓存 |
| `m08:record:config` | String(JSON) | 600s | 配置项 |
| `m08:record:stat:{ward}:{d1}:{d2}` | String(JSON) | 1800s | 质量统计 |
| `m08:record:lock:{record_id}` | String | 30s | 编辑锁（防两个窗口同时改） |
| `ws:m08:record:{ward_id}` | Pub/Sub | — | 工作台实时推送 |

**容量估算：**

| Key 类别 | 数量估算 | 单条大小 | 合计 |
|---|---|---|---|
| 模板缓存 | 10 个模板 | 约 3 KB | 30 KB |
| 模板列表 | 5 种类型 | 约 2 KB | 10 KB |
| 编号序列 | 1 个/天 | 20 B | 20 B |
| 签名失败计数 | 峰值 20 人 | 20 B | 400 B |
| 工作台缓存 | 5 病区 × 3 班次 | 约 8 KB | 120 KB |
| 配置 | 1 份 | 2 KB | 2 KB |
| 统计缓存 | 5 病区 × 30 查询 | 约 4 KB | 600 KB |
| 编辑锁 | 峰值 30 条 | 40 B | 1.2 KB |
| **合计** | | | **约 0.76 MB** |

**为什么工作台缓存只有 30 秒：** 工作台显示「已写/待写」，护士签完一条记录后应立刻看到自己少了一条待办。30 秒是本系统所有「个人待办」类缓存的统一 TTL（与 M08-01 一致）。若缓存 5 分钟，护士会以为签名没成功而重复操作。

```python
                        WHERE s.admission_status = 'IN_HOSPITAL'
                          AND s.nursing_level IN ('SPECIAL','LEVEL_1')
                          AND s.is_deleted = FALSE
                        GROUP BY s.ward_id, s.patient_id, s.patient_name, s.bed_no
                        """
                    )
                )
            ).mappings().all()

            alerts = []
            now = datetime.now()
            for r in rows:
                last = r["last_time"]
                if last is None or (now - last).total_seconds() > 120 * 60:
                    alerts.append(
                        {
                            "ward_id": r["ward_id"],
                            "patient_id": r["patient_id"],
                            "patient_name": r["patient_name"],
                            "bed_no": r["bed_no"],
                            "last_time": last.isoformat() if last else None,
                            "minutes": int((now - last).total_seconds() / 60)
                            if last else None,
                        }
                    )
            return alerts

    alerts = asyncio.run(_run())
    if alerts:
        logger.warning("危重护理记录超时 %d 例", len(alerts))
    return {"alert_count": len(alerts), "items": alerts}


@shared_task(name="m08.record.warmup")
def warmup_task() -> dict:
    """早班预热：预加载模板与工作台。"""
    import asyncio

    async def _run() -> int:
        from app.core.database import AsyncSessionLocal

        async with AsyncSessionLocal() as db:
            rows = (
                await db.execute(
                    __import__("sqlalchemy").text(
                        "SELECT template_code FROM m08_record_template "

            service = NursingRecordService(db)
```

**系统管理员为什么没有 `query` 权限：** 护理记录正文包含患者姓名、床号、诊断、治疗细节。IT 岗位不应看到临床内容。运维排查通过数据库只读账号（严格限制、操作记审计），而不是通过应用权限。

### 9.3 数据权限

| 角色 | 数据范围 | 实现 |
|---|---|---|
| 责任护士 / 辅助护士 | 本病区 | `ward_id = user.ward_id` |
| 护士长 | 本科室所有病区 | `ward_id IN (user.dept_ward_ids)` |
| 护理部 / 质控 | 全院 | 无过滤 |
| 系统管理员 | 无 | 拒绝 |

**实现方式：** `_apply_scope` 按权限码注入 `WHERE` 条件。不依赖前端传参，防止越权。

### 9.4 脱敏规则

| 场景 | 字段 | 处理 |
|---|---|---|
| 统计报表 | 患者姓名 | 显示「张**」 |
| 统计报表 | 住院号 | 显示后 4 位 |
| 导出明细 | 全文 | 不脱敏（导出行为记审计） |
| 内部契约 | 全文 | 不脱敏（仅服务间调用） |

**为什么导出不脱敏：** 导出的台账用于质控抽查，必须看到真实内容才能判断质量。脱敏会使质控失去意义。控制方式改为「导出行为记审计 + 导出权限受控」。

### 9.5 安全措施

| 措施 | 说明 |
|---|---|
| **签名防篡改** | SHA-256 摘要覆盖正文，验签时重算比对 |
| **签名防代签** | 口令校验（M02-05），口令错误 3 次锁定 |
| **签名时间戳** | 优先 RFC 3161 可信时间戳，降级本地并标记 |
| **只增日志** | `m08_nursing_record_log` 触发器禁止 UPDATE/DELETE |
| **作废留痕** | 作废记录永久保留，不物理删除 |
| **编辑锁** | `m08:record:lock:{id}` 防两个窗口同时改同一草稿 |
| **SQL 注入防护** | 全部用参数化查询；动态拼接的 `where` 只拼接固定字符串常量 |
| **XSS 防护** | 前端渲染时转义；PDF 渲染走服务端模板引擎 |
| **越权防护** | 一切数据范围由后端按权限注入，不信任前端参数 |
| **审计** | 创建/修改/签名/作废/打印全部写 `m08_nursing_record_log` 或 `m08_record_print` |

**签名摘要的防篡改验证流程（验签接口）：**

```
1. 读记录与全部段落
2. 按 _calc_digest 同样的规则重算摘要
3. 与 m08_nursing_record.signature_digest 比对
4. 一致 → 有效；不一致 → 立即告警（可能被 DBA 修改）
```

验签在以下时机自动执行：①M06-06 归档前 ②质控抽查 ③法务调阅。日常不调，避免性能开销。

## 11. 异常处理与日志

### 11.1 异常分类

| 类别 | 场景 | 处理 |
|---|---|---|
| **用户输入异常** | 字数不足、必填未填 | 返回业务错误码 + 字段级定位，前端高亮 |
| **状态异常** | 已签名记录被修改 | 返回 `"0805009"`，前端刷新到最新状态 |

| **依赖异常** | M02-05 不可用 | 阻断签名，明确提示 |
| **依赖降级** | M08-04/M08-03 不可用 | 段落渲染为提示语，护士手填 |
| **渲染异常** | 占位符渲染失败 | 该段落渲染为提示语，记 `render_errors` |
| **系统异常** | 数据库/Redis 异常 | 返回 500，记 error 日志 + 告警 |

```python
        "shift_code": record.shift_code,
        "signed_by": user["employee_id"],
        "signature_source": sign_source,
        "total_chars": total_chars,
        "trace_id": trace_id,
    },
)
```

**关键日志点：**

| 事件 | 级别 | 必含字段 |
|---|---|---|
| 创建草稿 | INFO | record_id, patient_id, record_type |
| 暂存 | DEBUG | record_id, version, 变化段落 |
| 签名成功 | INFO | record_id, signed_by, signature_source, 耗时 |
| 签名失败 | WARNING | record_id, employee_id, 失败原因 |
| 口令锁定 | WARNING | employee_id, 失败次数 |
| 作废 | WARNING | record_id, voided_by, reason 摘要 |
| 验签失败 | ERROR | record_id, 期望摘要, 实际摘要 |
| 渲染失败 | WARNING | record_id, 失败占位符, 异常 |
| 打印 | INFO | record_id, doc_type, copies |
| 汇总取数失败 | WARNING | source, patient_id, 异常 |

### 11.3 监控指标

| 指标 | 类型 | 告警阈值 |
|---|---|---|
| `m08_record_signed_total` | Counter | — |
