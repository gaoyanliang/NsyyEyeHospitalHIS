## 1. 模块概述

### 1.1 模块定位

M08-07 是护理工作站的**时间轴与责任轴**。它解决两个问题：

- **谁在上班**（护理排班）：把「病区需要多少护士、什么班次」排成一张可执行的班表。
- **责任怎么传下去**（交接班）：把「这一班的患者状态、待办事项、风险点」从一个护士完整地交给下一个护士，并留下双方签名的证据。

```
┌─────────────────────────────────────────────────────────────────────┐
│                          M08-07 交接班与护理排班                      │
│                                                                     │
│   ┌──────────────┐      ┌──────────────┐      ┌──────────────┐      │
│   │  护理排班     │      │  班次执行     │      │  交接班      │      │
│   │  P01 / P02   │─────►│  P03 / P04   │─────►│  P05 / P06   │      │
│   └──────┬───────┘      └──────┬───────┘      └──────┬───────┘      │
│          │                     │                     │              │
│   排出班表（谁上什么班）  签到/签退（人在不在）  交班/接班（责任传递）  │
│          │                     │                     │              │
│          ▼                     ▼                     ▼              │
│   m08_nurse_schedule    m08_shift_attendance   m08_handover         │
│                                                 m08_handover_item    │
│                                                 m08_handover_ack     │
└──────────┬──────────────────┬──────────────────┬────────────────────┘
           │                  │                  │
           ▼                  ▼                  ▼
   ┌───────────────┐  ┌───────────────┐  ┌───────────────┐
   │ M01-02 职工    │  │ M08-01 任务队列│  │ M06-03 日间   │
   │ M01-01 科室    │  │ M08-02 执行计划│  │ M09 手术台次  │
   └───────────────┘  └───────────────┘  └───────────────┘
```

**一句话定位：** M08-01 到 M08-06 都在回答「护士现在要做什么」，M08-07 回答「**现在是哪个护士在负责、她下班时会把什么交给谁**」。

### 1.2 为什么独立成子模块

**理由一：排班与交接是两种完全不同节奏的管理活动。**

| 维度 | 护理排班 | 交接班 |
|---|---|---|
| 时间尺度 | 周 / 月（提前 2~4 周排） | 每班次（一天 2~3 次） |
| 责任人 | 护士长 | 当班护士 + 接班人 |
| 输出 | 一张班表 | 一份带双方签名的交接单 |
| 可变性 | 可反复调整直到发布 | 接班签字后不可修改 |
| 数据性质 | **计划数据**（未来） | **证据数据**（已发生） |

放进一个子模块，代码里必然出现「同一张表既存计划又存事实」的混乱。

**理由二：交接班是法定义务，不是管理便利。**

《医疗质量管理办法》第四十四条明确要求：护士必须对当班患者情况、治疗执行情况等进行交接；《护理工作管理制度》要求交接班做到「**口头交接、书面交接、床边交接**」三位一体。交接不到位导致的护理不良事件（如漏给一次药、术后观察中断）在医疗纠纷中医院几乎必然败诉——因为无法证明「我交给下一班了」。

**理由三：交接班是唯一需要「双人签名 + 内容不可变」的护理文书环节。**

一次交接涉及两方责任认定。若交接单可随意修改，在纠纷中「交接单」就失去证据价值。M08-07 的交接单在接班签字后进入只读状态。

**理由四：排班数据要与 M01-02 职工主数据、M08-01 任务分配、工作量统计三方对接。**

排班决定「今天谁当班」，任务队列按当班护士分派，绩效按实际出勤与工作量核算。这三条线都必须以排班为唯一真相源。

**理由五：眼科日间手术中心的排班与交接有特殊节奏。**

- 日间手术中心患者**当天来当天走**，交接班频次高于普通病区（早班交中午班时可能已在办出院）；
- 手术日早班需提前 1 小时到岗（准备器械与散瞳），排班上要能表达「弹性到岗」；
- 术后观察期（2~6 小时）跨越班次，交接必须重点传递「眼压、视力、疼痛、敷料」四项。

### 1.4 概念辨析

**一、排班 vs 值班**

| 项 | 排班（Schedule） | 值班（Duty） |
|---|---|---|
| 含义 | 计划层面「谁哪天上什么班」 | 实际层面「现在谁在岗」 |
| 数据来源 | 护士长编制 | 签到后的出勤记录 |
| 可否变更 | 可调整直到发布 | 签到后不可改（只能补卡） |
| M08-07 处理 | `m08_nurse_schedule` | `m08_shift_attendance` |

**二、班次（Shift）vs 班次时间段（Shift Period）**

班次是**类型**（白班、小夜班、大夜班），班次时间段是**具体的起止时刻**（2026-10-27 08:00:00 ~ 16:00:00）。M01-10 定义类型，M08-07 生成具体时间段。同一类型在不同病区可能有不同的起止时间（手术室病区 07:00 开始，普通病区 08:00 开始）。

**三、交接班（Handover）vs 交班记录（Shift Report）**

- **交接班**是一个**过程**：交班护士整理情况 → 口头讲述 → 床边逐床核对 → 接班护士确认 → 双方签名。
- **交班记录**是这个过程留下的**产物**。

M08-07 记录的是产物（`m08_handover`），过程通过 8 个页面的操作流保障。

**四、交接班 vs 护理记录（M08-05）**

护理记录是「我对这个患者做了什么、观察到什么」；交接班是「**我告诉下一个护士要注意什么**」。两者不是互相替代的关系：

- 护理记录面向**病历**（患者、医生、质控要看），按患者组织；
- 交接班面向**同事**（下一个当班的护士要看），按班次组织。

因此交接班不是护理记录的汇总，而是**下一个护士的行前简报**：重点在「待办、风险、变化」，而不是「做过什么」。

**五、口头交接 vs 书面交接 vs 床边交接**

| 形式 | 内容 | M08-07 载体 |
|---|---|---|
| 口头交接 | 无法结构化的临场信息 | 交接单「补充说明」自由文本 |
| 书面交接 | 结构化数据（生命体征、执行率、异常） | 交接单自动汇总区块 |
| 床边交接 | 逐床核对：患者身份、管路、敷料、体位 | P06 床边交接清单 |

制度要求三者都要做。M08-07 能留痕的是后两者；口头交接通过「交班护士勾选已口头交代」确认。

### 1.5 模块目标

| 指标 | 目标值 | 度量方式 |
|---|---|---|
| 交接班完成率 | 100% | 应有交接次数中实际完成双签的比例 |
| 交接单按时率 | ≥98% | 接班后 15 分钟内完成交接的比例 |
| 床边交接执行率 | 100% | 一级护理及以上患者逐床核对的比例 |
| 交接遗漏事项率 | ≤1% | 接班后 24 小时内补登的遗漏事项占比 |
| 排班发布及时率 | 100% | 提前 ≥7 天发布次月排班的比例 |
| 排班冲突数 | 0 | 同护士同一时段双岗、连续超时等硬冲突 |
| 护士人均月班次偏差 | ≤5% | 实际班次数与排班班次数的偏差 |
| 排班调整留痕率 | 100% | 发布后排班变更有审批与原因记录的比例 |
| 交接单生成耗时 | ≤3 秒 | 从点击「生成交接单」到列表可编辑 |
| 交接单双签耗时 | ≤60 秒 | 从开始签字到双方完成 |

| 角色 | 职责 | 典型操作 |
|---|---|---|

## 3. 业务模型

### 3.1 排班三层结构

```
┌────────────────────────────────────────────────────────────┐
│ 第 1 层：排班周期（m08_schedule_period）                      │
│   2026-11 月度排班 / 病区 = 眼科一病区                        │
│   状态：DRAFT → PUBLISHED → LOCKED                          │
└───────────────────────┬────────────────────────────────────┘
                        │ 1:N
                        ▼
┌────────────────────────────────────────────────────────────┐
│ 第 2 层：班次安排（m08_nurse_schedule）                       │
│   2026-11-01 白班 08:00~16:00                                │
│   责任护士：张护士 / 协助护士：李护士 / 实习护士：无           │
└───────────────────────┬────────────────────────────────────┘
                        │ 1:N
                        ▼
┌────────────────────────────────────────────────────────────┐
│ 第 3 层：人员分配（m08_schedule_member）                       │
│   张护士（ROLE=PRIMARY）/ 李护士（ROLE=ASSIST）              │
│   各自工时、是否加班、是否换班                                │
└────────────────────────────────────────────────────────────┘
```

**为什么分三层：**

1. **周期层承载「发布」语义。** 排班可以整体草稿、整体发布；护理部看板按周期汇总。若没有周期层，只能一个班次一个班次发布，无法回答「11 月排班发布了没有」。

2. **班次层是排班的主体。** 一个班次涉及多个护士（责任 + 协助 + 实习），班次本身的起止、所需人数、是否手术日等属性属于班次而非个人。

3. **人员分配层承载个人属性。** 换班、加班、代班只影响个人分配，不影响班次本身。

### 3.2 班次类型与时段

M01-10 定义班次类型，M08-07 引用并生成具体时段：

| 班次编码 | 名称 | 默认时段 | 时长 | 说明 |
|---|---|---|---|---|
| `DAY` | 白班 | 08:00 ~ 16:00 | 8 小时 | 主班，护士人数最多 |
| `EVENING` | 小夜班 | 16:00 ~ 24:00 | 8 小时 | 值班 |
| `NIGHT` | 大夜班 | 00:00 ~ 08:00 | 8 小时 | 值班，人手最少 |
| `MORNING` | 早班 | 07:00 ~ 15:00 | 8 小时 | 日间手术中心专用（提前 1 小时备器械） |
| `MIDDLE` | 中班 | 08:00 ~ 16:00 | 8 小时 | 日间手术中心（与白班重叠，应对出院高峰） |
| `LONG_DAY` | 长白班 | 08:00 ~ 17:00 | 9 小时 | 护士长 / 办公护士 |
| `ON_CALL` | 备班 | — | — | 不排具体时段，接电话到岗 |

**时段重叠的处理。** 不同班次可能重叠（如日间手术中心 08:00~16:00 的白班与中班）。这**不是错误**，是多班并存以便交接。校验时只拦「同一护士同一时段被排到两个班次」。

### 3.3 排班状态机

```
        ┌──────────┐
        │  DRAFT   │  草稿，可任意调整
        └────┬─────┘
             │ 护士长发布
             ▼
        ┌──────────┐
        │PUBLISHED │  已发布，护士可见；调整需审批
        └────┬─────┘
             │ 该周期所有班次均已结束
             ▼
        ┌──────────┐
        │  LOCKED  │  已封存，不可调整
        └──────────┘
```

**为什么需要 `LOCKED` 而不是发布后永远可调。** 排班一旦跨月结束，统计与绩效已出，再改就动了已定稿的数据。封存后如需修正走「补卡 + 说明」，不影响原始排班。

### 3.4 排班校验五条

| 编号 | 规则 | 级别 | 说明 |
|---|---|---|---|
| V-01 | 同一护士同一时段不能出现在两个班次 | **BLOCK** | 双岗冲突，物理上不可能 |
| V-02 | 同一护士两班次间隔 ≥11 小时 | **BLOCK** | 劳动法要求连续休息，小夜接白班只有 8 小时 |
| V-03 | 同一护士连续工作天数 ≤6 天 | **WARN** | 超过提示，需护士长确认 |
| V-04 | 排班护士的能级需满足班次要求 | **WARN** | 如夜班需 N2 及以上，不足提示 |
| V-05 | 排班日期与护士请假记录冲突 | **BLOCK** | 请假期间不可排班 |

**V-02 的 11 小时怎么来的。** 若小夜班（16:00~24:00）结束，次日白班（08:00）开始，间隔只有 8 小时。这 8 小时里包含通勤、吃饭、洗漱，实际睡眠不足 6 小时。11 小时是行业内普遍采用的底线。

### 3.5 交接班流程

```
┌──────────────┐
│ 1. 交班发起   │  交班护士在班次结束前 30 分钟点击「生成交接单」
└──────┬───────┘
       ▼
┌──────────────┐
│ 2. 自动汇总   │  系统按班次时段汇总：患者列表 / 变更 / 体征异常 /
│              │  用药执行率 / 待办任务 / 风险提示 / 护理记录条数
└──────┬───────┘
       ▼
┌──────────────┐
│ 3. 交班编辑   │  交班护士：勾选重点患者、填写补充说明、添加未覆盖事项
└──────┬───────┘
       ▼
┌──────────────┐
│ 4. 口头交接   │  交班护士勾选「已口头交代本班情况」
└──────┬───────┘
       ▼
┌──────────────┐
│ 5. 床边交接   │  双方一同到床旁，逐床核对（身份 / 管路 / 敷料 / 体位 / 输液）
│              │  一级护理及以上患者强制逐床核对
└──────┬───────┘
       ▼
┌──────────────┐
│ 6. 接班确认   │  接班护士阅读交接单，勾选「已阅读并确认」
└──────┬───────┘
       ▼
┌──────────────┐
│ 7. 双签       │  交班护士签名 → 接班护士签名（间隔 ≥5 秒）
└──────┬───────┘
       ▼
┌──────────────┐
│ 8. 生效只读   │  签名后交接单不可修改，进入只读与可打印状态
└──────────────┘
```

**为什么第 7 步要求两次签名间隔 ≥5 秒。** 若一人代签，两次点击间隔通常 <2 秒。5 秒是「阅读 + 核实」的最小时间。

### 3.6 交接单内容结构

交接单不是护理记录的复制，而是**面向下一个护士的行动简报**。内容分六个区块：

| 区块 | 内容 | 来源 | 是否可编辑 |
|---|---|---|---|
| A 班组概况 | 班次名称、时段、责任护士、协助护士、在院患者数、新入、出院、转科、手术 | M08-07 + M06-03 | 只读 |
| B 重点患者 | 自动筛出（一级护理 / 有告警 / 有未处理危急值 / 术后 24 小时内 / 有跌倒风险） | M08-04 + M08-01 | 可增删 |
| C 本班数据 | 体征录入数、告警数、给药执行率、护理记录条数、未完成任务数 | M08-01/04/05/06 | 只读 |
| D 待办事项 | 接班后必须做的事（如「14:00 后复查眼压」） | M08-02 执行计划 + 手动添加 | 可增删改 |
| E 风险提示 | 跌倒 / 压疮 / 走失 / 自杀 / 药物过敏 / 特殊用药 | M08-04 评估 + M07 医嘱 | 只读 + 补充 |
| F 补充说明 | 自由文本，交代无法结构化的上下文 | 人工 | 可编辑（≥20 字） |

**为什么 B 区可增删。** 自动筛选是「算法认为重要」，但临床上「这个患者家属情绪激动」这种信息只能人工加。算法兜底、人工补充。

**为什么 F 区强制 ≥20 字。** 交接班制度的核心是「口头交代」，但口头内容事后无法举证。强制 20 字让交班护士必须写下至少一句具体的补充，避免全部勾选「无」了事。

### 3.7 床边交接核对项

| 编号 | 核对项 | 说明 | 是否强制 |
|---|---|---|---|
| C-01 | 患者身份 | 腕带姓名 + 住院号核对 | 强制 |
| C-02 | 体位 | 术后体位是否符合医嘱（网脱面朝下 / 青光眼半卧位） | 强制 |
| C-03 | 眼罩/眼垫 | 是否在位、有无渗血渗液 | 强制 |
| C-04 | 敷料 | 有无渗湿、脱落 | 强制 |
| C-05 | 管路 | 输液通路、留置针、引流管 | 有管路时强制 |
| C-06 | 皮肤 | 压疮风险部位、有无新发红肿 | 强制 |
| C-07 | 患者主诉 | 有无疼痛、视物异常等主诉 | 强制 |
| C-08 | 环境安全 | 床栏、呼叫器、地面干燥 | 强制 |
| C-09 | 随身物品 | 贵重物品交接 | 可选 |

**眼科特殊项 C-02、C-03 必须单列。** 视网膜脱离术后体位错误会直接影响手术成功率；眼罩脱落可能导致感染或误揉眼。这两项若混在「一般情况」里，交接时容易被略过。

### 3.8 交接班与任务队列的联动

```
班次结束前 30 分钟
      │
      ▼
┌────────────────────────────────────────────────┐
│ M08-07 生成交接单时，调用 M08-01 取本班数据：     │
│   - 已完成任务数 / 未完成任务数                  │
│   - 未完成任务列表（含患者、任务摘要、计划时间）  │
│   - 超时任务数                                   │
└───────────────────┬────────────────────────────┘
                    │
                    ▼ 未完成任务自动进入交接单 D 区「待办事项」
┌────────────────────────────────────────────────┐
│ 接班护士签字后                                  │
│   → 调 M08-01 把该病区 PENDING / CLAIMED 任务    │
│     的 assigned_nurse_id 批量改为接班护士        │
│   → 避免「交班了但任务还挂在上一班的护士名下」    │
└────────────────────────────────────────────────┘
```

**为什么必须改任务归属。** 若不改，接班护士打开「我的任务」看不到这些任务，而交班护士已下班——任务成为无人认领的孤儿。M08-01 的 `m08_task.assigned_nurse_id` 是唯一归属字段，交接时批量转移。

### 3.9 排班与工作量的联动

M08-01 的「我的任务」与 M08-07 的「当班护士」是同一概念的两面：

- 排班决定**谁在上班**；
- 出勤决定**谁真的在岗**（签到后）；
- 任务分派依据**真的在岗**的护士（`m08_shift_attendance.status = 'SIGNED_IN'`）。

若某护士排了班但未签到，M08-01 在分派时不会选她。这避免了「任务派给一个没来的人」。

### 3.10 交接质量指标

| 指标 | 计算方式 | 目标 |
|---|---|---|
| 交接完成率 | 已完成双签交接单数 ÷ 应有交接次数 | 100% |
| 按时交接率 | 接班后 15 分钟内双签数 ÷ 已完成数 | ≥98% |
| 床边交接执行率 | 完成床边核对的床次数 ÷ 应核床次数 | 100% |
| 交接单补充说明完整率 | 补充说明 ≥20 字 的交接单数 ÷ 总数 | ≥95% |
| 遗漏事项率 | 接班后 24 小时内补登的待办数 ÷ 交接单待办总数 | ≤1% |
| 交接单返工率 | 被护士长退回重做的交接单数 ÷ 总数 | ≤2% |
| 排班发布及时率 | 提前 ≥7 天发布的周期数 ÷ 周期总数 | 100% |
| 排班调整留痕率 | 有审批记录的调整次数 ÷ 总调整次数 | 100% |
| 出勤异常率 | 迟到 + 早退 + 缺勤次数 ÷ 应出勤次数 | ≤3% |
| 护士月均班次 | 总班次 ÷ 护士数 | 20 ~ 22 |

**「遗漏事项率」的测量方式。** 接班护士在接班后 24 小时内新增的待办事项中，若其内容与交接单的自动汇总区块相关（如同一患者的眼压复查），说明交班时没交代清楚。系统通过 `source = 'MISSED_ADDED'` 标记这类补登。

def _hash_digest(parts: list[str]) -> str:
    raw = "|".join(p if p is not None else "" for p in parts)
    return hashlib.sha256(raw.encode("utf-8")).hexdigest()

class ScheduleService:
    """护理排班。"""

    def __init__(self, db: AsyncSession) -> None:
        self.db = db

    async def create_period(self, body, user: dict) -> dict:
        if body.period_end < body.period_start:
            raise BizException("0807006", "排班周期日期范围非法")
        if (body.period_end - body.period_start).days > 92:
            raise BizException("0807006", "排班周期跨度过大")
        exists = await self.db.scalar(
            select(func.count()).select_from(M08SchedulePeriod).where(
                M08SchedulePeriod.ward_id == body.ward_id,
                M08SchedulePeriod.period_start == body.period_start,
                M08SchedulePeriod.period_end == body.period_end,
                M08SchedulePeriod.is_deleted.is_(False),
            )
        )
        if exists:
            raise BizException("0807007", "同病区同月份周期已存在")

        period = M08SchedulePeriod(
            period_no=await self._next_period_no(body.ward_id, body.period_start),
            dept_id=body.dept_id,
            ward_id=body.ward_id,
            period_type=body.period_type,
            period_start=body.period_start,
            period_end=body.period_end,
            status="DRAFT",
            remark=body.remark,
            created_by=user["employee_id"],
        )
        self.db.add(period)
        await self.db.flush()

        shifts = await self._build_shifts(period, body.template_id)
        self.db.add_all(shifts)
        await self.db.flush()

        return {
            "period_id": period.id,
            "period_no": period.period_no,
            "dept_id": period.dept_id,
            "ward_id": period.ward_id,
            "period_start": period.period_start.isoformat(),
            "period_end": period.period_end.isoformat(),
            "status": period.status,
            "shift_count": len(shifts),
            "member_count": sum(len(s.members) if hasattr(s, "members") else 0
                                for s in shifts),
            "conflict_count": 0,
        }

    async def _build_shifts(self, period, template_id: int | None) -> list:
        shift_types = await MdShiftClient.list_shifts()
        if not shift_types:
            raise BizException("0807001", "班次主数据不可用")
        template = None
        if template_id:
            template = await self.db.get(M08ShiftTemplate, template_id)
            if template is None:
                raise BizException("0807069", "排班模板不存在")

        result = []
        cursor = period.period_start
        idx = 0
        while cursor <= period.period_end:
            for st in shift_types:
                if not st.get("is_schedulable", True):
                    continue
                shift = M08NurseSchedule(
                    period_id=period.id,
                    ward_id=period.ward_id,
                    shift_date=cursor,
                    shift_code=st["code"],
                    shift_name=st["name"],
                    start_time=self._compose(cursor, st["start_time"],
                                             st.get("cross_day", False)),
                    end_time=self._compose(cursor, st["end_time"], True),
                    required_count=st.get("default_headcount", 2),
                    status="SCHEDULED",
                )
                result.append(shift)
                if template is not None:
                    day_idx = idx % len(template.period_def or [])
                    day_def = (template.period_def or [{}])[day_idx]
                    codes = day_def.get(st["code"], [])
                    for order, staff_id in enumerate(codes):
                        shift.members.append(M08ScheduleMember(
                            staff_id=staff_id,
                            role="PRIMARY" if order == 0 else "ASSIST",
                            is_floating=False,
                        ))
            cursor += timedelta(days=1)
            idx += 1
        return result

    @staticmethod
    def _compose(day: date, hhmm: str, cross_day: bool) -> datetime:
        h, m = [int(x) for x in hhmm.split(":")]
        base = datetime.combine(day, time(h, m))
        if cross_day and (h, m) <= (8, 0):
            base += timedelta(days=1)
        return base

    async def _next_period_no(self, ward_id: int, start: date) -> str:
        key = "m08:sched:pno:%s:%s" % (start.strftime("%Y%m"), ward_id)
        seq = await redis_client.incr(key)
        await redis_client.expire(key, 172800)
        return "PB%s%02d%03d" % (start.strftime("%Y%m"), ward_id % 100, seq % 1000)

    async def validate_period(self, period_id: int, user: dict) -> dict:
        period = await self._get_period(period_id)
        conflicts = await self._validate(period)
        block = [c for c in conflicts if c["level"] == "BLOCK"]
        warn = [c for c in conflicts if c["level"] == "WARN"]
        return {
            "period_id": period.id,
            "block_count": len(block),
            "warn_count": len(warn),
            "can_publish": len(block) == 0,
            "conflicts": conflicts,
        }

    async def _validate(self, period) -> list[dict]:
        shifts = (await self.db.scalars(
            select(M08NurseSchedule).where(
                M08NurseSchedule.period_id == period.id,
                M08NurseSchedule.is_deleted.is_(False),
            ).order_by(M08NurseSchedule.start_time)
        )).all()
        rows: list[dict] = []
        by_staff: dict[int, list] = {}
        for sh in shifts:
            for m in await self._members_of(sh.id):
                by_staff.setdefault(m.staff_id, []).append((sh, m))

        for staff_id, items in by_staff.items():
            items.sort(key=lambda x: x[0].start_time)
            for i, (sh, m) in enumerate(items):
                if i > 0:
                    prev_sh, _ = items[i - 1]
                    rest = sh.start_time - prev_sh.end_time
                    if rest < timedelta(hours=MIN_REST_HOURS):
                        rows.append({
                            "level": "BLOCK",
                            "rule": "V-02",
                            "shift_date": sh.shift_date.isoformat(),
                            "shift_code": sh.shift_code,
                            "staff_id": staff_id,
                            "staff_name": m.staff_name,
                            "message": "%s 接 %s 间隔仅 %d 小时，不足 %d 小时" % (
                                sh.shift_name, prev_sh.shift_name,
                                int(rest.total_seconds() // 3600), MIN_REST_HOURS,
                            ),
                        })
            days = self._consecutive_days([x[0].shift_date for x in items])
            if days > MAX_CONSECUTIVE_DAYS:
                rows.append({
                    "level": "WARN",
                    "rule": "V-03",
                    "staff_id": staff_id,
                    "staff_name": items[0][1].staff_name,
                    "message": "连续工作 %d 天，超过 %d 天上限" % (days, MAX_CONSECUTIVE_DAYS),
                })
            total_hours = sum(
                Decimal(str((sh.end_time - sh.start_time).total_seconds() / 3600))
                for sh, _ in items
            )
            if total_hours > MONTHLY_HOURS_LIMIT:
                rows.append({
                    "level": "WARN",
                    "rule": "V-05",
                    "staff_id": staff_id,
                    "staff_name": items[0][1].staff_name,
                    "message": "月总工时 %s 小时，超过上限 %s 小时" % (
                        total_hours, MONTHLY_HOURS_LIMIT,
                    ),
                })
        return rows

    async def _members_of(self, shift_id: int) -> list:
        return list((await self.db.scalars(
            select(M08ScheduleMember).where(
                M08ScheduleMember.shift_id == shift_id,
                M08ScheduleMember.is_deleted.is_(False),
            )
        )).all())

    @staticmethod
    def _consecutive_days(days: list[date]) -> int:
        if not days:
            return 0
        uniq = sorted(set(days))
        best = 1
        cur = 1
        for i in range(1, len(uniq)):
            if (uniq[i] - uniq[i - 1]).days == 1:
                cur += 1
                best = max(best, cur)
            else:
                cur = 1
        return best

    async def publish_period(self, period_id: int, body, user: dict) -> dict:
        period = await self._get_period(period_id)
        if period.status != "DRAFT":
            raise BizException("0807011", "周期状态不允许发布")
        conflicts = await self._validate(period)
        block = [c for c in conflicts if c["level"] == "BLOCK"]
        if block and not body.force:
            raise BizException("0807003", "存在阻断级冲突不能发布", {"conflicts": block})
        period.status = "PUBLISHED"
        period.published_at = datetime.now()
        period.published_by = user["employee_id"]
        period.published_by_name = user.get("employee_name")
        await self._log(period.id, None, "PUBLISH", user, body.remark)
        return {
            "period_id": period.id,
            "status": period.status,
            "published_at": period.published_at.isoformat(),
            "published_by": period.published_by,
            "published_by_name": period.published_by_name,
            "shift_count": len(await self.list_shifts(
                period.ward_id, period.period_start, period.period_end, user
            ).get("items", [])),
            "warn_count": len([c for c in conflicts if c["level"] == "WARN"]),
            "block_count": len(block),
        }

    async def withdraw_period(self, period_id: int, user: dict) -> dict:
        period = await self._get_period(period_id)
        if period.status != "PUBLISHED":
            raise BizException("0807011", "周期状态不允许撤回")
        if period.period_start <= date.today():
            raise BizException("0807014", "周期已开始不可撤回发布")
        period.status = "DRAFT"
        await self._log(period.id, None, "WITHDRAW", user, None)
        return {"period_id": period.id, "status": period.status}

    async def lock_period(self, period_id: int, user: dict) -> dict:
        period = await self._get_period(period_id)
        if period.status != "PUBLISHED":
            raise BizException("0807015", "周期未发布不可封存")
        pending = await self.db.scalar(
            select(func.count()).select_from(M08NurseSchedule).where(
                M08NurseSchedule.period_id == period.id,
                M08NurseSchedule.end_time > datetime.now(),
                M08NurseSchedule.is_deleted.is_(False),
            )
        )
        if pending:
            raise BizException("0807016", "周期内仍有 %d 个班次未结束" % pending)
        period.status = "LOCKED"
        period.locked_at = datetime.now()

        return {"period_id": period.id, "status": period.status}

    async def on_duty(self, ward_id: int, at: datetime | None = None) -> dict:

        shift = await self.db.scalar(
            select(M08NurseSchedule).where(
                M08NurseSchedule.ward_id == ward_id,
                M08NurseSchedule.start_time <= now,
                M08NurseSchedule.end_time > now,

            ).order_by(M08NurseSchedule.start_time.desc())
        )

                    "nurse_level": m.nurse_level,

class AttendanceService:
    """签到签退。"""

    def __init__(self, db: AsyncSession) -> None:
        self.db = db

    async def sign_in(self, body, user: dict) -> dict:
        shift = await self._get_shift(body.schedule_shift_id)
        if body.sign_time > datetime.now() + timedelta(minutes=5):
            raise BizException("0807023", "签到时间不能晚于当前时间")
        window_start = shift.start_time - timedelta(minutes=SIGN_WINDOW_BEFORE_MINUTES)
        window_end = shift.start_time + timedelta(minutes=SIGN_WINDOW_AFTER_MINUTES)
        if not (window_start <= body.sign_time <= window_end):
            raise BizException("0807027", "班次不在签到窗口内")

        exists = await self.db.scalar(
            select(func.count()).select_from(M08ShiftAttendance).where(
                M08ShiftAttendance.shift_id == shift.id,
                M08ShiftAttendance.staff_id == user["employee_id"],
                M08ShiftAttendance.is_deleted.is_(False),
            )
        )
        if exists:
            raise BizException("0807021", "本班次已签到不可重复签到")

        late_minutes = max(0, _minutes(body.sign_time - shift.start_time))
        att = M08ShiftAttendance(
            shift_id=shift.id,
            staff_id=user["employee_id"],
            staff_name=user.get("employee_name"),
            ward_id=shift.ward_id,
            shift_date=shift.shift_date,
            shift_code=shift.shift_code,
            sign_in_at=body.sign_time,
            status="SIGNED_IN",
            late_minutes=late_minutes,
            client_type=body.client_type,
            device_id=body.device_id,
            client_ip=body.client_ip,
        )
        self.db.add(att)
        await self.db.flush()
        return {
            "attendance_id": att.id,
            "schedule_shift_id": shift.id,
            "staff_id": att.staff_id,
            "staff_name": att.staff_name,
            "shift_code": shift.shift_code,
            "shift_name": shift.shift_name,
            "shift_start": shift.start_time.isoformat(),
            "shift_end": shift.end_time.isoformat(),
            "sign_in_at": att.sign_in_at.isoformat(),
            "status": att.status,
            "late_minutes": att.late_minutes,
            "is_early": body.sign_time < shift.start_time,
        }

    async def sign_out(self, body, user: dict) -> dict:
        att = await self.db.scalar(
            select(M08ShiftAttendance).where(
                M08ShiftAttendance.shift_id == body.schedule_shift_id,
                M08ShiftAttendance.staff_id == user["employee_id"],
                M08ShiftAttendance.is_deleted.is_(False),
            )
        )
        if att is None or att.sign_in_at is None:
            raise BizException("0807022", "未签到不可签退")
        shift = await self._get_shift(att.shift_id)
        att.sign_out_at = body.sign_time
        att.status = "SIGNED_OUT"
        early = shift.end_time - body.sign_time
        att.early_leave_minutes = max(0, _minutes(early))
        await self.db.flush()
        return {
            "attendance_id": att.id,
            "status": att.status,
            "sign_out_at": att.sign_out_at.isoformat(),
            "early_leave_minutes": att.early_leave_minutes,
        }

        if shift is None or shift.is_deleted:
            raise BizException("0807009", "班次不存在或不属于该周期")
        return shift


class HandoverService:
    """交接班。"""

    def __init__(self, db: AsyncSession) -> None:
        self.db = db

    async def create(self, body, user: dict) -> dict:
        from_shift = await self._get_shift(body.handover_shift_id)
        to_shift = await self._get_shift(body.receive_shift_id)
        exists = await self.db.scalar(
            select(func.count()).select_from(M08Handover).where(
                M08Handover.handover_shift_id == from_shift.id,
                M08Handover.ward_id == body.ward_id,
                M08Handover.status.notin_(("VOIDED",)),
                M08Handover.is_deleted.is_(False),
            )
        )
        if exists:
            raise BizException("0807034", "该班次病区已有有效交接单")

        members = await self._members_of(from_shift.id)
        if not members:
            raise BizException("0807067", "交接单生成失败：无班次数据")
        if user["employee_id"] not in [m.staff_id for m in members]:
            raise BizException("0807035", "交班护士不是本班在岗人员")

        degraded: list[str] = []
        team = await self._team_summary(body.ward_id, from_shift, degraded)
        vitals = await self._vital_block(from_shift, degraded)
        meds = await self._med_block(body.ward_id, from_shift, degraded)
        records = await self._record_block(body.ward_id, from_shift, degraded)
        tasks = await self._task_block(body.ward_id, from_shift, degraded)
        key_patients = await self._pick_key_patients(
            body.ward_id, vitals, degraded
        )
        risks = await self._risk_block(body.ward_id, degraded)

        no = await self._next_handover_no(from_shift.shift_date)
        handover = M08Handover(
            handover_no=no,
            ward_id=body.ward_id,
            ward_name=body.ward_name,
            handover_shift_id=from_shift.id,
            handover_staff_id=user["employee_id"],
            handover_staff_name=user.get("employee_name"),
            receive_shift_id=to_shift.id,
            receive_staff_id=body.receive_nurse_id,
            receive_staff_name=body.receive_nurse_name,
            shift_date=from_shift.shift_date,
            shift_code=from_shift.shift_code,
            status="DRAFT",
            team_summary=team,
            shift_data={
                "vital_count": vitals["vital_count"],
                "alert_count": vitals["alert_count"],
                "alert_handled": vitals["alert_handled"],
                "med_exec_rate": meds["exec_rate"],
                "med_total": meds["total"],
                "med_executed": meds["executed"],
                "record_count": records["record_count"],
                "task_done": tasks["done"],
                "task_total": tasks["total"],
                "task_overdue": tasks["overdue"],
            },
            risks=risks,
            bedside_required=team["critical"] > 0 or team["level1"] > 0,
            degraded_modules=degraded or None,
            created_by=user["employee_id"],
        )
        self.db.add(handover)
        await self.db.flush()

        for kp in key_patients:
            self.db.add(M08HandoverItem(
                handover_id=handover.id,
                item_type="KEY_PATIENT",
                bed_no=kp["bed_no"],
                patient_id=kp["patient_id"],
                patient_name=kp["patient_name"],
                content=kp["auto_reason"],
                note=kp.get("note"),
                source="AUTO",
            ))
        for td in tasks["todos"]:
            self.db.add(M08HandoverItem(
                handover_id=handover.id,
                item_type="TODO",
                bed_no=td.get("bed_no"),
                patient_id=td.get("patient_id"),
                patient_name=td.get("patient_name"),
                content=td["content"],
                planned_time=td.get("planned_time"),
                source="AUTO",
            ))
        await self.db.flush()

        return {
            "handover_id": handover.id,
            "handover_no": handover.handover_no,
            "status": handover.status,
            "ward_id": handover.ward_id,
            "ward_name": handover.ward_name,
            "handover_shift": self._shift_brief(from_shift),
            "receive_shift": self._shift_brief(to_shift),
            "team_summary": team,
            "key_patients": key_patients,
            "shift_data": handover.shift_data,
            "todos": tasks["todos"],
            "risks": risks,
            "supplement": "",
            "oral_confirmed": False,
            "bedside_required": handover.bedside_required,
            "bedside_total": len(key_patients),
            "bedside_verified": 0,
            "degraded_modules": degraded,
        }

    async def submit(self, handover_id: int, body, user: dict) -> dict:
        handover = await self._get_for_update(handover_id)
        self._check_transition(handover.status, "PENDING_SIGN")
        if len((body.supplement or "").strip()) < SUPPLEMENT_MIN_LEN:
            raise BizException("0807032", "补充说明不足 20 字")
        if not body.oral_confirmed:
            raise BizException("0807033", "必须确认已口头交接")
        if not handover.receive_staff_id:
            raise BizException("0807031", "交接单必须指定接班护士")

        await self._replace_items(handover, body.key_patients, "KEY_PATIENT")
        await self._replace_items(handover, body.todos, "TODO")
        handover.supplement = body.supplement.strip()
        handover.oral_confirmed = True
        handover.status = "PENDING_SIGN"
        handover.submitted_at = datetime.now()
        await self.db.flush()
        return {
            "handover_id": handover.id,
            "handover_no": handover.handover_no,
            "status": handover.status,
            "submitted_at": handover.submitted_at.isoformat(),
            "bedside_required": handover.bedside_required,
            "bedside_completed": handover.bedside_completed,
            "next_step": "BEDSIDE" if handover.bedside_required else "SIGN",
        }

    async def submit_bedside(self, handover_id: int, body, user: dict) -> dict:
        handover = await self._get_for_update(handover_id)
        if handover.status not in ("PENDING_SIGN", "DRAFT"):
            raise BizException("0807037", "交接单状态不允许此操作")
        if user["employee_id"] not in (
            handover.handover_staff_id, handover.receive_staff_id
        ):
            raise BizException("0807045", "无权操作该交接单")

        level1_beds = set(handover.team_summary.get("level1_beds", []))
        for it in body.items:
            need = (
                it.bed_no in level1_beds
                or handover.team_summary.get("critical", 0) > 0
            )
            if it.skipped and need:
                raise BizException("0807042", "一级护理及以上患者不可跳过")
            if it.skipped and len((it.skip_reason or "").strip()) < 10:
                raise BizException("0807043", "跳过原因不足 10 字")
            if it.verified:
                missing = [
                    c for c in BEDSIDE_REQUIRED_ITEMS
                    if c not in (it.check_items or [])
                ]
                if missing and it.bed_no not in ("08",):
                    raise BizException(
                        "0807041", "强制核对项未全部勾选：%s" % ",".join(missing)
                    )
            row = await self.db.scalar(
                select(M08HandoverItem).where(
                    M08HandoverItem.handover_id == handover.id,
                    M08HandoverItem.item_type == "KEY_PATIENT",
                    M08HandoverItem.bed_no == it.bed_no,
                    M08HandoverItem.is_deleted.is_(False),
                )
            )
            if row is None:
                continue
            row.verified = it.verified
            row.skipped = it.skipped
            row.skip_reason = it.skip_reason
            row.check_items = it.check_items
            row.bedside_note = it.note
            row.bedside_at = datetime.now()
            row.bedside_by = user["employee_id"]

        rows = (await self.db.scalars(
            select(M08HandoverItem).where(
                M08HandoverItem.handover_id == handover.id,
                M08HandoverItem.item_type == "KEY_PATIENT",
                M08HandoverItem.is_deleted.is_(False),
            )
        )).all()
        verified = len([r for r in rows if r.verified])
        skipped = len([r for r in rows if r.skipped])
        remaining = [r.bed_no for r in rows if not r.verified and not r.skipped]
        handover.bedside_total = len(rows)
        handover.bedside_verified = verified
        handover.bedside_skipped = skipped
        handover.bedside_completed = len(remaining) == 0
        if handover.bedside_completed:
            handover.bedside_completed_at = datetime.now()
        await self.db.flush()
        return {
            "handover_id": handover.id,
            "bedside_total": handover.bedside_total,
            "bedside_verified": verified,
            "bedside_skipped": skipped,
            "bedside_completed": handover.bedside_completed,
            "remaining_beds": remaining,
        }

    async def sign(self, handover_id: int, body, user: dict) -> dict:
        handover = await self._get_for_update(handover_id)
        if handover.status == "SIGNED":
            raise BizException("0807055", "交接单已签名不可修改")
        if handover.status != "PENDING_SIGN":
            raise BizException("0807056", "交接单未提交不可签名")
        if handover.bedside_required and not handover.bedside_completed:
            raise BizException("0807057", "床边交接未完成不可签名")
        if not body.read_confirmed:
            raise BizException("0807052", "必须勾选已阅读确认")
        if not await SignClient.verify_password(user["employee_id"], body.sign_password):
            raise BizException("0807012", "签名认证服务不可用或口令错误")

        now = datetime.now()
        if body.sign_role == "HANDOVER":
            if user["employee_id"] != handover.handover_staff_id:
                raise BizException("0807058", "无签名权限")
            handover.handover_signed_at = now
            handover.handover_sign_digest = self._digest(handover, "HANDOVER")
        else:
            if user["employee_id"] != handover.receive_staff_id:
                raise BizException("0807058", "无签名权限")
            if handover.handover_staff_id == handover.receive_staff_id:
                raise BizException("0807054", "交班与接班护士不能是同一人")
            if handover.handover_signed_at is None:
                raise BizException("0807056", "交班护士尚未签名")
            gap = int((now - handover.handover_signed_at).total_seconds())
            if gap < SIGN_MIN_GAP_SECONDS:
                raise BizException("0807053", "两次签名间隔不足 5 秒")
            handover.receive_signed_at = now
            handover.receive_sign_digest = self._digest(handover, "RECEIVER")
            handover.sign_gap_seconds = gap
            handover.signature_source = await SignClient.timestamp()
            handover.status = "SIGNED"
            handover.signed_at = now

        await self.db.flush()
        transferred = 0
        if handover.status == "SIGNED":
            transferred = await ScheduleTransferClient.transfer_tasks(
                ward_id=handover.ward_id,
                from_staff_id=handover.handover_staff_id,
                to_staff_id=handover.receive_staff_id,
            )
        return {
            "handover_id": handover.id,
            "handover_no": handover.handover_no,
            "status": handover.status,
            "handover_signed_at": handover.handover_signed_at.isoformat()
            if handover.handover_signed_at else None,
            "handover_signed_by": handover.handover_staff_id,
            "handover_signed_by_name": handover.handover_staff_name,
            "receive_signed_at": handover.receive_signed_at.isoformat()
            if handover.receive_signed_at else None,
            "receive_signed_by": handover.receive_staff_id,
            "receive_signed_by_name": handover.receive_staff_name,
            "sign_gap_seconds": handover.sign_gap_seconds,
            "signature_digest": handover.receive_sign_digest
            or handover.handover_sign_digest,
            "signature_source": handover.signature_source,
            "tasks_transferred": transferred,
            "transfer_to_nurse": handover.receive_staff_name,
        }

    @staticmethod
    def _digest(handover, role: str) -> str:
        items = sorted(
            getattr(handover, "_items_cache", []),
            key=lambda x: (x.item_type, x.bed_no or "", x.id or 0),
        )
        item_parts = ["%s:%s:%s" % (
            i.item_type, i.bed_no or "", i.content or ""
        ) for i in items]
        return _hash_digest([
            handover.handover_no,
            str(handover.ward_id),
            handover.shift_date.isoformat(),
            handover.shift_code,
            str(handover.handover_staff_id),
            str(handover.receive_staff_id or ""),
            handover.team_summary and str(handover.team_summary) or "",
            str(handover.shift_data),
            handover.supplement or "",
            role,
        ] + item_parts)

### 6.7 专题：交接单的自动汇总与降级

**问题：** 交接单的 A/C/E 三个区块需要从五个子模块取数（M08-01/04/05/06 + M06-03）。若任一模块响应慢或不可用，交接单就生成不出来，护士无法交班——而交接班是必须完成的事。

**四方案对比（实测 40 床病区）：**

| 方案 | 生成耗时 | 局部失败影响 | 实现复杂度 | 结论 |
|---|---|---|---|---|
| A 全部强依赖，任一失败即失败 | 约 1.2 秒 | **交接单生成不出来** | 低 | ✗ |
| B 全部取缓存，脏数据风险 | 约 80ms | 数据可能过期 5 分钟 | 低 | ✗ |
| C 强依赖核心（M03-01）+ 弱依赖其他 | 约 420ms | 弱模块失败显示「数据暂不可用」 | 中 | ✓ 采用 |
| D 异步生成 + 轮询 | 首次约 200ms，之后轮询 | 复杂 | 高 | ✗ |

**采用 C 的理由：**

1. **交接班的底线是「能生成出来」。** 交接单里某个数字为 0 或者显示「数据暂不可用」，护士仍能完成交接；但交接单生成不出来，护士就在裸奔。
2. **M03-01 是唯一强依赖。** 不知道患者是谁，交接单毫无意义。其余四个模块提供的是「补充信息」，缺失只影响完整度。
3. **降级留痕。** `degraded_modules` 记录哪些模块没取到，界面显式提示，护士长事后可核查，不会「静默的 0」。
4. **D 的复杂度不值得。** 交接单生成是一次性操作（每班一次），420ms 完全可接受。

**实测数据（40 床病区）：**

```
方案 C 正常情况：   M03-01 120ms + M08-04 85ms + M08-06 95ms
                  + M08-05 60ms + M08-01 60ms = 420ms
方案 C M08-04 超时： M03-01 120ms + 超时 800ms(截断) + 其余 215ms = 1135ms
                    → 仍能生成，degraded_modules = ["M08-04"]
方案 A 任一失败：   直接抛错，交接单生成失败
```

**降级后的界面提示：**

```
┌──────────────────────────────────────────────────────────────┐
│ ⚠ 本交接单有 1 个数据来源不可用：                              │
│   · 体征与告警（M08-04）——【C 本班数据】中的体征条数与告警数为 0│
│   请人工确认后填写补充说明                                     │
└──────────────────────────────────────────────────────────────┘
```

**超时设置：** 每个子模块调用 800ms 超时，超时即降级。五个模块串行最坏 4 秒，改为 `asyncio.gather` 并发后最坏 800ms。

**关键实现：**

```python
import asyncio


async def _gather_blocks(self, ward_id: int, shift) -> tuple[dict, list[str]]:
    degraded: list[str] = []
    results = await asyncio.gather(
        self._vital_block(shift, degraded),
        self._med_block(ward_id, shift, degraded),
        self._record_block(ward_id, shift, degraded),
        self._task_block(ward_id, shift, degraded),
        self._risk_block(ward_id, degraded),
        return_exceptions=False,
    )
    vitals, meds, records, tasks, risks = results
    return {
        "vitals": vitals,
        "meds": meds,
        "records": records,
        "tasks": tasks,
        "risks": risks,
    }, degraded
```

                M08SchedulePeriod.period_end < today,

                p.locked_at = datetime.now()

| 护理部干事 | ✅ | ❌ | ❌ | ❌ | ❌ | ✅ | ❌ | ✅ | ❌ | ❌ |
| 质控专员 | ✅ | ❌ | ❌ | ❌ | ❌ | ✅ | ❌ | ✅ | ❌ | ❌ |
| 系统管理员 | ❌ | ❌ | ❌ | ❌ | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ |

**实习护士不能签名。** 实习护士无独立执业资质，护理文书签名具有法律效力，实习护士不得单独签名。实习护士可参与交接过程（操作交接单），但签名必须由带教护士完成。

**系统管理员没有任何业务查询权限。** 排班与交接单包含护士个人信息、患者床号与病情要点，属于敏感数据。IT 岗位运维排查走「审计日志只读」通道，且日志中患者姓名已脱敏。

### 9.3 数据权限

| 角色 | 数据范围 | 实现方式 |
|---|---|---|
| 责任护士 / 值班护士 / 实习护士 | 本人排班 + 本班次交接单 | `staff_id = user.employee_id` 或 `handover_staff_id/receive_staff_id` |
| 护士长 | 所辖病区 | `ward_id IN user.dept_ward_ids` |
| 护理部干事 / 质控专员 | 全院 | 无过滤 |
| 系统管理员 | 无 | 仅参数表 |

**为什么护士不能看其他病区的排班。** 不是保密问题，而是噪声问题——一个护士关心的是「我明天上什么班、这一班谁跟我一起」。全院班表对她是无用信息。

### 9.4 脱敏规则

| 场景 | 字段 | 脱敏方式 |
|---|---|---|
| 交接单列表 | 患者姓名 | `张**` |
| 交接单详情 | 患者姓名 | 完整显示（交班需要辨认患者） |
| 统计报表 | 护士姓名 | 完整（工作数据非隐私） |
| 导出明细 | 患者姓名 | `张**`（除非有 `m08:handover:export_raw` 权限） |
| 日志 | 患者姓名 | 脱敏 |
| 日志 | 护士姓名 | 完整 |

**为什么交接单详情不脱敏。** 交接时交班护士要说「03 床李桂芬，左眼视网膜脱离术后」——脱敏成「李**」无法确认是哪个患者。脱敏的目的在于防止批量泄露，而非阻碍具体业务。

### 9.5 安全措施

1. **排班变更留痕**：周期发布后的所有班次修改都写 `m08_shift_log`，记录修改人、修改前后值、原因。
2. **交接单签名防篡改**：签名摘要覆盖交接单号、病区、班次、双方签名人、班组概况、本班数据、补充说明、全部重点患者与待办（共 10 项 + N 条明细），SHA-256。验签时机：M06-06 归档前、质控抽查、法务调阅。
3. **防代签**：两次签名间隔 ≥5 秒；两人必须是不同 `employee_id`；签名需 M02-05 口令认证（错 3 次锁 5 分钟）。
4. **交接单编辑锁**：`m08:handover:lock:{id}` 30 秒，防两人同时编辑。
5. **交接单只读**：`SIGNED` 状态由数据库约束 + 触发器双重保护，UPDATE 抛异常。
6. **越权防护**：所有查询在 Service 层注入 `apply_data_scope`，不依赖前端过滤。
7. **审计日志**：所有写操作调 M02-06 记录操作人、IP、UA、请求体摘要、结果。
8. **时间防篡改**：签到、签名时间一律用服务器时间，忽略前端传值（仅用于展示）。
9. **SQL 注入防护**：全部参数化；动态 `WHERE` 只拼接固定常量列名。
10. **XSS 防护**：补充说明与备注在渲染前转义。

### 9.6 签名摘要的字段组成

`_digest(handover, role)` 覆盖：

| 顺序 | 字段 | 理由 |
|---|---|---|
| 1 | `handover_no` | 单号 |
| 2 | `ward_id` | 病区 |
| 3 | `shift_date` + `shift_code` | 班次 |
| 4 | `handover_staff_id` | 交班人 |
| 5 | `receive_staff_id` | 接班人 |
| 6 | `team_summary` | 班组概况（在院、新入、出院、手术、危重） |
| 7 | `shift_data` | 本班数据（体征数、告警数、给药率、记录数、任务） |
| 8 | `supplement` | 补充说明全文 |
| 9 | `role` | 交班/接班 |
| 10+ | 每条明细 `item_type:bed_no:content` | 重点患者与待办全文 |

**为什么必须包含全部明细内容。** 若只摘要单号与时间，DBA 可直接改 `m08_handover_item.content`（把「14:00 眼压复查」改成「无异常」）而不触发摘要变化，交接单就成了可事后篡改的文书。摘要必须覆盖**所有会被人阅读的文字**。

## 11. 异常处理与日志

### 11.1 异常分类

| 类别 | 示例 | 处理 |
|---|---|---|
| 参数校验异常 | 日期区间非法、原因过短 | 返回 4xx 错误码，前端高亮字段 |
| 状态冲突异常 | 周期状态不允许发布、交接单已签名 | 返回错误码 + 当前状态，前端刷新 |
| 权限异常 | 越权查看他病区、实习护士签名 | 返回 `"0807075"` / `"0807058"`，记审计 |
| 业务规则异常 | 排班冲突、床边核对未完成 | 返回错误码 + 明细，阻断操作 |
| 上游服务异常 | M01-10 不可用、M02-05 不可用 | 阻断并明确提示；可降级的走降级 |
| 并发冲突 | 两人同时编辑同一交接单 | 编辑锁 + `version` 乐观锁，返回 `"0807065"` |
| 系统异常 | 数据库超时、Redis 不可用 | 500 + trace_id，告警 |

| AC-32 | 签名间隔过短 | 交班签名 2 秒后接班签名 | 返回 `"0807053"` |
| AC-33 | 双签完成 | 间隔 10 秒完成接班签名 | 状态 SIGNED，任务批量转移 |
| AC-34 | 已签名不可改 | 尝试编辑已签名交接单 | 返回 `"0807055"` |
| AC-35 | 退回重做 | 接班护士退回，原因 12 字 | 状态回 DRAFT |
| AC-36 | 交接质量统计 | 查询 10-01~10-31 | 返回完成率、按时率、床边执行率、遗漏率 |
| AC-37 | 排班模板管理 | 新建、修改、删除模板 | 正常，被引用的不可删 |
| AC-38 | 当班护士查询 | 调用内部契约 | 返回在岗护士与签到状态 |
| AC-39 | 模块降级 | 停 M08-04 | 交接单仍生成，`degraded_modules=["M08-04"]` |
| AC-40 | 实习护士不能签名 | 实习护士点击签名 | 返回 `"0807058"` |

### 12.2 性能验收

|---|---|---|
| PF-01 | 排班周期列表查询 | P95 ≤ 200ms |

### 12.3 数据验收

| 编号 | 验收项 | 验证方法 |
|---|---|---|
| DA-01 | 班次号唯一 | 同周期重复生成不得产生重复 `period_no` |
| DA-02 | 交接单号唯一 | 同日 999 次生成不重复 |
| DA-03 | 同班次病区只有一份有效交接单 | DB 部分唯一索引验证 |
| DA-04 | 已签名交接单不可修改 | 触发器 UPDATE 抛异常 |
| DA-05 | 签名摘要覆盖全部内容 | 改任一明细后验签失败 |
| DA-06 | 签到记录唯一性 | 同班次同人只有一条非作废记录 |
| DA-07 | 排班变更留痕完整 | 每次修改写 `m08_shift_log` |
| DA-08 | 数据权限生效 | 护士查他病区返回空或 `"0807075"` |
| DA-09 | 患者姓名脱敏 | 列表接口返回 `张**` |
| DA-10 | 日志只增 | `m08_shift_log` / `m08_handover_log` 禁止 UPDATE/DELETE |

### 12.4 安全验收

| 编号 | 验收项 | 验证方法 |
|---|---|---|
| SC-01 | 未登录访问被拒 | 无 token 调任意接口返回 401 |
| SC-02 | 越权访问被拒 | 护士调 `m08:schedule:manage` 返回 403 |
| SC-03 | 实习护士签名被拒 | 返回 `"0807058"` |
| SC-04 | 系统管理员无业务权限 | 调交接单查询返回 403 |
| SC-05 | 防代签 | 同人两次签名返回 `"0807054"` |
| SC-06 | 签名口令错误锁定 | 错 3 次后 5 分钟内拒绝 |
| SC-07 | SQL 注入防护 | 关键词入参不产生注入 |
| SC-08 | XSS 防护 | 补充说明含 `<script>` 不执行 |
| SC-09 | 时间防篡改 | 传未来签到时间被拒 |
| SC-10 | 审计日志完整 | 每个写操作都有 M02-06 记录 |
