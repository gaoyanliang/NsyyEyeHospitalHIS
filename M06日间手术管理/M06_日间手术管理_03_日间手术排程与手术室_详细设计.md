## 1. 模块概述

### 1.1 模块定位

M06-03 是日间手术的**资源编排器**。它回答三个问题：

1. **这台手术安排在哪一天、哪个手术间、第几台？**（台次编排）
2. **哪四位医生护士同时到位？**（人员编排）
3. **什么时候上线、什么时候下台、什么时候能接下一台？**（时间编排）

```
┌──────────────────────────────────────────────────────────────────────────┐
│                         M06 日间手术全流程                                │
└──────────────────────────────────────────────────────────────────────────┘

  M07-03 开手术医嘱
        │
        ▼
  ┌─────────────┐   准入通过
  │  M06-01     │──────────────┐
  │ 申请与准入   │               │
  └─────────────┘               ▼
                          ┌─────────────────────────────────┐
                          │        M06-03 排程与手术室       │
                          │                                 │
                          │  ┌─────────────────────────┐    │
                          │  │ ① 台次池（手术间×时段）  │    │
                          │  │    OR-01 08:00~08:45    │    │
                          │  │    OR-01 09:00~09:45    │    │
                          │  │    OR-02 08:00~08:30    │    │
                          │  └─────────────────────────┘    │
                          │  ┌─────────────────────────┐    │
                          │  │ ② 人员池（医生×护士）    │    │
                          │  │    主刀 / 一助 / 麻醉    │    │
                          │  │    器械 / 巡回 / 洗手     │    │
                          │  └─────────────────────────┘    │
                          │  ┌─────────────────────────┐    │
                          │  │ ③ 时间轴（上线→下台）    │    │

                          │  └─────────────────────────┘    │
                          └───────────────┬─────────────────┘
                                          │ 排程确定
                    ┌─────────────────────┼─────────────────────┐
                    ▼                     ▼                     ▼
            ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
            │  M06-02      │     │  M06-04      │     │  M06-05      │
            │ 术前准备      │     │ 术前核对      │     │ 术后复苏      │
```

**一句话概括：** 排程定下来之后，术前准备的 T-7/T-3/T-1 都是从 `surgery_start_at` 倒推出来的；没有人排程，M06-02 就算不出"该什么时候禁食"。

### 1.2 为什么独立成子模块

**理由一：排程是"资源约束求解"，与申请准入是完全不同的技术问题。**

| 维度 | M06-01 申请与准入 | M06-03 排程与手术室 |
|---|---|---|
| 核心问题 | 能不能做（是/否判定） | 什么时候做、谁做、在哪做（组合优化） |
| 输入 | 患者体征、手术配置、医师资质 | 手术间可用时段、人员可用时段、术式时长 |
| 算法 | 规则逐条判定，O(n) | 约束满足 + 贪心/回溯，O(n²)~O(n³) |
| 失败原因 | 单个判定项不过 | 时段冲突、人员冲突、设备冲突 |
| 时间敏感度 | 低（判定结果 30 分钟有效） | 高（一台改期引发连锁调整） |

合在一起会出现"准入判定器里混着排程算法"的代码，两类规则互相污染。

**理由二：手术间是医院里最贵的资源，必须独立核算利用率。**

一间标准眼科手术间（含层流、显微镜、超乳仪）投资约 80~150 万元，日均运行成本（折旧 + 人力 + 消毒 + 耗材基数）约 3,000~5,000 元。一天排 8 台和排 5 台，单台分摊成本差 60%。

| 指标 | 计算 | 作用 |
|---|---|---|
| 手术间利用率 | 占用分钟 / 可用分钟 | 决定"要不要再加一间手术间" |
| 准点开台率 | 按计划时刻开台台次 / 总台次 | 反映术前准备与患者流转 |
| 接台间隔时长 | 下一台开始 − 上一台结束 | 反映护士配合与消毒效率 |
| 空台率 | 空闲时段 / 可用时段 | 反映排程与患者取消 |

**这些指标必须以手术间为主体统计**，放在申请单里算不出来（申请单没有"手术间"这个维度）。

**理由三：排程变更的影响面远超单张申请单。**

一台手术改期要联动修改六处：

```
原申请单 surgery_date 10-23 08:00 OR-01
  → 改期为 10-24 09:00 OR-02
    ├─► M06-02 术前准备：全部 8 个准备项的 planned_at 重算（T-7/T-3/T-1 全变）
    ├─► M06-04 核对表：手术间、台次号、接台时间全变
    ├─► M06-05 复苏床位：原定 OR-01 相邻复苏位要释放、OR-02 的重新分配
    ├─► M14-08 耗材：已备台的耗材要退库（可能涉及晶体已开封无法退）
    ├─► M16-03 日间结算：预交金模式下的费用预估要重算
    └─► M03-05 患者通知：要重新通知患者（可能已出发）
```

放在 M06-01 里做，意味着"准入子模块要懂排程、准备、复苏、耗材、结算"——职责爆炸。放在 M06-03 里做，是"排程的子模块负责发起联动"。

**理由四：手术间与人员是跨申请单共享的资源池。**

一个手术间一天做 8 台手术，分别属于 8 张申请单、可能 5 位不同主刀。这是"多对一"的资源争用关系，天然需要独立的资源池模型（时段 + 占用 + 冲突检测），而不是挂在任意一张申请单下。

### 1.4 概念辨析

**排程 ≠ 预约 ≠ 排班**

| 概念 | 含义 | 归属 |
|---|---|---|
| **排班**（Scheduling of Staff） | 医生护士哪天上班、在哪个科室 | M01-02 人事排班 |
| **排程**（Scheduling of Surgery） | 这台手术哪天做、几点的第几台 | **M06-03** |
| **预约**（Appointment） | 患者和医院约定一个到院时间 | M04 门诊预约 / M06-03 手术预约 |

一句话区分：排班是人什么时候在；排程是台什么时候做；预约是患者什么时候来。

**台次 ≠ 时段**

- **时段**（`m06_or_slot`）：手术间的"时间格子"，如 OR-01 在 10-23 的 08:00~08:45。
- **台次**（`m06_or_schedule`）：占用某个时段的一次手术安排。

一个时段只能被一个台次占用（可配置为 2 台重叠用于"接台准备"，见 §3.3）。

**计划时长 ≠ 实际时长**

- **计划时长**：`surgery_duration_minutes + turnover_minutes`，来自 M01-07 术式定义。
- **实际时长**：`actual_end_at - actual_start_at`，来自 M09 回写或护士手工登记。

排程偏差分析（`actual − planned`）是唯一能回答"我们的排程准不准"的数据。

**停台 ≠ 取消**

| 概念 | 场景 | 影响 |
|---|---|---|
| **取消**（Cancel） | 这台手术不做了 | 释放时段，患者可能改期或放弃 |
| **停台**（Suspend） | 手术间/医生临时不可用（设备故障、医生急诊） | 该时段所有台次要重新安排 |

停台是"资源不可用"，取消是"手术不做"。停台会连带引发多台改期。

### 1.5 模块目标

| 指标 | 目标 | 现状（无系统） | 说明 |

## 2. 业务范围与边界

### 2.1 范围内

1. **手术间资源管理**：手术间台账、可用时段模板、临时停台。
2. **时段生成与配额**：按周模板生成日时段、按术式时长切分时段、配额计算。
3. **手术排程**：为已准入的申请单选择日期 + 手术间 + 时段，计算时间轴。
4. **人员编排**：主刀、一助、麻醉医生、器械护士、巡回护士的分配与冲突检测。
5. **冲突检测**：时段冲突、人员冲突、设备冲突、患者冲突（同日两台）、间隔不足。
6. **改期与转台**：改期（换日期/手术间）、转台（换手术间）、换主刀、插台（加急）。
7. **停台与批量改期**：停台审批、受影响台次的重排向导。
8. **实际执行登记**：实际开台/结束时刻登记（M09 回写或人工补录）。
9. **排程看板与统计**：日/周排程看板、手术间利用率、准点率、接台间隔、空台率。

## 3. 业务模型

### 3.1 手术间模型

**手术间是排程的原子资源。**

```
┌──────────────────────────────────────────────────────────────────────┐
│  m06_or_room（手术间台账）                                           │
├──────────────────────────────────────────────────────────────────────┤
│  room_code    OR-01 / OR-02 / OR-03 / OR-04                          │
│  room_name    一号手术间                                              │
│  room_type    STANDARD（标准） / CLEAN（层流洁净） / INFECTIOUS（感染）│
│  microscope   显微镜型号（ZEISS_LUMERA / LEICA_PROVIDO）              │
│  phaco        超乳仪型号（ALCON_CENTURION / BAUSCH_STELLARIS）         │
│  is_emergency_reserved  是否预留急诊（TRUE 则 20% 时段不开放排程）      │
│  daily_capacity_minutes 日可用分钟（默认 480 = 8h）                    │
│  turnover_minutes       接台间隔（默认 20）                            │
│  status       ACTIVE / MAINTENANCE / DISABLED                        │
└──────────────────────────────────────────────────────────────────────┘
```

**为什么手术间要有显微镜与超乳仪型号字段**：不同术式需要不同设备。玻璃体切除需要广角观察系统，白内障超声乳化需要超乳仪。排程时必须校验"这个手术间有没有这台手术需要的设备"（见 §8 R-05）。设备型号从 M01-07 `md_operation.equipment_ids` 与本表的对应关系校验。

**眼科手术间的特殊要求**：

| 术式 | 特殊要求 | 影响排程 |
|---|---|---|
| 白内障超声乳化 | 超乳仪 | 只有装了超乳仪的手术间可排 |
| 玻璃体切除 | 玻切机 + 广角系统 | 只有玻切手术间可排，且时长较长（60~120 分钟） |
| 玻璃体腔注药 | 仅需无菌条件 | 任何手术间均可，可在"注药专场"批量排 |
| 斜视矫正 | 需同视机术中验证 | 部分医院术中不验证，按普通排 |
| 眼内炎急诊 | 感染手术间 | 必须最后台，且术后需终末消毒 60 分钟 |

**注药专场**：玻璃体腔注药单台仅需 10~15 分钟，40 个患者排一天不可行（接台 20 分钟 > 手术 15 分钟）。因此 M06-03 支持"专场模式"（`m06_or_session.session_type = 'INJECTION'`），专场内接台间隔降到 5 分钟，且可多个患者在同一手术间循环。

### 3.2 时段模型

**时段 = 手术间 × 日期 × 起止时间。**

```
10-23 一号手术间（OR-01）时段表
┌──────────┬──────────┬──────────┬──────────┬────────────────────────┐
│ 时段号    │ 开始     │ 结束     │ 状态      │ 说明                    │
├──────────┼──────────┼──────────┼──────────┼────────────────────────┤
│ SLOT-01  │ 08:00    │ 08:45    │ BOOKED   │ 白内障超乳（王医生）    │
│ SLOT-02  │ 09:05    │ 09:50    │ BOOKED   │ 白内障超乳（王医生）    │
│ SLOT-03  │ 10:10    │ 10:55    │ BOOKED   │ 白内障超乳（李医生）    │
│ SLOT-04  │ 11:15    │ 12:00    │ FREE     │ 可排                    │
│ ─────────│──── 午休 ─────│          │                        │
│ SLOT-05  │ 13:30    │ 14:15    │ BOOKED   │ 翼状胬肉（张医生）      │
│ SLOT-06  │ 14:35    │ 15:20    │ RESERVED │ 急诊预留                │
│ SLOT-07  │ 15:40    │ 16:25    │ FREE     │ 可排                    │
│ SLOT-08  │ 16:45    │ 17:30    │ FREE     │ 可排                    │
└──────────┴──────────┴──────────┴──────────┴────────────────────────┘
```

**时段状态机（5 态）**

```
                    ┌────────────┐
                    │   FREE     │  ← 初始：可排
                    └─────┬──────┘
                          │ 排程
                          ▼
                    ┌────────────┐
              ┌─────│  BOOKED    │─────┐
              │     └─────┬──────┘     │
              │           │ 停台        │ 释放
              │           ▼             │
              │     ┌────────────┐     │
              │     │ SUSPENDED  │     │
              │     └─────┬──────┘     │
              │           │ 停台解除    │
              │           ▼             ▼
              │     ┌────────────┐  ┌────────────┐
              └────►│   FREE     │  │  RESERVED  │ 急诊预留
                    └────────────┘  └────────────┘
```

| 状态 | 中文 | 可操作 |
|---|---|---|
| `FREE` | 空闲 | 可排程、可设预留 |
| `BOOKED` | 已排 | 可改期、可取消、可停台 |
| `SUSPENDED` | 已停台 | 需重新安排受影响的台次 |
| `RESERVED` | 急诊预留 | 只有急诊手术可排，需护士长授权 |

**时段时长如何确定**

时段时长不是固定的，而是按术式切分：

```
时段起始 = 上时段结束 + turnover_minutes
时段时长 = surgery_duration_minutes（术式定义）向上取整到 slot_minutes（默认 5 分钟）
```

例：白内障超乳 `duration_minutes=40`、`turnover_minutes=20`、`slot_minutes=5`
→ 时段 08:00~08:45（45 分钟 = 40 手术 + 5 余量），下一时段 08:50~09:35

**为什么时段不预先固定切好而是排程时动态计算**：不同术式时长差异极大（注药 15 分钟，玻切 120 分钟）。预切 45 分钟格子会让玻切占 3 格、注药浪费 30 分钟。

### 3.3 时间轴模型

一台手术的完整时间轴（从患者到达到离开手术间）：

```
计划时间轴                                   实际时间轴
─────────────────────────────────────────  ─────────────────────────
T-60min  患者到达日间病房、报到              08:00  actual_arrive_at
T-30min  更衣、核对、建立静脉通道            08:05
T-15min  术前核对（M06-04 Time-Out）         08:20  check_time_out_at
T-10min  转运至手术间                       08:25  actual_transfer_at
T-5min   摆体位、消毒铺巾                    08:30
T-0      开始手术（计划 surgery_start_at）    08:35  actual_start_at
                                                    ↑ 偏差 +5 分钟
        手术进行中（surgery_duration_minutes）
                                             09:20  actual_end_at
T+40min  手术结束
        包扎、撤单、观察                     09:25
T+50min  离开手术间 → 送回日间病房           09:30  actual_leave_at
                                                    ↑ 偏差 +10 分钟
        ────────────────────────────────────
        接台间隔（turnover_minutes = 20 分钟）
        消毒、清理、重置手术间
                                             09:50  下一台可开始
```

**为什么"上线"要区分 `actual_start_at` 和 `surgery_start_at`**：

- `surgery_start_at` 是**计划值**，决定术前准备的全部时序（T-7 开单/禁食起算/T-60 报到）。
- `actual_start_at` 是**实际值**，用于准点率统计与偏差分析。

两者混淆会导致：准点率永远 100%（因为计划 = 计划），或术前准备时序随实际变更而乱跳。

**接台间隔（Turnover）的组成**

| 环节 | 时长 | 说明 |
|---|---|---|
| 患者离场与转运 | 3~5 分钟 | 送出手术间、送回病房 |
| 术间清理（器械、污物） | 5~8 分钟 | 器械护士 + 巡回护士 |
| 消毒（物表擦拭、紫外线/汽化） | 5~10 分钟 | 不同术式要求不同 |
| 新患者进入与摆位 | 5~8 分钟 | 与上一步可部分并行 |

默认 `turnover_minutes = 20`，来源 M01-07 `md_operation.turnover_minutes`（若无则用手术间默认值）。**感染手术后接台需终末消毒 60 分钟**，这是硬约束（§8 R-08）。

### 3.4 人员编排模型

**一台日间手术需要 4~6 名人员同时到位。**

| 角色 | 必需性 | 说明 | 来源 |
|---|---|---|---|
| 主刀医生 | 必需 | 手术执行者，需资质校验通过 | M06-01 资质准入结论 |
| 一助医生 | 视术式 | 部分术式要求（如玻切、复杂白内障） | M01-07 `md_operation.assistant_required` |
| 麻醉医生 | 视麻醉方式 | 局麻不需要，全麻/镇静必需 | M01-07 `md_anesthesia.need_anesthetist` |
| 器械护士 | 必需 | 术中器械传递 | 手术室排班 |
| 巡回护士 | 必需 | 术中巡回、记录、登记 | 手术室排班 |
| 洗手护士（部分医院与器械护士合并） | 视配置 | — | 手术室配置 |

**人员冲突检测**

同一人同一时段只能在一个手术间：

```
人员占用 = {(staff_id, date) → [(start, end, schedule_id), ...]}

冲突判定：existing.start < new.end AND existing.end > new.start
```

**人员可用时段来源**：

| 来源 | 用途 |
|---|---|
| M01-02 排班表 | 该员工今天是否上班 |
| M01-02 请假/外出 | 是否请假、外出学习 |
| M06-03 `m06_staff_leave` | 手术相关的特殊占用（如会议、急诊手术） |
| 已有台次 | 已被其他台次占用进行冲突检测 |

**为什么需要 `m06_staff_leave` 而不只用 M01-02 请假**：医生可能"在内科会诊"、"在门诊出诊"——M01-02 排班只记录"是否上班"，不记录"这个时间段在忙什么"。M06-03 需要更细的占用数据。

### 3.5 排程状态机

**台次状态机（9 态）**

```
                    ┌──────────────┐
                    │   DRAFT      │  排程草稿（未确认）
                    └──────┬───────┘
                           │ 提交
                           ▼
                    ┌──────────────┐
                    │  PENDING     │  待手术室确认
                    └──────┬───────┘
                           │ 确认
                           ▼
              ┌────────────────────────┐
              │     CONFIRMED          │  已排定（进术前准备）
              └────┬──────────┬────────┘
                   │          │
          患者到达 │          │ 停台/取消
                   ▼          ▼
              ┌────────┐  ┌────────────┐
              │ CHECKED│  │ SUSPENDED  │ 已停台
              │ _IN    │  └─────┬──────┘
              └───┬────┘        │ 重新安排
                  │             ▼
                  │        ┌────────────┐
                  │        │ RESCHEDULED│ 已改期
                  │        └────────────┘
                  │ 开台
                  ▼
              ┌──────────┐
              │IN_SURGERY│ 术中
              └────┬─────┘
                   │ 下台
                   ▼
              ┌──────────┐
              │ COMPLETED│ 已完成
              └──────────┘
```

| 状态 | 中文 | 终态 | 操作权限 |
|---|---|---|---|
| `DRAFT` | 排程草稿 | 否 | 排程员 |
| `PENDING` | 待确认 | 否 | 排程员提交、手术室确认 |
| `CONFIRMED` | 已排定 | 否 | 手术室护士长确认 |
| `CHECKED_IN` | 已报到 | 否 | 日间病房护士 |
| `IN_SURGERY` | 术中 | 否 | M09 回写或护士登记 |
| `COMPLETED` | 已完成 | **是** | 自动 |
| `SUSPENDED` | 已停台 | 否 | 护士长 |
| `RESCHEDULED` | 已改期 | **是** | 自动（原台次终结、新台次创建） |
| `CANCELLED` | 已取消 | **是** | 排程员/护士长 |

**为什么 `RESCHEDULED` 是终态而不是把原台次改到新日期**：

- 改期后术前准备的全部时序要重算，如果原地改日期，M06-02 的历史准备项（已执行的那些）与新的 T-7 会矛盾。
- 保留原台次（`RESCHEDULED`）+ 创建新台次，形成 `台次 A → RESCHEDULED → 台次 B` 的链条，可以统计"改期率"和"改期原因分布"。
- 与 M06-01 的 `INELIGIBLE` 终态设计同源：**保留历史比修改历史更重要**。

### 3.6 冲突检测模型

**五类冲突**

| 类型 | 判定 | 严重度 | 处理 |
|---|---|---|---|
| `SLOT_OCCUPIED` | 目标时段已被占用 | BLOCK | 必须换时段 |
| `STAFF_CONFLICT` | 某人在该时段已有其他台次 | BLOCK | 换人或换时段 |
| `STAFF_UNAVAILABLE` | 某人该时段请假/不在岗 | BLOCK | 换人 |
| `EQUIPMENT_MISSING` | 手术间无该术式所需设备 | BLOCK | 换手术间 |
| `INTERVAL_TOO_SHORT` | 与前后台次间隔 < turnover | WARN | 需护士长确认 |
| `SAME_PATIENT_SAME_DAY` | 同一患者同日两台 | WARN | 需说明 |
| `SAME_PATIENT_EYE_GAP` | 同一患者双眼术式间隔 < 14 天 | WARN | 需说明 |
| `ROOM_RESERVED` | 时段为急诊预留 | BLOCK | 需护士长授权 |

**冲突检测的时机**

```
① 排程预览（preview）  → 返回全部冲突，不落库
② 保存排程（create）   → 再检一次（防并发），有 BLOCK 直接拒
③ 保存后锁定时段       → PostgreSQL 行锁 + Redis 分布式锁
```

**为什么预览和保存都要检**：预览时没冲突，但用户填了 5 分钟才点保存，这 5 分钟里时段可能被另一个人占了。保存时必须重检。

**并发保护的实现**

```python
# ① Redis 分布式锁（粗粒度，30 秒）
lock_key = "m06:schedule:lock:%s:%s" % (date_str, room_code)
acquired = await redis.set(lock_key, "1", nx=True, ex=30)

# ② PostgreSQL 行锁（细粒度，事务内）
slot = await db.execute(
    select(M06OrSlot)
    .where(M06OrSlot.id == slot_id)
    .with_for_update()
)
```

**两级锁的必要性**：Redis 锁防"两个人同时排同一手术间"，DB 行锁防"锁过期后仍并发写"。

### 3.7 改期与联动模型

**改期的六处联动**（这就是 M06-03 独立成子模块的核心理由之一）

```
改期（仅换日期时间，不换手术间）
  │
  ├─① 原台次 status = RESCHEDULED（终态，保留历史）
  ├─② 新建台次 status = PENDING → CONFIRMED
  ├─③ 原时段 status = FREE（释放）
  ├─④ 新时段 status = BOOKED（占用）
  ├─⑤ 发事件 m06.schedule.changed
  │     ├─► M06-02 on-scheduled：重算 8 个准备项的 planned_at
  │     ├─► M06-04：重建核对表（术间、台次、接台时间全变）
  │     ├─► M06-05：释放原复苏位、重新分配
  │     ├─► M14-08：退还已备台耗材（若晶体已开封则无法退，需告警）
  │     ├─► M16-03：重算费用预估（预交金模式）
  │     └─► M03-05：重新通知患者
  └─⑥ 记录改期日志
```

**改期 vs 转台 vs 换主刀**

| 操作 | 变更内容 | 影响面 |
|---|---|---|
| **改期** | 日期或时刻 | 六处全变 |
| **转台** | 只换手术间（同日同时刻） | 术间、设备校验、耗材位置；术前准备时序不变 |
| **换主刀** | 只换主刀医生 | 资质要重检、人员冲突重检；其他不变 |
| **插台** | 在已排序列中插入一台（加急） | 后续台次全部顺延 |

**转台不重算准备时序的理由**：术前准备的时间锚点是 `surgery_start_at`，转台时 `surgery_start_at` 不变（只换房间），所以 T-7/T-3/T-1 全不变。这是 M06-03 支持"最小变更"的关键。

### 3.8 停台与批量改期

**停台三种场景**

| 场景 | 触发 | 影响台次数 |
|---|---|---|
| 设备故障 | 超乳仪坏了 | 该手术间全天的台次 |
| 医生临时不可用 | 主刀急会诊/生病 | 该医生的台次 |
| 手术间临时征用 | 急诊抢救 | 部分时段 |

**停台流程**

```
停台申请（护士长填写原因、影响范围）
  → 影响台次预览（列出所有受影响台次）
  → 批量改期向导：
      ├─ 方案 A：顺延到次日同一时段
      ├─ 方案 B：换到其他手术间同时段
      ├─ 方案 C：逐台手工重新安排
      └─ 方案 D：直接取消（患者情况允许时）
  → 确认 → 批量执行 → 通知各方
```

**批量改版的原子性**

```python
async def batch_reschedule(items, strategy, reason, operator):
    """批量改期。

    策略：要么全成，要么全不成（事务）。
    例外：某些台次物理上不可改（如新日期无空档），
    允许部分成功并在返回中列出失败明细。
    """
    # ① 预演：先全部试算，收集失败
    preview = [await _try_reschedule(db, it, strategy) for it in items]
    fails = [p for p in preview if not p.ok]
    if fails and strategy == "ALL_OR_NOTHING":
        raise BizException("0603026", "批量改期失败：%d 台无法安排"
                           % len(fails), data={"fails": fails})

    # ② 执行
    succeeded = []
    for it in preview:
        if it.ok:
            await _do_reschedule(db, it, reason, operator)
            succeeded.append(it)
    return succeeded
```

**为什么允许部分成功**：真实场景中"次日没有空档"是常见的，全有或全无会让护士长反复尝试。默认用"部分成功 + 失败明细"（可在参数中切换为 `ALL_OR_NOTHING`）。

### 3.9 专场与批量排程

**眼科日间手术三种典型编排**

| 编排 | 场景 | 时长/台 | 接台 | 日排台数 |
|---|---|---|---|---|
| 普通排程 | 白内障、翼状胬肉 | 40~60 分钟 | 20 分钟 | 8~10 |
| **注药专场** | 玻腔注药（AMD/糖网） | 10~15 分钟 | 5 分钟 | 30~40 |
| **玻切专场** | 复杂眼底 | 60~120 分钟 | 25 分钟 | 4~5 |

专场（`m06_or_session`）是一段时间标签：

```
10-24 一号手术间
├── 上午专场（08:00~12:00）：INJECTION，接台 5 分钟，可排 30 台
└── 下午专场（13:30~17:30）：NORMAL，接台 20 分钟，可排 6 台
```

专场的价值：**接台间隔按专场覆盖**，避免注药患者每个之间空 20 分钟浪费 40%。

### 3.10 排程算法

**排程推荐算法（供排程员参考，不强制）**

```
输入：apply_id（术式、眼别、麻醉方式）、候选日期范围
输出：按推荐度排序的时段列表

Step 1  取术式参数
        duration = md_operation.duration_minutes
        turnover = md_operation.turnover_minutes OR room.turnover_minutes
        equipment_ids = md_operation.equipment_ids

Step 2  候选手术间筛选
        rooms = [r for r in m06_or_room
                 if r.status == 'ACTIVE'
                 and _has_equipment(r, equipment_ids)]

Step 3  时间窗筛选
        for date in candidate_dates:
            校验 date >= today + min_lead_days（参数，默认 1）
            校验 date <= today + max_lead_days（参数，默认 90）

Step 4  时段匹配
        for room in rooms:
            slots = 查找该房间当天能容纳 duration + turnover 的空闲时段
            优先级：
              ① 完全空档（slot.status = 'FREE'）      
              ② 可合并的相邻空档
              ③ 无（可插台但需改后续台次，WARN）

Step 5  人员可用性
        for each candidate:
            主刀在该时段无其他台次
            麻醉医生（若需要）在该时段无其他台次
            器械护士、巡回护士在该时段无其他台次
            （若某人不满足，标记可替代人）

Step 6  打分排序
        score = w1 × 时段连续度（同医生连台）
              + w2 × 手术间偏好（同术式集中）
              + w3 × 患者便利度（与门诊日期接近）
              + w4 × 设备匹配度
        按 score 降序返回前 10 个候选
```

**为什么只给推荐不强制**：排程是人的判断——护士长知道"王医生的第二台可能会拖到 11 点""这台患者的晶体还没到"。系统给候选，人做决定。

### 6.2 错误码规范

| `"0603003"` | 手术间不存在或已停用 | `room.status≠ACTIVE` |

| `"0603010"` | 该时段为急诊预留，需护士长授权 | `slot.status='RESERVED'` |
| `"0603011"` | 该患者当日已有其他手术 | 同日两台 |

| `"0603017"` | 受影响台次超过 10 台需医务科审批 | 批量停台 |

| `"0603026"` | 批量改期失败 | 部分/全部无法安排 |
| `"0603027"` | 排程冲突未确认，不可保存 | WARN 冲突未勾选知悉 |

| `"0603029"` | 手术间服务不可用 | M01-07/本地服务超时 |
| `"0603030"` | 插台会导致后续台次超时，需确认 | 插台 WARN |

```python
    @classmethod
    async def preview(cls, db: AsyncSession, apply_id: int,
                      date_from: Optional[date],
                      date_to: Optional[date]) -> dict:
        """生成候选时段并打分。"""
        apply = await db.get(M06DaySurgery, apply_id)
        if not apply:
            raise BizException("0603001", "申请单不存在")
        if apply.status != "ELIGIBLE":
            raise BizException("0603001", "申请单未通过准入，不可排程")

        cfg = await SurgeryClient.get_full_config(apply.operation_code)
        duration = int(cfg["operation"]["duration_minutes"])
        turnover = int(cfg["operation"].get("turnover_minutes")
                       or get_config("M06.SCHEDULE.TURNOVER_MINUTES", 20))
        equipment_ids = cfg["operation"].get("equipment_ids") or []

        min_lead = get_config("M06.SCHEDULE.MIN_LEAD_DAYS", 1)
        max_lead = get_config("M06.SCHEDULE.MAX_LEAD_DAYS", 90)
        today = date.today()
        d_from = date_from or (today + timedelta(days=min_lead))
        d_to = date_to or min(today + timedelta(days=max_lead),
                              d_from + timedelta(
                                  days=cls.PREVIEW_HORIZON_DAYS))
        d_from = max(d_from, today + timedelta(days=min_lead))
        d_to = min(d_to, today + timedelta(days=max_lead))

        rooms = (await db.execute(
            select(M06OrRoom).where(
                M06OrRoom.status == "ACTIVE",
                M06OrRoom.is_deleted.is_(False),
            )
        )).scalars().all()

        candidates = []
        for room in rooms:
            if not cls._has_equipment(room, equipment_ids):
                continue
            for d in cls._date_range(d_from, d_to):
                slots = await cls._find_free_slots(
                    db, room.room_code, d, duration, turnover)
                for slot in slots:
                    staff = await cls._resolve_staff(
                        db, apply, slot.start_dt, duration)
                    conflicts = await cls._detect_conflicts(
                        db, apply, slot, staff, duration, turnover)
                    if any(c["severity"] == "BLOCK" for c in conflicts):
                        continue
                    score = cls._score(apply, room, slot, d, staff)
                    candidates.append({
                        "date": d.isoformat(),
                        "room_code": room.room_code,
                        "room_name": room.room_name,
                        "slot_id": slot.slot_id,
                        "start_time": slot.start_dt.isoformat(),
                        "end_time": slot.end_dt.isoformat(),
                        "score": round(score["total"], 2),
                        "score_detail": score["detail"],
                        "conflicts": conflicts,
                        "staff_available": staff,
                    })

        candidates.sort(key=lambda x: x["score"], reverse=True)
        return {
            "apply_id": apply_id,
            "ds_no": apply.ds_no,
            "operation_code": apply.operation_code,
            "operation_name": apply.operation_name,
            "duration_minutes": duration,
            "turnover_minutes": turnover,
            "candidates": candidates[:cls.MAX_CANDIDATES],
            "total_candidates": len(candidates),
            "generated_at": datetime.now().isoformat(),
        }

    @staticmethod
    def _date_range(d_from: date, d_to: date):
        cur = d_from
        while cur <= d_to:
            yield cur
            cur += timedelta(days=1)

    @staticmethod
    def _has_equipment(room, equipment_ids: List[int]) -> bool:
        """手术间是否具备所需设备。"""
        if not equipment_ids:
            return True
        room_equip = set()
        if room.microscope:
            room_equip.add(room.microscope)
        if room.phaco:
            room_equip.add(room.phaco)
        if isinstance(room.extra_equipment, list):
            room_equip.update(room.extra_equipment)
        return all(str(e) in room_equip for e in equipment_ids)

    @classmethod
    async def _find_free_slots(cls, db: AsyncSession, room_code: str,
                               d: date, duration: int,
                               turnover: int) -> List[dict]:
        """查找该手术间当天能容纳 duration + turnover 的空闲时段。"""
        slot_minutes = get_config("M06.SCHEDULE.SLOT_MINUTES", 5)
        need = cls._round_up(duration, slot_minutes)

        rows = (await db.execute(
            select(M06OrSlot).where(
                M06OrSlot.room_code == room_code,
                M06OrSlot.slot_date == d,
                M06OrSlot.status.in_(["FREE", "BOOKED"]),
                M06OrSlot.is_deleted.is_(False),
            ).order_by(M06OrSlot.start_time.asc())
        )).scalars().all()

        out = []
        # ① 单个空闲时段足够长
        for s in rows:
            if s.status != "FREE":
                continue
            start_dt = datetime.combine(d, s.start_time)
            end_dt = start_dt + timedelta(minutes=need + turnover)
            if datetime.combine(d, s.end_time) >= end_dt:
                out.append({
                    "slot_id": s.id,
                    "start_dt": start_dt,
                    "end_dt": end_dt,
                    "merged": False,
                })

        # ② 相邻空闲时段合并（仅当中间无已排台次）
        free = [s for s in rows if s.status == "FREE"]
        i = 0
        while i < len(free):
            j = i
            start_dt = datetime.combine(d, free[i].start_time)
            cur_end = datetime.combine(d, free[i].end_time)
            while j + 1 < len(free):
                nxt = free[j + 1]
                nxt_start = datetime.combine(d, nxt.start_time)
                if nxt_start != cur_end:
                    break
                j += 1
                cur_end = datetime.combine(d, nxt.end_time)
            total = int((cur_end - start_dt).total_seconds() // 60)
            if j > i and total >= need + turnover:
                out.append({
                    "slot_id": free[i].id,
                    "start_dt": start_dt,
                    "end_dt": start_dt + timedelta(minutes=need + turnover),
                    "merged": True,
                })
            i = j + 1
        return out

    @staticmethod
    def _round_up(value: int, step: int) -> int:
        if step <= 0:
            return value
        return ((value + step - 1) // step) * step

    @classmethod
    async def _resolve_staff(cls, db: AsyncSession, apply,
                             start_dt: datetime,
                             duration: int) -> Dict:
        """解析人员可用性。"""
        end_dt = start_dt + timedelta(minutes=duration)
        out = {}
        pairs = [
            ("surgeon", apply.surgeon_id, apply.surgeon_name),
            ("anesthetist", getattr(apply, "anesthetist_id", None),
             getattr(apply, "anesthetist_name", None)),
        ]
        for key, staff_id, staff_name in pairs:
            if not staff_id:
                out[key] = None
                continue
            busy = await cls._staff_busy(db, staff_id, start_dt, end_dt)
            leave = await cls._staff_on_leave(db, staff_id, start_dt.date())
            out[key] = {
                "staff_id": staff_id,
                "name": staff_name,
                "available": (not busy) and (not leave),
                "busy_schedule_id": busy,
                "on_leave": leave,
            }
        return out

    @staticmethod
    async def _staff_busy(db: AsyncSession, staff_id: int,
                          start_dt: datetime,
                          end_dt: datetime) -> Optional[int]:
        """该员工在该时段是否已有其他台次。"""
        row = (await db.execute(
            select(M06OrSchedule.id).where(
                or_(
                    M06OrSchedule.surgeon_id == staff_id,
                    M06OrSchedule.assistant_id == staff_id,
                    M06OrSchedule.anesthetist_id == staff_id,
                    M06OrSchedule.scrub_nurse_id == staff_id,
                    M06OrSchedule.circular_nurse_id == staff_id,
                ),
                M06OrSchedule.status.in_(
                    ["PENDING", "CONFIRMED", "CHECKED_IN", "IN_SURGERY"]),
                M06OrSchedule.surgery_start_at < end_dt,
                M06OrSchedule.expected_leave_at > start_dt,
                M06OrSchedule.is_deleted.is_(False),
            ).limit(1)
        )).scalar()
        return row

    @staticmethod
    async def _staff_on_leave(db: AsyncSession, staff_id: int,
                              d: date) -> bool:
        row = (await db.execute(
            select(M06StaffLeave.id).where(
                M06StaffLeave.staff_id == staff_id,
                M06StaffLeave.leave_date == d,
                M06StaffLeave.is_deleted.is_(False),
            ).limit(1)
        )).scalar()
        return row is not None

    @classmethod
    async def _detect_conflicts(cls, db: AsyncSession, apply, slot: dict,
                                staff: Dict, duration: int,
                                turnover: int) -> List[dict]:
        """八类冲突检测。"""
        conflicts = []
        start_dt = slot["start_dt"]
        end_dt = start_dt + timedelta(minutes=duration)

        # ① 时段占用
        occupied = (await db.execute(
            select(M06OrSchedule).where(
                M06OrSchedule.slot_id == slot["slot_id"],
                M06OrSchedule.status.in_(
                    ["PENDING", "CONFIRMED", "CHECKED_IN", "IN_SURGERY"]),
                M06OrSchedule.is_deleted.is_(False),
            ).limit(1)
        )).scalar()
        if occupied:
            conflicts.append({
                "type": "SLOT_OCCUPIED",
                "severity": "BLOCK",
                "message": CONFLICT_TEXT["SLOT_OCCUPIED"],
            })

        # ② 人员冲突 / 不可用
        for key, val in staff.items():
            if not val:
                continue
            if val.get("on_leave"):
                conflicts.append({
                    "type": "STAFF_UNAVAILABLE",
                    "severity": "BLOCK",
                    "message": "%s 当日请假" % val["name"],
                })
            elif val.get("busy_schedule_id"):
                conflicts.append({
                    "type": "STAFF_CONFLICT",
                    "severity": "BLOCK",
                    "message": "%s 该时段已有台次" % val["name"],
                })

        # ③ 急诊预留
        slot_row = await db.get(M06OrSlot, slot["slot_id"])
        if slot_row and slot_row.status == "RESERVED":
            conflicts.append({
                "type": "ROOM_RESERVED",
                "severity": "BLOCK",
                "message": CONFLICT_TEXT["ROOM_RESERVED"],
            })

        # ④ 接台间隔
        prev_row = (await db.execute(
            select(M06OrSchedule).where(
                M06OrSchedule.room_code == slot_row.room_code,
                M06OrSchedule.schedule_date == start_dt.date(),
                M06OrSchedule.expected_leave_at <= start_dt,
                M06OrSchedule.status.in_(["CONFIRMED", "COMPLETED"]),
                M06OrSchedule.is_deleted.is_(False),
            ).order_by(M06OrSchedule.expected_leave_at.desc()).limit(1)
        )).scalar()
        if prev_row:
            gap = int((start_dt - prev_row.expected_leave_at).total_seconds()
                      // 60)
            if gap < turnover:
                conflicts.append({
                    "type": "INTERVAL_TOO_SHORT",
                    "severity": "WARN",
                    "message": "与前一台次间隔 %d 分钟（标准 %d 分钟）"
                               % (gap, turnover),
                })

        # ⑤ 同患者同日
        same_day = (await db.execute(
            select(M06OrSchedule.id).where(
                M06OrSchedule.patient_id == apply.patient_id,
                M06OrSchedule.schedule_date == start_dt.date(),
                M06OrSchedule.status.in_(
                    ["PENDING", "CONFIRMED", "CHECKED_IN", "IN_SURGERY"]),
                M06OrSchedule.is_deleted.is_(False),
            ).limit(1)
        )).scalar()
        if same_day:
            conflicts.append({
                "type": "SAME_PATIENT_SAME_DAY",
                "severity": "WARN",
                "message": CONFLICT_TEXT["SAME_PATIENT_SAME_DAY"],
            })

        # ⑥ 双眼间隔
        gap_days = get_config("M06.SCHEDULE.BILATERAL_GAP_DAYS", 14)
        other_eye = (await db.execute(
            select(M06OrSchedule).where(
                M06OrSchedule.patient_id == apply.patient_id,
                M06OrSchedule.operation_code == apply.operation_code,
                M06OrSchedule.schedule_date != start_dt.date(),
                M06OrSchedule.status.in_(["CONFIRMED", "COMPLETED"]),
                M06OrSchedule.is_deleted.is_(False),
            )
        )).scalars().all()
        for oe in other_eye:
            if not oe.schedule_date:
                continue
            diff = abs((oe.schedule_date - start_dt.date()).days)
            if diff < gap_days:
                conflicts.append({
                    "type": "SAME_PATIENT_EYE_GAP",
                    "severity": "WARN",
                    "message": "与另一眼手术间隔 %d 天（建议 ≥%d 天）"
                               % (diff, gap_days),
                })
                break
        return conflicts

    @classmethod
    def _score(cls, apply, room, slot: dict, d: date,
               staff: Dict) -> Dict:
        """时段打分。"""
        # 连续性：同日同医生已有台次则加分
        continuity = 0.5
        if staff.get("surgeon") and staff["surgeon"].get("busy_schedule_id"):
            continuity = 0.3
        # 房间偏好：同术式集中
        room_pref = 0.9 if room.room_code.startswith("OR-0") else 0.75
        # 患者便利度：与申请日期越近越好
        try:
            apply_d = apply.created_at.date()
            delta = abs((d - apply_d).days)
            patient = max(0.3, 1.0 - delta * 0.05)
        except Exception:
            patient = 0.7
        equipment = 1.0
        total = (cls.SCORE_W_CONTINUITY * continuity
                 + cls.SCORE_W_ROOM * room_pref
                 + cls.SCORE_W_PATIENT * patient
                 + cls.SCORE_W_EQUIPMENT * equipment)
        return {
            "total": total,
            "detail": {
                "continuity": round(continuity, 2),
                "room_preference": round(room_pref, 2),
                "patient_convenience": round(patient, 2),
                "equipment_match": round(equipment, 2),
            },
        }

    # 创建 / 修改 / 确认
    # ------------------------------------------------------------------

    @classmethod
    async def create(cls, db: AsyncSession, body, user) -> dict:
        """创建排程。"""
        # ① 幂等与状态校验
        apply = await db.get(M06DaySurgery, body.apply_id)
        if not apply:
            raise BizException("0603001", "申请单不存在")
        if apply.status != "ELIGIBLE":
            raise BizException("0603001", "申请单未通过准入，不可排程")

        # ② 分布式锁（按手术间+日期）
        slot = await db.get(M06OrSlot, body.slot_id)
        if not slot:
            raise BizException("0603004", "时段不存在")
        lock_key = SHARED_LOCK_KEY % (slot.slot_date.isoformat(),
                                      slot.room_code)
        acquired = await redis_client.set(lock_key, "1", nx=True, ex=30)
        if not acquired:
            raise BizException("0603005", "排程繁忙，请稍后重试")

        try:
            # ③ 行锁锁定时段
            slot = (await db.execute(
                select(M06OrSlot).where(M06OrSlot.id == body.slot_id)
                .with_for_update()
            )).scalar_one()
            if slot.status != "FREE":
                raise BizException("0603005", "该时段已被占用")

            # ④ 术式参数
            cfg = await SurgeryClient.get_full_config(apply.operation_code)
            duration = int(cfg["operation"]["duration_minutes"])
            turnover = int(cfg["operation"].get("turnover_minutes")
                           or get_config("M06.SCHEDULE.TURNOVER_MINUTES", 20))

            # ⑤ 资质校验（换主刀时重检）
            if body.surgeon_id != apply.surgeon_id:
                auth = await SurgeryClient.check_auth(
                    body.surgeon_id, apply.operation_code)
                if not auth.get("allowed"):
                    raise BizException(
                        "0603028", "该医生未通过该术式资质校验")

            # ⑥ 冲突检测
            start_dt = datetime.combine(slot.slot_date, slot.start_time)
            staff = {
                "surgeon": {"staff_id": body.surgeon_id,
                            "name": apply.surgeon_name,
                            "available": True},
                "anesthetist": ({"staff_id": body.anesthetist_id,
                                 "name": None, "available": True}
                                if body.anesthetist_id else None),
            }
            pseudo = {"slot_id": slot.id, "start_dt": start_dt,
                      "end_dt": start_dt + timedelta(minutes=duration)}
            conflicts = await cls._detect_conflicts(
                db, apply, pseudo, staff, duration, turnover)
            blocked = [c for c in conflicts if c["severity"] == "BLOCK"]
            if blocked:
                raise BizException(
                    blocked[0]["type"] == "STAFF_CONFLICT"
                    and "0603007" or "0603005",
                    blocked[0]["message"],
                    data={"conflicts": conflicts})

            acked = set(body.acknowledged_warnings or [])
            unacked = [c for c in conflicts
                       if c["severity"] == "WARN"
                       and c["type"] not in acked]
            if unacked:
                raise BizException(
                    "0603027", "存在未确认的警告，请确认后再保存",
                    data={"warnings": unacked})

            # ⑦ 落库
            now = datetime.now()
            schedule = M06OrSchedule(
                schedule_no=await cls._next_schedule_no(db, slot.slot_date),
                schedule_date=slot.slot_date,
                room_code=slot.room_code,
                room_name=slot.room_name,
                slot_id=slot.id,
                apply_id=apply.id,
                ds_no=apply.ds_no,
                patient_id=apply.patient_id,
                patient_name=apply.patient_name,
                operation_code=apply.operation_code,
                operation_name=apply.operation_name,
                eye_side=apply.eye_side,
                surgeon_id=body.surgeon_id,
                surgeon_name=apply.surgeon_name,
                assistant_id=body.assistant_id,
                anesthetist_id=body.anesthetist_id,
                scrub_nurse_id=body.scrub_nurse_id,
                circular_nurse_id=body.circular_nurse_id,
                planned_duration_minutes=duration,
                turnover_minutes=turnover,
                surgery_start_at=start_dt,
                surgery_end_at=start_dt + timedelta(minutes=duration),
                expected_leave_at=start_dt + timedelta(
                    minutes=duration + 5),
                status="CONFIRMED" if body.confirm_immediately else "PENDING",
                seq_no=await cls._next_seq_no(
                    db, slot.room_code, slot.slot_date),
                remark=body.remark,
                created_by=user["employee_id"],
                created_at=now,
            )
            db.add(schedule)
            await db.flush()

            # ⑧ 锁定时段
            slot.status = "BOOKED"
            slot.schedule_id = schedule.id
            slot.updated_at = now

            # ⑨ 写冲突留痕
            for c in conflicts:
                db.add(M06ScheduleConflict(
                    schedule_id=schedule.id,
                    conflict_type=c["type"],
                    severity=c["severity"],
                    conflict_desc=c["message"],
                    is_acknowledged=(c["severity"] == "WARN"
                                     and c["type"] in acked),
                    acknowledged_by=(user["employee_id"]
                                     if c["type"] in acked else None),
                    acknowledged_at=(now if c["type"] in acked else None),
                    detected_at=now,
                ))

            await cls._log(db, schedule, "CREATE", user, None, "PENDING")
            await db.commit()

            if schedule.status == "CONFIRMED":
                await cls._after_confirm(db, schedule)

            return cls._dict(schedule, conflicts)
        finally:
            await redis_client.delete(lock_key)

    @staticmethod
    async def _next_schedule_no(db: AsyncSession, d: date) -> str:
        key = "m06:schedule:seq:%s" % d.strftime("%Y%m%d")
        seq = await redis_client.incr(key)
        await redis_client.expire(key, 172800)
        return "OP%s%04d" % (d.strftime("%Y%m%d"), seq)
        
    @staticmethod
    async def _next_seq_no(db: AsyncSession, room_code: str,
                           d: date) -> int:
        row = (await db.execute(
            select(func.coalesce(func.max(M06OrSchedule.seq_no), 0))
            .where(
                M06OrSchedule.room_code == room_code,
                M06OrSchedule.schedule_date == d,
                M06OrSchedule.is_deleted.is_(False),
            )
        )).scalar()
        return int(row or 0) + 1

    @classmethod
    async def confirm(cls, db: AsyncSession, schedule_id: int,
                      user) -> dict:
        """确认排程：进入术前准备。"""
        return await cls._transit(
            db, schedule_id, user, "CONFIRMED",
            from_status=("PENDING",), action="CONFIRM")

    @classmethod
    async def _after_confirm(cls, db: AsyncSession, schedule) -> None:
        """确认后的联动：通知准备、通知患者、备台耗材。"""
        payload = {
            "schedule_id": schedule.id,
            "schedule_no": schedule.schedule_no,
            "apply_id": schedule.apply_id,
            "ds_no": schedule.ds_no,
            "surgery_start_at": schedule.surgery_start_at.isoformat(),
            "surgery_end_at": schedule.surgery_end_at.isoformat(),
            "room_code": schedule.room_code,
            "seq_no": schedule.seq_no,
            "surgeon_id": schedule.surgeon_id,
        }
        await EventBus.publish("m06.schedule.confirmed", payload)
        try:
            await MessageClient.send(
                channel="INBOX",
                biz_type="M06_SCHEDULE",
                biz_id=str(schedule.id),
                title="日间手术已排程",
                content="患者 %s 的手术已排在 %s %s 第 %d 台，预计 %s 开始"
                        % (schedule.patient_name,
                           schedule.schedule_date,
                           schedule.room_name,
                           schedule.seq_no,
                           schedule.surgery_start_at.strftime("%H:%M")),
                staff_ids=[schedule.surgeon_id],
            )
        except Exception:
            logger.exception("排程通知失败 schedule=%s", schedule.id)

    @classmethod
    async def _transit(cls, db: AsyncSession, schedule_id: int, user,
                       to_status: str, from_status: Tuple[str, ...],
                       action: str, extra: Optional[dict] = None) -> dict:
        row = (await db.execute(
            select(M06OrSchedule).where(M06OrSchedule.id == schedule_id)
            .with_for_update()
        )).scalar_one_or_none()
        if not row:
            raise BizException("0603004", "排程不存在")
        if row.status not in from_status:
            raise BizException(
                "0603024",
                "排程状态不允许此操作（当前 %s）"
                % STATUS_TEXT.get(row.status, row.status))
        old = row.status
        row.status = to_status
        row.updated_at = datetime.now()
        if extra:
            for k, v in extra.items():
                setattr(row, k, v)
        await cls._log(db, row, action, user, old, to_status)
        await db.commit()
        await EventBus.publish(
            "m06.schedule.%s" % action.lower(),
            {"schedule_id": row.id, "apply_id": row.apply_id,
             "old_status": old, "new_status": to_status})
        return cls._dict(row, [])

    @classmethod
    async def reschedule(cls, db: AsyncSession, schedule_id: int,
                         body, user) -> dict:
        """改期：原台次终结 + 新建台次 + 六处联动。"""
        old = (await db.execute(
            select(M06OrSchedule).where(M06OrSchedule.id == schedule_id)
            .with_for_update()
        )).scalar_one_or_none()
        if not old:
            raise BizException("0603004", "排程不存在")
        if old.status == "IN_SURGERY":
            raise BizException("0603025", "该台次已开始，不可改期")
        if old.status in ("COMPLETED", "CANCELLED", "RESCHEDULED"):
            raise BizException("0603024", "排程状态不允许改期")

        new_slot = await db.get(M06OrSlot, body.new_slot_id)
        if not new_slot or new_slot.status != "FREE":
            raise BizException("0603005", "目标时段不可用")

        old_status = old.status
        old.slot_id_released = old.slot_id
        old.status = "RESCHEDULED"
        old.released_at = datetime.now()

        cur_slot = await db.get(M06OrSlot, old.slot_id)
        if cur_slot:
            cur_slot.status = "FREE"
            cur_slot.schedule_id = None

        new_start = datetime.combine(new_slot.slot_date, new_slot.start_time)
        duration = old.planned_duration_minutes
        new_row = M06OrSchedule(
            schedule_no=await cls._next_schedule_no(db, new_slot.slot_date),
            schedule_date=new_slot.slot_date,
            room_code=new_slot.room_code,
            room_name=new_slot.room_name,
            slot_id=new_slot.id,
            apply_id=old.apply_id,
            ds_no=old.ds_no,
            patient_id=old.patient_id,
            patient_name=old.patient_name,
            operation_code=old.operation_code,
            operation_name=old.operation_name,
            eye_side=old.eye_side,
            surgeon_id=(body.new_surgeon_id or old.surgeon_id),
            surgeon_name=old.surgeon_name,
            assistant_id=old.assistant_id,
            anesthetist_id=old.anesthetist_id,
            scrub_nurse_id=old.scrub_nurse_id,
            circular_nurse_id=old.circular_nurse_id,
            planned_duration_minutes=duration,
            turnover_minutes=old.turnover_minutes,
            surgery_start_at=new_start,
            surgery_end_at=new_start + timedelta(minutes=duration),
            expected_leave_at=new_start + timedelta(minutes=duration + 5),
            status="PENDING",
            seq_no=await cls._next_seq_no(
                db, new_slot.room_code, new_slot.slot_date),
            previous_schedule_id=old.id,
            remark=body.reason,
            created_by=user["employee_id"],
            created_at=datetime.now(),
        )
        db.add(new_row)
        await db.flush()

        new_slot.status = "BOOKED"
        new_slot.schedule_id = new_row.id

        await cls._log(db, old, "RESCHEDULE_OUT", user,
                       old_status, "RESCHEDULED")
        await cls._log(db, new_row, "RESCHEDULE_IN", user,
                       None, "PENDING")
        await db.commit()

        propagated, failures = await cls._propagate_reschedule(
            db, old, new_row, body)
        return {
            "old_schedule_id": old.id,
            "old_schedule_no": old.schedule_no,
            "old_status": "RESCHEDULED",
            "new_schedule_id": new_row.id,
            "new_schedule_no": new_row.schedule_no,
            "new_status": new_row.status,
            "new_surgery_start_at": new_row.surgery_start_at.isoformat(),
            "released_slot_id": old.slot_id_released,
            "locked_slot_id": new_slot.id,
            "propagated": propagated,
            "propagate_failures": failures,
        }

    @classmethod
    async def _propagate_reschedule(cls, db, old, new_row,
                                    body) -> Tuple[List[dict], List[dict]]:
        """改期六处联动。"""
        propagated, failures = [], []
        targets = [
            ("M06-02", "PREPARE_ITEMS_RECALCULATED"),
            ("M06-04", "CHECKLIST_REBUILT"),
            ("M06-05", "RECOVERY_BED_REALLOCATED"),
            ("M14-08", "MATERIAL_RETURN_REQUESTED"),
            ("M16-03", "ESTIMATE_RECALCULATED"),
            ("M03-05", "PATIENT_NOTIFY"),
        ]
        for module, action in targets:
            try:
                await EventBus.publish(
                    "m06.schedule.changed",
                    {
                        "module": module,
                        "action": action,
                        "apply_id": new_row.apply_id,
                        "old_schedule_id": old.id,
                        "new_schedule_id": new_row.id,
                        "new_surgery_start_at":
                            new_row.surgery_start_at.isoformat(),
                        "reason": body.reason,
                    })
                propagated.append({"module": module, "action": action,
                                   "affected": 1})
            except Exception as exc:
                logger.exception("改期联动失败 %s", module)
                failures.append({"module": module, "error": str(exc)})
        return propagated, failures

        await db.commit()

    @classmethod
    async def insert(cls, db: AsyncSession, schedule_id: int,
                     body, user) -> dict:
        """插台：在已排序列中插入，后续台次顺延。"""
        row = await db.get(M06OrSchedule, schedule_id)
        if not row:
            raise BizException("0603004", "排程不存在")
        later = (await db.execute(
            select(M06OrSchedule).where(
                M06OrSchedule.room_code == row.room_code,
                M06OrSchedule.schedule_date == row.schedule_date,
                M06OrSchedule.seq_no >= body.insert_before_seq,
                M06OrSchedule.status.in_(["PENDING", "CONFIRMED"]),
                M06OrSchedule.is_deleted.is_(False),
            ).order_by(M06OrSchedule.seq_no.asc())
        )).scalars().all()
        shift = row.planned_duration_minutes + row.turnover_minutes
        for s in later:
            s.seq_no += 1
            s.surgery_start_at += timedelta(minutes=shift)
            s.surgery_end_at += timedelta(minutes=shift)
            s.expected_leave_at += timedelta(minutes=shift)
        row.seq_no = body.insert_before_seq
        await cls._log(db, row, "INSERT", user, None, row.status)
        await db.commit()
        return {
            "schedule_id": row.id,
            "shifted_count": len(later),
            "shift_minutes": shift,
        }

    @classmethod
    async def suspend_preview(cls, db: AsyncSession, body) -> dict:
        """停台影响预览。"""
        conds = [M06OrSchedule.status.in_(["PENDING", "CONFIRMED"])]
        if body.scope == "ROOM":
            conds.append(M06OrSchedule.room_code == body.room_code)
        if body.surgeon_id:
            conds.append(M06OrSchedule.surgeon_id == body.surgeon_id)
        conds.append(M06OrSchedule.surgery_start_at >= body.start_at)
        conds.append(M06OrSchedule.surgery_start_at < body.end_at)
        conds.append(M06OrSchedule.is_deleted.is_(False))

        rows = (await db.execute(
            select(M06OrSchedule).where(and_(*conds))
            .order_by(M06OrSchedule.surgery_start_at.asc())
        )).scalars().all()

        affected = []
        for r in rows:
            sug = await cls._suggest_for_suspend(db, r, body)
            affected.append({
                "schedule_id": r.id,
                "schedule_no": r.schedule_no,
                "patient_name": r.patient_name,
                "operation_name": r.operation_name,
                "current_start_at": r.surgery_start_at.isoformat(),
                "suggestion": sug,
            })
        return {
            "affected_count": len(affected),
            "affected": affected,
            "needs_medical_affairs_approval": len(affected) > 10,
        }

    @classmethod
    async def _suggest_for_suspend(cls, db: AsyncSession, row,
                                   body) -> dict:
        """为受影响的台次生成建议方案。"""
        # 优先尝试当日其他手术间同时段
        same_day_slot = (await db.execute(
            select(M06OrSlot).where(
                M06OrSlot.slot_date == row.schedule_date,
                M06OrSlot.room_code != row.room_code,
                M06OrSlot.status == "FREE",
                M06OrSlot.start_time == row.surgery_start_at.time(),
                M06OrSlot.is_deleted.is_(False),
            ).limit(1)
        )).scalar()
        if same_day_slot:
            return {
                "type": "MOVE_ROOM",
                "new_room_code": same_day_slot.room_code,
                "new_slot_id": same_day_slot.id,
                "new_start_at": datetime.combine(
                    same_day_slot.slot_date,
                    same_day_slot.start_time).isoformat(),
                "feasible": True,
                "warnings": [],
            }
        # 次日同时段
        next_day = row.schedule_date + timedelta(days=1)
        next_slot = (await db.execute(
            select(M06OrSlot).where(
                M06OrSlot.slot_date == next_day,
                M06OrSlot.status == "FREE",
                M06OrSlot.start_time == row.surgery_start_at.time(),
                M06OrSlot.is_deleted.is_(False),
            ).order_by(M06OrSlot.room_code.asc()).limit(1)
        )).scalar()
        if next_slot:
            return {
                "type": "RESCHEDULE",
                "new_slot_id": next_slot.id,
                "new_start_at": datetime.combine(
                    next_slot.slot_date, next_slot.start_time).isoformat(),
                "feasible": True,
                "warnings": [],
            }
        return {
            "type": "MANUAL",
            "feasible": False,
            "warnings": [{"type": "NO_SLOT",
                          "message": "暂无可用时段，需人工安排"}],
        }

    @classmethod
    async def suspend(cls, db: AsyncSession, body, user) -> dict:
        """停台并批量改期。"""
        if len(body.reason_desc.strip()) < 20:
            raise BizException("0603014", "停台原因说明不足 20 字")
        if body.reason_type == "EQUIPMENT" and not body.attachment_id:
            raise BizException("0603015", "设备故障停台必须上传报修单")

        preview = await cls.suspend_preview(db, body)
        if preview["affected_count"] == 0:
            raise BizException("0603004", "该范围内没有可停台的台次")

        succeeded, failed = [], []
        for item in preview["affected"]:
            sug = item["suggestion"]
            if body.strategy == "AUTO" and sug.get("feasible"):
                try:
                    new_row = await cls._apply_suspend_move(
                        db, item["schedule_id"], sug, body, user)
                    succeeded.append({"schedule_id": item["schedule_id"],
                                      "new_schedule_id": new_row.id})
                except BizException as exc:
                    failed.append({"schedule_id": item["schedule_id"],
                                   "reason": exc.message})
            elif body.strategy == "CANCEL":
                await cls.cancel(
                    db, item["schedule_id"],
                    type("B", (), {"reason": body.reason_desc})(), user)
                succeeded.append({"schedule_id": item["schedule_id"],
                                  "cancelled": True})
            else:
                failed.append({"schedule_id": item["schedule_id"],
                               "reason": "需人工安排"})

        await db.commit()
        return {
            "suspend_id": None,
            "affected_count": preview["affected_count"],
            "succeeded": succeeded,
            "failed": failed,
            "strategy": body.strategy,
        }

    @classmethod

        duration = old.planned_duration_minutes

class ScheduleExecService:
    """执行登记服务。"""

    MAX_EARLY_MINUTES = 120

    @classmethod
    async def check_in(cls, db: AsyncSession, schedule_id: int,
                       user) -> dict:
        row = (await db.execute(
            select(M06OrSchedule).where(M06OrSchedule.id == schedule_id)
            .with_for_update()
        )).scalar_one_or_none()
        if not row:
            raise BizException("0603004", "排程不存在")
        if row.status != "CONFIRMED":
            raise BizException("0603024", "只有已排定的台次可以报到")
        row.status = "CHECKED_IN"
        row.actual_arrive_at = datetime.now()
        await db.commit()
        await EventBus.publish("m06.schedule.checked_in",
                               {"schedule_id": row.id,
                                "apply_id": row.apply_id})
        return {"schedule_id": row.id, "status": "CHECKED_IN",
                "actual_arrive_at": row.actual_arrive_at.isoformat()}

    @classmethod
    async def record_actual_time(cls, db: AsyncSession, schedule_id: int,
                                 body, user) -> dict:
        row = (await db.execute(
            select(M06OrSchedule).where(M06OrSchedule.id == schedule_id)
            .with_for_update()
        )).scalar_one_or_none()
        if not row:
            raise BizException("0603004", "排程不存在")
        if row.status == "COMPLETED":
            raise BizException("0603033", "该台次已完成，不可登记")

        if body.actual_start_at and row.surgery_start_at:
            early = (row.surgery_start_at
                     - body.actual_start_at).total_seconds() / 60
            if early > cls.MAX_EARLY_MINUTES:
                raise BizException(
                    "0603031", "实际开始时间早于计划时间超过 2 小时")
        if body.actual_start_at and body.actual_end_at:
            if body.actual_end_at <= body.actual_start_at:
                raise BizException(
                    "0603032", "实际结束时间早于实际开始时间")

        if body.actual_start_at:
            row.actual_start_at = body.actual_start_at
            row.status = "IN_SURGERY"
            if row.surgery_start_at:
                row.delay_minutes = int(
                    (body.actual_start_at - row.surgery_start_at)
                    .total_seconds() // 60)
        if body.actual_end_at:
            row.actual_end_at = body.actual_end_at
            row.status = "COMPLETED"
            row.completed_at = datetime.now()
            slot = await db.get(M06OrSlot, row.slot_id)
            if slot:
                slot.status = "FREE"
                slot.schedule_id = None
        await db.commit()

        if row.status == "IN_SURGERY":
            await EventBus.publish("m06.schedule.surgery_started",
                                   {"schedule_id": row.id,
                                    "apply_id": row.apply_id})
        elif row.status == "COMPLETED":
            await EventBus.publish("m06.schedule.surgery_ended",
                                   {"schedule_id": row.id,
                                    "apply_id": row.apply_id,
                                    "actual_duration_minutes": int(
                                        (row.actual_end_at
                                         - row.actual_start_at
                                         ).total_seconds() // 60)})
        return {"schedule_id": row.id, "status": row.status,
                "delay_minutes": row.delay_minutes}

    @classmethod
    async def on_surgery_started(cls, db: AsyncSession,
                                 schedule_id: int) -> dict:
        row = await db.get(M06OrSchedule, schedule_id)
        if not row:
            raise BizException("0603004", "排程不存在")
        row.status = "IN_SURGERY"
        row.actual_start_at = datetime.now()
        if row.surgery_start_at:
            row.delay_minutes = int(
                (row.actual_start_at - row.surgery_start_at)
                .total_seconds() // 60)
        await db.commit()
        await EventBus.publish("m06.schedule.surgery_started",
                               {"schedule_id": row.id,
                                "apply_id": row.apply_id})
        return {"schedule_id": row.id, "status": "IN_SURGERY"}

    @classmethod
    async def on_surgery_ended(cls, db: AsyncSession,
                               schedule_id: int) -> dict:
        row = await db.get(M06OrSchedule, schedule_id)
        if not row:
            raise BizException("0603004", "排程不存在")
        row.status = "COMPLETED"
        row.actual_end_at = datetime.now()
        row.completed_at = datetime.now()
        slot = await db.get(M06OrSlot, row.slot_id)
        if slot:
            slot.status = "FREE"
            slot.schedule_id = None
        await db.commit()
        await EventBus.publish("m06.schedule.surgery_ended",
                               {"schedule_id": row.id,
                                "apply_id": row.apply_id})
        return {"schedule_id": row.id, "status": "COMPLETED"}

    @classmethod
    async def generate_slots(cls, db: AsyncSession, room_id: int,
                             d: date, user) -> dict:
        """按术式排程情况动态生成时段。

        说明：M06-03 采用「排程时动态切分」模式，
        本接口用于「预生成次日时段」场景，
        按上一日实际术式分布预估。
        """
        room = await db.get(M06OrRoom, room_id)
        if not room:
            raise BizException("0603002", "手术间不存在")
        now = datetime.now()
        start = datetime.combine(d, room.open_time)
        close = datetime.combine(d, room.close_time)
        created = 0
        cur = start
        default_minutes = get_config(
            "M06.SCHEDULE.DEFAULT_SLOT_MINUTES", 45)
        while cur + timedelta(minutes=default_minutes) <= close:
            exists = (await db.execute(
                select(M06OrSlot.id).where(
                    M06OrSlot.room_code == room.room_code,
                    M06OrSlot.slot_date == d,
                    M06OrSlot.start_time == cur.time(),
                    M06OrSlot.is_deleted.is_(False),
                ).limit(1)
            )).scalar()
            if not exists:
                db.add(M06OrSlot(
                    room_code=room.room_code,
                    room_name=room.room_name,
                    slot_date=d,
                    start_time=cur.time(),
                    end_time=(cur + timedelta(
                        minutes=default_minutes)).time(),
                    capacity=1,
                    status="FREE",
                    session_type="NORMAL",
                    created_at=now,
                ))
                created += 1
            cur += timedelta(minutes=default_minutes
                             + room.turnover_minutes)
        await db.commit()
        return {"room_code": room.room_code, "date": d.isoformat(),
                "created": created}


class ScheduleStatService:
    """排程统计服务。"""

    @classmethod
    async def statistics(cls, db: AsyncSession, d_from: date,
                         d_to: date, room_code=None) -> dict:
        conds = [M06OrSchedule.schedule_date >= d_from,
                 M06OrSchedule.schedule_date <= d_to,
                 M06OrSchedule.is_deleted.is_(False)]
        if room_code:
            conds.append(M06OrSchedule.room_code == room_code)
        row = (await db.execute(
            select(
                func.count(M06OrSchedule.id).label("total"),
                func.count(M06OrSchedule.id).filter(
                    M06OrSchedule.status == "COMPLETED").label("completed"),
                func.count(M06OrSchedule.id).filter(
                    M06OrSchedule.status == "CANCELLED").label("cancelled"),
                func.count(M06OrSchedule.id).filter(
                    M06OrSchedule.status == "RESCHEDULED").label(
                        "rescheduled"),
                func.count(M06OrSchedule.id).filter(
                    M06OrSchedule.previous_schedule_id.isnot(None)).label(
                        "is_rescheduled"),
                func.avg(M06OrSchedule.planned_duration_minutes).label(
                    "avg_planned"),
                func.avg(
                    func.extract(
                        "epoch",
                        M06OrSchedule.actual_end_at
                        - M06OrSchedule.actual_start_at) / 60.0
                ).label("avg_actual"),
            ).where(and_(*conds))
        )).one()

        rooms = (await db.execute(
            select(M06OrRoom).where(M06OrRoom.is_deleted.is_(False))
        )).scalars().all()
        days = (d_to - d_from).days + 1
        room_stats = []
        for room in rooms:
            r = (await db.execute(
                select(
                    func.count(M06OrSchedule.id).label("total"),
                    func.coalesce(
                        func.sum(func.extract(
                            "epoch",
                            M06OrSchedule.actual_end_at
                            - M06OrSchedule.actual_start_at) / 60.0), 0
                    ).label("used_minutes"),
                ).where(
                    M06OrSchedule.room_code == room.room_code,
                    M06OrSchedule.schedule_date >= d_from,
                    M06OrSchedule.schedule_date <= d_to,
                    M06OrSchedule.status == "COMPLETED",
                    M06OrSchedule.is_deleted.is_(False),
                )
            )).one()
            available = room.daily_capacity_minutes * days
            util = (float(r.used_minutes) / available) if available else 0
            room_stats.append({
                "room_code": room.room_code,
                "room_name": room.room_name,
                "total": r.total,
                "used_minutes": round(float(r.used_minutes), 1),
                "available_minutes": available,
                "utilization_rate": round(util, 4),
            })

        total = row.total or 0
        return {
            "date_from": d_from.isoformat(),
            "date_to": d_to.isoformat(),
            "total": total,
            "completed": row.completed or 0,
            "cancelled": row.cancelled or 0,
            "rescheduled": row.is_rescheduled or 0,
            "reschedule_rate": round(
                (row.is_rescheduled or 0) / total, 4) if total else 0,
            "cancel_rate": round(
                (row.cancelled or 0) / total, 4) if total else 0,
            "avg_planned_minutes": round(
                float(row.avg_planned or 0), 1),
            "avg_actual_minutes": round(
                float(row.avg_actual or 0), 1),
            "rooms": room_stats,
        }

    @classmethod
    async def punctuality(cls, db: AsyncSession, d_from: date,
                          d_to: date) -> dict:
        rows = (await db.execute(
            select(M06OrSchedule).where(
                M06OrSchedule.schedule_date >= d_from,
                M06OrSchedule.schedule_date <= d_to,
                M06OrSchedule.actual_start_at.isnot(None),
                M06OrSchedule.surgery_start_at.isnot(None),
                M06OrSchedule.is_deleted.is_(False),
            )
        )).scalars().all()

        threshold = get_config(
            "M06.SCHEDULE.DELAY_THRESHOLD_MINUTES", 10)
        early, on_time, late_sh, late_mh, late_lh = 0, 0, 0, 0, 0
        gaps = []
        for r in rows:
            delta = int((r.actual_start_at - r.surgery_start_at)
                        .total_seconds() // 60)
            if delta <= -threshold:
                early += 1
            elif abs(delta) <= threshold:
                on_time += 1
            elif delta <= 20:
                late_sh += 1
            elif delta <= 30:
                late_mh += 1
            else:
                late_lh += 1

        # 接台间隔
        prev = {}
        for r in sorted(rows, key=lambda x: (
                x.room_code, x.schedule_date, x.surgery_start_at)):
            key = (r.room_code, r.schedule_date)
            if key in prev and prev[key].actual_end_at:
                gap = int((r.actual_start_at - prev[key].actual_end_at)
                          .total_seconds() // 60)
                if 0 <= gap <= 240:
                    gaps.append(gap)
            prev[key] = r

        total = len(rows)
        avg_gap = round(sum(gaps) / len(gaps), 1) if gaps else 0
        return {
            "total_started": total,
            "early": early,
            "on_time": on_time,
            "late_10_20": late_sh,
            "late_20_30": late_mh,
            "late_over_30": late_lh,
            "on_time_rate": round(on_time / total, 4) if total else 0,
            "avg_turnover_minutes": avg_gap,
            "delay_threshold_minutes": threshold,
        }

    @classmethod
    async def export(cls, db: AsyncSession, body, user) -> dict:
        if (body.date_to - body.date_from).days > 366:
            raise BizException("0603034", "日期跨度超出限制")
        conds = [M06OrSchedule.schedule_date >= body.date_from,
                 M06OrSchedule.schedule_date <= body.date_to,
                 M06OrSchedule.is_deleted.is_(False)]
        if body.room_code:
            conds.append(M06OrSchedule.room_code == body.room_code)
        max_rows = get_config("M06.SCHEDULE.MAX_EXPORT_ROWS", 50000)
        rows = (await db.execute(
            select(M06OrSchedule).where(and_(*conds))
            .order_by(M06OrSchedule.surgery_start_at.asc())
            .limit(max_rows + 1)
        )).scalars().all()
        if len(rows) > max_rows:
            raise BizException("0603035", "导出行数超出限制")
        return {
            "file_name": "M06_schedule_%s_%s.xlsx"
                         % (body.date_from, body.date_to),
            "file_url": "/files/export/m06_schedule_%s.xlsx"
                        % datetime.now().strftime("%Y%m%d%H%M%S"),
            "row_count": len(rows),
            "expire_at": (datetime.now()
                          + timedelta(hours=2)).isoformat(),
        }
```

|---|---|---|

| `job_m06_schedule_pending_alert` | `0 9,15 * * *` | 待排超期告警 |
| `job_m06_schedule_clean_cache` | `0 4 * * *` | 清理过期缓存 |

**为什么预生成次日时段放在 20:00**：护士长通常晚上才把明天的手术排完。20:00 生成次日时段，护士长可以在 20:00 之后直接排程。若等到次日 08:00 才生成，早班没人能排。

**为什么冲突扫描每日两次而每小时又扫一次**：07:00 扫描是"上班前发现昨天遗留的问题"；12:00 扫描是"午休时发现问题下午还能补救"。每小时轻量扫描只查当日台次，成本低（约 8 台 × 3 人 = 24 次查询）。

### 9.4 脱敏

| 字段 | 脱敏规则 | 使用场景 |
|---|---|---|
| 患者身份证号 | 后 4 位（`************1234`） | 大屏展示 |
| 患者手机号 | 中间 4 位（`138****5678`） | 大屏展示 |
| 患者姓名 | 大屏展示"李**"（保留姓） | 手术室大屏（其他患者可见） |
| 患者姓名 | 全显示 | 排程员工作台（内部使用） |

**为什么大屏要脱敏**：手术室走廊大屏任何路过的人都能看到。全名+术式会泄露患者隐私（"张伟 白内障"足以被识别）。设计上大屏只显示"张** 白内障 OS"。

**关键参数说明：**

- **`TURNOVER_INFECTION_MINUTES` 标敏感 + 只读**：眼内炎等感染术后必须终末消毒 60 分钟，这是《医院手术部（室）管理规范》的硬性要求。不允许在系统中改小。
- **`EMERGENCY_RESERVE_RATIO` 标敏感**：决定急诊产能，改错会导致眼科急诊（眼内炎）排不上台。

### 附录 E：术语表

| 术语 | 说明 |
|---|---|
| 台次 | 一台手术在某个时段占用某个手术间的安排记录 |
| 时段 | 手术间的时间格子，被台次占用 |
| 专场 | 某手术间在某时间段的特殊编排（如注药专场接台 5 分钟） |
| 接台间隔（Turnover） | 上一台离开到下一台开始的间隔（消毒+转运+准备） |
| 准点开台 | 实际开始时间与计划开始时间偏差 ≤ 阈值 |
| 停台 | 手术间或医生临时不可用导致该时段所有台次需重新安排 |
| 插台 | 在已排序列中插入一台紧急手术，后续台次顺延 |
| 转台 | 只换手术间，日期与时刻不变 |
| 终末消毒 | 感染手术后对整个手术间进行的彻底消毒 |
| 急诊预留 | 为眼科急诊预留的手术间时段，当日未使用时可释放 |
| 排程偏差 | `actual_start_at - surgery_start_at` |
| 空台率 | 空闲时段数 / 可用时段总数 |
