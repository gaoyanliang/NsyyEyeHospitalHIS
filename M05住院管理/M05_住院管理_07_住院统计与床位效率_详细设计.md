## 1. 模块概述

### 1.1 模块定位

M05-07 是住院管理的**度量端**——它不产生任何业务数据，只回答「住院业务做得怎么样」这个问题。

```
      ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐
      │ M05-01   │  │ M05-02   │  │ M05-03   │  │ M05-04   │  │ M05-05   │
      │ 入院登记  │  │ 床位管理  │  │ 在院管理  │  │ 费用联动  │  │ 出院归档  │
      └────┬─────┘  └────┬─────┘  └────┬─────┘  └────┬─────┘  └────┬─────┘
           │             │             │             │             │
           └─────────────┴──────┬──────┴─────────────┴─────────────┘
                                │ 业务事件（状态变更）
                                ▼
                    ┌───────────────────────┐
                    │      M05-07           │
                    │  住院统计与床位效率      │
                    │                       │
                    │  ┌─────────────────┐  │
                    │  │ 日快照采集        │  │ ← Celery 定时
                    │  ├─────────────────┤  │
                    │  │ 指标计算引擎      │  │ ← 唯一口径
                    │  ├─────────────────┤  │
                    │  │ 多维聚合          │  │ ← 科室/病区/病种/医师
                    │  └─────────────────┘  │
                    └───────────┬───────────┘
                                │
              ┌─────────────────┼─────────────────┐
              ▼                 ▼                 ▼
      ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
      │ M22 报表中心   │  │ 院长驾驶舱    │  │ 等级评审/DRG  │
      │ (明细下钻)     │  │ (实时指标)    │  │ (指标上报)    │
      └──────────────┘  └──────────────┘  └──────────────┘
```

**一句话定位：** M05-07 是全院住院指标的**唯一计算口径来源**——同一组基础数据，只在这里算一次，所有报表、看板、评审材料都从这里取数。

### 1.2 为什么独立成子模块

| 维度 | 若并入其他子模块 | 独立后 |
|---|---|---|
| **口径唯一性** | M05-01~05 各自算「床位使用率」，可能出现 72% 与 81% 并存 | 一张表一套公式，全院一个数 |
| **时间维度** | 业务表按事件发生实时写，统计要「按日/月/年」切片 | 日快照预聚合，月报秒出 |
| **历史追溯** | 床位类型调整、科室合并后旧数据被覆盖 | 快照冻结当时口径，历史不可变 |
| **性能隔离** | 月报查询扫 130 万行在院表，会拖慢临床操作 | 预聚合表 4 万余行，月报 < 1s |
| **审计要求** | 报表数据谁用谁算，无留痕 | 每次生成记录版本与快照时间，可复现 |

**最关键的理由是口径唯一性。** 床位使用率至少有四种算法（见附录 A），实测差异达 **36 个百分点**：72% / 58% / 81% / 94%。如果各子模块自算，院长拿到的数字与科室主任手里的数字不同，任何决策都无法开展。M05-07 的唯一职责就是：**定义口径、冻结快照、统一出口**。

### 1.4 概念辨析

| 概念 A | 概念 B | 区别 |
|---|---|---|
| **开放床位数** | **实有床位数** | 实有 = 物理存在的床；开放 = 实际可收治（扣除停用、维修、隔离）。使用率分母必须是**开放** |
| **实际占用床日** | **出院人数 × 平均住院日** | 前者逐日累加（含当日出院），后者是近似值。实测差异 3~5%，必须用前者 |
| **床位使用率** | **床位周转率** | 使用率 = 占用床日 / 开放床日（时间维度）；周转率 = 出院人数 / 平均开放床位（次数维度） |
| **平均住院日** | **平均占用床日** | 前者 = 出院者总床日 / 出院人数（后者分母含在院）；前者是等级评审口径 |
| **床位周转次数** | **床位周转率** | 次数是绝对数（次/年）；率是相对数（%）。评审用次数 |
| **日间手术** | **住院手术** | 日间手术不过夜，不占床日，归 M06。若计入住院会虚增周转率 |
| **在院人数** | **占床人数** | 加床、包床、日间病房留观可能占位但不一定是"在院" |
| **预出院** | **已出院** | 预出院（DISCHARGING）仍占床，已出院（DISCHARGED）释放床位。统计口径按「是否释放床位」判定 |

## 2. 业务范围与边界

1. **日快照采集**：每日 00:30 冻结前一日全院、科室、病区三级床位与住院指标。

6. **历史复现**：任意历史日期按当时口径重算。

## 3. 业务模型

### 3.1 统计对象模型

```
全院（HOSPITAL）
  └── 科室（DEPT）─┐
        └── 病区（WARD）─┐
              └── 床位（BED）─┐
                    └── 床位日（BED DAY）  ← 最小统计单元
```

**最小统计单元是「床位日」**（bed-day）：某张床在某一天被某个患者占用。所有床位指标都从床位日出发：

- 实际占用床日 = COUNT(床位日)
- 开放床日 = COUNT(当日开放的床) × 1
- 床位使用率 = 实际占用床日 / 开放床日

### 3.2 床位日判定规则

一张床、一天，是否算「占用」，按以下优先级判定（命中即停）：

| 序号 | 条件 | 计入占用 | 说明 |
|---|---|---|---|
| R-01 | 当日 00:00 该床 `status='OCCUPIED'` | ✅ | 跨日连续占用 |
| R-02 | 当日有入住事件（`occupied_at` 落在当日）且当日未出院 | ✅ | 当日新入住 |
| R-03 | 当日有出院事件且出院时间 > 当日 00:00 | ✅ | 当天出院，当日仍占床 |
| R-04 | 当日有转床，转出前时间 > 当日 00:00 | ✅ | 转出床当日占用 |
| R-05 | 当日有转床，转入时间 > 当日 00:00 | ✅ | 转入床当日也占用（**双床日**） |
| R-06 | 当日 `status IN ('CLEANING','MAINTENANCE','DISABLED')` | ❌ | 不可用 |
| R-07 | 当日床位尚未开放（`opened_at` > 当日 23:59） | ❌ | 不计入开放床日 |
| R-08 | 当日为包床，实际无患者 | ❌ | 包床不计占用（但计入开放） |

**为什么转床会产生双床日**：患者甲从 301 床转到 302 床，当天两床都占用了物理资源（301 需要清洁，302 已经住人）。若只算一次，会低估实际资源消耗。行业标准做法就是双床日。

**为什么包床不计占用**：包床（VIP 单间预留）是医院主动保留床位不收患者，若计入占用会使使用率虚高、周转率虚低。

### 3.3 指标计算模型

指标分为三层，层层依赖：

```
L0 基础量（直接采集，不可再拆）
  ├── 开放床日数
  ├── 实际占用床日数
  ├── 入院人数
  ├── 出院人数
  ├── 出院者占用总床日
  └── 转科/转床次数

L1 派生指标（L0 组合）
  ├── 床位使用率 = L0.占用床日 / L0.开放床日
  ├── 床位周转次数 = L0.出院人数 / 平均开放床位
  ├── 平均住院日 = L0.出院者占用床日 / L0.出院人数
  ├── 病床工作日 = L0.占用床日 / 平均开放床位
  └── 床位效率指数 = 使用率 × 周转次数

L2 综合评价（L1 + 外部权重）
  ├── 床位综合效率排名
  ├── 科室运营健康度评分
  └── 等级评审达标判定
```

**关键设计：L1 与 L2 不落库，实时计算。** 因为 L1/L2 只是公式，落库会导致「L0 修正后 L1 忘记重算」。L0 落库（`m05_stat_daily` 等），L1/L2 在查询时用 SQL 表达式计算，一次查询最多 20 行聚合，代价可忽略。

### 3.4 快照与实时的一致性模型

```
               业务实时表（可变更）
                     │
                     │ 每日 00:30 冻结
                     ▼
            ┌────────────────────┐
            │  m05_stat_daily    │  日快照（不可变）
            │  （T-1 日数据）     │
            └─────────┬──────────┘
                      │
        ┌─────────────┼─────────────┐
        ▼             ▼             ▼
   月报/年报      历史任意日      等级评审
   （聚合）        （快照直读）    （快照直读）

          实时指标（今日，未冻结）
                      │
                      ▼
            ┌────────────────────┐
            │  Redis 实时缓存     │  TTL 60s
            │  （业务表实时算）    │
            └────────────────────┘
```

**铁律：T-1 日及以前的数据一律读快照，今日数据才读业务表。**

理由：如果 T-1 也读业务表，那么「昨天看到的使用率」与「今天回看昨天的使用率」会不同（因为昨天之后仍有补录、修改床位状态）。这与「院长看到的数」和「报表上的数」必须一致的要求冲突。

### 3.5 床位效率四种算法

| 算法 | 公式 | 特点 | 本院主推 |
|---|---|---|---|
| **A. 简单使用率** | 占用床日 / 开放床日 | 最常用，但受加床影响 | ❌ |
| **B. 工作日法** | 占用床日 / (实有床位 × 日历日) | 分母用实有床位（含停用），偏低 | ❌ |
| **C. 有效使用率** | 占用床日 / (开放床日 − 加床床日) | 剔除加床，反映标准床位利用率 | ❌ |
| **D. 出院者占用法** | 出院者占用床日 / (开放床位 × 出院人数) | 只看已出院者，忽略在院 | ❌ |

**主推口径 = A. 简单使用率**（占用床日 / 开放床日）。但报表同时提供 B/C/D 三种作为对照，避免「只有一种算法，无法解释差异」。

实测差异：某眼科病区（开放 40 床、实有 45 床、加床 5 床、占用 1.1 万床日、开放 1.46 万床日）：
- A = 11000/14600 = **75.3%**
- B = 11000/(45×365) = **67.0%**
- C = 11000/(14600−1825) = **86.2%**
- D = 假设出院 1,200 人、出院者占用 9,800 床日 → 9800/(40×1200) = **20.4%**（口径完全不同，不能横向比）

**A 与 C 差 10.9 个百分点，B 与 C 差 19.2 个百分点。** 这就是必须唯一口径的原因。

### 3.6 科室口径变更模型

科室合并、病区重组会导致历史数据归属变化。M05-07 的处理：

1. 快照生成时把 `dept_id` / `dept_name` / `ward_id` / `ward_name` **全部写入快照**（名称冗余）。
2. 科室调整后，历史快照**不回溯修改**——历史报表显示的是「当时的科室」。
3. 需按新口径看历史时，调用「口径重算」功能：按当前组织架构重新映射 `dept_id`（写入 `regroup_id` 字段），生成「重组口径视图」，原快照不变。

### 3.7 报表生成模型

| 报表类型 | 数据来源 | 生成时机 | 时效 |
|---|---|---|---|
| 日报 | T-1 日快照单行 | 每日 00:30 后自动 | 实时可查 |
| 月报 | 当月快照聚合 | 每月 1 日 01:00 预生成 | 预生成后可查 |
| 年报 | 全年快照聚合 | 次年 1 月 1 日 02:00 预生成 | 预生成后可查 |
| 等级评审 | 年报 + 专项补充 | 手动触发 | 10s 内 |
| 自定义区间 | 区间快照聚合 | 查询时实时 | 3s 内 |

### 3.8 指标下钻模型

任意指标值 → 下钻三层：

```
L1 指标值（如：眼科 2026-09 床位使用率 75.3%）
  │
  ▼ 点击
L2 构成分解（如：分子 11,000 占用床日、分母 14,600 开放床日）
  │
  ▼ 点击
L3 明细记录（11,000 条床位日记录，分页展示，可按患者/床位/日期筛选）
```

L3 明细由 `m05_bed_snapshot` + `m05_stay` 实时关联查询，支持导出。**下钻是统计可信度的保证**——任何指标都能追到底层记录，才能说服科室主任「这个数是对的」。

### 3.9 统计状态模型

```
   PENDING ──► COLLECTING ──► COLLECTED ──► VERIFIED ──► PUBLISHED
      │             │              │            │            │
      │ 失败         │ 失败          │ 校验不通过   │ 需修正      │ 撤回
      ▼             ▼              ▼            ▼            ▼
   FAILED       FAILED         ABNORMAL ──► RECALC ──► COLLECTED
```

| 状态 | 说明 |
|---|---|
| `PENDING` | 待采集（当日 00:30 前） |
| `COLLECTING` | 采集中 |
| `COLLECTED` | 已采集，未校验 |
| `VERIFIED` | 校验通过（交叉校验、环比阈值） |
| `PUBLISHED` | 已发布，对外可见 |
| `ABNORMAL` | 校验异常（如使用率 > 100% 或 < 20%） |
| `FAILED` | 采集失败（重试 3 次后） |
| `RECALC` | 重算中 |

**发布机制的意义：** 采集完成不等于可发布。必须通过三项校验才能标 `PUBLISHED`：
1. **内部一致性**：占用床日 ≤ 开放床日（使用率 ≤ 100%，除非允许加床）。
2. **环比阈值**：与前 7 日均值偏差 ≤ 30%。
3. **交叉校验**：`Σ科室开放床日 = 全院开放床日`，允许误差 0。

不通过则标 `ABNORMAL` 并告警，人工确认后再发布。

### 6.2 错误码规范

**错误码前缀：** `"0507"` + 3 位序号，共 `"0507001"` ~ `"0507050"`。

| 错误码 | 说明 | 触发场景 |
|---|---|---|
| `"0507001"` | 快照数据不存在 | 查询未采集日期的快照 |
| `"0507002"` | 快照尚未发布 | 查询 ABNORMAL/PENDING 状态数据 |
| `"0507003"` | 日期区间非法 | 结束日期早于开始日期 |
| `"0507004"` | 日期跨度超过限制 | > 366 天 |
| `"0507005"` | 指标代码不存在 | 查询未知指标 |
| `"0507006"` | 统计维度组合非法 | 科室 + 病区同时指定时层级冲突 |
| `"0507007"` | 报表所属期未结束 | 生成当月月报 |
| `"0507008"` | 报表已存在 | 重复生成同类型同期同范围 |
| `"0507009"` | 报表生成失败 | Celery 任务异常 |
| `"0507010"` | 报表文件已过期 | 下载超过 30 分钟 |
| `"0507011"` | 导出行数超过 5 万 | 同步导出超限 |
| `"0507012"` | 导出任务不存在 | 查询无效 task_id |
| `"0507013"` | 导出任务已取消 | 取消后再查询 |
| `"0507014"` | 无权导出该科室数据 | 越权 |
| `"0507015"` | 参数值超出范围 | 使用率阈值 < 0 或 > 200 |
| `"0507016"` | 阈值关系不合法 | 过低 ≥ 过高 |
| `"0507017"` | 口径变更需二次确认 | 修改核心算法未带 `confirm=true` |
| `"0507018"` | 重算区间与已发布报表冲突 | 重算会改变已发布月报 |
| `"0507019"` | 分区已存在 | 手动建分区重复 |
| `"0507020"` | 分区预建失败 | DDL 执行异常 |
| `"0507021"` | 校验任务正在运行 | 并发执行 |
| `"0507022"` | 校验区间无数据 | 全为 PENDING |
| `"0507023"` | 交叉校验不通过 | Σ科室 ≠ 全院 |

| `"0507031"` | 发布状态不允许此操作 | PUBLISHED → PENDING |

class StatCollectService:
    """日快照采集服务"""

    def __init__(self, db: AsyncSession):
        self.db = db

    async def collect_day(self, stat_date: date) -> dict:
        """采集指定日期的全院/科室/病区三级快照"""
        exists = await self._snapshot_exists(stat_date)
        if exists:
            logger.info("m05.stat.collect.skip", extra={"stat_date": str(stat_date),
                                                        "reason": "already_collected"})
            return {"stat_date": str(stat_date), "skipped": True}

        try:
            await self._mark(stat_date, STATUS_COLLECTING)

            hospital = await self._collect_hospital(stat_date)
            depts = await self._collect_depts(stat_date)
            wards = await self._collect_wards(stat_date)

            self._check_internal_consistency(hospital, depts)

            await self.db.commit()

            status = STATUS_COLLECTED
            abnormal = await self._verify_day(stat_date)
            if abnormal:
                status = STATUS_ABNORMAL

            await self._mark(stat_date, status)
            await self.db.commit()

            logger.info("m05.stat.collect.done", extra={
                "stat_date": str(stat_date),
                "dept_count": len(depts),
                "ward_count": len(wards),
                "status": status,
            })
            return {
                "stat_date": str(stat_date),
                "skipped": False,
                "status": status,
                "dept_count": len(depts),
                "ward_count": len(wards),
            }
        except Exception as exc:
            await self.db.rollback()
            logger.error("m05.stat.collect.fail",
                         extra={"stat_date": str(stat_date), "error": str(exc)})
            await self._mark(stat_date, STATUS_FAILED)
            await self.db.commit()
            raise

    async def _collect_hospital(self, stat_date: date) -> dict:
        """采集全院级 L0 基础量"""
        sql = text("""
            SELECT
                COUNT(*) FILTER (WHERE status = 'IN_HOSPITAL')            AS in_hospital_count,
                COUNT(*) FILTER (WHERE DATE(discharge_time) = :d)         AS discharge_count,
                COUNT(*) FILTER (WHERE DATE(admission_time) = :d)         AS admission_count,
                COALESCE(SUM(actual_stay_days) FILTER
                    (WHERE DATE(discharge_time) = :d), 0)                 AS discharged_bed_days,
                COUNT(*) FILTER (WHERE DATE(discharge_time) = :d
                    AND discharge_type = 'DECEASED')                      AS death_count
            FROM m05_admission
            WHERE is_deleted = FALSE
              AND admission_time < :d_end
              AND (discharge_time IS NULL OR discharge_time >= :d_start)
        """)
        row = (await self.db.execute(sql, {
            "d": stat_date,
            "d_start": datetime.combine(stat_date, datetime.min.time()),
            "d_end": datetime.combine(stat_date + timedelta(days=1), datetime.min.time()),
        })).mappings().first()

        bed_sql = text("""
            SELECT
                COUNT(*) FILTER (WHERE status = 'OCCUPIED')              AS occupied_beds,
                COUNT(*) FILTER (WHERE status NOT IN
                    ('MAINTENANCE', 'DISABLED'))                          AS open_beds,
                COUNT(*)                                                  AS total_beds,
                COUNT(*) FILTER (WHERE is_extra_bed = TRUE)               AS extra_beds
            FROM m05_bed
            WHERE is_deleted = FALSE
        """)
        beds = (await self.db.execute(bed_sql)).mappings().first()

        open_beds = int(beds["open_beds"] or 0)
        occupied_beds = int(beds["occupied_beds"] or 0)
        # 占用床日：有在院患者的床位数（含当日出院者占床）
        occupied_bed_days = occupied_beds

        return {
            "stat_date": stat_date,
            "in_hospital_count": int(row["in_hospital_count"] or 0),
            "discharge_count": int(row["discharge_count"] or 0),
            "admission_count": int(row["admission_count"] or 0),
            "discharged_bed_days": int(row["discharged_bed_days"] or 0),
            "death_count": int(row["death_count"] or 0),
            "open_beds": open_beds,
            "total_beds": int(beds["total_beds"] or 0),
            "extra_beds": int(beds["extra_beds"] or 0),
            "occupied_beds": occupied_beds,
            "open_bed_days": open_beds,
            "occupied_bed_days": occupied_bed_days,
        }

    async def _collect_depts(self, stat_date: date) -> List[dict]:
        """采集科室级快照"""
        sql = text("""
            SELECT
                a.discharge_dept_id                                        AS dept_id,
                COUNT(*) FILTER (WHERE DATE(a.discharge_time) = :d)         AS discharge_count,
                COUNT(*) FILTER (WHERE DATE(a.admission_time) = :d)         AS admission_count,
                COALESCE(SUM(a.actual_stay_days) FILTER
                    (WHERE DATE(a.discharge_time) = :d), 0)                 AS discharged_bed_days
            FROM m05_admission a
            WHERE a.is_deleted = FALSE
              AND a.discharge_dept_id IS NOT NULL
              AND a.admission_time < :d_end
              AND (a.discharge_time IS NULL OR a.discharge_time >= :d_start)
            GROUP BY a.discharge_dept_id
        """)
        rows = (await self.db.execute(sql, {
            "d": stat_date,
            "d_start": datetime.combine(stat_date, datetime.min.time()),
            "d_end": datetime.combine(stat_date + timedelta(days=1), datetime.min.time()),
        })).mappings().all()

        bed_sql = text("""
            SELECT
                w.dept_id,
                COUNT(*) FILTER (WHERE b.status = 'OCCUPIED')            AS occupied_bed_days,
                COUNT(*) FILTER (WHERE b.status NOT IN
                    ('MAINTENANCE', 'DISABLED'))                          AS open_bed_days,
                COUNT(*) FILTER (WHERE b.is_extra_bed = TRUE)             AS extra_bed_days
            FROM m05_bed b
            JOIN mdm_ward w ON w.id = b.ward_id AND w.is_deleted = FALSE
            WHERE b.is_deleted = FALSE
            GROUP BY w.dept_id
        """)
        bed_rows = {r["dept_id"]: r for r in
                    (await self.db.execute(bed_sql)).mappings().all()}

        result = []
        for r in rows:
            b = bed_rows.get(r["dept_id"], {})
            result.append({
                "dept_id": r["dept_id"],
                "discharge_count": int(r["discharge_count"] or 0),
                "admission_count": int(r["admission_count"] or 0),
                "discharged_bed_days": int(r["discharged_bed_days"] or 0),
                "open_bed_days": int(b.get("open_bed_days") or 0),
                "occupied_bed_days": int(b.get("occupied_bed_days") or 0),
                "extra_bed_days": int(b.get("extra_bed_days") or 0),
            })
        return result

    async def _collect_wards(self, stat_date: date) -> List[dict]:
        """采集病区级快照"""
        sql = text("""
            SELECT
                w.id                                                       AS ward_id,
                w.name                                                     AS ward_name,
                COUNT(*) FILTER (WHERE b.status = 'OCCUPIED')            AS occupied_bed_days,
                COUNT(*) FILTER (WHERE b.status NOT IN
                    ('MAINTENANCE', 'DISABLED'))                          AS open_bed_days,
                COUNT(*) FILTER (WHERE b.is_extra_bed = TRUE)             AS extra_bed_days,
                COUNT(*)                                                   AS total_beds
            FROM m05_bed b
            JOIN mdm_ward w ON w.id = b.ward_id AND w.is_deleted = FALSE
            WHERE b.is_deleted = FALSE
            GROUP BY w.id, w.name
        """)
        rows = (await self.db.execute(sql)).mappings().all()
        return [dict(r) for r in rows]

    def _check_internal_consistency(self, hospital: dict, depts: List[dict]):
        """内部一致性：Σ科室开放床日必须等于全院开放床日"""
        dept_open = sum(d["open_bed_days"] for d in depts)
        hospital_open = hospital["open_bed_days"]
        if dept_open != hospital_open:
            logger.warning("m05.stat.consistency.warn", extra={
                "hospital_open_bed_days": hospital_open,
                "dept_open_bed_days": dept_open,
                "diff": dept_open - hospital_open,
            })
            # 不抛异常：可能存在未归属科室的床位，记录告警由人工核查

    async def _verify_day(self, stat_date: date) -> bool:
        """单日三项校验，返回是否异常"""
        snapshot = await self._load_snapshot(stat_date)
        if not snapshot:
            return False

        open_days = snapshot["open_bed_days"]
        occupied_days = snapshot["occupied_bed_days"]

        # 校验 1：使用率合理区间
        if open_days > 0:
            rate = occupied_days / open_days
            if rate < self._cfg_min_rate() or rate > self._cfg_max_rate():
                logger.warning("m05.stat.verify.rate_out_of_range", extra={
                    "stat_date": str(stat_date), "rate": round(rate, 4)})
                return True

        # 校验 2：环比偏差
        recent = await self._load_recent_rates(stat_date, RECENT_DAYS_WINDOW)
        if recent:
            avg = sum(recent) / len(recent)
            if avg > 0 and open_days > 0:
                cur = occupied_days / open_days
                if abs(cur - avg) / avg > MOM_DEVIATION_LIMIT:
                    logger.warning("m05.stat.verify.mom_deviation", extra={
                        "stat_date": str(stat_date),
                        "current": round(cur, 4),
                        "recent_avg": round(avg, 4),
                        "deviation": round(abs(cur - avg) / avg, 4),
                    })
                    return True
        return False

    def _cfg_min_rate(self) -> float:
        return 0.20

    def _cfg_max_rate(self) -> float:
        return 1.00

    async def _snapshot_exists(self, stat_date: date) -> bool:
        sql = select(func.count()).select_from(M05StatDaily).where(
            and_(M05StatDaily.stat_date == stat_date,
                 M05StatDaily.stat_level == "HOSPITAL",
                 M05StatDaily.is_deleted.is_(False)))
        return (await self.db.execute(sql)).scalar_one() > 0

    async def _mark(self, stat_date: date, status: str):
        rows = (await self.db.execute(
            select(M05StatDaily).where(
                and_(M05StatDaily.stat_date == stat_date,
                     M05StatDaily.is_deleted.is_(False)))
        )).scalars().all()
        for r in rows:
            r.status = status
        if not rows and status in (STATUS_COLLECTING, STATUS_FAILED):
            return

    async def _load_snapshot(self, stat_date: date) -> Optional[dict]:
        sql = select(M05StatDaily).where(
            and_(M05StatDaily.stat_date == stat_date,
                 M05StatDaily.stat_level == "HOSPITAL",
                 M05StatDaily.is_deleted.is_(False)))
        row = (await self.db.execute(sql)).scalars().first()
        if not row:
            return None
        return {
            "open_bed_days": row.open_bed_days,
            "occupied_bed_days": row.occupied_bed_days,
        }

    async def _load_recent_rates(self, stat_date: date, days: int) -> List[float]:
        start = stat_date - timedelta(days=days)
        sql = select(M05StatDaily).where(
            and_(M05StatDaily.stat_date >= start,
                 M05StatDaily.stat_date < stat_date,
                 M05StatDaily.stat_level == "HOSPITAL",
                 M05StatDaily.is_deleted.is_(False)))
        rows = (await self.db.execute(sql)).scalars().all()
        rates = []
        for r in rows:
            if r.open_bed_days and r.open_bed_days > 0:
                rates.append(r.occupied_bed_days / r.open_bed_days)
        return rates


class StatQueryService:
    """统计查询服务"""

    def __init__(self, db: AsyncSession):
        self.db = db

    async def overview(self, start_date: date, end_date: date,
                       dept_id: Optional[int], ward_id: Optional[int],
                       include_day_surgery: bool, refresh: bool,
                       user: dict) -> dict:
        self._check_range(start_date, end_date)
        if include_day_surgery:
            logger.info("m05.stat.overview.include_day_surgery",
                        extra={"operator": user.get("employee_id")})

        rows = await self._load_snapshots(start_date, end_date, dept_id, ward_id)
        if not rows:
            raise BizException("0507001", "快照数据不存在")

        agg = self._aggregate(rows)
        data_status = self._data_status(rows)

        return {
            "period": {
                "start_date": str(start_date),
                "end_date": str(end_date),
                "days": (end_date - start_date).days + 1,
            },
            "data_status": data_status,
            "metrics": self._build_metrics(agg, rows),
            "trend": await self._build_trend(start_date, end_date, dept_id),
            "dept_ranking": await self._dept_ranking(start_date, end_date),
            "discharge_type_dist": await self._discharge_type_dist(
                start_date, end_date, dept_id),
        }

    def _check_range(self, start_date: date, end_date: date):
        if end_date < start_date:
            raise BizException("0507003", "结束日期早于开始日期")
        if (end_date - start_date).days > MAX_QUERY_DAYS:
            raise BizException("0507004",
                               "日期跨度超过 %d 天" % MAX_QUERY_DAYS)
        if end_date > date.today():
            raise BizException("0507003", "结束日期不能晚于今日")

    async def _load_snapshots(self, start_date: date, end_date: date,
                              dept_id: Optional[int],
                              ward_id: Optional[int]) -> List[M05StatDaily]:
        conds = [
            M05StatDaily.stat_date >= start_date,
            M05StatDaily.stat_date <= end_date,
            M05StatDaily.is_deleted.is_(False),
        ]
        if ward_id:
            conds.append(M05StatDaily.stat_level == "WARD")
            conds.append(M05StatDaily.scope_id == ward_id)
        elif dept_id:
            conds.append(M05StatDaily.stat_level == "DEPT")
            conds.append(M05StatDaily.scope_id == dept_id)
        else:
            conds.append(M05StatDaily.stat_level == "HOSPITAL")

        sql = select(M05StatDaily).where(and_(*conds)).order_by(
            M05StatDaily.stat_date)
        return list((await self.db.execute(sql)).scalars().all())

    def _aggregate(self, rows: List) -> dict:
        """聚合 L0 基础量"""
        open_days = sum(r.open_bed_days or 0 for r in rows)
        occupied_days = sum(r.occupied_bed_days or 0 for r in rows)
        discharge = sum(r.discharge_count or 0 for r in rows)
        admission = sum(r.admission_count or 0 for r in rows)
        discharged_days = sum(r.discharged_bed_days or 0 for r in rows)
        extra_days = sum(r.extra_bed_days or 0 for r in rows)
        days = len({r.stat_date for r in rows}) or 1

        avg_open_beds = open_days / days if days else 0
        return {
            "open_bed_days": open_days,
            "occupied_bed_days": occupied_days,
            "discharge_count": discharge,
            "admission_count": admission,
            "discharged_bed_days": discharged_days,
            "extra_bed_days": extra_days,
            "days": days,
            "avg_open_beds": avg_open_beds,
            "bed_usage_rate": self._div(occupied_days, open_days),
            "avg_stay_days": self._div(discharged_days, discharge),
            "bed_turnover": self._div(discharge, avg_open_beds),
            "bed_work_days": self._div(occupied_days, avg_open_beds),
        }

    @staticmethod
    def _div(a, b) -> float:
        if not b:
            return 0.0
        return round(float(a) / float(b), 4)

    def _data_status(self, rows: List) -> dict:
        statuses = {r.status for r in rows}
        if STATUS_ABNORMAL in statuses:
            status = STATUS_ABNORMAL
        elif STATUS_FAILED in statuses:
            status = STATUS_FAILED
        elif statuses == {STATUS_PUBLISHED}:
            status = STATUS_PUBLISHED
        else:

        last = max((r.collected_at for r in rows if r.collected_at), default=None)

    async def _dept_ranking(self, start_date: date, end_date: date) -> List[dict]:
        sql = select(
            M05StatDaily.scope_id,
            M05StatDaily.scope_name,
            func.sum(M05StatDaily.occupied_bed_days),
            func.sum(M05StatDaily.open_bed_days),
            func.sum(M05StatDaily.discharge_count),
            func.sum(M05StatDaily.discharged_bed_days),
        ).where(
            and_(M05StatDaily.stat_date >= start_date,
                 M05StatDaily.stat_date <= end_date,
                 M05StatDaily.stat_level == "DEPT",
                 M05StatDaily.is_deleted.is_(False))
        ).group_by(M05StatDaily.scope_id, M05StatDaily.scope_name)
        rows = (await self.db.execute(sql)).all()

        items = []
        for row in rows:
            occupied, open_days, discharge, discharged_days = row[2], row[3], row[4], row[5]
            days = (end_date - start_date).days + 1
            avg_open = (open_days or 0) / days if days else 0
            items.append({
                "dept_id": row[0],
                "dept_name": row[1],
                "bed_usage_rate": self._div(occupied or 0, open_days or 0),
                "avg_stay_days": self._div(discharged_days or 0, discharge or 0),
                "bed_turnover": self._div(discharge or 0, avg_open),
            })
        items.sort(key=lambda x: x["bed_usage_rate"], reverse=True)
        for idx, it in enumerate(items, start=1):
            it["rank"] = idx
        return items

    async def _discharge_type_dist(self, start_date: date, end_date: date,
                                   dept_id: Optional[int]) -> List[dict]:
        sql = text("""

            FROM m05_admission

              AND DATE(discharge_time) BETWEEN :s AND :e
              AND (:dept_id IS NULL OR discharge_dept_id = :dept_id)
            GROUP BY discharge_type
            ORDER BY cnt DESC

        rows = (await self.db.execute(sql, {
            "s": start_date, "e": end_date, "dept_id": dept_id,
        })).mappings().all()
        total = sum(r["cnt"] for r in rows) or 1
        names = {
            "MEDICAL_ADVICE": "医嘱离院",
            "TRANSFER_HOSPITAL": "医嘱转院",
            "TRANSFER_COMMUNITY": "医嘱转社区",
            "AGAINST_ADVICE": "非医嘱离院",
            "DECEASED": "死亡",
            "OTHER": "其他",
        }
        return [{"code": r["discharge_type"],
                 "name": names.get(r["discharge_type"], r["discharge_type"]),
                 "count": r["cnt"],
                 "ratio": round(r["cnt"] / total, 4)} for r in rows]

    async def trend(self, metric: str, start_date: date, end_date: date,
                    granularity: str, dept_id: Optional[int], user: dict) -> dict:
        self._check_range(start_date, end_date)
        rows = await self._load_snapshots(start_date, end_date, dept_id, None)
        if not rows:
            raise BizException("0507001", "快照数据不存在")

        buckets = {}
        for r in rows:
            key = self._bucket_key(r.stat_date, granularity)
            b = buckets.setdefault(key, {"occupied": 0, "open": 0})
            b["occupied"] += r.occupied_bed_days or 0
            b["open"] += r.open_bed_days or 0

        points = []
        for key in sorted(buckets.keys()):
            b = buckets[key]
            points.append({"period": key,
                           "value": self._div(b["occupied"], b["open"])})
        return {"metric": metric, "granularity": granularity, "points": points}

    @staticmethod
    def _bucket_key(d: date, granularity: str) -> str:
        if granularity == STAT_DAY:
            return d.isoformat()
        if granularity == STAT_WEEK:
            iso = d.isocalendar()
            return "%d-W%02d" % (iso[0], iso[1])
        if granularity == STAT_MONTH:
            return "%d-%02d" % (d.year, d.month)
        if granularity == STAT_QUARTER:
            return "%d-Q%d" % (d.year, (d.month - 1) // 3 + 1)
        return str(d.year)

    async def health(self) -> dict:
        today = date.today()
        sql = select(M05StatDaily).where(
            and_(M05StatDaily.stat_date == today - timedelta(days=1),
                 M05StatDaily.stat_level == "HOSPITAL",
                 M05StatDaily.is_deleted.is_(False)))
        row = (await self.db.execute(sql)).scalars().first()
        return {
            "last_stat_date": str(row.stat_date) if row else None,
            "last_status": row.status if row else "MISSING",
            "last_collected_at": (row.collected_at.isoformat()
                                  if row and row.collected_at else None),
            "healthy": bool(row and row.status in (STATUS_PUBLISHED,
                                                   STATUS_COLLECTED)),
        }

### 6.7 床位日判定实现

```python
from datetime import date, datetime, time, timedelta

def build_bed_days(bed_rows, stay_rows, stat_date):
    """
    按 3.2 节 R-01~R-08 规则，计算某日床位日。

    bed_rows:  [{"bed_id","ward_id","status","is_extra_bed","opened_at"}]
    stay_rows: [{"admission_id","bed_id","occupied_at","released_at","is_package"}]
    返回：[{"bed_id","admission_id","occupancy_type","counted":bool,"reason":str}]
    """
    day_start = datetime.combine(stat_date, time.min)
    day_end = datetime.combine(stat_date + timedelta(days=1), time.min)

    day_stays = [s for s in stay_rows
                 if (s["occupied_at"] or day_end) < day_end
                 and (s["released_at"] is None or s["released_at"] > day_start)]

    result = []
    for bed in bed_rows:
        # R-07：当日尚未开放
        opened = bed.get("opened_at")
        if opened and opened >= day_end:
            result.append({"bed_id": bed["bed_id"], "admission_id": None,
                           "occupancy_type": None, "counted": False,
                           "reason": "NOT_OPENED"})
            continue

        # R-06：清洁/维修/停用
        if bed["status"] in ("CLEANING", "MAINTENANCE", "DISABLED"):
            result.append({"bed_id": bed["bed_id"], "admission_id": None,
                           "occupancy_type": None, "counted": False,
                           "reason": bed["status"]})
            continue

        matched = [s for s in day_stays if s["bed_id"] == bed["bed_id"]]
        if not matched:
            result.append({"bed_id": bed["bed_id"], "admission_id": None,
                           "occupancy_type": None, "counted": False,
                           "reason": "EMPTY"})
            continue

        stay = matched[0]

        # R-08：包床不计占用
        if stay.get("is_package"):
            result.append({"bed_id": bed["bed_id"],
                           "admission_id": stay["admission_id"],
                           "occupancy_type": "PACKAGE", "counted": False,
                           "reason": "PACKAGE_NOT_COUNTED"})
            continue

        # R-01 / R-02 / R-03 / R-04 / R-05
        occupied_at = stay["occupied_at"]
        released_at = stay["released_at"]

        if occupied_at < day_start and (released_at is None or released_at >= day_end):
            occ_type = "CONTINUOUS"          # R-01 跨日连续占用
        elif occupied_at >= day_start and (released_at is None
                                           or released_at >= day_end):
            occ_type = "NEW_ADMISSION"       # R-02 当日新入住
        elif released_at is not None and released_at < day_end:
            occ_type = "DISCHARGE_TODAY"     # R-03 / R-04 / R-05 当日出院或转出
        else:
            occ_type = "PARTIAL"

        result.append({"bed_id": bed["bed_id"],
                       "admission_id": stay["admission_id"],
                       "occupancy_type": occ_type, "counted": True,
                       "reason": "OCCUPIED"})
    return result
```

## 附录 A：床位效率四种算法

### A.1 算法定义

| 算法 | 公式 | 分子 | 分母 |
|---|---|---|---|
| **A 简单使用率** | 占用床日 / 开放床日 | 实际占用床日 | Σ每日开放床位数 |
| **B 工作日法** | 占用床日 / (实有床位 × 日历日) | 实际占用床日 | 实有床位数（含停用）× 天数 |
| **C 有效使用率** | 占用床日 / (开放床日 − 加床床日) | 实际占用床日 | 标准开放床日（剔除加床） |
| **D 出院者占用法** | 出院者占用床日 / (开放床位 × 出院人数) | 出院者占用床日 | 平均开放床位 × 出院人数 |

### A.2 实测差异（某眼科病区 2026-09）

**基础数据：** 开放 40 床、实有 45 床（含 5 床停用）、加床 2 床、期间 30 天、占用床日 1060、开放床日 1200、出院 268 人、出院者占用床日 1018。

| 算法 | 计算 | 结果 |
|---|---|---|
| A | 1060 / 1200 | **88.3%** |
| B | 1060 / (45 × 30) = 1060 / 1350 | **78.5%** |
| C | 1060 / (1200 − 60) = 1060 / 1140 | **93.0%** |
| D | 1018 / (40 × 268) = 1018 / 10720 | **9.5%** |

**A 与 C 差 4.7 个百分点，B 与 C 差 14.5 个百分点。** D 口径完全不同（是「每出院人次占用床日数」的倒数关系），不能横向比较。

### A.3 各算法适用场景

| 算法 | 适用 | 局限 |
|---|---|---|
| A | 日常运营监控、全院横向对比 | 加床多时偏高 |
| B | 资产利用率（含停用床位） | 分母含不可用床位，偏低 |
| C | 标准床位利用率、扩容决策 | 剔除加床，反映真实供需 |
| D | 单病种资源消耗分析 | 不是使用率，是效率指标 |

**本院主推 A**，报表同时提供 B/C/D 作为对照。所有报表页脚必须标注「口径：算法 A」。

### A.4 使用率异常诊断

```
使用率 < 20%  ──► 空床过多，收入不足
                  检查：是否新开病区、季节性淡季、是否数据异常

使用率 20%~60% ──► 运营正常偏低
                  检查：开放床位是否过多、收治是否不足

使用率 60%~90% ──► 理想区间
                  眼科目标：80%~90%（周转快、住院短）

使用率 90%~100% ─► 接近饱和
                  检查：是否频繁加床、是否影响质量

使用率 > 100%  ──► 加床或数据异常
                  检查：加床比例、床位状态是否有遗漏
```
