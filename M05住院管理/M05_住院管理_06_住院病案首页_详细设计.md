## 1. 模块概述

### 1.1 模块定位

M05-06 住院病案首页是**住院病案首页这一法定文书的生成、质控、编码与上报中心**。它是住院过程中所有临床行为的最终结构化总结，也是 DRG/DIP 医保支付、医院绩效考核、卫生统计上报的数据源。

```

│                     M05-06 在住院数据流中的位置                                │
└──────────────────────────────────────────────────────────────────────────────┘

  住院期间各模块产生的数据
  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
  │ M05-01   │ │ M05-03   │ │ M05-04   │ │ M07-02   │ │ M09      │

  │ 患者信息  │ │ 转科记录  │ │ 费用明细  │ │ 主诊断    │ │ 手术名称  │
  └────┬─────┘ └────┬─────┘ └────┬─────┘ └────┬─────┘ └────┬─────┘
```

**一句话定位：** M05-06 回答「这例住院，从病案首页的角度，到底该怎么写、写得对不对、能不能报」。

### 1.2 为什么独立成子模块

住院病案首页是**国家卫健委强制标准的法定文书**（《住院病案首页数据填写质量规范（暂行）》国卫办医发〔2016〕24 号），有独立的填写规则、质控标准、上报格式。它与 M05-05 病历归档的关系是「内容」与「载体」的关系，必须分开。

| 理由 | 说明 |
|---|---|
| **① 独立的国家标准与质控规则** | 首页有 76 个标准字段 + 眼科扩展字段，有 Q-01~Q-12 共 12 条强制质控规则，与归档的 D-01~D-15 完整性检查完全是两套体系 |
| **② 独立的编码职责** | 首页的核心价值在于 ICD-10 诊断编码与 ICD-9-CM-3 手术操作编码。编码员是独立岗位，不属于医生也不属于护士，需要独立的排班、工作量统计与绩效考核 |
| **③ 独立的报送链路** | 首页数据要报医保（DRG/DIP 分组）、报卫健委（卫生统计年报）、报病案质控中心（首页质量评分）。三条链路格式不同、时限不同、失败处理不同 |
| **④ 独立的质量评分体系** | 首页填写质量是医院等级评审与绩效考核的硬指标（甲级病案率、首页准确率、编码准确率）。评分算法本身是一套业务逻辑，需要独立设计与独立报表 |
| **⑤ 时间与经济价值不对等** | 一条诊断编码选错，DRG 入组可能从「眼科晶体植入」掉到「其他眼科疾病」，单例支付差额可达数千元。首页是住院收入的实际决定环节之一，容不得与归档流程混在一起 |

### 1.4 概念辨析

| 易混淆概念 | 区别 | 为什么重要 |
|---|---|---|
| **病案首页 vs 出院小结** | 首页是**结构化数据表格**（国家标准 76 字段），供统计与医保使用；出院小结是**叙述性文书**（自由文本），供下次就诊参考 | 两者常被混为一谈。首页没有自由文本段落，只有字段；出院小结不是首页 |
| **主诊断 vs 主要诊断** | 国家标准的术语是「**主要诊断**」（Principal Diagnosis），指本次住院的主要原因；「主诊断」是临床习惯说法。本文档统一用「主要诊断」，数据库字段 `diag_role='PRINCIPAL'` | 术语不统一会导致接口字段命名混乱 |
| **主要诊断 vs 入院诊断** | 主要诊断是出院时确定的、本次住院消耗医疗资源最多的诊断；入院诊断是入院时的初步判断，两者经常不同 | DRG 分组依据**主要诊断**，不是入院诊断。用错会直接改变支付金额 |
| **其他诊断 vs 并发症** | 其他诊断是首页上的所有非主要诊断；并发症特指在住院期间新发生的、由疾病或诊疗引起的病症，通常是其他诊断的子集 | 并发症率是医疗质量指标，需要单独标记 |
| **手术 vs 操作** | ICD-9-CM-3 中「手术」特指有切口的治疗性操作；「操作」包括无切口的治疗（如玻璃体腔注药、激光光凝）与检查性操作 | 眼科大量治疗是无切口的（注药、激光），编码时容易只填「手术」漏掉「操作」，直接影响 DRG 手术操作组 |
| **首页填写 vs 首页质控** | 填写是「把数据放进去」，质控是「检查放得对不对」 | 两者的责任人不同：填写是医生与编码员，质控是病案质控员。权限必须分开 |
| **首页上报 vs 归档** | 归档是 M05-05 的任务（把病历收起来），上报是 M05-06 的任务（把数据发出去） | 可以上报未归档，也可以归档未上报。两条独立状态 |

## 2. 业务范围与边界

### 2.1 范围内

| 功能 | 说明 |
|---|---|
| 首页自动生成 | 出院时从各模块聚合数据，自动填充 70% 以上字段 |
| 首页填写与编辑 | 医生填临床部分，编码员填编码部分 |
| 主要诊断与主要手术选择 | 支持多诊断排序，主要诊断唯一 |
| ICD 编码 | ICD-10 诊断编码 + ICD-9-CM-3 手术操作编码 |
| 质控 Q-01~Q-12 | 12 条强制质控规则，阻断 / 警告两级 |
| 首页审核与签字 | 病案科主任审核放行 |
| DRG 预分组 | 本地轻量分组，用于编码自查（正式分组由医保端完成） |
| 上报 | 报医保、报卫健委、报病案质控中心 |
| 上报重试与对账 | 失败重试、报文留档、回执核对 |
| 首页打印 | 标准 A4 首页打印 |
| 首页质量报表 | 甲级病案率、编码准确率、人均工作量 |

### 2.2 范围外

| 功能 | 归属 | 说明 |
|---|---|---|
| 诊断的临床文本记录 | M07-02 诊断与印象 | 首页读取其主要诊断，编码在此二次确认 |

| DRG 正式分组与医保结算 | M16-03 住院结算 / 医保平台 | 首页只做预分组自查 |
| 医院绩效考核总分计算 | M22 报表 | 首页只提供首页质量指标 |
| 卫生统计年报汇总 | M22 | 首页只提供单例数据与导出 |
| 病案借阅与复印 | M18 | 首页随病案整体管理 |

## 3. 病案首页模型

### 3.1 首页结构与国家标准

住院病案首页按国家标准分为 7 个信息段：

```
┌──────────────────────────────────────────────────────────────────┐
│ 住院病案首页（国家标准 76 字段 + 眼科扩展 18 字段）                  │
├──────────────────────────────────────────────────────────────────┤
│ ① 基本信息段（Basic）                                              │
│   医疗机构、组织机构代码、患者姓名、性别、出生日期、年龄、民族、      │
│   国籍、身份证号、职业、婚姻状况、现住址、电话、工作单位及地址电话、  │
│   联系人姓名关系地址电话、入院途径、住院次数、住院号、病案号          │
├──────────────────────────────────────────────────────────────────┤
│ ② 住院过程段（Admission）                                          │
│   入院时间、入院科别、入院病房、转科科别、出院时间、出院科别、        │
│   出院病房、实际住院天数                                            │
├──────────────────────────────────────────────────────────────────┤
│ ③ 诊断段（Diagnosis）                                              │
│   门（急）诊诊断、入院诊断、主要诊断、其他诊断（含入院病情）、        │
│   病理诊断、损伤中毒外部原因、诊断编码（ICD-10）                    │
├──────────────────────────────────────────────────────────────────┤
│ ④ 手术操作段（Operation）                                          │
│   手术操作代码（ICD-9-CM-3）、手术操作日期、手术级别、手术名称、     │
│   术者、第一助手、麻醉方式、麻醉医师                                │
├──────────────────────────────────────────────────────────────────┤
│ ⑤ 费用段（Fee）                                                    │
│   总费用、自付费用、各类别费用（床位/护理/西药/中药/检查/化验/       │
│   手术/麻醉/材料/输血/诊疗/其他）                                    │
├──────────────────────────────────────────────────────────────────┤
│ ⑥ 质量安全段（Quality）                                            │
│   离院方式、是否有出院 31 天内再住院计划、颅脑损伤昏迷时间、          │
│   是否实行临床路径管理、是否完成临床路径、是否抗菌药物使用、          │
│   是否手术患者、是否非计划重返手术室、是否发生院内感染、              │
│   是否发生压疮、是否发生跌倒坠床、是否输血反应、是否输液反应          │
├──────────────────────────────────────────────────────────────────┤
│ ⑦ 签名与上报段（Sign）                                             │
│   科主任、主治医师、住院医师、编码员、质控医师、质控护士、病案质量、 │
│   签名日期                                                          │
└──────────────────────────────────────────────────────────────────┘
```

```
                    └────┬─────┘
```

### 3.3 诊断模型

**诊断角色（`diag_role`）：**

| 角色 | 中文 | 数量 | 说明 |
|---|---|---|---|
| `PRINCIPAL` | 主要诊断 | **1，必填** | DRG 分组依据 |
| `OTHER` | 其他诊断 | 0~15 | 按重要程度排序 |
| `ADMISSION` | 入院诊断 | 0~8 | 入院时的判断，可为空 |
| `OUTPATIENT` | 门急诊诊断 | 0~1 | 入院前门诊诊断 |
| `PATHOLOGY` | 病理诊断 | 0~5 | 有病理结果时填 |
| `EXTERNAL` | 损伤中毒外部原因 | 0~1 | ICD-10 第二十章 V~Y 类 |

**8 种入院病情（`admission_condition`）：**

| 代码 | 中文 | 说明 |
|---|---|---|
| `1` | 有 | 入院时已存在，本次住院原因 |
| `2` | 临床未确定 | 入院时存在但未确诊 |
| `3` | 情况不明 | 不清楚入院时是否存在 |
| `4` | 无 | 入院时不存在，住院期间新发生（含并发症） |
| `9` | 未填 | 默认值，质控 Q-04 会报 BLOCK |

**为什么入院病情必须填：** DRG 分组时，「入院时无、住院期间发生」的诊断会作为**并发症/合并症（CC/MCC）**参与分组，可能进入高权重组；「入院时已有」的诊断作为**合并症**处理。漏填或错填会直接影响支付。

**主要诊断选择原则（国家标准）：**

1. 本次住院**对健康危害最大**的诊断；
2. **花费医疗资源最多**的诊断（住院时间、费用、手术）；
3. **住院时间最长**的诊断；
4. 一般情况下，**主要诊断应该是出院科别**对应的诊断；
5. 眼科特殊情况：**本次入院的原因是眼科手术**时，主要诊断应为导致手术的眼病，而非并发症。

**眼科主要诊断的常见陷阱：**

| 场景 | 错误做法 | 正确做法 | 影响 |
|---|---|---|---|
| 白内障患者合并糖尿病 | 主要诊断填「2 型糖尿病」 | 主要诊断填「老年性白内障」，糖尿病列为其他诊断（入院病情=1） | 错填糖尿病会进「内分泌」DRG 组，权重可能只有眼科的 1/3 |
| 双眼白内障分期手术 | 两次住院填同一个 ICD 编码，不分眼别 | 编码相同但必须标注眼别（扩展字段） | 医保稽核时无法证明两次手术侧别不同 |
| 玻璃体腔注药 | 主要诊断填「手术后状态」 | 填具体眼底疾病（如「糖尿病性视网膜病变」） | 填「状态」类编码会导致无法入组 |
| 角膜移植 | 漏填「角膜材料」其他诊断 | 填「角膜白斑」（主要）+「角膜移植状态」（其他） | 影响 DRG 高值耗材识别 |

### 3.4 手术操作模型

**手术操作角色（`op_role`）：**

| 角色 | 中文 | 数量 | 说明 |
|---|---|---|---|
| `PRINCIPAL` | 主要手术操作 | 0~1 | 本次住院消耗资源最多的手术 |
| `OTHER` | 其他手术操作 | 0~15 | 按时间先后排序 |

**手术级别（`op_level`）：**

| 代码 | 中文 | 说明 |
|---|---|---|
| `1` | 一级手术 | 风险低、过程简单 |
| `2` | 二级手术 | 有一定风险 |
| `3` | 三级手术 | 风险较高 |
| `4` | 四级手术 | 风险高、过程复杂 |

**眼科手术分级示例：**

| 手术 | 级别 |
|---|---|
| 眼睑板腺囊肿切除术 | 一级 |
| 翼状胬肉切除术 | 二级 |
| 白内障超声乳化抽吸术 | 三级 |
| 玻璃体切除术 | 四级 |
| 穿透性角膜移植术 | 四级 |

**眼别扩展字段（`eye_side`）：** OD 右眼 / OS 左眼 / OU 双眼 / NA 不适用。这是国家标准的眼科扩展，二级医院必须填，否则医保稽核无法确认手术侧别。

**为什么无切口操作也必须编码：** ICD-9-CM-3 中「操作」包含大量无切口的治疗性操作。眼科典型的有：

| 操作 | ICD-9-CM-3 示例 | 是否计入 DRG 手术操作组 |
|---|---|---|
| 玻璃体腔药物注射 | 14.72 | 是 |
| 视网膜激光光凝 | 14.25 | 是（部分省份） |
| 全视网膜光凝（PRP） | 14.23 | 是（部分省份） |
| 前房穿刺术 | 12.91 | 是 |
| 眼内异物取出 | 14.00 | 是 |

漏编这些操作会导致病例从「有手术操作组」掉入「内科治疗组」，支付差额显著。

### 3.5 质控模型 Q-01~Q-12

| 规则 | 名称 | 级别 | 判定 |
|---|---|---|---|
| `Q-01` | 主要诊断必填 | **BLOCK** | `PRINCIPAL` 诊断缺失或编码为空 |
| `Q-02` | 主要诊断唯一 | **BLOCK** | `PRINCIPAL` 诊断 > 1 条 |
| `Q-03` | 诊断编码有效 | **BLOCK** | ICD-10 编码不在 M01-09 有效编码表内 |
| `Q-04` | 入院病情已填 | **BLOCK** | 任一其他诊断 `admission_condition='9'` |
| `Q-05` | 手术操作编码有效 | **BLOCK** | ICD-9-CM-3 编码不在有效表内 |
| `Q-06` | 手术必有术者与麻醉 | **BLOCK** | `op_date` 非空但 `surgeon_id` / `anesthesia_code` 为空 |
| `Q-07` | 眼别必填 | **BLOCK** | 诊断或手术涉及眼别但 `eye_side='NA'` |
| `Q-08` | 实际住院天数一致 | **WARN** | `actual_stay_days` 与 `discharge_time - admission_time` 推算值不符 |
| `Q-09` | 费用合计一致 | **WARN** | `fee_total` 与 M05-04 费用合计不符或为空 |
| `Q-10` | 离院方式与出院记录一致 | **WARN** | 首页 `discharge_type` ≠ `m05_discharge.discharge_type` |
| `Q-11` | 主要诊断与出院科别匹配 | **INFO** | 主要诊断科室与出院科别不同 |
| `Q-12` | 编码员与审核人分离 | **BLOCK** | `coder_id = auditor_id` |

**为什么只有 5 条 BLOCK：** BLOCK 会阻断审核与上报，如果过多会导致大量病例卡住。Q-01/Q-02/Q-03/Q-04/Q-05/Q-06/Q-07/Q-12 都是数据客观错误或法规要求，必须阻断；Q-08/Q-09/Q-10 可能是数据延迟导致，允许放行后补；Q-11 是提示性问题。

**Q-12 为什么也阻断：** 编码员与审核人必须是两个不同人，这是病案质控的制度要求（《病历书写基本规范》），防止一个人自编自审导致编码质量失控。此约束在数据库层用 CHECK 兜底（同表同行比较可行）。

### 3.6 首页质量评分模型

```
总分 = 100

扣分项：
  BLOCK 级质控问题：每个 -10 分（最多扣 50 分）
  WARN 级质控问题：每个 -3 分（最多扣 20 分）
  主要诊断编码与医保分组反馈不符：-15 分
  手术操作编码漏编（医保反馈）：-10 分
  首页填写超时（超过 72 小时）：-5 分

等级：
  A 级（甲级病案）：≥ 90 分
  B 级（乙级病案）：75 ~ 89 分
  C 级（丙级病案）：< 75 分
```

**为什么要有分级：** 甲级病案率是医院等级评审与绩效考核的硬门槛（二级医院要求甲级病案率 ≥ 90%）。分级能把首页质量从「一堆字段填没填」变成「一个可管理的数字」。

### 3.7 DRG 预分组模型

**目的：** 在正式上报医保前，用本地轻量分组器做一次自查，发现「分组结果与临床判断严重不符」的病例，提前修正编码。

**轻量分组逻辑（不是完整 DRG 分组，只做粗分类）：**

```
输入：主要诊断 ICD-10、主要手术 ICD-9-CM-3、其他诊断、年龄、住院天数、费用
  │
  ▼
① 按主要诊断 MDC（Major Diagnostic Category）分类
   眼科对应 MDC 02（Diseases and Disorders of the Eye）
   主要诊断在 H00~H59 → MDC 02
  │
  ▼
② 判断是否为手术组
   主要手术 ICD-9-CM-3 非空且属于眼科操作 → 手术组
   否则 → 内科治疗组
  │
  ▼
③ 粗分组（示例）
   手术组：
     - 玻璃体视网膜手术 → MDC02-OP-VR
     - 白内障手术       → MDC02-OP-CATARACT
     - 青光眼手术       → MDC02-OP-GLAUCOMA
     - 角膜手术         → MDC02-OP-CORNEA
     - 眼睑眼表手术     → MDC02-OP-OCULOPLASTY
   内科组：
     - 葡萄膜炎/视网膜疾病内科治疗 → MDC02-MED-UVEITIS
     - 糖尿病眼病内科治疗         → MDC02-MED-DR
     - 其他眼科内科治疗           → MDC02-MED-OTHER
  │
  ▼
输出：预分组代码 + 粗权重区间 + 与上次同类病例的对比
```

| 代码 | 中文 | 触发条件 |
|---|---|---|
| `MDC02-OP-VR` | 玻璃体视网膜手术组 | 主要诊断为 H33/H34/H35 且主要手术属于 14.x |
| `MDC02-OP-CATARACT` | 白内障手术组 | 主要诊断为 H25/H26 且主要手术为 13.41/13.71/13.90 |
| `MDC02-OP-GLAUCOMA` | 青光眼手术组 | 主要诊断为 H40/H42 且主要手术为 12.x |

| `MDC02-OP-OCULOPLASTY` | 眼睑眼表手术组 | 主要诊断为 H00~H02/H10~H11 且主要手术为 08.x |
| `MDC02-MED-UVEITIS` | 葡萄膜炎内科组 | 主要诊断为 H20 且无手术 |
| `MDC02-MED-DR` | 糖尿病眼病内科组 | 主要诊断为 H36 且无手术 |
| `MDC02-MED-OTHER` | 眼科其他内科组 | 其他眼科诊断且无手术 |

### 6.2 错误码规范

| 错误码 | 说明 | 触发场景 |
|---|---|---|
| `"0506001"` | 首页不存在 | 查询不存在的 `admission_id` |
| `"0506002"` | 首页状态不允许此操作 | 对 `APPROVED` 的首页执行编辑 |
| `"0506003"` | 主要诊断未填写 | Q-01 触发，提交或审核时 |
| `"0506004"` | 主要诊断不唯一 | Q-02 触发，存在多条 `PRINCIPAL` |
| `"0506005"` | 诊断编码无效或不在有效表内 | Q-03 触发，编码非法 |
| `"0506006"` | 手术操作编码无效 | Q-05 触发，ICD-9-CM-3 非法 |
| `"0506007"` | 入院病情未填写 | Q-04 触发，`admission_condition='9'` |
| `"0506008"` | 眼别必填 | Q-07 触发，涉及眼病但眼别为 `NA` |
| `"0506009"` | 手术必须有术者与麻醉方式 | Q-06 触发，字段为空 |
| `"0506010"` | 诊断数量超过上限（其他诊断 15 / 病理 5） | 保存诊断段时 |
| `"0506011"` | 存在阻断级质控问题，不可提交审核 | 提交审核时 Q 存在 BLOCK |
| `"0506012"` | 编码员与审核人不能为同一人 | Q-12 触发，或审核时校验 |
| `"0506013"` | 审核退回必须填写审核意见 | 退回时 `audit_comment` 为空或 < 5 字 |
| `"0506014"` | 该首页已被审核，不可重复审核 | 状态非 `QC_OK` 时调用审核 |
| `"0506015"` | 上报前必须审核通过 | 状态非 `APPROVED` 时调用上报 |
| `"0506016"` | 上报服务不可用，已加入重试队列 | 上报链路超时 |
| `"0506017"` | 医保上报失败：编码校验不通过 | 医保接口返回编码错误 |
| `"0506018"` | 卫健委上报失败：报表格式不符 | 卫健委接口返回格式错误 |
| `"0506019"` | 质控中心上报失败：必填字段缺失 | 质控中心接口返回字段缺失 |
| `"0506020"` | 编码表服务不可用 | M01-09 超时 |
| `"0506021"` | 患者主索引服务不可用 | M03-01 超时（生成首页时） |
| `"0506022"` | 住院主档不存在或已作废 | 生成首页时 `m05_admission` 状态非法 |
| `"0506023"` | 该住院已存在首页 | 重复触发生成 |
| `"0506024"` | 自动填充失败，需人工填写 | 聚合任务失败 |
| `"0506025"` | 质控规则执行超时 | Q 执行超过 30 秒 |
| `"0506026"` | 日期跨度超过限制 | 统计 / 导出参数 |
| `"0506027"` | 导出行数超过限制 | 导出参数 |
| `"0506028"` | 无权查看该病例首页 | 数据权限不足 |
| `"0506029"` | 首页已上报，不可再修改 | 修改 `REPORTED` 的首页 |
| `"0506030"` | DRG 预分组失败 | 本地分组器异常 |
| `"0506031"` | 编码表同步失败 | M01-09 同步通知异常 |
| `"0506032"` | 批量重新生成数量超过上限 | 超过 100 条 |
| `"0506033"` | 稽核回写金额格式非法 | 医保稽核反馈解析失败 |
| `"0506034"` | 该编码已停用，不可使用 | 编码 `status='DISABLED'` |
| `"0506035"` | 手术级别不合法 | `op_level` 不在 1~4 |

**共 35 个错误码**，区间 `"0506001"`~`"0506035"`。

#### HomeFillService

```python
import logging
from datetime import datetime
from decimal import Decimal, ROUND_HALF_UP
from typing import Optional

from sqlalchemy import select, update, func
from sqlalchemy.ext.asyncio import AsyncSession

from app.core.exceptions import BizException
from app.core.redis_client import RedisClient
from app.modules.m05_06.models import (
    M05MedicalRecordHome, M05HomeDiagnosis, M05HomeOperation,
    M05HomeQuality, M05HomeLog, M05HomeConfig,
)
from app.modules.m05_06.clients import (
    AdmissionClient, StayClient, DischargeClient,
    ChargeClient, DiagnosisClient, OperationClient, PatientClient,
)
from app.modules.m05_06.drg import DrgPreGrouper

logger = logging.getLogger("m05_06.home_fill")

CENT = Decimal("0.01")


def money(value) -> Decimal:
    return Decimal(str(value)).quantize(CENT, rounding=ROUND_HALF_UP)


class HomeFillService:

    # ---------------------------------------------------------------
    # 出院事件：创建首页并自动填充
    # ---------------------------------------------------------------
    @staticmethod
    async def on_discharged(payload: dict) -> dict:
        """出院事件触发，幂等创建首页，异步自动填充"""
        admission_id = payload["admission_id"]
        async with get_db() as db:
            # ① 幂等检查
            exist = await db.scalar(
                select(M05MedicalRecordHome).where(
                    M05MedicalRecordHome.admission_id == admission_id,
                    M05MedicalRecordHome.is_deleted == False,
                )
            )
            if exist:
                logger.info(
                    "首页已存在，跳过创建",
                    extra={"admission_id": admission_id, "home_id": exist.id},
                )
                return {
                    "admission_id": admission_id,
                    "home_id": exist.id,
                    "medical_record_no": exist.medical_record_no,
                    "status": exist.status,
                    "is_duplicate": True,
                    "async_fill_started": False,
                    "estimated_seconds": 0,
                }

            # ② 校验住院主档
            adm = await AdmissionClient.get_admission(admission_id)
            if not adm or adm["status"] not in ("DISCHARGED", "DISCHARGED_OWED", "SETTLED"):
                raise BizException("0506022", "住院主档不存在或已作废")

            # ③ 生成病案号
            mr_no = await HomeFillService._next_medical_record_no(db)

            # ④ 创建首页主记录（PENDING）
            home = M05MedicalRecordHome(
                admission_id=admission_id,
                admission_no=adm["admission_no"],
                medical_record_no=mr_no,
                patient_id=adm["patient_id"],
                patient_name=adm["patient_name"],
                gender=adm["gender"],
                status="PENDING",
                discharge_time=payload["discharge_time"],
                drg_group=None,
                created_by=0,
                created_at=datetime.now(),
            )
            db.add(home)
            await db.flush()

            await HomeFillService._log(
                db, home.id, "CREATE", 0, "系统",
                {"trigger": "DischargedEvent", "admission_id": admission_id},
            )
            await db.commit()

            home_id = home.id

        # ⑤ 异步自动填充（事务外，避免长事务）
        from app.modules.m05_06.tasks import auto_fill_home_task
        auto_fill_home_task.delay(home_id, payload)

        logger.info("首页创建成功，已异步触发自动填充", extra={"home_id": home_id})
        return {
            "admission_id": admission_id,
            "home_id": home_id,
            "medical_record_no": mr_no,
            "status": "PENDING",
            "is_duplicate": False,
            "async_fill_started": True,
            "estimated_seconds": 5,
        }

    # ---------------------------------------------------------------
    # 自动填充（由 Celery 任务调用）
    # ---------------------------------------------------------------
    @staticmethod
    async def auto_fill(home_id: int, payload: dict) -> dict:

                return {"home_id": home_id, "skipped": True}

            degraded = []

                    home.contact_phone = patient.get("contact_phone")

                    home.occupation = patient.get("occupation")
                    home.marital_status = patient.get("marital_status")
                    home.nation = patient.get("nation")
                    home.nationality = patient.get("nationality")
                    filled_fields.extend(["contact_name", "current_address", "occupation"])
            except Exception as exc:
                logger.warning("拉取患者信息失败，降级", extra={"error": str(exc)})
                degraded.append("PATIENT")

            # ② 住院过程段
            try:
                discharge = await DischargeClient.get_by_admission(admission_id)
                if discharge:
                    home.discharge_dept_id = discharge["discharge_dept_id"]
                    home.discharge_dept_name = discharge["discharge_dept_name"]
                    home.discharge_ward = discharge["discharge_ward"]
                    home.discharge_type = discharge["discharge_type"]
                    home.actual_stay_days = discharge["stay_days"]
                    filled_fields.extend(["discharge_dept", "actual_stay_days"])
            except Exception as exc:
                logger.warning("拉取出院记录失败", extra={"error": str(exc)})
                degraded.append("DISCHARGE")

            # ③ 诊断段（同步 M07-02）
            try:
                diags = await DiagnosisClient.get_by_encounter(home.encounter_id)
                await HomeFillService._fill_diagnosis(db, home, diags)
                filled_fields.append("diagnosis")
            except Exception as exc:
                logger.warning("同步诊断失败，需人工填写", extra={"error": str(exc)})
                degraded.append("DIAGNOSIS")

            # ④ 手术操作段（同步 M09）
            try:
                ops = await OperationClient.get_by_admission(admission_id)
                await HomeFillService._fill_operation(db, home, ops)
                filled_fields.append("operation")
            except Exception as exc:
                logger.warning("同步手术记录失败", extra={"error": str(exc)})
                degraded.append("OPERATION")

            # ⑤ 费用段（同步 M05-04）
            try:
                fees = await ChargeClient.get_fee_summary(admission_id)
                if fees:
                    home.fee_total = money(fees["total_amount"])
                    home.bed_fee = money(fees.get("bed_fee", 0))
                    home.nursing_fee = money(fees.get("nursing_fee", 0))
                    home.western_medicine_fee = money(fees.get("drug_fee", 0))
                    home.exam_fee = money(fees.get("exam_fee", 0))
                    home.lab_fee = money(fees.get("lab_fee", 0))
                    home.operation_fee = money(fees.get("operation_fee", 0))
                    home.anesthesia_fee = money(fees.get("anesthesia_fee", 0))
                    home.material_fee = money(fees.get("material_fee", 0))
                    home.treatment_fee = money(fees.get("treatment_fee", 0))
                    home.other_fee = money(fees.get("other_fee", 0))
                    home.fee_pending = False
                    filled_fields.append("fee")
                else:
                    home.fee_pending = True
                    degraded.append("FEE")
            except Exception as exc:
                logger.warning("拉取费用汇总失败", extra={"error": str(exc)})
                home.fee_pending = True
                degraded.append("FEE")

            # ⑥ 质量安全段默认值
            home.antibiotic_used = await HomeFillService._detect_antibiotic(db, home)
            home.is_operation_patient = await db.scalar(
                select(func.count()).select_from(M05HomeOperation).where(
                    M05HomeOperation.home_id == home.id,
                    M05HomeOperation.is_deleted == False,
                )
            ) > 0

            # ⑦ 签名段（默认取 M05-03 记录的医生）
            try:
                stay = await StayClient.get_current_by_admission(admission_id)
                if stay:
                    home.resident_doctor_id = stay.get("attending_doctor_id")
                    home.attending_doctor_id = stay.get("attending_doctor_id")
                    home.dept_director_id = stay.get("dept_director_id")
            except Exception as exc:
                logger.warning("拉取在院医生失败", extra={"error": str(exc)})

            # ⑧ DRG 预分组
            try:
                home.drg_group = await DrgPreGrouper.predict(db, home)
            except Exception as exc:
                logger.warning("DRG 预分组失败", extra={"error": str(exc)})
                degraded.append("DRG")

            # ⑨ 更新状态
            home.status = "DRAFT"
            home.filled_fields = filled_fields
            home.degraded_modules = degraded
            home.updated_at = datetime.now()

            await HomeFillService._log(
                db, home.id, "AUTO_FILL", 0, "系统",
                {"filled": filled_fields, "degraded": degraded},
            )
            await db.commit()

            logger.info(
                "首页自动填充完成",
                extra={
                    "home_id": home_id,
                    "filled": len(filled_fields),
                    "degraded": degraded,
                },
            )
            return {"home_id": home_id, "filled": filled_fields, "degraded": degraded}

    @staticmethod

                source_diag_id=diag.get("id"),

                created_at=datetime.now(),
            ))
        # 入院诊断：取所有诊断的前 8 条
        for index, diag in enumerate(diags[:8], start=1):

                eye_side=diag.get("eye_side", "NA"),
                admission_condition="1",
                seq_no=index,
                source="M07",
                source_diag_id=diag.get("id"),
                created_by=0,
                created_at=datetime.now(),
            ))
        await db.flush()

                surgeon_id=op.get("surgeon_id"),

                first_assistant_name=op.get("first_assistant_name"),
                anesthesia_code=op.get("anesthesia_code"),
                anesthesia_name=op.get("anesthesia_name"),
                anesthesiologist_id=op.get("anesthesiologist_id"),

                source="M09",
                source_op_id=op.get("id"),
                created_by=0,
                created_at=datetime.now(),
            ))
        await db.flush()

    # ---------------------------------------------------------------
    # 抗菌药物判定

    @staticmethod

    @staticmethod
    async def _next_medical_record_no(db: AsyncSession) -> str:
        redis = await RedisClient.get_instance()
        key = "m05:home:mr_seq:%s" % datetime.now().strftime("%Y%m%d")
        seq = await redis.incr(key)
        await redis.expire(key, 172800)
        if seq > 9999:
            raise BizException("0506003", "当日病案号已用尽")
        return "BA%s%04d" % (datetime.now().strftime("%Y%m%d"), seq)

            operator_name=operator_name,
            detail_json=detail,
            operated_at=datetime.now(),
        ))
```

**关键设计说明：**

1. **幂等创建**：`on_discharged` 先查 `admission_id` 是否已有首页，避免出院事件重复投递导致多份首页。数据库层还有 `uk_m05_home_admission` 唯一索引兜底。
2. **自动填充在事务外异步执行**：出院事件在 M05-03 的事务里发出，若在事件回调里做长事务聚合会拖慢出院。因此先建 `PENDING` 记录并提交，再 `delay()` 派发 Celery 任务。
3. **每个数据源独立 try/except**：某个模块挂了不应该让整个首页填充失败。降级模块记入 `degraded_modules`，前端可以提示「费用段待补」。
4. **`admission_condition` 默认填 `'9'`（未填）而不是 `'1'`（有）**：宁可让质控 Q-04 报出来让人确认，也不要默认猜一个值。默认 `1` 会导致「住院期间新发生的并发症」被错标成「入院已有」，直接影响 DRG 分组。

```python
import logging
from datetime import datetime
from typing import List

from sqlalchemy import select, func
from sqlalchemy.ext.asyncio import AsyncSession

from app.core.exceptions import BizException
from app.modules.m05_06.models import (
    M05MedicalRecordHome, M05HomeDiagnosis, M05HomeOperation,
    M05HomeQuality, M05HomeLog, M05HomeConfig,
)

logger = logging.getLogger("m05_06.home_qc")

# 质控规则定义：code, name, level
QC_RULES = [
    ("Q-01", "主要诊断必填", "BLOCK"),
    ("Q-02", "主要诊断唯一", "BLOCK"),
    ("Q-03", "诊断编码有效", "BLOCK"),
    ("Q-04", "入院病情已填", "BLOCK"),
    ("Q-05", "手术操作编码有效", "BLOCK"),
    ("Q-06", "手术必有术者与麻醉", "BLOCK"),
    ("Q-07", "眼别必填", "BLOCK"),
    ("Q-08", "实际住院天数一致", "WARN"),
    ("Q-09", "费用合计一致", "WARN"),
    ("Q-10", "离院方式与出院记录一致", "WARN"),
    ("Q-11", "主要诊断与出院科别匹配", "INFO"),
    ("Q-12", "编码员与审核人分离", "BLOCK"),
]

EYE_SIDE_REQUIRED_CHAPTERS = ("H",)  # 眼科诊断章节


class HomeQcService:

    @staticmethod
    async def run(admission_id: int, body, user: dict) -> dict:
        async with get_db() as db:
            home = await db.scalar(
                select(M05MedicalRecordHome).where(
                    M05MedicalRecordHome.admission_id == admission_id,
                    M05MedicalRecordHome.is_deleted == False,
                )
            )
            if not home:
                raise BizException("0506001", "首页不存在")

            if home.status not in ("DRAFT", "QC_FAIL", "QC_CHECK"):
                if not body.force:
                    raise BizException("0506002", "首页状态不允许此操作")

            qc_batch_no = await HomeQcService._next_qc_batch_no(db, admission_id)

            diags = (await db.scalars(
                select(M05HomeDiagnosis).where(
                    M05HomeDiagnosis.home_id == home.id,
                    M05HomeDiagnosis.is_deleted == False,
                )
            )).all()

            ops = (await db.scalars(
                select(M05HomeOperation).where(
                    M05HomeOperation.home_id == home.id,
                    M05HomeOperation.is_deleted == False,
                )
            )).all()

            results = []

            # Q-01 / Q-02：主要诊断
            principals = [d for d in diags if d.diag_role == "PRINCIPAL"]
            if len(principals) == 0:
                results.append(HomeQcService._fail(
                    "Q-01", "未选择主要诊断", "请从诊断列表中选择本次住院的主要诊断",
                    "diagnosis.principal",
                ))
            elif len(principals) > 1:
                results.append(HomeQcService._fail(
                    "Q-02",
                    "存在 %d 条主要诊断：%s" % (
                        len(principals), "、".join(p.code for p in principals)),
                    "主要诊断只能有一条，请将其余改为其他诊断",
                    "diagnosis.principal",
                ))
            else:
                results.extend([HomeQcService._pass("Q-01"), HomeQcService._pass("Q-02")])

            # Q-03：诊断编码有效
            invalid_diags = []
            for diag in diags:
                if not await HomeQcService._is_valid_code(db, diag.code, "DIAGNOSIS"):
                    invalid_diags.append(diag)
            if invalid_diags:
                results.append(HomeQcService._fail(
                    "Q-03",
                    "编码不在有效表内：%s" % "、".join(
                        "%s(%s)" % (d.name, d.code) for d in invalid_diags),
                    "请重新选择编码",
                    "diagnosis",
                ))
            else:
                results.append(HomeQcService._pass("Q-03"))

            # Q-04：入院病情已填
            unset_conditions = [
                d for d in diags
                if d.diag_role in ("PRINCIPAL", "OTHER") and d.admission_condition == "9"
            ]
            if unset_conditions:
                results.append(HomeQcService._fail(
                    "Q-04",
                    "以下诊断入院病情未填：%s" % "、".join(d.name for d in unset_conditions),
                    "请为每条主要/其他诊断选择入院病情（1有/2临床未确定/3情况不明/4无）",
                    "diagnosis.admission_condition",
                ))
            else:
                results.append(HomeQcService._pass("Q-04"))

            # Q-05：手术操作编码有效
            invalid_ops = []
            for op in ops:
                if not await HomeQcService._is_valid_code(db, op.code, "OPERATION"):
                    invalid_ops.append(op)
            if invalid_ops:
                results.append(HomeQcService._fail(
                    "Q-05",
                    "手术操作编码无效：%s" % "、".join(
                        "%s(%s)" % (o.name, o.code) for o in invalid_ops),
                    "请选择有效的 ICD-9-CM-3 编码",
                    "operation",
                ))
            else:
                results.append(HomeQcService._pass("Q-05"))

            # Q-06：手术必有术者与麻醉
            missing_ops = [
                o for o in ops
                if not o.surgeon_id or not o.anesthesia_code
            ]
            if missing_ops:
                results.append(HomeQcService._fail(
                    "Q-06",
                    "以下手术缺少术者或麻醉方式：%s" % "、".join(o.name for o in missing_ops),
                    "请补充术者与麻醉方式",
                    "operation",
                ))
            else:
                results.append(HomeQcService._pass("Q-06"))

            # Q-07：眼别必填
            eye_missing = []
            for diag in diags:
                if diag.diag_role in ("PRINCIPAL", "OTHER") and diag.code:
                    if diag.code.startswith("H") and diag.eye_side == "NA":
                        eye_missing.append("诊断「%s」" % diag.name)
            for op in ops:
                if op.code and op.eye_side == "NA" and HomeQcService._is_eye_operation(op.code):
                    eye_missing.append("手术「%s」" % op.name)
            if eye_missing:
                results.append(HomeQcService._fail(
                    "Q-07",
                    "以下项目缺少眼别：%s" % "、".join(eye_missing),
                    "眼科诊断与手术必须标注眼别（OD 右眼 / OS 左眼 / OU 双眼）",
                    "diagnosis.eye_side",
                ))
            else:
                results.append(HomeQcService._pass("Q-07"))

            # Q-08：实际住院天数一致
            if home.admission_time and home.discharge_time:
                calc_days = (home.discharge_time.date() - home.admission_time.date()).days + 1
                if home.actual_stay_days != calc_days:
                    results.append(HomeQcService._warn(
                        "Q-08",
                        "首页住院天数 %d 天，按出/入院时间推算为 %d 天（当日按 1 天计算）"
                        % (home.actual_stay_days, calc_days),
                        "请确认住院天数，当前按出院当日计费口径为 %d 天" % calc_days,
                        "process.actual_stay_days",
                    ))
                else:
                    results.append(HomeQcService._pass("Q-08"))
            else:
                results.append(HomeQcService._pass("Q-08"))

            # Q-09：费用合计一致
            if home.fee_pending or home.fee_total is None:
                results.append(HomeQcService._warn(
                    "Q-09", "首页费用段为空（费用待补）",
                    "请等待 M05-04 费用汇总完成后重新质控", "fee.fee_total",
                ))
            else:
                results.append(HomeQcService._pass("Q-09"))

            # Q-10：离院方式一致
            try:
                from app.modules.m05_06.clients import DischargeClient
                discharge = await DischargeClient.get_by_admission(home.admission_id)
                if discharge and discharge.get("discharge_type") != home.discharge_type:
                    results.append(HomeQcService._warn(
                        "Q-10",
                        "首页离院方式「%s」与出院记录「%s」不一致"
                        % (home.discharge_type, discharge.get("discharge_type")),
                        "请与出院记录核对后修正", "quality_safety.discharge_type",
                    ))
                else:
                    results.append(HomeQcService._pass("Q-10"))
            except Exception:
                results.append(HomeQcService._pass("Q-10"))

            # Q-11：主要诊断与出院科别匹配
            if principals:
                p = principals[0]
                if p.dept_id and home.discharge_dept_id and p.dept_id != home.discharge_dept_id:
                    results.append(HomeQcService._info(
                        "Q-11",
                        "主要诊断科室与出院科别不同",
                        "国家标准建议主要诊断应为出院科别对应的诊断，请确认",
                        "diagnosis.principal",
                    ))
                else:
                    results.append(HomeQcService._pass("Q-11"))
            else:
                results.append(HomeQcService._pass("Q-11"))

            # Q-12：编码员与审核人分离
            if home.coder_id and home.auditor_id and home.coder_id == home.auditor_id:
                results.append(HomeQcService._fail(
                    "Q-12", "编码员与审核人同为「%s」" % home.coder_name,
                    "请将审核人改为其他人员（通常为病案科主任）",
                    "sign.auditor",
                ))
            else:
                results.append(HomeQcService._pass("Q-12"))

            # 汇总
            block_count = sum(1 for r in results if r["level"] == "BLOCK" and r["result"] == "FAIL")
            warn_count = sum(1 for r in results if r["level"] == "WARN" and r["result"] == "WARN")
            info_count = sum(1 for r in results if r["level"] == "INFO" and r["result"] == "INFO")
            passed = sum(1 for r in results if r["result"] == "PASS")

            score = 100
            score -= min(block_count * 10, 50)
            score -= min(warn_count * 3, 20)
            score = max(score, 0)

            if score >= 90:
                level = "A"
            elif score >= 75:
                level = "B"
            else:
                level = "C"

            # 落库质控结果
            for r in results:
                db.add(M05HomeQuality(
                    home_id=home.id,
                    admission_id=home.admission_id,
                    qc_batch_no=qc_batch_no,
                    rule_code=r["rule_code"],
                    rule_name=r["rule_name"],
                    level=r["level"],
                    result=r["result"],
                    issue_desc=r.get("issue_desc"),
                    suggestion=r.get("suggestion"),
                    field_path=r.get("field_path"),
                    created_by=user["employee_id"],
                    created_at=datetime.now(),
                ))

            home.quality_score = score
            home.quality_level = level
            home.qc_batch_no = qc_batch_no
            home.qc_at = datetime.now()
            home.status = "QC_OK" if block_count == 0 else "QC_FAIL"
            home.updated_at = datetime.now()

            await HomeFillService._log(
                db, home.id, "QC", user["employee_id"], user["employee_name"],
                {
                    "qc_batch_no": qc_batch_no,
                    "block": block_count,
                    "warn": warn_count,
                    "score": score,
                },
            )
            await db.commit()

            return {
                "admission_id": admission_id,
                "qc_batch_no": qc_batch_no,
                "executed_at": home.qc_at.strftime("%Y-%m-%d %H:%M:%S"),
                "total_rules": len(QC_RULES),
                "passed_count": passed,
                "block_count": block_count,
                "warn_count": warn_count,
                "info_count": info_count,
                "quality_score": score,
                "quality_level": level,
                "status": home.status,
                "items": results,
            }

    # ---------------------------------------------------------------
    # 规则结果构造
    # ---------------------------------------------------------------
    @staticmethod
    def _pass(code: str) -> dict:
        name, level = HomeQcService._meta(code)
        return {
            "rule_code": code, "rule_name": name, "level": level,
            "result": "PASS", "issue_desc": None,
            "suggestion": None, "field_path": None,
        }

    @staticmethod
    def _fail(code: str, desc: str, suggestion: str, field_path: str) -> dict:
        name, level = HomeQcService._meta(code)
        return {
            "rule_code": code, "rule_name": name, "level": level,
            "result": "FAIL", "issue_desc": desc,
            "suggestion": suggestion, "field_path": field_path,
        }

    @staticmethod
    def _warn(code: str, desc: str, suggestion: str, field_path: str) -> dict:
        name, level = HomeQcService._meta(code)
        return {
            "rule_code": code, "rule_name": name, "level": level,
            "result": "WARN", "issue_desc": desc,
            "suggestion": suggestion, "field_path": field_path,
        }

    @staticmethod
    def _info(code: str, desc: str, suggestion: str, field_path: str) -> dict:
        name, level = HomeQcService._meta(code)
        return {
            "rule_code": code, "rule_name": name, "level": level,
            "result": "INFO", "issue_desc": desc,
            "suggestion": suggestion, "field_path": field_path,
        }

    @staticmethod
    def _meta(code: str):
        for item in QC_RULES:
            if item[0] == code:
                return item[1], item[2]
        return code, "INFO"

    # ---------------------------------------------------------------
    # 编码有效性
    # ---------------------------------------------------------------
    @staticmethod
    async def _is_valid_code(db: AsyncSession, code: str, code_type: str) -> bool:
        if not code:
            return False
        from app.modules.m05_06.clients import CodeTableClient
        try:
            return await CodeTableClient.is_valid(code, code_type)
        except Exception as exc:
            logger.warning("编码表不可用，跳过校验", extra={"error": str(exc)})
            return True  # 降级：编码表不可用时不阻断

    @staticmethod
    def _is_eye_operation(code: str) -> bool:
        """判断是否眼科操作（ICD-9-CM-3 08~16 章）"""
        if not code:
            return False
        try:
            prefix = code.split(".")[0]
            num = int(prefix)
            return 8 <= num <= 16
        except (ValueError, IndexError):
            return False

    # ---------------------------------------------------------------
    # 质控批次号
    # ---------------------------------------------------------------
    @staticmethod
    async def _next_qc_batch_no(db: AsyncSession, admission_id: int) -> str:
        from app.core.redis_client import RedisClient
        redis = await RedisClient.get_instance()
        key = "m05:home:qc_seq:%d" % admission_id
        seq = await redis.incr(key)
        await redis.expire(key, 86400)
        return "QC%d%03d" % (admission_id, seq)

    # ---------------------------------------------------------------
    # 催办
    # ---------------------------------------------------------------
    @staticmethod
    async def urge(body, user: dict) -> dict:
        from app.modules.m05_06.clients import MessageClient
        async with get_db() as db:
            stmt = select(M05MedicalRecordHome).where(
                M05MedicalRecordHome.is_deleted == False,
                M05MedicalRecordHome.status.in_(["DRAFT", "QC_FAIL"]),
            )
            if body.dept_id:
                stmt = stmt.where(M05MedicalRecordHome.discharge_dept_id == body.dept_id)
            if body.overdue_hours:
                threshold = datetime.now() - timedelta(hours=body.overdue_hours)
                stmt = stmt.where(M05MedicalRecordHome.discharge_time <= threshold)
            homes = (await db.scalars(stmt.limit(body.max_count))).all()

            sent = 0
            for home in homes:
                try:
                    await MessageClient.send(
                        template="HOME_URGE",
                        receiver_id=home.coder_id or home.attending_doctor_id,
                        params={
                            "patient_name": home.patient_name,
                            "admission_no": home.admission_no,
                            "status": home.status,
                        },
                    )
                    sent += 1
                except Exception as exc:
                    logger.warning("催办消息发送失败", extra={"home_id": home.id, "error": str(exc)})

            return {
                "matched_count": len(homes),
                "sent_count": sent,
                "failed_count": len(homes) - sent,
            }
```

### 6.7 DRG 预分组实现

```python
import logging
from typing import Optional

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from app.modules.m05_06.models import M05HomeDiagnosis, M05HomeOperation

logger = logging.getLogger("m05_06.drg")


class DrgPreGrouper:
    """轻量眼科 DRG 预分组器（粗分类，仅用于编码自查）"""

    # 主要诊断 ICD-10 章节 → MDC
    OPHTHALMIC_PREFIXES = ("H00", "H01", "H02", "H03", "H04", "H05",
                           "H10", "H11", "H15", "H16", "H17", "H18",
                           "H20", "H21", "H22", "H25", "H26", "H27",
                           "H30", "H31", "H32", "H33", "H34", "H35",
                           "H36", "H40", "H42", "H43", "H44", "H45",
                           "H46", "H47", "H48", "H49", "H50", "H51",
                           "H52", "H53", "H54", "H55", "H57", "H58",
                           "H59")

    # 主要手术 ICD-9-CM-3 前缀 → 手术组
    OP_GROUP_MAP = [
        (("14.",), "MDC02-OP-VR", "玻璃体视网膜手术组"),
        (("13.",), "MDC02-OP-CATARACT", "白内障手术组"),
        (("12.",), "MDC02-OP-GLAUCOMA", "青光眼手术组"),
        (("11.6",), "MDC02-OP-CORNEA", "角膜手术组"),
        (("08.", "09.", "10."), "MDC02-OP-OCULOPLASTY", "眼睑眼表手术组"),
    ]

    # 主要诊断 → 内科组
    MED_GROUP_MAP = [
        (("H20",), "MDC02-MED-UVEITIS", "葡萄膜炎内科组"),
        (("H36",), "MDC02-MED-DR", "糖尿病眼病内科组"),
    ]

    @classmethod
    async def predict(cls, db: AsyncSession, home) -> Optional[str]:
        """返回预分组代码"""
        diags = (await db.scalars(
            select(M05HomeDiagnosis).where(
                M05HomeDiagnosis.home_id == home.id,
                M05HomeDiagnosis.diag_role == "PRINCIPAL",
                M05HomeDiagnosis.is_deleted == False,
            )
        )).all()
        if not diags:
            return None
        principal = diags[0]
        code = principal.code or ""

        # ① 是否眼科
        if not any(code.startswith(p) for p in DrgPreGrouper.OPHTHALMIC_PREFIXES):
            return "NON-OPHTHALMIC"

        # ② 取主要手术
        ops = (await db.scalars(
            select(M05HomeOperation).where(
                M05HomeOperation.home_id == home.id,
                M05HomeOperation.op_role == "PRINCIPAL",
                M05HomeOperation.is_deleted == False,
            )
        )).all()

        if ops:
            op_code = ops[0].code or ""
            for prefixes, group, _desc in DrgPreGrouper.OP_GROUP_MAP:
                if any(op_code.startswith(p) for p in prefixes):
                    return group

        # ③ 内科组
        for prefixes, group, _desc in DrgPreGrouper.MED_GROUP_MAP:
            if any(code.startswith(p) for p in prefixes):
                return group

        return "MDC02-MED-OTHER"

    @classmethod
    def describe(cls, group_code: str) -> str:
        for _prefixes, group, desc in cls.OP_GROUP_MAP:
            if group == group_code:
                return desc
        for _prefixes, group, desc in cls.MED_GROUP_MAP:
            if group == group_code:
                return desc
        mapping = {
            "MDC02-MED-OTHER": "眼科其他内科组",
            "NON-OPHTHALMIC": "非眼科",
        }
        return mapping.get(group_code, "未知")
```

**关键设计说明：**

1. **预分组只看主要诊断+主要手术**：真实 DRG 分组还要看并发症合并症（CC/MCC）、年龄、出院状态等，本地预分组不追求准确，只求「粗分不对时能报警」。如果预分组是「白内障手术组」但主要诊断填了「2 型糖尿病」，说明编码选错了。
2. **`MED_GROUP_MAP` 只在无主要手术时生效**：有手术就是手术组，不管诊断是什么。
3. **`NON-OPHTHALMIC` 的用途**：如果眼科医院出现非眼科主要诊断，通常是编码错误或收治了非眼科病人，需要人工复核。

### 7.1 Redis 缓存

| 身份证号 | 保留前 4 位与后 4 位，中间用 `*` 填充 |
| 手机号 | 保留前 3 位与后 4 位 |
| 现住址 | 详情页完整显示（首页本身就是病案内容）；列表页不显示 |
| 工作单位 | 同上 |

**为什么首页可以显示完整身份证号：** 病案首页是法定文书，本就必须含完整信息。患者查阅权限制由「谁能打开病案首页」的权限控制，而非字段级脱敏。列表页不含完整信息是为了减少屏幕截屏泄露面。

**为什么眼科需要 18 个扩展字段：**

眼科的核心特殊性是「**同一个疾病编码，左右眼是两个独立的治疗事件**」。国家标准首页只有「诊断编码」一个维度，无法表达「左眼做了手术、右眼还在观察」。如果不做扩展：

1. **医保稽核无法确认**：两次同编码住院，无法证明是左右眼而非重复收费。
2. **DRG 分组失真**：双眼同期手术与单眼手术的医疗资源消耗不同，但出院同一个组。
3. **临床质量无法评价**：白内障手术的术后视力提升是核心质量指标，但首页无视力字段。

因此眼科扩展字段是**必填的业务需求**，不是「锦上添花」。其中眼别、植入物信息、日间手术标记三项在多数省份已纳入医保报送要求。
