## 1. 模块概述

### 1.1 模块定位

M05-05 出院办理与病历归档是住院闭环的**收口子模块**。M05-03 完成了「患者离床、住院单关闭」，M05-05 负责「这份病历从散落在各科室的碎片，变成一份完整、可追溯、可提交病案室的正式病案」。

```
┌──────────────────────────────────────────────────────────────────────────┐
│                     M05-05 在住院闭环中的位置                             │
└──────────────────────────────────────────────────────────────────────────┘

  M05-01          M05-03          M05-04          M16-03
  入院登记  →  在院管理/出院登记 →  费用联动  →  出院结算
                                        │
                                        ▼  结算完成
  ┌────────────────────────────────────────────────────────────────────┐
  │              M05-05 出院办理与病历归档                              │
  │  ────────────────────────────────────────────────────────────────  │
  │  ① 出院小结归档（从 M07-06 取文书、核签字）                          │
  │  ② 病历完整性检查（14 项 D-01~D-14）                                │
  │  ③ 缺陷整改与催办                                                   │
  │  ④ 病案整理与提交病案室                                              │
  │  ⑤ 归档封存与借阅控制                                               │
  └────────────────────────────────┬───────────────────────────────────┘
                                   │ 提交
                                   ▼
  ┌────────────────────────────────────────────────────────────────────┐
  │           M18 电子病历与知识库（病案库/CA 签名/长期保存）             │
  └────────────────────────────────────────────────────────────────────┘
```

**一句话定位：** M05-05 **不写病历内容、不做临床判断**，它负责「确认病历齐不齐、补齐缺的、封存交给病案室」—— 病案质控的第一道关口。

### 1.2 为什么独立成子模块

| # | 理由 | 详述 |
|---|---|---|
| 1 | **出院办理是一个跨 5 个岗位的协作流程** | 医生（小结）→ 护士（护理记录/交接）→ 医技（报告）→ 住院处（结算）→ 病案室（归档）。每个岗位只能看到自己的一段，需要一个「总协调方」跟踪整份病历的状态 |
| 2 | **病历完整性检查是一套独立的判定体系** | 14 项必检项（D-01~D-14）分别来自 M07/M08/M09/M12/M13/M16 六个模块，判定逻辑（PRESENT/MISSING/UNKNOWN）与催办策略自成一体 |
| 3 | **归档封存是不可逆的法律动作** | 一旦提交病案室，病历进入只读。撤销归档需要病案室主任审批 + 原因留痕。这是独立的权限与状态机 |
| 4 | **病案首页提交前必须质控** | M05-06 定义首页字段，M05-05 负责在提交前跑质控规则、拦截不合格病案 |
| 5 | **眼科日间手术「当天走」的归档压力** | 日间手术中心患者 2~6 小时离院，出院小结必须在患者离院前完成，否则患者走了医生还在写小结。M05-05 需要「快速归档通道」 |

**反证：** 若不独立，把完整性检查塞进 M05-03 的出院登记流程里，会得到两套不一致的判定标准；把归档塞进 M18，会让 M18 从「电子病历库」变成「病案质控岗」。

### 1.4 概念辨析

| 概念对 | 区别 |
|---|---|
| **出院登记 vs 出院办理** | 前者是 M05-03 的「患者离床、住院单关闭」动作；后者是 M05-05 的「病历整理归档」动作。患者可以在 10:00 出院登记，15:00 才办完出院办理 |
| **出院小结 vs 出院记录** | 出院小结是给患者/家属看的简要总结（病情、治疗、出院医嘱）；出院记录是病历组成部分（含完整的入院情况、诊疗经过、出院情况）。眼科医院两者合一，统称出院小结 |
| **病历完整性 vs 病案质控** | 完整性是「有没有」的二元判定（D-01~D-14）；质控是「好不好」的等级评定（甲级/乙级/丙级），归病案室 |
| **归档 vs 封存** | 归档是把纸质/电子病历整理后提交病案室；封存是发生医疗纠纷时由医务科/法院贴封条，封存期间任何人不得查阅 |
| **提交病案室 vs 提交病案首页** | 前者是整份病历（M05-05 做）；后者是首页数据上报医保/卫健（M05-06 做） |

### 1.5 模块目标

| 指标 | 目标值 | 说明 |
|---|---|---|
| 出院小结归档率 | 100% | 出院后 24 小时内完成归档 |
| 日间手术当日归档率 | ≥ 98% | 患者离院前完成（快速通道） |
| 病历完整性检查覆盖率 | 100% | 每份病历必须检查 |
| 缺陷发现率 | ≥ 5% | 说明检查有效（太低说明检查走形式） |
| 缺陷整改率 | ≥ 95% | 24 小时内整改 |
| 平均归档时长 | ≤ 8 小时 | 从出院登记到提交病案室 |
| 迟归档率 | ≤ 3% | 超 48 小时未归档 |
| 归档差错率 | 0 | 归档后发现内容缺失 |
| 病案首页质控通过率 | ≥ 95% | 首次提交通过 |
| 封存响应时长 | ≤ 1 小时 | 接到通知后完成封存 |

## 2. 业务范围与边界

### 2.1 范围内

1. **出院小结归档**
   - 从 M07-06 取 `DISCHARGE_SUMMARY` 文书
   - 核验文书状态为 `SIGNED`
   - 建立归档记录与文书关联
   - 豁免场景：转院 / 自动离院 / 死亡（`summary_exempt=TRUE`）

2. **病历完整性检查（14 项）**
   - D-01 入院记录、D-02 入院证（住院通知单）、D-03 首次病程记录、D-04 日常病程记录、D-05 上级医师查房记录、D-06 术前讨论记录、D-07 手术记录、D-08 麻醉记录、D-09 术后首次病程记录、D-10 手术安全核查记录、D-11 手术清点记录、D-12 手术同意书、D-13 麻醉同意书、D-14 护理记录
   - 判定结果 `PRESENT` / `MISSING` / `UNKNOWN` / `EXEMPT`
   - 逐项记录来源模块与可跳转链接

3. **缺陷整改与催办**
   - 生成缺陷清单（项 + 责任人 + 时限）
   - 通过 M03-05 通知责任人
   - 超时升级至科主任 / 医务科
   - 逐项关闭与复检

4. **病案整理与提交**
   - 病案排序（按《医疗机构病历管理规定》第三章）
   - 首页质控（调 M05-06）
   - 编码补全（诊断/手术 ICD）
   - 提交病案室（状态 `ARCHIVED`）

5. **归档封存**
   - 医务科发起封存通知
   - 病历状态置 `SEALED`
   - 封存期间禁止任何修改、查阅、借出
   - 解除封存需医务科 + 病案室主任双签

6. **归档撤销**
   - 需要在归档后补正的场景（如漏签小结）
   - 需病案室主任审批 + 原因 ≥20 字
   - 撤销后病历回到 `PENDING_ARCHIVE`，整改完成后重新提交

### 2.2 范围外

| 事项 | 归属 | 说明 |
|---|---|---|
| 出院小结书写与签字 | M07-06 | M05-05 只核状态 |
| 病案首页字段定义与质控规则 | M05-06 | M05-05 调用其质控接口 |
| 病历长期保存与 CA 签名 | M18 | M05-05 提交后转交 |
| 病案等级评定（甲乙丙级） | 病案室 / M22 | M05-05 只提供数据 |
| 医保首页上报 | 医保接口 | 走 M05-06 → 接口 |
| 医疗纠纷处理 | 医务科 / 法务 | M05-05 只执行封存 |
| 纸质病历扫描 | M18 | 电子化后统一处理 |
| 死亡证明开具 | 医务科 / 防保科 | M05-05 只记录死亡信息 |

### 2.3 与相邻模块的分工边界（一句话）

- M05-05 说「**这份病历齐不齐、能不能交**」
- M07-06 说「**出院小结写好了、医生签了**」
- M05-06 说「**病案首页的 300 个字段填对了没有**」
- M18 说「**病历存哪儿、存多久、给谁看**」

## 3. 业务模型

### 3.1 出院办理全景

```
患者出院登记（M05-03，住院单 DISCHARGED）
    │
    ▼
┌─────────────────────────────────────────────────────────────────────┐
│ ① 自动创建归档单（archiving_status = PENDING）                        │
│    来源：m05_discharge 记录，含 admission_id / stay_id / discharge_id │
└───────────────────────────┬─────────────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────────────────┐
│ ② 拉取出院小结（M07-06）                                              │
│    ├─ 有 SIGNED 小结 → summary_status = SIGNED                        │
│    ├─ 只有 DRAFT     → summary_status = DRAFT，缺陷 D-15             │
│    └─ 无小结         → summary_status = MISSING，缺陷 D-15           │
│        （豁免：转院/自动离院/死亡 → EXEMPT）                            │
└───────────────────────────┬─────────────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────────────────┐
│ ③ 病历完整性检查（14 项，并发调用 6 个模块）                            │
│    ├─ 全部 PRESENT/EXEMPT → 通过                                      │
│    ├─ 有 MISSING          → 生成缺陷清单 → 催办 → 等待整改             │
│    └─ 有 UNKNOWN          → 24 小时内自动重检                          │
└───────────────────────────┬─────────────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────────────────┐
│ ④ 首页质控（M05-06）                                                  │
│    ├─ 通过 → 继续                                                     │
│    └─ 不通过 → 缺陷清单（Q-01~Q-12）→ 催办                            │
└───────────────────────────┬─────────────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────────────────┐
│ ⑤ 病案整理（编码补全、排序）                                          │
└───────────────────────────┬─────────────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────────────────┐
│ ⑥ 提交病案室（M18）                                                   │
│    ├─ 成功 → archiving_status = ARCHIVED，设 archived_at             │
│    └─ 失败 → 补偿队列重试 5 次 → 人工介入                             │
└─────────────────────────────────────────────────────────────────────┘
```

### 3.2 归档状态机（10 态）

```
                    ┌──────────┐
                    │ PENDING  │ 归档单已创建，待检查
                    └────┬─────┘
                         │ 完整性检查
              ┌──────────┼──────────┐
              ▼                     ▼
      ┌──────────────┐      ┌──────────────┐
      │ CHECKING     │      │ 检查完成       │
      │ 检查中        │      └──────┬───────┘
      └──────┬───────┘             │
             │                     ▼
             │         ┌────────────────────┐
             │         │                    │
             │    ┌────▼─────┐      ┌───────▼──────┐
             │    │ DEFECT   │      │ READY        │
             │    │ 有缺陷    │      │ 检查通过待提交│
             │    └────┬─────┘      └───────┬──────┘
             │         │ 整改完成            │ 提交病案室
             │         └──────► CHECKING     ▼
             │                       ┌──────────────┐
             │                       │ ARCHIVED     │
             │                       │ 已归档        │
             │                       └──────┬───────┘
             │                              │ 撤销归档（审批）
             │                              ▼
             │                       ┌──────────────┐
             │                       │ REOPENED     │
             │                       └──────┬───────┘
             │                              │ 重新提交
             │                              └──────► ARCHIVED
             │
             │  ┌──────────┐   ┌──────────────┐
             └─►│ SEALED   │◄──│ 封存通知       │
                │ 已封存    │   └──────────────┘
                └────┬─────┘
                     │ 解除封存（双签）
                     ▼
              ┌──────────────┐
              │ UNSEALED     │ → 回到 SEALED 前状态
              └──────────────┘

  CANCELLED：归档单作废（如误创建、住院单撤销），需审批
```

**状态说明：**

| 状态 | 中文 | 说明 | 可执行操作 |
|---|---|---|---|
| `PENDING` | 待检查 | 归档单创建，尚未检查 | 开始检查、作废 |
| `CHECKING` | 检查中 | 正在并发调用 6 个模块 | 无（等待） |
| `DEFECT` | 有缺陷 | 存在 MISSING 项 | 催办、重检、整改 |
| `READY` | 待提交 | 检查全部通过 | 提交病案室、强制提交 |
| `ARCHIVED` | 已归档 | 已提交病案室 | 撤销归档、封存 |
| `REOPENED` | 已撤回 | 撤销归档后回到整改 | 重检、重新提交 |
| `SEALED` | 已封存 | 纠纷封存，只读 | 解除封存 |
| `UNSEALED` | 已解封 | 解除封存，回到封存前状态 | 同封存前状态 |
| `CANCELLED` | 已作废 | 归档单无效 | 无 |
| `FAILED` | 提交失败 | M18 提交失败 | 重试、人工 |

**关键决策：`ARCHIVED` 之后为什么还有 `REOPENED`**

医学现实：归档后才发现「漏签一个手术同意书」「诊断编码写错了」。若不允许撤销归档，就只能「在已归档病历上直接改」，那会破坏病历的不可篡改性（法律要求）。

正确做法是：撤销归档 → 病历回到可编辑状态 → 补正 → 重新提交并生成新的归档批次号。**撤销与重新归档都必须留痕**（`m05_archive_log`）。

**D-15（出院小结）不在 D-01~D-14 内，由 M05-05 单独检查**，因为它不由外部模块提供「存在性」，而是 M05-05 自己拉取并核状态。

**判定规则：**

```python
# 判定逻辑（伪代码，实现见 6.6）
def judge(item_code, source_result, context):
    # ① 豁免优先
    if is_exempt(item_code, context):
        return "EXEMPT"
    # ② 来源模块返回明确「有」
    if source_result is True:
        return "PRESENT"
    # ③ 来源模块返回明确「无」
    if source_result is False:
        return "MISSING"
    # ④ 来源模块不可用或无返回
    return "UNKNOWN"
```

**`UNKNOWN` 与 `MISSING` 必须分开的三个理由：**

1. **性质不同**：`MISSING` 是「确定没有」（医生漏写），`UNKNOWN` 是「系统不知道」（M08 挂了）。前者要催办医生，后者要等系统恢复重检。
2. **催办对象不同**：`MISSING` 催办到具体责任人，`UNKNOWN` 催办到 IT + 该模块负责人。
3. **归档决策不同**：`MISSING` 阻断归档；`UNKNOWN` 连续 24 小时未恢复时可人工确认后放行（`m05_archive.unknown_waived=TRUE`）。

**这是 M06-06 引入的同一套判定体系的延伸** —— `M06日间手术管理/M06_日间手术管理_06_日间结算与病历归档_详细设计.md:3077` 的 `if owner in ("M09", "M08") and result == "MISSING"` 逻辑与本模块一致。

### 3.4 缺陷整改闭环

```
缺陷生成（D-01~D-15 / Q-01~Q-12）
    │
    ├── 定责：责任科室 + 责任人 + 时限
    │     ├─ D-01/D-03~D-06/D-09/D-15 → 责任医生（4 小时）
    │     ├─ D-02 → 住院处（2 小时）
    │     ├─ D-07/D-08/D-10/D-11/D-13 → 麻醉科/手术室（4 小时）
    │     ├─ D-12 → 责任医生（4 小时）
    │     ├─ D-14 → 病区护士（4 小时）
    │     └─ Q-01~Q-12 → 病案室编码员（8 小时）
    │
    ├── 通知（M03-05）：站内 + 短信
    │
    ├── 超时升级：
    │     ├─ 超时限 1 倍 → 科主任
    │     ├─ 超时限 2 倍 → 医务科
```

**为什么按缺陷类型定责任人而不是按科室：**
一份病历的缺陷可能分散在 6 个模块。按科室定责会导致「医生说我写完了、护士说不是我」的推诿。按「缺陷类型 → 唯一责任人」定责，无争议。

### 3.7 封存模型

**触发：**
- 医务科发起封存通知（医疗纠纷、法院调取证据、患者投诉）
- 输入：住院号、封存原因、发起人、有效期（可选）

**执行：**
- 归档单状态 → `SEALED`
- 写入 `m05_archive_seal` 记录（封存单号、原因、发起人、封存时刻、有效期）
- 通知 M18 同步封存（M18 侧禁止任何读写）

**解除：**
- 需医务科 + 病案室主任双签
- 记录解除时刻、解除原因、双签人
- 归档单回到 `SEALED` 之前的状态

**封存期间的行为限制：**

| 操作 | 封存期间 |
|---|---|
| 查看病历正文 | ❌ 禁止（除非医务科授权只读） |
| 修改任何字段 | ❌ 禁止 |
| 借阅 | ❌ 禁止 |
| 打印 | ❌ 禁止（法院调取走医务科流程） |
| 撤销归档 | ❌ 禁止 |

### 3.8 归档撤销模型

**允许撤销的场景：**

| 场景 | 审批人 | 原因字数 |
|---|---|---|
| 漏签文书 | 病案室主任 | ≥ 20 |
| 诊断编码错误 | 病案室主任 | ≥ 20 |
| 首页数据错误 | 病案室主任 + 病案质控 | ≥ 20 |
| 法院/医保核查要求补正 | 医务科 + 病案室主任 | ≥ 20 |

**撤销与重新归档的留痕：**

`m05_archive_log` 记录：
- `REOPEN` 动作（含审批人、原因、撤销时刻）
- `REARCHIVE` 动作（含新的 `archive_batch_no`）

**`archive_batch_no` 递增：** 首次归档为 `BA202610280001-1`，撤销后重新归档为 `-2`，保证「同一个住院号可能有多份归档记录，最后一份有效」。

### 3.9 数量与状态铁律

1. **一住院单对应一个归档单**（`uk_m05_archive_admission`），撤销后复用同一条记录，不新建
2. **`ARCHIVED` 必须由 M18 确认成功后置位**，不允许乐观置位
3. **封存期间任何写操作返回 `"0505010"`**
4. **D-01~D-14 全部 PRESENT/EXEMPT 才可进 `READY`**
5. **`UNKNOWN` 连续 24 小时可人工豁免**，`unknown_waived=TRUE` 且必须填审批人
6. **归档撤销必须重新走完整检查**，不允许「只补这一项就重新提交」
7. **归档批次号单调递增**

```python
    async def run_check(self, archive_id: int, force: bool = False) -> Dict[str, Any]:
        """执行完整性检查。"""
        archive = await self._get(archive_id)
        if archive.status == ST_SEALED:

        await self._transition(archive, ST_CHECKING)

        started = datetime.now()
        ctx = await self._load_context(archive)
        results = await self._check_all(ctx)
        duration = int((datetime.now() - started).total_seconds() * 1000)

        check_batch_no = "%s" % await self._next_check_no()
        present = missing = unknown = exempt = 0
        for item, result in results:
            if result["result"] == "PRESENT":
                present += 1
            elif result["result"] == "MISSING":
                missing += 1
            elif result["result"] == "UNKNOWN":
                unknown += 1
            else:
                exempt += 1
            self.db.add(M05ArchiveCheck(
                archive_id=archive.id,
                check_batch_no=check_batch_no,
                item_code=item["code"],
                item_name=item["name"],
                source_module=item["module"],
                result=result["result"],
                document_id=result.get("document_id"),
                source_ref=result.get("source_ref"),
                detail=result.get("detail"),
                responsible_role=result.get("responsible_role"),
                responsible_id=result.get("responsible_id"),
                responsible_name=result.get("responsible_name"),
                checked_at=datetime.now(),
            ))

        archive.present_count = present
        archive.missing_count = missing
        archive.unknown_count = unknown
        archive.exempt_count = exempt
        archive.last_checked_at = datetime.now()
        archive.check_batch_no = check_batch_no

        new_status = ST_DEFECT if (missing > 0 or
                                   (unknown > 0 and not archive.unknown_waived)) \
            else ST_READY
        await self._transition(archive, new_status)
        await self._log(archive.id, "CHECK",
                        "完整性检查：PRESENT=%d MISSING=%d UNKNOWN=%d EXEMPT=%d"
                        % (present, missing, unknown, exempt),

        logger.info(
            "m05 archive checked id=%d present=%d missing=%d unknown=%d ms=%d",
            archive_id, present, missing, unknown, duration,
        )
        return {
            "archive_id": archive.id,
            "check_batch_no": check_batch_no,
            "status": new_status,
            "checked_at": started.isoformat(),
            "duration_ms": duration,
            "present_count": present,
            "missing_count": missing,
            "unknown_count": unknown,
            "exempt_count": exempt,
            "items": [
                {"item_code": i["code"], "item_name": i["name"],
                 "result": r["result"], "source_module": i["module"]}
                for i, r in results
            ],
        }

    async def _check_all(self, ctx: Dict[str, Any]) -> List[tuple]:
        """并发检查 14 项。"""
        results: List[tuple] = []
        for item in CHECK_ITEMS:
            try:
                res = await self._check_one(item, ctx)
            except Exception as exc:  # noqa: BLE001
                logger.warning(
                    "m05 archive check item failed code=%s err=%s",
                    item["code"], exc,
                )
                res = {"result": "UNKNOWN", "detail": str(exc)[:200]}
            if res["result"] == "MISSING":
                owner = DEFECT_OWNER.get(item["code"], ("DOCTOR", 4))
                res["responsible_role"] = owner[0]
            results.append((item, res))
        return results

    async def _check_one(
        self, item: Dict[str, Any], ctx: Dict[str, Any]
    ) -> Dict[str, Any]:
        """单项检查。"""
        code = item["code"]

        # ① 豁免判定
        exempt = self._is_exempt(item, ctx)
        if exempt:
            return {"result": "EXEMPT", "detail": exempt}

        # ② 按来源模块分派
        if code == "D-02":
            return {"result": "PRESENT" if ctx["admission"] else "MISSING",
                    "source_ref": ctx["admission"].get("admission_no")}

        if item["module"] in ("M07-06", "M08", "M09"):
            docs = ctx["documents"].get(code, [])
            if docs:
                return {"result": "PRESENT", "document_id": docs[0].get("id"),
                        "source_ref": docs[0].get("document_no")}
            return {"result": "MISSING"}

        return {"result": "UNKNOWN"}

    def _is_exempt(self, item: Dict[str, Any], ctx: Dict[str, Any]) -> Optional[str]:
        """豁免判定。"""
        stay_hours = ctx.get("stay_hours", 0)
        if item.get("min_stay_hours") and stay_hours < item["min_stay_hours"]:
            return "住院时长 %d 小时，未达 %d 小时豁免阈值" % (
                stay_hours, item["min_stay_hours"]
            )
        if item.get("min_stay_days") and ctx.get("stay_days", 0) < item["min_stay_days"]:
            return "住院 %d 天，未达 %d 天豁免阈值" % (
                ctx.get("stay_days", 0), item["min_stay_days"]
            )
        cond = item.get("required_if")
        if cond == "has_surgery" and not ctx.get("has_surgery"):
            return "本次住院无手术"
        if cond == "has_anesthesia" and not ctx.get("has_anesthesia"):
            return "本次住院无麻醉"
        if cond == "surgery_level>=2" and ctx.get("surgery_level", 0) < 2:
            return "手术分级 %d 级，无需术前讨论" % ctx.get("surgery_level", 0)
        return None

    async def _load_context(self, archive: M05Archive) -> Dict[str, Any]:
        """加载检查上下文。"""
        from app.clients.m05 import AdmissionClient, StayClient
        from app.clients.m07 import DocumentClient
        from app.clients.m08 import NursingClient
        from app.clients.m09 import SurgeryClient

        ctx: Dict[str, Any] = {
            "admission": await AdmissionClient(self.db).get(archive.admission_id),
            "stay": await StayClient(self.db).by_admission(archive.admission_id),
            "documents": {},
            "has_surgery": False,
            "has_anesthesia": False,
            "surgery_level": 0,
            "stay_hours": 0,
            "stay_days": 0,
        }
        stay = ctx["stay"]
        if stay:
            ctx["stay_days"] = stay.get("stay_days", 0)
            ctx["stay_hours"] = ctx["stay_days"] * 24

        # 并发拉取 M07/M08/M09
        doc_task = DocumentClient(self.db).by_source(
            "ADMISSION", archive.admission_id
        )
        nursing_task = NursingClient(self.db).by_admission(archive.admission_id)
        surgery_task = SurgeryClient(self.db).by_admission(archive.admission_id)
        docs, nursing, surgery = await asyncio.gather(
            doc_task, nursing_task, surgery_task, return_exceptions=True,
        )

        if not isinstance(docs, Exception) and docs:
            ctx["documents"].update(self._map_documents(docs))
            ctx["documents"]["D-15"] = [
                d for d in docs if d.get("doc_type") == "DISCHARGE_SUMMARY"
            ]
        if not isinstance(nursing, Exception) and nursing:
            ctx["documents"]["D-14"] = nursing.get("records", [])
        if not isinstance(surgery, Exception) and surgery:
            ctx["has_surgery"] = bool(surgery.get("operations"))
            ctx["has_anesthesia"] = bool(surgery.get("anesthesia"))
            ctx["surgery_level"] = surgery.get("max_surgery_level", 0)
            ctx["documents"]["D-07"] = surgery.get("operations", [])
            ctx["documents"]["D-08"] = surgery.get("anesthesia", [])
            ctx["documents"]["D-10"] = surgery.get("safety_checks", [])
            ctx["documents"]["D-11"] = surgery.get("count_records", [])
            ctx["documents"]["D-13"] = surgery.get("anesthesia_consents", [])
        return ctx

    @staticmethod
    def _map_documents(docs: List[Dict[str, Any]]) -> Dict[str, List[Dict[str, Any]]]:
        """M07-06 文书类型 → D 项映射。"""
        mapping = {
            "ADMISSION_RECORD": "D-01",
            "FIRST_PROGRESS": "D-03",
            "PROGRESS_NOTE": "D-04",
            "ROUND_NOTE": "D-05",
            "PRE_OP_DISCUSSION": "D-06",
            "POST_OP_PROGRESS": "D-09",
            "OPERATION_CONSENT": "D-12",
        }
        out: Dict[str, List[Dict[str, Any]]] = {}
        for doc in docs:
            key = mapping.get(doc.get("doc_type", ""))
            if key:
                out.setdefault(key, []).append(doc)
        return out

    # ==================== 提交 ====================

    async def submit(self, archive_id: int, body: Any) -> Dict[str, Any]:
        """提交病案室。"""
        archive = await self._get(archive_id)
        if archive.status == ST_SEALED:
            raise BizException("0505010", "病历已封存，禁止此操作")
        if archive.status == ST_ARCHIVED:
            raise BizException("0505038", "该病历已归档，无需重复提交")
        if archive.status not in SUBMITTABLE:
            raise BizException("0505002", "归档单状态不允许此操作")
        if archive.missing_count and archive.missing_count > 0:
            raise BizException("0505009", "存在未整改缺陷，不能提交")

        # ICD 编码校验
        await self._check_icd(archive)

        # 首页质控
        quality = await self._quality_check(archive)
        if not quality.get("passed"):
            raise BizException("0505013", "病案首页质控未通过")

        # 提交 M18
        from app.clients.m18 import ArchiveClient

        batch_no = await self._next_batch_no()
        try:
            m18_result = await ArchiveClient(self.db).submit({
                "admission_id": archive.admission_id,
                "admission_no": archive.admission_no,
                "archive_batch_no": batch_no,
                "document_count": quality.get("document_count", 0),
                "home_page": quality.get("home_page"),
            })
        except Exception as exc:  # noqa: BLE001
            archive.submit_retry = (archive.submit_retry or 0) + 1
            archive.fail_reason = str(exc)[:500]
            if archive.submit_retry >= self.MAX_SUBMIT_RETRY:
                await self._transition(archive, ST_FAILED)
            await self.db.flush()
            logger.error(
                "m05 archive submit failed id=%d retry=%d err=%s",
                archive_id, archive.submit_retry, exc,
            )
            raise BizException("0505014", "提交病案库失败: %s" % exc)

        old_status = archive.status
        archive.archive_batch_no = batch_no
        archive.archived_at = datetime.now()
        archive.archived_by = self.user.get("employee_id") if self.user else 0
        archive.m18_archive_id = m18_result.get("archive_id")
        archive.document_count = quality.get("document_count", 0)
        archive.submit_retry = 0
        archive.fail_reason = None
        await self._transition(archive, ST_ARCHIVED)
        await self._log(archive.id, "ARCHIVE",
                        "提交病案室，批次号 %s" % batch_no, old_status, ST_ARCHIVED)
        await self.db.flush()

        duration_hours = (
            (archive.archived_at - archive.discharged_at).total_seconds() / 3600
        )
        logger.info(
            "m05 archive submitted id=%d admit=%d batch=%s hours=%.2f",
            archive_id, archive.admission_id, batch_no, duration_hours,
        )
        return {
            "archive_id": archive.id,
            "admission_no": archive.admission_no,
            "archive_batch_no": batch_no,
            "status": ST_ARCHIVED,
            "archived_at": archive.archived_at.isoformat(),
            "m18_archive_id": archive.m18_archive_id,
            "document_count": archive.document_count,
            "quality_status": "PASSED",
            "duration_hours": round(duration_hours, 2),
        }

            raise BizException("0505030", "强制提交说明不足 20 字")

        await self._log(archive.id, "FORCE_SUBMIT",
                        "强制提交：%s" % body.force_reason, archive.status,
                        archive.status)

    async def _check_icd(self, archive: M05Archive) -> None:

            raise BizException("0505012", "主要手术未编码")

    async def _quality_check(self, archive: M05Archive) -> Dict[str, Any]:
        """病案首页质控。"""
        from app.clients.m05 import HomePageClient

        try:
            return await HomePageClient(self.db).quality_check(archive.admission_id)

    # ==================== 撤销与重新归档 ====================

    async def reopen(self, archive_id: int, body: Any) -> Dict[str, Any]:
        """撤销归档。"""
        if not body.reopen_reason or len(body.reopen_reason.strip()) < self.REOPEN_REASON_MIN:
            raise BizException("0505016", "撤销归档原因不足 20 字")
        archive = await self._get(archive_id)
        if archive.status not in (ST_ARCHIVED,):
            raise BizException("0505002", "归档单状态不允许此操作")

        from app.clients.m18 import ArchiveClient

        await ArchiveClient(self.db).release(archive.m18_archive_id)

        old_batch = archive.archive_batch_no
        old_status = archive.status
        archive.reopen_reason = body.reopen_reason
        archive.reopened_at = datetime.now()
        archive.reopened_by = self.user.get("employee_id") if self.user else 0
        archive.archive_batch_seq = (archive.archive_batch_seq or 1)
        await self._transition(archive, ST_REOPENED)
        await self._log(archive.id, "REOPEN",
                        "撤销归档：%s" % body.reopen_reason,
                        old_status, ST_REOPENED)
        await self.db.flush()
        logger.warning(
            "m05 archive reopened id=%d batch=%s by=%s reason=%s",
            archive_id, old_batch, archive.reopened_by, body.reopen_reason,
        )
        return {
            "archive_id": archive.id,
            "admission_no": archive.admission_no,
            "old_batch_no": old_batch,
            "new_status": ST_REOPENED,
            "reopened_at": archive.reopened_at.isoformat(),
            "reopened_by": archive.reopened_by,
            "m18_released": True,
            "message": "已撤销归档，请补正后重新提交",
        }

    async def rearchive(self, archive_id: int, body: Any) -> Dict[str, Any]:
        """重新归档（增量批次号）。"""
        archive = await self._get(archive_id)
        if archive.status != ST_REOPENED:
            raise BizException("0505002", "归档单状态不允许此操作")
        archive.archive_batch_seq = (archive.archive_batch_seq or 1) + 1
        await self.db.flush()
        result = await self.submit(archive_id, body)
        await self._log(archive.id, "REARCHIVE",
                        "重新归档，批次序号 %d" % archive.archive_batch_seq,
                        ST_REOPENED, ST_ARCHIVED)
        return result

    async def get_workbench(

    async def _status_counts(
        self, ward_id: Optional[int], target: date
    ) -> Dict[str, int]:
        """状态计数。"""
        stmt = select(M05Archive.status, func.count(M05Archive.id)).where(

        if ward_id:
            stmt = stmt.where(M05Archive.ward_id == ward_id)
        stmt = stmt.group_by(M05Archive.status)
        rows = (await self.db.execute(stmt)).all()
        counts = {r[0]: r[1] for r in rows}
        late_stmt = select(func.count(M05Archive.id)).where(
            M05Archive.is_deleted.is_(False),
            M05Archive.status.notin_((ST_ARCHIVED, ST_CANCELLED)),
            M05Archive.discharged_at < datetime.now() - timedelta(hours=48),
        )
        if ward_id:
            late_stmt = late_stmt.where(M05Archive.ward_id == ward_id)
        late = (await self.db.execute(late_stmt)).scalar() or 0
        return {
            "pending": counts.get(ST_PENDING, 0) + counts.get(ST_CHECKING, 0),
            "defect": counts.get(ST_DEFECT, 0),
            "ready": counts.get(ST_READY, 0),
            "archived_today": counts.get(ST_ARCHIVED, 0),
            "late": late,
        }

    async def _timeliness(self, target: date) -> List[Dict[str, Any]]:
        """时效分布。"""
        start = datetime.combine(target, datetime.min.time()) - timedelta(days=7)
        stmt = select(M05Archive).where(
            M05Archive.is_deleted.is_(False),
            M05Archive.archived_at.isnot(None),
            M05Archive.archived_at >= start,
        )
        rows = list((await self.db.execute(stmt)).scalars().all())
        buckets = {"<=4h": 0, "4-8h": 0, "8-24h": 0, ">24h": 0}
        total = len(rows) or 1
        for r in rows:
            hours = (r.archived_at - r.discharged_at).total_seconds() / 3600
            if hours <= 4:
                buckets["<=4h"] += 1
            elif hours <= 8:
                buckets["4-8h"] += 1
            elif hours <= 24:
                buckets["8-24h"] += 1
            else:
                buckets[">24h"] += 1
        return [
            {"bucket": k, "count": v, "ratio": round(v / total, 4)}
            for k, v in buckets.items()
        ]

class CompletenessService:
    """完整性检查服务。"""

    UNKNOWN_WAIVE_HOURS = 24
    WAIVE_REASON_MIN = 10

    def __init__(self, db: AsyncSession, user: Optional[Dict[str, Any]]):
        self.db = db
        self.user = user

    async def run_check(self, archive_id: int, force: bool = False) -> Dict[str, Any]:
        return await ArchiveService(self.db, self.user).run_check(archive_id, force)

    async def get_checks(self, archive_id: int) -> Dict[str, Any]:
        """查询检查明细。"""
        stmt = select(M05ArchiveCheck).where(
            M05ArchiveCheck.archive_id == archive_id
        ).order_by(M05ArchiveCheck.item_code)
        rows = list((await self.db.execute(stmt)).scalars().all())
        if not rows:
            return {"archive_id": archive_id, "items": [],
                    "present_count": 0, "missing_count": 0,
                    "unknown_count": 0, "exempt_count": 0}
        present = sum(1 for r in rows if r.result == "PRESENT")
        missing = sum(1 for r in rows if r.result == "MISSING")
        unknown = sum(1 for r in rows if r.result == "UNKNOWN")
        exempt = sum(1 for r in rows if r.result == "EXEMPT")
        return {
            "archive_id": archive_id,
            "check_batch_no": rows[0].check_batch_no,
            "checked_at": rows[0].checked_at.isoformat(),
            "present_count": present,
            "missing_count": missing,
            "unknown_count": unknown,
            "exempt_count": exempt,
            "items": [
                {
                    "item_code": r.item_code,
                    "item_name": r.item_name,
                    "source_module": r.source_module,
                    "result": r.result,
                    "document_id": r.document_id,
                    "detail": r.detail,
                    "responsible_role": r.responsible_role,
                    "responsible_name": r.responsible_name,
                }
                for r in rows
            ],
        }

    async def waive_unknown(self, archive_id: int, body: Any) -> Dict[str, Any]:
        """人工豁免 UNKNOWN。"""
        if not body.reason or len(body.reason.strip()) < self.WAIVE_REASON_MIN:
            raise BizException("0505019", "人工豁免原因不足 10 字")
        archive = await ArchiveService(self.db, self.user)._get(archive_id)
        if archive.last_checked_at:
            elapsed = (datetime.now() - archive.last_checked_at).total_seconds()
            if elapsed < self.UNKNOWN_WAIVE_HOURS * 3600:
                raise BizException("0505018", "未到允许人工豁免时间")
        archive.unknown_waived = True
        archive.unknown_waive_reason = body.reason
        archive.unknown_waive_by = (
            self.user.get("employee_id") if self.user else 0
        )
        archive.unknown_waive_at = datetime.now()
        await self.db.flush()
        if archive.status == ST_DEFECT and (archive.missing_count or 0) == 0:
            await ArchiveService(self.db, self.user)._transition(
                archive, ST_READY
            )
        logger.warning(
            "m05 archive unknown waived id=%d by=%s reason=%s",
            archive_id, archive.unknown_waive_by, body.reason,
        )
        return {
            "archive_id": archive_id,
            "unknown_waived": True,
            "status": archive.status,
            "waived_at": archive.unknown_waive_at.isoformat(),
            "message": "已人工豁免 UNKNOWN 项，请重新检查",
        }

    async def document_status(self, admission_id: int) -> Dict[str, Any]:
        """文书齐备状态（M06-06 D-01~D-14 调用）。"""
        archive = await ArchiveService(self.db, self.user)._find_by_admission(
            admission_id
        )
        if not archive:
            return {
                "admission_id": admission_id,
                "exists": False,
                "all_present": False,
                "items": [],
            }
        stmt = select(M05ArchiveCheck).where(
            M05ArchiveCheck.archive_id == archive.id
        )
        rows = list((await self.db.execute(stmt)).scalars().all())
        return {
            "admission_id": admission_id,
            "exists": True,
            "archive_id": archive.id,
            "status": archive.status,
            "all_present": all(
                r.result in ("PRESENT", "EXEMPT") for r in rows
            ) if rows else False,
            "items": [
                {
                    "item_code": r.item_code,
                    "item_name": r.item_name,
                    "result": r.result,
                }
                for r in rows
            ],
        }


class DefectService:

    FIX_NOTE_MIN = 10

    def __init__(self, db: AsyncSession, user: Optional[Dict[str, Any]]):

        if mine and self.user:

        elif responsible_id:
            stmt = stmt.where(M05ArchiveDefect.responsible_id == responsible_id)
        total = (await self.db.execute(
            select(func.count()).select_from(stmt.subquery())
        )).scalar() or 0
        stmt = stmt.order_by(

            "pages": (total + page_size - 1) // page_size,
        }

    async def fix(self, defect_id: int, body: Any) -> Dict[str, Any]:
        if not body.fix_note or len(body.fix_note.strip()) < self.FIX_NOTE_MIN:
            raise BizException("0505022", "整改说明不足 10 字")
        defect = await self.db.get(M05ArchiveDefect, defect_id)
        if not defect or defect.is_deleted:
            raise BizException("0505020", "缺陷不存在")
        if defect.status == "CLOSED":
            raise BizException("0505023", "缺陷已关闭")
        if self.user and defect.responsible_id != self.user.get("employee_id"):
            raise BizException("0505021", "无权整改他人责任缺陷")
        defect.status = "FIXED"
        defect.fix_note = body.fix_note
        defect.fixed_by = self.user.get("employee_id") if self.user else 0
        defect.fixed_at = datetime.now()
        defect.attachment_urls = body.attachment_urls
        await self.db.flush()
        await self._maybe_recheck(defect.archive_id)
        return {
            "defect_id": defect.id,
            "status": defect.status,
            "fixed_at": defect.fixed_at.isoformat(),
            "message": "整改已提交，等待复检",
        }

    async def batch_fix(self, body: Any) -> Dict[str, Any]:
        if len(body.defect_ids) > self.MAX_BATCH:
            raise BizException("0505024", "批量整改数量超限")
        if not body.fix_note or len(body.fix_note.strip()) < self.FIX_NOTE_MIN:
            raise BizException("0505022", "整改说明不足 10 字")
        fixed = 0
        archive_ids = set()
        for did in body.defect_ids:
            try:
                await self.fix(did, body)
                fixed += 1
                defect = await self.db.get(M05ArchiveDefect, did)
                if defect:
                    archive_ids.add(defect.archive_id)
            except BizException as exc:
                logger.warning(
                    "m05 defect batch fix skip id=%d err=%s", did, exc.message
                )
        for aid in archive_ids:
            await self._maybe_recheck(aid)
        return {
            "defect_id": 0,
            "status": "FIXED",
            "fixed_at": datetime.now().isoformat(),
            "message": "批量整改完成 %d 条" % fixed,
            "fixed_count": fixed,
        }

    async def _maybe_recheck(self, archive_id: int) -> None:
        """全部缺陷整改后触发复检。"""
        stmt = select(func.count(M05ArchiveDefect.id)).where(
            M05ArchiveDefect.archive_id == archive_id,
            M05ArchiveDefect.status != "CLOSED",
            M05ArchiveDefect.is_deleted.is_(False),
        )
        remain = (await self.db.execute(stmt)).scalar() or 0
        if remain == 0:
            from app.tasks.m05_archive import run_check_task

            run_check_task.delay(archive_id)

    async def urge(self, archive_id: int, body: Any) -> Dict[str, Any]:
        """催办。"""
        from app.clients.m03 import MessageClient

        stmt = select(M05ArchiveDefect).where(
            M05ArchiveDefect.archive_id == archive_id,
            M05ArchiveDefect.status != "CLOSED",
            M05ArchiveDefect.is_deleted.is_(False),
        )
        rows = list((await self.db.execute(stmt)).scalars().all())
        sent = 0
        for d in rows:
            try:
                await MessageClient(self.db).send({
                    "receiver_id": d.responsible_id,
                    "channel": ["INBOX", "SMS"],
                    "title": "病案缺陷催办",
                    "content": "住院号 %s 的「%s」尚未完成，请在 %s 前整改"
                               % (d.admission_no, d.item_name,
                                  d.deadline_at.strftime("%m-%d %H:%M")),
                    "biz_type": "M05_ARCHIVE_DEFECT",
                    "biz_id": d.id,
                })
                sent += 1
            except Exception as exc:  # noqa: BLE001
                logger.warning(
                    "m05 urge failed defect=%d err=%s", d.id, exc
                )
        return {
            "archive_id": archive_id,
            "urged": sent,
            "total": len(rows),
            "message": "已催办 %d 项" % sent,

    async def statistics(self, date_from: date, date_to: date,

class SealService:
    """封存服务。"""

    SEAL_REASON_MIN = 20
    SEAL_REASONS = ("MEDICAL_DISPUTE", "COURT", "COMPLAINT", "INSURANCE", "OTHER")

    def __init__(self, db: AsyncSession, user: Optional[Dict[str, Any]]):
        self.db = db
        self.user = user

    async def seal(self, archive_id: int, body: Any) -> Dict[str, Any]:
        if not body.seal_desc or len(body.seal_desc.strip()) < self.SEAL_REASON_MIN:
            raise BizException("0505025", "封存原因不足 20 字")
        archive = await ArchiveService(self.db, self.user)._get(archive_id)
        if archive.status == ST_SEALED:
            raise BizException("0505002", "归档单状态不允许此操作")

        seal = M05ArchiveSeal(
            seal_no=await self._next_seal_no(),
            archive_id=archive.id,
            admission_id=archive.admission_id,
            admission_no=archive.admission_no,
            patient_name=archive.patient_name,
            seal_reason=body.seal_reason,
            seal_desc=body.seal_desc,
            seal_until=body.seal_until,
            sealed_by=self.user.get("employee_id") if self.user else 0,
            sealed_by_name=self.user.get("name", "") if self.user else "",
            sealed_at=datetime.now(),
            status="SEALED",
        )
        self.db.add(seal)

        old_status = archive.status
        archive.pre_seal_status = old_status
        await ArchiveService(self.db, self.user)._transition(archive, ST_SEALED)
        await ArchiveService(self.db, self.user)._log(
            archive.id, "SEAL", "封存：%s" % body.seal_desc,
            old_status, ST_SEALED,
        )
        await self.db.flush()

        m18_synced = False
        if body.notify_m18 and archive.m18_archive_id:
            from app.clients.m18 import ArchiveClient

            try:
                await ArchiveClient(self.db).seal(archive.m18_archive_id, {
                    "seal_no": seal.seal_no,
                    "reason": body.seal_desc,
                })
                m18_synced = True
            except Exception as exc:  # noqa: BLE001
                logger.error(
                    "m05 seal m18 sync failed archive=%d err=%s", archive_id, exc
                )

        logger.warning(
            "m05 archive sealed id=%d seal=%s reason=%s by=%s",
            archive_id, seal.seal_no, body.seal_reason, seal.sealed_by,
        )
        return {
            "seal_id": seal.id,
            "seal_no": seal.seal_no,
            "archive_id": archive.id,
            "admission_no": archive.admission_no,
            "old_status": old_status,
            "new_status": ST_SEALED,
            "sealed_at": seal.sealed_at.isoformat(),
            "m18_synced": m18_synced,
        }

    async def unseal(self, seal_id: int, body: Any) -> Dict[str, Any]:
        """解除封存（双签）。"""
        seal = await self.db.get(M05ArchiveSeal, seal_id)
        if not seal or seal.status != "SEALED":
            raise BizException("0505027", "封存单不存在")
        if not body.medical_affairs_password or not body.director_password:
            raise BizException("0505026", "解除封存需双签")
        archive = await ArchiveService(self.db, self.user)._get(seal.archive_id)
        if archive.status != ST_SEALED:
            raise BizException("0505028", "该病历未封存")

        seal.status = "UNSEALED"
        seal.unsealed_at = datetime.now()
        seal.unsealed_by = self.user.get("employee_id") if self.user else 0
        seal.unseal_note = body.unseal_note
        seal.medical_affairs_signer = body.medical_affairs_signer
        seal.director_signer = body.director_signer

        old_status = archive.status
        back_status = archive.pre_seal_status or ST_ARCHIVED
        await ArchiveService(self.db, self.user)._transition(archive, ST_UNSEALED)
        archive.status = back_status
        await ArchiveService(self.db, self.user)._log(
            archive.id, "UNSEAL", "解除封存：%s" % body.unseal_note,
            old_status, back_status,
        )
        await self.db.flush()

        if archive.m18_archive_id:
            from app.clients.m18 import ArchiveClient

            try:
                await ArchiveClient(self.db).unseal(archive.m18_archive_id)
            except Exception as exc:  # noqa: BLE001
                logger.error(
                    "m05 unseal m18 sync failed archive=%d err=%s",
                    archive.id, exc,
                )

        return {
            "seal_id": seal.id,
            "seal_no": seal.seal_no,
            "archive_id": archive.id,
            "new_status": back_status,
            "unsealed_at": seal.unsealed_at.isoformat(),
            "medical_affairs_signer": seal.medical_affairs_signer,
            "director_signer": seal.director_signer,
        }

class ArchiveStatService:
    """归档统计服务。"""

    def __init__(self, db: AsyncSession, user: Optional[Dict[str, Any]]):
        self.db = db
        self.user = user

    async def statistics(self, date_from: date, date_to: date,
                         dept_id: Optional[int]) -> Dict[str, Any]:
        """归档统计。"""
        stmt = select(M05Archive).where(
            M05Archive.is_deleted.is_(False),
            M05Archive.discharged_at >= datetime.combine(
                date_from, datetime.min.time()
            ),
            M05Archive.discharged_at < datetime.combine(
                date_to, datetime.min.time()
            ) + timedelta(days=1),
        )
        if dept_id:
            stmt = stmt.where(M05Archive.dept_id == dept_id)
        rows = list((await self.db.execute(stmt)).scalars().all())
        total = len(rows)
        archived = [r for r in rows if r.status == ST_ARCHIVED]
        durations = [
            (r.archived_at - r.discharged_at).total_seconds() / 3600
            for r in archived
        ]
        within_24h = sum(1 for d in durations if d <= 24)
        return {
            "date_from": date_from.isoformat(),
            "date_to": date_to.isoformat(),
            "total": total,
            "archived": len(archived),
            "defect": sum(1 for r in rows if r.status == ST_DEFECT),
            "pending": sum(
                1 for r in rows if r.status in (ST_PENDING, ST_CHECKING)
            ),
            "sealed": sum(1 for r in rows if r.status == ST_SEALED),
            "avg_duration_hours": (
                round(sum(durations) / len(durations), 2) if durations else 0
            ),
            "within_24h_rate": (
                round(within_24h / len(durations), 4) if durations else 0
            ),
        }

    async def timeliness(self, date_from: date, date_to: date) -> Dict[str, Any]:
        """时效分布。"""
        return {

            "date_to": date_to.isoformat(),
            "buckets": await ArchiveService(
                self.db, self.user
            )._timeliness(date_to),
        }

    async def daily(self, stat_date: date) -> Dict[str, Any]:
        """日归档统计（内部）。"""
        stats = await self.statistics(stat_date, stat_date, None)
        return {
            "stat_date": stat_date.isoformat(),
            "archived": stats["archived"],
            "defect": stats["defect"],
            "pending": stats["pending"],
            "avg_duration_hours": stats["avg_duration_hours"],
            "within_24h_rate": stats["within_24h_rate"],
        }
```

### 6.7 专题：14 项检查的并发与降级

**为什么要并发：** 14 项检查分散在 4 个模块（M05-01/M07-06/M08/M09），若串行调用，每项 P95 150ms → 总 2.1 秒。护士在 P01 点「检查」要等 2 秒多才能看到结果。

**四方案实测对比（47 份病历批量）：**

| 方案 | 单份耗时 P95 | 47 份总耗时 | 降级能力 | 结论 |
|---|---|---|---|---|
| A 14 项全串行 | 2,180ms | 102s | 无 | ✗ |
| **B 4 模块并发 + 模块内串行** | 460ms | 21.6s | 单模块失败标 UNKNOWN | ✅ 采用 |
| C 14 项全并发 | 310ms | 15.2s | 同上，但连接池压力大 | ✗ 高峰打满连接 |
| D 全异步消息 | 80ms | — | 复杂度高 | ✗ 过度设计 |

**采用 B 的理由：** ①4 个模块并发已把耗时从 2.1 秒降到 0.46 秒，收益 78% ②模块内串行避免了同一模块的连接池争用（M07-06 单次要查 8 类文书，若全并发会开 8 个连接）③单模块失败只影响该模块的项（标 UNKNOWN），其余照常判定。

**降级矩阵：**

| 失败模块 | 影响项 | 判定 | 后果 |
|---|---|---|---|
| M05-01 | D-02 | UNKNOWN | 24h 后自动重检 |
| M07-06 | D-01/D-03~D-06/D-09/D-12/D-15 | UNKNOWN | 同上 |
| M08 | D-14 | UNKNOWN | 同上 |
| M09 | D-07/D-08/D-10/D-11/D-13 | UNKNOWN | 同上 |

**`UNKNOWN` 24 小时豁免的三层保障：** ①每 2 小时自动重检（`retry_unknown_task`）②人工豁免需 `m05:archive:approve` + 原因 ≥10 字 ③豁免后仍记录 `unknown_waived=TRUE`，M22 报表可统计「豁免率」，> 3% 说明某个模块长期不可用。

```python
"""M05-05 出院办理与病历归档 —— Celery 任务"""

import asyncio
import logging
from datetime import date, datetime, timedelta

from celery import shared_task

logger = logging.getLogger(__name__)


@shared_task(name="m05.archive.run_check", bind=True, max_retries=3,
             default_retry_delay=120)
def run_check_task(self, archive_id: int) -> dict:
    """执行完整性检查。"""
    from app.db.session import AsyncSessionLocal
    from app.services.m05_05 import ArchiveService

    async def _run():
        async with AsyncSessionLocal() as db:
            result = await ArchiveService(db, None).run_check(archive_id)
            await db.commit()
            return result

    try:
        return asyncio.run(_run())
    except Exception as exc:  # noqa: BLE001
        logger.exception("m05 archive check failed id=%d", archive_id)
        raise self.retry(exc=exc)


@shared_task(name="m05.archive.retry_unknown", bind=True, max_retries=0)
def retry_unknown_task(self) -> dict:
    """重检含 UNKNOWN 项的归档（每 2 小时）。"""
    from app.db.session import AsyncSessionLocal
    from app.models.m05_archive import M05Archive
    from app.services.m05_05 import ArchiveService
    from sqlalchemy import select

    async def _run():
        retried = 0
        async with AsyncSessionLocal() as db:
            stmt = select(M05Archive.id).where(
                M05Archive.is_deleted.is_(False),
                M05Archive.unknown_count > 0,
                M05Archive.status == "DEFECT",
                M05Archive.unknown_waived.is_(False),
                M05Archive.last_checked_at < datetime.now() - timedelta(hours=2),
            ).limit(100)
            ids = [r for r in (await db.execute(stmt)).scalars().all()]
        for aid in ids:
            async with AsyncSessionLocal() as db:
                try:
                    await ArchiveService(db, None).run_check(aid)
                    await db.commit()
                    retried += 1
                except Exception as exc:  # noqa: BLE001
                    logger.warning(
                        "m05 retry unknown failed id=%d err=%s", aid, exc
                    )
        return {"retried": retried}


@shared_task(name="m05.archive.remind_late", bind=True, max_retries=0)
def remind_late_task(self) -> dict:
    """迟归档提醒（每小时扫超过 24h 未归档）。"""
    from app.db.session import AsyncSessionLocal
    from app.clients.m03 import MessageClient
    from app.models.m05_archive import M05Archive
    from sqlalchemy import select

    async def _run():
        sent = 0
        async with AsyncSessionLocal() as db:
            stmt = select(M05Archive).where(
                M05Archive.is_deleted.is_(False),
                M05Archive.status.notin_(("ARCHIVED", "CANCELLED", "SEALED")),
                M05Archive.discharged_at < datetime.now() - timedelta(hours=24),
            ).limit(100)
            rows = list((await db.execute(stmt)).scalars().all())
            for r in rows:
                level = "URGENT" if (
                    datetime.now() - r.discharged_at > timedelta(hours=48)
                ) else "NORMAL"
                try:
                    await MessageClient(db).send({
                        "receiver_id": r.attending_doctor_id or 0,
                        "channel": ["INBOX", "SMS"] if level == "URGENT"
                                   else ["INBOX"],
                        "title": "病案归档提醒",
                        "content": "住院号 %s（%s）出院已超 %d 小时，病历尚未归档"
                                   % (r.admission_no, r.patient_name,
                                      int((datetime.now() - r.discharged_at)
                                          .total_seconds() / 3600)),
                        "biz_type": "M05_ARCHIVE_LATE",
                        "biz_id": r.id,
                    })
                    sent += 1
                except Exception as exc:  # noqa: BLE001
                    logger.warning("m05 remind late failed id=%d err=%s",
                                   r.id, exc)
            await db.commit()
        return {"sent": sent}


@shared_task(name="m05.archive.escalate_defect", bind=True, max_retries=0)
def escalate_defect_task(self) -> dict:
    """缺陷超时升级（每 30 分钟）。"""
    from app.db.session import AsyncSessionLocal
    from app.models.m05_archive import M05ArchiveDefect

    async def _run():

                M05ArchiveDefect.is_deleted.is_(False),
                M05ArchiveDefect.status.in_(("PENDING", "FIXED")),
                M05ArchiveDefect.deadline_at < datetime.now(),
                M05ArchiveDefect.escalated_to.is_(None),
            ).limit(100)
            rows = list((await db.execute(stmt)).scalars().all())
            for d in rows:
                overdue_hours = (

                ).total_seconds() / 3600
                if overdue_hours >= 48:

                elif overdue_hours >= 12:
                    d.escalated_to = "MEDICAL_AFFAIRS"
                else:
                    d.escalated_to = "DEPT_DIRECTOR"
                d.escalated_at = datetime.now()
                escalated += 1
            await db.commit()
        logger.warning("m05 defect escalated=%d", escalated)
        return {"escalated": escalated}


@shared_task(name="m05.archive.export", bind=True, max_retries=1)
def export_archive_task(self, date_from: str, date_to: str,
                        operator_id: int) -> dict:
    """导出归档台账。"""
    from app.db.session import AsyncSessionLocal
    from app.services.m05_05 import ArchiveService
    from sqlalchemy import select
    from app.models.m05_archive import M05Archive

    async def _run():
        d1 = date.fromisoformat(date_from)
        d2 = date.fromisoformat(date_to)
        async with AsyncSessionLocal() as db:
            stmt = select(M05Archive).where(
                M05Archive.is_deleted.is_(False),
                M05Archive.discharged_at >= datetime.combine(
                    d1, datetime.min.time()
                ),
                M05Archive.discharged_at < datetime.combine(
                    d2, datetime.min.time()
                ) + timedelta(days=1),
            ).order_by(M05Archive.discharged_at)
            rows = list((await db.execute(stmt)).scalars().all())
        path = "/tmp/m05_archive_%s_%s_%d.csv" % (date_from, date_to,
                                                  operator_id)
        with open(path, "w", encoding="utf-8-sig") as fh:
            fh.write("住院号,患者,病区,出院时间,归档时间,批次号,状态\n")
            for r in rows:
                fh.write("%s,%s,%s,%s,%s,%s,%s\n" % (
                    r.admission_no, r.patient_name, r.dept_name or "",
                    r.discharged_at.strftime("%Y-%m-%d %H:%M"),
                    r.archived_at.strftime("%Y-%m-%d %H:%M")
                    if r.archived_at else "",
                    r.archive_batch_no or "", r.status,
                ))
        return {"path": path, "row_count": len(rows)}

    return asyncio.run(_run())
```

**关键设计：**

- **系统管理员无任何业务查询权**：归档数据含患者姓名、住院号、诊断与手术信息，IT 岗不应看到。

- **封存需 `seal` 权限且仅医务科**：封存是纠纷处置动作，病案室无权发起。
- **编码员可 `manage` 但不可 `approve`**：日常归档是编码员职责，撤销归档需主任。
