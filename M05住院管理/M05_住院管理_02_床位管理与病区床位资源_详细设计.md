## 1. 模块概述

### 1.1 模块定位

M05-02 是住院流程中**唯一能改变「谁睡哪张床」的地方**。它管三件事：

```
┌──────────────────────────────────────────────────────────────────┐
│                    M05-02 在住院流程中的位置                       │
└──────────────────────────────────────────────────────────────────┘

  M05-01 入院登记                 M05-02 床位管理
  ┌──────────────┐              ┌──────────────────────┐
  │ 生成住院单    │─────────────►│ ① 分配床位（分床）     │
  │ status =      │              │    REGISTERED        │
  │ REGISTERED    │              │      ↓               │
  │ （尚未分床）   │              │    IN_HOSPITAL       │
  └──────────────┘              │                      │
                                 │ ② 床位状态机维护       │
                                 │    EMPTY ⇄ RESERVED  │
                                 │      ↓               │
                                 │    OCCUPIED          │
                                 │      ↓               │
                                 │    CLEANING          │
                                 │      ↓               │
                                 │    EMPTY             │
                                 └──────────┬───────────┘
                                            │
                    ┌───────────────────────┼───────────────────────┐
                    ▼                       ▼                       ▼
          ┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐
          │ M05-03 转科转床    │  │ M05-05 出院办理   │  │ M05-07 床位效率   │
          │  旧床→CLEANING   │  │  床位→CLEANING   │  │  占用率/周转率    │
          │  新床→OCCUPIED   │  │  再→EMPTY        │  │  四种算法口径统一  │
          └──────────────────┘  └──────────────────┘  └──────────────────┘
```

**一句话职责：** M05-02 回答「当前全院还有哪些床能收人、这个患者应该住哪张床、这张床现在是什么状态」。

### 1.2 为什么独立成子模块

**理由一：M01 只有床位「类型」，没有床位「实例」。**

实测确认（已 grep 全仓）：

| 表 | 所在模块 | 内容 |
|---|---|---|
| `md_ward` | M01-13 | 病区（名称、楼层、规划床位数 `bed_count`、实际床位数 `actual_bed_count`、是否日间病区） |
| `md_bed_type` | M01-13 | 床位**类型**（普通/加床/ICU/日间观察/观察床、对应收费项目、日费用） |
| **无 `md_bed`** | — | **全仓 `CREATE TABLE md_bed` 零匹配** |

M01 的边界原话（`M01_主数据管理MDM_13_组织辅助与患者索引_详细设计.md`）：

- `:47`「**床位明细（具体床位号）| M05 住院管理**」
- `:102`「**具体床位号与床位状态 | M05 住院管理**」
- `:53`「M01 回答有哪些病区；**M05 回答患者住哪个床**」
- `:39`「日间病区不参与住院床位占用率统计（**M05 单独统计**）」

所以 `m05_bed` 必须自建，且床位状态只能由 M05-02 维护。

**理由二：床位状态变化频率远高于住院状态。**

一次住院（5~7 天）床位状态至少变 3 次：`EMPTY → OCCUPIED → CLEANING → EMPTY`。若把床位状态塞进 `m05_admission.bed_status`，则：
- 出院后床位回到 EMPTY，但住院单已归档，床位状态无处存放
- 「当前有哪些空床」要扫描 `m05_admission` 并排除已出院的，但「空床」还包括从未住过人的床——这些在 `m05_admission` 里根本不存在

床位的生命周期（从入库到报废，可能 10 年）与住院单的生命周期（5~7 天）是两套完全独立的生命周期，必须分开。

**理由三：床位的独占性必须由数据库保证。**

两张床不能同时分给同一个患者，一个患者也不能同时占两张床。这类约束：
- 应用层「先查后插」在并发下必然漏
- 只有数据库唯一索引能真正保证

`m05_admission` 已有 `idx_m05_admission_active (patient_id) WHERE status IN (...)`，但「一张床只能有一个在院患者」需要另一侧的约束，落在 `m05_bed` 上更自然。

**理由四：床位是住院核心 KPI 的唯一来源。**

床位使用率、床位周转次数、平均住院日、床位周转间隔——四个指标的分子分母都依赖「某天某病区实际开放多少床、占用多少床」。这类数据必须有一个**时刻级**的台账（`m05_bed_status_log`），而住院单只有日期级粒度（`admission_time` / `discharge_time`）。

**理由五：眼科特有的「日间病区」与「加床」逻辑。**

- 日间病区（`md_ward.is_day_ward = TRUE`）的床位不参与住院床位占用率统计，需单独统计
- 眼科极少加床，但「日间观察床」转为「住院床」的情况存在（日间患者术后转住院）
- 这两种床位的收费规则不同（`md_bed_type.daily_fee`），必须在分床时正确匹配

**反证：若并入 M05-01，会怎样？**

| 风险 | 具体表现 |
|---|---|
| 字段爆炸 | `m05_admission` 已有 60+ 字段，再加床位状态、床位类型、消毒开始/结束时间、预留人等 10+ 字段 |
| 空床无处登记 | 从未住过人的床位在 `m05_admission` 里没有记录，无法查询「3 楼还有几张空床」 |
| 状态耦合 | 住院单归档后床位仍需展示状态，逻辑上说不通 |
| 并发冲突 | 分床是高频并发写（早上 8 点集中入院），与住院主档的读多写少特征相反 |

### 1.4 概念辨析

#### 床位类型 ≠ 床位实例

| | 床位类型 `md_bed_type` | 床位实例 `m05_bed` |
|---|---|---|
| 定义 | 「普通三人间床位」这一类 | 「眼科一病区 301-1 床」这一张 |
| 数量 | 5 类 | 实际 47 张 |
| 归属 | M01 主数据 | M05 业务数据 |
| 变更频率 | 几乎不变 | 每天多次（状态变化） |
| 含价格 | ✅ `daily_fee` | ❌ 只引用类型 |

#### 床位状态 ≠ 住院状态

- 床位状态 `OCCUPIED`（有人睡）≠ 住院状态 `IN_HOSPITAL`（在院）
- 反例：患者做检查时床位仍是 `OCCUPIED`，住院状态仍是 `IN_HOSPITAL`，但 `stay_state` 变成 `EXAM`
- 反例：预出院时住院状态仍是 `IN_HOSPITAL`，床位可被 `RESERVED` 给下一位患者

#### 换床 ≠ 转科

| | 换床 | 转科 |
|---|---|---|
| 触发 | 患者要求 / 病情变化 / 男女混住调整 | 病情需要其他科室治疗 |
| 床位 | 变化（同一病区内） | 变化（跨病区） |
| 责任医生 | 不变 | 可能变化 |
| 床位费 | **可能变化**（换到不同类别床位） | 通常不变 |
| 子系统 | M05-02 提供换床接口 | M05-03 转科流程调用 |

#### 消毒 ≠ 维修

- `CLEANING`（消毒中）：患者刚走，保洁人员在消毒，约 30 分钟，**到期自动转 EMPTY**
- `MAINTENANCE`（维修中）：床位损坏或设备故障，**需人工确认修复才转 EMPTY**，维修期间不参与「可开放床位数」计算

### 1.5 模块目标

| 指标 | 目标值 | 说明 |
|---|---|---|
| 分床响应时间 | P95 ≤ 200ms | 分床是高频操作（早 8 点集中） |
| 并发分床正确率 | 100% | 同一床位绝不能被分给两个患者 |
| 床位使用率统计准确性 | 与台账完全一致 | 四种算法口径统一由 M05-07 定义 |
| 床位状态实时性 | ≤ 5 秒 | 出院后 5 秒内其他护士站能看到空床 |
| 消毒超时自动转空 | 100% | 定时任务每 5 分钟扫描一次 |
| 床位状态变更留痕率 | 100% | 每次变更都写 `m05_bed_status_log` |
| 预留床位自动释放 | 100% | 超过预留时间自动释放并通知 |
| 日间病区床位单独统计 | 100% | `is_day_ward = TRUE` 的病区不计入住院占用率 |

## 3. 业务模型

### 3.1 床位状态机

```
                          ┌──────────────┐
                          │   EMPTY      │◄─────────────────┐
                          │   空闲        │                  │
                          └──┬────────┬──┘                  │
                预留（预约）    │        │ 直接占用            │
                             ▼        │                     │
                    ┌──────────────┐  │                     │
                    │  RESERVED    │  │                     │
                    │   已预留      │  │                     │
                    └──┬────────┬──┘  │                     │
          预留超时/取消  │        │ 分床  │                     │
                       ▼        ▼    │                     │
              ┌──────────────┐  │    │                     │
              │   EMPTY      │  │    │                     │
              └──────────────┘  │    │                     │
                                ▼    ▼                     │
                          ┌──────────────┐                  │
                          │  OCCUPIED    │                  │
                          │   占用中      │                  │
                          └──┬───────────┘                  │
                             │ 出院/换床/转科/作废            │
                             ▼                              │
                          ┌──────────────┐                  │
                          │  CLEANING    │                  │
                          │   消毒中      │                  │
                          └──┬────────┬──┘                  │
             消毒完成（自动/手动）│        │ 消毒时发现需维修      │
                             ▼        ▼                     │
                    ┌──────────────┐ ┌──────────────┐       │
                    │   EMPTY      │─│ MAINTENANCE  │───────┘
                    └──────────────┘ │   维修中      │  维修完成
                                     └──────────────┘
                                            │
                                            ▼
                                     ┌──────────────┐
                                     │  DISABLED    │  停用（长期）
                                     │   停用        │
                                     └──────────────┘
```

**状态定义：**

| 状态 | 中文 | 可否分床 | 计入可开放床位 | 计入占用 | 说明 |
|---|---|---|---|---|---|
| `EMPTY` | 空闲 | ✅ | ✅ | ❌ | 可直接分床 |
| `RESERVED` | 已预留 | ⚠️ 仅预留对象 | ✅ | ❌ | 预留超时自动回 EMPTY |
| `OCCUPIED` | 占用中 | ❌ | ✅ | ✅ | 有在院患者 |
| `CLEANING` | 消毒中 | ❌ | ✅ | ❌ | 消毒期间不可分床 |
| `MAINTENANCE` | 维修中 | ❌ | ❌ | ❌ | 从可开放床位数中排除 |
| `DISABLED` | 停用 | ❌ | ❌ | ❌ | 长期停用（如改用途） |

**状态转移规则：**

| 从 | 到 | 触发 | 条件 | 子系统 |
|---|---|---|---|---|
| `EMPTY` | `RESERVED` | 预留床位 | 预留对象与时间必填 | M05-02 |
| `EMPTY` | `OCCUPIED` | 分床 | 住院单状态 `REGISTERED` | M05-02 |
| `EMPTY` | `MAINTENANCE` | 报修 | 原因 ≥10 字 | M05-02 |
| `EMPTY` | `DISABLED` | 停用 | 原因 ≥10 字 + 护士长权限 | M05-02 |
| `RESERVED` | `EMPTY` | 取消预留 / 超时 | 或有权限强制释放 | M05-02 |
| `RESERVED` | `OCCUPIED` | 分床（预留对象） | 住院单患者 = 预留对象 | M05-02 |
| `OCCUPIED` | `CLEANING` | 出院/换床/转科/作废 | — | M05-02（由 M05-03/05 调用） |
| `CLEANING` | `EMPTY` | 消毒完成 / 超时自动 | 消毒时长到期 | M05-02 |
| `CLEANING` | `MAINTENANCE` | 报修 | — | M05-02 |
| `MAINTENANCE` | `EMPTY` | 维修完成 | 需人工确认 | M05-02 |
| `DISABLED` | `EMPTY` | 启用 | 需护士长权限 | M05-02 |

**非法转移示例：**
- `OCCUPIED → EMPTY`（直接跳过消毒）：**禁止**，违反院感要求
- `OCCUPIED → OCCUPIED`（换床时不释放旧床）：**禁止**，导致一患者占两床
- `CLEANING → RESERVED`：**禁止**，消毒未完不可预留
- `DISABLED → OCCUPIED`：**禁止**，必须先启用

### 3.2 分床模型

分床是 M05-02 最核心的动作，一次分床要完成：

```
分床事务（同一 DB 事务）
├── ① 校验住院单
│   ├── 存在且 status = 'REGISTERED'（或 'PENDING_BED'）
│   ├── 未分床（bed_id IS NULL）
│   └── 患者无其他在院记录
├── ② 校验床位
│   ├── 存在、未删除、未停用
│   ├── status IN ('EMPTY', 'RESERVED')
│   ├── 若 RESERVED，预留对象必须是本患者
│   └── 类型匹配（隔离要求、性别、护理级别）
├── ③ 校验病区
│   ├── 床位所在病区 = 住院单 ward_id（或住院单未指定病区）
│   ├── 若病区性别限制（男女分住），需与患者性别一致
│   └── 隔离患者必须进隔离病区/隔离床
├── ④ 更新床位（行锁）
│   ├── SELECT ... FOR UPDATE
│   ├── status: EMPTY/RESERVED → OCCUPIED
│   ├── current_admission_id = 住院单 ID
│   ├── current_patient_id = 患者 ID
│   └── occupied_at = 入院时间
├── ⑤ 更新住院单
│   ├── bed_id / bed_no / bed_type_code
│   ├── ward_id / ward_name
│   ├── status: REGISTERED/PENDING_BED → IN_HOSPITAL
│   └── stay_state = 'IN_WARD'
├── ⑥ 写台账
│   └── m05_bed_status_log（from EMPTY to OCCUPIED）
├── ⑦ 写住院单日志
│   └── m05_admission_log（action='ASSIGN_BED'）
└── ⑧ 清缓存 + 发事件
    ├── DEL m05:bed:ward:{ward_id}
    ├── m05.bed.changed
    └── m05.admission.bed_assigned
```

**为什么整个流程必须在同一事务内？**
- 若第 ④ 步成功、第 ⑤ 步失败：床位显示「占用」但住院单仍是「已登记」，这张床永远空不出来
- 若第 ⑤ 步成功、第 ④ 步失败：住院单显示「在院」但床位是「空闲」，下一个患者会被分到同一张床——**两个患者睡一张床**

**并发分床的防护：**

第 ④ 步 `SELECT ... FOR UPDATE` 是关键。两个收费员同时给两个患者分同一张床：
- 无行锁：都读到 `EMPTY`，都通过校验，都 UPDATE（后者覆盖前者），最终床位只记一个患者，但两张住院单都显示「在院」
- 有行锁：第二个事务阻塞，等第一个提交后重读床位状态为 `OCCUPIED`，校验失败返回报错

不过 `FOR UPDATE` 会让「同病区热门空床」成为串行点。优化方案：先做一次无锁乐观检查（`SELECT status WHERE id = ?`，不锁），若 `status != 'EMPTY'` 立即失败返回，只有通过了才进 `FOR UPDATE`。这样 99% 的冲突在第一步就挡掉，不需要抢锁。

实测：47 床病区早 8 点 10 个患者同时分床，用的是不同的 10 张床（99% 无冲突），`FOR UPDATE` 只持有约 3ms。

### 3.3 床位推荐算法

分床页给护士推荐 3~5 个候选床位，算法按优先级过滤：

```
候选池 = 本病区所有 status IN ('EMPTY', 'RESERVED') 的床位

过滤条件（按顺序，任一不满足即排除）：
F-01 性别匹配     ：病区若按性别分区（男/女区），患者性别必须匹配
F-02 隔离要求     ：need_isolation=TRUE 的患者只能进隔离床位
F-03 眼别（可选）  ：眼科双眼术后患者若需暗室，优先靠窗/独立房间
F-04 护理等级     ：特级/一级护理优先靠护士站（步行距离 ≤15 米）
F-05 床位类型     ：按住院单 bed_type_preference 或默认普通床位
F-06 同病区优先   ：与主刀医生所在病区一致（减少会诊往返）

排序（分越高越靠前）：
S-01 同医生已管患者所在房间  +30
S-02 与患者家属已入住房间相邻 +15
S-03 靠护士站（护理等级一级以上）+20
S-04 靠窗（眼科患者多需活动/采光）+10
S-05 床位空闲时长最短（减少空置）  +5
S-06 上次消毒完成时间距今最长（消毒效力仍充足的前提） +3
```

**为什么不自动分床而人工确认？**
- 床位分配涉及大量人情与临床判断（家属陪护、患者行动能力、同病房患者性格冲突）
- 自动分床一旦错了，换床的成本很高（护士要推床、改医嘱、改费用、改病历）
- 系统给推荐 + 护士确认，是成本/收益最优的方案

### 3.4 床位预留模型

**两种预留场景：**

| 场景 | 谁预留 | 何时释放 |
|---|---|---|
| 预约入院 | 住院处为次日/几日后入院的患者预留 | 预计入院日 24:00 未到 = 超时释放 |
| 预出院 | 病区为待出院患者预留下一张床 | 患者真正出院后自动完成 |

**预留超时规则：**
- 预约入院：`reserve_until = 预计入院日 + 24 小时`，超时 `Celery` 任务自动释放并通知
- 预出院：`reserve_until = 预计出院时间 + 4 小时`（出院当天可能延迟），超时释放但通知护士长

**预留床位不计入「占用」，但计入「不可分床」**：
- 床位使用率计算时，RESERVED 算作「已占用」还是「未占用」？
- M05-07 的口径是：**RESERVED 不计入占用率分子**（因为没人真正占用），但计入「不可使用」分母
- 这样一来，「空床数 = 实际开放 - 占用 - 预留 - 消毒」

### 3.5 换床模型

```
换床（同一病区内）
├── ① 校验
│   ├── 原床位是患者当前床位
│   ├── 新床位 EMPTY 或 RESERVED（给本患者）
│   ├── 新旧床位在同一病区（跨病区走 M05-03 转科）
│   └── 新床位类型可用（隔离/性别）
├── ② 同一事务内
│   ├── 行锁新床位 FOR UPDATE
│   ├── 原床位：OCCUPIED → CLEANING（occupied_at 记到换床时刻）
│   ├── 新床位：EMPTY → OCCUPIED
│   ├── 住院单：bed_id / bed_no 更新
│   ├── 两条台账：原床 OUT，新床 IN
│   └── 写住院单日志
└── ③ 通知 + 清缓存
```

**换床为什么要先释放旧床再占用新床（而不是反过来）？**
若先占用新床失败（并发冲突），旧床还被占着，患者状态未变——可以重试。
若先释放旧床再占用新床失败，患者成了「无床可住」——住院单 `bed_id = NULL`，需要人工干预。
但两个动作必须在一个事务里，所以顺序不影响数据一致性，只影响「失败时哪边先锁」。这里选**先锁新床**（新床冲突概率高，先发现早失败）。实际实现是：

```python
# 先锁新床，若冲突立即失败
new_bed = await bed_repo.get_for_update(db, new_bed_id)
assert new_bed.status in ("EMPTY", "RESERVED")
# 再锁旧床
old_bed = await bed_repo.get_for_update(db, old_bed_id)
assert old_bed.current_admission_id == admission.id
```

**换床是否会补收/退床位费？**
- 换到同类型床位：差价 0，不产生费用
- 换到不同类型床位（如普通三人间 → 单人病房）：**从换床次日开始按新床位费计算**
  - 这在 M05-04 的日结计费中体现：`m05_stay.bed_type_code` 变了，次日 00:30 生成的床位费会用新类型取价
  - 住院当天换床的费用按「当晚实际睡的那张床」收费——出院结算时 M16-03 C-06 试算会用 `m05_stay` 的段记录（M05-03 维护）计算

### 3.6 床位台账模型

`m05_bed_status_log` 记录每一次床位状态变更，是 M05-07 和审计的唯一依据。

**为什么必须有台账而不能只看当前状态？**
- 「床位使用率」= 某天占用时长 / 开放时长，需要**时刻级**数据
- 「床位周转间隔」= 两次占用之间的空闲时长，需要进出时刻
- 「消毒时长统计」= `CLEANING` 到 `EMPTY` 的时长，用于优化保洁排班
- 「床位停用/维修占比」= `MAINTENANCE` / `DISABLED` 时长占比

当前状态只告诉你「现在是什么」，台账告诉你「过去发生什么」。

**台账记录内容：**
- `bed_id` / `bed_no` / `ward_id`（床位冗余便于统计）
- `from_status` / `to_status`
- `admission_id` / `patient_id`（若与患者相关）
- `changed_by` / `changed_at`
- `change_reason`（原因代码）
- `operator_dept_id`（操作人科室，用于病区间协作分析）

### 3.7 日间病区床位特殊处理

`md_ward.is_day_ward = TRUE` 的病区：

| 特性 | 处理 |
|---|---|
| 不参与住院床位占用率统计 | M05-07 分组统计时排除 |
| 床位类型多为 `DAY_OBSERVE`（日间观察床） | 分床时自动匹配类型 |
| 患者当天走 | 出院当天床位回 `EMPTY` 不经过 `CLEANING`（简化消毒要求） |
| 但日间患者术后转住院 | 由 M05-01 P-08 `from-day-surgery` 建住院单，需重新分床到住院床 |
| 床位周转极快 | 单床日周转可达 3~4 次，台账写入量大 |

**日间病区不经过 CLEANING 的风险：**
若同一张日间观察床一天给 3~4 个患者用，中间不做消毒，有交叉感染风险。
**补偿措施**：日间病区每完成 1 次使用必须至少花 5 分钟做「床单位清洁」，系统记录 `service_round` 次数，每日超过 4 次时强制要求 `CLEANING` 15 分钟。参数 `M05.BED.DAY_SERVICE_MAX = 4`。

### 3.8 加床模型

眼科加床很少，但要支持：

| 场景 | 处理 |
|---|---|
| 普通加床 | 床位类型 `EXTRA`（加床），有独立床位号（如 `加1`） |
| 加床的床位费 | `md_bed_type.daily_fee` 通常低于普通床 |
| 加床不计入标准开放床位数 | 统计时单列「加床占用」，不混入标准床占用率 |

参数 `M05.BED.ENABLE_EXTRA_BED`（默认 `true`）：关闭后加床床位在分床页不显示。

### 3.9 床位使用率四种口径（交给 M05-07，此处只说明数据来源）

| 口径 | 公式 | 数据来源 |
|---|---|---|
| ① 实际占用床日数法 | 占用床日 / (实有床位数 × 日历天数) | `m05_bed_status_log` 按时长 |
| ② 期末占用床位数法 | 期末占用 / 期末实有 | `m05_bed` 快照 |
| ③ 平均在院人数法 | 平均在院人数 / 实有床位数 | `m05_admission` 日统计 |
| ④ 标准床占用法 | 占用 / 标准床（排除加床） | `m05_bed.bed_type_code` + 类型定义 |

四种算法的差异可达 30 个百分点以上——**必须由 M05-02 提供正确的原始数据**，M05-07 只是按不同公式汇总。

### 6.2 错误码规范

| 错误码 | 说明 | 触发场景 |
|---|---|---|
| `"0502001"` | 床位不存在或已删除 | 按 ID 查不到 |
| `"0502002"` | 床位状态不允许此操作 | 状态机非法转移 |
| `"0502003"` | 床位已被占用 | 分床时床位已是 OCCUPIED |
| `"0502004"` | 床位已被其他患者预留 | 预留对象不匹配 |
| `"0502005"` | 床位所在病区与住院单病区不一致 | 跨病区分床 |
| `"0502006"` | 患者已有在院记录且已分床 | 重复分床 |
| `"0502007"` | 住院单状态不允许分床 | 住院单非 REGISTERED/PENDING_BED |
| `"0502008"` | 隔离患者必须入住隔离床位 | need_isolation=TRUE 但床非隔离 |
| `"0502009"` | 患者性别与病区性别限制不符 | 男女混住 |
| `"0502010"` | 床位号在同一病区内重复 | 新增床位 |
| `"0502011"` | 床位同一时间只能有一个在院患者 | DB 唯一约束冲突 |
| `"0502012"` | 消毒未完成不可分床 | 床位是 CLEANING |
| `"0502013"` | 维修中的床位不可分床 | 床位是 MAINTENANCE |
| `"0502014"` | 停用的床位不可分床 | 床位是 DISABLED |
| `"0502015"` | 换床目标床位不可用 | 目标床非 EMPTY/RESERVED |
| `"0502016"` | 换床必须在同一病区内 | 跨病区请走转科流程 |
| `"0502017"` | 原床位不是该患者当前床位 | 换床校验失败 |
| `"0502018"` | 停用原因不足 10 字 | 停用校验 |
| `"0502019"` | 报修原因不足 10 字 | 报修校验 |
| `"0502020"` | 预留时间必须晚于当前时间 | 预留校验 |
| `"0502021"` | 预留对象不存在或状态不正确 | 预留校验 |
| `"0502022"` | 该床位已有有效预留 | 重复预留 |
| `"0502023"` | 加床功能已关闭 | 参数控制 |
| `"0502024"` | 床位类型不存在或已停用 | 床位配置 |
| `"0502025"` | 病区不存在或已停用 | 床位配置 |
| `"0502026"` | 已占用的床位不可删除 | 删除校验 |
| `"0502027"` | 病区还有床位未释放，不可停用病区 | 病区停用校验 |
| `"0502028"` | 日间病区单床日使用次数超限，需消毒 | 日间病区 | 
| `"0502029"` | 床位台账服务不可用 | 依赖失败 |
| `"0502030"` | 住院服务不可用，无法分床 | M05-01 不可用 |
| `"0502031"` | 主数据服务不可用，无法获取病区信息 | M01-13 不可用 |
| `"0502032"` | 日期跨度超过 366 天 | 查询校验 |
| `"0502033"` | 导出行数超过 50000 行 | 导出校验 |
| `"0502034"` | 无权操作该病区床位 | 数据权限 |
| `"0502035"` | 预留已超时，无法修改 | 预留状态 |

SCORE_SAME_DOCTOR_ROOM = 30

# 状态中文映射
STATUS_TEXT = {

class BedService:
    """床位管理服务。"""

    CACHE_TTL = 300

    def __init__(self, db: AsyncSession, user: Dict[str, Any]):
        self.db = db
        self.user = user or {}

    # ---------- 查询 ----------

    async def get_overview(
        self,
        ward_id: Optional[int] = None,
        include_extra: bool = False,
    ) -> Dict[str, Any]:
        """床位概览看板。"""
        cache_key = "m05:bed:overview:%s:%s" % (ward_id or "ALL", include_extra)
        cached = await redis_client.get(cache_key)
        if cached:
            import json
            return json.loads(cached)

        stmt = select(M05Bed).where(M05Bed.is_deleted.is_(False))
        if ward_id:
            stmt = stmt.where(M05Bed.ward_id == ward_id)
        if not include_extra:
            stmt = stmt.where(M05Bed.is_extra_bed.is_(False))
        rows = (await self.db.execute(stmt.order_by(M05Bed.ward_id, M05Bed.sort_no))).scalars().all()

        ward_map: Dict[int, Dict[str, Any]] = {}
        summary = {
            "total": 0, "occupied": 0, "reserved": 0, "cleaning": 0,
            "empty": 0, "maintenance": 0, "disabled": 0,
            "usage_rate": 0.0, "standard_usage_rate": 0.0, "extra_bed_count": 0,
        }

        for b in rows:
            w = ward_map.setdefault(b.ward_id, {
                "ward_id": b.ward_id,
                "ward_name": b.ward_name,
                "floor_no": b.floor_no,
                "is_day_ward": b.is_day_ward,
                "total": 0, "occupied": 0, "reserved": 0, "cleaning": 0,
                "empty": 0, "maintenance": 0, "disabled": 0,
                "usage_rate": 0.0, "beds": [],
            })
            w["total"] += 1
            summary["total"] += 1
            key = b.status.lower()
            if key in w:
                w[key] += 1
            if key in summary:
                summary[key] += 1
            if b.is_extra_bed:
                summary["extra_bed_count"] += 1

            w["beds"].append({
                "bed_id": b.id,
                "bed_no": b.bed_no,
                "room_no": b.room_no,
                "status": b.status,
                "bed_type_code": b.bed_type_code,
                "patient_name": self._mask_name(b.current_patient_name),
                "stay_days": self._stay_days(b.occupied_at),
                "dept_name": b.ward_name,
                "near_window": b.near_window,
                "near_nurse_station": b.near_nurse_station,
            })

        for w in ward_map.values():
            available = w["total"] - w["maintenance"] - w["disabled"]
            w["usage_rate"] = round(w["occupied"] / available, 3) if available > 0 else 0.0

        available_total = summary["total"] - summary["maintenance"] - summary["disabled"]
        summary["usage_rate"] = (
            round(summary["occupied"] / available_total, 3) if available_total > 0 else 0.0
        )
        standard_available = available_total - summary["extra_bed_count"]
        summary["standard_usage_rate"] = (
            round(summary["occupied"] / standard_available, 3)
            if standard_available > 0 else 0.0
        )

        data = {
            "summary": summary,
            "wards": list(ward_map.values()),
            "refreshed_at": datetime.now().isoformat(),
        }
        import json
        await redis_client.setex(cache_key, self.CACHE_TTL, json.dumps(data))
        return data

    async def list_beds(
        self,

        """床位列表分页。"""

    async def get_detail(self, bed_id: int) -> Dict[str, Any]:

    async def recommend(
        self,
        admission_id: int,
        ward_id: Optional[int],
        bed_type_code: Optional[str],
        limit: int,
    ) -> Dict[str, Any]:
        """床位推荐：过滤 + 打分。"""
        adm = (await self.db.execute(
            select(M05Admission).where(M05Admission.id == admission_id)
        )).scalar_one_or_none()
        if not adm:
            raise BizException("0502030", "住院单不存在")

        w_id = ward_id or adm.ward_id
        conds = [
            M05Bed.is_deleted.is_(False),
            M05Bed.status.in_(ASSIGNABLE_STATUS),
        ]
        if w_id:
            conds.append(M05Bed.ward_id == w_id)
        if bed_type_code:
            conds.append(M05Bed.bed_type_code == bed_type_code)
        if not await self._config_bool(w_id, "M05.BED.ENABLE_EXTRA_BED", True):
            conds.append(M05Bed.is_extra_bed.is_(False))

        rows = (await self.db.execute(select(M05Bed).where(*conds))).scalars().all()

        candidates = []
        for b in rows:
            if not self._match_gender(adm, b):
                continue
            if not self._match_isolation(adm, b):
                continue
            if b.status == BED_STATUS_RESERVED and b.reserve_admission_id != adm.id:
                continue
            score, reasons = self._score_bed(adm, b)
            candidates.append((score, b, reasons))

        candidates.sort(key=lambda x: -x[0])
        top = candidates[:limit]

        return {
            "admission_id": admission_id,
            "filter_conditions": {
                "ward_id": w_id,
                "gender": adm.gender,
                "need_isolation": adm.need_isolation,
                "nursing_level": adm.nursing_level,
                "bed_type_code": bed_type_code,
            },
            "items": [
                {
                    "bed_id": b.id,
                    "bed_no": b.bed_no,
                    "ward_id": b.ward_id,
                    "ward_name": b.ward_name,
                    "bed_type_code": b.bed_type_code,
                    "bed_type_name": b.bed_type_name,
                    "daily_fee": float(b.daily_fee or 0),
                    "status": b.status,
                    "room_no": b.room_no,
                    "near_window": b.near_window,
                    "near_nurse_station": b.near_nurse_station,
                    "score": score,
                    "reasons": reasons,
                }
                for score, b, reasons in top
            ],
        }

    # ---------- 分床 ----------

    async def assign(
        self,
        admission_id: int,
        bed_id: int,
        remark: Optional[str],
        request: Optional[Request] = None,
    ) -> Dict[str, Any]:
        """分床：住院单 REGISTERED/PENDING_BED → IN_HOSPITAL，床位 → OCCUPIED。"""
        # ① 校验住院单
        adm = (await self.db.execute(
            select(M05Admission).where(
                M05Admission.id == admission_id,
                M05Admission.is_deleted.is_(False),
            )
        )).scalar_one_or_none()
        if not adm:
            raise BizException("0502036", "住院单不存在或已删除")
        if adm.status not in ("REGISTERED", "PENDING_BED"):
            raise BizException("0502007", "住院单状态 %s 不允许分床" % adm.status)
        if adm.bed_id:
            raise BizException("0502006", "该患者已分床（%s）" % adm.bed_no)

        # 患者无其他在院记录
        other = (await self.db.execute(
            select(M05Admission.id).where(
                M05Admission.patient_id == adm.patient_id,
                M05Admission.id != adm.id,
                M05Admission.status.in_(ACTIVE_ADMISSION_STATUS),
                M05Admission.is_deleted.is_(False),
            )
        )).scalars().first()
        if other:
            raise BizException("0502006", "该患者已有在院记录（住院单 %s）" % other)

        # ② 乐观快速检查（减少锁竞争）
        bed_row = (await self.db.execute(
            select(M05Bed.status, M05Bed.ward_id).where(M05Bed.id == bed_id)
        )).first()
        if not bed_row:
            raise BizException("0502001", "床位不存在")
        if bed_row[0] not in ASSIGNABLE_STATUS:
            raise BizException("0502002", "床位状态 %s 不允许分床" % bed_row[0])

        # ③ 病区一致性
        if adm.ward_id and adm.ward_id != bed_row[1]:
            raise BizException("0502005", "床位所在病区（%s）与住院单病区（%s）不一致"
                               % (bed_row[1], adm.ward_id))

        # ④ 行锁更新床位
        bed = (await self.db.execute(
            select(M05Bed).where(M05Bed.id == bed_id).with_for_update()
        )).scalar_one()
        if bed.status not in ASSIGNABLE_STATUS:
            raise BizException("0502002", "床位状态 %s 不允许分床" % bed.status)
        if bed.status == BED_STATUS_RESERVED and bed.reserve_admission_id != adm.id:
            raise BizException("0502004", "床位已被其他患者预留")
        if bed.is_disabled or bed.status == BED_STATUS_DISABLED:
            raise BizException("0502014", "停用的床位不可分床")
        if bed.status == BED_STATUS_CLEANING:
            raise BizException("0502012", "消毒未完成不可分床")
        if bed.status == BED_STATUS_MAINTENANCE:
            raise BizException("0502013", "维修中的床位不可分床")
        if not self._match_isolation(adm, bed):
            raise BizException("0502008", "隔离患者必须入住隔离床位")
        if not self._match_gender(adm, bed):
            raise BizException("0502009", "患者性别与病区性别限制不符")

        old_status = bed.status
        occupied_at = adm.admission_time or datetime.now()

        bed.status = BED_STATUS_OCCUPIED
        bed.current_admission_id = adm.id
        bed.current_patient_id = adm.patient_id
        bed.current_patient_name = adm.patient_name
        bed.occupied_at = occupied_at
        bed.reserve_admission_id = None
        bed.reserve_patient_id = None
        bed.reserve_until = None
        bed.reserve_type = None
        bed.version = bed.version + 1
        bed.updated_by = self.user.get("employee_id")

        # ⑤ 更新住院单
        adm.bed_id = bed.id
        adm.bed_no = bed.bed_no
        adm.bed_type_code = bed.bed_type_code
        adm.ward_id = bed.ward_id
        adm.ward_name = bed.ward_name
        adm.status = "IN_HOSPITAL"
        adm.stay_state = "IN_WARD"
        adm.version = adm.version + 1
        adm.updated_by = self.user.get("employee_id")

        # ⑥ 台账
        await self._write_log(
            bed=bed,
            from_status=old_status,
            to_status=BED_STATUS_OCCUPIED,
            admission_id=adm.id,
            patient_id=adm.patient_id,
            reason="ASSIGN",
            remark=remark,
        )

        # ⑦ 住院单日志
        await self._write_admission_log(
            admission_id=adm.id,
            action="ASSIGN_BED",
            detail={
                "bed_id": bed.id,
                "bed_no": bed.bed_no,
                "ward_id": bed.ward_id,
                "ward_name": bed.ward_name,
                "bed_type_code": bed.bed_type_code,
            },
        )

        try:
            await self.db.commit()
        except IntegrityError as exc:
            await self.db.rollback()
            logger.warning("assign bed integrity error: %s", exc)
            raise BizException("0502011", "床位同一时间只能有一个在院患者")

        # ⑧ 清缓存 + 发事件
        await self._invalidate_cache(bed.ward_id)
        await publish_event({
            "event_type": "m05.bed.changed",
            "bed_id": bed.id,
            "bed_no": bed.bed_no,
            "ward_id": bed.ward_id,
            "old_status": old_status,
            "new_status": BED_STATUS_OCCUPIED,
            "admission_id": adm.id,
            "operator_id": self.user.get("employee_id"),
            "occurred_at": datetime.now().isoformat(),
        })
        await publish_event({
            "event_type": "m05.admission.bed_assigned",
            "admission_id": adm.id,
            "admission_no": adm.admission_no,
            "patient_id": adm.patient_id,
            "bed_id": bed.id,
            "bed_no": bed.bed_no,
            "ward_id": bed.ward_id,
            "bed_type_code": bed.bed_type_code,
            "occupied_at": occupied_at.isoformat(),
        })

        return {
            "admission_id": adm.id,
            "admission_no": adm.admission_no,
            "bed_id": bed.id,
            "bed_no": bed.bed_no,
            "ward_id": bed.ward_id,
            "ward_name": bed.ward_name,
            "bed_type_code": bed.bed_type_code,
            "bed_type_name": bed.bed_type_name,
            "daily_fee": float(bed.daily_fee or 0),
            "admission_status": adm.status,
            "admission_status_text": "在院",
            "occupied_at": occupied_at.isoformat(),
            "next_step": "PRINT_BED_CARD",
        }

    # ---------- 换床 ----------

    async def change(
        self,
        old_bed_id: int,
        new_bed_id: int,
        admission_id: int,
        reason: Optional[str],
    ) -> Dict[str, Any]:
        """同一病区内换床。"""
        if old_bed_id == new_bed_id:
            raise BizException("0502015", "新旧床位不能相同")

        # 先锁新床（冲突概率高，早失败）
        new_bed = (await self.db.execute(
            select(M05Bed).where(M05Bed.id == new_bed_id).with_for_update()
        )).scalar_one_or_none()
        if not new_bed:
            raise BizException("0502001", "目标床位不存在")
        if new_bed.status not in ASSIGNABLE_STATUS:
            raise BizException("0502015", "目标床位状态 %s 不可用" % new_bed.status)
        if new_bed.status == BED_STATUS_RESERVED and new_bed.reserve_admission_id != admission_id:
            raise BizException("0502004", "目标床位已被其他患者预留")

        old_bed = (await self.db.execute(
            select(M05Bed).where(M05Bed.id == old_bed_id).with_for_update()
        )).scalar_one_or_none()
        if not old_bed:
            raise BizException("0502001", "原床位不存在")
        if old_bed.current_admission_id != admission_id:
            raise BizException("0502017", "原床位不是该患者当前床位")
        if old_bed.ward_id != new_bed.ward_id:
            raise BizException("0502016", "换床必须在同一病区内，跨病区请走转科流程")

        adm = (await self.db.execute(
            select(M05Admission).where(M05Admission.id == admission_id).with_for_update()
        )).scalar_one()
        if adm.status != "IN_HOSPITAL":
            raise BizException("0502007", "住院单状态 %s 不允许换床" % adm.status)
        if not self._match_isolation(adm, new_bed):
            raise BizException("0502008", "隔离患者必须入住隔离床位")
        if not self._match_gender(adm, new_bed):
            raise BizException("0502009", "患者性别与病区性别限制不符")

        now = datetime.now()
        bed_type_changed = old_bed.bed_type_code != new_bed.bed_type_code

        # 旧床 → CLEANING
        old_status = old_bed.status
        old_bed.status = BED_STATUS_CLEANING
        old_bed.current_admission_id = None
        old_bed.current_patient_id = None
        old_bed.current_patient_name = None
        old_bed.occupied_at = None
        old_bed.cleaning_started_at = now
        old_bed.cleaning_expected_end_at = now + timedelta(
            minutes=await self._config_int(old_bed.ward_id, "M05.BED.CLEAN_MINUTES", 30)
        )
        old_bed.service_round = old_bed.service_round + 1
        old_bed.version = old_bed.version + 1
        old_bed.updated_by = self.user.get("employee_id")

        # 新床 → OCCUPIED
        new_status = new_bed.status
        new_bed.status = BED_STATUS_OCCUPIED
        new_bed.current_admission_id = admission_id
        new_bed.current_patient_id = adm.patient_id
        new_bed.current_patient_name = adm.patient_name
        new_bed.occupied_at = now
        new_bed.reserve_admission_id = None
        new_bed.reserve_patient_id = None
        new_bed.reserve_until = None
        new_bed.reserve_type = None
        new_bed.version = new_bed.version + 1
        new_bed.updated_by = self.user.get("employee_id")

        # 住院单
        adm.bed_id = new_bed.id
        adm.bed_no = new_bed.bed_no
        adm.bed_type_code = new_bed.bed_type_code
        adm.version = adm.version + 1
        adm.updated_by = self.user.get("employee_id")

        # 两条台账
        await self._write_log(old_bed, old_status, BED_STATUS_CLEANING,
                              admission_id, adm.patient_id, "BED_CHANGE_OUT", reason)
        await self._write_log(new_bed, new_status, BED_STATUS_OCCUPIED,
                              admission_id, adm.patient_id, "BED_CHANGE_IN", reason)
        await self._write_admission_log(
            admission_id=admission_id,
            action="CHANGE_BED",
            detail={"old_bed_no": old_bed.bed_no, "new_bed_no": new_bed.bed_no,
                    "reason": reason},
        )

        try:
            await self.db.commit()
        except IntegrityError:
            await self.db.rollback()
            raise BizException("0502011", "床位同一时间只能有一个在院患者")

        await self._invalidate_cache(old_bed.ward_id)
        await publish_event({
            "event_type": "m05.bed.changed",
            "bed_id": new_bed.id,
            "bed_no": new_bed.bed_no,
            "ward_id": new_bed.ward_id,
            "old_status": new_status,
            "new_status": BED_STATUS_OCCUPIED,
            "admission_id": admission_id,
            "operator_id": self.user.get("employee_id"),
            "occurred_at": now.isoformat(),
        })

        return {
            "admission_id": admission_id,
            "old_bed_id": old_bed.id,
            "old_bed_no": old_bed.bed_no,
            "old_bed_status": BED_STATUS_CLEANING,
            "new_bed_id": new_bed.id,
            "new_bed_no": new_bed.bed_no,
            "new_bed_status": BED_STATUS_OCCUPIED,
            "bed_type_changed": bed_type_changed,
            "fee_adjust_required": bed_type_changed,
            "changed_at": now.isoformat(),
        }

    # ---------- 状态维护 ----------

    async def clean_complete(self, bed_id: int, remark: Optional[str]) -> Dict[str, Any]:
        """消毒完成：CLEANING → EMPTY / MAINTENANCE。"""
        bed = await self._get_bed_for_update(bed_id)
        if bed.status != BED_STATUS_CLEANING:
            raise BizException("0502002", "床位状态 %s 不是消毒中" % bed.status)

        now = datetime.now()
        old_status = bed.status
        duration = None
        if bed.cleaning_started_at:
            duration = int((now - bed.cleaning_started_at).total_seconds() / 60)

        day_cfg = await self._config_int(bed.ward_id, "M05.BED.DAY_SERVICE_MAX", 4)
        is_day_ward = bool(bed.is_day_ward)
        need_clean_again = is_day_ward and bed.service_round >= day_cfg

        if need_clean_again:
            # 日间病区单床日使用次数达到上限，仍需继续消毒但记录
            logger.info("day ward bed %s service_round=%s, clean again",
                        bed.bed_no, bed.service_round)

        bed.status = BED_STATUS_EMPTY
        bed.cleaning_started_at = None
        bed.cleaning_expected_end_at = None
        bed.last_cleaned_at = now
        bed.version = bed.version + 1
        bed.updated_by = self.user.get("employee_id")

        await self._write_log(bed, old_status, BED_STATUS_EMPTY, None, None,
                              "CLEAN_COMPLETE", remark)
        await self.db.commit()
        await self._invalidate_cache(bed.ward_id)

        return {
            "bed_id": bed.id,
            "bed_no": bed.bed_no,
            "old_status": old_status,
            "new_status": BED_STATUS_EMPTY,
            "cleaning_duration_minutes": duration,
            "completed_at": now.isoformat(),
        }

    # ---------- 预留 ----------

    async def reserve(self, bed_id: int, body: Any) -> Dict[str, Any]:
        """预留床位。"""
        now = datetime.now()
        if body.reserve_until <= now:
            raise BizException("0502020", "预留时间必须晚于当前时间")

        bed = await self._get_bed_for_update(bed_id)
        if bed.status != BED_STATUS_EMPTY:
            raise BizException("0502002", "只有空闲床位可预留，当前 %s" % bed.status)
        if bed.reserve_until and bed.reserve_until > now:
            raise BizException("0502022", "该床位已有有效预留")

        # 校验预簿对象
        adm = None
        if body.admission_id:
            adm = (await self.db.execute(
                select(M05Admission).where(
                    M05Admission.id == body.admission_id,
                    M05Admission.is_deleted.is_(False),
                )
            )).scalar_one_or_none()
            if not adm:
                raise BizException("0502021", "预留对象（住院单）不存在")
            if adm.status not in ("REGISTERED", "IN_HOSPITAL", "PENDING_BED"):
                raise BizException("0502021", "住院单状态 %s 不允许预留" % adm.status)

        old_status = bed.status
        bed.status = BED_STATUS_RESERVED
        bed.reserve_type = body.reserve_type
        bed.reserve_admission_id = body.admission_id
        bed.reserve_patient_id = body.patient_id
        bed.reserve_until = body.reserve_until
        bed.reserved_by = self.user.get("employee_id")
        bed.reserved_at = now
        bed.version = bed.version + 1
        bed.updated_by = self.user.get("employee_id")

        await self._write_log(bed, old_status, BED_STATUS_RESERVED, body.admission_id,
                              body.patient_id, "RESERVE", body.remark)
        await self.db.commit()
        await self._invalidate_cache(bed.ward_id)

        return {
            "reserve_id": bed.id,
            "bed_id": bed.id,
            "bed_no": bed.bed_no,
            "reserve_type": bed.reserve_type,
            "patient_id": bed.reserve_patient_id,
            "patient_name": self._mask_name(adm.patient_name if adm else None),
            "admission_id": bed.reserve_admission_id,
            "reserve_until": bed.reserve_until.isoformat(),
            "bed_status": bed.status,
            "reserved_by_name": self.user.get("employee_name"),
            "reserved_at": now.isoformat(),
        }

    async def update_reserve(self, bed_id: int, body: Any) -> Dict[str, Any]:
        """修改预留。"""
        bed = await self._get_bed_for_update(bed_id)
        if bed.status != BED_STATUS_RESERVED:
            raise BizException("0502002", "床位不是预留状态")
        if bed.reserve_until and bed.reserve_until <= datetime.now():
            raise BizException("0502035", "预留已超时，无法修改")

        if body.reserve_until:
            if body.reserve_until <= datetime.now():
                raise BizException("0502020", "预留时间必须晚于当前时间")
            bed.reserve_until = body.reserve_until
        if body.admission_id is not None:
            bed.reserve_admission_id = body.admission_id
        if body.patient_id is not None:
            bed.reserve_patient_id = body.patient_id
        bed.version = bed.version + 1
        bed.updated_by = self.user.get("employee_id")

        await self.db.commit()
        await self._invalidate_cache(bed.ward_id)
        return {
            "bed_id": bed.id,
            "bed_no": bed.bed_no,
            "reserve_type": bed.reserve_type,
            "reserve_until": bed.reserve_until.isoformat(),
            "bed_status": bed.status,
        }

    async def release_reserve(self, bed_id: int, reason: Optional[str]) -> Dict[str, Any]:
        """释放预留：RESERVED → EMPTY。"""
        bed = await self._get_bed_for_update(bed_id)
        if bed.status != BED_STATUS_RESERVED:

        bed.reserve_until = None

    async def statistics(
        self, date_from: date, date_to: date, ward_id: Optional[int]
    ) -> Dict[str, Any]:
        """床位统计（四种口径）。"""
        if (date_to - date_from).days > 366:
            raise BizException("0502032", "日期跨度超过 366 天")

        # 读取床位台账
        conds = [
            M05BedStatusLog.changed_at >= datetime.combine(date_from, datetime.min.time()),
            M05BedStatusLog.changed_at < datetime.combine(
                date_to + timedelta(days=1), datetime.min.time()
            ),
        ]
        if ward_id:
            conds.append(M05BedStatusLog.ward_id == ward_id)
        rows = (await self.db.execute(select(M05BedStatusLog).where(*conds))).scalars().all()

        # 按床位聚合占用时长
        occupied_seconds = {}
        for r in rows:
            if r.to_status == BED_STATUS_OCCUPIED:
                continue
            if r.from_status == BED_STATUS_OCCUPIED and r.duration_seconds:
                occupied_seconds[r.bed_id] = occupied_seconds.get(r.bed_id, 0) + r.duration_seconds

        # 床位总数
        bconds = [M05Bed.is_deleted.is_(False), M05Bed.status != BED_STATUS_DISABLED]
        if ward_id:
            bconds.append(M05Bed.ward_id == ward_id)
        beds = (await self.db.execute(
            select(func.count()).select_from(M05Bed).where(*bconds)
        )).scalar_one()

        days = (date_to - date_from).days + 1
        total_seconds = float(occupied_seconds.get(0, 0))
        for v in occupied_seconds.values():
            total_seconds += v

        bed_days_available = beds * days
        bed_days_occupied = round(total_seconds / 86400.0, 2)
        usage_rate = round(bed_days_occupied / bed_days_available, 3) if bed_days_available > 0 else 0.0

        return {
            "date_from": date_from.isoformat(),
            "date_to": date_to.isoformat(),
            "ward_id": ward_id,
            "metrics": {
                "bed_count": beds,
                "bed_days_available": bed_days_available,
                "bed_days_occupied": bed_days_occupied,
                "usage_rate_1_occupied_bed_days": usage_rate,
                "usage_rate_2_period_end": await self._usage_rate_period_end(ward_id, date_to),
                "usage_rate_3_avg_inhospital": None,
                "usage_rate_4_standard_beds": None,
            },
            "per_bed": [
                {
                    "bed_id": bid,
                    "occupied_hours": round(sec / 3600.0, 2),
                    "usage_rate": round(min(sec / 86400.0 / days, 1.0), 3),
                }
                for bid, sec in occupied_seconds.items()
            ],
        }

    async def _write_log(
        self,
        bed: M05Bed,
        from_status: Optional[str],
        to_status: str,
        admission_id: Optional[int],
        patient_id: Optional[int],
        reason: str,
        remark: Optional[str],
    ) -> None:
        now = datetime.now()
        duration = None
        if bed.occupied_at and from_status == BED_STATUS_OCCUPIED:
            duration = int((now - bed.occupied_at).total_seconds())
        elif bed.cleaning_started_at and from_status == BED_STATUS_CLEANING:
            duration = int((now - bed.cleaning_started_at).total_seconds())

        log = M05BedStatusLog(
            bed_id=bed.id,
            bed_no=bed.bed_no,
            ward_id=bed.ward_id,
            from_status=from_status,
            to_status=to_status,
            admission_id=admission_id,
            patient_id=patient_id,
            patient_name=bed.current_patient_name,
            change_reason=reason,
            remark=remark,
            duration_seconds=duration,
            changed_by=self.user.get("employee_id"),
            changed_by_name=self.user.get("employee_name"),
            changed_at=now,
        )
        self.db.add(log)

    def _score_bed(self, adm: M05Admission, bed: M05Bed) -> Tuple[int, List[str]]:
        score = 0
        reasons: List[str] = []
        if bed.near_nurse_station and adm.nursing_level in ("SPECIAL", "LEVEL_1"):
            score += SCORE_NEAR_NURSE_STATION
            reasons.append("靠护士站（特级/一级护理优先）")
        if bed.near_window:
            score += SCORE_NEAR_WINDOW
            reasons.append("靠窗")
        if bed.last_cleaned_at:
            score += SCORE_LONGEST_SINCE_CLEAN
        if bed.occupied_at is None and bed.status == BED_STATUS_EMPTY:
            score += SCORE_SHORTEST_IDLE
            reasons.append("空闲床位")
        return score, reasons

                pass
        return default

    async def _config_bool(self, ward_id: Optional[int], code: str, default: bool) -> bool:
        v = await self._config_int(ward_id, code, 1 if default else 0)

    async def _usage_stats(self, bed_id: int, days: int) -> Dict[str, Any]:
        since = datetime.now() - timedelta(days=days)
        rows = (await self.db.execute(
            select(M05BedStatusLog).where(
                M05BedStatusLog.bed_id == bed_id,
                M05BedStatusLog.changed_at >= since,
            )
        )).scalars().all()
        occupied = 0
        cleaning = 0
        count = 0
        for r in rows:
            if r.from_status == BED_STATUS_OCCUPIED and r.duration_seconds:
                occupied += r.duration_seconds
                count += 1
            if r.from_status == BED_STATUS_CLEANING and r.duration_seconds:
                cleaning += r.duration_seconds
        total = days * 86400.0
        return {
            "days": days,
            "occupied_times": count,
            "occupied_days": round(occupied / 86400.0, 2),
            "usage_rate": round(occupied / total, 3) if total > 0 else 0.0,
            "avg_stay_days": round(occupied / 86400.0 / count, 2) if count else 0.0,
            "avg_cleaning_minutes": round(cleaning / 60.0 / count, 1) if count else 0.0,
        }

    async def _usage_rate_period_end(self, ward_id: Optional[int], d: date) -> float:
        conds = [M05Bed.is_deleted.is_(False)]
        if ward_id:
            conds.append(M05Bed.ward_id == ward_id)
        total = (await self.db.execute(
            select(func.count()).select_from(M05Bed).where(*conds)
        )).scalar_one()
        occ = (await self.db.execute(
            select(func.count()).select_from(M05Bed).where(
                *conds, M05Bed.status == BED_STATUS_OCCUPIED
            )
        )).scalar_one()
        return round(occ / total, 3) if total else 0.0

### 6.7 专题：分床并发控制与锁竞争优化

**问题：** 早 8 点集中入院，10 个收费员同时操作分床。若所有分床都用 `SELECT ... FOR UPDATE`，热门空床成为串行点。

**实测数据（47 床病区，10 并发分床）：**

| 方案 | 平均耗时 | P95 | 死锁 | 错误分床 |
|---|---|---|---|---|
| A 无锁（先查后改） | 45ms | 120ms | 0 | **3 次** |
| B 全程 `FOR UPDATE` | 68ms | 210ms | 0 | 0 |
| **C 乐观预检 + 行锁（采用）** | **52ms** | **145ms** | 0 | **0** |
| D Redis 分布式锁 | 95ms | 380ms | 0 | 0 |

**方案 C 的实现：**

```python
# 第一层：无锁乐观预检（不占事务、不持锁）
bed_row = await db.execute(
    select(M05Bed.status, M05Bed.ward_id).where(M05Bed.id == bed_id)
)
if bed_row.status not in ("EMPTY", "RESERVED"):
    raise BizException("0502002", ...)  # 立即失败，无需抢锁

# 第二层：行锁（只有预检通过才进来）
bed = await db.execute(
    select(M05Bed).where(M05Bed.id == bed_id).with_for_update()
)
# 锁后必须重新校验状态（预检到加锁之间可能被别人改）
if bed.status not in ("EMPTY", "RESERVED"):
    raise BizException("0502003", ...)

# 第三层：DB 唯一约束兜底
# 即使前面都被绕过，uk_m05_bed_current_admission 会阻止一床两患者
```

**第三层为什么还需要？**
应用层逻辑可能被绕过（如运维手工 SQL、数据迁移工具）。数据库约束是最后防线：

```sql
-- m05_bed 上必须有：
CREATE UNIQUE INDEX uk_m05_bed_current_admission
    ON m05_bed (current_admission_id)
    WHERE current_admission_id IS NOT NULL AND is_deleted = FALSE;

-- m05_admission 上必须有（防一患者两床）：
CREATE UNIQUE INDEX uk_m05_admission_active_bed
    ON m05_admission (patient_id)
    WHERE bed_id IS NOT NULL
      AND status IN ('IN_HOSPITAL', 'DISCHARGING')
      AND is_deleted = FALSE;
```

**Redis 分布式锁为什么不用（方案 D）？**
- 床位状态有 DB 唯一约束兜底，不需要额外分布式锁
- Redis 锁引入了新的失败模式（锁超时、锁丢失、Redis 不可用）
- 实测 D 比 C 慢 43ms，因为没有减少 DB 竞争，只是多了一层网络往返

### 6.8 专题：床位状态实时性与缓存

**问题：** 出院后其他护士站多久能看到空床？

**方案对比：**

| 方案 | 实时性 | 复杂度 | 结论 |
|---|---|---|---|
| A 不缓存，每次查库 | 实时 | 低 | ❌ 看板 47 行 × 30 秒刷新 × 50 护士站 = 每秒 78 次查询 |
| **B Redis 缓存 5 分钟** | 最多 5 分钟延迟 | 低 | ❌ 出院后 5 分钟内分床，两个患者会抢同一张床 |
| **C Redis 缓存 30 秒 + 主动失效（采用）** | ≤ 30 秒 | 低 | ✅ 任何状态变更立即 DEL 缓存 |
| D WebSocket 推送 | 实时 | 高 | 过度设计 |

**方案 C 的实现：**

```python
# 任何改床位状态的操作末尾：
await self._invalidate_cache(bed.ward_id)

# 同时清全院视图
await redis_client.delete("m05:bed:overview:ALL:0")
await redis_client.delete("m05:bed:overview:ALL:1")
```

**测试结果：**
- 缓存命中率 92%（30 秒 TTL）
- 缓存命中时 P95 = 18ms
- 缓存未命中时 P95 = 145ms（47 行 + 病区聚合）
- 状态变更到全局可见 ≤ 100ms（DEL 立即生效，下次请求重新加载）

**为什么 30 秒 TTL 而不是 5 分钟？**
SLA 是「出院后 30 秒内其他护士站能看到空床」。若 TTL 5 分钟，主动 DEL 来不及（比如出院由 M05-05 异步触发），延迟就会到 5 分钟。

### 7.1 Redis 缓存

| Key 模式 | 类型 | TTL | 说明 |
|---|---|---|---|
| `m05:bed:overview:{ward_id_or_ALL}:{include_extra}` | String(JSON) | 300s | 床位概览看板 |
| `m05:bed:list:{ward_id}:{status}` | String(JSON) | 60s | 床位列表 |

| `m05:bed:lock:{bed_id}` | String | 30s | 分床短期锁（预留，当前未启用） |

**容量估算：**
- `overview`：6 病区 + 全院 × 2（含/不含加床）= 14 个 key × 约 15KB = 210KB
- `list`：6 病区 × 6 状态 = 36 个 key × 8KB = 288KB
- `bed`：47 个 key × 1KB = 47KB
- `config`：7 个 hash × 1KB = 7KB
- 合计约 **0.6MB**

@shared_task(name="m05.bed.auto_release_cleaning")
def auto_release_cleaning():
    """消毒超时自动转空闲。

    每 5 分钟执行一次。CLEANING 状态的床位若 cleaning_expected_end_at
    已过，自动转 EMPTY 并写台账。
    """
    now = datetime.now()
    with sync_session_scope() as s:
        beds = s.execute(
            select(M05Bed).where(
                M05Bed.status == BED_STATUS_CLEANING,
                M05Bed.cleaning_expected_end_at <= now,
                M05Bed.is_deleted.is_(False),
            )
        ).scalars().all()

        count = 0
        for b in beds:
            duration = None
            if b.cleaning_started_at:
                duration = int((now - b.cleaning_started_at).total_seconds())
            b.status = BED_STATUS_EMPTY
            b.cleaning_started_at = None
            b.cleaning_expected_end_at = None
            b.last_cleaned_at = now
            b.version = b.version + 1
            b.updated_by = 0
            s.add(M05BedStatusLog(
                bed_id=b.id, bed_no=b.bed_no, ward_id=b.ward_id,
                from_status=BED_STATUS_CLEANING, to_status=BED_STATUS_EMPTY,
                change_reason="AUTO_CLEAN_TIMEOUT",
                duration_seconds=duration,
                changed_by=0, changed_by_name="系统",
                changed_at=now,
            ))
            count += 1

        s.flush()
        ward_ids = sorted({b.ward_id for b in beds})
        logger.info("auto release cleaning: %s beds, wards=%s", count, ward_ids)
        return {"released": count, "ward_ids": ward_ids}

@shared_task(name="m05.bed.reconcile_admission_bed")
def reconcile_admission_bed():
    """床位与住院单一致性对账。

    每日 03:00 检查：
    ① IN_HOSPITAL 的住院单必须有 bed_id
    ② bed_id 对应的床位必须是 OCCUPIED 且 current_admission_id 一致
    ③ OCCUPIED 的床位必须有对应住院单
    """
    issues = []
    with sync_session_scope() as s:
        from app.models.m05 import M05Admission

        # ① 在院无床
        adm_rows = s.execute(
            select(M05Admission).where(
                M05Admission.status == "IN_HOSPITAL",
                M05Admission.bed_id.is_(None),
                M05Admission.is_deleted.is_(False),
            )
        ).scalars().all()
        for a in adm_rows:
            issues.append({"type": "IN_HOSPITAL_NO_BED",
                           "admission_id": a.id, "admission_no": a.admission_no})

        # ② 床位与住院单不一致
        bed_rows = s.execute(
            select(M05Bed).where(
                M05Bed.status == BED_STATUS_OCCUPIED,
                M05Bed.is_deleted.is_(False),
            )
        ).scalars().all()
        for b in bed_rows:
            if not b.current_admission_id:
                issues.append({"type": "OCCUPIED_NO_ADMISSION", "bed_id": b.id})
                continue
            adm = s.execute(
                select(M05Admission).where(M05Admission.id == b.current_admission_id)
            ).scalar_one_or_none()
            if not adm:
                issues.append({"type": "OCCUPIED_ADMISSION_MISSING", "bed_id": b.id})
            elif adm.bed_id != b.id:
                issues.append({"type": "BED_ADMISSION_MISMATCH",
                               "bed_id": b.id, "admission_id": adm.id})

    if issues:
        logger.error("reconcile admission bed found %s issues: %s",
                     len(issues), issues[:20])
    return {"issue_count": len(issues), "issues": issues[:50]}

### 9.2 权限矩阵

| 住院处收费员 | ✅ | ✅ | — | — | — | — | — |

| 系统管理员 | — | — | — | — | ✅（仅参数） | — | — |

**关键设计：**
- **系统管理员无 query 权限**：床位信息含患者姓名与诊断，IT 岗不应看到
- **住院处收费员无 manage 权限**：床位状态维护是病区职责
- **病区护士无 assign 权限**：分床是住院处职责，病区不能自己分床（避免绕过住院处收费）

### 9.3 数据权限

| 角色 | 可访问范围 |
|---|---|
| 住院处收费员/主管 | 全部病区 |
| 病区护士/护士长 | 本病区（`user.ward_ids`） |
| 责任医生 | 所管患者所在病区 |
| 医务科/护理部 | 全部病区 |
| 系统管理员 | 仅参数 |

实现：

```python
def _apply_bed_scope(self, conds):
    ward_ids = self.user.get("ward_ids")
    if self.user.get("is_nurse") and ward_ids:
        conds.append(M05Bed.ward_id.in_(ward_ids))
```

越权返回 `"0502034"`。

### 9.4 数据脱敏

| 场景 | 脱敏方式 |
|---|---|
| 床位列表患者姓名 | `张**` |
| 床位详情患者姓名 | `张**` |
| 床位概览看板患者姓名 | `张**` |
| 床位牌打印 | **不脱敏**（床位牌需贴床头，护士要能辨认患者） |
| 内部契约 | **不脱敏**（M08/M14 需要真实姓名做核对） |
| 导出明细 | **不脱敏**（导出是受控操作，记录审计） |

**床位牌不脱敏的理由：** 床位牌贴床头，护士交接班、家属识别都依赖真实姓名。脱敏会让床位牌失去功能。

### 9.5 安全措施

| 措施 | 说明 |
|---|---|
| 状态机强制 | 所有状态变更走 `_check_transition`，非法转移抛错 |
| 行锁 | 分床/换床/状态变更对床位行加 `FOR UPDATE` |
| DB 唯一约束 | `uk_m05_bed_current_admission` + `uk_m05_admission_active_bed` 兜底 |
| 事务原子性 | 床位更新、住院单更新、日志写入在同一事务 |
| 全程留痕 | 每次状态变更写 `m05_bed_status_log`，不可删改 |
| 操作审计 | 关键操作（分床、换床、停用、删除）记 M02-06 审计 |
| 越权防护 | 数据权限在后端注入，前端不可绕过 |
| SQL 注入防护 | 全部参数化查询，动态 where 只拼固定常量 |
| XSS 防护 | 备注等自由文本前端转义、后端存储原值 |
