## 4. 数据结构设计

### 4.1 ER 关系图

```

└──────────────────────────────┬───────────────────────────────────────┘
                               │

┌──────────────────────────────────┐
│ m04_registration（挂号主表）★核心  │
│  · registration_no / visit_no    │
│  · schedule_id / slot_id         │
│  · patient_id / doctor_id        │
│  · status（REGISTERED/PAID/...）  │
│  · billing_no（M16 收费单）        │
└───────┬──────────────┬───────────┴──────────────┬─────────────────┐
```

**设计说明：**

- `m04_registration` 是挂号主体，一条记录对应一个号源（`slot_id`）
- `visit_no` 是就诊号（按班次顺序），`queue_no` 是排队号（含科室前缀）
- **收费单号 `billing_no` 存于本表**，但收费单实体在 M16
- `m04_refund_request` 与挂号单是 1:N（一次挂号可能有多次退号申请，只有一次生效）
- `m04_reg_fee_item` 是费用明细快照（定价变化不影响历史）

**约束说明**

```sql
ALTER TABLE m04_registration
    ADD CONSTRAINT ck_m04_reg_no
    CHECK (registration_no ~ '^RG[0-9]{8}[A-Z0-9]{6}$');

ALTER TABLE m04_registration
    ADD CONSTRAINT ck_m04_reg_period
    CHECK (period IN ('AM', 'PM', 'NIGHT', 'ALL_DAY'));

ALTER TABLE m04_registration
    ADD CONSTRAINT ck_m04_reg_type
    CHECK (reg_type IN ('NORMAL', 'APPOINTMENT', 'EMERGENCY',
                         'FOLLOWUP', 'SPECIAL', 'SUPPLEMENT'));

ALTER TABLE m04_registration
    ADD CONSTRAINT ck_m04_reg_charge_mode
    CHECK (charge_mode IN ('IMMEDIATE', 'LATER', 'WAIVE'));

ALTER TABLE m04_registration
    ADD CONSTRAINT ck_m04_reg_status
    CHECK (status IN ('REGISTERED', 'PAID', 'WAIVED', 'VISITING',
                       'COMPLETED', 'REFUNDED', 'CANCELLED'));

-- 金额非负
ALTER TABLE m04_registration
    ADD CONSTRAINT ck_m04_reg_amount
    CHECK (reg_fee >= 0 AND exam_fee >= 0 AND discount_amount >= 0
       AND total_amount >= 0 AND paid_amount >= 0 AND refund_amount >= 0);

-- 就诊号正数
ALTER TABLE m04_registration
    ADD CONSTRAINT ck_m04_reg_visit_no
    CHECK (visit_no > 0);

-- 关键：一个号源只能有一条有效挂号
CREATE UNIQUE INDEX uk_m04_reg_slot
    ON m04_registration (slot_id)
    WHERE status NOT IN ('REFUNDED', 'CANCELLED') AND is_deleted = FALSE;

-- 关键：同班次内就诊号唯一
CREATE UNIQUE INDEX uk_m04_reg_visit_no
    ON m04_registration (schedule_id, visit_no)
    WHERE is_deleted = FALSE;

-- PAID 必须有收费信息
ALTER TABLE m04_registration
    ADD CONSTRAINT ck_m04_reg_paid
    CHECK (status <> 'PAID'
           OR (billing_no IS NOT NULL AND paid_at IS NOT NULL));
```

```sql
    ON m04_refund_request (registration_id)
    WHERE audit_status = 'PENDING';

-- 已执行必须有审核状态

    ADD CONSTRAINT ck_m04_refund_executed
    CHECK (executed = FALSE OR audit_status = 'APPROVED');
```
