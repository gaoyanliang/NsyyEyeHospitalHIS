## 1. 模块概述

### 1.1 模块定位

叫号是门诊候诊环节的**执行端**。它回答："**下一位叫谁？怎么通知患者？**"

```
┌──────────────────────────────────────────────────────────────┐
│  M04-04 分诊（已分诊、已入队，状态 TRIAGED）                   │
└────────────────────────┬─────────────────────────────────────┘
                         │ 队列就绪
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M04-05 叫号与候诊（本文档）                                   │
│  呼叫下一位 → 屏显 + 语音 → 应答 → 进入诊室                     │
│              ↓ 未应答                                          │
│          过号 → 复叫 / 过号队列                                 │
└────────────────────────┬─────────────────────────────────────┘
                         │ 患者进入诊室
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M07 医生站（开始接诊）                                        │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 叫号 vs 分诊（边界）

| 维度 | 分诊（M04-04） | **叫号（本子模块）** |
|---|---|---|
| 职责 | 决定**排哪个队**、**什么优先级** | 决定**何时叫**、**怎么通知** |
| 操作者 | 分诊护士 | 医生 / 护士 |
| 输出 | 队列条目 | 叫号记录、屏显、语音 |
| 状态 | `TRIAGED` | `CALLED` / `PASSED` |
| 表 | `m04_triage`、`m04_queue_entry` | **`m04_call_record`** |

> **一句话：** 分诊是"排好队"，叫号是"按顺序喊人"。

### 1.3 与相邻模块的分工

| 能力 | 归属 |
|---|---|
| 分诊与队列维护 | M04-04 |
| **叫号（呼叫下一位）** | **M04-05 本子模块** |
| **过号与复叫** | **M04-05 本子模块** |
| **叫号屏显示** | **M04-05 本子模块** |
| **语音播报** | **M04-05 本子模块**（调 M21 语音服务） |
| **优先叫号（危重插队）** | **M04-05 本子模块** |
| **候诊监控** | **M04-05 本子模块** |
| 就诊（接诊、写病历） | M07 |
| 分诊规则与优先级 | M04-04 |
| 特殊号优先 | M04-06（本模块消费） |

> **边界一句话：** 本子模块只管"叫号这个动作及其通知"，**不做**队列排序规则（M04-04）、**不做**就诊内容（M07）。

### 1.4 叫号场景

| 场景 | 说明 | 触发 |
|---|---|---|
| **正常叫号** | 医生点"下一位" | 医生操作 |
| **优先叫号** | 危重患者插队 | 医生/护士操作 |
| **指定叫号** | 叫指定患者 | 护士操作 |
| **复叫** | 重复呼叫过号患者 | 护士操作 |
| **过号处理** | 叫号无应答，标记过号 | 自动/手动 |
| **重新排队** | 过号患者重新入队 | 护士操作 |
| **绿色通道叫号** | 绿色通道患者优先 | 自动（权重已提升） |
| **迟到叫号** | 迟到患者（已过号） | 护士操作 |

### 1.5 模块目标

- **清晰**：患者清楚知道"什么时候轮到我"。
- **不遗漏**：每位候诊患者都会被叫到。
- **公平**：按优先级 + 先到先看。
- **高效**：单次叫号 ≤ 3 秒完成。
- **可见**：屏显 + 语音 + 短信三通道。
- **可追溯**：每次叫号有记录。

### 1.6 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 医生 | 叫号接诊 | 呼叫下一位、优先叫号 |
| 分诊护士 | 协助叫号 | 复叫、过号处理、重新排队 |
| 患者 | 候诊 | 看屏、听播报、进入诊室 |
| 护士长 | 监控 | 候诊监控、队列调整 |

## 3. 业务模型

### 3.1 叫号状态机

```
        ┌──────────────┐
        │   WAITING    │  候诊（队列中）
        └──────┬───────┘
               │ 呼叫
               ▼
        ┌──────────────┐
        │   CALLING    │  正在叫号（播报中）
        └──────┬───────┘
               │
       ┌───────┼────────────┬──────────────┐
       │ 应答   │ 无应答超时   │ 主动跳过       │
       ▼       ▼            ▼              ▼
┌───────────┐┌──────────┐┌──────────┐┌──────────┐
│ ENTERING  ││ NO_ANSWER││ SKIPPED  ││ CANCELLED│
│ 进入诊室   ││ 无应答    ││ 已跳过    ││ 已取消    │
└─────┬─────┘└────┬─────┘└──────────┘└──────────┘
      │           │
      │           │ 复叫
      │           ├──────────► CALLING
      │           │
      │           │ 过号
      │           ▼
      │      ┌──────────┐
      │      │  PASSED  │  过号
      │      └────┬─────┘
      │           │ 重新排队
      │           ▼
      │      ┌──────────┐
      │      │ WAITING  │
      │      └──────────┘
      │
      │ 就诊开始（M07）
      ▼
┌──────────────┐
│  IN_VISIT    │  就诊中
└──────┬───────┘
       │ 完成
       ▼
┌──────────────┐
│  COMPLETED   │  已完成
└──────────────┘
```

**状态说明：**

| 状态 | 说明 | 可复叫 |
|---|---|---|
| `WAITING` | 候诊中 | — |
| `CALLING` | 正在叫号（播报中） | — |
| `ENTERING` | 已应答，进入诊室 | — |
| `NO_ANSWER` | 无应答（已叫但未到） | ✅ |
| `PASSED` | 已过号 | ✅（需重新排队） |
| `SKIPPED` | 主动跳过 | ✅ |
| `IN_VISIT` | 就诊中 | — |
| `COMPLETED` | 已完成 | — |
| `CANCELLED` | 已取消 | — |

### 3.2 叫号队列模型

#### 3.2.1 队列排序（继承 M04-04）

```
队列 = 该诊室 WAITING 状态条目
排序 = priority_weight DESC, triaged_at ASC
```

#### 3.2.2 叫号时的取号逻辑

```
医生点"下一位"
   ↓
① 取队列首位（WAITING）
   ├─ 无 → 提示"暂无候诊患者"
   └─ 有 ↓
② 检查是否有待复叫的（NO_ANSWER）
   ├─ 有 → 优先复叫（可配置）
   └─ 无 ↓
③ 检查是否有危重插队（L1/L2 且等待超时）
   ├─ 有 → 优先叫危重
   └─ 无 ↓
④ 正常取首位
   ↓
⑤ 状态 → CALLING
⑥ 触发屏显 + 语音 + 短信
⑦ 启动应答计时（默认 60 秒）
```

#### 3.2.3 叫号优先级规则

| 优先级 | 条件 | 说明 |
|---|---|---|
| 1 | L1 濒危 | 立即叫 |
| 2 | L2 危重超时 | 超过响应时限 |
| 3 | 待复叫（NO_ANSWER） | 可配置是否优先 |
| 4 | 队列首位（按权重） | 正常顺序 |
| 5 | 指定叫号 | 护士手动指定 |

> **可配置：** `M04.CALL.PRIORITY_NO_ANSWER_FIRST`（待复叫是否优先）

### 3.3 过号模型

#### 3.3.1 过号判定

```
叫号后启动计时（默认 60 秒）
   ↓
60 秒内患者未应答（未进入诊室）
   ↓
自动标记 NO_ANSWER
   ↓
再过 120 秒（可配置）仍未应答
   ↓
自动标记 PASSED（过号）
```

**也可手动标记过号。**

#### 3.3.2 过号后的处理

| 处理方式 | 说明 | 队列位置 |
|---|---|---|
| **重新排队到队尾** | 默认 | 队尾 |
| **重新排队到原位置** | 保留原位置 | 原位 |
| **优先插队** | 立即叫（若患者已到） | 队首 |
| **作废** | 视为放弃就诊 | — |

**配置：** `M04.CALL.PASSED_REQUEUE_POSITION = TAIL / ORIGINAL`

#### 3.3.3 过号次数限制

| 次数 | 后果 |
|---|---|
| 1 次 | 重新排队 |
| 2 次 | 重新排队 + 提示 |
| 3 次 | **需护士确认**方可重新排队 |

#### 3.4.3 显示规则

### 3.5 语音播报模型

#### 3.5.1 播报内容

```
"请 王五 患者 到 302 诊室 就诊"
"请 A019 号 王五 到 302 诊室"
```

**配置：** `M04.CALL.VOICE_TEMPLATE`

#### 3.5.2 播报规则

| 规则 | 说明 |
|---|---|
| 播报次数 | 2 次（间隔 3 秒） |
| 音量 | 可配 |
| 语言 | 普通话（可配粤语） |
| 姓名处理 | 播报全名（屏显脱敏） |
| 静音时段 | 可配置（如 12:00-14:00 降低音量） |

#### 3.5.3 TTS 方案

```
叫号触发
   ↓
生成播报文本
   ↓
检查缓存（相同文本复用音频）
   ├─ 命中 → 直接播放
   └─ 未命中 ↓
调 M21 TTS 服务合成
   ↓
存入对象存储
   ↓
推送音频 URL 到播放终端
```

### 3.6 叫号通知模型

| 渠道 | 时机 | 内容 |
|---|---|---|
| **叫号屏** | 呼叫时 | 姓名 + 队列号 + 诊室 |
| **语音** | 呼叫时 | TTS 播报 |
| **短信** | 前 3 位时 | "前面还有 3 位，请到候诊区等待" |
| **微信** | 前 3 位时 | 公众号推送 |
| **APP 推送** | 前 3 位时 | 预留 |

**说明：** 叫号通知是**增量通知**——只在前 3 位时发一次，避免打扰。

### 3.7 候诊监控模型

| 指标 | 说明 |
|---|---|
| 当前候诊数 | 该诊室 WAITING 数量 |
| 平均等待 | 已叫患者的平均等待时长 |
| 最长等待 | 当前候诊中最长 |
| 预计完成时间 | 当前时间 + 剩余人数 × 平均就诊时长 |
| 队列健康度 | 绿/黄/红 |
| 过号率 | 过号/叫号 |

### 3.8 叫号与就诊的关系

```
叫号 → CALLED
   ↓
患者进入诊室
   ↓
医生点"开始接诊"
   ↓
M07 调用 M04-03 start-visit
   ↓
M04-03 调用 M04-04 on-visit-start
   ↓
M04-04 更新队列 IN_VISIT
   ↓
M04-05 监听并更新叫号记录 IN_VISIT
```

### 6.5 Service 层核心逻辑示例

```python
# app/services/m04/call_service.py
"""叫号服务"""
import json
import uuid
from datetime import date, datetime, timedelta
from typing import Optional, List

from sqlalchemy import select, and_, or_, func, desc
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.m04.call import (
    M04CallRecord, M04CallConfig, M04CallLog,
)
from app.models.m04.triage import M04Triage, M04QueueEntry
from app.core.exceptions import BizException
from app.core.redis import redis_client
from app.clients.mpi_message_client import MpiMessageClient


class CallService:
    """叫号主流程"""

    def __init__(self, db: AsyncSession):
        self.db = db
        self.msg = MpiMessageClient()

    # ---------- 预览下一位 ----------
    async def preview_next(self, room_id: int) -> dict:
        """预览下一位（不实际叫号）"""
        config = await self._get_config(room_id)
        next_entry = await self._pick_next(room_id, config)

        if not next_entry:
            return {
                "room_id": room_id,
                "next_patient": None,
                "queue_total": 0,
                "message": "暂无候诊患者",
            }

        passed_count = (await self.db.execute(
            select(func.count()).select_from(M04CallRecord).where(
                M04CallRecord.room_id == room_id,
                M04CallRecord.call_date == date.today(),
                M04CallRecord.status == "PASSED",
            )
        )).scalar_one()

        return {
            "room_id": room_id,
            "room_no": next_entry.get("room_no"),
            "next_patient": {
                "queue_entry_id": next_entry["id"],
                "triage_id": next_entry["triage_id"],
                "queue_no": next_entry["queue_no"],
                "patient_id": next_entry["patient_id"],
                "patient_name": next_entry["patient_name"],
                "patient_name_masked": self._mask_name(next_entry["patient_name"]),
                "triage_level": next_entry["triage_level"],
                "triage_level_text": self._level_text(next_entry["triage_level"]),
                "level_color": self._level_color(next_entry["triage_level"]),
                "waiting_minutes": next_entry["waiting_minutes"],
                "is_overdue": next_entry["is_overdue"],
                "is_critical": next_entry["triage_level"] in ("L1", "L2"),
            },
            "queue_total": next_entry["queue_total"],
            "has_pending_recall": passed_count > 0,
            "pending_recall_count": passed_count,
            "priority_hint": self._priority_hint(next_entry),
        }

    # ---------- 呼叫下一位 ----------
    async def call_next(self, payload, user) -> dict:
        """呼叫下一位"""
        room_id = payload.room_id
        config = await self._get_config(room_id)

        # 1. 检查是否有正在叫号未处理的
        current = (await self.db.execute(
            select(M04CallRecord).where(
                M04CallRecord.room_id == room_id,
                M04CallRecord.call_date == date.today(),
                M04CallRecord.status == "CALLING",
            )
        )).scalar_one_or_none()

        if current:
            elapsed = int((datetime.now() - current.called_at).total_seconds())
            raise BizException(54403, "当前患者未到诊，请先处理",
                data={
                    "current_call": {
                        "call_id": current.id,
                        "queue_no": current.queue_no,
                        "patient_name_masked": self._mask_name(
                            current.patient_name),
                        "status": "CALLING",
                        "called_at": current.called_at.isoformat(),
                        "elapsed_seconds": elapsed,
                        "is_expired": elapsed > (config.get("answer_limit_seconds", 60)),
                    },
                    "suggestion": "请对该患者执行：复叫 / 过号 / 已到诊",
                    "actions": ["RECALL", "PASS", "ARRIVE"],
                })

        # 2. 暂停叫号检查
        if config.get("paused_rooms") and room_id in config["paused_rooms"]:
            raise BizException(54405, "该诊室已暂停叫号")

        # 3. 取下一个
        next_entry = await self._pick_next(room_id, config)

        if not next_entry:
            raise BizException(54403, "当前诊室暂无候诊患者",
                data={
                    "room_id": room_id,
                    "queue_total": 0,
                    "suggestion": "今日已全部接诊完毕",
                })

        # 4. 创建叫号记录
        call = await self._create_call(next_entry, room_id, payload, user)

        # 5. 通知
        announce_info = await self._announce(call, config, payload)

        # 6. 更新队列
        await self.db.execute(
            M04QueueEntry.__table__.update()
            .where(M04QueueEntry.id == next_entry["id"])
            .values(
                status="CALLED",
                called_at=datetime.now(),
                call_count=(M04QueueEntry.call_count + 1),
            )
        )

        await self.db.commit()

        # 7. 屏显推送
        await self._push_screen(room_id, call)

        # 8. 取下一号提示
        next_hint = await self._peek_next(room_id, config)

        return {
            "call_id": call.id,
            "call_no": call.call_no,
            "queue_entry_id": next_entry["id"],
            "triage_id": next_entry["triage_id"],
            "room_id": room_id,
            "room_no": call.room_no,
            "queue_no": call.queue_no,
            "patient_id": call.patient_id,
            "patient_name": call.patient_name,
            "patient_name_masked": self._mask_name(call.patient_name),
            "triage_level": call.triage_level,
            "triage_level_text": self._level_text(call.triage_level),
            "level_color": self._level_color(call.triage_level),
            "waiting_minutes": next_entry["waiting_minutes"],
            "call_at": call.called_at.isoformat(),
            "status": "CALLING",
            "status_text": "正在叫号",
            "announce_text": announce_info["text"],
            "announce_url": announce_info["url"],
            "answer_limit_seconds": config.get("answer_limit_seconds", 60),
            "answer_deadline": (call.called_at + timedelta(
                seconds=config.get("answer_limit_seconds", 60))).isoformat(),
            "screen_pushed": True,
            "voice_played": announce_info["played"],
            "sms_sent": announce_info["sms_sent"],
            "queue_total_after": next_entry["queue_total"] - 1,
            "next_patient_hint": next_hint,
        }

    async def _pick_next(self, room_id: int, config: dict) -> Optional[dict]:
        """选取下一个患者"""
        # 1. 待复叫优先（可配置）
        if config.get("priority_no_answer_first", True):
            recall = (await self.db.execute(
                select(M04CallRecord).where(
                    M04CallRecord.room_id == room_id,
                    M04CallRecord.call_date == date.today(),
                    M04CallRecord.status.in_(("NO_ANSWER", "PASSED")),
                    M04CallRecord.requeued == False,
                ).order_by(M04CallRecord.called_at.asc()).limit(1)
            )).scalar_one_or_none()

            if recall:
                # 转为队列条目
                entry = (await self.db.execute(
                    select(M04QueueEntry).where(
                        M04QueueEntry.triage_id == recall.triage_id)
                )).scalar_one_or_none()

                if entry and entry.status in ("WAITING", "PASSED"):
                    return await self._build_entry_dict(entry, room_id)

        # 2. 正常队列（按优先级 + 时间）
        entry = (await self.db.execute(
            select(M04QueueEntry).where(
                M04QueueEntry.room_id == room_id,
                M04QueueEntry.queue_date == date.today(),
                M04QueueEntry.status == "WAITING",
            ).order_by(
                M04QueueEntry.priority_weight.desc(),
                M04QueueEntry.triaged_at.asc(),
            ).limit(1)
        )).scalar_one_or_none()

        if not entry:
            return None

        return await self._build_entry_dict(entry, room_id)

    async def _build_entry_dict(self, entry: M04QueueEntry,
                                  room_id: int) -> dict:
        """构建条目字典"""
        now = datetime.now()
        waited = int((now - entry.triaged_at).total_seconds() / 60) \
            if entry.triaged_at else 0

        # 查分诊获取响应时限
        triage = (await self.db.execute(
            select(M04Triage).where(M04Triage.id == entry.triage_id)
        )).scalar_one_or_none()

        limit = triage.response_limit_minutes if triage else 60
        is_overdue = waited > (limit or 60)

        total = (await self.db.execute(
            select(func.count()).select_from(M04QueueEntry).where(
                M04QueueEntry.room_id == room_id,
                M04QueueEntry.queue_date == date.today(),
                M04QueueEntry.status == "WAITING",
            )
        )).scalar_one()

        return {
            "id": entry.id,
            "triage_id": entry.triage_id,
            "registration_id": entry.registration_id,
            "patient_id": entry.patient_id,
            "patient_name": entry.patient_name,
            "queue_no": entry.queue_no,
            "room_no": entry.room_no,
            "triage_level": entry.triage_level,
            "priority_weight": entry.priority_weight,
            "waiting_minutes": waited,
            "is_overdue": is_overdue,
            "queue_total": total,
        }

    async def _peek_next(self, room_id: int, config: dict) -> Optional[dict]:
        """查看下一个（不消耗）"""
        entry = (await self.db.execute(
            select(M04QueueEntry).where(
                M04QueueEntry.room_id == room_id,
                M04QueueEntry.queue_date == date.today(),
                M04QueueEntry.status == "WAITING",
            ).order_by(
                M04QueueEntry.priority_weight.desc(),
                M04QueueEntry.triaged_at.asc(),
            ).limit(1)
        )).scalar_one_or_none()

        if not entry:
            return None

        return {
            "queue_no": entry.queue_no,
            "patient_name_masked": self._mask_name(entry.patient_name),
            "triage_level": entry.triage_level,
        }

    async def _create_call(self, entry: dict, room_id: int,
                             payload, user) -> M04CallRecord:
        """创建叫号记录"""
        call_no = f"CL{datetime.now().strftime('%Y%m%d')}" \
                  f"{uuid.uuid4().hex[:4].upper()}"

        # 查诊室与医生
        from app.models.m04.triage import M04TriageRoom
        room = (await self.db.execute(
            select(M04TriageRoom).where(M04TriageRoom.id == room_id)
        )).scalar_one_or_none()

        call = M04CallRecord(
            call_no=call_no,
            call_date=date.today(),
            queue_entry_id=entry["id"],
            triage_id=entry["triage_id"],
            registration_id=entry["registration_id"],
            patient_id=entry["patient_id"],
            patient_name=entry["patient_name"],
            queue_no=entry["queue_no"],
            triage_level=entry["triage_level"],
            dept_id=room.dept_id if room else None,
            doctor_id=payload.doctor_id or (room.doctor_id if room else None),
            doctor_name=room.doctor_name if room else None,
            room_id=room_id,
            room_no=entry["room_no"] or (room.room_no if room else None),
            call_mode=payload.call_mode or "NORMAL",
            waiting_minutes=entry["waiting_minutes"],
            status="CALLING",
            called_at=datetime.now(),
            called_by=getattr(user, "id", None),
            called_by_name=getattr(user, "name", None),
        )
        self.db.add(call)
        await self.db.flush()

        return call

    async def _announce(self, call: M04CallRecord, config: dict,
                          payload) -> dict:
        """播报与通知"""
        # 1. 生成播报文本
        template = config.get("voice_template",
                                "请 {name} 患者 到 {room} 诊室 就诊")
        text = template.format(
            name=call.patient_name or call.queue_no,
            room=call.room_no,
            queue_no=call.queue_no,
        )

        # 2. TTS 合成
        url = None
        played = False
        if payload.announce and config.get("voice_enabled", True):
            try:
                from app.services.m04.tts_service import TtsService
                url = await TtsService().synthesize(text)
                played = True
            except Exception:
                played = False

        # 3. 短信（前 3 位才发）
        sms_sent = False
        if payload.send_sms and config.get("sms_enabled", True):
            try:
                remain = await self._count_ahead(call.room_id)
                if remain <= config.get("sms_ahead_threshold", 3):
                    await self.msg.send(
                        biz_type="CALL_NOTICE",
                        receivers=[call.patient_id],
                        params={
                            "patient_name": call.patient_name,
                            "queue_no": call.queue_no,
                            "room_no": call.room_no,
                        })
                    sms_sent = True
            except Exception:
                pass

        return {"text": text, "url": url,
                "played": played, "sms_sent": sms_sent}

    async def _count_ahead(self, room_id: int) -> int:
        """计算前面还有几人"""
        return (await self.db.execute(
            select(func.count()).select_from(M04QueueEntry).where(
                M04QueueEntry.room_id == room_id,
                M04QueueEntry.queue_date == date.today(),
                M04QueueEntry.status == "WAITING",
            )
        )).scalar_one()

    async def _push_screen(self, room_id: int, call: M04CallRecord) -> None:
        """推送叫号屏"""
        try:
            payload = {
                "type": "CALL",
                "room_id": room_id,
                "room_no": call.room_no,
                "call_id": call.id,
                "queue_no": call.queue_no,
                "patient_name_masked": self._mask_name(call.patient_name),
                "triage_level": call.triage_level,
                "is_critical": call.triage_level in ("L1", "L2"),
                "timestamp": datetime.now().isoformat(),
            }
            await redis_client.publish(
                f"m04:call:screen:{room_id}", json.dumps(payload))
        except Exception:
            pass

    # ---------- 复叫 ----------
    async def recall(self, call_id: int, payload, user) -> dict:
        """复叫"""
        call = await self._get_call(call_id)

        if call.status not in ("CALLING", "NO_ANSWER", "PASSED"):
            raise BizException(54402,
                f"当前状态 {call.status} 不可复叫")

        config = await self._get_config(call.room_id)
        max_recall = config.get("max_recall", 3)

        if call.recall_count >= max_recall:
            raise BizException(54428, "复叫次数过多，请改为过号处理",
                data={
                    "call_id": call.id,
                    "recall_count": call.recall_count,
                    "max_recall": max_recall,
                    "suggestion": "建议标记过号，患者到后可重新排队",
                })

        call.recall_count += 1
        call.recalled_at = datetime.now()
        call.status = "CALLING"

        self.db.add(M04CallLog(
            call_id=call.id,
            call_no=call.call_no,
            action="RECALL",
            reason=payload.reason,
            operator_id=getattr(user, "id", None),
            operator_name=getattr(user, "name", None),
        ))

        await self.db.commit()

        # 播报
        announce_info = await self._announce(call, config, payload)
        await self._push_screen(call.room_id, {
            "type": "RECALL", **self._call_payload(call)})

        return {
            "call_id": call.id,
            "call_no": call.call_no,
            "recall_count": call.recall_count,
            "queue_no": call.queue_no,
            "patient_name_masked": self._mask_name(call.patient_name),
            "room_no": call.room_no,
            "announce_text": announce_info["text"],
            "announce_url": announce_info["url"],
            "recalled_at": call.recalled_at.isoformat(),
            "answer_deadline": (call.recalled_at + timedelta(
                seconds=config.get("answer_limit_seconds", 60))).isoformat(),
            "screen_pushed": True,
            "voice_played": announce_info["played"],
        }

    # ---------- 过号 ----------
    async def mark_passed(self, call_id: int, payload, user) -> dict:
        """标记过号"""
        call = await self._get_call(call_id)

        if call.status not in ("CALLING", "NO_ANSWER"):
            raise BizException(54402,
                f"当前状态 {call.status} 不可标记过号")

        config = await self._get_config(call.room_id)

        call.status = "PASSED"
        call.passed_at = datetime.now()
        call.pass_count = (call.pass_count or 0) + 1
        call.pass_reason = payload.reason
        call.pass_reason_detail = payload.reason_detail

        self.db.add(M04CallLog(
            call_id=call.id,
            call_no=call.call_no,
            action="PASS",
            reason=payload.reason,
            detail=payload.reason_detail,
            operator_id=getattr(user, "id", None),
            operator_name=getattr(user, "name", None),
        ))

        await self.db.commit()

        # 屏显更新
        await self._push_screen(call.room_id, {
            "type": "PASS", **self._call_payload(call)})

        # 自动叫下一位
        next_call = None
        if payload.auto_next:
            try:
                result = await self.call_next(
                    type("P", (), {
                        "room_id": call.room_id,
                        "doctor_id": call.doctor_id,
                        "call_mode": "NORMAL",
                        "announce": True,
                        "send_sms": True,
                        "auto_next": False,
                    })(), user)
                next_call = {
                    "call_id": result["call_id"],
                    "queue_no": result["queue_no"],
                    "patient_name_masked": result["patient_name_masked"],
                    "triage_level": result["triage_level"],
                    "auto_called": True,
                }
            except BizException:
                pass

        return {
            "call_id": call.id,
            "queue_no": call.queue_no,
            "patient_name_masked": self._mask_name(call.patient_name),
            "status": "PASSED",
            "status_text": "已过号",
            "passed_at": call.passed_at.isoformat(),
            "pass_count": call.pass_count,
            "requeue_position": config.get("passed_requeue_position", "TAIL"),
            "next_call": next_call,
        }

    # ---------- 重新排队 ----------
    async def requeue(self, call_id: int, payload, user) -> dict:
        """过号后重新排队"""
        call = await self._get_call(call_id)

        if call.status not in ("PASSED", "NO_ANSWER"):
            raise BizException(54402,
                f"当前状态 {call.status} 不可重新排队")

        config = await self._get_config(call.room_id)
        max_pass = config.get("max_pass_count", 3)

        if call.pass_count >= max_pass:
            raise BizException(54408,
                f"该患者已过号 {call.pass_count} 次，需护士长确认",
                data={
                    "call_id": call.id,
                    "pass_count": call.pass_count,
                    "max_pass_count": max_pass,
                    "suggestion": "请护士长确认后手动处理",
                })

        entry = (await self.db.execute(
            select(M04QueueEntry).where(
                M04QueueEntry.triage_id == call.triage_id)
        )).scalar_one_or_none()

        if not entry:
            raise BizException(54427, "过号恢复失败，队列条目丢失")

        # 重新入队
        if payload.position == "TAIL":
            entry.priority_weight = max(1, (entry.priority_weight or 0) - 500)
        elif payload.position == "ORIGINAL":
            pass    # 保持原权重
        elif payload.position == "TOP":
            entry.priority_weight = 9999

        entry.status = "WAITING"
        entry.triaged_at = datetime.now()    # 重置等待计时

        call.status = "REQUEUED"
        call.requeued = True
        call.requeued_at = datetime.now()

        self.db.add(M04CallLog(
            call_id=call.id,
            call_no=call.call_no,
            action="REQUEUE",
            detail=f"位置：{payload.position}",
            operator_id=getattr(user, "id", None),
            operator_name=getattr(user, "name", None),
        ))

        await self.db.commit()

        # 计算新位置
        position = (await self.db.execute(
            select(func.count()).select_from(M04QueueEntry).where(
                M04QueueEntry.room_id == entry.room_id,
                M04QueueEntry.queue_date == date.today(),
                M04QueueEntry.status == "WAITING",
                M04QueueEntry.priority_weight > entry.priority_weight,
            )
        )).scalar_one() + 1

        return {
            "call_id": call.id,
            "queue_no": call.queue_no,
            "patient_name_masked": self._mask_name(call.patient_name),
            "status": "WAITING",
            "status_text": "已重新排队",
            "new_position": position,
            "estimated_wait_minutes": (position - 1) * config.get(
                "avg_visit_minutes", 8),
            "pass_count": call.pass_count,
        }

    # ---------- 就诊回调 ----------
    async def on_visit_start(self, payload: dict) -> dict:
        """就诊开始"""
        room_id = payload.get("room_id")

        call = (await self.db.execute(
            select(M04CallRecord).where(
                M04CallRecord.registration_id == payload["registration_id"],
                M04CallRecord.call_date == date.today(),
                M04CallRecord.status.in_(("CALLING", "NO_ANSWER", "PASSED")),
            ).order_by(desc(M04CallRecord.called_at)).limit(1)
        )).scalar_one_or_none()

        if not call:
            return {"updated": False, "reason": "无有效叫号记录"}

        call.status = "IN_VISIT"
        call.visit_start_at = datetime.now()

        # 更新队列
        await self.db.execute(
            M04QueueEntry.__table__.update()
            .where(M04QueueEntry.triage_id == call.triage_id)
            .values(status="IN_VISIT", in_visit_at=datetime.now())
        )

        await self.db.commit()

        # 屏显更新
        await self._push_screen(call.room_id, {
            "type": "VISIT_START", **self._call_payload(call)})

        return {
            "call_id": call.id,
            "updated": True,
            "status": "IN_VISIT",
            "visit_start_at": call.visit_start_at.isoformat(),
            "wait_minutes": call.waiting_minutes,
        }

    async def on_visit_complete(self, payload: dict) -> dict:
        """就诊完成"""
        call = (await self.db.execute(
            select(M04CallRecord).where(
                M04CallRecord.registration_id == payload["registration_id"],
                M04CallRecord.call_date == date.today(),
                M04CallRecord.status == "IN_VISIT",
            )
        )).scalar_one_or_none()

        if not call:
            return {"updated": False}

        call.status = "COMPLETED"
        call.completed_at = datetime.now()

        if call.visit_start_at:
            call.visit_minutes = int(
                (call.completed_at - call.visit_start_at).total_seconds() / 60)

        await self.db.commit()

        return {"call_id": call.id, "updated": True,
                "status": "COMPLETED",
                "visit_minutes": call.visit_minutes}
```

```python
import hashlib

from typing import Optional

from app.core.config import settings

class TtsService:
    """语音合成（调 M21 或本地 TTS 引擎）"""

    CACHE_DIR = Path(settings.AUDIO_CACHE_DIR or "/tmp/m04_tts")

    @classmethod
    async def synthesize(cls, text: str) -> str:
        """合成语音，返回 URL"""
        cache_key = cls._cache_key(text)

        # 缓存命中
        exists = await redis_client.exists(f"m04:tts:{cache_key}")
        if exists:
            return f"/api/v1/m04/call/tts/{cache_key}"

        # 生成本地文件（或调 M21）
        cls.CACHE_DIR.mkdir(parents=True, exist_ok=True)
        file_path = cls.CACHE_DIR / f"{cache_key}.mp3"

        try:
            await cls._generate_audio(text, file_path)
            await redis_client.setex(f"m04:tts:{cache_key}", 86400, "1")
            return f"/api/v1/m04/call/tts/{cache_key}"
        except Exception:
            # 降级：返回空，由前端使用浏览器 TTS
            return ""

    @classmethod
    async def preview(cls, text: str) -> dict:
```

```python
                                 "call_id": call.id,

            except Exception:
                pass

        await db.commit()
        return {"passed": len(passed), "detail": passed}

    from datetime import date, timedelta
    from sqlalchemy import select, func
    from app.models.m04.call import M04CallRecord, M04CallStatistics
    from app.core.database import AsyncSessionLocal

    async with AsyncSessionLocal() as dbs:
```

**降级策略：**

| 依赖 | 故障时 |
|---|---|
| TTS 服务 | **静音降级**，屏显仍有 |
| 短信 | 跳过，屏显仍有 |
| WebSocket | 降级到 HTTP 轮询 |
| Redis | 直连 DB，屏显轮询 |

> **关键：** 叫号核心功能（屏显）不可降级；语音、短信可降级。
