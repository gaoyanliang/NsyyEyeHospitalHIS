## 1. 模块概述

### 1.1 模块定位

挂号是门诊业务的**起点**。它回答："**这个患者今天要看病，给他挂个号，收多少挂号费？**"

```
┌──────────────────────────────────────────────────────────────┐
│  M04-01 排班与号源（号源供给）                                 │
└────────────────────────┬─────────────────────────────────────┘
                         │ slot/reserve + confirm
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M04-03 挂号与退号（本文档）                                   │
│  选择号源 → 占用号源 → 生成挂号单 → 生成就诊号 → 收费           │
│                    ↓ 退号                                       │
│              释放号源 → 退费                                    │
└────────────────────────┬─────────────────────────────────────┘
                         ▼ 挂号成功
┌──────────────────────────────────────────────────────────────┐
│  M04-04 分诊 → M04-05 候诊叫号 → M07 医生站就诊                │
└──────────────────────────────────────────────────────────────┘
                         │
                         ▼ 挂号费
┌──────────────────────────────────────────────────────────────┐
│  M16 收费结算（价格、支付、发票、退费）                         │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 挂号 vs 预约 vs 收费（三者边界）

| 维度 | 预约（M04-02） | **挂号（M04-03）** | 收费（M16） |
|---|---|---|---|
| 时机 | 提前 | **当天** | 挂号后/就诊中 |
| 号源 | 占用 | **占用** | — |
| 收费 | 不收费 | **产生收费单** | **执行收费** |
| 就诊号 | — | **生成** | — |
| 取消 | 释放号源 | **退号（需退费）** | 退费单 |
| 主键 | `appt_no` | **`registration_no`** | `billing_no` |

> **一句话：** 挂号生成"就诊许可"，收费是"付钱"，两者解耦但必须配对——**挂号未收费不可就诊**（可配置）。

### 1.3 与相邻模块的分工

| 能力 | 归属 |
|---|---|
| 号源生成与库存 | M04-01 |
| 预约管理 | M04-02 |
| **现场挂号** | **M04-03 本子模块** |
| **预约转挂号** | **M04-03 本子模块**（M04-02 调用） |
| **退号** | **M04-03 本子模块** |
| **挂号单管理** | **M04-03 本子模块** |
| **就诊号生成** | **M04-03 本子模块** |
| **挂号费定价** | M16 |
| **收费、支付、发票** | M16 / M21 |
| **退费执行** | M16 |
| 分诊 | M04-04 |
| 叫号 | M04-05 |
| 特殊号（军残等） | M04-06 |
| 患者信息 | M03-01 |

> **边界一句话：** 本子模块只管"挂号这个动作的过程与结果"；**不做**号源生成（M04-01）、**不做**收费价格与支付（M16/M21）、**不做**分诊叫号（M04-04/05）。

### 1.4 模块目标

- **快速**：单次挂号 ≤ 30 秒（现场）。
- **准确**：号源、挂号、收费三者一一对应。
- **可退**：退号-退费联动，资金可追溯。
- **防重复**：同一患者同一班次不可重复挂号。
- **可追溯**：挂号全过程留痕。
- **多入口**：窗口、自助机、预约转、门户（预留）。

### 1.5 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 患者 | 挂号 | 自助机挂号 |
| 收费员 | 挂号收费 | 现场挂号、收费、退号 |
| 导医 | 协助 | 挂号、退号申请 |
| 财务 | 监督 | 退号退费审核 |
| 科室主任 | 管理 | 查看挂号量 |

## 3. 业务模型

### 3.1 挂号类型

| 类型 | 代码 | 说明 | 收费 |
|---|---|---|---|
| 普通挂号 | `NORMAL` | 现场挂号 | 按号别定价 |
| 预约挂号 | `APPOINTMENT` | 预约转挂号 | 按号别定价 |
| 急诊挂号 | `EMERGENCY` | 急诊通道 | 按号别定价 |
| 复诊挂号 | `FOLLOWUP` | 复诊患者（可免费） | 按配置 |
| 特殊号 | `SPECIAL` | 军残/老年等 | 免费或减免 |
| 补挂号 | `SUPPLEMENT` | 事后补录 | 按号别定价 |

### 3.2 挂号状态机

```
                    ┌──────────────┐
                    │   REGISTERED │  已挂号（待收费）
                    └──────┬───────┘
                           │
        ┌──────────────────┼──────────────────┐
        │ 支付成功           │ 免收费/挂账         │ 退号
        ▼                  ▼                  ▼
  ┌──────────┐      ┌──────────┐      ┌──────────┐
  │  PAID    │      │  WAIVED  │      │ REFUNDED │
  │ 已收费    │      │ 免收费    │      │ 已退号    │
  └────┬─────┘      └────┬─────┘      └──────────┘
       │                 │
       └────────┬────────┘
                │ 分诊/就诊
                ▼
        ┌──────────────┐
        │  VISITING    │  就诊中
        └──────┬───────┘
               │ 完成
               ▼
        ┌──────────────┐
        │  COMPLETED   │  已完成
        └──────────────┘
```

**状态说明：**

| 状态 | 说明 | 可退号 |
|---|---|---|
| `REGISTERED` | 已挂号，待收费 | ✅ |
| `PAID` | 已收费 | ✅（需退费审核） |
| `WAIVED` | 免收费（特殊号、复诊） | ✅ |
| `VISITING` | 正在就诊 | ❌（需医生确认） |
| `COMPLETED` | 就诊完成 | ❌ |
| `REFUNDED` | 已退号 | ❌ |
| `CANCELLED` | 已作废（异常数据） | ❌ |

### 3.3 就诊号模型

#### 3.3.1 两种编号

| 编号 | 说明 | 示例 | 用途 |
|---|---|---|---|
| **挂号单号** | 唯一凭证 | `RG2026102001234` | 财务凭证 |
| **就诊号** | 排队序号 | `10` | 分诊叫号 |
| **排队号** | 叫号屏显示 | `A010` | 患者可见 |

#### 3.3.2 就诊号生成规则

| 模式 | 说明 |
|---|---|
| **按班次** | 同一班次内顺序编号（1,2,3...） |
| **按科室** | 同一科室当天顺序编号 |
| **按时段** | 同一时段内顺序编号 |

**默认：按班次**（与号源 `slot_no` 一致）。

**队列号格式：** `{科室首字母}{3位序号}`，如 `A010`（A 为白内障科）。

### 3.4 挂号费定价模型

#### 3.4.1 定价来源

**定价归 M16**，本模块只查询与传递。

```
M04-03 挂号
   ↓ 查询
M16: GET /internal/v1/billing/reg-fee
   { dept_id, doctor_id, reg_type_code, patient_type, charge_type }
   ↓ 返回
   { fee: 50.00, fee_code: "REG_EXPERT", discount: 0 }
```

#### 3.4.2 影响因素

| 因素 | 影响 |
|---|---|
| 号别（普通/专家/特需） | 基础价格 |
| 医生职称 | 专家号价格 |
| 患者类型（普通/医保/会员） | 医保支付比例、会员折扣 |
| 时段（节假日/夜间） | 加价 |
| 特殊号 | 减免 |

### 3.5 收费模型

#### 3.5.1 收费时机

| 模式 | 说明 | 适用 |
|---|---|---|
| **先收费后就诊**（默认） | 挂号即收费 | 普通门诊 |
| **后收费** | 挂号后就诊，就诊中一并收费 | 急诊、绿色通道 |
| **免收费** | 特殊号、职工 | 特殊场景 |

**配置：** `M04.REG.CHARGE_MODE = BEFORE_VISIT`

#### 3.5.2 收费单结构

挂号产生的收费单（由 M16 创建）：

```
收费单 billing_no = BL2026102001234
  项目：
    ├─ 挂号费（REG_EXPERT）  ¥50.00
    └─ 诊查费（可选）        ¥10.00
  合计：¥60.00
  支付方式：微信/现金/医保
```

### 3.6 退号模型

#### 3.6.1 退号类型

| 类型 | 说明 | 退费 |
|---|---|---|
| **全额退号** | 未就诊，退全额 | 全额退 |
| **部分退号** | 已就诊部分（罕见） | 按比例 |
| **作废** | 数据错误（管理员） | 视情况 |

#### 3.6.2 退号规则

| 规则 | 说明 |
|---|---|
| 时间窗 | 就诊前可退；就诊后需医生确认 |
| 状态窗 | `REGISTERED`/`PAID`/`WAIVED` 可退 |
| 审核 | 已收费需财务审核（可配置） |
| 号源 | 退号后号源释放（可配置是否可再挂） |
| 退费 | 调 M16 退费，原路返回 |
| 预约关联 | 预约转挂号的退号，预约状态回退 |

#### 3.6.3 退号流程

```
退号申请
   ↓
校验（状态、时间、权限）
   ↓
需要审核？
   ├─ 是 → 提交审核 → 财务审批
   │                  ├─ 驳回 → 结束
   │                  └─ 通过 ↓
   └─ 否 ↓
执行退号
   ├─ 更新挂号单 status = REFUNDED
   ├─ 释放号源（M04-01）
   ├─ 退费（M16）
   ├─ 回退预约状态（M04-02）
   ├─ 从分诊队列移除（M04-04）
   └─ 通知患者（M03-05）
   ↓
记录 m04_reg_refund_log
```

### 3.8 挂号与预约的联动

| 场景 | 处理 |
|---|---|
| 预约已签到 → 转挂号 | 挂号单关联 `appt_id` |
| 挂号成功 | 更新 `m04_appointment.status = REGISTERED` |
| 退号（预约来源） | 预约状态回退到 `CHECKED_IN` 或 `CANCELLED` |
| 无预约直接挂号 | `appt_id = NULL` |

### 3.9 挂号费稽核

| 稽核项 | 说明 |
|---|---|
| 挂号单数 = 收费单数 | 除免收费外 |
| 收费金额 = 应收金额 | 差异告警 |
| 退号数 = 退费单数 | 除免收费外 |
| 号源占用数 = 挂号单数 | 防止号源与挂号不一致 |

        # 2. 患者校验
        patient = await self.mpi.get_patient(payload.patient_id)
        if not patient:
            raise BizException(54209, "患者不存在")

            payload.patient_id, payload.schedule_id, config)

            dept_id=schedule.dept_id,
            doctor_id=schedule.doctor_id,
            reg_type_code=schedule.reg_type_code,
            patient_id=payload.patient_id,
            reg_type=payload.reg_type,
        )

        # 7. 生成挂号单
        reg_no = self._gen_reg_no()
        visit_no = await self._gen_visit_no(schedule)
        queue_no = self._gen_queue_no(schedule.dept_id, visit_no)

        if payload.reg_type == "SPECIAL" or payload.charge_mode == "WAIVE":
            status = "WAIVED"

            registration_id=reg.id,

    async def _check_duplicate(self, patient_id: int, schedule_id: int,
                                 config: dict) -> None:
        """重复挂号校验"""
        if not config.get("check_duplicate", True):
            return

        existing = (await self.db.execute(
            select(M04Registration).where(
                M04Registration.patient_id == patient_id,
                M04Registration.schedule_id == schedule_id,
                M04Registration.status.notin_(
                    ("REFUNDED", "CANCELLED")),
            )
        )).scalar_one_or_none()

        if existing:
            raise BizException(54203, "该患者本班次已挂过号",
                data={
                    "existing_registration": {
                        "registration_no": existing.registration_no,
                        "visit_no": existing.visit_no,
                        "status_text": self._status_text(existing.status),
                        "reg_time": (existing.created_at.isoformat()
                                      if existing.created_at else None),
                    }
                })

        # 同日同科室校验
        if config.get("check_same_day_dept", False):
            same_dept = (await self.db.execute(
                select(M04Registration).where(
                    M04Registration.patient_id == patient_id,
                    M04Registration.registration_date == date.today(),
                    M04Registration.dept_id == (
                        select(M04Schedule.dept_id).where(
                            M04Schedule.id == schedule_id
                        ).scalar_subquery()),
                    M04Registration.status.notin_(
                        ("REFUNDED", "CANCELLED")),
                )
            )).scalar_one_or_none()

            if same_dept:
                raise BizException(54204, "该患者今日已在本院同科室挂号")

    # ---------- 稽核 ----------
    async def audit_check(self, audit_date: date) -> dict:
        """挂号费稽核"""
        # 挂号单统计
        reg_stats = (await self.db.execute(
            select(
                func.count().label("total"),
                func.count().filter(
                    M04Registration.status == "PAID").label("paid"),
                func.count().filter(
                    M04Registration.status == "WAIVED").label("waived"),
                func.count().filter(
                    M04Registration.status == "REFUNDED").label("refunded"),
                func.coalesce(
                    func.sum(M04Registration.paid_amount)
                    .filter(M04Registration.status == "PAID"), 0
                ).label("income"),
            ).where(
                M04Registration.registration_date == audit_date,
                M04Registration.is_deleted == False,
            )
        )).one()

        # 号源占用数
        slot_count = (await self.db.execute(
            select(func.count()).select_from(M04RegSlot).join(
                M04Schedule, M04RegSlot.schedule_id == M04Schedule.id
            ).where(
                M04Schedule.schedule_date == audit_date,
                M04RegSlot.biz_type == "REGISTRATION",
                M04RegSlot.status.in_(("BOOKED", "CHECKED_IN")),
            )
        )).scalar_one()

        items = []
        all_passed = True

        # 稽核项 1
        passed = reg_stats.total == slot_count
        items.append({
            "item": "挂号单数 = 号源占用数",
            "expected": reg_stats.total,
            "actual": slot_count,
            "diff": slot_count - reg_stats.total,
            "passed": passed,
        })
        if not passed:
            all_passed = False

        # 稽核项 2（不含免收费）
        paid_and_waived = reg_stats.paid + reg_stats.waived
        items.append({
            "item": "挂号单数 = 收费单数",
            "expected": paid_and_waived,
            "actual": reg_stats.paid,
            "diff": 0,
            "passed": True,
            "note": f"免收费 {reg_stats.waived} 单",
        })

        result = {
            "audit_date": audit_date.isoformat(),
            "audit_at": datetime.now().isoformat(),
            "result": "PASS" if all_passed else "FAILED",
            "items": items,
            "total_registrations": reg_stats.total,
            "total_paid": reg_stats.paid,
            "total_waived": reg_stats.waived,
            "total_refunded": reg_stats.refunded,
            "total_income": float(reg_stats.income or 0),
        }

        if not all_passed:
            raise BizException(54227, "稽核发现差异", data=result)

        return result

    async def _find_alternatives(self, schedule: M04Schedule) -> List[dict]:
        """找替代号源"""
        rows = (await self.db.execute(
            select(M04Schedule).where(
                M04Schedule.schedule_date == schedule.schedule_date,

    @staticmethod
    def _gen_reg_no() -> str:
        return f"RG{datetime.now().strftime('%Y%m%d')}{uuid.uuid4().hex[:6].upper()}"

    @staticmethod
    def _period_text(period: str) -> str:
        return {"AM": "上午", "PM": "下午", "NIGHT": "夜间",
                "ALL_DAY": "全天"}.get(period, period)

    @staticmethod
    def _period_range(schedule) -> str:
        period = {"AM": "上午", "PM": "下午", "NIGHT": "夜间",
                  "ALL_DAY": "全天"}.get(schedule.period, schedule.period)
        if schedule.start_time and schedule.end_time:
            return (f"{period} "
                    f"{schedule.start_time.strftime('%H:%M')}"
                    f"-{schedule.end_time.strftime('%H:%M')}")
        return period

        return {
            "REGISTERED": "已挂号（待收费）", "PAID": "已收费",
            "WAIVED": "免收费", "VISITING": "就诊中",
            "COMPLETED": "已完成", "REFUNDED": "已退号",
            "CANCELLED": "已作废",
        }.get(status, status)

    async def _get_config(self) -> dict:

# app/services/m04/refund_service.py
"""退号服务"""
import uuid
from datetime import datetime
from decimal import Decimal
from typing import Optional

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.m04.registration import (
    M04Registration, M04RefundRequest, M04RegLog, M04RegConfig,
)
from app.core.exceptions import BizException
from app.core.redis import redis_client
from app.clients.m04_client import M04InternalClient
from app.clients.m16_client import M16Client
from app.clients.mpi_message_client import MpiMessageClient


class RefundService:
    """退号与退费"""

    def __init__(self, db: AsyncSession):
        self.db = db
        self.m04 = M04InternalClient()
        self.m16 = M16Client()
        self.msg = MpiMessageClient()

    # ---------- 申请退号 ----------
    async def apply(self, reg_id: int, payload, user) -> dict:
        """申请退号"""
        reg = (await self.db.execute(
            select(M04Registration).where(
                M04Registration.id == reg_id,
                M04Registration.is_deleted == False,
            )
        )).scalar_one_or_none()

        if not reg:
            raise BizException(54201, "挂号单不存在")

        # 状态校验
        if reg.status in ("REFUNDED", "CANCELLED"):
            raise BizException(54202, "该挂号单已退号或作废")

        if reg.status == "VISITING":
            raise BizException(54221, "就诊已开始，需医生确认后方可退号")

        if reg.status == "COMPLETED":
            raise BizException(54222, "就诊已完成，无法退号")

        config = await self._get_config()

        if config.get("refund_before_visit_only", True) and \
                reg.status not in ("REGISTERED", "PAID", "WAIVED"):
            raise BizException(54215, "当前状态不允许退号")

        # 已有待审申请
        existing = (await self.db.execute(
            select(M04RefundRequest).where(
                M04RefundRequest.registration_id == reg_id,
                M04RefundRequest.audit_status == "PENDING",
            )
        )).scalar_one_or_none()

        if existing:
            raise BizException(54216, "该挂号单已有待审核的退号申请")

        # 计算退费金额
        refund_amount = (
            Decimal(str(payload.refund_amount))
            if payload.refund_amount is not None
            else reg.paid_amount or reg.total_amount or Decimal("0")
        )

        need_audit = (
            config.get("refund_need_audit", True)
            and reg.status == "PAID"
            and refund_amount > Decimal(str(config.get("refund_audit_threshold", 0)))
        )

        refund_no = f"RF{datetime.now().strftime('%Y%m%d')}{uuid.uuid4().hex[:6].upper()}"

        request = M04RefundRequest(
            request_no=f"RFQ{datetime.now().strftime('%Y%m%d%H%M%S')}",
            registration_id=reg.id,
            registration_no=reg.registration_no,
            patient_id=reg.patient_id,
            patient_name=reg.patient_name,
            refund_no=refund_no,
            refund_type=payload.refund_type,
            original_amount=reg.paid_amount or Decimal("0"),
            refund_amount=refund_amount,
            refund_method=payload.refund_method,
            release_slot=payload.release_slot,
            reason=payload.reason,
            remark=payload.remark,
            audit_status="PENDING" if need_audit else "APPROVED",
            apply_by=getattr(user, "id", None),
            apply_by_name=getattr(user, "name", None) or "系统",
        )
        self.db.add(request)
        await self.db.flush()

        if need_audit:
            # 待审核
            await self.db.commit()
            return {
                "registration_no": reg.registration_no,
                "refund_request_no": request.request_no,
                "status": "PENDING_AUDIT",
                "refund_amount": float(refund_amount),
                "need_audit": True,
                "audit_hint": "已收费退号需财务审核",
                "message": "退号申请已提交，等待财务审核",
            }

        # 无需审核，直接执行
        await self.db.commit()
        return await self._execute_refund(request, user)

    # ---------- 审核 ----------
    async def approve(self, request_id: int, user) -> dict:
        """审核通过"""
        request = await self._get_request(request_id)

        if request.audit_status != "PENDING":
            raise BizException(54217,
                f"当前审核状态 {request.audit_status} 不允许通过")

        request.audit_status = "APPROVED"
        request.audit_by = getattr(user, "id", None)
        request.audit_by_name = getattr(user, "name", None)
        request.audit_at = datetime.now()

        await self.db.commit()

        return await self._execute_refund(request, user)

    async def reject(self, request_id: int, reason: str, user) -> dict:
        """审核驳回"""
        if not reason or len(reason.strip()) < 2:
            raise BizException(40001, "驳回原因至少 2 个字")

        request = await self._get_request(request_id)

        if request.audit_status != "PENDING":
            raise BizException(54217,
                f"当前审核状态 {request.audit_status} 不允许驳回")

        request.audit_status = "REJECTED"
        request.audit_by = getattr(user, "id", None)
        request.audit_by_name = getattr(user, "name", None)
        request.audit_at = datetime.now()
        request.audit_remark = reason

        await self.db.commit()

        return {
            "request_no": request.request_no,
            "audit_status": "REJECTED",
            "reason": reason,
        }

    # ---------- 执行退号 ----------
    async def _execute_refund(self, request: M04RefundRequest,
                                user) -> dict:
        """执行退号 + 退费"""
        reg = (await self.db.execute(
            select(M04Registration).where(
                M04Registration.id == request.registration_id)
        )).scalar_one_or_none()

        if not reg:
            raise BizException(54201, "挂号单不存在")

        old_status = reg.status

        # 1. 退费（调 M16）
        billing_refund_no = None
        if reg.status == "PAID" and reg.billing_no and \
                request.refund_amount > Decimal("0"):
            try:
                result = await self.m16.refund(
                    billing_no=reg.billing_no,
                    refund_amount=float(request.refund_amount),
                    refund_method=request.refund_method,
                    reason=request.reason,
                )
                if result:
                    billing_refund_no = result.get("refund_no")
            except Exception as e:
                raise BizException(54219, f"退费失败：{str(e)[:100]}")

        # 2. 释放号源
        slot_released = False
        if request.release_slot:
            try:
                await self.m04.release_slot(
                    slot_id=reg.slot_id, reason="退号释放")
                slot_released = True
            except Exception:
                pass    # 释放失败不阻断退号

        # 3. 更新挂号单
        reg.status = "REFUNDED"
        reg.refunded_at = datetime.now()
        reg.refund_amount = request.refund_amount
        reg.refund_reason = request.reason
        reg.refund_no = request.refund_no

        # 4. 更新申请
        request.executed = True
        request.executed_at = datetime.now()
        request.billing_refund_no = billing_refund_no
        request.slot_released = slot_released

        # 5. 日志
        self.db.add(M04RegLog(
            registration_id=reg.id,
            registration_no=reg.registration_no,
            action="REFUND",
            before_json={"status": old_status},
            after_json={
                "status": "REFUNDED",
                "refund_amount": float(request.refund_amount),
            },
            reason=request.reason,
            operator_id=getattr(user, "id", None),
            operator_name=getattr(user, "name", None) or "系统",
        ))

        await self.db.commit()

        # 6. 联动
        await self._after_refund(reg, request)

        return {
            "registration_no": reg.registration_no,
            "refund_no": request.refund_no,
            "status": "REFUNDED",
            "refund_amount": float(request.refund_amount),
            "refund_method": request.refund_method,
            "slot_released": slot_released,
            "billing_refund_no": billing_refund_no,
            "refunded_at": reg.refunded_at.isoformat(),
            "need_audit": False,
        }

    async def _after_refund(self, reg, request) -> None:
        """退号后的联动"""
        # 1. 回退预约状态
        if reg.appt_id:
            from app.models.m04.appointment import M04Appointment
            appt = (await self.db.execute(
                select(M04Appointment).where(
                    M04Appointment.id == reg.appt_id)
            )).scalar_one_or_none()

            if appt and appt.status == "REGISTERED":
                appt.status = "CANCELLED"
                appt.cancel_reason = "挂号已退号"
                await self.db.commit()

        # 2. 从分诊队列移除
        try:
            await self.m04.notify_triage_removed(
                registration_id=reg.id)
        except Exception:
            pass

        # 3. 通知患者
        try:
            await self.msg.send(
                biz_type="REG_REFUNDED",
                receivers=[reg.patient_id],
                params={
                    "registration_no": reg.registration_no,
                    "refund_amount": float(request.refund_amount),
                    "refund_method": request.refund_method,
                })
        except Exception:
            pass

    async def _get_request(self, request_id: int) -> M04RefundRequest:
        request = (await self.db.execute(
            select(M04RefundRequest).where(
                M04RefundRequest.id == request_id)
        )).scalar_one_or_none()

        if not request:
            raise BizException(54218, "退号申请不存在")

        return request

    async def _get_config(self) -> dict:
        import json
        cached = await redis_client.get("m04:reg:config")
        if cached:
            return json.loads(cached)

        cfg = (await self.db.execute(
            select(M04RegConfig).where(M04RegConfig.id == 1)
        )).scalar_one_or_none()

        data = {
            "refund_need_audit": cfg.refund_need_audit if cfg else True,
            "refund_audit_threshold": (float(cfg.refund_audit_threshold)
                                        if cfg and cfg.refund_audit_threshold
                                        else 0),
            "refund_release_slot": cfg.refund_release_slot if cfg else True,
            "refund_before_visit_only": (cfg.refund_before_visit_only
                                           if cfg else True),
        }
        await redis_client.setex("m04:reg:config", 600, json.dumps(data))
        return data

async def _audit(audit_date: str = None):
    from datetime import date, timedelta
    from app.core.database import AsyncSessionLocal
    from app.services.m04.registration_service import RegistrationService
    from app.clients.mpi_message_client import MpiMessageClient

    """自动退号未收费挂号（挂号后超时未缴费）"""
    import asyncio
    return asyncio.run(_auto_refund())


async def _auto_refund():
    from datetime import datetime, timedelta
    from sqlalchemy import select
    from app.models.m04.registration import M04Registration, M04RegConfig
    from app.core.database import AsyncSessionLocal
    from app.clients.m04_client import M04InternalClient

    async with AsyncSessionLocal() as db:
        cfg = (await db.execute(
            select(M04RegConfig).where(M04RegConfig.id == 1)
        )).scalar_one_or_none()

        if not cfg or not cfg.auto_refund_unpaid:
            return {"skipped": True}

        timeout_min = cfg.unpaid_timeout_minutes or 30
        deadline = datetime.now() - timedelta(minutes=timeout_min)

        rows = (await db.execute(
            select(M04Registration).where(
                M04Registration.status == "REGISTERED",
                M04Registration.created_at <= deadline,
            )
        )).scalars().all()

        released = 0
        for reg in rows:
            reg.status = "CANCELLED"
            reg.cancel_reason = "超时未缴费自动作废"

            try:
                await M04InternalClient().release_slot(
                    slot_id=reg.slot_id, reason="超时未缴费")
                released += 1
            except Exception:
                pass

        await db.commit()
        return {"cancelled": len(rows), "released": released}

| 挂号异常 | 不存在、重复 | 54201~54204 |
| 号源异常 | 已占、无号 | 54205~54206 |
| 班次异常 | 停诊、过期 | 54207~54208 |
| 患者异常 | 不存在、黑名单 | 54209~54210 |
| 收费异常 | 定价失败、收费单失败 | 54211~54213 |
| 退号异常 | 状态不允许 | 54215~54222 |
| 稽核异常 | 差异 | 54227 |
| 系统异常 | DB 失败 | 50003 |

**降级策略：**

| 依赖 | 故障时 |
|---|---|
| M04-01 号源 | **拒绝挂号**（安全优先） |
| M03-01 患者 | 拒绝 |
| M16 定价 | 拒绝（无法确定金额） |
| M16 创建收费单 | 挂号成功但待收费 |
| M16 支付 | 挂号成功，待支付 |
| M16 退费 | **退号失败**（必须退费成功才能退号） |
| M04-04 分诊 | 挂号成功，分诊延后 |

> **关键：** 退号时**退费必须先成功**，否则退号不生效。避免"退了号但没退钱"。
