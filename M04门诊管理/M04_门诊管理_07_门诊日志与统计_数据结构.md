**设计说明：**

- `m04_clinic_log` 是**唯一事实源**，所有统计从这里聚合
- 日志**一挂号一行**（`registration_id` 唯一），冗余科室/医生/患者/金额
- `m04_daily_report` 只存**日粒度**，周/月/年实时聚合
- `m04_data_check` 与 `m04_check_rule` 分离：规则可配置，结果为记录
- `m04_export_task` 是异步导出任务状态表

**约束说明**

```sql
ALTER TABLE m04_clinic_log
    ADD CONSTRAINT ck_m04_log_no
    CHECK (log_no ~ '^CL[0-9]{8}[A-Z0-9]{4}$');

ALTER TABLE m04_clinic_log
    ADD CONSTRAINT ck_m04_log_status
    CHECK (status IN ('REGISTERED', 'IN_VISIT', 'COMPLETED',
                       'PASSED', 'NO_SHOW', 'REFUNDED'));

ALTER TABLE m04_clinic_log
    ADD CONSTRAINT ck_m04_log_level
    CHECK (triage_level IS NULL
           OR triage_level IN ('L1','L2','L3','L4','L5'));

-- 金额非负且逻辑自洽
ALTER TABLE m04_clinic_log
    ADD CONSTRAINT ck_m04_log_amount
    CHECK (reg_fee >= 0
       AND discount_fee >= 0
       AND actual_fee >= 0
       AND refund_fee >= 0
       AND discount_fee <= reg_fee);

-- 时长非负
ALTER TABLE m04_clinic_log
    ADD CONSTRAINT ck_m04_log_minutes
    CHECK (wait_minutes >= 0 AND visit_minutes >= 0);

-- 就诊完成必须有起止时间
ALTER TABLE m04_clinic_log
    ADD CONSTRAINT ck_m04_log_completed
    CHECK (status <> 'COMPLETED'
           OR (visit_start_at IS NOT NULL AND visit_end_at IS NOT NULL));

-- 已退号实收必须为 0
ALTER TABLE m04_clinic_log
    ADD CONSTRAINT ck_m04_log_refunded
    CHECK (status <> 'REFUNDED' OR actual_fee = 0);

-- 特殊号索引（部分索引，减少体积）
CREATE INDEX idx_m04_log_special
    ON m04_clinic_log (log_date, dept_id)
    WHERE is_special = TRUE;

-- 姓名模糊搜索
CREATE INDEX idx_m04_log_name
    ON m04_clinic_log USING gin (patient_name gin_trgm_ops);
```

**分区：** 按 `log_date` 年度 RANGE 分区；保留 **15 年**（医疗文书要求）。

**分区建表示例：**

```sql
CREATE TABLE m04_clinic_log (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY,
    log_no VARCHAR(32) NOT NULL,
    log_date DATE NOT NULL,
    -- 其余字段略
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (id, log_date)
) PARTITION BY RANGE (log_date);

CREATE TABLE m04_clinic_log_p2026 PARTITION OF m04_clinic_log
    FOR VALUES FROM ('2026-01-01') TO ('2027-01-01');

CREATE TABLE m04_clinic_log_p2027 PARTITION OF m04_clinic_log
    FOR VALUES FROM ('2027-01-01') TO ('2028-01-01');
```

> **注意：** 分区表的主键必须包含分区键（`log_date`），因此主键为 `(id, log_date)`。
> ORM 中仍以 `id` 作为业务主键，`log_date` 通过写入时保证一致。

**约束说明**

```sql
-- 三维度唯一（NULL 需特殊处理）
CREATE UNIQUE INDEX uk_m04_report
    ON m04_daily_report (
        report_date,
        COALESCE(dept_id, 0),
        COALESCE(doctor_id, 0)
    );

ALTER TABLE m04_daily_report
    ADD CONSTRAINT ck_m04_report_status
    CHECK (status IN ('PENDING', 'GENERATED', 'PARTIAL', 'FAILED'));

ALTER TABLE m04_daily_report
    ADD CONSTRAINT ck_m04_report_source
    CHECK (data_source IN ('FULL', 'PARTIAL'));

-- 医生维度必须指定科室与医生
ALTER TABLE m04_daily_report
    ADD CONSTRAINT ck_m04_report_dim
    CHECK (doctor_id IS NULL OR dept_id IS NOT NULL);

-- 人次逻辑自洽
ALTER TABLE m04_daily_report
    ADD CONSTRAINT ck_m04_report_counts
    CHECK (reg_count >= 0
       AND refund_count >= 0
       AND valid_reg_count = reg_count - refund_count
       AND visit_count >= 0
       AND patient_count >= 0
       AND patient_count <= visit_count
       AND passed_count >= 0);

-- 分诊级别合计 = 分诊人次
ALTER TABLE m04_daily_report
    ADD CONSTRAINT ck_m04_report_triage
    CHECK (l1_count + l2_count + l3_count + l4_count + l5_count
           = triage_count);

ALTER TABLE m04_daily_report
    ADD CONSTRAINT ck_m04_report_weekday
    CHECK (stat_weekday BETWEEN 1 AND 7);
```
