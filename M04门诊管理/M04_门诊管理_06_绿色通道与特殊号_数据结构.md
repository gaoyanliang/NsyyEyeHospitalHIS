**设计说明：**

- **配置类**：`m04_special_person_type`（人群类型）+ `m04_special_policy`（减免政策）通过 `person_type_code` 关联
- **凭证类**：`m04_special_cert` 是主体，`cert_no` 全局唯一（防冒用）
- **使用类**：`m04_special_usage` 记录每一次使用，支撑 `annual_used` 与减免统计
- **加号类**：`m04_add_quota_apply` + `m04_add_quota_approval` 实现多级审批
- **风控类**：`m04_special_blacklist` 与 `m04_special_spot_check`

**约束说明**

```sql
ALTER TABLE m04_special_policy
    ADD CONSTRAINT ck_m04_policy_discount
    CHECK (discount_type IN ('FREE', 'PERCENT', 'FIXED', 'FULL_FREE'));

-- 比例减免必须在 0~100 之间
ALTER TABLE m04_special_policy
    ADD CONSTRAINT ck_m04_policy_percent
    CHECK (discount_type <> 'PERCENT'
           OR (discount_value >= 0 AND discount_value <= 100));

-- 固定金额必须 ≥ 0
ALTER TABLE m04_special_policy
    ADD CONSTRAINT ck_m04_policy_fixed
    CHECK (discount_type <> 'FIXED' OR discount_value >= 0);

-- 减免范围至少选一项
ALTER TABLE m04_special_policy
    ADD CONSTRAINT ck_m04_policy_scope
    CHECK (scope_reg_fee OR scope_consult_fee OR scope_exam_fee
           OR scope_treat_fee OR scope_all);

ALTER TABLE m04_special_policy
    ADD CONSTRAINT ck_m04_policy_period
    CHECK (effective_to IS NULL OR effective_to >= effective_from);
```

**约束说明**

```sql
ALTER TABLE m04_special_cert
    ADD CONSTRAINT ck_m04_cert_status
    CHECK (status IN ('PENDING', 'VERIFIED', 'REJECTED',
                       'EXPIRED', 'REVOKED', 'USED'));

ALTER TABLE m04_special_cert
    ADD CONSTRAINT ck_m04_cert_verify_mode
    CHECK (verify_mode IS NULL OR verify_mode IN ('MANUAL', 'AUTO'));

ALTER TABLE m04_special_cert
    ADD CONSTRAINT ck_m04_cert_period
    CHECK (valid_to IS NULL OR valid_to >= valid_from);

ALTER TABLE m04_special_cert
    ADD CONSTRAINT ck_m04_cert_usage
    CHECK (annual_used >= 0
           AND (annual_limit IS NULL OR annual_limit > 0));

ALTER TABLE m04_special_cert
    ADD CONSTRAINT ck_m04_cert_flags
    CHECK (special_flags IS NULL
           OR special_flags ~ '^(GREEN_CHANNEL|VETERAN|ELDERLY|CHILD)'
              '(,(GREEN_CHANNEL|VETERAN|ELDERLY|CHILD))*$');

-- 已核验必须有核验时间
ALTER TABLE m04_special_cert
    ADD CONSTRAINT ck_m04_cert_verified
    CHECK (status <> 'VERIFIED'
           OR (verified_at IS NOT NULL AND verify_mode IS NOT NULL));

-- 已撤销必须有撤销原因
ALTER TABLE m04_special_cert
    ADD CONSTRAINT ck_m04_cert_revoked
    CHECK (status <> 'REVOKED' OR revoke_reason IS NOT NULL);

-- 核心：凭证号全局唯一（有效状态）
CREATE UNIQUE INDEX uk_m04_cert_no
    ON m04_special_cert (cert_no)
    WHERE status IN ('PENDING', 'VERIFIED') AND is_deleted = FALSE;

-- 核心：同患者同类型只能有一条有效凭证
CREATE UNIQUE INDEX uk_m04_cert_patient_type
    ON m04_special_cert (patient_id, person_type_code)
    WHERE status IN ('PENDING', 'VERIFIED') AND is_deleted = FALSE;
```

            parts.append("挂号费")
        if self.scope_consult_fee:
            parts.append("诊查费")
        if self.scope_exam_fee:
            parts.append("检查费")
        if self.scope_treat_fee:

                or self.scope_all):
            raise ValueError("减免范围至少选择一项")

            raise ValueError("固定金额减免必须大于 0")

        if self.effective_to and self.effective_to < self.effective_from:
            raise ValueError("失效日期不可早于生效日期")

        return self
