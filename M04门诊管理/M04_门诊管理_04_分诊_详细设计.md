## 1. 模块概述

### 1.1 模块定位

分诊是门诊流程的**调度中枢**。它回答："**这个患者该去哪个诊室、排在谁前面、谁先看？**"

```
┌──────────────────────────────────────────────────────────────┐
│  M04-03 挂号（患者已挂号、已收费）                              │
└────────────────────────┬─────────────────────────────────────┘
                         │ 挂号成功事件
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M04-04 分诊（本文档）                                         │
│  分诊登记 → 危重识别 → 诊室分配 → 优先级排序 → 入候诊队列       │
└────────────────────────┬─────────────────────────────────────┘
                         │ 队列就绪
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M04-05 叫号与候诊（叫号、过号、就诊）                          │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 分诊 vs 叫号（边界）

| 维度 | 分诊（本子模块） | 叫号（M04-05） |
|---|---|---|
| 触发 | 挂号后 | 医生呼叫 |
| 产出 | **分诊记录 + 队列位置** | **叫号记录 + 状态变化** |
| 决定 | 去哪个诊室、什么优先级 | 谁先被叫 |
| 状态 | `PENDING`→`TRIAGED` | `WAITING`→`CALLED`→`IN_VISIT` |
| 表 | `m04_triage_*` | `m04_queue_*` |

> **一句话：** 分诊决定"排哪个队"，叫号决定"队里谁先被叫"。

### 1.3 与相邻模块的分工

| 能力 | 归属 |
|---|---|
| 挂号 | M04-03 |
| **分诊登记** | **M04-04 本子模块** |
| **危重/急危识别** | **M04-04 本子模块** |
| **诊室分配** | **M04-04 本子模块** |
| **分诊优先级** | **M04-04 本子模块** |
| **候诊队列生成** | **M04-04 本子模块**（维护队列） |
| 叫号 | M04-05 |
| 绿色通道 / 特殊号 | M04-06（本模块消费其标记） |
| 医生站 | M07 |
| 生命体征采集 | M04-04（眼科简化：视力、眼压） |

> **边界一句话：** 本子模块只管"患者被分到哪、以什么优先级排队"；**不做**叫号与就诊（M04-05/M07）、**不做**特殊号审批（M04-06）。

### 1.4 眼科分诊的特殊性

| 特点 | 说明 |
|---|---|
| **急症识别** | 急性青光眼、眼外伤、视网膜动脉阻塞需**立即处置** |
| **视力骤降** | 是重要分诊依据 |
| **单侧/双侧** | 单眼急症也需优先 |
| **化学伤** | 需立即冲洗，最高优先级 |
| **儿童** | 配合度差，需单独考虑 |

**眼科分诊五级（参照预检分诊）：**

| 级别 | 名称 | 响应时间 | 示例 |
|---|---|---|---|
| **1 级** | 濒危 | 立即 | 化学伤、眼球穿孔伤、急性视力丧失 |
| **2 级** | 危重 | ≤10 分钟 | 急性闭角型青光眼发作、视网膜中央动脉阻塞 |
| **3 级** | 急症 | ≤30 分钟 | 眼外伤、急性结膜炎伴剧痛、新发闪光感 |
| **4 级** | 亚急症 | ≤60 分钟 | 视力渐进下降、慢性眼痛 |
| **5 级** | 非急症 | 按序 | 常规复查、验光配镜咨询 |

### 1.5 模块目标

- **安全**：危重患者不漏诊、不延误。
- **有序**：队列按优先级 + 时间排序，公平可解释。
- **高效**：分诊操作 ≤ 20 秒/人。
- **均衡**：诊室负载自动均衡。
- **可追溯**：每次分诊决定可查、可调。

### 1.6 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 导医/分诊护士 | 分诊 | 登记、评估、分诊、改分诊 |
| 护士长 | 管理 | 队列监控、调队列 |
| 医生 | 接诊 | 查看分诊信息 |
| 医务科 | 质量管理 | 分诊准确率、危重处置时效 |

## 3. 业务模型

### 3.1 分诊级别模型

#### 3.1.1 五级分诊

| 级别 | 代码 | 名称 | 响应时限 | 权重 | 颜色 |
|---|---|---|---|---|---|
| 1 | `L1` | 濒危 | 立即 | 1000 | 🔴 红 |
| 2 | `L2` | 危重 | ≤10 分钟 | 800 | 🟠 橙 |
| 3 | `L3` | 急症 | ≤30 分钟 | 600 | 🟡 黄 |
| 4 | `L4` | 亚急症 | ≤60 分钟 | 400 | 🟢 绿 |
| 5 | `L5` | 非急症 | 按序 | 200 | ⚪ 白 |

#### 3.1.2 眼科危重识别规则

| 症状/诊断 | 级别 | 说明 |
|---|---|---|
| 眼部化学伤 | **L1** | 立即冲洗 |
| 眼球穿孔伤 | **L1** | 立即处置 |
| 急性视力丧失（突发） | **L1** | 单侧或双侧 |
| 急性闭角型青光眼发作 | **L2** | 眼压极高、剧痛 |
| 视网膜中央动脉阻塞 | **L2** | 黄金 90 分钟 |
| 视网膜脱离（新发） | **L2** | — |
| 严重眼外伤（非穿孔） | **L3** | — |
| 急性结膜炎伴剧痛 | **L3** | — |
| 新发闪光感/飞蚊骤增 | **L3** | 疑似网脱先兆 |
| 眼压升高（>25mmHg） | **L4** | — |
| 视力渐进下降 | **L4** | — |
| 常规复查 | **L5** | — |
| 验光配镜咨询 | **L5** | — |

#### 3.1.3 分级覆盖

| 场景 | 强制级别 |
|---|---|
| 走绿色通道（M04-06） | ≥ L2 |
| 年龄 ≥ 80 岁 | 最低 L4 |
| 年龄 ≤ 3 岁 | 最低 L4 |
| 急诊挂号 | ≥ L2 |
| 特殊号（军残等） | 最低 L4 |

> **注意：** 覆盖只能**提升**级别（数字变小），不能降低。

### 3.2 分诊状态机

```
┌──────────────┐
│   PENDING    │  待分诊（挂号后自动创建）
└──────┬───────┘
       │ 分诊登记
       ▼
┌──────────────┐
│   TRIAGED    │  已分诊（已入队列）
└──────┬───────┘
       │
  ┌────┼──────────────┬──────────────┐
  │    │              │              │
  │改分诊│ 呼叫          │ 退号          │ 取消
  ▼    ▼              ▼              ▼
(更新) ┌──────────┐  ┌──────────┐  ┌──────────┐
       │ CALLED   │  │CANCELLED │  │CANCELLED │
       └────┬─────┘  └──────────┘  └──────────┘
            │
       ┌────┼──────────┐
       │    │          │
       │过号│ 就诊中    │ 拒绝就诊
       ▼    ▼          ▼
  ┌──────┐┌──────────┐┌──────────┐
  │PASSED││IN_VISIT  ││REFUSED   │
  └──────┘└────┬─────┘└──────────┘
               │ 完成
               ▼
          ┌──────────┐
          │ COMPLETED│
          └──────────┘
```

**状态说明：**

| 状态 | 说明 | 归属子模块 |
|---|---|---|
| `PENDING` | 待分诊 | M04-04 |
| `TRIAGED` | 已分诊，在队列中 | M04-04 / M04-05 |
| `CALLED` | 已呼叫 | M04-05 |
| `PASSED` | 过号 | M04-05 |
| `IN_VISIT` | 就诊中 | M04-05 / M07 |
| `COMPLETED` | 就诊完成 | M07 |
| `CANCELLED` | 已取消（退号） | M04-04 |
| `REFUSED` | 拒绝就诊 | M04-04 |

### 3.3 候诊队列模型

#### 3.3.1 队列维度

| 维度 | 说明 | 示例 |
|---|---|---|
| **按诊室** | 每个诊室一个队列 | 302 诊室队列 |
| **按医生** | 每个医生一个队列（可多诊室） | 张明华队列 |
| **按科室** | 科室级候诊区 | 白内障科候诊区 |

**默认：按诊室**（医生与诊室一一对应时等价）。

#### 3.3.2 队列排序规则

```
排序键 = (负优先级权重, 挂号/分诊时间, 序号)

优先级权重：
  L1 → 1000
  L2 → 800
  L3 → 600
  L4 → 400
  L5 → 200
  + 绿色通道加分 200
  + 老年/儿童加分 50

示例队列（按队列位置）：
  位1: L2 (800)  王五    09:15  ← 急性青光眼
  位2: L5 (200+200=400) 李四  09:10  ← 绿色通道
  位3: L4 (400+50=450) 赵六   09:20  ← 老年
  ...
```

**注意：** 排序先按**级别**，同级别按**时间**（先到先看），加分项**微调**同级别内位置。

#### 3.3.3 队列位置与预计等待

| 指标 | 计算方式 |
|---|---|
| 队列位置 | 排在前面的患者数 + 1 |
| 预计等待 | 前面患者数 × 平均就诊时长（默认 8 分钟） |
| 实际等待 | 当前时间 - 分诊时间 |

### 3.4 诊室分配模型

#### 3.4.1 分配策略

| 策略 | 说明 | 适用 |
|---|---|---|
| **按排班绑定** | 号源已绑定诊室，直接分配 | 默认 |
| **按医生** | 查医生当前诊室 | 医生换诊室时 |
| **按负载均衡** | 选队列最短的诊室 | 多诊室共享 |
| **按专科** | 按分诊级别分配到不同诊室 | 危重优先 |

**默认：按排班绑定**（`m04_schedule.room_no`）。

#### 3.4.2 诊室交换

```
同科室多诊室时：
  张明华 在 302 和 303 两个诊室
  ↓
  分诊时选择队列短的
```

### 3.5 分诊规则模型

#### 3.5.1 规则类型

| 类型 | 说明 | 示例 |
|---|---|---|
| `SYMPTOM` | 按主诉症状 | 主诉含"化学"→ L1 |
| `DIAGNOSIS` | 按既往诊断 | 诊断"闭角型青光眼"→ L2 |
| `VITAL` | 按生命体征 | 眼压 > 40 → L2 |
| `AGE` | 按年龄 | 年龄 ≥ 80 → 最低 L4 |
| `REG_TYPE` | 按挂号类型 | 急诊挂号 → L2 |
| `SPECIAL` | 按特殊号 | 绿色通道 → 最低 L2 |

#### 3.5.2 规则优先级

**多条规则命中时取最高级别（数字最小）；同级别取优先级最高的规则。**

### 3.6 生命体征采集（眼科简化）

| 项目 | 必填 | 说明 |
|---|---|---|
| 主诉 | ✅ | 自由文本 + 关键词标签 |
| 视力（右眼/左眼） | 可选 | 裸眼/矫正 |
| 眼压（右眼/左眼） | 可选 | mmHg |
| 血压 | 可选 | 老年患者建议采集 |
| 脉搏 | 可选 | — |
| 体温 | 可选 | — |

> **说明：** 眼科门诊生命体征**非强制**，但主诉必填（用于分诊分级）。

### 3.7 分诊到就诊的衔接

```
M04-04 分诊完成
   ↓ 状态 TRIAGED
   ↓ 在 m04_queue_entry 中生成队列条目
   ↓
M04-05 叫号
   ├─ 医生点"呼叫下一位"
   ├─ 队列取首位
   ├─ 状态 → CALLED
   └─ 屏显 + 语音
   ↓
M07 医生站
   ├─ 点"开始就诊"
   ├─ 状态 → IN_VISIT
   └─ M04-04 分诊记录同步更新
```

### 6.5 Service 层核心逻辑示例

```python
# app/services/m04/triage_service.py
"""分诊服务"""
import uuid
from datetime import date, datetime
from typing import Optional, List

from sqlalchemy import select, and_, func, desc
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.m04.triage import (
    M04Triage, M04TriageLog, M04TriageConfig,
    M04TriageRule, M04QueueEntry,
)
from app.models.m04.registration import M04Registration
from app.core.exceptions import BizException
from app.core.redis import redis_client
from app.clients.mpi_client import MpiClient


class TriageService:
    """分诊主流程"""

    LEVEL_WEIGHTS = {"L1": 1000, "L2": 800, "L3": 600, "L4": 400, "L5": 200}
    LEVEL_NAMES = {"L1": "濒危", "L2": "危重", "L3": "急症",
                    "L4": "亚急症", "L5": "非急症"}
    LEVEL_COLORS = {"L1": "RED", "L2": "ORANGE", "L3": "YELLOW",
                     "L4": "GREEN", "L5": "WHITE"}

    def __init__(self, db: AsyncSession):
        self.db = db
        self.mpi = MpiClient()

    # ---------- 执行分诊 ----------
    async def create(self, payload, user) -> dict:
        """执行分诊"""
        config = await self._get_config()

        # 1. 查挂号
        reg = (await self.db.execute(
            select(M04Registration).where(
                M04Registration.id == payload.registration_id,
                M04Registration.is_deleted == False,
            )
        )).scalar_one_or_none()

        if not reg:
            raise BizException(54201, "挂号单不存在")

        if reg.status in ("REFUNDED", "CANCELLED"):
            raise BizException("0404005", "该挂号单已退号或作废，不可分诊")

        if reg.status == "REGISTERED":
            raise BizException("0404004", "该挂号单尚未收费，请先完成收费",
                data={
                    "registration_no": reg.registration_no,
                    "fee": float(reg.total_amount or 0),
                    "charge_url": f"/api/v1/m04/registrations/{reg.id}/charge",
                })

        if reg.status == "COMPLETED":
            raise BizException("0404002", "该挂号单已完成就诊")

        # 2. 已分诊校验
        existing = (await self.db.execute(
            select(M04Triage).where(
                M04Triage.registration_id == reg.id,
                M04Triage.status.notin_(("CANCELLED", "COMPLETED")),
            )
        )).scalar_one_or_none()

        if existing:
            raise BizException("0404003", "该挂号单已分诊",
                data={"existing_triage": {
                    "triage_id": existing.id,
                    "room_no": existing.room_no,
                    "doctor_name": existing.doctor_name,
                    "triage_level": existing.triage_level,
                    "queue_position": existing.queue_position,
                }})

        # 3. 主诉校验
        if not payload.chief_complaint or \
                len(payload.chief_complaint.strip()) < 5:
            raise BizException("0404006", "主诉不能为空，且至少 5 个字")

        # 4. 级别校验与覆盖
        level = payload.triage_level
        if level not in self.LEVEL_WEIGHTS:
            raise BizException("0404007", f"分诊级别无效：{level}")

        level = await self._apply_level_override(
            level, reg, payload.special_flags or [], config)

        # 危重必须填原因
        if level in ("L1", "L2", "L3") and \
                not (payload.level_reason and
                     len(payload.level_reason.strip()) >= 2):
            raise BizException("0404008", "危重级别必须填写分级原因")

        # 5. 生命体征校验
        self._validate_vitals(payload.vital_signs)

        # 6. 诊室校验
        room = await self._get_room(payload.room_id, reg.dept_id)

        # 7. 创建分诊记录
        triage_no = f"TR{datetime.now().strftime('%Y%m%d')}" \
                    f"{uuid.uuid4().hex[:4].upper()}"

        triage = M04Triage(
            triage_no=triage_no,
            triage_date=date.today(),
            registration_id=reg.id,
            registration_no=reg.registration_no,
            patient_id=reg.patient_id,
            empi_no=reg.empi_no,
            patient_name=reg.patient_name,
            patient_gender=reg.patient_gender,
            patient_age=reg.patient_age,
            dept_id=reg.dept_id,
            dept_name=reg.dept_name,
            doctor_id=payload.doctor_id or reg.doctor_id,
            doctor_name=reg.doctor_name,
            room_id=payload.room_id,
            room_no=room.room_no,
            chief_complaint=payload.chief_complaint,
            symptom_tags=",".join(payload.symptom_tags or []),
            vital_signs=payload.vital_signs,
            special_flags=",".join(payload.special_flags or []),
            triage_level=level,
            triage_level_text=self.LEVEL_NAMES[level],
            level_color=self.LEVEL_COLORS[level],
            level_weight=self.LEVEL_WEIGHTS[level],
            level_reason=payload.level_reason,
            ai_suggested_level=payload.ai_suggested_level,
            accept_ai_suggestion=payload.accept_ai_suggestion,
            response_limit_minutes=self._response_limit(level, config),
            status="TRIAGED",
            triaged_at=datetime.now(),
            triaged_by=getattr(user, "id", None),
            triaged_by_name=getattr(user, "name", None),
        )
        self.db.add(triage)
        await self.db.flush()

        # 8. 入队列
        queue_entry = await self._enqueue(triage, config)

        # 9. 更新分诊记录的队列信息
        triage.queue_entry_id = queue_entry.id
        triage.queue_position = queue_entry.position
        triage.queue_no = queue_entry.queue_no
        triage.estimated_wait_minutes = queue_entry.estimated_wait_minutes

        # 10. 日志
        self.db.add(M04TriageLog(
            triage_id=triage.id,
            triage_no=triage_no,
            action="TRIAGE",
            after_json={
                "level": level,
                "room_id": payload.room_id,
                "queue_position": queue_entry.position,
            },
            operator_id=getattr(user, "id", None),
            operator_name=getattr(user, "name", None),
        ))

        await self.db.commit()

        return {
            "triage_id": triage.id,
            "triage_no": triage_no,
            "registration_no": reg.registration_no,
            "patient_name": reg.patient_name,
            "triage_level": level,
            "triage_level_text": self.LEVEL_NAMES[level],
            "level_color": self.LEVEL_COLORS[level],
            "level_reason": payload.level_reason,
            "response_limit_minutes": triage.response_limit_minutes,
            "room_id": room.id,
            "room_no": room.room_no,
            "doctor_name": reg.doctor_name,
            "queue_position": queue_entry.position,
            "queue_no": queue_entry.queue_no,
            "waiting_ahead": max(0, queue_entry.position - 1),
            "estimated_wait_minutes": queue_entry.estimated_wait_minutes,
            "queue_entry_id": queue_entry.id,
            "status": "TRIAGED",
            "status_text": "已分诊",
            "is_critical": level in ("L1", "L2"),
            "actions": self._critical_actions(level),
            "triage_at": triage.triaged_at.isoformat(),
        }

    async def _apply_level_override(self, level: str, reg,
                                      special_flags: List[str],
                                      config: dict) -> str:
        """应用级别覆盖（只能提升）"""
        override = level

        # 绿色通道
        if "GREEN_CHANNEL" in special_flags:
            override = self._max_level(override, "L2")

        # 急诊挂号
        if reg.reg_type == "EMERGENCY":
            override = self._max_level(override, "L2")

        # 高龄
        age = reg.patient_age or 0
        if age >= config.get("elderly_age", 80):
            override = self._max_level(override, "L4")

        # 儿童
        if 0 < age <= config.get("child_age", 3):
            override = self._max_level(override, "L4")

        # 军残优抚
        if "VETERAN" in special_flags:
            override = self._max_level(override, "L4")

        return override

    @staticmethod
    def _max_level(a: str, b: str) -> str:
        """取更紧急的级别（数字小的）"""
        order = {"L1": 1, "L2": 2, "L3": 3, "L4": 4, "L5": 5}
        return a if order[a] <= order[b] else b

    def _validate_vitals(self, vitals: Optional[dict]) -> None:
        """生命体征校验"""
        if not vitals:
            return

        for key in ("iop_right", "iop_left"):
            v = vitals.get(key)
            if v is not None and not (3 <= float(v) <= 80):
                raise BizException("0404026",
                    f"眼压 {key} 超出合理范围（3~80 mmHg）")

        for key in ("vision_right", "vision_left"):
            v = vitals.get(key)
            if v is not None and not (0 <= float(v) <= 2.0):
                raise BizException("0404026",
                    f"视力 {key} 超出合理范围（0~2.0）")

        for key in ("bp_systolic", "bp_diastolic"):
            v = vitals.get(key)
            if v is not None and not (30 <= float(v) <= 300):
                raise BizException("0404026", f"血压 {key} 超出合理范围")

        t = vitals.get("temperature")
        if t is not None and not (30 <= float(t) <= 45):
            raise BizException("0404026", "体温超出合理范围（30~45℃）")

    async def _get_room(self, room_id: int, dept_id: int):
        """校验诊室"""
        from app.models.m04.triage import M04TriageRoom

        room = (await self.db.execute(
            select(M04TriageRoom).where(
                M04TriageRoom.id == room_id,
                M04TriageRoom.is_deleted == False,
            )
        )).scalar_one_or_none()

        if not room:
            raise BizException("0404009", "目标诊室不存在")

        if not room.is_enabled:
            raise BizException("0404009", "目标诊室已停用")

        if room.dept_id != dept_id:
            raise BizException("0404010", "目标诊室与科室不匹配")

        return room

    async def _enqueue(self, triage: M04Triage,
                         config: dict) -> M04QueueEntry:
        """入队列并计算位置"""
        # 当前诊室队列
        entries = (await self.db.execute(
            select(M04QueueEntry).where(
                M04QueueEntry.room_id == triage.room_id,
                M04QueueEntry.status == "WAITING",
                M04QueueEntry.queue_date == date.today(),
            ).order_by(
                M04QueueEntry.priority_weight.desc(),
                M04QueueEntry.triaged_at.asc(),
            )
        )).scalars().all()

        # 计算加分
        bonus = await self._calc_bonus(triage, config)
        weight = (triage.level_weight or 0) + bonus

        # 计算插入位置
        position = 1
        for e in entries:
            e_weight = e.priority_weight or 0
            if e_weight > weight:
                position += 1
            elif e_weight == weight and e.triaged_at <= triage.triaged_at:
                position += 1

        avg_minutes = config.get("avg_visit_minutes", 8)
        estimated = max(0, (position - 1) * avg_minutes)

        # 队列号
        seq = (await self.db.execute(
            select(func.count()).select_from(M04QueueEntry).where(
                M04QueueEntry.room_id == triage.room_id,
                M04QueueEntry.queue_date == date.today(),
            )
        )).scalar_one() + 1

        queue_no = f"{triage.room_no or 'X'}-{seq:03d}"

        entry = M04QueueEntry(
            queue_date=date.today(),
            triage_id=triage.id,
            registration_id=triage.registration_id,
            patient_id=triage.patient_id,
            patient_name=triage.patient_name,
            dept_id=triage.dept_id,
            doctor_id=triage.doctor_id,
            room_id=triage.room_id,
            room_no=triage.room_no,
            queue_no=queue_no,
            triage_level=triage.triage_level,
            priority_weight=weight,
            bonus_weight=bonus,
            position=position,
            estimated_wait_minutes=estimated,
            status="WAITING",
            triaged_at=triage.triaged_at,
        )
        self.db.add(entry)
        await self.db.flush()

        # 后续条目位置 +1
        for e in entries[position - 1:]:
            e.position = (e.position or 0) + 1

        return entry

    async def _calc_bonus(self, triage: M04Triage, config: dict) -> int:
        """计算加分"""
        bonus = 0
        flags = (triage.special_flags or "").split(",")

        if "GREEN_CHANNEL" in flags:
            bonus += config.get("bonus_green_channel", 200)
        if "VETERAN" in flags:
            bonus += config.get("bonus_veteran", 100)

        age = triage.patient_age or 0
        if age >= config.get("elderly_age", 80):
            bonus += config.get("bonus_elderly", 50)
        if 0 < age <= config.get("child_age", 3):
            bonus += config.get("bonus_child", 50)

        return bonus

    def _response_limit(self, level: str, config: dict) -> int:
        """响应时限（分钟）"""
        return {
            "L1": config.get("limit_l1", 0),
            "L2": config.get("limit_l2", 10),
            "L3": config.get("limit_l3", 30),
            "L4": config.get("limit_l4", 60),
            "L5": config.get("limit_l5", 120),
        }.get(level, 120)

    def _critical_actions(self, level: str) -> List[str]:
        if level == "L1":
            return ["CALL_IMMEDIATELY", "NOTIFY_DOCTOR", "NOTIFY_DIRECTOR"]
        if level == "L2":
            return ["CALL_NOW", "NOTIFY_DOCTOR"]
        if level == "L3":
            return ["PRIORITIZE"]
        return []

    # ---------- AI 建议 ----------
    async def suggest_level(self, payload) -> dict:
        """AI 分级建议（规则引擎）"""
        rules = (await self.db.execute(
            select(M04TriageRule).where(
                M04TriageRule.is_enabled == True,
                M04TriageRule.is_deleted == False,
            ).order_by(M04TriageRule.priority.desc())
        )).scalars().all()

        chief = (payload.chief_complaint or "").lower()
        tags = set(payload.symptom_tags or [])
        vitals = payload.vital_signs or {}

        matched = []
        best_level = None

        for rule in rules:
            if not rule.matches_context(
                    chief, tags, vitals, payload.patient_age,
                    payload.reg_type):
                continue

            matched.append({
                "rule_code": rule.rule_code,
                "rule_name": rule.rule_name,
                "level": rule.suggested_level,
                "matched_keywords": rule.get_matched_keywords(chief, tags),
                "matched_value": rule.get_matched_value(vitals),
            })

            if best_level is None or \
                    self._max_level(best_level, rule.suggested_level) == \
                    rule.suggested_level:
                best_level = rule.suggested_level

        if not best_level:
            best_level = "L5"

        confidence = min(0.99, 0.6 + len(matched) * 0.1)

        return {
            "suggested_level": best_level,
            "suggested_level_text": self.LEVEL_NAMES[best_level],
            "confidence": round(confidence, 2),
            "response_limit_minutes": self._response_limit(best_level, {}),
            "matched_rules": matched,
            "reasoning": self._build_reasoning(matched, vitals),
            "suggested_actions": self._critical_actions(best_level),
            "alternative_levels": [],
        }

    def _build_reasoning(self, matched: List[dict], vitals: dict) -> str:
        if not matched:
            return "未匹配到特定规则，建议按普通门诊顺序就诊"

        parts = []
        for m in matched:
            parts.append(f"{m['rule_name']}（{m['level']}）")

        return "；".join(parts) + "。建议优先处置。"

    # ---------- 改分诊 ----------
    async def re_triage(self, triage_id: int, payload, user) -> dict:
        """改分诊"""
        triage = await self._get_triage(triage_id)

        if triage.status not in ("TRIAGED", "PENDING"):

                f"当前状态 {triage.status_label()} 不可改分诊")

        before = {
            "room_id": triage.room_id,
            "doctor_id": triage.doctor_id,
            "triage_level": triage.triage_level,
        }

        # 跨科室校验
        if payload.change_type == "CHANGE_DEPT" and \
                payload.new_dept_id and payload.new_dept_id != triage.dept_id:
            # 需管理员权限（在 API 层通过权限区分）

            triage.dept_id = payload.new_dept_id
            # 重新获取诊室

        # 更新
        if payload.new_room_id:
            room = await self._get_room(payload.new_room_id, triage.dept_id)
            triage.room_id = room.id
            triage.room_no = room.room_no

        if payload.new_doctor_id:
            triage.doctor_id = payload.new_doctor_id

        if payload.new_level:
            triage.triage_level = payload.new_level
            triage.triage_level_text = self.LEVEL_NAMES[payload.new_level]
            triage.level_color = self.LEVEL_COLORS[payload.new_level]
            triage.level_weight = self.LEVEL_WEIGHTS[payload.new_level]

        # 重新入队：先移除旧条目
        await self.db.execute(
            M04QueueEntry.__table__.update()
            .where(
                M04QueueEntry.triage_id == triage.id,
                M04QueueEntry.status == "WAITING",
            )
            .values(status="CANCELLED")
        )

        config = await self._get_config()
        new_entry = await self._enqueue(triage, config)

        triage.queue_entry_id = new_entry.id
        triage.queue_position = new_entry.position
        triage.queue_no = new_entry.queue_no
        triage.estimated_wait_minutes = new_entry.estimated_wait_minutes

        self.db.add(M04TriageLog(
            triage_id=triage.id,
            triage_no=triage.triage_no,
            action="RE_TRIAGE",
            before_json=before,
            after_json={
                "room_id": triage.room_id,
                "doctor_id": triage.doctor_id,
                "triage_level": triage.triage_level,
            },
            reason=payload.reason,
            operator_id=getattr(user, "id", None),
            operator_name=getattr(user, "name", None),
        ))

        await self.db.commit()

        return {
            "triage_id": triage.id,
            "triage_no": triage.triage_no,
            "new_room_no": triage.room_no,
            "new_doctor_name": triage.doctor_name,
            "triage_level": triage.triage_level,
            "queue_position": new_entry.position,
            "queue_no": new_entry.queue_no,
            "estimated_wait_minutes": new_entry.estimated_wait_minutes,
            "need_notify_patient": True,
```

```python
            if busiest["waiting_count"] - idlest["waiting_count"] >= 3:

    async def get_room_queue(self, room_id: int) -> dict:

            select(M04QueueEntry).where(

                M04QueueEntry.queue_date == date.today(),
                M04QueueEntry.status.in_(("WAITING", "CALLED")),

                M04QueueEntry.priority_weight.desc(),
                M04QueueEntry.triaged_at.asc(),

    async def balance(self, payload, user) -> dict:
        """一键分流"""
        from_room = payload.from_room_id
        to_room = payload.to_room_id
        count = payload.move_count or 1

        if from_room == to_room:
            raise BizException("0404015", "源诊室与目标诊室相同")

        # 取源诊室末尾的 N 个（优先级最低的）
        entries = (await self.db.execute(
            select(M04QueueEntry).where(
                M04QueueEntry.room_id == from_room,
                M04QueueEntry.queue_date == date.today(),
                M04QueueEntry.status == "WAITING",
            ).order_by(
                M04QueueEntry.priority_weight.asc(),
                M04QueueEntry.triaged_at.desc(),
            ).limit(count)
        )).scalars().all()

        if not entries:
            raise BizException("0404014", "源诊室无候诊患者")

        target_room = (await self.db.execute(
            select(M04TriageRoom).where(M04TriageRoom.id == to_room)
        )).scalar_one_or_none()

        if not target_room:
            raise BizException("0404009", "目标诊室不存在")

        moved = []
        for e in entries:
            e.room_id = to_room
            e.room_no = target_room.room_no
            e.position = None    # 重新计算
            moved.append({
                "queue_entry_id": e.id,
                "patient_name": e.patient_name,
                "queue_no": e.queue_no,
            })

        await self.db.commit()

        return {
            "from_room_id": from_room,
            "to_room_id": to_room,
            "moved_count": len(moved),
            "moved": moved,
            "need_notify_patients": True,
        }
```

```python
                )
            )).scalars().all()

            now = datetime.now()
            overdue = []

            for t in rows:
                if t.is_overdue:
                    continue
                if not t.triaged_at:
                    continue

                limit = limits.get(t.triage_level, 60)
                elapsed = (now - t.triaged_at).total_seconds() / 60

                if elapsed > limit:
                    t.is_overdue = True
                    t.overdue_minutes = int(elapsed - limit)
                    overdue.append({
                        "triage_id": t.id,
                        "patient_name": t.patient_name,
                        "triage_level": t.triage_level,
                        "overdue_minutes": t.overdue_minutes,
                    })

            await db.commit()

            if overdue:
                await MpiMessageClient().send(
                    biz_type="TRIAGE_OVERDUE_ALERT",
                    receivers=[],
                    params={"count": len(overdue), "items": overdue})

            return {"checked": len(rows), "overdue": len(overdue),
                    "detail": overdue}
    finally:
        await redis_client.delete("m04:triage:overdue:lock")


@shared_task
def aggregate_triage_stats_task(stat_date: str = None):
    """分诊统计聚合（每日）"""
    import asyncio
    return asyncio.run(_aggregate(stat_date))


async def _aggregate(stat_date: str = None):
    from datetime import date, datetime, timedelta
    from sqlalchemy import select, func
    from app.models.m04.triage import M04Triage, M04TriageStatistics
    from app.core.database import AsyncSessionLocal

    async with AsyncSessionLocal() as db:
        d = date.fromisoformat(stat_date) if stat_date else \
            (date.today() - timedelta(days=1))

        # 按科室聚合
        rows = (await db.execute(
            select(
                M04Triage.dept_id,
                func.count().label("total"),
                func.count().filter(
                    M04Triage.triage_level == "L1").label("l1"),
                func.count().filter(
                    M04Triage.triage_level == "L2").label("l2"),
                func.count().filter(
                    M04Triage.triage_level == "L3").label("l3"),
                func.count().filter(
                    M04Triage.triage_level == "L4").label("l4"),
                func.count().filter(
                    M04Triage.triage_level == "L5").label("l5"),
                func.count().filter(
                    M04Triage.is_overdue == True).label("overdue"),
            ).where(
                M04Triage.triage_date == d,
            ).group_by(M04Triage.dept_id)
        )).all()

        saved = 0
        for r in rows:
            stat = M04TriageStatistics(
                stat_date=d,
                dept_id=r.dept_id,
                total_count=r.total,
                l1_count=r.l1,
                l2_count=r.l2,
                l3_count=r.l3,
                l4_count=r.l4,
                l5_count=r.l5,
                overdue_count=r.overdue,
            )
            db.add(stat)
            saved += 1

        await db.commit()
        return {"date": d.isoformat(), "records": saved}
```
