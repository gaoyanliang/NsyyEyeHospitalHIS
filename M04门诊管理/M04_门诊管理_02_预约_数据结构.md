**设计说明：**

- `m04_appointment` 是预约主体，一条记录对应一个号源（`slot_id`）
- **改约不新增记录**，而是更新原记录 + `reschedule_count + 1` + 记录变更日志
- `m04_appt_credit` 是患者级信用分，全局唯一（一人一分）
- `m04_appt_reminder` 是提醒计划表，由定时任务消费
- `m04_appt_suspend_handle` 是停诊产生的人工待办

**约束说明**

```sql
ALTER TABLE m04_appointment
    ADD CONSTRAINT ck_m04_appt_no
    CHECK (appt_no ~ '^AP[0-9]{8}[A-Z0-9]{6}$');

ALTER TABLE m04_appointment
    ADD CONSTRAINT ck_m04_appt_period
    CHECK (period IN ('AM', 'PM', 'NIGHT', 'ALL_DAY'));

ALTER TABLE m04_appointment
    ADD CONSTRAINT ck_m04_appt_status
    CHECK (status IN ('PENDING', 'BOOKED', 'CHECKED_IN', 'REGISTERED',
                       'NO_SHOW', 'CANCELLED', 'CHANGED', 'EXPIRED',
                       'SUSPENDED'));

ALTER TABLE m04_appointment
    ADD CONSTRAINT ck_m04_appt_source
    CHECK (source IN ('PORTAL', 'KIOSK', 'WINDOW', 'PHONE',
                       'DOCTOR', 'IMPORT'));

ALTER TABLE m04_appointment
    ADD CONSTRAINT ck_m04_appt_reschedule
    CHECK (reschedule_count >= 0 AND reschedule_count <= 10);

ALTER TABLE m04_appointment
    ADD CONSTRAINT ck_m04_appt_weekday
    CHECK (weekday IS NULL OR weekday BETWEEN 1 AND 7);

-- 一个号源只能被一个有效预约占用
CREATE UNIQUE INDEX uk_m04_appt_slot_active
    ON m04_appointment (slot_id)
    WHERE status IN ('PENDING', 'BOOKED', 'CHECKED_IN', 'REGISTERED')
      AND is_deleted = FALSE;
```

**状态机**

```
                     ┌──────────────┐
                     │   PENDING    │
                     └──────┬───────┘
                            │
           ┌────────────────┼────────────────┐
           │ confirm        │ cancel/expire  │
           ▼                ▼                ▼
     ┌──────────┐    ┌───────────┐    ┌──────────┐
     │  BOOKED  │    │ CANCELLED │    │ EXPIRED  │
     └────┬─────┘    └───────────┘    └──────────┘
          │
     ┌────┼────────────────┬──────────────┐
     │    │                │              │
     │改约 │ 签到            │ 爽约          │ 停诊
     ▼    ▼                ▼              ▼
  (更新) ┌────────────┐  ┌──────────┐  ┌───────────┐
         │ CHECKED_IN │  │ NO_SHOW  │  │ SUSPENDED │
         └─────┬──────┘  └──────────┘  └─────┬─────┘
               │                             │
               │ 转挂号                       │ 改约/退号
               ▼                             ▼
         ┌────────────┐                ┌────────────┐
         │ REGISTERED │                │ CANCELLED  │
         └────────────┘                │ 或改约成功  │
                                       └────────────┘
```

> **注意：** 状态枚举保留了 `CHANGED`，但本期实现采用"改约更新原记录"策略（不新建记录），`CHANGED` 仅在需要保留历史时使用。

**量级估算：**

| 项 | 数值 |
|---|---|
| 日预约量 | ≈300 条 |
| 年预约量 | ≈11 万条 |
| 单行大小 | ≈600 B |
| 年存储 | ≈66 MB |

**分区：** 按年或暂不分区（11 万/年可接受）。若超过 50 万/年，建议按 `appointment_date` 年度分区。

| 0~59 | `BLOCKED` | 过低，需人工审核 |
