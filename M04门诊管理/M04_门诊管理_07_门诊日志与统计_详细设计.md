## 1. 模块概述

### 1.1 模块定位

门诊日志与统计是 M04 的**收官环节**。它回答："**今天门诊发生了什么？谁干了多少活？数据对得上吗？**"

```
┌──────────────────────────────────────────────────────────────┐
│  M04-01 排班号源  M04-02 预约   M04-03 挂号退号                │
│  M04-04 分诊      M04-05 叫号   M04-06 绿色通道                │
└────────────────────────┬─────────────────────────────────────┘
                         │ 业务流水
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M04-07 门诊日志与统计（本文档）                               │
│  · 门诊日志（每患者每就诊一行）                                 │
│  · 工作日报（每日汇总）                                         │
│  · 工作量统计（科室 / 医生）                                    │
│  · 数据核对（挂号 = 收费 = 台账）                               │
└────────────────────────┬─────────────────────────────────────┘
                         │
        ┌────────────────┼────────────────┐
        ▼                ▼                ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ M17 报表中心  │ │ M16 财务对账  │ │ 卫健委上报    │
└──────────────┘ └──────────────┘ └──────────────┘
```

### 1.2 为什么统计要独立成子模块

| 理由 | 说明 |
|---|---|
| **性能隔离** | 统计查询重，不能与业务库争抢资源 |
| **口径统一** | 门诊量、人次、人数的口径必须唯一 |
| **财务对账** | 挂号数与收费数必须可核对 |
| **上报合规** | 卫健委要求特定格式的门诊统计 |
| **历史留存** | 日志需长期保存（≥15 年） |
| **多层汇总** | 日 → 月 → 年，科室 → 全院 |

### 1.3 与相邻模块的分工

| 能力 | 归属 |
|---|---|
| 挂号/退号业务 | M04-03 |
| 分诊/叫号业务 | M04-04 / M04-05 |
| **门诊日志生成** | **M04-07 本子模块** |
| **工作日报** | **M04-07 本子模块** |
| **科室/医生工作量统计** | **M04-07 本子模块** |
| **数据核对（日结核对）** | **M04-07 本子模块** |
| 门诊病历内容 | M07 / M18 |
| 收费与收入统计 | M16 |
| 综合报表与 BI | M17 |
| 医保结算统计 | M15 |

> **边界一句话：** 本子模块只做**门诊业务数据**的汇总与核对；**不做**病历内容（M07/M18）、**不做**收入财务（M16）、**不做**综合报表（M17）。

### 1.4 核心指标口径（最关键）

> 口径不统一是 HIS 统计最大的坑。本节定义**院内唯一口径**，全系统必须引用。

#### 1.4.1 门诊量指标

| 指标 | 定义 | 说明 |
|---|---|---|
| **挂号人次** | 当日挂出的号数（含退号前的） | 不含退号 |
| **退号人次** | 当日退号的号数 | — |
| **有效挂号人次** | 挂号人次 - 退号人次 | **最常用于门诊量** |
| **就诊人次** | 实际开始就诊的人次 | 状态 ≥ IN_VISIT |
| **就诊人数** | 去重后的患者数（同一患者当日多次就诊算 1 人） | **人数 ≤ 人次** |
| **过号人次** | 叫号后未就诊的人次 | — |
| **爽约人次** | 预约后未到院的人次 | 归 M04-02 |

#### 1.4.2 关键区别

```
人次 vs 人数：
  患者张明上午看白内障、下午看眼底病 → 2 人次、1 人数

有效挂号 vs 就诊：
  挂号后没来 / 过号 → 计入有效挂号，不计入就诊
```

#### 1.4.3 时间口径

| 口径 | 说明 | 用途 |
|---|---|---|
| **挂号时间** | `registration_time` | 挂号量统计 |
| **就诊时间** | `visit_start_at` | 就诊量统计 |
| **结账时间** | M16 `settle_time` | 财务对账 |
| **统计日期** | 默认按**就诊时间**归日 | 卫健委上报口径 |

> **可配置：** `M04.STAT.DATE_BASIS = VISIT_DATE / REG_DATE`，默认 `VISIT_DATE`。

### 1.5 模块目标

- **口径唯一**：全院一套口径，可解释。
- **准确**：日结核对零差异（或差异可解释）。
- **及时**：日报次日 01:00 自动生成。
- **可追溯**：任何数字可下钻到原始记录。
- **合规**：满足卫健委上报要求。
- **留存**：日志保存 ≥15 年。

### 1.6 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 门诊部主任 | 管理 | 看日报、科室工作量 |
| 科主任 | 科室管理 | 看本科室工作量、医生工作量 |
| 医生 | 自查 | 看个人工作量 |
| 统计员 | 数据管理 | 生成日报、核对、上报 |
| 财务 | 对账 | 挂号收费核对 |
| 院长 | 决策 | 院级汇总 |

## 3. 业务模型

### 3.1 门诊日志模型

#### 3.1.1 门诊日志定义

**一人一次就诊 = 一行日志。**

```
┌────────────────────────────────────────────────────────────────────┐
│ 门诊日志（m04_clinic_log）                                          │
│  · 日志号       CL202610200001                                     │
│  · 就诊日期     2026-10-20                                         │
│  · 患者         王五  P202610200001                                │
│  · 科室         白内障科                                            │
│  · 医生         张明华                                              │
│  · 挂号单号      RG2026102001234                                   │
│  · 挂号类型      普通号                                             │
│  · 分诊级别      L4                                                 │
│  · 就诊状态      已完成                                             │
│  · 挂号时间      09:12                                              │
│  · 就诊开始      09:42                                              │
│  · 就诊结束      09:50                                              │
│  · 等待时长      30 分钟                                            │
│  · 挂号费        54.00                                              │
│  · 减免          0.00                                               │
│  · 实收          54.00                                              │
└────────────────────────────────────────────────────────────────────┘
```

#### 3.1.2 日志生成时机

| 时机 | 说明 |
|---|---|
| **实时生成** | 挂号成功即创建日志行（初始状态） |
| **实时更新** | 就诊开始/完成时更新 |
| **日终校正** | 次日 01:00 重算当日日志 |

> **设计选择：** 日志**不依赖定时任务**生成，而是在业务事件发生时同步写入（保证不丢），日终任务只做**校正**。

#### 3.1.3 日志与源表的关系

```
m04_clinic_log 是 m04_registration 的"宽表"
   · 冗余科室、医生、患者姓名（避免关联查询）
   · 冗余分诊级别、等待时长、就诊时长
   · 冗余金额（从 M16 同步）
   · 一对一：registration_id 唯一
```

### 3.2 日报模型

#### 3.2.1 日报维度

| 维度 | 说明 | 记录数 |
|---|---|---|
| **全院** | `dept_id = NULL, doctor_id = NULL` | 1 条/日 |
| **科室** | `dept_id = X, doctor_id = NULL` | N 条/日（N=科室数） |
| **医生** | `dept_id = X, doctor_id = Y` | M 条/日（M=出诊医生数） |

#### 3.2.2 日报指标

| 分类 | 指标 |
|---|---|
| **挂号** | 挂号人次、退号人次、有效挂号人次、加号人次 |
| **就诊** | 就诊人次、就诊人数、过号人次、未到人次 |
| **预约** | 预约人次、爽约人次、履约率 |
| **分诊** | 分诊人次、L1~L5 分布、平均等待、最长等待 |
| **叫号** | 叫号次数、复叫次数、过号人次、过号率 |
| **特殊号** | 特殊号人次、减免金额、加号数 |
| **号源** | 放号数、使用率、爽约率 |
| **金额** | 挂号费总额、减免总额、实收总额 |

#### 3.2.3 日报生成流程

```
次日 01:00 定时任务
   ↓
① 锁定上一日数据（只读）
   ↓
② 从 m04_clinic_log 聚合
   ↓
③ 从各子模块统计接口取补充数据
   ├─ M04-04 分诊统计
   ├─ M04-05 叫号统计
   ├─ M04-06 特殊号统计
   └─ M16 收费统计
   ↓
④ 写入 m04_daily_report（三种维度各一条）
   ↓
⑤ 数据核对
   ├─ 挂号人次 = 日志行数？
   ├─ 就诊人次 = 状态≥IN_VISIT 的行数？
   └─ 实收金额 = M16 金额？
   ↓
⑥ 核对结果写入 m04_data_check
   ↓
⑦ 差异 > 阈值 → 告警
```

### 3.3 工作量统计模型

#### 3.3.1 医生工作量

| 指标 | 说明 |
|---|---|
| 出诊天数 | 当月出诊天数 |
| 出诊班次 | 出诊班次数 |
| 接诊人次 | 实际就诊人次 |
| 人均诊时 | 总诊时 / 接诊人次 |
| 加号数 | 本人审批的加号 |
| 过号率 | 本诊室过号/叫号 |
| 出勤率 | 出诊班次 / 应出诊班次 |

#### 3.3.2 科室工作量

| 指标 | 说明 |
|---|---|
| 门诊人次 | 科室门诊总量 |
| 门诊人数 | 去重患者数 |
| 出诊医生数 | 当日出诊医生 |
| 人均接诊 | 门诊人次 / 出诊医生 |
| 号源使用率 | 已用号源 / 放号数 |
| 平均等待 | 分诊到就诊的平均时长 |
| 复诊率 | 复诊人次 / 总人次 |

#### 3.3.3 汇总层级

```
日 → 周 → 月 → 季 → 年
```

**设计：** 只存**日粒度**（`m04_daily_report`），其余层级**实时聚合**（数据量小，聚合快）。

> **理由：** 一年 365 天 × 50 科室 × 100 医生 = 182 万行，聚合查询 P95 < 500ms，无需预聚合月表。

### 3.4 数据核对模型

#### 3.4.1 核对项

| 编号 | 核对项 | 公式 | 容差 |
|---|---|---|---|
| `CHK-01` | 挂号人次 | 日报挂号人次 = 日志行数 | 0 |
| `CHK-02` | 就诊人次 | 日报就诊人次 = 状态≥IN_VISIT 行数 | 0 |
| `CHK-03` | 有效挂号 | 挂号 - 退号 = 有效挂号 | 0 |
| `CHK-04` | 分诊人次 | 分诊统计分诊数 = 日志有分诊记录的 | 0 |
| `CHK-05` | 叫号人次 | 叫号统计叫号数 ≥ 就诊人次 | 0 |
| `CHK-06` | 收费金额 | 日志实收合计 = M16 挂号费合计 | ¥0.01 |
| `CHK-07` | 号源占用 | 号源已用数 = 有效挂号数 | 0 |
| `CHK-08` | 加号数 | 加号流水数 = 号源新增数 | 0 |
| `CHK-09` | 减免金额 | 特殊号统计减免 = 日志减免合计 | ¥0.01 |
| `CHK-10` | 科室合计 | Σ科室 = 全院 | 0 |

#### 3.4.2 核对状态

| 状态 | 说明 | 处理 |
|---|---|---|
| `PASSED` | 差异 = 0 | 无 |
| `TOLERATED` | 差异 ≤ 容差 | 无 |
| `FAILED` | 差异 > 容差 | **告警** + 待处理 |
| `RESOLVED` | 已处理 | 记录处理说明 |
| `IGNORED` | 已知差异 | 记录原因 |

#### 3.4.3 核对执行时机

```
① 日终任务生成日报后自动核对
② 手工触发重核（数据修正后）
③ 每月 1 日核对上月（月结）
```

### 3.5 统计口径例外处理

| 场景 | 口径处理 |
|---|---|
| **退号** | 当日的退号，若原挂号是当日 → 有效挂号 -1；跨日退号 → 原日期不变 |
| **改约** | 不计入新日期门诊量，以实际就诊日期为准 |
| **加号** | 计入当日放号数与挂号人次 |
| **跨科室就诊** | 以实际就诊科室为准 |
| **一次就诊多科室** | 各科室各计 1 人次，全院计 1 人次（去重） |
| **急诊转门诊** | 只计一次 |
| **撤单重挂** | 退号 -1，新挂号 +1 |

### 3.6 上报数据模型

#### 3.6.1 卫健委上报指标（参考）

| 指标 | 公式 |
|---|---|
| 门诊总人次 | 有效挂号人次 |
| 门诊人数 | 去重患者数 |
| 急诊人次 | 急诊挂号人次 |
| 专家门诊人次 | 主任医师号 |
| 普通门诊人次 | 普通号 |
| 门诊次均费用 | 总收入 / 就诊人次 |

> **说明：** 各地报表格式不同，本模块提供**基础数据导出**，具体格式由 M17 或配置模板适配。

"""工作日报服务"""
from datetime import date, datetime, timedelta

from sqlalchemy import select, and_, func, desc
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.m04.clinic_log import (

from app.core.exceptions import BizException


class DailyReportService:
    """门诊工作日报"""

    def __init__(self, db: AsyncSession):
        self.db = db

    # ---------- 生成 ----------
    async def generate(self, payload, user) -> dict:
        """生成日报（三个维度）"""
        report_date = payload.report_date

        if report_date > date.today():
            raise BizException("0407005", "统计日期不可为未来日期")

        # 已存在检查
        existing = (await self.db.execute(
            select(M04DailyReport).where(
                M04DailyReport.report_date == report_date,
                M04DailyReport.dept_id.is_(None),
                M04DailyReport.doctor_id.is_(None),
            )
        )).scalar_one_or_none()

        if existing and not payload.force:
            raise BizException("0407003", "该日日报已生成",
                data={
                    "report_date": report_date.isoformat(),
                    "existing": {
                        "generated_at": (existing.generated_at.isoformat()
                                          if existing.generated_at else None),
                        "is_verified": existing.is_verified,
                        "visit_count": existing.visit_count,
                    },
                    "suggestion": "如需重新生成，请使用重算接口并指定 force=true",
                })

        started = datetime.now()

        # 1. 全院
        hospital = await self._build_hospital_report(report_date)

        # 2. 科室
        dept_ids = await self._get_dept_ids(report_date)
        dept_reports = []
        for did in dept_ids:
            dept_reports.append(await self._build_dept_report(report_date, did))

        # 3. 医生
        doctor_reports = []
        doctors = await self._get_doctors(report_date)
        for d in doctors:
            doctor_reports.append(
                await self._build_doctor_report(report_date, d))

        await self.db.commit()

        # 4. 核对
        check_result = None
        if payload.run_check:
            from app.services.m04.data_check_service import DataCheckService
            svc = DataCheckService(self.db)
            check_result = await svc.run_for_date(report_date, user)

        duration_ms = int(
            (datetime.now() - started).total_seconds() * 1000)

        return {
            "report_date": report_date.isoformat(),
            "generated_at": datetime.now().isoformat(),
            "duration_ms": duration_ms,
            "reports": {
                "hospital": len([hospital]),
                "dept": len(dept_reports),
                "doctor": len(doctor_reports),
                "total": 1 + len(dept_reports) + len(doctor_reports),
            },
            "detail": {
                "hospital_report_id": hospital.id,
                "dept_report_ids": [r.id for r in dept_reports],
                "visit_count": hospital.visit_count,
                "valid_reg_count": hospital.valid_reg_count,
            },
            "check_result": check_result,
        }

    async def _build_hospital_report(self, report_date: date) -> M04DailyReport:
        """全院日报"""
        return await self._build_report(report_date, None, None)

    async def _build_dept_report(self, report_date: date,
                                    dept_id: int) -> M04DailyReport:
        return await self._build_report(report_date, dept_id, None)

    async def _build_doctor_report(self, report_date: date,
                                     doctor_info) -> M04DailyReport:
        return await self._build_report(
            report_date, doctor_info["dept_id"], doctor_info["doctor_id"])

    async def _build_report(self, report_date: date,
                              dept_id: Optional[int],
                              doctor_id: Optional[int]) -> M04DailyReport:
        """构建一条日报"""
        # 聚合日志
        agg = await self._aggregate_logs(report_date, dept_id, doctor_id)

        # 查询或创建
        stmt = select(M04DailyReport).where(
            M04DailyReport.report_date == report_date,
        )
        if dept_id is None:
            stmt = stmt.where(M04DailyReport.dept_id.is_(None))
        else:
            stmt = stmt.where(M04DailyReport.dept_id == dept_id)

        if doctor_id is None:
            stmt = stmt.where(M04DailyReport.doctor_id.is_(None))
        else:
            stmt = stmt.where(M04DailyReport.doctor_id == doctor_id)

        report = (await self.db.execute(stmt)).scalar_one_or_none()

        if not report:
            report = M04DailyReport(
                report_date=report_date,
                stat_weekday=report_date.isoweekday(),
                dept_id=dept_id,
                doctor_id=doctor_id,
            )
            self.db.add(report)

        # 填充
        report.reg_count = agg["reg_count"]
        report.refund_count = agg["refund_count"]
        report.valid_reg_count = agg["reg_count"] - agg["refund_count"]
        report.visit_count = agg["visit_count"]
        report.patient_count = agg["patient_count"]
        report.passed_count = agg["passed_count"]
        report.no_show_count = agg["no_show_count"]

        report.reg_fee_total = agg["reg_fee_total"]
        report.discount_total = agg["discount_total"]
        report.actual_total = agg["actual_total"]
        report.avg_fee = (agg["actual_total"] / agg["visit_count"]
                           if agg["visit_count"] else Decimal("0"))

        report.l1_count = agg["l1_count"]
        report.l2_count = agg["l2_count"]
        report.l3_count = agg["l3_count"]
        report.l4_count = agg["l4_count"]
        report.l5_count = agg["l5_count"]
        report.triage_count = (agg["l1_count"] + agg["l2_count"]
                                + agg["l3_count"] + agg["l4_count"]
                                + agg["l5_count"])

        report.avg_wait_minutes = agg["avg_wait"]
        report.max_wait_minutes = agg["max_wait"]
        report.avg_visit_minutes = agg["avg_visit"]

        report.doctor_count = agg["doctor_count"]
        report.avg_visit_per_doctor = (
            Decimal(agg["visit_count"]) / agg["doctor_count"]
            if agg["doctor_count"] else Decimal("0"))

        report.status = "GENERATED"
        report.generated_at = datetime.now()
        report.is_verified = True

        await self.db.flush()
        return report

    async def _aggregate_logs(self, report_date: date,
                                dept_id: Optional[int],
                                doctor_id: Optional[int]) -> dict:
        """从日志聚合"""
        conditions = [M04ClinicLog.log_date == report_date]
        if dept_id:
            conditions.append(M04ClinicLog.dept_id == dept_id)
        if doctor_id:
            conditions.append(M04ClinicLog.doctor_id == doctor_id)

        VISITED = ("IN_VISIT", "COMPLETED")

        r = (await self.db.execute(
            select(
                func.count().label("total"),
                func.count().filter(
                    M04ClinicLog.status != "REFUNDED").label("reg"),
                func.count().filter(
                    M04ClinicLog.status == "REFUNDED").label("refund"),
                func.count().filter(
                    M04ClinicLog.status.in_(VISITED)).label("visit"),
                func.count(func.distinct(
                    M04ClinicLog.patient_id)).filter(
                    M04ClinicLog.status.in_(VISITED)).label("patients"),
                func.count().filter(
                    M04ClinicLog.status == "PASSED").label("passed"),
                func.count().filter(
                    M04ClinicLog.status == "NO_SHOW").label("no_show"),
                func.coalesce(func.sum(
                    M04ClinicLog.reg_fee), 0).label("reg_fee"),
                func.coalesce(func.sum(
                    M04ClinicLog.discount_fee), 0).label("discount"),
                func.coalesce(func.sum(
                    M04ClinicLog.actual_fee), 0).label("actual"),
                func.count().filter(
                    M04ClinicLog.triage_level == "L1").label("l1"),
                func.count().filter(
                    M04ClinicLog.triage_level == "L2").label("l2"),
                func.count().filter(
                    M04ClinicLog.triage_level == "L3").label("l3"),
                func.count().filter(
                    M04ClinicLog.triage_level == "L4").label("l4"),
                func.count().filter(
                    M04ClinicLog.triage_level == "L5").label("l5"),
                func.avg(M04ClinicLog.wait_minutes).label("avg_wait"),
                func.max(M04ClinicLog.wait_minutes).label("max_wait"),
                func.avg(M04ClinicLog.visit_minutes).label("avg_visit"),
                func.count(func.distinct(
                    M04ClinicLog.doctor_id)).label("doctors"),
            ).where(and_(*conditions))
        )).one()

        return {
            "reg_count": r.reg or 0,
            "refund_count": r.refund or 0,
            "visit_count": r.visit or 0,
            "patient_count": r.patients or 0,
            "passed_count": r.passed or 0,

            "discount_total": Decimal(str(r.discount or 0)),
            "actual_total": Decimal(str(r.actual or 0)),
            "l1_count": r.l1 or 0,
            "l2_count": r.l2 or 0,
            "l3_count": r.l3 or 0,
            "l4_count": r.l4 or 0,
            "l5_count": r.l5 or 0,
            "avg_wait": (Decimal(str(round(r.avg_wait, 1)))
                          if r.avg_wait else Decimal("0")),
            "max_wait": r.max_wait or 0,
            "avg_visit": (Decimal(str(round(r.avg_visit, 1)))
                           if r.avg_visit else Decimal("0")),
            "doctor_count": r.doctors or 0,
        }

    async def _get_dept_ids(self, report_date: date) -> List[int]:
        rows = (await self.db.execute(

        return [r[0] for r in rows if r[0]]

    async def _get_doctors(self, report_date: date) -> List[dict]:
        rows = (await self.db.execute(
            select(
                M04ClinicLog.dept_id,
                M04ClinicLog.doctor_id,
            ).where(
                M04ClinicLog.log_date == report_date,
                M04ClinicLog.doctor_id.isnot(None),
            ).distinct()
        )).all()
        return [{"dept_id": r[0], "doctor_id": r[1]} for r in rows]

    async def get_report(self, report_date: date,
                           dept_id: Optional[int] = None,
                           doctor_id: Optional[int] = None) -> dict:
        """日报详情"""
        stmt = select(M04DailyReport).where(
            M04DailyReport.report_date == report_date)

        if dept_id is None:
            stmt = stmt.where(M04DailyReport.dept_id.is_(None))
        else:
            stmt = stmt.where(M04DailyReport.dept_id == dept_id)

        if doctor_id is None:
            stmt = stmt.where(M04DailyReport.doctor_id.is_(None))
        else:
            stmt = stmt.where(M04DailyReport.doctor_id == doctor_id)

        report = (await self.db.execute(stmt)).scalar_one_or_none()

        if not report:
            raise BizException("0407002", "日报不存在",
                data={
                    "report_date": report_date.isoformat(),
                    "suggestion": "请先生成日报",
                })

        # 科室/医生明细
        by_dept = []
        by_doctor = []

        if dept_id is None and doctor_id is None:
            dept_rows = (await self.db.execute(
                select(M04DailyReport).where(
                    M04DailyReport.report_date == report_date,
                    M04DailyReport.dept_id.isnot(None),
                    M04DailyReport.doctor_id.is_(None),
                ).order_by(desc(M04DailyReport.visit_count))
            )).scalars().all()

            by_dept = [
                {
                    "dept_id": r.dept_id,
                    "dept_name": r.dept_name,
                    "valid_reg_count": r.valid_reg_count,
                    "visit_count": r.visit_count,
                    "patient_count": r.patient_count,
                    "avg_wait_minutes": float(r.avg_wait_minutes or 0),
                    "usage_rate": float(r.quota_usage_rate or 0),
                    "actual_total": float(r.actual_total or 0),
                }
                for r in dept_rows
            ]

            doctor_rows = (await self.db.execute(
                select(M04DailyReport).where(
                    M04DailyReport.report_date == report_date,
                    M04DailyReport.doctor_id.isnot(None),
                ).order_by(desc(M04DailyReport.visit_count))
            )).scalars().all()

            by_doctor = [
                {
                    "doctor_id": r.doctor_id,
                    "doctor_name": r.doctor_name,
                    "title_name": r.title_name,
                    "dept_name": r.dept_name,
                    "visit_count": r.visit_count,
                    "passed_count": r.passed_count,
                    "avg_visit_minutes": float(r.avg_visit_minutes or 0),
                    "avg_wait_minutes": float(r.avg_wait_minutes or 0),
                }
                for r in doctor_rows
            ]

        return self._to_detail(report, by_dept, by_doctor)

    async def list_reports(self, start_date, end_date,
                             dept_id, doctor_id,
                             page, page_size) -> dict:
        """日报列表"""
        stmt = select(M04DailyReport).where(
            M04DailyReport.report_date >= start_date,
            M04DailyReport.report_date <= end_date,
        )
        if dept_id is None:
            stmt = stmt.where(M04DailyReport.dept_id.is_(None))
        else:
            stmt = stmt.where(M04DailyReport.dept_id == dept_id)

        if doctor_id is None:
            stmt = stmt.where(M04DailyReport.doctor_id.is_(None))
        else:
            stmt = stmt.where(M04DailyReport.doctor_id == doctor_id)

        total = (await self.db.execute(
            select(func.count()).select_from(stmt.subquery())
        )).scalar_one()

        rows = (await self.db.execute(
            stmt.order_by(M04DailyReport.report_date.desc())
            .offset((page - 1) * page_size).limit(page_size)
        )).scalars().all()

        return {
            "items": [self._to_item(r) for r in rows],
            "total": total,
            "page": page,
            "page_size": page_size,
            "pages": (total + page_size - 1) // page_size,
        }

    async def get_internal_daily_stat(self, stat_date: date,
                                        dept_id: Optional[int]) -> dict:

async def _reconcile(log_date: str = None):
    """找出有挂号但无日志的记录，补建日志"""
    from datetime import date, timedelta
    from sqlalchemy import select, not_, exists
    from app.models.m04.registration import M04Registration
    from app.models.m04.clinic_log import M04ClinicLog
    from app.core.database import AsyncSessionLocal
    from app.services.m04.clinic_log_service import ClinicLogService

    d = (date.fromisoformat(log_date) if log_date
         else date.today() - timedelta(days=1))

    async with AsyncSessionLocal() as db:
        missing = (await db.execute(
            select(M04Registration).where(
                func_date(M04Registration.reg_time) == d,
                M04Registration.is_deleted == False,
                not_(exists().where(
                    M04ClinicLog.registration_id == M04Registration.id)),
            )
        )).scalars().all()

        svc = ClinicLogService(db)
        created = 0
        for reg in missing:
            await svc.on_registration({
                "registration_id": reg.id,
                "registration_no": reg.registration_no,
                "visit_no": reg.visit_no,
                "patient_id": reg.patient_id,
                "empi_no": reg.empi_no,
                "patient_name": reg.patient_name,
                "patient_gender": reg.patient_gender,

                              if reg.reg_time else None),
                "reg_fee": float(reg.total_amount or 0),
                "actual_fee": float(reg.total_amount or 0),
            })
            created += 1

        return {"log_date": d.isoformat(),
                "missing": len(missing), "created": created}

## 附录 A：指标口径

| 指标 | 定义 | 公式 |
|---|---|---|
| 挂号人次 | 当日挂出号数 | COUNT(status ≠ REFUNDED) |

| 有效挂号人次 | 挂号 - 退号 | reg_count - refund_count |

| 号源使用率 | 已用/放号 | used_quota / total_quota × 100% |
| 爽约率 | 爽约/放号 | no_show / total_quota × 100% |
| 过号率 | 过号/叫号 | passed / call_count × 100% |
| 复诊率 | 复诊/总 | return / total × 100% |
| 平均等待 | 等待时长均值 | AVG(wait_minutes) |
| 平均诊时 | 诊时均值 | AVG(visit_minutes) |
| 出勤率 | 出诊/应出诊 | shift / expected × 100% |
| 门诊次均费用 | 总收入/人次 | actual_total / visit_count |
