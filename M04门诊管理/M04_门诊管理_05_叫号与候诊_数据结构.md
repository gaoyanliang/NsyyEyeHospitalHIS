## 4. 数据结构设计

### 4.1 ER 关系图

```
┌──────────────────────────────────────────────────────────────────────┐
│ 上游（引用，不建物理外键）                                             │
│  m04_triage / m04_queue_entry（M04-04）                               │
│  m04_registration（M04-03）、mdm_employee（M01）                       │
└──────────────────────────────┬───────────────────────────────────────┘
                               │
                               ▼
┌──────────────────────────────────┐
│ m04_call_record（叫号记录）★核心   │
│  · call_no                       │
│  · queue_entry_id / triage_id    │
│  · room_id / doctor_id           │
│  · status（CALLING/PASSED/...）   │
│  · call_mode / recall_count      │
│  · pass_count / waiting_minutes  │
└───────┬──────────────┬───────────┴──────────────┬─────────────────┐
        │ 1:N          │ 1:N                      │                 │
        ▼              ▼                          ▼                 ▼
┌──────────────┐ ┌──────────────┐      ┌──────────────────┐ ┌──────────────┐
│m04_call_log  │ │m04_call_tts_ │      │m04_call_statistics│ │m04_call_     │
│（操作日志）   │ │cache（语音）  │      │（统计，独立）      │ │screen（屏配置）│
└──────────────┘ └──────────────┘      └──────────────────┘ └──────────────┘

字典表：
┌──────────────────────────┐  ┌──────────────────────────┐
│ m04_call_pass_reason     │  │ m04_call_config          │
│ （过号原因字典）           │  │ （叫号配置，单行）         │
└──────────────────────────┘  └──────────────────────────┘
```

**设计说明：**

- `m04_call_record` 是叫号主体，**一次叫号一条**；复叫更新同一记录 `recall_count +1`
- 过号后重新排队会**新建**一条叫号记录（保留历史），原记录 `requeued = TRUE`
- `m04_call_log` 记录**每次操作**（叫号、复叫、过号、重排、作废）
- `m04_call_tts_cache` 缓存 TTS 音频，避免重复合成
- 屏显内容**不落表**，实时从 `m04_queue_entry` + `m04_call_record` 组合生成

**约束说明**

```sql
ALTER TABLE m04_call_record
    ADD CONSTRAINT ck_m04_call_no
    CHECK (call_no ~ '^CL[0-9]{8}[A-Z0-9]{4}$');

ALTER TABLE m04_call_record
    ADD CONSTRAINT ck_m04_call_mode
    CHECK (call_mode IN ('NORMAL', 'PRIORITY', 'MANUAL', 'RECALL'));

ALTER TABLE m04_call_record
    ADD CONSTRAINT ck_m04_call_status
    CHECK (status IN ('CALLING', 'ENTERING', 'NO_ANSWER', 'PASSED',
                       'SKIPPED', 'REQUEUED', 'IN_VISIT', 'COMPLETED',
                       'CANCELLED'));

ALTER TABLE m04_call_record
    ADD CONSTRAINT ck_m04_call_counts
    CHECK (recall_count >= 0 AND pass_count >= 0 AND waiting_minutes >= 0);

-- 关键：同一诊室只能有一个正在叫号的记录
CREATE UNIQUE INDEX uk_m04_call_calling
    ON m04_call_record (room_id)
    WHERE status = 'CALLING';

-- 当前叫号查询索引（覆盖 IN_VISIT）
CREATE INDEX idx_m04_call_current
    ON m04_call_record (room_id, status)
    WHERE status IN ('CALLING', 'IN_VISIT');

-- 过号必须有原因
ALTER TABLE m04_call_record
    ADD CONSTRAINT ck_m04_call_pass
    CHECK (status <> 'PASSED' OR pass_reason IS NOT NULL);
```

```

   ▼        ▼            ▼              ▼
┌────────┐┌──────────┐┌──────────┐┌──────────┐
│ENTERING││NO_ANSWER ││  PASSED  ││ SKIPPED  │
│已应答  ││ 无应答    ││  已过号   ││ 已跳过   │
└───┬────┘└────┬─────┘└────┬─────┘└──────────┘
    │          │            │
    │          │ 复叫        │ 重新排队
    │          └──► CALLING  ▼

    │                  │ REQUEUED │
```

```python
        return self.patient_name[0] + "*" * (len(self.patient_name) - 1)

        return self.triage_level in ("L1", "L2")

        return (self.status in ("CALLING", "NO_ANSWER", "PASSED")

        return self.status in ("CALLING", "NO_ANSWER")

                and not self.requeued

        if not self.called_at:

    def check_timeout(self) -> bool:
        """是否已超应答时限"""
        if self.status != "CALLING" or not self.answer_limit_seconds:
            return False
        return self.elapsed_seconds() > self.answer_limit_seconds

    def display_text(self) -> str:
        """屏显文本"""
        return f"请 {self.masked_name()} 到 {self.room_no} 诊室"

                              queue_no: Optional[str] = None) -> str:

            template = "请 {queue_no} 号 {name} 到 {room} 诊室 就诊"
        else:
            template = self.voice_template

        return template.format(
            name=name, room=room_no, queue_no=queue_no or "")

    def is_quiet_hours(self, now: Optional[time] = None) -> bool:
        """是否处于静音时段"""
        if not self.quiet_hours_enabled:
            return False
        if not self.quiet_start_time or not self.quiet_end_time:
            return False

        t = now or datetime.now().time()

        if self.quiet_start_time <= self.quiet_end_time:
            return self.quiet_start_time <= t < self.quiet_end_time
        # 跨天（如 22:00-08:00）
        return t >= self.quiet_start_time or t < self.quiet_end_time

    def effective_volume(self, now: Optional[time] = None) -> int:
        """实际音量（静音时段降低）"""
        return self.quiet_volume if self.is_quiet_hours(now) else self.voice_volume

    def calc_passed_rate(self) -> Decimal:
        if not self.total_count:
            return Decimal("0.00")
```
