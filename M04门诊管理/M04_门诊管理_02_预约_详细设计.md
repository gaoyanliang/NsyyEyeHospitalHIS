## 1. 模块概述

### 1.1 模块定位

预约是门诊业务的**需求端**。它回答："**这个患者什么时候来、看哪个医生、占哪个号？**"

```
┌──────────────────────────────────────────────────────────────┐
│  M04-01 排班与号源（号源供给）                                 │
└────────────────────────┬─────────────────────────────────────┘
                         │ slot/reserve
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M04-02 预约（本文档）                                         │
│  预约申请 → 号源占用 → 确认 → 到院签到 → 挂号 → 完成            │
│               ↓ 取消/改约                                       │
│            号源释放                                             │
└────────────────────────┬─────────────────────────────────────┘
                         ▼ 已到院
┌──────────────────────────────────────────────────────────────┐
│  M04-03 挂号与退号 → M04-04 分诊 → M04-05 叫号                 │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 预约 vs 挂号（关键区分）

| 维度 | 预约（本子模块） | 挂号（M04-03） |
|---|---|---|
| 时机 | 提前（提前 1~30 天） | 当天到院 |
| 号源 | **占用**（锁定） | **占用**（锁定） |
| 收费 | **不收费**（预约免费） | **收费**（挂号费） |
| 是否产生就诊记录 | ❌ | ✅ |
| 到院后 | **转挂号** | 直接就诊 |
| 取消 | 释放号源，无费用影响 | 退号，需退费 |

> **一句话：** 预约是"占个位"，挂号是"真正开始就诊并收费"。预约到院后必须**转为挂号**才能就诊。

### 1.3 与相邻模块的分工

| 能力 | 归属 |
|---|---|
| 号源生成与库存 | M04-01 |
| **预约申请与确认** | **M04-02 本子模块** |
| **预约改约、取消** | **M04-02 本子模块** |
| **爽约管理** | **M04-02 本子模块** |
| 到院签到（预约转挂号） | M04-03（本模块提供转挂号能力） |
| 挂号与收费 | M04-03 / M16 |
| 分诊与叫号 | M04-04 / M04-05 |
| 特殊号（军残/绿色通道） | M04-06 |
| 患者门户预约入口 | M03-06（调用本模块） |
| 预约提醒消息 | M03-05 |
| 医生停诊时预约处理 | M04-01 发起，本模块配合 |

> **边界一句话：** 本子模块只管"预约业务的完整生命周期"；**不做**号源生成（M04-01）、**不做**挂号收费（M04-03/M16）、**不做**分诊叫号（M04-04/05）。

### 1.4 模块目标

- **准确**：号源与预约一一对应，不超卖。
- **灵活**：支持自助、现场、电话、门户多渠道。
- **可追溯**：每次预约变更全量留痕。
- **防爽约**：提醒 + 信用分 + 爽约限制。
- **可改约**：改约不损失号源。
- **高可用**：预约高峰（放号瞬间）稳定。

### 1.5 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 患者 | 自助预约 | 门户预约、改约、取消 |
| 导医/挂号员 | 协助预约 | 现场预约、查询、改约 |
| 客服 | 电话预约 | 电话预约 |
| 医生 | 查看预约 | 查看患者列表 |
| 科室主任 | 管理 | 查看本科室预约、审批改约 |

## 3. 业务模型

### 3.1 预约来源

| 来源 | 代码 | 说明 | 提前期 |
|---|---|---|---|
| 患者门户 | `PORTAL` | 公众号/小程序 | 7 天 |
| 院内自助机 | `KIOSK` | 院内终端 | 当天 |
| 院内窗口 | `WINDOW` | 导医 | 30 天 |
| 电话 | `PHONE` | 客服 | 30 天 |
| 医生诊间 | `DOCTOR` | 医生为复诊患者预约 | 30 天 |
| 系统导入 | `IMPORT` | 批量导入 | — |

### 3.2 预约状态机

```
                    ┌──────────────┐
                    │   PENDING    │  待确认（可配置是否需要确认）
                    └──────┬───────┘
                           │
          ┌────────────────┼────────────────┐
          │ confirm        │ cancel         │ timeout
          ▼                ▼                ▼
    ┌──────────┐    ┌───────────┐    ┌──────────┐
    │ BOOKED   │    │ CANCELLED │    │ EXPIRED  │
    │ 已预约    │    └───────────┘    └──────────┘
    └────┬─────┘
         │
    ┌────┼──────────────┬──────────────┐
    │    │              │              │
    │改约 │ 到院签到       │ 爽约          │ 停诊
    ▼    ▼              ▼              ▼
┌──────┐┌──────────┐┌──────────┐┌──────────────┐
│CHANGED││CHECKED_IN││ NO_SHOW  ││ SUSPENDED    │
│已改约 ││ 已签到    ││ 爽约      ││ 因停诊待处理  │
└──────┘└────┬─────┘└──────────┘└──────┬───────┘
             │                          │
             │ 转挂号                    │ 改约/退号
             ▼                          ▼
       ┌──────────┐              ┌──────────┐
       │REGISTERED│              │RESCHEDULED│
       │已转挂号   │              │ 已改约     │
       └──────────┘              └──────────┘
```

**状态说明：**

| 状态 | 说明 | 终态 |
|---|---|---|
| `PENDING` | 待确认 | — |
| `BOOKED` | 已预约（占号成功） | — |
| `CHECKED_IN` | 已到院签到 | — |
| `REGISTERED` | 已转挂号（就诊开始） | ✅ |
| `NO_SHOW` | 爽约（未到院） | ✅ |
| `CANCELLED` | 已取消 | ✅ |
| `CHANGED` | 已改约（此条作废） | ✅ |
| `EXPIRED` | 待确认超时 | ✅ |
| `SUSPENDED` | 因医生停诊待处理 | — |

### 3.3 预约号源关系

```
预约创建
   ↓
M04-01 reserve()
   ├─ 成功 → m04_reg_slot.status = LOCKED
   │           m04_reg_slot.biz_type = 'APPOINTMENT'
   │           m04_reg_slot.biz_no = 预约号
   ↓
M04-01 confirm()
   └─ m04_reg_slot.status = BOOKED
   ↓
预约确认（BOOKED）

预约取消
   ↓
M04-01 release()
   └─ m04_reg_slot.status = AVAILABLE
       m04_reg_slot.patient_id = NULL

预约转挂号
   └─ 号源不变（仍 BOOKED），biz_type 改为 'REGISTRATION'
```

### 3.4 预约确认模式

| 模式 | 说明 | 适用 |
|---|---|---|
| **自动确认** | 提交即 BOOKED | 门户、自助机（默认） |
| **人工确认** | 提交为 PENDING，需审核 | 特殊号、大额检查 |
| **超时确认** | PENDING 15 分钟内确认，否则失效 | 需预付费场景 |

**配置：** `M04.APPT.AUTO_CONFIRM = TRUE`

### 3.5 预约规则模型

#### 3.5.1 提前期

| 渠道 | 默认提前期 | 配置 |
|---|---|---|
| 门户 | 7 天 | `M04.BOOK.PORTAL_ADVANCE_DAYS` |
| 院内窗口 | 30 天 | `M04.BOOK.INHOUSE_ADVANCE_DAYS` |
| 自助机 | 当天 | `M04.BOOK.ONSITE_ADVANCE_DAYS` |

#### 3.5.2 预约数量限制

| 规则 | 默认值 | 说明 |
|---|---|---|
| 单患者同期有效预约上限 | 3 个 | 防占用号源 |
| 单患者单科室同期上限 | 2 个 | — |
| 单患者单医生同期上限 | 1 个 | — |
| 单账号单日预约上限 | 5 个 | 门户防刷 |
| 同一时段重复预约 | 禁止 | — |

#### 3.5.3 术前/检查前置条件

**眼科特殊场景：**

| 场景 | 前置条件 | 校验 |
|---|---|---|
| 屈光手术咨询 | 无特殊 | — |
| 白内障术前 | 需先完成术前检查 | 校验检查完成 |
| 复查 | 需有历史就诊 | 校验历史记录 |
| 首诊 | 无限制 | — |

**配置表 `m04_appt_rule`：**

| 规则类型 | 示例 |
|---|---|
| `PRE_EXAM_REQUIRED` | 白内障术前需先做 A/B 超 |
| `HISTORY_REQUIRED` | 复查需有 6 个月内就诊记录 |
| `AGE_LIMIT` | 儿童眼科仅限 14 岁以下 |
| `REFERRAL_REQUIRED` | 专家号需基层医院转诊 |

### 3.6 改约模型

```
原预约（日期 10-22，张明华）
   ↓ 改约请求
① 选择新号源（10-23，张明华，或 10-22，李建国）
   ↓
② M04-01 reserve(新号源)
   ├─ 失败 → 提示无号，原预约不变
   └─ 成功 ↓
③ 释放原号源 M04-01 release(原号源)
   ↓
④ 更新预约记录
   ├─ 原预约 status = 'CHANGED'
   ├─ 新建预约（或更新同一条 + 记录变更历史）
   └─ m04_appt_change_log
   ↓
⑤ 通知患者
```

**改约规则：**

| 规则 | 说明 |
|---|---|
| 改约次数限制 | 单次预约最多改约 2 次 |
| 改约时间窗 | 开诊前 2 小时内不可改约 |
| 改约费 | 免费（默认） |
| 改约后可取消 | ✅ |

### 3.7 爽约模型

#### 3.7.1 爽约判定

| 条件 | 判定 |
|---|---|
| 预约时间已过 | 班次结束时间 < 当前时间 |
| 且状态仍为 `BOOKED` | 未签到、未转挂号、未取消 |
| 且非停诊导致 | — |
| → 标记 `NO_SHOW` | 定时任务执行 |

**执行时机：** 班次结束后 30 分钟（`M04.APPT.NOSHOW_DELAY_MINUTES = 30`）

#### 3.7.2 信用分模型

| 事件 | 分值变化 |
|---|---|
| 初始分值 | 100 |
| 爽约 | **-10** |
| 正常就诊 | +1（上限 100） |
| 开诊前 2 小时内取消 | -5 |
| 黑名单阈值 | < 60 |

**黑名单后果：**

| 分值区间 | 限制 |
|---|---|
| ≥ 80 | 正常 |
| 60~79 | 提示信用偏低，不可预约专家号 |
| < 60 | **需人工审核**，仅可预约普通号 |

#### 3.7.3 信用分表

`m04_appt_credit`：患者信用分与事件记录。

### 3.8 停诊联动模型

```
M04-01 停诊
   ↓ 发布事件 m04.schedule.suspended
本模块消费
   ├─ 该班次所有 BOOKED 预约 → status = 'SUSPENDED'
   ├─ 记录 m04_appt_suspend_handle（待处理）
   └─ 通知患者（M03-05）
   ↓
医护人员/客服处理
   ├─ 改约到其他班次
   ├─ 取消并致歉
   └─ 转为待约（等待医生恢复）
```

### 3.9 患者合并联动

```
M03-02 合并患者
   ↓ 发布 mpi.patient.merged
本模块消费
   ├─ 合并患者的所有预约 → patient_id 改为 survivor
   ├─ 若同一时段重复 → 保留一条，取消另一条
   └─ 记录 m04_appt_change_log
```

```python
from datetime import date
from typing import Optional, List

from fastapi import APIRouter, Depends, Query
from sqlalchemy.ext.asyncio import AsyncSession

from app.api.deps import get_db, require_permission
from app.core.audit import audit_log
from app.core.response import success_response
from app.schemas.m04.appointment import (
    AppointmentCreate, RescheduleRequest, CancelRequest,
    CheckInRequest, ToRegistrationRequest, AppointmentQuery,
    CreditAdjustRequest, HandleSuspendRequest, BatchCheckInRequest,

from app.services.m04.appointment_service import AppointmentService
from app.services.m04.credit_service import CreditService

router = APIRouter(prefix="/api/v1/m04", tags=["门诊-预约"])
internal_router = APIRouter(prefix="/internal/v1/m04/appt", tags=["门诊-预约内部"])
portal_router = APIRouter(prefix="/internal/v1/registration", tags=["门诊-门户预约"])


# ---------- 预约管理 ----------
@router.get("/appointments", summary="预约列表")
async def list_appointments(
    appointment_date: Optional[date] = None,
    status: Optional[str] = None,
    source: Optional[str] = None,
    dept_id: Optional[int] = None,
    doctor_id: Optional[int] = None,
    patient_keyword: Optional[str] = None,
    appt_no: Optional[str] = None,
    page: int = Query(1, ge=1),
    page_size: int = Query(20, ge=1, le=200),

    user=Depends(require_permission("m04:appt:list")),
):
    svc = AppointmentService(db)
    result = await svc.list_appointments(
        appointment_date, status, source, dept_id, doctor_id,
        patient_keyword, appt_no, page, page_size)
    return success_response(result)


@router.get("/appointments/{appt_id}", summary="预约详情")

    appt_id: int,
    db: AsyncSession = Depends(get_db),
    user=Depends(require_permission("m04:appt:list")),
):
    svc = AppointmentService(db)
    result = await svc.get_detail(appt_id)
    return success_response(result)


@router.post("/appointments", summary="新建预约")
@audit_log(
    event_code="APPT_CREATE",
    audit_type="OPERATION",
    object_type="m04_appointment",
    capture_after=True,
    risk_level="MEDIUM",
)
async def create_appointment(
    payload: AppointmentCreate,
    db: AsyncSession = Depends(get_db),
    user=Depends(require_permission("m04:appt:create")),
```

### 6.5 Service 层核心逻辑示例

```python
# app/services/m04/appointment_service.py
"""预约服务"""
import uuid
from datetime import date, datetime, time, timedelta
from typing import Optional, List

from sqlalchemy import select, and_, or_, func, desc
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.m04.appointment import (
    M04Appointment, M04ApptChangeLog, M04ApptReminder,
    M04ApptConfig, M04ApptRule,
)
from app.models.m04.schedule import M04Schedule, M04RegSlot
from app.core.exceptions import BizException
from app.core.redis import redis_client
from app.clients.mpi_client import MpiClient
from app.clients.mpi_message_client import MpiMessageClient
from app.clients.m04_client import M04InternalClient


class AppointmentService:
    """预约生命周期管理"""

    def __init__(self, db: AsyncSession):
        self.db = db
        self.mpi = MpiClient()
        self.m04 = M04InternalClient()
        self.msg = MpiMessageClient()

    # ---------- 创建 ----------
    async def create(self, payload, user) -> dict:
        """新建预约"""
        config = await self._get_config()

        # 1. 查排班
        schedule = (await self.db.execute(
            select(M04Schedule).where(
                M04Schedule.id == payload.schedule_id,
                M04Schedule.is_deleted == False,
            )
        )).scalar_one_or_none()

        if not schedule:
            raise BizException(54006, "排班不存在")

        if schedule.status != "NORMAL":
            raise BizException(54007, "该班次不可预约",
                data={"status": schedule.status})

        # 2. 提前期校验
        self._check_advance(schedule, payload.source, config)

        # 3. 患者校验
        patient = await self.mpi.get_patient(payload.patient_id)
        if not patient:
            raise BizException("0402006", "患者不存在")

        # 4. 信用分校验
        credit = await self._get_credit(payload.patient_id)
        if credit["score"] < config.get("blacklist_threshold", 60):
            raise BizException("0402013",
                f"患者信用分过低（{credit['score']} 分），需人工审核")
        if credit["score"] < 80 and schedule.reg_type_code == "EXPERT":
            raise BizException("0402013",
                f"信用分 {credit['score']} 分，暂不可预约专家号")

        # 5. 预约上限校验
        await self._check_limits(payload, config)

        # 6. 前置规则校验
        await self._check_rules(payload, schedule)

        # 7. 占用号源
        reserve_result = await self.m04.reserve_slot(
            schedule_id=payload.schedule_id,
            patient_id=payload.patient_id,
            biz_type="APPOINTMENT",
            prefer_period_id=payload.period_id,
            lock_seconds=300,
        )

        if not reserve_result:
            raise BizException("0402005", "无可预约号源")

        # 8. 创建预约记录
        appt_no = self._gen_appt_no()
        appt = M04Appointment(
            appt_no=appt_no,
            appointment_date=schedule.schedule_date,
            period=schedule.period,
            start_time=schedule.start_time,
            end_time=schedule.end_time,
            schedule_id=schedule.id,
            slot_id=reserve_result["slot_id"],
            slot_no=reserve_result["slot_no"],
            queue_no=reserve_result.get("queue_no"),
            period_id=reserve_result.get("period_id"),
            period_text=reserve_result.get("period_text"),
            dept_id=schedule.dept_id,
            dept_name=schedule.dept_name,
            doctor_id=schedule.doctor_id,
            doctor_name=schedule.doctor_name,
            title_name=schedule.title_name,
            reg_type_code=schedule.reg_type_code,
            reg_type_name=schedule.reg_type_name,
            room_no=schedule.room_no,
            fee=schedule.fee,
            patient_id=payload.patient_id,
            empi_no=patient.get("empi_no"),
            patient_name=patient.get("patient_name"),
            visit_person_id=payload.visit_person_id or payload.patient_id,
            phone=payload.phone,
            source=payload.source,
            status="PENDING" if not payload.auto_confirm
                     and not config.get("auto_confirm", True) else "BOOKED",
            remark=payload.remark,
            created_by=getattr(user, "id", None),
        )
        self.db.add(appt)
        await self.db.flush()

        # 9. 确认号源
        if appt.status == "BOOKED":
            await self.m04.confirm_slot(
                slot_id=reserve_result["slot_id"],
                lock_id=reserve_result["lock_id"])

        # 10. 变更日志
        self.db.add(M04ApptChangeLog(
            appt_id=appt.id,
            appt_no=appt_no,
            action="CREATE",
            after_json={"status": appt.status, "slot_no": appt.slot_no},
            operator_id=getattr(user, "id", None),
            operator_name=getattr(user, "name", None) or "患者自助",
        ))

        # 11. 提醒计划
        reminders = await self._create_reminders(appt, config)

        await self.db.commit()

        # 12. 发送预约成功通知
        if appt.status == "BOOKED":
            await self._send_notify(appt, "APPT_SUCCESS")

        return {
            "id": appt.id,
            "appt_no": appt_no,
            "slot_id": appt.slot_id,
            "slot_no": appt.slot_no,
            "queue_no": appt.queue_no,
            "appointment_date": appt.appointment_date.isoformat(),
            "period_text": self._period_full_text(appt),
            "doctor_name": appt.doctor_name,
            "dept_name": appt.dept_name,
            "status": appt.status,
            "status_text": self._status_text(appt.status),
            "credit_score": credit["score"],
            "remind_plan": reminders,
        }

    def _check_advance(self, schedule, source: str, config: dict) -> None:
        """提前期校验"""
        advance_map = {
            "PORTAL": config.get("portal_advance_days", 7),
            "KIOSK": config.get("onsite_advance_days", 0),
            "WINDOW": config.get("inhouse_advance_days", 30),
            "PHONE": config.get("inhouse_advance_days", 30),
            "DOCTOR": config.get("inhouse_advance_days", 30),
        }
        max_advance = advance_map.get(source, 30)
        days_ahead = (schedule.schedule_date - date.today()).days

        if days_ahead < 0:
            raise BizException("0402007", "该班次已过期，无法预约")

        if days_ahead > max_advance:
            raise BizException("0402006",
                f"{source} 渠道最多提前 {max_advance} 天预约")

    async def _check_limits(self, payload, config: dict) -> None:
        """预约数量限制校验"""
        base = select(func.count()).select_from(M04Appointment).where(
            M04Appointment.patient_id == payload.patient_id,
            M04Appointment.status.in_(("PENDING", "BOOKED", "CHECKED_IN")),
        )

        # 总上限
        total = (await self.db.execute(base)).scalar_one()
        max_total = config.get("max_active_per_patient", 3)
        if total >= max_total:
            raise BizException("0402008",
                f"该患者已有 {total} 个有效预约，超过上限 {max_total}",
                data={"current_count": total, "max_limit": max_total})

        # 单科室
        schedule = (await self.db.execute(
            select(M04Schedule).where(M04Schedule.id == payload.schedule_id)
        )).scalar_one()

        dept_count = (await self.db.execute(
            base.where(M04Appointment.dept_id == schedule.dept_id)
        )).scalar_one()
        max_dept = config.get("max_per_dept", 2)
        if dept_count >= max_dept:
            raise BizException("0402009",
                f"该患者在本院同一科室已有 {dept_count} 个预约")

        # 单医生
        doctor_count = (await self.db.execute(
            base.where(M04Appointment.doctor_id == schedule.doctor_id)
        )).scalar_one()
        if doctor_count >= 1:
            raise BizException("0402010",
                f"该患者已预约 {schedule.doctor_name} 医生")

        # 同时段冲突
        conflict = (await self.db.execute(
            base.where(
                M04Appointment.appointment_date == schedule.schedule_date,
                M04Appointment.period == schedule.period,
            )
        )).scalar_one_or_none()
        if conflict:
            raise BizException("0402012", "该患者此时段已有预约")

    async def _check_rules(self, payload, schedule) -> None:
        """前置规则校验"""
        rules = (await self.db.execute(
            select(M04ApptRule).where(
                M04ApptRule.is_enabled == True,
                M04ApptRule.is_deleted == False,
                or_(
                    M04ApptRule.dept_id.is_(None),
                    M04ApptRule.dept_id == schedule.dept_id,
                ),
            )
        )).scalars().all()

        for rule in rules:
            if not rule.check:
                continue

            if rule.rule_type == "HISTORY_REQUIRED":
                days = rule.param_json.get("within_days", 180)
                since = date.today() - timedelta(days=days)
                has_history = (await self.db.execute(
                    select(func.count()).select_from(M04Appointment).where(
                        M04Appointment.patient_id == payload.patient_id,
                        M04Appointment.status == "REGISTERED",
                        M04Appointment.appointment_date >= since,
                    )
                )).scalar_one() > 0
                if not has_history:
                    raise BizException("0402015",
                        f"复查需有 {days} 天内的就诊记录")

            elif rule.rule_type == "PRE_EXAM_REQUIRED":
                # 调 M12 校验检查完成
                from app.clients.m12_client import M12Client
                exam_code = rule.param_json.get("exam_code")
                done = await M12Client().check_exam_done(
                    payload.patient_id, exam_code)
                if not done:
                    raise BizException("0402015",
                        f"需先完成检查：{rule.param_json.get('exam_name')}")

    # ---------- 改约 ----------
    async def reschedule(self, appt_id: int, payload, user) -> dict:
        """改约（核心：先占新号，再放旧号）"""
        appt = await self._get_appt(appt_id)

        if appt.status not in ("BOOKED", "SUSPENDED"):
            raise BizException("0402002",
                f"当前状态 {self._status_text(appt.status)} 不可改约")

        config = await self._get_config()

        # 改约次数
        max_reschedule = config.get("max_reschedule", 2)
        if appt.reschedule_count >= max_reschedule:
            raise BizException("0402016",
                f"该预约已改约 {appt.reschedule_count} 次，无法再改约")

        # 时间窗口
        cutoff_hours = config.get("reschedule_cutoff_hours", 2)
        appt_dt = datetime.combine(appt.appointment_date, appt.start_time or time(8, 0))
        if datetime.now() + timedelta(hours=cutoff_hours) > appt_dt:
            raise BizException("0402017",
                f"距开诊不足 {cutoff_hours} 小时，无法改约")

        # 新排班
        new_schedule = (await self.db.execute(
            select(M04Schedule).where(
                M04Schedule.id == payload.new_schedule_id,
                M04Schedule.is_deleted == False,
            )
        )).scalar_one_or_none()

        if not new_schedule or new_schedule.status != "NORMAL":
            raise BizException(54007, "目标班次不可预约")

        # 1. 先占新号（失败则原预约不变）
        reserve = await self.m04.reserve_slot(
            schedule_id=payload.new_schedule_id,
            patient_id=appt.patient_id,
            biz_type="APPOINTMENT",
            prefer_period_id=payload.new_period_id,
        )

        if not reserve:
            raise BizException("0402018", "新号源已被占用，改约失败，原预约保持不变")

        try:
            # 2. 释放旧号
            await self.m04.release_slot(
                slot_id=appt.slot_id, reason="改约释放")

            # 3. 更新原预约（保留一条，记录改约次数）
            old_snapshot = {
                "appt_no": appt.appt_no,
                "schedule_id": appt.schedule_id,
                "slot_id": appt.slot_id,
                "appointment_date": appt.appointment_date.isoformat(),
            }

            old_appt_no = appt.appt_no
            appt.appt_no = self._gen_appt_no()
            appt.schedule_id = new_schedule.id
            appt.slot_id = reserve["slot_id"]
            appt.slot_no = reserve["slot_no"]
            appt.queue_no = reserve.get("queue_no")
            appt.period_id = reserve.get("period_id")
            appt.period_text = reserve.get("period_text")
            appt.appointment_date = new_schedule.schedule_date
            appt.period = new_schedule.period
            appt.start_time = new_schedule.start_time
            appt.end_time = new_schedule.end_time
            appt.doctor_id = new_schedule.doctor_id
            appt.doctor_name = new_schedule.doctor_name
            appt.room_no = new_schedule.room_no
            appt.status = "BOOKED"
            appt.reschedule_count += 1
            appt.rescheduled_at = datetime.now()

            await self.m04.confirm_slot(
                slot_id=reserve["slot_id"], lock_id=reserve.get("lock_id"))

            self.db.add(M04ApptChangeLog(
                appt_id=appt.id,
                appt_no=appt.appt_no,
                action="RESCHEDULE",
                before_json=old_snapshot,
                after_json={
                    "appointment_date": new_schedule.schedule_date.isoformat(),
                    "slot_no": reserve["slot_no"],
                },
                reason=payload.reason,
                operator_id=getattr(user, "id", None),
                operator_name=getattr(user, "name", None),
            ))

            await self.db.commit()

        except Exception:
            # 回滚：释放新号
            await self.m04.release_slot(
                slot_id=reserve["slot_id"], reason="改约失败回滚")
            raise BizException("0402018", "改约失败，原预约保持不变")

        # 4. 通知
        if payload.notify:
            await self._send_notify(appt, "APPT_RESCHEDULED")

        return {
            "old_appt_no": old_appt_no,
            "new_appt_no": appt.appt_no,
            "old_slot_id": old_snapshot["slot_id"],
            "new_slot_id": appt.slot_id,
            "new_appointment_date": appt.appointment_date.isoformat(),
            "new_period_text": self._period_full_text(appt),
            "reschedule_count": appt.reschedule_count,
            "max_reschedule": max_reschedule,
            "status": appt.status,
            "notified": payload.notify,
        }

    # ---------- 取消 ----------
    async def cancel(self, appt_id: int, payload, user) -> dict:
        """取消预约"""
        appt = await self._get_appt(appt_id)

        if appt.status in ("CANCELLED", "REGISTERED", "NO_SHOW", "CHANGED"):
            raise BizException("0402002",
                f"当前状态 {self._status_text(appt.status)} 不可取消")

        if appt.status == "CHECKED_IN":
            raise BizException("0402020", "预约已签到，无法取消，请走退号流程")

        config = await self._get_config()
        cutoff_hours = config.get("cancel_cutoff_hours", 2)
        appt_dt = datetime.combine(appt.appointment_date,
                                     appt.start_time or time(8, 0))
        is_late = datetime.now() + timedelta(hours=cutoff_hours) > appt_dt

        if is_late and payload.source == "PORTAL":
            raise BizException("0402019",
                f"距开诊不足 {cutoff_hours} 小时，请到院办理")

        # 释放号源
        await self.m04.release_slot(slot_id=appt.slot_id, reason="取消预约")

        appt.status = "CANCELLED"
        appt.cancelled_at = datetime.now()
        appt.cancel_reason = payload.reason
        appt.cancelled_by = getattr(user, "id", None)

        self.db.add(M04ApptChangeLog(
            appt_id=appt.id,
            appt_no=appt.appt_no,
            action="CANCEL",
            before_json={"status": "BOOKED"},
            after_json={"status": "CANCELLED"},
            reason=payload.reason,
            operator_id=getattr(user, "id", None),
            operator_name=getattr(user, "name", None) or "患者自助",
        ))

        # 取消提醒
        await self.db.execute(
            M04ApptReminder.__table__.update()
            .where(
                M04ApptReminder.appt_id == appt.id,
                M04ApptReminder.send_status == "PENDING",
            )
            .values(send_status="CANCELLED")
        )

        await self.db.commit()

        # 临近取消扣分
        credit_change = 0
        if is_late:
            credit_change = -(config.get("late_cancel_penalty", 5))
            await self._adjust_credit(appt.patient_id, credit_change,
                                        "临近开诊取消预约")

        if payload.notify:
            await self._send_notify(appt, "APPT_CANCELLED")

        return {
            "appt_no": appt.appt_no,
            "status": "CANCELLED",
            "slot_released": True,
            "credit_change": credit_change,
            "notified": payload.notify,
        }

    async def check_in(self, appt_id: int, payload, user) -> dict:

                f"当前状态 {self._status_text(appt.status)} 不可签到")

        earlier_minutes = config.get("checkin_earlier_minutes", 60)

        if datetime.now() < earliest:
            raise BizException("0402022",
                f"签到时间未到，最早可提前 {earlier_minutes} 分钟签到")

        # 班次结束前可签到
        end_dt = datetime.combine(appt.appointment_date,
                                    appt.end_time or time(17, 0))
        if datetime.now() > end_dt + timedelta(hours=1):
            raise BizException("0402023", "已过签到时间")

        appt.status = "CHECKED_IN"
        appt.checkin_at = datetime.now()
        appt.checkin_by = getattr(user, "id", None)

        self.db.add(M04ApptChangeLog(
            appt_id=appt.id,
            appt_no=appt.appt_no,
            action="CHECK_IN",
            after_json={"status": "CHECKED_IN"},
            operator_id=getattr(user, "id", None),
            operator_name=getattr(user, "name", None),
        ))

        await self.db.commit()

        return {
            "appt_no": appt.appt_no,
            "status": "CHECKED_IN",
            "checkin_at": appt.checkin_at.isoformat(),
            "queue_no": appt.queue_no,

    async def on_patient_merged(self, payload: dict) -> dict:
        """患者合并，重定向预约"""
        merged = payload["merged_patient_id"]
        survivor = payload["survivor_patient_id"]

        rows = (await self.db.execute(
            select(M04Appointment).where(
                M04Appointment.patient_id == merged,
                M04Appointment.status.in_(("PENDING", "BOOKED", "CHECKED_IN")),
            )
        )).scalars().all()

        changed = 0
        cancelled = 0

        for appt in rows:
            # 检查是否重复预约同一时段
            dup = (await self.db.execute(
                select(M04Appointment).where(
                    M04Appointment.patient_id == survivor,
                    M04Appointment.appointment_date == appt.appointment_date,
                    M04Appointment.period == appt.period,
                    M04Appointment.status.in_(("PENDING", "BOOKED", "CHECKED_IN")),
                )
            )).scalar_one_or_none()

            if dup:
                # 释放号源
                await self.m04.release_slot(
                    slot_id=appt.slot_id, reason="患者合并去重")
                appt.status = "CANCELLED"
                appt.cancel_reason = "患者合并，重复预约已取消"
                cancelled += 1
            else:
                appt.patient_id = survivor
                changed += 1

            self.db.add(M04ApptChangeLog(
                appt_id=appt.id,
                appt_no=appt.appt_no,
                action="MERGE_REDIRECT",
                after_json={"patient_id": survivor},
                reason=f"患者合并 {merged} → {survivor}",
            ))

        await self.db.commit()

        return {
            "affected": len(rows),
            "redirected": changed,
            "cancelled": cancelled,
        }

            if d > datetime.now():
```

```python
"""患者预约信用分服务"""
from datetime import datetime
from typing import Optional

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.m04.appointment import M04ApptCredit, M04ApptCreditLog
from app.core.exceptions import BizException


class CreditService:
    """预约信用分"""

    DEFAULT_SCORE = 100
    MAX_SCORE = 100
    MIN_SCORE = 0
    NO_SHOW_PENALTY = 10
    NORMAL_VISIT_BONUS = 1
    BLACKLIST_THRESHOLD = 60

    def __init__(self, db: AsyncSession):
        self.db = db

    async def get_credit(self, patient_id: int) -> dict:
        """获取信用分"""
        credit = (await self.db.execute(
            select(M04ApptCredit).where(
                M04ApptCredit.patient_id == patient_id,
                M04ApptCredit.is_deleted == False,
            )
        )).scalar_one_or_none()

        if not credit:
            # 懒创建
            credit = M04ApptCredit(
                patient_id=patient_id,
                score=self.DEFAULT_SCORE,
                no_show_count=0,
                visit_count=0,
                is_blacklisted=False,
            )
            self.db.add(credit)
            await self.db.commit()

        return {
            "patient_id": patient_id,
            "score": credit.score,
            "level": self._level(credit.score),
            "level_text": self._level_text(credit.score),
            "no_show_count": credit.no_show_count,
            "visit_count": credit.visit_count,
            "is_blacklisted": credit.is_blacklisted,
            "last_no_show_at": (credit.last_no_show_at.isoformat()
                                 if credit.last_no_show_at else None),
        }

    async def adjust(self, patient_id: int, payload, user) -> dict:
        """手动调整信用分（需权限）"""
        if not payload.reason or len(payload.reason.strip()) < 5:
            raise BizException(40001, "调整原因至少 5 个字")

        return await self.adjust_internal(
            patient_id, payload.delta, payload.reason,
            operator_id=getattr(user, "id", None),
            operator_name=getattr(user, "name", None))

    async def adjust_internal(self, patient_id: int, delta: int,
                                reason: str,
                                operator_id: Optional[int] = None,
                                operator_name: Optional[str] = None) -> dict:
        """调整信用分（内部）"""
        credit = (await self.db.execute(
            select(M04ApptCredit).where(
                M04ApptCredit.patient_id == patient_id,
                M04ApptCredit.is_deleted == False,
            )
        )).scalar_one_or_none()

        if not credit:
            credit = M04ApptCredit(
                patient_id=patient_id,
                score=self.DEFAULT_SCORE,
                no_show_count=0,
                visit_count=0,
            )
            self.db.add(credit)
            await self.db.flush()

        before = credit.score
        after = max(self.MIN_SCORE, min(self.MAX_SCORE, before + delta))
        credit.score = after
        credit.is_blacklisted = after < self.BLACKLIST_THRESHOLD

        self.db.add(M04ApptCreditLog(
            patient_id=patient_id,
            before_score=before,
            after_score=after,
            delta=after - before,
            reason=reason,
            operator_id=operator_id,
            operator_name=operator_name,
        ))

        await self.db.commit()

        return {
            "patient_id": patient_id,
            "before_score": before,
            "after_score": after,
            "delta": after - before,
            "is_blacklisted": credit.is_blacklisted,
        }

    async def on_no_show(self, patient_id: int) -> dict:
        """爽约扣分"""
        credit = (await self.db.execute(
            select(M04ApptCredit).where(
                M04ApptCredit.patient_id == patient_id,
            )
        )).scalar_one_or_none()

        if credit:
            credit.no_show_count += 1
            credit.last_no_show_at = datetime.now()

        return await self.adjust_internal(
            patient_id, -self.NO_SHOW_PENALTY, "预约爽约")

    async def on_visit(self, patient_id: int) -> dict:
        """正常就诊加分"""
        credit = (await self.db.execute(
            select(M04ApptCredit).where(
                M04ApptCredit.patient_id == patient_id,
            )
        )).scalar_one_or_none()

        if credit:
            credit.visit_count += 1

        return await self.adjust_internal(
            patient_id, self.NORMAL_VISIT_BONUS, "正常就诊")

    @staticmethod
    def _level(score: int) -> str:
        if score >= 80:
            return "GOOD"
        if score >= 60:
            return "WARNING"
        return "BLOCKED"

    @staticmethod
    def _level_text(score: int) -> str:
        if score >= 80:
            return "正常"
        if score >= 60:
            return "偏低（不可约专家号）"
        return "过低（需人工审核）"
```

```python
    try:
        async with AsyncSessionLocal() as db:
            d = date.fromisoformat(target_date) if target_date else date.today()

            config = (await db.execute(
                select(M04ApptConfig).where(M04ApptConfig.id == 1)
            )).scalar_one_or_none()
            delay_min = config.no_show_delay_minutes if config else 30

            # 当天所有 BOOKED 的预约
            appts = (await db.execute(
                select(M04Appointment).where(
                    M04Appointment.appointment_date == d,
                    M04Appointment.status == "BOOKED",
                )
            )).scalars().all()

            now = datetime.now()
            marked = 0
            credit_svc = CreditService(db)

            for appt in appts:
                end_dt = datetime.combine(
                    appt.appointment_date,
                    appt.end_time or time(17, 0))
                if now < end_dt + timedelta(minutes=delay_min):
                    continue

                appt.status = "NO_SHOW"
                appt.no_show_at = now

                db.add(M04ApptChangeLog(
                    appt_id=appt.id,
                    appt_no=appt.appt_no,
                    action="NO_SHOW",
                    after_json={"status": "NO_SHOW"},
                    reason="班次结束未到院",
                ))

                await credit_svc.on_no_show(appt.patient_id)
                marked += 1

            await db.commit()
            return {"date": d.isoformat(), "marked": marked}
    finally:
        await redis_client.delete("m04:appt:no-show:lock")


@shared_task
def expire_pending_appointments_task():
    """过期未确认的预约"""
    import asyncio
    return asyncio.run(_expire_pending())


async def _expire_pending():
    from datetime import datetime, timedelta
    from sqlalchemy import select
    from app.models.m04.appointment import (
        M04Appointment, M04ApptConfig, M04ApptChangeLog,
    )
    from app.core.database import AsyncSessionLocal

    async with AsyncSessionLocal() as db:
        config = (await db.execute(
            select(M04ApptConfig).where(M04ApptConfig.id == 1)
        )).scalar_one_or_none()
        timeout_min = config.pending_timeout_minutes if config else 15

        deadline = datetime.now() - timedelta(minutes=timeout_min)

        rows = (await db.execute(
            select(M04Appointment).where(
                M04Appointment.status == "PENDING",
                M04Appointment.created_at <= deadline,
            )
        )).scalars().all()

        for appt in rows:
            appt.status = "EXPIRED"
            db.add(M04ApptChangeLog(
                appt_id=appt.id,
                appt_no=appt.appt_no,
                action="EXPIRE",
                after_json={"status": "EXPIRED"},
                reason=f"待确认超过 {timeout_min} 分钟",
            ))

            # 释放号源
            from app.clients.m04_client import M04InternalClient
            try:
                await M04InternalClient().release_slot(
                    slot_id=appt.slot_id, reason="预约确认超时")
            except Exception:
                pass

        await db.commit()
        return {"expired": len(rows)}
```
