## 1. 模块概述

### 1.1 模块定位

绿色通道与特殊号是门诊的**公平性调节机制**。它回答："**哪些人应该优先？加号给谁？怎么防止滥用？**"

```
┌──────────────────────────────────────────────────────────────┐
│  M04-01 排班与号源（号源供给）                                 │
└────────────────────────┬─────────────────────────────────────┘
                         │ 加号 / 留号
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M04-06 绿色通道与特殊号（本文档）                             │
│  · 优先人群认定（军残、老年、儿童、急危重）                     │
│  · 特殊号凭证管理                                             │
│  · 加号申请与审批                                             │
│  · 免费/减免登记                                              │
└────────────────────────┬─────────────────────────────────────┘
                         │
        ┌────────────────┼────────────────┐
        ▼                ▼                ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ 02 预约       │ │ 03 挂号      │ │ 04 分诊       │
│  优先预约     │ │  特殊号挂号   │ │  优先级提升   │
└──────────────┘ └──────────────┘ └──────────────┘
```

### 1.2 为什么需要独立子模块

| 理由 | 说明 |
|---|---|
| **政策性强** | 军残、优抚、老年人权益保护有明确政策依据 |
| **需要审核** | 加号、免费必须有审批，防止滥用 |
| **凭证管理** | 残疾证、优抚证需要登记、核验、留档 |
| **跨子模块** | 影响预约、挂号、分诊、叫号四个环节 |
| **可追溯** | 谁享受了优惠、谁审批的，必须留痕 |

### 1.3 与相邻模块的分工

| 能力 | 归属 |
|---|---|
| 号源生成与库存 | M04-01 |
| **特殊号凭证登记与核验** | **M04-06 本子模块** |
| **加号申请与审批** | **M04-06 本子模块** |
| **免费/减免政策配置** | **M04-06 本子模块** |
| **优先人群认定** | **M04-06 本子模块** |
| 预约（含优先预约） | M04-02 |
| 挂号（含特殊号挂号） | M04-03 |
| 分诊（含优先级提升） | M04-04 |
| 叫号（继承优先级） | M04-05 |
| 费用减免执行 | M16 |
| 残疾证/优抚证真实性核验 | M21（对接残联/民政） |

> **边界一句话：** 本子模块只管"谁有资格优先、加号给谁、优惠给谁"；**不做**号源生成（M04-01）、**不做**实际挂号收费（M04-03/M16）、**不做**队列排序算法（M04-04）。

### 1.4 优先人群分类

| 类别 | 代码 | 依据 | 优惠 |
|---|---|---|---|
| 残疾军人 | `DISABLED_MILITARY` | 《军人抚恤优待条例》 | 免挂号费 + 优先 |
| 伤残人民警察 | `DISABLED_POLICE` | 《人民警察抚恤优待办法》 | 免挂号费 + 优先 |
| 残疾消防救援人员 | `DISABLED_FIRE` | 相关政策 | 免挂号费 + 优先 |
| 优抚对象 | `PREFERENTIAL` | 《优抚对象医疗保障办法》 | 减免 + 优先 |
| 老年人 | `ELDERLY` | 《老年人权益保障法》 | 优先（≥80 岁） |
| 儿童 | `CHILD` | 儿科惯例 | 优先（≤3 岁） |
| 急危重 | `CRITICAL` | 医疗安全 | 立即优先 |
| 计划生育特殊家庭 | `FAMILY_PLAN` | 相关政策 | 优先 |
| 见义勇为人员 | `GOOD_SAMARITAN` | 地方政策 | 免挂号费 + 优先 |
| 无偿献血荣誉者 | `BLOOD_DONOR` | 地方政策（"三免"） | 免挂号费 |

> **说明：** 以上为**默认配置**，各医院可根据当地政策调整。

### 1.5 与分诊优先级的衔接

**M04-04 已定义五级分诊与加分规则，本子模块为其提供"特殊标记"来源：**

| 本子模块 | 传入 M04-04 的 `special_flags` | M04-04 的级别覆盖 |
|---|---|---|
| 绿色通道 | `GREEN_CHANNEL` | 最低 L2 |
| 军残/优抚 | `VETERAN` | 最低 L4 + 加分 100 |
| 老年人（≥80） | `ELDERLY` | 最低 L4 + 加分 50 |
| 儿童（≤3） | `CHILD` | 最低 L4 + 加分 50 |

> **关键：** 本子模块**不直接决定分诊级别**，只提供标记；级别与加分的具体规则在 M04-04。

### 1.6 模块目标

- **合规**：严格执行优抚政策，可审计。
- **防滥用**：凭证核验 + 审核流程 + 次数限制。
- **便捷**：导医一键登记，患者少跑腿。
- **可追溯**：每次优惠、加号、审批全留痕。
- **可配置**：政策变化时能快速调整。

### 1.7 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 导医/挂号员 | 登记特殊号 | 凭证登记、加盖标记 |
| 科室主任 | 审核加号 | 审批本科室加号 |
| 医务科 | 审核特殊加号 | 审批跨科室/大额加号 |
| 院领导 | 特批 | 特批权限 |
| 财务 | 核对减免 | 查看减免统计 |
| 审计员 | 监督 | 查看审批与减免记录 |

## 3. 业务模型

### 3.1 优先人群认定模型

#### 3.1.1 认定条件

| 类型 | 认定条件 | 所需凭证 | 有效期 |
|---|---|---|---|
| 残疾军人 | 持《残疾军人证》 | 残疾军人证 | 证件有效期 |
| 伤残警察 | 持《伤残人民警察证》 | 伤残人民警察证 | 证件有效期 |
| 残疾消防 | 持《残疾消防救援人员证》 | 相应证件 | 证件有效期 |
| 优抚对象 | 持《优抚对象优待证》 | 优待证 | 证件有效期 |
| 老年人 | 年龄 ≥ 80（可配） | 身份证 | 长期 |
| 儿童 | 年龄 ≤ 3（可配） | 身份证/出生证 | 至 3 岁 |
| 急危重 | 分诊 L1/L2 | 无需 | 单次 |
| 计划生育特殊家庭 | 持《计划生育特殊家庭扶助证》 | 扶助证 | 证件有效期 |
| 见义勇为 | 持荣誉证书 | 证书 | 长期 |
| 无偿献血荣誉者 | 持荣誉证 | 荣誉证 | 证件有效期 |

#### 3.1.2 认定流程

```
患者到院
   ↓
导医识别 → 询问/主动出示
   ↓
出示凭证？
   ├─ 是 → 登记凭证 → 核验
   │        ├─ 核验通过 → 建立特殊号资格 → 加标记
   │        └─ 核验失败 → 提示不符，走普通流程
   └─ 否 ↓
按年龄自动识别（老年/儿童）
   ├─ 满足 → 自动标记
   └─ 不满足 → 普通流程
```

### 3.2 特殊号凭证模型

#### 3.2.1 凭证状态机

```
        ┌──────────────┐
        │   PENDING    │  待核验（已登记）
        └──────┬───────┘
               │
       ┌───────┼────────────┬──────────────┐
       │ 核验通过│ 核验失败     │ 过期          │
       ▼       ▼            ▼              ▼
┌──────────┐┌──────────┐┌──────────┐┌──────────┐
│ VERIFIED ││ REJECTED ││ EXPIRED  ││ REVOKED  │
│ 已核验    ││ 已拒绝    ││ 已过期    ││ 已撤销    │
└────┬─────┘└──────────┘└──────────┘└──────────┘
     │
     │ 使用
     ▼
┌──────────┐
│  USED    │  已使用（单次凭证）
└──────────┘
```

**状态说明：**

| 状态 | 说明 | 可否使用 |
|---|---|---|
| `PENDING` | 已登记待核验 | ❌ |
| `VERIFIED` | 核验通过，可多次使用（至有效期） | ✅ |
| `REJECTED` | 核验失败 | ❌ |
| `EXPIRED` | 超过有效期 | ❌ |
| `REVOKED` | 人工撤销 | ❌ |
| `USED` | 单次凭证已用 | ❌ |

#### 3.2.2 凭证有效期

| 凭证类型 | 有效期 |
|---|---|
| 残疾军人证 | 证件有效期（通常 10 年） |
| 优抚对象优待证 | 证件有效期 |
| 年龄类（老年/儿童） | 长期（至条件不再满足） |
| 单次特殊（急危重） | 当次 |

#### 3.2.3 使用次数限制

| 类型 | 年度次数上限 | 说明 |
|---|---|---|
| 残疾军人 | 不限 | 政策要求 |
| 优抚对象 | 不限 | 政策要求 |
| 老年/儿童 | 不限 | — |
| 见义勇为 | 不限 | — |
| **急危重** | 不限 | 每次独立 |
| **特批减免** | 12 次/年 | 防滥用 |

> **说明：** 政策类（军残、优抚）**不设次数限制**；特批类需限制。

### 3.3 加号模型

#### 3.3.1 加号场景

| 场景 | 说明 | 审批 |
|---|---|---|
| **医生加号** | 医生为复诊/熟人加号 | 医生直接（≤上限） |
| **科室加号** | 科室为特殊患者加号 | 科主任 |
| **绿色通道加号** | 军残等优先人群 | 导医直接（自动） |
| **急危重加号** | 急诊患者 | 导医直接 |
| **患者请求加号** | 患者主动要求 | 科主任/医务科 |
| **特批加号** | 院领导特批 | 院领导 |

#### 3.3.2 加号审批流程

```
加号申请
   ↓
申请类型？
├─ AUTO（绿色通道/急危重）→ 直接执行
└─ MANUAL（其他）↓
   数量判断？
   ├─ ≤ 医生上限（默认 5/班次）→ 科主任审批
   └─ > 上限 → 医务科审批
       ↓
   审批
   ├─ 通过 → 执行加号（调 M04-01）
   └─ 驳回 → 通知申请人
```

#### 3.3.3 加号状态机

```
        ┌──────────┐
        │ PENDING  │  待审批
        └────┬─────┘
             │
    ┌────────┼────────┐
    │ 通过    │ 驳回    │ 取消
    ▼        ▼        ▼
┌──────────┐┌──────────┐┌──────────┐
│ APPROVED ││ REJECTED ││CANCELLED │
└────┬─────┘└──────────┘└──────────┘
     │ 执行
     ▼
┌──────────┐
│ EXECUTED │
└──────────┘
```

### 3.5 优先级衔接模型

```
本子模块认定特殊号
   ↓
生成 special_flags
   ├─ GREEN_CHANNEL（绿色通道）
   ├─ VETERAN（军残/优抚）
   ├─ ELDERLY（老年）
   └─ CHILD（儿童）
   ↓
传递给 M04-02 / M04-03 / M04-04
   ↓
M04-04 分诊时：
   - 应用级别覆盖（只能提升）
   - 应用加分（priority_weight）
   ↓
M04-05 叫号时按权重排序
```

### 3.6 防滥用机制

| 机制 | 说明 |
|---|---|
| **凭证核验** | 必须通过核验才能获得资格 |
| **单患者单凭证** | 一个患者同一类凭证只能登记一次 |
| **凭证唯一** | 同一凭证号不能被多个患者使用 |
| **有效期管理** | 过期自动失效 |
| **次数限制** | 特批类年度限制 |
| **审批留痕** | 所有审批记录不可删除 |
| **异常监控** | 单人高频使用告警 |
| **抽查复核** | 每月随机抽查（人工） |

### 6.5 Service 层核心逻辑示例

```python
# app/services/m04/special_service.py
"""特殊号凭证服务"""
import uuid
from datetime import date, datetime, timedelta
from decimal import Decimal
from typing import Optional, List

from sqlalchemy import select, and_, or_, func, desc
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.m04.special import (
    M04SpecialCert, M04SpecialPersonType, M04SpecialPolicy,
    M04SpecialUsage, M04SpecialAnomaly, M04SpecialBlacklist,
)
from app.core.exceptions import BizException
from app.core.redis import redis_client
from app.clients.mpi_client import MpiClient
from app.clients.m21_client import M21Client


class SpecialCertService:
    """特殊号凭证管理"""

    def __init__(self, db: AsyncSession):
        self.db = db
        self.mpi = MpiClient()
        self.m21 = M21Client()

    # ---------- 登记 ----------
    async def create(self, payload, user) -> dict:
        """登记特殊号凭证"""
        # 1. 人群类型校验
        ptype = (await self.db.execute(
            select(M04SpecialPersonType).where(
                M04SpecialPersonType.type_code == payload.person_type_code,
                M04SpecialPersonType.is_enabled == True,
                M04SpecialPersonType.is_deleted == False,
            )
        )).scalar_one_or_none()

        if not ptype:
            raise BizException("0406009", "不合格的人群类型")

        # 2. 患者校验
        patient = await self.mpi.get_patient(payload.patient_id)
        if not patient:
            raise BizException("0406031", "患者不存在或已注销")

        # 3. 黑名单校验
        blacklisted = (await self.db.execute(
            select(M04SpecialBlacklist).where(
                M04SpecialBlacklist.patient_id == payload.patient_id,
                M04SpecialBlacklist.is_active == True,
            )
        )).scalar_one_or_none()

        if blacklisted:
            raise BizException("0406025", "该患者已被列入特殊号黑名单",
                data={"reason": blacklisted.reason})

        # 4. 年龄类自动判定
        if ptype.auto_by_age:
            age = patient.get("age") or 0
            if ptype.min_age is not None and age < ptype.min_age:
                raise BizException("0406010",
                    f"患者年龄 {age} 岁，不满足 {ptype.type_name} 的条件"
                    f"（≥{ptype.min_age} 岁）")
            if ptype.max_age is not None and age > ptype.max_age:
                raise BizException("0406010",
                    f"患者年龄 {age} 岁，不满足 {ptype.type_name} 的条件"
                    f"（≤{ptype.max_age} 岁）")

        # 5. 重复登记校验
        existing = (await self.db.execute(
            select(M04SpecialCert).where(
                M04SpecialCert.patient_id == payload.patient_id,
                M04SpecialCert.person_type_code == payload.person_type_code,
                M04SpecialCert.status.in_(("VERIFIED", "PENDING")),
            )
        )).scalar_one_or_none()

        if existing:
            raise BizException("0406003", "该患者已登记同类型特殊号凭证",
                data={"existing_cert": {
                    "cert_id": existing.id,
                    "cert_no": existing.cert_no,
                    "person_type_name": ptype.type_name,
                    "status_text": existing.status_label(),
                    "valid_to": (existing.valid_to.isoformat()
                                  if existing.valid_to else None),
                }})

        # 6. 凭证号唯一性
        if payload.cert_no:
            conflict = (await self.db.execute(
                select(M04SpecialCert).where(
                    M04SpecialCert.cert_no == payload.cert_no,
                    M04SpecialCert.patient_id != payload.patient_id,
                    M04SpecialCert.status.in_(("VERIFIED", "PENDING")),
                )
            )).scalar_one_or_none()

            if conflict:
                raise BizException("0406004", "该凭证号已被其他患者使用",
                    data={
                        "cert_no": payload.cert_no,
                        "used_by": {
                            "patient_id": conflict.patient_id,
                            "patient_name": conflict.patient_name,
                            "registered_at": (conflict.created_at.isoformat()
                                                if conflict.created_at else None),
                        },
                        "severity": "HIGH",
                        "suggestion": "疑似冒用，请核实后处理",
                    })

        # 7. 有效期校验
        if payload.valid_to and payload.valid_to < date.today():
            raise BizException("0406030", "凭证有效期无效",
                data={
                    "valid_from": (payload.valid_from.isoformat()
                                    if payload.valid_from else None),
                    "valid_to": payload.valid_to.isoformat(),
                    "today": date.today().isoformat(),
                    "is_expired": True,
                    "suggestion": "该凭证已过期，请患者更新后再登记",
                })

        # 8. 凭证照片必传（政策类）
        if not ptype.auto_by_age and not payload.cert_photo_front:
            raise BizException("0406008", "政策类凭证必须上传正面照片")

        # 9. 创建记录
        cert = M04SpecialCert(
            cert_no=payload.cert_no or f"AUTO{datetime.now().strftime('%Y%m%d%H%M%S')}",
            patient_id=payload.patient_id,
            empi_no=patient.get("empi_no"),
            patient_name=patient.get("patient_name"),
            patient_age=patient.get("age"),
            person_type_code=payload.person_type_code,
            person_type_name=ptype.type_name,
            cert_issuer=payload.cert_issuer,
            valid_from=payload.valid_from or date.today(),
            valid_to=payload.valid_to,
            disability_level=payload.disability_level,
            cert_photo_front=payload.cert_photo_front,
            cert_photo_back=payload.cert_photo_back,
            verify_mode=payload.verify_mode,
            status="PENDING",
            special_flags=ptype.special_flags,
            priority_bonus=ptype.priority_bonus,
            override_level=ptype.override_level,
            annual_limit=ptype.annual_limit,
            annual_used=0,
            remark=payload.remark,
            created_by=getattr(user, "id", None),
            created_by_name=getattr(user, "name", None),
        )
        self.db.add(cert)
        await self.db.flush()

        await self.db.commit()

        # 10. 立即核验
        return await self._do_verify(cert, payload.verify_mode, payload, user)

    # ---------- 核验 ----------
    async def verify(self, cert_id: int, payload, user) -> dict:
        """核验凭证"""
        cert = await self._get_cert(cert_id)

        if cert.status not in ("PENDING", "REJECTED"):
            raise BizException("0406002",
                f"凭证状态 {cert.status_label()} 不可核验")

        fail_reason = None

                    cert_type=cert.person_type_code,
                    cert_no=cert.cert_no,
                    patient_name=cert.patient_name,
                    id_no=None,
                )
                verified = bool(result and result.get("valid"))
                if not verified:
                    fail_reason = (result or {}).get("reason", "联网核验未通过")
            except Exception as e:
                raise BizException("0406026", "联网核验服务不可用，请改用手工核验")
        else:
            # 手工核验：导医已目视核对，直接通过
            verified = True

        if verified:
            cert.status = "VERIFIED"
            cert.verified_at = datetime.now()
            cert.verified_by = getattr(user, "id", None)
            cert.verified_by_name = getattr(user, "name", None)
            cert.verify_mode = mode
        else:
            cert.status = "REJECTED"
            cert.reject_reason = fail_reason

        await self.db.commit()

        if not verified:
            raise BizException("0406007", f"凭证核验失败：{fail_reason}")

        # 计算权益
        policy = await self._get_policy(cert.person_type_code)

        return {

        for c in valid_certs:
            all_flags.update(c.get_flags())
            total_bonus += c.priority_bonus or 0
            if c.override_level:
                if (best_override is None
                        or LEVEL_ORDER.get(c.override_level, 99)
                        < LEVEL_ORDER.get(best_override, 99)):

        blacklisted = (await self.db.execute(
            select(M04SpecialBlacklist).where(
                M04SpecialBlacklist.patient_id == patient_id,
                M04SpecialBlacklist.is_active == True,
            )
        )).scalar_one_or_none()

        return {
            "patient_id": patient_id,
            "has_special": True,
            "flags": sorted(all_flags),
            "bonus_weight": total_bonus,
            "override_level": best_override,
            "certs": [
                {
                    "cert_id": c.id,
                    "person_type_code": c.person_type_code,

                    "cert_no": c.cert_no,

        month_start = date.today().replace(day=1)
        high_freq = (await self.db.execute(
            select(

                func.count().label("cnt"),
            ).where(
                M04SpecialUsage.used_at >= month_start,

                M04SpecialUsage.patient_id, M04SpecialUsage.patient_name
            ).having(func.count() > 10)
        )).all()

        avg_usage = 4.0
        for pid, pname, cnt in high_freq:
            if cnt > avg_usage * 3:
                anomalies.append({
                    "type": "HIGH_FREQUENCY",
                    "severity": "WARNING",
                    "patient_id": pid,
                    "patient_name": pname,
                    "description": f"本月使用 {cnt} 次，超出均值 "
                                    f"{round(cnt / avg_usage, 1)} 倍",
                    "count": cnt,
                    "average": avg_usage,
                    "actions": ["VIEW_DETAIL", "MARK_REVIEW"],
                })

        # 2. 凭证冲突（同凭证号多患者）
        conflicts = (await self.db.execute(
            select(
                M04SpecialCert.cert_no,
                func.count().label("cnt"),
            ).where(
                M04SpecialCert.status.in_(("VERIFIED", "PENDING")),
                M04SpecialCert.cert_no.isnot(None),
            ).group_by(M04SpecialCert.cert_no)
            .having(func.count() > 1)
        )).all()

        for cert_no, cnt in conflicts:
            patients = (await self.db.execute(
                select(M04SpecialCert.patient_id,
                        M04SpecialCert.patient_name)
                .where(M04SpecialCert.cert_no == cert_no,
                        M04SpecialCert.status.in_(("VERIFIED", "PENDING")))
            )).all()

            anomalies.append({
                "type": "CERT_CONFLICT",
                "severity": "CRITICAL",
                "cert_no": cert_no,
                "patient_ids": [p[0] for p in patients],
                "patient_names": [p[1] for p in patients],
                "description": f"同一凭证号被 {cnt} 个患者登记",
                "actions": ["VIEW_CONFLICT", "HANDLE"],

                M04SpecialCert.status == "VERIFIED",
                M04SpecialCert.valid_to.isnot(None),

                M04SpecialCert.valid_to >= date.today(),

                "severity": "INFO",
```

```python
    async def approve(self, apply_id: int, payload, user) -> dict:
        """审批通过"""
        apply = await self._get_apply(apply_id)

        if apply.status != "PENDING":
            raise BizException("0406018",
                f"该申请已 {self._status_text(apply.status)}")

        node = (await self.db.execute(
            select(M04AddQuotaApproval).where(
                M04AddQuotaApproval.apply_id == apply_id,
                M04AddQuotaApproval.status == "PENDING",
            ).order_by(M04AddQuotaApproval.seq.asc()).limit(1)
        )).scalar_one_or_none()

        if not node:
            raise BizException("0406012", "无待审批节点")

        # 权限校验
        if node.approver_id and node.approver_id != getattr(user, "id", None):
            # 允许同角色审批
            if not self._can_approve(node, user):
                raise BizException("0406016", "无权审批该申请")

        node.status = "APPROVED"
        node.approved_at = datetime.now()
        node.opinion = payload.opinion
        node.actual_approver_id = getattr(user, "id", None)
        node.actual_approver_name = getattr(user, "name", None)

        # 下一节点
        next_node = (await self.db.execute(
            select(M04AddQuotaApproval).where(
                M04AddQuotaApproval.apply_id == apply_id,
                M04AddQuotaApproval.seq > node.seq,
                M04AddQuotaApproval.status == "WAITING",
            ).order_by(M04AddQuotaApproval.seq.asc()).limit(1)
        )).scalar_one_or_none()

        if next_node:
            next_node.status = "PENDING"
            apply.current_node = next_node.seq
            await self.db.commit()

            return {
                "apply_id": apply.id,
                "apply_no": apply.apply_no,
                "status": "PENDING",
                "status_text": "待审批",
                "approved_node": {
                    "seq": node.seq,
                    "node_name": node.node_name,
                    "approver_name": node.actual_approver_name,
                    "approved_at": node.approved_at.isoformat(),
                },
                "next_node": {
                    "seq": next_node.seq,
                    "node_name": next_node.node_name,
                    "status": "PENDING",
                },
                "message": f"已通过本级审批，转交{next_node.node_name}",
            }

        # 全部完成
        apply.status = "APPROVED"
        apply.current_node = None
        apply.approved_at = datetime.now()

        await self.db.commit()

        # 执行加号
        result = await self._execute(apply)

        return {
            "apply_id": apply.id,
            "apply_no": apply.apply_no,
            "status": "EXECUTED",
            "status_text": "已执行",
            "approved_node": {
                "seq": node.seq,
                "node_name": node.node_name,
                "approver_name": node.actual_approver_name,
                "approved_at": node.approved_at.isoformat(),
            },
            "next_node": None,
            "add_quota_result": result,
            "patient_notified": True,
            "message": "审批完成，加号已执行",
        }

    def _can_approve(self, node, user) -> bool:
        """判断是否有审批权"""
        user_roles = getattr(user, "roles", []) or []
        if node.approver_role == "DEPT_HEAD" and "DEPT_HEAD" in user_roles:
            return True
        if node.approver_role == "MEDICAL_AFFAIRS" and \
                "MEDICAL_AFFAIRS" in user_roles:
            return True
        return False

    async def reject(self, apply_id: int, payload, user) -> dict:
        """审批驳回"""
        apply = await self._get_apply(apply_id)

        if apply.status != "PENDING":
            raise BizException("0406018", f"该申请已 {self._status_text(apply.status)}")

        if not payload.reason or len(payload.reason.strip()) < 2:
            raise BizException(40001, "驳回原因至少 2 个字")

        node = (await self.db.execute(
            select(M04AddQuotaApproval).where(
                M04AddQuotaApproval.apply_id == apply_id,
                M04AddQuotaApproval.status == "PENDING",
            ).order_by(M04AddQuotaApproval.seq.asc()).limit(1)
        )).scalar_one_or_none()

        if node:
            node.status = "REJECTED"
            node.rejected_at = datetime.now()
            node.opinion = payload.reason
            node.actual_approver_id = getattr(user, "id", None)
            node.actual_approver_name = getattr(user, "name", None)

        # 后续节点作废
        await self.db.execute(
            M04AddQuotaApproval.__table__.update()
            .where(
                M04AddQuotaApproval.apply_id == apply_id,
                M04AddQuotaApproval.status == "WAITING",
            )
            .values(status="CANCELLED")
        )

        apply.status = "REJECTED"
        apply.reject_reason = payload.reason
        apply.rejected_at = datetime.now()

        await self.db.commit()

        # 通知申请人
        try:
            await self.msg.send(
                biz_type="ADD_QUOTA_REJECTED",
                receivers=[apply.patient_id],
                params={
                    "apply_no": apply.apply_no,
                    "reason": payload.reason,
                })
        except Exception:
            pass

        return {
            "apply_id": apply.id,
            "apply_no": apply.apply_no,
            "status": "REJECTED",
            "status_text": "已驳回",
            "reason": payload.reason,
        }

    # ---------- 执行加号 ----------
    async def _execute(self, apply: M04AddQuotaApply) -> dict:
        """执行加号（调 M04-01）"""
        try:
            result = await self.m04.add_quota(
                schedule_id=apply.schedule_id,
                add_count=apply.add_count,
                reason=f"加号申请 {apply.apply_no}",
            )

            apply.status = "EXECUTED"
            apply.executed_at = datetime.now()
            apply.executed = True
            apply.new_slot_nos = ",".join(
                str(n) for n in result.get("slot_nos", []))
            apply.new_total_quota = result.get("new_total_quota")

            await self.db.commit()

            # 通知患者
            try:
                await self.msg.send(
                    biz_type="ADD_QUOTA_APPROVED",
                    receivers=[apply.patient_id],
                    params={
                        "apply_no": apply.apply_no,
                        "schedule_date": apply.schedule_date.isoformat(),
                        "period_text": apply.period_text,
                        "doctor_name": apply.doctor_name,
                        "add_count": apply.add_count,
                    })
            except Exception:
                pass

            return {
                "schedule_id": apply.schedule_id,
                "added": apply.add_count,
                "new_quota": f"{apply.used_quota}/{result.get('new_total_quota')}",
                "slot_nos": result.get("slot_nos", []),
            }

        except Exception as e:
            apply.status = "FAILED"
            apply.error_msg = str(e)[:500]
            await self.db.commit()
            raise BizException("0406017", f"加号执行失败：{str(e)[:100]}")

    # ---------- 辅助 ----------
    async def _get_apply(self, apply_id: int) -> M04AddQuotaApply:
        apply = (await self.db.execute(
            select(M04AddQuotaApply).where(
                M04AddQuotaApply.id == apply_id)
        )).scalar_one_or_none()

        if not apply:
            raise BizException("0406011", "加号申请不存在")

        return apply

    async def _get_schedule(self, schedule_id: int) -> M04Schedule:
        schedule = (await self.db.execute(
            select(M04Schedule).where(
                M04Schedule.id == schedule_id,
                M04Schedule.is_deleted == False,
            )
        )).scalar_one_or_none()

        if not schedule:
            raise BizException("0406014", "目标排班不存在")

        if schedule.status != "NORMAL":
            raise BizException("0406014", "目标排班不可加号")

        if schedule.schedule_date < date.today():
            raise BizException("0406014", "目标排班已过期")

        return schedule

    @staticmethod
    def _period_text(schedule) -> str:
        period = {"AM": "上午", "PM": "下午", "NIGHT": "夜间",
                  "ALL_DAY": "全天"}.get(schedule.period, schedule.period)
        if schedule.start_time and schedule.end_time:
            return (f"{period} "
                    f"{schedule.start_time.strftime('%H:%M')}"
                    f"-{schedule.end_time.strftime('%H:%M')}")
        return period

    @staticmethod
    def _status_text(status: str) -> str:
        return {
            "PENDING": "待审批", "APPROVED": "已通过",
            "REJECTED": "已驳回", "EXECUTED": "已执行",
            "CANCELLED": "已取消", "FAILED": "执行失败",
        }.get(status, status)

    async def _get_config(self) -> dict:
        import json
        cached = await redis_client.get("m04:special:config")
        if cached:
            return json.loads(cached)

        data = {
            "max_add_per_schedule": 5,
            "max_add_per_time": 5,
            "auto_approve_max": 3,
        }
        await redis_client.setex("m04:special:config", 600, json.dumps(data))
        return data
```
