## 1. 模块概述

### 1.1 模块定位

排班与号源是门诊业务的**供给端**。它回答："**这个医生哪天出诊、看几个号、还剩几个号？**"

```
┌──────────────────────────────────────────────────────────────┐
│  M01 主数据（职工、科室、职称）                                │
└────────────────────────┬─────────────────────────────────────┘
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  M04-01 排班与号源（本文档）                                   │
│  排班模板 → 批量排班 → 号源池 → 停诊/调班                       │
└────────────────────────┬─────────────────────────────────────┘
                         ▼ 号源
      ┌──────────────────┼──────────────────┬──────────────┐
      ▼                  ▼                  ▼              ▼
┌──────────┐      ┌──────────┐      ┌──────────┐   ┌──────────┐
│02 预约    │      │03 挂号    │      │06 绿色通道│   │03 门户    │
│          │      │          │      │  特殊号    │   │  (M03-06) │
└──────────┘      └──────────┘      └──────────┘   └──────────┘
```

### 1.2 为什么排班独立成子模块

| 理由 | 说明 |
|---|---|
| **供给唯一源** | 预约、挂号、门户都消耗同一份号源，必须统一管理 |
| **并发竞争** | 号源是稀缺资源，需要原子扣减 |
| **复杂度高** | 模板、批量生成、停诊、调班、加号、留号 |
| **时间维度** | 排班是按日期展开的，与挂号（按次）不同 |

### 1.3 关键概念区分

| 概念 | 说明 | 表 |
|---|---|---|
| **排班模板** | 周期性规则，如"每周一上午张医生出诊" | `m04_schedule_template` |
| **排班**（班次） | 某医生某日的具体出诊安排 | `m04_schedule` |
| **号源** | 某班次下可挂号的槽位 | `m04_reg_slot` |
| **时段** | 班次内的时间段（如 8:00-8:30） | `m04_schedule_period` |

> **一句话：** 模板是"规则"，排班是"某天的实际安排"，号源是"能挂几个号"，时段是"几点看"。

### 1.4 与相邻模块的分工

| 能力 | 归属 |
|---|---|
| 职工、科室、职称、执业级别 | M01 |
| 医生资质校验（执业证、多点执业） | M01 |
| **排班模板** | **M04-01 本子模块** |
| **排班生成与调整** | **M04-01 本子模块** |
| **号源池（库存）** | **M04-01 本子模块** |
| **停诊、调班、加号** | **M04-01 本子模块** |
| 停诊通知患者 | M03-05 消息（本模块发事件） |
| 预约业务 | M04-02 |
| 挂号业务 | M04-03 |
| 特殊号/绿色通道 | M04-06 |
| 挂号费定价 | M16 |
| 出诊地点（诊室） | 本模块（诊室号字段） |

> **边界一句话：** 本子模块只管"号源怎么产生、怎么变化、还剩多少"；**不做**预约申请（M04-02）、**不做**挂号收费（M04-03/M16）、**不做**患者通知发送（M03-05）。

## 3. 业务模型

### 3.1 班次模型

#### 3.1.1 班次类型

| 代码 | 名称 | 典型时间 | 号源特点 |
|---|---|---|---|
| `AM` | 上午 | 08:00-12:00 | 号多，最长 |
| `PM` | 下午 | 14:00-17:30 | 号中等 |
| `NIGHT` | 夜间 | 17:30-21:00 | 号少，急诊为主 |
| `ALL_DAY` | 全天 | 08:00-17:30 | 合并上午下午 |

#### 3.1.2 时段划分

**一个班次可划分为多个时段，每个时段有独立号数：**

```
2026-10-22 上午（张明华 白内障专病）
┌──────────────┬──────────┬────────┬────────┐
│ 时段          │ 时间      │ 号数    │ 已约   │
├──────────────┼──────────┼────────┼────────┤
│ 1            │ 08:00-08:30 │ 4    │ 4      │
│ 2            │ 08:30-09:00 │ 4    │ 3      │
│ 3            │ 09:00-09:30 │ 4    │ 2      │
│ 4            │ 09:30-10:00 │ 4    │ 0      │
│ ...          │ ...        │ ...    │ ...    │
│ 8            │ 11:30-12:00 │ 4    │ 0      │
├──────────────┴──────────┴────────┴────────┤
│ 合计：32 个号，已约 9 个，剩余 23 个        │
└───────────────────────────────────────────┘
```

**为什么分时段：** 眼科门诊需要精确控制到诊时间，减少候诊积压。

#### 3.1.3 不分时段模式

**小科室或号少时可关闭时段划分**，整个班次共用一个号池：

```
配置：mpi/m04 schedule_period_enabled = FALSE
结果：班次 → 一个号池（号数 20），无时段
```

### 3.3 号源状态机

```
        ┌──────────────┐
        │  AVAILABLE   │ 可用
        └──────┬───────┘
               │
    ┌──────────┼──────────┬──────────────┐
    │ reserve  │ reserve  │ reserve      │ lock
    ▼          ▼          ▼              ▼
┌────────┐┌────────┐┌──────────┐  ┌──────────┐
│ BOOKED ││ LOCKED ││ RESERVED │  │ LOCKED   │
│ 已预约  ││ 锁定中  ││ 预留给   │  │ 操作中    │
└───┬────┘└───┬────┘└──────────┘  └────┬─────┘
    │         │                        │
    │ checked │ 超时                    │ 超时/失败
    ▼         ▼                        ▼
┌──────────┐┌──────────┐         ┌──────────┐
│ CHECKED_IN││AVAILABLE│         │AVAILABLE │
│ 已签到    ││ 释放     │         │ 释放     │
└────┬─────┘└──────────┘         └──────────┘
     │
     │ cancel
     ▼
┌──────────┐
│ CANCELLED│
│ 已取消    │
└────┬─────┘
     │ 退号（是否可再放）
     ▼
┌──────────┐
│ AVAILABLE│（可配置）
└──────────┘
```

**状态说明：**

| 状态 | 说明 | 可否再挂 |
|---|---|---|
| `AVAILABLE` | 可用 | ✅ |
| `LOCKED` | 临时锁定（操作中，如支付中） | ❌（超时释放） |
| `RESERVED` | 预留给特殊场景（现场/急诊/绿色通道） | ❌（由 M04-06 消费） |
| `BOOKED` | 已预约或已挂号 | ❌ |
| `CHECKED_IN` | 已签到（患者到院） | ❌ |
| `CANCELLED` | 已取消 | 视配置 |
| `CLOSED` | 停诊关闭 | ❌ |

### 3.4 号源扣减模型

#### 3.4.1 并发控制三选一

| 方案 | 优点 | 缺点 | 选用 |
|---|---|---|---|
| **数据库行锁**（`SELECT FOR UPDATE`） | 强一致 | 高并发下锁竞争 | ❌ |
| **Redis 原子扣减** | 高性能 | 需与 DB 对账 | ✅ **选用** |
| **乐观锁 version_no** | 无锁 | 冲突重试率高 | 备用 |

#### 3.4.2 Redis + DB 双层模型

```
Redis（权威计数，快速扣减）
  key: m04:slot:stock:{schedule_id}
  value: 剩余号数
  命令: DECR（原子）
        DECR 后 < 0 → INCR 回滚，拒绝

DB（持久化，最终一致）
  m04_schedule.used_quota += 1
  m04_reg_slot.status = 'BOOKED'

对账（每 5 分钟）
  Redis 剩余 vs DB 剩余 → 不一致则告警并修正
```

**为什么用 Redis 扣减：** 挂号高峰（早 7:30-8:30）号源竞争激烈，DB 行锁会有明显排队。

#### 3.4.3 扣减流程

```python
# 伪代码
async def reserve_slot(schedule_id: int, patient_id: int, biz_type: str):
    # 1. Redis 原子扣减
    key = f"m04:slot:stock:{schedule_id}"
    remaining = await redis.decr(key)
    if remaining < 0:
        await redis.incr(key)          # 回滚
        raise BizException(54001, "号源已挂完")

    try:
        # 2. DB 分配具体号源（最小的 AVAILABLE slot）
        slot = await assign_specific_slot(schedule_id)
        if not slot:
            raise BizException(54001, "无可分配号源")

        # 3. 更新 slot 状态 + schedule 计数
        slot.status = "BOOKED"
        slot.patient_id = patient_id
        schedule.used_quota += 1

        # 4. 记锁
        await redis.setex(f"m04:slot:lock:{slot.id}", 300, biz_type)
        return slot
    except Exception:
        await redis.incr(key)          # 失败回滚
        raise
```

### 3.5 停诊与调班模型

#### 3.5.1 停诊类型

| 类型 | 说明 | 影响 |
|---|---|---|
| **整班停诊** | 医生整个上午/下午不出诊 | 所有号源关闭 |
| **时段停诊** | 仅某几个时段停 | 部分号源关闭 |
| **临时停诊** | 当天突发（如手术） | 已挂号患者需通知改约 |

#### 3.5.2 停诊处理流程

```
医生/科室申请停诊
   ↓
检查是否已有挂号/预约
   ├─ 无 → 直接停诊
   └─ 有 ↓
提示影响的患者数（N 人）
   ↓
选择处理方式
   ├─ A. 全部改约到指定排班（推荐）
   ├─ B. 全部退号 + 通知
   └─ C. 保留挂号，安排代诊医生
   ↓
执行
   ├─ 关闭号源（status = CLOSED）
   ├─ 处理已占号源
   ├─ 发布事件 m04.schedule.suspended
   └─ M03-05 通知患者
   ↓
记录 m04_schedule_change_log
```

#### 3.5.3 换班/代诊

| 场景 | 处理 |
|---|---|
| **换班** | 两个医生交换排班（A 的周一换给 B） |
| **代诊** | 某班次临时由他人代替，保留原班次结构 |
| **加号** | 已有排班增加号数 |
| **减号** | 减少号数（需确认未超已挂数） |

### 3.6 留号模型

**为现场挂号、急诊、绿色通道预留号源：**

| 留号类型 | 说明 | 默认比例 | 消费方 |
|---|---|---|---|
| `ONSITE` | 现场挂号预留 | 20% | M04-03 |
| `EMERGENCY` | 急诊预留 | 5% | M04-06 |
| `GREEN` | 绿色通道（军残/老年等） | 5% | M04-06 |
| `FOLLOWUP` | 复诊预留 | 0%（可配） | M04-03 |

**示例：** 32 个号

```
全量 32
 ├─ ONSITE    7（20%）
 ├─ EMERGENCY 2（5%）
 ├─ GREEN     2（5%）
 └─ OPEN     21（可预约可现场挂）
```

> **说明：** 留号是"预分配"而非"物理隔离"。到期未用完的留号可释放到 OPEN。

| 每时段号数 | ≥ 1 |
| 总号数 | ≤ 200（防误填） |
| 留号比例 | 合计 ≤ 50% |

```python
# app/services/m04/slot_service.py
"""号源服务（Redis 原子扣减 + DB 持久化）"""
import secrets
import uuid
from datetime import datetime, timedelta
from typing import Optional, List

from sqlalchemy import select, and_, func, update
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.m04.schedule import (
    M04Schedule, M04SchedulePeriod, M04RegSlot,
)
from app.core.exceptions import BizException
from app.core.redis import redis_client


class SlotService:
    """号源占用与释放"""

    STOCK_KEY = "m04:slot:stock:{schedule_id}"
    LOCK_KEY = "m04:slot:lock:{slot_id}"
    RECONCILE_KEY = "m04:slot:drift:{schedule_id}"

    def __init__(self, db: AsyncSession):
        self.db = db

    # ---------- 占用 ----------
    async def reserve(self, payload) -> dict:
        """占用号源（原子操作）"""
        schedule = (await self.db.execute(
            select(M04Schedule).where(
                M04Schedule.id == payload.schedule_id,
                M04Schedule.is_deleted == False,
            )
        )).scalar_one_or_none()

        if not schedule:
            raise BizException(54006, "排班不存在")

        if schedule.status == "SUSPENDED":
            raise BizException(54007, "该班次已停诊")

        if schedule.status == "CLOSED":
            raise BizException(54007, "该班次已关闭")

        # 1. Redis 原子扣减
        stock_key = self.STOCK_KEY.format(schedule_id=payload.schedule_id)
        await self._ensure_stock(schedule)
        remaining = await redis_client.decr(stock_key)

        if remaining < 0:
            await redis_client.incr(stock_key)     # 回滚
            alternatives = await self._find_alternatives(schedule)
            raise BizException(54001, "该班次号源已挂完",
                data={"alternative_schedules": alternatives})

        lock_id = f"lk_{secrets.token_hex(6)}"

        try:
            # 2. 分配具体号源
            slot = await self._assign_slot(
                schedule, payload.patient_id,
                payload.biz_type, payload.biz_no,
                payload.prefer_period_id, lock_id)

            if not slot:
                raise BizException(54001, "无可分配号源")

            # 3. 更新排班计数
            schedule.used_quota = (schedule.used_quota or 0) + 1

            # 4. 写锁（TTL）
            ttl = payload.lock_seconds or 300
            await redis_client.setex(self.LOCK_KEY.format(slot_id=slot.id),
                                      ttl, lock_id)

            await self.db.commit()

            period = None
            if slot.period_id:
                period = (await self.db.execute(
                    select(M04SchedulePeriod).where(
                        M04SchedulePeriod.id == slot.period_id)
                )).scalar_one_or_none()

            return {
                "slot_id": slot.id,
                "slot_no": slot.slot_no,
                "period_id": slot.period_id,
                "period_text": period.period_text if period else None,
                "queue_no": slot.slot_no,
                "lock_id": lock_id,
                "lock_expire_at": (datetime.now()
                    + timedelta(seconds=ttl)).isoformat(),
                "remaining_quota": max(0, remaining),
            }

        except BizException:
            await redis_client.incr(stock_key)
            raise
        except Exception:
            await redis_client.incr(stock_key)
            raise BizException(50003, "号源占用失败，请重试")

    async def _ensure_stock(self, schedule: M04Schedule) -> None:
        """确保 Redis 中有号源库存（首次访问时初始化）"""
        stock_key = self.STOCK_KEY.format(schedule_id=schedule.id)
        exists = await redis_client.exists(stock_key)

        if not exists:
            # 从 DB 计算真实剩余
            used = (await self.db.execute(
                select(func.count()).select_from(M04RegSlot).where(
                    M04RegSlot.schedule_id == schedule.id,
                    M04RegSlot.status.in_(
                        ("BOOKED", "CHECKED_IN", "LOCKED")),
                )
            )).scalar_one()

            remaining = schedule.total_quota - used

            # SET NX 防并发覆盖
            await redis_client.set(stock_key, remaining, nx=True, ex=86400)

    async def _assign_slot(self, schedule: M04Schedule, patient_id: int,
                             biz_type: str, biz_no: Optional[str],
                             prefer_period_id: Optional[int],
                             lock_id: str) -> Optional[M04RegSlot]:
        """分配具体号源（最小可用号序）"""
        stmt = select(M04RegSlot).where(
            M04RegSlot.schedule_id == schedule.id,
            M04RegSlot.status == "AVAILABLE",
            M04RegSlot.is_deleted == False,
        )

        if prefer_period_id:
            stmt = stmt.where(M04RegSlot.period_id == prefer_period_id)

        stmt = stmt.order_by(M04RegSlot.slot_no.asc()).limit(1).with_for_update(
            skip_locked=True)

        slot = (await self.db.execute(stmt)).scalar_one_or_none()

        if not slot:
            return None

        slot.status = "LOCKED"
        slot.lock_id = lock_id
        slot.lock_at = datetime.now()
        slot.lock_expire_at = datetime.now() + timedelta(minutes=5)
        slot.patient_id = patient_id
        slot.biz_type = biz_type
        slot.biz_no = biz_no

        await self.db.flush()
        return slot

    async def _find_alternatives(self, schedule: M04Schedule,
                                   limit: int = 3) -> List[dict]:
        """找替代号源"""
        rows = (await self.db.execute(
            select(M04Schedule).where(
                M04Schedule.doctor_id == schedule.doctor_id,
                M04Schedule.schedule_date >= schedule.schedule_date,
                M04Schedule.status == "NORMAL",
                M04Schedule.id != schedule.id,
                M04Schedule.used_quota < M04Schedule.total_quota,
            ).order_by(M04Schedule.schedule_date.asc())
            .limit(limit)
        )).scalars().all()

        return [
            {
                "schedule_id": r.id,
                "schedule_date": r.schedule_date.isoformat(),
                "doctors_name": r.doctor_name,
                "period_text": self._period_text(r.period),
                "remaining_quota": r.total_quota - r.used_quota,
            }
            for r in rows
        ]

    # ---------- 确认 ----------
    async def confirm(self, slot_id: int, lock_id: Optional[str]) -> dict:
        """确认占用（LOCKED → BOOKED）"""
        slot = (await self.db.execute(
            select(M04RegSlot).where(M04RegSlot.id == slot_id)
        )).scalar_one_or_none()

        if not slot:
            raise BizException(54002, "号源不存在")

        if slot.status == "BOOKED":
            return {"slot_id": slot.id, "status": "BOOKED"}

        if slot.status != "LOCKED":
            raise BizException(54003, f"号源状态 {slot.status} 不允许确认")

        # 校验锁
        if lock_id:
            cached = await redis_client.get(self.LOCK_KEY.format(slot_id=slot_id))
            if cached and cached != lock_id:
                raise BizException(54004, "号源锁定信息不匹配")

        slot.status = "BOOKED"
        slot.lock_id = None
        slot.lock_expire_at = None
        slot.booked_at = datetime.now()

        await self.db.commit()
        await redis_client.delete(self.LOCK_KEY.format(slot_id=slot_id))

        return {"slot_id": slot.id, "status": "BOOKED",
                "booked_at": slot.booked_at.isoformat()}

    # ---------- 释放 ----------
    async def release(self, payload) -> dict:
        """释放号源（回到 AVAILABLE）"""
        slot = (await self.db.execute(
            select(M04RegSlot).where(M04RegSlot.id == payload.slot_id)
        )).scalar_one_or_none()

        if not slot:
            raise BizException(54002, "号源不存在")

        if slot.status not in ("LOCKED", "BOOKED"):
            raise BizException(54003, f"号源状态 {slot.status} 不允许释放")

        old_status = slot.status
        slot.status = "AVAILABLE"
        slot.patient_id = None
        slot.biz_type = None
        slot.biz_no = None
        slot.lock_id = None
        slot.lock_expire_at = None
        slot.booked_at = None

        # 排班计数回退
        schedule = (await self.db.execute(
            select(M04Schedule).where(M04Schedule.id == slot.schedule_id)
        )).scalar_one_or_none()
        if schedule and schedule.used_quota > 0:
            schedule.used_quota -= 1

        await self.db.commit()

        # Redis 库存增加
        stock_key = self.STOCK_KEY.format(schedule_id=slot.schedule_id)
        await redis_client.incr(stock_key)
        await redis_client.delete(self.LOCK_KEY.format(slot_id=slot.id))

        return {"slot_id": slot.id, "released": True, "old_status": old_status}

    # ---------- 超时释放 ----------
    async def release_expired_locks(self, limit: int = 500) -> dict:
        """释放超时的锁定号源（定时任务调用）"""
        now = datetime.now()

        slots = (await self.db.execute(
            select(M04RegSlot).where(
                M04RegSlot.status == "LOCKED",
                M04RegSlot.lock_expire_at <= now,
                M04RegSlot.is_deleted == False,
            ).limit(limit)
        )).scalars().all()

        if not slots:
            return {"released": 0}

        schedule_ids = set()
        for slot in slots:
            slot.status = "AVAILABLE"
            slot.patient_id = None
            slot.biz_type = None
            slot.biz_no = None
            slot.lock_id = None
            slot.lock_expire_at = None
            schedule_ids.add(slot.schedule_id)

        # 每个受影响排班的库存 +计数
        for sid in schedule_ids:
            cnt = sum(1 for s in slots if s.schedule_id == sid)
            schedule = (await self.db.execute(
                select(M04Schedule).where(M04Schedule.id == sid)
            )).scalar_one_or_none()
            if schedule:
                schedule.used_quota = max(0, schedule.used_quota - cnt)

            stock_key = self.STOCK_KEY.format(schedule_id=sid)
            await redis_client.incrby(stock_key, cnt)

        await self.db.commit()
        return {"released": len(slots), "schedules": list(schedule_ids)}

    # ---------- 加号 ----------
    async def add_quota(self, schedule_id: int, payload, user) -> dict:
        """加号"""
        schedule = (await self.db.execute(
            select(M04Schedule).where(
                M04Schedule.id == schedule_id,
                M04Schedule.is_deleted == False,
            )
        )).scalar_one_or_none()

        if not schedule:
            raise BizException(54006, "排班不存在")

        config = await self._get_config()
        max_add = config.get("max_add_per_schedule", 5)

        add_count = payload.add_count
        if add_count <= 0 or add_count > max_add:
            raise BizException(54027, f"单次加号数量应在 1~{max_add} 之间")

        # 找当前最大号序
        max_no = (await self.db.execute(
            select(func.max(M04RegSlot.slot_no)).where(
                M04RegSlot.schedule_id == schedule_id)
        )).scalar() or 0

        # 创建新号源
        new_slots = []
        for i in range(1, add_count + 1):
            slot = M04RegSlot(
                schedule_id=schedule_id,
                slot_no=max_no + i,
                period_id=payload.period_id,
                status="AVAILABLE",
                source_type="ADDED",
                remark=payload.reason,
            )
            self.db.add(slot)
            new_slots.append(slot)

        schedule.total_quota += add_count

        await self.db.commit()

        # Redis 库存增加
        stock_key = self.STOCK_KEY.format(schedule_id=schedule_id)
        await redis_client.incrby(stock_key, add_count)

        return {
            "schedule_id": schedule_id,
            "added": add_count,
            "new_total_quota": schedule.total_quota,
            "slot_nos": [s.slot_no for s in new_slots],
        }

    # ---------- 对账 ----------
    async def reconcile(self, schedule_id: int) -> dict:
        """号源对账（Redis vs DB）"""
        schedule = (await self.db.execute(
            select(M04Schedule).where(M04Schedule.id == schedule_id)
        )).scalar_one_or_none()

        if not schedule:
            raise BizException(54006, "排班不存在")

        used = (await self.db.execute(
            select(func.count()).select_from(M04RegSlot).where(
                M04RegSlot.schedule_id == schedule_id,
                M04RegSlot.status.in_(("BOOKED", "CHECKED_IN", "LOCKED")),
            )
        )).scalar_one()

        db_remaining = schedule.total_quota - used
        stock_key = self.STOCK_KEY.format(schedule_id=schedule_id)
        redis_remaining = int(await redis_client.get(stock_key) or 0)

        drift = redis_remaining - db_remaining

        if drift != 0:
            await redis_client.set(stock_key, db_remaining, ex=86400)
            await redis_client.setex(
                self.RECONCILE_KEY.format(schedule_id=schedule_id), 600,
                str(drift))

        return {
            "schedule_id": schedule_id,
            "db_remaining": db_remaining,
            "redis_remaining": redis_remaining,
            "drift": drift,
            "corrected": drift != 0,
        }

    @staticmethod
    def _period_text(period: str) -> str:
        return {"AM": "上午", "PM": "下午", "NIGHT": "夜间",
                "ALL_DAY": "全天"}.get(period, period)

    async def _get_config(self) -> dict:

        cached = await redis_client.get("m04:schedule:config")
```

```python
# app/services/m04/schedule_service.py
"""排班服务"""
from datetime import date, datetime, timedelta
from typing import Optional, List
import uuid

from sqlalchemy import select, and_, func, or_
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.m04.schedule import (
    M04ScheduleTemplate, M04Schedule, M04SchedulePeriod,
    M04RegSlot, M04ScheduleChangeLog, M04ScheduleConfig,
)
from app.core.exceptions import BizException
from app.core.redis import redis_client


class ScheduleService:
    """排班生成、调整、停诊"""

    WEEKDAY_MIN = 1      # 周一
    WEEKDAY_MAX = 7      # 周日
    MAX_RANGE_DAYS = 365

    def __init__(self, db: AsyncSession):
        self.db = db

    # ---------- 生成 ----------
    async def generate(self, payload, user) -> dict:
        """批量生成排班"""
        if payload.end_date < payload.start_date:
            raise BizException(40001, "结束日期不能早于开始日期")

        days = (payload.end_date - payload.start_date).days + 1
        if days > self.MAX_RANGE_DAYS:
            raise BizException(40001, f"生成范围不能超过 {self.MAX_RANGE_DAYS} 天")

        task_id = f"SG{datetime.now().strftime('%Y%m%d%H%M%S')}001"

        # 异步任务
        from app.tasks.m04.schedule_tasks import generate_schedules_task
        generate_schedules_task.delay(
            task_id=task_id,
            dept_id=payload.dept_id,
            include_sub=payload.include_sub_depts,
            start_date=payload.start_date.isoformat(),
            end_date=payload.end_date.isoformat(),
            source=payload.source,
            conflict=payload.conflict_strategy,
            skip_holidays=payload.skip_holidays,
            auto_open=payload.auto_open,
            operator_id=getattr(user, "id", None),
        )

        # 预估
        dept_ids = await self._collect_dept_ids(
            payload.dept_id, payload.include_sub_depts)
        templates = (await self.db.execute(
            select(M04ScheduleTemplate).where(
                M04ScheduleTemplate.dept_id.in_(dept_ids),
                M04ScheduleTemplate.is_enabled == True,
                M04ScheduleTemplate.is_deleted == False,
            )
        )).scalars().all()

        est_schedules = 0
        est_slots = 0
        current = payload.start_date
        weekdays = set()
        while current <= payload.end_date:
            weekdays.add(current.isoweekday())
            current += timedelta(days=1)

        for tpl in templates:
            matched_days = sum(
                1 for wd in weekdays
                if wd in self._parse_weekdays(tpl.weekday))
            est_schedules += matched_days * len(self._parse_periods(tpl.period))
            est_slots += matched_days * tpl.total_quota

        return {
            "task_id": task_id,
            "status": "RUNNING",
            "estimated_schedules": est_schedules,
            "estimated_slots": est_slots,
            "message": "生成任务已提交，请通过进度接口查询",
        }

    async def _collect_dept_ids(self, dept_id: int, include_sub: bool) -> List[int]:
        """收集科室 ID（含子科室）"""
        ids = [dept_id]
        if include_sub:
            from app.clients.mdm_client import MdmClient
            client = MdmClient()
            children = await client.get_dept_children(dept_id)
            ids.extend(c.get("id") for c in children)
        return ids

    @staticmethod
    def _parse_weekdays(value: str) -> List[int]:
        """解析周几（如 '1,4' → [1, 4]）"""
        if not value:
            return []
        return [int(x) for x in value.split(",") if x.strip().isdigit()]

    @staticmethod
    def _parse_periods(value: str) -> List[str]:
        """解析班次（如 'AM,PM' → ['AM', 'PM']）"""
        if not value:
            return []
        return [x.strip() for x in value.split(",") if x.strip()]

    # ---------- 日历 ----------
    async def get_calendar(self, dept_id: Optional[int],
                             doctor_id: Optional[int],
                             start_date: date, end_date: date) -> dict:
        """出诊日历"""
        if not doctor_id and not dept_id:
            raise BizException(40001, "科室与医生至少指定一个")

        days = (end_date - start_date).days + 1
        if days > 62:
            raise BizException(40001, "日历最多查询 62 天")

        stmt = select(M04Schedule).where(
            M04Schedule.schedule_date >= start_date,
            M04Schedule.schedule_date <= end_date,
            M04Schedule.is_deleted == False,
        )

        if dept_id:
            stmt = stmt.where(M04Schedule.dept_id == dept_id)
        if doctor_id:
            stmt = stmt.where(M04Schedule.doctor_id == doctor_id)

        rows = (await self.db.execute(
            stmt.order_by(M04Schedule.doctor_id.asc(),
                          M04Schedule.schedule_date.asc(),
                          M04Schedule.period.asc())
        )).scalars().all()

        # 按医生分组
        by_doctor = {}
        for r in rows:
            if r.doctor_id not in by_doctor:
                by_doctor[r.doctor_id] = {
                    "doctor_id": r.doctor_id,
                    "doctor_name": r.doctor_name,
                    "title_name": r.title_name,
                    "schedules": [],
                }
            by_doctor[r.doctor_id]["schedules"].append({
                "schedule_id": r.id,
                "schedule_date": r.schedule_date.isoformat(),
                "weekday": r.schedule_date.isoweekday(),
                "period": r.period,
                "period_text": self._period_text(r.period),
                "time_range": f"{r.start_time.strftime('%H:%M')}"
                              f"-{r.end_time.strftime('%H:%M')}"
                              if r.start_time and r.end_time else None,
                "room_no": r.room_no,
                "reg_type_code": r.reg_type_code,
                "reg_type_name": r.reg_type_name,
                "total_quota": r.total_quota,
                "used_quota": r.used_quota,
                "remaining_quota": max(0, r.total_quota - r.used_quota),
                "status": r.status,
                "status_text": self._status_text(r.status),
                "suspend_reason": r.suspend_reason,
                "stock_level": self._stock_level(r),
            })

        total = sum(r.total_quota for r in rows)
        used = sum(r.used_quota for r in rows)

        return {
            "dept_id": dept_id,
            "start_date": start_date.isoformat(),
            "end_date": end_date.isoformat(),
            "summary": {
                "doctor_count": len(by_doctor),
                "schedule_count": len(rows),
                "total_quota": total,
                "used_quota": used,
                "remaining_quota": total - used,
                "usage_rate": round(used / total * 100, 1) if total else 0,
            },
            "doctors": list(by_doctor.values()),
        }

    def _stock_level(self, row) -> str:
        """号源紧张程度"""
        if row.status == "SUSPENDED":
            return "SUSPENDED"
        if row.status == "NOT_GENERATED":
            return "NOT_GENERATED"
        remaining = row.total_quota - row.used_quota
        if remaining <= 0:
            return "RED"
        if remaining / row.total_quota <= 0.2:
            return "YELLOW"
        return "GREEN"

    # ---------- 停诊 ----------
    async def suspend(self, schedule_id: int, payload, user) -> dict:
        """停诊"""
        schedule = (await self.db.execute(
            select(M04Schedule).where(
                M04Schedule.id == schedule_id,
                M04Schedule.is_deleted == False,
            )
        )).scalar_one_or_none()

        if not schedule:
            raise BizException(54006, "排班不存在")

        if schedule.status == "SUSPENDED":
            raise BizException(54003, "该班次已停诊")

        # 统计受影响患者
        affected = (await self.db.execute(
            select(M04RegSlot).where(
                M04RegSlot.schedule_id == schedule_id,
                M04RegSlot.status.in_(("BOOKED", "CHECKED_IN")),
            )
        )).scalars().all()

        affected_count = len(affected)

        if affected_count > 0 and not payload.handle_type:
            raise BizException(54022,
                f"该班次有 {affected_count} 名已挂号患者，请选择处理方式")

        before = {
            "status": schedule.status,
            "total_quota": schedule.total_quota,
            "used_quota": schedule.used_quota,
        }

        # 处理受影响患者
        result_detail = {}
        if affected_count > 0:
            if payload.handle_type == "RESCHEDULE":
                result_detail = await self._reschedule_affected(
                    schedule, affected, payload, user)
            elif payload.handle_type == "REFUND":
                result_detail = await self._refund_affected(
                    schedule, affected, payload, user)
            elif payload.handle_type == "SUBSTITUTE":
                result_detail = await self._substitute_affected(
                    schedule, affected, payload, user)

        # 关闭号源
        await self.db.execute(
            M04RegSlot.__table__.update()
            .where(
                M04RegSlot.schedule_id == schedule_id,
                M04RegSlot.status == "AVAILABLE",
            )
            .values(status="CLOSED")
        )

        schedule.status = "SUSPENDED"
        schedule.suspend_reason = payload.reason
        schedule.suspended_at = datetime.now()
        schedule.suspended_by = getattr(user, "id", None)

        # 变更日志
        self.db.add(M04ScheduleChangeLog(
            schedule_id=schedule_id,
            change_type="SUSPEND",
            before_json=before,
            after_json={"status": "SUSPENDED",
                         "reason": payload.reason},
            affected_patient_count=affected_count,
            handle_type=payload.handle_type,
            reason=payload.reason,
            operator_id=getattr(user, "id", None),
            operator_name=getattr(user, "name", None),
        ))

        await self.db.commit()

        # 清空 Redis 库存
        await redis_client.delete(
            f"m04:slot:stock:{schedule_id}")

        # 发布事件
        await self._publish_event("m04.schedule.suspended", {
            "schedule_id": schedule_id,
            "schedule_date": schedule.schedule_date.isoformat(),
            "doctor_id": schedule.doctor_id,
            "doctor_name": schedule.doctor_name,
            "period": schedule.period,
            "reason": payload.reason,
            "affected_count": affected_count,
        })

        # 通知患者
        if payload.notify and affected_count > 0:
            await self._notify_patients(schedule, affected, payload)

        return {
            "schedule_id": schedule_id,
            "status": "SUSPENDED",
            "affected_count": affected_count,
            "handle_type": payload.handle_type,
            "detail": result_detail,
        }

    async def _reschedule_affected(self, schedule, affected, payload,
                                     user) -> dict:
        """改约到其他排班"""
        target = (await self.db.execute(
            select(M04Schedule).where(
                M04Schedule.id == payload.target_schedule_id,
                M04Schedule.is_deleted == False,
            )
        )).scalar_one_or_none()

        if not target:
            raise BizException(54006, "目标排班不存在")

        target_remaining = target.total_quota - target.used_quota

        if target_remaining < len(affected) and not payload.auto_add_quota:
            raise BizException(54023,
                f"目标排班号源不足（需 {len(affected)}，剩 {target_remaining}）")

        # 自动加号
        if target_remaining < len(affected):
            need = len(affected) - target_remaining
            await self._add_quota_internal(target, need, "停诊改约加号")

        moved = 0
        for slot in affected:
            slot.schedule_id = target.id
            slot.remark = f"由 {schedule.id} 改约"
            moved += 1

        return {"target_schedule_id": target.id, "moved": moved}

    async def _refund_affected(self, schedule, affected, payload,
                                 user) -> dict:
        """退号并通知"""
        for slot in affected:
            slot.status = "CANCELLED"
            slot.cancel_reason = "停诊退号"

        return {"cancelled": len(affected), "refund": payload.auto_refund}

    async def _substitute_affected(self, schedule, affected, payload,
                                     user) -> dict:
        """安排代诊"""
        if not payload.substitute_doctor_id:
            raise BizException(40001, "未指定代诊医生")

        # 校验代诊医生此时段空闲
        conflict = (await self.db.execute(
            select(M04Schedule).where(
                M04Schedule.doctor_id == payload.substitute_doctor_id,
                M04Schedule.schedule_date == schedule.schedule_date,
                M04Schedule.period == schedule.period,
                M04Schedule.id != schedule.id,
                M04Schedule.status != "SUSPENDED",
                M04Schedule.is_deleted == False,
            )
        )).scalar_one_or_none()

        if conflict:
            raise BizException(54024, "代诊医生此时段已有排班")

        schedule.substitute_doctor_id = payload.substitute_doctor_id
        schedule.substitute_doctor_name = payload.substitute_doctor_name

        return {"substitute_doctor_id": payload.substitute_doctor_id,
                "affected": len(affected)}

    async def _add_quota_internal(self, schedule, count: int,
                                    reason: str) -> None:
        """内部加号"""
        max_no = (await self.db.execute(
            select(func.max(M04RegSlot.slot_no)).where(
                M04RegSlot.schedule_id == schedule.id)
        )).scalar() or 0

        for i in range(1, count + 1):
            self.db.add(M04RegSlot(
                schedule_id=schedule.id,
                slot_no=max_no + i,
                status="AVAILABLE",
                source_type="ADDED",
                remark=reason,
            ))
        schedule.total_quota += count

    async def get_portal_schedule(self, dept_id: Optional[int],
                                    doctor_id: Optional[int],
                                    date_from: Optional[date],
                                    date_to: Optional[date]) -> dict:
        """门户号源查询（只返回 OPEN 部分，不含现场留号）"""
        if not dept_id and not doctor_id:
            raise BizException(40001, "科室与医生至少指定一个")

        date_from = date_from or date.today()
        date_to = date_to or (date_from + timedelta(days=7))

        # 提前期限制
        config = await self._get_config()
        max_advance = config.get("portal_advance_days", 7)
        max_date = date.today() + timedelta(days=max_advance)
        if date_to > max_date:
            date_to = max_date

        stmt = select(M04Schedule).where(
            M04Schedule.schedule_date >= date_from,
            M04Schedule.schedule_date <= date_to,
            M04Schedule.status == "NORMAL",
            M04Schedule.is_deleted == False,
        )
        if dept_id:
            stmt = stmt.where(M04Schedule.dept_id == dept_id)
        if doctor_id:
            stmt = stmt.where(M04Schedule.doctor_id == doctor_id)

        rows = (await self.db.execute(
            stmt.order_by(M04Schedule.schedule_date.asc(),
                          M04Schedule.start_time.asc())
        )).scalars().all()

        items = []
        for r in rows:
            # 门户可见 = OPEN 号源（AVAILABLE 且非留号）
            open_count = (await self.db.execute(
                select(func.count()).select_from(M04RegSlot).where(
                    M04RegSlot.schedule_id == r.id,
                    M04RegSlot.status == "AVAILABLE",
                    or_(
                        M04RegSlot.source_type.is_(None),
                        M04RegSlot.source_type == "OPEN",
                    ),
                )
            )).scalar_one()

            if open_count <= 0:
                continue

            items.append({
                "schedule_id": r.id,
                "schedule_date": r.schedule_date.isoformat(),
                "weekday": r.schedule_date.isoweekday(),
                "weekday_text": self._weekday_text(r.schedule_date.isoweekday()),
                "doctor_id": r.doctor_id,
                "doctor_name": r.doctor_name,
                "title_name": r.title_name,
                "period": r.period,
                "period_text": self._period_text(r.period),
                "time_range": f"{r.start_time.strftime('%H:%M')}"
                              f"-{r.end_time.strftime('%H:%M')}",
                "reg_type_code": r.reg_type_code,
                "reg_type_name": r.reg_type_name,
                "fee": float(r.fee) if r.fee else None,
                "remaining_quota": open_count,
                "total_quota": r.total_quota,
                "can_book": True,
            })

        return {
            "dept_id": dept_id,
            "date_from": date_from.isoformat(),
            "date_to": date_to.isoformat(),
            "items": items,
        }

    @staticmethod
    def _weekday_text(weekday: int) -> str:
        return {1: "周一", 2: "周二", 3: "周三", 4: "周四",
                5: "周五", 6: "周六", 7: "周日"}.get(weekday, "")
```

```python
# app/tasks/m04/schedule_tasks.py
"""排班异步任务"""
from celery import shared_task


@shared_task(bind=True, max_retries=2)
def generate_schedules_task(self, task_id: str, dept_id: int,
                              include_sub: bool, start_date: str,
                              end_date: str, source: str,
                              conflict: str, skip_holidays: bool,
                              auto_open: bool, operator_id: int = None):
    """生成排班（异步）"""
    import asyncio
    try:
        return asyncio.run(_generate(
            task_id, dept_id, include_sub, start_date, end_date,
            source, conflict, skip_holidays, auto_open, operator_id))
    except Exception as e:
        asyncio.run(_mark_failed(task_id, str(e)))
        raise


async def _generate(task_id, dept_id, include_sub, start_date, end_date,
                     source, conflict, skip_holidays, auto_open, operator_id):
    from datetime import date, datetime, timedelta, time
    from sqlalchemy import select
    from app.models.m04.schedule import (
        M04ScheduleTemplate, M04Schedule, M04SchedulePeriod,
        M04RegSlot, M04ScheduleConfig,
    )
    from app.core.database import AsyncSessionLocal
    from app.core.redis import redis_client

    start = date.fromisoformat(start_date)
    end = date.fromisoformat(end_date)

    async with AsyncSessionLocal() as db:
        # 收集科室
        dept_ids = [dept_id]
        if include_sub:
            from app.clients.mdm_client import MdmClient
            children = await MdmClient().get_dept_children(dept_id)
            dept_ids.extend(c.get("id") for c in children)

        templates = (await db.execute(
            select(M04ScheduleTemplate).where(
                M04ScheduleTemplate.dept_id.in_(dept_ids),
                M04ScheduleTemplate.is_enabled == True,
                M04ScheduleTemplate.is_deleted == False,
            )
        )).scalars().all()

        # 节假日
        holidays = set()
        if skip_holidays:
            raw = await redis_client.get(f"m04:holiday:{start.year}")
            if raw:
                import json
                holidays = set(date.fromisoformat(d)
                                for d in json.loads(raw))

        config = (await db.execute(
            select(M04ScheduleConfig).where(M04ScheduleConfig.id == 1)
        )).scalar_one_or_none()

        created = 0
        skipped = 0
        total_days = (end - start).days + 1

        current = start
        idx = 0
        while current <= end:
            idx += 1

            # 进度
            if idx % 10 == 0:
                await redis_client.setex(
                    f"m04:gen:progress:{task_id}", 3600,
                    f"{int(idx / total_days * 100)}")

            if current in holidays:
                current += timedelta(days=1)
                continue

            weekday = current.isoweekday()

            for tpl in templates:
                wds = [int(x) for x in (tpl.weekday or "").split(",")
                       if x.strip().isdigit()]
                if weekday not in wds:
                    continue

                # 生效区间
                if tpl.effective_from and current < tpl.effective_from:
                    continue
                if tpl.effective_to and current > tpl.effective_to:
                    continue

                for period in [p.strip() for p in tpl.period.split(",")
                                if p.strip()]:
                    # 检查已存在
                    exist = (await db.execute(
                        select(M04Schedule).where(
                            M04Schedule.doctor_id == tpl.doctor_id,
                            M04Schedule.schedule_date == current,
                            M04Schedule.period == period,
                            M04Schedule.is_deleted == False,
                        )
                    )).scalar_one_or_none()

                    if exist:
                        if conflict == "SKIP":
                            skipped += 1
                            continue
                        elif conflict == "ERROR":
                            raise ValueError(
                                f"{current} {period} 已存在排班")
                        else:   # OVERWRITE
                            if exist.used_quota > 0:
                                skipped += 1
                                continue
                            exist.is_deleted = True

                    # 创建排班
                    start_t, end_t = _period_time(period)
                    schedule = M04Schedule(
                        schedule_date=current,
                        period=period,
                        start_time=start_t,
                        end_time=end_t,
                        dept_id=tpl.dept_id,
                        doctor_id=tpl.doctor_id,
                        doctor_name=tpl.doctor_name,
                        title_name=tpl.title_name,
                        reg_type_code=tpl.reg_type_code,
                        reg_type_name=tpl.reg_type_name,
                        room_no=tpl.room_no,
                        total_quota=tpl.total_quota,
                        used_quota=0,
                        status="NORMAL" if auto_open else "LOCKED",
                        template_id=tpl.id,
                    )
                    db.add(schedule)
                    await db.flush()

                    # 时段与号源
                    if tpl.period_split_enabled:
                        period_count = tpl.total_quota // tpl.per_period_quota
                        slot_no = 1
                        for p_idx in range(period_count):
                            p_start = _add_minutes(start_t, p_idx * tpl.period_minutes)
                            p_end = _add_minutes(p_start, tpl.period_minutes)

                            period_obj = M04SchedulePeriod(
                                schedule_id=schedule.id,
                                period_seq=p_idx + 1,
                                period_text=f"{p_start.strftime('%H:%M')}"
                                            f"-{p_end.strftime('%H:%M')}",
                                start_time=p_start,
                                end_time=p_end,
                                quota=tpl.per_period_quota,
                                used_quota=0,
                            )
                            db.add(period_obj)
                            await db.flush()

                            for _ in range(tpl.per_period_quota):
                                db.add(M04RegSlot(
                                    schedule_id=schedule.id,
                                    period_id=period_obj.id,
                                    slot_no=slot_no,
                                    status="AVAILABLE",
                                    source_type="OPEN",
                                ))
                                slot_no += 1
                    else:
                        for slot_no in range(1, tpl.total_quota + 1):
                            db.add(M04RegSlot(
                                schedule_id=schedule.id,
                                slot_no=slot_no,
                                status="AVAILABLE",
                                source_type="OPEN",
                            ))

                    # 留号标记
                    await _apply_reserved(db, schedule, config)

                    created += 1
                    await db.commit()

            current += timedelta(days=1)

        await redis_client.setex(
            f"m04:gen:progress:{task_id}", 3600, "100")

        return {"task_id": task_id, "created": created, "skipped": skipped}


async def _apply_reserved(db, schedule, config):
    """应用留号"""
    from app.models.m04.schedule import M04RegSlot
    from sqlalchemy import select

    if not config:
        return

    total = schedule.total_quota
    onsite = int(total * (config.reserve_onsite_pct or 0) / 100)
    emergency = int(total * (config.reserve_emergency_pct or 0) / 100)
    green = int(total * (config.reserve_green_pct or 0) / 100)

    slots = (await db.execute(
        select(M04RegSlot)
        .where(M04RegSlot.schedule_id == schedule.id)
        .order_by(M04RegSlot.slot_no.desc())
    )).scalars().all()

    idx = 0
    for item in slots:
        if idx < green:
            item.source_type = "GREEN"
        elif idx < green + emergency:
            item.source_type = "EMERGENCY"
        elif idx < green + emergency + onsite:
            item.source_type = "ONSITE"
        else:
            break
        idx += 1

    await db.flush()


def _period_time(period: str):
    from datetime import time
    return {
        "AM": (time(8, 0), time(12, 0)),
        "PM": (time(14, 0), time(17, 30)),
        "NIGHT": (time(17, 30), time(21, 0)),
        "ALL_DAY": (time(8, 0), time(17, 30)),
    }.get(period, (time(8, 0), time(12, 0)))


def _add_minutes(t, minutes):
    from datetime import datetime, timedelta
    dt = datetime.combine(datetime.today(), t) + timedelta(minutes=minutes)
    return dt.time()


async def _mark_failed(task_id: str, error: str):

@shared_task
def release_expired_locks_task():
    """释放超时锁定的号源"""

async def _release_expired():

async def _reconcile_all():
    """对账所有未来排班"""
    from datetime import date
    from sqlalchemy import select
    from app.models.m04.schedule import M04Schedule
    from app.core.database import AsyncSessionLocal
    from app.services.m04.slot_service import SlotService

    async with AsyncSessionLocal() as db:
        rows = (await db.execute(
            select(M04Schedule.id).where(
                M04Schedule.schedule_date >= date.today(),
                M04Schedule.status == "NORMAL",
                M04Schedule.is_deleted == False,
            )
        )).scalars().all()

        svc = SlotService(db)
        drifted = []
        for sid in rows:
            result = await svc.reconcile(sid)
            if result["corrected"]:
```

```python
# app/tasks/m04/schedule_jobs.py
from apscheduler.schedulers.asyncio import AsyncIOScheduler
from apscheduler.triggers.cron import CronTrigger


scheduler = AsyncIOScheduler(timezone="Asia/Shanghai")


async def release_reserved_slots():
    """开诊前释放未用的留号"""
    from datetime import datetime, timedelta, date
    from sqlalchemy import select
    from app.models.m04.schedule import M04Schedule, M04RegSlot, M04ScheduleConfig
    from app.core.database import AsyncSessionLocal
    from app.core.redis import redis_client

    async with AsyncSessionLocal() as db:
        config = (await db.execute(
            select(M04ScheduleConfig).where(M04ScheduleConfig.id == 1)
        )).scalar_one_or_none()

        if not config or config.release_reserved_mode == "NONE":
            return {"released": 0}

        now = datetime.now()
        threshold = now + timedelta(minutes=30)     # 开诊前 30 分钟

        # 找即将开诊的排班
        schedules = (await db.execute(
            select(M04Schedule).where(
                M04Schedule.schedule_date == date.today(),
                M04Schedule.status == "NORMAL",
                M04Schedule.is_deleted == False,
            )
        )).scalars().all()

        released = 0
        for s in schedules:
            if not s.start_time:
                continue
            start_dt = datetime.combine(s.schedule_date, s.start_time)
            if start_dt > threshold:
                continue
            if start_dt < now:
                continue    # 已开诊

            # 释放 ONSITE / GREEN 未用号源到 OPEN
            slots = (await db.execute(
                select(M04RegSlot).where(
                    M04RegSlot.schedule_id == s.id,
                    M04RegSlot.status == "AVAILABLE",
                    M04RegSlot.source_type.in_(("ONSITE", "GREEN")),
                )
            )).scalars().all()

            for slot in slots:
                slot.source_type = "OPEN"
                released += 1

        await db.commit()
        return {"released": released}


scheduler.add_job(
    release_reserved_slots,
    CronTrigger(minute="*/10"),
    id="job_m04_release_reserved",
    name="释放未用留号",
    replace_existing=True,
)
```

**降级策略：**

| 依赖 | 故障时 |
|---|---|
| Redis（号源库存） | **拒绝挂号**（安全优先，不可超卖） |
| DB | 拒绝 |
| M01 医生/科室 | 用缓存 |
| M03-05 消息 | 停诊成功但通知延后 |
| Redis（日历缓存） | 直连 DB |

> **关键：** 号源库存是 Redis 权威，Redis 不可用时**不可降级到 DB 直接扣减**（高并发下会超卖），必须拒绝挂号并提示稍后重试。
