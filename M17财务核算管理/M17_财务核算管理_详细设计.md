## 1. 模块定位

### 1.1 一句话定位

**M17 财务核算管理是全院唯一的「会计账本」**：把 M16 收到的钱、M14/M15 花掉的钱、M05/M06/M09 产生的业务量，按会计科目和核算项目归集成**收入、成本、科室损益、绩效**，产出**总账、明细账、科目余额表**，并与银行/支付渠道对账，最终支撑医院财务核算与院领导决策。

### 1.2 为什么财务核算必须独立成模块

| # | 理由 | 事实支撑 |
|---|---|---|
| 1 | **会计准则的强制性** | 医院须执行《政府会计制度》或《企业会计准则》，凭证、账簿、报表有法定格式与勾稽关系，不能混在业务系统里 |
| 2 | **数据来源已齐备** | M16-09 已有 `m16_daily_close`（日结三层快照）、M14 有期间出库成本、M15 有消耗成本、M07 有工作量——**M17 所需上游数据 100% 就绪** |
| 3 | **业务系统的金额不可作账** | 业务系统的「金额」按业务口径（应收/实收/减免），会计需要按**科目 + 核算项目**的复式记账口径，两者维度不同 |
| 4 | **绩效与成本必须同源** | 绩效方案依赖科室结余，科室结余依赖成本分摊，把绩效放在别的模块会导致口径分裂，科室不认账 |

### 1.3 与相邻模块的边界

| 模块 | 归它的 | 归 M17 的 |
|---|---|---|
| M16 收费结算 | 收钱、开票、日结、退费 | 把日结拆成会计分录 |
| M14 药房药库 | 药品出库、批次成本 | 药品成本归集到科室 |
| M15 物资耗材 | 耗材消耗、二级库 | 耗材成本归集到科室/台次 |
| M05 / M06 / M09 | 住院费用、手术台次、业务量 | 业务量 → 绩效金额 |
| M01 主数据 | 科室、职工、收费项目（含默认科目编码） | **会计科目表本身、科目树、核算项目** |
| M22 报表 | 管理口径报表、可视化 | 法定口径财务报表 |

## 3. 核算闭环

### 3.1 主闭环：日 → 月 → 年

```
【日】  M16 日结封账 (m16.daily.frozen)
            │
            ▼
      M17-02 收入凭证生成  ──┐
            │                │
【日】  M14/M15 成本上报      │
            ▼                │
      M17-03 成本凭证生成  ──┤
            │                │
【日/月】 M17-04 科室损益 ←──┘
            │
            ▼
【月】  M17-05 凭证审核 → 过账 → 试算平衡 → 月末结账
            │
            ▼
【月】  M17-06 银行对账（账面 vs 银行流水）
            │
            ▼
【月】  M17-07 绩效结算（科室结余 × 权重）
            │
            ▼
【月/季/年】 M17-08 财务报表 → 院领导 / M22
            │
            ▼
【年】  年结 → 下年期初
```

### 3.2 关键勾稽关系（必须成立的六条）

| # | 关系 | 说明 |
|---|---|---|
| 1 | **借贷平衡** | 每张凭证 `debit_total = credit_total` |
| 2 | **试算平衡** | 全院 Σ借方发生 = Σ贷方发生 |
| 3 | **余额连续** | 期末余额 = 期初余额 + 本期借方 − 本期贷方 |
| 4 | **资产负债表平衡** | 资产 = 负债 + 所有者权益 |
| 5 | **收入勾稽** | M17 收入合计 = M16 净收入合计（差异须有说明） |
| 6 | **成本勾稽** | M17 成本合计 = M14 出库成本 + M15 消耗成本 + 其他（差异须有说明） |

## 4. 全局状态机

### 4.1 会计期间状态机

```
     ┌──────────┐  启用   ┌────────┐  结账   ┌────────┐  年结  ┌────────┐
     │ NOT_OPEN │───────▶│  OPEN  │────────▶│ CLOSED │──────▶│ LOCKED │
     └──────────┘        └────────┘         └────────┘       └────────┘
                              ▲                  │                 │
                              │      反结账      │      反年结     │
                              └──────────────────┴─────────────────┘
                                       (需审批，产生 REOPENED 记录)
```

| 状态 | 中文 | 允许操作 |
|---|---|---|
| `NOT_OPEN` | 未开启 | 仅可配置，不可录凭证 |
| `OPEN` | 已开启 | 全部业务 |
| `CLOSED` | 已结账 | 只读；更正须「反结账 → 改 → 再结账」 |
| `LOCKED` | 已封存 | 只读；反年结需院长审批 |

### 4.2 凭证状态机

```
   ┌───────┐ 提交  ┌───────────┐ 审核  ┌────────┐ 过账  ┌────────┐
   │ DRAFT │──────▶│ SUBMITTED │──────▶│ AUDITED│──────▶│ POSTED │
   └───────┘       └───────────┘       └────────┘       └────────┘
       │                 │                                          │
       │ 作废            │ 驳回                                     │ 冲销
       ▼                 ▼                                          ▼
  ┌───────────┐    (回 DRAFT)                                ┌──────────┐
  │ CANCELLED │                                              │ REVERSED │
  └───────────┘                                              └──────────┘
```

| 状态 | 中文 | 可否修改 | 说明 |
|---|---|---|---|
| `DRAFT` | 草稿 | ✅ | — |
| `SUBMITTED` | 待审核 | ❌ | 需先驳回 |
| `AUDITED` | 已审核 | ❌ | 待过账 |
| `POSTED` | 已过账 | ❌ **物理禁止** | 只能红冲 |
| `REVERSED` | 已冲销 | ❌ | 已被红字冲销 |
| `CANCELLED` | 已作废 | ❌ | 未过账即作废 |

## 6. 核心计算模型

### 6.1 借贷平衡（凭证级）

```
Σ debit_amount = Σ credit_amount
```

- 精度：`NUMERIC(18,2)`，精确到分
- 强制：数据库 `CHECK` 约束
- 失败：`"1705001"` 借贷不平衡

**算例：** 门诊某日收入毛额 129,250.00 元

患者应付（毛额）129,250.00 元，其中现金 15,300.00、微信/支付宝/POS 到账 108,450.00、医保应收 5,200.00，合计 128,950.00；渠道手续费 300.00 元由医院承担，单独列支借方。**收入按毛额记贷方，手续费单独列支，不减记收入**：

| 方向 | 科目 | 金额 |
|---|---|---|
| 借 | 1001 库存现金 | 15,300.00 |
| 借 | 1002 银行存款 | 108,450.00 |
| 借 | 1122 应收账款-医保 | 5,200.00 |
| 借 | 6602 管理费用-手续费 | 300.00 |
| 贷 | 4001 医疗收入-门诊 | 129,250.00 |
| **合计** | — | **借 129,250.00 = 贷 129,250.00** ✓ |

> **口径说明（务必按此实现）：** 借方四行合计恰为 129,250.00，与贷方收入毛额 129,250.00 相等。其中现金 15,300.00 + 到账 108,450.00 + 医保应收 5,200.00 = 128,950.00，是**净到账额**；手续费 300.00 补足差额，使「毛额收入 = 净到账 + 手续费 + 医保应收」。**若把手续费同时记入收入贷方，就会重复计算并造成借贷差 300.00。** 净额法记账时医保应收与手续费的双向体现规则见 M17-02 详细设计 §3.4.5。

### 6.2 科目余额（余额级）

```
期末余额 = 期初余额 + 本期借方发生 − 本期贷方发生   （借方科目）
期末余额 = 期初余额 + 本期贷方发生 − 本期借方发生   （贷方科目）
```

- 强制：`CHECK (end_balance = open_balance + period_debit - period_credit)` 的等价形式（按余额方向）
- 算例：1002 银行存款，期初 2,000,000.00，本期借方 3,450,000.00，贷方 2,780,000.00
  → 期末 = 2,000,000.00 + 3,450,000.00 − 2,780,000.00 = **2,670,000.00**

### 6.3 间接费用分摊

```
某科室分摊额 = 待分摊总额 × (该科室分摊基数 / 全部分摊基数之和)
```

- 基数：按收入 / 按成本 / 按人数 / 按面积 / 按工作量（`allocate_method`）
- **尾差处理**：前 N−1 个科室按公式四舍五入到分，**最后一个科室 = 总额 − 前 N−1 个之和**
- 失败条件：基数之和 = 0 → 错误码 `"1703001"`

**算例：** 待分摊水电费 50,000.00 元，按面积分摊

| 科室 | 面积(㎡) | 占比 | 公式值 | 实际分摊 |
|---|---|---|---|---|
| 白内障 | 400 | 0.333333 | 16,666.67 | 16,666.67 |
| 屈光 | 350 | 0.291667 | 14,583.33 | 14,583.33 |
| 视光 | 300 | 0.25 | 12,500.00 | 12,500.00 |
| 门诊 | 150 | 0.125 | 6,750.00 | **6,250.00**（吸收尾差） |
| **合计** | **1,200** | **1.000000** | **50,500.00** | **50,000.00** ✓ |

### 6.4 科室结余

```
科室结余 = 科室收入 − 科室直接成本 − 科室分摊成本
```

**算例：** 屈光科室收入 1,850,000.00，直接成本 980,000.00，分摊成本 320,000.00
→ 结余 = 1,850,000.00 − 980,000.00 − 320,000.00 = **550,000.00**，结余率 = 550,000.00 / 1,850,000.00 = **0.297297**

### 6.5 绩效计算

```
个人绩效 = Σ (指标实际值 × 单位分值 × 权重) × 科室系数 × 质量调整系数
```

- 单位分值、权重见 `m17_perf_indicator`
- 质量调整系数：由 M11-07 质量指标、M16 差错率决定，范围 `0.85` ~ `1.00`
- 失败条件：方案未生效 / 期间未结账

**算例：** 医生 A，门诊量 680 人次，手术量 42 台

| 指标 | 实际值 | 单价 | 权重 | 得分 |
|---|---|---|---|---|
| 门诊量 | 680 | 8.00 | 0.40 | 2,176.00 |
| 手术量 | 42 | 120.00 | 0.60 | 3,024.00 |
| **小计** | — | — | — | **5,200.00** |

科室系数 1.05，质量系数 0.98 → 绩效 = 5,200.00 × 1.05 × 0.98 = **5,350.80**

### 6.6 资产负债平衡

```
资产合计 = 负债合计 + 所有者权益合计
```

- 校验容差：`0.00`（严格相等）
- 失败：`"1708001"` 报表不平衡
