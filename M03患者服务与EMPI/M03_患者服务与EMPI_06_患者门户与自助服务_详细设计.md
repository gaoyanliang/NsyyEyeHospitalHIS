## 1. 模块概述

### 1.1 模块定位

患者门户是 M03 面向**院外患者**的唯一入口，覆盖三条触达渠道：

```
┌───────────────────────────────────────────────────────────────────┐
│                        患者（院外）                                │
└──────────────┬────────────────────┬────────────────────┬──────────┘
               ▼                    ▼                    ▼
      ┌────────────────┐   ┌────────────────┐   ┌────────────────┐
      │ 微信公众号      │   │ 微信小程序      │   │ 院内自助机      │
      │ （服务号）      │   │                │   │ （大屏终端）    │
      └────────┬───────┘   └────────┬───────┘   └────────┬───────┘
               └────────────────────┼────────────────────┘
                                    ▼
      ┌───────────────────────────────────────────────────────────┐
      │  M03-06 患者门户与自助服务（本文档）                        │
      │  · 患者身份认证（微信授权 / 手机号 / 身份证 / 人脸）        │
      │  · 患者绑定与家庭账号                                       │
      │  · 自助建档与信息补全                                       │
      │  · 预约挂号 / 缴费 / 报告查询（对接 M04/M12/M13/M16）        │
      │  · 会员中心 / 随访问卷 / 消息中心                           │
      │  · 服务协议与隐私授权                                       │
      └───────────────────────────┬───────────────────────────────┘
                                  ▼
      ┌───────────────────────────────────────────────────────────┐
      │  M03-01 患者主索引 │ M03-03 会员 │ M03-04 随访 │ M03-05 消息 │
      │  M04 门诊挂号 │ M12 检查 │ M13 检验 │ M16 收费             │
      └───────────────────────────────────────────────────────────┘
```

**核心特征：**

| 特征 | 说明 |
|---|---|
| **院外访问** | 患者不在院内网络，需经公网防护（M02-07 白名单例外） |
| **弱身份** | 患者不是职工，不能走 M02 职工账号体系 |
| **强隐私** | 医疗数据高度敏感，必须严格绑定与授权 |
| **多渠道** | 同一患者可能同时用公众号、小程序、自助机 |
| **无需登录也能用** | 报告查询、预约等部分能力允许一次性凭证 |

### 1.3 与 M02 的严格分离

**这是本子模块最重要的架构约束：**

| 维度 | M02 职工账号 | M03-06 患者账号 |
|---|---|---|
| 主体 | 职工 | 患者 |
| 表 | `sys_account` | `mpi_portal_account`（本模块） |
| 登录入口 | 内网 PC / 移动办公 | 公众号 / 小程序 / 自助机 |
| 认证方式 | 密码 + MFA | 微信授权 / 手机验证码 / 身份证 / 人脸 |
| 令牌 | Access + Refresh（M02-03） | Patient Token（本模块，独立签发） |
| 权限模型 | 功能/数据/字段三维 | **仅患自身数据**（硬编码约束） |
| 网络 | 内网 / VPN | **公网** |
| 审计 | `sys_audit_log` | `sys_audit_log`（同一套） |

> **禁止：** 患者门户**绝不允许**调用 M02 的职工登录接口，也**绝不允许**获得任何 `sys_perm_*` 权限。患者令牌只能用于访问本模块接口，本模块再以**服务身份**调用 M03/M04/M12/M13/M16 的内部接口。

### 1.4 模块目标

- **易用**：3 步完成绑定，扫码即用。
- **安全**：患者只能看自己的数据，绑定需强验证。
- **一致**：多端（公众号/小程序/自助机）数据完全一致。
- **隐私**：授权可查、可撤回，全量留痕。
- **可运营**：公告、Banner、服务入口可配置。
- **高可用**：公网访问，需抗压与限流。

### 1.5 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 患者 | 使用者 | 绑定、建档、预约、缴费、查报告 |
| 家属/监护人 | 代操作 | 绑定家庭成员 |
| 客服/导医 | 协助 | 解绑审核、绑定异常处理 |
| 信息科 | 运维 | 渠道配置、自助机管理、公告 |
| 会员运营 | 运营 | 会员权益展示配置 |

## 3. 业务模型

### 3.1 渠道模型

| 渠道代码 | 名称 | 载体 | 认证方式 | 特点 |
|---|---|---|---|---|
| `WECHAT_MP` | 微信公众号 | 微信服务号 H5 | 微信授权 + 手机号 | 老年患者友好 |
| `WECHAT_MINI` | 微信小程序 | 小程序 | 微信授权 + 手机号 | 体验最佳 |
| `ALIPAY_MINI` | 支付宝小程序 | 支付宝 | 支付宝授权 | 预留 |
| `KIOSK` | 院内自助机 | 大屏终端 | 身份证 + 人脸 | 现场使用 |
| `WEB` | 网页版 | 浏览器 | 手机验证码 | 兜底 |

**渠道差异：**

| 能力 | 公众号 | 小程序 | 自助机 | 网页 |
|---|---|---|---|---|
| 微信授权登录 | ✅ | ✅ | — | — |
| 手机号一键获取 | ✅ | ✅ | — | — |
| 身份证读卡 | — | — | ✅ | — |
| 人脸识别 | — | — | ✅ | — |
| 支付 | H5 支付 | 小程序支付 | 扫码支付 | H5 支付 |
| 报告打印 | — | — | ✅ | — |
| 设备绑定 | — | — | ✅ | — |

### 3.2 患者认证模型

#### 3.2.1 认证方式

| 方式 | 代码 | 说明 | 信任等级 |
|---|---|---|---|
| 微信授权 | `WECHAT_OAUTH` | openid/unionid | 中（只证明微信身份） |
| 手机验证码 | `SMS_CODE` | 手机号 + 验证码 | 中 |
| 身份证 + 姓名 | `ID_CARD` | 二要素核验 | 高 |
| 身份证 + 姓名 + 手机 | `ID_CARD_PHONE` | 三要素核验 | 高 |
| 就诊卡 + 密码 | `CARD_PASSWORD` | 院内就诊卡 | 中 |
| 人脸识别 | `FACE` | 对接公安/第三方 | 高 |
| 人工审核 | `MANUAL` | 客服审核 | 高 |

#### 3.2.2 绑定验证等级

**不同敏感度的操作要求不同验证等级：**

| 操作 | 最低验证等级 | 说明 |
|---|---|---|
| 浏览公告、查看服务入口 | 无需绑定 | 匿名可访问 |
| 预约挂号 | 基础绑定 | 手机号或微信即可 |
| 查看本人报告 | **强绑定** | 身份证二要素或人脸 |
| 查看家属报告 | **强绑定 + 关系证明** | 需添加家庭成员 |
| 缴费 | 基础绑定 | 支付即验证 |
| 查看病历 | **强绑定** | 最严格 |
| 修改关键信息 | **强绑定** | 姓名、证件不可自助改 |

**验证等级定义：**

| 等级 | 代码 | 达成条件 |
|---|---|---|
| 匿名 | `NONE` | 未登录 |
| 基础 | `BASIC` | 手机验证码 / 微信授权 |
| 强 | `STRONG` | 身份证二要素 / 人脸 / 人工审核 |
| 家属 | `FAMILY` | 强验证 + 家庭关系绑定 |

### 3.3 患者绑定模型

#### 3.3.1 绑定关系

```
┌──────────────────────┐
│ mpi_portal_account   │  一个门户账号（微信 openid 或手机号）
│  · account_id        │
│  · channel           │
│  · openid / unionid  │
│  · phone             │
└──────────┬───────────┘
           │ 1 : N
           ▼
┌──────────────────────┐
│ mpi_portal_binding   │  绑定关系（本人 + 家属）
│  · account_id        │
│  · patient_id        │──► mpi_patient（M03-01）
│  · relation          │  SELF / SPOUSE / CHILD / PARENT / OTHER
│  · verify_level      │  BASIC / STRONG / FAMILY
│  · is_default        │
└──────────────────────┘
```

#### 3.3.2 家庭账号规则

| 规则 | 说明 |
|---|---|
| 绑定上限 | 单账号最多绑定 **8** 个患者 |
| 本人绑定 | 每个账号必须有且仅有一个 `relation=SELF` |
| 家属关系 | SPOUSE / CHILD / PARENT / OTHER |
| 代操作权限 | 家属可代预约、代缴费；**不可**代签知情同意、不可代撤回授权 |
| 未成年人 | 儿童患者需监护人绑定，`guardian_id` 必填 |
| 解绑 | 本人可自助解绑家属；解绑本人需客服审核 |

#### 3.3.3 绑定状态

| 状态 | 说明 |
|---|---|
| `PENDING` | 待验证 |
| `ACTIVE` | 已绑定 |
| `REJECTED` | 绑定被拒 |
| `UNBOUND` | 已解绑 |
| `MERGED` | 患者已合并，指向新患者 |

### 3.4 自助建档模型

#### 3.4.1 建档流程

```
患者选择"自助建档"
   ↓
① 证件采集（身份证读卡 / 手工输入 / 拍照 OCR）
   ↓
② 调用 M03-01 `by-id-card` 查是否已存在
   ├─ 已存在 → 直接绑定（走 §3.5）
   └─ 不存在 → 继续
   ↓
③ 填写基本信息（姓名、性别、出生日期、手机、地址）
   ↓
④ 证件二要素核验（M21 对接公安库）
   ├─ 通过 → 继续
   └─ 不通过 → 提示重新填写（最多 3 次）
   ↓
⑤ 签署服务协议 + 隐私授权
   ↓
⑥ 调用 M03-01 `POST /internal/v1/patient/create`
   ├─ 成功 → 绑定 + 返回 EMPI
   └─ 疑似重复（quality < 阈值）→ 提示"可能已建档"并引导绑定
   ↓
⑦ 建档完成，可预约
```

#### 3.4.2 自助建档字段范围

| 字段 | 必填 | 可自助修改 | 说明 |
|---|---|---|---|
| 姓名 | 是 | 否（需审核） | — |
| 证件类型 | 是 | 否 | — |
| 证件号 | 是 | 否 | — |
| 性别 | 是 | 否 | 由证件推导 |
| 出生日期 | 是 | 否 | 由证件推导 |
| 手机号 | 是 | 是（需验证） | — |
| 现住址 | 否 | 是 | — |
| 民族 | 否 | 是 | — |
| 婚姻 | 否 | 是 | — |
| 职业 | 否 | 是 | — |
| 学历 | 否 | 是 | — |
| 过敏史 | 否 | 是 | **需强验证** |
| 既往史 | 否 | 否 | 门诊录入 |

> **关键约束：** 姓名、证件类型、证件号、性别、出生日期**只能由 M03-01 在强验证后修改**，门户不可自助改。

### 3.5 门户会话模型

```
患者登录（微信授权 / 手机验证码 / 身份证+人脸）
        ↓
M03-06 认证服务
   ├─ 校验渠道凭证
   ├─ 查找/创建 mpi_portal_account
   ├─ 查找绑定关系
   └─ 签发 Patient Token
        ↓
Patient Token（JWT）
  {
    "sub": "pa_9e8d7c6b5a4f",       // 门户账号 ID
    "channel": "WECHAT_MINI",
    "binding_ids": [1001, 1002],     // 当前可用绑定
    "active_binding": 1001,          // 当前操作的患者
    "verify_level": "STRONG",
    "jti": "...",
    "exp": 1743500640,
    "iat": 1743497040
  }
```

**Token 规格：**

| 项 | 值 | 说明 |
|---|---|---|
| 有效期 | **2 小时** | 比职工 Access Token 短（院外环境更不安全） |
| 刷新 | 静默续期 | 有活跃操作时自动续期 |
| 存储 | `sessionStorage`（H5）/ 小程序 Storage | **不用 Cookie**（避免 CSRF） |
| 签发密钥 | 独立于 M02 的 JWT 密钥 | 患者与职工令牌不可互换 |
| 注销 | 立即失效 | Redis 黑名单 |

### 3.6 协议与授权模型

#### 3.6.1 协议类型

| 类型 | 代码 | 内容 | 签署时机 |
|---|---|---|---|
| 服务协议 | `SERVICE` | 平台使用条款 | 首次注册 |
| 隐私政策 | `PRIVACY` | 个人信息处理规则 | 首次注册 + 版本更新 |
| 就诊授权 | `TREATMENT` | 允许调阅就诊记录 | 首次绑定 + 每次就诊 |
| 家属代操作授权 | `GUARDIAN` | 允许家属代为操作 | 绑定家属时 |
| 数据共享授权 | `SHARING` | 允许向第三方共享（如保险） | 按需，默认拒绝 |
| 营销推送授权 | `MARKETING` | 允许发送营销消息 | 可选，可单独撤回 |

#### 3.6.2 授权生命周期

```
未授权 → 患者签署 → 已授权 → 患者撤回 / 过期 → 已失效
                     ↓
               记录 consent_id、签署时间、版本、IP、UA
```

**授权记录落 `mpi_patient_consent`（M03-01 表，本模块写入）：**

| 字段 | 值 |
|---|---|
| patient_id | 患者 ID |
| consent_type | SERVICE / PRIVACY / TREATMENT / GUARDIAN / SHARING / MARKETING |
| consent_version | 协议版本号 |
| consent_value | GRANTED / REVOKED |
| channel | 门户渠道 |
| signed_at | 签署时间 |
| revoked_at | 撤回时间 |
| evidence_json | IP、UA、微信 openid 等证据 |

### 3.9 患者合并联动

```
M03-02 执行合并
   ↓ 发布事件 mpi.patient.merged

   ↓
```

```python
# app/services/portal/auth_service.py
"""门户认证服务"""
import hashlib
import secrets
import uuid
from datetime import datetime, timedelta
from typing import Optional

import jwt
from sqlalchemy import select, func
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.portal.account import MpiPortalAccount, MpiPortalSession
from app.models.portal.binding import MpiPortalBinding
from app.schemas.portal.auth import WechatLoginRequest, SmsLoginRequest
from app.core.config import settings
from app.core.exceptions import BizException
from app.core.redis import redis_client
from app.core.crypto import hash_value
from app.clients.m21_client import M21Client


class PortalAuthService:
    """门户认证"""

    TOKEN_TTL = 7200                # 2 小时
    SMS_TTL = 300                   # 验证码 5 分钟
    SMS_INTERVAL = 60               # 发送间隔 60 秒
    SMS_DAILY_LIMIT = 10            # 单手机号每日 10 次
    MAX_BINDINGS = 8                # 最多绑定 8 个患者

    def __init__(self, db: AsyncSession):
        self.db = db
        self.m21 = M21Client()

    # ---------- 微信登录 ----------
    async def wechat_login(self, payload: WechatLoginRequest,
                            request) -> dict:
        """微信授权登录"""
        if not payload.agree_service or not payload.agree_privacy:
            raise BizException(52025, "请先阅读并同意服务协议与隐私政策")

        # 1. 换取 openid
        oauth = await self.m21.wechat_oauth(
            code=payload.code, channel=payload.channel)
        if not oauth or not oauth.get("openid"):
            raise BizException(52004, "微信授权失败，请重试")

        openid = oauth["openid"]
        unionid = oauth.get("unionid")

        # 2. 查找或创建账号
        account = await self._find_or_create_by_openid(
            openid, unionid, payload.channel)

        if account.status != "ACTIVE":
            raise BizException(52002, "账号已被禁用，请联系客服")

        # 3. 可选：获取手机号
        phone = None
        if payload.phone_code:
            phone = await self.m21.wechat_phone(payload.phone_code)
            if phone and not account.phone:
                account.phone = hash_value(phone)
                account.phone_mask = self._mask_phone(phone)

        # 4. 记录登录
        account.last_login_at = datetime.now()
        account.last_login_ip = self._client_ip(request)
        account.login_count = (account.login_count or 0) + 1
        await self.db.commit()

        # 5. 签发 Token
        bindings = await self._load_bindings(account.account_id)
        token = await self._issue_token(account, bindings)

        return {
            "token": token,
            "expires_in": self.TOKEN_TTL,
            "account_id": account.account_id,
            "is_new_account": account.login_count == 1,
            "bindings": bindings,
            "need_binding": len(bindings) == 0,
            "next_action": "BIND_PATIENT" if not bindings else "HOME",
        }

    # ---------- 短信登录 ----------
    async def sms_login(self, payload: SmsLoginRequest,
                         request) -> dict:
        """手机验证码登录"""
        if not payload.agree_service or not payload.agree_privacy:
            raise BizException(52025, "请先阅读并同意服务协议与隐私政策")

        phone = payload.phone
        if not self._valid_phone(phone):
            raise BizException(52006, "手机号格式不正确")

        # 校验验证码
        await self._verify_sms(phone, payload.sms_code)

        phone_hash = hash_value(phone)
        account = (await self.db.execute(
            select(MpiPortalAccount).where(
                MpiPortalAccount.phone == phone_hash,
                MpiPortalAccount.status != "CANCELLED",
            )
        )).scalar_one_or_none()

        is_new = account is None
        if is_new:
            account = MpiPortalAccount(
                account_id=self._gen_account_id(),
                phone=phone_hash,
                phone_mask=self._mask_phone(phone),
                channel=payload.channel or "WEB",
                status="ACTIVE",
                login_count=1,
                last_login_at=datetime.now(),
                last_login_ip=self._client_ip(request),
            )
            self.db.add(account)
        else:
            if account.status != "ACTIVE":
                raise BizException(52002, "账号已被禁用，请联系客服")
            account.last_login_at = datetime.now()
            account.last_login_ip = self._client_ip(request)
            account.login_count = (account.login_count or 0) + 1

        await self.db.commit()

        bindings = await self._load_bindings(account.account_id)
        token = await self._issue_token(account, bindings)

        return {
            "token": token,
            "expires_in": self.TOKEN_TTL,
            "account_id": account.account_id,
            "is_new_account": is_new,
            "bindings": bindings,
            "need_binding": len(bindings) == 0,
            "next_action": "BIND_PATIENT" if not bindings else "HOME",
            "verify_hint": self._verify_hint(bindings),
        }

    # ---------- 验证码 ----------
    async def _verify_sms(self, phone: str, code: str) -> None:
        """校验短信验证码"""
        key = f"portal:sms:{hash_value(phone)}"
        stored = await redis_client.get(key)

        if not stored or stored != code:
            raise BizException(52007, "验证码错误或已过期")

        # 一次性使用
        await redis_client.delete(key)

    # ---------- Token ----------
    async def _issue_token(self, account: MpiPortalAccount,
                             bindings: list) -> str:
        """签发患者 Token"""
        now = datetime.now()
        jti = uuid.uuid4().hex

        active_binding = next(
            (b for b in bindings if b["is_default"]), bindings[0] if bindings else None)

        payload = {
            "sub": account.account_id,
            "channel": account.channel,
            "binding_ids": [b["binding_id"] for b in bindings],
            "active_binding": active_binding["binding_id"] if active_binding else None,
            "verify_level": active_binding["verify_level"] if active_binding else "NONE",
            "jti": jti,
            "iat": int(now.timestamp()),
            "exp": int((now + timedelta(seconds=self.TOKEN_TTL)).timestamp()),
            "typ": "PATIENT",          # 关键：与职工 Token 区分
        }

        token = jwt.encode(
            payload,
            settings.PORTAL_JWT_SECRET,     # 独立密钥，不与 M02 共用
            algorithm="HS256",
            headers={"kid": settings.PORTAL_JWT_KID},
        )

        # 记录会话
        self.db.add(MpiPortalSession(
            session_id=jti,
            account_id=account.account_id,
            channel=account.channel,
            active_binding=payload["active_binding"],
            verify_level=payload["verify_level"],
            client_ip=None,
            created_at=now,
            expires_at=now + timedelta(seconds=self.TOKEN_TTL),
            status="ACTIVE",
        ))
        await self.db.commit()

        return token

    async def refresh(self, account, request) -> dict:
        """刷新 Token"""
        bindings = await self._load_bindings(account.account_id)
        token = await self._issue_token(account, bindings)
        return {
            "token": token,
            "expires_in": self.TOKEN_TTL,
            "bindings": bindings,
        }

    async def logout(self, account, request) -> None:
        """登出（吊销当前会话）"""
        session_id = getattr(account, "session_id", None)
        if session_id:
            sess = (await self.db.execute(
                select(MpiPortalSession).where(
                    MpiPortalSession.session_id == session_id)
            )).scalar_one_or_none()
            if sess:
                sess.status = "REVOKED"
                sess.revoked_at = datetime.now()
                await self.db.commit()

            # 加入黑名单
            await redis_client.setex(
                f"portal:blacklist:{session_id}", self.TOKEN_TTL, "1")

    # ---------- 辅助 ----------
    async def _find_or_create_by_openid(self, openid: str,
                                          unionid: Optional[str],
                                          channel: str) -> MpiPortalAccount:
        account = (await self.db.execute(
            select(MpiPortalAccount).where(
                MpiPortalAccount.openid == openid,
                MpiPortalAccount.status != "CANCELLED",
            )
        )).scalar_one_or_none()

        if account:
            return account

        # unionid 已存在 → 复用（同一微信在公众号/小程序间共享）
        if unionid:
            account = (await self.db.execute(
                select(MpiPortalAccount).where(
                    MpiPortalAccount.unionid == unionid,
                    MpiPortalAccount.status != "CANCELLED",
                )
            )).scalar_one_or_none()
            if account:
                account.openid = openid
                return account

        account = MpiPortalAccount(
            account_id=self._gen_account_id(),
            openid=openid,
            unionid=unionid,
            channel=channel,
            status="ACTIVE",
            login_count=0,
        )
        self.db.add(account)
        await self.db.flush()
        return account

    async def _load_bindings(self, account_id: str) -> list:
        rows = (await self.db.execute(
            select(MpiPortalBinding).where(
                MpiPortalBinding.account_id == account_id,
                MpiPortalBinding.status == "ACTIVE",
            ).order_by(
                MpiPortalBinding.is_default.desc(),
                MpiPortalBinding.bound_at.asc(),
            )
        )).scalars().all()

        return [
            {
                "binding_id": r.id,
                "patient_id": r.patient_id,
                "empi_no": r.empi_no,
                "patient_name": r.patient_name,
                "relation": r.relation,
                "relation_text": self._relation_text(r.relation),
                "verify_level": r.verify_level,
                "is_default": r.is_default,
            }
            for r in rows
        ]

    async def build_home(self, account, binding_id: Optional[int]) -> dict:
        """构建首页聚合数据"""
        from app.services.portal.home_service import PortalHomeService
        svc = PortalHomeService(self.db)
        return await svc.build(account, binding_id)

    @staticmethod
    def _gen_account_id() -> str:
        return f"pa_{secrets.token_hex(6)}"

    @staticmethod
    def _valid_phone(phone: str) -> bool:
        import re
        return bool(re.fullmatch(r"1[3-9]\d{9}", phone))

    @staticmethod
    def _mask_phone(phone: str) -> str:
        return f"{phone[:3]}****{phone[-4:]}"

    @staticmethod
    def _relation_text(relation: str) -> str:
        return {
            "SELF": "本人", "SPOUSE": "配偶", "CHILD": "子女",
            "PARENT": "父母", "OTHER": "其他",
        }.get(relation, relation)

    @staticmethod
    def _verify_hint(bindings: list) -> Optional[str]:
        if not bindings:
            return None
        if all(b["verify_level"] == "BASIC" for b in bindings):
            return "当前为基础验证，查看报告需完成身份验证"
        return None

    @staticmethod
    def _client_ip(request) -> Optional[str]:
        xff = request.headers.get("x-forwarded-for")
        if xff:
            return xff.split(",")[0].strip()
        return request.client.host if request.client else None
```

```python
# app/services/portal/binding_service.py
"""门户绑定服务"""
from datetime import datetime
from typing import List

from sqlalchemy import select, and_, func
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.portal.account import MpiPortalAccount
from app.models.portal.binding import MpiPortalBinding, MpiPortalBindingLog
from app.schemas.portal.binding import BindingCreate
from app.core.exceptions import BizException
from app.core.redis import redis_client
from app.core.crypto import hash_value
from app.clients.mpi_client import MpiClient
from app.clients.m21_client import M21Client


class PortalBindingService:
    """患者绑定"""

    MAX_BINDINGS = 8
    MAX_VERIFY_FAIL = 3
    LOCK_SECONDS = 3600

    def __init__(self, db: AsyncSession):
        self.db = db
        self.mpi = MpiClient()
        self.m21 = M21Client()

    async def list_bindings(self, account_id: str) -> dict:
        rows = (await self.db.execute(
            select(MpiPortalBinding).where(
                MpiPortalBinding.account_id == account_id,
                MpiPortalBinding.status == "ACTIVE",
            ).order_by(MpiPortalBinding.is_default.desc())
        )).scalars().all()

        return {
            "total": len(rows),
            "max": self.MAX_BINDINGS,
            "items": [self._to_item(r) for r in rows],
        }

    async def bind_self(self, account, payload: BindingCreate,
                          request) -> dict:
        """绑定本人"""
        # 1. 校验是否已有本人绑定
        exist_self = (await self.db.execute(
            select(MpiPortalBinding).where(
                MpiPortalBinding.account_id == account.account_id,
                MpiPortalBinding.relation == "SELF",
                MpiPortalBinding.status == "ACTIVE",
            )
        )).scalar_one_or_none()

        if exist_self:
            raise BizException(52021, "已绑定本人，如需更换请联系客服")

        return await self._do_bind(
            account, payload, "SELF", request, require_strong=True)

    async def bind_family(self, account, payload: BindingCreate,
                            request) -> dict:
        """绑定家属"""
        if payload.relation == "SELF":
            raise BizException(52022, "家属关系不能为本人")

        # 数量校验
        count = (await self.db.execute(
            select(func.count()).select_from(MpiPortalBinding).where(
                MpiPortalBinding.account_id == account.account_id,
                MpiPortalBinding.status == "ACTIVE",
            )
        )).scalar_one()

        if count >= self.MAX_BINDINGS:
            raise BizException(52020, f"最多绑定 {self.MAX_BINDINGS} 位就诊人")

        return await self._do_bind(
            account, payload, payload.relation, request, require_strong=True)

    async def _do_bind(self, account, payload: BindingCreate,
                         relation: str, request,
                         require_strong: bool) -> dict:
        """执行绑定（核心）"""
        # 1. 校验锁定状态
        lock_key = f"portal:verify:fail:{account.account_id}"
        fails = int(await redis_client.get(lock_key) or 0)
        if fails >= self.MAX_VERIFY_FAIL:
            raise BizException(52011, "验证失败次数过多，请 1 小时后再试")

        # 2. 二要素核验
        verified = await self.m21.verify_idcard(
            name=payload.patient_name,
            id_no=payload.id_no,
        )
        if not verified:
            await redis_client.incr(lock_key)
            await redis_client.expire(lock_key, self.LOCK_SECONDS)
            raise BizException(52010, "姓名与证件号不匹配，请核对后重试")

        await redis_client.delete(lock_key)

        # 3. 查患者
        id_hash = hash_value(payload.id_no)
        patient = await self.mpi.get_by_id_hash(id_hash)

        if not patient:
            raise BizException(52018, "未查询到该患者就诊记录，可选择自助建档")

        patient_id = patient["patient_id"]

        # 4. 检查是否已被其他账号绑定
        other = (await self.db.execute(
            select(MpiPortalBinding).where(
                MpiPortalBinding.patient_id == patient_id,
                MpiPortalBinding.status == "ACTIVE",
            )
        )).scalar_one_or_none()

        if other and other.account_id != account.account_id:
            raise BizException(52019, "该就诊人已被其他账号绑定，如需变更请联系客服")

        # 5. 同账号重复绑定
        if other and other.account_id == account.account_id:
            return self._to_item(other)

        # 6. 创建绑定
        is_default = relation == "SELF"
        if is_default:
            # 取消其他默认
            await self.db.execute(
                MpiPortalBinding.__table__.update()
                .where(MpiPortalBinding.account_id == account.account_id)
                .values(is_default=False)
            )

        binding = MpiPortalBinding(
            account_id=account.account_id,
            patient_id=patient_id,
            empi_no=patient.get("empi_no"),
            patient_name=payload.patient_name,
            relation=relation,
            verify_level="STRONG",
            verify_method="ID_CARD",
            is_default=is_default,
            status="ACTIVE",
            bound_at=datetime.now(),
            bound_ip=self._client_ip(request),
        )
        self.db.add(binding)
        await self.db.flush()

        self.db.add(MpiPortalBindingLog(
            binding_id=binding.id,
            account_id=account.account_id,
            patient_id=patient_id,
            action="BIND",
            detail=f"绑定方式：{binding.verify_method}",
        ))
        await self.db.commit()

        return self._to_item(binding)

    async def unbind(self, account, binding_id: int, request) -> None:
        """解绑"""
        binding = (await self.db.execute(
            select(MpiPortalBinding).where(
                MpiPortalBinding.id == binding_id,
                MpiPortalBinding.account_id == account.account_id,
                MpiPortalBinding.status == "ACTIVE",
            )
        )).scalar_one_or_none()

        if not binding:
            raise BizException(52017, "绑定关系不存在")

        if binding.relation == "SELF":
            raise BizException(52021, "本人绑定不可自助解绑，请联系客服")

        binding.status = "UNBOUND"
        binding.unbound_at = datetime.now()

        self.db.add(MpiPortalBindingLog(
            binding_id=binding.id,
            account_id=account.account_id,
            patient_id=binding.patient_id,
            action="UNBIND",
            detail="患者自助解绑",
        ))
        await self.db.commit()

    async def upgrade_verify_level(self, account, binding_id: int,
                                     payload: dict, request) -> dict:
        """提升验证等级"""
        binding = (await self.db.execute(
            select(MpiPortalBinding).where(
                MpiPortalBinding.id == binding_id,
                MpiPortalBinding.account_id == account.account_id,
                MpiPortalBinding.status == "ACTIVE",
            )
        )).scalar_one_or_none()

        if not binding:
            raise BizException(52017, "绑定关系不存在")

        method = payload.get("method")

        if method == "ID_CARD":
            ok = await self.m21.verify_idcard(
                name=payload.get("patient_name"),
                id_no=payload.get("id_no"),
            )
            if not ok:
                raise BizException(52010, "身份证核验失败")

        elif method == "FACE":
            ok = await self.m21.verify_face(
                name=payload.get("patient_name"),
                id_no=payload.get("id_no"),
                image=payload.get("image_base64"),
            )
            if not ok:
                raise BizException(52012, "人脸核验失败")

        else:
            raise BizException(40001, "不支持的验证方式")

        binding.verify_level = "STRONG"
        binding.verify_method = method
        binding.verified_at = datetime.now()

        self.db.add(MpiPortalBindingLog(
            binding_id=binding.id,
            account_id=account.account_id,
            patient_id=binding.patient_id,
            action="VERIFY_UPGRADE",
            detail=f"验证方式：{method}",
        ))
        await self.db.commit()

        return {"binding_id": binding.id, "verify_level": "STRONG"}

    async def on_patient_merged(self, payload: dict) -> dict:
        """处理患者合并事件"""
        merged_id = payload["merged_patient_id"]
        survivor_id = payload["survivor_patient_id"]

        rows = (await self.db.execute(
            select(MpiPortalBinding).where(
                MpiPortalBinding.patient_id == merged_id,
                MpiPortalBinding.status == "ACTIVE",
            )
        )).scalars().all()

        redirected = 0
        for b in rows:
            # 检查该账号是否已绑定 survivor
            dup = (await self.db.execute(
                select(MpiPortalBinding).where(
                    MpiPortalBinding.account_id == b.account_id,
                    MpiPortalBinding.patient_id == survivor_id,
                    MpiPortalBinding.status == "ACTIVE",
                )
            )).scalar_one_or_none()

            if dup:
                b.status = "MERGED"
                b.merged_to_binding_id = dup.id
            else:
                b.patient_id = survivor_id
                b.status = "ACTIVE"
                redirected += 1

            self.db.add(MpiPortalBindingLog(
                binding_id=b.id,
                account_id=b.account_id,
                patient_id=b.patient_id,
                action="MERGED",
                detail=f"患者合并：{merged_id} → {survivor_id}",
            ))

        await self.db.commit()

        return {
            "affected_bindings": len(rows),
            "redirected": redirected,
            "removed_duplicates": len(rows) - redirected,
        }

    @staticmethod
    def _to_item(b) -> dict:
        return {
            "binding_id": b.id,
            "patient_id": b.patient_id,
            "empi_no": b.empi_no,
            "patient_name": b.patient_name,
            "relation": b.relation,
            "verify_level": b.verify_level,
            "is_default": b.is_default,
            "bound_at": b.bound_at.isoformat() if b.bound_at else None,

    def _client_ip(request) -> str:
        xff = request.headers.get("x-forwarded-for")
        if xff:
            return xff.split(",")[0].strip()
        return request.client.host if request.client else "unknown"
```

```python
def send_sms_code_task(phone: str, code: str, scene: str = "LOGIN"):

async def _aggregate_stats(target_date: str = None):
    """按渠道聚合访问与绑定数据"""
    from datetime import date, datetime, timedelta
    from sqlalchemy import select, func
    from app.models.portal.account import MpiPortalAccount
    from app.models.portal.binding import MpiPortalBinding
    from app.models.portal.statistics import MpiPortalStatistics
    from app.core.database import AsyncSessionLocal

    async with AsyncSessionLocal() as db:
        d = date.fromisoformat(target_date) if target_date else \
            (date.today() - timedelta(days=1))

        day_start = datetime.combine(d, datetime.min.time())
        day_end = day_start + timedelta(days=1)

        # 按渠道聚合
        rows = (await db.execute(
            select(
                MpiPortalAccount.channel,
                func.count().label("visit_count"),
            ).where(
                MpiPortalAccount.last_login_at >= day_start,
                MpiPortalAccount.last_login_at < day_end,
            ).group_by(MpiPortalAccount.channel)
        )).all()

        saved = 0
        for channel, visit_count in rows:
            bind_count = (await db.execute(
                select(func.count()).select_from(MpiPortalBinding).where(
                    MpiPortalBinding.bound_at >= day_start,
                    MpiPortalBinding.bound_at < day_end,
                    MpiPortalBinding.status == "ACTIVE",
                )
            )).scalar_one()

            stat = MpiPortalStatistics(
                stat_date=d,
                channel=channel,
                visit_count=visit_count,
                binding_count=bind_count,
                conversion_rate=round(bind_count / visit_count * 100, 2)
                if visit_count else 0,
            )
            db.add(stat)
            saved += 1

        await db.commit()
        return {"date": d.isoformat(), "records": saved}

async def _check_kiosk():
    """检测离线自助机并告警"""
    from datetime import datetime, timedelta
    from sqlalchemy import select
    from app.models.portal.kiosk import MpiPortalKiosk
    from app.core.database import AsyncSessionLocal
    from app.clients.mpi_message_client import MpiMessageClient

    OFFLINE_THRESHOLD = timedelta(minutes=10)

    async with AsyncSessionLocal() as db:
        kiosks = (await db.execute(
            select(MpiPortalKiosk).where(
                MpiPortalKiosk.status == "ONLINE",
                MpiPortalKiosk.is_deleted == False,
            )
        )).scalars().all()

        offline = []
        for k in kiosks:
            if k.last_heartbeat_at and \
                    datetime.now() - k.last_heartbeat_at > OFFLINE_THRESHOLD:
                k.status = "OFFLINE"
                offline.append(k.device_code)

        await db.commit()

        if offline:
            client = MpiMessageClient()
            await client.send(
                biz_type="KIOSK_OFFLINE_ALERT",
                receivers=[],       # 从配置读取运维组
                params={"devices": offline, "count": len(offline)},
            )

        return {"checked": len(kiosks), "offline": offline}
```
