## 1. 模块概述

### 1.1 模块定位

M12-06 回答一个问题：**"M12 检查管理这套流程，按什么规则跑？"**

具体包括三件事：

1. **每台设备能干哪些检查项目**（设备能力矩阵）
2. **每类报告长什么样、怎么从 PDF 里把数据抽出来**（OCR 解析模板）
3. **整套流程的可调参数存在哪、谁能改、改了什么**（系统配置）


**一句话边界：** M12-06 只管"规则存在哪、怎么维护、谁改过"，不产生任何业务动作——它不排号、不执行、不采集、不解析、不审核，只是其他五个子模块背后的**配置基座**。

### 1.2 为什么独立成子模块

#### 理由一：配置的生命周期与业务数据完全不同

检查执行的记录（谁能干几分几秒）是**流水**，只增不改；而设备能力、解析模板、系统参数是**规则**，会被反复修改，且必须能回答"上个月用的是哪一版"。

把规则与流水放在一起会导致：

- 规则表被流水表的写入压力拖慢（业务高峰期排程要读设备能力，100 次/分钟）
- 修改规则需要锁大量业务记录
- 版本追溯被业务数据淹没

#### 理由二：OCR 模板是"代码级资产"，需要独立的版本管理

一份 OCT 报告的解析模板长这样：

```
title_pattern:  ^OCT\s*黄斑区扫描报告
field_rules:
  - code: CMT
    type: REGEX
    pattern: 黄斑中心凹厚度[：:]\s*(\d+(?:\.\d+)?)\s*(?:μ|u)m
  - code: CMT_UPPER
    type: REGEX
    pattern: 上方厚度[：:]\s*(\d+(?:\.\d+)?)
```

这实际上是一段**声明式代码**。它的每一次修改都可能让历史报告解析失败或解析出错。必须有：

- 版本号（V1/V2/V3）
- 生效时间（改了不等于立刻生效）
- 回归测试（用最近 100 份样本验证命中率）
- 回滚能力（出问题切回上一版）

这些要求与"检查任务"这种业务数据毫无共同点。

#### 理由三：设备能力是排程的约束来源，必须独立可靠

眼科检查项目的设备依赖很强：

| 检查项目 | 可用设备 | 单次时长 |
|---|---|---|
| OCT 黄斑 | OCT-01、OCT-02 | 8 分钟 |
| 视野 | VF-01 | 15 分钟 |
| 角膜地形图 | TOP-01 | 6 分钟 |
| 眼压 | TON-01、TON-02 | 2 分钟 |

M12-01 排程时要做三道校验：设备是否支持该项目、设备是否在维护期、设备当日是否已满。这些校验的数据源必须是**单一且可靠的**。

如果设备能力散落在 M01（设备主数据）、M12-01（排程）、M12-02（执行）三处各存一份，必然出现"排程说能做、执行说不能做"。

#### 理由四：权限边界差异极大

| 操作 | 执行者 | 技术要求 |
|---|---|---|
| 排号 | 前台 | 业务培训 |
| 执行检查 | 技师 | 操作培训 |
| 改 OCR 模板 | **IT + 检查科主任双签** | 需懂正则、懂报告格式 |
| 改系统参数 | **IT** | 需懂系统影响面 |
| 停用设备 | **设备科 + 科主任** | 需懂设备状态 |

把"改模板"和"排号"放进同一个子模块，权限模型就没法收敛——要么 IT 有了排号权限，要么前台有了改模板权限。

### 1.4 概念辨析

#### 设备 vs 检查项目

| 概念 | 定义 | 例子 | 归属 |
|---|---|---|---|
| **检查项目**（Exam Item） | 医学意义上的检查 | OCT 黄斑、视野、眼压 | **M01-09 临床主数据** |
| **设备**（Device） | 物理机器 | OCT-01、VF-01 | **M01-09 临床主数据**（基础档案）+ **M12-06**（运营状态） |
| **设备能力**（Device Capability） | 某台设备能做哪些项目 | OCT-01 能做 OCT 黄斑、OCT 视神经 | **M12-06** |

为什么设备基础档案在 M01-09 而运营状态在 M12-06：

- M01-09 存的是**全院共享的设备身份**：设备编码、型号、厂商、购置日期、资产编号。这些也会被 M15 物资、M17 财务（固定资产折旧）使用。
- M12-06 存的是**检查业务专属的状态**：当前是否在维护、今日已排多少、单次时长、检查前准备事项。这些只对 M12 有意义。

#### 模板 vs 规则

| 概念 | 定义 | 归属 |
|---|---|---|
| **OCR 解析模板** | "这份 PDF 的标题长什么样、每个字段在什么位置" | **M12-06** |
| **危急值判定规则** | "眼压超过什么值算危急" | **M01-09**（`md_exam_critical_rule`） |

区别：模板是**技术规约**（IT 维护），规则是**临床标准**（医师维护）。模板错了系统抽不出数，规则错了系统判错危急值。

#### 参数 vs 主数据

| 概念 | 定义 | 例子 | 归属 |
|---|---|---|---|
| **主数据** | 全系统共享、变化慢、有业务含义 | 检查项目、科室、员工 | M01 |
| **参数** | 单个模块的可调阈值 | 审核时限、推送重试次数 | **M12-06** |

判据：改了之后是否需要重启服务 / 是否只影响本模块 / 是否有业务人员关心。三个"否"就是参数。

#### 停用 vs 停诊

| 概念 | 定义 | 影响 | 归属 |
|---|---|---|---|
| **停用设备** | 设备生命周期结束或长期不用 | 不能再排号、不能再执行 | **M12-06** |
| **停诊** | 设备今天临时不能做检查（维护 2 小时） | 已排的号需要改约 | **M12-01**（`m12_exam_suspension`） |

M12-06 管"这台设备从此不用了"，M12-01 管"这台设备今天下午有事"。

### 1.5 模块目标

| 指标 | 目标值 | 说明 |
|---|---|---|
| 设备能力准确率 | 100% | 排程校验的唯一依据，错了就排错 |
| 模板匹配成功率 | ≥ 95% | 每个模板按最近 100 次匹配统计 |
| 模板变更回归通过率 | ≥ 98% | 新版本上线前用样本验证 |
| 配置读取延迟 | P95 ≤ 10ms | 缓存命中率 ≥ 99% |
| 配置变更生效延迟 | ≤ 60s | Redis 缓存 TTL |
| 参数误配置导致事故 | 0 | 值域校验 + 敏感项双签 |

| 角色 | 职责 | 关键权限 |

## 3. 业务模型

### 3.1 设备运营模型

#### 设备状态机

```
        ┌──────────┐
        │  ACTIVE  │◄─────────────┐
        │  在用     │              │
        └────┬─────┘              │
             │                    │
     ┌───────┼────────┐           │
     │       │        │           │
维护 │  故障 │        │ 报废      │ 修复/维护完成
     ▼       ▼        ▼           │
┌─────────┐ ┌──────┐ ┌─────────┐ │
│MAINTAIN │ │FAULT │ │ RETIRED │ │
│ maintenance│  │故障  │ │ 已报废  │ │
└────┬────┘ └──┬───┘ └─────────┘ │
     │         │                  │
     └─────────┴──────────────────┘
        （不可恢复路径：RETIRED 是终态）
```

| 状态 | 可排号 | 可执行 | 说明 |
|---|---|---|---|
| `ACTIVE` | ✅ | ✅ | 正常在用 |
| `MAINTAIN` | ❌ | ❌ | 维护中（计划内，如定期保养） |
| `FAULT` | ❌ | ❌ | 故障中（计划外，需报修） |
| `RETIRED` | ❌ | ❌ | 已报废（终态） |

**为什么 `MAINTAIN` 与 `FAULT` 要分开？**

- 维护是**计划内**的（每月第 1 个周六上午保养），可以在排程时提前避开；
- 故障是**计划外**的（突然黑屏），需要立刻通知已排号患者改约。

两者的处理方法、通知对象、统计口径都不同。合并成一个"不可用"状态，就分不清"这台设备本月该保养几次"和"这台设备今年坏了多少次"。

**为什么 `RETIRED` 不可恢复？**

报废是资产处置决定（要报财务、要销账），不是技术状态。如果允许恢复，财务台账与业务状态就会不一致。要重新启用一台已报废设备，必须走新增设备流程（新资产编号）。

### 3.2 设备能力矩阵模型

```
        ┌──────────────────────────────────────────────┐
        │          检查项目（M01-09）                   │
        │  EXAM_OCT_MACULA  EXAM_VF  EXAM_IOP  ...     │
        └────┬──────────────┬──────────┬───────────────┘
             │              │          │
        ┌────▼──────────────▼──────────▼───────────────┐
        │        m12_device_item（能力矩阵）            │
        │                                              │
        │  device_code  exam_code  duration  concurrent│
        │  ───────────  ────────  ────────  ────────── │
        │  OCT-01       OCT_MACULA   8min      1       │
        │  OCT-01       OCT_NERVE    8min      1       │
        │  VF-01        VF           15min     1       │
        │  TON-01       IOP          2min      1       │
        │  ...                                         │
        └────┬──────────────┬──────────────────────────┘
             │              │
        ┌────▼──────────────▼──────────────────────────┐
        │         设备（M12-06 运营档案）               │
        │  OCT-01  OCT-02  VF-01  TOP-01  TON-01  ...  │
        └──────────────────────────────────────────────┘
```

#### 能力矩阵的两个用途

1. **排号校验**：M12-01 排程时必须校验"这项检查能不能在这台设备上做"
2. **时长估算**：M12-01 生成号源时按 `duration_minutes` 计算每台设备每天能排多少号

#### 时长从哪来？

优先级：`m12_device_item.duration_minutes` > `md_exam_item.duration_minutes` > 系统默认 15 分钟。

**为什么设备级时长能覆盖项目级？**

因为同一项目在不同设备上耗时不同。OCT 黄斑在新款高速机上 5 分钟，在老款机上 8 分钟。项目级时长是"一般情况"，设备级时长是"这台机器的实际情况"。排程必须用后者才能把号排满且不超时。

#### 并发数

`concurrent_count` 表示这台设备同时能处理几个患者。绝大多数是 1（一台机器一次只能做一个人）。少数情况是 1：

- 眼压计：一人一台，1
- 视力表：可以隔着 1 米同时两人（但从质控角度不建议）

系统默认全部配 1，保留字段是为未来留口（比如将来有自动验光仪可加第二台）。

### 3.3 OCR 模板模型

#### 模板结构

一份模板由四部分组成：

```
① 标题匹配（title_pattern）
   ↓  用于判断"这份 PDF 是不是我这个模板管"
② 字段规则（field_rules）
   ↓  用于从文本/坐标里抽出每个字段
③ 坐标锚点（anchors，可选）
   ↓  用于表格型报告的单元格定位
④ 版本与状态（version / status）
```

#### 三种字段抽取方式

| 类型 | 适用场景 | 抽取方式 | 例子 |
|---|---|---|---|
| `REGEX` | 有固定标签的数值 | 正则捕获组 | `黄斑中心凹厚度[：:]\s*(\d+(?:\.\d+)?)` |
| `SECTION` | 长文本字段 | 起止标记切片 | `检查所见：[起]` … `[止]检查结论` |
| `COORD` | 表格型报告（视野） | 按 OCR 块坐标定位行列 | `anchor_text: "平均偏差"`, `row_offset: 0`, `col_offset: 2` |

#### 模板版本管理

```
  V1 ──► V2 ──► V3（当前）
   │      │      │
   │      │      └── is_current = TRUE, is_enabled = TRUE
   │      └───────── is_current = FALSE, is_enabled = FALSE
   └──────────────── is_current = FALSE, is_enabled = FALSE
```

**规则：** 同一台设备（或同一通用模板）同一时刻只有一版 `is_current=TRUE`。

**为什么版本要和 `is_current` 分开？**

因为"哪一版是当前版"和"哪一版能用于解析"是两个独立问题：

| 场景 | is_current | is_enabled |
|---|---|---|
| 当前生产版本 | TRUE | TRUE |
| 历史版本（已下线） | FALSE | FALSE |
| **灰度测试版本** | FALSE | TRUE |
| **已发现问题紧急下线** | TRUE | FALSE |

第三种情况最关键：新版本 V4 已经在跑回归测试，但还没确认能不能全量上，此时 V4 不 current 但 enabled（测试时指定用 V4）；V3 仍是 current。

第四种情况：V3 是 current，但发现它对某类报告有系统性问题，先 enabled=FALSE 让它停止服务，等 V4 修好。

#### 回归测试机制

```
新建/修改模板
      │
      ▼
┌──────────────────┐
│ 选择样本集        │  最近 100 份同设备报告（M12-04 已有解析结果作基准）
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ 用新模板重新解析  │  只跑模板匹配，不跑 OCR（用已存 raw_text）
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ 对比命中率        │  必需字段命中率 vs 基准值
└────────┬─────────┘
         │
    ┌────┴────┐
    │         │
   ≥98%      <98%
    │         │
    ▼         ▼
 允许启用   拒绝启用
           （列出失败样本）
```

**为什么必须回归才能启用？**

因为正则改一个字符就可能让另一个字段不匹配。真实案例：

- 原正则 `黄斑中心凹厚度[：:]\s*(\d+)`（匹配 "黄斑中心凹厚度：486"）
- 改为 `黄斑中心凹厚度\s*[：:]\s*(\d+)`（多允许空白）
- 看起来更宽松了，但如果新版本报告写成 "黄斑中心凹厚度(μm)：486"，两版都匹配不上

只有拿真实样本跑一遍才知道。上线后才发现，就意味着已经有一批报告解析失败或解析错误。

### 3.4 系统参数模型

#### 参数分组

| 分组 | 前缀 | 示例 | 消费者 |
|---|---|---|---|
| 排程 | `M12.SCHEDULE.*` | `SLOT_MINUTES`、`MAX_PER_DAY` | M12-01 |
| 执行 | `M12.EXEC.*` | `BEFORE_TOLERANCE`、`MAX_CONCURRENT` | M12-02 |
| 采集 | `M12.COLLECT.*` | `SAMPLE_INTERVAL`、`INSPECT_TIME` | M12-03 |
| 解析 | `M12.PARSE.*` | `OCR_DPI`、`CONFIDENCE_AUTO` | M12-04 |
| 审核 | `M12.REVIEW.*` | `SLA_HOURS`、`MAX_BATCH_PASS` | M12-05 |
| 危急值 | `M12.CRITICAL.*` | `ESCALATE_1_MINUTES` | M12-05 |
| 推送 | `M12.PUBLISH.*` | `MAX_RETRY` | M12-05 |

#### 参数作用域三级

```
GLOBAL（全局默认）
   │
   ├──► DEVICE（设备级覆盖）   例：VF-01 的 OCR_DPI=300，其他 200
   │
   └──► EXAM（项目级覆盖）     例：EXAM_VF 的 SLA_HOURS=8，其他 4
```

**读取优先级：** `EXAM` > `DEVICE` > `GLOBAL`。

**为什么需要设备级覆盖？**

因为不同设备的最优参数不同，前面已述：

| 设备 | OCR_DPI | 理由 |
|---|---|---|
| 眼压计 TON-01 | 150 | 纯文本报告，150 够用，300 速度减半 |
| 眼底照相 CAM-01 | 300 | 图片为主，300 才能认出小字 |
| OCT-01 | 200 | 折中 |

只有全局参数时只能取最差配置（300），所有设备的解析都会慢。

#### 敏感参数与双签

某些参数改了会造成重大影响，必须双签：

| 参数 | 影响 | 双签 |
|---|---|---|
| `M12.PARSE.CRITICAL_FIELDS` | 决定哪些字段必须人工确认 | ✅ |
| `M12.PARSE.CONFIDENCE_AUTO` | 决定多少置信度可以自动通过 | ✅ |
| `M12.CRITICAL.ESCALATE_*_MINUTES` | 危急值升级时限 | ✅ |
| `M12.REVIEW.SLA_HOURS` | 审核时限 | ✅ |
| `M12.COLLECT.ROOT_PATH` | 共享文件夹路径 | ✅ |
| 其他 | — | ❌（单签即可） |

**为什么 `M12.COLLECT.ROOT_PATH` 需要双签？**

改错了所有报告都采集不到，整个检查流程断掉。而且这个参数只有 IT 能改，单签意味着一个人就能让系统停摆。

### 3.5 设备维护模型

```
┌──────────────┐
│ 维护计划      │  每月第 1 个周六 09:00-12:00，OCT-01 定期保养
└──────┬───────┘
       │ 生成维护任务
       ▼
┌──────────────┐
│ 维护任务      │  设备状态置 MAINTAIN，M12-01 自动避开该时段
└──────┬───────┘
       │ 完成
       ▼
┌──────────────┐
│ 维护记录      │  保养人、内容、耗材、下次日期
└──────────────┘
```

**核心联动：** 设备进入 `MAINTAIN` 时，M12-06 发事件 `m12.device.status_changed`，M12-01 收到后：

- 未来时段：不生成号源
- 已排号：生成改约待办

如果 M12-01 未响应（消息丢失），M12-06 有兜底：M12-01 每次排号前实时校验设备状态。

**为什么排队号前缀要按科室唯一？**

因为叫号屏滚动显示的是前台/病区**全科室**的队列。如果 OCT-01 和 VF-01 都用 `A`，患者看到 "A003" 不知道去哪个诊室。用不同前缀（OCT 用 A/B，视野用 C，眼压用 D），患者一眼能看出来。

**为什么报废必须 ≥20 字原因？**

设备报废是资产处置决定，要报财务销账。20 字的原因能落进资产台账（"镜头划伤严重，维修成本超残值"），3 个字（"坏了"）则毫无信息量。

**为什么"取消能力"要检查在途任务？**

因为取消后，已排在这台设备上的号就"排到了一台做不了的设备上"。M12-01 排号时校验通过，现在校验会失败，任务变成脏数据。

正确做法是先改约这些任务，再取消能力。

**为什么"仅显示差异"是有用的？**

典型场景：新进一台 OCT-03，要配齐所有 OCT 项目。如果矩阵有 24 行 × 12 列 = 288 个单元格，全部看一遍很累。勾选"仅显示差异"后，只显示"与项目默认时长不同的单元格"，一眼能看出哪台设备配错了。

因为模板修改后，历史失败不再代表当前质量。用最近 100 次（约一周的量）能反映"当前版本好不好"。

**回归通过判据（V-29 的具体化）：**

```
通过 = (整体命中率 ≥ 98%)
   AND (每个必填字段命中率 ≥ 90%)
   AND (无字段命中率相对基准下降 > 2%)
```

**为什么回归要求"无字段下降 >2%"而不只是"整体达标"？**

假设模板有 8 个字段，原版本整体 98%。新版本 CMT 从 99% 降到 88%（-11%），但 FINDINGS 从 92% 升到 99%（+7%），整体还是 98%。

整体达标了，但**CMT 是核心测量值**，下降 11% 意味着每 10 份报告有 1 份测不出黄斑厚度——这是不可接受的。

所以必须有"单字段不下降"的约束。

**为什么"保存并启用"必须先过回归？**

这是硬性质量闸门。允许直接启用的话，模板改错就会立刻影响生产：后续所有报告都用错误模板解析，可能几十份报告解析失败或解析出错误数值。

代价是每次改模板要多等 15 秒。这个代价远小于一批报告解析错误。

**为什么只读参数要标出来？**

因为有些参数与硬编码/DB 约束联动，改了会冲突。例如：

- `M12.PARSE.MAX_RETRY=3` 与 `ck_m12_parse_retry CHECK (retry_count <= 3)` 联动。若允许改成 5，第 4 次重试会触发 DB 约束异常。
- `M12.COLLECT.MAX_SIZE_MB=200` 若改成 2000，可能压垮磁盘。

标出"只读"并在 DB 层加 `is_editable=FALSE`，前端置灰，后端拒绝，双保险。

**为什么变更预览要显示"预估影响"？**

因为参数改动的影响往往不直观。`CONFIDENCE_AUTO 0.95 → 0.90` 听起来是"更宽松了"，但实际效果是**更多字段需要人工确认**（原来 0.90 的字段自动通过，现在要标黄）。

不显示影响的后果：管理员以为在优化，实际让审核工作量增加 50%，第二天被医师投诉。

### 6.2 错误码规范

| 错误码 | 说明 | 触发场景 |
|---|---|---|
| `"1206001"` | 设备在 M01-09 不存在 | 新增/更新设备时编码查不到 |
| `"1206002"` | 排队号前缀在同科室重复 | 保存设备运营配置 |
| `"1206003"` | 参数值超出允许范围 | 时长/并发数/每日上限越界 |
| `"1206004"` | 故障描述不足 20 字 | 设备转 FAULT |
| `"1206005"` | 报废原因不足 20 字 | 设备转 RETIRED |
| `"1206006"` | 设备状态不允许此操作 | 已报废设备再改状态 |
| `"1206007"` | 该能力存在在途检查任务 | 取消设备能力 |
| `"1206008"` | 模板编码格式错误或已存在 | 新建模板 |
| `"1206009"` | 标题正则无效或执行超时 | 保存模板 |
| `"1206010"` | 字段编码在模板内重复 | 保存模板 |
| `"1206011"` | 字段数量不合法（需 ≥1 且 ≤100，至少 1 个必填） | 保存模板 |
| `"1206012"` | 字段规则配置不完整 | REGEX 缺正则/SECTION 缺标记/COORD 缺锚点 |
| `"1206013"` | 模板未通过回归测试 | 启用模板 |
| `"1206014"` | 同一设备已有当前版本 | 启用模板 |
| `"1206015"` | 通用模板不可停用或删除 | 停用 GENERIC_V1 |
| `"1206016"` | 参数值类型或格式错误 | 保存参数 |
| `"1206017"` | 敏感参数必须双签审批 | 直接保存敏感参数 |
| `"1206018"` | 该参数为只读参数 | 修改只读参数 |
| `"1206019"` | 设备级/项目级参数必须指定作用域 | 保存参数 |
| `"1206020"` | 不能审批自己发起的变更 | 审批 |
| `"1206021"` | 变更单状态不允许此操作 | 重复审批 |
| `"1206022"` | 驳回必须填写原因（≥10 字） | 驳回 |
| `"1206023"` | 配置读取失败（缓存与数据库均不可用） | 内部契约 |
| `"1206024"` | 样本数量不足 | 回归测试 |
| `"1206025"` | 上传文件不是有效 PDF 或超过 20MB | 测试 PDF |
| `"1206026"` | 模板版本号已达上限（V99） | 另存新版本 |
| `"1206027"` | 回滚目标版本不存在或已停用 | 回滚 |
| `"1206028"` | 设备仍有未完成的检查任务（转 RETIRED） | 报废设备 |
| `"1206029"` | 参数变更影响面校验未通过 | 保存参数 |
| `"1206030"` | 审批已超时自动驳回 | 审批 |

```python
def safe_search(pattern: str, text_src: str) -> Optional[re.Match]:
    """带超时保护的正则匹配。

    防止恶意或低效正则导致 ReDoS。
    """
    if len(pattern) > MAX_PATTERN_LEN:
        raise BizException("1206009", "正则表达式过长（上限 500 字符）")
    if len(text_src) > 200000:
        text_src = text_src[:200000]
    try:
        compiled = re.compile(pattern)
    except re.error as exc:
        raise BizException(
            "1206009", "正则表达式无效：%s" % str(exc))
    start = time.monotonic()
    try:
        result = compiled.search(text_src)
    except Exception:
        raise BizException("1206009", "正则执行异常")
    cost = time.monotonic() - start
    if cost > REGEX_TIMEOUT_SECONDS:
        raise BizException(
            "1206009",
            "正则执行超时 %.1f 秒，请简化表达式" % cost)
    return result

                        "device_code": dev["device_code"],

                    })
            rows.append({
                "exam_code": item["exam_code"],
                "exam_name": item["exam_name"],
                "default_duration": item["duration_minutes"],
                "cells": cells,
            })

        return {

            "devices": [dict(r._mapping) for r in dev_rows],
            "rows": rows,
            "warnings": cls._matrix_warnings(rows, dev_rows),

                            })
                            continue
                        cur.is_deleted = True
                        removed += 1
                    continue

                # ④ 参数校验
                dur = ch.duration_minutes or 15
                if dur < 1 or dur > 120:
                    raise BizException(
                        "1206003", "单次时长必须在 1~120 分钟")
                conc = ch.concurrent_count or 1
                if conc < 1 or conc > 5:
                    raise BizException(
                        "1206003", "同时检查数必须在 1~5")

                if cur is None:
                    db.add(M12DeviceItem(
                        device_code=dev_code,
                        exam_code=exam_code,
                        duration_minutes=dur,
                        concurrent_count=conc,
                        created_by=user.employee_id,
                    ))
                    added += 1
                else:
                    cur.duration_minutes = dur
                    cur.concurrent_count = conc
                    updated += 1

            await db.commit()

        if blocked:
            raise BizException(
                "1206007",
                "以下能力存在在途检查任务，请先改约",
                data={"blocked": blocked})

        # ⑤ 更新后重新校验无设备项目
        warnings.extend(cls._matrix_warnings(
            await cls._reload_matrix_rows(user), []))

        AuditClient.log(
            module="M12-06",
            action="CAPABILITY_UPDATE",
            user=user,
            detail={"added": added, "updated": updated,
                    "removed": removed},
        )

        return {
            "added": added,
            "updated": updated,
            "removed": removed,
            "warnings": warnings,
            "removed_blocked": blocked,
            "message": "能力矩阵已更新",
        }

    @classmethod
    async def list_templates(cls, user, device_code=None,
                             status=None, keyword=None,
                             only_alert=False, page=1, page_size=50):
        """模板列表。"""
        conds = ["is_deleted = FALSE"]
        params: Dict[str, Any] = {}
        if device_code:
            conds.append("(device_code = :dc OR device_code IS NULL)")
            params["dc"] = device_code
        if status:
            conds.append("status = :st")
            params["st"] = status
        if keyword:
            conds.append(
                "(template_code ILIKE :kw OR template_name ILIKE :kw)")
            params["kw"] = "%" + keyword + "%"
        where = " AND ".join(conds)

        offset = (page - 1) * page_size
        async with get_session() as db:
            total = await db.scalar(
                text("SELECT COUNT(*) FROM m12_parse_template WHERE "
                     + where).bindparams(**params))
            rows = (await db.execute(
                text(
                    "SELECT id, template_code, template_name, "
                    "       device_code, title_pattern, version_no, "
                    "       status, is_current, is_enabled, priority, "
                    "       match_total, match_success "
                    "  FROM m12_parse_template "
                    " WHERE " + where + " "
                    " ORDER BY is_current DESC, priority, template_code "
                    " LIMIT :lim OFFSET :off").bindparams(
                        lim=page_size, off=offset, **params)
            )).mappings().all()

        items = []
        for r in rows:
            total_m = r["match_total"] or 0
            succ = r["match_success"] or 0
            rate = round(succ / total_m, 4) if total_m else None
            if only_alert and (rate is None or rate >= 0.95):
                continue
            items.append({
                "template_id": r["id"],
                "template_code": r["template_code"],
                "template_name": r["template_name"],
                "device_code": r["device_code"],
                "title_pattern": r["title_pattern"],
                "version_no": r["version_no"],
                "status": r["status"],
                "is_current": r["is_current"],
                "is_enabled": r["is_enabled"],
                "priority": r["priority"],
                "match_total": total_m,
                "match_success": succ,
                "match_rate": rate,
                "need_alert": (rate is not None and rate < 0.95),
            })
        return {"items": items, "total": int(total or 0)}

    @classmethod
    def _validate_template_payload(cls, payload):
        """模板校验。"""
        # ① 编码
        if not re.match(r"^[A-Z][A-Z0-9_]{2,63}$", payload.template_code):
            raise BizException(
                "1206008", "模板编码格式错误（大写字母开头，3~64 位）")
        # ② 标题正则
        safe_search(payload.title_pattern, "OCT 黄斑区扫描报告")
        # ③ 字段数量
        if len(payload.field_rules) < MIN_FIELD_COUNT:
            raise BizException("1206011", "至少需要 1 个字段")
        if len(payload.field_rules) > MAX_FIELD_COUNT:
            raise BizException("1206011", "字段数量不能超过 100 个")
        required = [f for f in payload.field_rules if f.required]
        if not required:
            raise BizException("1206011", "至少需要 1 个必填字段")
        # ④ 字段编码唯一
        codes = [f.field_code for f in payload.field_rules]
        if len(codes) != len(set(codes)):
            raise BizException("1206010", "字段编码在模板内不能重复")
        # ⑤ 字段规则完整性
        for f in payload.field_rules:
            if not re.match(r"^[A-Z][A-Z0-9_]{0,63}$", f.field_code):
                raise BizException(
                    "1206010", "字段编码 %s 格式错误" % f.field_code)
            if f.field_type not in FIELD_TYPES:
                raise BizException(
                    "1206012", "字段 %s 类型无效" % f.field_code)
            if f.field_type == "REGEX":
                if not f.pattern:
                    raise BizException(
                        "1206012", "字段 %s 缺正则" % f.field_code)
                if f.group_index is None or f.group_index < 1:
                    raise BizException(
                        "1206012", "字段 %s 缺捕获组" % f.field_code)
                compiled = safe_search(f.pattern, "测试文本")
                _ = compiled
            elif f.field_type == "SECTION":
                if not f.start_marker or not f.end_marker:
                    raise BizException(
                        "1206012", "字段 %s 缺起止标记" % f.field_code)
            elif f.field_type == "COORD":
                if not f.anchor_text:
                    raise BizException(
                        "1206012", "字段 %s 缺锚点文本" % f.field_code)
            if (f.ref_min is not None and f.ref_max is not None
                    and float(f.ref_min) > float(f.ref_max)):
                raise BizException(
                    "1206012",
                    "字段 %s 参考区间下限大于上限" % f.field_code)

    @classmethod
    async def test_regex(cls, user, payload):
        """测试正则。"""
        start = time.monotonic()
        matched = safe_search(payload.pattern, payload.text)
        cost_ms = int((time.monotonic() - start) * 1000)
        groups = []
        if matched:
            groups = list(matched.groups())
        return {
            "matched": matched is not None,
            "matched_text": matched.group(0) if matched else None,
            "groups": groups,
            "elapsed_ms": cost_ms,
        }

    @classmethod
    async def test_template(cls, user, template_id, payload):
        """用样本测试模板。"""
        async with get_session() as db:
            tpl = await db.get(M12Template, template_id)
            if tpl is None or tpl.is_deleted:
                raise BizException("1206008", "模板不存在")

            # 取样本：最近 N 份已解析报告
            sample_limit = payload.sample_count or 20
            if sample_limit < 10:
                raise BizException("1206024", "样本数量不足（至少 10 份）")
            rows = (await db.execute(text(
                "SELECT id, raw_text, template_code, "
                "       parse_status, extracted_fields "
                "  FROM m12_parse_record "
                " WHERE device_code = :dc "
                "   AND parse_status IN ('PARSED','PARSE_FAILED') "
                "   AND raw_text IS NOT NULL "
                "   AND is_deleted = FALSE "
                " ORDER BY created_at DESC LIMIT :lim"),
                {"dc": tpl.device_code or "", "lim": sample_limit})).all()

        matched = 0
        failures = []
        field_hit: Dict[str, int] = {}
        for f in (tpl.field_rules or []):
            field_hit[f["field_code"]] = 0

        for r in rows:
            raw = r["raw_text"] or ""
            # ① 标题匹配
            hit = safe_search(tpl.title_pattern, raw[:2000])
            if hit is None:
                failures.append({
                    "parse_id": r["id"],
                    "reason": "TITLE_MISMATCH",
                    "detected_title": (raw[:80].strip()
                                       if raw else ""),
                })
                continue
            matched += 1
            # ② 字段抽取
            for f in (tpl.field_rules or []):
                val = cls._extract_field(f, raw)
                if val is not None:
                    field_hit[f["field_code"]] += 1

        total = len(rows) or 1
        fields = []
        passed = True
        for f in (tpl.field_rules or []):
            hit_cnt = field_hit[f["field_code"]]
            rate = round(hit_cnt / total, 4)
            is_passed = (not f.get("required")) or rate >= \
                REGRESSION_MIN_FIELD_RATE
            if not is_passed:
                passed = False
            fields.append({
                "field_code": f["field_code"],
                "field_name": f.get("field_name"),
                "required": bool(f.get("required")),
                "hit": hit_cnt,
                "hit_rate": rate,
                "passed": is_passed,
            })

        match_rate = round(matched / total, 4)
        if match_rate < REGRESSION_MIN_RATE:
            passed = False

        return {
            "template_id": template_id,
            "template_code": tpl.template_code,
            "sample_count": total,
            "matched": matched,
            "match_rate": match_rate,
            "fields": fields,
            "failures": failures[:20],
            "passed": passed,
            "threshold": REGRESSION_MIN_RATE,
        }

    @classmethod
    def _extract_field(cls, rule, raw_text):
        """按规则抽取单个字段。"""
        ftype = rule.get("field_type")
        try:
            if ftype == "REGEX":
                m = safe_search(rule.get("pattern") or "", raw_text)
                if m is None:
                    return None
                gi = rule.get("group_index") or 1
                if gi > len(m.groups()):
                    return None
                return m.group(gi)
            if ftype == "SECTION":
                start = rule.get("start_marker") or ""
                end = rule.get("end_marker") or ""
                i = raw_text.find(start)
                if i < 0:
                    return None
                i += len(start)
                j = raw_text.find(end, i)
                if j < 0:
                    return None
                return raw_text[i:j].strip()
        except BizException:
            return None
        return None

    @classmethod
    async def regression(cls, user, template_id, payload):
        """全量回归（100 份样本）。"""
        sample_count = payload.sample_count or 100
        result = await cls.test_template(
            user, template_id,
            type("P", (), {"sample_count": sample_count})())

        # 与基准对比
        async with get_session() as db:
            tpl = await db.get(M12Template, template_id)
            baseline_rate = float(tpl.baseline_rate or 0)

        failed_fields = []
        for f in result["fields"]:
            if not f["passed"]:
                failed_fields.append(f["field_code"])

        overall_passed = (
            result["match_rate"] >= REGRESSION_MIN_RATE
            and not failed_fields)

        return {
            "template_id": template_id,
            "sample_count": result["sample_count"],
            "matched": result["matched"],
            "match_rate": result["match_rate"],
            "baseline_rate": baseline_rate,
            "fields": result["fields"],
            "failed_fields": failed_fields,
            "overall_passed": overall_passed,
            "criteria": {
                "min_match_rate": REGRESSION_MIN_RATE,
                "min_field_rate": REGRESSION_MIN_FIELD_RATE,
                "max_field_drop": REGRESSION_MAX_FIELD_DROP,
            },
            "conclusion": ("回归通过，可启用" if overall_passed
                           else "回归未通过，请检查字段规则"),
        }

    @classmethod
    async def enable_template(cls, user, template_id, payload):
        """启用模板（必须回归通过）。"""
        # ① 回归印记校验
        if not payload.regression_passed:
            raise BizException(
                "1206013", "模板未通过回归测试，不能启用")

        async with get_session() as db:
            tpl = await db.get(M12Template, template_id)
            if tpl is None or tpl.is_deleted:
                raise BizException("1206008", "模板不存在")

            # ② 通用模板保护
            if tpl.template_code == "GENERIC_V1" and tpl.is_system:
                tpl.is_enabled = True
                await db.commit()
                return {"template_id": template_id,
                        "message": "通用模板已启用"}

            # ③ 同设备已有 current 版本时，需先停用
            if payload.set_current:
                if tpl.device_code:
                    others = (await db.execute(
                        select(M12Template).where(
                            M12Template.device_code == tpl.device_code,
                            M12Template.is_current.is_(True),
                            M12Template.id != template_id,
                            M12Template.is_deleted.is_(False))
                    )).scalars().all()
                    for o in others:
                        o.is_current = False
                        o.status = TPL_DISABLED
                else:
                    others = (await db.execute(
                        select(M12Template).where(
                            M12Template.device_code.is_(None),
                            M12Template.is_current.is_(True),
                            M12Template.id != template_id,
                            M12Template.is_deleted.is_(False))
                    )).scalars().all()
                    for o in others:
                        o.is_current = False
                        o.status = TPL_DISABLED
                tpl.is_current = True

            tpl.is_enabled = True
            tpl.status = TPL_ENABLED
            tpl.enabled_at = datetime.now()
            tpl.enabled_by = user.employee_id
            await db.commit()

        # ④ 清缓存
        await redis_client.delete("m12:template:list")
        await redis_client.delete(
            "m12:template:%d" % template_id)

        AuditClient.log(
            module="M12-06",
            action="TEMPLATE_ENABLE",
            user=user,
            detail={"template_id": template_id,
                    "template_code": tpl.template_code,
                    "set_current": payload.set_current},
        )
        return {
            "template_id": template_id,
            "message": "模板已启用",
        }

    @classmethod
    async def match(cls, device_code, title):
        """内部契约：按设备与标题匹配模板。"""
        cache_key = "m12:template:match:%s:%s" % (
            device_code or "_", hashlib.md5(title.encode()).hexdigest())
        cached = await redis_client.get(cache_key)
        if cached:
            import json as jsonmod
            return jsonmod.loads(cached)

        async with get_session() as db:
            # ① 设备专属模板（优先级高的在前）
            rows = []
            if device_code:
                rows = (await db.execute(
                    select(M12Template).where(
                        M12Template.device_code == device_code,
                        M12Template.is_enabled.is_(True),
                        M12Template.is_deleted.is_(False))
                    .order_by(M12Template.priority)
                )).scalars().all()

            result = None
            for tpl in rows:
                hit = safe_search(tpl.title_pattern, title)
                if hit is not None:
                    result = {
                        "matched": True,
                        "template_id": tpl.id,
                        "template_code": tpl.template_code,
                        "template_version": "V%d" % tpl.version_no,
                        "title_pattern": tpl.title_pattern,
                        "priority": tpl.priority,
                        "is_generic": False,
                        "device_matched": True,
                    }
                    break

            # ② 通用模板兜底
            if result is None:
                generic = (await db.execute(
                    select(M12Template).where(
                        M12Template.device_code.is_(None),
                        M12Template.is_enabled.is_(True),
                        M12Template.is_deleted.is_(False))
                    .order_by(M12Template.priority)
                )).scalars().first()
                if generic is not None:
                    result = {
                        "matched": True,
                        "template_id": generic.id,
                        "template_code": generic.template_code,
                        "template_version": "V%d" % generic.version_no,
                        "title_pattern": generic.title_pattern,
                        "priority": generic.priority,
                        "is_generic": True,
                        "device_matched": False,
                    }
                else:
                    result = {"matched": False}

        await redis_client.setex(
            cache_key, 1800,
            __import__("json").dumps(result, ensure_ascii=False))
        return result

    @classmethod
    async def on_matched(cls, template_id, payload):
        """回写匹配统计。"""
        async with get_session() as db:
            await db.execute(
                update(M12Template)
                .where(M12Template.id == template_id)
                .values(
                    match_total=M12Template.match_total + 1,
                    match_success=(M12Template.match_success
                                   + (1 if payload.success else 0)),
                    last_matched_at=datetime.now(),
                ))
            await db.commit()
        return {"template_id": template_id, "updated": True}

        pending = 0
        change_ids = []
        items = []

        async with get_session() as db:
            for item in payload.items:
                code = item.param_code
                # ① 只读校验
                if code in READONLY_PARAMS:
                    raise BizException(
                        "1206018",
                        "参数 %s 为只读参数，不能修改" % code)

                # ② 类型与范围校验
                await cls._validate_value(db, code, item.param_value)

                # ③ 敏感参数走审批

                    ch = M12ChangeLog(
                        change_type="CONFIG",
                        target_code=code,
                        scope=item.scope or "GLOBAL",

                        status="PENDING",
                        applicant_id=user.employee_id,
                        applicant_name=user.employee_name,

                    db.add(ch)
                    await db.flush()
                    change_ids.append(ch.id)
                    pending += 1
                    items.append({
                        "param_code": code,
                        "applied": False,
                        "message": "敏感参数，已提交双签审批"
                                   "（变更单 %d）" % ch.id,
                    })
                    continue

                # ④ 直接生效
                row = await db.scalar(
                    select(M12DeviceConfig).where(
                        M12DeviceConfig.param_code == code,
                        M12DeviceConfig.scope == (
                            item.scope or "GLOBAL"),
                        M12DeviceConfig.scope_id == item.scope_id,
                        M12DeviceConfig.is_deleted.is_(False)))
                if row is None:
                    db.add(M12DeviceConfig(
                        param_code=code,
                        param_value=item.param_value,
                        param_type=cls._infer_type(item.param_value),
                        scope=item.scope or "GLOBAL",
                        scope_id=item.scope_id,
                        created_by=user.employee_id,
                    ))
                else:
                    row.old_value_tmp = row.param_value
                    row.param_value = item.param_value
                    row.version = (row.version or 1) + 1
                    row.updated_by = user.employee_id

                db.add(M12ChangeLog(
                    change_type="CONFIG",
                    target_code=code,
                    scope=item.scope or "GLOBAL",
                    scope_id=item.scope_id,
                    old_value="",
                    new_value=item.param_value,
                    status="EFFECTIVE",
                    applicant_id=user.employee_id,
                    applicant_name=user.employee_name,
                ))
                saved += 1
                items.append({
                    "param_code": code,
                    "applied": True,
                    "message": "已生效",
                })

            await db.commit()

        # ⑤ 清缓存
        await cls._clear_cache()

        AuditClient.log(
            module="M12-06",
            action="CONFIG_SAVE",
            user=user,
            detail={"saved": saved, "pending": pending},
        )
        return {
            "saved": saved,
            "pending_approval": pending,
            "change_ids": change_ids,
            "items": items,
        }

    @classmethod
    def _infer_type(cls, value):
        """推断参数类型。"""
        v = str(value)
        if re.match(r"^-?\d+$", v):
            return "INT"
        if re.match(r"^-?\d+\.\d+$", v):
            return "FLOAT"
        if v in ("true", "false"):
            return "BOOL"
        return "STRING"

    @classmethod
    async def _validate_value(cls, db, code, value):
        """校验参数值。"""
        async with get_session() as db2:
            meta = await db2.scalar(
                select(M12DeviceConfig).where(
                    M12DeviceConfig.param_code == code,
                    M12DeviceConfig.is_deleted.is_(False)))
        if meta is None:
            # 首次写入，只做基本类型推断
            cls._infer_type(value)
            return
        ptype = meta.param_type
        v = str(value)
        try:
            if ptype == "INT":
                iv = int(v)
                if meta.min_value is not None and iv < int(meta.min_value):
                    raise BizException(
                        "1206016",
                        "参数 %s 不得小于 %s" % (code, meta.min_value))
                if meta.max_value is not None and iv > int(meta.max_value):
                    raise BizException(
                        "1206016",
                        "参数 %s 不得大于 %s" % (code, meta.max_value))
            elif ptype == "FLOAT":
                fv = float(v)
                if (meta.min_value is not None
                        and fv < float(meta.min_value)):
                    raise BizException(
                        "1206016",
                        "参数 %s 不得小于 %s" % (code, meta.min_value))
                if (meta.max_value is not None
                        and fv > float(meta.max_value)):
                    raise BizException(
                        "1206016",
                        "参数 %s 不得大于 %s" % (code, meta.max_value))
            elif ptype == "BOOL":
                if v not in ("true", "false"):
                    raise BizException(
                        "1206016", "参数 %s 必须为 true/false" % code)
        except ValueError:
            raise BizException(
                "1206016", "参数 %s 类型不匹配（要求 %s）" % (code, ptype))

        # 交叉约束：置信度阈值必须有序
        if code == "M12.PARSE.CONFIDENCE_AUTO":
            warn = await cls.get_one_optional(
                "M12.PARSE.CONFIDENCE_WARN")
            if warn is not None and float(v) <= float(warn):
                raise BizException(
                    "1206016",
                    "CONFIDENCE_AUTO 必须大于 CONFIDENCE_WARN")

    @classmethod
    async def get_one_optional(cls, param_code):
        """读取参数（不存在返回 None）。"""
        try:
            data = await cls.get_one(param_code)
            return data["param_value"]
        except BizException:
            return None

    @classmethod
    async def approve(cls, user, change_id, payload):
        """审批通过。"""
        async with get_session() as db:
            row = await db.get(M12ChangeLog, change_id)
            if row is None or row.is_deleted:
                raise BizException("1206021", "变更单不存在")
            # ① 职责分离
            if row.applicant_id == user.employee_id:
                raise BizException("1206020", "不能审批自己发起的变更")
            # ② 状态
            if row.status != "PENDING":
                raise BizException(
                    "1206021", "变更单状态不是待审批")
            # ③ 超时
            if row.expire_at and datetime.now() > row.expire_at:
                row.status = "EXPIRED"
                await db.commit()
                raise BizException("1206030", "审批已超时，已自动驳回")

            # ④ 应用变更
            cfg = await db.scalar(
                select(M12DeviceConfig).where(
                    M12DeviceConfig.param_code == row.target_code,
                    M12DeviceConfig.scope == row.scope,
                    M12DeviceConfig.scope_id == row.scope_id,
                    M12DeviceConfig.is_deleted.is_(False)))
            if cfg is not None:
                row.old_value = cfg.param_value
                cfg.param_value = row.new_value
                cfg.version = (cfg.version or 1) + 1
                cfg.updated_by = user.employee_id

            row.status = "EFFECTIVE"
            row.approver_id = user.employee_id
            row.approver_name = user.employee_name
            row.approved_at = datetime.now()
            row.approve_comment = payload.comment
            await db.commit()

        await ConfigService._clear_cache()

        AuditClient.log(
            module="M12-06",
            action="CHANGE_APPROVE",
            user=user,
            detail={"change_id": change_id,
                    "target": row.target_code,
                    "new_value": row.new_value},
        )
        return {
            "change_id": change_id,
            "status": "EFFECTIVE",
            "message": "变更已生效",
        }

    @classmethod
    async def reject(cls, user, change_id, payload):
        """审批驳回。"""
        reason = (payload.reason or "").strip()
        if len(reason) < 10:
            raise BizException("1206022", "驳回原因不少于 10 字")

        async with get_session() as db:

            if row is None or row.is_deleted:

            if row.applicant_id == user.employee_id:
                raise BizException("1206020", "不能审批自己发起的变更")
            if row.status != "PENDING":
                raise BizException("1206021", "变更单状态不是待审批")

            row.status = "REJECTED"
            row.approver_id = user.employee_id
            row.approver_name = user.employee_name
            row.approved_at = datetime.now()
            row.reject_reason = reason
            await db.commit()

        return {
            "change_id": change_id,
            "status": "REJECTED",
            "message": "变更已驳回",
        }
```

### 6.7 配置读取与缓存一致性

M12-01~05 每次操作都会读参数与设备能力，QPS 峰值约 **50 次/秒**。若每次都查库，会拖垮 PostgreSQL。

**三层缓存策略：**

```
第 1 层：进程内 LRU（TTL 10s，容量 500）
   ↓ 未命中
第 2 层：Redis（TTL 600s）
   ↓ 未命中
第 3 层：PostgreSQL
```

**变更后的一致性保障：**

1. 写入方（M12-06）在 `save_config` / `approve` 后主动 `DELETE m12:cfg:*`
2. 发布事件 `m12.config.changed`，各子模块收到后清自己的进程内缓存
3. 兜底：即使事件丢失，Redis TTL 600s 后也会自动失效

**为什么进程内缓存 TTL 只有 10 秒而 Redis 是 600 秒？**

进程内缓存无法被其他进程删除（Python 进程间无共享内存）。只能靠短 TTL 自然过期。10 秒是"参数变更后最多 10 秒内所有实例都生效"的可接受延迟。

Redis 是共享的，可以被主动删除，所以 TTL 可以长。

**为什么 IT 管理员没有 approve 权限？**

因为审批的意义是"业务侧确认这个技术变更是否可以承担"。IT 自己提交、自己审批，等于没有审批。

**为什么系统管理员没有业务权限？**

最小权限原则。系统管理员管的是数据库、服务器、部署，不需要也不应该能改设备状态或 OCR 模板。

### 9.3 数据权限

| 数据 | 范围 | 说明 |
|---|---|---|
| 设备 | `dept_id` 在用户数据权限内 | 分院设备互不可见 |
| 能力矩阵 | 同设备 | — |
| 模板 | `device_code` 属于权限内设备，或 `device_code IS NULL`（通用） | — |
| 参数 | `GLOBAL` 全员可读；`DEVICE`/`EXAM` 按设备/项目权限 | — |
| 变更历史 | 同数据权限 | — |

**脱敏：** 设备负责人手机号脱敏显示（`138****5678`）。

### 9.4 安全措施

| 措施 | 说明 |
|---|---|
| 双签机制 | 敏感参数与模板变更需两人确认 |
| 职责分离 | 申请人 ≠ 审批人（DB 约束 + 服务层双校验） |
| 正则 ReDoS 防护 | 长度限制 500 + 执行超时 2 秒 + 文本截断 20 万字符 |
| 模板编辑器 XSS 防护 | 所有字段值做 HTML 转义 |
| 路径遍历防护 | `ROOT_PATH` 变更需双签 + 校验新路径存在 |
| 全量审计 | 所有写操作调 M02-06 审计 |
| 二次确认 | 报废、清空能力列、恢复默认需二次确认 |
| 会话超时 | 模板编辑器 30 分钟无操作自动锁定 |

**为什么模板编辑器要做 XSS 防护？**

因为模板里存的是正则与字段名，这些内容会在 M12-04 的页面上展示（"当前使用模板 OCT_MACULA_V3"）。如果模板名写成 `<script>...</script>`，而前端渲染时未转义，就会造成 XSS。

虽然只有 IT 能建模板，但"可信人员输入"不等于"安全输入"——误操作或账号被盗都可能。

## 11. 异常处理与日志

### 11.1 异常分类

| 类别 | 场景 | 处理 |
|---|---|---|
| **参数错误** | 值域越界、格式错误 | 返回 `"1206003"`/`"1206016"`，不写库 |
| **状态冲突** | 状态机不允许、重复审批 | 返回 `"1206006"`/`"1206021"` |
| **业务约束** | 有在途任务、有未完成任务 | 返回 `"1206007"`/`"1206028"`，附上明细 |
| **依赖失败** | M01-09 不可用 | 降级用本地快照；审批阻断 |
| **系统错误** | DB 异常、Redis 异常 | 50000，记录完整堆栈 |
| **正则异常** | 编译失败、执行超时 | 返回 `"1206009"`，附错误详情 |
