## 4. 数据结构设计

### 4.1 ER 关系图

```
                    ┌──────────────────────────────────┐
                    │ sys_account（M02-01）             │
                    │  phone / phone_backup /           │
                    │  mfa_totp_secret / mfa_totp_enabled│
                    └──────────┬───────────────────────┘
                               │ 1:N
        ┌──────────────────────┼──────────────────────┬──────────────────────┐
        │                      │                      │                      │
        ▼                      ▼                      ▼                      ▼
┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐
│sys_mfa_credential│  │sys_mfa_recovery_ │  │sys_mfa_record    │  │sys_mfa_ticket    │
│（手势密码）        │  │code（恢复码）     │  │（验证记录）       │  │（重置工单）       │
└──────────────────┘  └──────────────────┘  └──────────────────┘  └──────────────────┘

┌──────────────────────────────┐  1:N  ┌──────────────────────────────────┐
│ sys_mfa_policy               │◄──────│ sys_mfa_operation_policy         │
│ （全局策略，单行）             │       │ （操作级策略）                    │
└──────────────────────────────┘       └──────────────────────────────────┘

┌──────────────────────────────┐
│ sys_mfa_challenge            │  （验证挑战，短期数据）
└──────────────────────────────┘

运行时缓存（Redis，非表）：
  sys:mfa:verified:{sid}        会话已验证状态 15min
  sys:mfa:sms:{challenge_id}    短信验证码哈希 5min
  sys:mfa:fail:{account_id}     失败计数
  sys:mfa:lock:account:{id}     账号 MFA 锁定
  sys:mfa:totp:{acc}:{code}     TOTP 防重放
```

**设计说明：**

- `sys_mfa_policy` 为**单行配置**，全局策略
- `sys_mfa_operation_policy` 按操作配置验证方式
- `sys_mfa_challenge` 为**短生命周期**数据，5 分钟，定时清理
- `sys_mfa_credential` 存手势密码（哈希）
- `sys_mfa_recovery_code` 存恢复码（哈希，一次性）
- `sys_mfa_record` 为**审计数据**，保留 1 年
- TOTP 密钥存在 `sys_account`（M02-01），**不重复定义**

**工单流程：**

```
用户提交（PENDING）
   ↓
信息科电话核实（VERIFYING）
   ↓
   ├─ 核实通过 → 管理员重置（APPROVED → COMPLETED）
   └─ 核实失败 → 拒绝（REJECTED）
```

### 4.9 SQLAlchemy 2.0 模型定义

```python
# app/models/mfa/verify.py
"""二次验证 ORM 模型"""
from datetime import datetime
from typing import Optional, List

from sqlalchemy import (
    BigInteger, String, Integer, Boolean, DateTime, JSONB,
    Index, UniqueConstraint, func, Text,
)
from sqlalchemy.orm import Mapped, mapped_column, relationship

from app.models.base import Base


class SysMfaPolicy(Base):
    """MFA 全局策略（单行）"""
    __tablename__ = "sys_mfa_policy"

    id: Mapped[int] = mapped_column(BigInteger, primary_key=True, autoincrement=True)

    is_enabled: Mapped[bool] = mapped_column(Boolean, default=True, nullable=False)
    verify_ttl_minutes: Mapped[int] = mapped_column(Integer, default=15, nullable=False)
    max_attempts: Mapped[int] = mapped_column(Integer, default=5, nullable=False)
    account_fail_limit: Mapped[int] = mapped_column(Integer, default=10, nullable=False)
    account_lock_minutes: Mapped[int] = mapped_column(Integer, default=60, nullable=False)
    device_fail_limit: Mapped[int] = mapped_column(Integer, default=20, nullable=False)
    device_lock_minutes: Mapped[int] = mapped_column(Integer, default=60, nullable=False)

    # 方式开关
    enable_sms: Mapped[bool] = mapped_column(Boolean, default=True, nullable=False)
    enable_totp: Mapped[bool] = mapped_column(Boolean, default=True, nullable=False)
    enable_gesture: Mapped[bool] = mapped_column(Boolean, default=False, nullable=False)
    enable_password: Mapped[bool] = mapped_column(Boolean, default=True, nullable=False)
    enable_email: Mapped[bool] = mapped_column(Boolean, default=False, nullable=False)
```
