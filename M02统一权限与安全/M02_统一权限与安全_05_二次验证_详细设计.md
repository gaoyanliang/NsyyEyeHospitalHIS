## 1. 模块概述

### 1.1 模块定位

二次验证（MFA）是**敏感操作的增强认证**。密码泄露时，仅凭密码不足以完成高风险操作。

M01 权限子模块已定义"**哪些操作需要二次验证**"（`mdm_second_factor_policy` 表 + `second_factor_ops` 列表），M02-04 判定后返回 `NEED_SECOND_FACTOR`。本子模块负责"**如何验证**"。

```
用户在会话中操作
        ↓
┌──────────────────────────────────────────────────────────┐
│ M02-04 权限引擎判定                                       │
│   perm_code ∈ second_factor_ops？                        │
│      ├─ 否 → 放行                                        │
│      └─ 是 → 本会话已验证过？                             │
│              ├─ 是 → 放行                                │
│              └─ 否 → 返回 428 + X-Need-Second-Factor     │
└──────────────────────┬───────────────────────────────────┘
                       ↓ 428
┌──────────────────────────────────────────────────────────┐
│ M02-05 二次验证（本文档）                                 │
│  1. 选择验证方式（短信/TOTP/手势/密码）                    │
│  2. 校验验证码                                           │
│  3. 通过 → 标记本会话"已验证"（TTL 15 分钟）               │
│  4. 失败 → 计数、锁定                                    │
└──────────────────────┬───────────────────────────────────┘
                       ↓ 验证通过
              前端重试原请求 → 放行
```

| 职责 | 归属 |
|---|---|
| 定义"哪些操作需要二次验证" | **M01 权限**（`mdm_second_factor_policy`） |
| 判断"本次请求是否需二次验证" | **M02-04** |
| **验证方式的选择与管理** | **M02-05 本子模块** |
| **验证码的生成与校验** | **M02-05 本子模块** |
| **用户 MFA 绑定（手机/TOTP）** | **M02-05 本子模块** |
| **会话级"已验证"状态** | **M02-05 本子模块** |
| **验证失败计数与锁定** | **M02-05 本子模块** |
| 手机号存储 | M02-01（`sys_account.phone`） |
| 短信发送 | M20 消息中心 |

> **一句话边界**：M01 说"**这个操作要验证**"，M02-04 说"**现在需要验证**"，M02-05 说"**验证通过没通过**"。

### 1.2 为什么需要二次验证

二级眼科医院的**高风险操作**清单（来自 M01 定义）：

| 操作 | 风险 | 后果 |
|---|---|---|
| 退费审批 | 财务 | 资金损失 |
| 手术审批 | 医疗 | 医疗事故 |
| 调价审批 | 财务 | 收入损失 |
| 账号重置密码 | 安全 | 账号被盗 |
| 权限变更 | 安全 | 越权 |
| 查看患者身份证明文 | 隐私 | 隐私泄露 |
| 删除主数据 | 数据 | 数据丢失 |
| 药品停用 | 业务 | 用药中断 |

**威胁模型：**

| 威胁 | 仅密码 | 加二次验证 |
|---|---|---|
| 密码被同事窥见 | ❌ 可直接操作 | ✅ 无法完成（需手机） |
| 密码泄露到外网 | ❌ 攻击者可操作 | ✅ 无法完成 |
| 终端未锁屏被冒用 | ❌ 可直接操作 | ✅ 无法完成 |
| 钓鱼获取密码 | ❌ 可直接操作 | ✅ 无法完成 |
| 手机丢失 | — | ⚠ 降级到其他方式 |

### 1.3 模块目标

- **多方式支持**：短信、TOTP、手势、密码重验四种。
- **会话级记忆**：验证一次，15 分钟内同类操作无需重复。
- **可配置粒度**：按操作配置验证方式与有效期。
- **失败防护**：连续失败锁定，防暴力破解。
- **可自助绑定**：用户可自行更换手机、开启 TOTP。
- **降级可用**：手机丢失时可用备用方式恢复。
- **完整审计**：每次验证尝试留痕。

### 1.4 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 全部系统用户 | 使用 | 敏感操作时二次验证 |
| 全部系统用户 | 自助 | 绑定/更换手机、开启 TOTP |
| 系统管理员 | 运维 | 重置用户 MFA、查看验证记录 |
| 信息科长 | 安全策略 | 配置验证方式与有效期 |
| 审计员 | 追溯 | 查看验证历史 |

## 3. 二次验证模型

### 3.1 验证方式

| 方式 | 代码 | 安全性 | 便捷性 | 依赖 | 适用 |
|---|---|---|---|---|---|
| 短信验证码 | `SMS` | 中 | 高 | 手机、短信通道 | 通用首选 |
| TOTP 动态口令 | `TOTP` | 高 | 中 | 手机 App | 高安全操作 |
| 手势密码 | `GESTURE` | 低 | 很高 | 无 | 移动端便捷 |
| 密码重验 | `PASSWORD` | 低 | 高 | 无 | 低风险操作 |
| 邮件验证码 | `EMAIL` | 中 | 中 | 邮箱 | 备用 |
| 备用手机短信 | `SMS_BACKUP` | 中 | 中 | 备用手机 | SMS 不可用 |

**安全等级排序：** `TOTP > SMS ≈ SMS_BACKUP ≈ EMAIL > PASSWORD > GESTURE`

### 3.2 短信验证码

#### 3.2.1 生成规则

| 项 | 方案 |
|---|---|
| 长度 | 6 位数字 |
| 随机性 | `secrets.randbelow(1000000)`，补零 |
| 有效期 | **5 分钟**（可配 1~10 分钟） |
| 存储 | Redis `sms:{token}` → SHA-256(验证码)，TTL 5min |
| 一次性 | 校验成功后立即删除 |
| 校验次数 | 最多 5 次，超过即失效 |

#### 3.2.2 发送限制

| 维度 | 限制 | 说明 |
|---|---|---|
| 同手机号间隔 | **60 秒** | 防轰炸 |
| 同手机号每小时 | **5 次** | — |
| 同手机号每日 | **20 次** | — |
| 同账号每小时 | **10 次** | — |
| 同 IP 每小时 | **20 次** | — |

#### 3.2.3 短信模板

```
【南石眼科医院】您的验证码是 {code}，{expire_min} 分钟内有效，
请勿泄露给他人。您正在进行：{operation_name}
```

**关键：** 短信中必须包含**操作名称**，让用户识别是否为本人操作。

### 3.3 TOTP 动态口令

#### 3.3.1 标准

遵循 **RFC 6238**（TOTP）+ **RFC 4226**（HOTP）：

| 参数 | 值 |
|---|---|
| 算法 | HMAC-SHA1（兼容性最好） |
| 位数 | 6 位 |
| 周期 | 30 秒 |
| 密钥长度 | 160 bit（Base32 编码 32 字符） |
| 容错窗口 | ±1 个周期（即 ±30 秒） |

#### 3.3.2 绑定流程

```
1. 用户点击"开启 TOTP"
   ↓
2. 服务端生成密钥（160 bit 随机）
   ↓
3. 返回 otpauth:// URI + 二维码
   otpauth://totp/南石眼科HIS:wangwu?secret=XXX&issuer=南石眼科医院
   ↓
4. 用户用 App（Google Authenticator / 微软 Authenticator）扫描
   ↓
5. 用户输入 App 显示的一次性验证码
   ↓
6. 服务端校验通过 → 启用 TOTP
   ↓
7. 生成 10 个恢复码，仅显示一次
```

#### 3.3.3 恢复码

| 项 | 说明 |
|---|---|
| 数量 | 10 个 |
| 格式 | 10 位 Base32（如 `A1B2-C3D4-E5`） |
| 存储 | 哈希存储 |
| 使用 | 一次性，用后作废 |
| 用途 | 手机丢失时恢复 |

#### 3.3.4 防重放

TOTP 同一周期内**只允许使用一次**：

```
Redis: sys:mfa:totp:{account_id}:{code_hash} → TTL 60s
校验前检查是否存在，存在则拒绝（防重放）
```

### 3.4 手势密码

#### 3.4.1 规则

| 项 | 值 |
|---|---|
| 点数 | 4~9 点（3×3 网格） |
| 存储 | 哈希存储 |
| 有效期 | 会话级（同 SMS） |
| 适用 | 仅移动端 |
| 安全等级 | **低**（易被窥视） |

#### 3.4.2 限制

- **不得**用于高风险操作（退费、手术审批）
- 仅用于中低风险（如查看患者明细）
- 连续失败 5 次 → 禁用，必须用其他方式

### 3.5 会话级已验证状态

#### 3.5.1 状态模型

```
用户登录成功
   ↓
会话建立，mfa_verified = false
   ↓
触发敏感操作
   ↓
M02-04 判定需二次验证 → 428
   ↓
用户完成验证 → mfa_verified = true（TTL 15 分钟）
   ↓
15 分钟内同类操作 → 直接放行
   ↓
15 分钟后 → 重新验证
```

#### 3.5.2 粒度设计

| 粒度 | 说明 | 采用 |
|---|---|---|
| 会话级 | 验证一次，本会话全部敏感操作都可 | ✅ **采用** |
| 操作级 | 每次敏感操作都验证 | ❌ 太繁琐 |
| 权限码级 | 每个 perm_code 单独记忆 | ⚠ 复杂 |
| 等级级 | 按风险等级记忆 | ⚠ 过度设计 |

**采用会话级 + 15 分钟 TTL**，兼顾安全与体验。

#### 3.5.3 存储

```
Redis: sys:mfa:verified:{session_id} → JSON
{
  "verified_at": "2026-04-01T14:20:15",
  "expire_at": "2026-04-01T14:35:15",
  "method": "SMS",
  "ops": ["m16:refund:approve", "m09:surgery:approve"]
}
TTL: 900 秒
```

### 3.6 验证失败处理

#### 3.6.1 失败计数维度

| 维度 | 阈值 | 锁定对象 | 锁定时长 |
|---|---|---|---|
| 单次验证 | 5 次 | 该次验证令牌 | 立即失效 |
| 单账号 | 10 次/小时 | 账号 MFA | 1 小时 |
| 单设备 | 20 次/小时 | 设备 | 1 小时 |

#### 3.6.2 锁定后果

| 锁定对象 | 后果 |
|---|---|
| 验证令牌锁定 | 本次验证作废，需重新发起 |
| 账号 MFA 锁定 | 1 小时内无法使用任何敏感操作 |
| 设备锁定 | 该设备无法完成二次验证 |

**解锁：**
- 自动：到期解锁
- 人工：管理员重置

### 3.7 验证方式选择策略

#### 3.7.1 策略来源

M01 的 `mdm_second_factor_policy` 定义每种操作的可用方式与要求：

| 字段 | 说明 |
|---|---|
| `operation_code` | 操作权限码 |
| `allowed_methods` | 允许的方式（多选） |
| `required_methods` | 必须的方式（如必须 TOTP） |
| `verify_ttl_minutes` | 验证有效期 |
| `max_fail_count` | 失败阈值 |
| `require_all` | 是否需多种方式都通过 |

#### 3.7.2 方式选择逻辑

```
读取策略 → allowed_methods
   ↓
过滤用户已绑定的方式
   （未绑定 SMS → 不可选 SMS）
   ↓
按安全性排序展示
   ↓
用户选择 → 验证
```

**示例：**

```
操作：m16:refund:approve（退费审批）
策略：allowed_methods = ["SMS", "TOTP"]
      required_methods = []（无强制）
      verify_ttl_minutes = 15

用户 wangwu 已绑定：SMS（138****5678）、TOTP
可选：SMS、TOTP

操作：sys:account:reset（重置密码）
策略：allowed_methods = ["TOTP"]
      required_methods = ["TOTP"]
可选：仅 TOTP
```

### 3.8 MFA 绑定模型

#### 3.8.1 绑定项

| 项目 | 表字段 | 说明 |
|---|---|---|
| 手机号 | `sys_account.phone` | 主手机（M02-01） |
| 备用手机 | `sys_account.phone_backup` | — |
| TOTP 密钥 | `sys_account.mfa_totp_secret` | 加密存储 |
| TOTP 启用 | `sys_account.mfa_totp_enabled` | — |
| 手势密码 | `sys_mfa_credential` | 哈希 |
| 恢复码 | `sys_mfa_recovery_code` | 哈希，10 个 |

#### 3.8.2 绑定流程

**绑定手机：**

```
1. 用户输入新手机号
2. 服务端发送验证码到新号
3. 用户输入验证码
4. 校验通过 → 更新 sys_account.phone
5. 记录审计
```

**绑定 TOTP：**

```
1. 生成密钥 → 返回二维码
2. 用户扫码 → 输入验证码
3. 校验通过 → 保存密钥、启用
4. 生成 10 个恢复码（仅显示一次）
```

#### 3.8.3 解绑与重置

| 场景 | 权限 | 说明 |
|---|---|---|
| 用户自助更换手机 | 本人 | 需旧手机验证 |
| 用户自助开启/关闭 TOTP | 本人 | 开启需验证，关闭需 TOTP |
| 管理员重置用户 MFA | 系统管理员 | 用户手机丢失时，需工单 |
| 用户使用恢复码 | 本人 | 恢复后可重新绑定 |

# app/api/v1/mfa/verify.py
"""二次验证 REST 接口"""
from typing import Optional
from fastapi import APIRouter, Depends, Query, Body, Request
from sqlalchemy.ext.asyncio import AsyncSession

from app.core.database import get_db
from app.core.response import success_response, PageResult
from app.core.security import get_current_user, require_permission
from app.schemas.mfa.verify import (
    ChallengeRequest, SendCodeRequest, VerifyRequest, RecoveryVerifyRequest,
    BindPhoneRequest, TotpEnableRequest, GestureSetupRequest,
    MfaPolicyUpdate, OperationPolicyUpdate, ResetMfaRequest, TicketCreate,
)
from app.services.mfa.challenge_service import ChallengeService
from app.services.mfa.verify_service import VerifyService
from app.services.mfa.bind_service import BindService
from app.services.mfa.policy_service import PolicyService
from app.services.mfa.admin_service import MfaAdminService
from app.services.mfa.ticket_service import TicketService

router = APIRouter(prefix="/api/v1/mfa", tags=["M02-二次验证"])
internal_router = APIRouter(prefix="/internal/v1/mfa", tags=["M02-MFA内部接口"])


# ==================== 验证 ====================
@router.get("/challenge", summary="获取验证挑战")
async def get_challenge(
    perm_code: str = Query(...),
    biz_no: Optional[str] = Query(None),
    db: AsyncSession = Depends(get_db),
    user=Depends(get_current_user),
):
    svc = ChallengeService(db)
    data = await svc.create_challenge(user, perm_code, biz_no)
    return success_response(data)


@router.post("/send-code", summary="发送验证码")
async def send_code(
    payload: SendCodeRequest,
    db: AsyncSession = Depends(get_db),
    user=Depends(get_current_user),
):
    svc = ChallengeService(db)
    data = await svc.send_code(user, payload)
    return success_response(data)


@router.post("/verify", summary="校验验证码")
async def verify(
    payload: VerifyRequest,
    request: Request,
    db: AsyncSession = Depends(get_db),
    user=Depends(get_current_user),
):
    svc = VerifyService(db)
    data = await svc.verify(user, payload, request)
    return success_response(data)


@router.get("/status", summary="当前会话验证状态")
async def get_status(
    db: AsyncSession = Depends(get_db),
    user=Depends(get_current_user),
):
    svc = VerifyService(db)
    data = await svc.get_session_status(user.session_id)
    return success_response(data)


@router.post("/verify-with-recovery", summary="使用恢复码验证")
async def verify_with_recovery(
    payload: RecoveryVerifyRequest,
    db: AsyncSession = Depends(get_db),
    user=Depends(get_current_user),
):
    svc = VerifyService(db)
    data = await svc.verify_recovery(user, payload)
    return success_response(data)


# ==================== 绑定 ====================
@router.post("/bind-phone/send-code", summary="绑定手机-发送验证码")
async def bind_phone_send_code(

# app/services/mfa/verify_service.py
"""二次验证校验服务（核心）"""
import hashlib
import hmac
import json
import time
from datetime import datetime, timedelta
from typing import Optional

import pyotp
from sqlalchemy import select, func
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.mfa.verify import (
    SysMfaChallenge, SysMfaRecord, SysMfaCredential, SysMfaRecoveryCode,
    SysMfaPolicy, SysMfaOperationPolicy,
)
from app.models.sys.account import SysAccount
from app.core.exceptions import BizException
from app.core.redis import redis_client
from app.services.sys.password_service import PasswordService


class VerifyService:
    def __init__(self, db: AsyncSession):
        self.db = db

    # ---------- 会话验证状态 ----------
    async def get_session_status(self, session_id: str) -> dict:
        """查询会话验证状态"""
        key = f"sys:mfa:verified:{session_id}"
        cached = await redis_client.get(key)
        if not cached:
            return {"session_id": session_id, "verified": False,
                    "remaining_seconds": 0}

        data = json.loads(cached)
        expire_at = datetime.fromisoformat(data["expire_at"])
        remaining = int((expire_at - datetime.now()).total_seconds())

        if remaining <= 0:
            await redis_client.delete(key)
            return {"session_id": session_id, "verified": False,
                    "remaining_seconds": 0}

        return {
            "session_id": session_id,
            "verified": True,
            "method": data.get("method"),
            "verified_at": data.get("verified_at"),
            "expire_at": data.get("expire_at"),
            "remaining_seconds": remaining,
        }

    async def mark_verified(self, session_id: str, method: str,
                              perm_code: str, ttl_minutes: int = 15) -> dict:
        """标记会话已验证"""
        now = datetime.now()
        expire_at = now + timedelta(minutes=ttl_minutes)

        key = f"sys:mfa:verified:{session_id}"
        existing = await redis_client.get(key)

        ops = []
        if existing:
            old = json.loads(existing)
            ops = old.get("ops", [])

        if perm_code not in ops:
            ops.append(perm_code)

        data = {
            "verified_at": now.isoformat(),
            "expire_at": expire_at.isoformat(),
            "method": method,
            "ops": ops,
        }
        await redis_client.setex(key, ttl_minutes * 60, json.dumps(data))

        return {
            "session_id": session_id,
            "verified": True,
            "method": method,
            "verified_at": now.isoformat(),
            "expire_at": expire_at.isoformat(),
        }

    # ---------- 验证主流程 ----------
    async def verify(self, user, payload, request) -> dict:
        """校验验证码（用户接口）"""
        return await self._do_verify(
            session_id=user.session_id,
            account_id=user.account_id,
            staff_id=user.staff_id,
            perm_code=payload.challenge_id and await self._get_challenge_perm(payload.challenge_id),
            method=payload.method,
            code=payload.code,
            challenge_id=payload.challenge_id,
            request=request,
        )

    async def verify_internal(self, session_id: str, account_id: int,
                                perm_code: str, method: str, code: str,
                                challenge_id: Optional[str] = None) -> dict:
        """校验验证码（内部接口，M02-04 调用）"""
        return await self._do_verify(
            session_id=session_id,
            account_id=account_id,
            staff_id=None,
            perm_code=perm_code,
            method=method,
            code=code,
            challenge_id=challenge_id,
            request=None,
        )

    async def _do_verify(self, session_id: str, account_id: int,
                          staff_id: Optional[int], perm_code: str,
                          method: str, code: str,
                          challenge_id: Optional[str],
                          request) -> dict:
        """验证核心逻辑"""
        start = time.time()

        # 1. 检查账号 MFA 锁定
        lock_check = await self._check_mfa_lock(account_id)
        if lock_check:
            raise BizException("0205022", "账号二次验证已锁定，请稍后重试",
                                data={"unlock_at": lock_check})

        # 2. 获取挑战（可选）
        challenge = None
        if challenge_id:
            challenge = await self._get_challenge(challenge_id)
            if not challenge:
                raise BizException("0205001", "验证挑战不存在或已过期")
            perm_code = challenge.perm_code

        # 3. 检查单次验证尝试次数
        if challenge and challenge.attempt_count >= challenge.max_attempts:
            raise BizException("0205006", "验证码校验次数超限，请重新发起验证")

        # 4. 按方式校验
        if method == "SMS":
            result = await self._verify_sms(account_id, code, challenge)
        elif method == "TOTP":
            result = await self._verify_totp(account_id, code)
        elif method == "GESTURE":
            result = await self._verify_gesture(account_id, code)
        elif method == "PASSWORD":
            result = await self._verify_password(account_id, code)
        elif method == "RECOVERY":
            result = await self._verify_recovery(account_id, code)
        else:
            raise BizException("0205002", f"不支持的验证方式：{method}")

        # 5. 记录尝试
        if challenge:
            challenge.attempt_count += 1
            await self.db.commit()

        # 6. 失败处理
        if not result["success"]:
            await self._handle_fail(account_id, challenge, method)
            remaining = (challenge.max_attempts - challenge.attempt_count
                          if challenge else 0)

            # 记录验证记录
            await self._log_record(
                account_id=account_id, session_id=session_id,
                perm_code=perm_code, method=method,
                success=False, fail_reason=result.get("reason"),
                cost_ms=int((time.time() - start) * 1000))

            return {
                "verified": False,
                "error_code": "CODE_INVALID",
                "error_message": result.get("message", "验证码错误"),
                "remaining_attempts": max(0, remaining),
                "challenge_id": challenge_id,
            }

        # 7. 成功 → 标记会话已验证
        ttl = challenge.verify_ttl_minutes if challenge else 15
        marked = await self.mark_verified(session_id, method, perm_code, ttl)

        # 8. 清理
        if challenge:
            await self._consume_challenge(challenge_id)
        await self._reset_fail_count(account_id)

        # 9. 记录
        await self._log_record(
            account_id=account_id, session_id=session_id,
            perm_code=perm_code, method=method,
            success=True, cost_ms=int((time.time() - start) * 1000))

        return {
            "verified": True,
            "session_id": session_id,
            "method": method,
            "verified_at": marked["verified_at"],
            "expire_at": marked["expire_at"],
            "verify_ttl_minutes": ttl,
            "message": f"验证成功，{ttl} 分钟内同类操作无需重复验证",
        }

    # ---------- 各方式校验 ----------
    async def _verify_sms(self, account_id: int, code: str,
                            challenge) -> dict:
        """校验短信验证码"""
        if not challenge:
            raise BizException("0205001", "缺少验证挑战")

        # 从 Redis 取验证码哈希
        key = f"sys:mfa:sms:{challenge.challenge_id}"
        stored = await redis_client.get(key)

        if not stored:
            return {"success": False, "reason": "CODE_EXPIRED",
                    "message": "验证码已过期，请重新发送"}

        stored_data = json.loads(stored)
        code_hash = self._hash_code(code, challenge.challenge_id)

        if not hmac.compare_digest(code_hash, stored_data["code_hash"]):
            return {"success": False, "reason": "CODE_INVALID",
                    "message": "验证码错误"}

        # 校验通过 → 删除
        await redis_client.delete(key)
        return {"success": True}

    async def _verify_totp(self, account_id: int, code: str) -> dict:
        """校验 TOTP"""
        account = await self._get_account(account_id)

        if not account.mfa_totp_enabled or not account.mfa_totp_secret:
            raise BizException("0205013", "TOTP 未启用")

        # 解密密钥
        from app.core.crypto import aes_decrypt
        secret = aes_decrypt(account.mfa_totp_secret)

        # 校验（±1 周期容错）
        totp = pyotp.TOTP(secret, digits=6, interval=30)
        if not totp.verify(code, valid_window=1):
            return {"success": False, "reason": "TOTP_INVALID",
                    "message": "动态口令错误"}

        # 防重放：同一周期内只能使用一次
        replay_key = f"sys:mfa:totp:{account_id}:{code}"
        if await redis_client.get(replay_key):
            return {"success": False, "reason": "TOTP_REPLAY",
                    "message": "该动态口令已被使用，请等待下一次刷新"}
        await redis_client.setex(replay_key, 60, "1")

        return {"success": True}

    async def _verify_gesture(self, account_id: int, gesture: str) -> dict:
        """校验手势密码"""
        cred = (await self.db.execute(
            select(SysMfaCredential).where(
                SysMfaCredential.account_id == account_id,
                SysMfaCredential.cred_type == "GESTURE",
                SysMfaCredential.is_enabled == True)
        )).scalar_one_or_none()

        if not cred:
            raise BizException("0205003", "手势密码未设置")

        if not self._verify_hash(gesture, cred.cred_hash):
            return {"success": False, "reason": "GESTURE_INVALID",
                    "message": "手势密码错误"}

        return {"success": True}

    async def _verify_password(self, account_id: int, password: str) -> dict:
        """校验密码（重验）"""
        account = await self._get_account(account_id)
        pwd_svc = PasswordService(self.db)

        if not pwd_svc.verify_password(password, account.password_hash):
            return {"success": False, "reason": "PASSWORD_INVALID",
                    "message": "密码错误"}

        return {"success": True}

    async def _verify_recovery(self, account_id: int, code: str) -> dict:
        """校验恢复码"""
        # 规范化格式（去掉连字符，转大写）
        normalized = code.replace("-", "").replace(" ", "").upper()

        codes = (await self.db.execute(
            select(SysMfaRecoveryCode).where(
                SysMfaRecoveryCode.account_id == account_id,
                SysMfaRecoveryCode.is_used == False)
        )).scalars().all()

        for c in codes:
            if self._verify_hash(normalized, c.code_hash):
                c.is_used = True
                c.used_at = datetime.now()
                await self.db.commit()
                return {"success": True, "recovery_used": True}

        return {"success": False, "reason": "RECOVERY_INVALID",
                "message": "恢复码无效或已被使用"}

    # ---------- 失败处理 ----------
    async def _handle_fail(self, account_id: int, challenge,
                            method: str) -> None:
        """处理验证失败"""
        # 单次验证失败
        if challenge and challenge.attempt_count >= challenge.max_attempts:
            await self._consume_challenge(challenge.challenge_id)
            # 同时锁定挑战
            await redis_client.setex(
                f"sys:mfa:lock:challenge:{challenge.challenge_id}",
                300, "1")

        # 账号级失败计数
        fail_key = f"sys:mfa:fail:{account_id}"
        count = await redis_client.incr(fail_key)
        if count == 1:
            await redis_client.expire(fail_key, 3600)

        policy = await self._get_policy()
        if count >= policy.account_fail_limit:
            # 锁定账号 MFA
            await redis_client.setex(
                f"sys:mfa:lock:account:{account_id}",
                policy.account_lock_minutes * 60,
                str(count))

    async def _reset_fail_count(self, account_id: int) -> None:
        """重置失败计数"""
        await redis_client.delete(f"sys:mfa:fail:{account_id}")

    async def _check_mfa_lock(self, account_id: int) -> Optional[str]:
        """检查账号 MFA 锁定"""
        key = f"sys:mfa:lock:account:{account_id}"
        if await redis_client.get(key):
            ttl = await redis_client.ttl(key)
            return (datetime.now()
                    + timedelta(seconds=max(0, ttl))).isoformat()
        return None

    # ---------- 辅助 ----------
    async def _get_account(self, account_id: int) -> SysAccount:
        acc = (await self.db.execute(
            select(SysAccount).where(SysAccount.id == account_id)
        )).scalar_one_or_none()
        if not acc:
            raise BizException("0205027", "账号不存在")
        return acc

    async def _get_challenge(self, challenge_id: str) -> Optional[SysMfaChallenge]:
        return (await self.db.execute(
            select(SysMfaChallenge).where(
                SysMfaChallenge.challenge_id == challenge_id,
                SysMfaChallenge.is_consumed == False,
                SysMfaChallenge.expire_at > datetime.now())
        )).scalar_one_or_none()

    async def _get_challenge_perm(self, challenge_id: str) -> str:
        ch = await self._get_challenge(challenge_id)
        return ch.perm_code if ch else ""

    async def _consume_challenge(self, challenge_id: str) -> None:
        ch = await self._get_challenge(challenge_id)
        if ch:
            ch.is_consumed = True
            ch.consumed_at = datetime.now()
            await self.db.commit()

    async def _get_policy(self) -> SysMfaPolicy:
        policy = (await self.db.execute(
            select(SysMfaPolicy).where(SysMfaPolicy.id == 1)
        )).scalar_one_or_none()
        if not policy:
            raise BizException("0205024", "MFA 策略未配置")
        return policy

    @staticmethod
    def _hash_code(code: str, salt: str) -> str:
        """验证码哈希"""
        return hashlib.sha256(f"{code}:{salt}".encode()).hexdigest()

    @staticmethod
    def _hash_credential(raw: str) -> str:
        """凭据哈希"""
        return hashlib.sha256(raw.encode()).hexdigest()

    @staticmethod
    def _verify_hash(raw: str, stored: str) -> bool:
        return hmac.compare_digest(
            hashlib.sha256(raw.encode()).hexdigest(), stored)

    async def _log_record(self, account_id: int, session_id: str,
                            perm_code: str, method: str, success: bool,
                            fail_reason: Optional[str] = None,
                            cost_ms: int = 0) -> None:
        """记录验证历史"""
        self.db.add(SysMfaRecord(
            account_id=account_id,
            session_id=session_id,
            perm_code=perm_code,
            method=method,
            result="SUCCESS" if success else "FAILED",
            fail_reason=fail_reason,
            cost_ms=cost_ms,
        ))
        await self.db.commit()

    async def verify_recovery(self, user, payload) -> dict:
        """使用恢复码验证（用户接口）"""
        result = await self._verify_recovery(user.account_id, payload.recovery_code)

        if not result["success"]:
            return {
                "verified": False,
                "error_code": "RECOVERY_INVALID",
                "error_message": result.get("message"),
            }

        # 恢复码验证通过 → 标记会话已验证
        marked = await self.mark_verified(
            user.session_id, "RECOVERY",
            payload.perm_code or "*", 15)

        return {
            "verified": True,
            "method": "RECOVERY",
            "verified_at": marked["verified_at"],
            "expire_at": marked["expire_at"],
            "remaining_codes": await self._count_recovery(user.account_id),
            "suggestion": "恢复码已使用，建议重新绑定 MFA 并生成新恢复码",
        }

    async def _count_recovery(self, account_id: int) -> int:
        return (await self.db.execute(
            select(func.count()).select_from(SysMfaRecoveryCode).where(
                SysMfaRecoveryCode.account_id == account_id,
                SysMfaRecoveryCode.is_used == False)
        )).scalar_one()

        token = f"bind_{uuid.uuid4().hex[:16]}"

        await redis_client.setex(
            f"sys:mfa:bind:phone:{token}", 300,
            json.dumps({"phone": phone, "code": code,
                        "account_id": user.account_id}))
        await redis_client.setex(rate_key, 60, "1")

        # 发送短信
        await self._send_sms(phone, code, "绑定手机")

        return {
            "bind_token": token,
            "phone_mask": self._mask_phone(phone),
            "expire_in": 300,
            "resend_after": 60,
            "message": "验证码已发送，请查收",
        }

    async def bind_phone(self, user, payload) -> dict:
        """绑定/更换手机"""
        key = f"sys:mfa:bind:phone:{payload.bind_token}"
        stored = await redis_client.get(key)

        if not stored:
            raise BizException("0205005", "验证码已过期，请重新获取")

        data = json.loads(stored)

        if data["code"] != payload.code:
            raise BizException("0205004", "验证码错误")

        if data["account_id"] != user.account_id:
            raise BizException("0205002", "绑定令牌不属于当前用户")

        # 更新账号手机
        account = (await self.db.execute(
            select(SysAccount).where(SysAccount.id == user.account_id)
        )).scalar_one()

        old_phone = account.phone
        account.phone = data["phone"]
        account.mfa_bound = True
        await self.db.commit()

        await redis_client.delete(key)

        return {
            "bound": True,
            "phone_mask": self._mask_phone(data["phone"]),
            "old_phone_mask": self._mask_phone(old_phone) if old_phone else None,
            "message": "手机号绑定成功",
        }

    # ---------- TOTP ----------
    async def totp_setup(self, user) -> dict:
        """TOTP 初始化"""
        account = (await self.db.execute(
            select(SysAccount).where(SysAccount.id == user.account_id)
        )).scalar_one()

        if account.mfa_totp_enabled:
            raise BizException("0205012", "TOTP 已启用，如需重置请先关闭")

        # 生成密钥
        secret = pyotp.random_base32()

        # 临时存储（未启用前不入库）
        setup_token = f"totp_setup_{uuid.uuid4().hex[:12]}"
        await redis_client.setex(
            f"sys:mfa:totp:setup:{setup_token}", 600,
            json.dumps({"secret": secret, "account_id": user.account_id}))

        # 生成 otpauth URL
        uri = pyotp.totp.TOTP(secret).provisioning_uri(
            name=user.username, issuer_name="南石眼科医院")

        # 生成二维码
        qr = qrcode.QRCode(version=1, box_size=10, border=2)
        qr.add_data(uri)
        qr.make(fit=True)
        img = qr.make_image(fill_color="black", back_color="white")
        buffer = io.BytesIO()
        img.save(buffer, format="PNG")
        qr_base64 = base64.b64encode(buffer.getvalue()).decode()

        return {
            "secret": secret,
            "otpauth_url": uri,
            "qr_code": f"data:image/png;base64,{qr_base64}",
            "setup_token": setup_token,
            "expire_in": 600,
            "message": "请使用身份验证器 App 扫描二维码，然后输入验证码完成启用",
        }

    async def totp_enable(self, user, payload) -> dict:
        """TOTP 启用"""
        key = f"sys:mfa:totp:setup:{payload.setup_token}"
        stored = await redis_client.get(key)

        if not stored:
            raise BizException("0205001", "设置令牌已过期，请重新初始化")

        data = json.loads(stored)
        if data["account_id"] != user.account_id:
            raise BizException("0205002", "设置令牌不属于当前用户")

        secret = data["secret"]

        # 校验验证码
        totp = pyotp.TOTP(secret)
        if not totp.verify(payload.code, valid_window=1):
            raise BizException("0205004", "验证码不正确，请确认手机时间是否准确")

        # 启用
        account = (await self.db.execute(
            select(SysAccount).where(SysAccount.id == user.account_id)
        )).scalar_one()

        account.mfa_totp_secret = aes_encrypt(secret)
        account.mfa_totp_enabled = True
        account.mfa_bound = True

        # 生成恢复码
        codes = await self._generate_recovery_codes(user.account_id)

        await self.db.commit()
        await redis_client.delete(key)

        return {
            "enabled": True,
            "recovery_codes": codes,
            "recovery_codes_display_once": True,
            "message": "动态口令已启用，请立即保存恢复码",
        }

    async def totp_disable(self, user, code: str) -> dict:
        """TOTP 关闭"""
        account = (await self.db.execute(
            select(SysAccount).where(SysAccount.id == user.account_id)
        )).scalar_one()

        if not account.mfa_totp_enabled:
            raise BizException("0205013", "TOTP 未启用")

        # 校验 TOTP
        from app.core.crypto import aes_decrypt
        secret = aes_decrypt(account.mfa_totp_secret)
        totp = pyotp.TOTP(secret)

        if not totp.verify(code, valid_window=1):
            raise BizException("0205004", "动态口令错误")

        account.mfa_totp_enabled = False
        account.mfa_totp_secret = None
        await self.db.commit()

        return {"enabled": False, "message": "动态口令已关闭"}

    # ---------- 恢复码 ----------
    async def _generate_recovery_codes(self, account_id: int,
                                         count: int = 10) -> List[str]:
        """生成恢复码（作废旧码）"""
        # 作废旧码
        old = (await self.db.execute(
            select(SysMfaRecoveryCode).where(
                SysMfaRecoveryCode.account_id == account_id,
                SysMfaRecoveryCode.is_used == False)
        )).scalars().all()
        for c in old:
            c.is_used = True
            c.used_at = datetime.now()

        # 生成新码
        codes = []
        for _ in range(count):
            raw = "".join(secrets.choice(RECOVERY_CHARS) for _ in range(10))
            display = f"{raw[:4]}-{raw[4:8]}-{raw[8:]}"
            normalized = raw

            self.db.add(SysMfaRecoveryCode(
                account_id=account_id,
                code_hash=VerifyService._hash_credential(normalized),
                is_used=False,
            ))
            codes.append(display)

        return codes

    async def regenerate_recovery(self, user, password: str) -> dict:
        """重新生成恢复码（需密码验证）"""
        account = (await self.db.execute(
            select(SysAccount).where(SysAccount.id == user.account_id)
        )).scalar_one()

        pwd_svc = PasswordService(self.db)
        if not pwd_svc.verify_password(password, account.password_hash):
            raise BizException("0205004", "密码错误")

        codes = await self._generate_recovery_codes(user.account_id)
        await self.db.commit()

        return {
            "recovery_codes": codes,
            "recovery_codes_display_once": True,
            "message": "恢复码已重新生成，旧恢复码全部作废",
        }

    # ---------- 我的设置 ----------
    async def get_my_settings(self, user) -> dict:
        """获取我的 MFA 设置"""
        account = (await self.db.execute(
            select(SysAccount).where(SysAccount.id == user.account_id)
        )).scalar_one()

        # 恢复码剩余
        remaining = (await self.db.execute(
            select(func.count()).select_from(SysMfaRecoveryCode).where(
                SysMfaRecoveryCode.account_id == user.account_id,
                SysMfaRecoveryCode.is_used == False)
        )).scalar_one()

        # 手势
        gesture = (await self.db.execute(
            select(SysMfaCredential).where(
                SysMfaCredential.account_id == user.account_id,
                SysMfaCredential.cred_type == "GESTURE",
                SysMfaCredential.is_enabled == True)
        )).scalar_one_or_none()

        # 安全评分
        score = 0
        if account.phone:
            score += 35
        if account.phone_backup:
            score += 15
        if account.mfa_totp_enabled:
            score += 35
        if remaining > 0:
            score += 15

        suggestions = []
        if not account.mfa_totp_enabled:
            suggestions.append("您尚未开启 TOTP，建议开启以获得更高安全性")
        if not account.phone_backup:
            suggestions.append("备用手机未设置，主手机丢失后可能无法恢复")
        if remaining < 5 and account.mfa_totp_enabled:
            suggestions.append(f"恢复码仅剩 {remaining} 个，建议重新生成")

        level = "EXCELLENT" if score >= 90 else \
                "GOOD" if score >= 70 else \
                "FAIR" if score >= 50 else "WEAK"

        return {
            "phone": {"bound": bool(account.phone),
                       "mask": self._mask_phone(account.phone)},
            "phone_backup": {"bound": bool(account.phone_backup),
                              "mask": self._mask_phone(account.phone_backup)},
            "totp": {"enabled": bool(account.mfa_totp_enabled),
                      "bound_at": None},
            "gesture": {"enabled": gesture is not None},
            "recovery_codes": {"total": 10, "remaining": remaining},
            "security_score": score,
            "security_level": level,
            "suggestions": suggestions,
        }

    id="job_mfa_unlock_expired",

async def unlock_expired_mfa():
    """自动解锁到期的 MFA 锁定"""
    from datetime import datetime
    from sqlalchemy import select
    from app.models.mfa.verify import SysMfaRecord
    from app.core.database import AsyncSessionLocal
    from app.core.redis import redis_client

    async with AsyncSessionLocal() as db:
        # Redis 中的锁会自动过期，此处只做统计
        keys = await redis_client.keys("sys:mfa:lock:account:*")
        unlocked = 0
        for key in keys:
            if not await redis_client.get(key):
                k = key.decode() if isinstance(key, bytes) else key
                acc_id = k.split(":")[-1]
                db.add(SysMfaRecord(
                    account_id=int(acc_id),
                    session_id="SYSTEM",
                    perm_code="*",
                    method="SYSTEM",
                    result="UNLOCKED",
                    fail_reason="锁定期到期自动解锁",
                ))
                unlocked += 1

        await db.commit()
        return {"unlocked": unlocked, "active_locks": len(keys) - unlocked}

| `GET /internal/v1/mfa/session-status` | 查询会话验证状态 | P95 ≤ 10ms |
| `POST /internal/v1/mfa/verify` | 校验验证码 | P95 ≤ 100ms |
| `POST /internal/v1/mfa/mark-verified` | 标记已验证 | P95 ≤ 10ms |

**约定：**
- M02-04 判定需二次验证 → 返回 428 + `X-Need-Second-Factor`
- 前端弹窗 → 调 M02-05
- 验证通过 → 前端重试原请求
- M02-04 再次判定时查询会话状态 → 通过
