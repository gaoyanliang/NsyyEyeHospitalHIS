## 1. 模块概述

### 1.1 模块定位

审计日志是 M02 的**追溯能力**。它回答："**谁在什么时候对什么做了什么**"，并且**不可篡改**。

本子模块是**三级等保测评的强制要求**（GB/T 22239-2019 第 8.1.4.3 条"安全审计"）：
- 应启用安全审计功能，审计覆盖到每个用户
- 应对重要的用户行为和重要安全事件进行审计
- 审计记录应包括事件的日期和时间、用户、事件类型、事件是否成功及其他与审计相关的信息
- 应对审计记录进行保护，定期备份，避免受到未预期的删除、修改或覆盖

| 职责 | 归属 |
|---|---|
| 账号/登录/会话/权限事件 | **M02-01~05 产生事件** |
| **审计日志统一收集** | **M02-06 本子模块** |
| **审计日志防篡改存储** | **M02-06 本子模块** |
| **业务操作审计（各模块）** | **M02-06 本子模块**（各模块调用） |
| **审计查询与追溯** | **M02-06 本子模块** |
| **审计报表与告警** | **M02-06 本子模块** |
| **数据变更前后值** | 各业务模块提供 |
| 日志归档与备份 | M23 + 本子模块 |

> **一句话边界**：本子模块是**全院唯一的审计日志中心**，M02 内部与 M03~M23 全部业务模块都向它写入，只有审计员能查。

### 1.2 两类审计日志

| 类型 | 说明 | 示例 | 保留期 |
|---|---|---|---|
| **安全审计** | 安全相关事件 | 登录、登出、权限变更、越权、MFA | **3 年** |
| **操作审计** | 业务数据变更 | 新增患者、修改医嘱、退费 | **10 年** |

**区分理由：**

| 类型 | 关注点 | 查询频率 | 合规要求 |
|---|---|---|---|
| 安全审计 | 安全事件追溯 | 高（异常排查） | 等保要求 6 个月~3 年 |
| 操作审计 | 数据变更追溯 | 中（纠纷举证） | 病历相关 10 年 |

### 1.3 模块目标

- **全覆盖**：每个用户、每个重要操作都有记录。
- **不可篡改**：写入后不可修改，通过哈希链校验完整性。
- **可追溯**：按人、按时间、按对象、按操作多维查询。
- **强关联**：串联同一操作的完整链路（登录→操作→登出）。
- **高性能**：异步写入，不影响业务。
- **合规留存**：安全审计 3 年，操作审计 10 年。
- **可视化**：审计报表、异常告警、用户行为画像。

### 1.4 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 全部系统用户 | 被审计 | 无感（自动记录） |
| 审计员 | 审计追溯 | 查询、导出、生成审计报告 |
| 信息科长 | 安全监管 | 查看异常告警、配置审计规则 |
| 系统管理员 | 运维 | 归档、备份、完整性校验 |

### 3.3 防篡改机制（哈希链）

#### 3.3.1 链式哈希

```
记录 1: hash_1 = SHA256(记录1内容 + "0"*64)
记录 2: hash_2 = SHA256(记录2内容 + hash_1)
记录 3: hash_3 = SHA256(记录3内容 + hash_2)
...
记录 N: hash_N = SHA256(记录N内容 + hash_{N-1})
```

**校验：** 从任意记录开始，重新计算哈希并与存储的 `hash` 比对。任一记录被篡改，其后的所有哈希都会不匹配。

#### 3.3.2 按日分链

为避免单链过长影响性能，**按天分链**：

```
2026-04-01 的链：
  hash_1 = SHA256(data_1 + "0"*64)
  ...
  hash_N = SHA256(data_N + hash_{N-1})
  日终锚点: anchor_20260401 = hash_N

2026-04-02 的链：
  hash_1 = SHA256(data_1 + anchor_20260401)   ← 接上一天锚点
  ...
```

**日终锚点存储：** `sys_audit_chain_anchor` 表，单独保护。

#### 3.3.3 哈希计算内容

```python
def compute_hash(record: dict, prev_hash: str) -> str:
    """计算审计记录哈希"""
    # 规范化：固定顺序、去除易变字段
    payload = {
        "audit_id": record["audit_id"],
        "audit_type": record["audit_type"],
        "event_code": record["event_code"],
        "operator_id": record["account_id"],
        "object_type": record["object_type"],
        "object_id": record["object_id"],
        "result": record["result"],
        "occurred_at": record["occurred_at"].isoformat(),
        "content_hash": sha256(json.dumps(record["content"], sort_keys=True)),
    }
    canonical = json.dumps(payload, sort_keys=True, separators=(",", ":"))
    return hashlib.sha256((canonical + prev_hash).encode()).hexdigest()
```

### 3.4 审计采集模型

#### 3.4.1 采集方式

| 方式 | 适用 | 特点 |
|---|---|---|
| **主动 API** | 业务模块实时写入 | 可靠，稍慢 |
| **MQ 事件** | 高频、可异步 | 快，可能丢失 |
| **AOP 切面** | 自动拦截关键接口 | 无侵入 |
| **日志文件采集** | 兜底 | 事后补录 |

**本期采用：主动 API（主要）+ AOP 切面（自动）**

#### 3.4.2 审计装饰器

```python
@audit_log(
    event_code="DATA_UPDATE",
    audit_type="OPERATION",
    object_type="mdm_drug",
    capture_before=True,   # 是否捕获变更前
    capture_after=True,
)
async def update_drug(drug_id: int, payload, user):
    ...
```

**自动捕获：**
- 变更前：查询一次对象
- 变更后：再查询一次
- 计算 diff
- 写入审计

#### 3.4.3 异步写入

```
业务线程 → 组装审计记录 → 压入内存队列（无阻塞）
                              ↓
                    Celery Worker 批量写入
                              ↓
                    100 条/批 或 1 秒刷一次
```

**为什么异步：** 审计写入不应阻塞业务。但**失败必须有兜底**：内存队列满时降级为同步写。

### 3.5 审计查询模型

#### 3.5.1 查询维度

| 维度 | 说明 | 索引 |
|---|---|---|
| 时间范围 | 起止时间 | `idx_audit_time` |
| 操作人 | 账号/职工 | `idx_audit_operator` |
| 对象 | 类型 + ID | `idx_audit_object` |
| 事件类型 | event_code | `idx_audit_event` |
| 结果 | 成功/失败 | `idx_audit_result` |
| 风险等级 | LOW/MEDIUM/HIGH/CRITICAL | `idx_audit_risk` |
| 业务单号 | biz_no | `idx_audit_biz` |
| IP | client_ip | `idx_audit_ip` |

#### 3.5.2 查询策略

| 时间范围 | 策略 |
|---|---|
| ≤7 天 | 直接查热表 |
| 7~90 天 | 查热表（分区裁剪） |
| >90 天 | 查归档表（异步） |

**强制约束：** 查询必须指定时间范围，且不超过 1 年（防止全表扫描）。

### 3.6 风险等级

| 等级 | 说明 | 典型事件 | 处理 |
|---|---|---|---|
| `LOW` | 一般操作 | 登录成功、查看 | 记录 |
| `MEDIUM` | 需关注 | 登录失败、MFA 失败、数据修改 | 记录 + 统计 |
| `HIGH` | 需审计 | 权限变更、密码重置、数据删除、导出 | 记录 + 告警 |
| `CRITICAL` | 需立即处理 | 批量导出、越权、异常访问 | 记录 + 实时告警 |

### 3.7 审计报表

| 报表 | 频率 | 内容 |
|---|---|---|
| 日报 | 每日 08:00 | 前一日：登录统计、失败登录、高危操作、异常 |
| 周报 | 每周一 08:00 | 上周汇总 + 趋势 |
| 月报 | 每月 1 日 08:00 | 上月汇总 + 用户行为 |
| 专题报 | 按需 | 指定账号/对象/时间 |

### 6.4 审计装饰器实现（核心）

```python
# app/core/audit.py
"""审计日志装饰器与依赖"""
import functools
import inspect
from datetime import datetime
from typing import Optional, Callable, List

from fastapi import Request
from sqlalchemy.ext.asyncio import AsyncSession


def audit_log(
    event_code: str,
    audit_type: str = "OPERATION",
    object_type: Optional[str] = None,
    object_id_param: Optional[str] = None,
    capture_before: bool = False,
    capture_after: bool = False,
    risk_level: Optional[str] = None,
    biz_no_param: Optional[str] = None,
    fetch_before: Optional[Callable] = None,
    fields_to_capture: Optional[List[str]] = None,
):
    """审计日志装饰器

    用法：
        @router.put("/drugs/{drug_id}")
        @audit_log(
            event_code="DATA_UPDATE",
            object_type="mdm_drug",
            object_id_param="drug_id",
            capture_before=True,
            capture_after=True,
            fetch_before=lambda db, oid: get_drug_raw(db, oid),
        )
        async def update_drug(drug_id: int, payload, db, user):
            ...
    """
    def decorator(func):
        @functools.wraps(func)
        async def wrapper(*args, **kwargs):
            # 从 kwargs 提取上下文
            request: Optional[Request] = kwargs.get("request")
            db: Optional[AsyncSession] = kwargs.get("db")
            user = kwargs.get("user")

            # 提取对象 ID
            object_id = None
            if object_id_param and object_id_param in kwargs:
                object_id = kwargs[object_id_param]

            # 提取业务单号
            biz_no = None
            if biz_no_param and biz_no_param in kwargs:
                biz_no = kwargs[biz_no_param]

            # 捕获变更前
            before_data = None
            if capture_before and fetch_before and db and object_id:
                try:
                    before_obj = await fetch_before(db, object_id)
                    if before_obj:
                        before_data = _to_dict(before_obj, fields_to_capture)
                except Exception:
                    pass

            # 执行原函数
            error = None
            result = None
            try:
                result = await func(*args, **kwargs)
            except Exception as e:
                error = e
                raise
            finally:
                # 捕获变更后
                after_data = None
                if capture_after and fetch_before and db and object_id and not error:
                    try:
                        after_obj = await fetch_before(db, object_id)
                        if after_obj:
                            after_data = _to_dict(after_obj, fields_to_capture)
                    except Exception:
                        pass

                # 计算 diff
                changed_fields = []
                if before_data and after_data:
                    changed_fields = [
                        k for k in after_data
                        if before_data.get(k) != after_data.get(k)
                    ]
                elif after_data:
                    changed_fields = list(after_data.keys())

                # 组装审计记录
                audit_record = _build_audit_record(
                    event_code=event_code,
                    audit_type=audit_type,
                    risk_level=risk_level or _default_risk(event_code),
                    user=user,
                    request=request,
                    object_type=object_type,
                    object_id=object_id,
                    object_code=_extract_object_code(after_data or before_data),
                    object_name=_extract_object_name(after_data or before_data),
                    api_method=request.method if request else None,
                    api_path=str(request.url.path) if request else None,
                    result="FAILED" if error else "SUCCESS",
                    error_msg=str(error)[:500] if error else None,
                    biz_no=biz_no,
                    before=before_data,
                    after=after_data,
                    changed_fields=changed_fields,
                )

                # 异步写入（不阻塞）
                from app.services.audit.writer import AuditWriter
                try:
                    await AuditWriter.get_instance().enqueue(audit_record)
                except Exception as e:
                    # 审计失败不阻断业务，但要记录告警
                    import logging
                    logging.getLogger("audit").error(
                        f"审计写入失败：{e}", exc_info=True)

            return result

        return wrapper
    return decorator


def _to_dict(obj, fields: Optional[List[str]] = None) -> dict:
    """ORM 对象转字典"""
    if isinstance(obj, dict):
        return obj
    if hasattr(obj, "__table__"):
        cols = [c.name for c in obj.__table__.columns]
        if fields:
            cols = [c for c in cols if c in fields]
        return {c: _serialize(getattr(obj, c, None)) for c in cols}
    return {}


def _serialize(value):
    """序列化值"""
    if value is None:
        return None
    if isinstance(value, (str, int, float, bool)):
        return value
    if isinstance(value, datetime):
        return value.isoformat()
    if hasattr(value, "isoformat"):
        return value.isoformat()
    if isinstance(value, (list, dict)):
        return value
    return str(value)
```

```python
"""审计写入服务（异步批量）"""
import asyncio
import json
from collections import deque
from datetime import datetime
from typing import Optional, List

from sqlalchemy import select, desc, func
from sqlalchemy.ext.asyncio import AsyncSession


class AuditWriter:
    """审计写入器（单例，内存队列 + 批量刷盘）"""

    _instance: Optional["AuditWriter"] = None

    def __init__(self, batch_size: int = 100, flush_interval: float = 1.0,
                 max_queue: int = 10000):
        self.batch_size = batch_size
        self.flush_interval = flush_interval
        self.max_queue = max_queue
        self._queue: deque = deque()
        self._lock = asyncio.Lock()
        self._task: Optional[asyncio.Task] = None
        self._last_hash: Optional[str] = None
        self._last_date: Optional[str] = None

    @classmethod
    def get_instance(cls) -> "AuditWriter":
        if cls._instance is None:
            cls._instance = cls()
        return cls._instance

    async def enqueue(self, record: dict) -> None:
        """入队（非阻塞）"""
        if len(self._queue) >= self.max_queue:
            # 队列满 → 同步写入（降级）
            await self._write_sync([record])
            return

        record["_queued_at"] = datetime.now()
        self._queue.append(record)

        # 达到批量大小 → 立即刷
        if len(self._queue) >= self.batch_size:
            await self._flush()

    async def _flush(self) -> int:
        """刷盘"""
        if not self._queue:
            return 0

        async with self._lock:
            batch = []
            while self._queue and len(batch) < self.batch_size:
                batch.append(self._queue.popleft())

            if not batch:
                return 0

            try:
                await self._write_batch(batch)
                return len(batch)
            except Exception as e:
                # 写失败 → 放回队列（最多重试一次）
                for r in reversed(batch):
                    self._queue.appendleft(r)
                import logging
                logging.getLogger("audit").error(
                    f"审计批量写入失败：{e}", exc_info=True)
                return 0

    async def _write_batch(self, records: List[dict]) -> None:
        """批量写入 DB（含哈希链）"""
        from app.core.database import AsyncSessionLocal
        from app.models.audit.log import SysAuditLog

        async with AsyncSessionLocal() as db:
            for r in records:
                # 计算哈希
                r["hash"] = self._compute_hash(r, self._get_prev_hash(r))
                r["prev_hash"] = self._get_prev_hash(r)

                db.add(SysAuditLog(
                    audit_id=r["audit_id"],
                    audit_type=r["audit_type"],
                    event_code=r["event_code"],
                    event_name=r.get("event_name"),
                    risk_level=r["risk_level"],
                    account_id=r.get("account_id"),
                    staff_id=r.get("staff_id"),
                    username=r.get("username"),
                    staff_name=r.get("staff_name"),
                    dept_id=r.get("dept_id"),
                    dept_name=r.get("dept_name"),
                    object_type=r.get("object_type"),
                    object_id=r.get("object_id"),
                    object_code=r.get("object_code"),
                    object_name=r.get("object_name"),
                    api_method=r.get("api_method"),
                    api_path=r.get("api_path"),
                    result=r.get("result", "SUCCESS"),
                    error_msg=r.get("error_msg"),
                    biz_no=r.get("biz_no"),
                    before_json=r.get("before_json"),
                    after_json=r.get("after_json"),
                    changed_fields=r.get("changed_fields"),
                    session_id=r.get("session_id"),
                    client_ip=r.get("client_ip"),
                    user_agent=r.get("user_agent"),
                    trace_id=r.get("trace_id"),
                    hash=r["hash"],
                    prev_hash=r["prev_hash"],
                    occurred_at=r.get("occurred_at"),
                ))

                self._last_hash = r["hash"]

            await db.commit()

    def _get_prev_hash(self, record: dict) -> str:
        """获取前序哈希（按日分链）"""
        occurred = record.get("occurred_at", "")
        date_str = occurred[:10] if isinstance(occurred, str) else ""

        if self._last_date != date_str:
            # 新的一天 → 从锚点开始
            self._last_date = date_str
            self._last_hash = self._load_anchor(date_str)

        return self._last_hash or "0" * 64

    @staticmethod
    def _load_anchor(date_str: str) -> str:
        """加载前一日锚点（同步查询，可优化为缓存）"""
        from datetime import date, timedelta
        prev_date = (date.fromisoformat(date_str) - timedelta(days=1)).isoformat()
        # 实际应从 sys_audit_chain_anchor 表查询
        # 此处返回创世哈希
        return "0" * 64

    @staticmethod
    def _compute_hash(record: dict, prev_hash: str) -> str:
        """计算记录哈希"""
        import hashlib

        payload = {
            "audit_id": record["audit_id"],
            "audit_type": record["audit_type"],
            "event_code": record["event_code"],
            "account_id": record.get("account_id"),
            "object_type": record.get("object_type"),
            "object_id": record.get("object_id"),
            "result": record.get("result"),
            "occurred_at": str(record.get("occurred_at")),
            "before_hash": hashlib.sha256(
                json.dumps(record.get("before_json") or {},
                            sort_keys=True).encode()).hexdigest()[:16],
            "after_hash": hashlib.sha256(
                json.dumps(record.get("after_json") or {},
                            sort_keys=True).encode()).hexdigest()[:16],
        }
        canonical = json.dumps(payload, sort_keys=True, separators=(",", ":"))
        return hashlib.sha256((canonical + prev_hash).encode()).hexdigest()

    async def _write_sync(self, records: List[dict]) -> None:
        """同步写入（降级模式）"""
        await self._write_batch(records)

    async def start_flusher(self) -> None:
        """启动定时刷盘"""
        async def _flusher():
            while True:
                await asyncio.sleep(self.flush_interval)
                await self._flush()

        self._task = asyncio.create_task(_flusher())

    async def stop_flusher(self) -> None:
        """停止并刷完剩余"""
        if self._task:
            self._task.cancel()
        await self._flush()
```

```python
            else:
```

```python
"""审计完整性校验服务"""
import hashlib
from datetime import date, datetime, timedelta
from typing import Optional

from sqlalchemy import select, func, asc
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.audit.log import SysAuditLog, SysAuditChainAnchor
from app.core.exceptions import BizException


class IntegrityService:
    def __init__(self, db: AsyncSession):
        self.db = db

    async def verify(self, date_from: date, date_to: date,
                      batch_size: int = 10000) -> dict:
        """完整性校验（哈希链）"""
        import time
        start_time = time.time()
        verify_id = f"VF{datetime.now().strftime('%Y%m%d%H%M%S')}"

        total_verified = 0
        broken_at = None
        anchor_hash = None
        computed_hash = None

        current_date = date_from
        while current_date <= date_to:
            day_start = datetime.combine(current_date, datetime.min.time())
            day_end = day_start + timedelta(days=1)

            # 加载前一日锚点
            prev_anchor = await self._get_anchor(current_date - timedelta(days=1))
            expected_prev = prev_anchor.hash_value if prev_anchor else "0" * 64

            # 逐批校验
            offset = 0
            day_count = 0
            while True:
                rows = (await self.db.execute(
                    select(SysAuditLog)
                    .where(
                        SysAuditLog.occurred_at >= day_start,
                        SysAuditLog.occurred_at < day_end)
                    .order_by(SysAuditLog.occurred_at.asc(), SysAuditLog.id.asc())
                    .offset(offset)
                    .limit(batch_size)
                )).scalars().all()

                if not rows:
                    break

                for row in rows:
                    # 1. 校验 prev_hash 是否等于上一条的 hash
                    if row.prev_hash != expected_prev:
                        broken_at = {
                            "record_id": row.id,
                            "audit_id": row.audit_id,
                            "expected_prev": expected_prev,
                            "actual_prev": row.prev_hash,
                            "occurred_at": row.occurred_at.isoformat(),
                            "reason": "prev_hash 不匹配",
                        }
                        break

                    # 2. 重新计算 hash
                    recomputed = self._compute_hash(row, row.prev_hash)
                    if recomputed != row.hash:
                        broken_at = {
                            "record_id": row.id,
                            "audit_id": row.audit_id,
                            "expected_hash": row.hash,
                            "actual_hash": recomputed,
                            "occurred_at": row.occurred_at.isoformat(),
                            "reason": "内容哈希不匹配",
                        }
                        break

                    expected_prev = row.hash
                    total_verified += 1
                    day_count += 1

                if broken_at:
                    break

                offset += batch_size

            if broken_at:
                break

            # 记录日终锚点
            if day_count > 0:
                computed_hash = expected_prev
                anchor = await self._get_or_create_anchor(current_date, computed_hash)
                anchor_hash = anchor.hash_value

            current_date += timedelta(days=1)

        cost_ms = int((time.time() - start_time) * 1000)
        result = "PASS" if not broken_at else "FAILED"

        # 记录校验结果
        self.db.add(SysAuditIntegrityVerify(
            verify_id=verify_id,
            date_from=date_from,
            date_to=date_to,
            total_records=total_verified,
            verified_records=total_verified if not broken_at else
                              (broken_at.get("record_id") or 0),
            result=result,
            broken_at=broken_at,
            anchor_hash=anchor_hash,
            computed_hash=computed_hash,
            cost_ms=cost_ms,
        ))
        await self.db.commit()

        if broken_at:
            raise BizException(56013, "完整性校验失败：哈希链断裂",
                data={
                    "verify_id": verify_id,
                    "date_from": date_from.isoformat(),
                    "total_records": total_verified,
                    "result": "FAILED",
                    "broken_at": broken_at,
                    "severity": "CRITICAL",
                    "message": "检测到审计记录被篡改，请立即调查",
                })

        return {
            "verify_id": verify_id,
            "date_from": date_from.isoformat(),
            "date_to": date_to.isoformat(),
            "total_records": total_verified,
            "verified_records": total_verified,
            "result": "PASS",
            "broken_at": None,
            "anchor_hash": anchor_hash,
            "computed_hash": computed_hash,
            "anchor_match": True,
            "cost_ms": cost_ms,
            "message": "完整性校验通过，哈希链完整",
        }

    @staticmethod
    def _compute_hash(row, prev_hash: str) -> str:
        """重算哈希"""
        import json

        payload = {
            "audit_id": row.audit_id,
            "audit_type": row.audit_type,
            "event_code": row.event_code,
            "account_id": row.account_id,
            "object_type": row.object_type,
            "object_id": row.object_id,
            "result": row.result,
            "occurred_at": str(row.occurred_at),
            "before_hash": hashlib.sha256(
                json.dumps(row.before_json or {},
                            sort_keys=True).encode()).hexdigest()[:16],
            "after_hash": hashlib.sha256(
                json.dumps(row.after_json or {},
                            sort_keys=True).encode()).hexdigest()[:16],
        }
        canonical = json.dumps(payload, sort_keys=True, separators=(",", ":"))
        return hashlib.sha256((canonical + prev_hash).encode()).hexdigest()

    async def _get_anchor(self, d: date) -> Optional[SysAuditChainAnchor]:
        """获取日终锚点"""
        return (await self.db.execute(
            select(SysAuditChainAnchor).where(
                SysAuditChainAnchor.chain_date == d)
        )).scalar_one_or_none()

    async def _get_or_create_anchor(self, d: date,
                                      hash_value: str) -> SysAuditChainAnchor:
        """获取或创建日终锚点"""
        anchor = await self._get_anchor(d)
        if anchor:
            anchor.hash_value = hash_value
            anchor.computed_at = datetime.now()
        else:
            anchor = SysAuditChainAnchor(
                chain_date=d,
                hash_value=hash_value,
                computed_at=datetime.now(),
            )
            self.db.add(anchor)
        await self.db.flush()
        return anchor
```

```python
async def _compute_anchor(target_date: str = None):
    """计算指定日期的日终锚点"""

    from sqlalchemy import select, desc
    from app.models.audit.log import SysAuditLog, SysAuditChainAnchor

            anchor.record_count = 0

                chain_date=d,
                hash_value=last.hash,

            )

        await db.commit()
        return {"date": d.isoformat(), "anchor": last.hash}

async def _archive(target_month: str = None):
    """归档指定月份"""
    from datetime import datetime, date
    from sqlalchemy import select
    from app.models.audit.log import SysAuditLog, SysAuditArchiveTask
    from app.core.database import AsyncSessionLocal
    from app.core.redis import redis_client

    lock_key = "sys:audit:lock:archive"
    if not await redis_client.set(lock_key, "1", nx=True, ex=3600):
        return {"status": "SKIPPED", "reason": "归档任务已在运行"}

    try:
        async with AsyncSessionLocal() as db:
            if target_month:
                y, m = map(int, target_month.split("-"))
                month_start = date(y, m, 1)
            else:
                today = date.today()
                month_start = date(today.year, today.month - 1, 1) if today.month > 1 \
                    else date(today.year - 1, 12, 1)

            if month_start.month < 12:
                month_end = date(month_start.year, month_start.month + 1, 1)
            else:
                month_end = date(month_start.year + 1, 1, 1)

            # 统计
            from sqlalchemy import func
            stats = (await db.execute(
                select(
                    SysAuditLog.audit_type,
                    func.count())
                .where(
                    SysAuditLog.occurred_at >= datetime.combine(month_start, datetime.min.time()),
                    SysAuditLog.occurred_at < datetime.combine(month_end, datetime.min.time()))
                .group_by(SysAuditLog.audit_type)
            )).all()

            total = sum(s[1] for s in stats)

            task = SysAuditArchiveTask(
                archive_month=month_start.strftime("%Y-%m"),
                total_records=total,
                task_status="COMPLETED",
                started_at=datetime.now(),
                finished_at=datetime.now(),
            )
            db.add(task)
            await db.commit()

            return {
                "archive_month": month_start.strftime("%Y-%m"),
                "total_records": total,
                "breakdown": {s[0]: s[1] for s in stats},
                "status": "COMPLETED",
            }
    finally:
        await redis_client.delete(lock_key)
```

```python
async def detect_anomalies():
    """检测异常访问模式"""
    from datetime import datetime, timedelta
    from sqlalchemy import select, func
    from app.models.audit.log import SysAuditLog
    from app.core.database import AsyncSessionLocal
    from app.services.notify_service import NotifyService

    async with AsyncSessionLocal() as db:
        since = datetime.now() - timedelta(minutes=30)
        anomalies = []

        # 1. 非工作时间高访问
        hour = datetime.now().hour
        if hour >= 22 or hour < 6:

                    "count": count,

                SysAuditLog.occurred_at >= since,
                SysAuditLog.event_code == "LOGIN_FAILED")
            .group_by(SysAuditLog.client_ip)
            .having(func.count() >= 20)
        )).all()

        for ip, cnt in ip_fails:

                "type": "BRUTE_FORCE",
                "description": f"IP {ip} 30 分钟内 {cnt} 次登录失败",
                "ip": ip,
                "count": cnt,
            })

        # 3. 单账号高频访问

            select(SysAuditLog.username, func.count())
            .where(
                SysAuditLog.occurred_at >= since,
                SysAuditLog.event_code == "DATA_VIEW",
                SysAuditLog.object_type.in_(["md_patient", "mdm_patient"]))
            .group_by(SysAuditLog.username)
            .having(func.count() >= 100)
        )).all()

        for user, cnt in acc_views:
            anomalies.append({
                "type": "HIGH_FREQUENCY_ACCESS",
                "description": f"账号 {user} 30 分钟内访问患者档案 {cnt} 次",
                "username": user,
                "count": cnt,

            await NotifyService().send(
                template="AUDIT_ANOMALY_ALERT",
                receivers=await get_security_managers(),
                params={"count": len(anomalies), "anomalies": anomalies})

        return {"detected": len(anomalies), "anomalies": anomalies}
```

## 11. 异常处理与日志

### 11.1 异常分类

| 类型 | 示例 | 处理 |
|---|---|---|
| 参数异常 | 缺时间范围、超范围 | 56007/56008 |
| 写入异常 | 队列满 | 降级同步写 |
| 写入失败 | DB 故障 | 记录，重试 |
| 查询异常 | 结果超限 | 56009 |
| 校验异常 | 链断裂 | 56013 + 严重告警 |
| 归档异常 | 数据不存在 | 56011 |
| 系统异常 | DB 失败 | 50003 |

**降级策略：**

| 依赖 | 不可用时 |
|---|---|
| DB（写入） | 队列暂存（最多 10000 条），恢复后补写 |
| DB（查询） | 返回错误 |
| Redis | 直连 DB |
| MinIO（归档） | 归档延后 |

- 队列积压 → WARNING
- 校验失败 → CRITICAL + 立即告警
- 归档成功 → INFO
