## 4. 数据结构设计

### 4.1 ER 关系图

```
┌──────────────────────────────────────────────────────────────────────┐
│  sys_sec_config（安全配置，单行）                                     │
│   · IP 模式 / 时段 / 限流开关 / 风控阈值 / 锁屏                       │
└────────────────────────────┬─────────────────────────────────────────┘
                             │ 被引用
        ┌────────────────────┼─────────────────────┬──────────────────┐
        ▼                    ▼                     ▼                  ▼
┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐
│ sys_ip_rule      │  │ sys_rate_limit   │  │ sys_risk_rule    │  │ sys_device       │
│ （IP 规则）       │  │ （限流规则）      │  │ （风控规则）      │  │ （设备）          │
└──────────────────┘  └──────────────────┘  └────────┬─────────┘  └──────────────────┘
                                                      │ 触发
                                                      ▼
                        ┌──────────────────┐  ┌──────────────────┐
                        │ sys_user_baseline│  │ sys_risk_event   │
                        │ （行为基线）      │  │ （风控事件）      │
                        └──────────────────┘  └────────┬─────────┘
                                                       │
                                                       ▼
                                              ┌──────────────────┐
                                              │ sys_emergency_   │
                                              │ action（应急）    │
                                              └──────────────────┘

运行时缓存（Redis，非表）：
  sys:sec:config               安全配置 5min
  sys:sec:ip_rules:{type}      IP 规则 5min
  sys:sec:rl:{dim}:{key}       令牌桶 120s
  sys:sec:lockdown             全局锁定状态
  sys:sec:user_baseline:{id}   行为基线 24h
```

**设计说明：**

- `sys_sec_config` 为**单行全局配置**
- `sys_ip_rule` 同时承载白名单与黑名单（`rule_type` 区分）
- `sys_rate_limit` 支持多维度限流配置
- `sys_risk_rule` 定义风控评分权重与阈值
- `sys_risk_event` 记录每次风控判定结果
- `sys_device` 记录设备指纹与信任状态
- `sys_emergency_action` 记录紧急操作（封禁/全局锁定）
- `sys_user_baseline` 保存用户行为基线（可在线计算或离线物化）

| 字段名 | 类型 | 允许空 | 默认 | 说明 |

| dimension | VARCHAR(32) | N | - | 维度：LOGIN_LOCATION/LOGIN_TIME/DEVICE/BEHAVIOR/FAIL_COUNT |
| weight | NUMERIC(5,2) | N | - | 权重（%） |

**索引：** `uk_risk_rule_code(rule_code)` 唯一；`idx_risk_rule_dim(dimension, is_enabled)`。

**分档阈值格式（`thresholds`）：**

```json
{
  "levels": [
    { "condition": "HISTORY_IP", "score": 0, "label": "历史 IP" },
    { "condition": "NEW_IP_SAME_CITY", "score": 30, "label": "新 IP 同城" },
    { "condition": "NEW_IP_OTHER_CITY", "score": 70, "label": "新 IP 异地" },
    { "condition": "OVERSEAS", "score": 100, "label": "境外" }
  ]
}
```

**预置规则：**

| rule_code | dimension | weight | 说明 |
|---|---|---|---|
| `RISK_LOGIN_LOCATION` | LOGIN_LOCATION | 25 | 登录地点异常 |
| `RISK_LOGIN_TIME` | LOGIN_TIME | 15 | 登录时间异常 |
| `RISK_DEVICE` | DEVICE | 20 | 设备异常 |
| `RISK_BEHAVIOR` | BEHAVIOR | 25 | 行为异常 |
| `RISK_FAIL_COUNT` | FAIL_COUNT | 15 | 失败次数 |

**约束：** 权重合计必须 = 100

```sql
-- 应用层校验，DB 层可用触发器
CREATE OR REPLACE FUNCTION check_risk_weight_sum()
RETURNS TRIGGER AS $$
DECLARE
    total NUMERIC;
BEGIN
    SELECT COALESCE(SUM(weight), 0) INTO total
    FROM sys_risk_rule WHERE is_enabled = TRUE;

    IF total <> 100 THEN
        RAISE EXCEPTION '风控权重合计必须为 100%%，当前为 %', total;
    END IF;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_check_risk_weight
    AFTER INSERT OR UPDATE OR DELETE ON sys_risk_rule
    FOR EACH STATEMENT EXECUTE FUNCTION check_risk_weight_sum();
```

```
NEW/KNOWN ──用户信任──► TRUSTED（30 天）

```

```python
    idle_lock_minutes: Mapped[int] = mapped_column(Integer, default=15, nullable=False)
    sensitive_lock_minutes: Mapped[int] = mapped_column(Integer, default=5, nullable=False)
    force_logout_minutes: Mapped[int] = mapped_column(Integer, default=120, nullable=False)

    degrade_on_fail: Mapped[bool] = mapped_column(Boolean, default=True, nullable=False)

    version_no: Mapped[int] = mapped_column(Integer, default=1, nullable=False)
    updated_by: Mapped[Optional[int]] = mapped_column(BigInteger)
    updated_by_name: Mapped[Optional[str]] = mapped_column(String(64))
    updated_at: Mapped[Optional[datetime]] = mapped_column(
        DateTime, server_default=func.now(), onupdate=func.now())

    __table_args__ = (
        {"comment": "安全配置（单行）"},
    )

    def is_time_allowed(self, hour: int) -> bool:
        """当前小时是否允许访问"""
        if not self.time_limit_enabled:
            return True
        if self.allow_start_hour <= self.allow_end_hour:
            return self.allow_start_hour <= hour < self.allow_end_hour
        return hour >= self.allow_start_hour or hour < self.allow_end_hour

    def risk_level_for(self, score: float) -> str:
        """按分数判定风险等级"""
        if score >= self.risk_critical_threshold:
            return "CRITICAL"
        if score >= self.risk_high_threshold:
            return "HIGH"
        if score >= self.risk_medium_threshold:
            return "MEDIUM"
        return "LOW"

    def action_for_level(self, level: str) -> str:
        """按等级取处置动作"""
        return {
            "LOW": "ALLOW",
            "MEDIUM": "ALLOW",
            "HIGH": self.risk_high_action,
            "CRITICAL": self.risk_critical_action,
        }.get(level, "ALLOW")
```
