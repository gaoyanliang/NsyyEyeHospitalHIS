## 1. 模块概述

### 1.1 模块定位

认证与登录是全院系统的**唯一入口**。它回答："**你是不是你说的那个人**"。

M02-01 解决了"账号存在且可用"，本子模块解决"**如何证明你是这个账号的主人**"，并在验证通过后**转交 M02-03 签发 Token**。

```
用户输入登录名+密码
        ↓
┌───────────────────────────────────┐
│ M02-02 认证与登录（本文档）        │
│  1. 图形验证码校验                 │
│  2. 调用 M02-01 verify-credential  │
│     （账号状态 + 密码校验）         │
│  3. 判断是否需要二次验证           │
│     → 需要：转 M02-05             │
│  4. 记录登录尝试                   │
│  5. 记录成功/失败（回写 M02-01）    │
└───────────────┬───────────────────┘
                │ 认证通过
                ▼
┌───────────────────────────────────┐
│ M02-03 会话与 Token（下一子模块）  │
│  签发 Access Token + Refresh Token │
└───────────────────────────────────┘
```

| 职责 | 归属 |
|---|---|
| 账号存在性、密码正确性、账号状态 | **M02-01**（本子模块调用） |
| **登录流程编排** | **M02-02 本子模块** |
| **图形验证码** | **M02-02 本子模块** |
| **登录方式（密码/短信/扫码/SSO/CA）** | **M02-02 本子模块** |
| **登录尝试记录** | **M02-02 本子模块** |
| **首次登录强制改密引导** | **M02-02 本子模块** |
| **二次验证触发判断** | M02-02 判断，M02-05 执行 |
| Token 签发与刷新 | **M02-03** |
| 权限计算 | **M02-04** |
| 审计日志 | **M02-06** |

> **一句话边界**：本子模块只管"**认证过程**"——从用户点击登录到"你是谁"被确认。**不签发 Token**（M02-03），**不判断权限**（M02-04）。

### 1.2 模块目标

- **多方式登录**：密码、短信验证码、扫码、SSO（预留）、CA（预留）。
- **防暴力破解**：图形验证码 + 失败锁定 + IP 限流。
- **防时序攻击**：账号不存在与密码错误响应一致。
- **清晰的错误提示**：区分"密码错误"与"账号锁定/停用"，但**不泄露账号是否存在**。
- **强制改密引导**：首次登录/密码过期时强制跳转改密。
- **完整留痕**：每次登录尝试（含失败）记录 IP、终端、结果。
- **可审计**：登录记录可查询、可追溯。

### 1.3 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 全部系统用户 | 登录 | 密码登录、短信登录 |
| 系统管理员 | 登录运维 | 查看登录记录、解锁账号 |
| 信息科长 | 安全策略 | 配置登录方式开关 |
| 审计员 | 追溯 | 查询登录历史、异常登录 |

### 2.3 登录方式矩阵

| 方式 | 代码 | 状态 | 适用场景 | 需图形码 |
|---|---|---|---|---|
| 密码登录 | `PASSWORD` | ✅ 启用 | PC、移动 | 是 |
| 短信登录 | `SMS` | ⚙️ 可选 | 移动端 | 是 |
| 扫码登录 | `QRCODE` | ⚙️ 可选 | PC 端（移动已登录） | 否 |
| SSO 登录 | `SSO` | 🔜 预留 | 统一认证 | 否 |

- `SMS`、`QRCODE` 由参数 `SYS.LOGIN.SMS_ENABLED` / `SYS.LOGIN.QRCODE_ENABLED` 控制。
- `SSO`、`CA` 为接口预留，本期不实现。

## 3. 认证模型

### 3.1 密码登录流程

```
┌──────────────────────────────────────────────────────────────────────┐
│ 1. 用户访问登录页                                                     │
│    ↓                                                                  │
│ 2. 前端 GET /captcha → 获取验证码图片 + captcha_id                     │
│    ↓                                                                  │
│ 3. 用户输入 登录名 + 密码 + 验证码                                     │
│    ↓                                                                  │
│ 4. POST /login                                                        │
│    ├─ 4.1 校验图形验证码（Redis）                                      │
│    │      └─ 失败 → 40001 CAPTCHA_INVALID（刷新验证码）               │
│    ├─ 4.2 调用 M02-01 verify-credential                               │
│    │      ├─ 账号不存在 → 记录失败，返回统一错误                        │
│    │      ├─ 账号锁定   → 返回锁定提示（含解锁时间）                    │
│    │      ├─ 账号停用   → 返回停用提示                                │
│    │      ├─ 密码错误   → 调用 record-fail，返回统一错误 + 剩余次数     │
│    │      └─ 密码正确   → 继续                                        │
│    ├─ 4.3 判断是否需要二次验证                                         │
│    │      ├─ 账号 MFA 已绑定 + 策略要求 → 返回 MFA_REQUIRED           │
│    │      └─ 否则 → 继续                                              │
│    ├─ 4.4 判断是否需要强制改密                                         │
│    │      ├─ 首次登录 / 密码过期 → 返回 NEED_CHANGE_PASSWORD           │
│    │      └─ 否则 → 继续                                              │
│    ├─ 4.5 调用 M02-03 创建会话                                        │
│    ├─ 4.6 调用 M02-01 record-success                                 │
│    ├─ 4.7 记录 sys_login_attempt（SUCCESS）                          │
│    └─ 4.8 返回 Access Token + Refresh Token + 用户信息                │
│    ↓                                                                  │
│ 5. 前端存储 Token，跳转首页                                            │
└──────────────────────────────────────────────────────────────────────┘
```

### 3.2 带二次验证的登录流程

```
密码校验通过
    ↓
返回 200 + { need_mfa: true, mfa_token: "临时令牌(5min)", mfa_methods: ["SMS","TOTP"] }
    ↓
前端弹出二次验证弹窗
    ↓
用户选择方式 + 输入验证码
    ↓
POST /login/mfa-verify { mfa_token, method, code }
    ↓
调用 M02-05 verify
    ├─ 失败 → 返回剩余次数
    └─ 成功 → 调用 M02-03 创建会话 → 返回 Token
```

**关键设计：**
- `mfa_token` 为**一次性临时令牌**，仅可用于 `mfa-verify` 接口，有效期 5 分钟。
- `mfa_token` 中**不含**权限信息，只含 `account_id` 与 `purpose=MFA`。
- 二次验证失败不消耗登录失败次数（单独计算，阈值由 M02-05 定义）。

### 3.3 短信验证码登录流程

```
┌──────────────────────────────────────────────────────────────────────┐
│ 1. 用户输入手机号                                                      │
│    ↓                                                                  │
│ 2. GET /captcha → 验证码                                             │
│    ↓                                                                  │
│ 3. POST /login/sms-code { phone, captcha_id, captcha_code }          │
│    ├─ 校验图形验证码                                                  │
│    ├─ 查手机号对应账号（可能多个 → 返回列表让用户选择）                 │
│    ├─ 生成 6 位随机码，存 Redis（TTL 5min）                           │
│    ├─ 调用 M20 发送短信                                               │
│    └─ 返回 { sms_token, expire_in: 300, phone_mask }                 │
│    ↓                                                                  │
│ 4. 用户输入短信码                                                     │
│    ↓                                                                  │
│ 5. POST /login/sms-verify { sms_token, code }                        │
│    ├─ 校验短信码（Redis，最多 5 次）                                   │
│    ├─ 校验账号状态                                                    │
│    ├─ 创建会话                                                        │
│    └─ 返回 Token                                                      │
└──────────────────────────────────────────────────────────────────────┘
```

**限制：**
- 同一手机号 **60 秒内**只能发送 1 次。
- 同一手机号 **每小时最多 5 次**。
- 同一 IP **每小时最多 20 次**。
- 短信码 **6 位数字**，有效期 **5 分钟**，最多校验 **5 次**。

### 3.4 扫码登录流程

```
PC 端                                  移动端（已登录）
  │                                        │
  ├─ 1. GET /login/qrcode                  │
  │     → { qr_id, qr_content, expire_in } │
  │     → 状态 PENDING                     │
  │                                        │
  ├─ 2. 前端轮询 /login/qrcode/{qr_id}     │
  │                                        │
  │                              3. 用户扫码 ├─ POST /login/qrcode/{qr_id}/confirm
  │                                        │    （带移动端 Token）
  │                              4. 状态 →  CONFIRMED
  │                                        │
  ├─ 5. 轮询返回 CONFIRMED                 │
  │     → POST /login/qrcode/{qr_id}/exchange
  │     → 返回 Token                       │
  │                              6. 状态 →  EXCHANGED
  │                                        │
```

**状态机：**

| 状态 | 说明 |
|---|---|
| `PENDING` | 待扫描 |
| `SCANNED` | 已扫描待确认 |
| `CONFIRMED` | 已确认待兑换 |
| `EXCHANGED` | 已兑换（不可重复） |
| `EXPIRED` | 已过期（120 秒） |
| `CANCELLED` | 已取消 |

### 3.5 图形验证码模型

#### 3.5.1 验证码生成

| 项 | 方案 |
|---|---|
| 类型 | 4 位字符（去除易混淆 0/O/1/l/I） |
| 存储 | Redis `sys:captcha:{captcha_id}` → 答案（小写），TTL 120s |
| 图片 | 内存生成 PNG（干扰线 + 噪点），base64 返回 |
| 大小 | 120×40 像素 |
| 校验 | 一次性，校验后立即删除 |

#### 3.5.2 验证码触发策略

| 场景 | 是否需验证码 |
|---|---|
| 首次登录 | 是 |
| 连续失败 ≥ 1 次 | **强制**是 |
| 正常登录 | 是（默认） |
| 扫码登录 | 否 |
| 短信登录 | 是 |

> **默认全场景需要图形验证码**，可通过参数 `SYS.LOGIN.CAPTCHA_ALWAYS` 关闭（仅在不必要时）。

### 3.6 登录失败处理

#### 3.6.1 失败计数维度

| 维度 | 阈值 | 锁定对象 | 说明 |
|---|---|---|---|
| 账号维度 | 5 次 / 30 分钟 | 账号 | 由 M02-01 处理 |
| IP 维度 | 20 次 / 1 小时 | IP | 由本子模块处理 |
| 账号+IP 维度 | 10 次 / 30 分钟 | 组合 | 由本子模块处理 |

#### 3.6.2 统一错误响应

**安全原则：** 账号不存在与密码错误返回**完全相同**的消息与响应时间。

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "success": false,
    "error_code": "BAD_CREDENTIAL",
    "error_message": "登录名或密码错误",
    "remaining_attempts": 4,
    "captcha_required": true
  },
  "trace_id": "9f8a7b6c"
}
```

**例外：** 账号锁定/停用/过期时，因为用户已知道账号存在（否则无法进入该状态），可以明确提示。

### 3.7 首次登录与密码过期引导

| 场景 | 触发条件 | 处理 |
|---|---|---|
| 首次登录 | `need_change_password=true` 且 `change_reason=FIRST_LOGIN` | 返回 `NEED_CHANGE_PASSWORD` + `temp_token` |
| 密码过期 | `password_expire_at < now` | 返回 `NEED_CHANGE_PASSWORD` + `temp_token` + 提示 |
| 密码即将到期 | 剩余 ≤ `warn_days` | 正常登录 + `password_warn_days` 字段提示 |

**`temp_token` 说明：**
- 仅可用于 `POST /login/change-password` 与 `GET /login/me-brief`。
- 有效期 **5 分钟**。
- 含 `purpose=PASSWORD_CHANGE`。
- 改密成功后自动签发正式 Token。

### 6.2 统一响应格式

```json
{

  "message": "success",
  "data": {},
  "trace_id": "9f8a7b6c5d4e3f2a"

```

**业务失败响应（HTTP 200）：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "success": false,
    "error_code": "BAD_CREDENTIAL",
    "error_message": "登录名或密码错误",
    "remaining_attempts": 4
  },
```

### 6.5 Service 层核心逻辑示例

```python
# app/services/auth/login_service.py
"""登录服务（核心编排）"""
import uuid
from datetime import datetime, timedelta
from typing import Optional

from sqlalchemy import select, func
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.sys.account import SysAccount, SysLoginAttempt
from app.core.exceptions import BizException
from app.core.redis import redis_client
from app.services.auth.captcha_service import CaptchaService
from app.core.clients import m01_client, m02_session_client, m03_mfa_client
from app.core.config import settings


class LoginService:
    def __init__(self, db: AsyncSession):
        self.db = db
        self.captcha_svc = CaptchaService(db)

    # ---------- 密码登录 ----------
    async def login(self, req, request) -> dict:
        """密码登录主流程"""
        login_ip = self._get_client_ip(request)
        user_agent = request.headers.get("user-agent", "")[:255]
        device_type = self._detect_device(user_agent)

        # 1. IP 限流
        ip_check = await self.check_ip_limit(login_ip)
        if not ip_check["allowed"]:
            await self._record_attempt(
                username=req.username, account_id=None,
                login_type="PASSWORD", result="IP_BLOCKED",
                fail_reason="IP 登录受限",
                login_ip=login_ip, user_agent=user_agent,
                device_type=device_type)
            return {
                "success": False,
                "error_code": "IP_BLOCKED",
                "error_message": "当前 IP 登录过于频繁，请稍后重试",
                "blocked_until": ip_check.get("blocked_until"),
            }

        # 2. 图形验证码
        config = await self.get_config()
        if config["captcha_enabled"]:
            captcha_ok = await self.captcha_svc.verify(
                req.captcha_id, req.captcha_code, consume=True)
            if not captcha_ok:
                await self._record_attempt(
                    username=req.username, account_id=None,
                    login_type="PASSWORD", result="CAPTCHA_FAILED",
                    fail_reason="验证码错误",
                    login_ip=login_ip, user_agent=user_agent,
                    device_type=device_type)
                return {
                    "success": False,
                    "error_code": "CAPTCHA_INVALID",
                    "error_message": "验证码错误，请重新输入",
                    "captcha_required": True,
                }

        # 3. 调用 M02-01 校验凭据
        verify_result = await m01_client.verify_credential(
            username=req.username,
            password=req.password,
            login_ip=login_ip,
            user_agent=user_agent,
        )

        if not verify_result["verified"]:
            return await self._handle_verify_failure(
                verify_result, req, login_ip, user_agent, device_type)

        # 4. 密码正确 → 检查是否需要二次验证
        account_id = verify_result["account_id"]

        if verify_result.get("need_mfa"):
            mfa_token = await self._issue_mfa_token(account_id)
            # 记录：需要二次验证（尚未成功）
            await self._record_attempt(
                username=req.username, account_id=account_id,
                login_type="PASSWORD", result="MFA_REQUIRED",
                fail_reason=None,
                login_ip=login_ip, user_agent=user_agent,
                device_type=device_type)
            return {
                "success": False,
                "error_code": "MFA_REQUIRED",
                "error_message": "为保障账号安全，需进行二次验证",
                "mfa_token": mfa_token,
                "mfa_methods": ["SMS", "TOTP"],
                "mfa_phone_mask": verify_result.get("mfa_phone_mask"),
                "expire_in": 300,
            }

        # 5. 检查是否需要强制改密
        if verify_result.get("need_change_password"):
            temp_token = await self._issue_temp_token(
                account_id,
                reason=verify_result.get("change_reason", "FIRST_LOGIN"))
            await self._record_attempt(
                username=req.username, account_id=account_id,
                login_type="PASSWORD", result="NEED_CHANGE_PASSWORD",
                fail_reason=None,
                login_ip=login_ip, user_agent=user_agent,
                device_type=device_type)
            return {
                "success": False,
                "error_code": "NEED_CHANGE_PASSWORD",
                "error_message": "首次登录，请先修改初始密码"
                    if verify_result.get("change_reason") == "FIRST_LOGIN"
                    else "密码已过期，请先修改密码",
                "change_reason": verify_result.get("change_reason"),
                "temp_token": temp_token,
                "expire_in": 300,
                "user": {
                    "username": verify_result["username"],
                    "staff_code": verify_result.get("staff_code"),
                    "staff_name": verify_result.get("staff_name"),
                    "dept_name": verify_result.get("dept_name"),
                },
            }

        # 6. 创建会话 + 签发 Token
        return await self._create_session_and_login(
            verify_result, login_ip, user_agent, device_type,
            login_type="PASSWORD")

    # ---------- 失败处理 ----------
    async def _handle_verify_failure(self, verify_result, req,
                                      login_ip, user_agent, device_type) -> dict:
        """处理凭据校验失败"""
        error_code = verify_result.get("error_code")

        # 账号锁定/停用/过期：可明确提示
        if error_code in ("ACCOUNT_LOCKED", "ACCOUNT_DISABLED",
                           "ACCOUNT_EXPIRED", "ACCOUNT_TERMINATED"):
            await self._record_attempt(
                username=req.username,
                account_id=verify_result.get("account_id"),
                login_type="PASSWORD",
                result=error_code,
                fail_reason=verify_result.get("error_message"),
                login_ip=login_ip, user_agent=user_agent,
                device_type=device_type)
            return {
                "success": False,
                "error_code": error_code,
                "error_message": verify_result.get("error_message"),
                "locked_until": verify_result.get("locked_until"),
            }

        # 密码错误 / 账号不存在：统一提示
        account_id = verify_result.get("account_id")
        if account_id:
            # 记录失败（M02-01 累加计数）
            fail_result = await m01_client.record_fail(
                account_id=account_id,
                login_ip=login_ip,
                user_agent=user_agent,
                reason="BAD_PASSWORD")
            remaining = fail_result.get("remaining_attempts", 0)
            locked = fail_result.get("locked", False)
        else:
            remaining = None
            locked = False

        await self._record_attempt(
            username=req.username,
            account_id=account_id,
            login_type="PASSWORD",
            result="BAD_PASSWORD" if account_id else "NO_ACCOUNT",
            fail_reason="密码错误" if account_id else "账号不存在",
            login_ip=login_ip, user_agent=user_agent,
            device_type=device_type)

        # 统一响应（不泄露账号是否存在）
        message = "登录名或密码错误"
        if locked:
            message = "登录失败次数过多，账号已被锁定"
        elif remaining is not None and remaining <= 2:
            message = f"登录名或密码错误，还可尝试 {remaining} 次"

        return {
            "success": False,
            "error_code": "BAD_CREDENTIAL",
            "error_message": message,
            "remaining_attempts": remaining,
            "captcha_required": True,
        }

    # ---------- 二次验证 ----------
    async def mfa_verify(self, req, request) -> dict:
        """二次验证"""
        # 1. 校验 mfa_token
        payload = await self._decode_temp_token(req.mfa_token, "MFA")
        account_id = payload["account_id"]

        login_ip = self._get_client_ip(request)
        user_agent = request.headers.get("user-agent", "")[:255]
        device_type = self._detect_device(user_agent)

        # 2. 调用 M02-05 校验
        result = await m03_mfa_client.verify(
            account_id=account_id,
            method=req.method,
            code=req.code,
            purpose="LOGIN",
            token_id=req.mfa_token,
        )

        if not result["success"]:
            await self._record_attempt(
                username=payload.get("username"),
                account_id=account_id,
                login_type="PASSWORD",
                result="MFA_FAILED",
                fail_reason=result.get("error_message"),
                login_ip=login_ip, user_agent=user_agent,
                device_type=device_type)
            return {
                "success": False,
                "error_code": "MFA_CODE_INVALID",
                "error_message": result.get("error_message", "验证码错误"),
                "remaining_attempts": result.get("remaining_attempts"),
            }

        # 3. 二次验证通过 → 创建会话
        account = (await self.db.execute(
            select(SysAccount).where(SysAccount.id == account_id)
        )).scalar_one()

        verify_result = {
            "account_id": account.id,
            "username": account.username,
            "staff_id": account.staff_id,
            "staff_code": account.staff_code,
            "staff_name": account.staff_name,
            "dept_id": account.dept_id,
            "dept_name": account.dept_name,
            "account_type": account.account_type,
        }
        return await self._create_session_and_login(
            verify_result, login_ip, user_agent, device_type,
            login_type="PASSWORD", mfa_passed=True)

    # ---------- 创建会话 ----------
    async def _create_session_and_login(self, verify_result, login_ip,
                                          user_agent, device_type,
                                          login_type: str,
                                          mfa_passed: bool = False) -> dict:
        """创建会话、签发 Token、记录成功"""
        account_id = verify_result["account_id"]

        # 1. 调用 M02-03 创建会话
        try:
            session = await m02_session_client.create_session(
                account_id=account_id,
                staff_id=verify_result.get("staff_id"),
                login_ip=login_ip,
                user_agent=user_agent,
                device_type=device_type,
                login_type=login_type,
                mfa_passed=mfa_passed,
            )
        except Exception as e:
            raise BizException("0202034", f"会话创建失败：{str(e)[:100]}")

        # 2. 记录登录成功（M02-01 清零计数）
        await m01_client.record_success(
            account_id=account_id,
            login_ip=login_ip,
            user_agent=user_agent,
            session_id=session["session_id"])

        # 3. 记录登录尝试
        await self._record_attempt(
            username=verify_result["username"],
            account_id=account_id,
            login_type=login_type,
            result="SUCCESS",
            fail_reason=None,
            login_ip=login_ip, user_agent=user_agent,
            device_type=device_type,
            session_id=session["session_id"])

        # 4. 清除 IP 失败计数
        await redis_client.delete(f"sys:login:ipfail:{login_ip}")

        # 5. 获取上次登录信息（本次之前）
        last_login = await self._get_previous_login(account_id)

        # 6. 构造响应
        user = {
            "account_id": account_id,
            "username": verify_result["username"],
            "staff_id": verify_result.get("staff_id"),
            "staff_code": verify_result.get("staff_code"),
            "staff_name": verify_result.get("staff_name"),
            "dept_id": verify_result.get("dept_id"),
            "dept_name": verify_result.get("dept_name"),
            "account_type": verify_result.get("account_type"),
        }

        return {
            "success": True,
            "access_token": session["access_token"],
            "refresh_token": session["refresh_token"],
            "token_type": "Bearer",
            "expires_in": session["expires_in"],
            "refresh_expires_in": session["refresh_expires_in"],
            "session_id": session["session_id"],
            "user": user,
            "last_login": last_login,
            "password_warn_days": verify_result.get("password_expire_in_days"),
            "must_change_password": False,
        }

    # ---------- 强制改密 ----------
    async def change_password_login(self, req, authorization: str,
                                      request) -> dict:
        """强制改密后登录"""
        token = authorization.replace("Temp ", "").strip()
        payload = await self._decode_temp_token(token, "PASSWORD_CHANGE")
        account_id = payload["account_id"]

        # 1. 两次一致
        if req.new_password != req.confirm_password:

        # 2. 调用 M02-01 校验原密码 + 改密
        result = await m01_client.change_password_by_temp(

            old_password=req.old_password,
            new_password=req.new_password)
        if not result["success"]:
            return {
                "success": False,
                "error_code": result.get("error_code", "CHANGE_FAILED"),
                "error_message": result.get("error_message", "修改密码失败"),
            }

        # 3. 改密成功 → 创建会话
        login_ip = self._get_client_ip(request)
        user_agent = request.headers.get("user-agent", "")[:255]
        device_type = self._detect_device(user_agent)

        verify_result = {
            "account_id": account_id,

        return resp

    # ---------- IP 限流 ----------
    async def check_ip_limit(self, login_ip: str) -> dict:
        """检查 IP 登录限制"""
        config = await self.get_config()
        limit = config["ip_fail_limit"]
        window = config["ip_fail_window_min"]

        key = f"sys:login:ipfail:{login_ip}"
        fail_count = int(await redis_client.get(key) or 0)

        if fail_count >= limit:
            ttl = await redis_client.ttl(key)
            return {
                "allowed": False,
                "reason": "IP_LOGIN_LIMIT",
                "fail_count_1h": fail_count,
                "limit": limit,
                "blocked_until": (datetime.now()
                                   + timedelta(seconds=max(0, ttl))).isoformat(),
            }
        return {"allowed": True, "fail_count_1h": fail_count, "limit": limit}

    async def _incr_ip_fail(self, login_ip: str) -> None:
        """增加 IP 失败计数"""
        config = await self.get_config()
        key = f"sys:login:ipfail:{login_ip}"
        count = await redis_client.incr(key)
        if count == 1:
            await redis_client.expire(key, config["ip_fail_window_min"] * 60)

    # ---------- 临时令牌 ----------
    async def _issue_mfa_token(self, account_id: int) -> str:
        """签发二次验证临时令牌"""
        token = f"mfa_{uuid.uuid4().hex[:16]}"
        await redis_client.setex(

    async def _decode_temp_token(self, token: str, purpose: str) -> dict:
        """解析临时令牌"""
        key = f"sys:token:{'mfa' if purpose == 'MFA' else 'tmp'}:{token}"
        val = await redis_client.get(key)
        if not val:
            raise BizException("0202013" if purpose == "MFA" else 52017,
                                "临时令牌无效或已过期")
        account_id = int(val)
        account = (await self.db.execute(
            select(SysAccount).where(SysAccount.id == account_id)
        )).scalar_one_or_none()
        if not account:
            raise BizException("0202013", "账号不存在")
        return {
            "account_id": account.id,
            "username": account.username,
            "staff_id": account.staff_id,
            "staff_code": account.staff_code,
            "staff_name": account.staff_name,
            "dept_id": account.dept_id,
            "dept_name": account.dept_name,
            "account_type": account.account_type,
        }

    # ---------- 记录 ----------
    async def _record_attempt(self, username: str, account_id: Optional[int],

                                fail_reason: Optional[str],
                                login_ip: str, user_agent: str,
                                device_type: str,
                                session_id: Optional[str] = None) -> None:
        """记录登录尝试"""
        self.db.add(SysLoginAttempt(
            username=username,
            account_id=account_id,
            login_type=login_type,
            attempt_result=result,
            fail_reason=fail_reason,
            login_ip=login_ip,
            ip_location=self._get_ip_location(login_ip),
            user_agent=user_agent,
            device_type=device_type,
            session_id=session_id,
        ))
        await self.db.commit()

        # 失败时累加 IP 计数
        if result not in ("SUCCESS", "MFA_REQUIRED", "NEED_CHANGE_PASSWORD"):
            await self._incr_ip_fail(login_ip)

    async def _get_previous_login(self, account_id: int) -> Optional[dict]:
        """获取上一次成功登录"""
        row = (await self.db.execute(
            select(SysLoginAttempt)
            .where(
                SysLoginAttempt.account_id == account_id,
                SysLoginAttempt.attempt_result == "SUCCESS")
            .order_by(SysLoginAttempt.created_at.desc())
            .offset(1)   # 跳过本次
            .limit(1)
        )).scalar_one_or_none()
        if not row:
            return None
        return {
            "time": row.created_at.isoformat(),
            "ip": row.login_ip,
            "location": row.ip_location,
        }

    # ---------- 工具 ----------
    @staticmethod
    def _get_client_ip(request) -> str:
        """获取客户端 IP（支持代理）"""
        xff = request.headers.get("x-forwarded-for")
        if xff:
            return xff.split(",")[0].strip()
        xri = request.headers.get("x-real-ip")
        if xri:
            return xri
        return request.client.host if request.client else "unknown"

    @staticmethod
    def _detect_device(ua: str) -> str:
        """识别设备类型"""
        ua_lower = (ua or "").lower()
        if any(k in ua_lower for k in ("python", "curl", "postman", "java/", "okhttp")):
            return "API"
        if "mobile" in ua_lower or "android" in ua_lower or "iphone" in ua_lower:
            return "MOBILE"
        if "ipad" in ua_lower or "tablet" in ua_lower:
            return "TABLET"
        return "PC"

    @staticmethod
    def _get_ip_location(ip: str) -> str:
        """IP 归属地（简化：内网判定）"""
        if ip.startswith(("192.168.", "10.", "172.16.", "172.17.",
                           "172.18.", "172.19.", "172.2", "172.30.",
                           "172.31.", "127.")):
            return "院内网络"
        return "外部网络"

        """登出"""
        session_id = getattr(user, "session_id", None)
        if session_id:
            await m02_session_client.revoke_session(session_id, reason="LOGOUT")
        return {"success": True, "message": "已安全退出"}
```

```python
# app/services/auth/captcha_service.py
"""图形验证码服务"""
import io
import random
import string
import uuid
import base64
from typing import Optional

from PIL import Image, ImageDraw, ImageFont, ImageFilter
from sqlalchemy.ext.asyncio import AsyncSession

from app.core.redis import redis_client


# 去除易混淆字符
CAPTCHA_CHARS = "ABCDEFGHJKLMNPQRSTUVWXYZ23456789"


class CaptchaService:
    def __init__(self, db: AsyncSession):
        self.db = db

    async def generate(self, length: int = 4,
                        ttl: int = 120) -> dict:
        """生成验证码"""
        code = "".join(random.choice(CAPTCHA_CHARS) for _ in range(length))
        captcha_id = f"cap_{uuid.uuid4().hex[:12]}"

        # 存 Redis（小写，校验时统一小写比对）
        await redis_client.setex(
            f"sys:captcha:{captcha_id}", ttl, code.lower())

        # 生成图片
        image = self._render(code)

        return {
            "captcha_id": captcha_id,
            "captcha_image": f"data:image/png;base64,{image}",
            "expire_in": ttl,
            "width": 120,
            "height": 40,
        }

    async def verify(self, captcha_id: str, captcha_code: str,
                      consume: bool = True) -> bool:
        """校验验证码"""
        if not captcha_id or not captcha_code:
            return False

        key = f"sys:captcha:{captcha_id}"
        expected = await redis_client.get(key)

        if consume:
            await redis_client.delete(key)

        if not expected:
            return False

        # 兼容 bytes
        if isinstance(expected, bytes):
            expected = expected.decode()
        return expected.strip().lower() == captcha_code.strip().lower()

    @staticmethod
    def _render(code: str) -> str:
        """渲染验证码图片，返回 base64"""
        width, height = 120, 40
        image = Image.new("RGB", (width, height), (245, 247, 250))
        draw = ImageDraw.Draw(image)

        # 字体（优先使用系统字体，失败则用默认）
        try:
            font = ImageFont.truetype("/usr/share/fonts/dejavu/DejaVuSans-Bold.ttf", 26)
        except Exception:
            font = ImageFont.load_default()

        # 干扰线
        for _ in range(4):
            x1 = random.randint(0, width)
            y1 = random.randint(0, height)
            x2 = random.randint(0, width)
            y2 = random.randint(0, height)
            draw.line(
                [(x1, y1), (x2, y2)],
                fill=(random.randint(150, 200),
                      random.randint(150, 200),
                      random.randint(150, 200)),
                width=1)

        # 噪点
        for _ in range(60):
            draw.point(
                (random.randint(0, width), random.randint(0, height)),
                fill=(random.randint(100, 200),
                      random.randint(100, 200),
                      random.randint(100, 200)))

        # 字符
        for i, ch in enumerate(code):
            x = 12 + i * 26
            y = random.randint(4, 10)
            draw.text(
                (x, y), ch, font=font,
                fill=(random.randint(20, 90),
                      random.randint(20, 90),
                      random.randint(20, 90)))

        # 轻微模糊
        image = image.filter(ImageFilter.SMOOTH)

        buffer = io.BytesIO()
        image.save(buffer, format="PNG")
        return base64.b64encode(buffer.getvalue()).decode()
```

## 7. 缓存与异步任务设计

### 7.1 Redis 缓存设计

| Key 模式 | 类型 | TTL | 说明 | 失效时机 |
|---|---|---|---|---|
| `sys:captcha:{captcha_id}` | String | 120s | 图形验证码答案 | 校验后删除 |
| `sys:token:mfa:{token}` | String(account_id) | 300s | 二次验证临时令牌 | 验证后删除 |
| `sys:token:tmp:{token}` | String(account_id) | 300s | 改密临时令牌 | 改密后删除 |
| `sys:login:ipfail:{ip}` | String(计数) | 60min | IP 失败计数 | 成功登录清零 |

```python
# app/tasks/auth/login_jobs.py
"""登录定时任务"""
from apscheduler.schedulers.asyncio import AsyncIOScheduler
from apscheduler.triggers.cron import CronTrigger

scheduler = AsyncIOScheduler(timezone="Asia/Shanghai")

scheduler.add_job(
    alert_abnormal_login,
    CronTrigger(minute=0),
    id="job_login_abnormal_alert",
    name="异常登录告警",
    replace_existing=True,
)


async def alert_abnormal_login():
    """每小时检查异常登录并告警"""
    from datetime import datetime, timedelta
    from sqlalchemy import select, func
    from app.models.sys.account import SysLoginAttempt
    from app.core.database import AsyncSessionLocal
    from app.services.notify_service import NotifyService

    async with AsyncSessionLocal() as db:
        since = datetime.now() - timedelta(hours=1)

        # 1. 境外 IP 登录尝试
        abroad = (await db.execute(
            select(SysLoginAttempt)
            .where(
                SysLoginAttempt.created_at >= since,
                SysLoginAttempt.ip_location == "外部网络",
                SysLoginAttempt.attempt_result != "SUCCESS")
            .limit(100)
        )).scalars().all()

        # 2. 单 IP 高频失败
        ip_fails = (await db.execute(
            select(
                SysLoginAttempt.login_ip,
                func.count().label("cnt"))
            .where(
                SysLoginAttempt.created_at >= since,
                SysLoginAttempt.attempt_result.in_(
                    ["BAD_PASSWORD", "NO_ACCOUNT", "BAD_CREDENTIAL"]))
            .group_by(SysLoginAttempt.login_ip)
            .having(func.count() >= 10)
        )).all()

        # 3. 单账号高频失败
        acc_fails = (await db.execute(
            select(
                SysLoginAttempt.account_id,
                func.count().label("cnt"))
            .where(
                SysLoginAttempt.created_at >= since,
                SysLoginAttempt.account_id.isnot(None),
                SysLoginAttempt.attempt_result == "BAD_PASSWORD")
            .group_by(SysLoginAttempt.account_id)
            .having(func.count() >= 5)
        )).all()

        alerts = []
        if abroad:
            alerts.append(f"{len(abroad)} 次外部网络登录失败")
        if ip_fails:
            alerts.append(f"{len(ip_fails)} 个 IP 高频失败")
        if acc_fails:
            alerts.append(f"{len(acc_fails)} 个账号高频失败")

        if alerts:
            await NotifyService().send(
                template="LOGIN_ABNORMAL_ALERT",
                receivers=await get_it_managers(),
                params={"summary": "；".join(alerts),
                        "detail": {
                            "abroad_count": len(abroad),
                            "ip_fails": [{"ip": r[0], "count": r[1]}
                                          for r in ip_fails[:10]],
                            "acc_fails": [{"account_id": r[0], "count": r[1]}
                                           for r in acc_fails[:10]],
                        }})
        return {"abroad": len(abroad), "ip_fails": len(ip_fails),
                "acc_fails": len(acc_fails)}
```

| SC-03 | 时序攻击 | 响应时间差 <50ms |

| SC-07 | 临时令牌越权 | 不可访问业务接口 |
