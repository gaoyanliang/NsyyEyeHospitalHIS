```
运行时缓存（Redis，非表）：
  sys:perm:ctx:{staff_id}      权限上下文 8KB × 400 = 3.2MB
```

**设计说明：**

- 本模块**不重复定义**角色/权限/菜单表（那是 M01 的职责）
- 本模块只维护**运行时所需的支撑数据**：配置、映射、白名单、日志、统计
- 权限上下文**不进数据库**，放 Redis（高读、短生命周期）

**索引：** `uk_perm_api(http_method, api_path)` 唯一；`idx_perm_api_declared(declared, is_active)`；`idx_perm_api_module(module, declared)`；`idx_perm_api_code(perm_code)`；`idx_perm_api_calls(call_count_7d DESC)`。

**说明：**

- 启动时扫描全部路由自动同步（FastAPI `app.routes`）
- `declared=false` 且 `is_whitelisted=false` → **告警**（存在越权风险）
- `perm_code` 从装饰器 `@require_permission(...)` 中提取
- 统计字段由定时任务更新

**自动同步逻辑：**

```python
async def sync_api_mappings(app):
    """启动时扫描路由，同步接口映射"""
    for route in app.routes:
        if not hasattr(route, "methods"):
            continue
        for method in route.methods:
            if method in ("HEAD", "OPTIONS"):
                continue

            # 从路由依赖中提取 perm_code
            perm_code = extract_perm_code(route)
            whitelisted = is_whitelisted(method, route.path)

            await upsert_mapping(
                http_method=method,
                api_path=route.path,
                perm_code=perm_code,
                declared=perm_code is not None,
                is_whitelisted=whitelisted,
                handler_name=route.endpoint.__name__,
            )
```

### 4.8 SQLAlchemy 2.0 模型定义

```python
# app/models/perm/runtime.py
"""权限运行时引擎 ORM 模型"""
from datetime import date, datetime
from decimal import Decimal
from typing import Optional

from sqlalchemy import (
    BigInteger, String, Integer, SmallInteger, Boolean, Date, DateTime,
    Numeric, Index, UniqueConstraint, func,
)
from sqlalchemy.orm import Mapped, mapped_column

from app.models.base import Base


class SysPermConfig(Base):
    """权限引擎配置（单行）"""
    __tablename__ = "sys_perm_config"

    id: Mapped[int] = mapped_column(BigInteger, primary_key=True, autoincrement=True)

    # 缓存
    enable_cache: Mapped[bool] = mapped_column(Boolean, default=True, nullable=False)
    cache_ttl_seconds: Mapped[int] = mapped_column(Integer, default=300, nullable=False)
    degrade_ttl_seconds: Mapped[int] = mapped_column(Integer, default=1800, nullable=False)
    enable_dept_tree_cache: Mapped[bool] = mapped_column(Boolean, default=True, nullable=False)
    dept_tree_ttl: Mapped[int] = mapped_column(Integer, default=3600, nullable=False)

    # 鉴权
    deny_unmapped_api: Mapped[bool] = mapped_column(Boolean, default=True, nullable=False)
    default_scope_type: Mapped[str] = mapped_column(
        String(16), default="SELF", nullable=False)
    enable_field_mask: Mapped[bool] = mapped_column(Boolean, default=True, nullable=False)
    enable_wildcard: Mapped[bool] = mapped_column(Boolean, default=True, nullable=False)
    max_wildcard_count: Mapped[int] = mapped_column(Integer, default=50, nullable=False)

    # 日志
    log_allowed: Mapped[bool] = mapped_column(Boolean, default=True, nullable=False)
    log_sample_rate: Mapped[int] = mapped_column(Integer, default=100, nullable=False)
    slow_check_ms: Mapped[int] = mapped_column(Integer, default=100, nullable=False)
    notify_deny_threshold: Mapped[int] = mapped_column(Integer, default=50, nullable=False)

    # 其他
    enable_simulate: Mapped[bool] = mapped_column(Boolean, default=True, nullable=False)
    enable_degrade: Mapped[bool] = mapped_column(Boolean, default=True, nullable=False)

    version_no: Mapped[int] = mapped_column(Integer, default=1, nullable=False)
    updated_by: Mapped[Optional[int]] = mapped_column(BigInteger)
    updated_by_name: Mapped[Optional[str]] = mapped_column(String(64))
    updated_at: Mapped[Optional[datetime]] = mapped_column(
        DateTime, server_default=func.now(), onupdate=func.now())

    is_builtin: Mapped[bool] = mapped_column(Boolean, default=False, nullable=False)
    is_enabled: Mapped[bool] = mapped_column(Boolean, default=True, nullable=False)
    env_limit: Mapped[str] = mapped_column(String(32), default="ALL", nullable=False)
    sort_no: Mapped[int] = mapped_column(Integer, default=999, nullable=False)
    created_by: Mapped[Optional[int]] = mapped_column(BigInteger)
    created_by_name: Mapped[Optional[str]] = mapped_column(String(64))
    created_at: Mapped[datetime] = mapped_column(DateTime, server_default=func.now())
    updated_at: Mapped[Optional[datetime]] = mapped_column(
        DateTime, server_default=func.now(), onupdate=func.now())

    __table_args__ = (
        UniqueConstraint("http_method", "path_pattern", name="uk_whitelist"),
        Index("idx_whitelist_enabled", "is_enabled", "env_limit"),
        {"comment": "免鉴权白名单"},
    )

    def matches(self, method: str, path: str, env: str = "PROD") -> bool:
        """判断是否匹配"""
        if not self.is_enabled:
            return False
        if self.env_limit != "ALL" and self.env_limit != env:
            return False
        if self.http_method != "*" and self.http_method != method:
            return False

        if self.match_type == "EXACT":
            return path == self.path_pattern
        if self.match_type == "PREFIX":
            pattern = self.path_pattern
            if pattern.endswith("**"):
                return path.startswith(pattern[:-2])
            if pattern.endswith("*"):
                return path.startswith(pattern[:-1])
            return path.startswith(pattern)
        if self.match_type == "REGEX":
            import re
            try:
                return bool(re.match(self.path_pattern, path))
            except re.error:
                return False
        return False
```
