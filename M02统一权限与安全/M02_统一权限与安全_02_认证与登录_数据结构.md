```
└──────────────────────────────┘
```

**设计说明：**

- `sys_login_config` 为**单行配置表**（`id=1`），全院统一
- `sys_login_method` 定义可用的登录方式及开关
- `sys_sms_code` 记录短信验证码（哈希存储），用于审计与问题排查
- `sys_qrcode_session` 记录扫码登录会话，用于状态机管理
- `sys_login_fail_lock` 记录账号/IP/组合维度的失败锁定（Redis 为主，DB 兜底）
- `sys_sso_config` 为预留表，本期不实现
- `sys_login_statistics` 为按日聚合的统计表，避免每次查明细

### 4.9 SQLAlchemy 2.0 模型定义

```python
# app/models/sys/login.py
"""认证与登录 ORM 模型"""
from datetime import date, datetime
from typing import Optional, List

from sqlalchemy import (
    BigInteger, String, Integer, SmallInteger, Boolean, Date, DateTime,
    Text, Index, UniqueConstraint, func,
)
from sqlalchemy.orm import Mapped, mapped_column

from app.models.base import Base


class SysLoginConfig(Base):
    """登录配置（单行）"""
    __tablename__ = "sys_login_config"

    id: Mapped[int] = mapped_column(BigInteger, primary_key=True, autoincrement=True)

    # 验证码
    captcha_enabled: Mapped[bool] = mapped_column(Boolean, default=True, nullable=False)
    captcha_always: Mapped[bool] = mapped_column(Boolean, default=True, nullable=False)
    captcha_ttl: Mapped[int] = mapped_column(Integer, default=120, nullable=False)

    # 登录方式开关
    password_enabled: Mapped[bool] = mapped_column(Boolean, default=True, nullable=False)
    sms_enabled: Mapped[bool] = mapped_column(Boolean, default=True, nullable=False)
    qrcode_enabled: Mapped[bool] = mapped_column(Boolean, default=True, nullable=False)
    sso_enabled: Mapped[bool] = mapped_column(Boolean, default=False, nullable=False)
    ca_enabled: Mapped[bool] = mapped_column(Boolean, default=False, nullable=False)

    # 失败锁定
    account_fail_limit: Mapped[int] = mapped_column(Integer, default=5, nullable=False)
    account_lock_minutes: Mapped[int] = mapped_column(Integer, default=30, nullable=False)
    ip_fail_limit: Mapped[int] = mapped_column(Integer, default=20, nullable=False)
    ip_fail_window_min: Mapped[int] = mapped_column(Integer, default=60, nullable=False)
    combo_fail_limit: Mapped[int] = mapped_column(Integer, default=10, nullable=False)
    combo_fail_window_min: Mapped[int] = mapped_column(Integer, default=30, nullable=False)

    # 短信
    sms_code_ttl: Mapped[int] = mapped_column(Integer, default=300, nullable=False)
    sms_max_verify: Mapped[int] = mapped_column(Integer, default=5, nullable=False)

    def is_time_allowed(self, now: Optional[datetime] = None) -> bool:
        """是否在允许登录时段内"""
        if not self.allowed_login_hours:
            return True
        now = now or datetime.now()
        hhmm = now.strftime("%H:%M")
        try:
            start, end = self.allowed_login_hours.split("-")
            if start <= end:
                return start <= hhmm <= end
            # 跨天（如 22:00-06:00）
            return hhmm >= start or hhmm <= end
        except ValueError:
            return True
```
