## 1. 模块概述

### 1.1 模块定位

权限运行时引擎是 M02 的**价值核心**，也是本次 M02 设计的**最关键子模块**。

M01 权限子模块已经定义了"**谁有什么权限**"（数据）；本子模块负责"**每次请求时如何高效、准确地判断**"（执行）。

```
请求到达
   ↓
┌──────────────────────────────────────────────────────────────┐
│ M02-03 Token 校验 → 得到 { account_id, staff_id, dept_id }   │
└──────────────────────────┬───────────────────────────────────┘
                           ↓
┌──────────────────────────────────────────────────────────────┐
│ M02-04 权限运行时引擎（本文档）                                │
│                                                               │
│  ① 取权限上下文（缓存优先，M01 为权威源）                       │
│     { roles, perm_codes, menus, data_scopes, field_rules }    │
│                                                               │
│  ② 功能权限判定                                                │
│     perm_code 是否在 perm_codes 中？                           │
│                                                               │
│  ③ 数据权限注入（SQL 层）                                       │
│     按数据域生成 WHERE 条件                                   │
│                                                               │
│  ④ 字段权限处理（响应层）                                       │
│     按规则脱敏 / 隐藏 / 触发二次验证                            │
│                                                               │
│  ⑤ 记录审计                                                   │
└──────────────────────────┬───────────────────────────────────┘
                           ↓
                    业务逻辑执行
```

| 职责 | 归属 |
|---|---|
| 菜单/角色/权限定义（`mdm_*` 表） | **M01 权限子模块** |
| 数据范围与字段规则**定义** | **M01 权限子模块** |
| 权限上下文**计算**（组装） | **M01 权限子模块**（提供接口） |
| **权限上下文缓存** | **M02-04 本子模块** |
| **功能权限判定** | **M02-04 本子模块** |
| **数据权限 SQL 注入** | **M02-04 本子模块** |
| **字段权限脱敏执行** | **M02-04 本子模块** |
| **鉴权装饰器/依赖注入** | **M02-04 本子模块** |
| **鉴权失败处理** | **M02-04 本子模块** |
| 身份解析 | M02-03 |
| 二次验证触发 | M02-05（本模块只返回"需要"） |
| 审计存储 | M02-06 |

> **一句话边界**：M01 回答"**规则是什么**"，M02-04 回答"**这次请求过不过**"，并**把规则翻译成 SQL 与响应处理**。

### 1.2 为什么这是最关键的子模块

**全院 M03~M23 共 21 个模块、预计 3,000+ 个接口，每一个都要经过本子模块。**

| 影响面 | 说明 |
|---|---|
| **安全性** | 一旦有接口绕过鉴权，整个系统失守 |
| **性能** | 每个请求都要判定，P95 每增加 1ms，全院放大数百倍 |
| **可用性** | 引擎故障 = 全院不可用（比数据库故障影响更大） |
| **正确性** | 数据权限写错 → 医生看到其他科室患者（医疗隐私事故） |

因此本子模块的设计必须做到：
- **零遗漏**：默认拒绝（Deny by Default），宁可误拒不可误放
- **高性能**：权限上下文缓存，判定 O(1)
- **高可用**：M01 不可用时降级到缓存，缓存失效才拒绝
- **可测试**：提供权限模拟器，验证任意用户 × 任意接口的结果

### 1.3 模块目标

- **默认拒绝**：未显式授权的接口一律拒绝。
- **单点鉴权**：所有接口通过统一装饰器，不允许手写判断。
- **缓存优先**：权限上下文缓存 5 分钟，判定 O(1)，P95 ≤ 10ms。
- **数据隔离**：五种数据范围自动翻译为 SQL 条件，杜绝越权查询。
- **字段脱敏**：敏感字段按规则自动处理，业务代码无需关心。
- **权限版本**：权限变更后缓存主动失效，无需等待 TTL。
- **可观测**：每次鉴权结果可查，拒绝原因明确。
- **可模拟**：提供权限模拟器，便于验证与排障。

### 1.4 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 全部系统用户 | 使用 | 无感（引擎自动工作） |
| 系统管理员 | 运维 | 查看鉴权日志、清理缓存 |
| 信息科长 | 配置 | 配置免鉴权白名单、降级策略 |
| 审计员 | 追溯 | 查看越权尝试记录 |
| 开发人员 | 接入 | 使用装饰器、权限模拟器 |

## 3. 权限运行时模型

### 3.1 权限上下文结构

```json
{
  "staff_id": 1024,
  "account_id": 1024,
  "username": "wangwu",
  "staff_name": "王五",
  "dept_id": 15,
  "dept_name": "白内障科",
  "dept_path": "/1/5/15/",
  "org_id": 1,

  "roles": [
    { "role_id": 12, "role_code": "R012", "role_name": "科主任", "dept_id": 15 },
    { "role_id": 8, "role_code": "R008", "role_name": "眼科医师", "dept_id": 15 }
  ],

  "perm_codes": [
    "mdm:drug:list", "mdm:drug:view",
    "m05:register:create", "m05:register:cancel",
    "m05:emr:write", "m16:refund:apply"
  ],

  "data_scopes": {
    "DEPT":      { "scope_type": "DEPT_TREE", "dept_ids": [15, 16, 17] },
    "DOCTOR":    { "scope_type": "DEPT_TREE", "dept_ids": [15, 16, 17] },
    "PATIENT":   { "scope_type": "DEPT_TREE", "dept_ids": [15, 16, 17] },
    "WAREHOUSE": { "scope_type": "SELF", "staff_id": 1024 },
    "ORG":       { "scope_type": "ALL" }
  },

  "field_rules": {
    "patient.id_card":  { "action": "MASKED", "mask_rule": "ID_CARD", "need_second_factor": true },
    "patient.mobile":   { "action": "MASKED", "mask_rule": "MOBILE", "need_second_factor": false },
    "staff.bank_account": { "action": "HIDDEN" },
    "drug.cost_price":  { "action": "VISIBLE" }
  },

  "second_factor_ops": [
    "m09:surgery:approve",
    "m16:refund:approve",
    "mdm:drug:price:update"
  ],

  "menu_version": "v2:20260401-102345",
  "computed_at": "2026-04-01T10:23:45+08:00"
}
```

**关键设计：**

| 设计 | 理由 |
|---|---|
| `perm_codes` 用**扁平数组**而非树 | 判定时用 Set，O(1) 而非 O(n) 遍历 |
| `data_scopes` 按**数据域**分组 | 同一用户对科室数据和仓库数据可能范围不同 |
| `field_rules` 用**字段键**索引 | 脱敏时按字段名直接查 |
| `second_factor_ops` 单独列表 | 二次验证判定独立于功能权限 |
| 含 `menu_version` | 用于缓存失效判断 |

### 3.2 功能权限判定模型

#### 3.2.1 权限编码规范

```
{module}:{resource}:{action}

示例：
mdm:drug:list        主数据-药品-查询
mdm:drug:create      主数据-药品-新增
m16:refund:approve   M16收费-退费-审批
sys:account:reset    M02系统-账号-重置密码
```

| 段 | 说明 | 取值 |
|---|---|---|
| `module` | 模块代码 | `mdm`/`m03`~`m23`/`sys` |
| `resource` | 资源 | 表名或业务对象 |
| `action` | 操作 | `list`/`view`/`create`/`update`/`delete`/`approve`/`export`/`print`/`import` |

#### 3.2.2 判定算法

```
输入：staff_id, perm_code, context
    ↓
1. 取权限上下文（缓存或 M01）
    ↓
2. 超级管理员？ → 直接通过
   （role_code = R001 或 account_type = SUPER_ADMIN）
    ↓
3. perm_code ∈ perm_codes？（Set 查找 O(1)）
   ├─ 是 → 通过
   └─ 否 → 拒绝
    ↓
4. 通过后：是否需要二次验证？
   perm_code ∈ second_factor_ops？
   ├─ 是 → 返回 NEED_SECOND_FACTOR
   └─ 否 → 完全通过
```

#### 3.2.3 权限通配符

支持**有限的通配符**（避免过度授权）：

| 形式 | 说明 | 示例 |
|---|---|---|
| `*` | 全部权限（仅超管） | 不授予普通角色 |
| `mdm:*` | 某模块全部 | 谨慎授予 |
| `mdm:drug:*` | 某资源全部 | 常见 |
| `mdm:drug:list` | 精确 | 最常用 |

**匹配规则：** 授权侧可使用通配符，请求侧永远是精确码。

```
授权了 "mdm:drug:*"
请求 "mdm:drug:list"   → 通过
请求 "mdm:drug:create" → 通过
请求 "mdm:material:list" → 拒绝
```

### 3.3 数据权限模型

#### 3.3.1 五种数据范围

| `scope_type` | 名称 | SQL 条件 |
|---|---|---|
| `ALL` | 全院 | 无条件 |
| `DEPT` | 本科室 | `{field} = :current_dept_id` |
| `DEPT_TREE` | 本科室及下级 | `{field} IN (:dept_ids)` |
| `SELF` | 本人 | `{field} = :current_staff_id` |
| `CUSTOM` | 自定义 | `{field} IN (:custom_ids)` |

#### 3.3.2 数据域与隔离字段

| 数据域 | 隔离字段 | 说明 |
|---|---|---|
| `DEPT` | `dept_id` | 按科室隔离 |
| `DOCTOR` | `doctor_id` | 按医生隔离 |
| `NURSE` | `nurse_id` | 按护士隔离 |
| `PATIENT` | `patient_id` | 按患者隔离 |
| `WAREHOUSE` | `warehouse_id` | 按仓库隔离 |
| `ORG` | `org_id` | 按院区隔离 |
| `SELF_CREATED` | `created_by` | 按创建人隔离 |

#### 3.3.3 多角色合并规则

**同一数据域取最宽范围：**

```
优先级：ALL > CUSTOM(超集) > DEPT_TREE > DEPT > SELF
```

**示例：**

```
用户角色：
  · 科主任 → DEPT 域: DEPT_TREE
  · 眼科医师 → DEPT 域: SELF

合并结果：DEPT 域 = DEPT_TREE（更宽）
```

**合并算法：**

```python
PRIORITY = {"ALL": 100, "CUSTOM": 80, "DEPT_TREE": 60, "DEPT": 40, "SELF": 20}

def merge_scopes(scopes: list) -> dict:
    """多角色数据范围合并，取最宽"""
    best = {}
    for s in scopes:
        domain = s["domain"]
        if domain not in best:
            best[domain] = s
        elif PRIORITY[s["scope_type"]] > PRIORITY[best[domain]["scope_type"]]:
            best[domain] = s
        elif PRIORITY[s["scope_type"]] == PRIORITY[best[domain]["scope_type"]]:
            # 同级取并集
            if s["scope_type"] == "CUSTOM":
                best[domain]["ids"] = list(set(best[domain]["ids"]) | set(s["ids"]))
    return best
```

#### 3.3.4 数据权限注入方式

**方式 A：SQL 条件注入（推荐）**

```python
# 业务代码
stmt = select(Patient).where(Patient.status == "ACTIVE")
stmt = apply_data_scope(stmt, Patient, user, domain="DEPT")
# → 自动追加 WHERE dept_id IN (15, 16, 17)
```

**方式 B：装饰器自动注入**

```python
@router.get("/patients")
@require_permission("m03:patient:list")
@apply_data_scope(model=Patient, domain="DEPT")
async def list_patients(user=Depends(get_current_user)):
    # 无需手写数据范围条件
    ...
```

**方式 C：后置过滤（仅小数据量）**

```python
items = await fetch_all()
items = [i for i in items if can_access(user, i)]
```

> **规范**：**必须使用方式 A 或 B**，禁止方式 C（性能差且易遗漏）。代码审查必查。

### 3.4 字段权限模型

#### 3.4.1 字段动作

| `action` | 说明 | 响应表现 |
|---|---|---|
| `VISIBLE` | 可见 | 原值 |
| `MASKED` | 脱敏 | 按 `mask_rule` 处理 |
| `HIDDEN` | 隐藏 | 字段不返回 |
| `ENCRYPTED` | 加密 | 返回密文（极少用） |

#### 3.4.2 脱敏规则

| `mask_rule` | 说明 | 示例输入 | 输出 |
|---|---|---|---|
| `ID_CARD` | 身份证 | `330102199001011234` | `3301**********1234` |
| `MOBILE` | 手机号 | `13812345678` | `138****5678` |
| `NAME` | 姓名 | `王小明` | `王*明` |
| `BANK` | 银行账号 | `6222021234567890123` | `**** **** **** **** 0123` |
| `ADDRESS` | 地址 | `北京市朝阳区XX路1号` | `北京市朝阳区****` |
| `EMAIL` | 邮箱 | `wangwu@hospital.com` | `w****@hospital.com` |
| `CUSTOM` | 自定义 | — | 按 `mask_expr` |

#### 3.4.3 字段权限处理时机

**关键设计：在序列化层处理，业务代码无感知。**

```python
# 业务代码
patient = await get_patient(empi_id)
return success_response(patient)   # 不关心脱敏

# 引擎自动处理
# 1. 从 user 取 field_rules
# 2. 按规则处理响应字段
# 3. 返回脱敏后的数据
```

**实现：** 在 `response` 中间件或 Pydantic 序列化钩子中处理。

#### 3.4.4 需要二次验证的字段

部分敏感字段（如身份证明文）允许有权限的用户查看，但需二次验证：

```
用户请求 → 字段规则 need_second_factor=true
   ↓
已在本会话通过二次验证？
   ├─ 是 → 返回明文
   └─ 否 → 返回脱敏值 + hint "查看明文需二次验证"
```

### 3.5 鉴权执行流程

```
请求进入
   ↓
① 从 Header 提取 Token
   ├─ 无 Token → 免鉴权接口？ → 是则放行，否则 401
   └─ 有 Token → 继续
   ↓
② 调用 M02-03 validate
   ├─ 无效 → 401
   └─ 有效 → 得到 user 身份
   ↓
③ 匹配接口所需权限
   ├─ 路由在白名单 → 放行
   ├─ 路由有 @require_permission → 取 perm_code
   └─ 路由无声明 → **拒绝**（默认拒绝原则）
   ↓
④ 取权限上下文（缓存 → M01）
   ├─ 超管 → 通过
   ├─ perm_code ∈ perm_codes → 通过
   └─ 否则 → 403
   ↓
⑤ 需要二次验证？
   perm_code ∈ second_factor_ops？
   ├─ 是且本会话未验证 → 428 NEED_SECOND_FACTOR
   └─ 否/已验证 → 继续
   ↓
⑥ 记录鉴权日志（拒绝必记，通过按采样）
   ↓
业务逻辑
```

### 3.6 权限缓存模型

#### 3.6.1 缓存层次

| 层 | 位置 | TTL | 命中率 |
|---|---|---|---|
| L1 | 进程内存（可选） | 30s | 高（热点用户） |
| L2 | Redis | 5min | 很高 |
| L3 | M01 接口 | — | 兜底 |

> **本期只实现 L2 + L3**，L1 视压测结果再定。

#### 3.6.2 缓存键

| Key | 值 | TTL |
|---|---|---|
| `sys:perm:ctx:{staff_id}` | 权限上下文 JSON | 300s |
| `sys:perm:version` | 全局权限版本 | 永久（主动更新） |
| `sys:perm:role_version` | 角色版本（按角色） | 永久 |
| `sys:perm:ctx:version:{staff_id}` | 该用户缓存的版本 | 300s |
| `sys:perm:wildcard:{staff_id}` | 通配符权限集 | 300s |

#### 3.6.3 缓存失效策略

**主动失效（首选）：**

```
M01 权限变更
   ↓
发布事件 sys.permission.changed { role_ids, staff_ids }
   ↓
M02-04 订阅
   ├─ 按 staff_ids 精确失效
   └─ 按 role_ids 找出关联用户批量失效
   ↓
更新 sys:perm:version
```

**被动失效：**

```
每次取上下文时：
   比较 ctx.menu_version 与 sys:perm:version
   ├─ 相同 → 使用缓存
   └─ 不同 → 重新拉取
```

#### 3.6.4 缓存预热

```
登录成功 → 异步预热 sys:perm:ctx:{staff_id}
         → 避免首次请求慢
```

### 3.7 降级策略

| 场景 | 处理 | 安全性 |
|---|---|---|
| Redis 不可用 | 直连 M01 | 可用，稍慢 |
| M01 不可用 + 有缓存 | 使用缓存（延长 TTL 至 30 分钟） | 可用，权限可能陈旧 |
| M01 不可用 + 无缓存 | **拒绝**（503） | 安全优先 |
| M01 超时（>500ms） | 使用缓存（若有） | 可用 |

> **核心原则：安全优先**。无法确定权限时**拒绝**，不放行。

# app/middleware/perm_middleware.py
"""权限校验中间件（全局兜底）"""
import time

from fastapi import Request
from starlette.middleware.base import BaseHTTPMiddleware
from starlette.responses import JSONResponse

from app.core.response import error_response


class PermissionMiddleware(BaseHTTPMiddleware):
    """权限中间件

    职责：
    1. 白名单接口直接放行
    2. 未声明权限的接口记录告警
    3. 统计鉴权耗时
    """

    def __init__(self, app, whitelist: Set[Tuple[str, str]] = None):
        super().__init__(app)
        self.whitelist = whitelist or set()

    async def dispatch(self, request: Request, call_next):
        start = time.time()

        # 1. 白名单检查
        if self._is_whitelisted(request):
            request.state.perm_skipped = True
            response = await call_next(request)
            response.headers["X-Perm-Skipped"] = "whitelist"
            return response

        # 2. 记录请求
        request.state.perm_start = start

        response = await call_next(request)

        # 3. 耗时统计
        cost_ms = int((time.time() - start) * 1000)
        response.headers["X-Auth-Cost-Ms"] = str(cost_ms)

        if cost_ms > 100:
            import logging
            logging.getLogger("perm").warning(
                f"Slow permission check: {request.method} {request.url.path} "
                f"cost={cost_ms}ms")

        return response

    def _is_whitelisted(self, request: Request) -> bool:
        """是否在白名单"""
        path = request.url.path
        method = request.method

        for m, p in self.whitelist:
            if m == "*" or m == method:
                if p.endswith("**"):
                    if path.startswith(p[:-2]):
                        return True
                elif p.endswith("*"):
                    if path.startswith(p[:-1]):
                        return True
                elif path == p:
                    return True
        return False

"""权限服务（核心判定引擎）"""
import json
import time

class PermService:
    def __init__(self, db: AsyncSession):
        self.db = db

    # ==================== 权限上下文 ====================
    async def get_context(self, staff_id: int,
                            force_refresh: bool = False) -> dict:
        """获取权限上下文（缓存优先）"""
        cache_key = f"sys:perm:ctx:{staff_id}"

        if not force_refresh:
            cached = await redis_client.get(cache_key)
            if cached:
                ctx = json.loads(cached)
                # 版本校验
                current_version = await self.get_version()
                if ctx.get("menu_version") == current_version:
                    ttl = await redis_client.ttl(cache_key)
                    ctx["cache_hit"] = True
                    ctx["cache_ttl"] = max(0, ttl)
                    return ctx
                # 版本过期 → 重新拉取

        # 从 M01 拉取
        try:
            remote = await m01_perm_client.get_permission_context(staff_id)
        except Exception as e:
            # M01 不可用 → 降级到旧缓存
            cached = await redis_client.get(cache_key)
            if cached:
                ctx = json.loads(cached)
                ctx["cache_hit"] = False
                ctx["degraded"] = True
                ctx["cache_ttl"] = 0
                # 延长 TTL 至 30 分钟（降级）
                await redis_client.expire(cache_key, 1800)
                return ctx
            raise BizException("0204002", f"权限上下文获取失败：{str(e)[:100]}")

        ctx = self._normalize_context(remote)

        # 写缓存
        ttl = await self._get_cache_ttl()
        await redis_client.setex(cache_key, ttl, json.dumps(ctx))

        ctx["cache_hit"] = False
        ctx["cache_ttl"] = ttl
        return ctx

    def _normalize_context(self, raw: dict) -> dict:
        """标准化上下文：构建 perm_set 用于快速判定"""
        perm_codes = raw.get("perm_codes", [])
        # 构建通配符集合（授权侧可能含通配符）
        wildcards = [p for p in perm_codes if "*" in p]

        return {
            "staff_id": raw.get("staff_id"),
            "account_id": raw.get("account_id"),
            "username": raw.get("username"),
            "staff_name": raw.get("staff_name"),
            "dept_id": raw.get("dept_id"),
            "dept_name": raw.get("dept_name"),
            "dept_path": raw.get("dept_path"),
            "org_id": raw.get("org_id", 1),
            "roles": raw.get("roles", []),
            "perm_codes": perm_codes,
            "wildcards": wildcards,
            "data_scopes": raw.get("data_scopes", {}),
            "field_rules": raw.get("field_rules", {}),
            "second_factor_ops": raw.get("second_factor_ops", []),
            "menu_version": raw.get("menu_version"),
            "computed_at": raw.get("computed_at") or datetime.now().isoformat(),
            "is_super_admin": self._is_super_admin(raw),
        }

    @staticmethod
    def _is_super_admin(raw: dict) -> bool:
        """是否超管"""
        if raw.get("acct_type") == "SUPER_ADMIN":
            return True
        for r in raw.get("roles", []):
            if r.get("role_code") == "R001":
                return True
        return False

    # ==================== 功能权限判定 ====================
    async def check_permission(self, staff_id: int, perm_code: str,
                                 second_factor_verified: bool = False) -> dict:
        """判定功能权限（核心，O(1)）"""
        start = time.time()

        ctx = await self.get_context(staff_id)

        # 1. 超管直接通过
        if ctx["is_super_admin"]:
            return self._pass(staff_id, perm_code, ["SUPER_ADMIN"], ctx,
                                start)

        # 2. 精确匹配
        if perm_code in ctx["perm_codes"]:
            need_sf = perm_code in ctx["second_factor_ops"]
            return self._pass(staff_id, perm_code, self._match_roles(ctx),
                                ctx, start, need_sf, second_factor_verified)

        # 3. 通配符匹配
        for wc in ctx["wildcards"]:
            if self._wildcard_match(wc, perm_code):
                need_sf = perm_code in ctx["second_factor_ops"]
                return self._pass(staff_id, perm_code, self._match_roles(ctx),
                                    ctx, start, need_sf, second_factor_verified)

        # 4. 拒绝
        return {
            "passed": False,
            "staff_id": staff_id,
            "perm_code": perm_code,
            "reason": "该用户无此功能权限",
            "deny_reason": "NO_PERMISSION",
            "matched_roles": self._match_roles(ctx),
            "suggestion": "请联系管理员在 M01 权限管理中分配相应角色或权限",
            "cost_ms": int((time.time() - start) * 1000),
        }

    def _pass(self, staff_id, perm_code, roles, ctx, start,
               need_sf=False, sf_verified=False) -> dict:
        return {
            "passed": True,
            "staff_id": staff_id,
            "perm_code": perm_code,
            "matched_roles": roles,
            "need_second_factor": need_sf,
            "second_factor_verified": sf_verified or not need_sf,
            "cost_ms": int((time.time() - start) * 1000),
        }

    @staticmethod
    def _wildcard_match(pattern: str, code: str) -> bool:
        """通配符匹配"""
        if pattern == "*":
            return True
        if pattern.endswith(":*"):
            prefix = pattern[:-1]   # 保留 :*
            return code.startswith(pattern[:-1])
        if pattern.endswith("*"):
            return code.startswith(pattern[:-1])
        return pattern == code

    @staticmethod
    def _match_roles(ctx: dict) -> List[str]:
        """格式化角色列表"""
        return [f"{r['role_code']} {r['role_name']}"
                for r in ctx.get("roles", [])]

    async def check_any_permission(self, staff_id: int,
                                     perm_codes: List[str]) -> dict:
        """任一权限通过"""
        for code in perm_codes:
            result = await self.check_permission(staff_id, code)
            if result["passed"]:
                return result
        return {
            "passed": False,
            "staff_id": staff_id,
            "perm_code": ",".join(perm_codes),
            "reason": "该用户无任一所需权限",
            "deny_reason": "NO_PERMISSION",
        }

    # ==================== 数据权限 ====================
    async def resolve_data_scope(self, staff_id: int, domain: str,
                                   field: str = None) -> dict:
        """解析数据权限范围"""
        if domain not in DOMAIN_FIELD and domain != "ORG":
            raise BizException("0204005", f"数据域 {domain} 不存在")

        ctx = await self.get_context(staff_id)
        scopes = ctx.get("data_scopes", {})

        # 超管 → ALL
        if ctx["is_super_admin"]:
            return {
                "scope_type": "ALL",
                "domain": domain,
                "field": field or DOMAIN_FIELD.get(domain),
                "has_condition": False,
                "dept_ids": [],
                "sqlalchemy_condition": None,
            }

        scope = scopes.get(domain)
        if not scope:
            # 未配置 → 默认 SELF（最严格）
            scope = {"scope_type": "SELF"}

        scope_type = scope.get("scope_type", "SELF")
        field = field or DOMAIN_FIELD.get(domain, "dept_id")

        result = {
            "scope_type": scope_type,
            "domain": domain,
            "field": field,
            "has_condition": scope_type != "ALL",
        }

        if scope_type == "ALL":
            result.update({"dept_ids": [], "sqlalchemy_condition": None,
                            "sql_condition": None, "readable_sql": "（无限制）"})

        elif scope_type == "DEPT":
            dept_id = ctx.get("dept_id")
            result.update({
                "dept_ids": [dept_id] if dept_id else [],
                "sql_condition": f"{field} = :dept_id",
                "params": {"dept_id": dept_id},
                "readable_sql": f"{field} = {dept_id}",
            })

        elif scope_type == "DEPT_TREE":
            dept_ids = await self._resolve_dept_tree(ctx)
            result.update({
                "dept_ids": dept_ids,
                "sql_condition": f"{field} IN (:dept_ids)",
                "params": {"dept_ids": dept_ids},
                "readable_sql": f"{field} IN ({','.join(map(str, dept_ids))})",
            })

        elif scope_type == "SELF":
            staff = ctx.get("staff_id")
            result.update({
                "staff_id": staff,
                "dept_ids": [],
                "sql_condition": f"{field} = :staff_id",
                "params": {"staff_id": staff},
                "readable_sql": f"{field} = {staff}",
            })

        elif scope_type == "CUSTOM":
            ids = scope.get("dept_ids") or scope.get("ids") or []
            result.update({
                "dept_ids": ids,
                "sql_condition": f"{field} IN (:dept_ids)",
                "params": {"dept_ids": ids},
                "readable_sql": f"{field} IN ({','.join(map(str, ids))})",
            })

        return result

    async def _resolve_dept_tree(self, ctx: dict) -> List[int]:
        """解析科室树（本科室 + 所有下级）"""
        dept_path = ctx.get("dept_path")
        dept_id = ctx.get("dept_id")

        if not dept_path or not dept_id:
            return [dept_id] if dept_id else []

        # 从 M01 拉取下级科室（缓存）
        cache_key = f"sys:perm:dept_tree:{dept_path}"
        cached = await redis_client.get(cache_key)
        if cached:
            return json.loads(cached)

        try:
            dept_ids = await m01_perm_client.get_dept_tree(dept_path)
        except Exception:
            dept_ids = [dept_id]

        await redis_client.setex(cache_key, 3600, json.dumps(dept_ids))
        return dept_ids

    # ==================== 字段脱敏 ====================
    async def mask_fields(self, staff_id: int, data: dict,
                            field_prefix: str = None) -> dict:
        """字段脱敏处理"""
        ctx = await self.get_context(staff_id)
        field_rules = ctx.get("field_rules", {})

        masked_data = dict(data)
        hidden_fields = []
        applied_rules = {}
        ns_fields = []

        for key, value in list(data.items()):
            full_key = f"{field_prefix}.{key}" if field_prefix else key

            rule = field_rules.get(full_key)
            if not rule:
                continue

            action = rule.get("action", "VISIBLE")

            if action == "HIDDEN":
                masked_data.pop(key, None)
                hidden_fields.append(key)
                applied_rules[full_key] = rule

            elif action == "MASKED":
                masked_data[key] = self._mask_value(
                    value, rule.get("mask_rule"), rule.get("mask_expr"))
                applied_rules[full_key] = rule
                if rule.get("need_second_factor"):
                    ns_fields.append(full_key)

            elif action == "VISIBLE":
                applied_rules[full_key] = rule

        return {
            "masked_data": masked_data,
            "hidden_fields": hidden_fields,
            "applied_rules": applied_rules,
            "need_second_factor_fields": ns_fields,
        }

    @staticmethod
    def _mask_value(value, mask_rule: Optional[str],
                     mask_expr: Optional[str] = None):
        """执行脱敏"""
        if value is None:
            return value
        s = str(value)

        if mask_rule == "ID_CARD":
            if len(s) <= 8:
                return "*" * len(s)
            return s[:4] + "*" * (len(s) - 8) + s[-4:]

        if mask_rule == "MOBILE":
            if len(s) < 7:
                return "*" * len(s)
            return s[:3] + "****" + s[-4:]

        if mask_rule == "NAME":
            if len(s) <= 1:
                return s
            if len(s) == 2:
                return s[0] + "*"
            return s[0] + "*" * (len(s) - 2) + s[-1]

        if mask_rule == "BANK":
            if len(s) <= 4:
                return "*" * len(s)
            return "**** " * ((len(s) - 4) // 4) + s[-4:]

        if mask_rule == "ADDRESS":
            if len(s) <= 6:
                return s[:2] + "****"
            return s[:6] + "****"

        if mask_rule == "EMAIL":
            if "@" not in s:
                return "*" * len(s)
            name, domain_part = s.split("@", 1)
            if len(name) <= 1:
                return "*@" + domain_part
            return name[0] + "****@" + domain_part

        if mask_rule == "CUSTOM" and mask_expr:
            import re
            try:
                return re.sub(mask_expr, "*", s)
            except Exception:
                return "*" * len(s)

        # 默认全掩码
        return "*" * len(s)

    # ==================== 版本与缓存 ====================
    async def get_version(self) -> str:
        """获取当前权限版本"""
        v = await redis_client.get("sys:perm:version")
        if v:
            return v.decode() if isinstance(v, bytes) else v

        # 从 M01 拉取
        try:
            remote = await m01_perm_client.get_version()
            version = remote.get("menu_version", "v1:init")
        except Exception:
            version = "v1:init"

        await redis_client.set("sys:perm:version", version)
        return version

    async def refresh_cache(self, staff_id: int) -> dict:
        """刷新指定用户缓存"""
        await redis_client.delete(f"sys:perm:ctx:{staff_id}")
        # 重新加载
        ctx = await self.get_context(staff_id, force_refresh=True)
        return {"staff_id": staff_id, "refreshed": True,
                "version": ctx.get("menu_version")}

    async def invalidate_by_role(self, role_ids: List[int]) -> dict:
        """按角色失效缓存"""
        staff_ids = await self._get_staff_by_roles(role_ids)

        for sid in staff_ids:
            await redis_client.delete(f"sys:perm:ctx:{sid}")

        # 更新全局版本
        new_version = f"v{int(time.time())}:{datetime.now().strftime('%Y%m%d-%H%M%S')}"
        await redis_client.set("sys:perm:version", new_version)

        return {
            "invalidated_count": len(staff_ids),
            "new_version": new_version,
            "affected_staff_ids": staff_ids[:100],
        }

    async def _get_staff_by_roles(self, role_ids: List[int]) -> List[int]:
        """查询角色关联的职工"""
        try:
            return await m01_perm_client.get_staff_by_roles(role_ids)
        except Exception:
            return []

    async def _get_cache_ttl(self) -> int:
        """获取缓存 TTL"""
        cfg = (await self.db.execute(
            select(SysPermConfig).where(SysPermConfig.id == 1)
        )).scalar_one_or_none()
        return cfg.cache_ttl_seconds if cfg else 300

async def _aggregate_stats():
    """从日志聚合统计到 Redis"""
    from datetime import date, datetime
    from sqlalchemy import select, func
    from app.models.perm.runtime import SysPermLog
    from app.core.database import AsyncSessionLocal
    from app.core.redis import redis_client
    import json

    async with AsyncSessionLocal() as db:
        today = date.today()
        start = datetime.combine(today, datetime.min.time())

        # 总数/通过/拒绝
        rows = (await db.execute(
            select(SysPermLog.result, func.count())
            .where(SysPermLog.created_at >= start)
            .group_by(SysPermLog.result)
        )).all()

        stats = {"total": 0, "allowed": 0, "denied": 0,
                 "avg_cost_ms": 0, "cache_hit_rate": 0}

        for result, cnt in rows:
            stats["total"] += cnt
            if result == "ALLOWED":
                stats["allowed"] = cnt
            elif result == "DENIED":
                stats["denied"] = cnt

        # 平均耗时与缓存命中
        agg = (await db.execute(
            select(
                func.avg(SysPermLog.cost_ms),
                func.count().filter(SysPermLog.cache_hit == True),
                func.count())
            .where(SysPermLog.created_at >= start)
        )).one()

        if agg[0]:
            stats["avg_cost_ms"] = round(float(agg[0]), 2)
        if agg[2]:
            stats["cache_hit_rate"] = round(agg[1] / agg[2] * 100, 2)

        await redis_client.setex(
            f"sys:perm:stats:{today}", 3600, json.dumps(stats))

        return stats
