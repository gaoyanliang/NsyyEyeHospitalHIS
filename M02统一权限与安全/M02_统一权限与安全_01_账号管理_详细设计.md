## 1. 模块概述

### 1.1 模块定位

账号管理是 M02 的**主体基础**。它回答一个前置问题："**谁是系统的使用者**"。

M01 管理的 `mdm_staff`（职工）是**人事意义上的"人"**——有工号、职称、职务、所属科室、执业证书。而本子模块管理的 `sys_account`（账号）是**系统意义上的"使用者"**——有登录名、密码、状态、有效期。

**二者关系：**

```
mdm_staff（M01，职工）  1 ──── 0..1  sys_account（M02，账号）
   人事档案                          系统登录凭据
   · 工号 E24030017                  · 登录名 wangwu
   · 姓名 王五                        · 密码（哈希）
   · 科室 白内障科                    · 状态 正常/锁定/停用
   · 职称 主任医师                    · 有效期
   · 执业证                          · MFA 绑定
```

> **不是每个职工都有账号**（如清洁工、部分后勤），**一个职工最多一个账号**。

| 职责 | 归属 |
|---|---|
| 职工人事档案（工号/姓名/职称/职务/证书） | **M01** |
| 科室、岗位、用户组 | **M01** |
| **账号（登录名、密码、状态、有效期、MFA 绑定）** | **M02 本子模块** |
| 密码策略（复杂度、有效期、历史） | **M02 本子模块** |
| 账号生命周期（创建/启用/锁定/停用/注销） | **M02 本子模块** |
| 用户-角色绑定数据 | M01 定义表，M02 提供操作入口 |
| 登录认证 | M02-02 |
| 会话与 Token | M02-03 |
| 权限计算与校验 | M02-04 |

> **一句话边界**：本子模块只管"**账号这个凭据容器本身**"——存在、可用、能登录、密码合规。它**不做认证判断**（那是 M02-02），**不做权限判断**（那是 M02-04）。

### 1.2 为什么账号必须独立于职工

将账号与职工分离是**安全设计的必然**，而非多此一举：

| 场景 | 若账号等同职工 | 分离后 |
|---|---|---|
| 职工离职 | 删除职工 → 历史单据操作人丢失 | 停用账号，职工保留（审计需要） |
| 职工调岗 | 改职工 → 连带影响职称/科室 | 账号不变，仅调整角色绑定 |
| 一人多岗 | 无法表达 | 一个账号，多角色（M01 角色绑定） |
| 外部用户（如厂家工程师） | 无职工档案无法建账号 | 建"非职工账号" |
| 密码泄露临时锁定 | 需改职工记录 | 只锁账号 |
| 审计追溯 | 删职工后查不到 | 账号永久保留，标记停用 |

### 1.3 模块目标

- **一职工一账号**：职工与账号 1:0..1 绑定，杜绝一人多号。
- **密码合规**：强制复杂度、有效期、历史不可重用。
- **状态可控**：正常/锁定/停用/注销四态清晰，可恢复。
- **生命周期完整**：入职建号 → 在岗可用 → 离岗停用 → 长期归档。
- **可批量**：支持批量建号、导入、批量重置。
- **强审计**：每次状态变更、密码重置全部留痕。

### 1.4 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 系统管理员 | 账号全生命周期 | 建号、停用、锁定、重置密码 |
| 人事科 | 建档触发 | 职工入职后建号申请 |
| 科室负责人 | 本科室账号查看 | 查看本科室账号状态 |
| 本人 | 自助 | 修改密码、绑定 MFA、查看登录记录 |
| 审计员 | 追溯 | 查看账号变更与登录记录 |
| 信息科长 | 策略配置 | 配置密码策略、有效期策略 |

## 3. 账号模型

### 3.1 账号状态机

```
                    ┌──────────────┐
                    │   PENDING    │ 待激活（初始建号）
                    └──────┬───────┘
                           │ 首次登录/管理员激活
                           ▼
   ┌──────────────┐   ┌──────────────┐   ┌──────────────┐
   │  DISABLED    │◄──│    ACTIVE    │──►│   LOCKED     │
   │  已停用       │   │    正常      │   │  已锁定       │
   └──────┬───────┘   └──────┬───────┘   └──────┬───────┘
          │                  │                  │
          │ 启用              │ 解锁              │ 解锁
          └──────────────────┘                  │
                    ▲                           │
                    └───────────────────────────┘
                           │
                           ▼ 注销
                    ┌──────────────┐
                    │  TERMINATED  │ 已注销（不可恢复）
                    └──────────────┘
```

**状态说明：**

| 状态 | 代码 | 说明 | 能否登录 | 恢复方式 |
|---|---|---|---|---|
| 待激活 | `PENDING` | 建号后未首次登录 | 否 | 首次登录或管理员激活 |
| 正常 | `ACTIVE` | 正常使用 | **是** | — |
| 已锁定 | `LOCKED` | 密码错误超限/管理员锁定 | 否 | 自动解锁（到期）或管理员解锁 |
| 已停用 | `DISABLED` | 离职/长期休假/安全事件 | 否 | 管理员启用 |
| 已注销 | `TERMINATED` | 永久停用 | 否 | **不可恢复**（只能新建） |

**状态转换规则：**

| 当前 | 操作 | 目标 | 触发方 | 校验 |
|---|---|---|---|---|
| PENDING | 首次登录 | ACTIVE | 本人 | 密码正确 |
| PENDING | 管理员激活 | ACTIVE | 管理员 | — |
| PENDING | 停用 | DISABLED | 管理员 | — |
| ACTIVE | 密码错误超限 | LOCKED | 系统 | 达锁定阈值 |
| ACTIVE | 管理员锁定 | LOCKED | 管理员 | 需填原因 |
| ACTIVE | 停用 | DISABLED | 管理员 | 需填原因 |
| ACTIVE | 有效期到期 | DISABLED | 系统 | 到期日 ≤ 今天 |
| LOCKED | 自动解锁 | ACTIVE | 系统 | 锁定到期 |
| LOCKED | 管理员解锁 | ACTIVE | 管理员 | — |
| LOCKED | 停用 | DISABLED | 管理员 | — |
| DISABLED | 启用 | ACTIVE | 管理员 | 需验证职工在职 |
| DISABLED | 注销 | TERMINATED | 管理员 | 需信息科长权限 |
| 任意 | 注销 | TERMINATED | 管理员 | **二次确认** |

### 3.2 账号类型

| 类型 | 代码 | 说明 | 是否必须绑定职工 | 有效期 |
|---|---|---|---|---|
| 正式职工 | `EMPLOYEE` | 在职职工 | 是 | 长期 |
| 临时职工 | `TEMP_EMPLOYEE` | 实习/进修/规培 | 是 | 必填，≤1 年 |
| 外部人员 | `EXTERNAL` | 厂家工程师、医保专员 | 否 | 必填，≤6 月 |
| 系统集成 | `SERVICE` | 服务间调用账号 | 否 | 长期，仅 API |
| 超级管理员 | `SUPER_ADMIN` | 应急管理账号 | 是 | 长期，强审计 |

**说明：**
- `SERVICE` 账号**不可登录 UI**，仅供内部服务调用（`service_token`）。
- `SUPER_ADMIN` 账号数量上限由参数控制（默认 2 个），登录强二次验证。
- `EXTERNAL` 账号须关联负责科室（`owner_dept_id`），权限受限。

### 3.3 登录名规则

#### 3.3.1 生成规则

| 规则 | 说明 |
|---|---|
| 默认 | 职工工号（如 `E24030017`） |
| 备选 | 姓名拼音全拼（如 `wangwu`） |
| 冲突处理 | 追加数字（`wangwu2`） |
| 字符集 | 字母、数字、下划线，4~32 字符 |
| 首字符 | 必须字母 |
| 大小写 | **不敏感**（存储小写，登录时转小写比对） |
| 保留字 | `admin`、`root`、`system`、`test`、`sa`、`guest` 等不可用 |

#### 3.3.2 登录名修改

| 场景 | 允许 | 说明 |
|---|---|---|
| 建号后 7 天内 | ✅ 允许 | 纠错期 |
| 7 天后 | ❌ 禁止 | 需信息科长审批 |
| 修改后 | — | 记录 `sys_account_log`，旧名进入 `sys_account_alias` |

**旧登录名保留**：修改登录名后，旧名保留 90 天映射（防止业务方按旧名调用），90 天后释放。

### 3.4 密码模型

#### 3.4.1 密码存储

| 项 | 方案 |
|---|---|
| 算法 | **bcrypt**（cost=12）或 **Argon2id** |
| 存储 | `password_hash`（VARCHAR(255)） |
| 盐 | 算法内置，无需单独存 |
| 明文 | **永不存储、永不记录日志** |
| 查看 | **不可查看**（仅可重置） |

> **强制规范**：任何接口、日志、异常信息中**不得出现明文密码**。代码审查必须检查。

#### 3.4.2 密码策略（`sys_password_policy`）

| 策略项 | 默认值 | 说明 |
|---|---|---|
| `min_length` | 8 | 最小长度 |
| `max_length` | 32 | 最大长度 |
| `require_upper` | 是 | 必须含大写字母 |
| `require_lower` | 是 | 必须含小写字母 |
| `require_digit` | 是 | 必须含数字 |
| `require_special` | 否 | 必须含特殊字符 |
| `forbid_username` | 是 | 不得含登录名 |
| `forbid_weak` | 是 | 不得为弱口令（字典库） |
| `history_count` | 5 | 不可重复最近 N 次密码 |
| `expire_days` | 90 | 密码有效期（天），0=不过期 |
| `warn_days` | 7 | 到期前提醒天数 |
| `max_fail_count` | 5 | 连续错误锁定阈值 |
| `lock_minutes` | 30 | 自动锁定时长（分钟） |
| `first_login_change` | 是 | 首次登录强制改密 |

#### 3.4.3 弱口令库

内置常见弱口令（约 5,000 条）+ 医院相关词（`hospital`、`doctor`、`nurse`、`eye`）+ 数字序列（`12345678`、`88888888`）。

**校验方式：** 加载到 Redis Set，`SISMEMBER` 查询，O(1)。

#### 3.4.4 密码强度评分

```
基础分（长度）：
  8~11 字符 → 20 分
  12~15 → 40 分
  16+ → 60 分

字符种类加分（每类 +10，最多 +40）：
  含大写、含小写、含数字、含特殊

扣分：
  含连续 3 位以上键盘序列（qwe/asd/123）→ -20
  含登录名 → -30
  命中弱口令库 → 直接 0 分（不允许）

等级：
  0~39  → 弱（不允许）
  40~69 → 中（允许，提示加强）
  70~89 → 强
  90+   → 很强
```

#### 3.4.5 密码历史

每次修改密码，将新密码哈希写入 `sys_password_history`，保留最近 `history_count` 条。修改时比对：新密码哈希不得与历史中任一相同。

    dept_id: Optional[int] = Query(None),

    # ---------- 密码校验 ----------
    async def validate(self, password: str, username: Optional[str] = None) -> dict:
        """校验密码是否符合策略，并返回强度评分"""
        policy = await self.get_policy()
        errors, suggestions = [], []

        # 1. 长度
        if len(password) < policy["min_length"]:
            errors.append({"code": "LENGTH",
                           "message": f"密码长度不足，至少 {policy['min_length']} 位"})
        if len(password) > policy["max_length"]:
            errors.append({"code": "LENGTH_MAX",
                           "message": f"密码长度超限，最多 {policy['max_length']} 位"})

        # 2. 字符种类
        has_upper = bool(re.search(r"[A-Z]", password))
        has_lower = bool(re.search(r"[a-z]", password))
        has_digit = bool(re.search(r"\d", password))
        has_special = bool(re.search(r"[^A-Za-z0-9]", password))

        if policy["require_upper"] and not has_upper:
            errors.append({"code": "NO_UPPER", "message": "必须包含大写字母"})
        if policy["require_lower"] and not has_lower:
            errors.append({"code": "NO_LOWER", "message": "必须包含小写字母"})
        if policy["require_digit"] and not has_digit:
            errors.append({"code": "NO_DIGIT", "message": "必须包含数字"})
        if policy["require_special"] and not has_special:
            errors.append({"code": "NO_SPECIAL", "message": "必须包含特殊字符"})

        # 3. 不得含登录名
        if policy["forbid_username"] and username:
            if username.lower() in password.lower():
                errors.append({"code": "CONTAIN_USERNAME",
                               "message": "密码不得包含登录名"})

        # 4. 弱口令库
        if policy["forbid_weak"]:
            is_weak = await redis_client.sismember(WEAK_PWD_KEY, password.lower())
            if is_weak:
                errors.append({"code": "WEAK_PASSWORD",
                               "message": "该密码为常见弱口令，请更换"})

        # 5. 强度评分
        score = self._score(password, username, has_upper, has_lower,
                            has_digit, has_special)
        level, level_text = self._level(score)

        # 6. 建议
        if score < 70 and not errors:
            suggestions.append("建议使用 12 位以上、大小写字母+数字+特殊字符的组合")
        if re.search(r"(012|123|234|345|456|567|678|789|890)", password):
            suggestions.append("避免使用连续数字序列")
        if re.search(r"(qwe|asd|zxc|wsx|edc)", password.lower()):
            suggestions.append("避免使用键盘连续序列")

        return {
            "valid": len(errors) == 0,
            "score": score,
            "level": level,
            "level_text": level_text,
            "errors": errors,
            "suggestions": suggestions,
        }

    @staticmethod
    def _score(password: str, username: Optional[str],
               has_upper: bool, has_lower: bool,
               has_digit: bool, has_special: bool) -> int:
        """密码强度评分"""
        # 长度分
        n = len(password)
        if n >= 16:
            base = 60
        elif n >= 12:
            base = 40
        elif n >= 8:
            base = 20
        else:
            base = 0

        # 字符种类分
        kinds = sum([has_upper, has_lower, has_digit, has_special])
        kind_score = min(kinds * 10, 40)

        score = base + kind_score

        # 扣分
        if re.search(r"(012|123|234|345|456|567|678|789|890)", password):
            score -= 20
        if re.search(r"(qwe|asd|zxc|wsx|edc)", password.lower()):
            score -= 20
        if username and username.lower() in password.lower():
            score -= 30

        return max(0, min(100, score))

    @staticmethod
    def _level(score: int) -> tuple:
        if score >= 90:
            return "VERY_STRONG", "很强"
        if score >= 70:
            return "STRONG", "强"
        if score >= 40:
            return "MEDIUM", "中"
        return "WEAK", "弱"

    # ---------- 生成随机密码 ----------
    @staticmethod
    def generate_password(length: int = 10) -> str:
        """生成符合策略的随机密码"""
        upper = string.ascii_uppercase
        lower = string.ascii_lowercase
        digits = string.digits
        special = "!@#$%^&*"

        # 确保每类至少一个
        pwd = [
            secrets.choice(upper),
            secrets.choice(lower),
            secrets.choice(digits),
            secrets.choice(special),
        ]
        # 剩余随机
        all_chars = upper + lower + digits + special
        pwd.extend(secrets.choice(all_chars) for _ in range(length - 4))
        secrets.SystemRandom().shuffle(pwd)
        return "".join(pwd)

    # ---------- 密码哈希 ----------
    @staticmethod
    def hash_password(plain: str) -> str:
        return pwd_context.hash(plain)

    @staticmethod
    def verify_password(plain: str, hashed: str) -> bool:
        try:
            return pwd_context.verify(plain, hashed)
        except Exception:
            return False

    # ---------- 凭据验证（M02-02 调用） ----------
    async def verify_credential(self, req) -> dict:
        """校验登录凭据"""
        # 1. 查账号（登录名不区分大小写）
        account = (await self.db.execute(
            select(SysAccount).where(
                func.lower(SysAccount.username) == req.username.lower(),
                SysAccount.is_deleted == False)
        )).scalar_one_or_none()

        # 账号不存在 —— 仍需做一次哈希比对以防时序攻击
        if not account:
            pwd_context.hash("dummy_password_for_timing")
            return {
                "verified": False,
                "error_code": "BAD_CREDENTIAL",
                "error_message": "登录名或密码错误",
            }

        # 2. 状态检查
        status_check = self._check_status(account)
        if status_check:
            return status_check

        # 3. 密码验证
        if not self.verify_password(req.password, account.password_hash):
            return {
                "verified": False,
                "error_code": "BAD_PASSWORD",
                "error_message": "登录名或密码错误",
                "fail_count": account.fail_count,
                "remaining_attempts": max(
                    0, (await self.get_policy())["max_fail_count"] - account.fail_count - 1),
                "locked": False,
            }

        # 4. 密码有效期检查
        policy = await self.get_policy()
        need_change = False
        change_reason = None
        expire_in_days = None

        if account.need_change_password:
            need_change = True
            change_reason = "FIRST_LOGIN"

        if policy["expire_days"] > 0 and account.password_changed_at:
            expire_at = account.password_changed_at + timedelta(days=policy["expire_days"])
            expire_in_days = (expire_at.date() - datetime.now().date()).days
            if expire_in_days <= 0:
                need_change = True
                change_reason = "PASSWORD_EXPIRED"
            elif expire_in_days <= policy["warn_days"]:
                need_change = False   # 仅提醒，不强制

        # 5. 返回
        return {
            "verified": True,
            "account_id": account.id,
            "username": account.username,
            "staff_id": account.staff_id,
            "staff_code": account.staff_code,
            "staff_name": getattr(account, "staff_name", None),
            "dept_id": getattr(account, "dept_id", None),
            "account_type": account.account_type,
            "status": account.status,
            "need_change_password": need_change,
            "change_reason": change_reason,
            "password_expire_in_days": expire_in_days,
            "need_mfa": bool(account.mfa_bound),
            "mfa_phone_mask": self._mask_phone(account.phone),
            "fail_count": account.fail_count,
        }

    def _check_status(self, account) -> Optional[dict]:
        """状态检查，返回错误响应或 None"""
        now = datetime.now()

        if account.status == "DISABLED":
            return {"verified": False, "error_code": "ACCOUNT_DISABLED",
                    "error_message": "账号已停用，请联系管理员"}

        if account.status == "TERMINATED":
            return {"verified": False, "error_code": "ACCOUNT_TERMINATED",
                    "error_message": "账号已注销"}

        if account.status == "LOCKED":
            if account.locked_until and account.locked_until > now:
                return {"verified": False, "error_code": "ACCOUNT_LOCKED",
                        "error_message": "账号已被锁定，请稍后重试或联系管理员",
                        "locked_until": account.locked_until.isoformat()}
            # 锁定已到期，自动解锁（延迟执行，此处只放行）
            account.status = "ACTIVE"
            account.locked_until = None
            account.fail_count = 0

        if account.status == "PENDING":
            # 初次登录允许，登录成功后转 ACTIVE
            pass

        if account.status == "ACTIVE":
            # 检查账号有效期
            if account.expire_date and account.expire_date < now.date():
                return {"verified": False, "error_code": "ACCOUNT_EXPIRED",
                        "error_message": f"账号已于 {account.expire_date} 过期"}

        return None

    @staticmethod
    def _mask_phone(phone: Optional[str]) -> Optional[str]:
        if not phone or len(phone) < 7:
            return phone
        return phone[:3] + "****" + phone[-4:]

    # ---------- 记录成功/失败 ----------
    async def record_fail(self, account_id: int, req) -> dict:
        """记录登录失败，达阈值则锁定"""
        policy = await self.get_policy()
        account = await self._get(account_id)

        account.fail_count = (account.fail_count or 0) + 1
        locked = False
        lock_until = None

        if account.fail_count >= policy["max_fail_count"]:
            account.status = "LOCKED"
            account.locked_until = datetime.now() + timedelta(
                minutes=policy["lock_minutes"])
            account.lock_reason = f"连续登录失败 {account.fail_count} 次"
            locked = True
            lock_until = account.locked_until
            account.fail_count = 0   # 锁定后重置计数

        await self.db.commit()

        return {
            "account_id": account_id,
            "fail_count": account.fail_count,
            "remaining_attempts": max(0, policy["max_fail_count"] - account.fail_count),
            "locked": locked,
            "locked_until": lock_until.isoformat() if lock_until else None,
            "lock_threshold": policy["max_fail_count"],
        }

    async def record_success(self, account_id: int, req) -> dict:
        """记录登录成功：清零失败次数、更新最后登录、激活账号"""
        account = await self._get(account_id)

        account.fail_count = 0
        account.locked_until = None
        account.last_login_at = datetime.now()
        account.last_login_ip = req.login_ip

            account.activated_at = datetime.now()

        await self.db.commit()

        return {
            "account_id": account_id,
            "status": account.status,
            "last_login_at": account.last_login_at.isoformat(),
        }

    async def _get(self, account_id: int) -> SysAccount:

            select(SysAccount).where(
                SysAccount.id == account_id, SysAccount.is_deleted == False)
        )).scalar_one_or_none()
        if not acc:
            raise BizException("0201001", f"账号 {account_id} 不存在")
        return acc

    # ---------- 修改自己密码 ----------
    async def change_own(self, account_id: int, payload, operator) -> dict:
        """用户修改自己的密码"""
        account = await self._get(account_id)

        # 1. 原密码校验
        if not self.verify_password(payload.old_password, account.password_hash):
            raise BizException("0201029", "原密码不正确")

        # 2. 两次一致
        if payload.new_password != payload.confirm_password:
            raise BizException("0201030", "两次输入的密码不一致")

        # 3. 新密码不得与旧密码相同
        if self.verify_password(payload.new_password, account.password_hash):
            raise BizException("0201028", "新密码不能与当前密码相同")

        # 4. 策略校验
        result = await self.validate(payload.new_password, account.username)
        if not result["valid"]:
            raise BizException(40001, "密码不符合策略",
                                data={"errors": result["errors"]})

        # 5. 历史校验
        await self._check_history(account_id, payload.new_password)

        # 6. 保存历史 + 更新
        policy = await self.get_policy()
        await self._save_history(account_id, account.password_hash,
                                  policy["history_count"])

        account.password_hash = self.hash_password(payload.new_password)
        account.password_changed_at = datetime.now()
        account.need_change_password = False

        # 7. 记录日志
        self.db.add(SysAccountLog(
            account_id=account_id, action="CHANGE_PASSWORD",
            operator_id=operator.id, operator_name=operator.name,
            detail="用户自助修改密码",
        ))

        await self.db.commit()

        expire_date = None
        if policy["expire_days"] > 0:
            expire_date = (datetime.now()
                           + timedelta(days=policy["expire_days"])).date().isoformat()

        return {
            "changed": True,
            "password_expire_date": expire_date,
            "revoked_other_sessions": 0,   # 由调用方（路由层）调 M02-03 吊销
        }

    async def _check_history(self, account_id: int, new_password: str) -> None:

                    SysAccount.account_type == "SUPER_ADMIN",
                    SysAccount.status != "TERMINATED",
                    SysAccount.is_deleted == False)
            )).scalar_one()
            if cnt >= MAX_SUPER_ADMIN:
                raise BizException("0201036",
                    f"超管账号数量已达上限（{MAX_SUPER_ADMIN} 个）")

        # 4. 有效期校验
        if payload.account_type in ("TEMP_EMPLOYEE", "EXTERNAL"):
            if not payload.expire_date:
                raise BizException("0201009", "临时/外部账号必须设置到期日")
        if payload.expire_date and payload.expire_date < date.today():
            raise BizException("0201010", "到期日不能早于今天")

        # 5. 非职工账号必须指定负责科室
        if payload.account_type == "EXTERNAL" and not payload.owner_dept_id:
            raise BizException("0201008", "外部人员账号必须指定负责科室")

        # 6. 生成密码
        policy = await self.pwd_svc.get_policy()
        if payload.init_password_mode == "RANDOM":
            plain_pwd = self.pwd_svc.generate_password(max(10, policy["min_length"]))
        else:
            plain_pwd = payload.manual_password
            result = await self.pwd_svc.validate(plain_pwd, username)
            if not result["valid"]:
                raise BizException(40001, "密码不符合策略",
                                    data={"errors": result["errors"]})

        # 7. 建号
        account = SysAccount(
            username=username,
            staff_id=payload.staff_id,
            staff_code=staff["code"] if staff else None,
            staff_name=staff["name"] if staff else payload.staff_name,
            dept_id=staff["dept_id"] if staff else payload.owner_dept_id,
            dept_name=staff.get("dept_name") if staff else None,
            account_type=payload.account_type,
            password_hash=self.pwd_svc.hash_password(plain_pwd),
            password_changed_at=datetime.now(),
            need_change_password=payload.force_change_on_first_login,
            status="PENDING",
            is_long_term=payload.is_long_term,
            expire_date=payload.expire_date,
            phone=payload.phone,
            mfa_bound=bool(payload.phone),
            fail_count=0,
            remark=payload.remark,
            created_by=operator.id,
        )
        self.db.add(account)
        await self.db.flush()

        # 8. 日志
        self.db.add(SysAccountLog(
            account_id=account.id, action="CREATE",
            operator_id=operator.id, operator_name=operator.name,
            detail=f"创建账号 {username}（{payload.account_type}）",
            ip=ip,
        ))

        # 9. 分配初始角色（调用 M01）
        if payload.role_ids:
            await self._assign_roles(account.id, payload.role_ids, operator)

        await self.db.commit()

        # 10. 短信通知
        sms_sent = False
        if payload.send_password_by_sms and payload.phone:
            sms_sent = await self._send_sms(payload.phone, username, plain_pwd)

        return {
            "id": account.id,
            "username": account.username,
            "staff_id": account.staff_id,
            "staff_name": account.staff_name,
            "account_type": account.account_type,
            "status": account.status,
            "init_password": plain_pwd,
            "password_display_once": True,
            "sms_sent": sms_sent,
            "message": "账号创建成功，初始密码仅显示一次，请立即转交本人",
        }

    async def _validate_username(self, username: str) -> None:
        """校验登录名"""
        import re
        if username in RESERVED_USERNAMES:
            raise BizException("0201003", f"登录名 {username} 为系统保留字")
        if not re.match(USERNAME_PATTERN, username):
            raise BizException("0201004",
                "登录名格式不正确（4~32 位，首字符字母，可含字母数字下划线）")
        # 唯一性（含已注销）
        exist = (await self.db.execute(
            select(SysAccount).where(
                func.lower(SysAccount.username) == username)
        )).scalar_one_or_none()
        if exist:
            raise BizException("0201002", f"登录名 {username} 已被使用")

    async def _gen_username(self, staff_id: Optional[int]) -> str:
        """按工号生成登录名"""
        staff = await self._get_staff(staff_id) if staff_id else None
        base = (staff["code"] if staff else f"user{staff_id}").lower()
        base = re.sub(r"[^a-z0-9_]", "", base)[:28]
        if not base or not base[0].isalpha():
            base = "u" + base

        username = base
        i = 1
        while (await self.db.execute(
            select(SysAccount).where(func.lower(SysAccount.username) == username)
        )).scalar_one_or_none():
            i += 1
            username = f"{base}{i}"
        return username

    # ---------- 状态变更 ----------
    async def disable(self, account_id: int, payload, operator) -> dict:
        """停用账号"""
        if not payload.reason or len(payload.reason.strip()) < 5:
            raise BizException("0201017", "停用账号必须填写原因（≥5 字）")

        account = await self._get(account_id)
        if account.status in ("DISABLED", "TERMINATED"):
            raise BizException("0201011", f"账号状态为 {account.status}，无需停用")

        account.status = "DISABLED"
        account.disabled_at = datetime.now()
        account.disable_reason = payload.reason

        self.db.add(SysAccountLog(
            account_id=account_id, action="DISABLE",
            operator_id=operator.id, operator_name=operator.name,
            detail=f"停用账号：{payload.reason}",
        ))
        await self.db.commit()

        revoked = 0
        if payload.revoke_sessions:
            revoked = await self._revoke_sessions(account_id)

        return {
            "id": account_id,
            "username": account.username,
            "status": "DISABLED",
            "disabled_at": account.disabled_at.isoformat(),
            "revoked_sessions": revoked,
        }

    async def enable(self, account_id: int, operator) -> dict:
        """启用账号"""
        account = await self._get(account_id)
        if account.status != "DISABLED":
            raise BizException("0201011", "只有已停用的账号才能启用")

        # 校验职工在职
        if account.staff_id:
            staff = await self._get_staff(account.staff_id)
            if not staff or staff.get("status") != "ACTIVE":
                raise BizException("0201007", "关联职工已不在职，请先在 M01 恢复职工状态")

        account.status = "ACTIVE"
        account.disabled_at = None
        account.disable_reason = None
        account.fail_count = 0

        self.db.add(SysAccountLog(
            account_id=account_id, action="ENABLE",
            operator_id=operator.id, operator_name=operator.name,
            detail="启用账号",
        ))
        await self.db.commit()

        return {"id": account_id, "username": account.username, "status": "ACTIVE"}

    async def lock(self, account_id: int, payload, operator) -> dict:
        """管理员锁定"""
        if not payload.reason or len(payload.reason.strip()) < 5:
            raise BizException("0201018", "锁定账号必须填写原因（≥5 字）")

        account = await self._get(account_id)
        if account.status == "TERMINATED":
            raise BizException("0201014", "账号已注销，不可锁定")

        account.status = "LOCKED"
        account.locked_until = payload.locked_until
        account.lock_reason = payload.reason

        self.db.add(SysAccountLog(
            account_id=account_id, action="LOCK",
            operator_id=operator.id, operator_name=operator.name,
            detail=f"管理员锁定：{payload.reason}",
        ))
        await self.db.commit()

        revoked = await self._revoke_sessions(account_id)
        return {
            "id": account_id, "username": account.username,
            "status": "LOCKED", "revoked_sessions": revoked,
        }

    async def unlock(self, account_id: int, operator) -> dict:
        """解锁"""
        account = await self._get(account_id)
        if account.status != "LOCKED":
            raise BizException("0201011", "只有已锁定的账号才能解锁")

        account.status = "ACTIVE"
        account.locked_until = None
        account.lock_reason = None
        account.fail_count = 0

        self.db.add(SysAccountLog(
            account_id=account_id, action="UNLOCK",
            operator_id=operator.id, operator_name=operator.name,
            detail="管理员解锁账号",
        ))
        await self.db.commit()
        return {"id": account_id, "username": account.username, "status": "ACTIVE"}

    async def terminate(self, account_id: int, reason: str, operator) -> dict:
        """注销（不可恢复）"""
        account = await self._get(account_id)
        if account.status == "TERMINATED":
            raise BizException("0201014", "账号已注销")

        account.status = "TERMINATED"
        account.terminated_at = datetime.now()
        account.terminate_reason = reason

        self.db.add(SysAccountLog(
            account_id=account_id, action="TERMINATE",
            operator_id=operator.id, operator_name=operator.name,
            detail=f"注销账号：{reason}",
        ))
        await self.db.commit()

        revoked = await self._revoke_sessions(account_id)
        return {
            "id": account_id, "username": account.username,
            "status": "TERMINATED", "revoked_sessions": revoked,
            "message": "账号已注销，不可恢复",
        }

    async def _get(self, account_id: int) -> SysAccount:
        acc = (await self.db.execute(
            select(SysAccount).where(
                SysAccount.id == account_id, SysAccount.is_deleted == False)
        )).scalar_one_or_none()

    async def _get_staff(self, staff_id: int) -> Optional[dict]:
        """调用 M01 获取职工信息"""
        import httpx
        try:
            async with httpx.AsyncClient(timeout=5) as client:
                resp = await client.get(
                    f"{settings.M01_BASE_URL}/internal/v1/mdm/staff/{staff_id}/brief")
                data = resp.json()
                if data.get("code") == 0:
                    return data["data"]
        except Exception:
            pass
        return None

    async def _revoke_sessions(self, account_id: int) -> int:
        """吊销账号全部会话（调用 M02-03）"""
        import httpx
        try:
            async with httpx.AsyncClient(timeout=5) as client:
                resp = await client.post(
                    f"{settings.M02_BASE_URL}/internal/v1/session/revoke-all",
                    json={"account_id": account_id, "reason": "ACCOUNT_STATUS_CHANGE"})
                return resp.json().get("data", {}).get("revoked", 0)
        except Exception:
            return 0

    async def _assign_roles(self, account_id: int, role_ids: List[int], operator) -> None:
        """分配角色（调用 M01）"""

        try:

                await client.post(
                    f"{settings.M01_BASE_URL}/internal/v1/auth/role-user/bind",
                    json={"account_id": account_id, "role_ids": role_ids,
                          "operator_id": operator.id})
        except Exception:
            pass

    async def _send_sms(self, phone: str, username: str, password: str) -> bool:
        """发送初始密码短信（M20）"""
        import httpx
        try:
            async with httpx.AsyncClient(timeout=5) as client:
                resp = await client.post(
                    f"{settings.M20_BASE_URL}/internal/v1/sms/send",
                    json={"phone": phone, "template": "ACCOUNT_CREATED",
                          "params": {"username": username, "password": password}})
                return resp.json().get("code") == 0
        except Exception:
            return False
