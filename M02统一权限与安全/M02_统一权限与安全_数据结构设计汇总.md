## 第 1 章 全局设计约定

### 1.1 数据库与命名规范

#### 1.1.1 数据库

| 项 | 值 |
|---|---|
| 数据库 | **PostgreSQL 16** |
| 字符集 | UTF8 |
| 排序规则 | `zh_CN.UTF-8` / `C`（混合） |
| 时区 | `Asia/Shanghai` |
| 连接池 | asyncpg，pool_size=20，max_overflow=10 |

#### 1.1.2 命名规范

| 对象 | 规范 | 示例 |
|---|---|---|
| 表名 | `sys_` + 小写下划线，**单数** | `sys_account`、`sys_login_config` |
| 字段名 | 小写下划线 | `created_at`、`staff_id` |
| 主键 | 统一 `id` | — |
| 索引 | `idx_` + 表名简写 + 字段 | `idx_sys_account_status` |
| 唯一索引 | `uk_` + 表名简写 + 字段 | `uk_sys_account_username` |
| 约束 | `ck_` + 表名简写 + 规则 | `ck_session_status` |
| 分区 | 表名 + `_YYYY_MM` | `sys_audit_log_2026_04` |
| 序列 | 表名 + `_id_seq` | `sys_account_id_seq` |

#### 1.1.3 类型映射（PostgreSQL 16）

| 场景 | 类型 | 说明 |
|---|---|---|
| 主键 | `BIGINT GENERATED BY DEFAULT AS IDENTITY` | — |
| 外键/关联 ID | `BIGINT` | 跨模块不建物理 FK |
| 布尔 | `BOOLEAN`，默认 `TRUE`/`FALSE` | — |
| 时间 | `TIMESTAMP`（无时区） | 统一 Asia/Shanghai |
| 日期 | `DATE` | — |
| JSON | `JSONB` | 可建 GIN 索引 |
| 金额 | `NUMERIC(12,4)` / `NUMERIC(10,2)` | — |
| 百分比/权重 | `NUMERIC(5,2)` / `NUMERIC(7,4)` | — |
| 短字符串 | `VARCHAR(n)` | — |
| 长文本 | `TEXT` | — |
| 哈希 | `CHAR(64)`（SHA-256）/ `CHAR(32)`（MD5） | 定长 |

#### 1.2.2 `updated_at` 触发器

```sql
CREATE OR REPLACE FUNCTION trg_set_updated_at()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = CURRENT_TIMESTAMP;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

-- 每张含 updated_at 的表都需创建：
CREATE TRIGGER trg_sys_account_updated
    BEFORE UPDATE ON sys_account
    FOR EACH ROW EXECUTE FUNCTION trg_set_updated_at();
```

### 1.3 索引与约束规范

#### 1.3.1 索引原则

| 原则 | 说明 |
|---|---|
| 主键 | 每表必有 |
| 唯一 | 业务唯一键（含 `is_deleted`） |
| 查询索引 | 高频 WHERE 字段 |
| 组合索引 | 区分度高的字段在前 |
| 部分索引 | 用于 `is_deleted=FALSE` 等 |
| JSONB | 需要检索时建 GIN 索引 |

#### 1.3.2 唯一索引与逻辑删除

```sql
-- 唯一键需包含 is_deleted，允许删除后重新创建
CREATE UNIQUE INDEX uk_sys_account_username
    ON sys_account (username);

-- 若允许同名重建，使用部分唯一索引
CREATE UNIQUE INDEX uk_sys_account_username
    ON sys_account (username)
    WHERE is_deleted = FALSE;
```

#### 1.3.3 中文检索

```sql
-- 安装扩展
CREATE EXTENSION IF NOT EXISTS pg_trgm;

-- 中文模糊检索用 GIN 索引
CREATE INDEX idx_sys_account_name_trgm
    ON sys_account USING GIN (staff_name gin_trgm_ops);
```

#### 1.3.4 跨模块外键

**M02 与 M01 之间不建物理外键**，由应用层校验：

| M02 表.字段 | 引用 | 说明 |
|---|---|---|
| `sys_account.staff_id` | `mdm_staff.id` | 职工 |
| `sys_session.staff_id` | `mdm_staff.id` | 职工 |
| `sys_mfa_operation_policy.operation_code` | `mdm_role_permission.perm_code` | 权限码 |
| `sys_mfa_credential`（无） | — | — |

**理由：** 模块解耦、便于分库、避免级联删除风险。

### 1.4 分区策略

| 表 | 分区键 | 粒度 | 保留期 |
|---|---|---|---|
| `sys_audit_log` | `occurred_at` | 月度 | 安全 3 年 / 操作 10 年 |
| `sys_login_attempt` | `created_at` | 月度 | 1 年 |
| `sys_mfa_record` | `created_at` | 月度 | 1 年 |
| `sys_sms_code` | `created_at` | 月度 | 3 个月 |
| `sys_qrcode_session` | `created_at` | 月度 | 3 个月 |
| `sys_risk_event` | `occurred_at` | 月度 | 1 年 |
| `sys_perm_log` | `created_at` | 月度 | 90 天 |
| `sys_session_log` | `created_at` | 月度 | 1 年 |

**分区创建示例：**

```sql
CREATE TABLE sys_audit_log (
    ...
) PARTITION BY RANGE (occurred_at);

-- 每月由定时任务创建下月分区
CREATE TABLE IF NOT EXISTS sys_audit_log_2026_05
    PARTITION OF sys_audit_log
    FOR VALUES FROM ('2026-05-01') TO ('2026-06-01');

-- 归档：DETACH 后导出再 DROP
ALTER TABLE sys_audit_log DETACH PARTITION sys_audit_log_2026_01;
```

**注意：** 分区表的主键必须包含分区键。

```sql
-- 正确
PRIMARY KEY (id, occurred_at)
-- 或使用唯一索引
CREATE UNIQUE INDEX uk_audit_id ON sys_audit_log (audit_id, occurred_at);
```
