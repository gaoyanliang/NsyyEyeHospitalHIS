## 1. 模块概述

### 1.1 模块定位

**M15-04 回答一个问题：一级库里的耗材，是怎么到用它的地方去的？**

出库是库存的**唯一合法减少入口**（除了盘点调减与报损）。它是「一级总库 → 二级库 / 使用科室」这一物理移动过程的完整记录。

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                       M15-04 出库与二级库全景                                  │
└──────────────────────────────────────────────────────────────────────────────┘

                   ┌──────────────────────────────────────┐
                   │        一级总库（CENTRAL）            │
                   │  m15_stock + m15_stock_batch           │
                   │  归属科室采购 → 库管员统一管理          │
                   └───────┬──────────────────┬────────────┘
                           │                  │
          ┌────────────────┘                  └────────────────┐
          │ ① 科室领用出库                    ② 调拨出库        │
          │    （日常消耗、非手术）              （库房间转移）    │
          ▼                                                     ▼
  ┌───────────────────────┐                          ┌──────────────────────┐
  │  使用科室（二级库）     │                          │   其他一级库/分库     │
  │  如：门诊治疗室        │                          │  （调拨目标库）       │
  └───────────────────────┘                          └──────────────────────┘

                           │ ③ 手术备台出库
                           ▼
                   ┌──────────────────────────────────────┐
                   │      手术室二级库（OPERATING）         │
                   │  按台次备台 → 器械护士签收              │
                   │  术中扫码消耗 → 术后退料                │
                   │  （消耗与退料归 M15-06）                │
                   └──────────────────────────────────────┘

   旁支：
   ④ 报损出库（发现破损、过期）→ 不走二级库，直接报废，需审批
   ⑤ 退货出库（退回供应商）→ 归 M15-03 采购退货，本子模块只做库存扣减
```

### 1.2 为什么出库与二级库独立成子模块

| # | 理由 | 若合并到 M15-01 的后果 |
|---|---|---|
| 1 | **出库是「一次性承诺」，不是「数量增减」** | M15-01 只管「现在有多少」。合并后没有「谁在什么时候为什么领走了多少」的完整记录，科室间扯皮无据可查 |
| 2 | **二级库有独立的实物管理责任** | 手术室二级库的 60 片人工晶体价值 30~90 万元，物理上在手术室、账上在库管系统。若不独立，二级库的盘点、交接、责任划分无处承载 |
| 3 | **出库有多层审批与限额控制** | 单次领用超 5,000 元需科长审批、超科室月度限额需预警。这些规则与库存台账的职责完全不同 |
| 4 | **出库流程与入库流程是对称的两套** | 入库有「到货→验收→入库」三道门，出库必须有「申请→审批→拣货→出库→签收」五道门。合并会让 M15-01 同时承担两条流程 |
| 5 | **出库失败模式与入库完全不同** | 入库失败在「验收不合格」，出库失败在「库存不足、批次过期、审批未过」。分开才能分别优化失败率指标 |

### 1.3 与相邻子模块的分工

| 职责 | 归属 | 说明 |
|---|---|---|
| 库存台账、库位、批次、流水 | **M15-01** | M15-04 通过内部契约读写 |

| **科室领用出库、调拨出库、报损出库** | **M15-04 ✅** | 唯一责任 |

| **手术备台出库、术中消耗、术后退料** | **M15-06** | M15-04 只管「货到二级库」，M15-06 管「二级库到患者」 |

### 1.4 概念辨析

| 易混概念 | 区别 |
|---|---|
| **出库 ≠ 消耗** | 出库是「一级库 → 二级库」的物理移动（责任人：库管员）；消耗是「二级库 → 患者」的使用（责任人：器械护士）。**M06-06 的「材料退回率」统计的正是「备台出库后没用退回」的比例，两者不分开这个指标根本算不出来** |
| **调拨 ≠ 领用** | 调拨是「仓库 ↔ 仓库」，不改变医院总库存；领用是「仓库 → 消耗科室」，医院总库存不变但科目从「库存物资」转为「已领用成本」 |
| **二级库 ≠ 分库** | 二级库是「使用科室自管的小库」（手术室、门诊治疗室），一般无独立采购权，靠一级库补货；分库是「一级库的一个物理分布」（如城东院区分库），有独立采购权 |
| **报损 ≠ 退货** | 报损是「东西不能用了，报废」（无对价方）；退货是「东西退回供应商，冲减应付」（有对价方，归 M15-03） |
| **锁定 ≠ 出库** | 锁定是「预占」，库存还在；出库是「实物已离开仓库」，库存减少。M15-02 锁定 + M15-04 出库是同一个业务动作的两个阶段 |

### 1.5 模块目标

| 编号 | 目标 | 现状 | 目标值 | 度量方式 |
|---|---|---|---|---|
| G-01 | 出库单及时生成率 | 手工约 70% | ≥98% | 有出库动作即生成单据的比例 |
| G-02 | 出库审批及时率 | 约 60% | ≥95% | 4 小时内完成审批的比例 |
| G-03 | 拣货准确率 | 约 96% | ≥99.5% | 拣货批次与申请一致的比例 |
| G-04 | 二级库账实相符率 | 约 85% | ≥98% | 盘点相符品种 / 总盘点品种 |
| G-05 | 手术备台齐套率 | 约 88% | ≥99% | 备台一次配齐的比例 |
| G-06 | 备台到签收时长 | 约 45 分钟 | ≤20 分钟 | 出库完成到二级库签收的中位数 |
| G-07 | 报损率 | 约 2.1% | ≤0.6% | 报损金额 / 出库金额 |
| G-08 | 高值耗材二级库交接完成率 | 约 50% | **100%** | 每班次交接执行的比例 |

## 3. 业务模型

### 3.1 四层单据模型

```
出库申请（m15_issue）
    │ 1 : N
    ▼
出库明细（m15_issue_item）
    │ 1 : N（一明细可按批次拆多行）
    ▼
出库批次（m15_issue_batch）
    │
    ▼
库存流水（m15_stock_txn，M15-01）
```

**为什么「出库明细」与「出库批次」分两张表：**

一条明细「一次性手术包 白内障 × 2 套」可能来自两个批次（B240501 一套、B240715 一套）。若只记明细，库存扣减时不知道扣了哪一批，FEFO 与追溯全部失效。

### 3.2 出库单类型与流程

| 类型 | `issue_type` | 审批 | 目标 | 谁发起 |
|---|---|---|---|---|
| 科室领用 | `REQUISITION` | 按金额 | 使用科室二级库 | 科室申领人 |
| 调拨 | `TRANSFER` | 科长 | 其他库 | 库管员 |
| 手术备台 | `PREPARE` | 免审（限定额度） | 手术室二级库 | M15-06 |
| 报损 | `SCRAP` | 质量负责人 | 报废（不入任何库） | 库管员/科室 |
| 采购退货 | `RETURN` | M15-03 审批 | 供应商（出库单由 M15-03 生成） | M15-03 |

### 3.3 出库单状态机（7 态）

```
┌────────┐  提交   ┌──────────────┐  审批通过  ┌───────────┐
│ DRAFT  │───────►│ SUBMITTED    │─────────►│ APPROVED  │
│ 草稿    │        │ 已提交待审批  │          │ 已批准     │
└───┬────┘        └──────┬───────┘          └─────┬─────┘
    │                    │ 驳回                    │ 拣货
    │ 作废                ▼                        ▼
    │              ┌───────────┐           ┌─────────────┐
    │              │ REJECTED  │           │  PICKING    │
    │              └───────────┘           │  拣货中      │
    │                                       └──────┬──────┘
    │                                              │ 确认出库
    │                                              ▼
    │                                       ┌─────────────┐
    │                                       │  ISSUED     │
    │                                       │  已出库      │
    │                                       └──────┬──────┘
    ▼                                              │ 签收
┌───────────┐                                      ▼
│ CANCELLED │                              ┌─────────────┐
└───────────┘                              │  RECEIVED   │
                                           │  已签收（终态）│
                                           └─────────────┘
```

**关键设计：`ISSUED` 与 `RECEIVED` 分开**

出库（库管员确认货离开一级库）与签收（二级库管理员确认货到了）之间有时间差，且可能出问题（途中丢失、送错科室）。若合并成「已出库」，出了问题（二级库没收到）无法定位是「出了没问题」还是「中途丢了」。

### 3.4 数量恒等式

```
申请数量（requested_qty）
  = 批准数量（approved_qty）    ← 审批可减量
  = 实发数量（issued_qty）      ← 拣货可缺货
  + 缺货数量（short_qty）

实发数量（issued_qty）
  = 各批次实发数量之和（m15_issue_batch.qty）
```

数据库落地：

```sql
-- 明细层
CHECK (approved_qty >= 0 AND approved_qty <= requested_qty)
CHECK (issued_qty >= 0 AND issued_qty <= approved_qty)
CHECK (short_qty = approved_qty - issued_qty)

-- 批次层
CHECK (qty > 0)
```

**为什么允许「实发 < 批准」而不阻断：**

库存不足是常态（尤其是高值耗材按需采购）。若阻断，库管员只能把申请单退回让科室重提，白跑一趟。允许「部分实发 + 缺货记录」，缺货量进入次日补货建议——这是「先满足能给的，缺的记录下来」的务实做法。

### 3.5 审批路由模型

| 条件 | 审批人 | 说明 |
|---|---|---|
| 同科室，金额 ≤5,000 元 | 科室负责人 | 常规领用 |
| 同科室，金额 >5,000 元 | 科室负责人 + 耗材科科长 | 大额领用 |
| 跨科室（申领科室 ≠ 库房归属科室） | 耗材科科长 | 跨科领用 |
| 手术备台（`PREPARE`） | 免审（单次 ≤ 配置限额） | 保障手术，额度内先出后审 |
| 报损（`SCRAP`） | 质量负责人 | 需原因与照片 |

**为什么手术备台免审：**

手术室每天备台 30~60 次，若每次审批，审批人会被淹没；而备台是「术前必须发生的动作」，审不审都要做。设计上：单次备案金额在 `M15.ISSUE.PREPARE_AUDIT_FREE`（默认 50,000）以内免审，超出走科长审批。**风险由 M15-06 的「术后退料率 ≥90%」指标反向控制**——备多了不用会拉低退料率。

### 3.6 二级库模型

**二级库的四种视角：**

| 视角 | 含义 |
|---|---|
| 物理 | 使用科室里实际放货的柜子/房间 |
| 账务 | 库存仍属医院资产，科目为「库存物资」 |
| 责任 | 由科室负责人（或指定管理员）负责 |
| 补货 | 由一级库按「最低库存 + 补货点」自动补货 |

**二级库与一级库的差异：**

| 维度 | 一级库 | 二级库 |
|---|---|---|
| 归属 | 耗材科 | 使用科室 |
| 采购权 | 有 | 无（只能向一级库申领） |
| 库存精度 | 批号 + 序列号 | 批号（高值二级库也管序列号） |
| 盘点频率 | 月度 | 每日（高值柜）+ 月度（普通） |
| 责任人 | 库管员 | 科室负责人 |
| 是否需要交接 | 否 | **是**（高值柜每班次交接） |

**为什么高值柜必须每班次交接：**

手术室高值柜 60 片晶体，价值 30~90 万元。交班时若不点数量，下一班发现少了 2 片也说不清是哪一班丢的。交接单要记录「账面数 / 实点数 / 差异 / 交接双方签名」，差异 >0 立即启动查找流程。

### 3.7 调拨模型

```
调拨出库：A 库 → B 库
   ① A 库库管员创建调拨出库单，审批
   ② A 库拣货、确认出库 → A 库库存减少（OUT_TRANSFER）
   ③ 实物运输（可能有 1~2 天）
   ④ B 库管理员签收 → B 库库存增加（IN_TRANSFER）
```

**「在途库存」的处理：**

② 到 ④ 之间，库存「不在 A 库、也不在 B 库」。若系统只记 `qty_on_hand`，会出现「总共少了 100 片」的假警报。

处理方式：M15-01 的 `m15_stock_txn` 中 `OUT_TRANSFER` 与 `IN_TRANSFER` 是两条流水，两条流水之间的差额即「在途」。查询「全院可用库存」时：

```
全院可用 = SUM(各库 qty_available) + SUM(在途数量)
```

**为什么允许调拨长期在途：**

跨院区调拨（城东分院 → 总院）物流 1~2 天是正常的。若要求「当天必须签收」，会迫使库管员提前签收（乱账）。设计上允许在途，但超 `M15.ISSUE.TRANSFER_ALERT_DAYS`（默认 3 天）未签收触发告警。

### 3.8 报损模型

**报损四种原因：**

| 原因 | 说明 | 审批 |
|---|---|---|
| `EXPIRED` | 过期失效 | 质量负责人 |
| `DAMAGED` | 破损、污染 | 质量负责人 |
| `RECALLED` | 召回 | 质量负责人 + 医务科 |
| `OTHER` | 其他（需说明） | 质量负责人 |

**为什么报损率是核心指标：**

报损率 = 报损金额 / 出库金额。现状约 2.1%（含临期未能及时使用），目标 ≤0.6%。按年出库 1,200 万元计，**2.1% 是 25.2 万元，0.6% 是 7.2 万元，年节省 18 万元**。

报损率的治理手段是 FEFO（M15-02）+ 近效期预警（M15-01）+ 二级库补货控制（本模块）。

### 3.9 手术备台出库模型

```
M15-06 生成备台清单（基于 M09 台次预计耗材）
        │
        ▼
M15-04 生成 PREPARE 出库单（免审）
        │
        ▼
库管员按手术室补货周期统一拣货（每日 06:00 / 14:00 两批）
        │
        ▼
送往手术室 → 器械护士签收
        │
        ▼
术中消耗（M15-06）→ 术后退料（M15-06）
```

**为什么备台出库按批次统一拣货而不是逐台次拣：**

若按台次逐单拣货，一天 40 台手术要拣 40 次，库管员来回应答 40 次。按批次统一拣（每日两批），一次拣完 20 台手术的耗材，效率提升 20 倍。代价是「上午拣的货下午才用」——但耗材不是易腐品，可接受。

**例外**：高值耗材（人工晶体等）必须逐台次拣货——因每片晶体对应具体患者的度数，混在一起会发错。

### 3.10 出库与成本

出库时按批次实际成本计入科室成本：

```
出库金额 = SUM(批次数量 × 该批次 unit_cost)
```

**为什么按批次实际成本而不是移动加权平均：**

人工晶体采购价 2,800 与 3,200 可能同月进货。若用移动加权平均，每片成本变成 3,000，既不是真实的 2,800 也不是 3,200。批次成本法下：

- 科室领到 B240815 批次（2,800）就是 2,800
- 财务能算出「这个月因批次不同导致的成本波动」
- 高值耗材单价差异大，批次法才反映真实成本

    @classmethod
    async def list_issues(cls, query, user: dict) -> dict:
        """出库单列表。"""
        db = get_session()
        async with db as session:
            where = ["is_deleted = FALSE"]
            params = {}
            if query.status:
                where.append("status = :status")
                params["status"] = query.status
            if query.issue_type:
                where.append("issue_type = :itype")
                params["itype"] = query.issue_type
            if query.dept_id:
                where.append("dept_id = :dept_id")
                params["dept_id"] = query.dept_id
            if query.date_from:
                where.append("issue_date >= :d0")
                params["d0"] = query.date_from
            if query.date_to:
                where.append("issue_date <= :d1")
                params["d1"] = query.date_to
            if not user.get("has_permission", lambda p: False)("m15:issue:all"):
                where.append(
                    "(dept_id = :u_dept OR created_by = :u_id)"
                )
                params["u_dept"] = user.get("dept_id") or -1
                params["u_id"] = user["employee_id"]
            where_sql = " AND ".join(where)

            total = int(
                (
                    await session.execute(
                        text("SELECT COUNT(*) FROM m15_issue WHERE " + where_sql),
                        params,
                    )
                ).scalar()
                or 0
            )
            params["lim"] = query.page_size
            params["off"] = (query.page - 1) * query.page_size
            rows = (
                await session.execute(
                    text(
                        "SELECT id, issue_no, issue_type, dept_name, status, "
                        "total_amount, item_count, issue_date, created_by_name, "

    @classmethod
    async def create(cls, body, user: dict) -> dict:
        """创建出库申请。"""
        today = date.today()
        if body.expected_date < today:
            raise BizException("1504003", "期望出库日期不早于今天")
        if not body.items:
            raise BizException("1504004", "出库明细至少 1 项")

        codes = [it.material_code for it in body.items]
        if len(codes) != len(set(codes)):
            raise BizException("1504005", "同一耗材重复出现")

        for it in body.items:
            if Decimal(str(it.qty)) <= 0 or Decimal(str(it.qty)) % 1 != 0:
                raise BizException("1504006", "数量必须为正整数")

        if len((body.reason or "").strip()) < 10:
            raise BizException("1504007", "申请理由不足 10 字")

        if body.issue_type == "TRANSFER":
            if not body.target_warehouse_id or body.target_warehouse_id == body.warehouse_id:
                raise BizException("1504008", "调拨必须指定目标库且不同于出库库")
        if body.issue_type == "SCRAP":
            if not body.scrap_reason or not body.scrap_photos:
                raise BizException("1504009", "报损必须选择原因并上传照片")

        # 查询库存
        stock_map = await StockClient.available(
            body.warehouse_id, codes
        )
        short_items = [
            it.material_code
            for it in body.items
            if stock_map.get(it.material_code, Decimal("0")) <= 0
        ]

        # 估算金额（按当前批次成本加权）
        est_amount = Decimal("0")
        for it in body.items:
            info = await MaterialClient.brief(it.material_code)
            cost = Decimal(str(info.get("current_cost") or 0))
            est_amount += money4(Decimal(str(it.qty)) * cost)
        est_amount = money(est_amount)

        tier = cls._resolve_tier(est_amount, body.issue_type, body.dept_id, user)

        db = get_session()
        async with db as session:
            async with session.begin():
                issue_no = await cls._next_no(session)
                issue = M15Issue(
                    issue_no=issue_no,
                    issue_type=body.issue_type,
                    dept_id=body.dept_id,
                    dept_name=body.dept_name,
                    warehouse_id=body.warehouse_id,
                    warehouse_name=body.warehouse_name,
                    target_warehouse_id=body.target_warehouse_id,
                    target_warehouse_name=body.target_warehouse_name,
                    purpose=body.purpose,
                    reason=body.reason,
                    status="DRAFT",
                    issue_date=today,
                    expected_date=body.expected_date,
                    total_amount=est_amount,
                    item_count=len(body.items),
                    required_approver=tier,
                    created_by=user["employee_id"],
                    created_by_name=user["name"],
                )
                session.add(issue)
                await session.flush()

                for idx, it in enumerate(body.items, start=1):
                    info = await MaterialClient.brief(it.material_code)
                    cost = Decimal(str(info.get("current_cost") or 0))
                    session.add(
                        M15IssueItem(
                            issue_id=issue.id,
                            line_no=idx,
                            material_code=it.material_code,
                            material_name=info["material_name"],
                            spec=info.get("spec"),
                            unit=info.get("min_unit"),
                            requested_qty=Decimal(str(it.qty)),
                            approved_qty=Decimal("0"),
                            issued_qty=Decimal("0"),
                            short_qty=Decimal("0"),
                            unit_cost=money4(cost),
                            amount=Decimal("0"),
                        )
                    )

        await AuditClient.record(
            module="M15-04",
            action="ISSUE_CREATE",
            biz_id=issue.id,
            biz_no=issue_no,
            detail={"type": body.issue_type, "amount": str(est_amount)},
            user=user,
        )
        await cls._clear_cache(body.warehouse_id)

        return {
            "issue_id": issue.id,
            "issue_no": issue_no,
            "status": "DRAFT",
            "item_count": len(body.items),
            "estimated_amount": float(est_amount),
            "short_items": short_items,
            "required_approver": tier,
            "required_approver_name": ROLE_NAMES.get(tier, tier),
            "created_at": datetime.now().isoformat(),
        }

    @classmethod
    async def submit(cls, issue_id: int, body, user: dict) -> dict:
        """提交审批。"""
        db = get_session()
        async with db as session:
            async with session.begin():
                issue = (
                    await session.execute(
                        select(M15Issue).where(M15Issue.id == issue_id).with_for_update()
                    )
                ).scalar_one_or_none()
                if not issue:
                    raise BizException("1504001", "出库单不存在")

                    raise BizException("1504002", "出库单状态不允许此操作")

                    raise BizException("1504007", "申请理由不足 10 字")

                item_count = (
                    await session.execute(
                        text(
                            "SELECT COUNT(*) FROM m15_issue_item "
                            "WHERE issue_id = :iid AND is_deleted = FALSE"
                        ),
                        {"iid": issue_id},
                    )
                ).scalar()
                if not item_count:
                    raise BizException("1504004", "出库明细至少 1 项")

                # 备台免审
                if (
                    issue.issue_type == "PREPARE"
                    and issue.total_amount <= cls.PREPARE_AUDIT_FREE
                ):
                    old = issue.status
                    issue.status = "APPROVED"
                    issue.approved_by = 0
                    issue.approved_by_name = "系统免审"

                    return {
                        "issue_id": issue_id,
                        "issue_no": issue.issue_no,
                        "old_status": old,
                        "new_status": "APPROVED",
                        "audit_free": True,
                    }

                old = issue.status
                issue.status = "SUBMITTED"
                issue.submitted_at = datetime.now()

        await MessageClient.send_internal(
            to_role=issue.required_approver,
            title="出库申请待审批",
            content="%s %s 金额 %.2f 元待您审批"

            "issue_no": issue.issue_no,
            "old_status": old,
            "new_status": "SUBMITTED",
            "required_approver": issue.required_approver,
        }

    @classmethod
    async def approve(cls, issue_id: int, body, user: dict) -> dict:
        """审批通过。"""
        db = get_session()
        async with db as session:
            async with session.begin():
                issue = (
                    await session.execute(
                        select(M15Issue).where(M15Issue.id == issue_id).with_for_update()
                    )
                ).scalar_one_or_none()
                if not issue:
                    raise BizException("1504001", "出库单不存在")
                if issue.status != "SUBMITTED":
                    raise BizException("1504002", "出库单状态不允许此操作")
                if issue.created_by == user["employee_id"]:
                    raise BizException("1504011", "不能审批自己提交的申请")
                if issue.required_approver not in user.get("roles", []):
                    raise BizException("1504012", "审批权限不足该金额档位")

                # 审批可减量
                qty_map = {it.item_id: it.approved_qty for it in body.items} if body.items else {}
                if qty_map:
                    items = (
                        await session.execute(
                            select(M15IssueItem).where(M15IssueItem.issue_id == issue_id)
                        )
                    ).scalars()
                    for it in items:
                        if it.id in qty_map:
                            aq = Decimal(str(qty_map[it.id]))
                            if aq < 0 or aq > it.requested_qty:
                                raise BizException("1504016", "批准数量超出范围")
                            it.approved_qty = aq
                        else:
                            it.approved_qty = it.requested_qty
                else:
                    items = (
                        await session.execute(
                            select(M15IssueItem).where(M15IssueItem.issue_id == issue_id)
                        )
                    ).scalars()
                    for it in items:
                        it.approved_qty = it.requested_qty

                total = Decimal("0")
                for it in items:
                    total += money4(it.approved_qty * it.unit_cost)
                issue.total_amount = money(total)
                issue.status = "APPROVED"
                issue.approved_by = user["employee_id"]
                issue.approved_by_name = user["name"]
                issue.approved_at = datetime.now()
                issue.approval_comment = body.comment

        await MessageClient.send_internal(
            to_user=issue.created_by,
            title="出库申请已批准",
            content="%s 已批准，可拣货出库" % issue.issue_no,
            biz_url="/m15/issue/%d" % issue_id,
        )
        await cls._clear_cache(issue.warehouse_id)

        return {
            "issue_id": issue_id,
            "issue_no": issue.issue_no,
            "old_status": "SUBMITTED",
            "new_status": "APPROVED",
            "approved_amount": float(issue.total_amount),
            "approved_by_name": user["name"],
            "approved_at": datetime.now().isoformat(),
        }

    @classmethod
    async def allocate(cls, issue_id: int, user: dict) -> dict:
        """拣货页：调 M15-02 分配批次。"""
        db = get_session()
        async with db as session:
            issue = (
                await session.execute(
                    select(M15Issue).where(M15Issue.id == issue_id)
                )
            ).scalar_one_or_none()
            if not issue:
                raise BizException("1504001", "出库单不存在")
            if issue.status not in ("APPROVED", "PICKING"):
                raise BizException("1504002", "出库单状态不允许拣货")

            items = list(
                (
                    await session.execute(
                        select(M15IssueItem)
                        .where(M15IssueItem.issue_id == issue_id)
                        .order_by(M15IssueItem.line_no)
                    )
                ).scalars()
            )

        result_items = []
        short_count = 0
        est_amount = Decimal("0")
        for it in items:
            try:
                alloc = await AllocClient.allocate(
                    warehouse_id=issue.warehouse_id,
                    material_code=it.material_code,
                    qty=it.approved_qty,
                    biz_type="ISSUE",
                    biz_id=issue_id,
                )
                batches = alloc.get("items", [])
                avail = sum(Decimal(str(b["qty"])) for b in batches)
                suggest = min(avail, it.approved_qty)
                for b in batches:
                    est_amount += money4(
                        Decimal(str(b["qty"])) * Decimal(str(b.get("unit_cost") or 0))
                    )
            except Exception as exc:
                logger.warning(
                    "分配服务失败 material=%s err=%s，降级为手工选批",
                    it.material_code,
                    exc,
                )
                stock = await StockClient.available_codes(
                    issue.warehouse_id, [it.material_code]
                )
                batches = stock
                avail = sum(Decimal(str(b["qty"])) for b in batches)
                suggest = min(avail, it.approved_qty)

            if suggest < it.approved_qty:
                short_count += 1

            result_items.append({
                "item_id": it.id,
                "material_code": it.material_code,
                "material_name": it.material_name,
                "spec": it.spec,
                "unit": it.unit,
                "requested_qty": float(it.requested_qty),
                "approved_qty": float(it.approved_qty),
                "available_qty": float(avail),
                "batches": batches,
                "suggest_issued_qty": float(suggest),
                "short_qty": float(it.approved_qty - suggest),
            })

        return {
            "issue_id": issue_id,
            "issue_no": issue.issue_no,
            "strategy": "FEFO",
            "items": result_items,
            "summary": {
                "item_count": len(items),
                "estimated_amount": float(money(est_amount)),
                "short_item_count": short_count,
            },
        }

    @classmethod
    async def confirm_issue(cls, issue_id: int, body, user: dict) -> dict:
        """确认出库：写批次 + 调库存 + 释放锁定。"""
        db = get_session()
        async with db as session:
            async with session.begin():
                issue = (
                    await session.execute(
                        select(M15Issue).where(M15Issue.id == issue_id).with_for_update()
                    )
                ).scalar_one_or_none()
                if not issue:
                    raise BizException("1504001", "出库单不存在")
                if issue.status == "ISSUED":
                    raise BizException("1504018", "该出库单已出库，不可重复操作")
                if issue.status not in ("APPROVED", "PICKING"):
                    raise BizException("1504002", "出库单状态不允许出库")

                items = {
                    it.id: it
                    for it in (
                        await session.execute(
                            select(M15IssueItem).where(M15IssueItem.issue_id == issue_id)
                        )
                    ).scalars()
                }

                # 逐项校验批次可用量并写批次记录
                for pik in body.items:
                    it = items.get(pik.item_id)
                    if not it:
                        raise BizException("1504004", "出库明细不存在")
                    total_qty = Decimal("0")
                    total_amt = Decimal("0")
                    for b in pik.batches:
                        batch = await StockClient.batch_detail(b.batch_id)
                        if not batch:
                            raise BizException("1504015", "批次不存在")
                        avail = Decimal(str(batch["qty_available"]))
                        if Decimal(str(b.qty)) > avail:
                            raise BizException(
                                "1504015",
                                "实发数量超过批次可用数量：%s 可用 %s"
                                % (batch["batch_no"], avail),
                            )
                        cost = Decimal(str(batch.get("unit_cost") or 0))
                        amt = money4(Decimal(str(b.qty)) * cost)
                        total_qty += Decimal(str(b.qty))
                        total_amt += amt
                        session.add(
                            M15IssueBatch(
                                issue_id=issue_id,
                                item_id=it.id,
                                batch_id=b.batch_id,
                                batch_no=batch["batch_no"],
                                location_code=batch.get("location_code"),
                                qty=Decimal(str(b.qty)),
                                unit_cost=money4(cost),
                                amount=amt,
                                expiry_date=batch.get("expiry_date"),
                            )
                        )
                    if total_qty > it.approved_qty:
                        raise BizException("1504016", "实发合计超过批准数量")
                    it.issued_qty = total_qty
                    it.short_qty = it.approved_qty - total_qty
                    it.amount = money(total_amt)

                # 汇总金额与缺货
                total_amount = Decimal("0")
                short_total = Decimal("0")
                for it in items.values():
                    total_amount += it.amount or Decimal("0")
                    short_total += it.short_qty or Decimal("0")

                issue.total_amount = money(total_amount)
                issue.short_qty_total = short_total
                issue.status = "ISSUED"
                issue.issued_at = datetime.now()
                issue.picker_note = body.picker_note

                issue_id_val = issue.id
                wh_id = issue.warehouse_id
                target_wh = issue.target_warehouse_id
                issue_type = issue.issue_type
                issue_no = issue.issue_no

        # 调 M15-01 出库（事务外，失败进补偿）
        try:
            txn_result = await StockClient.outbound(
                warehouse_id=wh_id,
                issue_id=issue_id_val,
                issue_type=issue_type,
                idempotency_key="ISSUE:%d" % issue_id_val,
                items=[
                    {
                        "batch_id": b.batch_id,
                        "material_code": it.material_code,
                        "qty": float(b.qty),
                    }
                    for it in items.values()
                    for b in [
                        x for x in body.items if x.item_id == it.id
                    ] for b in b.batches
                ],
                target_warehouse_id=target_wh,
            )
        except Exception as exc:
            logger.error("出库调用库存服务失败 issue_id=%s err=%s", issue_id_val, exc)
            raise BizException("1504025", "库存服务不可用，出库失败")

        # 释放 M15-02 锁定
        released = True
        try:
            await AllocClient.release(
                biz_type="ISSUE", biz_id=issue_id_val, reason="ISSUED"
            )
        except Exception as exc:
            released = False
            logger.warning("释放锁定失败 issue_id=%s err=%s", issue_id_val, exc)

        await AuditClient.record(
            module="M15-04",
            action="ISSUE_CONFIRM",
            biz_id=issue_id_val,
            biz_no=issue_no,
            detail={"amount": str(total_amount), "short": str(short_total)},
            user=user,
        )
        await cls._clear_cache(wh_id)

        return {
            "issue_id": issue_id_val,
            "issue_no": issue_no,
            "old_status": "APPROVED",
            "new_status": "ISSUED",
            "issued_amount": float(total_amount),
            "issued_qty_total": float(
                sum(it.issued_qty for it in items.values())
            ),
            "short_qty_total": float(short_total),
            "stock_txn_nos": txn_result.get("txn_nos", []),
            "lock_released": released,
            "issued_by_name": user["name"],
            "issued_at": datetime.now().isoformat(),
        }

    @classmethod
    async def receive(cls, issue_id: int, body: dict, user: dict) -> dict:
        """二级库签收：写二级库库存。"""
        db = get_session()
        async with db as session:
            async with db.begin():
                issue = (
                    await session.execute(
                        select(M15Issue).where(M15Issue.id == issue_id).with_for_update()
                    )
                ).scalar_one_or_none()
                if not issue:
                    raise BizException("1504001", "出库单不存在")
                if issue.status != "ISSUED":
                    raise BizException("1504002", "出库单状态不允许签收")
                if not issue.target_warehouse_id:
                    raise BizException("1504017", "出库单未指定目标库")

                items = {
                    it.id: it
                    for it in (
                        await session.execute(
                            select(M15IssueItem).where(M15IssueItem.issue_id == issue_id)
                        )
                    ).scalars()
                }

                has_diff = False
                diff_notes = []
                for ri in body.get("receive_items", []):
                    it = items.get(ri["item_id"])
                    if not it:
                        continue
                    rq = Decimal(str(ri["received_qty"]))
                    if rq != it.issued_qty:
                        has_diff = True
                        diff_notes.append(
                            "%s 出库 %s 实收 %s" % (it.material_code, it.issued_qty, rq)
                        )
                    it.received_qty = rq

                if has_diff and not body.get("diff_reason"):
                    raise BizException("1504029", "签收差异必须说明原因")
                if has_diff and len(str(body.get("diff_reason") or "").strip()) < 10:
                    raise BizException("1504029", "签收差异必须说明原因")

                issue.status = "RECEIVED"
                issue.received_by = user["employee_id"]
                issue.received_by_name = user["name"]
                issue.received_at = datetime.now()
                issue.receiver_signature = body.get("receiver_signature")
                issue.receive_diff_reason = body.get("diff_reason")

                issue_id_val = issue.id
                target_wh = issue.target_warehouse_id
                issue_no = issue.issue_no
                received_amount = issue.total_amount

        # 写二级库库存（M15-01 的 IN_TRANSFER 流水）
        try:
            txn_result = await StockClient.inbound_transfer(
                warehouse_id=target_wh,
                issue_id=issue_id_val,
                idempotency_key="ISSUE_RECV:%d" % issue_id_val,
                items=[
                    {"batch_id": b.batch_id, "material_code": it.material_code,
                     "qty": float(b.qty)}
                    for it in items.values()
                    for b in (
                        await cls._batches_of(issue_id_val, it.id)
                    )
                ],
            )
        except Exception as exc:
            logger.error("签收写二级库失败 issue_id=%s err=%s", issue_id_val, exc)
            raise BizException("1504025", "库存服务不可用，签收失败")

        await cls._clear_cache(target_wh)

        return {
            "issue_id": issue_id_val,
            "issue_no": issue_no,
            "old_status": "ISSUED",
            "new_status": "RECEIVED",
            "has_diff": has_diff,
            "diff_notes": diff_notes,
            "received_amount": float(received_amount),
            "secondary_wh_id": target_wh,
            "receiver_name": user["name"],
            "received_at": datetime.now().isoformat(),
            "stock_txn_nos": txn_result.get("txn_nos", []),
        }

    @classmethod

    async def stock(cls, wh_id: int, keyword, page, page_size, user) -> dict:

        db = get_session()
        async with db as session:
            where = ["s.warehouse_id = :wid", "s.is_deleted = FALSE"]
            params = {"wid": wh_id}
            if keyword:
                where.append(
                    "(s.material_code ILIKE :kw OR s.material_name ILIKE :kw)"
                )
                params["kw"] = "%" + keyword + "%"
            where_sql = " AND ".join(where)

            total = int(
                (
                    await session.execute(
                        text(
                            "SELECT COUNT(DISTINCT s.material_code) FROM m15_stock s "
                            "WHERE " + where_sql
                        ),
                        params,
                    )
                ).scalar()
                or 0
            )
            params["lim"] = page_size
            params["off"] = (page - 1) * page_size
            rows = (
                await session.execute(
                    text(
                        "SELECT s.material_code, s.material_name, s.spec, s.unit, "
                        "       SUM(s.qty_on_hand), SUM(s.qty_available), "
                        "       SUM(s.qty_on_hand * s.unit_cost) AS amount, "
                        "       MIN(s.expiry_date) AS nearest_expiry, "
                        "       sp.reorder_point "
                        "FROM m15_stock s "
                        "LEFT JOIN mdm_material_stock_policy sp "
                        "  ON sp.material_id = s.material_id AND sp.warehouse_id = s.warehouse_id "
                        "WHERE " + where_sql + " "
                        "GROUP BY s.material_code, s.material_name, s.spec, s.unit, "
                        "         sp.reorder_point "
                        "ORDER BY s.material_code LIMIT :lim OFFSET :off"
                    ),
                    params,
                )
            ).all()

        items = []
        for r in rows:
            qty = float(r[5] or 0)
            reorder = float(r[8] or 0)
            items.append({
                "material_code": r[0],
                "material_name": r[1],
                "spec": r[2],
                "unit": r[3],
                "qty_on_hand": float(r[4] or 0),
                "qty_available": qty,
                "amount": float(money(r[6] or 0)),
                "nearest_expiry": r[7].isoformat() if r[7] else None,
                "reorder_point": reorder,
                "need_replenish": qty <= reorder,
            })
        return {
            "warehouse_id": wh_id,
            "items": items,
            "total": total,
            "page": page,
            "page_size": page_size,
            "pages": (total + page_size - 1) // page_size,
        }

    @classmethod
    async def submit(cls, wh_id: int, body, user: dict) -> dict:
        """提交交接单。"""
        if body.to_staff_id == user["employee_id"]:
            raise BizException("1504021", "接班人不得为交班人本人")

        db = get_session()
        async with db as session:
            async with session.begin():
                # 检查是否已交接
                exist = (
                    await session.execute(
                        text(
                            "SELECT COUNT(*) FROM m15_secondary_handover "
                            "WHERE warehouse_id = :wid AND shift_type = :st "
                            "AND DATE(handover_at) = CURRENT_DATE AND is_deleted = FALSE"
                        ),
                        {"wid": wh_id, "st": body.shift_type},
                    )
                ).scalar()
                if int(exist or 0) > 0:
                    raise BizException("1504023", "该班次已完成交接")

                # 高值柜必须覆盖全部品种
                if body.is_high_value:
                    cnt = (
                        await session.execute(
                            text(
                                "SELECT COUNT(DISTINCT material_code) FROM m15_stock "
                                "WHERE warehouse_id = :wid AND is_deleted = FALSE "
                                "AND qty_on_hand > 0"
                            ),
                            {"wid": wh_id},
                        )
                    ).scalar()
                    if len(body.items) < int(cnt or 0):
                        raise BizException("1504022", "高值柜交接必须覆盖全部品种")

                diff_total = Decimal("0")
                for it in body.items:
                    d = Decimal(str(it.actual_qty)) - Decimal(str(it.book_qty))
                    diff_total += d
                    if d != 0 and len((it.remark or "").strip()) < 5:
                        raise BizException("1504020", "交接差异不为 0 必须填写备注")

                handover_no = await cls._next_no(session)
                handover = M15SecondaryHandover(
                    handover_no=handover_no,
                    warehouse_id=wh_id,
                    shift_type=body.shift_type,
                    handover_at=datetime.now(),
                    from_staff_id=user["employee_id"],
                    from_staff_name=user["name"],
                    to_staff_id=body.to_staff_id,
                    to_staff_name=body.to_staff_name,
                    diff_total=diff_total,
                    status="COMPLETED",
                    is_high_value=body.is_high_value,
                )
                session.add(handover)
                await session.flush()

                for idx, it in enumerate(body.items, start=1):
                    d = Decimal(str(it.actual_qty)) - Decimal(str(it.book_qty))
                    session.add(
                        M15SecondaryHandoverItem(
                            handover_id=handover.id,
                            line_no=idx,
                            material_code=it.material_code,
                            material_name=it.material_name,
                            book_qty=Decimal(str(it.book_qty)),
                            actual_qty=Decimal(str(it.actual_qty)),
                            diff_qty=d,
                            remark=it.remark,
                        )
                    )

        if diff_total != 0:
            await MessageClient.send_internal(
                to_role="NURSE_LEADER",
                title="高值柜交接差异告警",
                content="二级库 %d 交接差异 %s 件，请立即核查" % (wh_id, diff_total),
                biz_url="/m15/secondary/%d/handover" % wh_id,
            )
            logger.warning(
                "高值柜交接差异 warehouse=%s diff=%s", wh_id, diff_total
            )

        return {
            "handover_id": handover.id,
            "handover_no": handover_no,
            "diff_total": float(diff_total),
            "item_count": len(body.items),
            "status": "COMPLETED",
        }

    @classmethod
    async def _next_no(cls, session) -> str:
        today = date.today()
        rk = "m15:handover:seq:%s" % today.strftime("%Y%m%d")
        seq = await redis_client.incr(rk)
        if seq == 1:
            await redis_client.expire(rk, 172800)
        return "HO-%s-%04d" % (today.strftime("%Y%m%d"), seq)

### 6.7 专题：为什么出库必须「先确认批次，再写库存」

出库最后一个动作既要写「出库批次记录」（业务），又要调 M15-01「扣库存」（事实）。两种顺序都可能在异常时留下不一致：

| 顺序 | 异常点 | 结果 |
|---|---|---|
| A. 先扣库存再写批次 | 扣库存成功后写批次失败 | 库存已减，但查不到「扣了哪些批次」，追溯断链 |
| **B. 先写批次再扣库存** | 写批次成功后扣库存失败 | 有批次记录但库存未减，可重试（幂等键保证不重复扣） |
| C. 两者同一事务 | 跨服务无法同事务 | 不成立 |

**选 B 的理由**：批次记录是「出库意图」的落库，库存扣减是「意图生效」。意图先落库，生效失败可重试；反之生效先发生但意图丢失，就再也说不清扣的是什么。

**幂等保护：**

- 写批次：`m15_issue_batch` 用 `(issue_id, item_id, batch_id)` 唯一约束，重复写抛 `IntegrityError` → 视为已写过，跳过
- 扣库存：`idempotency_key = "ISSUE:{issue_id}"`，M15-01 对同一键第二次调用直接返回上次结果
- 状态机：`APPROVED/PICKING → ISSUED` 用 `with_for_update` + 状态判断，并发出库第二次进来会因状态已是 `ISSUED` 而抛 `"1504018"`

### 9.3 数据权限

```python
"""M15-04 数据权限。"""

from typing import Tuple

from sqlalchemy import Select

from app.models.m15.issue import M15Issue


def apply_issue_scope(stmt: Select, user: dict, domain: str = "DEPT") -> Select:
    """按数据权限域过滤。

    域：
      - ALL: 不过滤（耗材科、库房主管、财务）
      - DEPT: 按申领科室过滤
      - SELF: 按创建人过滤
    """
    has = user.get("has_permission", lambda p: False)
    if has("m15:issue:all"):
        return stmt
    if domain == "ALL":
        return stmt
    if domain == "DEPT":
        dept_id = user.get("dept_id")
        if not dept_id:
            return stmt.where(M15Issue.id == -1)
        return stmt.where(
            (M15Issue.dept_id == dept_id)
            | (M15Issue.created_by == user["employee_id"])
        )
    if domain == "SELF":
        return stmt.where(M15Issue.created_by == user["employee_id"])
    return stmt.where(M15Issue.id == -1)


def resolve_scope(user: dict) -> Tuple[str, str]:
    """决定默认域。"""
    if user.get("has_permission", lambda p: False)("m15:issue:all"):
        return "ALL", "全部"
    if user.get("dept_id"):
        return "DEPT", "本科室"
    return "SELF", "本人"
```

| 参数 | 政策来源 | 篡改后果 |
|---|---|---|
| `PREPARE_AUDIT_FREE` | 本院手术室耗材管理规定 | 调高 → 大额备台绕过审批；调低 → 手术室频繁等待审批 |
| `ISSUE.APPROVAL_TIER_1` | 本院物资领用制度 | 调高 → 大额领用免审 |
| `SECONDARY.HANDOVER_REQUIRED` | 高值耗材管理制度 | 关闭 → 高值柜无交接，丢失无法追责 |
