## 1. 模块概述

### 1.1 模块定位

**M15-05 回答一个问题：账上说有 100 片，柜子里到底有几片？差了的怎么办？**

盘点是库存管理的**自我校正机制**。M15-01 建立台账、M15-02 分配批次、M15-03 入库、M15-04 出库，这些动作**都依赖「数量记录正确」这个前提**。但现实中有六类偏差来源：

| 偏差来源 | 典型场景 |
|---|---|
| 收发错误 | 出库时少发 2 片，系统按 10 片记账 |
| 拣错批次 | 领 2 片却拿了 3 片 |
| 破损未报 | 掉地上碎了但没走报损 |
| 被盗 | 高值柜少 1 片晶体 |
| 系统错误 | 幂等漏做导致重复扣减 |
| 供应商短装 | 到货 100 但实际装 98，验收时未逐片点 |

**盘点是唯一能发现这些偏差的手段。** 而发现偏差后系统不能自动改账（自动改账等于掩盖问题），必须走「差异记录 → 原因分析 → 审批 → 调整单 → 库存流水」的完整流程。

### 1.2 为什么盘点与库存调整独立成子模块

| # | 理由 | 若合并到 M15-01 的后果 |
|---|---|---|
| 1 | **盘点是一个多阶段的业务流程，不是一次查询** | 有「制定计划 → 冻结出库 → 生成盘点表 → 实盘录入 → 差异分析 → 多级审批 → 生成调整单 → 库存生效」八个阶段，每个阶段有不同责任人 |
| 2 | **盘点必须冻结库存** | 盘点期间若有出库发生，账面数一直在变，实盘数永远对不上。冻结机制要跨子模块协调（M15-04/M15-06 都要配合） |
| 3 | **差异调整涉及金额审批** | 盘亏 500 元与盘亏 5 万元的处理完全不同。金额分级审批是独立的管理流程 |
| 4 | **盘点有独立的法规要求** | 《医疗器械经营质量管理规范》要求「定期盘点，做到账、货相符」；高值耗材要求「每月至少盘点一次」。《事业单位国有资产管理暂行办法》要求年度全面清查 |
| 5 | **盘点数据是独立的管理数据** | 盘点准确率、盘亏率、各库位差异分布是库房管理的核心 KPI，需要独立统计与趋势分析 |

| 职责 | 归属 | 说明 |
|---|---|---|

### 1.4 概念辨析

| 易混概念 | 区别 |
|---|---|
| **盘点 ≠ 对账** | 对账是「系统内部自校」（台账 vs 流水），**不涉及实物**；盘点是「实物 vs 账面」，必须走到货架前清点 |
| **盘亏 ≠ 报损** | 报损是「知道东西坏了，主动报废」；盘亏是「东西不知道去哪了」。报损有原因、有审批、走 M15-04 的报损出库；盘亏是不明原因的差异 |
| **盘盈 ≠ 好事** | 盘盈看似「多了」，实际最常见原因是「入库重复记录」或「出库漏记」。**盘盈与盘亏的处理流程完全相同** |
| **调整 ≠ 改账** | 调整是「按审批后的差异生成调整单 + 库存流水」，留下完整痕迹；改账是直接修改数字，破坏审计链 |
| **全面盘点 ≠ 循环盘点** | 全面盘点每月一次，停业或分批进行，盘所有品种；循环盘点每天盘一部分（如每天 5% 品种），不停业 |

### 1.5 模块目标

| 编号 | 目标 | 现状 | 目标值 | 度量方式 |
|---|---|---|---|---|

| G-02 | 账实相符率 | 约 85% | **≥98%** | 相符品种数 / 盘点品种数 |
| G-03 | 盘亏金额率 | 约 1.8%/年 | **≤0.3%/年** | 盘亏金额 / 库存年末金额 |
| G-04 | 盘盈盘亏处理闭环率 | 约 55% | **100%** | 有差异即有审批与原因的比例 |
| G-05 | 盘点耗时 | 一天（人工） | **≤3 小时** | 全库盘点从开始到完成 |
| G-06 | 高值耗材月度盘点执行率 | 约 50% | **100%** | 高值柜月度盘点完成比例 |

| 角色 | 职责 | 权限要点 |
|---|---|---|
| **盘点计划人**（库房主管） | 制定盘点计划、分配任务 | 不能自己实盘 |

## 3. 业务模型

### 3.1 盘点三类型

| 类型 | `stocktake_type` | 频率 | 范围 | 是否冻结 | 是否停业务 |
|---|---|---|---|---|---|
| **全面盘点** | `FULL` | 月度/季度 | 整个仓库 | **是** | 分批停业或非营业时段 |
| **循环盘点** | `CYCLE` | 每日 | 按规则抽出的部分品种 | 否（只冻结被盘批次） | 否 |
| **专项盘点** | `SPECIAL` | 按需 | 指定品种/批次/库位 | 可选 | 否 |

**为什么必须有循环盘点：**

全面盘点要停业务几个小时，每月一次已经是极限。但高值耗材（人工晶体）价值高、流转快，一个月不盘就可能丢 3~5 片而不自知。

循环盘点每天盘 5% 品种（按 ABC 分类：A 类高值每天盘、B 类每周、C 类每月），**无需停业**，20 天覆盖全库。代价是每日有少量额外工作量（约 30 分钟）。

### 3.2 盘点生命周期（10 态）

```
┌──────────┐ 创建  ┌──────────────┐ 生成盘点表 ┌──────────────┐ 开始实盘 ┌──────────────┐
│ PLANNING │─────►│ TABLE_READY  │──────────►│ COUNTING     │────────►│ COUNTED      │
│ 计划中    │      │ 盘点表已生成 │            │ 实盘中        │          │ 实盘完成     │
└──────────┘      └──────────────┘            └──────────────┘          └──────┬───────┘
                                                                                 │ 差异分析
                                                                                 ▼
┌──────────┐ 驳回  ┌──────────────┐ 审批通过 ┌──────────────┐ 生成调整单 ┌──────────────┐
│ CANCELLED│◄─────│ REJECTED     │◄─────────│ PENDING_APPR │───────────►│ ADJUSTING    │
│ 已取消    │      │ 已驳回        │            │ 待审批        │            │ 调整中        │
└──────────┘      └──────────────┘            └──────────────┘            └──────┬───────┘
                                                                                 │ 全部生效
                                                                                 ▼
                                                                          ┌──────────────┐
                                                                          │ COMPLETED    │
                                                                          │ 已完成（终态）│
                                                                          └──────────────┘
```

**关键设计：`COUNTING` 与 `COUNTED` 分开**

一个仓库盘点 800 个品种可能需要 2 小时，中途盘点人会休息。`COUNTING` 表示「还有品种未录入」，`COUNTED` 表示「全部录完可以进入差异分析」。合并后无法知道盘点是否有遗漏。

### 3.3 库存冻结模型

**冻结方式两种：**

| 方式 | `freeze_mode` | 说明 | 场景 |
|---|---|---|---|
| **仓库级冻结** | `WAREHOUSE` | 该仓库全部出库停 | 全面盘点 |
| **批次级冻结** | `BATCH` | 只冻结被盘的批次 | 循环盘点、专项盘点 |

**冻结的跨子模块协作：**

```
M15-05 写冻结标记
        │
        ├─► m15_stocktake_freeze 表（冻结记录，含 warehouse_id / material_code / batch_no）
        │
        └─► Redis 键 m15:freeze:{warehouse_id}（快速查询）
                │
                ├─► M15-04 出库时校验：若命中冻结，返回 "1505010"
                ├─► M15-06 消耗时校验：若命中冻结，返回 "1505010"
                └─► M15-01 出库流水写入时校验：兜底拦截
```

**为什么冻结标记要落表而不是只放 Redis：**

Redis 重启会丢失冻结标记。若盘点进行到一半 Redis 挂了，出库恢复，账面数与实盘数就对不上，盘点作废重来。落表 + Redis 缓存，Redis 挂了从表里重建。

**为什么冻结粒度要支持批次级：**

循环盘点每天盘 5% 品种，若把整个仓库冻结，等于每天停业 30 分钟，业务无法接受。批次级冻结只锁被盘的批次，其他批次正常出库。

### 3.4 盘点表生成模型

**盘点表 = 盘点时刻的库存快照 + 待录入的实盘栏**

```
m15_stocktake_task（盘点任务，按仓库/区域）
    │ 1 : N
    ▼
m15_stocktake_item（盘点明细，一行 = 一个「耗材 + 批次 + 库位」组合）
    │ 字段：book_qty（账面数，快照）/ actual_qty（实盘数，待录）/ diff_qty（差异，生成列）
```

**为什么按「耗材 + 批次 + 库位」而不是只按耗材：**

M15-01 的台账唯一键是 `(warehouse_id, location_id, material_code, batch_no)`。同一耗材在 A-01-01 有 50 片、A-01-02 有 30 片，若盘点表只按耗材汇总成 80 片，实盘也是 80 片，看起来相符——但实际是 A-01-01 的 30 片跑到 A-01-02 去了，**批次错位没被发现**。

按库位+批次生成 2 行，盘点人必须分别核对两个货架，才能发现混放问题。

**例外配置**：`M15.STOCKTAKE.GROUP_BY` 可配为 `MATERIAL`（只按耗材汇总），用于品种多但库存少的场景（如小型二级库）。默认 `BATCH`。

### 3.5 差异计算与归因

**差异计算：**

```
差异数量 diff_qty = 实盘数量 actual_qty − 账面数量 book_qty
差异金额 diff_amount = |diff_qty| × 单价 unit_cost
```

**注意**：`diff_qty` 是**普通列而非生成列**。原因：实盘录入可能有多次修正（先录 98 再改成 99），每次修改要保留修改痕迹（`m15_stocktake_item_log`），且差异金额在调整时按审批后的单价计算，不能实时生成。

**七种差异原因：**

| 原因 | `diff_reason` | 典型场景 | 后续处理 |
|---|---|---|---|
| 收发错误 | `RECEIVING_ERROR` | 出库少发、入库多记 | 培训 + 流程改进 |
| 破损未报 | `UNDAMAGED_REPORT` | 掉地碎了没报废 | 加强报损意识 |
| 过期未报 | `EXPIRED_UNDETECTED` | 过期了还放在货架上 | 近效期预警优化 |
| 串货错位 | `MIXED_BATCH` | 两个批次混放，分不清 | 加强库位管理 |
| 盗损 | `THEFT` | 高值柜少件 | 报警 + 追责 |
| 系统错误 | `SYSTEM_ERROR` | 幂等漏做导致重复扣减 | 技术排查 + 修复 |
| 原因不明 | `UNKNOWN` | 查不清 | 记入管理成本 |

**归因强制规则：**

| 差异金额 | 是否须归因 |
|---|---|
| ≤ 100 元 | 可选 |
| 100 ~ 1,000 元 | 必须选原因 |
| 1,000 ~ 5,000 元 | 必须选原因 + 文字说明 ≥20 字 |
| > 5,000 元 | 必须选原因 + 文字说明 ≥50 字 + 上传调查报告 |

**为什么分级强制归因：**

盘亏 50 元的纱布不可能是盗窃，可能是掉地上了；盘亏 8,000 元的人工晶体若不查清，库房就会形成「丢了就调账」的习惯。分级的目的不是问责，是「大额差异必须有人真的去看过」。

### 3.6 调整审批模型

| 差异金额（累加） | 审批人 | 时限 |
|---|---|---|
| ≤ 500 元 | 库房主管 | 24h |
| 500 ~ 5,000 元 | 库房主管 + 耗材科科长 | 48h |
| 5,000 ~ 50,000 元 | 耗材科科长 + 财务 | 72h |
| > 50,000 元 | 耗材科科长 + 财务 + 分管院长 | 72h |

**审批显示的内容：**

审批人看到的不是「差异 8,000 元」这一个数字，而是：
- 差异明细（哪些品种、哪些批次、差多少）
- 归因结果与说明
- 近期同类差异（该品种近半年盘亏几次）
- 相关人员（盘点人、复核人）
- 历史调整记录

**为什么审批要看「近期同类差异」：**

某型号晶体半年盘亏 3 次共 12 片（约 4 万元），每次都是「原因不明」。若只看单次 3,000 元可能就批了；看到「3 次」这个事实，审批人就会要求彻查。

### 3.7 调整单与库存生效

```
审批通过
    │
    ▼
按差异生成调整明细（m15_stocktake_adjust）
    │ 汇总为 m15_stock_adjust（调整单）
    ▼
调 M15-01 POST /internal/v1/m15/stock/adjust
    │ 幂等键 ADJUST:{adjust_id}
    ▼
m15_stock_txn 写 ADJUST_STOCKTAKE 流水
    │ direction = IN（盘盈）/ OUT（盘亏）
    ▼
台账 qty_on_hand 变更
```

**为什么调整要一张调整单而不是直接改 800 条台账：**

- 调整单有单据号、有审批、有金额合计，是财务入账凭证
- M15-01 接口按「调整单」粒度幂等，一张调整单只生效一次
- 财务查「本月盘亏多少」直接查调整单，不用扫 800 条流水

### 3.8 循环盘点规则

**ABC 分类与盘点频率：**

| 分类 | 判定规则 | 盘点频率 | 覆盖天数 |
|---|---|---|---|
| A 类 | 年出库金额前 70%（约 60 个品种） | 每日 | 60 天全覆盖 |
| B 类 | 70%~90%（约 120 个品种） | 每周 | 120 天 |
| C 类 | 后 10%（约 320 个品种） | 每月 | 320 天 |

**自动生成逻辑：**

每日 06:00，`CycleStocktakeService.generate_daily()`：
1. 查上次盘点日期
2. 按分类计算「到期品种」
3. 生成 `CYCLE` 类型盘点任务
4. 盘点人当日完成，无需审批（差异 ≤100 元时）

**为什么 C 类每月盘一次而不是每季：**

C 类品种多（320 个）但价值低，若每季盘，一次要盘 100 个品种（约 1 小时）。每月盘一次每次约 15 个品种（10 分钟），工作量摊平更好执行。

### 3.9 抽查复核模型

**复核人做的事：**

| 复核方法 | 说明 | 抽样比例 |
|---|---|---|
| **全复核** | 逐项重新清点 | 差异项 100% |
| **抽复核** | 从相符项中随机抽查 | 相符项的 5%（最少 10 项） |
| **盲盘** | 复核人看不到账面数与盘点人数 | 全盘时用 |

**为什么要有抽复核：**

若盘点人把 100 项全填成「与账面一致」（偷懒），全复核只查差异项会发现 0 个差异——因为根本没有差异项。抽复核能在相符项中发现问题。

**判定**：抽复核发现 ≥2 项数量不符 → 该盘点人负责的全部区域重新盘。

### 6.2 错误码规范

| 错误码 | 说明 | 触发场景 |

| `"1505003"` | 计划日期不早于今天 | 创建 |
| `"1505004"` | 盘点仓库不存在或已停用 | 创建 |
| `"1505005"` | 盘点范围不得为空 | 生成盘点表 |
| `"1505006"` | 必须至少分配一名盘点人 | 创建 |
| `"1505007"` | 复核人不得与盘点人相同 | 创建/复核 |
| `"1505008"` | 该仓库已存在未完成的盘点 | 创建 |
| `"1505009"` | 仓库级冻结需要库房主管权限 | 生成盘点表 |
| `"1505010"` | 实盘数量必须为非负整数 | 录入 |
| `"1505011"` | 差异不为 0 必须选择原因 | 录入 |
| `"1505012"` | 大额差异说明不足 20 字 | 录入 |
| `"1505013"` | 大额差异必须上传附件 | 录入/提交 |
| `"1505014"` | 存在未盘点的明细项 | 完成盘点 |
| `"1505015"` | 抽复核发现多项差异，需重新盘点 | 提交复核 |
| `"1505016"` | 存在未归因的大额差异 | 提交审批 |
| `"1505017"` | 总体说明字数不足 | 提交审批 |
| `"1505018"` | 必须上传调查报告 | 提交审批 |
| `"1505019"` | 不能审批自己参与盘点的差异 | 审批 |

def resolve_diff_level(amount: Decimal):
    """按金额判定差异级别。"""
    abs_amount = abs(money(amount))
    for cap, level, min_len, need_attach in DIFF_LEVELS:

    return "CRITICAL", 50, True

    @classmethod
    async def generate(cls, stocktake_id: int, body: dict, user: dict) -> dict:
        """生成盘点表：快照库存 + 冻结。"""
        group_by = body.get("group_by") or "BATCH"
        include_zero = bool(body.get("include_zero_stock"))

        db = get_session()
        async with db as session:
            async with session.begin():
                st = (
                    await session.execute(
                        select(M15Stocktake)
                        .where(M15Stocktake.id == stocktake_id)
                        .with_for_update()
                    )
                ).scalar_one_or_none()
                if not st:
                    raise BizException("1505001", "盘点单不存在")
                if st.status != "PLANNING":
                    raise BizException("1505002", "盘点单状态不允许此操作")

                if st.freeze_mode == "WAREHOUSE" and not user.get(
                    "has_permission", lambda p: False
                )("m15:stocktake:freeze_all"):
                    raise BizException("1505009", "仓库级冻结需要库房主管权限")

                # 查库存快照
                where = ["warehouse_id = :wid", "is_deleted = FALSE"]
                params = {"wid": st.warehouse_id}
                if not include_zero:
                    where.append("qty_on_hand > 0")
                where_sql = " AND ".join(where)
                rows = (
                    await session.execute(
                        text(
                            "SELECT id, location_id, location_code, material_id, "
                            "material_code, material_name, spec, unit, batch_no, "
                            "qty_on_hand, unit_cost, expiry_date "
                            "FROM m15_stock WHERE " + where_sql + " ORDER BY location_code, material_code, batch_no"
                        ),
                        params,
                    )
                ).all()

                if not rows:
                    raise BizException("1505005", "盘点范围不得为空")

                # 写明细
                total_amount = Decimal("0")
                for idx, r in enumerate(rows, start=1):
                    amt = money2(Decimal(str(r[9] or 0)) * Decimal(str(r[10] or 0)))
                    total_amount += amt
                    session.add(
                        M15StocktakeItem(
                            stocktake_id=stocktake_id,
                            line_no=idx,
                            stock_id=r[0],
                            location_id=r[1],
                            location_code=r[2],
                            material_id=r[3],
                            material_code=r[4],
                            material_name=r[5],
                            spec=r[6],
                            unit=r[7],
                            batch_no=r[8],
                            book_qty=Decimal(str(r[9] or 0)),
                            actual_qty=None,
                            diff_qty=None,
                            unit_cost=money2(r[10] or 0),
                            diff_amount=Decimal("0"),
                            expiry_date=r[11],
                        )
                    )

                # 写冻结
                freeze = M15StocktakeFreeze(
                    stocktake_id=stocktake_id,
                    stocktake_no=st.stocktake_no,
                    warehouse_id=st.warehouse_id,
                    freeze_mode=st.freeze_mode,
                    scope_json={},
                    frozen_at=datetime.now(),
                    expire_at=datetime.now() + timedelta(hours=24),
                    status="ACTIVE",
                )
                session.add(freeze)
                await session.flush()

                st.item_count = len(rows)
                st.counted_count = 0
                st.total_book_amount = money2(total_amount)
                st.status = "TABLE_READY"
                st.freeze_id = freeze.id
                st.generated_at = datetime.now()

                freeze_id = freeze.id
                st_id = st.id
                st_no = st.stocktake_no
                freeze_mode = st.freeze_mode
                item_count = len(rows)
                material_count = len({r[4] for r in rows})
                wh_id = st.warehouse_id

        # 写 Redis 冻结标记
        await redis_client.setex(
            "m15:freeze:%d" % wh_id, 86400, str(freeze_id)
        )
        await cls._clear_cache(wh_id)

        return {
            "stocktake_id": st_id,
            "stocktake_no": st_no,
            "old_status": "PLANNING",
            "new_status": "TABLE_READY",
            "item_count": item_count,
            "material_count": material_count,
            "total_book_amount": float(money2(total_amount)),
            "freeze_id": freeze_id,
            "freeze_mode": freeze_mode,
            "freeze_expire_at": (datetime.now() + timedelta(hours=24)).isoformat(),
            "generated_at": datetime.now().isoformat(),
        }

    @classmethod
    async def count_one(cls, stocktake_id: int, item_id: int, body, user: dict) -> dict:
        """录入单项实盘数。"""
        db = get_session()
        async with db as session:
            async with session.begin():
                st = (
                    await session.execute(
                        select(M15Stocktake).where(M15Stocktake.id == stocktake_id)
                    )
                ).scalar_one_or_none()
                if not st:
                    raise BizException("1505001", "盘点单不存在")
                if st.status not in ("TABLE_READY", "COUNTING"):
                    raise BizException("1505002", "盘点单状态不允许录入")

                item = (
                    await session.execute(
                        select(M15StocktakeItem)
                        .where(M15StocktakeItem.id == item_id)
                        .with_for_update()
                    )
                ).scalar_one_or_none()
                if not item:
                    raise BizException("1505023", "盘点明细不存在")

                if body.version is not None and item.version != body.version:
                    raise BizException("1505024", "该明细已被他人录入")

                if body.actual_qty < 0 or Decimal(str(body.actual_qty)) % 1 != 0:
                    raise BizException("1505010", "实盘数量必须为非负整数")

                diff = Decimal(str(body.actual_qty)) - item.book_qty
                diff_amt = money2(abs(diff) * item.unit_cost)
                level, min_len, need_attach = resolve_diff_level(
                    diff * item.unit_cost
                )

                if diff != 0:
                    if not body.diff_reason:
                        raise BizException("1505011", "差异不为 0 必须选择原因")
                    if body.diff_reason not in DIFF_REASON_NAMES:
                        raise BizException("1505011", "差异不为 0 必须选择原因")
                    note = (body.diff_note or "").strip()
                    if len(note) < min_len:
                        raise BizException(
                            "1505012",
                            "大额差异说明不足 %d 字" % min_len,
                        )
                    if need_attach and not body.attachment_url:
                        raise BizException("1505013", "大额差异必须上传附件")

                item.actual_qty = Decimal(str(body.actual_qty))
                item.diff_qty = diff
                item.diff_amount = diff_amt
                item.diff_reason = body.diff_reason if diff != 0 else None
                item.diff_note = body.diff_note if diff != 0 else None
                item.attachment_url = body.attachment_url
                item.diff_level = level if diff != 0 else None
                item.counted_by = user["employee_id"]
                item.counted_by_name = user["name"]
                item.counted_at = datetime.now()
                item.version = item.version + 1

                # 更新盘点单计数
                if st.status == "TABLE_READY":
                    st.status = "COUNTING"
                st.counted_count = int(
                    (
                        await session.execute(
                            text(
                                "SELECT COUNT(*) FROM m15_stocktake_item "
                                "WHERE stocktake_id = :sid AND actual_qty IS NOT NULL "
                                "AND is_deleted = FALSE"
                            ),
                            {"sid": stocktake_id},
                        )
                    ).scalar()
                    or 0
                )

                result = {
                    "item_id": item.id,
                    "material_code": item.material_code,
                    "material_name": item.material_name,
                    "batch_no": item.batch_no,
                    "location_code": item.location_code,
                    "book_qty": float(item.book_qty),
                    "actual_qty": float(item.actual_qty),
                    "diff_qty": float(item.diff_qty),
                    "unit_cost": float(item.unit_cost),
                    "diff_amount": float(item.diff_amount),
                    "diff_level": item.diff_level,
                    "counted_count": st.counted_count,
                    "total_count": st.item_count,
                    "version": item.version,
                }

        return result

    @classmethod
    async def count_batch(cls, stocktake_id: int, body, user: dict) -> dict:
        """批量录入。"""
        results = []
        errors = []
        for it in body.items:
            try:
                r = await cls.count_one(
                    stocktake_id,
                    it.item_id,
                    type("B", (), {
                        "actual_qty": it.actual_qty,
                        "diff_reason": it.diff_reason,
                        "diff_note": it.diff_note,
                        "attachment_url": it.attachment_url,
                        "version": it.version,
                    })(),
                    user,
                )
                results.append(r)
            except BizException as exc:
                errors.append({"item_id": it.item_id, "code": exc.code, "message": exc.message})
        return {
            "succeeded": len(results),
            "failed": len(errors),
            "errors": errors,
            "items": results,
        }

    @classmethod
    async def scan(cls, stocktake_id: int, item_id: int, delta: int, user: dict) -> dict:
        """扫码累加。"""
        db = get_session()
        async with db as session:
            item = (
                await session.execute(
                    select(M15StocktakeItem).where(M15StocktakeItem.id == item_id)
                )
            ).scalar_one_or_none()
            if not item:
                raise BizException("1505023", "盘点明细不存在")
            cur = item.actual_qty if item.actual_qty is not None else Decimal("0")

            "diff_note": item.diff_note,

    @classmethod
    async def finish(cls, stocktake_id: int, user: dict) -> dict:
        """完成盘点：校验无未盘项。"""
        db = get_session()
        async with db as session:
            async with session.begin():
                st = (
                    await session.execute(
                        select(M15Stocktake)
                        .where(M15Stocktake.id == stocktake_id)
                        .with_for_update()
                    )
                ).scalar_one_or_none()
                if not st:
                    raise BizException("1505001", "盘点单不存在")
                if st.status != "COUNTING":
                    raise BizException("1505002", "盘点单状态不允许完成")

                pending = (
                    await session.execute(
                        text(
                            "SELECT COUNT(*) FROM m15_stocktake_item "
                            "WHERE stocktake_id = :sid AND actual_qty IS NULL "
                            "AND is_deleted = FALSE"
                        ),
                        {"sid": stocktake_id},
                    )
                ).scalar()
                if int(pending or 0) > 0:
                    raise BizException(
                        "1505014", "存在 %d 项未盘点" % int(pending)
                    )

                # 统计差异
                row = (
                    await session.execute(
                        text(
                            "SELECT COUNT(*), COALESCE(SUM(diff_amount),0) "
                            "FROM m15_stocktake_item WHERE stocktake_id = :sid "
                            "AND diff_qty IS NOT NULL AND diff_qty <> 0 AND is_deleted = FALSE"
                        ),
                        {"sid": stocktake_id},
                    )
                ).first()

                st.status = "COUNTED"
                st.diff_item_count = int(row[0] or 0)
                st.diff_amount = money2(
                    Decimal(str(row[1] or 0))
                    * Decimal("-1")
                )
                st.finished_at = datetime.now()

        return {
            "stocktake_id": stocktake_id,
            "stocktake_no": st.stocktake_no,
            "old_status": "COUNTING",
            "new_status": "COUNTED",
            "diff_item_count": st.diff_item_count,
            "diff_amount": float(st.diff_amount),
            "finished_at": datetime.now().isoformat(),
        }

        db = get_session()

            total = int(
                (
                    await session.execute(
                        text(
                            "SELECT COUNT(*) FROM m15_stocktake_item "
                            "WHERE stocktake_id = :sid AND diff_qty IS NOT NULL "
                            "AND diff_qty <> 0 AND is_deleted = FALSE"

                        "FROM m15_stocktake_item WHERE stocktake_id = :sid "

                        "ORDER BY abs(diff_amount) DESC LIMIT :lim OFFSET :off"
                    ),
                    {"sid": stocktake_id, "lim": page_size, "off": (page - 1) * page_size},
                )
            ).all()

            summ = (
                await session.execute(
                    text(
                        "SELECT "
                        " SUM(CASE WHEN diff_qty < 0 THEN 1 ELSE 0 END), "
                        " SUM(CASE WHEN diff_qty < 0 THEN diff_amount ELSE 0 END), "
                        " SUM(CASE WHEN diff_qty > 0 THEN 1 ELSE 0 END), "
                        " SUM(CASE WHEN diff_qty > 0 THEN diff_amount ELSE 0 END) "
                        "FROM m15_stocktake_item WHERE stocktake_id = :sid "
                        "AND diff_qty IS NOT NULL AND diff_qty <> 0 AND is_deleted = FALSE"
                    ),
                    {"sid": stocktake_id},
                )
            ).first()

        items = []
        for r in rows:
            items.append({
                "item_id": r[0],
                "material_code": r[1],
                "material_name": r[2],
                "batch_no": r[3],
                "location_code": r[4],
                "book_qty": float(r[5] or 0),
                "actual_qty": float(r[6]) if r[6] is not None else None,
                "diff_qty": float(r[7] or 0),
                "unit_cost": float(r[8] or 0),
                "diff_amount": float(r[9] or 0),
                "diff_reason": r[10],
                "diff_reason_text": DIFF_REASON_NAMES.get(r[10]),
                "diff_note": r[11],
                "diff_level": r[12],
                "attachment_url": r[13],
            })

        loss_amount = -float(summ[1] or 0)
        gain_amount = float(summ[3] or 0)
        return {
            "items": items,
            "total": total,
            "page": page,
            "page_size": page_size,
            "pages": (total + page_size - 1) // page_size,
            "summary": {
                "loss_count": int(summ[0] or 0),
                "loss_amount": -loss_amount,
                "gain_count": int(summ[2] or 0),
                "gain_amount": gain_amount,
                "net_amount": round(gain_amount - loss_amount, 2),
            },
        }

    @classmethod
    async def diff_summary(cls, stocktake_id: int, user: dict) -> dict:
        """差异按归因汇总。"""
        db = get_session()
        async with db as session:
            rows = (
                await session.execute(
                    text(
                        "SELECT diff_reason, COUNT(*), COALESCE(SUM(diff_amount),0) "
                        "FROM m15_stocktake_item WHERE stocktake_id = :sid "
                        "AND diff_qty IS NOT NULL AND diff_qty <> 0 AND is_deleted = FALSE "
                        "GROUP BY diff_reason ORDER BY 3 DESC"
                    ),
                    {"sid": stocktake_id},
                )
            ).all()

        total = sum(float(r[2] or 0) for r in rows)
        items = [
            {
                "diff_reason": r[0] or "UNKNOWN",
                "diff_reason_text": DIFF_REASON_NAMES.get(r[0] or "UNKNOWN", "原因不明"),
                "count": int(r[1] or 0),
                "amount": float(r[2] or 0),
                "ratio": round(float(r[2] or 0) / total, 4) if total else 0,
            }
            for r in rows
        ]
        return {"items": items, "total_amount": total}

    @classmethod
    async def check(cls, warehouse_id: int, material_code, batch_no) -> dict:
        """检查是否冻结（M15-04/M15-06 调用）。"""
        cached = await redis_client.get("m15:freeze:%d" % warehouse_id)
        if cached:
            db = get_session()
            async with db as session:
                row = (
                    await session.execute(
                        text(
                            "SELECT f.id, f.freeze_mode, f.stocktake_no, s.status, f.expire_at "
                            "FROM m15_stocktake_freeze f "
                            "JOIN m15_stocktake s ON s.id = f.stocktake_id "
                            "WHERE f.warehouse_id = :wid AND f.status = 'ACTIVE' "
                            "AND f.is_deleted = FALSE LIMIT 1"
                        ),
                        {"wid": warehouse_id},
                    )
                ).first()
                if row:
                    return {
                        "frozen": True,
                        "freeze_id": row[0],
                        "freeze_mode": row[1],
                        "stocktake_no": row[2],
                        "stocktake_status": row[3],
                        "expire_at": row[4].isoformat() if row[4] else None,
                        "reason": "仓库级冻结：%s 盘点进行中" % row[2],
                    }
                return {"frozen": False}

class AdjustService:
    """调整单服务。"""

    @classmethod
    async def create(cls, stocktake_id: int, user: dict) -> dict:
        """生成调整单并生效。"""
        db = get_session()
        async with db as session:
            async with session.begin():
                st = (
                    await session.execute(
                        select(M15Stocktake)
                        .where(M15Stocktake.id == stocktake_id)
                        .with_for_update()
                    )
                ).scalar_one_or_none()
                if not st:
                    raise BizException("1505001", "盘点单不存在")
                if st.status != "PENDING_APPROVAL":
                    raise BizException("1505002", "盘点单状态不允许生成调整单")

                # 检查审批是否通过
                if not st.approved_at:
                    raise BizException("1505002", "盘点单状态不允许生成调整单")

                diffs = (
                    await session.execute(
                        text(
                            "SELECT id, stock_id, location_id, material_id, material_code, "
                            "material_name, batch_no, book_qty, actual_qty, diff_qty, "
                            "unit_cost, diff_amount FROM m15_stocktake_item "
                            "WHERE stocktake_id = :sid AND diff_qty IS NOT NULL "
                            "AND diff_qty <> 0 AND is_deleted = FALSE"
                        ),
                        {"sid": stocktake_id},
                    )
                ).all()

                if not diffs:
                    st.status = "COMPLETED"
                    st.completed_at = datetime.now()
                    return {
                        "adjust_id": None,
                        "stocktake_id": stocktake_id,
                        "stocktake_no": st.stocktake_no,
                        "item_count": 0,
                        "total_amount": 0,
                        "message": "无差异，直接完成",
                    }

                adjust_no = await cls._next_no(session)
                total = Decimal("0")
                for d in diffs:
                    total += Decimal(str(d[11] or 0))

                adjust = M15StockAdjust(
                    adjust_no=adjust_no,
                    stocktake_id=stocktake_id,
                    stocktake_no=st.stocktake_no,
                    warehouse_id=st.warehouse_id,
                    warehouse_name=st.warehouse_name,
                    item_count=len(diffs),
                    total_amount=money2(total),
                    status="ADJUSTING",
                    created_by=user["employee_id"],
                    created_by_name=user["name"],
                )
                session.add(adjust)
                await session.flush()

                for idx, d in enumerate(diffs, start=1):
                    session.add(
                        M15StockAdjustItem(
                            adjust_id=adjust.id,
                            line_no=idx,
                            stocktake_item_id=d[0],
                            stock_id=d[1],
                            location_id=d[2],
                            material_id=d[3],
                            material_code=d[4],
                            material_name=d[5],
                            batch_no=d[6],
                            book_qty=Decimal(str(d[7] or 0)),
                            actual_qty=Decimal(str(d[8] or 0)),
                            diff_qty=Decimal(str(d[9] or 0)),
                            unit_cost=money2(d[10] or 0),
                            diff_amount=money2(d[11] or 0),
                            adjust_type="IN" if Decimal(str(d[9])) > 0 else "OUT",
                        )
                    )

                adjust_id = adjust.id
                wh_id = st.warehouse_id
                st_no = st.stocktake_no
                item_count = len(diffs)
                total_amount = money2(total)
                lines = [
                    {
                        "stock_id": d[1],
                        "material_code": d[4],
                        "batch_no": d[6],
                        "diff_qty": float(d[9]),
                    }
                    for d in diffs
                ]

        # 调 M15-01 调整库存
        try:
            txn_result = await StockClient.adjust(
                warehouse_id=wh_id,
                adjust_id=adjust_id,
                adjust_no=adjust_no,
                idempotency_key="ADJUST:%d" % adjust_id,
                items=lines,
            )
        except Exception as exc:
            logger.error("调整生效失败 adjust_id=%s err=%s", adjust_id, exc)
            raise BizException("1505029", "库存服务不可用，调整失败")

        # 更新状态
        db = get_session()
        async with db as session:
            async with session.begin():
                await session.execute(
                    text(
                        "UPDATE m15_stock_adjust SET status='COMPLETED', "
                        "completed_at = CURRENT_TIMESTAMP WHERE id = :aid"
                    ),
                    {"aid": adjust_id},
                )
                await session.execute(
                    text(
                        "UPDATE m15_stocktake SET status='COMPLETED', "
                        "completed_at = CURRENT_TIMESTAMP WHERE id = :sid"
                    ),
                    {"sid": stocktake_id},
                )
                await session.execute(
                    text(
                        "UPDATE m15_stocktake_freeze SET status='RELEASED', "
                        "released_at = CURRENT_TIMESTAMP WHERE stocktake_id = :sid "
                        "AND status = 'ACTIVE'"
                    ),
                    {"sid": stocktake_id},
                )

        await redis_client.delete("m15:freeze:%d" % wh_id)

        return {
            "adjust_id": adjust_id,
            "adjust_no": adjust_no,
            "stocktake_id": stocktake_id,
            "stocktake_no": st_no,
            "item_count": item_count,
            "total_amount": float(total_amount),
            "status": "COMPLETED",
            "stock_txn_nos": txn_result.get("txn_nos", []),
            "stocktake_new_status": "COMPLETED",
        }

class StocktakeStatService:
    """盘点统计。"""

    @classmethod
    async def statistics(cls, d0, d1, wh_id, user) -> dict:
        """盘点统计。"""
        db = get_session()
        async with db as session:
            where = [
                "status = 'COMPLETED'",
                "is_deleted = FALSE",
                "DATE(completed_at) BETWEEN :d0 AND :d1",
            ]
            params = {"d0": d0, "d1": d1}
            if wh_id:
                where.append("warehouse_id = :wid")
                params["wid"] = wh_id
            where_sql = " AND ".join(where)

            rows = (
                await session.execute(
                    text(
                        "SELECT COUNT(*), COALESCE(SUM(item_count),0), "
                        "COALESCE(SUM(diff_item_count),0), COALESCE(SUM(diff_amount),0) "
                        "FROM m15_stocktake WHERE " + where_sql
                    ),
                    params,
                )
            ).first()

        cnt = int(rows[0] or 0)
        item_total = int(rows[1] or 0)
        diff_items = int(rows[2] or 0)
        diff_amount = float(rows[3] or 0)
        accuracy = round(1 - diff_items / item_total, 4) if item_total else 0

        return {
            "date_from": d0,
            "date_to": d1,
            "stocktake_count": cnt,
            "item_total": item_total,
            "diff_item_count": diff_items,
            "accuracy": accuracy,
            "target_accuracy": 0.98,
            "diff_amount": diff_amount,
        }

    @classmethod
    async def accuracy_trend(cls, months: int, user) -> dict:
        """准确率趋势。"""
        db = get_session()
        async with db as session:
            rows = (
                await session.execute(
                    text(
                        "SELECT TO_CHAR(completed_at, 'YYYY-MM') AS m, "
                        "       SUM(item_count), SUM(diff_item_count) "
                        "FROM m15_stocktake WHERE status = 'COMPLETED' "
                        "AND completed_at >= CURRENT_DATE - INTERVAL '%s months' "
                        "AND is_deleted = FALSE "
                        "GROUP BY 1 ORDER BY 1" % int(months)
                    )
                )
            ).all()

        items = []
        for r in rows:
            total = int(r[1] or 0)
            diff = int(r[2] or 0)
            items.append({
                "month": r[0],
                "item_total": total,
                "diff_item_count": diff,
                "accuracy": round(1 - diff / total, 4) if total else 0,
            })
        return {"items": items, "target_accuracy": 0.98}

    @classmethod
    async def diff_reason(cls, d0, d1, user) -> dict:
        """差异归因分布。"""
        db = get_session()
        async with db as session:
            rows = (
                await session.execute(
                    text(
                        "SELECT i.diff_reason, COUNT(*), "
                        "COALESCE(SUM(ABS(i.diff_amount)),0) "
                        "FROM m15_stocktake_item i "
                        "JOIN m15_stocktake s ON s.id = i.stocktake_id "
                        "WHERE s.status = 'COMPLETED' "
                        "AND DATE(s.completed_at) BETWEEN :d0 AND :d1 "
                        "AND i.diff_qty IS NOT NULL AND i.diff_qty <> 0 "
                        "AND i.is_deleted = FALSE GROUP BY 1 ORDER BY 3 DESC"
                    ),
                    {"d0": d0, "d1": d1},
                )
            ).all()

        total = sum(float(r[2] or 0) for r in rows)
        items = [
            {
                "diff_reason": r[0] or "UNKNOWN",
                "diff_reason_text": DIFF_REASON_NAMES.get(r[0] or "UNKNOWN", "原因不明"),
                "count": int(r[1] or 0),
                "amount": float(r[2] or 0),
                "ratio": round(float(r[2] or 0) / total, 4) if total else 0,
            }
            for r in rows
        ]
        return {"items": items, "total_amount": total}

    @classmethod
    async def daily(cls, stat_date: str) -> dict:
        """内部：每日盘点统计。"""
        return await cls.statistics(stat_date, stat_date, None, {"employee_id": 0})

    @classmethod
    async def submit(cls, stocktake_id: int, user: dict) -> dict:
        """提交审批。"""
        db = get_session()
        async with db as session:
            async with session.begin():
                st = (
                    await session.execute(
                        select(M15Stocktake)
                        .where(M15Stocktake.id == stocktake_id)
                        .with_for_update()
                    )
                ).scalar_one_or_none()
                if not st:
                    raise BizException("1505001", "盘点单不存在")
                if st.status != "COUNTED":
                    raise BizException("1505002", "盘点单状态不允许提交")

                # 校验大额差异已归因
                bad = (
                    await session.execute(
                        text(
                            "SELECT COUNT(*) FROM m15_stocktake_item "
                            "WHERE stocktake_id = :sid AND diff_qty IS NOT NULL "
                            "AND diff_qty <> 0 AND ABS(diff_amount) > 100 "
                            "AND (diff_reason IS NULL OR diff_reason = 'UNKNOWN') "
                            "AND is_deleted = FALSE"
                        ),
                        {"sid": stocktake_id},
                    )
                ).scalar()
                if int(bad or 0) > 0:
                    raise BizException(
                        "1505016", "存在 %d 项未归因的大额差异" % int(bad)
                    )

                abs_amount = abs(st.diff_amount or Decimal("0"))
                level, min_len, need_attach = resolve_diff_level(abs_amount)
                if len((st.analysis_note or "").strip()) < min_len:
                    raise BizException(
                        "1505017", "总体说明不足 %d 字" % min_len
                    )
                if need_attach and not st.analysis_attachment_url:
                    raise BizException("1505018", "必须上传调查报告")

                # 审批档位
                tier_roles = APPROVAL_TIERS[-1][1]
                for cap, roles, _name in APPROVAL_TIERS:
                    if cap is None or abs_amount <= cap:
                        tier_roles = roles

### 6.7 专题：为什么盘点必须冻结库存

**不冻结时的真实场景：**

盘点人 10:00 查账面 100 片 → 10:05 出库员发出 20 片 → 10:30 盘点人数到 80 片 → 差异 -20 片。

系统记录 -20，管理层看到「本月盘亏 20 片」，启动调查，最后发现是「已出库但盘点时账面未同步」。

**冻结的三重作用：**

1. **保证账面数与实盘数在同一个时点**：冻结后出库停，账面数不变
2. **防止盘点期间出库导致数据来回变**：盘点人一条条录，录入过程 2 小时，若期间有出库，前面的数与后面的数不在同一基准
3. **盘点期间不允许产生新业务**：正常业务用「冻结期间不接单」，避免事后「盘点时到底有没有出库」的争议

**为什么冻结需要超时：**

盘点人卡在某一项上迟迟不完成（比如某批次找不到），冻结会一直持续，业务全部停摆。设计上：
- 冻结有 `expire_at`，默认 24 小时
- 到期自动解冻并发告警
- 盘点人可手动「延长冻结」（最多再延 24 小时）
- 若盘点超过 24 小时仍未完成，该盘点需作废重来

**为什么不「只冻结被盘的批次」在全面盘点时：**

全面盘点的目的是「整个仓库账实相符」。若只冻结被盘的批次，未盘的批次仍可出入，最后汇总时「账面合计」与「实盘合计」不在同一基准，结论无效。所以全面盘点必须仓库级冻结。

1. **`manage` 与 `count` 互斥（库管员领）**：制定盘点计划的人不能自己实盘。库管员只实盘，库房主管制定计划。
2. **`count` 与 `review` 互斥**：实盘人不能自己复核。
3. **`count`/`adjust` 与 `approve` 互斥**：盘点人、分析人都不能审批差异。
4. **`manage` 与 `approve` 互斥**：制定计划的人不能审批自己计划的盘点结果。

### 9.3 数据权限

```python
"""M15-05 数据权限。"""

from typing import Tuple

from sqlalchemy import Select

from app.models.m15.stocktake import M15Stocktake


def apply_stocktake_scope(stmt: Select, user: dict, domain: str = "DEPT") -> Select:
    """按数据权限域过滤。"""
    has = user.get("has_permission", lambda p: False)
    if has("m15:stocktake:all"):
        return stmt
    if domain == "ALL":
        return stmt
    if domain == "DEPT":
        dept_id = user.get("dept_id")
        if not dept_id:
            return stmt.where(M15Stocktake.id == -1)
        return stmt.where(
            M15Stocktake.warehouse_id.in_(
                __import__("sqlalchemy").text(
                    "SELECT id FROM m15_warehouse WHERE dept_id = %d" % int(dept_id)
                )
            )
        )
    return stmt.where(M15Stocktake.id == -1)


def resolve_scope(user: dict) -> Tuple[str, str]:
    """决定默认域。"""
    if user.get("has_permission", lambda p: False)("m15:stocktake:all"):
        return "ALL", "全部"
    if user.get("dept_id"):
        return "DEPT", "本科室"
    return "SELF", "本人"
```

**敏感参数的政策来源与篡改后果：**

| 参数 | 政策来源 | 篡改后果 |
|---|---|---|
| `FREEZE_HOURS` | 盘点作业标准 | 调小 → 盘点未完就解冻，业务恢复导致账实再次不符 |
| `DIFF_REASON_MIN` | 差异归因制度 | 调高 → 小额差异原因可选，归因率下降；调低 → 每项都要归因，工作量剧增 |
| `DIFF_ATTACH_MIN_AMOUNT` | 大额差异查证制度 | 调高 → 大额差异无调查报告，舞弊无制衡 |
| `APPROVAL_TIER_1/2/3` | 资产管理内控 | 调高 → 大额调整单人可批 |
| `ACCURACY_TARGET` | 库房管理 KPI | 调低 → 目标形同虚设 |
