## 1. 模块概述

### 1.1 模块定位

M13-04 是检验链路的**终点与出口**。它回答三个问题：

1. **这份结果能不能发？** —— 检验医师审核并签字
2. **发出去出事了谁负责？** —— 审核签字人是唯一的责任人
3. **危急值多久能让医生知道？** —— 15 分钟内必须确认

```
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│ M13-01   │──►│ M13-02   │──►│ M13-03   │──►│ M13-04   │──►│ M07-04   │
│ 标本管理 │   │ 文件采集 │   │ OCR 解析 │   │ 审核发布 │   │ 医生查看 │
└──────────┘   └──────────┘   └──────────┘   └────┬─────┘   └──────────┘
                                                   │
                                    ┌──────────────┼──────────────┐
                                    ▼              ▼              ▼
                              ┌──────────┐   ┌──────────┐   ┌──────────┐
                              │ 危急值   │   │ 修订重发 │   │ 质量分析 │
                              │ 闭环通知 │   │ 版本管理 │   │ 与追溯   │
                              └──────────┘   └──────────┘   └──────────┘
```

**一句话定义：** M13-04 把 M13-03 解析出的结构化数据变成**医生可据以决策的正式医疗文书**，并对其中可能导致患者损害的异常值执行**限时闭环通知**。

### 1.2 为什么独立成子模块

| 维度 | M13-03（解析） | M13-04（审核发布） |
|---|---|---|
| 性质 | 技术加工 | **法律责任承担** |
| 责任人 | 系统 | **审核医师（签字）** |
| 时效要求 | 无硬性要求 | **危急值 15 分钟** |
| 失败后果 | 结果看不到 | **患者失明** |
| 状态流转 | 解析状态机 | 审核 + 发布 + 版本 三套状态机 |
| 数据留存 | 15 年 | **15 年且不可删** |

**四条独立理由：**

1. **审核是法定责任，不是技术流程。** 《医疗机构临床实验室管理办法》第三十一条明确要求检验报告须经审核者签字后方可发出。M13-03 做的是"把 PDF 变成数字"，M13-04 做的是"我，某某医师，对这份数字负责"。责任主体不同，必须有独立的签字记录、资质校验、活动留痕。

2. **危急值的时效与解析完全不在一个量级。** 危急值发现后 **15 分钟**内必须医生确认，2 小时内必须处置。这条链路涉及短信、电话、升级、督办，是一套独立的、必须可度量的闭环。把它塞在解析里，会被解析的 3~12 秒耗时掩盖，也无法独立统计"危急值及时率"。

3. **报告需要"可修改、可重发、可撤回"的独立生命周期。** 检验结果发出后可能被修订（仪器复测、人工复核、临床反馈），修订后已读过的医生必须被再次通知。这是版本管理问题，与解析无关。

4. **审核质量数据是科室管理的核心指标。** 审核及时率、修改率、退回率、危急值处置率——这四个数字是检验科月度考核的硬指标，必须由 M13-04 独立产生。

### 1.4 概念辨析

| 概念 | 定义 | 归属 |
|---|---|---|
| **审核（Review）** | 检验医师判断数据与结论是否正确并签字 | M13-04 |
| **复核（Recheck）** | 技师判断标本质量与操作是否规范 | M13-01 |
| **发布（Publish）** | 本地状态变更为"已发布" | M13-04 |
| **推送（Push）** | 跨模块调用 M07-04 让医生可见 | M13-04 |
| **危机值（Critical Value）** | 危及生命的异常结果，需限时通知 | M13-04 |
| **异常值（Abnormal）** | 超出参考区间但未达危急阈值 | M13-04 标记，不通知 |
| **修订（Revise）** | 已发布报告的更正，生成新版本 | M13-04 |
| **撤回（Withdraw）** | 撤销已发布报告，医生不可再看到 | M13-04 |

**为什么"发布"与"推送"必须分开？**

发布是本地状态变更（一次 UPDATE），推送是跨模块 HTTP 调用（可能超时、可能 500）。**发布成功但推送失败是常态**——M07 重启 30 秒，这期间发布的 12 份报告全部推送失败。如果两者合并成一个状态，就会出现"报告在 M13 里是已发布、医生却看不到"的黑洞。分开记录才能精确重试。

### 1.5 模块目标

| 指标 | 目标值 | 说明 |
|---|---|---|
| 审核及时率（4 小时内） | ≥ 95% | 普通检验报告 |
| 加急审核及时率（1 小时内） | ≥ 98% | 急诊检验 |
| 危急值 15 分钟确认率 | **100%** | 硬指标，不达标立即升级 |
| 危急值 2 小时处置率 | ≥ 98% | — |
| 报告修改率 | ≤ 5% | 审核医师修改 M13-03 结果的占比 |
| 报告退回率 | ≤ 3% | 退回让技师重做 |
| 推送成功率（24 小时内） | **100%** | 失败必须人工介入 |
| 免审核项目抽查覆盖率 | 100% | 每周抽查 5% |

| U-06 | M01-02 | `GET /internal/v1/employee/{id}/qualification` | 2s | 无法校验审核资质 | **降级放行 + WARN** |
| U-07 | M07-04 | `POST /internal/v1/m07/reports/on-report-ready` | 3s | 医生看不到报告 | 重试 10 次 |
| U-08 | M07-04 | `POST /internal/v1/m07/reports/on-critical-value` | 3s | **危急值未通知** | 重试 5 次 + 升级人工 |
| U-09 | M03-05 | `POST /internal/v1/message/send` | 2s | 短信未发 | 异步重试 |
| U-10 | M02-06 | `POST /internal/v1/audit/record` | 1s | 审计缺失 | 异步补偿 |

**为什么 U-06 资质校验失败允许放行？**

M01-02 是全院职工服务，它挂了意味着全院都受影响（挂号、收费、发药全停）。此时阻断审核会让检验科停工，患者拿不到报告。放行的代价是"可能有不具备资质的人审核了"，但检验科本身就只授权有资质的人登录审核界面，二次防线仍在。这条降级必须记录 WARN 告警并纳入月度审计。

**为什么 U-05 危急阈值不可降级为"不判定"？**

漏判危急值是本子模块最严重的失败——患者可能因此死亡。如果 M01-09 与 M13-05 都不可用，必须：
1. 记录 `critical_rules_missing=TRUE`
2. 报告**仍然可以发布**，但审核界面顶部红色横幅提示"危急值规则获取失败，请人工核对全部数值"
3. 发送告警给检验科主任
4. 规则恢复后自动补判（`job_m13_critical_recheck`）

## 3. 业务模型

### 3.1 审核状态机

```
                    ┌─────────┐
       进队列 ─────►│ PENDING │
                    └────┬────┘
              认领（乐观锁）│
                         ▼
                    ┌──────────┐
              ┌────►│ REVIEWING│◄───┐
              │     └────┬─────┘    │
              │          │          │ 会诊/暂存
              │   ┌──────┼──────┐   │
              │   ▼      ▼      ▼   │
              │ PASS  MODIFY  REJECT│
              │   │      │      │   │
              │   ▼      ▼      ▼   │
              │ ┌──────┐┌──────┐┌────────┐
              └─│PUBLISH││PUBLISH││REJECTED│
                └───┬──┘└──────┘└────────┘
                    │            （终态）
                    │ 修订
                    ▼
              ┌─────────────┐
              │ SUPERSEDED  │（上一版本）
              └─────────────┘
                    │
                    │ 撤回
                    ▼
              ┌───────────┐
              │ WITHDRAWN │（终态）
              └───────────┘
```

**状态说明：**

| 状态 | 中文 | 终态 | 说明 |
|---|---|---|---|
| `PENDING` | 待审核 | 否 | 解析完成且绑定的报告 |
| `REVIEWING` | 审核中 | 否 | 已认领，他人不可操作 |
| `PUBLISHED` | 已发布 | 否 | 可修订、可撤回 |
| `REJECTED` | 已退回 | **是** | 技师需重做，生成新报告 |
| `SUPERSEDED` | 已取代 | **是** | 被新版本取代 |
| `WITHDRAWN` | 已撤回 | **是** | 撤销发布 |

**为什么 `REJECTED` 是终态？**

退回意味着这份报告不能用了。技师重新采样、重新检验、重新出报告，会产生一份**全新的报告记录**。让它回到 `PENDING` 会导致：
- 退回次数无法统计（退回率是核心 KPI）
- 同一份报告被反复退回重审，历史混在一起
- 医生看到的版本号混乱

### 3.2 危急值状态机

```
    ┌───────────┐
    │ DETECTED  │  ← 审核时判定命中危急阈值
    └─────┬─────┘
          │ 发送通知
          ▼
    ┌───────────┐  15 分钟未确认
    │ NOTIFIED  │──────────────┐
    └─────┬─────┘              │
          │ 医生确认            ▼
          │              ┌──────────────┐
          │              │ ESCALATED_1  │（科室主任）
          │              └──────┬───────┘
          ▼                     │ 30 分钟仍未确认
    ┌─────────────┐             ▼
    │ACKNOWLEDGED │      ┌──────────────┐
    └──────┬──────┘      │ ESCALATED_2  │（医务科）
           │ 医生处置     └──────┬───────┘
           ▼                    │ 60 分钟仍未确认
    ┌───────────┐               ▼
    │  HANDLED  │        ┌──────────────┐
    └─────┬─────┘        │ ESCALATED_3  │（分管院长）
          │ 24 小时后      └──────────────┘
          ▼ 或人工关闭
    ┌───────────┐
    │  CLOSED   │（终态）
    └───────────┘
```

**为什么"确认"与"处置"必须分开？**

- **确认（ACKNOWLEDGED）**：医生点一下"我看到了"。15 分钟内完成是合理的。
- **处置（HANDLED）**：医生联系患者、安排复诊、开药。2 小时内完成是合理的。

合并成一个"已处理"会导致两种失真：
1. 医生在 15 分钟内点"已处理"，但患者还没联系上——记录不实
2. 医生不敢点，因为点一下就要填一堆内容——超时率虚高

分开后，确认环节可严格考核（100% 必须 15 分钟内），处置环节给出合理窗口（2 小时）。

### 3.3 报告版本模型

```
  版本 V1（初始发布）
  ┌─────────────────────────┐
  │ report_no = LBR202610220001 │
  │ version_no = 1          │
  │ status = SUPERSEDED     │
  │ 快照：WBC 6.8  HGB 145  │
  └───────────┬─────────────┘
              │ 修订（仪器复测 WBC 实际为 7.2）
              ▼
  版本 V2（新版本）
  ┌─────────────────────────┐
  │ report_no = LBR202610220001 │  ← 报告号不变
  │ version_no = 2          │
  │ status = PUBLISHED      │
  │ 快照：WBC 7.2  HGB 145  │
  │ changed_fields = [WBC]  │
  └─────────────────────────┘
```

**修订六约束：**

| 编号 | 约束 | 理由 |
|---|---|---|
| M-01 | 修订原因 ≥ 20 字 | 修订会重新通知医生，必须说清为什么 |
| M-02 | 修订后必须重新审核签字 | 修改了数据就要重新负责 |
| M-03 | 原版本标 `SUPERSEDED` 不删 | 纠纷时需还原"当时医生看到什么" |
| M-04 | 已读医生收到"报告已更新" | 否则医生看着旧数据做决定 |
| M-05 | 超 3 次修订需科主任批准 | 反复修订说明流程有问题 |
| M-06 | 发布超 7 天不可修订 | 只能补充说明，不能改原数据 |

**M-06 的理由：** 报告发布 7 天后，医生早已据此做了诊疗决定、可能已写进病历、可能已出院。此时改原数据会造成"病历里写的和系统里不一样"。补充说明（`m13_report_annex`）是唯一正确的做法。

### 3.4 危急值判定规则

**数据来源优先级：**

```
1. M13-05 本科室自定义危急阈值（最近维护，最贴合本院）
   ↓ 未命中
2. M01-09 md_lab_item.critical_min / critical_max
   ↓ 未命中
3. 无规则 → critical_rules_missing=TRUE，整体 WARN 告警
```

**判定运算符：**

| 运算符 | 说明 | 示例 |
|---|---|---|
| `GT` | 大于阈值 | 血钾 > 6.5 |
| `LT` | 小于阈值 | 血钾 < 2.8 |
| `GTE` | 大于等于 | — |
| `LTE` | 小于等于 | — |
| `BETWEEN` | 区间内 | pH 7.35~7.45 之外才算异常，不常用 |
| `OUTSIDE` | 区间外 | 血钾 < 3.5 或 > 5.5 |

**判定伪代码：**

```
def detect_critical(fields, rules):
    hits = []
    for rule in rules:
        field = fields.get(rule.field_code)
        if field is None or field.numeric_value is None:
            # 字段缺失或非数值：无法判定，记录跳过
            skipped.append(rule.rule_code)
            continue
        v = field.numeric_value
        hit = False
        if rule.operator == "GT":
            hit = v > rule.threshold_max
        elif rule.operator == "LT":
            hit = v < rule.threshold_min
        elif rule.operator == "GTE":
            hit = v >= rule.threshold_max
        elif rule.operator == "LTE":
            hit = v <= rule.threshold_min
        elif rule.operator == "OUTSIDE":
            hit = v < rule.threshold_min or v > rule.threshold_max
        elif rule.operator == "BETWEEN":
            hit = rule.threshold_min <= v <= rule.threshold_max
        if hit:
            hits.append({
                "rule_code": rule.rule_code,
                "field_code": rule.field_code,
                "value": v,
                "severity": rule.critical_level,   # CRITICAL / WARNING
            })
    return hits, skipped
```

**为什么字段缺失要记录而非跳过？**

危急值规则配了"血钾 < 2.8"，但这次报告里没有血钾（比如只做了血常规）。此时既不能报危急值（没有数据），也不能当作"正常"。记录 `skipped_rules` 让运维看到"这个设备经常缺血钾"，是模板或仪器的问题信号。

### 3.5 审核时限模型

| 优先级 | 时限 | 提醒（70%） | 告警（100%） | 升级（200%） |
|---|---|---|---|---|
| 普通 | 4 小时 | 2.8 小时 | 4 小时通知科主任 | 8 小时报医务科 |
| 加急 | 1 小时 | 42 分钟 | 1 小时通知科主任 | 2 小时报医务科 |

时限来源：`md_lab_item.report_sla_hours`，缺省取参数 `M13.REVIEW.SLA_HOURS`。

### 3.6 免审核项目模型

**免审核条件：** `md_lab_item.need_review = FALSE`，典型是快速血糖、尿常规干化学、隐血试验。

**免审核 ≠ 无把关，四道替代措施：**

| 措施 | 说明 |
|---|---|
| 危急值照常判定 | 免审核项目如果命中危急阈值，仍然走完整闭环 |
| 异常值标红 | 报告里超区间项仍然高亮 |
| 每周抽查 5% | 质控科随机抽 5% 人工复核，抽到不合格立即取消该项目免审核资格 |
| 全程可追溯 | 免审核也要记录"谁触发了直发"（通常是解析服务） |

### 3.7 推送重试模型

```
尝试 1  立即
尝试 2  +10 秒
尝试 3  +30 秒
尝试 4  +60 秒
尝试 5  +120 秒
尝试 6  +300 秒
尝试 7  +600 秒
尝试 8  +1200 秒
尝试 9  +1800 秒
尝试 10 +3600 秒
──────────────
累计约 128 分钟

10 次全部失败 → 转人工（标记 push_status='FAILED' + 告警）
```

**为什么 2 小时后转人工而不是无限重试？**

2 小时后仍未成功，根因通常不是网络抖动，而是：
- M07 接口契约变了（400/422）
- 患者记录不存在（404）
- 字段超长（400）
- M07 服务彻底挂了

这些情况无限重试只是掩盖问题。转人工后由检验科信息员排查，处理完可手工重推。

### 3.8 报告发布与推送的幂等

**发布幂等键：** `PUBLISH:{report_no}:V{version_no}`

**推送幂等键：** `PUSH:{report_no}:V{version_no}`

**为什么必须带版本号？**

同一份报告号，V1 发布推送成功、V2 修订发布又推送一次。如果幂等键只有 `report_no`，第二次会被误判重复而跳过，医生永远看不到修订版。

### 3.9 会诊与加签

**会诊（Consult）：** 审核医师对结果有疑问，请上级医师会诊。会诊不改变审核责任人——**最终签字的仍然是原审核医师**。

**加签（Co-sign）：** 特高危危急值（如血钾 > 7.0）需要科主任加签确认。加签后无审核人责任仍是双人。

| 场景 | 是否需要加签 |
|---|---|
| 普通报告 | 否 |
| 危急值 `CRITICAL` | 是（科主任） |
| 同一患者 24 小时内 3 次以上危急值 | 是（科主任） |
| 免审核项目命中危急值 | 是（科主任） |

### 6.2 错误码规范

| 错误码 | 说明 | 触发场景 |
|---|---|---|
| `"1304001"` | 报告不存在 | 传入的 review_id 无效 |
| `"1304002"` | 报告已被他人认领 | 认领时乐观锁失败 |
| `"1304003"` | 报告状态不允许此操作 | 状态机校验失败 |
| `"1304004"` | 未选择审核结论 | 提交时 conclusion 为空 |
| `"1304005"` | 关键字段未全部确认 | 存在 `is_critical AND NOT is_confirmed` |
| `"1304006"` | 修改后通过必须填写审核意见（≥10字） | MODIFY 时 opinion 不足 |
| `"1304007"` | 退回重做必须填写审核意见（≥20字） | REJECT 时 opinion 不足 |
| `"1304008"` | 修改结果值必须填写修改原因 | 字段改动但 edit_reason 为空 |
| `"1304009"` | 危急值规则获取失败 | M13-05 与 M01-09 均不可用且需判定 |
| `"1304010"` | 同一患者 24 小时内危急值超过 3 次需加签 | 未加签就提交 |
| `"1304011"` | 修订原因不足 20 字 | revise_reason 过短 |
| `"1304012"` | 修订次数超过上限需科主任批准 | revise_count > 3 |
| `"1304013"` | 报告发布超过 7 天不可修订 | 超出修订窗口 |
| `"1304014"` | 撤回原因不足 20 字 | withdraw_reason 过短 |
| `"1304015"` | 只能撤回已发布的报告 | 状态不是 PUBLISHED |
| `"1304016"` | 版本对比参数错误 | from_version 不小于 to_version |
| `"1304017"` | 推送记录不存在 | publish_id 无效 |
| `"1304018"` | 批量通过数量超过 20 条 | count > 20 |
| `"1304019"` | 批量通过包含危急值报告 | 选中项含危急值 |
| `"1304020"` | 危急值不存在 | critical_id 无效 |
| `"1304021"` | 危急值已闭环不可督办 | 状态为 CLOSED |
| `"1304022"` | 5 分钟内不可重复督办 | Redis 限流 |
| `"1304023"` | 强制关闭必须填写原因（≥20字） | force 时原因为空 |
| `"1304024"` | 无权操作他人的审核记录 | 非认领人提交 |
| `"1304025"` | 审核医师资质校验不通过 | M01-02 返回无资质 |
| `"1304026"` | 参数值超出允许范围 | 配置项越界 |
| `"1304027"` | 敏感参数修改需要二次确认 | is_sensitive 且未确认 |
| `"1304028"` | 查询日期跨度超过 366 天 | statistics 时间跨度超限 |
| `"1304029"` | 导出行数超过上限 | 超出 50000 行 |
| `"1304030"` | 报告正在被他人修订 | 修订锁冲突 |

```python
"""M13-04 检验结果审核与发布 —— Service 层。"""
import hashlib
import json
from datetime import datetime, timedelta
from decimal import Decimal

from sqlalchemy import text
from sqlalchemy.exc import IntegrityError

from app.core.exceptions import BizException
from app.core.redis_client import redis_client
from app.integrations.m01_client import M01Client
from app.integrations.m02_client import M02Client
from app.integrations.m03_client import M03Client
from app.integrations.m07_client import M07Client
from app.integrations.m12_client import M13Client
from app.services.m13.critical_detector import CriticalDetector
from app.services.m13.publish_service import PublishService
from app.tasks.m13_review_tasks import push_report_task

CENT = Decimal("0.01")

# 审核状态机
REVIEW_TRANSITIONS = {
    "PENDING": {"REVIEWING"},
    "REVIEWING": {"PUBLISHED", "REJECTED", "PENDING"},
    "PUBLISHED": {"SUPERSEDED", "WITHDRAWN"},
    "REJECTED": set(),
    "SUPERSEDED": set(),
    "WITHDRAWN": set(),
}

CONCLUSIONS = ("PASS", "MODIFY", "REJECT")

STATUS_TEXT = {
    "PENDING": "待审核",
    "REVIEWING": "审核中",
    "PUBLISHED": "已发布",
    "REJECTED": "已退回",
    "SUPERSEDED": "已被取代",
    "WITHDRAWN": "已撤回",
}


class ReviewService:
    """报告审核服务。"""

    MAX_BATCH_PASS = 20
    MIN_OPINION_MODIFY = 10
    MIN_OPINION_REJECT = 20
    MAX_REVISE_COUNT = 3
    REVISE_WINDOW_DAYS = 7

    @classmethod
    async def workbench(cls, user):
        """工作台概览。"""
        db = user["db"]
        today = datetime.now().date()
        row = (await db.execute(text("""
            SELECT
                COUNT(*) FILTER (WHERE status = 'PENDING') AS pending,
                COUNT(*) FILTER (WHERE status = 'REVIEWING') AS reviewing,
                COUNT(*) FILTER (
                    WHERE status IN ('PENDING', 'REVIEWING')
                      AND sla_deadline_at < now()) AS overdue,
                COUNT(*) FILTER (
                    WHERE reviewer_id = :uid
                      AND reviewed_at::date = :today
                      AND status IN ('PUBLISHED', 'REJECTED'))
                    AS reviewed_today
            FROM m13_report_review
            WHERE is_deleted = FALSE
        """), {"uid": user["employee_id"],
               "today": today})).one()

        crit = (await db.execute(text("""
            SELECT COUNT(*) FROM m13_critical_value
            WHERE status NOT IN ('CLOSED')
        """))).scalar()

        alerts = await cls._build_alerts(db)

        return {
            "pending": row.pending,
            "reviewing": row.reviewing,
            "overdue": row.overdue,
            "reviewed_today": row.reviewed_today,
            "critical_open": crit,
            "alerts": alerts,
        }

    @classmethod
    async def _build_alerts(cls, db):
        """构建工作台告警。"""
        rows = (await db.execute(text("""
            SELECT critical_id, critical_no, patient_name,
                   lab_name, detected_value, unit,
                   notified_at, severity
            FROM m13_critical_value
            WHERE status IN ('NOTIFIED', 'ESCALATED_1',
                             'ESCALATED_2')
              AND now() > notified_at + INTERVAL '15 minutes'
            ORDER BY notified_at ASC
            LIMIT 10
        """))).all()

        alerts = []
        for r in rows:
            elapsed = int(
                (datetime.now() - r.notified_at).total_seconds() // 60)
            alerts.append({
                "level": "CRITICAL",
                "type": "CRITICAL_TIMEOUT",
                "critical_id": r.critical_id,
                "message": "%s 危急%s %s 已通知 %d 分钟未确认" % (
                    r.patient_name, r.lab_name,
                    r.detected_value, elapsed),
            })
        return alerts

    @classmethod
    async def claim(cls, review_id: int, user):
        """认领报告（乐观锁）。"""
        db = user["db"]
        # ① 资质校验（失败降级放行 + WARN）
        qualified = await cls._check_qualification(
            user["employee_id"], user)
        if not qualified:
            cls._log_warn(db, "review_qualification_failed",
                          user, review_id)

        # ② 乐观更新认领
        res = await db.execute(text("""
            UPDATE m13_report_review
            SET status = 'REVIEWING',
                reviewer_id = :uid,
                reviewer_name = :name,
                claimed_at = now(),
                updated_at = now()
            WHERE id = :id AND status = 'PENDING'
              AND is_deleted = FALSE
        """), {"id": review_id, "uid": user["employee_id"],
               "name": user["employee_name"]})

        if res.rowcount == 0:
            await db.rollback()
            cur = (await db.execute(text("""
                SELECT status, reviewer_name
                FROM m13_report_review WHERE id = :id
            """), {"id": review_id})).first()
            if cur is None:
                raise BizException("1304001", "报告不存在")
            if cur.status == "REVIEWING":
                raise BizException(
                    "1304002",
                    "该报告已被 %s 医师认领" % cur.reviewer_name)
            raise BizException(
                "1304003", "报告状态不允许认领：%s" % cur.status)

        await db.commit()
        return {
            "review_id": review_id,
            "status": "REVIEWING",
            "reviewer_id": user["employee_id"],
            "reviewer_name": user["employee_name"],
            "claimed_at": datetime.now().isoformat(),
        }

    @classmethod
    async def submit(cls, review_id: int, body, user):
        """提交审核结论。"""
        db = user["db"]
        row = await cls._get_for_update(db, review_id)

        # ① 状态与归属校验
        if row.status != "REVIEWING":
            raise BizException(
                "1304003",
                "报告状态不允许提交：%s" % STATUS_TEXT.get(
                    row.status, row.status))
        if row.reviewer_id != user["employee_id"]:
            raise BizException(
                "1304024", "无权操作他人的审核记录")

        # ② 结论与意见校验
        conclusion = body.conclusion
        if conclusion not in CONCLUSIONS:
            raise BizException("1304004", "未选择审核结论")
        opinion = (body.opinion or "").strip()
        if conclusion == "MODIFY" and \
                len(opinion) < cls.MIN_OPINION_MODIFY:
            raise BizException(
                "1304006",
                "修改后通过必须填写审核意见（不少于 %d 个字符）"
                % cls.MIN_OPINION_MODIFY)
        if conclusion == "REJECT" and \
                len(opinion) < cls.MIN_OPINION_REJECT:
            raise BizException(
                "1304007",
                "退回重做必须填写审核意见（不少于 %d 个字符）"
                % cls.MIN_OPINION_REJECT)

        # ③ 关键字段确认校验
        unconf = (await db.execute(text("""
            SELECT field_code FROM m13_review_field
            WHERE review_id = :rid
              AND is_critical = TRUE
              AND is_confirmed = FALSE
              AND is_deleted = FALSE
        """), {"rid": review_id})).all()
        if unconf and conclusion != "REJECT":
            codes = ",".join([u.field_code for u in unconf])
            raise BizException(
                "1304005", "关键字段未全部确认：%s" % codes)

        # ④ 字段修改落库（含修改原因校验）
        if body.field_edits:
            await cls._apply_field_edits(
                db, review_id, body.field_edits)

        # ⑤ 危急值判定（必须在发布前）
        criticals, skipped = await CriticalDetector.detect(
            db, review_id, user)
        need_co_sign = cls._need_co_sign(db, row, criticals)
        if need_co_sign and not body.co_sign:
            raise BizException(
                "1304010",
                "同一患者 24 小时内危急值超过 3 次，需科主任加签")

        # ⑥ 退回分支
        if conclusion == "REJECT":
            return await cls._do_reject(
                db, row, opinion, user)

        # ⑦ 生成版本快照
        snapshot = await cls._build_snapshot(
            db, review_id, row.parse_id)
        version_no = 1
        await db.execute(text("""
            INSERT INTO m13_report_version
                (review_id, report_no, version_no, snapshot_json,
                 field_count, changed_fields, reviewer_id,
                 reviewer_name, published_at, created_at)
            VALUES
                (:rid, :rno, :ver, :snap, :fcnt, :changed,
                 :uid, :uname, now(), now())
        """), {
            "rid": review_id, "rno": row.report_no,
            "ver": version_no,
            "snap": json.dumps(snapshot, ensure_ascii=False),
            "fcnt": len(snapshot["fields"]),
            "changed": json.dumps(
                [e.field_code for e in (body.field_edits or [])],
                ensure_ascii=False),
            "uid": user["employee_id"],
            "uname": user["employee_name"],
        })

        # ⑧ 置发布状态
        await db.execute(text("""
            UPDATE m13_report_review
            SET status = 'PUBLISHED',
                conclusion = :conc,
                opinion = :op,
                reviewer_id = :uid,
                reviewer_name = :uname,
                reviewed_at = now(),
                published_at = now(),
                version_no = :ver,
                critical_count = :ccnt,
                critical_level = :clevel,
                push_status = 'PENDING',
                updated_at = now()
            WHERE id = :id
        """), {
            "id": review_id, "conc": conclusion, "op": opinion,
            "uid": user["employee_id"],
            "uname": user["employee_name"],
            "ver": version_no,
            "ccnt": len(criticals),
            "clevel": cls._max_level(criticals),
        })

        # ⑨ 写发布记录
        await db.execute(text("""
            INSERT INTO m13_report_publish
                (review_id, report_no, version_no, publish_action,
                 push_status, attempt_count, operator_id,
                 operator_name, published_at, created_at)
            VALUES
                (:rid, :rno, :ver, 'PUBLISH', 'PENDING', 0,
                 :uid, :uname, now(), now())
        """), {
            "rid": review_id, "rno": row.report_no,
            "ver": version_no, "uid": user["employee_id"],
            "uname": user["employee_name"],
        })

        await db.commit()

        # ⑩ 异步推送（不阻塞响应）
        push_report_task.delay(review_id, version_no)

        # ⑪ 危急值紧急推送
        for c in criticals:
            await CriticalDetector.dispatch(db, c, user)

        return {
            "review_id": review_id,
            "review_no": row.report_no,
            "review_status": "PUBLISHED",
            "conclusion": conclusion,
            "version_no": version_no,
            "reviewer_id": user["employee_id"],
            "reviewer_name": user["employee_name"],
            "reviewed_at": datetime.now().isoformat(),
            "published_at": datetime.now().isoformat(),
            "critical_count": len(criticals),
            "critical_ids": [c["critical_id"] for c in criticals],
            "critical_skipped": skipped,
            "push": {"push_status": "PENDING"},
        }

    @classmethod
    async def _get_for_update(cls, db, review_id: int):
        """行锁读取。"""
        row = (await db.execute(text("""
            SELECT * FROM m13_report_review
            WHERE id = :id AND is_deleted = FALSE
            FOR UPDATE
        """), {"id": review_id})).first()
        if row is None:
            raise BizException("1304001", "报告不存在")
        return row

    @classmethod
    async def _apply_field_edits(cls, db, review_id, edits):
        """应用字段修改。"""
        for e in edits:
            cur = (await db.execute(text("""
                SELECT id, value_text, original_value
                FROM m13_review_field
                WHERE review_id = :rid AND field_code = :code
                  AND is_deleted = FALSE
            """), {"rid": review_id,
                   "code": e.field_code})).first()
            if cur is None:
                continue
            changed = (cur.value_text or "") != (e.value or "")
            if changed and not (e.edit_reason or "").strip():
                raise BizException(
                    "1304008",
                    "字段 %s 修改必须填写修改原因" % e.field_code)
            await db.execute(text("""
                UPDATE m13_review_field
                SET value_text = :val,
                    original_value = COALESCE(
                        original_value, :old),
                    is_manual_edited = TRUE,
                    edit_count = edit_count + 1,
                    edit_reason = :reason,
                    last_edited_at = now(),
                    last_edited_by = :uid,
                    updated_at = now()
                WHERE id = :id
            """), {
                "id": cur.id, "val": e.value,
                "old": e.value if cur.original_value is None
                else cur.original_value,
                "reason": e.edit_reason, "uid": review_id,
            })

    @classmethod
    async def _build_snapshot(cls, db, review_id, parse_id):
        """构建版本快照。"""
        rows = (await db.execute(text("""
            SELECT field_code, field_name, value_text,
                   numeric_value, unit, ref_low, ref_high,
                   ref_text, flag, confidence, is_critical
            FROM m13_review_field
            WHERE review_id = :rid AND is_deleted = FALSE
            ORDER BY seq_no
        """), {"rid": review_id})).all()

        head = (await db.execute(text("""
            SELECT patient_id, patient_name, gender, age,
                   visit_no, report_no, lab_code, lab_name,
                   specimen_no, test_date
            FROM m13_report_review WHERE id = :id
        """), {"id": review_id})).one()

        return {
            "fields": [
                {
                    "field_code": r.field_code,
                    "field_name": r.field_name,
                    "value": r.value_text,
                    "numeric_value": (
                        float(r.numeric_value)
                        if r.numeric_value is not None else None),
                    "unit": r.unit,
                    "ref_low": (float(r.ref_low)
                                if r.ref_low is not None else None),
                    "ref_high": (float(r.ref_high)
                                 if r.ref_high is not None else None),
                    "ref_text": r.ref_text,
                    "flag": r.flag,
                    "confidence": (float(r.confidence)
                                   if r.confidence is not None
                                   else None),
                    "is_critical": r.is_critical,
                }
                for r in rows
            ],
            "patient": {
                "patient_id": head.patient_id,
                "name": head.patient_name,
                "gender": head.gender,
                "age": head.age,
                "visit_no": head.visit_no,
            },
            "lab": {
                "report_no": head.report_no,
                "lab_code": head.lab_code,
                "lab_name": head.lab_name,
                "specimen_no": head.specimen_no,
                "test_date": (head.test_date.isoformat()
                              if head.test_date else None),
            },
            "source": {"parse_id": parse_id},
        }

    @classmethod
    def _max_level(cls, criticals):
        """取最高危急级别。"""
        levels = [c["severity"] for c in criticals]
        if "CRITICAL" in levels:
            return "CRITICAL"
        if "WARNING" in levels:
            return "WARNING"
        return None

    @classmethod
    def _need_co_sign(cls, db, row, criticals):
        """是否需要科主任加签。"""
        if not criticals:
            return False
        for c in criticals:
            if c["severity"] == "CRITICAL":
                return True
        return False

    @classmethod
    async def _do_reject(cls, db, row, opinion, user):
        """退回分支。"""
        await db.execute(text("""
            UPDATE m13_report_review
            SET status = 'REJECTED',
                conclusion = 'REJECT',
                opinion = :op,
                reviewer_id = :uid,
                reviewer_name = :uname,
                reviewed_at = now(),
                updated_at = now()

    async def batch_pass(cls, body, user):
        """批量通过。"""
        db = user["db"]
        ids = body.review_ids or []
        if len(ids) > cls.MAX_BATCH_PASS:
            raise BizException(
                "1304018",
                "批量通过数量不得超过 %d 条" % cls.MAX_BATCH_PASS)
        if not ids:
            raise BizException("1304004", "未选择任何报告")

        # 危急值报告不可批量通过
        crit = (await db.execute(text("""
            SELECT report_no FROM m13_report_review
            WHERE id = ANY(:ids) AND critical_count > 0
        """), {"ids": ids})).all()
        if crit:
            raise BizException(
                "1304019",
                "包含危急值报告，不允许批量通过：%s"
                % ",".join([c.report_no for c in crit]))

        ok, skipped = [], []
        for rid in ids:
            try:
                row = await cls._get_for_update(db, rid)
                if row.status != "PENDING":
                    skipped.append({
                        "review_id": rid,
                        "reason": "状态不允许",
                    })
                    continue
                res = await db.execute(text("""
                    UPDATE m13_report_review
                    SET status = 'PUBLISHED',
                        conclusion = 'PASS',
                        reviewer_id = :uid,
                        reviewer_name = :uname,
                        reviewed_at = now(),
                        published_at = now(),

                        updated_at = now()
                    WHERE id = :id AND status = 'PENDING'
                """), {
                    "id": rid, "uid": user["employee_id"],
                    "uname": user["employee_name"],
                })
                if res.rowcount:
                    ok.append(rid)
                    push_report_task.delay(rid, 1)
            except Exception as exc:
                skipped.append({
                    "review_id": rid, "reason": str(exc)[:100]})
        await db.commit()
        return {
            "passed": len(ok),
            "skipped": len(skipped),
            "passed_ids": ok,
            "skipped_items": skipped,
        }

    @classmethod
    async def revise(cls, review_id: int, body, user):
        """修订报告。"""
        db = user["db"]
        row = await cls._get_for_update(db, review_id)

        # ① 状态校验
        if row.status != "PUBLISHED":
            raise BizException(
                "1304003", "只有已发布的报告可以修订")
        if row.version_no >= 100:
            raise BizException(
                "1304012", "修订次数已达上限，请联系科主任")

        # ② 修订窗口
        days = (datetime.now() - row.published_at).days
        if days > cls.REVISE_WINDOW_DAYS:
            raise BizException(
                "1304013",
                "报告发布已超过 %d 天，不可修订（只能补充说明）"
                % cls.REVISE_WINDOW_DAYS)

        # ③ 修订原因
        reason = (body.revise_reason or "").strip()
        if len(reason) < 20:
            raise BizException(
                "1304011", "修订原因不得少于 20 个字符")

        # ④ 修订次数超限需科主任
        if row.version_no >= cls.MAX_REVISE_COUNT and \
                not cls._is_director(user):
            raise BizException(
                "1304012",
                "修订次数已达 %d 次，需科主任批准"
                % cls.MAX_REVISE_COUNT)

        # ⑤ 生成新版本
        new_ver = row.version_no + 1
        snapshot = await cls._build_snapshot(
            db, review_id, row.parse_id)
        await db.execute(text("""
            INSERT INTO m13_report_version

            SET version_no = :ver,
                revise_reason = :reason,
                revise_count = revise_count + 1,
                push_status = 'PENDING',

            INSERT INTO m13_report_publish

                 push_status, attempt_count, operator_id,
                 operator_name, published_at, created_at)

                (:rid, :rno, :ver, 'REVISE', 'PENDING', 0,
                 :uid, :uname, now(), now())
        """), {
            "rid": review_id, "rno": row.report_no,
            "ver": new_ver, "uid": user["employee_id"],
            "uname": user["employee_name"],

        await db.commit()

        await CriticalDetector.recheck(db, review_id, user)

            "revise_reason": reason,
            "published_at": datetime.now().isoformat(),
            "push": {"push_status": "PENDING"},
        }
```

```python
"""M13-04 危急值判定与通知。"""
import logging
from datetime import datetime, timedelta

from sqlalchemy import text

from app.integrations.m01_client import M01Client
from app.integrations.m07_client import M07Client
from app.services.m13.client import M13RefClient
from app.tasks.m13_review_tasks import (
    push_critical_task, notify_escalation_task,
)

logger = logging.getLogger("m13.critical")

ESCALATE_MINUTES = (15, 30, 60)
HANDLE_SLA_MINUTES = 120
AUTO_CLOSE_HOURS = 24


class CriticalDetector:
    """危急值检测器。"""

    @classmethod
    async def detect(cls, db, review_id, user):
        """检出危急值。"""
        # ① 读取规则（M13-05 优先，M01-09 兜底）
        rules, rules_ok = await cls._load_rules(db, review_id, user)

        # ② 读取字段值
        rows = (await db.execute(text("""
            SELECT field_code, field_name, numeric_value,
                   value_text, unit, ref_text
            FROM m13_review_field
            WHERE review_id = :rid AND is_deleted = FALSE
        """), {"rid": review_id})).all()

        fields = {}
        for r in rows:
            if r.numeric_value is not None:
                fields[r.field_code] = r

        # ③ 逐条判定
        hits, skipped = [], []
        for rule in rules:
            f = fields.get(rule["field_code"])
            if f is None:
                skipped.append(rule["rule_code"])
                continue
            v = f.numeric_value
            hit = cls._hit(v, rule)
            if not hit:
                continue
            hits.append({
                "rule_code": rule["rule_code"],
                "rule_name": rule.get("rule_name"),
                "field_code": f.field_code,
                "lab_name": f.field_name,
                "value": float(v),
                "value_text": f.value_text,
                "unit": f.unit,
                "ref_text": f.ref_text,
                "severity": rule.get(
                    "critical_level", "WARNING"),
                "threshold_text": cls._threshold_text(rule),
            })

        # ④ 落库
        created = []
        for h in hits:
            crit_no = await cls._next_no(db)
            cid = (await db.execute(text("""
                INSERT INTO m13_critical_value
                    (critical_no, review_id, rule_code,
                     rule_name, field_code, lab_name,
                     detected_value, value_text, unit,
                     ref_text, threshold_text, severity,
                     status, detected_at, detected_by,
                     created_at, updated_at)
                VALUES
                    (:cno, :rid, :rcode, :rname, :fcode, :lname,
                     :val, :vtext, :unit, :ref, :thr, :sev,
                     'DETECTED', now(), :uid, now(), now())
                RETURNING id
            """), {
                "cno": crit_no, "rid": review_id,
                "rcode": h["rule_code"],
                "rname": h.get("rule_name"),
                "fcode": h["field_code"],
                "lname": h["lab_name"],
                "val": h["value"], "vtext": h["value_text"],
                "unit": h["unit"], "ref": h["ref_text"],
                "thr": h["threshold_text"],
                "sev": h["severity"],
                "uid": user["employee_id"],
            })).scalar()
            h["critical_id"] = cid
            created.append(h)

        await db.commit()

        if not rules_ok:
            logger.warning(
                "critical rules unavailable, review_id=%s", review_id)
            await cls._alert_rules_missing(db, review_id)

        return created, skipped

    @classmethod
    def _hit(cls, v, rule):
        """单条规则判定。"""
        op = rule["operator"]
        lo = rule.get("threshold_min")
        hi = rule.get("threshold_max")
        if op == "GT" and hi is not None:
            return v > hi
        if op == "LT" and lo is not None:
            return v < lo
        if op == "GTE" and hi is not None:
            return v >= hi
        if op == "LTE" and lo is not None:
            return v <= lo
        if op == "OUTSIDE" and lo is not None and hi is not None:
            return v < lo or v > hi
        if op == "BETWEEN" and lo is not None and hi is not None:
            return lo <= v <= hi
        return False

    @classmethod
    def _threshold_text(cls, rule):
        """阈值文字描述。"""
        lo = rule.get("threshold_min")
        hi = rule.get("threshold_max")
        op = rule["operator"]
        if op == "GT":
            return "> %s" % hi
        if op == "LT":
            return "< %s" % lo
        if op == "GTE":
            return ">= %s" % hi
        if op == "LTE":
            return "<= %s" % lo
        if op == "OUTSIDE":
            return "< %s 或 > %s" % (lo, hi)
        if op == "BETWEEN":
            return "%s ~ %s" % (lo, hi)
        return ""

    @classmethod
    async def _load_rules(cls, db, review_id, user):
        """加载危急值规则。"""
        head = (await db.execute(text("""
            SELECT lab_code FROM m13_report_review
            WHERE id = :id
        """), {"id": review_id})).one()

        # ① M13-05 本科室自定义
        try:
            rules = await M13RefClient.get_critical_rules(
                head.lab_code, timeout=2.0)
            if rules:
                return rules, True
        except Exception:
            pass

        # ② M01-09 主数据
        try:
            rules = await M01Client.get_critical_rules(
                head.lab_code, timeout=2.0)
            if rules:
                return rules, True
        except Exception:
            pass

        return [], False

    @classmethod
    async def dispatch(cls, db, hit, user):
        """派发危急值通知。"""
        push_critical_task.delay(hit["critical_id"])
        return hit["critical_id"]

    @classmethod
    async def on_acknowledged(cls, critical_id, body):
        """医生确认回写。"""
        db = body["db"]
        row = (await db.execute(text("""
            UPDATE m13_critical_value
            SET status = 'ACKNOWLEDGED',
                acknowledged_at = :at,
                acknowledged_by = :uid,
                acknowledged_name = :name,
                ack_channel = :ch,
                ack_remark = :rmk,
                handle_deadline_at = (
                    :at::timestamptz
                    + INTERVAL '120 minutes'),
                updated_at = now()
            WHERE id = :id
              AND status IN ('NOTIFIED', 'ESCALATED_1',
                             'ESCALATED_2', 'ESCALATED_3')
            RETURNING detected_at, notified_at
        """), {
            "id": critical_id, "at": body["acknowledged_at"],
            "uid": body["doctor_id"],
            "name": body["doctor_name"],
            "ch": body.get("channel", "WEBSOCKET"),
            "rmk": body.get("remark"),
        })).first()

        if row is None:
            await db.rollback()
            cur = (await db.execute(text("""
                SELECT status FROM m13_critical_value
                WHERE id = :id
            """), {"id": critical_id})).first()
            if cur is None:
                from app.core.exceptions import BizException
                raise BizException("1304020", "危急值不存在")
            from app.core.exceptions import BizException
            raise BizException(
                "1304003", "危急值状态不允许确认：%s" % cur.status)

        await db.commit()

        ack_elapsed = 0
        if row.notified_at:
            ack_elapsed = int(
                (datetime.now() - row.notified_at)
                .total_seconds() // 60)

        return {
            "critical_id": critical_id,
            "status": "ACKNOWLEDGED",
            "acknowledged_at": body["acknowledged_at"],
            "ack_elapsed_minutes": ack_elapsed,
            "updated": True,
        }

    @classmethod
    async def escalate(cls, db, critical_id):
        """督办升级。"""
        # 5 分钟内不可重复督办
        key = "m13:critical:escalate:%d" % critical_id
        from app.core.redis_client import redis_client
        if not redis_client.set(key, "1", nx=True, ex=300):
            from app.core.exceptions import BizException
            raise BizException("1304022", "5 分钟内不可重复督办")

        row = (await db.execute(text("""
            UPDATE m13_critical_value
            SET escalation_level = LEAST(
                    escalation_level + 1, 3),
                status = 'ESCALATED_' || LEAST(
                    escalation_level + 1, 3),
                escalated_at = now(),
                updated_at = now()
            WHERE id = :id
              AND status <> 'CLOSED'
            RETURNING escalation_level, status
        """), {"id": critical_id})).first()
        if row is None:
            await db.rollback()
            from app.core.exceptions import BizException
            raise BizException(
                "1304021", "危急值已闭环不可督办")
        await db.commit()
        notify_escalation_task.delay(critical_id, row.escalation_level)
        return {
            "critical_id": critical_id,
            "escalation_level": row.escalation_level,
            "status": row.status,
        }

    @classmethod
    async def _next_no(cls, db):
        """生成危急值编号。"""
        from app.core.redis_client import redis_client
        today = datetime.now().strftime("%Y%m%d")
        key = "m13:critical:seq:%s" % today
        seq = redis_client.incr(key)
        redis_client.expire(key, 172800)
        return "CV%s%05d" % (today, seq % 100000)

    @classmethod
    async def _alert_rules_missing(cls, db, review_id):
        """危急值规则缺失告警。"""
        logger.error(
            "M13: critical rules missing for review_id=%s",
            review_id)

    @classmethod
    async def recheck(cls, db, review_id, user):
        """修订后重新判定危急值。"""

            UPDATE m13_critical_value
            SET status = 'SUPERSEDED', updated_at = now()
            WHERE review_id = :rid AND status <> 'CLOSED'
        """), {"rid": review_id})
        await db.commit()
        return await cls.detect(db, review_id, user)
```

### 6.8 推送服务

```python
"""M13-04 报告推送服务。"""
import logging
from datetime import datetime

from sqlalchemy import text

from app.integrations.m07_client import M07Client

logger = logging.getLogger("m13.publish")

RETRY_DELAYS = [10, 30, 60, 120, 300, 600, 1200, 1800, 3600]
MAX_RETRY = 10


class PublishService:
    """发布推送服务。"""

    @classmethod
    async def push(cls, db, review_id, version_no):
        """推送报告到 M07-04。"""
        row = (await db.execute(text("""
            SELECT r.*, v.snapshot_json
            FROM m13_report_review r
            LEFT JOIN m13_report_version v
                ON v.review_id = r.id
               AND v.version_no = :ver
            WHERE r.id = :id
        """), {"id": review_id, "ver": version_no})).first()
        if row is None:
            return {"ok": False, "reason": "REPORT_NOT_FOUND"}

        pub = (await db.execute(text("""
            SELECT id, attempt_count FROM m13_report_publish
            WHERE review_id = :rid AND version_no = :ver
              AND publish_action IN ('PUBLISH', 'REVISE')
            ORDER BY id DESC LIMIT 1
        """), {"rid": review_id, "ver": version_no})).first()
        if pub is None:
            return {"ok": False, "reason": "PUBLISH_RECORD_NOT_FOUND"}

        payload = cls._build_payload(row, version_no)
        try:
            res = await M07Client.push_report(
                payload, timeout=3.0)
        except Exception as exc:
            await cls._mark_attempt(
                db, pub.id, False, str(exc)[:200], None)
            return {"ok": False, "reason": str(exc)[:200]}

        ok = bool(res.get("saved"))
        await cls._mark_attempt(
            db, pub.id, ok, res.get("message"),
            200 if ok else None)
        return {
            "ok": ok,
            "saved": ok,
            "is_duplicate": res.get("is_duplicate"),
            "doctor_notified": res.get("doctor_notified"),
        }

    @classmethod
    def _build_payload(cls, row, version_no):
        """构建推送载荷。"""
        snap = row.snapshot_json or {}
        fields = snap.get("fields") or []
        return {
            "report_id": row.id,
            "report_no": row.report_no,
            "report_type": "LAB",
            "order_id": row.order_id,
            "order_no": row.order_no,
            "encounter_id": row.encounter_id,
            "patient_id": row.patient_id,
            "item_code": row.lab_code,
            "item_name": row.lab_name,
            "eye_side": row.eye_side or "NA",
            "status": ("WITHDRAWN"
                       if row.status == "WITHDRAWN"
                       else "FINAL"),
            "conclusion": cls._build_conclusion(fields),
            "findings": None,
            "recommendation": None,
            "has_critical": row.critical_count > 0,
            "structured_data": {
                "is_structured": True,
                "fields": [
                    {
                        "field_code": f["field_code"],
                        "field_name": f["field_name"],
                        "value": f["value"],
                        "unit": f.get("unit"),
                        "ref_min": f.get("ref_low"),
                        "ref_max": f.get("ref_high"),
                    }
                    for f in fields
                ],
            },
            "images": [],
            "executed_at": (row.published_at.isoformat()
                            if row.published_at else None),
            "reported_at": (row.published_at.isoformat()
                            if row.published_at else None),
            "reporter_name": row.reviewer_name,
            "reviewer_name": row.reviewer_name,
            "source_module": "M13",
            "version_no": version_no,
            "is_new_version": version_no > 1,
        }

    @classmethod
    def _build_conclusion(cls, fields):
        """生成结论摘要。"""
        abnormals = [
            f for f in fields
            if f.get("flag") in ("HIGH", "LOW",
                                 "CRITICAL_HIGH", "CRITICAL_LOW")
        ]
        if not abnormals:
            return "各项检验结果均在参考区间内"
        parts = []
        for f in abnormals[:5]:
            parts.append("%s %s%s" % (
                f["field_name"], f["value"],
                "↑" if f.get("flag") in ("HIGH", "CRITICAL_HIGH")
                else "↓"))
        text = "、".join(parts)
        if len(abnormals) > 5:
            text += " 等 %d 项异常" % len(abnormals)
        return text

    @classmethod
    async def _mark_attempt(cls, db, pub_id, ok, err, status):
        """记录推送尝试。"""
        if ok:
            await db.execute(text("""
                UPDATE m13_report_publish
                SET push_status = 'SUCCESS',
                    attempt_count = attempt_count + 1,
                    last_attempt_at = now(),
                    last_error = NULL,
                    last_http_status = :st,
                    updated_at = now()
                WHERE id = :id
            """), {"id": pub_id, "st": status})
        else:
            await db.execute(text("""
                UPDATE m13_report_publish
                SET push_status = CASE
                        WHEN attempt_count + 1 >= :maxr
                        THEN 'FAILED' ELSE 'PENDING' END,
                    attempt_count = attempt_count + 1,
                    last_attempt_at = now(),
                    last_error = :err,
                    last_http_status = :st,
                    updated_at = now()
                WHERE id = :id
            """), {
                "id": pub_id, "err": err, "st": status,
                "maxr": MAX_RETRY,
            })
        await db.commit()

    @classmethod
    def next_delay(cls, attempt_count):
        """计算下次重试延迟。"""
        idx = min(attempt_count, len(RETRY_DELAYS) - 1)
        return RETRY_DELAYS[idx]

    @classmethod
    async def list_publish(cls, page, page_size, push_status,
                           keyword, user):
        """推送记录列表。"""
        db = user["db"]
        where = ["is_deleted = FALSE"]
        params = {}
        if push_status:
            where.append("push_status = :ps")
            params["ps"] = push_status
        if keyword:
            where.append(
                "(report_no ILIKE :kw OR patient_name ILIKE :kw)")
            params["kw"] = "%" + keyword + "%"
        cond = " AND ".join(where)

        total = (await db.execute(text(
            "SELECT COUNT(*) FROM m13_report_publish "
            "WHERE " + cond), params)).scalar()
        params["lim"] = page_size
        params["off"] = (page - 1) * page_size
        rows = (await db.execute(text(
            "SELECT * FROM m13_report_publish WHERE " + cond +
            " ORDER BY created_at DESC LIMIT :lim OFFSET :off"),
            params)).all()

        return {
            "items": [
                {
                    "publish_id": r.id,
                    "report_no": r.report_no,
                    "patient_name": r.patient_name,
                    "version_no": r.version_no,
                    "publish_action": r.publish_action,
                    "push_status": r.push_status,
                    "attempt_count": r.attempt_count,
                    "last_attempt_at": (r.last_attempt_at.isoformat()
                                        if r.last_attempt_at else None),
                    "last_error": r.last_error,
                }
                for r in rows
            ],
            "total": total, "page": page, "page_size": page_size,
        }

    @classmethod
    async def repush(cls, publish_id, body, user):
        """重新推送。"""
        db = user["db"]
        res = await db.execute(text("""
            UPDATE m13_report_publish
            SET push_status = 'PENDING',
                attempt_count = 0,
                last_error = NULL,
                updated_at = now()
            WHERE id = :id AND is_deleted = FALSE
            RETURNING review_id, version_no
        """), {"id": publish_id})
        row = res.first()
        if row is None:
            from app.core.exceptions import BizException
            raise BizException("1304017", "推送记录不存在")
        await db.commit()
        from app.tasks.m13_review_tasks import push_report_task
        push_report_task.delay(row.review_id, row.version_no)
        return {
            "publish_id": publish_id,
            "push_status": "PENDING",
            "requeued": True,
        }
```

```python
import asyncio
import logging
from datetime import datetime, timedelta

from celery import shared_task

logger = logging.getLogger("m13.review.tasks")

RETRY_DELAYS = [10, 30, 60, 120, 300, 600, 1200, 1800, 3600]


@shared_task(bind=True, max_retries=10)
def push_report_task(self, review_id, version_no):
    """推送报告。"""
    from app.db.session import get_async_session
    from app.services.m13.publish_service import PublishService

    async def _run():
        async with get_async_session() as db:
            return await PublishService.push(
                db, review_id, version_no)

    try:
        res = asyncio.run(_run())
    except Exception as exc:
        logger.error(
            "push_report failed review=%s ver=%s err=%s",
            review_id, version_no, exc)
        delay = RETRY_DELAYS[
            min(self.request.retries, len(RETRY_DELAYS) - 1)]
        raise self.retry(exc=exc, countdown=delay)

    if not res.get("ok"):
        delay = RETRY_DELAYS[
            min(self.request.retries, len(RETRY_DELAYS) - 1)]
        if self.request.retries >= 9:
            logger.error(
                "push_report gave up review=%s ver=%s",
                review_id, version_no)
            return res
        raise self.retry(
            exc=RuntimeError(res.get("reason")), countdown=delay)
    return res

@shared_task
def check_escalation_task():
    """扫描超时危急值并升级。"""
    from app.db.session import get_async_session
    from sqlalchemy import text

    async def _run():
        async with get_async_session() as db:
            rows = (await db.execute(text("""
                SELECT id, notified_at, escalation_level
                FROM m13_critical_value
                WHERE status IN ('NOTIFIED', 'ESCALATED_1',
                                 'ESCALATED_2')
            """))).all()
            now = datetime.now()
            for r in rows:
                if r.notified_at is None:
                    continue
                elapsed = (now - r.notified_at).total_seconds() / 60
                limits = (15, 30, 60)
                should = 0
                for i, lim in enumerate(limits):
                    if elapsed >= lim:
                        should = i + 1
                if should > (r.escalation_level or 0):
                    await db.execute(text("""
                        UPDATE m13_critical_value
                        SET escalation_level = :lv,
                            status = 'ESCALATED_' || :lv,
                            escalated_at = now(),
                            updated_at = now()
                        WHERE id = :id
                    """), {"id": r.id, "lv": should})
            await db.commit()

    asyncio.run(_run())
```

### 9.4 安全措施

| 措施 | 说明 |
|---|---|
| 签字留痕 | 审核人、时间、IP、设备指纹全部记录 |
| 不可删除 | 报告记录只有软删除，无物理删除接口 |
| 版本不可篡改 | `m13_report_version` 触发器禁止 UPDATE/DELETE |
| 修订留痕 | 修订前后快照都保留 |
| 敏感操作审计 | 修订、撤回、强制关闭推送全部写 M02-06 |

**为什么报告记录不允许物理删除？**

检验报告是医疗证据，保存期 15 年（《医疗机构病历管理规定》）。即使患者要求删除，也只能软删除并保留审计痕迹。物理删除会破坏病历完整性。
