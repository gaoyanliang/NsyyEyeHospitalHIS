## 1. 模块概述

### 1.1 模块定位

M13-02 检验结果文件采集负责回答三个问题：

1. **文件有没有进来？** —— 监听共享文件夹，发现新增 PDF 报告
2. **是不是重复的？** —— 通过 SHA-256 指纹去重
3. **原件在哪？** —— 归档到长期目录，保留可追溯的文件路径

**M13-02 是整条检验报告链路的入口，也是唯一知道"文件在哪"的地方。**

```
             检验设备（LIS 系统或仪器工作站）
                        │
                        │ 检验技师导出 PDF
                        ▼
        \\fileserver\lab-reports\INBOX\
                        │
                        │ watchdog inotify + 定时扫描
                        ▼
        ┌──────────────────────────────────────────────┐
        │       M13-02 检验结果文件采集与归档            │
        │                                              │
        │  ① 发现 ──────────────────────────────────┐ │
        │     监听 INBOX，发现新增文件               │ │
        │                                            │ │
        │  ② 稳定性判定 ────────────────────────────┤ │
        │     等文件写完（大小不变 + 可独占打开）     │ │
        │                                            │ │
        │  ③ 去重 ──────────────────────────────────┤ │
        │     SHA-256 指纹比对                       │ │
        │                                            │ │
        │  ④ 登记 ──────────────────────────────────┤ │
        │     写 m13_report_file，状态 COLLECTED     │ │
        │                                            │ │
        │  ⑤ 派发解析 ──────────────────────────────┤ │
        │     通知 M13-03 开始 OCR 解析              │ │
        │                                            │ │
        │  ⑥ 归档 ──────────────────────────────────┤ │
        │     移入 ARCHIVE/yyyy/MM/dd/               │ │
        │                                            │ │
        └──────────────────────────────────────────────┘
                        │
                        ▼
        ┌──────────────────────────────────────────────┐
        │  M13-03 检验结果 OCR 解析与结构化             │
        │  （不认识文件，只认识 M13-02 给的 file_id）   │
        └──────────────────────────────────────────────┘
```

**M13-02 不认识患者，也不懂检验数据。它只回答"文件有没有进来、是不是重复、原件在哪"。**

### 1.2 为什么独立成子模块

**理由一：文件采集是整条链路唯一不可跳过的入口，也是最脆弱的一环。**

检验设备（生化仪、血球仪、免疫分析仪）全部无法接入 HIS，只能由技师在仪器工作站上导出 PDF 到共享文件夹。这个通路有 10 类技术问题需要处理：

| 问题 | 现象 | 处理 |
|---|---|---|
| 文件正在写入 | 读到半个 PDF | 稳定性判定（两次采样 + 可独占打开） |
| 技师重复导出 | 同一报告两份文件 | SHA-256 去重 |
| 文件名混乱 | `检验报告(1).pdf` / `新建文本文档.pdf` | 不依赖文件名，只依赖内容 |
| 多级子目录 | 技师建了自己的文件夹 | 递归扫描 |
| 文件超大 | 单份报告 300MB（含图像） | 大小上限 + 隔离 |
| 非 PDF | 误存了 .doc / .jpg | 魔数校验 + 隔离 |
| 中文乱码 | 文件名 GBK/UTF-8 混杂 | 不解析文件名 |
| 文件被占用 | 仪器软件仍持有句柄 | 重试（最多 20 次） |
| 设备时钟不准 | mtime 错误 | 用文件创建时间 + 采集时间双记录 |
| 同名覆盖 | 两份文件同名被覆盖 | 归档时加 SHA-256 前缀 |

这 10 类问题全部是"文件系统层"的问题，与"检验数据是什么"毫无关系。

**理由二：采集失败会导致后续所有环节无从谈起。**

```
采集失败 → 没有 file_id → M13-03 无从解析 → 没有报告
        → 医生看不到结果 → 患者白抽血 → 投诉
```

这个环节的可用性要求是 **99.9%**，而 OCR 解析（M13-03）挂掉时数字 PDF 仍可通过文本层解析（降级）。

职责分离后，采集服务可以用独立的进程、独立的资源池、独立的告警，M13-03 的 OCR 崩溃不会拖垮采集。

**理由三：归档是独立的数据生命周期管理问题。**

| 数据 | 保留期 | 存储位置 |
|---|---|---|
| 原件 PDF | **15 年**（病历法规） | 共享文件夹 `ARCHIVE/` |
| 文件元数据（指纹、路径、大小） | 15 年 | PostgreSQL |
| 采集日志 | 3 年 | PostgreSQL 分区表 |

归档策略：
- 立即校验 SHA-256 并记录
- 5 分钟后移入 `ARCHIVE/yyyy/MM/dd/`（按文件 mtime 分组）
- 每日 02:00 抽样巡检，发现丢失告警
- 只移不删，永不删除原件

这套策略与"解析数据是什么"完全无关，把它放在 M13-03 会让解析服务承担存储管理职责。

**理由四：采集率、延迟、巡检异常是独立的运维指标。**

| 指标 | 目标 | 责任方 |
|---|---|---|
| 采集率 | ≥ 99.9% | M13-02 |
| 采集延迟 | P95 ≤ 60 秒 | M13-02 |
| 待确认积压 | ≤ 50 条 | M13-03 |
| 解析成功率 | ≥ 97% | M13-03 |

如果合成一个子模块，"采集率 96%"的根因在共享文件夹没挂载，会被误判为"OCR 有问题"。

**关键边界：**

- M13-02 **不认识患者**。文件可能一开始是"无主文件"，绑定由 M13-03 完成。
- M13-02 **不解析 PDF 内容**。连"这是不是检验报告"都不判断（那是 M13-03 的事）。
- M13-02 **不判断标本**。标本关联只在解析出结果后才建立。

### 1.4 概念辨析

| 概念 | 定义 | 归属 |
|---|---|---|
| **文件** | 共享文件夹中的一个 PDF 物理文件 | **M13-02** |
| **报告** | 一份完整的检验结果报告（含多个项目） | M13-03 解析 / M13-04 审核 |
| **结果** | 报告中的一行（如"WBC 6.5 ×10^9/L"） | M13-03 |
| **报告文件** | 承载报告的 PDF 文件 | **M13-02** |
| **采集** | 从共享文件夹发现并登记文件 | **M13-02** |
| **归档** | 把文件从 INBOX 移到 ARCHIVE | **M13-02** |
| **解析** | 从 PDF 中提取结构化数据 | M13-03 |
| **绑定** | 把报告关联到患者与检验任务 | M13-03 |
| **无主** | 无法绑定到患者或任务的报告 | M13-03 |
| **重复** | SHA-256 与已有文件相同 | **M13-02** |

**最容易混淆的三组：**

**① 采集 ≠ 解析**

采集只做"文件搬进系统"：
- 算 SHA-256
- 记大小、页数、修改时间
- 判断是不是 PDF
- 判断是否重复
- 归档

它**不知道文件里写的是谁的、什么检查、结果是多少**。

**② 重复 ≠ 覆盖**

- **重复**：SHA-256 相同，内容完全一致。两份都保留记录，第二份标 `is_duplicate=TRUE`
- **覆盖**：后一份把前一份覆盖了。**采集层无法阻止**（文件系统行为），但归档时用 SHA-256 前 8 位命名可避免

**③ 归档 ≠ 删除**

归档是移动到 `ARCHIVE/yyyy/MM/dd/`。原件**永不删除**。哪怕已解析、已审核、已推送，原件仍保留 15 年。

这是 S3 方案（PDF 原件留在共享文件夹，库中只存路径）的必然要求：**库中没有文件内容，只有路径与指纹**。丢失原件就等于丢失报告。

### 1.5 模块目标

| 指标 | 目标 | 测量方式 |
|---|---|---|
| 文件发现延迟 | P95 ≤ 5 秒 | 文件 mtime 到登记时刻 |
| 稳定性判定时间 | 平均 6~10 秒 | 两次采样 + 独占打开 |
| SHA-256 计算（12MB） | P95 ≤ 100ms | 采集流水线 |
| 文件登记 | P95 ≤ 500ms | `POST /internal/v1/m13/collect/files` |
| 采集率 | ≥ 99.9% | 已采集文件数 / 应有报告数 |
| 重复识别率 | **100%** | SHA-256 相同必然识别 |
| 归档成功率 | ≥ 99.9% | 归档成功 / 需归档 |
| 巡检丢失发现率 | 100% | 抽样 320 份，丢失率 1% 时发现率 96% |
| 巡检误报率 | ≤ 0.1% | 误报为丢失但实际存在 |

## 2. 业务范围与边界

### 2.1 范围内

| 能力 | 说明 |
|---|---|
| 监听共享文件夹 | watchdog inotify + 定时全量扫描双保险 |
| 文件稳定性判定 | 大小不变 + 可独占打开 + PDF 魔数 + 年龄 |
| SHA-256 指纹计算 | 流式计算，1MB 分块 |
| 去重 | 指纹比对，完全相同标 DUPLICATE |
| 文件登记 | 写 `m13_report_file`，生成文件编号 |

| 原件巡检 | 每日抽样校验 SHA-256，发现丢失告警 |

| 采集监控看板 | 采集率、延迟、积压、异常 |

## 3. 业务模型

### 3.1 文件生命周期模型

```
       技师导出 PDF
            │
            ▼
    ┌───────────────┐
    │  INBOX/       │  共享文件夹收件箱
    │  （设备写入）   │
    └───────┬───────┘
            │ watchdog 事件 / 定时扫描
            ▼
    ┌───────────────────────────────────────┐
    │ ① 稳定性判定                           │
    │    大小两次采样一致（间隔 3 秒）        │
    │    + 可独占打开                        │
    │    + PDF 魔数 %PDF-                    │
    │    + 文件年龄 > 5 秒                    │
    │    不通过 → 重试（最多 20 次）          │
    └───────────────┬───────────────────────┘
                    │ 通过
                    ▼
    ┌───────────────────────────────────────┐
    │ ② SHA-256 计算（流式，1MB 分块）        │
    └───────────────┬───────────────────────┘
                    │
            ┌───────┴────────┐
            │                │
      指纹已存在        指纹不存在
            │                │
            ▼                ▼
    ┌──────────────┐  ┌──────────────────────┐
    │ DUPLICATE    │  │ ③ 登记 COLLECTED      │
    │ 记录重复关系  │  │    写 m13_report_file │
    │ 不派发解析    │  │    parse_status=      │
    │              │  │    PENDING_DISPATCH   │
    └──────────────┘  └──────────┬───────────┘
                                 │
                                 ▼
                     ┌───────────────────────┐
                     │ ④ 派发解析             │
                     │   调 M13-03 on-file-   │
                     │   collected            │
                     │   parse_status=         │
                     │   PARSING              │
                     └───────────┬───────────┘
                                 │
                     ┌───────────┴────────────┐
                     │                        │
              归档延迟 5 分钟           归档延迟 5 分钟
                     │                        │
                     ▼                        ▼
              ┌──────────────┐        ┌──────────────┐
              │ 归档中         │        │ 归档失败      │
              │ ARC_PENDING   │        │ ARC_FAILED   │
              └──────┬───────┘        └──────┬───────┘
                     │                        │
              移动成功│                 重试 3 次
                     ▼                        │
              ┌──────────────┐                │
              │ 已归档         │◄───────────────┘
              │ ARCHIVED     │
              └──────────────┘
                     │
              （原件保留 15 年，永不删除）
```

**文件状态（`m13_report_file.status`）：**

| 状态 | 含义 |
|---|---|
| `COLLECTED` | 已登记，等待派发解析 |
| `PARSING` | 已派发给 M13-03 |
| `PARSED` | M13-03 解析完成（无论是否绑定成功） |
| `PARSE_FAILED` | 解析失败 |
| `QUARANTINE` | 已隔离（非 PDF / 损坏 / 超大） |
| `DUPLICATE` | 重复文件 |
| `ORPHAN` | 无主（超期未绑定） |

**归档状态（`archive_status`）：**

| 状态 | 含义 |
|---|---|
| `PENDING` | 等待归档（5 分钟延迟） |
| `ARCHIVED` | 已归档 |
| `FAILED` | 归档失败（重试中） |

**解析状态（`parse_status`，M13-02 侧跟踪）：**

| 状态 | 含义 |
|---|---|
| `PENDING_DISPATCH` | 已登记但未派发 |
| `PARSING` | 已派发，M13-03 处理中 |
| `PARSED` | M13-03 回写解析完成 |
| `FAILED` | M13-03 回写解析失败 |

### 3.2 稳定性判定模型

**四条件缺一不可：**

| 条件 | 判据 | 为什么需要 |
|---|---|---|
| **大小稳定** | 两次采样（间隔 3 秒）大小相同 | 防止读到半个文件 |
| **可独占打开** | `open(path, 'rb')` 不抛 `PermissionError` / `OSError` | 仪器软件可能仍持有句柄 |
| **PDF 魔数** | 前 5 字节 `%PDF-` | 防止误收非 PDF |
| **文件年龄** | `now - mtime > 5 秒` | 防止刚创建还没写完就被判定"稳定" |

**重试策略：**

```
最多重试 20 次，间隔 3 秒
  ↓
20 次后仍不稳定
  ↓
标记采集失败（记 m13_collect_failure，reason=UNSTABLE）
  ↓
30 分钟后重新扫描（可能这次就稳定了）
```

**为什么是两次采样而不是三次？**

三次采样会多 3 秒延迟。设备导出通常 2~10 秒完成，两次采样（3 秒间隔）已足够覆盖 95% 场景。剩下 5% 会被重试机制接住。

如果两次采样间隔太短（<1 秒），大文件仍可能读到半个。3 秒是实测的经验值：12MB PDF 在两个机械硬盘上的写入通常 < 2 秒。

**为什么文件年龄要 > 5 秒？**

刚创建的文件大小可能是 0 或很小，且正在写入。等待 5 秒让文件"落定"。

### 3.3 去重模型

**SHA-256 流式计算：**

```
打开文件
  ↓
循环读取 1MB 分块
  ↓
update(hash, chunk)
  ↓
关闭文件
  ↓
得到 32 字节摘要 → hex 编码成 64 位字符串
```

**为什么用 SHA-256 而不是 MD5？**

| 算法 | 抗碰撞性 | 性能 |
|---|---|---|
| MD5 | **已被破解**（可构造碰撞） | 快 |
| SHA-1 | **已被破解**（SHAttered 攻击） | 中 |
| SHA-256 | 无已知实用攻击 | 慢约 30% |

医疗报告是**法律证据**。如果两个人能构造出相同 MD5 的两份不同报告，攻击者可把"A 的报告"替换成"B 的报告"而系统不报警。SHA-256 的碰撞概率是 2^-128，宇宙年龄内都碰不到。

**性能实测（12MB PDF，SSD）：**

| 算法 | 耗时 |
|---|---|
| MD5 | 42ms |
| SHA-1 | 48ms |
| SHA-256 | 68ms |

差异 26ms，在 500ms 的登记 SLA 内可忽略。

**去重策略：**

```
if sha256 已存在（非重复、非删除）:
    新记录 is_duplicate = TRUE
    新记录 duplicate_of_file_id = 已有记录 id
    新记录 status = 'DUPLICATE'
    不派发解析
else:
    新记录 is_duplicate = FALSE
    正常流程
```

**为什么要保留重复记录而不是直接丢弃？**

"技师导了两次"本身是信息：
- 统计"重复导出率"，可以推动技师改进操作
- 若原文件在归档中丢失，重复文件可作为备份
- 若原文件解析失败，可尝试用重复文件重试（虽然内容相同，但至少证明文件存在过）

### 3.4 归档模型

**目录结构：**

```
\\fileserver\lab-reports\
├── INBOX\                    ← 设备写入（技师导出目标）
│   ├── 检验报告_20261022.pdf
│   └── 生化\                 ← 技师自建子目录（递归扫描）
│       └── 2026-10-22.pdf
├── ARCHIVE\                  ← 归档区（系统写入）
│   ├── 2026\
│   │   ├── 10\
│   │   │   ├── 22\
│   │   │   │   ├── a1b2c3d4_RPT2026102200001.pdf
│   │   │   │   └── e5f6a7b8_RPT2026102200002.pdf
│   │   │   └── 23\
│   │   │       └── ...
│   └── 2025\
├── QUARANTINE\               ← 隔离区（异常文件）
│   ├── NOT_PDF\
│   ├── CORRUPTED\
│   └── OVERSIZE\
└── MANUAL\                   ← 手工补采暂存
```

**归档命名规则：**

```
{sha256 前 8 位}_{原文件名}
例：a1b2c3d4_检验报告_20261022.pdf
```

**为什么要加 SHA-256 前缀？**

防止同名覆盖。技师可能每天都导出"检验报告.pdf"，同一天有两份同名文件进入同一目录会互相覆盖。加指纹前缀后，完全不同内容的文件必然有不同前缀。

若两份文件内容完全相同（SHA-256 相同），则它们是重复文件，第二份不会归档（`DUPLICATE` 状态）。

**为什么按文件 mtime 分组日期而不是按归档时间？**

技师可能隔天才导出：
- 10 月 21 日做的检验
- 10 月 22 日才导出 PDF

如果按归档时间（10-22）分组，找"10-21 的报告"要去 10-22 目录。按文件 mtime（10-21）分组才符合人的直觉。

**归档延迟 5 分钟的原因：**

技师导出后可能发现导错了，重新导一份。若立即归档，第一份已经在 ARCHIVE 无法删除（但我们允许手工删除 QUARANTINE）。

延迟 5 分钟给技师一个"后悔窗口"。5 分钟后自动归档，避免 INBOX 积压。

### 3.5 巡检模型

**为什么要巡检？**

S3 方案（PDF 留在共享文件夹，库中只存路径）的固有风险：

| 风险 | 概率 | 后果 |
|---|---|---|
| 共享盘故障 | 低 | **历史报告全丢** |
| 运维误删目录 | 低 | 同上 |
| 文件被手工移动 | 中 | 部分丢失 |
| 权限变更 | 中 | 文件不可读 |
| 磁盘静默损坏 | 极低 | 单文件损坏 |

**三层兜底：**

1. **入库即计算 SHA-256 并存库** → 即使文件丢了，指纹还在，可证明"这份文件曾经存在且内容是什么"
2. **归档只移不删** → 归档是 `shutil.move`，失败时原文件仍在 INBOX，不会丢
3. **每日巡检抽样校验 SHA-256** → 发现丢失立即告警

**为什么抽样而不是全量？**

| 方案 | 文件数 | 数据量 | 耗时 | 磁盘压力 |
|---|---|---|---|---|
| 全量校验 | 12 万份 | 1.5 TB | 约 2 小时 | 高（压共享盘） |
| 抽样 320 份 | 320 份 | 约 4 GB | 约 20 秒 | 低 |

统计意义：若真实丢失率 1%，抽样 320 份至少发现 1 份的概率 = 1 - 0.99^320 ≈ **96%**。

**抽样比例：**

| 时间段 | 抽样比例 | 说明 |
|---|---|---|
| 近 30 天 | 20% | 新文件，最关键 |
| 30~180 天 | 10% | 中等 |
| 180 天以上 | 2% | 老文件，风险已稳定 |
| 每日最少 | 200 份 | 保底 |

**巡检流程：**

```
每日 02:00 触发
  ↓
按抽样比例随机选取文件
  ↓
逐个：
  ├─ 检查文件是否存在 → 不存在 = MISSING
  ├─ 计算 SHA-256 → 与库中比对
  │   ├─ 相同 = OK
  │   └─ 不同 = CORRUPTED
  ↓
生成巡检报告（m13_inspection + m13_inspection_detail）
  ↓
丢失率 > 0.1% → 严重告警
  ↓
巡检明细交人工处理（确认/标记已恢复/标记永久丢失）
```

### 3.6 隔离区模型

**隔离触发条件：**

| 原因 | 判定 | 目标目录 |
|---|---|---|
| `NOT_PDF` | 前 5 字节不是 `%PDF-` | `QUARANTINE/NOT_PDF/` |
| `CORRUPTED` | PDF 结构损坏（`pypdf` 抛异常） | `QUARANTINE/CORRUPTED/` |
| `TOO_LARGE` | 大小 > `MAX_SIZE_MB` | `QUARANTINE/OVERSIZE/` |
| `TOO_SMALL` | 大小 < `MIN_SIZE_KB` | `QUARANTINE/NOT_PDF/` |
| `ENCRYPTED` | 需要密码 | 不隔离，标记 `need_password` |

**为什么隔离而不删除？**

因为可能是人工失误（把照片存成 .pdf 后缀），删了无法恢复。隔离后保留证据，运维可以人工检查后决定删除。

**隔离区清理：**

- 30 天前隔离的文件由运维手工评估
- 系统不自动删除隔离区文件（需人工确认）

### 3.7 手工补采模型

**触发场景：**

| 场景 | 说明 |
|---|---|
| 设备故障 | 仪器无法导出，技师手工打印后扫描 |
| 网络故障 | 共享盘短时不可用，文件存在本地 |
| 历史补录 | 系统上线前的历史报告需要导入 |
| 系统故障 | watchdog 长时间失效，文件堆积 |

**补采流程：**

```
管理员上传文件（P06 手工补采）
  ↓
文件存入 MANUAL/ 目录
  ↓
走与自动采集相同的登记流程（SHA-256、去重、派发解析）
  ↓
source = 'MANUAL_UPLOAD'
  ↓
必须填写补采原因（≥10 字）
```

**为什么手工补采要单独记录 source？**

因为"手工补采率高"是一个重要的运维信号：
- 若手工补采占比 > 1%，说明自动采集有问题
- 若某一天手工补采突然激增，说明当天共享盘可能挂了

### 3.8 业务流程图

```
【自动采集全流程】

技师在仪器工作站导出 PDF
    │
    │ 保存到 \\fileserver\lab-reports\INBOX\
    ▼
watchdog 监听到文件创建事件
    │ 防抖 5 秒（避免一次保存触发多个事件）
    ▼
Celery 任务 collect_file_task
    │
    ├─ ① 稳定性判定
    │    ├─ 大小两次采样一致
    │    ├─ 可独占打开
    │    ├─ PDF 魔数校验
    │    └─ 文件年龄 > 5 秒
    │    不通过 → 重试计数 +1，5 秒后再试
    │
    ├─ ② SHA-256 计算
    │
    ├─ ③ 去重比对
    │    └─ 重复 → 标 DUPLICATE，不派发，结束
    │
    ├─ ④ 登记文件
    │    ├─ 生成 file_no (WF + YYYYMMDD + 6 位)
    │    ├─ 解析 PDF 基本信息（页数、是否加密、是否扫描件）
    │    └─ status = COLLECTED
    │
    ├─ ⑤ 派发解析
    │    └─ POST /internal/v1/m13/parse/on-file-collected
    │
    └─ ⑥ 调度归档（延迟 5 分钟）
         └─ archive_file_task
              └─ 移入 ARCHIVE/yyyy/MM/dd/{sha8}_{原名}

【失败分支】

稳定性判定 20 次失败
    └─ 记 m13_collect_failure(reason=UNSTABLE)
       └─ 30 分钟后重新扫描

非 PDF / 损坏 / 超大
    └─ 移入 QUARANTINE/
       └─ 标记 status = QUARANTINE
       └─ 通知运维

加密 PDF
    └─ 标记 need_password = TRUE
       └─ 通知管理员提供密码
       └─ P03 待确认队列显示

【定时全量扫描】

每 5 分钟
    └─ 遍历 INBOX 全部文件
       └─ 排除已登记（by path 或 by sha256）
       └─ 对未登记的走采集流程
```

**为什么需要定时全量扫描与 watchdog 双保险？**

watchdog 的 inotify 已知不可靠场景：

| 场景 | 说明 |
|---|---|
| 服务重启期间 | 停机时的文件变更收不到事件 |
| SMB/NFS 网络盘 | inotify 对网络文件系统支持有限 |
| 内核事件队列溢出 | `max_user_watches` 超限时事件丢失 |
| 归档目录被手工挪动 | 不会触发新事件 |

定时全量扫描是"兜底"：每 5 分钟扫一遍，靠 SHA-256 去重防止重复登记。

**全量扫描 1 万文件耗时约 30 秒**（只做 stat + 比对已有路径，不做 SHA-256）。这个开销可以接受。

**为什么密码要单独管理而不存在文件名里？**

`m13_report_file.pdf_password_enc` 用 AES-256-GCM 加密存储，密钥在 KMS/环境变量。

统一为经验值 3 秒 + 年龄 5 秒是默认值，允许调整以适应现场。

```
│ │ 重复导出      ████████████ 12                                    │    │
│ │ 非 PDF        ███ 3                                              │    │
│ │ 加密未提供密码 ██ 2                                               │    │
│ │ 文件损坏      █ 1                                                │    │
│ └───────────────────────────────────────────────────────────────────┘    │
│                                                                          │
│ ┌──── 按设备统计 ───────────────────────────────────────────────────┐    │
│ │ 设备              应采集   已采集   采集率   平均延迟  异常数      │    │
│ │ BS-800 生化仪      440      440     100%     8 秒      2          │    │
│ │ XN-1000 血球仪     352      351     99.7%    10 秒     1          │    │
│ │ Cobas e411 免疫    264      263     99.6%    14 秒     2          │    │
│ └───────────────────────────────────────────────────────────────────┘    │
└──────────────────────────────────────────────────────────────────────────┘
```

**字段说明：**

| 指标 | 计算方式 |
|---|---|
| 应有报告 | M13-01 中当日 `status='REPORTED'` 的任务所属报告数（或按设备应出报告数估算） |
| 已采集 | 当日登记的非重复文件数 |
| 采集率 | 已采集 / 应有报告 |
| 重复 | 当日 `is_duplicate=TRUE` 的文件数 |
| 采集延迟 P95 | 登记时刻 - 文件 mtime 的 95 分位 |
| 异常分布 | 按 `m13_collect_failure.fail_reason` 与 `status='QUARANTINE'` 分组 |

**交互说明：**

| 操作 | 触发 | 结果 |
|---|---|---|
| 查询 | 按钮 | 按条件过滤 |
| 导出 | 按钮 | 导出 Excel |
| 点击趋势图 | 折线 | 显示该日明细 |

**校验规则：**

| 编号 | 规则 | 错误码 |
|---|---|---|
| V-28 | 日期跨度 ≤ 366 天 | `"1302016"` |
| V-29 | 导出行数 ≤ 50,000 | `"1302019"` |

**为什么"应有报告"要用 M13-01 的已签收任务数？**

因为采集层不知道"设备出了多少份报告"。唯一可靠的来源是"多少检验任务应该出结果"。

严格说这两个数不完全相等（一份报告可能含多个任务），但用来算"采集率"足够准确：若 100 个任务应该出 1 份报告，系统会采集到 1 份文件，采集率 1/1 = 100%。

若某天采集率突然下降，说明"有任务签收了但文件没进来"，直接指向采集问题。

### 6.2 错误码规范

| 错误码 | 说明 | 触发场景 |
|---|---|---|
| `"1302001"` | 共享文件夹不可访问 | 目录不存在/无权限/未挂载 |
| `"1302002"` | 磁盘空间不足 | 使用率 > 95% |
| `"1302003"` | 文件已丢失 | 归档后巡检发现文件不存在 |
| `"1302004"` | 文件状态不允许此操作 | 状态机非法转移 |
| `"1302005"` | 文件状态不允许重新解析 | 非 PARSED/PARSE_FAILED |
| `"1302006"` | 文件已被其他任务占用 | 同一路径并发采集 |
| `"1302007"` | 恢复隔离文件需填写原因 | 原因为空或 <10 字 |
| `"1302008"` | 文件不是有效 PDF | 前 5 字节非 `%PDF-` |
| `"1302009"` | 文件大小超出限制 | 超过 `MAX_SIZE_MB` |
| `"1302010"` | 上传文件数量超出限制 | 超过 20 个 |
| `"1302011"` | 文件正在写入暂不可采集 | 稳定性判定未通过（最终） |
| `"1302012"` | PDF 已加密需要密码 | `need_password=TRUE` 且未提供 |
| `"1302013"` | PDF 密码错误或已锁定 | 密码校验失败 |
| `"1302014"` | 说明内容不足 10 字 | 处理说明过短 |
| `"1302015"` | 文件名或路径含非法字符 | 含 `..` 或特殊字符 |
| `"1302016"` | 日期跨度超出限制 | 查询超过 366 天 |
| `"1302017"` | 巡检任务正在运行 | 已有 RUNNING 巡检 |
| `"1302018"` | 目录配置无效 | 测试连接失败 |
| `"1302019"` | 导出行数超出限制 | 超过 50,000 行 |
| `"1302020"` | 参数值超出允许范围 | 配置校验失败 |
| `"1302021"` | 归档失败文件仍保留在 INBOX | 移动异常 |
| `"1302022"` | 不支持的文件类型 | 非 .pdf 后缀 |
| `"1302023"` | 上传文件为空 | 0 字节 |
| `"1302024"` | 补采原因不足 10 字 | 补采原因过短 |
| `"1302025"` | 该文件已被标记为无主 | 恢复已标记无主的文件 |
| `"1302026"` | 采集服务未就绪 | watchdog 心跳超时 |
| `"1302027"` | 文件已存在（SHA-256 重复） | 手工上传时命中重复 |
| `"1302028"` | 单次处理数量超出限制 | 批量操作超限 |

```python
class CollectService:
    """文件采集服务。"""

    @classmethod
    async def is_file_stable(
        cls,
        path: str,
        sample_interval: int = 3,
        min_age_seconds: int = 5,
        min_size: int = 1024,
        max_size: int = 200 * 1024 * 1024,
    ) -> Tuple[bool, str]:
        """稳定性判定（四条件）。

        Returns:
            (is_stable, reason)
        """
        # ① 文件存在？
        try:
            st1 = os.stat(path)
        except OSError:
            return False, "BAD_PATH"

        # ② 文件年龄 > min_age_seconds
        age = time.time() - st1.st_mtime
        if age < min_age_seconds:
            return False, "UNSTABLE"

        # ③ 大小范围
        if st1.st_size < min_size:
            return False, "TOO_SMALL"
        if st1.st_size > max_size:
            return False, "TOO_LARGE"

        # ④ 可独占打开
        try:
            fh = open(path, "rb")
        except (PermissionError, OSError):
            return False, "LOCKED"

        try:
            # ⑤ PDF 魔数
            magic = fh.read(5)
            if magic != PDF_MAGIC:
                return False, "NOT_PDF"

            # ⑥ 两次采样大小一致
            size1 = st1.st_size
            await asyncio.sleep(sample_interval)
            size2 = os.stat(path).st_size
            if size1 != size2:
                return False, "UNSTABLE"
        finally:
            fh.close()

        return True, "OK"

    @classmethod
    def compute_sha256(cls, path: str) -> str:
        """流式计算 SHA-256。"""
        h = hashlib.sha256()
        with open(path, "rb") as fh:
            while True:
                chunk = fh.read(READ_CHUNK)
                if not chunk:
                    break
                h.update(chunk)
        return h.hexdigest()

    @classmethod
    async def probe_pdf(
        cls, path: str
    ) -> Dict[str, Any]:
        """探测 PDF 基本信息。"""
        info = {
            "page_count": 0,
            "is_encrypted": False,
            "is_scanned": False,
        }
        try:
            from pypdf import PdfReader
            reader = PdfReader(path)
            info["page_count"] = len(reader.pages)
            info["is_encrypted"] = reader.is_encrypted
            if not reader.is_encrypted and reader.pages:
                try:
                    first = reader.pages[0].extract_text() or ""
                    info["is_scanned"] = len(
                        first.strip()) < 20
                except Exception:
                    info["is_scanned"] = True
        except ImportError:
            logger.warning("pypdf 未安装，跳过 PDF 探测")
        except Exception as exc:
            logger.warning("PDF 探测失败 path=%s err=%s", path, exc)
        return info

    @classmethod
    async def register_file(
        cls, db: AsyncSession, body
    ) -> Dict[str, Any]:
        """登记文件（唯一入口）。

        自动扫描、watchdog、手工上传全部走这里。
        """
        # ① 参数校验
        path = body.file_path
        if not _SAFE_RE.match(body.original_name):
            raise BizException(
                "1302015", "文件名含非法字符")

        cfg = await CollectConfigService.get_all(db)
        max_size = int(cfg.get(
            "M13.COLLECT.MAX_SIZE_MB", "200")) * 1024 * 1024
        min_size = int(cfg.get(
            "M13.COLLECT.MIN_SIZE_KB", "1")) * 1024
        sample_interval = int(cfg.get(
            "M13.COLLECT.SAMPLE_INTERVAL", "3"))
        min_age = int(cfg.get(
            "M13.COLLECT.MIN_AGE_SECONDS", "5"))

        # ② 磁盘空间检查
        root = cfg.get("M13.COLLECT.ROOT_PATH", "")
        if root:
            usage = cls._disk_usage(root)
            if usage >= 0.95:
                raise BizException(
                    "1302002",
                    "磁盘使用率 %.1f%%，拒绝采集" % (usage * 100))

        # ③ 稳定性判定
        stable, reason = await cls.is_file_stable(
            path, sample_interval, min_age, min_size, max_size)
        if not stable:
            await cls._record_failure(
                db, path, body.original_name, reason)
            if reason in ("NOT_PDF", "TOO_LARGE", "TOO_SMALL"):
                quarantine_dir = cls._quarantine_dir(
                    cfg, reason)
                await cls.quarantine(
                    db, path, body.original_name, reason,
                    quarantine_dir)
            raise BizException(
                cls._reason_code(reason),
                cls._reason_text(reason))

        # ④ SHA-256
        sha256 = cls.compute_sha256(path)

        # ⑤ 去重
        existing = await db.scalar(
            select(M13ReportFile).where(
                M13ReportFile.sha256 == sha256,
                M13ReportFile.is_duplicate.is_(False),
                M13ReportFile.is_deleted.is_(False)))
        if existing is not None:
            now = datetime.now()
            rec = M13ReportFile(
                file_no=await cls._next_file_no(db, now),
                file_name=body.original_name,
                original_path=path,
                current_path=path,
                size_bytes=body.file_size,
                sha256=sha256,
                file_mtime=body.file_mtime,
                device_code=body.device_code,
                source=body.source,
                page_count=0,
                is_encrypted=False,
                need_password=False,
                is_scanned=False,
                status="DUPLICATE",
                archive_status=None,
                bind_status="UNCONFIRMED",
                parse_status=None,
                is_duplicate=True,
                duplicate_of_file_id=existing.id,
                collected_at=now,
                collected_by=None,
                verify_count=0,
            )
            db.add(rec)
            await db.commit()
            return {
                "file_id": rec.id,
                "file_no": rec.file_no,
                "status": "DUPLICATE",
                "is_duplicate": True,
                "duplicate_of_file_id": existing.id,
                "sha256": sha256,
                "size_bytes": body.file_size,
                "collected_at": now,
                "parse_dispatched": False,
            }

        # ⑥ 探测 PDF
        probe = await cls.probe_pdf(path)

        # ⑦ 登记
        now = datetime.now()
        need_password = bool(
            probe["is_encrypted"] and not body.allow_password)
        rec = M13ReportFile(
            file_no=await cls._next_file_no(db, now),
            file_name=body.original_name,
            original_path=path,
            current_path=path,
            size_bytes=body.file_size,
            sha256=sha256,
            file_mtime=body.file_mtime,
            device_code=body.device_code,
            source=body.source,
            page_count=probe["page_count"],
            is_encrypted=probe["is_encrypted"],
            need_password=need_password,
            is_scanned=probe["is_scanned"],
            status="COLLECTED",
            archive_status="PENDING",
            bind_status="UNCONFIRMED",
            parse_status="PENDING_DISPATCH",
            is_duplicate=False,
            duplicate_of_file_id=None,
            collected_at=now,
            collected_by=body.operator_id,
            collected_seconds=cls._delay_seconds(
                body.file_mtime, now),
            verify_count=0,
        )
        db.add(rec)
        await db.commit()

        # ⑧ 调度归档（延迟 5 分钟）
        archive_delay = int(cfg.get(
            "M13.COLLECT.ARCHIVE_DELAY_MINUTES", "5"))
        archive_file_task.apply_async(
            args=[rec.id], countdown=archive_delay * 60)

        # ⑨ 派发解析
        dispatched = False
        if not need_password:
            dispatched = await cls._dispatch_parse(rec.id, sha256)

        return {
            "file_id": rec.id,
            "file_no": rec.file_no,
            "status": "COLLECTED",
            "is_duplicate": False,
            "sha256": sha256,
            "size_bytes": body.file_size,
            "page_count": probe["page_count"],
            "is_encrypted": probe["is_encrypted"],
            "need_password": need_password,
            "is_scanned": probe["is_scanned"],
            "collected_at": now,
            "parse_dispatched": dispatched,
            "parse_id": None,
        }

    @classmethod

    @classmethod
    async def _record_failure(
        cls, db: AsyncSession, path: str,
        file_name: str, reason: str,
    ) -> None:
        """记录采集失败。"""
        now = datetime.now()
        exist = await db.scalar(
            select(M13CollectFailure).where(
                M13CollectFailure.path == path,
                M13CollectFailure.status == "PENDING",

            exist.retry_count += 1
            exist.last_retry_at = now
            exist.fail_reason = reason

                "UNSTABLE", "LOCKED", "SHARE_UNAVAILABLE")),

    @classmethod
    async def quarantine(
        cls, db: AsyncSession, path: str, file_name: str,
        reason: str, target_dir: str,
    ) -> Optional[str]:
        """移入隔离区。"""
        try:
            os.makedirs(target_dir, exist_ok=True)
            target = safe_join(target_dir, file_name)
            if os.path.exists(target):
                base, ext = os.path.splitext(file_name)
                target = safe_join(
                    target_dir,
                    "%s_%s%s" % (
                        base, datetime.now().strftime("%H%M%S"),
                        ext))
            shutil.move(path, target)
            logger.warning(
                "文件已隔离 name=%s reason=%s target=%s",
                file_name, reason, target)
            return target
        except OSError as exc:
            logger.error(
                "隔离失败 name=%s err=%s", file_name, exc)
            return None

    @classmethod
    async def archive_file(
        cls, file_id: int
    ) -> Dict[str, Any]:
        """归档文件（移入 ARCHIVE/yyyy/MM/dd/）。"""
        from app.core.db import AsyncSessionLocal

        async with AsyncSessionLocal() as db:
            rec = await db.scalar(
                select(M13ReportFile).where(
                    M13ReportFile.id == file_id,
                    M13ReportFile.is_deleted.is_(False),
                ).with_for_update())
            if rec is None:
                return {"success": False, "reason": "NOT_FOUND"}
            if rec.status in ("DUPLICATE", "QUARANTINE"):
                return {"success": True, "skipped": True}
            if rec.archive_status == "ARCHIVED":
                return {"success": True, "already": True}

            cfg = await CollectConfigService.get_all(db)
            root = cfg.get("M13.COLLECT.ROOT_PATH", "")
            arc = cfg.get("M13.COLLECT.ARCHIVE_DIR", "ARCHIVE")

            # 按文件 mtime 分组
            group_by = cfg.get(
                "M13.COLLECT.ARCHIVE_GROUP_BY", "FILE_MTIME")
            base_dt = rec.file_mtime if (
                group_by == "FILE_MTIME"
                and rec.file_mtime is not None
            ) else rec.collected_at
            sub = os.path.join(
                arc,
                base_dt.strftime("%Y"),
                base_dt.strftime("%m"),
                base_dt.strftime("%d"))
            target_dir = safe_join(root, *sub.split("/"))

            src = rec.current_path or rec.original_path
            if not os.path.exists(src):
                rec.archive_status = "FAILED"
                rec.archive_error = "源文件不存在"
                rec.archive_retry += 1
                await db.commit()
                return {"success": False, "reason": "SRC_MISSING"}

            new_name = "%s_%s" % (rec.sha256[:8], rec.file_name)
            try:
                os.makedirs(target_dir, exist_ok=True)
                target = safe_join(target_dir, new_name)
                if os.path.exists(target):
                    base, ext = os.path.splitext(new_name)
                    target = safe_join(
                        target_dir,
                        "%s_%s%s" % (
                            base,
                            datetime.now().strftime("%H%M%S"),
                            ext))
                shutil.move(src, target)
            except OSError as exc:
                rec.archive_status = "FAILED"
                rec.archive_error = str(exc)[:500]
                rec.archive_retry += 1
                await db.commit()
                logger.error(
                    "归档失败 file_id=%s err=%s", file_id, exc)
                return {"success": False, "reason": "MOVE_FAILED"}

            rec.archive_status = "ARCHIVED"
            rec.current_path = target
            rec.archived_at = datetime.now()
            rec.archive_error = None
            await db.commit()
            return {
                "success": True,
                "file_no": rec.file_no,
                "archived_path": target,
            }

            raise BizException("1302013", "PDF 密码错误")

        # 存储加密后的密码
        from app.core.crypto import encrypt_secret
        rec.pdf_password_enc = encrypt_secret(body.password)
        rec.need_password = False
        rec.password_fail_count = 0
        rec.parse_status = "PENDING_DISPATCH"
        await db.commit()

        # 派发解析
        dispatched = await cls._dispatch_parse(rec.id, rec.sha256)
        return {
            "file_no": rec.file_no,
            "password_verified": True,
            "need_password": False,
            "parse_dispatched": dispatched,
            "parse_id": None,
        }

    @classmethod
    async def _verify_pdf_password(
        cls, path: str, password: str
    ) -> bool:
        """校验 PDF 密码。"""
        try:
            from pypdf import PdfReader
            reader = PdfReader(path)
            if not reader.is_encrypted:
                return True
            return bool(reader.decrypt(password))
        except Exception as exc:
            logger.warning("密码校验异常 err=%s", exc)
            return False

    @classmethod
    async def upload(
        cls, db, user, files, reason: str
    ) -> Dict[str, Any]:
        """手工补采上传。"""
        cfg = await CollectConfigService.get_all(db)
        max_count = int(cfg.get(
            "M13.COLLECT.MAX_UPLOAD_COUNT", "20"))
        max_mb = int(cfg.get(
            "M13.COLLECT.MAX_SIZE_MB", "200"))
        if len(files) > max_count:
            raise BizException(
                "1302010",
                "单次最多上传 %d 个文件" % max_count)
        if len((reason or "").strip()) < 10:
            raise BizException(
                "1302024", "补采原因不少于 10 字")

        root = cfg.get("M13.COLLECT.ROOT_PATH", "")
        manual = cfg.get("M13.COLLECT.MANUAL_DIR", "MANUAL")
        mdir = safe_join(root, manual)
        usage = cls._disk_usage(root) if root else 0
        if usage >= 0.95:
            raise BizException("1302002", "磁盘空间不足")

        results: List[Dict[str, Any]] = []
        for up in files:
            name = os.path.basename(up.filename or "upload.pdf")
            if not _SAFE_RE.match(name):
                results.append({
                    "file_name": name, "success": False,
                    "code": "1302015",
                    "message": "文件名含非法字符"})
                continue
            if not name.lower().endswith(".pdf"):
                results.append({
                    "file_name": name, "success": False,
                    "code": "1302022",
                    "message": "不支持的文件类型"})
                continue
            data = await up.read()
            if not data:
                results.append({
                    "file_name": name, "success": False,
                    "code": "1302023",
                    "message": "文件为空"})
                continue
            if len(data) > max_mb * 1024 * 1024:
                results.append({
                    "file_name": name, "success": False,
                    "code": "1302009",
                    "message": "文件超出 %d MB" % max_mb})
                continue

            os.makedirs(mdir, exist_ok=True)
            tmp = safe_join(
                mdir,
                "%s_%s" % (
                    datetime.now().strftime("%H%M%S%f"), name))
            try:
                with open(tmp, "wb") as fh:
                    fh.write(data)
            except OSError as exc:
                results.append({
                    "file_name": name, "success": False,
                    "code": "1302001",
                    "message": str(exc)[:100]})
                continue

            # 走统一登记入口
            from app.schemas.m13.collect import InternalRegisterIn
            body = InternalRegisterIn(
                file_path=tmp,
                original_name=name,
                source="MANUAL_UPLOAD",
                device_code=None,
                file_mtime=datetime.fromtimestamp(
                    os.stat(tmp).st_mtime),
                file_size=len(data),
                allow_password=False,
                operator_id=user.employee_id,
            )
            try:
                r = await cls.register_file(db, body)
                results.append({
                    "file_name": name, "success": True,
                    "file_no": r["file_no"],
                    "file_id": r["file_id"],
                    "status": r["status"],
                    "is_duplicate": r["is_duplicate"],
                })
            except BizException as exc:
                if exc.code == "1302027":
                    results.append({
                        "file_name": name, "success": False,
                        "code": exc.code,
                        "message": "该文件已存在（SHA-256 重复）"})
                else:
                    results.append({
                        "file_name": name, "success": False,
                        "code": exc.code,
                        "message": exc.message})

        await AuditClient.record(
            module="M13-02", action="MANUAL_UPLOAD",
            biz_id=0,
            extra={"count": len(files), "reason": reason,
                   "operator": user.employee_id})
        return {
            "total": len(files),
            "success_count": len(
                [r for r in results if r["success"]]),
            "failed_count": len(
                [r for r in results if not r["success"]]),
            "items": results,
        }

            select(func.count(M13ReportFile.id)).where(
                *base, M13ReportFile.archive_status == "FAILED"))
        return {
            "need_password": pwd or 0,
            "quarantine": qua or 0,
            "parse_failed": pf or 0,
            "archive_failed": arc or 0,
            "total": (pwd or 0) + (qua or 0) + (pf or 0) + (arc or 0),
        }

    @classmethod
    async def full_scan(
        cls, db, body
    ) -> Dict[str, Any]:
        """全量扫描 INBOX。"""
        cfg = await CollectConfigService.get_all(db)
        root = cfg.get("M13.COLLECT.ROOT_PATH", "")
        inbox = cfg.get("M13.COLLECT.INBOX_DIR", "INBOX")
        recursive = cfg.get(
            "M13.COLLECT.RECURSIVE", "true") == "true"
        base = safe_join(root, inbox)
        if not os.path.isdir(base):
            raise BizException(
                "1302001", "共享文件夹不可访问")

        scanned = 0
        registered = 0
        skipped = 0
        errors = 0
        walker = os.walk(base) if recursive else [
            (base, [], [f for f in os.listdir(base)
                        if os.path.isfile(os.path.join(base, f))])]
        for dirpath, _dirs, files in walker:
            for name in files:
                scanned += 1
                if not name.lower().endswith(".pdf"):
                    continue
                path = os.path.join(dirpath, name)
                # 已登记（by original_path）跳过
                exist = await db.scalar(
                    select(M13ReportFile.id).where(
                        or_(
                            M13ReportFile.original_path == path,
                            M13ReportFile.current_path == path),
                        M13ReportFile.is_deleted.is_(False)))
                if exist:
                    skipped += 1
                    continue
                try:
                    st = os.stat(path)
                    from app.schemas.m13.collect import (
                        InternalRegisterIn,
                    )
                    reg = InternalRegisterIn(
                        file_path=path,
                        original_name=name,
                        source="WATCHDOG",
                        device_code=None,
                        file_mtime=datetime.fromtimestamp(
                            st.st_mtime),
                        file_size=st.st_size,
                        allow_password=False,
                        operator_id=None,
                    )
                    await cls.register_file(db, reg)
                    registered += 1
                except BizException as exc:
                    errors += 1
                    logger.warning(
                        "扫描登记失败 path=%s code=%s", path,
                        exc.code)
                except OSError:
                    errors += 1
        return {
            "scanned": scanned,
            "registered": registered,
            "skipped": skipped,
            "errors": errors,
        }


class InspectionService:
    """巡检服务。"""

    @classmethod
    async def run(
        cls, db, user, body
    ) -> Dict[str, Any]:
        """执行巡检。"""
        running = await db.scalar(
            select(func.count(M13Inspection.id)).where(
                M13Inspection.status == "RUNNING"))
        if running and not body.force:
            raise BizException(
                "1302017", "巡检任务正在运行")

        cfg = await CollectConfigService.get_all(db)
        ratio_recent = float(cfg.get(
            "M13.COLLECT.INSPECT_RATIO_RECENT", "0.20"))
        ratio_mid = float(cfg.get(
            "M13.COLLECT.INSPECT_RATIO_MID", "0.10"))
        ratio_old = float(cfg.get(
            "M13.COLLECT.INSPECT_RATIO_OLD", "0.02"))
        min_sample = int(cfg.get(
            "M13.COLLECT.INSPECT_MIN_SAMPLE", "200"))

        now = datetime.now()
        sample_size = body.sample_size or min_sample
        insp = M13Inspection(
            inspection_no=await cls._next_no(db, now),
            inspection_date=now.date(),
            sample_total=sample_size,
            sample_ok=0,
            sample_missing=0,
            sample_corrupted=0,
            missing_rate=Decimal("0"),
            started_at=now,
            triggered_by="MANUAL" if user else "SCHEDULE",
            status="RUNNING",
        )
        db.add(insp)
        await db.commit()

        # 抽样三档
        recent_from = now - timedelta(days=30)
        mid_from = now - timedelta(days=180)
        samples = await cls._sample(
            db, sample_size, ratio_recent, ratio_mid, ratio_old,
            recent_from, mid_from)

        ok = 0
        missing = 0
        corrupted = 0
        for s in samples:
            path = s.current_path or s.original_path
            if not path or not os.path.exists(path):
                result = "MISSING"
                missing += 1
            else:
                try:
                    actual = CollectService.compute_sha256(path)
                except OSError:
                    result = "CORRUPTED"
                    corrupted += 1
                    actual = None
                else:
                    if actual == s.sha256:
                        result = "OK"
                        ok += 1
                    else:
                        result = "CORRUPTED"
                        corrupted += 1
            if result != "OK":
                bucket = (
                    "RECENT" if s.collected_at >= recent_from
                    else ("MID" if s.collected_at >= mid_from
                          else "OLD"))
                db.add(M13InspectionDetail(
                    inspection_id=insp.id,
                    file_id=s.id,
                    file_no=s.file_no,
                    file_name=s.file_name,
                    file_path=path,
                    expect_sha256=s.sha256,
                    actual_sha256=(
                        actual if result == "CORRUPTED" else None),
                    bucket=bucket,
                    result=result,
                    is_resolved=False,
                    created_at=now,
                ))
            # 更新校验时间
            await db.execute(
                update(M13ReportFile).where(
                    M13ReportFile.id == s.id,
                ).values(
                    last_verify_at=now,
                    verify_count=M13ReportFile.verify_count + 1,
                    is_missing=(result == "MISSING"),
                    missing_found_at=(
                        now if result == "MISSING" else None),
                ))

        insp.sample_ok = ok
        insp.sample_missing = missing
        insp.sample_corrupted = corrupted
        insp.missing_rate = (
            Decimal(missing) / Decimal(sample_size)
            if sample_size else Decimal("0"))
        insp.finished_at = datetime.now()
        insp.duration_seconds = int(
            (insp.finished_at - insp.started_at).total_seconds())
        insp.status = "FINISHED"
        await db.commit()

        # 丢失率告警
        alert_threshold = float(cfg.get(
            "M13.COLLECT.MISSING_RATE_ALERT", "0.001"))
        if insp.missing_rate > Decimal(str(alert_threshold)):
            await cls._alert_missing(insp)

        return {
            "inspection_id": insp.id,
            "inspection_no": insp.inspection_no,
            "status": insp.status,
            "sample_total": sample_size,
            "started_at": insp.started_at,
        }

    @classmethod
    async def _sample(
        cls, db, size, r_recent, r_mid, r_old,
        recent_from, mid_from,
    ) -> List[M13ReportFile]:
        """三档分层抽样。"""
        out: List[M13ReportFile] = []
        n_recent = int(size * r_recent)
        n_mid = int(size * r_mid)
        n_old = max(0, size - n_recent - n_mid)

        base_cond = [
            M13ReportFile.is_deleted.is_(False),
            M13ReportFile.status.in_(
                ["PARSED", "PARSING", "COLLECTED"]),
            M13ReportFile.archive_status == "ARCHIVED",
        ]
        for cond, n in (
            (M13ReportFile.collected_at >= recent_from, n_recent),
            (and_(
                M13ReportFile.collected_at >= mid_from,
                M13ReportFile.collected_at < recent_from), n_mid),
            (M13ReportFile.collected_at < mid_from, n_old),
        ):
            if n <= 0:
                continue
            rows = (await db.execute(
                select(M13ReportFile).where(
                    *base_cond, cond
                ).order_by(func.random()).limit(n))).scalars().all()
            out.extend(rows)
        return out

    @classmethod
    async def _next_no(
        cls, db, now: datetime
    ) -> str:
        """巡检编号 IJ + YYYYMMDD + 3 位。"""
        prefix = "IJ" + now.strftime("%Y%m%d")
        cnt = await db.scalar(
            select(func.count(M13Inspection.id)).where(
                M13Inspection.inspection_no.like(prefix + "%")))
        return "%s%03d" % (prefix, (cnt or 0) + 1)

    @classmethod
    async def _alert_missing(
        cls, insp: M13Inspection
    ) -> None:
        """丢失率告警。"""
        try:
            await MessageClient.send(
                target="ROLE:IT_ADMIN",
                title="原件丢失率告警：%.2f%%" % (
                    float(insp.missing_rate) * 100),
                content="巡检 %s 发现 %d 份文件丢失，"
                        "丢失率超过阈值，请立即排查"
                        % (insp.inspection_no,
                           insp.sample_missing),
                biz_type="M13_FILE_MISSING",
                biz_id=insp.id)
        except Exception as exc:
            logger.error("丢失告警发送失败 err=%s", exc)

                M13InspectionDetail.id == detail_id,
                M13InspectionDetail.inspection_id
                == inspection_id,
            ).with_for_update())

            raise BizException("1302004", "巡检明细不存在")
        if detail.is_resolved:
            raise BizException(
                "1302005", "该明细已处理")
        if len((body.remark or "").strip()) < 10:
            raise BizException(
                "1302014", "处理说明不少于 10 字")

        detail.is_resolved = True
        detail.resolved_at = datetime.now()
        detail.resolved_by = user.employee_id
        detail.resolve_action = body.action
        detail.resolve_remark = body.remark

        # 已恢复时清掉缺失标记
        if body.action == "RECOVERED":
            await db.execute(
                update(M13ReportFile).where(
                    M13ReportFile.id == detail.file_id,
                ).values(is_missing=False))
        await db.commit()
        return {
            "detail_id": detail_id,
            "result": detail.result,
            "is_resolved": True,
            "resolve_action": body.action,
        }

class CollectStatService:

        end = start + timedelta(days=1)

        collected = await db.scalar(
            select(func.count(M13ReportFile.id)).where(

                M13ReportFile.collected_at < end,

        pwd = await db.scalar(
            select(func.count(M13ReportFile.id)).where(
                M13ReportFile.need_password.is_(True),
                M13ReportFile.is_deleted.is_(False)))
        qua = await db.scalar(
            select(func.count(M13ReportFile.id)).where(
                M13ReportFile.status == "QUARANTINE"))
        avg_delay = await db.scalar(
            select(func.avg(M13ReportFile.collected_seconds))
            .where(
                M13ReportFile.collected_at >= start,
                M13ReportFile.collected_at < end))

        cfg = await CollectConfigService.get_all(db)
        root = cfg.get("M13.COLLECT.ROOT_PATH", "")
        disk = CollectService._disk_usage(root) if root else 0.0
        share_ok = bool(root and os.path.isdir(root))

        trend_rows = (await db.execute(
            select(
                func.date_trunc(
                    "hour", M13ReportFile.collected_at).label("h"),
                func.count(M13ReportFile.id))
            .where(
                M13ReportFile.collected_at >= start,
                M13ReportFile.collected_at < end,
                M13ReportFile.is_deleted.is_(False))
            .group_by(text("h")).order_by(text("h"))
        )).all()

        alerts: List[Dict[str, Any]] = []
        if qua:
            alerts.append({
                "level": "CRITICAL", "type": "QUARANTINE",
                "message": "%d 个文件已隔离" % qua,
                "count": qua})
        if pwd:
            alerts.append({
                "level": "WARNING", "type": "PASSWORD",
                "message": "%d 个文件待提供密码" % pwd,
                "count": pwd})
        if not share_ok:
            alerts.insert(0, {
                "level": "CRITICAL", "type": "SHARE_DOWN",
                "message": "共享文件夹不可访问",
                "count": 0})
        if disk >= 0.85:
            alerts.append({
                "level": "CRITICAL" if disk >= 0.95
                         else "WARNING",
                "type": "DISK", "count": 1,
                "message": "磁盘使用 %.1f%%" % (disk * 100)})

        return {

                for h, c in trend_rows],
        }

    @classmethod
    async def statistics(
        cls, db, start_date, end_date, device_code
    ) -> Dict[str, Any]:
        """采集统计。"""
        if (end_date - start_date).days > 366:
            raise BizException(
                "1302016", "查询日期跨度不得超过 366 天")
        start = datetime.combine(
            start_date, datetime.min.time())
        end = datetime.combine(
            end_date, datetime.min.time()) + timedelta(days=1)
        base = [
            M13ReportFile.collected_at >= start,
            M13ReportFile.collected_at < end,
            M13ReportFile.is_deleted.is_(False),
        ]
        if device_code:
            base.append(M13ReportFile.device_code == device_code)

        total = await db.scalar(
            select(func.count(M13ReportFile.id)).where(*base))
        dup = await db.scalar(
            select(func.count(M13ReportFile.id)).where(
                *base, M13ReportFile.is_duplicate.is_(True)))
        qua = await db.scalar(
            select(func.count(M13ReportFile.id)).where(
                *base, M13ReportFile.status == "QUARANTINE"))
        pf = await db.scalar(
            select(func.count(M13ReportFile.id)).where(
                *base, M13ReportFile.status == "PARSE_FAILED"))
        pwd = await db.scalar(
            select(func.count(M13ReportFile.id)).where(
                *base, M13ReportFile.need_password.is_(True)))
        avg_d = await db.scalar(
            select(func.avg(M13ReportFile.collected_seconds))
            .where(*base))

        # 应有报告数：从 M13-01 任务表取
        from app.models.m13.lab import M13LabTask
        expected = await db.scalar(
            select(func.count(M13LabTask.id)).where(
                M13LabTask.status == "REPORTED",
                M13LabTask.reported_at >= start,
                M13LabTask.reported_at < end))
        expected_n = expected or 0
        collected_n = (total or 0) - (dup or 0)

        dev_rows = (await db.execute(
            select(M13ReportFile.device_code,
                   func.count(M13ReportFile.id))
            .where(*base, M13ReportFile.device_code.isnot(None))
            .group_by(M13ReportFile.device_code))).all()

        return {
            "start_date": start_date.isoformat(),
            "end_date": end_date.isoformat(),
            "expected_reports": expected_n,
            "collected": collected_n,
            "collect_rate": (
                round(collected_n / expected_n, 4)
                if expected_n else 0),
            "duplicate_count": dup or 0,
            "quarantine_count": qua or 0,
            "parse_failed_count": pf or 0,
            "need_password_count": pwd or 0,
            "avg_delay_seconds": round(float(avg_d or 0), 1),
            "p95_delay_seconds": await cls._p95_delay(db, base),
            "abnormal_breakdown": [
                {"type": "DUPLICATE", "label": "重复导出",
                 "count": dup or 0},
                {"type": "QUARANTINE", "label": "隔离",
                 "count": qua or 0},
                {"type": "PARSE_FAILED", "label": "解析失败",
                 "count": pf or 0},
                {"type": "NEED_PASSWORD", "label": "待密码",
                 "count": pwd or 0},
            ],
            "by_device": [
                {"device_code": dc, "device_name": dc,
                 "expected": 0, "collected": c,
                 "rate": 0, "avg_delay": 0, "abnormal": 0}
                for dc, c in dev_rows],
        }

    @classmethod
    async def _p95_delay(
        cls, db, base
    ) -> int:
        """采集延迟 95 分位。"""
        rows = (await db.execute(
            select(M13ReportFile.collected_seconds)
            .where(*base, M13ReportFile.collected_seconds.isnot(None))
            .order_by(M13ReportFile.collected_seconds))).scalars().all()
        if not rows:
            return 0
        idx = int(len(rows) * 0.95)
        idx = min(idx, len(rows) - 1)
        return int(rows[idx])

    @classmethod
    async def daily_stat(
        cls, db, stat_date
    ) -> Dict[str, Any]:
        """内部：每日采集统计。"""
        d = stat_date or date.today()
        return await cls.statistics(db, d, d, None)

    @classmethod
    async def export(
        cls, db, user, body
    ) -> Dict[str, Any]:
        """导出。"""
        limit = int(await CollectConfigService.get_one(
            db, "M13.COLLECT.MAX_EXPORT_ROWS", "50000"))
        start = datetime.combine(
            body.start_date, datetime.min.time())
        end = datetime.combine(
            body.end_date, datetime.min.time()) + timedelta(days=1)
        rows = (await db.execute(
            select(M13ReportFile).where(
                M13ReportFile.collected_at >= start,
                M13ReportFile.collected_at < end,
                M13ReportFile.is_deleted.is_(False),
            ).order_by(M13ReportFile.collected_at)
            .limit(limit + 1))).scalars().all()
        if len(rows) > limit:
            raise BizException(
                "1302019",
                "导出数据超过 %d 行，请缩小日期范围" % limit)
        return {
            "row_count": len(rows),
            "items": [CollectService._dict(r) for r in rows],
        }

            row.updated_by = user.employee_id
```

### 6.7 专题：为什么文件采集必须做"稳定性判定"

**这是 M13-02 最容易出错的地方，也是最难排查的地方。**

**问题场景：**

技师在仪器工作站上点"导出 PDF"，仪器软件的执行过程是：

```
① 创建文件（大小 0 字节）
② 写入 PDF 头部（大小 1 KB）
③ 写入第一页内容（大小 80 KB）
④ 写入第二页内容（大小 245 KB）
⑤ 关闭文件
```

整个过程在 SSD 上约 200ms，在机械盘 + 网络共享上可能 2~5 秒。

**如果系统在 ② 或 ③ 时刻读到文件会怎样？**

- `pypdf` 抛异常（PDF 结构不完整）→ 判 `CORRUPTED` → 移入隔离区
- **但文件其实是完整的，只是还没写完**

真正的报告被误隔离，技师以为导出了，实际系统里没有。**这是最危险的失败模式：没有人知道报告丢了。**

**四条件防护对应四个失败模式：**

| 条件 | 防的是什么 |
|---|---|
| 大小两次采样一致 | 正在写入（第 ②③④ 步） |
| 可独占打开 | 仪器软件仍持有句柄（第 ⑤ 步之前） |
| PDF 魔数 | 文件是空但占位（第 ① 步） |
| 文件年龄 > 5 秒 | 刚创建还没写完 |

**为什么"可独占打开"是关键？**

Windows 文件系统有共享模式：
- 仪器软件以 `FILE_SHARE_READ | FILE_SHARE_WRITE` 打开文件时，其他进程可以同时打开
- 但**写入过程中持有写锁**，其他进程尝试 `open(path, 'rb')` 会得到 `PermissionError`（Errcode 32: 文件正在被另一个程序使用）

所以 `open(path, 'rb')` 成功 = 仪器软件已关闭文件 = 写入完成。

这在 Linux + SMB 网络盘上不完全可靠（SMB 的锁语义与本地文件不同），所以还需要"大小两次采样一致"作为补充。

**为什么两次采样间隔是 3 秒？**

实测数据（12MB PDF，千兆网络共享盘）：

| 采样间隔 | 误判为稳定（仍写入中）的概率 |
|---|---|
| 0.5 秒 | 18% |
| 1 秒 | 9% |
| 2 秒 | 3% |
| **3 秒** | **< 0.5%** |
| 5 秒 | < 0.2% |

3 秒是延迟与准确率的平衡点。若把间隔调到 5 秒，稳定判定耗时从 6 秒升到 10 秒，延迟 SLA（P95 ≤ 60 秒）会更容易超标。

**为什么重试上限是 20 次？**

20 次 × 3 秒 = 60 秒。若 60 秒后仍不稳定，说明这不是"正在写入"，而是：

- 文件被某个进程长期占用（仪器软件崩溃未释放句柄）
- 网络盘异常（读写超时）
- 权限问题

这些都需要人工介入，继续重试只是浪费资源。

**兜底：30 分钟后重新扫描**

失败记录保留在 `m13_collect_failure`（`can_auto_recover=TRUE`）。`job_m13_retry_failures` 每 30 分钟扫一次，对这些文件重新走采集流程。很多情况下"当时占用"是暂时的，30 分钟后就能采到。

**为什么不直接读文件内容做"完整性校验"？**

因为 PDF 完整性校验（`pypdf` 解析）本身很慢（12MB 需 100~300ms），在稳定性判定的高频路径上做会拖慢。而且 `pypdf` 对某些厂商生成的"非标准但可读"的 PDF 会误判损坏。

策略是：稳定性判定只看"文件是否写完"（物理事实），不判断"PDF 是否标准"（那是解析阶段的事）。

### 7.4 watchdog 监听服务设计

**独立进程部署：**

```python
"""M13-02 INBOX 监听服务（独立进程）。"""
import logging
import os
import time

from watchdog.events import FileSystemEventHandler
from watchdog.observers.polling import PollingObserver

from app.tasks.m13.collect import collect_file_task

logger = logging.getLogger("m13.collect.watcher")

DEBOUNCE_SECONDS = 5


class InboxHandler(FileSystemEventHandler):
    """INBOX 文件事件处理器。"""

    def __init__(self):
        super().__init__()
        self._seen = {}

    def _debounce(self, path: str) -> bool:
        """防抖：同一路径 5 秒内只处理一次。"""
        now = time.time()
        last = self._seen.get(path, 0)
        if now - last < DEBOUNCE_SECONDS:
            return False
        self._seen[path] = now
        # 清理过期
        if len(self._seen) > 10000:
            cutoff = now - 300
            self._seen = {
                k: v for k, v in self._seen.items()
                if v > cutoff}
        return True

    def on_created(self, event):
        """文件创建。"""
        if event.is_directory:
            return
        if not event.src_path.lower().endswith(".pdf"):
            return
        if not self._debounce(event.src_path):
            return
        name = os.path.basename(event.src_path)
        logger.info("发现新文件 path=%s", event.src_path)
        collect_file_task.delay(event.src_path, name)

    def on_moved(self, event):
        """文件移动（重命名到 INBOX）。"""
        if event.is_directory:
            return
        dest = getattr(event, "dest_path", None)
        if not dest or not dest.lower().endswith(".pdf"):
            return
        if not self._debounce(dest):
            return
        name = os.path.basename(dest)
        logger.info("发现移动文件 path=%s", dest)
        collect_file_task.delay(dest, name)


def start():
    """启动监听服务。"""
    from app.services.m13.collect_service import (
        CollectConfigService,
    )
    from app.core.db import run_sync
    from app.core.file_security import safe_join

    cfg = run_sync(CollectConfigService.get_all)
    root = cfg.get("M13.COLLECT.ROOT_PATH", "")
    inbox = cfg.get("M13.COLLECT.INBOX_DIR", "INBOX")
    watch_dir = safe_join(root, inbox)
    if not os.path.isdir(watch_dir):
        logger.error("监听目录不存在 dir=%s", watch_dir)
        return

    # 用 PollingObserver：兼容 SMB/NFS 网络盘
    observer = PollingObserver(timeout=3)
    observer.schedule(InboxHandler(), watch_dir, recursive=True)
    observer.start()
    logger.info("INBOX 监听已启动 dir=%s", watch_dir)
    try:
        while True:
            time.sleep(30)
            # 心跳
            from app.core.redis import run_sync_redis
            run_sync_redis(
                "setex", "m13:collect:watchdog:heartbeat",
                60, str(int(time.time())))
    except KeyboardInterrupt:
        observer.stop()
    observer.join()
```

**为什么用 `PollingObserver` 而不是 `Observer`（inotify）？**

| 观察器 | 机制 | 网络盘支持 | CPU |
|---|---|---|---|
| `Observer` | inotify（Linux 内核事件） | **差**（SMB/NFS 常无事件） | 极低 |
| `PollingObserver` | 轮询（每 3 秒 scan 一次） | **好** | 低（1 万文件约 3% CPU） |

生产环境必须用 `PollingObserver`，因为共享文件夹是 SMB 挂载。inotify 在网络盘上经常失效，这是踩过的坑。

**为什么还要定时全量扫描？**

`PollingObserver` 虽好，但仍可能漏：
- 服务重启期间的变更
- 轮询间隔内快速创建又移动的文件

每 5 分钟全量扫描一次是兜底。

### 9.4 安全措施

1. **路径穿越防护**：所有路径拼接用 `safe_join(root, *paths)`，校验 `target.startswith(root_abs + os.sep)`。
2. **密码加密存储**：`pdf_password_enc` 用 AES-256-GCM，密钥在 KMS/环境变量，不明文落库。
3. **下载审计**：每次下载写 `FILE_DOWNLOAD` 审计（含操作人、IP、文件号）。
4. **条码/文件名不入二维码**：文件名可能含患者姓名，不写入可扫描的外部标识。
5. **上传大小限制**：单文件 200MB，单次 20 个。
6. **MIME 类型校验**：除后缀检查外，验证文件头部魔数。
7. **临时文件隔离**：上传先写 `MANUAL/` 临时目录，登记成功后才进入正式流程。
8. **密码重试锁定**：3 次错误锁定 30 分钟（Redis）。

**为什么 IT 管理员不能下载原件？**

IT 管理员有系统配置权限，但**不应有医疗数据访问权**。检查报告包含患者姓名、性别、年龄、诊断结论。

若 IT 可下载：
- 内部人员可批量导出患者诊断数据
- 违反《个人信息保护法》最小必要原则
- 审计追踪模糊（"IT 维护需要"成了万能借口）

若确需排查文件问题（如 PDF 损坏），可通过"文件校验结果"页面查看 SHA-256、大小、页数、前 256 字节 hex，无需下载完整原件。

## 11. 异常处理与日志

### 11.1 异常分类

| 类别 | 示例 | 处理 |
|---|---|---|
| **文件系统异常** | 文件不存在、权限不足、磁盘满 | 返回 4xx/5xx，记录 ERROR |
| **稳定性异常** | 文件长时间不稳定、被占用 | 重试 20 次后记失败，30 分钟后再试 |
| **格式异常** | 非 PDF、损坏、超大 | 隔离 + 通知运维 |
| **加密异常** | 需要密码、密码错误 | 待确认队列 + 锁定 |
| **去重** | SHA-256 重复 | 正常流程，标 DUPLICATE |
| **依赖异常** | M13-03 超时、消息发不出 | Celery 重试，记录 WARN |
| **并发异常** | 路径锁冲突 | 返回 409 |
