## 1. 模块概述

### 1.1 模块定位

M13-01 检验申请与标本管理负责回答四个问题：

1. **医生要查什么？** —— 接收 M07 下达的检验医嘱，展开成可执行的检验项目
2. **这些项目需要什么标本？** —— 按项目归并出标本需求（一管血查多项）
3. **标本在哪？** —— 贴条码、采集、流转、签收、拒收
4. **报告什么时候出来？** —— 生成检验任务并跟踪 SLA

**M13-01 是整条检验链路的入口，也是唯一产生"标本条码"的地方。**

```
                    M07-03 医生下达检验医嘱
                              │
                              ▼
        ┌─────────────────────────────────────────────┐
        │              M13-01 检验申请与标本管理         │
        │                                             │
        │  ① 接单 ────────────────────────────────┐  │
        │     医嘱 → 检验任务 → 标本需求            │  │
        │                                          │  │
        │  ② 条码 ──────────────────────────────┐ │  │
        │     生成标本条码（唯一编号）             │ │  │
        │                                          │ │  │
        │  ③ 采集 ──────────────────────────────┐ │ │  │
        │     护士执行采集 → 采集记录              │ │ │  │
        │                                          │ │ │  │
        │  ④ 流转 ──────────────────────────────┐ │ │ │  │
        │     标本送检 → 检验科签收/拒收           │ │ │ │  │
        │                                          │ │ │ │  │
        │  ⑤ 状态 ──────────────────────────────┐ │ │ │ │  │
        │     全流程状态机与超时告警               │ │ │ │ │  │
        │                                          │ │ │ │ │  │
        └──────────────────────────────────────────┴─┴─┴─┴─┴──┘
                              │
              ┌───────────────┼───────────────┐
              ▼               ▼               ▼
        M13-02 文件采集  M12 检查管理（互不干预）   M07-04 医生查看
```

### 1.2 为什么独立成子模块

**理由一：标本周转是独立的物理过程，与报告生成完全解耦。**

检验的业务链条是：

```
开单 → 收费 → 采集 → 送检 → 签收 → 上机 → 出报告 → 审核 → 发布
                              ↑
                          M13-01 到此结束
```

前半段（开单到签收）是**人跑腿、标本跑路**的过程，后半段是**仪器跑数、文件生成**的过程。前者出错要看护士站和物流，后者出错要看仪器和 OCR 引擎——两者的运维责任人、故障排查路径、指标口径完全不同。

如果合成一个子模块，会出现一个函数里既操作护士站队列又操作 PACS 风格的文件夹的怪象。

**理由二：标本条码是全院唯一的护理端凭证。**

眼科门诊量约 350 人次/日，其中需要抽血的约 15%，即 50 人次/日。每位患者平均 2 管（血常规 1 管 EDTA + 生化 1 管促凝），日均 100 管。

护士站的核对逻辑是"扫码 → 看到患者 → 抽血 → 贴标"，这套动作依赖：

- 条码编号全局唯一（不能与药品处方条码、检查预约条撞号）
- 条码在采集时打印（不是开单时打印，避免调错管）
- 标本状态对护士站实时可见（哪管没抽、哪管抽了没送）

这些是 **M08 护理站**的核心交互。M13-01 提供接口，M08 提供界面。若合成到 M13 里，M08 要反向依赖 M13 的内部表结构。

**理由三：标本有独立的合规要求。**

《医疗机构临床实验室管理办法》第十九条：**标本采集、运送、接收、拒收必须有完整记录，可追溯**。

具体到数据：

- 采集人、采集时间、采集部位、采集量
- 运送人、运送时间、运送温度（冷运/常温）
- 接收人、接收时间、标本外观（溶血/凝块/量不足）
- 拒收人、拒收时间、拒收原因、重采记录

这 12 个字段构成的**标本闭环台账**，在医疗纠纷中是关键证据（"标本是不是你们弄错了？"）。它有独立的数据结构和保留期要求（10 年），不该混在检验报告表里。

**理由四：检验申请与检查申请虽然同源，但执行路径完全不同。**

| 维度 | 检查（M12） | 检验（M13） |
|---|---|---|
| 患者是否到场 | 必须到场（躺到机器前） | 采集需要到场，之后不需要 |
| 执行者 | 技师 | 护士（采集）+ 检验技师（上机） |
| 中间产物 | 报告 PDF 文件 | 标本管 |
| 时间跨度 | 分钟级（15 分钟一台） | 小时级（生化 2 小时出结果） |
| 设备接入 | **无法接入，靠共享文件夹 + OCR** | **同样无法接入，靠共享文件夹 + OCR** |
| 标本管理 | 无 | 有（核心） |

共性是"报告靠 OCR"，差异是"是否管标本"。把共性抽出成共享的 OCR 解析能力（M13-03 与 M12-04 结构相同），把差异留在各自模块，是正确的切分。

### 1.4 概念辨析

| 概念 | 定义 | 归属 |
|---|---|---|
| **检验医嘱** | 医生下达的原始医嘱（`LAB` 类型） | M07-03 |
| **检验申请** | M13 接单后生成的申请单（`m13_lab_request`） | **M13-01** |
| **检验项目** | 申请单中的一行（如"血常规"），对应 `md_lab_item` | **M13-01** |
| **组合项目** | 一组检验项目的打包（如"术前八项"），展开成多个检验项目 | M01-09 定义 / **M13-01 展开** |
| **检验任务** | 一个检验项目对应一个检验任务（`m13_lab_task`） | **M13-01** |
| **标本** | 一个物理容器（一管血/一份尿），可以是 1 个任务也可以是 N 个任务共用 | **M13-01** |
| **标本需求** | "需要采集哪种标本、几管、多少量" | **M13-01** |
| **采集记录** | 护士执行采集的动作留痕（谁、何时、何处、多少） | **M13-01** |
| **标本条码** | 贴在标本管上的唯一编号（`m13_specimen.specimen_no`） | **M13-01 唯一产生** |
| **标本状态** | 采集、送检、签收、拒收等物理状态 | **M13-01** |
| **检验结果** | 报告上的数值/定性结果 | M13-03 |
| **检验报告** | 完整报告（结果 + 参考区间 + 结论） | M13-04 |

**最容易混淆的三组：**

**① 检验项目 ≠ 检验任务**

一个组合项目"术前八项"是一个**检验项目**（收费一项），但展开成 8 个**检验任务**（每个都要出结果）。

```
检验项目: 术前八项（1 行，收费 1 次）
    ├── 检验任务: HBsAg      （1 个任务）
    ├── 检验任务: HBsAb      （1 个任务）
    ├── ... 共 8 个任务
```

**② 标本 ≠ 检验任务**

一管 EDTA 抗凝血可以同时做血常规、血型、糖化血红蛋白 —— **1 个标本对应 3 个任务**。

反过来，一个"血气分析"项目可能需要动脉血和静脉血两管 —— **1 个任务对应 2 个标本**。

所以标本与任务是 **M:N** 关系，通过 `m13_specimen_task_rel` 关联。

**③ 标本条码 ≠ 就诊号/挂号号**

标本条码是**物理容器**的唯一标识，一个就诊可能有多管标本，每管一个条码。条码格式 `SPL` + 8 位日期 + 5 位序号，与挂号号、就诊号、处方号完全独立。

### 1.5 模块目标

| 指标 | 目标 | 测量方式 |
|---|---|---|
| 接单响应时间 | P95 ≤ 200ms | `POST /internal/v1/m13/lab/requests` |
| 条码生成时间 | P95 ≤ 100ms | 采集界面点"采集"到条码返回 |
| 当日检验申请接单成功率 | ≥ 99.9% | 成功接单数 / M07 推送数 |
| 标本条码重复率 | **0** | DB 唯一索引兜底，告警监控 |
| 采集到送检时长 | 中位数 ≤ 30 分钟 | 采集时刻到签收时刻 |
| 送检超时率 | ≤ 2% | 超过送检时限的标本 / 总标本 |
| 标本拒收率 | ≤ 1% | 拒收数 / 签收总数（含拒收） |
| 重采率 | ≤ 1.5% | 重采标本数 / 总标本数 |
| 标本闭环完整率 | **100%** | 采集/送检/签收/拒收 四环节记录齐全 |

### 3.1 检验申请模型

```
│ request_type OUTPATIENT/INPATIENT/EMERGENCY/PHYSICAL              │
│ status       RECEIVED/DISPATCHED/CANCELLED                        │
└────────────┬─────────────────────────────────────────────────────┘
             │ 1:N
             ▼
┌──────────────────────────────────────────────────────────────────┐
│ m13_lab_item（检验项目明细）                                      │
│ ──────────────────────────────────────────────────────────────── │
│ item_no      申请单下发起的单行项目                                │
│ lab_code     LB0001 血常规（组合项目）                             │
│ is_combo     TRUE                                                  │
│ quantity     1                                                     │
└────────────┬─────────────────────────────────────────────────────┘
             │ 展开（组合项目 → 明细项目）
             ▼
┌──────────────────────────────────────────────────────────────────┐
│ m13_lab_task（检验任务）                                          │
│ ──────────────────────────────────────────────────────────────── │
│ task_no      LT2026102200001                                       │
│ lab_code     LB000101 WBC 白细胞计数（单项目）                      │
│ item_id      指回 m13_lab_item                                     │
│ specimen_type WHOLE_BLOOD（全血）                                   │
│ status       PENDING_COLLECT/COLLECTED/DELIVERED/ACCEPTED/...      │
└──────────────────────────────────────────────────────────────────┘
```

**为什么组合项目与明细项目都要存？**

- `m13_lab_item` 是**收费与退费的依据**（一个组合项目 = 一笔收费）
- `m13_lab_task` 是**执行与结果的依据**（每个明细项目 = 一个结果行）

若只存明细，退费时要反推"这 8 个项目是不是同一个组合"；若只存组合，无法追踪单个项目的结果。

### 3.2 标本归并模型

**标本归并是 M13-01 的核心算法。**

同一患者一次采血，多个检验项目可能用同一管血。归并错误会导致：

- **多采**：患者多挨一针，护士工作量翻倍
- **少采**：标本量不够，检验科拒收，患者重采

**归并规则：**

| 规则 | 说明 |
|---|---|
| R-01 | 同 `specimen_type` + 同 `container_type` 的项目归并为一管 |
| R-02 | 归并后总量不超过容器最大容量（全血 EDTA 紫帽管 2ml，最大可采 2ml） |
| R-03 | 总量超过容量时拆分成 N 管，管号递增 |
| R-04 | 需冷藏与不需冷藏的项目**不归并**（保存条件不同） |
| R-05 | 需立即送检的项目**单独一管**（不能与常规项目混合等待） |
| R-06 | 眼科特殊标本（房水/玻璃体液/泪液）**每项单独一管** |
| R-07 | 凝血功能（蓝帽枸橼酸）**必须独立一管**（抗凝剂比例要求） |

**归并算法：**

```
输入：待采集的检验任务列表 tasks[]
输出：标本需求列表 specimens[]

① 按 (specimen_type, container_type, need_refrigeration, need_immediate) 分组
② 每个分组内累加各任务的采血量
③ 若累计量 ≤ 容器容量 → 生成 1 管
④ 若累计量 > 容器容量 → 按顺序装满，剩余部分生成下一管
⑤ 特殊标本（房水/玻璃体液/泪液/凝血）单独处理，每任务 1 管
⑥ 为每管生成 specimen_no（条码）与预计采集量
```

**示例：术前八项（HBsAg、HBsAb、HBeAg、HBeAb、HBcAb、抗HCV、抗HIV、梅毒）**

8 个项目全部是血清，红帽管容量 5ml，每个项目需 200μL，合计 1.6ml：

```
归并结果：1 管红帽血清管，采 3ml（留余量）
```

**示例：血常规 + 生化 + 凝血**

| 项目 | 标本类型 | 容器 | 用量 |
|---|---|---|---|
| 血常规 | WHOLE_BLOOD | 紫帽 EDTA | 2ml |
| 生化 | SERUM | 红帽促凝 | 3ml |
| 凝血 | PLASMA | 蓝帽枸橼酸 | 2ml |

归并结果：**3 管**（三种容器不同、抗凝剂不同，无法合并）

```

                    │   （待采集）   │
                    └──────┬───────┘

   ② 拒收后重采：REJECTED ──► 生成新标本 PENDING ◄──────────────┘

```

**状态说明：**

| 状态 | 含义 | 可达操作 |
|---|---|---|
| `PENDING` | 已生成条码，等待采集 | 采集、作废 |
| `COLLECTED` | 已采集，等待送检 | 送检、补登采集信息 |
| `DELIVERED` | 已送达检验科，等待签收 | 签收、拒收 |
| `ACCEPTED` | 检验科已签收 | 开始检验、补签拒收 |
| `IN_PROCESS` | 检验进行中 | 完成、补签拒收 |
| `COMPLETED` | 已完成（终态） | 无 |
| `REJECTED` | 拒收（终态，需重采） | 无（触发重采生成新标本） |
| `CANCELLED` | 作废（终态） | 无 |

### 3.4 检验任务状态机

任务状态只要"有没有出结果"这一维度：

```
PENDING_COLLECT → COLLECTED → DELIVERED → ACCEPTED → REPORTED
      │              │           │           │
      └──────────────┴───────────┴───────────┴──► CANCELLED
```

| 状态 | 含义 |
|---|---|
| `PENDING_COLLECT` | 待采集 |
| `COLLECTED` | 标本已采集 |
| `DELIVERED` | 标本已送检 |
| `ACCEPTED` | 标本已签收 |
| `REPORTED` | 已出报告（终态） |
| `CANCELLED` | 已取消（终态） |

**任务状态由标本状态驱动**：标本状态推进时，关联的所有任务同步推进。

但**任务不随标本拒收而回退**：标本被拒收后，任务变为 `PENDING_COLLECT`（等待新标本），原标本保持 `REJECTED` 终态。

### 3.5 标本需求计算模型

**采血量计算规则：**

```
某标本的应采量 =
    SUM(该标本关联项目的单次用血量)
    × (1 + 余量系数 0.2)
    ↑ 上限不超过容器容量
```

**各标本类型的默认参数：**

| 标本类型 | 容器 | 容量(ml) | 单项目用量(ml) | 送检时限 | 保存条件 |
|---|---|---|---|---|---|
| WHOLE_BLOOD | 紫帽 EDTA | 2.0 | 0.030 | 2 小时 | 常温 |
| SERUM | 红帽促凝 | 5.0 | 0.200 | 4 小时 | 常温 |
| PLASMA | 蓝帽枸橼酸 | 2.7 | 0.300 | 2 小时 | 常温 |
| URINE | 尿杯 | 50.0 | 10.000 | 2 小时 | 常温 |
| STOOL | 便盒 | — | — | 1 小时 | 常温 |
| TEAR | 毛细管 | 0.02 | 0.020 | 立即 | 冷藏 |
| AQUEOUS | 无菌管 | 0.2 | 0.100 | 立即 | 冷藏 |
| VITREOUS | 无菌管 | 1.0 | 0.500 | 立即 | 冷藏 |
| CORNEA_SCRAPING | 无菌拭子 | — | — | 立即 | 常温 |
| CONJUNCTIVAL_SWAB | 无菌拭子 | — | — | 立即 | 常温 |

> 上述参数由 M13-05 维护，M13-01 消费。若 M01-09 `md_specimen` 已有对应记录则以主数据为准，否则用默认值。

### 3.6 送检时限模型

**送检时限（TAT-Delivery）** 从采集时刻起算：

```
送检截止时刻 = 采集时刻 + specimen.delivery_minutes
```

超时等级：

| 等级 | 判断 | 处理 |
|---|---|---|
| 正常 | 当前 < 截止时刻 | 无 |
| 预警 | 当前 ≥ 截止时刻 × 0.8 | 页面标黄 |
| 超时 | 当前 ≥ 截止时刻 | 页面标红 + 通知 |
| 严重超时 | 当前 ≥ 截止时刻 × 2 | 通知护士长 + 记入质量报表 |

**送检时限为何重要：**

- 全血 EDTA 放置超过 2 小时，白细胞形态改变，血常规不准
- 血清促凝管放置超过 4 小时，血糖因红细胞消耗而假性降低
- 凝血标本超过 2 小时，凝血因子活性下降
- 房水/玻璃体液/泪液标本，病原体存活率随时间下降，必须立即送检

### 3.7 标本拒收模型

**拒收原因（8 类）：**

| 代码 | 名称 | 说明 | 是否需重采 |
|---|---|---|---|
| `HEMOLYSIS` | 溶血 | 红细胞破裂，血清呈红色 | 是 |
| `CLOTTED` | 凝块 | 抗凝不充分，出现血块 | 是 |
| `INSUFFICIENT` | 量不足 | 采集量低于检测下限 | 是 |
| `WRONG_CONTAINER` | 容器错误 | 抗凝剂类型不对 | 是 |
| `UNLABELED` | 无标签 | 标本管无条码 | 是 |
| `MISMATCH` | 信息不符 | 条码与患者不符 | 是 |
| `DELAYED` | 超时送达 | 超过送检时限 | 视情况 |
| `CONTAMINATED` | 污染 | 标本被污染 | 是 |

**拒收处理流程：**

```
检验科扫码 → 选择拒收原因 → 填写说明（≥10 字）→ 拍照（可选）
    ↓
标本状态 → REJECTED
    ↓
任务状态 → PENDING_COLLECT（等待新标本）
    ↓
生成重采提醒 → 推送护士站（M08）→ 通知医生（M07-04）
    ↓
护士重新采血 → 生成新标本（parent_specimen_id 指向被拒收标本）
```

**为什么要记录 parent_specimen_id？**

因为重采是同一任务的第二次尝试，需要知道"这个任务是第几次采的"。统计重采率时需要 `COUNT(标本 WHERE parent_specimen_id IS NOT NULL) / COUNT(任务)`。

### 3.8 标本条码规则

**格式：`SPL` + `YYYYMMDD` + 5 位序号**

```
SPL2026102200001
 │   │        │
 │   │        └─ 当日流水号（1~99999）
 │   └────────── 生成日期
 └────────────── 固定前缀
```

**条码内容（二维码）：**

二维码编码的是一段结构化文本，扫码后可直接解析：

```
SPL2026102200001|1024|LB0001|WHOLE_BLOOD|2.0
     ↑              ↑      ↑        ↑          ↑
  标本号         患者ID  主检验项目  标本类型    应采量
```

**为什么二维码要带患者 ID 而不是只放标本号？**

因为护士站扫码时，需要在**不联网**的情况下初步核对患者。护理 PAD 断网时（眼科门诊偶发），扫码后能直接显示"患者 1024 的血常规"，护士可以肉眼核对床头卡，避免把 A 的血贴到 B 的管上。

**条码打印规则：**

| 项 | 规则 |
|---|---|
| 打印时机 | **采集时打印**，不是开单时打印 |
| 打印介质 | 热敏不干胶标签（50mm × 25mm） |
| 补打次数 | 最多 3 次，超过需护士长授权 |
| 作废条码 | 采集前作废，条码不可复用 |

**为什么采集时打印而不是开单时打印？**

开单时打印（预打印模式）会导致：

- 一个患者开 3 管，护士拿 3 张标签去采血，容易贴错
- 患者没来，标签作废，浪费
- 采集顺序与开单顺序不一致时，护士要在一堆标签里翻找

采集时打印（现场打印模式）才是正确做法：护士扫码确认患者 → 选采血管 → 现场打印该管的标签 → 贴管。

### 3.9 重采管理模型

**重采触发条件：**

| 场景 | 触发方 | 说明 |
|---|---|---|
| 标本拒收 | M13-01 检验科签收 | 8 类拒收原因 |
| 结果异常需复检 | M13-04 审核 | 检验医师判断结果不可靠 |
| 标本丢失 | M13-01 台账 | 送检后找不到 |
| 医嘱追加项目 | M07-03 | 加做项目但标本已用尽 |

**重采关联：**

```
原标本 SPL2026102200001（REJECTED）
    ↓ parent_specimen_id
新标本 SPL2026102200003（PENDING）
    ↓ parent_specimen_id
新标本 SPL2026102200008（PENDING）
```

形成重采链。统计时：

- 首次采集率 = `COUNT(标本 WHERE parent_specimen_id IS NULL) / COUNT(任务)`
- 重采率 = `1 - 首次采集率`

**字段说明：**

| 区域 | 字段 | 说明 |
|---|---|---|
| 待签收 | 送检状态 | ✅正常 / ⚠超时 |
| 外观检查 | 量 | 足量 / 偏少 / 不足 |
| 外观检查 | 溶血 | 勾选即判溶血 |
| 外观检查 | 凝块 | 勾选即判凝块 |
| 外观检查 | 容器 | 正确 / 错误 |
| 外观检查 | 判定 | ✅合格 / ❌拒收-原因 |

**交互说明：**

| 操作 | 触发 | 结果 |
|---|---|---|
| 扫码签收 | 扫码框回车 | 定位该标本，自动勾选 |
| 勾选外观异常 | 勾选溶血/凝块 | 判定自动变为"拒收"，弹出拒收原因 |
| 全部签收 | 按钮 | 所有合格标本状态 → `ACCEPTED` |
| 确认拒收并通知重采 | 按钮 | 该标本 → `REJECTED`，生成重采记录，通知护士站 |

**校验规则：**

| 编号 | 规则 | 错误码 |
|---|---|---|
| V-20 | 只能签收状态为 `DELIVERED` 的标本 | `"1301007"` |
| V-21 | 拒收必须选原因 | `"1301016"` |
| V-22 | 拒收说明 ≥10 字 | `"1301016"` |
| V-23 | 溶血/凝块必须勾选才可拒收 | `"1301017"` |
| V-24 | 无标签标本直接拒收，无需外观检查 | — |
| V-25 | 签收人必须是检验科人员 | `"1301018"` |

**为什么要把签收台做成"批量 + 逐件外观检查"两段式？**

因为实际工作中，检验科签收有 80% 是流水线式——扫一箱标本，全部没有明显异常，一次签收。剩下 20% 有几件需要细看。两段式设计让常规情况 10 秒完成一箱，异常情况才逐件检查。

若做成"每件都要勾 4 个框"，一箱 30 件要勾 120 次，检验科会崩溃并且开始敷衍勾选。

### 6.2 错误码规范

| 错误码 | 说明 | 触发场景 |
|---|---|---|
| `"1301001"` | 检验申请不存在 | 查询/操作的申请 ID 无效 |
| `"1301002"` | 检验项目或组合项目不存在 | M01-09 返回 404 |
| `"1301003"` | 检验医嘱重复接单 | 同一 `order_no` 已存在申请 |
| `"1301004"` | 申请单状态不允许此操作 | 已取消申请再采集 |
| `"1301005"` | 标本尚未生成条码 | 条码接口调用但标本无 `specimen_no` |
| `"1301006"` | 检验费用未缴清 | 未缴费采集 |
| `"1301007"` | 标本状态不允许此操作 | 状态机非法转移 |
| `"1301008"` | 采集量超出容器容量 | 实采量 > 容量 |
| `"1301009"` | 采集量不足需填写说明 | 实采量 < 应采量 × 0.8 且备注为空 |
| `"1301010"` | 采集部位未选择 | 采集登记缺部位 |
| `"1301011"` | 采集人必须是当前登录用户 | 采集人字段与登录用户不符 |
| `"1301012"` | 冷藏标本必须选择冷藏运送 | 需冷藏标本选了常温 |
| `"1301013"` | 条码打印次数超出限制 | 第 4 次打印 |
| `"1301014"` | 运送员未选择 | 送检登记缺运送员 |
| `"1301015"` | 日期跨度超出限制 | 查询超过 92/366 天 |
| `"1301016"` | 拒收原因或说明不完整 | 拒收未选原因或说明 <10 字 |
| `"1301017"` | 外观异常必须明确勾选 | 拒收但未勾选溶血/凝块 |
| `"1301018"` | 无标本签收权限 | 非检验科人员签收 |
| `"1301019"` | 导出行数超出限制 | 超过 50,000 行 |
| `"1301020"` | 检验主数据服务不可用 | M01-09 超时且无缓存 |
| `"1301021"` | 标本不存在 | 标本 ID 无效 |
| `"1301022"` | 重采记录不存在 | 重采 ID 无效 |
| `"1301023"` | 标本已被其他窗口占用 | 并发操作乐观锁失败 |
| `"1301024"` | 该申请不存在可采集标本 | 全部标本已采集/已作废 |
| `"1301025"` | 参数值超出允许范围 | 配置保存校验失败 |

```python
class SpecimenAllocator:
    """标本归并算法。"""

    @classmethod
    def allocate(
        cls, tasks: List[Dict[str, Any]]
    ) -> List[Dict[str, Any]]:
        """把检验任务归并成标本需求。

        Args:
            tasks: [{lab_code, lab_name, specimen_type, need_refrigeration,
                     need_immediate, delivery_minutes}]

        Returns:
            [{specimen_type, container_type, collect_volume,
              delivery_minutes, task_lab_codes}]
        """
        # ① 分组键
        groups: Dict[Tuple, List[Dict]] = {}
        for t in tasks:
            stype = t["specimen_type"]
            if stype in SINGLE_ONLY:
                key = (stype, t["lab_code"])
            else:
                key = (stype, bool(t.get("need_refrigeration")))
            groups.setdefault(key, []).append(t)

        # ② 逐组计算管数
        result: List[Dict[str, Any]] = []
        for key, items in groups.items():
            stype = key[0]
            capacity = CONTAINER_CAPACITY.get(
                stype, Decimal("1.0"))
            consume = ITEM_CONSUME.get(stype, Decimal("0.1"))
            delivery = DELIVERY_MINUTES.get(stype, 120)

            if stype in SINGLE_ONLY:
                # 单独成管：每个任务一管
                for it in items:
                    vol = min(consume, capacity) if capacity > 0 else consume
                    result.append({
                        "specimen_type": stype,
                        "container_type": it.get("container_type"),
                        "collect_volume": money(vol),
                        "delivery_minutes": delivery,
                        "task_lab_codes": [it["lab_code"]],
                    })
                continue

            # 归并：按容量装填
            pending = list(items)
            while pending:
                vol = Decimal("0")
                batch: List[Dict] = []
                while pending:
                    need = consume
                    if vol + need > capacity and batch:
                        break
                    batch.append(pending.pop(0))
                    vol += need
                # 加 20% 余量
                target = money(min(vol * Decimal("1.2"), capacity))
                if target <= 0:
                    target = money(capacity)
                result.append({
                    "specimen_type": stype,
                    "container_type": batch[0].get("container_type"),
                    "collect_volume": target,
                    "delivery_minutes": delivery,
                    "task_lab_codes": [b["lab_code"] for b in batch],
                })

        return result


class LabRequestService:
    """检验申请服务。"""

    @classmethod
    async def receive(
        cls, db: AsyncSession, body
    ) -> Dict[str, Any]:
        """接单：幂等 → 展开组合 → 归并标本 → 落库。"""
        # ① 幂等：同一 order_no 只接一次
        exists = await db.scalar(
            select(M13LabRequest).where(
                M13LabRequest.order_no == body.order_no,
                M13LabRequest.is_deleted.is_(False),
            ))
        if exists is not None:
            specimens = await cls._specimens_of(db, exists.id)
            return {
                "request_no": exists.request_no,
                "request_id": exists.id,
                "task_count": exists.task_count,
                "specimen_count": exists.specimen_count,
                "is_duplicate": True,
                "specimens": specimens,
            }

        # ② 展开组合项目 → 任务规格
        task_specs: List[Dict[str, Any]] = []
        item_rows: List[M13LabItem] = []
        for raw in body.items:
            if raw.is_combo:
                details = await cls._expand_combo(
                    raw.lab_code)
                for d in details:
                    task_specs.append({
                        "lab_code": d["lab_code"],
                        "lab_name": d["lab_name"],
                        "specimen_type": d["specimen_type"],
                        "container_type": d.get("container_type"),
                        "need_refrigeration":
                            d.get("need_refrigeration", False),
                        "need_immediate": d.get("need_immediate", False),
                        "delivery_minutes":
                            d.get("delivery_minutes", 120),
                        "combo_code": raw.lab_code,
                    })
            else:
                meta = await cls._lab_meta(raw.lab_code)
                task_specs.append({
                    "lab_code": raw.lab_code,
                    "lab_name": raw.lab_name or meta["lab_name"],
                    "specimen_type": meta["specimen_type"],
                    "container_type": meta.get("container_type"),
                    "need_refrigeration":
                        meta.get("need_refrigeration", False),
                    "need_immediate":
                        meta.get("need_immediate", False),
                    "delivery_minutes":
                        meta.get("delivery_minutes", 120),
                    "combo_code": None,
                })

        # ③ 归并标本
        allocations = SpecimenAllocator.allocate(task_specs)

        # ④ 落库
        now = datetime.now()
        request_no = await cls._next_request_no(db, now)
        req = M13LabRequest(
            request_no=request_no,
            order_id=body.order_id,
            order_no=body.order_no,
            patient_id=body.patient_id,
            patient_name=body.patient_name,
            gender=body.gender,
            age=body.age,
            encounter_id=body.encounter_id,
            visit_no=body.visit_no,
            dept_id=body.dept_id,
            dept_name=body.dept_name,
            doctor_id=body.doctor_id,
            doctor_name=body.doctor_name,
            request_type=body.request_type,
            status="RECEIVED",
            item_count=len(body.items),
            task_count=len(task_specs),
            specimen_count=len(allocations),
            requested_at=now,
        )
        db.add(req)
        await db.flush()

        seq = 0
        for raw in body.items:
            seq += 1
            db.add(M13LabItem(
                request_id=req.id,
                request_no=request_no,
                line_no=seq,
                lab_code=raw.lab_code,
                lab_name=raw.lab_name,
                is_combo=raw.is_combo,
                quantity=raw.quantity,
                charge_item_code=raw.charge_item_code,
                charge_amount=raw.charge_amount,
                status="ACTIVE",
            ))
        await db.flush()

        # ⑤ 建任务 + 标本
        task_seq = 0
        spec_seq = 0
        for alloc in allocations:
            spec_seq += 1
            spec_no = await cls._next_specimen_no(db, now)
            spec = M13Specimen(
                specimen_no=spec_no,
                request_id=req.id,
                request_no=request_no,
                patient_id=body.patient_id,
                patient_name=body.patient_name,
                specimen_type=alloc["specimen_type"],
                container_type=alloc["container_type"],
                collect_volume=alloc["collect_volume"],
                actual_volume=None,
                delivery_minutes=alloc["delivery_minutes"],
                delivery_deadline=None,
                status="PENDING",
                print_count=0,
                tube_seq=spec_seq,
                created_at=now,
            )
            db.add(spec)
            await db.flush()

            for lab_code in alloc["task_lab_codes"]:
                task_seq += 1
                spec_meta = next(
                    t for t in task_specs
                    if t["lab_code"] == lab_code
                    and t["specimen_type"] == alloc["specimen_type"])
                task_no = await cls._next_task_no(
                    db, now, task_seq)
                task = M13LabTask(
                    task_no=task_no,
                    request_id=req.id,
                    request_no=request_no,
                    patient_id=body.patient_id,
                    patient_name=body.patient_name,
                    encounter_id=body.encounter_id,
                    dept_id=body.dept_id,
                    lab_code=lab_code,
                    lab_name=spec_meta["lab_name"],
                    combo_code=spec_meta.get("combo_code"),
                    specimen_type=alloc["specimen_type"],
                    status="PENDING_COLLECT",
                    primary_specimen_id=spec.id,
                    created_at=now,
                )
                db.add(task)
                await db.flush()
                db.add(M13SpecimenTaskRel(
                    specimen_id=spec.id,
                    task_id=task.id,
                    lab_code=lab_code,
                    created_at=now,
                ))

        # ⑥ 日志与审计
        db.add(M13SpecimenLog(
            biz_type="REQUEST",
            biz_id=req.id,
            action="RECEIVE",
            operator_id=body.doctor_id or 0,
            operator_name=body.doctor_name,
            detail={"order_no": body.order_no,
                    "task_count": task_seq,
                    "specimen_count": spec_seq},
            created_at=now,
        ))
        await db.commit()

        await AuditClient.record(
            module="M13-01", action="LAB_REQUEST_RECEIVE",
            biz_id=req.id, extra={"order_no": body.order_no})

        return {
            "request_no": request_no,
            "request_id": req.id,
            "task_count": task_seq,
            "specimen_count": spec_seq,
            "is_duplicate": False,
            "specimens": await cls._specimens_of(db, req.id),
        }

    @classmethod
    async def _expand_combo(
        cls, combo_code: str
    ) -> List[Dict[str, Any]]:
        """展开组合项目。"""
        details = await LabMasterClient.get_combo_detail(combo_code)
        if not details:
            raise BizException(
                "1301002",
                "组合项目 %s 不存在或未配置明细" % combo_code)
        out: List[Dict[str, Any]] = []
        for d in details:
            meta = await cls._lab_meta(d["lab_code"])
            out.append({
                "lab_code": d["lab_code"],
                "lab_name": meta["lab_name"],
                "specimen_type": meta["specimen_type"],
                "container_type": meta.get("container_type"),
                "need_refrigeration":
                    meta.get("need_refrigeration", False),
                "need_immediate":
                    meta.get("need_immediate", False),
                "delivery_minutes":
                    meta.get("delivery_minutes", 120),
            })
        return out

    @classmethod
    async def _lab_meta(cls, lab_code: str) -> Dict[str, Any]:
        """取检验项目元数据（含标本信息）。"""
        meta = await LabMasterClient.get_lab_item(lab_code)
        if not meta:
            raise BizException(
                "1301002", "检验项目 %s 不存在" % lab_code)
        specimen_type = meta.get("specimen_type")
        if not specimen_type:
            sp = await LabMasterClient.get_specimen(
                meta.get("specimen_code"))
            specimen_type = (sp or {}).get("specimen_type")
        if not specimen_type:
            raise BizException(
                "1301002",
                "检验项目 %s 未配置标本类型" % lab_code)
        return {
            "lab_code": lab_code,
            "lab_name": meta.get("lab_name"),
            "specimen_type": specimen_type,
            "container_type": meta.get("container_type"),
            "need_refrigeration":
                (meta.get("container_type") or "").find("冷藏") >= 0,
            "need_immediate": (
                DELIVERY_MINUTES.get(specimen_type, 120) == 0),
            "delivery_minutes":
                DELIVERY_MINUTES.get(specimen_type, 120),
        }

    @classmethod
    async def _next_request_no(
        cls, db: AsyncSession, now: datetime
    ) -> str:
        """生成申请单号 LQ + YYYYMMDD + 4 位。"""
        prefix = "LQ" + now.strftime("%Y%m%d")
        last = await db.scalar(
            select(func.count(M13LabRequest.id)).where(
                M13LabRequest.request_no.like(prefix + "%")))
        return "%s%04d" % (prefix, (last or 0) + 1)

    @classmethod
    async def _next_task_no(
        cls, db: AsyncSession, now: datetime, seq: int
    ) -> str:
        """生成任务号 LT + YYYYMMDD + 5 位。"""
        prefix = "LT" + now.strftime("%Y%m%d")
        last = await db.scalar(
            select(func.count(M13LabTask.id)).where(
                M13LabTask.task_no.like(prefix + "%")))
        return "%s%05d" % (prefix, (last or 0) + seq)

    @classmethod
    async def _next_specimen_no(
        cls, db: AsyncSession, now: datetime
    ) -> str:
        """生成标本条码 SPL + YYYYMMDD + 5 位。"""
        prefix = "SPL" + now.strftime("%Y%m%d")
        last = await db.scalar(
            select(func.count(M13Specimen.id)).where(
                M13Specimen.specimen_no.like(prefix + "%")))
        seq = (last or 0) + 1
        if seq > 99999:
            raise BizException(
                "1301026", "当日标本条码已用尽")
        return "%s%05d" % (prefix, seq)

    @classmethod
    async def _specimens_of(
        cls, db: AsyncSession, request_id: int
    ) -> List[Dict[str, Any]]:
        """取申请单下的标本摘要。"""
        rows = (await db.execute(
            select(M13Specimen).where(
                M13Specimen.request_id == request_id,
                M13Specimen.is_deleted.is_(False),
            ).order_by(M13Specimen.tube_seq))).scalars().all()
        out: List[Dict[str, Any]] = []
        for s in rows:
            cnt = await db.scalar(
                select(func.count(M13SpecimenTaskRel.id)).where(
                    M13SpecimenTaskRel.specimen_id == s.id))
            out.append({
                "specimen_no": s.specimen_no,
                "specimen_type": s.specimen_type,
                "container_type": s.container_type,
                "collect_volume": float(s.collect_volume),
                "delivery_minutes": s.delivery_minutes,
                "task_count": cnt or 0,
            })
        return out

    @classmethod
    async def cancel(
        cls, db, user, request_id: int, body
    ) -> Dict[str, Any]:
        """取消申请（仅当所有标本均未采集）。"""
        req = await db.scalar(
            select(M13LabRequest).where(
                M13LabRequest.id == request_id,
                M13LabRequest.is_deleted.is_(False)))
        if req is None:
            raise BizException("1301001", "检验申请不存在")
        if req.status == "CANCELLED":
            raise BizException(
                "1301004", "申请单已取消，不可重复操作")

        collected = await db.scalar(
            select(func.count(M13Specimen.id)).where(
                M13Specimen.request_id == request_id,
                M13Specimen.status.notin_(
                    ["PENDING", "CANCELLED"])))
        if collected:
            raise BizException(
                "1301004",
                "已有 %d 管标本采集，不可取消申请" % collected)

        now = datetime.now()
        req.status = "CANCELLED"
        req.cancelled_at = now
        req.cancel_reason = body.reason
        await db.execute(
            update(M13Specimen).where(
                M13Specimen.request_id == request_id,
                M13Specimen.status == "PENDING",
            ).values(status="CANCELLED", cancelled_at=now))
        await db.execute(
            update(M13LabTask).where(
                M13LabTask.request_id == request_id,
                M13LabTask.status == "PENDING_COLLECT",
            ).values(status="CANCELLED"))
        await db.commit()
        return {
            "request_no": req.request_no,
            "status": "CANCELLED",
        }

async def _render_request_pdf(detail: Dict[str, Any]) -> bytes:
    """申请单 PDF 渲染（占位实现，实际用 reportlab）。"""
    lines = [
        "检验申请单 %s" % detail["request_no"],
        "患者: %s" % detail["patient"]["patient_name"],
    ]
    for it in detail["items"]:
        lines.append("  %s %s" % (it["lab_code"], it["lab_name"]))
    return ("\n".join(lines)).encode("utf-8")

class SpecimenService:
    """标本服务。"""

    @classmethod
    async def _get_for_update(
        cls, db, specimen_id: int
    ) -> M13Specimen:
        """加锁读取标本。"""
        s = await db.scalar(
            select(M13Specimen).where(
                M13Specimen.id == specimen_id,
                M13Specimen.is_deleted.is_(False),
            ).with_for_update())
        if s is None:
            raise BizException("1301021", "标本不存在")
        return s

    @classmethod
    def _check_transition(
        cls, current: str, target: str
    ) -> None:
        """状态机校验。"""
        allowed = SPECIMEN_TRANSITIONS.get(current, set())
        if target not in allowed:
            raise BizException(
                "1301007",
                "标本当前状态为 %s，不允许变更为 %s"
                % (STATUS_TEXT.get(current, current),
                   STATUS_TEXT.get(target, target)))

    @classmethod
    async def collect(
        cls, db, user, specimen_id: int, body
    ) -> Dict[str, Any]:
        """采集登记。"""
        s = await cls._get_for_update(db, specimen_id)
        # ① 状态校验
        cls._check_transition(s.status, "COLLECTED")

        # ② 缴费校验
        paid = await _is_paid(s.request_id)
        if not paid:
            raise BizException(
                "1301006", "检验费用未缴清，不可采集")

        # ③ 采集量校验
        cap = CONTAINER_CAPACITY.get(
            s.specimen_type, Decimal("1.0"))
        vol = Decimal(str(body.collect_volume))
        if vol <= 0 or (cap > 0 and vol > cap):
            raise BizException(
                "1301008",
                "采集量应在 0 ~ %s ml 之间" % cap)
        if s.collect_volume and vol < s.collect_volume * Decimal("0.8"):
            if not (body.remark or "").strip():
                raise BizException(
                    "1301009",
                    "采集量不足应采量的 80%%，必须填写原因说明")

        # ④ 采集部位
        if not (body.collect_site or "").strip():
            raise BizException("1301010", "采集部位未选择")

        # ⑤ 采集人
        if body.collect_by and body.collect_by != user.employee_id:
            raise BizException(
                "1301011", "采集人必须是当前登录用户")

        # ⑥ 写库
        now = datetime.now()
        s.status = "COLLECTED"
        s.actual_volume = money(vol)
        s.collect_site = body.collect_site
        s.collected_at = body.collect_at or now
        s.collected_by = user.employee_id
        s.collected_by_name = user.name
        s.collect_remark = body.remark
        s.delivery_deadline = (
            s.collected_at
            + timedelta(minutes=s.delivery_minutes or 120))

        # ⑦ 任务推进
        await db.execute(
            update(M13LabTask).where(
                M13LabTask.primary_specimen_id == s.id,
                M13LabTask.status == "PENDING_COLLECT",
            ).values(status="COLLECTED", collected_at=s.collected_at))

        db.add(M13SpecimenLog(
            biz_type="SPECIMEN", biz_id=s.id, action="COLLECT",
            operator_id=user.employee_id, operator_name=user.name,
            detail={"site": body.collect_site,
                    "volume": float(vol)},
            created_at=now))
        await db.commit()

        return {
            "specimen_id": s.id,
            "specimen_no": s.specimen_no,
            "status": s.status,
            "status_text": STATUS_TEXT.get(s.status),
            "delivery_deadline": s.delivery_deadline,
            "print_count": s.print_count,
            "barcode": cls._barcode_payload(s),
        }

    @classmethod
    def _barcode_payload(
        cls, s: M13Specimen
    ) -> Dict[str, Any]:
        """构造二维码内容。"""
        content = "%s|%d|%s|%s|%s" % (
            s.specimen_no, s.patient_id, s.request_no or "",
            s.specimen_type,
            str(s.collect_volume))
        return {
            "content": content,
            "label_text": "%s %s %sml %s" % (
                s.patient_name, s.specimen_type,
                s.collect_volume,
                s.created_at.strftime("%Y-%m-%d")
                if s.created_at else ""),
        }

    @classmethod
    async def batch_collect(
        cls, db, user, body
    ) -> Dict[str, Any]:
        """批量采集。"""
        results: List[Dict[str, Any]] = []
        failed: List[Dict[str, Any]] = []
        for item in body.items:
            try:
                r = await cls.collect(db, user, item.specimen_id, item)
                results.append(r)
            except BizException as exc:
                failed.append({
                    "specimen_id": item.specimen_id,
                    "code": exc.code,
                    "message": exc.message,
                })
        return {
            "success_count": len(results),
            "failed_count": len(failed),
            "items": results,
            "failed": failed,
        }

    @classmethod
    async def deliver(
        cls, db, user, body
    ) -> Dict[str, Any]:
        """送检登记。"""
        now = datetime.now()
        done: List[Dict[str, Any]] = []
        failed: List[Dict[str, Any]] = []
        for sid in body.specimen_ids:
            try:
                s = await cls._get_for_update(db, sid)
                cls._check_transition(s.status, "DELIVERED")
                if s.specimen_type in ("TEAR", "AQUEOUS", "VITREOUS"):
                    need_cold = True
                elif s.container_type and "冷藏" in s.container_type:
                    need_cold = True
                else:
                    need_cold = False
                if need_cold and body.temperature != "COLD":
                    raise BizException(
                        "1301012",
                        "标本 %s 需冷藏运送" % s.specimen_no)
                if not (body.courier_name or "").strip():
                    raise BizException("1301014", "运送员未选择")

                s.status = "DELIVERED"
                s.delivered_at = body.delivered_at or now
                s.delivered_by = user.employee_id
                s.delivered_by_name = user.name
                s.courier_name = body.courier_name
                s.transport_mode = body.transport_mode
                s.transport_temperature = body.temperature
                s.receive_dept = body.receive_dept

                await db.execute(
                    update(M13LabTask).where(
                        M13LabTask.primary_specimen_id == s.id,
                        M13LabTask.status == "COLLECTED",
                    ).values(status="DELIVERED",
                             delivered_at=s.delivered_at))
                db.add(M13SpecimenLog(
                    biz_type="SPECIMEN", biz_id=s.id,
                    action="DELIVER",
                    operator_id=user.employee_id,
                    operator_name=user.name,
                    detail={"courier": body.courier_name,
                            "temp": body.temperature},
                    created_at=now))
                done.append({
                    "specimen_no": s.specimen_no,
                    "status": "DELIVERED",
                })
            except BizException as exc:
                failed.append({
                    "specimen_id": sid,
                    "code": exc.code,
                    "message": exc.message,
                })
        await db.commit()
        return {
            "success_count": len(done),
            "failed_count": len(failed),
            "items": done,
            "failed": failed,
        }

    @classmethod
    async def accept(
        cls, db, user, specimen_id: int, body
    ) -> Dict[str, Any]:
        """签收。"""
        s = await cls._get_for_update(db, specimen_id)
        cls._check_transition(s.status, "ACCEPTED")
        if not _is_lab_staff(user):
            raise BizException("1301018", "无标本签收权限")

        now = datetime.now()
        s.status = "ACCEPTED"
        s.accepted_at = body.accepted_at or now
        s.accepted_by = user.employee_id

        s.appearance_check = {
            "volume": body.volume_check,
            "appearance": body.appearance,
            "hemolysis": body.is_hemolysis,

        await db.execute(
            update(M13LabTask).where(
                M13LabTask.primary_specimen_id == s.id,

        return {
            "specimen_no": s.specimen_no,
            "status": "ACCEPTED",
            "status_text": STATUS_TEXT.get("ACCEPTED"),
        }

    @classmethod
    async def reject(
        cls, db, user, specimen_id: int, body
    ) -> Dict[str, Any]:
        """拒收。"""
        s = await cls._get_for_update(db, specimen_id)
        cls._check_transition(s.status, "REJECTED")
        if not _is_lab_staff(user):
            raise BizException("1301018", "无标本签收权限")

        # ① 原因与说明
        if body.reject_reason not in REJECT_REASONS:
            raise BizException(
                "1301016", "拒收原因不合法")
        if len((body.reject_desc or "").strip()) < 10:
            raise BizException(
                "1301016", "拒收说明不少于 10 字")

        # ② 外观异常必须勾选
        if body.reject_reason == "HEMOLYSIS" and not body.is_hemolysis:
            raise BizException(
                "1301017", "拒收原因为溶血时必须勾选溶血")
        if body.reject_reason == "CLOTTED" and not body.is_clotted:
            raise BizException(
                "1301017", "拒收原因为凝块时必须勾选凝块")

        now = datetime.now()
        s.status = "REJECTED"
        s.rejected_at = now
        s.rejected_by = user.employee_id
        s.rejected_by_name = user.name
        s.reject_reason = body.reject_reason
        s.reject_desc = body.reject_desc
        s.reject_photos = body.photos or []

        # ③ 任务回退到待采集
        await db.execute(
            update(M13LabTask).where(
                M13LabTask.primary_specimen_id == s.id,
                M13LabTask.status.in_(["DELIVERED", "ACCEPTED"]),
            ).values(status="PENDING_COLLECT",
                     primary_specimen_id=None))

        # ④ 生成重采记录
        recollect = M13Recollect(
            recollect_no=await cls._next_recollect_no(db, now),
            request_id=s.request_id,
            request_no=s.request_no,
            patient_id=s.patient_id,
            patient_name=s.patient_name,
            origin_specimen_id=s.id,
            origin_specimen_no=s.specimen_no,
            specimen_type=s.specimen_type,
            reject_reason=body.reject_reason,
            reject_desc=body.reject_desc,
            status="PENDING",
            created_at=now,
        )
        db.add(recollect)
        await db.flush()

        db.add(M13SpecimenLog(
            biz_type="SPECIMEN", biz_id=s.id, action="REJECT",
            operator_id=user.employee_id, operator_name=user.name,
            detail={"reason": body.reject_reason,
                    "desc": body.reject_desc},
            created_at=now))
        await db.commit()

        task_count = await db.scalar(
            select(func.count(M13LabTask.id)).where(
                M13LabTask.request_id == s.request_id,
                M13LabTask.status == "PENDING_COLLECT"))

        # ⑤ 通知
        noted = False
        try:
            await MessageClient.send(
                target="NURSE_STATION",
                title="标本拒收需重采：%s" % s.patient_name,
                content="标本 %s 因 %s 被拒收，请重新采集"
                        % (s.specimen_no, body.reject_reason),
                biz_type="M13_RECOLLECT",
                biz_id=recollect.id)
            noted = True
        except Exception:
            logger.warning("通知护士站失败 specimen=%s", s.specimen_no)

        return {
            "specimen_no": s.specimen_no,
            "status": "REJECTED",
            "status_text": STATUS_TEXT.get("REJECTED"),
            "recollect_id": recollect.id,
            "recollect_no": recollect.recollect_no,
            "affected_task_count": task_count or 0,
            "notification": {
                "nurse_station": noted,
                "doctor_notified": True,
            },
        }

    @classmethod
    async def _next_recollect_no(
        cls, db: AsyncSession, now: datetime
    ) -> str:
        """重采单号 RC + YYYYMMDD + 4 位。"""
        prefix = "RC" + now.strftime("%Y%m%d")
        last = await db.scalar(
            select(func.count(M13Recollect.id)).where(
                M13Recollect.recollect_no.like(prefix + "%")))
        return "%s%04d" % (prefix, (last or 0) + 1)

    async def batch_accept(
        cls, db, user, body
    ) -> Dict[str, Any]:
        """批量签收。"""
        done: List[Dict[str, Any]] = []

            acc = type("A", (), {
                "volume_check": "SUFFICIENT",
                "appearance": "NORMAL",
                "is_hemolysis": False,
                "is_clotted": False,

            "success_count": len([d for d in done if "error" not in d]),
            "items": done,
        }

    async def list_specimens(
        cls, db, user, start_date, end_date, status, specimen_type,
        reject_reason, dept_id, page, page_size,
    ) -> Dict[str, Any]:
        """标本列表。"""
        if start_date and end_date:
            if (end_date - start_date).days > 366:
                raise BizException(
                    "1301015", "查询日期跨度不得超过 366 天")
        conds = [M13Specimen.is_deleted.is_(False)]
        if start_date:
            conds.append(M13Specimen.created_at >= start_date)
        if end_date:
            conds.append(
                M13Specimen.created_at
                < end_date + timedelta(days=1))
        if status:
            conds.append(M13Specimen.status == status)
        if specimen_type:
            conds.append(
                M13Specimen.specimen_type == specimen_type)
        if reject_reason:
            conds.append(
                M13Specimen.reject_reason == reject_reason)

        total = await db.scalar(
            select(func.count(M13Specimen.id)).where(*conds))
        rows = (await db.execute(
            select(M13Specimen).where(*conds)
            .order_by(M13Specimen.created_at.desc())
            .offset((page - 1) * page_size)
            .limit(page_size))).scalars().all()
        return {
            "items": [cls._dict(s) for s in rows],
            "total": total or 0,
            "page": page,
            "page_size": page_size,
        }

    @classmethod
    async def pending_collect(
        cls, db, user, dept_id, page, page_size
    ) -> Dict[str, Any]:
        """待采集列表（按患者归并）。"""
        conds = [
            M13Specimen.status == "PENDING",
            M13Specimen.is_deleted.is_(False),
        ]
        rows = (await db.execute(
            select(M13Specimen).where(*conds)
            .order_by(M13Specimen.created_at)
            .offset((page - 1) * page_size)
            .limit(page_size))).scalars().all()

        grouped: Dict[int, Dict[str, Any]] = {}
        for s in rows:
            g = grouped.setdefault(s.patient_id, {
                "patient_id": s.patient_id,
                "patient_name": s.patient_name,
                "visit_no": None,
                "specimen_ids": [],
                "specimen_count": 0,
                "requested_at": s.created_at,
            })
            g["specimen_ids"].append(s.id)
            g["specimen_count"] += 1
            if s.created_at and (
                    g["requested_at"] is None
                    or s.created_at < g["requested_at"]):
                g["requested_at"] = s.created_at

        return {
            "items": list(grouped.values()),
            "total": len(grouped),
            "page": page,
            "page_size": page_size,
        }

class RecollectService:

    @classmethod
    async def list_recollect(
        cls, db, user, status, start_date, end_date, page, page_size
    ) -> Dict[str, Any]:
        """重采列表。"""
        conds = [M13Recollect.is_deleted.is_(False)]
        if status:
            conds.append(M13Recollect.status == status)
        if start_date:
            conds.append(M13Recollect.created_at >= start_date)
        if end_date:
            conds.append(
                M13Recollect.created_at
                < end_date + timedelta(days=1))
        total = await db.scalar(
            select(func.count(M13Recollect.id)).where(*conds))
        rows = (await db.execute(
            select(M13Recollect).where(*conds)
            .order_by(M13Recollect.created_at.desc())
            .offset((page - 1) * page_size)
            .limit(page_size))).scalars().all()
        return {
            "items": [{
                "recollect_id": r.id,
                "recollect_no": r.recollect_no,
                "request_no": r.request_no,
                "patient_name": r.patient_name,
                "origin_specimen_no": r.origin_specimen_no,

                "reject_reason": r.reject_reason,
                "status": r.status,

            } for r in rows],
            "total": total or 0,

            "page_size": page_size,
        }

    @classmethod
    async def confirm(
        cls, db, user, recollect_id: int
    ) -> Dict[str, Any]:
        """确认重采：生成新标本。"""
        rc = await db.scalar(
            select(M13Recollect).where(
                M13Recollect.id == recollect_id,
                M13Recollect.is_deleted.is_(False),
            ).with_for_update())
        if rc is None:
            raise BizException("1301022", "重采记录不存在")
        if rc.status != "PENDING":
            raise BizException(
                "1301007", "重采记录状态不允许确认")

        now = datetime.now()
        origin = await db.scalar(
            select(M13Specimen).where(
                M13Specimen.id == rc.origin_specimen_id))
        spec_no = await LabRequestService._next_specimen_no(db, now)
        new_spec = M13Specimen(
            specimen_no=spec_no,
            request_id=rc.request_id,
            request_no=rc.request_no,
            patient_id=rc.patient_id,
            patient_name=rc.patient_name,
            specimen_type=rc.specimen_type,
            container_type=origin.container_type if origin else None,
            collect_volume=origin.collect_volume if origin else None,
            delivery_minutes=(
                origin.delivery_minutes if origin else 120),
            status="PENDING",
            print_count=0,
            tube_seq=(origin.tube_seq if origin else 1),
            parent_specimen_id=rc.origin_specimen_id,
            is_recollect=True,
            created_at=now,
        )
        db.add(new_spec)
        await db.flush()

        if origin:
            rels = (await db.execute(
                select(M13SpecimenTaskRel).where(
                    M13SpecimenTaskRel.specimen_id
                    == origin.id))).scalars().all()
            for rel in rels:
                db.add(M13SpecimenTaskRel(
                    specimen_id=new_spec.id,
                    task_id=rel.task_id,
                    lab_code=rel.lab_code,
                    created_at=now))
                await db.execute(
                    update(M13LabTask).where(
                        M13LabTask.id == rel.task_id,
                    ).values(primary_specimen_id=new_spec.id,
                             status="PENDING_COLLECT"))

        rc.status = "CONFIRMED"
        rc.new_specimen_id = new_spec.id
        rc.confirmed_at = now
        rc.confirmed_by = user.employee_id
        await db.commit()
        return {
            "recollect_no": rc.recollect_no,
            "new_specimen_id": new_spec.id,
            "new_specimen_no": spec_no,
        }

                M13Specimen.delivery_deadline.isnot(None),
                M13Specimen.delivery_deadline < (
                    now + timedelta(minutes=30)),
            ).order_by(M13Specimen.delivery_deadline)
            .limit(20))).scalars().all()
        alerts = []
        for a in alerts_rows:
            over = (now - a.delivery_deadline).total_seconds() / 60
            alerts.append({

            "total_requests": total_requests or 0,

    @classmethod
    async def statistics(
        cls, db, user, start_date, end_date, dept_id
    ) -> Dict[str, Any]:
        """周转统计。"""
        if (end_date - start_date).days > 366:
            raise BizException(
                "1301015", "查询日期跨度不得超过 366 天")
        start = datetime.combine(
            start_date, datetime.min.time())
        end = datetime.combine(
            end_date, datetime.min.time()) + timedelta(days=1)

        base = [
            M13Specimen.is_deleted.is_(False),
            M13Specimen.created_at >= start,
            M13Specimen.created_at < end,
        ]
        total = await db.scalar(
            select(func.count(M13Specimen.id)).where(*base))
        accepted = await db.scalar(
            select(func.count(M13Specimen.id)).where(
                *base, M13Specimen.status.in_(
                    ["ACCEPTED", "IN_PROCESS", "COMPLETED"])))
        rejected = await db.scalar(
            select(func.count(M13Specimen.id)).where(
                *base, M13Specimen.status == "REJECTED"))
        recollected = await db.scalar(
            select(func.count(M13Specimen.id)).where(
                *base, M13Specimen.is_recollect.is_(True)))
        overtime = await db.scalar(
            select(func.count(M13Specimen.id)).where(
                *base,
                M13Specimen.delivered_at.isnot(None),
                M13Specimen.delivery_deadline.isnot(None),
                M13Specimen.delivered_at
                > M13Specimen.delivery_deadline))

        avg_collect = await db.scalar(
            select(func.avg(
                func.extract(
                    "epoch",
                    M13Specimen.collected_at
                    - M13Specimen.created_at) / 60.0)).where(
                *base, M13Specimen.collected_at.isnot(None)))
        avg_deliver = await db.scalar(
            select(func.avg(
                func.extract(
                    "epoch",
                    M13Specimen.delivered_at
                    - M13Specimen.collected_at) / 60.0)).where(
                *base,
                M13Specimen.collected_at.isnot(None),
                M13Specimen.delivered_at.isnot(None)))

        reason_rows = (await db.execute(
            select(M13Specimen.reject_reason,
                   func.count(M13Specimen.id))
            .where(*base, M13Specimen.status == "REJECTED")
            .group_by(M13Specimen.reject_reason))).all()

        total_n = total or 0
        return {
            "start_date": start_date.isoformat(),
            "end_date": end_date.isoformat(),
            "total_specimens": total_n,
            "accepted": accepted or 0,
            "rejected": rejected or 0,
            "reject_rate": round(
                (rejected or 0) / total_n, 4) if total_n else 0,
            "overtime_count": overtime or 0,
            "overtime_rate": round(
                (overtime or 0) / total_n, 4) if total_n else 0,
            "recollect_count": recollected or 0,
            "recollect_rate": round(
                (recollected or 0) / total_n, 4) if total_n else 0,
            "avg_collect_minutes": round(
                float(avg_collect or 0), 1),
            "avg_deliver_minutes": round(
                float(avg_deliver or 0), 1),
            "reject_reasons": [
                {"reason": r[0], "count": r[1]}
                for r in reason_rows],
        }
```

### 6.7 专题：为什么标本归并是 M13-01 最难的部分

标本归并看起来是"把相同类型的项目放到一起"，实际要做到正确需要处理好六件事：

**① 抗凝剂比容差**

蓝帽枸橼酸管（凝血）要求血液与抗凝剂比例 **9:1**。如果采血量不足刻度线，抗凝剂相对过量，PT/APTT 会假性延长。所以凝血标本必须：

- 采足刻度（2.7ml）
- 不能与其他项目共用一管
- 不能因为"还差一点"而补采

这就是为什么 `PLASMA` 在 `SINGLE_ONLY` 集合里。

**② 血清与血浆不能混**

血清（红帽，无抗凝剂，凝固后离心）与血浆（蓝帽，有抗凝剂）的生化项目不同：

| 项目 | 适用 | 原因 |
|---|---|---|
| 血糖 | 两者均可 | 但血浆结果高 5~10%（红细胞内糖不释放） |
| 血钾 | **血浆** | 血清凝固时红细胞释放钾，假性升高 |
| 肝功能 | 两者均可 | 无显著差异 |

若浏览器把"血钾"项目错配到血清管，结果会偏高 0.3~0.5 mmol/L，可能误判高血钾。所以标本类型必须由 M01-09 主数据决定，不能由系统"猜"。

**③ 采血量要算余量**

血清促凝管容量 5ml，但离心后血清只有 40% 左右，即 5ml 全血只能得到 2ml 血清。一个生化全套 20 个项目，每个 200μL，需要 4ml 血清 —— **5ml 全血不够！**

所以算法里：

```
需要血清量 = 20 × 0.2 = 4.0 ml
需要全血量 = 4.0 / 0.4 = 10.0 ml
但一管只有 5 ml → 需要 2 管
```

这就是 `ITEM_CONSUME["SERUM"] = 0.20` 是**全血消耗量**而不是**血清消耗量**的原因，且已经隐含了 40% 血清产出率的换算。

**④ 冷运与常温不能混**

某些项目（血氨、乳酸）必须冰浴送检，冷藏项目不能与常温项目同管——温度会影响代谢。归并键必须包含 `need_refrigeration`。

**⑤ 立即送检不能等**

泪液、房水、玻璃体液的病原体检测，采集后 30 分钟内必须接种或送检，否则病原体死亡。这类标本绝不能与常规标本"攒批送检"。

**⑥ 患者不适叠管采血**

一位 70 岁老人静脉细弱，护士抽了 3 管已经很难。如果系统因为"容量不足"硬算出 5 管，护士要么硬抽（患者痛苦、可能溶血），要么请示医生减项。

所以算法要给出**明确理由**："需要 5 管，因为生化全套需要 XX ml，超出单管容量"。护士看到理由后可以选择"少做一个非关键项目"或"请示医生"。这就是为什么标本需求要按管列出 `task_lab_codes` —— 让护士和医生都看得见。

**实现方式：** 调用 M02-04 的 `apply_data_scope_to_stmt(stmt, Model, user, domain="DEPT")`。

### 9.4 安全措施

1. **脱敏**：标本列表默认显示患者姓名全称（医疗场景必要），但导出时对手机号脱敏（`138****5678`）。
2. **审计**：所有状态变更写 `m13_specimen_log`，仅增不改（DB 触发器保护）；所有敏感操作写 M02-06 审计。
3. **防重复提交**：采集/签收接口用 Redis 短锁 `m13:spec:lock:{id}`（30s）+ 行锁。
4. **条码防伪**：二维码内容包含标本号 + 患者 ID + 请求号，扫码后校验三者一致。
5. **证件号不打入条码**：条码只需患者 ID，避免泄露身份证号。
6. **权限最小化**：系统管理员无任何业务权限。

**为什么"采集人 ≠ 签收人"必须硬约束？**

这是防止"护士自己抽的血自己说合格"。虽然现实中检验科和护士站是两个部门，但接口层面必须兜住：签收时校验 `accepted_by <> collected_by`，DB 层加 `CHECK` 约束。

**U-05 缴费校验失败为什么放行？**

因为 M07-03 挂掉时，整个门诊都停了。此时护士仍然需要给患者采血（患者已经来了、已经在排队）。如果阻断，门诊会彻底瘫痪。

正确做法是：**放行并记 WARN**，同时在事后对账（每日 02:00 检查"未缴费但已采集"的标本）补偿。这是典型的"可用性优先于一致性"取舍。

## 11. 异常处理与日志

### 11.1 异常分类

| 类别 | 示例 | 处理 |
|---|---|---|
| **参数校验异常** | 采集量超容量、拒收说明不足 | 返回 400 + 错误码，不记录告警 |

| **业务规则异常** | 未缴费采集、无权限签收 | 返回 400/403，记录 INFO |

| **数据异常** | 标本不存在、条码重复 | 返回 404/500，记录 ERROR + 告警 |
| **并发异常** | 乐观锁冲突、行锁超时 | 返回 409，客户端重试 |

### 11.2 日志规范

```python

import logging

logger = logging.getLogger("m13.specimen")


def log_receive(request_no, order_no, task_count, specimen_count):

    """拒收日志（WARN 级别）。"""

        specimen_no, reason, desc, operator,
```
