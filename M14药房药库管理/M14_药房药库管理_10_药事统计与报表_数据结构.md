## 4. 数据结构设计

### 4.1 ER 关系图

```
┌───────────────────────────────────────────────────────────────────────────┐
│                    M14-10 药事统计与报表 ER 图                            │
└───────────────────────────────────────────────────────────────────────────┘

   ┌──────────────────────────────────┐
   │  m14_stat_daily                  │
   │  指标日聚合事实表（L1）          │
   ├──────────────────────────────────┤
   │ PK id                            │
   │ UK (stat_date, indicator_code,   │
   │     dim_key)                     │
   │    stat_date                     │
   │    indicator_code  ─────────┐    │
   │    indicator_name           │    │
   │    category                 │    │
   │    indicator_version        │    │
   │    dim_type / dim_key       │    │
   │    dim_name                 │    │

   │    indicator_value          │    │
   │    data_quality             │    │

   └──────────────────────────────────┘│
                                       │
   ┌──────────────────────────────────┐│
   │  m14_stat_indicator              │◄┘
   │  指标定义与评审条款              │
   ├──────────────────────────────────┤
   │ PK id                            │
   │ UK (indicator_code WHERE          │
   │     stat_type='INDICATOR')       │
   │ UK (period, chapter_code,        │
   │     item_code WHERE              │

   │    stat_type                     │
   │    indicator_code / item_code    │
   │    category / unit / direction   │
   │    formula / denominator_desc    │
   │    target_value / warn_value     │
   │    version / effective_date      │
   │    chapter_code / item_desc      │
   │    value / target_text           │
   │    is_auto / is_modified         │
   │    modified_reason               │
   │    source_indicator ─────────────┘
   └──────────────────────────────────┘

   ┌──────────────────────────────────┐
   │  m14_stat_report                 │
   │  报表快照（L3）                  │
   ├──────────────────────────────────┤
   │ PK id                            │
   │ UK (report_type, period WHERE    │
   │     status IN                    │
   │     ('GENERATING','GENERATED',   │
   │      'REPORTED'))                │
   │    report_type / report_name     │
   │    period_type / period          │
   │    scope                         │
   │    status / data_quality         │

   │    generated_at / reported_at    │
   │    report_no                     │
   └──────────────────────────────────┘
```

**设计说明：**

| 说明 | 理由 |
|---|---|
| **四张表全部无外键** | 统计表与业务表之间是弱关联；指标编码是业务常量不是外键；报表快照必须能独立存活（业务表数据归档后报表仍然可看） |
| `m14_stat_daily` 是唯一的事实来源 | L2/L3 都从 L1 派生，避免多处计算口径漂移 |
| `m14_stat_indicator` 一个表两种用途 | `stat_type` 区分「指标定义」与「评审条款」，两者结构相似（都有编码、名称、目标、值），分表会产生大量重复定义 |
| `m14_stat_report.content_json` 存完整快照 | 报表生成那一刻的数据被冻结；即使业务表后续变化，历史报表内容不变（审计要求） |
| 预聚合表不加 `deleted` 逻辑删除 | 统计表用 `is_deleted` 标记异常记录，但从不物理保留已作废的统计；重算时直接 UPSERT |

### 4.2 表：`m14_stat_daily`（指标日聚合事实表）

**表说明：** L1 粒度预聚合事实表。每个「日期 × 指标 × 维度」一行，存分子分母而非比率（比率查询时现算，避免汇总误差）。

| 字段名 | 类型 | 允许空 | 默认 | 说明 |
|---|---|---|---|---|
| id | BIGINT | N | IDENTITY | 主键 |
| stat_date | DATE | N | — | 统计日期 |
| stat_year | SMALLINT | N | — | 统计年份（生成列） |
| stat_month | CHAR(7) | N | — | 统计月份 YYYY-MM（生成列） |
| indicator_code | VARCHAR(16) | N | — | 指标编码，如 `A-04` |
| indicator_name | VARCHAR(64) | N | — | 指标名称（冗余快照） |
| category | CHAR(1) | N | — | 指标大类 A/B/C/D |
| indicator_version | SMALLINT | N | 1 | 指标口径版本 |
| dim_type | VARCHAR(16) | N | `TOTAL` | 维度类型 |
| dim_key | VARCHAR(64) | N | `ALL` | 维度键，如 `DEPT:01` |
| dim_name | VARCHAR(64) | N | — | 维度名称 |
| numerator | NUMERIC(18,4) | N | 0 | 分子 |
| denominator | NUMERIC(18,4) | N | 0 | 分母 |
| indicator_value | NUMERIC(12,4) | Y | NULL | 指标值（分母为 0 时为空） |
| data_quality | VARCHAR(16) | N | `COMPLETE` | 数据质量等级 |
| source_snapshot | JSONB | Y | NULL | 原始数据源返回摘要（用于复算核对） |
| created_at | TIMESTAMP | N | now() | 创建时间 |
| updated_at | TIMESTAMP | N | now() | 更新时间 |
| is_deleted | BOOLEAN | N | FALSE | 逻辑删除 |

**索引设计：**

| 索引名 | 类型 | 字段 | 说明 |
|---|---|---|---|
| `pk_m14_stat_daily` | 主键 | `id` | — |
| `uk_m14_stat_daily_key` | 唯一 | `(stat_date, indicator_code, dim_key)` | 幂等核心 |
| `idx_m14_stat_daily_code` | B-tree | `(indicator_code, stat_date)` | 单指标趋势查询 |
| `idx_m14_stat_daily_dim` | B-tree | `(dim_type, dim_key, stat_date)` | 维度分解查询 |
| `idx_m14_stat_daily_category` | B-tree | `(category, stat_date)` | 按大类查 |
| `idx_m14_stat_daily_quality` | 部分 | `(stat_date) WHERE data_quality <> 'COMPLETE'` | 数据质量异常扫描 |

**约束说明：**

```sql
-- 唯一约束：同一天同指标同维度只有一条
ALTER TABLE m14_stat_daily
    ADD CONSTRAINT uk_m14_stat_daily_key
    UNIQUE (stat_date, indicator_code, dim_key);

-- 大类枚举
ALTER TABLE m14_stat_daily
    ADD CONSTRAINT ck_m14_stat_daily_category
    CHECK (category IN ('A', 'B', 'C', 'D'));

-- 维度类型枚举
ALTER TABLE m14_stat_daily
    ADD CONSTRAINT ck_m14_stat_daily_dim_type
    CHECK (dim_type IN ('TOTAL', 'DEPT', 'DRUG_CAT',
                        'WARD', 'SURGICAL', 'PATIENT_TYPE'));

-- dim_key 必须带维度前缀（TOTAL 除外）
ALTER TABLE m14_stat_daily
    ADD CONSTRAINT ck_m14_stat_daily_dim_key
    CHECK (
        (dim_type = 'TOTAL' AND dim_key = 'ALL')
        OR (dim_type <> 'TOTAL' AND dim_key LIKE dim_type || ':%')
    );

-- 分子分母非负
ALTER TABLE m14_stat_daily
    ADD CONSTRAINT ck_m14_stat_daily_nonneg
    CHECK (numerator >= 0 AND denominator >= 0);

-- 分母为 0 时指标值必须为空，反之必须有值
ALTER TABLE m14_stat_daily
    ADD CONSTRAINT ck_m14_stat_daily_value
    CHECK (
        (denominator = 0 AND indicator_value IS NULL)
        OR (denominator > 0 AND indicator_value IS NOT NULL)
    );

-- 数据质量枚举
ALTER TABLE m14_stat_daily
    ADD CONSTRAINT ck_m14_stat_daily_quality
    CHECK (data_quality IN ('COMPLETE', 'PARTIAL',
                            'ESTIMATED', 'MISSING'));

-- 版本号正整数
ALTER TABLE m14_stat_daily
    ADD CONSTRAINT ck_m14_stat_daily_version
    CHECK (indicator_version >= 1);

-- 生成列
ALTER TABLE m14_stat_daily
    ADD COLUMN stat_year SMALLINT
    GENERATED ALWAYS AS (EXTRACT(YEAR FROM stat_date)::SMALLINT) STORED;

ALTER TABLE m14_stat_daily
    ADD COLUMN stat_month CHAR(7)
    GENERATED ALWAYS AS (TO_CHAR(stat_date, 'YYYY-MM')) STORED;
```

**数据特点：**

| 特点 | 说明 |
|---|---|
| 只增不删 | 历史事实保留，重算时 UPSERT 覆盖同日同指标同维度 |
| 存分子分母不存比率 | 跨日汇总时 `SUM(分子)/SUM(分母)` 才正确；`AVG(比率)` 是错的 |
| 生成列自动补齐年月 | 避免应用层算错月份 |
| `source_snapshot` 可选 | 只对复杂指标（如抗菌药物使用率）存原始摘要，便于复算核对 |

**量级估算：**

| 项 | 数值 |
|---|---|
| 指标数 | 32 个 |
| 维度组合数 | TOTAL 32 + DEPT 32×12 + DRUG_CAT 20×8 + WARD 15×5 + 其他 30 ≈ 600 |
| 日增量 | 约 600 行 |
| 年增量 | 219,000 行 |
| 单行大小 | 约 600 B |
| 5 年总量 | 1,095,000 行，约 630 MB |

**分区：** 按 `stat_date` 年度 RANGE 分区，预建 5 年 + 每年自动建下一年分区。

### 4.3 表：`m14_stat_monthly`（指标月聚合事实表）

**表说明：** L2 粒度，从 `m14_stat_daily` 汇总。趋势图、年度对比、报表取数都读这张表。

| 字段名 | 类型 | 允许空 | 默认 | 说明 |
|---|---|---|---|---|
| id | BIGINT | N | IDENTITY | 主键 |
| stat_month | CHAR(7) | N | — | 统计月份 YYYY-MM |
| stat_year | SMALLINT | N | — | 统计年份 |
| indicator_code | VARCHAR(16) | N | — | 指标编码 |
| indicator_name | VARCHAR(64) | N | — | 指标名称 |
| category | CHAR(1) | N | — | 指标大类 |
| indicator_version | SMALLINT | N | 1 | 指标口径版本 |
| dim_type | VARCHAR(16) | N | `TOTAL` | 维度类型 |
| dim_key | VARCHAR(64) | N | `ALL` | 维度键 |
| dim_name | VARCHAR(64) | N | — | 维度名称 |
| numerator | NUMERIC(20,4) | N | 0 | 月累计分子 |
| denominator | NUMERIC(20,4) | N | 0 | 月累计分母 |
| indicator_value | NUMERIC(12,4) | Y | NULL | 指标值 |
| data_quality | VARCHAR(16) | N | `COMPLETE` | 数据质量等级 |
| day_count | SMALLINT | N | 0 | 参与汇总的天数 |
| created_at | TIMESTAMP | N | now() | 创建时间 |
| updated_at | TIMESTAMP | N | now() | 更新时间 |
| is_deleted | BOOLEAN | N | FALSE | 逻辑删除 |

**索引设计：**

| 索引名 | 类型 | 字段 | 说明 |
|---|---|---|---|
| `pk_m14_stat_monthly` | 主键 | `id` | — |
| `uk_m14_stat_monthly_key` | 唯一 | `(stat_month, indicator_code, dim_key)` | 幂等核心 |
| `idx_m14_stat_monthly_code` | B-tree | `(indicator_code, stat_month)` | 趋势图取数 |
| `idx_m14_stat_monthly_year` | B-tree | `(stat_year, category)` | 年度对比 |
| `idx_m14_stat_monthly_dim` | B-tree | `(dim_type, dim_key, stat_month)` | 维度分解 |

**约束说明：**

```sql
ALTER TABLE m14_stat_monthly
    ADD CONSTRAINT uk_m14_stat_monthly_key
    UNIQUE (stat_month, indicator_code, dim_key);

ALTER TABLE m14_stat_monthly
    ADD CONSTRAINT ck_m14_stat_monthly_month
    CHECK (stat_month ~ '^[0-9]{4}-(0[1-9]|1[0-2])$');

ALTER TABLE m14_stat_monthly
    ADD CONSTRAINT ck_m14_stat_monthly_category
    CHECK (category IN ('A', 'B', 'C', 'D'));

ALTER TABLE m14_stat_monthly
    ADD CONSTRAINT ck_m14_stat_monthly_nonneg
    CHECK (numerator >= 0 AND denominator >= 0);

ALTER TABLE m14_stat_monthly
    ADD CONSTRAINT ck_m14_stat_monthly_value
    CHECK (
        (denominator = 0 AND indicator_value IS NULL)
        OR (denominator > 0 AND indicator_value IS NOT NULL)
    );

ALTER TABLE m14_stat_monthly
    ADD CONSTRAINT ck_m14_stat_monthly_days
    CHECK (day_count >= 0 AND day_count <= 31);

ALTER TABLE m14_stat_monthly
    ADD CONSTRAINT ck_m14_stat_monthly_quality
    CHECK (data_quality IN ('COMPLETE', 'PARTIAL',
                            'ESTIMATED', 'MISSING'));
```

**设计说明：**

| 说明 | 理由 |
|---|---|
| `day_count` 单独存 | 判断「这个月有几天的数据是完整的」；分母是月累计但只有 20 天数据时必须能看出来 |
| `NUMERIC(20,4)` 比日表宽 2 位 | 月累计可能超过 18 位整数部分（如费用类指标单位为元） |
| 不分区 | 年增 7,200 行，5 年 36,000 行，单表毫无压力 |

**量级估算：**

| 项 | 数值 |
|---|---|
| 月增量 | 约 600 行 |
| 年增量 | 7,200 行 |
| 单行大小 | 约 500 B |
| 5 年总量 | 36,000 行，约 18 MB |

### 4.4 表：`m14_stat_indicator`（指标定义与评审条款）

**表说明：** 一个表承担两种用途——`stat_type='INDICATOR'` 存指标定义（公式、目标、版本），`stat_type='ACCREDITATION'` 存等级评审条款填报值。

| 字段名 | 类型 | 允许空 | 默认 | 说明 |
|---|---|---|---|---|
| id | BIGINT | N | IDENTITY | 主键 |
| stat_type | VARCHAR(16) | N | — | `INDICATOR` / `ACCREDITATION` |
| indicator_code | VARCHAR(16) | Y | NULL | 指标编码（INDICATOR 必填） |
| indicator_name | VARCHAR(128) | N | — | 指标/条款名称 |
| category | CHAR(1) | Y | NULL | 指标大类 A/B/C/D |
| unit | VARCHAR(16) | Y | NULL | 单位 `%` / `天` / `次` |
| direction | VARCHAR(8) | Y | NULL | `UP` / `DOWN` / `RANGE` |
| formula | VARCHAR(512) | Y | NULL | 计算公式文字描述 |
| denominator_desc | VARCHAR(512) | Y | NULL | 统计口径说明 |
| sources | JSONB | Y | NULL | 数据来源表清单 |
| target_value | NUMERIC(12,4) | Y | NULL | 目标值 |
| warn_value | NUMERIC(12,4) | Y | NULL | 警戒值 |
| version | SMALLINT | N | 1 | 口径版本 |
| effective_date | DATE | Y | NULL | 版本生效日期 |
| is_enabled | BOOLEAN | N | TRUE | 是否启用 |
| period | VARCHAR(8) | Y | NULL | 评审周期（ACCREDITATION 必填） |
| chapter_code | VARCHAR(16) | Y | NULL | 评审章节编码 |
| chapter_name | VARCHAR(64) | Y | NULL | 评审章节名称 |
| item_code | VARCHAR(32) | Y | NULL | 评审条款编码 |
| item_desc | VARCHAR(512) | Y | NULL | 评审条款描述 |
| value | NUMERIC(14,4) | Y | NULL | 填报值 |
| target_text | VARCHAR(64) | Y | NULL | 目标文字，如 `≥95%` |
| is_auto | BOOLEAN | N | FALSE | 是否自动取数 |
| is_on_target | BOOLEAN | Y | NULL | 是否达标 |
| is_modified | BOOLEAN | N | FALSE | 是否人工修改过 |
| modified_reason | VARCHAR(512) | Y | NULL | 修改原因 |
| modified_by | BIGINT | Y | NULL | 修改人 |
| modified_at | TIMESTAMP | Y | NULL | 修改时间 |
| source_indicator | VARCHAR(16) | Y | NULL | 关联的指标编码 |
| created_at | TIMESTAMP | N | now() | 创建时间 |
| updated_at | TIMESTAMP | N | now() | 更新时间 |
| is_deleted | BOOLEAN | N | FALSE | 逻辑删除 |

**索引设计：**

| 索引名 | 类型 | 字段 | 说明 |
|---|---|---|---|
| `pk_m14_stat_indicator` | 主键 | `id` | — |
| `uk_m14_stat_indicator_code` | 部分唯一 | `(indicator_code) WHERE stat_type='INDICATOR' AND is_deleted=FALSE` | 指标编码唯一 |
| `uk_m14_stat_indicator_item` | 部分唯一 | `(period, chapter_code, item_code) WHERE stat_type='ACCREDITATION' AND is_deleted=FALSE` | 评审条款唯一 |
| `idx_m14_stat_indicator_type` | B-tree | `(stat_type, category)` | 按类型分类查 |
| `idx_m14_stat_indicator_period` | B-tree | `(period, chapter_code)` | 按评审周期查 |
| `idx_m14_stat_indicator_source` | B-tree | `(source_indicator) WHERE source_indicator IS NOT NULL` | 取数时反向定位 |

**约束说明：**

```sql
-- 类型枚举
ALTER TABLE m14_stat_indicator
    ADD CONSTRAINT ck_m14_stat_indicator_type
    CHECK (stat_type IN ('INDICATOR', 'ACCREDITATION'));

-- INDICATOR 与 ACCREDITATION 各自必填项
ALTER TABLE m14_stat_indicator
    ADD CONSTRAINT ck_m14_stat_indicator_fields
    CHECK (
        (stat_type = 'INDICATOR'
            AND indicator_code IS NOT NULL
            AND category IS NOT NULL
            AND unit IS NOT NULL
            AND direction IS NOT NULL)
        OR (stat_type = 'ACCREDITATION'
            AND indicator_code IS NULL
            AND period IS NOT NULL
            AND chapter_code IS NOT NULL
            AND item_code IS NOT NULL)
    );

-- 大类枚举
ALTER TABLE m14_stat_indicator
    ADD CONSTRAINT ck_m14_stat_indicator_category
    CHECK (category IS NULL OR category IN ('A', 'B', 'C', 'D'));

-- 方向枚举
ALTER TABLE m14_stat_indicator
    ADD CONSTRAINT ck_m14_stat_indicator_direction
    CHECK (direction IS NULL
           OR direction IN ('UP', 'DOWN', 'RANGE'));

-- 版本号正整数
ALTER TABLE m14_stat_indicator
    ADD CONSTRAINT ck_m14_stat_indicator_version
    CHECK (version >= 1);

-- 百分比类指标目标值必须在 0~100
ALTER TABLE m14_stat_indicator
    ADD CONSTRAINT ck_m14_stat_indicator_target
    CHECK (unit <> '%' OR target_value IS NULL
           OR (target_value >= 0 AND target_value <= 100));

-- 人工修改必须填原因且不少于 10 字
ALTER TABLE m14_stat_indicator
    ADD CONSTRAINT ck_m14_stat_indicator_modified
```

```sql
RETURNS TRIGGER AS $$
BEGIN
    IF NEW.version < OLD.version THEN
        RAISE EXCEPTION '指标版本号必须递增：% -> %',
            OLD.version, NEW.version;
    END IF;
    IF NEW.version > OLD.version THEN

        END IF;
        IF NEW.effective_date < CURRENT_DATE THEN
            RAISE EXCEPTION '生效日期不得早于今天';
        END IF;
    END IF;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;
```

```sql
    ADD CONSTRAINT ck_m14_stat_report_quality
    CHECK (data_quality IN ('COMPLETE', 'PARTIAL',
                            'ESTIMATED', 'MISSING'));

-- 周期起止顺序

    ADD CONSTRAINT ck_m14_stat_report_range
    CHECK (period_end >= period_start);

-- 生成完成必须有内容与时间
ALTER TABLE m14_stat_report
    ADD CONSTRAINT ck_m14_stat_report_generated
    CHECK (
        status NOT IN ('GENERATED', 'REPORTED', 'ARCHIVED')
        OR (content_json IS NOT NULL AND generated_at IS NOT NULL)
    );

-- 上报必须有受理编号与时间
ALTER TABLE m14_stat_report
    ADD CONSTRAINT ck_m14_stat_report_reported
    CHECK (
        status <> 'REPORTED'
        OR (report_no IS NOT NULL
            AND reported_at IS NOT NULL
            AND reported_by IS NOT NULL)
    );

-- 失败必须有原因
ALTER TABLE m14_stat_report
    ADD CONSTRAINT ck_m14_stat_report_fail
    CHECK (status <> 'FAILED' OR fail_reason IS NOT NULL);
```

**设计说明：**

| 说明 | 理由 |
|---|---|
| `content_json` 存完整快照 | 报表是「某一时刻的数据切面」；业务表变化后重算会得出不同结果，但已发出的报表不能变 |
| 部分唯一索引含 `GENERATING/GENERATED/REPORTED` | 只有 `FAILED` 和 `ARCHIVED` 状态允许同周期存在多条（失败重试、归档后再生成） |
| `period` 用 VARCHAR 而非 DATE | 月/季/年三种周期的自然表达不同（`2026-10`、`2026-Q3`、`2025`），统一转 DATE 会丢失语义 |
| `version_note` | 跨指标口径版本时在报表上注明，避免被误比较 |

**自动建分区函数：**

```sql
CREATE OR REPLACE FUNCTION fn_m14_stat_daily_create_partition(
    p_year INTEGER)
RETURNS VOID AS $$
DECLARE
    v_partition TEXT;
    v_start DATE;
    v_end DATE;
BEGIN
    v_partition := 'm14_stat_daily_p' || p_year::TEXT;
    v_start := make_date(p_year, 1, 1);
    v_end := make_date(p_year + 1, 1, 1);
    IF NOT EXISTS (
        SELECT 1 FROM pg_class WHERE relname = v_partition
    ) THEN
        EXECUTE format(
            'CREATE TABLE %I PARTITION OF m14_stat_daily '
            'FOR VALUES FROM (%L) TO (%L)',
            v_partition, v_start, v_end);
    END IF;
END;
$$ LANGUAGE plpgsql;
```
