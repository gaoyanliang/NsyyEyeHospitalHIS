## 1. 模块概述

### 1.1 模块定位

M14-02 是药房药库的**决策层**。M14-01 记录"有多少"，M14-02 决定"该用哪一批、什么时候该预警、什么时候该补充、什么时候该处理掉"。

```
┌──────────────────────────────────────────────────────────────────────┐
│                       M14-01 库存台账（数量真相）                     │
│   m14_stock_batch（qty_on_hand / qty_locked / qty_available / status）│
└───────────────────────────────┬──────────────────────────────────────┘
                                │ 读批次与数量
                                ▼
┌──────────────────────────────────────────────────────────────────────┐
│                  M14-02 分配与效期（决策逻辑）                        │
│                                                                      │
│  ┌────────────────┐  ┌──────────────┐  ┌────────────┐  ┌──────────┐  │
│  │ 批次分配策略   │  │ 效期分级预警 │  │ 补货建议   │  │ 拆零管理 │  │
│  │ FEFO / 指定批  │  │ 90/30/过期   │  │ 再订货点   │  │ 拆零换算 │  │
│  └───────┬────────┘  └──────┬───────┘  └─────┬──────┘  └────┬─────┘  │
│          │                  │                │              │        │
└──────────┼──────────────────┼────────────────┼──────────────┼────────┘
           │                  │                │              │
           ▼                  ▼                ▼              ▼
    ┌────────────┐   ┌─────────────┐  ┌────────────┐  ┌──────────┐
    │ M14-07 发药│   │ 预警通知    │  │ M14-03 采购│  │ M14-01   │
    │ M14-08 摆药│   │ 促销/退换货 │  │ 补货单生成 │  │ 拆零流水 │
    └────────────┘   └─────────────┘  └────────────┘  └──────────┘
```

### 1.2 为什么独立成子模块

| 对比项 | 并入 M14-01 | 独立为 M14-02 |
|---|---|---|
| 职责边界 | 台账既要记数又要决策，代码耦合 | 台账只管记录，决策独立演进 |
| 变更频率 | 效期规则按药监政策调整，会牵动核心台账表 | 策略变更只改本子模块 |
| 测试难度 | 发药准确率与效期预警混在一起难定位 | 分配策略可单独用单元测试验证 |
| 眼科适配 | M14-01 是通用库存，M14-02 承载眼科特有的开封后效期 | 眼科特性集中一处 |

**一句话判断标准：** M14-01 回答"有多少"，M14-02 回答"用哪个、什么时候急、该补多少、怎么拆"。

### 1.3 与相邻子模块分工

| 能力 | M14-01 台账 | **M14-02 分配与效期** | M14-03 采购 | M14-07 发药 |
|---|---|---|---|---|
| 记录批次数量 | ✅ 唯一责任 | ❌ | ❌ | ❌ |
| 决定发哪一批 | ❌ | ✅ **唯一责任** | ❌ | ❌ 按返回结果执行 |
| 效期分级与预警 | ❌ 只存 `status` | ✅ **唯一责任** | ❌ | ❌ |
| 生成补货建议 | ❌ | ✅ **唯一责任** | ✅ 执行采购 | ❌ |
| 拆零换算与记录 | ✅ 写拆零流水 | ✅ **唯一责任** | ❌ | ❌ |
| 执行扣减 | ✅ 唯一责任 | ❌（只加锁） | ❌ | ❌ |

**关键分界：** M14-02 **不修改任何数量**。它只做三件事——选择、加锁、建议。真正的 `qty_on_hand` 变化仍由 M14-01 唯一入口完成。

### 1.4 概念辨析

| 概念 | 定义 | 示例 |
|---|---|---|
| **批次（Batch）** | 同厂家、同批号、同效期的一批药品 | 左氧氟沙星滴眼液 `240815` 批，效期 2026-08-14 |
| **效期分级** | 按剩余天数把批次分为四档 | 正常（>90天）、临近（31~90天）、警告（0~30天）、过期（<0天） |
| **FEFO** | First Expiry First Out，先到期先出 | 同一药品有 3 个批次，优先发效期最近的 |
| **再订货点** | 库存降到该值时触发补货 | 再订货点 50 盒，当前 48 盒 → 建议补货 |
| **拆零** | 把包装单位拆成最小单位发放 | 1 盒 10 支 → 拆成 2 支发给患者 |
| **开封效期** | 多剂量包装开封后的可用天数 | 玻璃酸钠滴眼液开封后 28 天，即使效期还有 1 年 |

### 1.5 模块目标

| 指标 | 目标值 | 测算口径 |
|---|---|---|
| 发药批次准确率 | ≥ 99.9% | 按 FEFO 应发的批次 = 实际发的批次占比 |
| 近效期漏报率 | 0 | 已进入警告期但未出现在预警列表的批次占比 |
| 药房过期药品损耗率 | ≤ 0.3% | 报废金额 / 期初库存金额 |
| 分配决策响应 | P95 ≤ 30ms | 单次 FEFO 分配的接口耗时 |
| 补货建议准确率 | ≥ 85% | 补货后未出现缺货的药品占比 |
| 拆零账实一致率 | 100% | 拆零后包装数与最小单位数换算校验通过率 |

## 3. 业务模型

### 3.1 批次分配模型

#### 3.1.1 五种分配策略

| 策略码 | 名称 | 排序规则 | 适用场景 |
|---|---|---|---|
| `FEFO` | 先到期先出 | `expiry_date ASC, batch_no ASC` | **默认**，所有常规发药 |
| `FIFO` | 先进先出 | `first_in_at ASC, batch_no ASC` | 无批次管理的药品 |
| `SPECIFIED` | 指定批号 | 按录入批号精确匹配 | 临床试验、特殊治疗 |
| `SPLIT_FIRST` | 拆零优先 | 已拆零批次优先，再 FEFO | 需要零散发量的科室 |
| `LARGEST_FIRST` | 大包装优先 | `qty_available DESC` | 批量出库、调拨 |

**策略选择优先级：**

```
① 处方/医嘱上明确指定批号  ──► SPECIFIED（最高优先级）
② 药品库存策略配置了默认策略 ──► 策略配置值
③ 科室参数配置了科室策略     ──► 科室策略
④ 以上都没有                ──► FEFO（系统默认）
```

#### 3.1.2 FEFO 分配算法

给定 `(warehouse_id, drug_id, need_qty)`，返回批次分配明细：

```
步骤 1：查询候选批次
  SELECT * FROM m14_stock_batch
   WHERE warehouse_id = :wid
     AND drug_id      = :did
     AND qty_available > 0
     AND status IN ('NORMAL','NEAR_EXPIRY')
     AND expiry_date > CURRENT_DATE
   ORDER BY expiry_date ASC, batch_no ASC
   FOR UPDATE SKIP LOCKED

步骤 2：逐批扣减
  remaining = need_qty
  result = []
  FOR batch IN candidates:
      take = MIN(remaining, batch.qty_available)
      IF take <= 0: CONTINUE
      result.append({batch_id, batch_no, expiry_date, qty: take})
      remaining -= take
      IF remaining == 0: BREAK

步骤 3：判断是否满足
  IF remaining > 0:
      RAISE 55251  "可用库存不足，缺口 {remaining} {unit}"
  RETURN result
```

**为什么用 `FOR UPDATE SKIP LOCKED` 而不是普通锁：**

眼科门诊高峰时段，同一瓶热门滴眼液可能在 5 个发药窗口同时被抢。普通 `FOR UPDATE` 会让后 4 个窗口排队等第一个窗口走完整个发药流程（约 3 秒），第 5 个窗口的患者要等 12 秒。

`SKIP LOCKED` 让后到的窗口跳过已被锁定的批次，直接看下一个效期稍远的批次。结果：

- 第 1 个窗口发最早到期的批次 ✅
- 第 2 个窗口发第二早到期的批次 ✅（FEFO 的"先到期先出"在并发下退化为近似，但不会错发过期药）
- 患者等待时间从 12 秒降到 3 秒

**用条件原子更新（方案 D）兜底：**

即使有 `SKIP LOCKED`，极端情况下仍可能两个事务选中同一批次。因此实际扣减时用带条件的原子更新：

```sql
UPDATE m14_stock_batch
   SET qty_locked = qty_locked + :qty,
       version    = version + 1,
       updated_at = CURRENT_TIMESTAMP
 WHERE id = :batch_id
   AND version = :version
   AND qty_available >= :qty
   AND status IN ('NORMAL','NEAR_EXPIRY')
RETURNING qty_locked, qty_on_hand
```

`rowcount = 0` 表示该批次已被别人抢先，重试下一批次（最多重试 3 次）。

#### 3.1.3 多批次组合规则

| 规则 | 内容 |
|---|---|
| R-01 | 单次分配最多组合 5 个批次，超出提示"请分次发放" |
| R-02 | 优先整包装发放，不足时才拆零 |
| R-03 | 拆零发放优先选择**已拆零批次**（避免开新盒） |
| R-04 | 冷链药品不允许跨批次混装发药（温度记录难追溯） |
| R-05 | 麻醉药品必须整包装发放，不允许拆零 |

### 3.2 效期分级模型

#### 3.2.1 四档分级

| 等级 | 判定条件 | 颜色 | 处理动作 |
|---|---|---|---|
| `NORMAL` 正常 | `days_to_expiry > alert_days`（默认 90） | 绿 | 无 |
| `NEAR_EXPIRY` 临近 | `warning_days < days_to_expiry <= alert_days`（30~90） | 黄 | 出现在效期预警列表 |
| `WARNING` 警告 | `0 < days_to_expiry <= warning_days`（0~30） | 橙 | 强提醒，需处理 |
| `EXPIRED` 过期 | `days_to_expiry <= 0` | 红 | **禁止发药**，进入待销毁流程 |

其中：

```
days_to_expiry = expiry_date - CURRENT_DATE
```

**关键设计：** `NEAR_EXPIRY` 与 `WARNING` 都在 `m14_stock_batch.status` 中占一档。但 M14-01 的表结构里 `status` 只有 `NORMAL/NEAR_EXPIRY/EXPIRED/HOLD/REJECTED/RECALLED/DESTROYED` 七态。

因此本模块约定：

- `NORMAL` ↔ `days_to_expiry > alert_days`
- `NEAR_EXPIRY` ↔ `days_to_expiry <= alert_days`（**包含警告期，即 ≤ 90 天**）
- `EXPIRED` ↔ `days_to_expiry <= 0`

而"警告期（≤30 天）"是**计算属性**，不落库，避免状态机爆炸。查询时用 `expiry_date <= CURRENT_DATE + warning_days` 过滤。

**为什么警告期不落状态：**

如果为警告期单独加一个 `WARNING` 状态，就要处理 `NORMAL → NEAR_EXPIRY → WARNING → EXPIRED` 的三次状态迁移，且 `HOLD` 与它们交叉（冻结的批次到期了算 `HOLD` 还是 `EXPIRED`？）。状态机组合爆炸后，每日巡检任务要写三层分支。

用"一个物理状态 `NEAR_EXPIRY` + 一个日期边界"表达，处理逻辑只有一句：

```python
warning = batch.expiry_date <= date.today() + timedelta(days=warning_days)
```

#### 3.2.2 分级阈值来源

| 阈值 | 来源优先级 |
|---|---|
| `expiry_alert_days`（默认 90） | ① M01-03 `mdm_drug_stock_policy.expiry_alert_days` ② 本模块 P06 全局配置 ③ 系统默认 90 |
| `expiry_warning_days`（默认 30） | ① M01-03 `mdm_drug_stock_policy.expiry_warning_days` ② 本模块 P06 全局配置 ③ 系统默认 30 |

**按药品类型差异化：**

| 药品类型 | 建议预警天数 | 理由 |
|---|---|---|
| 普通药品 | 90 / 30 | 标准 |
| 冷链药品 | 120 / 45 | 调拨受限，需更长时间处理 |
| 麻醉药品 | 180 / 60 | 退换流程复杂，需提前报备 |
| 高值药品 | 120 / 45 | 金额大，需提早促销或退厂 |
| 拆零药品 | 60 / 20 | 拆零后周转快，但开封效期才是真瓶颈 |

#### 3.2.3 开封效期

针对多剂量包装（滴眼液、瓶装液体）：

```
opened_expiry_date = opened_at + after_open_shelf_life 天
effective_expiry   = MIN(expiry_date, opened_expiry_date)
```

| 场景 | 判定 |
|---|---|
| 未开封 | `effective_expiry = expiry_date` |
| 已开封 | `effective_expiry = MIN(expiry_date, opened_expiry_date)` |
| 开封效期已到 | 视为过期，`status = EXPIRED`，禁止发药 |

**眼科特殊规则：** 滴眼液类药品`is_after_open_managed` 通常为 `TRUE`，`after_open_shelf_life` 常见值：

| 药品类别 | 开封效期 | 说明 |
|---|---|---|
| 玻璃酸钠滴眼液（多剂量） | 28 天 | 说明书标注 |
| 左氧氟沙星滴眼液 | 28 天 | 说明书标注 |
| 妥布霉素滴眼液 | 28 天 | 说明书标注 |
| 单剂量包装滴眼液 | 不适用 | 一次性使用 |
| 眼膏 | 30 天 | 说明书标注 |

**注意：开封是发药时的动作，不是在库动作。** 药房在库的多为整盒未开封。开封效期管理主要针对：

1. 病区备用药柜里的已开封药品
2. 门诊拆零后剩余支数
3. 手术室常备药

### 3.3 补货建议模型

#### 3.3.1 再订货点公式

```
再订货点 reorder_point = 日均消耗 × 采购提前期 + 安全库存
建议补货量 order_qty   = MAX_STOCK - (当前可用 + 在途 - 已锁定承诺)
```

其中：

- `日均消耗` = 最近 30 天出库数量 / 30（不足 30 天按实际天数）
- `采购提前期` = `mdm_drug_stock_policy.lead_time_days`（默认 7 天）
- `安全库存` = `mdm_drug_stock_policy.safety_stock`（默认 = 日均消耗 × 7）

#### 3.3.2 触发条件

| 条件码 | 判定 | 建议动作 |
|---|---|---|
| `BELOW_REORDER` | `qty_available + qty_in_transit <= reorder_point` | 补货至 `max_stock` |
| `BELOW_SAFETY` | `qty_available <= safety_stock` | **紧急补货**，补至 `max_stock` |
| `ZERO_STOCK` | `qty_available = 0` | **紧急补货 + 通知临床** |
| `ABOVE_MAX` | `qty_available > max_stock × 1.2` | 建议暂停采购/调拨出库 |
| `SLOW_MOVING` | 最近 90 天出库 = 0 且 `qty_available > 0` | 建议退货/调拨/促销 |

#### 3.3.3 补货量计算示例

```
某滴眼液：
  最近 30 天出库       = 420 盒
  日均消耗             = 14 盒/天
  lead_time_days       = 10 天
  safety_stock         = 100 盒
  max_stock            = 800 盒
  当前 qty_available   = 180 盒
  qty_in_transit       = 100 盒
  qty_locked           = 30 盒

reorder_point = 14 × 10 + 100 = 240 盒
current_total = 180 + 100 = 280 盒

280 > 240 → 不触发补货

若 qty_in_transit 为 0：
280 → 180 < 240 → 触发补货
order_qty = 800 - (180 + 0 - 30) = 800 - 150 = 650 盒
```

### 3.4 拆零模型

#### 3.4.1 拆零规则

| 字段 | 来源 | 说明 |
|---|---|---|
| `conversion_ratio` | M01-03 `mdm_drug.conversion_ratio` | 1 包装 = N 最小单位 |
| `is_split` | M01-03 `mdm_drug.is_split` | 是否允许拆零 |
| `min_unit` | M01-03 `mdm_drug.min_unit` | 最小单位名称 |

**不允许拆零的药品：**

- 麻醉药品、精神药品（法规要求整包装）
- 冷藏/冷冻药品（拆零后无法保持温度）
- 说明书标注"不可分割"的缓释、控释制剂
- 无菌包装眼膏（拆零后污染风险）

#### 3.4.2 拆零执行流程

```
① 药师发起拆零（发药时自动触发）
   ├─ need = 3 支，批次 qty_on_hand = 2 盒（= 20 支）
   └─ 选择拆零批次（已拆零批次优先）

② 校验
   ├─ is_split = TRUE？
   ├─ conversion_ratio > 1？
   ├─ 是否禁拆药品？
   └─ 拆零后剩余是否 ≥ 0？

③ 写流水（M14-01）
   ├─ SPLIT_OUT: 扣 -1 盒（包装）
   └─ SPLIT_IN:  加 +8 支（最小单位，剩余的部分）

④ 写拆零记录（M14-02 本模块）
   ├─ 源批次、目标批次、拆前拆后数量
   └─ 操作人、时间、原因

⑤ 发药扣减（M14-01）
   └─ DISPENSE_OUT: 扣 -3 支
```

**关键点：拆零是"一次减、一次加"，不是"减少一点"。**

1 盒 10 支，需要发 3 支：

- 扣：`SPLIT_OUT` -1 盒（整盒出库）
- 加：`SPLIT_IN` +10 支（整盒变成最小单位的 10 支）
- 扣：`DISPENSE_OUT` -3 支（发 3 支）
- 净变化：盒数 -1，支数 +7

如果只做"盒数 -0.3"，账面上就会出现"0.7 盒"这种无意义数量，且盘点时无法核对。

#### 3.4.3 最小单位批次的建立

拆零后生成一个新的批次记录（`m14_stock_batch`）：

| 字段 | 值 |
|---|---|
| `batch_no` | 原批号 + `-S`（如 `240815-S`） |
| `expiry_date` | 同原批次 |
| `package_unit` | `min_unit`（支/片/ml） |
| `specification` | 原规格 + `(拆零)` |
| `conversion_ratio` | 1（本身已是最小单位） |
| `remark` | 由批次 `xxx` 拆零而来 |

这样拆零批次与整包装批次物理隔离，查询时一眼能看出哪些是散装。

### 3.5 近效期处理动作

| 动作码 | 名称 | 适用 | 后续 |
|---|---|---|---|
| `OUTBOUND_FIRST` | 优先出库 | 剩余 30~90 天 | 系统自动在分配时前置该批次 |
| `RETURN_SUPPLIER` | 退厂 | 剩余 < 60 天且供应商接受 | 生成采购退货单（M14-03） |
| `TRANSFER_OUT` | 调拨 | 其他院区/药房有需求 | 生成调拨单（M14-04） |
| `PROMOTION` | 加速使用 | 剩余 < 30 天 | 通知临床、界面标记 |
| `DESTROY` | 报损销毁 | 已过期 | 生成报损单（M14-05） |

**处理优先级自动建议：**

```
if days_to_expiry <= 0:                      建议 DESTROY
elif days_to_expiry <= 30 and 供应商接受退货:  建议 RETURN_SUPPLIER（更优先）
elif days_to_expiry <= 30:                   建议 PROMOTION
elif days_to_expiry <= 60:                   建议 RETURN_SUPPLIER / TRANSFER_OUT
else:                                        建议 OUTBOUND_FIRST
```

### 6.6 Service 层核心逻辑

#### 6.6.1 AllocationService

```python
import uuid
from datetime import date, datetime, timedelta
from decimal import Decimal
from typing import List, Optional

from sqlalchemy import and_, or_, select, text

from app.core.cache import redis_client
from app.core.exceptions import BizError
from app.core.logging import logger
from app.modules.m14.models.allocation import M14AllocationTask
from app.modules.m14.models.stock import M14StockBatch
from app.modules.m14.services.stock_client import StockClient

DEFAULT_STRATEGY = "FEFO"
MAX_BATCHES = 5
LOCK_TTL_SECONDS = 1800
MAX_RETRY = 3


class AllocationService:
    """批次分配服务：决定发哪一批，但不改数量"""

    def __init__(self):
        self.client = StockClient()

    # ---------------- 试算 ----------------

    async def preview(self, body, user) -> dict:
        candidates = await self._load_candidates(body)
        items, shortage = self._allocate_by_strategy(
            candidates, body.need_qty, body.strategy,
            body.specified_batch_no)
        return {
            "warehouse_id": body.warehouse_id,
            "drug_id": body.drug_id,
            "need_qty": body.need_qty,
            "allocated_qty": body.need_qty - shortage,
            "satisfied": shortage == 0,
            "shortage_qty": shortage,
            "strategy": body.strategy,
            "items": items,
            "batch_count": len(items),
            "excluded_batches": self._excluded(candidates, items),
        }

    async def _load_candidates(self, body) -> List[M14StockBatch]:
        """加载候选批次，按策略排序后返回"""
        stmt = (
            select(M14StockBatch)
            .where(
                M14StockBatch.warehouse_id == body.warehouse_id,
                M14StockBatch.drug_id == body.drug_id,
                M14StockBatch.qty_available > 0,
                M14StockBatch.status.in_(["NORMAL", "NEAR_EXPIRY"]),
                M14StockBatch.expiry_date > date.today(),
                M14StockBatch.is_deleted.is_(False),
            )
        )
        rows = (await self._session().execute(stmt)).scalars().all()
        return self._sort_by_strategy(rows, body.strategy)

    def _sort_by_strategy(self, rows, strategy: str):
        if strategy == "FIFO":
            return sorted(rows, key=lambda r: (r.first_in_at, r.batch_no))
        if strategy == "SPLIT_FIRST":
            return sorted(
                rows,
                key=lambda r: (
                    0 if "-S" in (r.batch_no or "") else 1,
                    r.expiry_date,
                    r.batch_no))
        if strategy == "LARGEST_FIRST":
            return sorted(
                rows, key=lambda r: -r.qty_available)
        # FEFO 默认
        return sorted(rows, key=lambda r: (r.expiry_date, r.batch_no))

    def _allocate_by_strategy(
            self, candidates, need_qty, strategy,
            specified_batch_no: Optional[str]):
        """按策略逐批扣减，返回 (items, shortage)"""
        if strategy == "SPECIFIED" and specified_batch_no:
            candidates = [
                c for c in candidates
                if c.batch_no == specified_batch_no]
            if not candidates:
                raise BizError(
                    55253,
                    "批号 %s 在本仓库无可用库存" % specified_batch_no)

        items = []
        remaining = Decimal(need_qty)
        for batch in candidates:
            if remaining <= 0:
                break
            if len(items) >= MAX_BATCHES:
                raise BizError(
                    55255,
                    "单次分配最多 %d 个批次，请分次发放" % MAX_BATCHES)
            take = min(remaining, Decimal(batch.qty_available))
            if take <= 0:
                continue
            items.append({
                "batch_id": batch.id,
                "batch_no": batch.batch_no,
                "expiry_date": batch.expiry_date.isoformat(),
                "days_to_expiry": (batch.expiry_date - date.today()).days,
                "qty_available": str(batch.qty_available),
                "allocated_qty": str(take),
                "location_name": batch.location_code,
                "is_cold_chain": batch.is_cold_chain,
                "version": batch.version,
            })
            remaining -= take
        return items, remaining

    def _excluded(self, candidates, items) -> List[dict]:
        used = {i["batch_id"] for i in items}
        out = []
        for c in candidates:
            if c.id in used:
                continue
            out.append({
                "batch_id": c.id,
                "batch_no": c.batch_no,
                "expiry_date": c.expiry_date.isoformat(),
                "days_to_expiry": (
                    c.expiry_date - date.today()).days,
                "qty_available": str(c.qty_available),
                "exclude_reason": "效期更远，本次未用",
            })
        return out

    # ---------------- 预占 ----------------

    async def lock(self, body, user) -> dict:
        """分配并锁定：先试算，再逐个批次条件更新"""
        preview = await self.preview(body, user)
        if not preview["satisfied"]:
            raise BizError(
                55251,
                "可用库存不足，缺口 %s" % preview["shortage_qty"])

        lock_no = self._next_lock_no()
        locked = []
        for item in preview["items"]:
            ok = await self._lock_one(
                item["batch_id"], Decimal(item["allocated_qty"]),
                lock_no)
            if not ok:
                # 部分失败，回滚已锁的
                await self._rollback_locked(locked, lock_no)
                raise BizError(
                    55251,
                    "批次 %s 已被他人占用，请重试" % item["batch_no"])
            locked.append(item)

        expire_at = datetime.now() + timedelta(
            seconds=body.expire_seconds or LOCK_TTL_SECONDS)
        await self._save_task(lock_no, body, locked, expire_at)
        await redis_client.setex(
            "m14:alloc:lock:%s" % lock_no,
            body.expire_seconds or LOCK_TTL_SECONDS,
            "1")
        return {
            "lock_no": lock_no,
            "expire_at": expire_at.strftime("%Y-%m-%d %H:%M:%S"),
            "items": [
                {
                    "batch_id": i["batch_id"],
                    "batch_no": i["batch_no"],
                    "allocated_qty": i["allocated_qty"],
                    "qty_available_after": str(
                        Decimal(i["qty_available"])
                        - Decimal(i["allocated_qty"])),
                }
                for i in locked
            ],
            "total_qty": str(sum(
                Decimal(i["allocated_qty"]) for i in locked)),
        }

    async def _lock_one(self, batch_id: int, qty: Decimal,
                        lock_no: str) -> bool:
        """带条件的原子更新，防止超发"""
        for _ in range(MAX_RETRY):
            sql = text(
                "UPDATE m14_stock_batch "
                "   SET qty_locked = qty_locked + :qty, "
                "       version = version + 1, "
                "       updated_at = CURRENT_TIMESTAMP "
                " WHERE id = :bid "
                "   AND qty_available >= :qty "
                "   AND status IN ('NORMAL','NEAR_EXPIRY') "
                "   AND is_deleted = FALSE")
            res = await self._session().execute(
                sql, {"qty": qty, "bid": batch_id})
            if res.rowcount == 1:
                return True
            logger.warning(
                "批次 %s 锁定失败，重试 %s", batch_id, _)
        return False

    async def _rollback_locked(self, items, lock_no: str):
        for item in items:
            sql = text(
                "UPDATE m14_stock_batch "
                "   SET qty_locked = qty_locked - :qty, "
                "       version = version + 1 "
                " WHERE id = :bid AND qty_locked >= :qty")
            await self._session().execute(
                sql, {"qty": Decimal(item["allocated_qty"]),
                      "bid": item["batch_id"]})

    def _next_lock_no(self) -> str:
        today = date.today().strftime("%Y%m%d")
        seq = redis_client.incr("m14:alloc:seq:%s" % today)
        if seq == 1:
            redis_client.expire(
                "m14:alloc:seq:%s" % today, 86400 * 2)
        return "LK%s%06d" % (today, seq % 1000000)

    # ---------------- 释放 / 消费 ----------------

    async def release(self, lock_no: str, body, user) -> dict:
        task = await self._get_task(lock_no)
        if not task:
            raise BizError(55257, "预占任务不存在")
        if task["status"] == "CONSUMED":
            raise BizError(55258, "预占任务已被消费，不能释放")
        released = await self._do_release(task)
        return {
            "lock_no": lock_no,
            "released_qty": released,
            "status": "RELEASED",
        }

    async def _do_release(self, task) -> str:
        total = Decimal("0")
        for item in task["items"]:
            sql = text(
                "UPDATE m14_stock_batch "
                "   SET qty_locked = qty_locked - :qty, "
                "       version = version + 1 "
                " WHERE id = :bid AND qty_locked >= :qty")
            await self._session().execute(
                sql, {"qty": Decimal(item["allocated_qty"]),
                      "bid": item["batch_id"]})
            total += Decimal(item["allocated_qty"])
        await self._update_task_status(task["lock_no"], "RELEASED")
        await redis_client.delete(
            "m14:alloc:lock:%s" % task["lock_no"])
        return str(total)

    async def consume_internal(self, body) -> dict:
        """确认消费：锁已转成实际出库，仅更新任务状态"""
        task = await self._get_task(body.lock_no)
        if not task:
            raise BizError(55257, "预占任务不存在")
        await self._update_task_status(body.lock_no, "CONSUMED")
        await redis_client.delete(
            "m14:alloc:lock:%s" % body.lock_no)
        return {"lock_no": body.lock_no, "status": "CONSUMED"}
```

```python
class ExpiryService:
    """效期管理服务"""

    async def list_alerts(self, q) -> tuple:
        today = date.today()
        cfg = await AllocationConfigService().get()
        alert_days = cfg["expiry_alert_days"]
        warning_days = cfg["expiry_warning_days"]

        )
        if q.warehouse_id:
            stmt = stmt.where(

        if q.only_cold_chain:
            stmt = stmt.where(M14StockBatch.is_cold_chain.is_(True))
        if q.keyword:
            like = "%%%s%%" % q.keyword
            stmt = stmt.where(or_(
                M14StockBatch.drug_name.like(like),
                M14StockBatch.drug_code.like(like),
                M14StockBatch.batch_no.like(like)))
        if q.level and q.level != "ALL":
            stmt = self._filter_by_level(
                stmt, q.level, today, warning_days)

        stmt = stmt.order_by(M14StockBatch.expiry_date.asc())
        total = await self._count(stmt)
        rows = await self._page(stmt, q.page, q.page_size)
        return [self._to_alert(r, today, warning_days) for r in rows], total

    def _filter_by_level(self, stmt, level, today, warning_days):
        if level == "EXPIRED":
            return stmt.where(
                M14StockBatch.expiry_date <= today)
        if level == "WARNING":
            return stmt.where(
                M14StockBatch.expiry_date > today,
                M14StockBatch.expiry_date
                <= today + timedelta(days=warning_days))
        # NEAR：已进入预警期但不在警告期
        return stmt.where(
            M14StockBatch.expiry_date
            > today + timedelta(days=warning_days))

    def _to_alert(self, b, today, warning_days) -> dict:
        days = (b.expiry_date - today).days
        if days <= 0:
            level, text = "EXPIRED", "已过期"
        elif days <= warning_days:
            level, text = "WARNING", "警告"
        else:
            level, text = "NEAR_EXPIRY", "临近"
        action = self._suggest_action(days, b)
        return {
            "id": b.id,
            "level": level,
            "level_text": text,
            "warehouse_id": b.warehouse_id,
            "warehouse_name": b.warehouse_name,
            "drug_id": b.drug_id,
            "drug_code": b.drug_code,
            "drug_name": b.drug_name,
            "specification": b.specification,
            "batch_no": b.batch_no,
            "expiry_date": b.expiry_date.isoformat(),
            "days_to_expiry": days,
            "qty_available": str(b.qty_available),
            "unit_cost": str(b.purchase_price or 0),
            "amount": str(
                round(Decimal(b.qty_available)
                      * Decimal(b.purchase_price or 0), 2)),
            "is_cold_chain": b.is_cold_chain,
            "suggested_action": action,
            "suggested_action_text": ACTION_TEXT[action],
        }

    def _suggest_action(self, days: int, batch) -> str:
        if days <= 0:
            return "DESTROY"
        if days <= 30:
            if batch.supplier_id and _supplier_accepts_return(
                    batch.supplier_id):
                return "RETURN_SUPPLIER"
            return "PROMOTION"
        if days <= 60:
            return "RETURN_SUPPLIER"
        return "OUTBOUND_FIRST"

    async def rescan(self, body, user) -> dict:
        """重算所有批次 status：NORMAL / NEAR_EXPIRY / EXPIRED"""
        cfg = await AllocationConfigService().get()
        alert_days = cfg["expiry_alert_days"]
        today = date.today()
        normal_to_near = await self._execute(text(
            "UPDATE m14_stock_batch "
            "   SET status = 'NEAR_EXPIRY', updated_at = NOW() "
            " WHERE status = 'NORMAL' AND expiry_date <= :d "
            "   AND is_deleted = FALSE"),
            {"d": today + timedelta(days=alert_days)})
        near_to_normal = await self._execute(text(
            "UPDATE m14_stock_batch "
            "   SET status = 'NORMAL', updated_at = NOW() "
            " WHERE status = 'NEAR_EXPIRY' AND expiry_date > :d "
            "   AND is_deleted = FALSE"),
            {"d": today + timedelta(days=alert_days)})
        to_expired = await self._execute(text(
            "UPDATE m14_stock_batch "
            "   SET status = 'EXPIRED', updated_at = NOW() "
            " WHERE status IN ('NORMAL','NEAR_EXPIRY') "
            "   AND expiry_date <= :d AND is_deleted = FALSE"),
            {"d": today})
        await redis_client.delete("m14:expiry:summary:*")
        return {
            "normal_to_near": normal_to_near,
            "near_to_normal": near_to_normal,
            "to_expired": to_expired,
            "scanned_at": datetime.now().strftime("%Y-%m-%d %H:%M:%S"),
        }

    async def handle(self, body, user) -> dict:
        batch = await self._get_batch(body.batch_id)
        if not batch:
            raise BizError(55257, "批次不存在")
        if body.handle_qty > batch.qty_available:
            raise BizError(55259, "处理数量超出可用数量")
        if body.action == "RETURN_SUPPLIER":
            if batch.expiry_date <= date.today():
                raise BizError(55261, "已过期批次不可退厂")
            ratio = await self._supplier_return_ratio(batch)
            if body.return_ratio and body.return_ratio > ratio:
                raise BizError(55260, "退厂比例超出供应商协议")
        if body.action == "TRANSFER_OUT":
            ok = await self._target_has_cold_chain(
                body.target_warehouse_id, batch.is_cold_chain)
            if not ok:
                raise BizError(55262, "目标仓库无冷链资质")
        record = await self._create_handle(body, batch, user)
        return record
```

```python
class ReplenishService:
    """补货建议服务"""

    async def calc_for_warehouse(self, warehouse_id: int) -> List[dict]:
        """计算某仓库所有药品的补货建议"""
        cfg = await AllocationConfigService().get()
        usage_days = cfg["usage_days"]
        today = date.today()
        start = today - timedelta(days=usage_days)

        usage = await self._daily_usage(warehouse_id, start, today)
        stocks = await self._stock_summary(warehouse_id)
        policies = await self._load_policies(
            [s["drug_id"] for s in stocks])

        out = []
        for s in stocks:
            p = policies.get(s["drug_id"]) or {}
            avg_daily = usage.get(s["drug_id"], Decimal("0")) / usage_days
            lead_time = p.get("lead_time_days") or cfg["lead_time_days"]
            safety = p.get("safety_stock")
            if safety is None:
                safety = avg_daily * cfg["safety_days"]
            max_stock = p.get("max_stock") or (
                avg_daily * (lead_time + cfg["safety_days"]) * 3)
            reorder = avg_daily * lead_time + safety

            total = (Decimal(s["qty_available"])
                     + Decimal(s["qty_in_transit"]))
            trigger = self._judge_trigger(
                total, avg_daily, reorder, safety, max_stock, usage_days)
            if trigger is None:
                continue
            suggest = max_stock - (
                Decimal(s["qty_available"])
                + Decimal(s["qty_in_transit"])
                - Decimal(s["qty_locked"]))
            week_use = avg_daily * 7
            suggest = max(suggest, week_use)
            if suggest <= 0:
                continue
            out.append({
                "drug_id": s["drug_id"],
                "drug_code": s["drug_code"],
                "drug_name": s["drug_name"],
                "warehouse_id": warehouse_id,
                "qty_available": s["qty_available"],
                "qty_in_transit": s["qty_in_transit"],
                "qty_locked": s["qty_locked"],
                "avg_daily_usage": float(round(avg_daily, 2)),
                "lead_time_days": lead_time,
                "safety_stock": str(safety),
                "reorder_point": str(round(reorder, 2)),
                "max_stock": str(max_stock),
                "suggested_qty": str(round(suggest, 2)),
                "unit_price": str(p.get("current_price") or 0),
                "trigger_type": trigger,
                "priority": self._priority(trigger),
            })
        return out

    def _judge_trigger(self, total, avg_daily, reorder,
                       safety, max_stock, usage_days):
        if total <= 0:
            return "ZERO_STOCK"
        if total <= safety:
            return "BELOW_SAFETY"
        if total <= reorder:
            return "BELOW_REORDER"
        if avg_daily == 0 and total > max_stock * Decimal("1.2"):
            return "SLOW_MOVING"
        return None

    def _priority(self, trigger: str) -> str:
        return {
            "ZERO_STOCK": "HIGH",
            "BELOW_SAFETY": "HIGH",
            "BELOW_REORDER": "MEDIUM",
            "ABOVE_MAX": "LOW",
            "SLOW_MOVING": "LOW",
        }.get(trigger, "MEDIUM")
```

```python
class SplitService:
    """拆零服务"""

    FORBIDDEN_CATEGORIES = {"NARCOTIC", "PSYCHOTROPIC", "COLD_CHAIN"}

    async def execute(self, body, user) -> dict:

        if not batch:
            raise BizError(55257, "批次不存在")
        drug = await self._get_drug(batch.drug_id)
        if not drug.get("is_split"):
            raise BizError(55254, "该药品不允许拆零")
        ratio = Decimal(drug.get("conversion_ratio") or 1)
        if ratio <= 1:
            raise BizError(55266, "该药品换算比无效，无法拆零")
        if self._is_forbidden(drug):
            raise BizError(55254, "麻精药品/冷链药品不允许拆零")
        if body.split_qty > batch.qty_available:
            raise BizError(55267, "拆零数量超出可拆范围")

        base_units = body.split_qty * ratio
        split_out = await self.client.apply(StockApply(
            txn_type="SPLIT_OUT", direction="OUT",
            warehouse_id=batch.warehouse_id,
            drug_id=batch.drug_id, batch_id=batch.id,

            operator_id=user["id"], operator_name=user["name"],
            remark="拆零出库"))

            batch, drug, body.split_qty)

            source_id=body.source_id,
            operator_id=user["id"], operator_name=user["name"],
            remark="拆零入库"))
        split_no = await self._save_record(

        return {
            "split_no": split_no,
            "source_batch_id": batch.id,
            "source_batch_no": batch.batch_no,
            "split_out_qty": str(body.split_qty),
            "split_out_unit": batch.package_unit,
            "split_in_qty": str(base_units),

                 "direction": "IN",
                 "qty": str(base_units),

        }

        if exist:

        new = await self._create_batch(

            purchase_price=(
                Decimal(batch.purchase_price or 0)
                / Decimal(drug.get("conversion_ratio") or 1)),
            is_cold_chain=batch.is_cold_chain,
        )
        return {"batch_id": new.id, "batch_no": new.batch_no}
```

```python
def sort_candidates(rows, strategy: str) -> list:
    """按策略排序候选批次"""
    if strategy == "FIFO":
        return sorted(rows, key=lambda r: (r.first_in_at, r.batch_no))
    if strategy == "SPLIT_FIRST":
        return sorted(rows, key=lambda r: (
            0 if "-S" in (r.batch_no or "") else 1,
            r.expiry_date, r.batch_no))
    if strategy == "LARGEST_FIRST":
        return sorted(rows, key=lambda r: -r.qty_available)
    if strategy == "SPECIFIED":
        return sorted(rows, key=lambda r: r.batch_no)
    return sorted(rows, key=lambda r: (r.expiry_date, r.batch_no))
```
