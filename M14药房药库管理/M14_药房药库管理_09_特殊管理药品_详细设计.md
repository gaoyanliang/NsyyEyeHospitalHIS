## 1. 模块概述

### 1.1 模块定位

M14-09 是**特殊管理药品的全生命周期监管子模块**。它回答四个问题：

1. **这批药现在在哪个柜子里？**（专柜专账，与普通库存物理隔离）
2. **这一支给了谁？**（逐支登记，精确到最小单位）
3. **谁和谁一起动的？**（双人双签，任何操作必须两个人）
4. **用剩的、用完的空瓶子去哪了？**（空安瓿回收、残液销毁）

### 1.2 为什么独立成子模块

**判断标准：** 如果一个业务在「数据完整性与留痕要求」上和普通业务有量级差异，就必须独立。

| 对比维度 | 普通药品 | 特殊管理药品 | 差异性质 |
|---|---|---|---|
| 数量精度 | 按盒/支（整数） | **按支/片/毫升逐单位** | 量级差异 |
| 操作人数 | 一人可完成 | **必须两人同时在场** | 制度强制 |
| 存储位置 | 普通货架 | **专用保险柜 + 双锁** | 物理隔离 |
| 记录形式 | 系统流水足够 | **系统 + 纸质专册双记** | 双重留痕 |
| 采购审批 | 部门审批 | **药监备案 + 印鉴卡** | 行政许可 |
| 处方权限 | 有处方权即可 | **专项培训 + 授权名单** | 资质限制 |
| 使用后处置 | 无要求 | **空安瓿必须回收、残液必须销毁** | 强制闭环 |
| 失窃处理 | 内部处理 | **24 小时内报药监 + 公安** | 法定时限 |
| 追溯要求 | 3 年 | **5 年（麻精）/ 永久（滥用监测）** | 时限差异 |

**四条核心差异：**

1. **数量精度到最小单位**
   麻醉药品的计量单位是「支」「片」「毫升」，不是「盒」。一支芬太尼 2ml 用掉 1.5ml，剩 0.5ml 去哪了必须有交代。普通药品不会有这种问题。

2. **必须是两个人的业务**
   这不是管理要求，是**法规强制**。《麻醉药品和精神药品管理条例》第三十八条：医疗机构应当「双人验收、双人复核、双人签字」。所有涉及麻精药品的实物移动，必须有两个不同的人。

3. **用完还得闭环**
   - 空安瓿：麻醉药品用完后，空安瓿必须回收，与处方逐支核对数量
   - 残液：芬太尼等注射剂用剩的部分必须由两人监督销毁并记录
   - 回收率是药监飞检的**必查项**

4. **失窃必须上报**
   普通药品丢失是内部问题；麻精药品丢失，**24 小时内必须报当地药监部门和公安机关**，逾期不报属于违法。

**如果合到其他子模块会怎样？**

- 合到 M14-07 门诊发药：住院、手术室、急诊的使用场景无法覆盖
- 合到 M14-01 库存台账：普通库存按「批次 × 仓库」管理，特殊药品要按「支」管理，且每次出入都要双人签字，表结构完全不同
- 合到 M14-04 出库与调拨：空安瓿回收、残液销毁、专册登记无处安放

### 1.3 与相邻子模块分工

| 子模块 | 负责 | M14-09 与其关系 |
|---|---|---|
| M01-03 药品主数据 | 判定药品是否属于特殊管理（`management_class`） | ✅ M14-09 只消费，不改判定 |
| M14-01 库存台账 | 库存数量与流水（批次维度） | ❌ M14-09 有独立的**专柜台账**，不参与普通库存计算 |
| M14-02 分配与效期 | FEFO 批次分配 | ❌ 特殊药品不参与自动分配，必须人工指定批次 |
| M14-03 采购入库 | 到货验收 | ✅ 特殊药品验收时**调 M14-09 登记专柜入库** |
| M14-04 出库调拨 | 出库、报损 | ✅ 报废销毁时**调 M14-09 登记销毁** |
| M14-06 处方审核 | 处方合规性审查 | ✅ 特殊药品规则在 M14-06 执行，M14-09 提供登记所需数据 |
| M14-07 门诊发药 | 门诊发药 | ✅ 发药时**调 M14-09 逐支登记 + 双人核验** |
| M14-08 住院药房 | 住院摆药 | ✅ 住院使用特殊药品时**调 M14-09 登记** |
| M07-05 处方与用药 | 开具处方 | ✅ M14-09 提供限量校验接口 |
| M14-10 药事统计 | 报表 | ✅ M14-09 提供专册数据供导出 |

**唯一责任边界一句话：**

> **M14-09 是特殊管理药品「实物在哪、给了谁、谁和谁一起动的、瓶子哪去了」的唯一记录方；普通库存数量由 M14-01 管，处方合规判断由 M14-06 管，M14-09 不管这两件事。**

### 1.4 概念辨析

| 概念 | 定义 | 与相近概念的区别 |
|---|---|---|
| **特殊管理药品** | 国家规定需要特殊管理的药品总称 | 包含麻精毒放四类 + 高危药品 |
| **麻醉药品** | 连续使用易成瘾的药品 | 与「麻醉用药」不同：麻醉用药是麻醉科用药（含普通药），麻醉药品是管制药品 |
| **精神药品** | 直接作用于中枢神经系统、连续使用产生依赖性的药品 | 分第一类和第二类，管理严格程度不同 |
| **毒性药品** | 毒性剧烈、治疗剂量与中毒剂量相近的药品 | 与「有毒」不同，是法定分类 |
| **高危药品** | 用药错误造成患者严重伤害的药品 | 不高危≠不管制，但**管理要求不同**（高危药品不需双人双签，只需高警示标识） |
| **专柜** | 特殊药品专用保险柜 | 与「专库存放」不同：专柜在药房内，专库是独立库房 |
| **专册** | 特殊药品专用登记簿 | 系统台账 + 纸质专册，两者必须一致 |
| **空安瓿** | 用完的玻璃药瓶 | 不是「垃圾」，是**核销凭证**，必须回收 |
| **残液** | 注射剂用剩的药液 | 必须双人监督销毁，不能倒掉完事 |
| **印鉴卡** | 麻醉药品购用印鉴卡 | 药监核发的购用资格凭证，采购必须登记卡号 |
| **双人双签** | 两个人各自签字确认 | 与「复核」不同：复核是一人做另一人检查，双签是**两人都在场、都确认** |

## 3. 业务模型

### 3.1 特殊药品分类模型

**六类特殊管理药品：**

| 类别 | 代码 | 别名 | 管理强度 | 双人双签 | 专柜 | 处方限量 | 空瓿回收 |
|---|---|---|---|---|---|---|---|
| 麻醉药品 | `NARCOTIC` | 麻醉药品 | ★★★★★ | ✅ | ✅ 麻精柜 | ✅ 严格 | ✅ |
| 第一类精神药品 | `PSYCHOTROPIC_1` | 精一 | ★★★★★ | ✅ | ✅ 麻精柜 | ✅ 严格 | ✅ |
| 第二类精神药品 | `PSYCHOTROPIC_2` | 精二 | ★★★★ | ✅ | ✅ 麻精柜 | ✅ 一般 | ✅ |
| 毒性药品 | `TOXIC` | 毒性药品 | ★★★★ | ✅ | ✅ 毒柜 | ✅ | ✅ |
| 放射性药品 | `RADIOACTIVE` | 放射药 | ★★★★★ | ✅ | ✅ 铅柜 | ✅ | ✅ |
| 高危药品 | `HIGH_RISK` | 高警示 | ★★ | ❌ | ⭕ 专区 | ❌ | ❌ |

**判定优先级（命中即停）：**

```
取 M01-03 mdm_drug 记录：
  1. is_radioactive = TRUE                     → RADIOACTIVE
  2. is_narcotic = TRUE                        → NARCOTIC
  3. management_class = 'PSYCHOTROPIC_1'       → PSYCHOTROPIC_1
  4. management_class = 'PSYCHOTROPIC_2'
     OR is_psychotropic = TRUE                 → PSYCHOTROPIC_2
  5. is_toxic = TRUE OR management_class='TOXIC' → TOXIC
  6. is_high_risk = TRUE                       → HIGH_RISK
  7. 其余                                       → NORMAL（非特殊管理）
```

> **为什么先判放射药？** 因为放射性药品可能同时是「麻醉药品」或「精神药品」（如放射性同位素标记药物），但管理要求以放射防护为准，优先判定。

**`HIGH_RISK` 为什么要单独列出？**

高危药品（如高浓度氯化钾、化疗药）不需要双人双签和专柜，但需要：
- 高警示标识（红底黑字）
- 独立存放专区
- 双人核对（不需要双签）

所以 M14-09 对高危药品只做**标识与专区管理**，不做逐支登记。若把高危药品按麻精管，会导致氯化钾这种常用药每次领取都要两人到场，严重影响效率。

### 3.2 专柜模型

```
┌──────────────────────────────────────────────────────────┐
│  药房（warehouse）                                        │
│  ┌────────────────────────────────────────────────────┐  │
│  │  普通货架区（M14-01 管理）                          │  │
│  └────────────────────────────────────────────────────┘  │
│  ┌────────────────────────────────────────────────────┐  │
│  │  专柜区（M14-09 管理）                              │  │
│  │                                                     │  │
│  │  ┌──────────────┐  ┌──────────────┐  ┌──────────┐ │  │
│  │  │ NARCOTIC     │  │ TOXIC        │  │ RADIO    │ │  │
│  │  │ 麻精保险柜   │  │ 毒性药品柜   │  │ 铅柜     │ │  │
│  │  │ 双锁：A+B    │  │ 双锁：A+B    │  │ 单锁+铅  │ │  │
│  │  │ 专管药师：张 │  │ 专管药师：李 │  │ 专管：王 │ │  │
│  │  └──────────────┘  └──────────────┘  └──────────┘ │  │
│  │                                                     │  │
│  │  ┌──────────────────────────────────────────────┐  │  │
│  │  │  HIGH_RISK 专区（单独货架，高警示标识）      │  │  │
│  │  └──────────────────────────────────────────────┘  │  │
│  └────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────┘
```

**专柜属性：**

| 属性 | 说明 |
|---|---|
| 柜号 | 全局唯一，如 `CAB-OP-01`（门诊 1 号柜） |
| 柜类型 | `NARCOTIC` / `TOXIC` / `RADIOACTIVE` / `HIGH_RISK` |
| 所属药房 | 关联 M14-01 `warehouse_id` |
| 锁具类型 | `SINGLE`（单锁，高危专区）/ `DOUBLE`（双锁，麻精毒） |
| 双锁管理人 | 两名专管药师，各持一把钥匙 |
| 专管药师 | 谁对这个柜子负责 |
| 状态 | `ENABLED` / `DISABLED` / `SEALED`（封存） |

**双锁机制说明：**

双锁意味着两个锁芯都在柜门上，其中任一把锁持有者都无法单开柜门，必须两人同时到场。

系统层面的对应措施：
- 任何专柜操作必须两个不同的人（`operator_id ≠ checker_id`）
- 系统记录两人分别授权的时间戳
- 若两个签字时间差 > 15 分钟，视为异常并告警

### 3.3 逐支登记模型

**核心思想：每一次实物移动都是一条「支级」记录。**

```
┌────────────────────────────────────────────────────────────────┐
│                  特殊药品逐支登记簿                             │
├──────┬──────┬────────┬──────┬──────┬──────┬──────┬────────────┤
│ 日期 │ 柜号 │ 药品   │ 批号 │ 入/出│ 数量 │ 经手 │ 复核       │
├──────┼──────┼────────┼──────┼──────┼──────┼──────┼────────────┤
│10-22 │OP-01 │芬太尼  │2408  │ 入   │ 20 支│ 张敏 │ 李华       │
│10-22 │OP-01 │芬太尼  │2408  │ 出   │  2 支│ 张敏 │ 李华       │
│10-22 │OP-01 │芬太尼  │2408  │ 空瓿 │  2 支│ 张敏 │ 李华       │
│10-22 │OP-01 │吗啡针  │2409  │ 入   │ 10 支│ 张敏 │ 李华       │
└──────┴──────┴────────┴──────┴──────┴──────┴──────┴────────────┘
```

**八种登记动作：**

| 动作 | 代码 | 方向 | 说明 |
|---|---|---|---|
| 专柜入库 | `IN` | + | 从普通库或供应商进入专柜 |
| 专柜出库 | `OUT` | − | 从专柜调到普通库（罕见） |
| 处方发放 | `DISPENSE` | − | 发给患者/病区 |
| 空安瓿回收 | `AMPOULE_BACK` | 0 | 不影响库存，只做核销配对 |
| 残液销毁 | `RESIDUE_DESTROY` | − | 用剩部分的销毁（数量可小于发出量） |
| 过期销毁 | `EXPIRED_DESTROY` | − | 过期药品销毁 |
| 破损销毁 | `DAMAGED_DESTROY` | − | 破损药品销毁（需说明） |
| 盘点调整 | `STOCKTAKE_ADJUST` | ± | 盘点差异调整（需药房主任审批） |

**关键点：动作与库存方向必须自洽**

`AMPOULE_BACK` 是特殊的：它不改变专柜库存（空瓶子是垃圾，不是药品），但它**核销一条 DISPENSE 记录**。所以它的方向是 0，且必须关联到一条具体的 `DISPENSE` 记录。

### 3.4 双人核验模型

**任何专柜操作的面板必须有两个签字位：**

```
┌────────────────────────────────────────────────────────────────┐
│  芬太尼注射液 2ml:0.1mg  专柜发放                               │
├────────────────────────────────────────────────────────────────┤
│  出库数量：2 支      批号：240815      效期：2027-08-31         │
│                                                                │
│  处方号：RX20261022000123                                       │
│  患者：张三（男，58 岁）  诊断：青光眼术后镇痛                  │
│                                                                │
│  ┌──────────────────────────┐  ┌──────────────────────────┐   │
│  │ 操作人（专管药师）        │  │ 复核人（专管药师/主管）   │   │
│  │                          │  │                          │   │
│  │ 工号：[10086       ]     │  │ 工号：[10092       ]     │   │
│  │ 密码：[********]         │  │ 密码：[********]         │   │
│  │                          │  │                          │   │
│  │ □ 我已核对药品实物        │  │ □ 我已核对药品实物        │   │
│  └──────────────────────────┘  └──────────────────────────┘   │
│                                                                │
│  说明：两张签字必须为不同人员                                   │
└────────────────────────────────────────────────────────────────┘
```

**核验规则：**

| 规则 | 说明 |
|---|---|
| 两人不同 | `operator_id ≠ checker_id`，数据库硬约束 |
| 两人均需资质 | 都必须是持证专管药师（高危药品可放宽到药师） |
| 时间差 | 两个签字时间差 ≤ 15 分钟（超时告警，不阻断） |
| 顺序 | 先操作后复核，时间戳 `checked_at >= operated_at` |
| 不可代签 | 系统登录态校验，禁止切换账号 |
| 不可跳过 | 无复核人签字，记录不可提交 |

**为什么不能「一人操作、另一人后补签」？**

这是最常见的违规做法。系统层面通过以下方式限制：
- 操作时两人同时在线（Redis 会话校验双方都在活动）
- 复核签字时间必须在操作后 15 分钟内
- 若超过 15 分钟，记录标记 `is_late_check = TRUE`，进季度检查清单

### 3.5 处方限量模型

**不同类别 + 不同剂型 + 不同给药途径，限量不同：**

| 类别 | 剂型 | 单次限量 | 单日限量 | 疗程说明 |
|---|---|---|---|---|
| 麻醉药品 | 注射剂 | 一次用量 | — | 仅限院内使用 |
| 麻醉药品 | 片剂/胶囊 | 常用量 | 常用量 | 门诊 ≤ 3 天，住院 ≤ 1 天 |
| 麻醉药品 | 贴剂 | — | — | 门诊 ≤ 7 天 |
| 麻醉药品 | 控缓释口服 | — | — | 门诊 ≤ 7 天 |
| 第一类精神药品 | 注射剂 | 一次用量 | — | 仅限院内 |
| 第一类精神药品 | 口服 | 常用量 | 常用量 | 门诊 ≤ 3 天，住院 ≤ 1 天 |
| 第二类精神药品 | 口服 | — | — | 门诊 ≤ 7 天 |
| 毒性药品 | 全部 | 常用量 | 常用量 | 门诊 ≤ 1 天，住院 ≤ 1 天 |
| 放射性药品 | 全部 | 专用限值 | — | 按诊疗需求 |

**眼科特殊说明：**

眼科门诊极少开具麻醉药品处方（多为局部麻醉用药如奥布卡因，不属于麻醉药品管制范围）。实际会是：
- 青光眼急性发作时的强效镇痛（吗啡、哌替啶）
- 眼外伤的镇痛
- 术后疼痛管理（芬太尼贴剂，住院为主）

**限量来源优先级：**

```
1. M01-03 mdm_drug_prescription 的 max_single_dose / max_daily_dose / max_duration_days
2. 若主数据未定义 → 使用 M14-09 的 LIMIT_RULES 默认表
3. 若默认表也无 → 使用 SPECIAL_DRUG_DEFAULT（按类别通用限量）
```

### 3.6 空安瓿回收模型

**核心等式：**

```
发放数量 = 回收空瓿数量 + 在用数量 + 销毁数量
```

对麻醉药品注射剂：

- 患者带回家的可能性极小（多为院内使用）
- 一次使用后立即产生空安瓿
- 空安瓿必须当日回收，次日核对

```
┌──────────────────────────────────────────────────────────────┐
│  空安瓿回收闭环                                              │
└──────────────────────────────────────────────────────────────┘

  ① 发放                       ② 使用                 ③ 回收
  ┌──────────┐                 ┌──────────┐          ┌──────────┐
  │ 芬太尼   │────────────────►│ 患者使用 │─────────►│ 空瓿交回 │
  │ 2 支     │                 │ 2 支     │          │ 2 支     │
  └──────────┘                 └──────────┘          └────┬─────┘
       │                                                  │
       │                                                  │
       └──────────────── ④ 核销 ──────────────────────────┘
                    发放 2 = 回收 2 + 在用 0

  若回收 1 支：发放 2 ≠ 回收 1 + 在用 1
  → 系统标记「空瓿未回收」→ 通知护士/医生 → 追查
```

**回收状态：**

| 状态 | 说明 |
|---|---|
| `PENDING` | 已发放，等待回收 |
| `BACK` | 已回收，数量一致 |
| `PARTIAL` | 部分回收 |
| `MISSING` | 超过期限未回收（默认 24 小时） |

**为什么空安瓿这么重要？**

空安瓿是**药品确实被使用了的物理证据**。有人可能：

- 少用一支（实际用 1 支，报 2 支）→ 私藏带走
- 用完不回收 → 去向不明

药监飞检时会直接点数：**发出多少支、回收多少支、库存减少多少支**，三者必须吻合。

### 3.7 残液销毁模型

**注射剂用不完的残液必须销毁，不能留用。**

| 场景 | 处理 |
|---|---|
| 芬太尼 2ml 用了 1.5ml | 剩 0.5ml 抽入注射器，两人见证冲入下水道 |
| 吗啡 1ml 用了 0.6ml | 剩 0.4ml 同上 |
| 一支全用完 | 无残液，只需回收空瓿 |

**销毁记录要素：**

- 药品、批号、销毁数量（毫升）
- 是否回收空瓿
- 销毁人、监督人（两人不同）
- 销毁方式（冲入下水道 / 交由有资质单位）
- 销毁时间

### 3.8 失窃报告模型

**法定时限：24 小时内。**

| 时间 | 动作 |
|---|---|
| 发现丢失（T0） | 立即封存专柜、启动内部核查 |
| T0 + 2h | 查明丢失数量与批号 |
| T0 + 4h | 上报药房主任 |
| T0 + 8h | 上报医务科 |
| T0 + 24h（**硬性**） | 上报当地药品监督管理部门 + 公安机关 |
| T0 + 48h | 补交书面材料 |

**系统跟踪项：**

| 字段 | 说明 |
|---|---|
| `found_at` | 发现时间 |
| `report_deadline` | `found_at + 24h`（系统算） |
| `reported_at` | 实际上报时间 |
| `is_overdue` | `reported_at > report_deadline`（系统算） |
| `report_no` | 药监/公安报告的受理编号 |
| `report_org` | 上报单位 |
| `incident_desc` | 事件经过（≥50 字） |

### 3.9 账实核对模型

**每日 / 每月专柜盘点：**

| 频次 | 范围 | 负责人 |
|---|---|---|
| 每班次 | 当时段发生变动的药品 | 专管药师 + 复核人 |
| 每日 | 全部麻精药品 | 专管药师 + 值班主管 |
| 每月 | 全部特殊药品 | 药房主任 + 质控 |
| 每季 | 全部 + 历史台账核对 | 药事管理小组 |

**差异处理：**

| 差异 | 处理 |
|---|---|
| 台账多、实物少 | 立即上报，可能是失窃 |
| 台账少、实物多 | 检查是否有未登记入库，24 小时内查明 |
| 批号不符 | 立即查明，涉及批次混放 |

```python
    async def create_record(self, body, user: dict) -> dict:
        if body.operator.employee_id == body.checker.employee_id:
            raise BizError(55601, "操作人与复核人不得为同一人")

        operator = await self.emp_client.get_brief(
            body.operator.employee_id)
        checker = await self.emp_client.get_brief(
            body.checker.employee_id)
        if not self._has_special_cert(operator):
            raise BizError(55603, "操作人不具备专管药师资质")
        if not self._has_special_cert(checker):
            raise BizError(55603, "复核人不具备专管药师资质")
        if not body.operator.physical_verified:
            raise BizError(55604, "操作人物实核对未完成")
        if not body.checker.physical_verified:
            raise BizError(55604, "复核人物实核对未完成")

        special = await self.drug_client.get_special_class(
            body.drug_id)
        if not special or special.get("special_class") == "NORMAL":
            raise BizError(55610, "该药品不属于特殊管理药品")
        special_class = special["special_class"]

        cabinet = await self._get_cabinet(body.cabinet_id)
        if not cabinet or cabinet.status != "ENABLED":
            raise BizError(55623, "专柜不存在或已停用")

        stock = await self._get_stock_for_update(
            body.cabinet_id, body.drug_id, body.batch_no)
        if not stock:
            raise BizError(55624, "该批次在专柜中不存在")

        direction = ACTION_DIRECTION.get(body.action)
        if direction is None:
            raise BizError(55601, "登记类型非法")

        qty = Decimal(str(body.quantity))
        if qty <= 0:
            raise BizError(55602, "数量必须大于 0")
        before = stock.quantity
        after = before + direction * qty
        if after < 0:
            raise BizError(55602, "数量超过专柜当前库存")

        if body.action == "DISPENSE":
            if stock.expiry_date and stock.expiry_date < datetime.now().date():
                raise BizError(55609, "该批次已过期不可发放")
            await self._validate_dispense(body, special_class)

        stock.quantity = after
        stock.updated_at = datetime.now()

        record_no = self._next_record_no()
        record = M14SpecialRecord(
            record_no=record_no,
            action=body.action,
            cabinet_id=body.cabinet_id,
            cabinet_no=cabinet.cabinet_no,
            drug_id=body.drug_id,
            drug_name=special["drug_name"],
            specification=special.get("specification"),
            special_class=special_class,
            batch_no=body.batch_no,
            expiry_date=stock.expiry_date,
            quantity=qty,
            quantity_before=before,
            quantity_after=after,
            prescription_id=body.prescription_id,
            prescription_no=body.prescription_no,
            operator_id=body.operator.employee_id,
            operator_name=operator["employee_name"],
            operated_at=datetime.now(),
            checker_id=body.checker.employee_id,
            checker_name=checker["employee_name"],
            checked_at=datetime.now(),
            status="CONFIRMED",
            remark=body.remark,
        )
        self.db.add(record)
        await self.db.flush()

        ampoule_due_at = None
        if body.action == "DISPENSE" and special_class in (
                "NARCOTIC", "PSYCHOTROPIC_1", "PSYCHOTROPIC_2",
                "TOXIC"):
            ampoule_due_at = datetime.now() + timedelta(
                hours=AMPOULE_DUE_HOURS)
            amp = M14SpecialAmpoule(
                record_id=record.id,
                record_no=record_no,
                dispense_qty=qty,
                collected_qty=Decimal("0"),
                due_at=ampoule_due_at,
                status="PENDING",
            )
            self.db.add(amp)

        await self.db.commit()
        await self.db.refresh(record)
        await self._log(
            "RECORD_CREATE", record_no, user,
            {"action": body.action, "quantity": float(qty)})
        return self._record_dict(record, ampoule_due_at)

    async def ampoule_back(self, body, user: dict) -> dict:
        if body.operator.employee_id == body.witness.employee_id:
            raise BizError(55601, "操作人与监督人不得为同一人")

        amp = await self._get_ampoule_for_update(body.dispense_record_id)
        if not amp:
            raise BizError(55624, "发放记录不存在")
        remaining = amp.dispense_qty - amp.collected_qty
        if remaining <= 0:
            raise BizError(55627, "空安瓿已全部回收")

        qty = Decimal(str(body.ampoule_qty))
        if qty <= 0 or qty > remaining:
            raise BizError(55611, "回收数量超过发放数量")

        if body.has_residue:
            if not body.residue_ml or not body.destroy_method:
                raise BizError(55612, "有残液时必须填写销毁数量与方式")

        amp.collected_qty = amp.collected_qty + qty
        amp.collected_at = datetime.now()
        amp.collected_by = body.operator.employee_id
        amp.witness_id = body.witness.employee_id
        if amp.collected_qty >= amp.dispense_qty:
            amp.status = "BACK"
        else:
            amp.status = "PARTIAL"

        record_no = self._next_record_no()
        back_record = M14SpecialRecord(
            record_no=record_no,
            action="AMPOULE_BACK",
            cabinet_id=0,
            drug_id=amp.drug_id if hasattr(amp, "drug_id") else 0,
            drug_name="空安瓿回收",
            quantity=qty,
            quantity_before=amp.collected_qty - qty,
            quantity_after=amp.collected_qty,
            operator_id=body.operator.employee_id,
            operated_at=datetime.now(),
            checker_id=body.witness.employee_id,
            checked_at=datetime.now(),
            status="CONFIRMED",
            remark="关联发放记录 " + str(body.dispense_record_id),
        )
        self.db.add(back_record)

        residue_id = None
        if body.has_residue:
            residue_record = M14SpecialRecord(
                record_no=self._next_record_no(),
                action="RESIDUE_DESTROY",
                cabinet_id=0,
                drug_id=0,
                drug_name="残液销毁",
                quantity=Decimal(str(body.residue_ml)),
                quantity_before=Decimal("0"),
                quantity_after=Decimal("0"),
                operator_id=body.operator.employee_id,
                operated_at=datetime.now(),
                checker_id=body.witness.employee_id,
                checked_at=datetime.now(),
                status="CONFIRMED",
                remark="销毁方式 " + body.destroy_method,
            )
            self.db.add(residue_record)
            await self.db.flush()
            residue_id = residue_record.id

        await self.db.commit()
        await self._log(
            "AMPOULE_BACK", record_no, user,
            {"dispense_record_id": body.dispense_record_id,
             "qty": float(qty)})
        return {
            "back_record_id": back_record.id,
            "back_no": record_no,
            "dispense_record_id": body.dispense_record_id,

    async def check_limit(self, body) -> dict:
        special = await self.drug_client.get_special_class(
            body.drug_id)
        if not special or special.get("special_class") == "NORMAL":
            return {
                "is_special": False,
                "special_class": "NORMAL",
                "passed": True,
                "checks": [],
            }
        cls = special["special_class"]
        checks = []
        passed = True

        single_limit = MAX_SINGLE_DOSE.get(cls)
        if single_limit is not None:
            ok = Decimal(str(body.single_dose)) <= single_limit
            checks.append({
                "rule": "SINGLE_DOSE",
                "limit": float(single_limit),
                "actual": float(body.single_dose),
                "unit": special.get("dose_unit") or body.dose_unit or "支",
                "passed": ok,
            })
            if not ok:
                passed = False

        if body.prescription_type == "OUTPATIENT":
            day_limit = MAX_DAYS_OUTPATIENT.get(cls)
        else:
            day_limit = MAX_DAYS_INPATIENT.get(cls)
        if day_limit is not None:
            ok = body.duration_days <= day_limit
            checks.append({
                "rule": "DURATION_" + body.prescription_type,
                "limit_days": day_limit,
                "actual_days": body.duration_days,
                "passed": ok,
            })
            if not ok:
                passed = False

        total_limit = MAX_TOTAL_QTY.get(cls)
        if total_limit is not None:
            ok = Decimal(str(body.quantity)) <= total_limit
            checks.append({
                "rule": "TOTAL_QUANTITY",
                "limit": float(total_limit),
                "actual": float(body.quantity),
                "passed": ok,
            })
            if not ok:
                passed = False

        permit_valid = True
        if cls == "NARCOTIC":
            permit = await self._get_valid_permit()
            permit_valid = permit is not None

        return {
            "is_special": True,
            "special_class": cls,
            "special_class_text": self._class_text(cls),
            "checks": checks,
            "passed": passed,
            "need_special_prescription": cls in (
                "NARCOTIC", "PSYCHOTROPIC_1"),
            "need_permit": cls == "NARCOTIC",
            "permit_valid": permit_valid,
        }

    async def create_incident(self, body, user: dict) -> dict:
        if len(body.incident_desc.strip()) < INCIDENT_DESC_MIN_LEN:
            raise BizError(
                55618,
                "事件经过不得少于 %d 字" % INCIDENT_DESC_MIN_LEN)

        deadline = body.found_at + timedelta(
            hours=INCIDENT_REPORT_HOURS)

        if body.incident_type == "THEFT":
            if not body.reported_at or not body.report_no:
                raise BizError(55617, "失窃必须填写上报时间与受理编号")
            is_overdue = body.reported_at > deadline
        else:
            is_overdue = False

        if body.incident_type == "DAMAGE" and not body.photo_urls:
            raise BizError(55620, "破损必须上传照片")

        if body.operator_id == body.checker_id:
            raise BizError(55601, "操作人与复核人不得为同一人")

        incident_no = self._next_incident_no()
        incident = M14SpecialIncident(
            incident_no=incident_no,
            incident_type=body.incident_type,
            cabinet_id=body.cabinet_id,
            drug_id=body.drug_id,
            drug_name=body.drug_name,
            special_class=body.special_class,
            batch_no=body.batch_no,
            quantity=Decimal(str(body.quantity)),
            found_at=body.found_at,
            found_by=body.found_by,
            incident_desc=body.incident_desc,
            report_deadline=deadline,
            report_org=body.report_org,
            reported_at=body.reported_at,
            report_no=body.report_no,
            is_overdue=is_overdue,
            status="REPORTED" if body.reported_at else "PENDING_REPORT",
            operator_id=body.operator_id,
            checker_id=body.checker_id,
            approver_id=body.approver_id,
            photo_urls=body.photo_urls,
            created_by=user["employee_id"],
        )
        self.db.add(incident)

        # 失窃/破损从专柜库存扣减
        if body.incident_type in ("THEFT", "DAMAGE"):
            stock = await self._get_stock_for_update(
                body.cabinet_id, body.drug_id, body.batch_no)
            if stock:
                stock.quantity = stock.quantity - Decimal(
                    str(body.quantity))
                before = stock.quantity + Decimal(str(body.quantity))
                after = stock.quantity
                record_no = self._next_record_no()
                self.db.add(M14SpecialRecord(
                    record_no=record_no,
                    action=("STOCKTAKE_ADJUST"
                            if body.incident_type == "STOCKTAKE_DIFF"
                            else "DAMAGED_DESTROY"),
                    cabinet_id=body.cabinet_id,
                    drug_id=body.drug_id,
                    drug_name=body.drug_name,
                    batch_no=body.batch_no,
                    quantity=Decimal(str(body.quantity)),
                    quantity_before=before,
                    quantity_after=after,
                    operator_id=body.operator_id,
                    operated_at=datetime.now(),
                    checker_id=body.checker_id,
                    checked_at=datetime.now(),
                    status="CONFIRMED",
                    remark="异常单 " + incident_no,
                ))

        await self.db.commit()
        await self.db.refresh(incident)

        if body.incident_type == "THEFT":
            await self._notify_theft(incident)
        await self._log(
            "INCIDENT_CREATE", incident_no, user,
            {"type": body.incident_type,
             "qty": float(body.quantity)})
        return self._incident_dict(incident)

    async def _notify_theft(self, incident):
        content = (
            "特殊药品失窃告警：" + incident.drug_name
            + " " + str(incident.quantity) + " 单位，发现时间 "
            + incident.found_at.strftime("%Y-%m-%d %H:%M")
            + "。法定上报截止 "
            + incident.report_deadline.strftime("%Y-%m-%d %H:%M")
        )
        await self.msg_client.send(
            biz_type="SPECIAL_DRUG_THEFT",
            biz_id=incident.id,
            title="特殊药品失窃告警",
            content=content,
            receiver_roles=[
                "PHARMACY_DIRECTOR", "MEDICAL_AFFAIRS", "HOSPITAL_HEAD"],
```

```python
import asyncio
from datetime import datetime, timedelta

from celery import shared_task
from sqlalchemy import select, text

from app.core.database import get_db_context
from app.core.redis import redis_client
from app.models.m14_special import (

@shared_task(name="m14.special.ampoule_overdue_alert")
def ampoule_overdue_alert():
    """超期未回收空瓿告警"""
    asyncio.run(_ampoule_overdue_alert())


async def _ampoule_overdue_alert():
    async with get_db_context() as db:
        stmt = select(M14SpecialAmpoule).where(
            M14SpecialAmpoule.status.in_(["PENDING", "PARTIAL"]),
            M14SpecialAmpoule.due_at < datetime.now(),
            M14SpecialAmpoule.is_deleted == False,  # noqa: E712
        )
        rows = (await db.execute(stmt)).scalars().all()
        if not rows:
            return
        logger.warning(
            "M14-09 超期未回收空瓿 %d 条" % len(rows),
            extra={"module": "M14-09", "count": len(rows)},
        )
        payload = []
        for r in rows:
            hours = (datetime.now() - r.due_at).total_seconds() / 3600
            payload.append({
                "record_no": r.record_no,
                "dispense_qty": float(r.dispense_qty),
                "collected_qty": float(r.collected_qty),
                "overdue_hours": round(hours, 1),
            })
        redis_client.setex(
            "m14:special:ampoule:overdue_alert",
            86400,
            str(payload),
        )

def permit_expiry_check():
    """印鉴卡到期检查"""
    asyncio.run(_permit_expiry_check())


async def _permit_expiry_check():
    async with get_db_context() as db:
        warn_date = datetime.now().date() + timedelta(days=60)
        stmt = select(M14SpecialPermit).where(
            M14SpecialPermit.status == "ACTIVE",
            M14SpecialPermit.expire_date <= warn_date,
            M14SpecialPermit.is_deleted == False,  # noqa: E712
        )
        rows = (await db.execute(stmt)).scalars().all()
        for r in rows:
            days = (r.expire_date - datetime.now().date()).days
            logger.warning(
                "M14-09 印鉴卡即将到期 permit_no=%s days=%d"
                % (r.permit_no, days),
                extra={"module": "M14-09", "permit_no": r.permit_no},
            )


@shared_task(name="m14.special.incident_deadline_check")
def incident_deadline_check():
    """失窃上报时限检查"""
    asyncio.run(_incident_deadline_check())


async def _incident_deadline_check():
    async with get_db_context() as db:
        stmt = select(M14SpecialIncident).where(
            M14SpecialIncident.incident_type == "THEFT",
            M14SpecialIncident.status == "PENDING_REPORT",
            M14SpecialIncident.is_deleted == False,  # noqa: E712
        )
        rows = (await db.execute(stmt)).scalars().all()
        for r in rows:
            left = (r.report_deadline - datetime.now()).total_seconds()
            hours = left / 3600
            if hours <= 0:
                logger.error(
                    "M14-09 失窃上报已超时 incident_no=%s"
                    % r.incident_no,
                    extra={"module": "M14-09",
                           "incident_no": r.incident_no},
                )
            elif hours <= 6:
                logger.warning(
                    "M14-09 失窃上报剩余 %.1f 小时 incident_no=%s"
                    % (hours, r.incident_no),
                    extra={"module": "M14-09",
                           "incident_no": r.incident_no},
                )

        return
    logger.info(
        "M14-09 季度报表生成提醒 quarter=%dQ%d"

        extra={"module": "M14-09"},
    )


@shared_task(name="m14.special.export_ledger")

    """专册导出异步任务"""
    asyncio.run(_export_ledger(task_id, params))


async def _export_ledger(task_id: str, params: dict):
    async with get_db_context() as db:
        logger.info(
            "M14-09 专册导出开始 task_id=%s" % task_id,
            extra={"module": "M14-09", "task_id": task_id},

        rows = await _query_ledger_rows(db, params)
        path = await _write_excel(rows, params, task_id)
        redis_client.setex(
            "m14:special:export:" + task_id,
            86400,
            path,
        )


async def _query_ledger_rows(db, params: dict):

        SELECT record_no, action, drug_name, specification,
               batch_no, quantity, quantity_before, quantity_after,
               operator_name, checker_name, operated_at
        FROM m14_special_record
        WHERE operated_at >= :start
          AND operated_at <= :end
          AND is_deleted = FALSE
        ORDER BY operated_at
    """)
    result = await db.execute(sql, {
        "start": params["start_date"],
        "end": params["end_date"],
    })
    return result.fetchall()
```

| 院长 | ✅ | ❌ | ❌ | ✅ | ✅ | ❌ |
| 系统管理员 | ❌ | ❌ | ❌ | ❌ | ❌ | ✅ |

**职责分离铁律：**

| SoD | 说明 |
|---|---|
| SoD-01 | 专管药师不能是自己登记的第二签字人（数据库约束） |
| SoD-02 | 药房主任可以复核但不能自己操作（防止一人包办） |
| SoD-03 | 异常处置的确认人不能是操作人或复核人 |
| SoD-04 | 系统管理员无任何业务操作权限（即使有 `config` 也不含 `operate`） |

### 9.3 数据权限与脱敏

| 数据 | 脱敏规则 |
|---|---|
| 患者姓名 | 完整显示（专管药师需核对身份） |
| 患者证件号 | 中间 8 位掩码 `110101********1234` |
| 患者联系电话 | 中间 4 位掩码 |
| 药师密码 | 永不返回，只做校验 |

**数据范围：**

- 专管药师：只见自己所属药房的专柜
- 药房主任：见全部门诊药房专柜
- 药事质控/医务科/院长：全院专柜（只读）

### 9.4 安全措施

| 措施 | 说明 |
|---|---|
| **操作需重新输入密码** | 双人核验面板，双方各自输入密码，不复用登录态 |
| **会话绑定** | 登记必须在同一浏览器会话内完成，切换账号即作废 |
| **IP 限制** | 专柜操作只允许药房内网 IP |
| **防代签** | 复核签字时校验当前登录账号 = 复核人工号 |
| **时间戳防篡改** | 服务端生成，不接受前端传入 |
| **只增不改** | 登记记录插入后不可 UPDATE/DELETE（触发器保护） |
| **审计全覆盖** | 所有操作记审计日志 |
| **异常告警** | 同人连续多次异常、同柜短时大量出入库触发告警 |
