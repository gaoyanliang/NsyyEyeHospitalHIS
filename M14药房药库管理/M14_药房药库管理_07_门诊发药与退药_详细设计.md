## 1. 模块概述

### 1.1 模块定位

M14-07 门诊发药与退药，是药房与患者之间的**最后一道物理关口**。它回答一个问题：

> **这张已经审核通过的处方，药品是怎么从药架到患者手上的，患者又是怎么把它退回来的。**

```
┌──────────────────────────────────────────────────────────────────────┐
│                         门诊发药全链路                                │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  M07 医生开方                                                         │
│      │                                                               │
│      ▼                                                               │
│  M16 收费（患者缴费）                                                  │
│      │  处方状态 PAID                                                 │
│      ▼                                                               │
│  M14-06 处方审核 ──── PASSED / CONDITIONAL ────┐                      │
│      │                                        │                      │
│      ▼                                        ▼                      │
│  ┌─────────────────────────────────────────────────┐                 │
│  │           M14-07 门诊发药与退药                  │                 │
│  │                                                 │                 │
│  │  ① 收方（扫条码 / 读卡）                        │                 │
│  │  ② 调配（FEFO 选批次，药师取药）                │                 │
│  │  ③ 复核（第二人核对：药、量、标签、眼别）        │                 │
│  │  ④ 发药（交给患者，用药交代，签字）              │                 │
│  │  ⑤ 库存扣减（M14-01 唯一入口）                   │                 │
│  │  ⑥ 回写 M07 处方已发药 / M16 可结算              │                 │
│  │                                                 │                 │
│  │  退药：⑦ 收退 → ⑧ 质量判定 → ⑨ 入库 → ⑩ 回写     │                 │
│  └─────────────────────────────────────────────────┘                 │
│      │                                                               │
│      ▼                                                               │
│  患者取药离院                                                         │
│                                                                      │
└──────────────────────────────────────────────────────────────────────┘
```

**一句话职责：** M14-07 负责「把药准确无误地交到对的患者手上，并在需要时把药收回来」。

### 1.2 为什么独立成子模块

M14-06 处方审核回答「该不该发」，M14-07 回答「发得对不对」。两者必须分开，理由有四：

| 维度 | M14-06 处方审核 | M14-07 门诊发药与退药 |
|---|---|---|
| **核心问题** | 用药方案是否合理 | 交到手上的药是否与处方一致 |
| **判断依据** | 药品知识、临床指南、患者情况 | 处方文字与实物逐项比对 |
| **承担责任** | 药师的专业判断责任 | 操作差错的直接责任 |
| **出错后果** | 用药不当（隐蔽、延迟显现） | 发错药（立即、可见） |
| **执行人** | 审核药师（须有审方资格） | 调配员（药师或药士）+ 复核员 |
| **输入** | 处方文本 + 患者信息 + 知识库 | 已审核处方 + 货架实物 |
| **输出** | 审核结论（通过 / 退回 / 拒审） | 已发出药品 + 库存流水 |
| **时间尺度** | 数十秒至数分钟（思考为主） | 数十秒至数分钟（动作为主） |
| **可逆性** | 结论可退回重审 | 药已到患者手上，只能退药挽回 |

**四条独立理由：**

**理由一：法定职责独立，证据链必须分开**

《医疗机构药事管理规定》第三十六条：调剂包括**审核、调配、核对、发药**四个环节，且「发出药品应注明患者姓名和药品名称、用法、用量」。

这四个环节中，审核由 M14-06 覆盖，调配、核对、发药由 M14-07 覆盖。药监检查时要看的是**两个不同的记录**：

- 「谁审的方？」→ `m14_rx_review.reviewer_id`
- 「谁调的、谁核的、谁发的？」→ `m14_dispense.dispatcher_id` / `checker_id` / `dispenser_id`

如果合并成一个子模块，一张表里既有审核字段又有调配字段，检查时反而说不清楚。

**理由二：双人复核制度是硬性要求，需要独立的角色与工时**

《医疗机构处方审核规范》第十五条：**「调配药师与核对药师不得为同一人」**。

这是门诊发药最不能妥协的一条。它意味着：

- 至少两个岗位、两次操作、两个时间戳
- 复核发现差错时要能记录「发现了什么差错」
- 差错要能追溯、统计、考核

如果把它塞进处方审核（一个人可以独立完成的动作），就破坏了「必须两人」这个前提。

**理由三：退药是把发药倒着走一遍，且多一道质量判定**

退药不是简单地「库存加回来」：

```
发药：处方 → 调配 → 复核 → 发药 → 扣库存
退药：申请 → 质量判定 → 入库（能否再用？）→ 退费 → 回写
                    ↑
             这里多了一个「这套药还能不能给别人用」的判断
```

判定涉及：是否开封、是否冷链断链、包装是否破损、是否过期、是否特殊管理药品。**这些判断只有发药窗口的药师能看到实物**，处方审核药师看的是文本，做不了这个判断。

**理由四：眼科门诊发药有极强的窗口特性**

眼科门诊日均 350 张处方，90% 集中在上午 8:30~11:30。窗口排队是患者最直观的体验。所以：

- 收方与调配要能**并行**（一边叫号一边配药）
- 需要**预调配**（患者还在缴费，药房已在配）
- 需要**叫号取药**（配好了按号叫人，不是站着等）
- 发药时长要控制在 **2 分钟以内**（患者体验指标）

这些都用「窗口」「队列」「叫号」概念建模，与处方审核的「待办任务队列」形态完全不同。

### 1.4 概念辨析

门诊发药有四个极易混淆的概念，先厘清：

| 概念 | 定义 | 谁做 | 关键区别 |
|---|---|---|---|
| **调配** | 按处方从货架取出药品、贴标签、放入调配筐 | 调配员 | 只是「取出来」，此时药还在药房 |
| **核对（复核）** | 第二人比对：药名、规格、数量、用法、眼别、标签 | 复核员 | **必须与调配员不同人**，这是差错拦截点 |
| **发药** | 将药交给患者，做用药交代，患者/家属签收 | 发药员 | 药离开药房，责任转移 |
| **交付（handover）** | 患者实际拿到药并确认 | — | 系统记录时间点，是退药计时起点 |

再看三个「不是」：

**发药 ≠ 出库**

出库（M14-04）是仓库到药房的转移，是一个内部动作；发药是药房到患者的转移，是对外承诺。出库流水类型 `ISSUE_OUT`，发药流水类型 `DISPENSE_OUT`，两者在台账中必须能区分——否则「这个月药房发了多少药」这个问题答不出来。

**退药 ≠ 退货**

退药是**患者**把药退回药房（`RETURN_IN`），退还是**供应商**把药退回厂家（`PURCHASE_RETURN`，归 M14-03）。两者的收货方、检验标准、财务处理完全不同。

**发药完成 ≠ 处方结束**

发药完成后，处方进入「可退费」状态。真正的结束是：超过退药时限（默认 7 天）或患者确认不退。系统里这两个状态分别用 `DISPENSED` 和退药窗口的自然过期表达，不需要额外的状态。

### 1.5 模块目标

| 目标 | 指标 | 目标值 | 测量方式 |
|---|---|---|---|
| 发药速度 | 窗口平均服务时长 | ≤ 2 分钟 | `dispensed_at - window_called_at` |
| 调配效率 | 收方到配好的时长 | ≤ 3 分钟 | `prepared_at - received_at` |
| 差错拦截 | 复核拦截率 | ≥ 95% | 复核发现差分数 / 全部差错数 |
| 发药准确 | 发错药投诉 | ≤ 0.1‰ | 月投诉数 / 月处方数 |
| 退药处理 | 退药平均时长 | ≤ 5 分钟 | `completed_at - created_at` |
| 库存准确 | 发药扣减失败 | ≤ 0.01% | 扣减失败数 / 发药数 |
| 追溯完整 | 批次可追溯率 | 100% | 每条发药明细都有 batch_no |

### 1.6 关键业务角色

| 角色 | 岗位 | 主要职责 | 关键权限 |
|---|---|---|---|
| **调配员** | 药士 / 药师 | 收方、取药、贴标签、放调配筐 | `m14:dispense:prepare` |
| **复核员** | 药师 | 核对药品与处方一致性 | `m14:dispense:check` |
| **发药员** | 药师 | 交付患者、用药交代、签收 | `m14:dispense:issue` |
| **窗口组长** | 主管药师 | 排班、异常处置、强制放行 | `m14:dispense:manage` |
| **退药审核员** | 药师 | 判定退回药品能否再用 | `m14:dispense:return_judge` |
| **药房主任** | 副主任药师 | 退药审批、报表查看 | `m14:dispense:return_approve` |

> **注意：** 调配员与复核员**可以是同一人的不同时段**（上午调配下午复核），但**同一张处方上必须是两个人**。系统用 `ck_m14_dispense_double` 约束强制。

## 2. 业务范围与边界

### 2.1 范围内

| 编号 | 功能 | 说明 |
|---|---|---|
| S-01 | 收方 | 扫码 / 读卡 / 手工输入处方号，拉取待发药处方 |

| S-03 | 批次分配 | 调 M14-02 按 FEFO 分配批次 |
| S-04 | 调配登记 | 记录调配员、调配时间、实际取药批次 |
| S-05 | 双人复核 | 第二人核对，记录复核结果与发现的问题 |
| S-06 | 发药交付 | 记录发药员、发药时间、患者签收 |
| S-07 | 用药交代 | 打印/展示用药交代单，记录已交代项 |
| S-08 | 库存扣减 | 调 M14-01 扣减库存，写流水 |
| S-09 | 窗口叫号 | 调配完成后进入取药队列，叫号通知患者 |
| S-10 | 退药申请 | 患者申请退药，选择退药原因 |

| S-12 | 退药入库 | 可再用的药品回到库存（原批次） |
| S-13 | 退药通知 | 通知 M16 退费、M07 处方状态回滚 |

| S-16 | 发药统计 | 窗口效率、药师工作量、退药率、差错率 |

### 2.2 范围外

| 不做的事 | 归属模块 | 说明 |
|---|---|---|
| 判断处方是否合理 | M14-06 处方审核 | 只读取审核结论，不重复判断 |
| 决定用哪个批次 | M14-02 分配与效期 | 调用分配服务，不自选批次 |
| 修改库存数量 | M14-01 库存台账 | 通过 `POST /internal/v1/m14/stock/apply` 唯一入口 |
| 计算退费金额 | M16 退费与冲红 | 只提供「哪些明细可退、应退多少」 |
| 实际退款操作 | M16-05 支付与聚合收单 | 资金动作全部归 M16 |
| 补开处方或修改处方 | M07 医生工作站 | 处方内容归医生 |
| 住院发药与摆药 | M14-08 住院药房与病区用药 | 住院是整病区批量、按日摆药，形态完全不同 |
| 特殊管理药品的专项登记 | M14-09 特殊管理药品 | 麻精药品发药时调用 M14-09 的逐支登记 |
| 库存盘点 | M14-05 盘点与库存调整 | 退药入库后可能引发账实不符，由盘点发现 |
| 供应商退货 | M14-03 采购与入库 | 退药后的报废或退厂走 M14-04 报损 |

## 3. 业务模型

### 3.1 发药单状态机

发药单是本子模块的核心实体，一张处方对应一张发药单。

```
                        ┌──────────┐
                        │ RECEIVED │  已收方（扫码成功，校验通过）
                        └────┬─────┘
                             │ 开始调配
                             ▼
                        ┌──────────┐
        ┌───────────────│PREPARING │  调配中（正在取药）
        │               └────┬─────┘
        │ 缺药/处方有疑问   │ 调配完成
        ▼                    ▼
   ┌─────────┐          ┌──────────┐
   │ ON_HOLD │          │ PREPARED │  已配好（等待复核）
   └────┬────┘          └────┬─────┘
        │ 挂起解除            │ 开始复核
        │                    ▼
        │               ┌──────────┐
        │               │ CHECKING │  复核中
        │               └────┬─────┘
        │    复核不通过        │ 复核通过
        ├────────────────────┤
        │                    ▼
        │               ┌──────────┐
        │               │ CHECKED  │  已复核（等待发药）
        │               └────┬─────┘
        │                    │ 交付患者
        │                    ▼
        │               ┌──────────┐
        │               │DISPENSED │  已发药（终态）
        │               └────┬─────┘
        │                    │ 患者退药
        │                    ▼
        │               ┌──────────┐
        │               │ RETURNED │  已退药（终态）
        │               └──────────┘
        │
        │ 患者放弃/处方作废
        ▼
   ┌───────────┐
   │ CANCELLED │  已取消（终态）
   └───────────┘
```

**状态说明**

| 状态 | 中文名 | 终态 | 可退药 | 占用窗口 | 说明 |
|---|---|---|---|---|---|
| `RECEIVED` | 已收方 | 否 | 否 | 是 | 校验通过，进入调配队列 |
| `PREPARING` | 调配中 | 否 | 否 | 是 | 调配员正在取药 |
| `PREPARED` | 已配好 | 否 | 否 | 是 | 药已放入调配筐，等待复核 |
| `CHECKING` | 复核中 | 否 | 否 | 是 | 复核员正在核对 |
| `CHECKED` | 已复核 | 否 | 否 | 是 | 核对无误，等待交付 |
| `DISPENSED` | 已发药 | **是** | 是 | 否 | 药已交患者，释放窗口 |
| `RETURNED` | 已退药 | **是** | 否 | 否 | 全部或部分退回 |
| `ON_HOLD` | 挂起 | 否 | 否 | 否 | 缺药、处方疑问、收费问题 |
| `CANCELLED` | 已取消 | **是** | 否 | 否 | 作废 |

**关键设计：为什么要 `CHECKED` 而不是 `PREPARED → DISPENSED` 直接跳？**

因为复核与发药是**两个不同的人、两个不同的时间点**：

- 上午 9:00 复核员小张核完 20 张处方，全部放「待发药区」
- 9:30 发药窗口叫号，发药员小李逐张交付

如果只有 `PREPARED → DISPENSED`，就没法表达「核完了但还没发」这个中间状态，也没法统计「复核完成到实际发出」的等待时长（这恰恰是排队管理的核心指标）。

**关键设计：为什么 `ON_HOLD` 不占用窗口？**

窗口资源是稀缺的。如果某张处方缺药需要等供应商，让它一直占着一个窗口的状态机，会导致窗口无法服务下一位患者。`ON_HOLD` 把发药单暂时移出窗口队列，挂起解除后重新进入 `PREPARING`。

### 3.2 调配与复核模型

**三层结构：发药单 → 发药明细 → 发药批次**

```
m14_dispense（发药单，1 张处方 1 张发药单）
    │ 1:N
    ▼
m14_dispense_item（发药明细，按处方行，1 个药品 1 行）
    │ 1:N
    ▼
m14_dispense_batch（发药批次，1 个药品可能来自多个批次）
```

**为什么明细与批次要分两层？**

一张处方开了「左氧氟沙星滴眼液 2 支」，药房库存：

| 批次 | 批号 | 效期 | 可用数量 |
|---|---|---|---|
| A | 240815 | 2026-08-14 | 1 |
| B | 240920 | 2026-09-19 | 5 |

按 FEFO 分配：批次 A 取 1 支，批次 B 取 1 支。

如果只有一层：

```
item  drug 左氧氟沙星  qty 2  batch ???   ← 装不下两个批次
```

必须拆成两层：

```
item   drug 左氧氟沙星  qty 2
batch  └─ A  240815  qty 1
       └─ B  240920  qty 1
```

这不是设计选择，是**批次追溯的强制要求**。药监查「批号 240815 的左氧氟沙星发给谁了」，必须能精确回答。

**三个数量的区别**

| 字段 | 含义 | 由谁写 | 何时写 |
|---|---|---|---|
| `prescribed_qty` | 处方数量 | M07 | 收方时快照 |
| `dispensed_qty` | 实际调配数量 | 调配员 | 调配完成时 |
| `issued_qty` | 实际发出数量 | 发药员 | 发药时 |

三者通常相等。不等的情况：

- 处方 2 支，库存只有 1 支 → `prescribed_qty=2`，`dispensed_qty=1`（缺药）
- 调配 2 支，患者说「我家里还有 1 支」→ `dispensed_qty=2`，`issued_qty=1`（少发）

缺药时的处理见 §3.6。

### 3.3 发药批次分配

**分配算法**（调用 M14-02，此处说明 M14-07 侧的逻辑）

```
输入：drug_id, need_qty（= prescribed_qty − 已发数量）, warehouse_id
输出：[(batch_id, qty), ...]

① 调 M14-02 allocation/allocate（策略 FEFO）
② 若返回不足：
     - 记 short_qty = need_qty − 已分配
     - 弹出「缺药确认」对话框给调配员
③ 若 M14-02 不可用（超时 5s）：
     - 降级为手工选批：显示所有可用批次，按效期升序，药师勾选
     - 记录 degraded = TRUE
④ 若可拆零且整包装不足：
     - 调 M14-02 split/execute 拆零
     - 拆零后的批次批号为原批号 + "-S"
```

**为什么默认 FEFO 而不是 FIFO？**

FEFO（First Expired First Out，先到期先出）保证近效期药品先发出去，减少过期报损。

FIFO（First In First Out，先进先出）只看入库时间。两者在大多数情况一致，但当供应商送来的批次效期差异大时会分叉：

| 批次 | 入库时间 | 效期 |
|---|---|---|
| A | 2026-01 | 2027-06 |
| B | 2026-03 | 2026-12 |

FIFO 发 A，B 到期报损。FEFO 发 B，A 继续放。眼科药品单价高、品种多，报损金额敏感，必须 FEFO。

### 3.4 退药模型

**退药判定：三个问题**

```
问题一：这套药还在退药时限内吗？
        ├─ 是 → 继续
        └─ 否 → 拒绝（报 55507），走特殊审批

问题二：药品有没有被开封/破坏？
        ├─ 未开封且包装完好 → 可再用
        ├─ 已开封 → 不可再用，废
        └─ 包装破损 → 不可再用，废

问题三：是否特殊管理药品？
        ├─ 是 → 转 M14-09 专项处理，双人核验
        └─ 否 → 走常规入库
```

**四种判定结果**

| 结果 | 代码 | 后续动作 | 患者退费 |
|---|---|---|---|
| 可再用 | `REUSABLE` | 入原批次库存（`RETURN_IN`） | 全额退 |
| 不可再用 | `UNUSABLE` | 不入库，生成待报废记录 | 全额退（这是药房的损失） |
| 部分可用 | `PARTIAL` | 可用的入库，不可用的报废 | 按可入库部分退 |
| 不予退药 | `REFUSE` | 不入库 | 不退 |

**退药时限规则**

| 场景 | 时限 | 依据 |
|---|---|---|
| 常规退药 | 发药后 7 天 | 医院规定（可参数化） |
| 药品质量问题 | 无时限（效期内） | 质量问题药房责任 |
| 医生开错（开具错误） | 3 天 | 需医生确认 |
| 特殊管理药品 | 不予退药（除质量原因） | 法规规定麻精药品不得退药 |
| 冷链药品 | 2 小时（离开冷链后不可退） | 冷链完整性无法保证 |

**退药入库的批次归属**

退回的药必须回到**原发药批次**，不能新建批次。理由：

- 新批次会造成同一批号两条记录，库存虚增
- 药监追溯时批号对不上
- 效期管理出现两套数据

实现方式：发药明细上已经记录了 `batch_id`，退药时直接使用该 `batch_id` 做 `RETURN_IN`。

**退药不改变发药记录**

`m14_dispense` 一旦变成 `DISPENSED`，其明细与批次记录**永不修改**（只读触发器保护）。退药是**新建** `m14_drug_return` 记录，通过 `dispense_id` 关联。

理由：发药是发生过的事实。如果退药时把发药记录的 `issued_qty` 改成 0，就再也说不清「当时到底发了多少」。

### 3.5 窗口与叫号模型

**窗口状态**

```
┌────────┐   开启    ┌──────────┐   服务中   ┌──────────┐
│ CLOSED │─────────►│  IDLE    │◄──────────│ SERVING  │
└────────┘          └──────────┘   完成/取消 └──────────┘
     ▲                    │                      │
     │      关闭窗口       │      叫号             │
     └────────────────────┴──────────────────────┘
```

| 状态 | 说明 | 可叫号 | 可调配 |
|---|---|---|---|
| `CLOSED` | 窗口关闭 | 否 | 否 |
| `IDLE` | 空闲，等待患者 | 是 | 是 |
| `SERVING` | 服务中（一位患者） | 否 | 是（预调配） |

**叫号规则**

- 调配完成（`CHECKED`）→ 发药单进入叫号队列
- 队列按 `prepared_at` 升序（先配好的先叫）
- 叫号后 60 秒无应答 → 自动重叫，最多 3 次
- 3 次无应答 → 标记 `no_show`，移出队列，患者需重新到窗口登记

**预调配的场景**

患者交完费到药房窗口还有 3~5 分钟路程。如果等患者到了才开始配药，窗口平均要等 3 分钟。

预调配：缴费成功后立即推送「处方待调配」，药房后台先配好，患者到窗口直接取。

实现：`m14_dispense.status = PREPARED` 时窗口还没叫号，患者到了直接进入 `CHECKING`。

### 3.6 缺药处理

**情况一：部分缺药，其余可发**

```
处方：左氧氟沙星 2 支、玻璃酸钠 1 支
库存：左氧氟沙星 1 支、玻璃酸钠 1 支

处理：
  ① 调配员点「缺药登记」，选择缺药项与缺药数量
  ② 系统弹出确认：「左氧氟沙星缺 1 支，是否先发其余药品？」
  ③ 选「先发」→ dispensed_qty = 1，short_qty = 1，状态 PREPARED
  ④ 缺药部分生成 m14_dispense_shortage 记录，供后续补发或退费
  ⑤ 发药时告知患者：「这一支到货后通知您来取，或现在退费」
```

**情况二：全部缺药**

发药单置 `ON_HOLD`，缺药数量全部记录，通知患者与药库。

**情况三：药品缺货但患者急需**

转紧急采购（M14-03），不占用窗口。

**为什么不能简单报错退出？**

眼科门诊患者多数从外地来，往返成本高。一支药缺货让患者改天再来，体验极差。允许「先发一部分」是业务必需。

但必须记录清楚 `short_qty`，否则退费时算不清。

### 3.7 发药差错类型

复核发现的问题必须分类登记，这是质量管理的核心数据。

| 代码 | 类型 | 典型场景 | 拦截环节 |
|---|---|---|---|
| `WRONG_DRUG` | 药品错误 | 拿了左氧氟沙星而非加替沙星 | 复核 |
| `WRONG_SPEC` | 规格错误 | 配了 5ml 而非 10ml | 复核 |
| `WRONG_QTY` | 数量错误 | 处方 2 支只拿了 1 支 | 复核 |
| `WRONG_EYE` | 眼别错误 | 右眼药标成左眼用 | 复核 / 发药 |
| `WRONG_LABEL` | 标签错误 | 标签贴错瓶 | 复核 |
| `EXPIRE` | 效期问题 | 拿了过期或近效期 | 复核 |
| `DAMAGE` | 外观破损 | 瓶身破损、液体浑浊 | 复核 |
| `MISS_ITEM` | 漏配 | 处方 3 种药只配了 2 种 | 复核 / 发药 |
| `EXTRA_ITEM` | 多配 | 配了处方上没有的药 | 复核 |
| `OTHER` | 其他 | — | — |

**差错的处置方式**

| 处置 | 代码 | 说明 |
|---|---|---|
| 返工 | `REWORK` | 立即改正，重新调配（多数情况） |
| 报损 | `SCRAP` | 已拆封污染，无法再用 |
| 上报 | `REPORT` | 需上报药房主任/医务科（严重差错） |

### 6.2 错误码规范

| 错误码 | 说明 | 触发场景 |
|---|---|---|
| 55501 | 处方不存在 | 收方时处方号查不到 |
| 55502 | 处方未通过审核 | 审核状态非 PASSED/CONDITIONAL |
| 55503 | 处方未收费 | 收费状态非已收费 |
| 55504 | 处方已发药 | 已有 DISPENSED 的发药单 |
| 55505 | 处方已作废 | 处方状态为作废 |
| 55506 | 处方超过有效期 | 出具日期距今 > 3 天 |
| 55507 | 已超过退药时限 | 距发药 > 7 天 |
| 55508 | 库存/批次服务不可用 | M14-02 超时或报错 |
| 55509 | 退药数量超出可退范围 | 退药数量 > 可退 |
| 55510 | 未选择退药项目 | 全部数量为 0 |
| 55511 | 该处方已退药完成 | 重复退药 |
| 55512 | 特殊管理药品不予退药 | 麻精药品非质量原因 |
| 55513 | 退药原因说明不足 | 说明 < 10 字 |
| 55514 | 未选择药品状态判定 | 退药数量 > 0 未判定 |
| 55515 | 调配与复核不得为同一人 | 同一用户 |
| 55516 | 批次分配数量与处方不符 | 合计 ≠ 处方数量 − 缺药 |
| 55517 | 批次可用数量不足 | 取药数 > 可用数 |
| 55518 | 该批次已过期 | `expiry_date <= today` |
| 55519 | 核对项未全部完成 | 8 项未全勾 |

```python
    async def receive(self, body, user) -> dict:

        if not rx_no:
            raise BizException(55501, "处方号不能为空")

        # 1. 幂等：同一处方已有未取消的发药单
        existing = await self._find_active_by_rx(rx_no)
        if existing is not None:
            if existing.status == "DISPENSED":
                raise BizException(55504, "该处方已发药")
            if existing.status == "RETURNED":
                raise BizException(55511, "该处方已退药完成")
            raise BizException(55532, "该处方正在调配中")

        # 2. 拉取处方（M07）
        rx = await M07Client.get_rx_for_dispense(rx_no)
        if rx is None:
            raise BizException(55501, "处方号不存在")

        # 3. 处方状态
        if rx.get("status") == "VOIDED":
            raise BizException(55505, "处方已作废，无法发药")

        prescribed_at = _parse_dt(rx.get("prescribed_at"))

            if datetime.now() - prescribed_at > timedelta(

        now = datetime.now()
        dispense = M14Dispense(
            dispense_no=await self._next_dispense_no(now),
            rx_id=rx["id"],
            rx_no=rx_no,
            patient_id=rx["patient_id"],
            patient_name=rx.get("patient_name"),
            encounter_id=rx.get("encounter_id"),
            dept_id=rx.get("dept_id"),

            received_by_name=user["employee_name"],
            received_at=now,
            status="RECEIVED",
            writeback_status="NONE",
        )
        self.db.add(dispense)
        await self.db.flush()

        # 8. 建明细快照
        for line_no, item in enumerate(rx.get("items", []), start=1):
            seq = M14DispenseItem(
                dispense_id=dispense.id,

                line_no=line_no,

    async def prepare(self, dispense_id: int, body, user) -> dict:
        """提交调配：校验批次 → 落库明细与批次 → PREPARED"""
        row = await self._lock_dispense(dispense_id)
        self._check_transition(row.status, "PREPARED")

        # 调配与复核不得为同一人（复核人此时尚未确定，此处只记录调配人）
        items = {i["item_id"]: i for i in body.items}
        if not items:
            raise BizException(55516, "调配明细不能为空")

        short_total = Decimal("0.00")
        now = datetime.now()

        for item in await self._load_items(dispense_id):
            payload = items.get(item.id)
            if payload is None:
                continue
            dispensed = _money(payload["dispensed_qty"])
            if dispensed > item.prescribed_qty:
                raise BizException(55522, "调配数量不能超过处方数量")

            # 批次数量合计校验
            batch_sum = sum(
                Decimal(str(b["qty"])) for b in payload.get("batches", []))
            shortage = item.prescribed_qty - dispensed
            if abs(batch_sum - dispensed) > Decimal("0.0001"):
                raise BizException(55516, "批次分配数量与处方不符")

            for b in payload.get("batches", []):
                batch = await M14StockClient.get_batch(b["batch_id"])
                if batch is None:
                    raise BizException(55517, "批次不存在")
                if batch["expiry_date"] <= now.date().isoformat():
                    raise BizException(55518, "该批次已过期，不可发药")
                if Decimal(str(batch["available_qty"])) < Decimal(
                        str(b["qty"])):
                    raise BizException(55517, "批次可用数量不足")
                self.db.add(M14DispenseBatch(
                    dispense_id=dispense_id,
                    item_id=item.id,
                    batch_id=b["batch_id"],
                    batch_no=batch["batch_no"],
                    expiry_date=batch["expiry_date"],
                    location_code=batch.get("location_code"),
                    quantity=Decimal(str(b["qty"])),
                    unit_cost=batch.get("unit_cost"),
                ))

            item.dispensed_qty = dispensed
            item.short_qty = shortage
            short_total += shortage

        row.status = "PREPARED"
        row.prepared_at = now
        row.short_qty = short_total
        row.prepare_remark = body.remark
        await self._log(row, "PREPARE", "PREPARING", "PREPARED", user)
        await self.db.commit()

        return {
            "dispense_id": row.id,
            "dispense_no": row.dispense_no,
            "status": row.status,
            "status_text": "已配好",
            "dispatcher_id": row.dispatcher_id,
            "dispatcher_name": row.dispatcher_name,
            "prepared_at": now,
            "duration_seconds": int(
                (now - row.received_at).total_seconds()),
            "item_count": row.item_count,
            "short_qty": float(short_total),
            "need_check": True,
            "next_action": "等待复核",
        }

    async def register_shortage(self, dispense_id, body, user) -> dict:

            item.shortage_reason = s.get("reason")
        row.has_shortage = True
        await self._log(row, "SHORTAGE", None, row.status, user)
        await self.db.commit()
        return await self.get_detail(dispense_id, user)

    # ---------- 复核 ----------

    async def take_check(self, dispense_id: int, user) -> dict:

        return await self.get_detail(dispense_id, user)

    async def submit_check(self, dispense_id: int, body, user) -> dict:
        row = await self._lock_dispense(dispense_id)
        if row.status != "CHECKING":
            raise BizException(55532, "当前状态不允许提交复核")
        if row.checker_id != user["employee_id"]:
            raise BizException(55533, "该发药单由其他药师领取复核")
        if row.dispatcher_id == user["employee_id"]:
            raise BizException(55515, "调配与复核不得为同一人")

        result = body.get("result")
        now = datetime.now()

        if result == "PASS":
            checked = body.get("check_items") or {}
            missing = [k for k in self.CHECK_ITEMS if not checked.get(k)]
            if missing:
                raise BizException(55519, "请完成全部核对项")
            row.status = "CHECKED"
            row.checked_at = now
            row.check_result = "PASS"
            await self._log(row, "CHECK_PASS", "CHECKING", "CHECKED", user)
            await self.db.commit()
            queue_no, position = await self._enqueue_for_call(row)
            return {
                "dispense_id": row.id,
                "status": row.status,
                "status_text": "已复核",
                "checker_id": row.checker_id,
                "checker_name": row.checker_name,
                "checked_at": now,
                "queue_no": queue_no,
                "queue_position": position,
                "estimated_wait_seconds": position * 120,
            }

        # 复核不通过
        err_type = body.get("error_type")
        err_desc = (body.get("error_desc") or "").strip()
        if not err_type or len(err_desc) < 5:
            raise BizException(55520, "请选择差错类型并说明（至少 5 个字）")

        self.db.add(M14DispenseError(
            dispense_id=row.id,
            dispense_no=row.dispense_no,
            rx_no=row.rx_no,
            error_type=err_type,
            error_desc=err_desc,
            found_stage="CHECK",
            dispatcher_id=row.dispatcher_id,
            finder_id=user["employee_id"],
            finder_name=user["employee_name"],
            dispose_type=body.get("dispose_type", "REWORK"),
            found_at=now,
        ))
        row.status = "PREPARING"
        row.check_result = "REJECT"
        row.checker_id = None
        row.checker_name = None
        row.checking_at = None
        await self._log(row, "CHECK_REJECT", "CHECKING", "PREPARING", user)
        await self.db.commit()
        return {
            "dispense_id": row.id,
            "status": row.status,
            "status_text": "复核退回，重新调配",
            "error_type": err_type,
            "returned_at": now,
        }

    # ---------- 发药 ----------

    async def issue(self, dispense_id: int, body, user) -> dict:
        """确认发药：扣库存 → 回写 M07 → 置 DISPENSED"""
        row = await self._lock_dispense(dispense_id)
        self._check_transition(row.status, "DISPENSED")

        # 1. 发药与复核同一人校验（可配置）
        need_diff = await self._cfg_bool(
            "M14.DISPENSE.ISSUE_NEED_DIFFERENT", False)
        if need_diff and row.checker_id == user["employee_id"]:
            raise BizException(55527, "发药与复核不得为同一人")

        # 2. 交付药品不能为空
        issued = [i for i in body.items if Decimal(
            str(i.get("issued_qty", 0))) > 0]
        if not issued:
            raise BizException(55523, "请至少选择一项药品")

        # 3. 用药交代
        conf = body.instruction_confirmed or {}
        if not all(conf.get(k) for k in
                   ("usage", "precaution", "storage", "understood")):
            raise BizException(55524, "请完成用药交代确认")

        # 4. 签收
        if body.receiver_type and body.receiver_type != "SELF":
            if not body.receiver_relation:
                raise BizException(55525, "请填写代取人关系")
        if body.sign_type == "ELECTRONIC" and not body.signature:
            raise BizException(55526, "请患者签名")

        # 5. 缺药提示
        if row.has_shortage and not conf.get("shortage_notified"):
            raise BizException(55528, "请确认已告知患者缺药情况")

        now = datetime.now()
        issued_qty_total = Decimal("0.00")
        stock_items = []

        for payload in issued:
            item = await self._get_item(dispense_id, payload["item_id"])
            qty = Decimal(str(payload["issued_qty"]))
            if qty > item.dispensed_qty:
                raise BizException(55522, "发放数量不能超过调配数量")
            item.issued_qty = qty
            issued_qty_total += qty
            for b in await self._load_batches(item.id):
                stock_items.append({
                    "warehouse_id": row.warehouse_id,
                    "drug_id": item.drug_id,
                    "batch_id": b.batch_id,
                    "quantity": float(b.quantity),
                    "txn_type": "DISPENSE_OUT",
                    "source_type": "DISPENSE",
                    "source_id": row.id,
                    "source_no": row.dispense_no,
                })

        # 6. 扣库存（失败不阻断发药，进补偿队列）
        stock_result = await self._deduct_stock(row, stock_items)

        # 7. 置发药状态
        row.status = "DISPENSED"
        row.dispenser_id = user["employee_id"]
        row.dispenser_name = user["employee_name"]
        row.dispensed_at = now
        row.issued_qty_total = issued_qty_total
        row.receiver_type = body.receiver_type
        row.receiver_relation = body.receiver_relation
        row.sign_type = body.sign_type
        row.signature = body.signature
        row.returnable_until = now + timedelta(
            days=await self._cfg_int("M14.DISPENSE.RETURN_DAYS", 7))

        # 8. 回写 M07
        writeback = await self._writeback_dispensed(row)

        await self._log(row, "ISSUE", "CHECKED", "DISPENSED", user)
        await self.db.commit()

        await self._notify_issued(row)

        return {
            "dispense_id": row.id,
            "dispense_no": row.dispense_no,
            "status": row.status,
            "status_text": "已发药",
            "dispenser_id": row.dispenser_id,
            "dispenser_name": row.dispenser_name,
            "dispensed_at": now,
            "issued_item_count": len(issued),
            "issued_quantity": float(issued_qty_total),
            "stock_result": stock_result,
            "writeback": writeback,
            "returnable_until": row.returnable_until,
        }

    async def _deduct_stock(self, row, items: list) -> dict:
        if not items:
            return {"success": True, "affected_batches": 0, "txn_nos": []}
        try:
            result = await M14StockClient.apply(
                items=items,
                idempotency_key="DISPENSE:%d:OUT" % row.id,
            )
            return {
                "success": True,
                "affected_batches": len(items),
                "txn_nos": result.get("txn_nos", []),
            }
        except Exception as exc:                # noqa: BLE001
            logger.error(
                "库存扣减失败 dispense=%s: %s，进入补偿队列",
                row.id, exc)
            await self._push_compensation(row, items)
            return {
                "success": False,
                "affected_batches": 0,
                "txn_nos": [],
                "degraded": True,
                "reason": str(exc)[:200],
            }

    # ---------- 辅助 ----------

    async def _load_items(self, dispense_id: int):

                .where(M14DispenseItem.dispense_id == dispense_id)
                .order_by(M14DispenseItem.line_no))
        return list((await self.db.execute(stmt)).scalars().all())

    async def _load_batches(self, item_id: int):
        stmt = (select(M14DispenseBatch)
                .where(M14DispenseBatch.item_id == item_id,
                       M14DispenseBatch.quantity > 0))
        return list((await self.db.execute(stmt)).scalars().all())

    async def _get_item(self, dispense_id: int, item_id: int):
        stmt = select(M14DispenseItem).where(
            M14DispenseItem.id == item_id,
            M14DispenseItem.dispense_id == dispense_id)
        row = (await self.db.execute(stmt)).scalar_one_or_none()
        if row is None:
            raise BizException(55501, "发药明细不存在")
        return row

    async def _next_dispense_no(self, now: datetime) -> str:
        key = "m14:dispense:seq:%s" % now.strftime("%Y%m%d")
        seq = await self.redis.incr(key)
        if seq == 1:
            await self.redis.expire(key, 172800)
        if seq > 9999:
            raise BizException(55532, "当日发药单号已用尽")
        return "FY%s%04d" % (now.strftime("%Y%m%d"), seq)

    async def _log(self, row, action, old, new, user):
        self.db.add(M14DispenseLog(
            dispense_id=row.id,
            dispense_no=row.dispense_no,
            rx_no=row.rx_no,
            action=action,
            from_status=old,
            to_status=new,
            operator_id=user.get("employee_id"),
            operator_name=user.get("employee_name"),
            operator_ip=user.get("client_ip"),
            result="SUCCESS",
        ))

    async def _cfg_int(self, code: str, default: int) -> int:
        raw = await self.redis.hget("m14:dispense:config", code)
        if raw is None:
            return default
        try:
            return int(raw)
        except (TypeError, ValueError):
            return default

    async def _cfg_bool(self, code: str, default: bool) -> bool:
        raw = await self.redis.hget("m14:dispense:config", code)
        if raw is None:
            return default
        return str(raw).lower() in ("1", "true", "yes")


def _money(value) -> Decimal:
    return Decimal(str(value)).quantize(CENT, rounding=ROUND_HALF_UP)


def _parse_dt(value):
    if not value:
        return None
    if isinstance(value, datetime):
        return value
    try:
        return datetime.fromisoformat(str(value))
    except ValueError:
        return None
```

```python
import logging
from datetime import datetime
from decimal import Decimal

from sqlalchemy import select

from app.core.exceptions import BizException
from app.models.m14_dispense import (
    M14Dispense, M14DispenseBatch, M14DispenseItem,
    M14DispenseLog, M14DrugReturn, M14DrugReturnItem,
)
from app.services.clients import (
    BillingClient, M14StockClient, MessageClient, SpecialDrugClient,
)

logger = logging.getLogger(__name__)

CENT = Decimal("0.01")

# 退药原因
RETURN_REASONS = {
    "PATIENT_CANCEL": "患者不愿使用",
    "DOCTOR_ADJUST": "医生调整用药",
    "ADVERSE_REACTION": "药品不良反应",
    "QUALITY_ISSUE": "药品质量问题",
    "DUPLICATE": "重复开药",
    "CHARGE_ERROR": "收费错误",
    "OTHER": "其他",
}

# 判定结果
JUDGE_RESULTS = {
    "REUSABLE": ("包装完好，可再用", True),
    "OPENED": ("已开封", False),
    "DAMAGED": ("包装破损", False),
    "NEAR_EXPIRY": ("效期临近", False),
    "QUALITY": ("质量异常", False),
    "REFUSE": ("不予退药", False),
}


class DispenseReturnService:
    """门诊退药服务"""

    APPROVAL_THRESHOLD = Decimal("500.00")
    REASON_MIN_LEN = 10

    def __init__(self, db, redis):
        self.db = db
        self.redis = redis

    async def get_returnable(self, rx_no: str, user) -> dict:
        dispense = await self._get_dispensed(rx_no)
        items = []
        for item in await self._load_items(dispense.id):
            returned = await self._returned_qty(item.id)
            returnable = item.issued_qty - returned
            if returnable <= 0:
                continue
            items.append({
                "item_id": item.id,
                "drug_id": item.drug_id,
                "drug_name": item.drug_name,
                "specification": item.specification,
                "issued_qty": float(item.issued_qty),
                "returned_qty": float(returned),
                "returnable_qty": float(returnable),
                "unit_price": float(item.unit_price or 0),
                "amount": float(_money(
                    (item.unit_price or 0) * item.issued_qty)),
                "batches": [
                    {"batch_id": b.batch_id, "batch_no": b.batch_no,
                     "qty": float(b.quantity)}
                    for b in await self._load_batches(item.id)
                ],
                "is_special": bool(item.is_special),
                "is_cold_chain": bool(item.is_cold_chain),
            })

        now = datetime.now()
        deadline = dispense.returnable_until
        is_returnable = bool(items) and (
            deadline is None or now <= deadline)
        block_reason = None
        if not items:
            block_reason = "该处方无药品可退"
        elif not is_returnable:
            block_reason = "已超过退药时限"

        return {
            "rx_no": rx_no,
            "dispense_id": dispense.id,
            "patient_name": dispense.patient_name,
            "dispensed_at": dispense.dispensed_at,
            "days_since_dispense": (now - dispense.dispensed_at).days,
            "return_deadline": deadline,
            "is_returnable": is_returnable,
            "block_reason": block_reason,
            "items": items,
        }

    async def create_return(self, body, user) -> dict:
        """提交退药：判定 → 入库 → 通知退费"""
        dispense = await self._lock_dispense(body.dispense_id)
        if dispense.status not in ("DISPENSED", "RETURNED"):
            raise BizException(55532, "发药单状态不允许退药")

        payload_items = body.items or []
        if not payload_items:
            raise BizException(55510, "请至少选择一项退药")

        reason = body.return_reason
        if reason not in RETURN_REASONS:
            raise BizException(55513, "退药原因非法")
        desc = (body.reason_desc or "").strip()
        if len(desc) < self.REASON_MIN_LEN:
            raise BizException(55513, "请填写退药原因说明（至少 10 字）")

        now = datetime.now()
        rows = []
        total_amount = Decimal("0.00")
        reusable_items = []
        scrap_items = []

        for p in payload_items:
            item = await self._get_item(dispense.id, p["item_id"])
            qty = Decimal(str(p.get("return_qty", 0)))
            if qty <= 0:
                continue
            returned = await self._returned_qty(item.id)
            available = item.issued_qty - returned
            if qty > available:
                raise BizException(55509, "退药数量超出可退范围")

            judge = p.get("judge_result")
            if judge not in JUDGE_RESULTS:
                raise BizException(55514, "请选择药品状态判定")
            if judge == "REFUSE":
                raise BizException(55512, "该药品不予退药")

            # 麻精药品：仅质量问题可退
            if item.is_special and reason != "QUALITY_ISSUE":
                raise BizException(55512, "特殊管理药品不予退药")

            amount = _money((item.unit_price or 0) * qty)
            total_amount += amount
            reusable = JUDGE_RESULTS[judge][1]
            rows.append((item, qty, judge, amount, reusable))
            if reusable:
                reusable_items.append((item, qty))
            else:
                scrap_items.append((item, qty, judge))

        if not rows:
            raise BizException(55510, "请至少选择一项退药")

        # 退药时限（质量问题不受限）
        if reason != "QUALITY_ISSUE":
            deadline = dispense.returnable_until
            if deadline is not None and now > deadline:
                raise BizException(55507, "已超过退药时限（7 天）")

        # 大额退药转审批
        need_approve = total_amount > self.APPROVAL_THRESHOLD
        status = "PENDING_APPROVAL" if need_approve else "COMPLETED"

        ret = M14DrugReturn(
            return_no=await self._next_return_no(now),
            dispense_id=dispense.id,
            dispense_no=dispense.dispense_no,
            rx_no=dispense.rx_no,
            patient_id=dispense.patient_id,
            patient_name=dispense.patient_name,
            return_reason=reason,
            reason_desc=desc,
            return_type=body.return_type or "NORMAL",
            return_qty=sum(q for _, q, _, _, _ in rows),
            return_amount=total_amount,
            status=status,
            returned_by=user["employee_id"],
            returned_by_name=user["employee_name"],
            returned_at=now,
            warehouse_id=dispense.warehouse_id,
        )
        self.db.add(ret)
        await self.db.flush()

        for item, qty, judge, amount, reusable in rows:
            self.db.add(M14DrugReturnItem(
                return_id=ret.id,
                return_no=ret.return_no,
                dispense_item_id=item.id,
                drug_id=item.drug_id,
                drug_name=item.drug_name,
                specification=item.specification,
                return_qty=qty,
                judge_result=judge,
                is_reusable=reusable,
                unit_price=item.unit_price,
                amount=amount,
                batch_id=p_batch_id(rows, item),
            ))

        await self.db.commit()

        # 可再用药品入库
        stock_result = {"success": True, "txn_no": None}
        if reusable_items and status == "COMPLETED":
            stock_result = await self._stock_in(dispense, ret, reusable_items)

        # 报废登记
        scrap_qty = sum(q for _, q, _ in scrap_items)
        if scrap_items:
            await self._register_scrap(dispense, ret, scrap_items)

        # 通知 M16 退费
        refund_notice = {"success": False}
        if status == "COMPLETED":
            refund_notice = await self._notify_refund(dispense, ret)

        return {
            "return_id": ret.id,
            "return_no": ret.return_no,
            "dispense_id": dispense.id,
            "rx_no": dispense.rx_no,
            "status": ret.status,
            "status_text": ("已完成" if status == "COMPLETED"
                            else "待审批"),
            "return_qty": float(ret.return_qty),
            "return_amount": float(ret.return_amount),
            "stock_result": stock_result,
            "refund_notice": refund_notice,
            "scrap_qty": float(scrap_qty),
            "created_at": now,
        }

    async def _stock_in(self, dispense, ret, items) -> dict:
        """退回药品入原批次"""
        payload = []
        for item, qty in items:
            for b in await self._load_batches(item.id):
                if b.quantity <= 0:
                    continue
                take = min(b.quantity, qty)
                payload.append({
                    "warehouse_id": dispense.warehouse_id,
                    "drug_id": item.drug_id,
                    "batch_id": b.batch_id,
                    "batch_no": b.batch_no,
                    "expiry_date": b.expiry_date,
                    "quantity": float(take),
                    "txn_type": "RETURN_IN",
                    "source_type": "DRUG_RETURN",
                    "source_id": ret.id,
                    "source_no": ret.return_no,
                })
                qty -= take
                if qty <= 0:
                    break
        if not payload:
            return {"success": True, "txn_no": None, "skipped": True}
        try:
            result = await M14StockClient.apply(
                items=payload,
                idempotency_key="DRUGRETURN:%d:IN" % ret.id,
            )
            return {"success": True,
                    "txn_no": (result.get("txn_nos") or [None])[0]}
        except Exception as exc:                # noqa: BLE001
            logger.error("退药入库失败 return=%s: %s", ret.id, exc)
            await self._push_compensation(ret, payload)
            return {"success": False, "txn_no": None,
                    "reason": str(exc)[:200]}

    async def _notify_refund(self, dispense, ret) -> dict:
        try:
            result = await BillingClient.apply_refund(
                settlement_id=dispense.settlement_id,
                source_type="DRUG_RETURN",
                source_id=ret.id,
                source_no=ret.return_no,
                amount=float(ret.return_amount),
                reason=ret.return_reason,
            )
            return {
                "success": True,
                "refund_no": result.get("refund_no"),
                "refund_amount": result.get("refund_amount"),
            }
        except Exception as exc:                # noqa: BLE001
            logger.error("退费通知失败 return=%s: %s", ret.id, exc)
            return {"success": False, "reason": str(exc)[:200]}

    async def _returned_qty(self, item_id: int) -> Decimal:
        stmt = select(M14DrugReturnItem.return_qty).where(
            M14DrugReturnItem.dispense_item_id == item_id,
            M14DrugReturnItem.is_cancelled.is_(False))
        rows = (await self.db.execute(stmt)).scalars().all()
        return sum((r or Decimal("0")) for r in rows) or Decimal("0")

    async def _get_dispensed(self, rx_no: str) -> M14Dispense:
        stmt = (select(M14Dispense)
                .where(M14Dispense.rx_no == rx_no,
                       M14Dispense.status == "DISPENSED",
                       M14Dispense.is_deleted.is_(False))
                .order_by(M14Dispense.id.desc()).limit(1))
        row = (await self.db.execute(stmt)).scalar_one_or_none()
        if row is None:
            raise BizException(55511, "未找到已发药记录")
        return row

    async def _next_return_no(self, now: datetime) -> str:
        key = "m14:dispense:return:seq:%s" % now.strftime("%Y%m%d")
        seq = await self.redis.incr(key)
        if seq == 1:
            await self.redis.expire(key, 172800)
        return "TY%s%04d" % (now.strftime("%Y%m%d"), seq)
```

## 11. 异常处理与日志

### 11.1 异常分类

| 类别 | 场景 | 处理 | 用户提示 |
|---|---|---|---|

## 附录 C：术语表

| 术语 | 说明 |
|---|---|
| **FEFO** | First Expired First Out，先到期先出 |
| **FIFO** | First In First Out，先进先出 |
| **调配** | 按处方从货架取药、贴标签、装筐 |
| **复核** | 第二人比对药品与处方一致性 |
| **发药** | 将药品交付患者并做用药交代 |
| **用药交代** | 向患者说明用法用量、注意事项、储存方式 |
| **拆零** | 将整包装药品拆分为最小单位发放 |
| **预调配** | 缴费后即开始配药，患者到窗口直接取 |
| **差错** | 调配或发药过程中发现的不一致 |
| **报损** | 因破损、开封、过期等原因导致的库存损失 |
