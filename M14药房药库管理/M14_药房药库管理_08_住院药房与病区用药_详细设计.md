## 1. 模块概述

### 1.1 模块定位

M14-08 住院药房与病区用药，是药房与病区之间的**周期性供给通道**。它回答一个问题：

> **在院患者的长期医嘱，药是怎么一趟一趟从药房送到病区床边的。**

```
┌──────────────────────────────────────────────────────────────────────┐
│                      住院用药全链路                                   │
├──────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  M07 医生工作站                                                       │
│      │  长期医嘱 SAVED / 临时医嘱                                         │
│      ▼                                                               │
│  M14-06 处方审核（住院医嘱审核）                                        │
│      │  PASSED                                                       │
│      ▼                                                               │
│  ┌─────────────────────────────────────────────────────────────────┐  │
│  │              M14-08 住院药房与病区用药                           │  │
│  │                                                                 │  │
│  │  ① 医嘱接收（长期医嘱按频次拆日，临时医嘱单次）                 │  │
│  │  ② 摆药（按病区 + 按摆药时段，每日 3~4 次）                     │  │
│  │  ③ 单剂量分包（可选：口服药按次分包，贴患者条码）               │  │
│  │  ④ 病区发放（药车送达，护士扫码签收）                           │  │
│  │  ⑤ 病区用药执行（护士执行，M08 回写）                           │  │
│  │  ⑥ 退药（停医嘱 / 出院 退回药房）                               │  │
│  │                                                                 │  │
│  │  库存扣减：M14-01 唯一入口                                      │  │
│  └─────────────────────────────────────────────────────────────────┘  │
│      │                                                               │
│      ▼                                                               │
│  M16 住院结算（费用记账）                                             │
│                                                                      │
└──────────────────────────────────────────────────────────────────────┘
```

**一句话职责：** M14-08 负责「让在院患者每天该吃的药，按时、按人、按量出现在病区」。

### 1.2 为什么独立成子模块

M14-07 门诊发药与 M14-08 住院药房，看起来都是「把药给患者」，但两者的业务节奏、责任主体、出错后果完全不同，必须分开设计：

| 维度 | M14-07 门诊发药 | M14-08 住院药房与病区用药 |
|---|---|---|
| **触发方式** | 患者到窗口，逐张处方触发 | 按摆药时段批量触发，与患者无需见面 |
| **触发频率** | 一天 350 次，集中在上午 | 一天 3~4 次批量，全病区一起做 |
| **单次规模** | 1 张处方（1~5 个药品） | 1 个病区（20~40 张床位 × 5~10 个医嘱） |
| **计量方式** | 整盒 / 拆零到支 | 按次、按日、单剂量分包 |
| **交付对象** | 患者本人或家属（当面签字） | 病区护士（扫码签收），再由护士给患者 |
| **执行责任** | 药师发药即完成 | 发药只是第一步，真正用药在病区执行 |
| **差错发现** | 患者当场或 7 天内退回 | 摆药后护士核对时发现，跨科室协同 |
| **退回处理** | 退药后可直接退费 | 退回后需冲减住院费用账（M16-03） |
| **失败后果** | 患者多跑一趟 | 患者该吃的药没送到，影响治疗 |

**五条独立理由：**

**理由一：门诊是「人找药」，住院是「药找人」**

门诊的药房窗口是按患者的到访节奏工作的：患者缴费、排队、到窗口、取药、离开。药房只在患者出现的那一刻提供服务。

住院完全不同：患者固定在病床上，无法到药房。药房必须**主动、周期性地**把药送到病区。这决定了住院必须按「病区 + 时段」组织批量作业，而门诊必须按「单张处方」组织单点作业。

在一个子模块里做两种作业组织方式，会让所有代码都要 `if 门诊 then ... else ...`。

**理由二：住院有「摆药」这个门诊完全没有的环节**

摆药是指：把一位患者未来 24 小时（或某个时段）所有医嘱的药，从各个批次的药架上一一取下，汇总到同一个药筐里。

这个过程的特点：

- 一次处理多个患者（一个病区）
- 每位患者多个医嘱、多个批次
- 需要一个可移动的载具（药车 / 药筐 / 分包袋）
- 需要与病区护士交接签字

门诊没有这个环节——门诊的药是「一张处方一个袋子，直接给患者」。把摆药塞进门诊发药，会让 `m14_dispense` 表塞满两种完全不同的业务语义。

**理由三：住院是「频次驱动」，门诊是「处方驱动」**

一张住院长期医嘱写的是「左氧氟沙星滴眼液 每日 4 次，连用 7 天」，系统要把它展开成：

```
第 1 天：4 次 → 每次 1 滴
第 2 天：4 次
...
第 7 天：4 次
共 28 次
```

每一次执行都是一个独立的「摆药 + 执行 + 记账」单元。这个展开逻辑（频次 × 天数 → 执行计划）是住院药房的核心，门诊完全没有。

**理由四：单剂量分包是住院特有的药学服务**

眼科住院患者常同时使用 3~5 种滴眼液，频次各不相同（每日 2 次 / 每日 4 次 / 睡前 1 次）。手工点药极易出错。

单剂量分包机把「某患者某时点要用的所有药」包成一小袋，袋上打印患者姓名、床号、时间、药品清单。护士按袋子给药，不必自己数。

这个环节涉及：分包机对接、分包记录、分包核对、分包差错，属于独立的业务能力。

**理由五：退药的下游完全不同**

| 环节 | 门诊退药 | 住院退药 |
|---|---|---|
| 触发 | 患者拿药回来 | 医嘱停止 / 患者出院 / 药未使用 |
| 判定方 | 窗口药师看实物 | 病区护士 + 药房药师共同核对 |
| 库存 | 回原批次，可能可再用 | 未拆封的可再用，已拆封的报废 |
| 财务 | 走 M16-08 退费 | 冲减住院费用账（M16-03），不是退现金 |
| 时效 | 有 7 天时限 | 出院结算前必须全部处理完 |

如果合并，退药逻辑要分成两套，反而更复杂。

### 1.4 概念辨析

| 概念 | 定义 | 易混淆点 |
|---|---|---|
| **摆药** | 按病区把医嘱药品汇总到药车/药筐 | ≠ 发药（摆药还在药房内） |
| **病区发放** | 药车送达病区，护士签收 | ≠ 患者用药（还没给患者） |
| **单剂量分包** | 把某时点的药包成一袋 | ≠ 拆零（拆零是包装规格变化） |
| **长期医嘱** | 反复执行的医嘱，有频次 | ≠ 临时医嘱（执行一次即止） |
| **执行计划** | 系统按频次展开的每日摆药清单 | ≠ 医嘱本身（计划是医嘱的投影） |
| **退药** | 病区把未用的药退回药房 | ≠ 退费（退药是实物，退费是钱） |

### 1.5 模块目标

| 指标 | 目标值 | 测算方式 |
|---|---|---|
| 摆药准确率 | ≥ 99.8% | 1 − 摆药差错笔数 / 摆药总笔数 |
| 病区签收及时率 | ≥ 98% | 药车送达 30 分钟内签收的占比 |
| 单剂量分包差错率 | ≤ 0.05% | 分包差错袋数 / 分包总袋数 |
| 摆药耗时（单病区 30 人） | ≤ 15 分钟 | 从开始摆药到药车出库 |
| 退药处理时效 | ≤ 4 小时 | 申请到入库完成 |
| 缺药响应时效 | ≤ 30 分钟 | 缺药告警到调拨到位 |

## 2. 业务范围与边界

### 2.1 范围内

1. **住院医嘱接收**：从 M07 拉取已审核通过的住院医嘱，落本地快照
2. **执行计划生成**：按频次 × 天数展开成每日摆药清单
3. **摆药单管理**：按病区、按时段生成摆药单，支持增删改
4. **摆药执行**：按批次 FEFO 取药，记录每个药品的来源批次
5. **单剂量分包**：将同一时点的多种药品包成一袋，生成分包记录与条码
6. **药车装车与出库**：按病区装车，出库扣减药房库存
7. **病区签收**：护士扫码签收，差异登记
8. **退药管理**：停医嘱 / 出院退药，质量判定，回原批次入库
9. **缺药处理**：缺药告警、跨药房调拨、替代药品建议
10. **住院药房台账与统计**：摆药明细、分包明细、退药明细、工作量统计

## 3. 业务模型

### 3.1 医嘱到摆药的四步转换

```
住院长期医嘱（M07）
  「左氧氟沙星滴眼液 0.5%  OD 每日4次 每次1滴 连用7天」
        │
        │ ① 频次展开
        ▼
执行计划（freq × days）
  D1: 08:00 12:00 16:00 20:00
  D2: 08:00 12:00 16:00 20:00
  ...
  D7: 08:00 12:00 16:00 20:00
  共 28 个执行点
        │
        │ ② 按时段归并（一天 3 个摆药时段）
        ▼
摆药时段桶
  上午（08:00）：7 次 → 7 支
  下午（12:00+16:00）：14 次 → 14 支
  晚间（20:00）：7 次 → 7 支
        │
        │ ③ 按病区汇总
        ▼
摆药单（1 病区 × 1 时段）
  ADM001 张三 3床  左氧氟沙星 7 支
  ADM002 李四 5床  左氧氟沙星 3 支 + 玻璃酸钠 3 支
  ...
        │
        │ ④ 按批次拆解
        ▼
摆药批次明细
  ADM001 → 批次 240815 取 5 支 + 批次 241102 取 2 支（FEFO）
```

**为什么按「时段」归并而不是按「天」？**

因为病区护士是按班次给药的：早班给上午的药，中班给下午的药。如果一次把 24 小时的药全发过去，护士要自己分三次摆，等于把药房的工作推给了病区。

### 3.2 三种摆药模式

| 模式 | 说明 | 适用场景 | 优缺点 |
|---|---|---|---|
| **汇总摆药** | 按病区把药汇总，护士自己分配 | 床位少、药品种类少 | 简单，但护士分药易错 |
| **单剂量分包** | 按患者 × 时点分装成袋 | 口服药多、频次复杂 | 准确，但需要分包机 |
| **单患者摆药** | 按患者汇总到药筐 | 眼科最常见（3~5 种滴眼液） | 平衡点在准确与成本之间 |

**眼科默认：单患者摆药 + 单剂量分包（口服药）**

滴眼液不需要分包（本身就是单支），按患者装筐即可。口服药（如泼尼松片）需要分包。

### 3.3 摆药时段

| 时段代码 | 名称 | 默认时间 | 覆盖频次 |
|---|---|---|---|
| `MORNING` | 上午 | 08:00 | QD（上午）、BID（第一次）、TID（第一次）、QID（第一次） |
| `NOON` | 中午 | 12:00 | BID（第二次）、TID（第二次）、QID（第二次） |
| `AFTERNOON` | 下午 | 16:00 | TID（第三次）、QID（第三次） |
| `EVENING` | 晚间 | 20:00 | QD（晚间）、QID（第四次）、QN |
| `STAT` | 临时 | 即时 | 临时医嘱（ST） |

**频次到时段映射表：**

| 频次代码 | 含义 | 时段 |
|---|---|---|
| `QD` | 每日一次 | MORNING |
| `QN` | 每晚一次 | EVENING |
| `BID` | 每日两次 | MORNING, NOON |
| `TID` | 每日三次 | MORNING, NOON, AFTERNOON |
| `QID` | 每日四次 | MORNING, NOON, AFTERNOON, EVENING |
| `Q8H` | 每 8 小时 | MORNING, NOON, EVENING |
| `Q6H` | 每 6 小时 | MORNING, NOON, AFTERNOON, EVENING |
| `QOD` | 隔日一次 | MORNING（按起始日奇偶） |
| `QW` | 每周一次 | MORNING（按星期） |
| `PRN` | 必要时 | 不摆药（病区按需申请） |
| `ST` | 立即一次 | STAT |

### 3.4 状态机

#### 3.4.1 摆药单状态机（`m14_ward_dispense`）

```
                    ┌──────────┐
                    │ DRAFT    │  新建（系统自动生成或人工创建）
                    └────┬─────┘
                         │ generate / confirm
                         ▼
                    ┌──────────┐
              ┌─────│ PENDING  │─────┐  待摆药
              │     └────┬─────┘     │
              │ cancel   │ start     │ cancel
              │          ▼           │
              │     ┌──────────┐     │
              │     │PREPARING │     │  摆药中
              │     └────┬─────┘     │
              │          │ submit    │
              │          ▼           ▼
              │     ┌──────────┐  ┌───────────┐
              │     │ PREPARED │  │ CANCELLED │ 终态
              │     └────┬─────┘  └───────────┘
              │          │ check（第二人复核）
              │          ▼
              │     ┌──────────┐
              │     │ CHECKED  │  已复核，待装车
              │     └────┬─────┘
              │          │ ship（装车出库）
              │          ▼
              │     ┌──────────┐
              │     │ SHIPPED  │  在途中
              │     └────┬─────┘
              │          │ receive（病区签收）
              │          ▼
              │     ┌──────────┐
              │     │RECEIVED  │  已签收
              │     └────┬─────┘
              │          │ return（退药）／ close
              │          ▼
              │     ┌──────────┐
              │     │ RETURNED │  部分退药
              │     │  /CLOSED │  终态
              └────►└──────────┘
```

**状态说明：**

| 状态 | 说明 | 可执行动作 |
|---|---|---|
| `DRAFT` | 草稿，可增删明细 | generate / cancel |
| `PENDING` | 待摆药，已锁定 | start / cancel |
| `PREPARING` | 摆药中 | submit / cancel |
| `PREPARED` | 摆药完成，待复核 | check |
| `CHECKED` | 复核通过，待装车 | ship |
| `SHIPPED` | 已出库在途 | receive |
| `RECEIVED` | 病区已签收 | return / close |
| `RETURNED` | 有退药 | close |
| `CLOSED` | 已关闭 | — |
| `CANCELLED` | 已作废 | — |

**关键设计决策：为什么 `CHECKED` 与 `SHIPPED` 之间要拆开？**

复核完成到装车出库之间，可能间隔 1~2 小时（早班 6:30 复核完，7:30 统一装车）。

如果合并，会出现：
- 库存已经扣了，但药还在药房货架上
- 病区查「药到哪了」看到「已发出」，实际还在药房
- 无法统计「复核完成到实际出库」的等待时长

### 3.5 单剂量分包模型

```
分包袋 = 1 患者 × 1 时点 × 该时点全部口服药

┌────────────────────────────────┐
│ 眼科医院 2026-10-22            │
│ 姓名：张三  床号：3床           │
│ 时间：08:00  第 1 次/日         │
├────────────────────────────────┤
│ ○ 泼尼松片 5mg × 2 片          │
│ ○ 甲钴胺片 0.5mg × 1 片        │
├────────────────────────────────┤
│ [条码] PKG202610220001234      │
└────────────────────────────────┘
```

**分包规则：**
1. 只分包口服固体药品（片剂、胶囊），液体、滴眼液、注射剂不参与
2. 同一时点多个药品包成一袋
3. 每个分包袋生成唯一条码，护士扫码执行
4. 分包袋可打印、可重打（最多 3 次）
5. 分包记录保留 3 年

### 3.6 退药模型

| 退药场景 | 触发 | 时限 | 判定 | 库存处理 |
|---|---|---|---|---|
| **医嘱停止** | M07 停医嘱 | 24 小时内 | 病区护士确认未使用 | 回原批次 |
| **患者出院** | M05 出院（当前由 M07 触发） | 出院前 | 药房与病区共同核对 | 未拆封回原批次，已拆封报废 |
| **医嘱变更** | 剂量/药品变更 | 24 小时内 | 未使用的部分 | 回原批次 |
| **转科** | 患者转病区 | 24 小时内 | 已摆未用的药 | 回原批次 |
| **药品召回** | M14-02 召回 | 立即 | 全部退回 | 隔离待处置 |
| **药房错发** | 摆药差错 | 不限 | 药房责任 | 回原批次并报废重发 |

**退药五问判定（与 M14-07 一致）：**

1. 是否在时限内？
2. 是否开封？
3. 包装是否完好？
4. 是否特殊管理药品？
5. 是否冷链药品？冷链是否断链？

**判定结果：**

| 判定 | 说明 | 库存 |
|---|---|---|
| `REUSABLE` | 包装完好、未开封、在效期内 | 回原批次 |
| `OPENED` | 已开封 | 报废 |
| `DAMAGED` | 包装破损 | 报废 |
| `NEAR_EXPIRY` | 退回后效期不足 90 天 | 报废或退厂 |
| `QUALITY` | 质量问题 | 隔离待检 |
| `REFUSE` | 不予退药 | 无变化 |

### 3.7 缺药处理

```
摆药时发现批次可用量不足
        │
        ├─ ① 本仓库其他批次有货 → 自动切换批次（FEFO 继续找）
        │
        ├─ ② 兄弟药房有货 → 发起调拨申请（M14-04）
        │
        ├─ ③ 全院无货 → 标记缺药
        │      │
        │      ├─ 替代药品建议（同通用名不同规格 / 同药理类）
        │      ├─ 通知医生（M03-05）
        │      ├─ 缺药数量记为 0，摆药单标 has_shortage=TRUE
        │      └─ 触发采购补货提醒（M14-02）
        │
        └─ ④ 紧急 → 紧急采购 / 借药
```

**缺药处理时效：** 30 分钟内必须有结论（调拨 / 替代 / 缺货告知）。

### 3.8 与门诊发药的核心差异对照

| 维度 | 门诊（M14-07） | 住院（M14-08） |
|---|---|---|
| 业务单元 | 发药单 = 1 张处方 | 摆药单 = 1 病区 × 1 时段 |
| 明细层级 | 发药明细 → 发药批次 | 摆药明细 → 摆药批次 → 分包记录 |
| 交付对象 | 患者/家属 | 病区护士 |
| 签收方式 | 患者签字 | 护士扫码 + 电子签名 |
| 库存扣减时点 | 确认发药时 | **装车出库时** |
| 可退时限 | 7 天 | 出院结算前 |
| 退药财务 | 退费（M16-08） | 冲减住院账（M16-03） |
| 并发特征 | 5 窗口并发 | 单病区批量（一人操作） |

```python
import calendar
from datetime import date, datetime, timedelta
from decimal import Decimal

from fastapi import HTTPException

CENT = Decimal("0.01")

PERIOD_TIME_MAP = {
    "MORNING": "08:00",
    "NOON": "12:00",
    "AFTERNOON": "16:00",
    "EVENING": "20:00",

FREQ_PERIOD_MAP = {
    "QD": ["MORNING"],
    "QN": ["EVENING"],
    "BID": ["MORNING", "NOON"],
    "TID": ["MORNING", "NOON", "AFTERNOON"],
    "QID": ["MORNING", "NOON", "AFTERNOON", "EVENING"],
    "Q8H": ["MORNING", "NOON", "EVENING"],

ORAL_SOLID_FORMS = ("片剂", "胶囊", "颗粒", "散剂", "丸剂")

CHECK_ITEMS = (
    "patient_count", "drug_name", "quantity", "expiry",
    "label", "special_locked", "cold_chain", "seal",
)

MAX_RETURN_APPROVAL = Decimal("500.00")
RETURN_REASON_MIN_LEN = 10

DISPENSE_TRANSITIONS = {
    "DRAFT": ("PENDING", "CANCELLED"),
    "PENDING": ("PREPARING", "CANCELLED"),
    "PREPARING": ("PREPARED", "CANCELLED"),
    "PREPARED": ("CHECKED", "PREPARING"),
    "CHECKED": ("SHIPPED",),
    "SHIPPED": ("RECEIVED", "CHECKED"),
    "RECEIVED": ("RETURNED", "CLOSED"),
    "RETURNED": ("CLOSED",),
    "CLOSED": (),
    "CANCELLED": (),
}


def money(value):
    return Decimal(str(value)).quantize(CENT)


class InpatientService:
    """住院药房与病区用药核心服务"""

    def __init__(self, db: AsyncSession, user: dict):
        self.db = db
        self.user = user

    # ---------- 执行计划展开 ----------

    def expand_exec_plan(self, order: dict, period: str,
                         target_date: date):
        """把一条住院医嘱展开成某日的执行点数量

        返回该医嘱在 target_date 的 period 时段内的执行次数
        """
        freq = order.get("frequency", "")
        periods = FREQ_PERIOD_MAP.get(freq, [])
        if period not in periods:
            return 0

        start = order.get("start_date")
        days = order.get("days") or 0
        if not start or days <= 0:
            return 0

        elapsed = (target_date - start).days
        if elapsed < 0 or elapsed >= days:
            return 0

        if freq == "QOD" and elapsed % 2 != 0:
            return 0

        if freq == "QW" and start.weekday() != target_date.weekday():
            return 0

        return 1

    # ---------- 生成摆药单 ----------

    async def generate(self, body):
        from app.models.m14_inpatient import (
            M14WardDispense, M14WardDispenseItem)

        created = []
        skipped = []
        seq = 0

        for ward_id in body.ward_ids:
            exists = await self._find_active(
                body.dispense_date, body.period, ward_id)
            if exists:
                skipped.append({
                    "ward_id": ward_id,
                    "ward_name": exists.ward_name,
                    "reason": "该病区该时段已存在摆药单",
                })
                continue

            patients = await self._load_ward_patients(ward_id)
            if not patients:
                skipped.append({
                    "ward_id": ward_id,
                    "ward_name": None,
                    "reason": "该病区无在院患者",
                })
                continue

            rows = []
            for p in patients:
                for order in p["orders"]:
                    cnt = self.expand_exec_plan(
                        order, body.period, body.dispense_date)
                    if cnt <= 0:
                        continue
                    qty = Decimal(str(order.get("dose_qty", 1))) * cnt
                    rows.append({
                        "patient": p,
                        "order": order,
                        "qty": qty,
                    })

            if not rows:
                skipped.append({
                    "ward_id": ward_id,
                    "ward_name": patients[0]["ward_name"],
                    "reason": "该时段无应执行医嘱",
                })
                continue

            seq += 1
            dispense_no = "WD%s%s%02d" % (
                body.dispense_date.strftime("%Y%m%d"),
                body.period[0], seq)

            head = M14WardDispense(
                dispense_no=dispense_no,
                dispense_date=body.dispense_date,
                period=body.period,
                period_time=PERIOD_TIME_MAP.get(body.period),
                ward_id=ward_id,
                ward_name=patients[0]["ward_name"],
                warehouse_id=body.warehouse_id,
                patient_count=len({r["patient"]["admission_id"]
                                   for r in rows}),
                item_count=len(rows),
                total_qty=sum(r["qty"] for r in rows),
                shortage_count=0,
                status="PENDING",
                created_by=self.user["employee_id"],
            )
            self.db.add(head)
            await self.db.flush()

            for idx, r in enumerate(rows, start=1):
                self.db.add(M14WardDispenseItem(
                    dispense_id=head.id,
                    dispense_no=head.dispense_no,
                    seq_no=idx,
                    admission_id=r["patient"]["admission_id"],
                    admission_no=r["patient"]["admission_no"],
                    bed_no=r["patient"]["bed_no"],
                    patient_id=r["patient"]["patient_id"],
                    patient_name=r["patient"]["patient_name"],

            row.checking_at = None

        await self.db.commit()

    async def ship(self, dispense_id, body):
        from app.clients.m14_stock import M14StockClient
        from app.models.m14_inpatient import M14WardDispenseItem

        row = await self._lock_dispense(dispense_id)

        if row.status != "CHECKED":
            raise HTTPException(status_code=400, detail={
                "code": "1408004",
                "message": "摆药单状态不允许此操作",
            })

        stmt = (
            select(M14WardDispenseItem)
            .where(M14WardDispenseItem.dispense_id == dispense_id)
            .where(M14WardDispenseItem.status == "PREPARED")
        )
        res = await self.db.execute(stmt)
        items = res.scalars().all()

        has_cold = any(i.is_cold_chain for i in items)
        if has_cold and not body.cooler_no:
            raise HTTPException(status_code=400, detail={
                "code": "1408011",
                "message": "冷链药品必须指定保温箱",
            })

        payload = []
        for it in items:
            payload.append({
                "warehouse_id": row.warehouse_id,
                "batch_id": it.batch_id,
                "quantity": float(it.prepared_qty),
            })

        client = M14StockClient()
        result = await client.apply(
            direction="OUT",
            txn_type="WARD_DISPENSE_OUT",
            items=payload,
            idempotency_key="WARDDISPENSE:%d:OUT" % dispense_id,
        )

        if not result.get("success"):
            raise HTTPException(status_code=503, detail={
                "code": "1408003",
                "message": "库存服务不可用",
            })

        row.status = "SHIPPED"
        row.cart_no = body.cart_no
        row.cooler_no = body.cooler_no
        row.seal_no = body.seal_no
        row.shipped_at = datetime.now()
        row.shipped_by = self.user["employee_id"]
        await self.db.commit()

        return {
            "dispense_id": dispense_id,
            "dispense_no": row.dispense_no,
            "status": row.status,
            "shipped_at": row.shipped_at.isoformat(),
            "stock_result": result,
        }

    async def create_return(self, body):
        from app.clients.m14_stock import M14StockClient
        from app.models.m14_inpatient import (
            M14WardDispenseItem, M14WardReturn, M14WardReturnItem)

        items = body.items or []
        if not items:
            raise HTTPException(status_code=400, detail={
                "code": "1408020",
                "message": "退药明细不能为空",
            })
        if not body.reason_desc or len(
                body.reason_desc.strip()) < RETURN_REASON_MIN_LEN:
            raise HTTPException(status_code=400, detail={
                "code": "1408021",
                "message": "退药原因说明不足 10 字",
            })

        total_amount = Decimal("0.00")
        total_qty = Decimal("0")
        rows = []

        for it in items:
            src = await self.db.get(
                M14WardDispenseItem, it["dispense_item_id"])
            if src is None:
                raise HTTPException(status_code=404, detail={
                    "code": "1408020",
                    "message": "原摆药明细不存在",
                })

            qty = Decimal(str(it["quantity"]))
            if qty <= 0 or qty > src.issued_qty - src.returned_qty:
                raise HTTPException(status_code=400, detail={
                    "code": "1408020",
                    "message": "退药数量超过已签收数量",
                })

            if src.batch_id != it.get("batch_id"):
                raise HTTPException(status_code=400, detail={
                    "code": "1408027",
                    "message": "退药批次与发药批次不一致",
                })

            amount = money(Decimal(str(src.unit_price or 0)) * qty)
            total_amount += amount
            total_qty += qty
            rows.append((src, qty, amount))

        need_approve = total_amount > MAX_RETURN_APPROVAL
        status = "PENDING_APPROVE" if need_approve else "PENDING_JUDGE"

        head = M14WardReturn(
            return_no=await self._next_return_no(),
            dispense_id=body.dispense_id,
            admission_id=body.admission_id,
            return_reason=body.return_reason,
            reason_desc=body.reason_desc,
            total_qty=total_qty,
            total_amount=total_amount,
            status=status,
            need_approve=need_approve,
            requested_by=self.user["employee_id"],
            requested_by_name=self.user.get("employee_name"),
            requested_at=datetime.now(),
        )
        self.db.add(head)
        await self.db.flush()

        for idx, (src, qty, amount) in enumerate(rows, start=1):
            self.db.add(M14WardReturnItem(
                return_id=head.id,
                return_no=head.return_no,
                seq_no=idx,
                dispense_item_id=src.id,
                drug_id=src.drug_id,
                drug_name=src.drug_name,
                specification=src.specification,
                batch_id=src.batch_id,
                batch_no=src.batch_no,
                quantity=qty,
                unit_price=src.unit_price,
                amount=amount,
            ))

        await self.db.commit()

        return {
            "return_id": head.id,
            "return_no": head.return_no,
            "dispense_no": head.dispense_no,
            "item_count": len(rows),
            "total_qty": float(total_qty),
            "total_amount": float(total_amount),
            "status": head.status,
            "need_approve": need_approve,
            "created_at": head.requested_at.isoformat(),
        }

    async def judge_return(self, return_id, body):
        from app.clients.m14_stock import M14StockClient
        from app.clients.m16_inpatient import M16InpatientClient
        from app.models.m14_inpatient import (
            M14WardReturn, M14WardReturnItem)

        row = await self.db.get(M14WardReturn, return_id)
        if row is None:
            raise HTTPException(status_code=404, detail={
                "code": "1408026", "message": "退药单不存在"})
        if row.status != "PENDING_JUDGE":
            raise HTTPException(status_code=400, detail={
                "code": "1408026", "message": "退药单状态不允许此操作"})

        stmt = select(M14WardReturnItem).where(
            M14WardReturnItem.return_id == return_id)
        res = await self.db.execute(stmt)
        items = res.scalars().all()

        reusable = []
        scrap_qty = Decimal("0")

        for it in items:
            judge = (body.get("items") or {}).get(str(it.id))
            if not judge:
                raise HTTPException(status_code=400, detail={
                    "code": "1408026", "message": "请完成全部明细的判定"})
            it.judge_result = judge
            if judge == "REUSABLE":
                it.is_reusable = True
                reusable.append(it)
            else:
                it.is_reusable = False
                scrap_qty += it.quantity

        stock_result = {"success": True, "txn_nos": []}
        if reusable:
            client = M14StockClient()
            stock_result = await client.apply(
                direction="IN",
                txn_type="WARD_RETURN_IN",
                items=[
                    {
                        "warehouse_id": row.warehouse_id,
                        "batch_id": r.batch_id,
                        "quantity": float(r.quantity),
                    }
                    for r in reusable
                ],
                idempotency_key="WARDRETURN:%d:IN" % return_id,
            )

        row.status = "COMPLETED"
        row.completed_at = datetime.now()
        row.judged_by = self.user["employee_id"]
        row.reusable_qty = sum(r.quantity for r in reusable)
        row.scrap_qty = scrap_qty
        await self.db.commit()

        billing = M16InpatientClient()
        try:
            await billing.charge_reverse(
                admission_id=row.admission_id,
                source_type="DRUG_RETURN",
                source_id=str(row.id),
                amount=float(row.total_amount),
            )
        except Exception:
            pass

        return {
            "return_id": return_id,
            "return_no": row.return_no,
            "status": row.status,
            "reusable_qty": float(row.reusable_qty),
            "scrap_qty": float(row.scrap_qty),
            "stock_result": stock_result,
        }
```

## 11. 异常处理与日志

### 11.1 异常分类

| 类别 | 示例 | 处理方式 |
|---|---|---|
| **业务校验异常** | 状态非法、数量不符 | 返回错误码，记录 warn 日志 |
| **依赖不可用** | M14-01 超时 | 阻断并返回 "1408003"，进补偿队列 |
| **并发冲突** | 两人同时开始摆药 | 行锁 + 状态二次校验 |
| **数据不一致** | 应摆与已摆不符 | 拒绝提交，提示具体明细 |
| **外部设备故障** | 分包机离线 | 降级人工分包，标记 `is_manual` |

### 11.2 日志规范

```python
import logging

logger = logging.getLogger("m14.inpatient")


def log_dispense(action, row, extra=None):
    logger.info(
        "ward_dispense_%s" % action,
        extra={
            "dispense_id": row.id,
            "dispense_no": row.dispense_no,
            "ward_id": row.ward_id,
            "period": row.period,
            "status": row.status,
            "operator_id": row.updated_by or row.created_by,
            "extra": extra or {},
        },
    )


def log_error(action, payload, err):
    logger.warning(
        "ward_dispense_%s_failed" % action,
        extra={"payload": payload, "error": str(err)},
    )
```
