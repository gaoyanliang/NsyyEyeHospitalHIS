## 1. 模块概述

### 1.1 模块定位

M14-10 是**药事管理的数据出口**。它不产生业务数据，只把 M14-01~09 与 M07、M16 产生的数据按药事管理的要求重新组织。

它回答四类问题：

1. **药事管理的核心指标现在是多少？**（处方合格率、抗菌药物使用率、基本药物占比）
2. **等级评审要的数据能不能拿出来？**（二级医院评审标准药事条款）
3. **药监法定报表怎么报？**（麻精药品购用季报、药品不良反应）
4. **钱花得值不值？**（药品收入占比、库存周转、损耗率）

### 1.2 为什么独立成子模块

**判断标准：** 如果一个业务是「只读的、跨子模块的、指标口径需要治理的」，就必须独立。

| 维度 | 业务子模块 | M14-10 |
|---|---|---|
| 数据方向 | 读写 | **只读** |
| 数据范围 | 自己的表 | **跨 M14-01~09 + M07 + M16** |
| 一致性要求 | 实时 | **T+1 可接受** |
| 变更频率 | 跟随业务 | **跟随政策**（评审标准逐年改） |
| 使用者 | 业务人员 | **管理者 / 质控 / 药监** |
| 错误后果 | 业务受阻 | **数据误导决策 / 评审扣分** |

**四条核心差异：**

1. **指标口径必须唯一且可追溯**
   「抗菌药物使用率」在不同人嘴里可能是三个数：
   - 使用抗菌药物的门诊人次 / 门诊总人次
   - 抗菌药物处方数 / 处方总数
   - 抗菌药物费用 / 药品总费用

   如果每个报表各算各的，同一家医院同一月份会出现三个「抗菌药物使用率」。M14-10 必须**把每个指标的分子分母、统计口径、排除规则写死在代码里**，所有报表引用同一个函数。

2. **政策会变，但历史数据不能跟着变**
   2024 年等级评审要求「基本药物配备品种数占比 ≥ 80%」，2025 年可能改成 85%。若直接在业务表上加字段，口径一变历史上所有数据都要重算，而且无法证明"当年的数据是按当年口径算的"。

   M14-10 用**指标版本号**解决：每条预聚合记录带 `indicator_version`，历史数据保持当时的版本，新数据用新版本，报表标注版本。

3. **计算量大，不能实时**
   - 库存周转率要扫全年的出入库流水（87 万条）
   - 药品收入占比要关联 M16 收费明细
   - 季度趋势要聚合 90 天 × 全部药品

   实时算会让业务页面卡死，所以必须**T+1 预聚合**。

4. **输出格式受外部约束**
   药监的麻精药品季报有固定格式（Excel 模板行列固定），等级评审的数据填报有固定字段。这类「格式由外部定义」的输出不适合散落在各业务子模块里。

**如果合到 M14-01 会怎样？**

- M14-01 是库存台账，它不应该知道「抗菌药物使用率」这种临床指标
- M14-01 的查询接口是业务用的，加统计接口会让它变成一个谁都依赖的巨石
- 报表格式变更需要改 M14-01，风险波及库存核心

### 1.4 概念辨析

| 概念 | 定义 | 与相近概念的区别 |
|---|---|---|
| **药事管理** | 医院药事管理与药物治疗学委员会对药品全流程的管理 | 与「药房管理」不同：药事管理含临床用药合理性，药房管理只是调配发放 |
| **药事指标** | 衡量药事管理水平的量化值 | 与「业务统计」不同：指标有明确的目标值与评价标准 |
| **预聚合** | 提前算好并存下来的统计结果 | 与「缓存」不同：预聚合是持久化的，缓存是易失的 |
| **事实表** | 数仓术语，存指标值的宽表 | 与「业务表」不同：事实表只增不改，按日期分区 |
| **口径** | 指标的分子、分母、排除规则 | 与「公式」不同：口径含"什么算、什么不算" |
| **环比** | 与上一期比较 | 与「同比」不同：同比是与去年同期比较 |
| **药占比** | 药品收入 / 医疗总收入 | 与「药品加成率」不同：后者是（售价−进价）/进价 |
| **基药** | 国家基本药物目录内药品 | 与「医保药品」不同：基药目录与医保目录是两套 |
| **抗菌药物分级** | 非限制/限制/特殊使用三级 | 与「抗生素」不同：抗菌药物范围更广 |
| **处方合格率** | 合格处方 / 抽查处方总数 | 与「审核通过率」不同：后者是药师审核通过的占比 |

### 3.2 指标计算模型

**每个指标必须定义五个要素：**

| 要素 | 说明 | 示例（A-01 处方合格率） |
|---|---|---|
| 指标编码 | 唯一标识 | `A-01` |
| 计算公式 | 分子/分母 | `合格处方数 / 点评处方数 × 100%` |
| 统计口径 | 什么算、什么不算 | 分母为药师审核过的处方；排除已作废 |
| 数据来源 | 从哪些表取数 | `m14_rx_review` + `m07_prescription` |
| 目标值/阈值 | 评价标准 | ≥95%（二级医院评审要求） |

**指标定义表结构（不建表，用代码常量）：**

```python
INDICATORS = {
    "A-01": {
        "code": "A-01",
        "name": "处方合格率",
        "category": "A",
        "unit": "%",
        "direction": "UP",
        "formula": "pass_count / total_count * 100",
        "denominator_desc": "药师审核过的有效处方数",
        "target": 95.0,
        "warn": 93.0,
        "source": ["m14_rx_review", "m07_prescription"],
        "version": 1,
    },
    # ...
}
```

**`direction` 的含义：**

| 值 | 含义 | 示例 |
|---|---|---|
| `UP` | 越高越好 | 处方合格率、基本药物占比 |
| `DOWN` | 越低越好 | 抗菌药物使用率、发药差错率 |
| `RANGE` | 落在区间内最好 | 库存周转天数（太快可能缺货，太慢占用资金） |

### 3.3 预聚合模型

**三层聚合粒度：**

```
┌────────────────────────────────────────────────────────────┐
│  L1 日粒度（m14_stat_daily）                                │
│      date × indicator_code × dim_key                       │
│      → 事实表，最小的预聚合单元                             │
│      例：2026-10-22 / A-04 / dept=01                       │
├────────────────────────────────────────────────────────────┤
│  L2 月粒度（m14_stat_monthly）                              │
│      month × indicator_code × dim_key                      │
│      → 从 L1 汇总                                           │
├────────────────────────────────────────────────────────────┤
│  L3 报表快照（m14_stat_report）                             │
│      report_type × period × snapshot                       │
│      → 报表生成时的完整快照（含渲染参数）                   │
└────────────────────────────────────────────────────────────┘
```

**维度（`dim_key`）：**

| 维度类型 | 说明 | 示例 |
|---|---|---|
| `TOTAL` | 全院 | `dim_key = 'ALL'` |
| `DEPT` | 科室 | `dim_key = 'DEPT:01'` |
| `DRUG_CAT` | 药品大类 | `dim_key = 'DRUGCAT:ANTIBIOTIC'` |
| `WARD` | 病区 | `dim_key = 'WARD:W01'` |
| `SURGICAL` | 手术 | `dim_key = 'SURG:YES'` |
| `PATIENT_TYPE` | 患者类型 | `dim_key = 'PTYPE:OUTPATIENT'` |

**为什么用 `dim_key` 字符串而不是多列？**

指标的维度组合是稀疏的：A-04 抗菌药物使用率需要 `DEPT` 维度，B-01 库存周转率需要 `DRUG_CAT` 维度，A-01 处方合格率需要 `DEPT`。如果用多列（`dept_id`、`drug_cat`、`ward_id`...），每条记录大部分列是 NULL，且索引利用差。

用 `dim_key VARCHAR(64)` 加 `dim_type`，配合 `(date, indicator_code, dim_key)` 唯一约束，任何维度组合都只有一行，查询也只需一个条件。

### 3.4 报表模型

**报表分三类：**

| 类型 | 说明 | 更新频率 | 数据源 |
|---|---|---|---|
| **实时看板** | 药事大屏 | 30 秒 | Redis 缓存 |
| **定期报表** | 日报/月报/季报/年报 | T+1 06:00 | L1/L2 预聚合 |
| **对外报表** | 等级评审、药监报表 | 按需触发 | L1 + 明细 |

**9 个报表模板：**

| 编号 | 报表 | 频率 | 上报对象 |
|---|---|---|---|
| `RPT-RX` | 处方点评与合理用药分析 | 月 | 院内 / 医务科 |
| `RPT-ANTIBIOTIC` | 抗菌药物使用分析 | 月 / 季 | 院内 / 卫健 |
| `RPT-ESSENTIAL` | 基本药物使用分析 | 月 | 院内 / 卫健 |
| `RPT-INVENTORY` | 药品库存与周转分析 | 月 | 院内 |
| `RPT-PURCHASE` | 采购供应分析 | 月 | 院内 |
| `RPT-DISPENSE` | 发药服务质量分析 | 月 | 院内 |
| `RPT-SPECIAL` | 麻精药品专册季报 | 季 | 药监 |
| `RPT-REVIEW` | 等级评审药事数据 | 年 / 按需 | 评审组 |
| `RPT-ADR` | 药品不良反应汇总 | 年 / 按需 | 药监 |

### 3.5 数据下钻模型

**每个指标值都必须能下钻到明细。**

```
第 1 层：指标值          抗菌药物使用率 18.6%
   ↓ 点击
第 2 层：维度分解        内科 22.1% / 眼科 12.3% / 急诊 35.7%
   ↓ 点击
第 3 层：单据列表        内科 2026-10-22 使用抗菌药物的处方 47 张
   ↓ 点击
第 4 层：单据详情        处方号 RX20261022000123 / 患者 / 药品明细
   ↓ 点击
第 5 层：原始业务        跳转 M14-06 审核详情页
```

**下钻接口设计原则：**

- 第 1~3 层由 M14-10 提供（读预聚合 + 明细索引）
- 第 4 层之后调用业务子模块的详情接口（不重复实现）
- 每一层的跳转都带 `trace` 参数，便于追溯「这个数是哪来的」

### 3.6 指标版本模型

**政策变更是常态，历史数据不能跟着变。**

```
指标版本演进：

INDICATORS["A-04"] 版本 1（2024-01-01 起）
   分子：使用抗菌药物的门诊人次
   分母：门诊总人次

INDICATORS["A-04"] 版本 2（2025-07-01 起，政策变更）
   分子：使用抗菌药物的门诊人次（含出院带药）
   分母：门诊总人次
```

**预聚合记录带 `indicator_version`：**

- 2025-06-30 及之前的数据：`indicator_version = 1`
- 2025-07-01 起的数据：`indicator_version = 2`

**报表必须标注：** "本报表 2025 年 6 月前数据为口径版本 1，7 月起为版本 2，跨期比较仅供参考。"

这比"重算历史数据"更诚实，也符合审计要求。

### 3.7 数据质量模型

**指标数据的可信度分级：**

| 级别 | 含义 | 标记 |
|---|---|---|
| `COMPLETE` | 全部数据源已就绪 | — |
| `PARTIAL` | 部分数据源未就绪（如 M07 接口超时） | ⚠ 数据不完整 |
| `ESTIMATED` | 用历史值或近似值填充 | ⚠ 估算值 |
| `MISSING` | 数据源完全不可用 | ❌ 无数据 |

**每个预聚合记录都带 `data_quality` 字段。** 报表上对非 `COMPLETE` 的单元格加角标，让使用者知道这个数不能当真。

**为什么不直接显示空白？**

因为"空白"可能被误读为"0"。显示"18.6% ⚠数据不完整"比显示"空白"或"0"更有信息量。

def rate(numerator: Decimal, denominator: Decimal) -> Decimal:
    """安全计算比率，分母为 0 时返回 0"""
    if not denominator:
        return Decimal("0.00")
    value = (Decimal(str(numerator)) / Decimal(str(denominator))
             * Decimal("100"))
    return value.quantize(CENT, rounding=ROUND_HALF_UP)


def is_on_target(value: Decimal, target: Decimal,
                 direction: str) -> bool:
    """按方向判定是否达标"""
    if direction == DIRECTION_UP:
        return value >= target
    if direction == DIRECTION_DOWN:
        return value <= target
    return abs(value - target) <= Decimal("5.0")

            "AND stat_date BETWEEN :start AND :end "
            "AND (:dim_key IS NULL OR dim_key = :dim_key) "
            "ORDER BY stat_date DESC, id DESC "
            "LIMIT :limit OFFSET :offset"

            code=code, start=start, end=end, dim_key=dim_key,

    # ---------- 辅助 ----------

    def _period_range(self, period_type: str, period: str):
        if period_type == "DAY":
            d = datetime.strptime(period, "%Y-%m-%d").date()
            return d, d
        if period_type == "MONTH":
            d = datetime.strptime(period, "%Y-%m").date()
            start = d.replace(day=1)
            nxt = (start + timedelta(days=32)).replace(day=1)
            return start, nxt - timedelta(days=1)
        if period_type == "QUARTER":
            year = int(period.split("-Q")[0])
            q = int(period.split("-Q")[1])
            start_m = (q - 1) * 3 + 1
            start = date(year, start_m, 1)
            if start_m + 3 > 12:
                end = date(year, 12, 31)
            else:
                end = date(year, start_m + 3, 1) - timedelta(days=1)
            return start, end
        if period_type == "YEAR":
            year = int(period)
            return date(year, 1, 1), date(year, 12, 31)
        raise BizError(55652, "统计周期类型非法")

    def _current_period(self, period_type: str) -> str:
        now = datetime.now()
        if period_type == "DAY":
            return now.strftime("%Y-%m-%d")
        if period_type == "MONTH":
            return now.strftime("%Y-%m")
        if period_type == "QUARTER":
            return "%d-Q%d" % (now.year, (now.month - 1) // 3 + 1)
        if period_type == "YEAR":
            return str(now.year)
        raise BizError(55652, "统计周期类型非法")

    def _prev_period(self, period_type: str, period: str) -> str:
        if period_type == "MONTH":
            d = datetime.strptime(period, "%Y-%m")
            prev = (d - timedelta(days=1)).strftime("%Y-%m")
            return prev
        if period_type == "QUARTER":
            year = int(period.split("-Q")[0])
            q = int(period.split("-Q")[1])
            if q == 1:
                return "%d-Q4" % (year - 1)
            return "%d-Q%d" % (year, q - 1)
        if period_type == "YEAR":
            return str(int(period) - 1)
        if period_type == "DAY":
            d = datetime.strptime(period, "%Y-%m-%d").date()
            return (d - timedelta(days=1)).strftime("%Y-%m-%d")
        raise BizError(55652, "统计周期类型非法")

    def _validate_period(self, period_type: str, period: str):
        start, end = self._period_range(period_type, period)
        if end < start:
            raise BizError(55652, "统计周期非法")
        if (end - start).days > MAX_QUERY_DAYS:
            raise BizError(55653, "统计周期跨度超过 %d 天"
                           % MAX_QUERY_DAYS)

    def _validate_quarter(self, period: str):
        parts = period.split("-Q")
        if len(parts) != 2 or not parts[1].isdigit():
            raise BizError(55652, "季度格式非法")
        if int(parts[1]) not in (1, 2, 3, 4):
            raise BizError(55652, "季度必须是 1~4")

    def _validate_accreditation_period(self, period: str):
        if not period.isdigit() or len(period) != 4:
            raise BizError(55664, "评审周期格式非法")

    def _eval_target(self, value, target_text: str) -> bool:
        if value is None or not target_text:
            return False
        if target_text.startswith("≥"):
            return value >= Decimal(target_text[1:])
        if target_text.startswith("≤"):
            return value <= Decimal(target_text[1:])
        return False

    def _merge_quality(self, qualities: List[str]) -> str:
        if not qualities:
            return QUALITY_MISSING
        order = [QUALITY_COMPLETE, QUALITY_PARTIAL,
                 QUALITY_ESTIMATED, QUALITY_MISSING]
        worst = QUALITY_COMPLETE
        for q in qualities:
            if order.index(q) > order.index(worst):
                worst = q
        return worst

    async def _indicator_year_value(self, code: str, period: str):
        start, end = self._period_range("YEAR", period)

        return scope

    def _report_name(self, report_type: str) -> str:

async def _daily_aggregate(stat_date: str = None):
    target = (datetime.strptime(stat_date, "%Y-%m-%d").date()
              if stat_date else datetime.now().date()
              - timedelta(days=1))
    async with get_db_context() as db:
        service = _build_service(db)

                await _upsert_daily(
                    db, target, code, meta["version"], v)
                count += 1
        await db.commit()
        logger.info(
            "M14-10 日聚合完成 date=%s 记录数=%d" % (target, count),
            extra={"module": "M14-10", "date": str(target),
                   "count": count},
        )
        redis_client.delete(
            "m14:stat:dashboard:MONTH:"
            + target.strftime("%Y-%m") + ":ALL")


async def _calc_indicator(service, code: str,
                          target: date) -> list:
    """按指标编码分派计算"""
    if code == "A-01":
        data = await service.rx_client.statistics(target, target)
        return [_row("ALL", "全院", data.get("pass_count", 0),
                     data.get("total_count", 0))]
    if code == "A-04":
        data = await service.order_client.antibiotic_stat(target)
        rows = [_row("ALL", "全院", data.get("antibiotic_visits", 0),
                     data.get("total_visits", 0))]
        for dept in data.get("by_dept", []):
            rows.append(_row(
                "DEPT:" + str(dept["dept_id"]), dept["dept_name"],
                dept.get("antibiotic_visits", 0),
                dept.get("total_visits", 0)))
        return rows
    if code in ("B-01", "B-02"):
        data = await service.inv_client.turnover(target)
        return [_row("ALL", "全院", data.get("cost_of_goods", 0),
                     data.get("avg_inventory", 0))]
    if code == "C-01":
        data = await service.dispense_client.statistics(target, target)
        return [_row("ALL", "全院", data.get("error_count", 0),
                     data.get("dispense_count", 0))]
    if code == "D-01":
        data = await service.special_client.statistics(target, target)
        return [_row("ALL", "全院", data.get("ampoule_collected", 0),
                     data.get("ampoule_required", 0))]
    return []

         denominator: int) -> dict:

        "dim_name": dim_name,
        "numerator": numerator,

async def _upsert_daily(db, stat_date: date, code: str,
                        version: int, value: dict):
    stmt = select(M14StatDaily).where(
        M14StatDaily.stat_date == stat_date,
        M14StatDaily.indicator_code == code,
        M14StatDaily.dim_key == value["dim_key"],
    ).with_for_update()
    row = (await db.execute(stmt)).scalars().first()
    if row:
        row.numerator = value["numerator"]
        row.denominator = value["denominator"]
        row.indicator_version = version
        row.data_quality = value["quality"]
        row.updated_at = datetime.now()
    else:
        db.add(M14StatDaily(
            stat_date=stat_date,
            indicator_code=code,
            indicator_name=INDICATORS[code]["name"],
            category=INDICATORS[code]["category"],
            indicator_version=version,
            dim_type=(value["dim_key"].split(":")[0]
                      if ":" in value["dim_key"] else "TOTAL"),
            dim_key=value["dim_key"],
            dim_name=value["dim_name"],
            numerator=value["numerator"],
            denominator=value["denominator"],
            data_quality=value["quality"],
        ))

async def _monthly_aggregate(month: str = None):
    target = (month if month
              else (datetime.now() - timedelta(days=1)).strftime(
                  "%Y-%m"))
    start = datetime.strptime(target, "%Y-%m").date().replace(day=1)
    nxt = (start + timedelta(days=32)).replace(day=1)

            "MIN(data_quality) "
            "FROM m14_stat_daily "

            "AND is_deleted = FALSE "

            "indicator_version, dim_type, dim_key, dim_name"

            await _upsert_monthly(db, target, r)
        await db.commit()

async def _generate_reports(period: str = None,
                            report_types: str = None):
    target = period or (datetime.now() - timedelta(days=1)).strftime(
        "%Y-%m")
    types = (report_types.split(",") if report_types else
             ["RPT-RX", "RPT-ANTIBIOTIC", "RPT-ESSENTIAL",
              "RPT-INVENTORY", "RPT-PURCHASE", "RPT-DISPENSE"])
    async with get_db_context() as db:
        service = PharmacyStatService(db)
        for rt in types:
            lock_key = "m14:stat:lock:generate:" + rt + ":" + target
            if not redis_client.set(lock_key, "1", nx=True, ex=600):
                logger.warning(
                    "M14-10 报表生成锁占用 type=%s period=%s"
                    % (rt, target),
                    extra={"module": "M14-10", "report_type": rt},
                )
                continue
            try:
                await _render_report(service, rt, target)
            except Exception as exc:
                logger.error(
                    "M14-10 报表生成失败 type=%s period=%s err=%s"
                    % (rt, target, exc),
                    extra={"module": "M14-10", "report_type": rt},
                )
            finally:
                redis_client.delete(lock_key)


async def _render_report(service, report_type: str, period: str):
    logger.info(
        "M14-10 渲染报表 type=%s period=%s"
        % (report_type, period),
        extra={"module": "M14-10", "report_type": report_type},
    )


@shared_task(name="m14.stat.clean_cache")
def clean_cache():
    """清理过期缓存"""
    pattern = "m14:stat:dashboard:*"
    keys = redis_client.keys(pattern)
    for k in keys:
        ttl = redis_client.ttl(k)
        if ttl is not None and ttl < 0:
            redis_client.delete(k)
    logger.info(
        "M14-10 缓存清理完成 keys=%d" % len(keys),
        extra={"module": "M14-10"},
    )

async def _data_health_check():
    yesterday = datetime.now().date() - timedelta(days=1)
    async with get_db_context() as db:
        sql = text(
            "SELECT indicator_code, COUNT(1) "
            "FROM m14_stat_daily "
            "WHERE stat_date = :d AND is_deleted = FALSE "
            "GROUP BY indicator_code"
        ).bindparams(d=yesterday)
        rows = (await db.execute(sql)).all()
        existing = set(r[0] for r in rows)
        missing = [c for c in INDICATORS if c not in existing]
        if missing:
            logger.error(
                "M14-10 指标数据缺失 date=%s codes=%s"
                % (yesterday, ",".join(missing)),
                extra={"module": "M14-10", "missing": missing},
            )
