## 1. 模块概述

### 1.1 模块定位

M14-03 负责药品和耗材**从供应商进入医院**的全过程：申请买什么 → 向谁买、买多少 → 货到验收 → 入库上架变成库存。

它解决的是一条"账实相符"链路的入口问题：**没有控制好的入库，后面所有库存数字都不可信**。

```
┌──────────────────────────────────────────────────────────────────────┐
│                     M14-03 采购与入库 在全局中的位置                  │
└──────────────────────────────────────────────────────────────────────┘

  ┌─────────────┐
  │  M14-02     │  每日 07:00 生成补货建议
  │ 补货建议     │  低于订货点/零库存 → 建议采购量
  └──────┬──────┘
         │  接受建议
         ▼
  ┌───────────────────────────────────────────────────────────────┐
  │                     M14-03 采购与入库                          │
  │                                                               │
  │  ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐  │
  │  │ 采购申请 │ → │ 采购订单 │ → │ 到货验收 │ → │ 入库上架 │  │
  │  │ PLAN     │   │ ORDER    │   │ RECEIPT  │   │ INBOUND  │  │
  │  └──────────┘   └──────────┘   └──────────┘   └──────────┘  │
  │       │              │              │              │          │
  │       │ 审批         │ 供应商       │ 质量检验     │ 批次/效期│
  │       ▼              ▼              ▼              ▼          │
  │   M01-11 审批    M01 md_supplier  GSP 验收规范  M14-01 流水  │
  └───────────────────────────────────────────────────────────────┘
         │
         ▼
  ┌─────────────┐
  │  M14-01     │  唯一写库存入口
  │ 库存台账     │  PURCHASE_IN 入库流水
  └─────────────┘
         │
         ▼
  ┌─────────────┐
  │  M16 收费   │  采购发票登记 → 应付账款
  │  M17 财务   │  成本核算
  └─────────────┘
```

### 1.2 为什么独立成子模块

| 候选方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 并入 M14-01 库存台账 | 表少 | 库存台账是"当前状态"，采购是"过程单据"，状态机完全不同；采购单据有审批流、有供应商合同关系、有税务凭证 | ❌ 混在一起表会膨胀到 20+ 张 |
| 并入 M14-04 出入库 | 都是"改库存" | 采购退货与出库调拨虽然都减库存，但触发条件、审批人、单据类型完全不同 | ❌ 一个页面里塞两种业务 |
| **独立成子模块** | 过程单据独立、审批独立、可追溯独立 | 需要跨子模块调用 | ✅ **采纳** |

**核心论据**：采购与入库管的是"**这张单子怎么走到库存里**"，M14-01 管的是"**库存现在是多少**"。前者是过程，后者是结果。

### 1.4 概念辨析

| 概念 | 定义 | 关键区别 |
|---|---|---|
| **采购申请**（Purchase Plan） | 内部需求单，"我要买 100 支玻璃酸钠滴眼液" | 不对应任何供应商，只是一个需求 |
| **采购订单**（Purchase Order） | 对外的法律要约，"向 XX 药业采购 100 支，单价 25.00" | 有供应商、有价格、有交付期，可能分批发货 |
| **到货验收**（Receipt） | 货到了，逐项核对数量、批号、效期、外观、温度 | 一个订单可分多次到货，每次一张验收单 |
| **入库**（Inbound） | 验收合格后，库存数字真正增加 | 验收与入库可以是同一步（直入）或两步（质检后入） |
| **采购退货**（Purchase Return） | 退了货给供应商（质量问题或近效期协议退货） | 属出库，走 M14-03 的退货单但调 M14-01 写流水 |

**最常见的三处混淆：**

1. **"到货" ≠ "入库"**。货到门口还没验收，库存不能动；抗原试剂要先送到待检区，检验合格后才转入合格品库。
2. **"订单金额" ≠ "入库金额"**。订单 100 支，实到 98 支（破损 2 支），入库金额按 98 支算，另开 2 支的拒收单报损。
3. **"采购退货" ≠ "采购订单作废"**。订单作废是"这笔生意没做成"；采购退货是"生意做成了，但货退回去要退款"。

### 1.5 模块目标

| 指标 | 目标值 | 测算依据 |
|---|---|---|
| 采购申请到订单的平均周期 | ≤ 0.5 天 | 申请→审批→下单 |
| 订单到货准时率 | ≥ 95% | 供应商考核核心指标 |
| 验收单录入平均耗时 | ≤ 90 秒/单（含 10 行） | 扫码枪 + 快照带入 |
| 验收差错率（数量/批号） | ≤ 0.1% | 双人复核 + 扫码校验 |
| 供应商资质过期拦截率 | 100% | 硬阻断，不允许过期供应商下单 |
| 采购单证完整性 | 100% | 每笔入库必有订单号、验收人、批号、效期 |

### 1.6 关键业务角色

| 角色 | 职责 | 关键操作 |
|---|---|---|
| 药库管理员（药械科） | 提出申请、跟踪订单、验收入库 | 新建申请、下单、验收 |
| 科室申请人（临床/护理） | 提出科室需求 | 提交科室申请 |
| 药械科主任 | 审批采购订单 | 审批、驳回 |
| 财务/采购办 | 审批大额采购、签订合同 | 双签审批 |
| 质量管理员（GSP） | 首营企业审核、到货质量验收 | 首营资质审核、拒收判定 |
| 库管员 | 上架、贴签 | 确认入库库位 |

## 3. 业务模型

### 3.1 采购申请模型

采购申请是**内部意图**，不对应任何具体供应商。

```json
{
  "plan_no": "CG202610210001",
  "apply_dept_id": 1101,
  "apply_dept_name": "药械科",
  "applicant_id": 8001,
  "applicant_name": "张药库",
  "plan_type": "ROUTINE",
  "urgency": "NORMAL",
  "items": [
    {
      "drug_id": 3401,
      "drug_code": "YP000123",
      "drug_name": "玻璃酸钠滴眼液",
      "specification": "0.1% 5ml",
      "package_unit": "支",
      "request_qty": 200,
      "monthly_usage": 45,
      "current_stock": 12,
      "source_type": "REPLENISH",
      "source_id": 990001
    }
  ]
}
```

**申请来源四种：**

| source_type | 名称 | 生成方式 |
|---|---|---|
| `REPLENISH` | 补货建议 | 接受 M14-02 的补货建议 |
| `MANUAL` | 手工申请 | 药库管理员手工新建 |
| `DEPT_REQUEST` | 科室需求 | 临床/护理科室提交 |
| `NEW_DRUG` | 新药首次采购 | 药事会通过后首次采购 |

**申请表状态机：**

```
   ┌────────┐  提交   ┌────────────┐  审批通过  ┌───────────┐
   │ DRAFT  │────────►│ SUBMITTED  │──────────►│ APPROVED  │
   └────────┘         └─────┬──────┘            └─────┬─────┘
        ▲                   │ 驳回                    │
        │                   ▼                         │ 转订单
        │            ┌──────────┐                     ▼
        └────────────│ REJECTED │              ┌───────────┐
        修改重提     └──────────┘              │ CONVERTED │
                                                └───────────┘
   DRAFT/SUBMITTED ──► CANCELLED（申请人撤销）
```

| 状态 | 含义 | 可执行操作 |
|---|---|---|
| `DRAFT` | 草稿 | 编辑、删除、提交 |
| `SUBMITTED` | 待审批 | 撤回、审批 |
| `APPROVED` | 审批通过 | 转采购订单、作废 |
| `REJECTED` | 已驳回 | 修改重提、作废 |
| `CONVERTED` | 已转订单 | 仅查询 |
| `CANCELLED` | 已作废 | 仅查询 |

### 3.2 采购订单模型

```json
{
  "order_no": "CGDD202610210001",
  "plan_id": 880001,
  "supplier_id": 2201,
  "supplier_name": "华东医药股份有限公司",
  "supplier_contact": "李经理 13800138000",
  "order_date": "2026-10-21",
  "expected_date": "2026-10-28",
  "total_amount": 8600.00,
  "status": "CONFIRMED",
  "items": [
    {
      "line_no": 1,
      "drug_id": 3401,
      "drug_code": "YP000123",
      "drug_name": "玻璃酸钠滴眼液",
      "specification": "0.1% 5ml",
      "package_unit": "支",
      "conversion_ratio": 1,
      "order_qty": 200,
      "received_qty": 0,
      "unit_price": 25.0000,
      "amount": 5000.00,
      "tax_rate": 0.1300,
      "require_batch": true,
      "require_expiry": true,
      "min_expiry_days": 365
    }
  ]
}
```

**订单状态机：**

```
   ┌────────┐  下达   ┌───────────┐  首次到货  ┌───────────┐
   │ DRAFT  │───────►│ CONFIRMED │──────────►│ PARTIAL   │
   └────────┘        └─────┬─────┘            └─────┬─────┘
        │                  │ 供应商确认               │ 全到
        │ 作废             ▼                        ▼
        │            ┌──────────┐            ┌───────────┐
        └───────────►│ CANCELLED│            │ COMPLETED │
                     └──────────┘            └───────────┘
```

| 状态 | 含义 |
|---|---|
| `DRAFT` | 草稿，未下达 |
| `CONFIRMED` | 已下达，等待到货 |
| `PARTIAL` | 部分到货 |
| `COMPLETED` | 全部到货 |
| `CANCELLED` | 已作废 |

**关键规则：**

- `CONFIRMED` 状态下若从未到货，可作废；一旦有到货记录，只能走"未到货行关闭"而非整单作废。
- 允许多次到货，每次一张验收单，`received_qty` 累加，`received_qty <= order_qty`（超量到货需单独授权）。
- 超量到货容差：`M14.PURCHASE.OVER_RECEIPT_RATIO = 0.05`（默认 5%），超出部分需药械科主任授权。

### 3.3 到货验收模型

验收是**GSP 合规的核心环节**，必须逐项检查：

```json
{
  "receipt_no": "YS202610210001",
  "order_id": 770001,
  "supplier_id": 2201,
  "delivery_no": "SH20261021008",
  "arrival_at": "2026-10-21T14:30:00",
  "cold_chain_temp": 6.2,
  "items": [
    {
      "line_no": 1,
      "order_item_id": 550001,
      "drug_id": 3401,
      "batch_no": "A261001",
      "production_date": "2026-10-01",
      "expiry_date": "2028-09-30",
      "received_qty": 200,
      "rejected_qty": 0,
      "unit_price": 25.0000,
      "appearance_ok": true,
      "package_ok": true,
      "label_ok": true,
      "certificate_ok": true
    }
  ],
  "checker_id": 8010,
  "checker_name": "王药师",
  "result": "PASS"
}
```

**四必查（GSP 要求）：**

| 检查项 | 内容 | 不合格处理 |
|---|---|---|
| 外观 | 包装完整、无破损、无污染、颜色正常 | 拒收 |
| 标签 | 药品名称、规格、批号、有效期、生产企业 | 拒收 |
| 批号效期 | 与随货同行单一致；效期 ≥ 订单要求 | 拒收或降级处理 |
| 资质 | 随货同行单、检验报告书、冷链温度记录 | 缺一不可，拒收 |

**冷链温度判定：**

| 存储条件 | 合格区间 | 越界处理 |
|---|---|---|
| 冷藏（2~8℃） | 2.0 ~ 8.0℃ | 越界即拒收 |
| 阴凉（≤20℃） | ≤ 20.0℃ | 越界即拒收 |
| 常温（10~30℃） | 10.0 ~ 30.0℃ | 超出 30℃ 拒收 |

> **温度记录的来源**：验收时扫码读取冷链记录仪导出的数据，或供应商提供的纸质温度记录拍照上传。系统只做区间判定，不做曲线分析（曲线分析属 M15 物资供应）。

**验收结果三态：**

| 结果 | 含义 | 后续 |
|---|---|---|
| `PASS` | 全部合格 | 直接入库 |
| `PARTIAL_PASS` | 部分拒收 | 合格部分入库，拒收部分生成拒收单 |
| `REJECT` | 全部拒收 | 不入库，生成拒收单，订单状态不变 |

**拒收类型：**

| 代码 | 名称 | 说明 |
|---|---|---|
| `QUALITY` | 质量问题 | 包装破损、变色、浑浊 |
| `EXPIRY` | 效期不足 | 剩余效期短于订单要求 |
| `DOCUMENT` | 单证不全 | 缺检验报告、随货同行单 |

| 代码 | 名称 | 说明 |

| `RETURN_SUPPLIER` | 退回供应商 | 最常见 |

### 3.7 供应商资质校验模型

**硬阻断项**（任一不满足即禁止下单）：

| 校验项 | 来源字段 | 规则 |
|---|---|---|
| 供应商未删除 | `is_deleted = FALSE` | — |
| 供应商启用 | `status = ENABLED` | — |
| 资质合格 | `is_qualified = TRUE` | — |
| 非黑名单 | `is_blacklist = FALSE` | — |
| 营业执照未过期 | `license_expire >= TODAY` | 过期即阻断 |
| 质量协议未过期 | `quality_agreement_expire >= TODAY` | 过期即阻断 |
| 未超信用额度 | `credit_limit` | 超出需财务审批（非硬阻断） |

**软提示项**（允许继续但警告）：

| 校验项 | 说明 |
|---|---|
| 营业执照 30 天内到期 | 提示「请更新资质」 |
| 质量协议 30 天内到期 | 提示 |
| 超出信用额度 | 提示「需财务审批」 |
| 供应商评分低于 B | 提示「建议评估其他供应商」 |

### 3.8 采购价格与金额模型

**金额计算铁律**（与 M16 一致）：

- 行金额：`amount = ROUND(order_qty * unit_price, 2)`
- 订单金额：`total_amount = SUM(行金额)`
- **行级先舍入再累加**，不能先累加再舍入

**含税与不含税：**

| 字段 | 计算 | 说明 |
|---|---|---|
| `unit_price` | 录入 | 含税单价 |
| `tax_rate` | 算法 | 药品 13%，部分中药饮片 9%，医疗服务 0% |
| `amount_without_tax` | `ROUND(amount / (1 + tax_rate), 2)` | 不含税金额 |
| `tax_amount` | `amount - amount_without_tax` | 税额 |

> **不能用 `amount * tax_rate`** —— 那是把价内税当价外税，1000 元 13% 会算出 130 元税额，正确应为 115.04 元。这个错误会导致进项税额抵扣差额，财务对不上账。

**价格来源优先级：**

| 优先级 | 来源 | 说明 |
|---|---|---|
| 1 | 手工录入 | 议价采购 |
| 2 | 上次采购价 | `m14_purchase_order_item` 最近一单 |
| 3 | 合同价 | M15 物资供应（未设计） |
| 4 | 药品主数据参考价 | `mdm_drug_price` 的 `PURCHASE` 类型 |

### 3.9 单号编码规则

| 单据 | 前缀 | 格式 | 示例 |
|---|---|---|---|
| 采购申请 | `CG` | `CG` + YYYYMMDD + 4 位 | `CG202610210001` |
| 采购订单 | `CGDD` | `CGDD` + YYYYMMDD + 4 位 | `CGDD202610210001` |
| 到货验收 | `YS` | `YS` + YYYYMMDD + 4 位 | `YS202610210001` |
| 拒收单 | `JS` | `JS` + YYYYMMDD + 4 位 | `JS202610210001` |
| 采购退货 | `CT` | `CT` + YYYYMMDD + 4 位 | `CT202610210001` |

**取号方式**：PostgreSQL 序列 `seq_m14_purchase_no`，`CACHE 20 CYCLE`，按 `seq % 10000` 取后 4 位，同日冲突时重试。

### 6.6 Service 层核心逻辑

```python
from datetime import date, datetime, timedelta
from decimal import Decimal, ROUND_HALF_UP
from typing import Any, Dict, List, Optional

from sqlalchemy import func, select, update
from sqlalchemy.ext.asyncio import AsyncSession

from app.core.exceptions import BizError
from app.models.m14 import (
    M14PurchasePlan, M14PurchasePlanItem, M14PurchaseApproval,
    M14PurchaseOrder, M14PurchaseOrderItem,
    M14Receipt, M14ReceiptItem,
    M14Reject, M14RejectItem,
    M14PurchaseReturn, M14PurchaseReturnItem,
)
from app.services.m14.stock_client import StockClient
from app.services.m14.supplier_client import SupplierClient
from app.services.m14.mdm_client import MdmClient
from app.services.m14.audit_client import AuditClient

CENT = Decimal("0.01")


def money(value) -> Decimal:
    """金额两位小数，四舍五入"""
    if value is None:
        return Decimal("0.00")
    return Decimal(str(value)).quantize(CENT, rounding=ROUND_HALF_UP)


class PurchasePlanService:
    """采购申请"""

    APPROVAL_TIERS = [
        (Decimal("5000"), "L1", ["DEPT_DIRECTOR"]),
        (Decimal("50000"), "L2", ["DEPT_DIRECTOR", "FINANCE"]),
        (None, "L3", ["DEPT_DIRECTOR", "FINANCE", "PRESIDENT"]),
    ]

    @classmethod
    async def create_plan(
        cls, db: AsyncSession, user, payload
    ) -> Dict[str, Any]:
        """新建采购申请"""
        if not payload.items:
            raise BizError(55301, "采购明细不能为空")

        seen = set()
        for item in payload.items:
            if item.request_qty <= 0:
                raise BizError(55302, "需求数量必须大于 0")
            if item.drug_id in seen:
                raise BizError(55303, "同一药品不能重复申请")
            seen.add(item.drug_id)

        if payload.plan_type == "NEW_DRUG" and not payload.resolution_no:
            raise BizError(55304, "新药申请必须关联药事会决议号")

        if payload.urgency == "URGENT":
            if not payload.urgent_reason:
                raise BizError(55305, "加急申请必须填写加急理由")
            if len(payload.urgent_reason.strip()) < 10:
                raise BizError(55305, "加急理由不少于 10 个字")

        plan_no = await cls._next_plan_no(db)

        plan = M14PurchasePlan(
            plan_no=plan_no,
            plan_type=payload.plan_type,
            urgency=payload.urgency,
            apply_dept_id=payload.apply_dept_id,
            applicant_id=user.employee_id,
            applicant_name=user.name,
            status="DRAFT",
            remark=payload.remark,
            urgent_reason=payload.urgent_reason,
            resolution_no=payload.resolution_no,
            created_by=user.employee_id,
        )
        db.add(plan)
        await db.flush()

        total = Decimal("0.00")
        for idx, item in enumerate(payload.items, start=1):
            drug = await MdmClient.get_drug(item.drug_id)
            price = await cls._reference_price(db, item.drug_id)
            amount = money(price * item.request_qty)
            total += amount
            db.add(M14PurchasePlanItem(
                plan_id=plan.id,
                line_no=idx,
                drug_id=item.drug_id,
                drug_code=drug["drug_code"],
                drug_name=drug["drug_name"],
                specification=drug.get("specification"),
                package_unit=drug.get("package_unit"),
                request_qty=item.request_qty,
                reference_price=price,
                estimated_amount=amount,
                source_type=item.source_type,
                source_id=item.source_id,
            ))

        plan.total_amount = money(total)
        await db.flush()

        await AuditClient.record(
            user, "M14_PURCHASE_PLAN_CREATE",
            {"plan_no": plan_no, "items": len(payload.items)})

        return {
            "id": plan.id,
            "plan_no": plan_no,
            "status": "DRAFT",
            "status_text": "草稿",
            "item_count": len(payload.items),
            "estimated_amount": float(total),
            "created_at": plan.created_at.isoformat(),
        }

    @classmethod
    def resolve_approval_tier(
        cls, amount: Decimal, urgency: str
    ) -> Dict[str, Any]:
        """判定审批层级"""
        for limit, tier, roles in cls.APPROVAL_TIERS:
            if limit is None or amount < limit:
                if urgency == "URGENT":
                    tier = cls._raise_tier(tier)
                return {"tier": tier, "roles": roles}
        return {"tier": "L3", "roles": ["DEPT_DIRECTOR", "FINANCE"]}

    @staticmethod
    def _raise_tier(tier: str) -> str:
        order = ["L1", "L2", "L3"]
        idx = order.index(tier)
        return order[min(idx + 1, len(order) - 1)]

    @classmethod
    async def _reference_price(
        cls, db: AsyncSession, drug_id: int
    ) -> Decimal:
        """取参考价：上次采购价 > 主数据单价"""
        stmt = (
            select(M14PurchaseOrderItem.unit_price)
            .where(M14PurchaseOrderItem.drug_id == drug_id)
            .order_by(M14PurchaseOrderItem.id.desc())
            .limit(1)
        )
        row = (await db.execute(stmt)).scalar_one_or_none()
        if row is not None:
            return Decimal(str(row))
        drug = await MdmClient.get_drug(drug_id)
        return Decimal(str(drug.get("purchase_price") or 0))

    @staticmethod
    async def _next_plan_no(db: AsyncSession) -> str:
        stmt = select(func.nextval("seq_m14_purchase_no"))
        seq = (await db.execute(stmt)).scalar()
        return "CG%s%04d" % (
            date.today().strftime("%Y%m%d"), seq % 10000)


class PurchaseApprovalService:
    """采购审批"""

    @classmethod
    async def approve(
        cls, db: AsyncSession, user, plan_id: int, payload
    ) -> Dict[str, Any]:
        stmt = select(M14PurchasePlan).where(
            M14PurchasePlan.id == plan_id
        ).with_for_update()
        plan = (await db.execute(stmt)).scalar_one_or_none()
        if plan is None:
            raise BizError(55307, "申请不存在")
        if plan.status != "SUBMITTED":
            raise BizError(55307, "申请状态已变更，请刷新")
        if plan.applicant_id == user.employee_id:
            raise BizError(55306, "不能审批自己提交的申请")

        tier_info = PurchasePlanService.resolve_approval_tier(
            plan.total_amount, plan.urgency)

        current = await cls._current_step(db, plan_id)
        if current is None:
            raise BizError(55307, "审批流异常")

        current.status = "APPROVED"
        current.approver_id = user.employee_id
        current.approver_name = user.name
        current.comment = payload.comment
        current.approved_at = datetime.now()

        remaining = tier_info["roles"][tier_info["roles"].index(
            current.role_code) + 1:]
        if remaining:
            nxt = M14PurchaseApproval(
                plan_id=plan_id,
                step_no=current.step_no + 1,
                role_code=remaining[0],
                status="PENDING",
                deadline_at=datetime.now() + timedelta(
                    hours=cls._timeout_hours(tier_info["tier"])),
            )
            db.add(nxt)
            plan.status = "SUBMITTED"
            result_status = "PENDING_NEXT"
        else:
            plan.status = "APPROVED"
            plan.approved_at = datetime.now()
            result_status = "APPROVED"

        await db.flush()
        await AuditClient.record(
            user, "M14_PURCHASE_APPROVE",
            {"plan_no": plan.plan_no, "result": result_status})

        return {
            "plan_no": plan.plan_no,
            "status": plan.status,
            "tier": tier_info["tier"],
            "next_roles": remaining,
        }

    @staticmethod
    def _timeout_hours(tier: str) -> int:
        return {"L1": 24, "L2": 48, "L3": 72}.get(tier, 48)


class PurchaseOrderService:
    """采购订单"""

    OVER_RECEIPT_RATIO = Decimal("0.05")

    @classmethod
    async def create_order(
        cls, db: AsyncSession, user, payload
    ) -> Dict[str, Any]:
        stmt = select(M14PurchasePlan).where(
            M14PurchasePlan.id == payload.plan_id
        ).with_for_update()
        plan = (await db.execute(stmt)).scalar_one_or_none()
        if plan is None:
            raise BizError(55310, "采购申请不存在")
        if plan.status != "APPROVED":
            raise BizError(55310, "只有审批通过的申请才能转订单")

        # 供应商资质硬校验
        await cls._check_supplier(payload.supplier_id)

        if payload.expected_date < payload.order_date:
            raise BizError(55314, "预计到货日不得早于下单日")

        order_no = await cls._next_order_no(db)
        order = M14PurchaseOrder(
            order_no=order_no,
            plan_id=plan.id,
            supplier_id=payload.supplier_id,
            supplier_name=payload.supplier_name,
            order_date=payload.order_date,
            expected_date=payload.expected_date,
            status="CONFIRMED",
            created_by=user.employee_id,
        )
        db.add(order)
        await db.flush()

        total = Decimal("0.00")
        for idx, line in enumerate(payload.items, start=1):
            if line.unit_price <= 0:
                raise BizError(55313, "采购单价必须大于 0")
            drug = await MdmClient.get_drug(line.drug_id)
            amount = money(line.unit_price * line.order_qty)
            total += amount
            db.add(M14PurchaseOrderItem(
                order_id=order.id,
                line_no=idx,
                drug_id=line.drug_id,
                drug_code=drug["drug_code"],
                drug_name=drug["drug_name"],
                specification=drug.get("specification"),
                package_unit=drug.get("package_unit"),
                conversion_ratio=drug.get("conversion_ratio") or 1,
                order_qty=line.order_qty,
                received_qty=0,
                unit_price=line.unit_price,
                amount=amount,
                require_batch=bool(drug.get("is_batch_managed")),
                require_expiry=bool(drug.get("is_expiry_managed")),
                min_expiry_days=line.min_expiry_days or 365,
            ))

        order.total_amount = money(total)
        plan.status = "CONVERTED"

        await db.flush()
        await AuditClient.record(
            user, "M14_PURCHASE_ORDER_CREATE",
            {"order_no": order_no, "total": float(total)})

        return {"id": order.id, "order_no": order_no,
                "status": "CONFIRMED",
                "total_amount": float(total)}

    @classmethod
    async def _check_supplier(cls, supplier_id: int) -> None:
        """供应商资质硬校验"""
        sup = await SupplierClient.get(supplier_id)
        if sup is None or sup.get("is_deleted"):
            raise BizError(55312, "供应商不存在")
        if sup.get("status") != "ENABLED":
            raise BizError(55312, "供应商已停用")
        if not sup.get("is_qualified"):
            raise BizError(55312, "供应商资质未通过审核")
        if sup.get("is_blacklist"):
            raise BizError(55312, "供应商在黑名单中")
        today = date.today()
        lic = sup.get("license_expire")
        if lic and date.fromisoformat(str(lic)) < today:
            raise BizError(55312, "供应商营业执照已过期")
        qa = sup.get("quality_agreement_expire")
        if qa and date.fromisoformat(str(qa)) < today:
            raise BizError(55312, "供应商质量协议已过期")

    @classmethod
    async def update_order(
        cls, db: AsyncSession, user, order_id: int, payload
    ) -> Dict[str, Any]:
        stmt = select(M14PurchaseOrder).where(
            M14PurchaseOrder.id == order_id
        ).with_for_update()
        order = (await db.execute(stmt)).scalar_one_or_none()
        if order is None:
            raise BizError(55315, "订单不存在")
        if order.status in ("COMPLETED", "CANCELLED"):
            raise BizError(55315, "订单状态不允许变更")

        has_receipt = await cls._has_receipt(db, order_id)
        if has_receipt:
            for line in payload.items:
                item = await cls._get_item(db, order_id, line.line_no)
                if line.order_qty < item.received_qty:
                    raise BizError(
                        55315, "已有到货记录，不允许修改已到货行")

        if not payload.change_reason or len(
            payload.change_reason.strip()) < 10:
            raise BizError(55317, "变更必须填写原因（≥10 字）")

        old_total = order.total_amount
        new_total = Decimal("0.00")
        for line in payload.items:
            item = await cls._get_item(db, order_id, line.line_no)
            item.order_qty = line.order_qty
            item.unit_price = line.unit_price
            item.amount = money(line.unit_price * line.order_qty)
            new_total += item.amount

        order.total_amount = money(new_total)
        order.expected_date = payload.expected_date
        order.change_reason = payload.change_reason
        order.change_count = (order.change_count or 0) + 1

        need_reapprove = False
        if old_total > 0:
            ratio = abs(new_total - old_total) / old_total
            need_reapprove = ratio > Decimal("0.10")
        if need_reapprove:
            order.status = "DRAFT"
            order.reapprove_required = True

        await db.flush()
        await AuditClient.record(
            user, "M14_PURCHASE_ORDER_UPDATE",
            {"order_no": order.order_no,
             "old_total": float(old_total),
             "new_total": float(order.total_amount),
             "need_reapprove": need_reapprove})

        return {
            "order_no": order.order_no,
            "status": order.status,
            "total_amount": float(order.total_amount),
            "need_reapprove": need_reapprove,
        }

    @staticmethod
    async def _has_receipt(db: AsyncSession, order_id: int) -> bool:
        stmt = select(func.count()).select_from(M14Receipt).where(
            M14Receipt.order_id == order_id)
        return (await db.execute(stmt)).scalar() > 0

    @staticmethod
    async def _get_item(db, order_id, line_no):
        stmt = select(M14PurchaseOrderItem).where(
            M14PurchaseOrderItem.order_id == order_id,
            M14PurchaseOrderItem.line_no == line_no,
        )
        item = (await db.execute(stmt)).scalar_one_or_none()
        if item is None:
            raise BizError(55315, "订单行不存在")
        return item

    @staticmethod
    async def _next_order_no(db: AsyncSession) -> str:
        stmt = select(func.nextval("seq_m14_purchase_no"))
        seq = (await db.execute(stmt)).scalar()
        return "CGDD%s%04d" % (
            date.today().strftime("%Y%m%d"), seq % 10000)


class ReceiptService:
    """到货验收"""

    COLD_RANGE = (Decimal("2.0"), Decimal("8.0"))
    COOL_MAX = Decimal("20.0")
    NORMAL_RANGE = (Decimal("10.0"), Decimal("30.0"))

    @classmethod
    async def create_receipt(
        cls, db: AsyncSession, user, payload
    ) -> Dict[str, Any]:
        stmt = select(M14PurchaseOrder).where(
            M14PurchaseOrder.id == payload.order_id
        ).with_for_update()
        order = (await db.execute(stmt)).scalar_one_or_none()
        if order is None:
            raise BizError(55319, "订单不存在")
        if order.status not in ("CONFIRMED", "PARTIAL"):
            raise BizError(55319, "订单状态不允许验收")

        if payload.checker_id == payload.reviewer_id:
            raise BizError(55325, "验收人与复核人不能相同")

        receipt_no = await cls._next_receipt_no(db)
        receipt = M14Receipt(
            receipt_no=receipt_no,
            order_id=order.id,
            order_no=order.order_no,
            supplier_id=order.supplier_id,
            supplier_name=order.supplier_name,
            delivery_no=payload.delivery_no,
            arrival_at=payload.arrival_at,
            document_checked=payload.document_checked,
            inspection_report_checked=payload.inspection_report_checked,
            cold_chain_temp=payload.cold_chain_temp,
            checker_id=payload.checker_id,
            reviewer_id=payload.reviewer_id,
            status="DRAFT",
        )
        db.add(receipt)
        await db.flush()

        total_received = Decimal("0.00")
        total_rejected = Decimal("0.00")
        any_reject = False

        for idx, line in enumerate(payload.items, start=1):
            item = await cls._get_order_item(
                db, order.id, line.order_item_id)
            drug = await MdmClient.get_drug(item.drug_id)

            # 数量校验
            remain = item.order_qty - item.received_qty
            tolerance = money(
                remain * PurchaseOrderService.OVER_RECEIPT_RATIO)
            if line.received_qty > remain + tolerance:
                raise BizError(55319, "到货数量超出订单剩余量")

            # 批次与效期
            if item.require_batch and not line.batch_no:
                raise BizError(55321, "批次管理药品必须填写批号")
            if item.require_expiry and not line.expiry_date:
                raise BizError(55322, "效期管理药品必须填写有效期")

            if line.expiry_date:
                days = (line.expiry_date - date.today()).days
                if days < item.min_expiry_days:
                    raise BizError(
                        55323,
                        "剩余效期 %d 天，不满足要求 %d 天"
                        % (days, item.min_expiry_days))

            # 冷链温度
            if drug.get("is_cold_chain"):
                if payload.cold_chain_temp is None:
                    raise BizError(55324, "冷链药品必须记录温度")
                lo, hi = cls.COLD_RANGE
                if not (lo <= Decimal(str(payload.cold_chain_temp)) <= hi):
                    raise BizError(
                        55324, "冷链温度超出 2~8℃ 区间")

            amount = money(item.unit_price * line.received_qty)
            total_received += amount

            if line.rejected_qty > 0:
                any_reject = True
                if line.rejected_qty > line.received_qty:
                    raise BizError(55326, "拒收数量不能大于到货数量")
                total_rejected += money(
                    item.unit_price * line.rejected_qty)

            db.add(M14ReceiptItem(
                receipt_id=receipt.id,
                line_no=idx,
                order_item_id=item.id,
                drug_id=item.drug_id,
                drug_code=item.drug_code,
                drug_name=item.drug_name,
                specification=item.specification,
                package_unit=item.package_unit,
                received_qty=line.received_qty,
                rejected_qty=line.rejected_qty,
                unit_price=item.unit_price,
                amount=amount,
                batch_no=line.batch_no,
                production_date=line.production_date,
                expiry_date=line.expiry_date,
                appearance_ok=line.appearance_ok,
                package_ok=line.package_ok,
                label_ok=line.label_ok,
            ))

            item.received_qty = item.received_qty + line.received_qty

        # 判定结果
        if not any_reject:
            result = "PASS"
        elif total_received > total_rejected:
            result = "PARTIAL_PASS"
        else:
            result = "REJECT"

        receipt.result = result
        receipt.received_amount = money(total_received)
        receipt.rejected_amount = money(total_rejected)
        receipt.status = "CONFIRMED"

        # 订单状态
        if await cls._all_delivered(db, order.id):
            order.status = "COMPLETED"
        else:
            order.status = "PARTIAL"

        await db.flush()

        reject_no = None
        if any_reject:
            reject_no = await RejectService.auto_create(
                db, user, receipt)

        await AuditClient.record(
            user, "M14_RECEIPT_CREATE",
            {"receipt_no": receipt_no, "result": result})

        return {
            "id": receipt.id,
            "receipt_no": receipt_no,
            "result": result,
            "result_text": cls._result_text(result),
            "received_amount": float(receipt.received_amount),
            "rejected_amount": float(receipt.rejected_amount),
            "reject_no": reject_no,
            "order_status": order.status,
            "next_action": ("INBOUND"
                            if result != "REJECT" else "RETURN"),
        }

    @classmethod
    async def confirm(
        cls, db: AsyncSession, user, receipt_id: int,
        warehouse_id: int, idempotency_key: Optional[str],
    ) -> Dict[str, Any]:
        """确认验收并入库"""
        idem = idempotency_key or "RECEIPT:%d:IN" % receipt_id
        existed = await cls._find_idem(db, idem)
        if existed is not None:
            return existed

        stmt = select(M14Receipt).where(
            M14Receipt.id == receipt_id
        ).with_for_update()
        receipt = (await db.execute(stmt)).scalar_one_or_none()
        if receipt is None:
            raise BizError(55330, "验收单不存在")
        if receipt.result == "REJECT":
            raise BizError(55330, "验收结论为全部拒收，不允许入库")
        if receipt.inbound_status == "SUCCESS":
            return await cls._inbound_result(db, receipt)

        items = await cls._receipt_items(db, receipt_id)
        apply_items = []
        for it in items:
            qty = it.received_qty - it.rejected_qty
            if qty <= 0:
                continue
            apply_items.append({
                "drug_id": it.drug_id,
                "batch_no": it.batch_no,
                "expiry_date": (it.expiry_date.isoformat()
                                if it.expiry_date else None),
                "qty": float(qty),
                "unit": it.package_unit,
                "unit_cost": float(it.unit_price),
            })

        if not apply_items:
            raise BizError(55330, "没有可入库的明细")

        resp = await StockClient.apply({
            "idempotency_key": idem,
            "warehouse_id": warehouse_id,
            "apply_type": "PURCHASE_IN",
            "source_type": "RECEIPT",
            "source_id": receipt_id,
            "source_no": receipt.receipt_no,
            "operator_id": user.employee_id,
            "items": apply_items,
        })

        receipt.inbound_status = "SUCCESS"
        receipt.inbound_at = datetime.now()
        await db.flush()

        await AuditClient.record(
            user, "M14_RECEIPT_INBOUND",
            {"receipt_no": receipt.receipt_no,
             "txn_count": len(resp.get("txns", []))})

        return {
            "receipt_no": receipt.receipt_no,
            "inbound_status": "SUCCESS",
            "stock_txns": resp.get("txns", []),
            "location_tasks": len(apply_items),
            "order_status": None,
        }

    @staticmethod
    async def _all_delivered(db: AsyncSession, order_id: int) -> bool:
        stmt = select(func.count()).select_from(
            M14PurchaseOrderItem).where(
            M14PurchaseOrderItem.order_id == order_id,
            M14PurchaseOrderItem.received_qty
            < M14PurchaseOrderItem.order_qty,
        )
        return (await db.execute(stmt)).scalar() == 0

    @staticmethod
    def _result_text(result: str) -> str:
        return {"PASS": "全部合格",
                "PARTIAL_PASS": "部分拒收",
                "REJECT": "全部拒收"}.get(result, result)

    @staticmethod
    async def _next_receipt_no(db: AsyncSession) -> str:
        stmt = select(func.nextval("seq_m14_purchase_no"))
        seq = (await db.execute(stmt)).scalar()
        return "YS%s%04d" % (
            date.today().strftime("%Y%m%d"), seq % 10000)

    @staticmethod
    async def _get_order_item(db, order_id, item_id):
        stmt = select(M14PurchaseOrderItem).where(
            M14PurchaseOrderItem.id == item_id,
            M14PurchaseOrderItem.order_id == order_id,
        )
        item = (await db.execute(stmt)).scalar_one_or_none()
        if item is None:
            raise BizError(55319, "订单行不存在")
        return item

    @staticmethod
    async def _receipt_items(db, receipt_id):
        stmt = select(M14ReceiptItem).where(
            M14ReceiptItem.receipt_id == receipt_id
        ).order_by(M14ReceiptItem.line_no)
        return (await db.execute(stmt)).scalars().all()


class InboundService:
    """入库上架"""

    STORAGE_LOCATION_MAP = {
        "COLD": ("COLD", "COOL"),
        "COOL": ("COOL", "COLD"),
        "NORMAL": ("NORMAL",),
    }

    @classmethod
    async def inbound(
        cls, db: AsyncSession, user, receipt_id: int, payload
    ) -> Dict[str, Any]:
        stmt = select(M14Receipt).where(
            M14Receipt.id == receipt_id
        ).with_for_update()
        receipt = (await db.execute(stmt)).scalar_one_or_none()
        if receipt is None:
            raise BizError(55330, "验收单不存在")
        if receipt.inbound_status == "SUCCESS":
            return await ReceiptService._inbound_result(db, receipt)

        items = await ReceiptService._receipt_items(db, receipt_id)
        item_map = {it.id: it for it in items}

        apply_items = []
        for line in payload.items:
            it = item_map.get(line.receipt_item_id)
            if it is None:
                raise BizError(55330, "验收明细不存在")
            qty = it.received_qty - it.rejected_qty
            if qty <= 0:
                continue

            drug = await MdmClient.get_drug(it.drug_id)
            await cls._check_location(
                line.location_code, drug, it.drug_id)

            apply_items.append({
                "drug_id": it.drug_id,
                "batch_no": it.batch_no,
                "expiry_date": (it.expiry_date.isoformat()
                                if it.expiry_date else None),
                "qty": float(qty),
                "unit": it.package_unit,
                "unit_cost": float(it.unit_price),
                "location_code": line.location_code,
            })

        resp = await StockClient.apply({
            "idempotency_key": "RECEIPT:%d:IN" % receipt_id,
            "warehouse_id": payload.warehouse_id,
            "apply_type": "PURCHASE_IN",
            "source_type": "RECEIPT",
            "source_id": receipt_id,
            "source_no": receipt.receipt_no,
            "operator_id": user.employee_id,
            "items": apply_items,
        })

        receipt.inbound_status = "SUCCESS"
        receipt.inbound_at = datetime.now()
        await db.flush()

        return {
            "receipt_no": receipt.receipt_no,
            "inbound_qty": float(sum(
                Decimal(str(i["qty"])) for i in apply_items)),
            "stock_txn_count": len(resp.get("txns", [])),
            "status": "INBOUNDED",
        }

    @classmethod
    async def _check_location(
        cls, location_code: str, drug: Dict[str, Any], drug_id: int
    ) -> None:
        """校验库位与药品存储条件匹配"""
        loc = await StockClient.get_location(location_code)
        if loc is None:
            raise BizError(55312, "库位不存在")

        cond = drug.get("storage_condition") or "NORMAL"
        allowed = cls.STORAGE_LOCATION_MAP.get(cond, ("NORMAL",))
        if loc["location_type"] not in allowed:
            raise BizError(
                55312,
                "库位类型 %s 与药品存储条件 %s 不匹配"
                % (loc["location_type"], cond))

        if drug.get("is_narcotic") or drug.get("is_psychotropic"):
            if loc["location_type"] not in (
                    "NARCOTIC", "PSYCHOTROPIC"):
                raise BizError(55331, "麻精药品必须入专柜库位")


class RejectService:
    """拒收"""

    @classmethod
    async def auto_create(
        cls, db: AsyncSession, user, receipt
    ) -> str:
        items = await ReceiptService._receipt_items(db, receipt.id)
        reject_no = await cls._next_reject_no(db)
        rej = M14Reject(
            reject_no=reject_no,
            receipt_id=receipt.id,
            receipt_no=receipt.receipt_no,
            order_id=receipt.order_id,
            supplier_id=receipt.supplier_id,
            supplier_name=receipt.supplier_name,
            handler_action="RETURN_SUPPLIER",
            status="DRAFT",
        )
        db.add(rej)
        await db.flush()

        seq = 0
        for it in items:
            if it.rejected_qty <= 0:
                continue
            seq += 1
            db.add(M14RejectItem(
                reject_id=rej.id,
                line_no=seq,
                receipt_item_id=it.id,
                drug_id=it.drug_id,
                drug_code=it.drug_code,
                drug_name=it.drug_name,
                batch_no=it.batch_no,
                reject_qty=it.rejected_qty,
                reject_type="QUALITY",
                reject_reason="验收发现不合格",
            ))
        await db.flush()
        return reject_no

    @staticmethod
    async def _next_reject_no(db: AsyncSession) -> str:
        stmt = select(func.nextval("seq_m14_purchase_no"))
        seq = (await db.execute(stmt)).scalar()
        return "JS%s%04d" % (
            date.today().strftime("%Y%m%d"), seq % 10000)


class PurchaseReturnService:
    """采购退货"""

    @classmethod
    async def create_return(
        cls, db: AsyncSession, user, payload
    ) -> Dict[str, Any]:
        if not payload.reason or len(payload.reason.strip()) < 10:
            raise BizError(55335, "退货原因必须填写（≥10 字）")

        return_no = await cls._next_return_no(db)
        ret = M14PurchaseReturn(
            return_no=return_no,
            order_id=payload.order_id,
            supplier_id=payload.supplier_id,
            return_type=payload.return_type,
            return_reason=payload.reason,
            status="DRAFT",
            created_by=user.employee_id,
        )
        db.add(ret)
        await db.flush()

        total = Decimal("0.00")
        for idx, line in enumerate(payload.items, start=1):
            batch = await StockClient.get_batch(line.batch_id)
            if batch is None:
                raise BizError(55333, "只能退原采购入库的批次")
            if line.return_qty > Decimal(
                    str(batch["qty_available"])):
                raise BizError(55332, "退货数量超出可用库存")
            amount = money(line.unit_price * line.return_qty)
            total += amount
            db.add(M14PurchaseReturnItem(
                return_id=ret.id,
                line_no=idx,
                drug_id=line.drug_id,
                batch_id=line.batch_id,
                batch_no=batch["batch_no"],
                return_qty=line.return_qty,
                unit_price=line.unit_price,
                amount=amount,
            ))

        ret.total_amount = money(total)
        await db.flush()

        await AuditClient.record(
            user, "M14_PURCHASE_RETURN_CREATE",
            {"return_no": return_no, "total": float(total)})

        return {"id": ret.id, "return_no": return_no,
                "total_amount": float(total), "status": "DRAFT"}

    @classmethod
    async def confirm(
        cls, db: AsyncSession, user, return_id: int
    ) -> Dict[str, Any]:
        stmt = select(M14PurchaseReturn).where(
            M14PurchaseReturn.id == return_id
        ).with_for_update()
        ret = (await db.execute(stmt)).scalar_one_or_none()
        if ret is None:
            raise BizError(55332, "退货单不存在")
        if ret.status != "APPROVED":
            raise BizError(55332, "退货单未审批通过")

        items = await cls._items(db, return_id)
        apply_items = [{
            "drug_id": it.drug_id,
            "batch_id": it.batch_id,
            "qty": float(it.return_qty),
        } for it in items]

        resp = await StockClient.apply({
            "idempotency_key": "PURCHASE_RETURN:%d" % return_id,
            "warehouse_id": ret.warehouse_id or 1,
            "apply_type": "PURCHASE_RETURN",
            "source_type": "PURCHASE_RETURN",
            "source_id": return_id,
            "source_no": ret.return_no,
            "operator_id": user.employee_id,
            "items": apply_items,
        })

        ret.status = "CONFIRMED"
        ret.confirmed_at = datetime.now()
        await db.flush()

        return {"return_no": ret.return_no,
                "status": "CONFIRMED",
                "stock_txns": resp.get("txns", [])}

    @staticmethod
    async def _items(db, return_id):
        stmt = select(M14PurchaseReturnItem).where(
            M14PurchaseReturnItem.return_id == return_id)
        return (await db.execute(stmt)).scalars().all()

    @staticmethod
    async def _next_return_no(db: AsyncSession) -> str:
        stmt = select(func.nextval("seq_m14_purchase_no"))
        seq = (await db.execute(stmt)).scalar()
        return "CT%s%04d" % (
            date.today().strftime("%Y%m%d"), seq % 10000)
```
