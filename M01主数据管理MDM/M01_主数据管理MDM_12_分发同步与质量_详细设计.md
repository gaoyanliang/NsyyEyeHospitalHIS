## 1. 模块概述

### 1.1 模块定位

分发、同步与质量监控是 M01 的**对外出口与自检机制**。前序子模块解决了"主数据是什么、怎么管控"，本子模块解决"**如何可靠地送达各业务模块**"与"**数据质量是否达标**"。

总体设计第 10 章《主数据分发与集成》明确要求：主数据变更需实时分发给全部订阅方；第 11 章非功能性设计要求"数据一致性"与"可用性"。本子模块是这两项要求的落地。

| 职责 | 归属 | 说明 |
|---|---|---|
| 变更事件分发（`md_distribution`） | **M01 分发子模块（本文档）** | MQ/HTTP/Redis 三通道 |
| 订阅方消费位点（`md_sync_checkpoint`） | **M01 分发子模块（本文档）** | 每订阅方每域位点 |
| 全量快照服务 | **M01 分发子模块（本文档）** | 订阅方自愈式拉取 |
| 重推与补偿 | **M01 分发子模块（本文档）** | 失败重试、人工重推 |
| 数据质量规则（`md_quality_rule`） | **M01 分发子模块（本文档）** | 可配置质量规则 |
| 质量扫描结果（`md_quality_result`） | **M01 分发子模块（本文档）** | 每日扫描落库 |
| 质量问题工单（`md_quality_issue`） | **M01 分发子模块（本文档）** | 问题跟踪与修复 |
| 批量导入任务（`md_import_task`） | **M01 分发子模块（本文档）** | 向导式导入 |
| 批量导出任务（`md_export_task`） | **M01 分发子模块（本文档）** | 异步导出 |
| 业务模块消费 | 各业务模块 | 订阅事件、拉取快照 |
| 消息中间件运维 | 平台/M23 | — |

> **一句话边界**：本子模块回答"**变更有没有送到、送到哪了、有没有丢、数据干不干净**"；业务模块只负责"**收到后怎么用**"。

### 1.2 模块目标

- **不丢消息**：事件持久化 + 位点 + 快照重放，三重保障。
- **可观测**：每条分发记录可查状态、耗时、重试次数、错误信息。
- **可自愈**：订阅方位点落后时，自动触发全量快照重同步。
- **可补偿**：失败记录支持单条/批量重推，超阈值自动告警。
- **质量可量化**：8 类质量指标按域统计，阈值告警，周报推送。
- **问题可闭环**：质量问题生成工单，指派到人，跟踪到修复。
- **导入可控**：全量校验、预览确认、并发互斥、变更单联动。

### 1.3 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 信息科 | 分发运维 | 查看分发状态、重推失败记录 |
| 运维工程师 | 故障处理 | 全量同步、位点重置 |
| 数据管理员 | 质量治理 | 查看质量看板、处理质量工单 |
| 各域负责人 | 数据整改 | 接收质量工单、修正数据 |
| 主数据专员 | 批量导入 | 导入向导、错误修正 |
| 审计 | 追溯 | 查看分发与质量历史 |

## 3. 分发与质量模型

### 3.1 分发模型

#### 3.1.1 双通道设计

| 通道 | 用途 | 特点 | 容量 |
|---|---|---|---|
| **事件通道（增量）** | 变更实时通知 | 实时、轻量、可能丢失 | 高频 |
| **快照通道（全量）** | 订阅方自愈 | 完整、慢、可靠 | 低频 |

**核心原则：订阅方启动时先拉快照建立基线，再消费事件增量。**

```
订阅方启动
   ↓
GET /api/v1/mdm/snapshot/{domain}  → 获取全量快照 + version
   ↓
建立本地基线（version = V0）
   ↓
订阅 MQ 事件（从 V0 之后）
   ↓
消费事件 → 更新本地（version = V0+n）
   ↓
定时（每小时）比对位点，发现落后 → 重新拉快照
```

#### 3.1.2 投递方式

| 方式 | 说明 | 适用 |
|---|---|---|
| `MQ` | RabbitMQ 交换机 + 队列 | 绝大多数模块（推荐） |
| `HTTP` | 回调订阅方接口 | 外部系统（医保接口） |
| `REDIS` | Redis Pub/Sub | 轻量实时通知 |

#### 3.1.3 分发状态

| 状态 | 说明 |
|---|---|
| `PENDING` | 待投递 |
| `SENDING` | 投递中 |
| `SUCCESS` | 投递成功（MQ ack / HTTP 2xx） |
| `FAILED` | 投递失败 |
| `IGNORED` | 人工忽略 |
| `TIMEOUT` | 超时未 ack |

#### 3.1.4 重试策略

| 重试次数 | 间隔 | 说明 |
|---|---|---|
| 第 1 次 | 立即 | — |
| 第 2 次 | 30s | — |
| 第 3 次 | 2min | — |
| 第 4 次 | 10min | — |
| 第 5 次 | 30min | — |
| 超过 5 次 | — | 标记 FAILED，告警信息科 |

**退避算法：** `delay = min(30 * 2^(n-1), 1800)` 秒。

#### 3.1.5 事件类型命名

```
mdm.{domain}.{action}

示例：
mdm.drug.created
mdm.drug.updated
mdm.drug.disabled
mdm.dept.updated
mdm.price.changed
mdm.dict.item.changed
```

**域代码映射：**

| 域 | 事件前缀 |
|---|---|
| ORG | `mdm.dept.*` / `mdm.staff.*` |
| PAT | `mdm.patient.*` |
| MAT | `mdm.drug.*` / `mdm.material.*` |
| CLI | `mdm.diagnosis.*` / `mdm.exam.*` / `mdm.lab.*` / `mdm.operation.*` |
| FEE | `mdm.charge.*` / `mdm.price.*` |
| AUTH | `mdm.role.*` / `mdm.permission.*` |
| DICT | `mdm.dict.*` / `mdm.param.*` |
| OPT | `mdm.optical.*` |

### 3.2 快照模型

#### 3.2.1 快照结构

```json
{
  "domain_code": "MAT",
  "object_type": "mdm_drug",
  "snapshot_version": "V20260401093000-00128",
  "total_count": 1286,
  "page": 1,
  "page_size": 500,
  "items": [
    {
      "id": 1200021,
      "code": "DR1200021",
      "name": "妥布霉素滴眼液",
      "retail_price": 32.80,
      "status": "ENABLED",
      "updated_at": "2026-04-01T09:30:00"
    }
  ],
  "checksum": "sha256:abc123...",
  "generated_at": "2026-04-01T09:30:00+08:00"
}
```

#### 3.2.2 快照生成

| 方式 | 说明 |
|---|---|
| 实时生成 | 小域（<1000 条）直接查询生成 |
| 预生成 | 大域每日 02:00 预生成并缓存 |
| 增量快照 | 支持 `since_version` 参数只返回变化 |

#### 3.2.3 校验和

- 每页快照计算 `checksum`（sha256 of sorted items）。
- 订阅方全部拉取完成后比对总 `checksum`，不一致则重拉。

### 3.3 数据质量模型

#### 3.3.1 质量规则类型

| 规则代码 | 规则名称 | 计算方式 | 目标值 |
|---|---|---|---|
| `REQUIRED_COMPLETENESS` | 必填字段完整率 | 非空字段 / 应填字段 | ≥99% |
| `NAME_DUPLICATE` | 名称重复率 | 疑似重复 / 总数 | ≤0.5% |
| `CODE_STANDARD` | 编码规范率 | 符合规则 / 总数 | 100% |
| `UNUSED_DATA` | 长期未使用率 | 90 天无引用 / 总数 | — |
| `CERT_EXPIRING` | 证件到期数 | 60 天内到期数 | 0 |
| `PRICE_ANOMALY` | 价格异常数 | 低于成本或超限价 | 0 |
| `STOCK_ANOMALY` | 库存异常数 | 负库存 / 超上限 | 0 |
| `UNAPPROVED_DATA` | 未审批数据量 | 草稿+待审批 | 趋势下降 |

#### 3.3.2 规则配置

| 字段 | 说明 |
|---|---|
| `domain_code` | 适用主数据域 |
| `object_type` | 适用对象类型 |
| `rule_code` | 规则代码 |
| `rule_params` | 规则参数（JSON，如阈值字段名） |
| `threshold` | 告警阈值 |
| `compare_op` | 比较符（GT/LT/GTE/LTE） |
| `severity` | 严重级别（HIGH/MEDIUM/LOW） |
| `is_enabled` | 是否启用 |

#### 3.3.3 重复检测算法（三级）

**一级：精确匹配**
```
normalize(name) → 去空格、全角转半角、转小写、去标点
name_normalized 完全相等 → 判为重复
```

**二级：相似匹配**
```
similarity = 0.4 * (1 - edit_distance/max_len)
           + 0.3 * (pinyin_code 相同 ? 1 : 0)
           + 0.3 * (spec 相同 ? 1 : 0)

similarity ≥ MDM.DUP.NAME_THRESHOLD（默认 0.85）→ 疑似重复
```

**三级：关键字段匹配**

| 域 | 关键字段组合 |
|---|---|
| 药品 | `通用名 + 规格 + 厂商` |
| 耗材 | `名称 + 规格 + UDI` |
| 视光产品 | `品牌 + 品类 + 型号` |
| 手术 | `手术名称 + ICD-9` |
| 检查 | `检查名称 + 模态` |
| 诊断 | `ICD-10 编码` |

#### 3.3.4 质量问题分级

| 级别 | 说明 | 处理要求 |
|---|---|---|
| `HIGH` | 严重问题（如编码不规范、价格异常） | 7 天内修复 |
| `MEDIUM` | 中等问题（如名称重复、证件临期） | 30 天内修复 |
| `LOW` | 提示性问题（如长期未使用） | 持续观察 |

### 3.4 导入导出模型

#### 3.4.1 导入流程

```
步骤 1：选择目标（域 → 对象）
   ↓
步骤 2：下载模板（含下拉验证 + 示例行 + 字典说明 Sheet）
   ↓
步骤 3：上传文件（前端预校验：格式/大小/行数）
   ↓
步骤 4：后端异步校验
   · 全量校验，返回：总行数 / 通过 / 警告 / 错误
   · 错误明细可下载
   ↓
步骤 5：预览确认
   · 选择模式：仅新增 / 新增+更新 / 跳过错误行
   ↓
步骤 6：执行导入
   · 生成变更单（如需审批）
   · 后台分批写入
   ↓
步骤 7：结果通知
```

#### 3.4.2 导入模式

| 模式 | 说明 |
|---|---|
| `INSERT` | 仅新增，遇重复编码报错 |
| `UPDATE` | 仅更新，遇不存在编码报错 |
| `UPSERT` | 新增+更新（按编码匹配） |
| `SKIP_ERROR` | 跳过错误行继续 |

#### 3.4.3 导出模型

| 特性 | 说明 |
|---|---|
| 范围 | 当前筛选 / 全部 / 选中 |
| 列选择 | 可选导出哪些列 |
| 脱敏 | 敏感字段脱敏（如身份证） |
| 字典翻译 | 编码 → 名称 |
| 格式 | xlsx / csv |
| 异步 | >10000 行走异步任务 |

# app/services/mdm/distribution_service.py
"""分发服务（核心）"""
import json
import uuid
from datetime import datetime, timedelta
from typing import Optional, List

from sqlalchemy import select, and_
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.mdm.distribution import Distribution, DistributionRetry
from app.schemas.mdm.distribution import PublishEventRequest, DistributionRetryRequest
from app.core.exceptions import BizException
from app.core.message import rabbitmq_publisher
from app.core.redis import redis_client


# 订阅关系：域 → 订阅方列表
DOMAIN_SUBSCRIBERS = {
    "ORG": ["M04", "M05", "M06", "M07", "M08", "M09", "M10", "M11",
            "M12", "M13", "M14", "M15", "M16", "M19", "M20"],
    "PAT": ["M03", "M05", "M06", "M07"],
    "MAT": ["M05", "M06", "M07", "M09", "M14", "M15"],
    "CLI": ["M05", "M07", "M08", "M09", "M10", "M11", "M12",
            "M13", "M16", "M18", "M19"],
    "FEE": ["M04", "M05", "M06", "M07", "M10", "M16", "M17"],
    "AUTH": ["M20", "M23"],
    "DICT": ["M23"],
    "OPT": ["M10", "M11"],
}

# 投递方式
SUBSCRIBER_MODE = {
    "M21": "HTTP",   # 医保接口
    "M22": "MQ",     # 报表（另有 ETL）
}
DEFAULT_MODE = "MQ"


class DistributionService:
    def __init__(self, db: AsyncSession):
        self.db = db

    # ---------- 发布事件 ----------
    async def publish(self, req: PublishEventRequest) -> dict:
        """发布事件到全部订阅方"""
        event_id = req.payload.get("event_id") or str(uuid.uuid4())
        req.payload["event_id"] = event_id

        # 获取全局版本号
        version = await redis_client.incr("mdm:dist:version")

        subscribers = req.subscribers or DOMAIN_SUBSCRIBERS.get(req.domain_code, [])
        if not subscribers:
            return {
                "event_id": event_id,
                "version": version,
                "subscriber_count": 0,
                "dispatched": [],
                "failed_count": 0,
            }

        dispatched = []
        failed = 0
        for sub in subscribers:
            mode = SUBSCRIBER_MODE.get(sub, DEFAULT_MODE)
            dist = Distribution(
                event_id=event_id,
                event_type=req.event_type,
                domain_code=req.domain_code,
                object_type=req.object_type,
                object_id=req.object_id,
                object_code=req.object_code,
                object_name=req.object_name,
                change_type=req.change_type,
                subscriber=sub,
                deliver_mode=mode,
                exchange_name=f"mdm.{req.domain_code.lower()}",
                routing_key=f"mdm.{req.domain_code.lower()}.{sub.lower()}",
                payload=req.payload,
                payload_size=len(json.dumps(req.payload)),
                version=version,
                dist_status="PENDING",
            )
            self.db.add(dist)
            await self.db.flush()

            # 投递
            try:
                start = datetime.now()
                if mode == "MQ":
                    await rabbitmq_publisher.publish(
                        exchange=dist.exchange_name,
                        routing_key=dist.routing_key,
                        message=req.payload,
                        timeout=30,
                    )
                elif mode == "HTTP":
                    await self._deliver_http(dist, req.payload)
                elif mode == "REDIS":
                    await redis_client.publish(
                        f"mdm:{req.domain_code.lower()}:{sub.lower()}",
                        json.dumps(req.payload))

                cost = int((datetime.now() - start).total_seconds() * 1000)
                dist.dist_status = "SUCCESS"
                dist.cost_ms = cost
                dist.finished_at = datetime.now()
                dispatched.append({
                    "subscriber": sub, "dist_id": dist.id,
                    "status": "SUCCESS", "cost_ms": cost})
            except Exception as e:
                dist.dist_status = "FAILED"
                dist.error_msg = str(e)[:1000]
                dist.retry_count = 1
                dist.next_retry_at = datetime.now() + timedelta(seconds=30)
                dist.finished_at = datetime.now()
                failed += 1
                dispatched.append({
                    "subscriber": sub, "dist_id": dist.id,
                    "status": "FAILED", "error": str(e)[:200]})
                # 记录重试明细
                self.db.add(DistributionRetry(
                    distribution_id=dist.id, event_id=event_id,
                    retry_seq=1, retry_type="AUTO",
                    dist_status="FAILED", error_msg=str(e)[:1000]))

        await self.db.commit()
        return {
            "event_id": event_id,
            "version": version,
            "subscriber_count": len(subscribers),
            "dispatched": dispatched,
            "failed_count": failed,
        }

    async def _deliver_http(self, dist: Distribution, payload: dict) -> None:
        """HTTP 投递"""
        import httpx
        url = f"http://{dist.subscriber.lower()}.internal/api/v1/events"
        async with httpx.AsyncClient(timeout=30) as client:
            resp = await client.post(url, json=payload)
            dist.http_status = resp.status_code
            dist.response_body = resp.text[:2000]
            if resp.status_code >= 400:
                raise RuntimeError(f"HTTP {resp.status_code}: {resp.text[:200]}")

    # ---------- 重推 ----------
    async def retry(self, payload: DistributionRetryRequest, operator) -> dict:
        """批量重推"""
        results = []
        success, failed = 0, 0

        for dist_id in payload.ids:
            dist = (await self.db.execute(
                select(Distribution).where(Distribution.id == dist_id)
            )).scalar_one_or_none()

            if not dist:
                results.append({"id": dist_id, "status": "FAILED", "error": "分发记录不存在"})
                failed += 1
                continue

            if not payload.force and dist.retry_count >= dist.max_retry:
                results.append({"id": dist_id, "status": "FAILED",
                                "error": "已超过最大重试次数"})
                failed += 1
                continue

            try:
                start = datetime.now()
                if dist.deliver_mode == "MQ":
                    await rabbitmq_publisher.publish(
                        exchange=dist.exchange_name or f"mdm.{dist.domain_code.lower()}",
                        routing_key=dist.routing_key or "",
                        message=dist.payload, timeout=30)
                elif dist.deliver_mode == "HTTP":
                    await self._deliver_http(dist, dist.payload)
                elif dist.deliver_mode == "REDIS":
                    await redis_client.publish(
                        f"mdm:{dist.domain_code.lower()}:{dist.subscriber.lower()}",
                        json.dumps(dist.payload))

                cost = int((datetime.now() - start).total_seconds() * 1000)
                dist.dist_status = "SUCCESS"
                dist.cost_ms = cost
                dist.finished_at = datetime.now()
                dist.next_retry_at = None
                success += 1
                results.append({"id": dist_id, "event_id": dist.event_id,
                                "subscriber": dist.subscriber,
                                "status": "SUCCESS", "cost_ms": cost})
            except Exception as e:
                dist.retry_count += 1
                dist.dist_status = "FAILED"
                dist.error_msg = str(e)[:1000]
                dist.next_retry_at = datetime.now() + timedelta(
                    seconds=dist.next_backoff_seconds())
                failed += 1
                results.append({"id": dist_id, "status": "FAILED", "error": str(e)[:200]})

            self.db.add(DistributionRetry(
                distribution_id=dist.id, event_id=dist.event_id,
                retry_seq=dist.retry_count, retry_type="MANUAL",
                dist_status=dist.dist_status,
                error_msg=dist.error_msg,
                operator_id=operator.id))

        await self.db.commit()
        return {
            "total": len(payload.ids),
            "success_count": success,
            "failed_count": failed,
            "results": results,
        }

    # ---------- 忽略 ----------
    async def ignore(self, payload: DistributionIgnoreRequest, operator) -> dict:
        from sqlalchemy import update
        await self.db.execute(
            update(Distribution)
            .where(Distribution.id.in_(payload.ids))
            .values(dist_status="IGNORED", ignore_reason=payload.reason,
                    finished_at=datetime.now())
        )
        await self.db.commit()
        return {
            "total": len(payload.ids),
            "ignored_count": len(payload.ids),
            "reason": payload.reason,
        }

        stmt = select(QualityRule).where(QualityRule.is_enabled == True)
        if req.domain_code:
            stmt = stmt.where(QualityRule.domain_code == req.domain_code)
        if req.object_type:
            stmt = stmt.where(
                (QualityRule.object_type == req.object_type)
                | (QualityRule.object_type.is_(None)))
        if req.rule_codes:
            stmt = stmt.where(QualityRule.rule_code.in_(req.rule_codes))

        rules = (await self.db.execute(stmt)).scalars().all()

        results, alert_count = [], 0
        for rule in rules:
            r = await self._scan_one(rule, batch, scan_mode, req.sample_size)
            results.append(r)
            if r["is_alert"]:
                alert_count += 1
                # 自动建单
                if rule.auto_create_issue and r["detail"]:
                    await self._create_issues(rule, r, batch)

        await self.db.commit()
        return {
            "scan_batch": batch,
            "scan_mode": scan_mode,
            "total_rules": len(rules),
            "alert_count": alert_count,
            "results": results,
        }

    async def _scan_one(self, rule: QualityRule, batch: str,
                         scan_mode: str, sample_size: int) -> dict:
        """执行单条规则"""
        from app.models.mdm.distribution import QualityResult  # 延迟导入

        start = datetime.now()
        table = rule.object_type or self._default_table(rule.domain_code)
        if not table:
            return {"rule_code": rule.rule_code, "error": "无法确定表名"}

        total, issue = 0, 0
        detail = []

        try:
            if rule.rule_code == "REQUIRED_COMPLETENESS":
                total, issue, detail = await self._check_completeness(
                    table, rule, sample_size)
            elif rule.rule_code == "NAME_DUPLICATE":
                total, issue, detail = await self._check_duplicate(
                    table, rule, sample_size)
            elif rule.rule_code == "CODE_STANDARD":
                total, issue, detail = await self._check_code(
                    table, rule, sample_size)
            elif rule.rule_code == "CERT_EXPIRING":
                total, issue, detail = await self._check_cert(table, rule)
            elif rule.rule_code == "PRICE_ANOMALY":
                total, issue, detail = await self._check_price(table, rule)
            elif rule.rule_code == "UNAPPROVED_DATA":
                total, issue, detail = await self._check_unapproved(table)
            elif rule.rule_code == "UNUSED_DATA":
                total, issue, detail = await self._check_unused(table, rule)
            elif rule.rule_code == "STOCK_ANOMALY":
                total, issue, detail = await self._check_stock(table, rule)
        except Exception as e:
            return {"rule_code": rule.rule_code, "error": str(e)[:200]}

        rate = round(issue / total * 100, 4) if total else 0
        is_alert = rule.alert_enabled and rule.is_exceeded(Decimal(str(rate)))

        # 落库
        self.db.add(QualityResult(
            scan_batch=batch,
            scan_date=date.today(),
            scan_mode=scan_mode,
            domain_code=rule.domain_code,
            object_type=table,
            rule_id=rule.id,
            rule_code=rule.rule_code,
            rule_name=rule.rule_name,
            total_count=total,
            pass_count=total - issue,
            issue_count=issue,
            issue_rate=Decimal(str(rate)),
            threshold=rule.threshold,
            is_alert=is_alert,
            severity=rule.severity,
            detail_json={"items": detail[:50]},
            cost_ms=int((datetime.now() - start).total_seconds() * 1000),
        ))

        return {
            "rule_code": rule.rule_code,
            "rule_name": rule.rule_name,
            "domain_code": rule.domain_code,
            "object_type": table,
            "total_count": total,
            "issue_count": issue,
            "issue_rate": rate,
            "threshold": float(rule.threshold) if rule.threshold else None,
            "is_alert": is_alert,
            "severity": rule.severity,
            "detail": detail[:20],
        }

    async def _check_completeness(self, table: str, rule: QualityRule,
                                    sample_size: int):
        """必填字段完整率"""
        fields = (rule.rule_params or {}).get("fields", [])
        if not fields:
            return 0, 0, []

        conds = " OR ".join([f"{f} IS NULL" for f in fields])
        sql_total = text(f"SELECT COUNT(*) FROM {table} WHERE is_deleted = FALSE")
        sql_issue = text(
            f"SELECT COUNT(*) FROM {table} WHERE is_deleted = FALSE AND ({conds})")

        total = (await self.db.execute(sql_total)).scalar_one()
        issue = (await self.db.execute(sql_issue)).scalar_one()

        sql_detail = text(
            f"SELECT id, code, name, {', '.join(fields)} FROM {table} "
            f"WHERE is_deleted = FALSE AND ({conds}) LIMIT {sample_size}")
        rows = (await self.db.execute(sql_detail)).mappings().all()

        detail = [
            {"object_id": r["id"], "code": r.get("code"), "name": r.get("name"),
             "missing_fields": [f for f in fields if r.get(f) is None]}
            for r in rows
        ]
        return total, issue, detail

    async def _check_duplicate(self, table: str, rule: QualityRule,
                                 sample_size: int):
        """名称重复率（简化：同名计数）"""
        sql = text(
            f"SELECT name, COUNT(*) AS cnt FROM {table} "
            f"WHERE is_deleted = FALSE AND status = 'ENABLED' "
            f"GROUP BY name HAVING COUNT(*) > 1 LIMIT {sample_size}")
        rows = (await self.db.execute(sql)).mappings().all()

        sql_total = text(f"SELECT COUNT(*) FROM {table} WHERE is_deleted = FALSE")
        total = (await self.db.execute(sql_total)).scalar_one()
        issue = sum(r["cnt"] - 1 for r in rows)

        detail = [{"name": r["name"], "count": r["cnt"]} for r in rows]
        return total, issue, detail

    async def _check_code(self, table: str, rule: QualityRule,
                            sample_size: int):
        """编码规范率"""
        pattern = (rule.rule_params or {}).get("pattern", "^[A-Z]{2,4}[0-9]{5,6}$")
        sql_total = text(f"SELECT COUNT(*) FROM {table} WHERE is_deleted = FALSE")
        sql_issue = text(
            f"SELECT COUNT(*) FROM {table} WHERE is_deleted = FALSE "
            f"AND code !~ :pattern")
        sql_detail = text(
            f"SELECT id, code, name FROM {table} WHERE is_deleted = FALSE "
            f"AND code !~ :pattern LIMIT {sample_size}")

        total = (await self.db.execute(sql_total)).scalar_one()
        issue = (await self.db.execute(sql_issue, {"pattern": pattern})).scalar_one()
        rows = (await self.db.execute(sql_detail, {"pattern": pattern})).mappings().all()

        detail = [{"object_id": r["id"], "code": r["code"], "name": r["name"],
                   "pattern": pattern} for r in rows]
        return total, issue, detail

    async def _check_cert(self, table: str, rule: QualityRule):
        """证件到期"""
        days = (rule.rule_params or {}).get("days", 60)
        sql = text(
            f"SELECT id, code, name, registration_expire FROM {table} "
            f"WHERE is_deleted = FALSE AND registration_expire IS NOT NULL "
            f"AND registration_expire <= CURRENT_DATE + INTERVAL '{days} days'")
        rows = (await self.db.execute(sql)).mappings().all()

        sql_total = text(f"SELECT COUNT(*) FROM {table} WHERE is_deleted = FALSE")
        total = (await self.db.execute(sql_total)).scalar_one()

        detail = [{"object_id": r["id"], "code": r["code"], "name": r["name"],
                   "expire_date": str(r["registration_expire"])} for r in rows]
        return total, len(rows), detail

    async def _check_price(self, table: str, rule: QualityRule):
        """价格异常：低于成本或超限价"""
        sql = text(
            f"SELECT id, code, name, retail_price, cost_price, max_retail_price "
            f"FROM {table} WHERE is_deleted = FALSE AND ("
            f"(cost_price IS NOT NULL AND retail_price < cost_price) OR "
            f"(max_retail_price IS NOT NULL AND retail_price > max_retail_price))")
        rows = (await self.db.execute(sql)).mappings().all()

        sql_total = text(f"SELECT COUNT(*) FROM {table} WHERE is_deleted = FALSE")
        total = (await self.db.execute(sql_total)).scalar_one()

        detail = [
            {"object_id": r["id"], "code": r["code"], "name": r["name"],
             "retail_price": float(r["retail_price"]) if r["retail_price"] else None,
             "cost_price": float(r["cost_price"]) if r["cost_price"] else None,
             "max_retail_price": float(r["max_retail_price"]) if r["max_retail_price"] else None}
            for r in rows
        ]
        return total, len(rows), detail

    async def _check_unapproved(self, table: str):
        """未审批数据量"""
        sql_issue = text(
            f"SELECT COUNT(*) FROM {table} "
            f"WHERE is_deleted = FALSE AND audit_status IN ('DRAFT','PENDING')")
        sql_total = text(f"SELECT COUNT(*) FROM {table} WHERE is_deleted = FALSE")
        total = (await self.db.execute(sql_total)).scalar_one()
        issue = (await self.db.execute(sql_issue)).scalar_one()
        return total, issue, []

    async def _check_unused(self, table: str, rule: QualityRule):
        """长期未使用"""
        days = (rule.rule_params or {}).get("days", 90)
        sql = text(
            f"SELECT COUNT(*) FROM {table} "
            f"WHERE is_deleted = FALSE AND updated_at < CURRENT_DATE - INTERVAL '{days} days'")
        sql_total = text(f"SELECT COUNT(*) FROM {table} WHERE is_deleted = FALSE")
        total = (await self.db.execute(sql_total)).scalar_one()
        issue = (await self.db.execute(sql)).scalar_one()
        return total, issue, []

    async def _check_stock(self, table: str, rule: QualityRule):
        """库存异常（委托 M15）"""
        # 实际实现调用 M15 接口；此处返回占位
        return 0, 0, []

    @staticmethod
    def _default_table(domain_code: str) -> Optional[str]:
        return {
            "ORG": "mdm_department",
            "MAT": "mdm_material",
            "CLI": "md_exam_item",
            "FEE": "md_charge_item",
            "OPT": "mdm_optical_product",
        }.get(domain_code)

    async def _create_issues(self, rule: QualityRule, result: dict, batch: str):
        """自动生成质量工单"""
        for item in result["detail"][:100]:
            issue_no = f"QI{datetime.now().strftime('%Y%m%d')}{uuid.uuid4().hex[:5].upper()}"

                scan_batch=batch,

                object_type=result["object_type"],

                object_code=item.get("code"),
                object_name=item.get("name"),
                rule_code=rule.rule_code,
                rule_name=rule.rule_name,
                severity=rule.severity,
                issue_desc=f"{rule.rule_name}：{json.dumps(item, ensure_ascii=False)[:500]}",
                issue_detail=item,
                issue_status="OPEN",
                sla_deadline=(datetime.now()
                              + timedelta(days=rule.sla_days or 30)),
            ))

async def check_subscriber_lag():
    """检查订阅方落后，超过阈值告警"""
    from datetime import datetime
    from sqlalchemy import select
    from app.models.mdm.distribution import SyncCheckpoint
    from app.core.database import AsyncSessionLocal
    from app.services.notify_service import NotifyService

    async with AsyncSessionLocal() as db:
        rows = (await db.execute(
            select(SyncCheckpoint).where(SyncCheckpoint.sync_status != "STOPPED")
        )).scalars().all()

        lagging = []
        for cp in rows:
            if cp.last_sync_at:
                lag = int((datetime.now() - cp.last_sync_at).total_seconds())
                cp.lag_seconds = lag
                if lag > 3600:
                    cp.sync_status = "LAGGING"
                    lagging.append(cp)
                else:
                    cp.sync_status = "NORMAL"

        await db.commit()

        if lagging:
            await NotifyService().send(
                template="DIST_LAG_ALERT",
                receivers=await get_it_managers(),
                params={
                    "count": len(lagging),
                    "details": [
                        {"subscriber": c.subscriber, "domain": c.domain_code,
                         "lag_seconds": c.lag_seconds}
                        for c in lagging[:10]
                    ],
                },
            )
        return {"checked": len(rows), "lagging": len(lagging)}


async def quality_daily_scan():
    """每日质量扫描 + 告警"""
    from app.schemas.mdm.distribution import QualityScanRequest

                params={
                    "count": len(alerts),
                    "details": [
                        {"rule": a["rule_name"], "rate": a["issue_rate"],
                         "threshold": a["threshold"]}
                        for a in alerts
                    ],
                },
            )

## 10. 分发契约与集成

### 10.1 订阅方式（两种）

#### 方式 A：事件订阅（推荐）

**步骤：**

1. 启动时调用 `GET /internal/v1/distribute/checkpoint?subscriber=M14&domain_code=MAT` 获取当前位点。
2. 若位点为空或落后，调用 `GET /internal/v1/distribute/snapshot` 拉全量快照。
3. 订阅 MQ 队列 `mdm.mat.m14`，消费事件。
4. 每条消费成功后调用 `POST /internal/v1/distribute/checkpoint/ack` 上报位点。
5. 每小时比对位点，若落后 >1 小时则重新拉快照。

#### 方式 B：轮询快照（降级）

当 MQ 不可用时，订阅方改为每 5 分钟轮询 `GET /internal/v1/distribute/snapshot?since_version=X` 获取增量。

### 10.2 事件消息格式

```json
{
  "event_id": "7f3a2b1c-9d4e-4f5a-8b6c-1d2e3f4a5b6c",
  "event_type": "mdm.drug.updated",
  "domain_code": "MAT",
  "object_type": "mdm_drug",
  "object_code": "DR1200021",
  "action": "UPDATE",
  "version": 128,
  "changed_fields": ["retail_price", "origin_type"],
  "payload": {
    "retail_price": 32.80,
    "origin_type": "DOMESTIC"
  },
  "operator_id": 1001,
  "occurred_at": "2026-04-01T10:23:45+08:00",
  "trace_id": "3f2a1b9c",
  "schema_version": "1.0"
}
```

**字段说明：**

| 字段 | 必需 | 说明 |
|---|---|---|
| `event_id` | 是 | 全局唯一，幂等键 |
| `event_type` | 是 | 事件类型 |
| `domain_code` | 是 | 主数据域 |
| `object_type` | 是 | 对象类型 |
| `object_code` | 是 | 对象编码 |
| `action` | 是 | CREATE/UPDATE/DELETE/DISABLE |
| `version` | 是 | 全局版本号（单调递增） |
| `changed_fields` | 否 | 变更字段列表 |
| `payload` | 是 | 变更后的数据（DELETE 时为 code） |
| `occurred_at` | 是 | 发生时间 |

### 10.3 MQ 队列命名

| 对象 | 命名 | 示例 |
|---|---|---|
| 交换机 | `mdm.{domain}` | `mdm.mat` |
| 路由键 | `mdm.{domain}.{subscriber}` | `mdm.mat.m14` |
| 队列 | `queue.mdm.{domain}.{subscriber}` | `queue.mdm.mat.m14` |
| 死信队列 | `dlq.mdm.{domain}.{subscriber}` | `dlq.mdm.mat.m14` |

### 10.4 幂等与顺序

| 特性 | 说明 |
|---|---|
| **幂等** | 订阅方按 `event_id` 去重 |
| **顺序** | 同一 `object_code` 的事件保证有序（MQ 单队列） |
| **重复** | 允许重复投递，订阅方须幂等 |
| **乱序** | 订阅方按 `version` 判断，小于本地版本则丢弃 |
