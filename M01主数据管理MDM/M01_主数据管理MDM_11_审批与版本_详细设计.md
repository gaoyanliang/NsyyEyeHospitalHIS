## 1. 模块概述

### 1.1 模块定位

审批与版本管理是 M01 的**治理中枢**。M01 其余全部子模块（科室、职工、药品、耗材、权限、收费、手术、视光、临床、字典）的每一次变更，都通过本子模块完成**申请 → 审批 → 生效 → 快照 → 分发**的完整闭环。

总体设计 1.4 节设计原则明确："**变更可追溯**——每一次写操作记录 `md_change_log`，保留期不少于 10 年"；"**价格不可覆盖**——历史单据永远关联当时的 price_id"。本子模块是这两条原则的落地实现。

本子模块定位于 **横切能力（Cross-cutting Concern）**，不直接拥有任何业务主数据，只拥有**变更单据、审批流、版本快照、变更日志**。

| 职责 | 归属 | 说明 |
|---|---|---|
| 变更单据（`md_change_request`） | **M01 审批子模块（本文档）** | 申请单主体 |
| 审批流节点（`md_change_request_detail`） | **M01 审批子模块（本文档）** | 节点/审批人/意见/签名 |
| 审批链规则（`md_approval_chain_rule`） | **M01 审批子模块（本文档）** | 按域+类型配置 |
| 审批链节点规则（`md_approval_chain_node`） | **M01 审批子模块（本文档）** | 节点顺序/审批人来源 |
| 版本快照（`md_version`） | **M01 审批子模块（本文档）** | 每次生效生成 |
| 变更日志（`md_change_log`） | **M01 审批子模块（本文档）** | 全量审计 |
| 影响分析 | **M01 审批子模块（本文档）** | 引用扫描 |
| 回滚 | **M01 审批子模块（本文档）** | 生成回滚变更单 |
| 各业务主数据本身 | 各子模块 | 本子模块只做管控 |
| 权限与身份校验 | M02 | 本子模块调用 |
| 电子签名存储 | M01 职工子模块 | 引用签名 ID |
| 消息通知 | M20 移动办公 / 消息中心 | — |

> **一句话边界**：本子模块回答"**这次改了什么、谁批的、什么时候生效、以前是什么样、能不能退回**"；各业务子模块只回答"**当前是什么**"。

### 1.2 模块目标

- **全量管控**：M01 全部主数据的写操作必须经变更单（可配置直改白名单）。
- **分级审批**：按主数据域、变更类型、价格敏感度自动匹配审批链。
- **风险前置**：审批前自动生成影响分析，让审批人看清后果。
- **完整快照**：每次生效生成不可变版本快照，支持任意时点回溯。
- **可回滚**：任选历史版本回滚，回滚同样走审批，永不丢历史。
- **强审计**：所有变更、审批动作、签名、IP、终端全留痕，保留 10 年。
- **多端一致**：PC 与移动端审批体验一致，移动端支持二次验证。

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 主数据专员 | 提交变更申请 | 创建变更单、上传附件、查看审批进度 |

| 物价员 | 价格发起 | 发起调价单 |

## 3. 审批与版本模型

### 3.1 变更类型模型

| 代码 | 名称 | 说明 | 是否需审批 |
|---|---|---|---|
| `CREATE` | 新增 | 新建主数据 | 是 |
| `UPDATE` | 修改 | 修改已有字段 | 是 |
| `DISABLE` | 停用 | `status=DISABLED` | 是 |
| `DELETE` | 删除 | 逻辑删除 | 是 |
| `IMPORT` | 批量导入 | 批量导入数据 | 是（可配） |
| `PRICE_ADJUST` | 价格调整 | 调价单 | 是（强制） |
| `ROLLBACK` | 回滚 | 恢复历史版本 | 是（强制） |

### 3.2 变更单状态机

```
                    ┌──────────┐
                    │  DRAFT   │ 草稿（可编辑）
                    └────┬─────┘
                         │ 提交
                         ▼
                    ┌──────────┐
              ┌─────│ PENDING  │ 待审批（等待第一个审批人）
              │     └────┬─────┘
              │          │ 审批人处理
              │          ▼
              │     ┌──────────┐
              │     │APPROVING │ 审批中
              │     └────┬─────┘
              │          │
     撤回     │    ┌─────┴──────┐
              │    │            │
              ▼    ▼            ▼
        ┌──────────┐    ┌──────────┐
        │WITHDRAWN │    │ REJECTED │ 已驳回
        │ 已撤回    │    └──────────┘
        └──────────┘
                         │ 全部通过
                         ▼
                    ┌──────────┐
                    │ APPORVED │ 已通过（待生效）
                    └────┬─────┘
                         │ 写业务表 + 快照 + 分发
                         ▼
                    ┌──────────┐
                    │ EFFECTIVE│ 已生效
                    └──────────┘

                    ┌──────────┐
                    │ FAILED   │ 生效失败（可重试）
                    └──────────┘
```

### 3.3 审批节点状态

| 状态 | 说明 |
|---|---|
| `WAITING` | 未开始（前序节点未完成） |
| `PENDING` | 待处理（已到达该节点） |
| `APPROVED` | 已同意 |
| `REJECTED` | 已驳回 |
| `TRANSFERRED` | 已转办 |
| `SKIPPED` | 已跳过（如加签撤回） |
| `TIMEOUT` | 超时（仍可处理） |

### 3.4 审批链规则模型

#### 3.4.1 规则匹配

```
变更单提交
   ↓
提取 (domain_code, change_type, 条件字段)
   ↓
按 priority 升序匹配 md_approval_chain_rule
   ↓
命中第一条满足条件的规则
   ↓
按 md_approval_chain_node 生成审批节点链
   ↓
解析每个节点的审批人（按 approver_source）
   ↓
写入 md_change_request_detail
```

#### 3.4.2 匹配条件（`match_condition`）

JSON 结构，支持字段级条件：

```json
{
  "object_type": ["mdm_drug", "mdm_material"],
  "price_changed": true,
  "amount_threshold": { "field": "retail_price", "operator": "GT", "value": 1000 },
  "dept_in": ["108", "115"]
}
```

#### 3.4.3 审批人来源（`approver_source`）

| 来源 | 说明 | 解析方式 |
|---|---|---|
| `FIXED_STAFF` | 指定人员 | `approver_value` = staff_id |
| `FIXED_ROLE` | 指定角色 | 取该角色全部用户，任一审批即通过 |
| `DEPT_LEADER` | 申请人科室负责人 | 查 `mdm_department.leader_emp_id` |
| `APPLICANT_SUPERIOR` | 申请人上级 | 查组织架构上级 |
| `FIELD_STAFF` | 单据字段指定人 | 如调价单的 `approver_id` |
| `SYSTEM` | 系统自动通过 | 用于免审场景 |

#### 3.4.4 审批模式（`approve_mode`）

| 模式 | 说明 |
|---|---|
| `ALL` | 会签（全部通过） |
| `ANY` | 或签（任一人通过） |
| `SEQUENTIAL` | 顺序审批 |

### 3.5 版本快照模型

#### 3.5.1 快照结构

```json
{
  "object_type": "mdm_drug",
  "object_id": 1200021,
  "object_code": "DR1200021",
  "version_no": 8,
  "change_type": "UPDATE",
  "change_request_id": 8801,
  "changed_fields": ["manufacturer_name", "origin_type", "retail_price"],
  "snapshot": {
    "id": 1200021,
    "code": "DR1200021",
    "name": "妥布霉素滴眼液",
    "origin_type": "DOMESTIC",
    "manufacturer_name": "参天制药(中国)",
    "retail_price": 32.80,
    "status": "ENABLED",
    "...": "完整字段"
  },
  "children": {
    "mdm_drug_price": [ { "...": "子表快照" } ]
  },
  "created_at": "2026-03-15T11:30:00+08:00",
  "operator_id": 1001
}
```

#### 3.5.2 版本号规则

| 规则 | 说明 |
|---|---|
| 起始 | 首次创建为 `version_no=1` |
| 递增 | 每次生效 `version_no = max + 1` |
| 不可变 | 快照一经写入不可修改、不可删除 |
| 唯一 | `(object_type, object_id, version_no)` 唯一 |

#### 3.5.3 回滚模型

```
选择历史版本 v3
   ↓
生成回滚变更单（change_type=ROLLBACK）
   · before = 当前版本快照
   · after = v3 快照（去除 id/version_no 等）
   ↓
走审批（强制审批，不可跳过）
   ↓
审批通过 → 写业务表为新版本 v9（内容=v3）
   ↓
v4~v8 保留，形成新版本 v9
```

> **关键原则**：回滚**不是删除**，而是**以历史内容创建新版本**，历史链条永不中断。

### 3.6 影响分析模型

#### 3.6.1 分析维度

| 维度 | 说明 | 数据来源 |
|---|---|---|
| 引用关系 | 被哪些表引用 | `md_dict_ref` + 业务表扫描 |
| 库存影响 | 物资当前库存 | M15 |
| 价表影响 | 涉及哪些价表 | M01 收费 |
| 模板影响 | 被哪些模板引用 | M18 / M07 |
| 在途业务 | 未结算单据 | M16 |
| 授权影响 | 权限变更影响用户数 | M01 权限 |
| 价格影响 | 调价金额变动 | M01 收费 |

#### 3.6.2 分析结果结构

```json
{
  "references": [
    { "table": "md_prescription_template", "count": 3, "module": "M07" }
  ],
  "stock": { "total_qty": 1240, "warehouse_count": 4 },
  "price_lists": [
    { "price_list_code": "PL001", "old_price": 35.60, "new_price": 32.80, "change_rate": -7.87 }
  ],
  "templates": [ { "type": "ORDER", "count": 3 } ],
  "pending_bills": { "count": 0, "amount": 0 },
  "risk_level": "MEDIUM",
  "suggestions": ["价格下调将影响 2 个价表，建议同步通知财务"]
}
```

**风险等级：**

| 等级 | 判定 | 显示 |
|---|---|---|
| `LOW` | 无引用或无在途业务 | 绿 |
| `MEDIUM` | 有引用但无在途单据 | 黄 |
| `HIGH` | 有库存/在途单据/多价表影响 | 橙 |
| `CRITICAL` | 影响大量在途单据或权限 | 红 |

```python
# app/services/mdm/chain_rule_service.py
"""审批链规则解析服务（核心）"""
from typing import Optional, List
from datetime import datetime, timedelta

from sqlalchemy import select, or_, and_
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.mdm.approval import (
    ApprovalChainRule, ApprovalChainNode, ChangeRequestDetail,
)
from app.models.mdm.org import Department, Staff
from app.models.mdm.permission import Role, RoleUser
from app.core.exceptions import BizException


class ChainRuleService:
    """审批链解析"""

    def __init__(self, db: AsyncSession):
        self.db = db

    async def resolve(self, domain_code: str, change_type: str,
                       object_type: Optional[str] = None,
                       applicant_id: Optional[int] = None,
                       data: Optional[dict] = None) -> dict:
        """解析出审批节点链"""
        # 1. 查询同域全部启用规则，按优先级排序
        stmt = (
            select(ApprovalChainRule)
            .where(
                ApprovalChainRule.domain_code == domain_code,
                ApprovalChainRule.status == "ENABLED",
                ApprovalChainRule.is_deleted == False,
            )
            .order_by(ApprovalChainRule.priority.asc())
        )
        rules = (await self.db.execute(stmt)).scalars().all()

        ctx = {
            "change_type": change_type,
            "object_type": object_type,
            "applicant_id": applicant_id,
            "data": data or {},
        }

        # 2. 按优先级匹配
        matched = None
        default_rule = None
        for rule in rules:
            if rule.is_default:
                default_rule = rule
                continue
            if rule.match(ctx):
                matched = rule
                break

        # 3. 兜底规则
        if not matched:
            matched = default_rule
        if not matched:
            raise BizException(
                "0111014", "未匹配到审批链规则",
                data={"domain_code": domain_code, "change_type": change_type})

        # 4. 解析各节点审批人
        nodes_out = []
        for node in matched.nodes:
            approvers = await self._resolve_approvers(
                node.approver_source, node.approver_value,
                applicant_id, data, matched.allow_self_approve)
            nodes_out.append({
                "node_seq": node.node_seq,
                "node_name": node.node_name,
                "node_type": node.node_type,
                "approver_source": node.approver_source,
                "approve_mode": node.approve_mode,
                "sla_hours": node.sla_hours or matched.node_sla_hours,
                "resolved_approvers": approvers,
            })

        # 5. 校验至少一个审批节点有审批人
        approve_nodes = [n for n in nodes_out
                         if n["node_type"] == "APPROVE" and n["resolved_approvers"]]
        if not approve_nodes:
            raise BizException("0111020", "当前无可用的审批链（审批人为空）")

        return {
            "matched": True,
            "rule_code": matched.rule_code,
            "rule_name": matched.rule_name,
            "sla_hours": matched.sla_hours,
            "allow_batch_approve": matched.allow_batch_approve,
            "require_signature": matched.require_signature,
            "nodes": nodes_out,
            "total_nodes": len(nodes_out),
            "estimated_days": round(matched.sla_hours / 24, 1),
        }

    async def _resolve_approvers(self, source: str, value: Optional[str],
                                  applicant_id: Optional[int],
                                  data: Optional[dict],
                                  allow_self: bool) -> List[dict]:
        """按来源解析审批人"""
        if source == "SYSTEM":
            return [{"staff_id": 0, "staff_name": "系统"}]

        if source == "FIXED_STAFF":
            staff = await self._get_staff(int(value))
            if not staff:
                return []
            if not allow_self and applicant_id and staff.id == applicant_id:
                return []
            return [{"staff_id": staff.id, "staff_name": staff.name}]

        if source == "FIXED_ROLE":
            members = await self._get_role_members(value)
            return [
                {"staff_id": s.id, "staff_name": s.name}
                for s in members
                if allow_self or s.id != applicant_id
            ]

        if source == "DEPT_LEADER":
            if not applicant_id:
                return []
            staff = await self._get_staff(applicant_id)
            if not staff or not staff.main_dept_id:
                return []
            dept = (await self.db.execute(
                select(Department).where(Department.id == staff.main_dept_id)
            )).scalar_one_or_none()
            if not dept or not dept.leader_emp_id:
                return []
            leader = await self._get_staff(dept.leader_emp_id)
            if not leader:
                return []
            if not allow_self and applicant_id and leader.id == applicant_id:
                return []
            return [{"staff_id": leader.id, "staff_name": leader.name}]

        if source == "APPLICANT_SUPERIOR":
            if not applicant_id:
                return []
            superior_id = await self._get_superior(applicant_id)
            if not superior_id:
                return []
            sup = await self._get_staff(superior_id)
            return [{"staff_id": sup.id, "staff_name": sup.name}] if sup else []

        if source == "FIELD_STAFF":
            if not data or value not in data:
                return []
            sid = data.get(value)
            if not sid:
                return []
            staff = await self._get_staff(int(sid))
            return [{"staff_id": staff.id, "staff_name": staff.name}] if staff else []

        return []

    async def _get_staff(self, staff_id: int) -> Optional[Staff]:
        return (await self.db.execute(
            select(Staff).where(Staff.id == staff_id, Staff.is_deleted == False)
        )).scalar_one_or_none()

    async def _get_role_members(self, role_code: str) -> List[Staff]:
        stmt = (
            select(Staff)
            .join(RoleUser, RoleUser.staff_id == Staff.id)
            .join(Role, Role.id == RoleUser.role_id)
            .where(Role.code == role_code, Staff.is_deleted == False)
        )
        return (await self.db.execute(stmt)).scalars().all()

    async def _get_superior(self, staff_id: int) -> Optional[int]:
        """查组织架构上级（简化：用部门的上级部门负责人）"""
        staff = await self._get_staff(staff_id)
        if not staff or not staff.main_dept_id:
            return None
        dept = (await self.db.execute(
            select(Department).where(Department.id == staff.main_dept_id)
        )).scalar_one_or_none()
        if not dept or not dept.parent_id:
            return None
        parent = (await self.db.execute(
            select(Department).where(Department.id == dept.parent_id)
        )).scalar_one_or_none()
        return parent.leader_emp_id if parent else None
```

```python
# app/services/mdm/version_service.py
"""版本快照与回滚服务"""
from datetime import datetime
from typing import Optional, List

from sqlalchemy import select, func, desc
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.mdm.approval import MdVersion, ChangeRequest
from app.schemas.mdm.approval import RollbackRequest
from app.core.exceptions import BizException


class VersionService:
    def __init__(self, db: AsyncSession):
        self.db = db

    async def create_version(self, object_type: str, object_id: int,
                              object_code: str, object_name: Optional[str],
                              domain_code: str, snapshot: dict,
                              change_type: str,
                              change_request_id: Optional[int] = None,
                              change_request_code: Optional[str] = None,
                              changed_fields: Optional[str] = None,
                              is_rollback: bool = False,
                              rollback_from: Optional[int] = None,
                              operator_id: Optional[int] = None,
                              operator_name: Optional[str] = None,
                              children: Optional[dict] = None) -> MdVersion:
        """创建新版本快照"""
        # 取当前最大版本号
        max_ver = (await self.db.execute(
            select(func.max(MdVersion.version_no)).where(
                MdVersion.object_type == object_type,
                MdVersion.object_id == object_id)
        )).scalar() or 0

        ver = MdVersion(
            object_type=object_type,
            object_id=object_id,
            object_code=object_code,
            object_name=object_name,
            domain_code=domain_code,
            version_no=max_ver + 1,
            snapshot_json=snapshot,
            children_json=children,
            change_type=change_type,
            change_request_id=change_request_id,
            change_request_code=change_request_code,
            changed_fields=changed_fields,
            is_rollback=is_rollback,
            rollback_from_version=rollback_from,
            operator_id=operator_id,
            operator_name=operator_name,
        )
        self.db.add(ver)
        await self.db.flush()
        return ver

    async def list_versions(self, object_type: str, object_id: int) -> dict:
        """版本时间轴"""
        rows = (await self.db.execute(
            select(MdVersion)
            .where(MdVersion.object_type == object_type,
                   MdVersion.object_id == object_id)
            .order_by(desc(MdVersion.version_no))
        )).scalars().all()

        if not rows:
            raise BizException("0111021", "该对象暂无版本记录")

        return {
            "object_type": object_type,
            "object_id": object_id,
            "object_code": rows[0].object_code,
            "object_name": rows[0].object_name,
            "total_versions": len(rows),
            "items": [
                {
                    "id": v.id,
                    "version_no": v.version_no,
                    "change_type": v.change_type,
                    "change_request_code": v.change_request_code,
                    "changed_fields": v.changed_fields,
                    "is_rollback": v.is_rollback,
                    "rollback_from_version": v.rollback_from_version,
                    "operator_name": v.operator_name,
                    "created_at": v.created_at.isoformat() if v.created_at else None,
                }
                for v in rows
            ],
        }

    async def get_snapshot(self, object_type: str, object_id: int,
                            version_no: int) -> dict:
        v = (await self.db.execute(
            select(MdVersion).where(
                MdVersion.object_type == object_type,
                MdVersion.object_id == object_id,
                MdVersion.version_no == version_no)
        )).scalar_one_or_none()
        if not v:
            raise BizException("0111022", f"版本 v{version_no} 不存在")
        return {
            "version_no": v.version_no,
            "object_type": v.object_type,
            "object_code": v.object_code,
            "snapshot": v.snapshot_json,
            "children": v.children_json,
            "created_at": v.created_at.isoformat() if v.created_at else None,
        }

    async def compare(self, object_type: str, object_id: int,
                       from_version: int, to_version: int) -> dict:
        """版本对比"""
        va = (await self.db.execute(
            select(MdVersion).where(
                MdVersion.object_type == object_type,
                MdVersion.object_id == object_id,
                MdVersion.version_no == from_version)
        )).scalar_one_or_none()
        vb = (await self.db.execute(
            select(MdVersion).where(
                MdVersion.object_type == object_type,
                MdVersion.object_id == object_id,
                MdVersion.version_no == to_version)
        )).scalar_one_or_none()

        if not va or not vb:
            raise BizException("0111022", "版本不存在")

        diffs = self._diff_dict(va.snapshot_json or {}, vb.snapshot_json or {})
        return {
            "object_type": object_type,
            "object_code": vb.object_code,
            "object_name": vb.object_name,
            "from_version": from_version,
            "to_version": to_version,
            "changed_count": sum(1 for d in diffs if d["change_kind"] != "UNCHANGED"),
            "diffs": diffs,
        }

    @staticmethod
    def _diff_dict(a: dict, b: dict) -> List[dict]:
        """字段级 diff"""
        IGNORE = {"id", "created_at", "updated_at", "created_by", "updated_by", "version"}
        keys = (set(a.keys()) | set(b.keys())) - IGNORE
        out = []
        for k in sorted(keys):
            va, vb = a.get(k), b.get(k)
            if va == vb:
                kind = "UNCHANGED"
            elif k not in a:
                kind = "ADDED"
            elif k not in b:
                kind = "REMOVED"
            else:
                kind = "MODIFIED"
            out.append({"field": k, "before": va, "after": vb, "change_kind": kind})
        return out

    async def rollback(self, payload: RollbackRequest, operator) -> dict:
        """回滚：生成回滚变更单"""
        # 1. 查目标版本
        target = (await self.db.execute(
            select(MdVersion).where(
                MdVersion.object_type == payload.object_type,
                MdVersion.object_id == payload.object_id,
                MdVersion.version_no == payload.target_version)
        )).scalar_one_or_none()
        if not target:
            raise BizException("0111022", f"目标版本 v{payload.target_version} 不存在")

        # 2. 查当前版本
        current = (await self.db.execute(
            select(MdVersion)
            .where(MdVersion.object_type == payload.object_type,
                   MdVersion.object_id == payload.object_id)
            .order_by(desc(MdVersion.version_no))
            .limit(1)
        )).scalar_one_or_none()

        if current and current.version_no == payload.target_version:
            raise BizException("0111023", "回滚目标版本不能是当前版本")

        # 3. 计算差异
        diffs = self._diff_dict(
            current.snapshot_json or {} if current else {},
            target.snapshot_json or {})

        # 4. 生成回滚变更单
        from app.services.mdm.change_request_service import ChangeRequestService
        svc = ChangeRequestService(self.db)
        result = await svc.submit_for_approval_raw(
            change_type="ROLLBACK",
            domain_code=target.domain_code,
            object_type=payload.object_type,
            object_id=payload.object_id,
            object_code=target.object_code,
            object_name=target.object_name,
            before_json=current.snapshot_json if current else None,
            after_json=target.snapshot_json,
            reason=payload.reason,
            urgency=payload.urgency,
            applicant_id=operator.id,
            rollback_from_version=payload.target_version,
        )

        warnings = []
        if current and "retail_price" in (current.snapshot_json or {}):
            warnings.append("该对象含价格字段，回滚将影响后续计费")

        return {
            **result,
            "target_version": payload.target_version,
            "current_version": current.version_no if current else None,
            "diff_count": sum(1 for d in diffs if d["change_kind"] != "UNCHANGED"),
            "warnings": warnings,
            "message": "回滚申请已提交，需审批通过后生效",
        }
```

```python
async def scan_timeout_nodes():
    """扫描超时节点，标记 timeout_flag 并通知"""
    from datetime import datetime
    from sqlalchemy import select
    from app.models.mdm.approval import ChangeRequest, ChangeRequestDetail
    from app.core.database import AsyncSessionLocal

    async with AsyncSessionLocal() as db:
        now = datetime.now()

        # 超时的变更单
        overdue = (await db.execute(
            select(ChangeRequest).where(
                ChangeRequest.req_status.in_(["PENDING", "APPROVING"]),
                ChangeRequest.deadline_at.isnot(None),
                ChangeRequest.deadline_at < now,
                ChangeRequest.timeout_flag == False,
                ChangeRequest.is_deleted == False,
            )
        )).scalars().all()

        for req in overdue:
            req.timeout_flag = True
            # 通知当前审批人与申请人
            from app.services.mdm.notify_service import ApprovalNotifyService
            svc = ApprovalNotifyService()
            if req.current_approver_id:
                await svc.send_async(req.id, "TIMEOUT", req.current_approver_id, "INBOX")
            await svc.send_async(req.id, "TIMEOUT", req.applicant_id, "INBOX")

        # 超时的节点
        overdue_nodes = (await db.execute(
            select(ChangeRequestDetail).where(
                ChangeRequestDetail.node_status == "PENDING",
                ChangeRequestDetail.deadline_at.isnot(None),
                ChangeRequestDetail.deadline_at < now,
            )
        )).scalars().all()

        for node in overdue_nodes:
            node.node_status = "TIMEOUT"

        await db.commit()
        return {"overdue_requests": len(overdue), "overdue_nodes": len(overdue_nodes)}


async def escalate_overdue():
    """超时超过 24 小时，升级通知上级"""
    from datetime import datetime, timedelta
    from sqlalchemy import select
    from app.models.mdm.approval import ChangeRequest
    from app.core.database import AsyncSessionLocal
    from app.services.mdm.notify_service import ApprovalNotifyService

    async with AsyncSessionLocal() as db:
        threshold = datetime.now() - timedelta(hours=24)
        rows = (await db.execute(
            select(ChangeRequest).where(
                ChangeRequest.req_status.in_(["PENDING", "APPROVING"]),
                ChangeRequest.deadline_at.isnot(None),
                ChangeRequest.deadline_at < threshold,
                ChangeRequest.is_deleted == False,
            )
        )).scalars().all()

        svc = ApprovalNotifyService()
        for req in rows:
            # 通知审批人及其上级
            if req.current_approver_id:
                await svc.send_async(req.id, "URGE", req.current_approver_id, "SMS")
                superior = await get_staff_superior(req.current_approver_id)
                if superior:
                    await svc.send_async(req.id, "URGE", superior, "SMS")

        return {"escalated": len(rows)}


async def retry_failed_apply():
    """重试生效失败的变更单"""
    from sqlalchemy import select
    from app.models.mdm.approval import ChangeRequest
    from app.core.database import AsyncSessionLocal
    from app.services.mdm.change_apply_service import ChangeApplyService

    async with AsyncSessionLocal() as db:
        rows = (await db.execute(
            select(ChangeRequest).where(
                ChangeRequest.req_status == "FAILED",
                ChangeRequest.retry_count < 3,
                ChangeRequest.is_deleted == False,
            )
        )).scalars().all()

        svc = ChangeApplyService(db)
        ok, fail = 0, 0
        for req in rows:

                await svc.apply(req.id)
                ok += 1
            except Exception:
                req.retry_count += 1
                fail += 1
        await db.commit()
        return {"retried": len(rows), "success": ok, "failed": fail}
```

## 8. 业务规则与校验

### 8.1 变更单规则

| 规则 | 说明 |
|---|---|
| 单号格式 | `CR` + yyyyMMdd + 流水(5) |
| 变更类型必填 | 7 种之一 |
| 更新必带 before | `UPDATE` 必须提供 `before_json` |
| 新增不带 before | `CREATE` 不应有 `before_json` |
| 必须带 after | `CREATE`/`UPDATE` 必须有 `after_json` |
| 事由长度 | ≥5 字，≤500 字 |
| 紧急必填理由 | `URGENT`/`CRITICAL` 必须有 `urgency_reason` |
| 草稿可编辑 | 仅 `DRAFT` 状态可改 |
| 撤回条件 | `PENDING`/`APPROVING` 可撤回 |
| 撤回权限 | 仅申请人本人 |
| 乐观锁 | 审批时校验 `version_no`（47011） |

### 8.2 审批规则

| 规则 | 说明 |
|---|---|
| 仅当前审批人可审批 | `current_approver_id == operator.id`（47005） |
| 禁止自审 | 申请人不能审批自己的单据（47006，可配） |
| 驳回必填意见 | 47007 |
| 转办必填人与理由 | 47008 |
| 加签必填人 | 47009 |
| 节点已完成不可重复审批 | 47010 |
| 批量审批限制 | 价格类（47012）与高风险（47013）不可批量 |
| 电子签名 | 规则 `require_signature=true` 时必须签名（47027） |
| 二次验证 | 移动端必须二次验证（47028） |
| 最后节点通过 | 自动触发生效 |
| 任一节点驳回 | 整单 `REJECTED` |

### 8.3 审批链规则

| 规则 | 说明 |
|---|---|
| 规则编码格式 | `ACR` + 大写字母数字下划线 |
| 节点序号连续 | 从 1 开始，不可断档（47016） |
| 至少一个审批节点 | 47017 |
| 优先级同域唯一 | 47018 |
| 必须有兜底规则 | 每域至少一条 `is_default=true`（47019） |
| 审批人非空 | 解析后至少一个审批节点有人（47020） |
| 匹配顺序 | 按 `priority` 升序，首个命中即用 |

### 8.4 版本规则

| 规则 | 说明 |
|---|---|
| 版本号递增 | `max(version_no) + 1` |
| 版本唯一 | `(object_type, object_id, version_no)` 唯一 |
| 快照不可变 | 写入后不可修改 |
| 保留期 | 10 年 |
| 回滚不改历史 | 回滚生成新版本，不删除中间版本 |
| 回滚目标校验 | 不能是当前版本（47023） |
| 回滚必填原因 | ≥5 字（47024） |

### 8.5 影响分析规则

| 规则 | 说明 |
|---|---|
| 异步执行 | 提交时触发，审批前必须完成 |
| 超时降级 | 分析超 5s 降级为"分析中"，不阻断审批 |
| 风险判定 | 见 3.6.2 |
| 缓存 | 1 小时，重新分析时失效 |

### 8.6 并发控制

| 机制 | 说明 |
|---|---|
| 乐观锁 | 变更单 `version_no` |
| 审批互斥锁 | `mdm:lock:approval:request:{id}`，30s |
| 影响分析锁 | `mdm:lock:approval:impact:{id}`，60s |
| 生效幂等 | 生效前检查 `req_status='APPROVED'` |

### 10.3 与业务子模块的契约

| 接口 | 用途 | SLA |
|---|---|---|
| `POST /internal/v1/approval/submit` | **提交审批（核心）** | P95 ≤ 150ms |
| `GET /internal/v1/approval/requests/{code}/status` | 查询审批状态 | P95 ≤ 50ms |
| `GET /internal/v1/approval/chain/resolve` | 预览审批链 | P95 ≤ 80ms |
| `POST /internal/v1/approval/impact/analyze` | 触发影响分析 | P95 ≤ 500ms |
| `POST /internal/v1/approval/rollback` | 发起回滚 | P95 ≤ 150ms |
| `GET /internal/v1/approval/versions/{type}/{code}` | 查询版本 | P95 ≤ 80ms |

**关键约定：**

1. **业务子模块的所有写操作必须调用 `approval/submit`**，不得直接写表（除白名单）。
2. **业务子模块必须实现"生效回调"**：收到 `mdm.approval.effective` 事件后，或调用 `requests/{code}/apply` 时，执行实际写表。
3. **业务子模块创建主数据后必须触发版本快照**（通过 `versions/create` 或生效时自动生成）。
4. **业务子模块不得修改 `md_version` 与 `md_change_log`**，只读。
5. **审批通过后的生效由本子模块的 `ChangeApplyService` 统一协调**，调用业务服务的 `apply` 方法。

### 11.1 异常分类

| 系统异常 | DB 失败 | 50000 |

**降级策略：**

| 依赖 | 不可用时 |
|---|---|
| Redis | 直连 DB（性能下降） |
| MQ | 事件落库 PENDING，恢复后补投 |
| 影响分析服务 | 审批继续，影响分析显示"暂不可用" |
| 通知服务 | 记录 PENDING，定时重试 |
