### 4.2 表：`md_diagnosis_chapter`（诊断章节表）

| 字段名 | 类型 | 允许空 | 默认 | 说明 |
|---|---|---|---|---|
| id | BIGINT | N | IDENTITY | 主键 |
| chapter_code | VARCHAR(16) | N | - | 章节编码（如 `H00-H59`） |
| chapter_name | VARCHAR(128) | N | - | 章节名称（如"眼和附器疾病"） |
| parent_id | BIGINT | Y | NULL | 父章节 ID |
| chapter_level | SMALLINT | N | 1 | 层级 |
| chapter_path | VARCHAR(255) | N | - | 路径（如 `/1/12/`） |
| sort_no | INT | N | 999 | 排序 |
| status | VARCHAR(16) | N | 'ENABLED' | 状态 |
| deleted | BOOLEAN | N | FALSE | 逻辑删除 |
| created_at | TIMESTAMP | N | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | N | CURRENT_TIMESTAMP（触发器维护） | 更新时间 |

**索引：** `uk_diag_chapter_code(chapter_code, deleted)` 唯一；`idx_diag_chapter_parent(parent_id)`。

        UniqueConstraint("device_code", "deleted", name="uk_device_code"),
        UniqueConstraint("serial_no", "deleted", name="uk_device_serial"),
        UniqueConstraint("dicom_ae_title", name="uk_device_ae"),

        Index("idx_device_calibration", "next_calibration_date"),
        Index("idx_device_updated", "updated_at"),
        {"comment": "设备台账"},
    )

    @property
    def is_available(self) -> bool:
        """是否可排程"""
        return (
            self.status == "ENABLED"
            and self.run_status == "NORMAL"
            and self.is_schedulable
            and not self.deleted
        )

    def calibration_status(self) -> str:
        """检定状态"""
        if not self.next_calibration_date:
            return "UNKNOWN"
        from datetime import date
        delta = (self.next_calibration_date - date.today()).days
        if delta < 0:
            return "EXPIRED"
        if delta <= 30:
            return "EXPIRING"
        return "VALID"

        ranges = self.reference_ranges
        for i in range(len(ranges)):
            for j in range(i + 1, len(ranges)):
                a, b = ranges[i], ranges[j]
                if a.gender != "ALL" and b.gender != "ALL" and a.gender != b.gender:
                    continue
                a_from = a.age_from if a.age_from is not None else 0
                a_to = a.age_to if a.age_to is not None else 150
                b_from = b.age_from if b.age_from is not None else 0
                b_to = b.age_to if b.age_to is not None else 150
                if a_from <= b_to and b_from <= a_to:
                    raise ValueError(
                        f"参考区间重叠：序号 {i+1} 与 {j+1}（性别 {a.gender}/{b.gender}）")
        return self
