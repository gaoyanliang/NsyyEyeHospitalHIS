## 1. 模块概述

### 1.1 模块定位

收费管理是 M01 主数据管理 MDM 的核心子模块之一，是全院 HIS 系统**收费项目、价格体系、计价规则**的统一数据源头。

总体设计第 3 章 M01 行明确"收费"为主数据域之一（`FEE` 费用域）；第 6 章依赖矩阵显示 M04、M05、M06、M07、M09、M10、M11、M12、M13、M16、M17 共 11 个模块依赖"费用"主数据。因此收费主数据是整个收费体系的地基。

本子模块定位于：**价格的"定义、版本化与治理"**，而非收费的"业务执行"。

| 职责 | 归属 | 说明 |
|---|---|---|
| 收费项目定义（`md_charge_item`） | **M01 收费子模块（本文档）** | 项目名称、类别、计价方式、标准价、可打折/可退费规则 |
| 价表与分级定价（`md_price_list`、`md_price_item`） | **M01 收费子模块（本文档）** | 标准价表、会员价表、视光零售价表等 |
| 价格版本与历史（`md_price_history`） | **M01 收费子模块（本文档）** | 按生效日期版本化，保证历史单据金额不变 |
| 价格调整单（`md_price_adjust`） | **M01 收费子模块（本文档）** | 调价申请、审批、定时生效 |
| 优惠方案定义（`md_discount_policy`） | **M01 收费子模块（本文档）** | 折扣/满减/套餐/买赠规则 |
| 支付方式定义（`md_payment_method`） | **M01 收费子模块（本文档）** | 现金/微信/支付宝/会员储值/商保 |
| 退费规则定义（`md_refund_policy`） | **M01 收费子模块（本文档）** | 退费条件、审批阈值、退费方式 |
| 发票配置（`md_invoice_config`） | **M01 收费子模块（本文档）** | 票种、抬头、税率、号码段 |
| 收费组合/套餐（`md_charge_combo`） | **M01 收费子模块（本文档）** | 眼科检查套餐、手术套餐 |
| 收费**单据、结算、收款、退费执行** | **M16 收费结算管理** | 账单、支付流水、退费单 |
| 门诊挂号收费 | **M04 门诊管理** | 挂号费收取 |
| 住院预交金与出院结算 | **M05 住院管理** | — |
| 收入核算、成本核算、凭证 | **M17 财务核算管理** | — |
| 发票开具（税控对接） | **M16 + M21 集成平台** | 税控盘/电子发票平台对接 |
| 会员等级折扣 | **M03 患者服务与会员** | M01 定义折扣规则，M03 提供会员等级 |

> **一句话边界**：M01 回答"**有哪些收费项目、各价表多少钱、何时生效、能打几折、怎么退、怎么付、怎么开票**"；M16 回答"**某个患者这次要收多少钱、怎么收、收了之后退不退**"。

### 1.2 模块目标

- **统一源头**：全院收费项目与价格统一由 MDM 定义，禁止业务模块自建价格。
- **价格版本化**：任何调价不覆盖历史，按"业务发生时间"取当时价格，保证历史单据重打金额不变。
- **分级定价**：支持标准价、会员价、商保价、视光零售价、科室差异价，通过价表体系实现。
- **计价规则化**：支持按次、按天、按小时、按数量、按眼别、按面积、按部位等多种计价方式。
- **折扣可控**：折扣率下限、审批阈值、叠加规则、会员等级折扣全部可配置。
- **退费合规**：退费条件、时间窗口、金额比例、审批链可配置，防止恶意退费。
- **无医保适配**：默认自费，商保与医保字段预留，价表按 `price_type` 区分。
- **眼科专科适配**：按眼别计价（左/右眼分开收费）、手术套餐、检查套餐、视光产品与其他项目的组合收费。
- **可追溯**：所有价格变更记录前后值、操作人、审批单号，保留 10 年。
- **即时生效**：价格变更后主动失效缓存并广播，M16 下次取价即生效。

### 2.3 收费项目与药品/耗材/视光产品的关系

这是本子模块最关键的边界问题。**收费项目是"计费单位"，药品/耗材/视光产品是"物资实体"**，两者是 **1:N 或 N:1** 的映射关系：

```
┌──────────────────────────────────────────────────────────────────┐
│                        收费项目（md_charge_item）                 │
│  这是"收什么钱"的定义，是账单行的基础                             │
│  例：C0300127 光学相干断层扫描(OCT)  280.00 元/次                 │
│       C0300128 眼底照相              60.00 元/次                 │
│       C0600141 玻璃体腔注射术       800.00 元/眼                 │
│       C1200033 人工晶体(材料费)     3800.00 元/枚                │
└───────────────┬──────────────────────────────────────────────────┘
                │ 映射（md_charge_item_rel）
    ┌───────────┼─────────────┬──────────────┐
    ▼           ▼             ▼              ▼
┌────────┐ ┌─────────┐  ┌──────────┐  ┌────────────┐
│ 检查项目│ │ 手术项目│  │  药品    │  │ 耗材/视光  │
│M01-临床│ │M01-临床 │  │M01-药品  │  │M01-耗材    │
└────────┘ └─────────┘  └──────────┘  └────────────┘
   1:1         1:1          1:N            1:N
  (一个检查对应一个收费项)  (一个药品可有多个收费项：西药费/精麻费)
```

**归属原则：**

| 数据 | 权威源 | 说明 |
|---|---|---|
| 收费项目本体（名称、编码、计价方式） | **M01 收费子模块** | 账单行的定义 |
| 收费项目的**价格** | **M01 收费子模块**（通过价表） | 药品/耗材的零售价由其子模块维护，收费项目价引用之 |
| 检查项目、手术项目的**业务属性** | M01 临床子模块 | 收费项目只引用其 `charge_item_id` |
| 药品、耗材、视光产品的**目录与零售价** | M01 各子模块 | 收费项目通过关联获取价格 |
| 一次结算的**金额计算** | M16 | 依据 M01 价格 + 数量 + 折扣 |

**联动规则：**
- 检查/手术/药品/耗材新增时，**必须**关联一个收费项目（由各子模块的表 `charge_item_id` 字段承载）。
- 收费项目的标准价可由"关联对象"的价格自动同步（可配置为手工维护）。
- 价格调整单支持"联动调整"：调药品价时可选是否同步调整对应收费项目价。

## 3. 收费与价格模型

### 3.1 收费项目分类体系

收费项目采用**主分类 + 会计分类 + 医保分类**三维体系。

#### 3.1.1 主分类（charge_class）

主分类决定**编码前缀、默认计价方式、默认会计科目**。

| 代码 | 名称 | 编码段 | 默认计价 | 默认会计科目 | 典型示例 |
|---|---|---|---|---|---|
| `REG` | 挂号费 | 01 | 按次 | 医疗收入-门诊挂号 | 普通门诊挂号费、专家门诊挂号费 |
| `DIAG` | 诊查费 | 02 | 按次 | 医疗收入-诊查 | 门诊诊查费、住院诊查费 |
| `EXAM` | 检查费 | 03 | 按次/按眼别 | 医疗收入-检查 | OCT、眼底照相、视野、B超 |
| `LAB` | 检验费 | 04 | 按次 | 医疗收入-检验 | 血常规、生化、免疫 |
| `TREAT` | 治疗费 | 05 | 按次/按天 | 医疗收入-治疗 | 换成药、冲洗、激光治疗 |
| `OPER` | 手术费 | 06 | 按次/按眼别 | 医疗收入-手术 | 白内障超声乳化、玻璃体切割 |
| `ANES` | 麻醉费 | 07 | 按次 | 医疗收入-麻醉 | 表面麻醉、球后阻滞、全身麻醉 |
| `NURSE` | 护理费 | 08 | 按天/按次 | 医疗收入-护理 | 一级护理、二级护理 |
| `BED` | 床位费 | 09 | 按天 | 医疗收入-床位 | 普通床位、日间观察床 |
| `DRUG_W` | 西药费 | 10 | 按数量 | 药品收入-西药 | — |
| `DRUG_C` | 中成药费 | 11 | 按数量 | 药品收入-中成药 | — |
| `DRUG_H` | 中草药费 | 12 | 按数量 | 药品收入-中草药 | — |
| `MATERIAL` | 材料费 | 13 | 按数量 | 医疗收入-材料 | 人工晶体、粘弹剂、缝线 |
| `OPTICAL` | 视光产品费 | 14 | 按数量 | 商品销售-视光 | 镜架、镜片、隐形眼镜、OK镜 |
| `PROCESS` | 加工费 | 15 | 按次 | 商品销售-加工 | 磨边、装框、镀膜 |
| `OPT_REF` | 验光费 | 16 | 按次 | 医疗收入-检查 | 普通验光、综合验光、散瞳验光 |
| `REFUND_OTHER` | 其他费用 | 99 | 按次 | 其他收入 | 复印费、补卡费 |

**编码规则：** `C` + 分类段(2位) + 流水(5位)，如 `C0300127`（检查费第 127 项）。

#### 3.1.2 计价方式（pricing_mode）

| 代码 | 名称 | 计价公式 | 眼科典型场景 |
|---|---|---|---|
| `FIXED` | 按次 | 金额 = 单价 × 1 | 大多数检查、治疗 |
| `BY_EYE` | 按眼别 | 金额 = 单价 × 眼别数（1或2） | OCT、眼底照相、玻璃体腔注射 |
| `BY_QTY` | 按数量 | 金额 = 单价 × 数量 | 药品、耗材、视光产品 |
| `BY_DAY` | 按天 | 金额 = 单价 × 天数 | 床位费、护理费 |
| `BY_HOUR` | 按小时 | 金额 = 单价 × 小时数 | 麻醉监护、特护 |
| `BY_AREA` | 按面积 | 金额 = 单价 × 面积(cm²) | 激光治疗（按治疗区面积） |
| `BY_PART` | 按部位 | 金额 = 单价 × 部位数 | 双眼分开的检查 |
| `TIERED` | 阶梯价 | 按数量区间取不同单价 | 大批量检查 |
| `COMBO` | 组合价 | 按组合预设价，明细不出账 | 检查套餐、手术套餐 |
| `FREE` | 免费 | 金额 = 0 | 义诊、随访复查 |

### 3.2 价表体系

价表是"一组收费项目及其价格"的集合。医院可按对象、场景、渠道区分不同价表。

| 价表类型（price_type） | 名称 | 适用场景 | 优先级 |
|---|---|---|---|
| `STANDARD` | 标准价表（自费） | 默认，所有自费患者 | 100 |
| `MEMBER` | 会员价表 | 会员患者 | 80 |
| `INSURANCE` | 商保价表（预留） | 商保直付患者 | 70 |
| `INTERNAL` | 内部核算价表 | 内部结算、成本核算 | 50 |
| `DEPT` | 科室差异价表 | 特定科室的特殊定价 | 60 |
| `ACTIVITY` | 活动价表 | 限时活动 | 40 |

**取价优先级（高到低）：**

```
1. 活动价表（在活动期内）
2. 科室差异价表（患者就诊科室匹配）
3. 会员价表（患者是会员）
4. 商保价表（患者有商保计划）
5. 标准价表（兜底，必有）
```

**取价算法：**

```
def resolve_price(charge_item_code, patient, dept_id, biz_time):
    candidates = 按优先级排序的候选价表
    for price_list in candidates:
        price = 查 price_list 中该项目的有效价（effective_date <= biz_time <= expire_date）
        if price: return price
    return 标准价表价格  # 兜底
```

### 3.3 价格版本模型

价格**永不覆盖**，只新增版本。每次调价：

```
旧价格记录：expire_date = 新价格生效日 - 1天
新价格记录：effective_date = 生效日，expire_date = NULL
```

**时间轴示例：**

```
收费项目 C0300127 OCT
├─ 2024-01-01 ~ 2024-12-31  280.00 元   (price_history_id=1001)
├─ 2025-01-01 ~ 2025-12-31  300.00 元   (price_history_id=1002)
└─ 2026-01-01 ~ 至今        266.00 元   (price_history_id=1003，当前有效)
```

**取价规则：** M16 调用 `GET /internal/v1/charge/prices/effective?biz_time=2025-06-15T10:00:00`，返回 `300.00`。

这样即使 2025 年 6 月的单据在今天重打，金额仍是 300.00，不会因后续调价而变化。

### 3.4 价格构成模型

| 价格类型 | 说明 | 使用场景 |
|---|---|---|
| `standard_price` | 标准价 | 收费项目目录上的参考价 |
| `price_list_price` | 价表价 | 实际收费价 |
| `cost_price` | 成本价 | 成本核算（M17） |
| `max_retail_price` | 最高零售限价 | 物价局规定上限 |
| `min_retail_price` | 最低零售价 | 内部管控下限 |
| `insurance_price` | 医保价（预留） | — |
| `commercial_price` | 商保价（预留） | — |

**价表价计算公式：**

```
价表价 = 标准价 × (1 + 加价率)     —— 用于会员价、商保价
价表价 = 固定值                    —— 用于活动价、科室价
价表价 = 套餐明细合计 × 折扣系数   —— 用于套餐价
```

### 3.5 折扣与优惠模型

**折扣层次（从外到内）：**

```
1. 会员等级折扣（M03 提供等级，M01 提供折扣率配置）
        ↓
2. 优惠方案折扣（md_discount_policy）
        ↓
3. 手动折扣（收费员输入，受最低折扣率限制）
        ↓
4. 最终应收
```

**优惠方案类型：**

| 类型 | 代码 | 说明 | 示例 |
|---|---|---|---|
| 折扣 | `DISCOUNT` | 按比例打折 | 暑期学生配镜 8 折 |
| 满减 | `FULL_REDUCE` | 满 X 元减 Y 元 | 满 1000 减 200 |
| 套餐价 | `PACKAGE` | 组合打包价 | 屈光术前检查套餐 699 |
| 买赠 | `GIFT` | 买 A 赠 B | 配镜赠护理液 |
| 会员权益 | `MEMBER` | 会员专享 | 金卡会员 9 折 |
| 活动价 | `ACTIVITY` | 限时特价 | 暑期 OK 镜验配特惠 |

**折扣约束：**

| 约束 | 说明 |
|---|---|
| 最低折扣率 | `min_discount_rate`，低于此值需审批 |
| 叠加规则 | `allow_stack`，是否可与其他优惠叠加 |
| 互斥规则 | 同一收费项目只能使用一个优惠方案（可配置） |
| 审批阈值 | 折扣率低于 X% 需店长/财务审批 |
| 限期与名额 | 生效期、每人限次、总名额 |

**折扣计算顺序（可配置）：**

```
模式 A（先折后减）：应收 = 原价 × 折扣 → 再满减
模式 B（先减后折）：应收 = (原价 - 满减) × 折扣
默认模式 A
```

```python
# app/services/mdm/price_service.py
"""价格服务：取价、版本管理、调价"""
import json
from datetime import date, datetime, timedelta
from decimal import Decimal, ROUND_HALF_UP
from typing import Optional, List, Dict, Any

from sqlalchemy import select, func, and_, or_, update
from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy.orm import selectinload

from app.models.mdm.charge import (
    ChargeItem, PriceList, PriceItem, PriceHistory,
    PriceAdjust, PriceAdjustDetail,
)
from app.schemas.mdm.charge import PriceAdjustCreate, PriceItemSchema
from app.core.exceptions import BizException, ErrorCode
from app.core.redis import redis_client


class PriceService:
    """价格服务"""

    CACHE_PRICE = "mdm:price:{list_code}:{item_code}:{biz_date}"
    CACHE_LIST_ITEMS = "mdm:price:list:{list_id}"
    CACHE_VERSION = "mdm:price:version"
    CACHE_TTL = 7200

    # 价表类型优先级（数值越小越优先）
    TYPE_PRIORITY = {
        "ACTIVITY": 40, "DEPT": 60, "MEMBER": 80,
        "INSURANCE": 70, "STANDARD": 100, "INTERNAL": 50,
    }

    def __init__(self, db: AsyncSession):
        self.db = db

    # ==================== 核心：取生效价 ====================
    async def get_effective_prices(
        self, charge_item_codes: List[str], biz_time: str,
        price_list_code: Optional[str] = None,
    ) -> List[dict]:
        """按业务发生时间取价格（保证历史单据金额不变）"""
        biz_dt = datetime.fromisoformat(biz_time)
        biz_date = biz_dt.date()

        # 未指定价表时使用默认标准价表
        if not price_list_code:
            price_list_code = await self._get_default_list_code()

        results = []
        miss_codes = []

        # 1. 查缓存
        for code in charge_item_codes:
            key = self.CACHE_PRICE.format(
                list_code=price_list_code, item_code=code,
                biz_date=biz_date.isoformat(),
            )
            cached = await redis_client.get(key)
            if cached:
                results.append(json.loads(cached))
            else:
                miss_codes.append(code)

        # 2. 未命中查 DB
        if miss_codes:
            stmt = (
                select(PriceItem, ChargeItem)
                .join(ChargeItem, ChargeItem.id == PriceItem.charge_item_id)
                .where(
                    PriceItem.price_list_code == price_list_code,
                    PriceItem.charge_item_code.in_(miss_codes),
                    PriceItem.deleted == 0,
                    PriceItem.effective_date <= biz_date,
                    or_(
                        PriceItem.expire_date.is_(None),
                        PriceItem.expire_date >= biz_date,
                    ),
                )
                .order_by(PriceItem.charge_item_code, PriceItem.effective_date.desc())
            )
            seen = set()
            for pi, ci in (await self.db.execute(stmt)).all():
                if pi.charge_item_code in seen:
                    continue
                seen.add(pi.charge_item_code)
                item = {
                    "charge_item_code": pi.charge_item_code,
                    "charge_item_name": ci.name,
                    "price_list_code": pi.price_list_code,
                    "price": float(pi.price),
                    "original_price": float(pi.original_price),
                    "unit": ci.unit,
                    "effective_date": pi.effective_date.isoformat(),
                    "expire_date": pi.expire_date.isoformat() if pi.expire_date else None,
                    "price_id": pi.id,
                }
                results.append(item)
                # 写缓存
                key = self.CACHE_PRICE.format(
                    list_code=price_list_code, item_code=pi.charge_item_code,
                    biz_date=biz_date.isoformat(),
                )
                await redis_client.setex(key, self.CACHE_TTL,
                                         json.dumps(item, ensure_ascii=False))

        # 3. 校验缺失
        found = {r["charge_item_code"] for r in results}
        missing = [c for c in charge_item_codes if c not in found]
        if missing:
            # 降级：用收费项目当前价兜底
            fallback = await self._fallback_prices(missing)
            results.extend(fallback)

        return sorted(results, key=lambda x: charge_item_codes.index(x["charge_item_code"]))

    async def resolve_prices(self, payload: dict) -> dict:
        """智能取价：按患者会员等级/科室/患者类型选择最优先价表"""
        codes: List[str] = payload.get("charge_item_codes", [])
        member_level: Optional[str] = payload.get("member_level")
        dept_id: Optional[int] = payload.get("dept_id")
        patient_type: Optional[str] = payload.get("patient_type", "OUTPATIENT")
        biz_time: str = payload.get("biz_time") or datetime.now().isoformat()
        biz_date = datetime.fromisoformat(biz_time).date()

        # 1. 加载所有有效价表并按优先级排序
        stmt = (
            select(PriceList)
            .where(
                PriceList.deleted == 0,
                PriceList.status == 1,
                PriceList.effective_date <= biz_date,
                or_(PriceList.expire_date.is_(None), PriceList.expire_date >= biz_date),
            )
            .order_by(PriceList.priority.asc())
        )
        price_lists = (await self.db.execute(stmt)).scalars().all()

        # 2. 过滤适用价表
        candidates = []
        for pl in price_lists:
            if not self._match_price_list(pl, member_level, dept_id, patient_type):
                continue
            candidates.append(pl)

        # 3. 按优先级依次取价，命中即返回
        resolved = []
        remaining = set(codes)
        for pl in candidates:
            if not remaining:
                break
            prices = await self._get_prices_from_list(pl.code, list(remaining), biz_date)
            for p in prices:
                resolved.append({
                    **p,
                    "price_list_name": pl.name,
                    "reason": f"匹配价表 {pl.name}（优先级 {pl.priority}）",
                })
                remaining.discard(p["charge_item_code"])

        # 4. 剩余项目用标准价兜底
        if remaining:
            fallback = await self._fallback_prices(list(remaining))
            for f in fallback:
                resolved.append({
                    **f,
                    "price_list_name": "标准价表",
                    "reason": "无更优先价表，使用标准价表兜底",
                })

        return {"resolved": resolved}

    def _match_price_list(self, pl: PriceList, member_level: Optional[str],
                          dept_id: Optional[int], patient_type: str) -> bool:
        """判断价表是否适用于当前上下文"""
        if pl.price_type == "STANDARD":
            return True
        if pl.price_type == "MEMBER":
            if not member_level:
                return False
            levels = (pl.apply_member_levels or "").split(",")
            return member_level in levels
        if pl.price_type == "DEPT":
            if not dept_id:
                return False
            depts = (pl.apply_dept_ids or "").split(",")
            return str(dept_id) in depts
        if pl.apply_patient_types:
            types = pl.apply_patient_types.split(",")
            if patient_type not in types:
                return False
        if pl.apply_dept_ids and dept_id:
            depts = pl.apply_dept_ids.split(",")
            if str(dept_id) not in depts:
                return False
        return True

    async def _get_prices_from_list(self, list_code: str, codes: List[str],
                                    biz_date: date) -> List[dict]:
        stmt = (
            select(PriceItem, ChargeItem.name, ChargeItem.unit)
            .join(ChargeItem, ChargeItem.id == PriceItem.charge_item_id)
            .where(
                PriceItem.price_list_code == list_code,
                PriceItem.charge_item_code.in_(codes),
                PriceItem.deleted == 0,
                PriceItem.effective_date <= biz_date,
                or_(PriceItem.expire_date.is_(None),
                    PriceItem.expire_date >= biz_date),
            )

        )

                "charge_item_code": pi.charge_item_code,

                "price": float(pi.price),
                "original_price": float(pi.original_price),
                "unit": unit,
                "effective_date": pi.effective_date.isoformat(),
                "price_id": pi.id,
            })
        return result

    async def create_adjust(self, payload: PriceAdjustCreate, operator) -> dict:
        """新建调价单"""

        for d in payload.details:

                )

        # 3. 生成单号

        old_total = sum(d.old_price or Decimal("0") for d in valid_details)
        new_total = sum(d.new_price for d in valid_details)
        rates = [
            ((d.new_price - d.old_price) / d.old_price * 100).quantize(Decimal("0.01"))
            for d in valid_details if d.old_price

            approve_status="DRAFT",

            created_by=operator.id,

        self.db.add(adjust)

            if d.old_price:

    async def approve_adjust(self, adjust_id: int, opinion: Optional[str],
                             version: int, second_factor_token: Optional[str],
                             operator) -> dict:
        """审批调价单，终审通过后生效"""
        adjust = (await self.db.execute(
            select(PriceAdjust).where(PriceAdjust.id == adjust_id, PriceAdjust.deleted == 0)
        )).scalar_one_or_none()
        if not adjust:
            raise BizException(ErrorCode.NOT_FOUND, "调价单不存在")

        if adjust.version != version:
            raise BizException(42027, "调价单已被他人修改，请刷新后重试")

        if adjust.approve_status not in ("PENDING", "APPROVING"):
            raise BizException(42013, f"调价单状态 {adjust.approve_status} 不允许审批")

        # 二次验证（核心审批）
        if not await self._verify_second_factor(operator, second_factor_token):
            raise BizException(40001, "审批需二次验证，请提供验证码")

        # 是否终审
        chain = json.loads(adjust.approve_chain or "[]")
        current_idx = next(
            (i for i, n in enumerate(chain) if n.get("status") == "PENDING"), 0
        )
        is_final = current_idx >= len(chain) - 1

        async with self.db.begin_nested():
            chain[current_idx]["status"] = "APPROVED"
            chain[current_idx]["opinion"] = opinion
            chain[current_idx]["approved_at"] = datetime.now().isoformat()
            adjust.approve_chain = json.dumps(chain, ensure_ascii=False)
            adjust.version += 1

            if is_final:
                adjust.approve_status = "APPROVED"
                adjust.approver_id = operator.id
                adjust.approve_at = datetime.now()
                adjust.approve_opinion = opinion
            else:
                next_node = chain[current_idx + 1]
                adjust.current_node = next_node["node"]
                adjust.current_approver_id = next_node.get("approver_id")
                next_node["status"] = "PENDING"

        await self.db.commit()

        # 终审通过 → 生效
        if is_final:
            effect_result = await self._apply_adjust_effect(adjust, operator)
            return {
                "id": adjust.id,
                "code": adjust.code,
                "approve_status": "EFFECTIVE",
                "effect_at": effect_result["effect_at"],
                "affected_items": effect_result["affected_items"],
                "affected_price_lists": effect_result["affected_price_lists"],
                "price_history_created": effect_result["price_history_created"],
                "cache_task_no": effect_result["cache_task_no"],
                "distributed_to": effect_result["distributed_to"],
            }

        return {
            "id": adjust.id,
            "code": adjust.code,
            "approve_status": "APPROVING",
            "next_node": chain[current_idx + 1]["node"],
        }

    async def _apply_adjust_effect(self, adjust: PriceAdjust, operator) -> dict:
        """执行调价生效：旧价失效 + 新价写入 + 历史留痕 + 缓存失效"""
        details = (await self.db.execute(
            select(PriceAdjustDetail).where(PriceAdjustDetail.adjust_id == adjust.id)

        affected_lists = set()
        history_count = 0
        effective_date = adjust.effective_date

        async with self.db.begin():

                if d.object_type != "CHARGE_ITEM":
                    continue

                item = await self._get_charge_item(d.object_id)

                        expire_date=effective_date - timedelta(days=1),

                    )
                )

                item.current_price = d.new_price

            adjust.effect_at = datetime.now()

        async for key in redis_client.scan_iter(match="mdm:price:*", count=500):

        await self._publish_price_event(adjust, list(affected_lists))

# app/services/mdm/charge_calc_service.py
"""计费试算服务：按计价方式计算金额"""
from decimal import Decimal, ROUND_HALF_UP
from typing import List, Dict, Any
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.mdm.charge import ChargeItem, ChargeItemPricingRule

class ChargeCalcService:
    """计费试算"""

    EYE_FACTOR = {"LEFT": Decimal("1"), "RIGHT": Decimal("1"), "BOTH": Decimal("2")}

    def __init__(self, db: AsyncSession):
        self.db = db

    async def calculate(self, payload: dict) -> dict:
        items = payload.get("items", [])
        biz_time = payload.get("biz_time")
        apply_discount = payload.get("apply_discount", True)

        results = []
        original_total = Decimal("0")
        discount_total = Decimal("0")

        for it in items:
            code = it["charge_item_code"]
            qty = Decimal(str(it.get("qty", 1)))
            eye_side = it.get("eye_side")
            exec_dept_id = it.get("exec_dept_id")

            item = await self._get_item(code)
            rules = await self._get_rules(item.id)

            # 1. 基础单价
            unit_price = item.current_price or item.standard_price

            # 2. 阶梯价
            if item.pricing_mode == "TIERED":
                unit_price = self._resolve_tiered(rules, qty, unit_price)

            # 3. 眼别数量
            eye_factor = Decimal("1")
            if item.charge_by_eye or item.pricing_mode == "BY_EYE":
                eye_factor = self._resolve_eye_factor(rules, eye_side)
                if eye_factor == 0:
                    raise BizException(50002, f"项目 {item.name} 未配置眼别 {eye_side} 的计价规则")

            # 4. 金额
            original_amount = (unit_price * qty * eye_factor).quantize(
                Decimal("0.01"), rounding=ROUND_HALF_UP
            )

            # 5. 附加费
            extras = self._resolve_extras(rules, original_amount)
            original_amount += extras

            # 6. 折扣（由 DiscountService 处理，这里只做基础折扣）
            discount_amount = Decimal("0")
            final_amount = original_amount
            if apply_discount and item.allow_discount:
                # 简化：不做方案匹配，完整逻辑在 DiscountService
                pass

            results.append({
                "charge_item_code": code,
                "charge_item_name": item.name,
                "pricing_mode": item.pricing_mode,
                "unit_price": float(unit_price),
                "qty": float(qty),
                "eye_side": eye_side,
                "eye_factor": float(eye_factor),
                "extras": float(extras),
                "original_amount": float(original_amount),
                "discount_amount": float(discount_amount),
                "final_amount": float(final_amount),
                "price_list_code": "PL001",
                "pricing_rule_hit": f"{item.pricing_mode}:{eye_side or '-'}",
            })
            original_total += original_amount
            discount_total += discount_amount

        final_total = original_total - discount_total
        discount_rate = (
            (final_total / original_total).quantize(Decimal("0.0001"))
            if original_total else Decimal("1")
        )

        return {

            "summary": {

    def _resolve_tiered(self, rules, qty: Decimal,
                        default_price: Decimal) -> Decimal:
        """按数量区间取单价"""
        tiers = sorted(
            [r for r in rules if r.rule_type == "TIERED"],
            key=lambda r: r.priority,
        )
        for t in tiers:
            if t.min_qty is not None and qty < t.min_qty:
                continue
            if t.max_qty is not None and qty > t.max_qty:
                continue
            if t.unit_price is not None:
                return t.unit_price
            if t.total_price is not None and qty > 0:
                return (t.total_price / qty).quantize(Decimal("0.0001"))
        return default_price

    def _resolve_eye_factor(self, rules, eye_side: str) -> Decimal:
        """解析眼别系数"""
        if not eye_side:
            return Decimal("1")
        eye_rules = [r for r in rules if r.rule_type == "BY_EYE"]
        for r in eye_rules:
            if r.part_code == eye_side and r.part_qty_factor is not None:
                return r.part_qty_factor
        # 兜底：双脚 = 2，单眼 = 1
        return self.EYE_FACTOR.get(eye_side, Decimal("1"))

    def _resolve_extras(self, rules, base_amount: Decimal) -> Decimal:
        """计算附加费（EXTRA 固定金额 / SURCHARGE 比例）"""
        extra = Decimal("0")
        for r in rules:
            if r.rule_type == "EXTRA" and r.extra_amount:
                extra += r.extra_amount
            elif r.rule_type == "SURCHARGE" and r.extra_rate:
                extra += (base_amount * r.extra_rate / 100).quantize(Decimal("0.01"))
        return extra

    async def _get_item(self, code: str) -> ChargeItem:
        item = (await self.db.execute(
            select(ChargeItem).where(ChargeItem.code == code, ChargeItem.deleted == 0)
        )).scalar_one_or_none()
        if not item:
            raise BizException(50001, f"收费项目 {code} 不存在")
        return item

    async def _get_rules(self, item_id: int):
        return (await self.db.execute(
            select(ChargeItemPricingRule).where(
                ChargeItemPricingRule.charge_item_id == item_id,
                ChargeItemPricingRule.deleted == 0,
                ChargeItemPricingRule.status == "ENABLED",
            )
        )).scalars().all()
```

async def apply_pending_price_adjusts():
    """扫描今天生效的已审批调价单并执行"""
    from datetime import date
    from sqlalchemy import select
    from app.models.mdm.charge import PriceAdjust
    from app.services.mdm.price_service import PriceService
    from app.core.database import AsyncSessionLocal

    async with AsyncSessionLocal() as db:
        today = date.today()
        rows = (await db.execute(
            select(PriceAdjust).where(
                PriceAdjust.approve_status == "APPROVED",
                PriceAdjust.effective_date <= today,
                PriceAdjust.deleted == 0,
            )
        )).scalars().all()

        svc = PriceService(db)
        for adjust in rows:
            try:
                await svc._apply_adjust_effect(adjust, operator=None)
            except Exception as e:
                import structlog
                structlog.get_logger().error(
                    "price_effect_failed", adjust_code=adjust.code, error=str(e)
                )


async def scan_price_anomalies():
    """扫描价格异常（超限/低于成本/加价率异常）"""
    from sqlalchemy import select
    from app.models.mdm.charge import PriceItem, ChargeItem
    from app.core.database import AsyncSessionLocal
    from app.services.notify_service import NotifyService

    async with AsyncSessionLocal() as db:
        stmt = (
            select(PriceItem, ChargeItem)
            .join(ChargeItem, ChargeItem.id == PriceItem.charge_item_id)
            .where(PriceItem.is_current == 1, PriceItem.deleted == 0)
        )
        anomalies = []
        for pi, ci in (await db.execute(stmt)).all():
            if ci.max_retail_price and pi.price > ci.max_retail_price:
                anomalies.append({
                    "type": "OVER_LIMIT", "code": ci.code, "name": ci.name,
                    "price": float(pi.price), "limit": float(ci.max_retail_price),
                })
            if ci.cost_price and pi.price < ci.cost_price:
                anomalies.append({
                    "type": "BELOW_COST", "code": ci.code, "name": ci.name,
                    "price": float(pi.price), "cost": float(ci.cost_price),
                })

        if anomalies:
            notify = NotifyService()
            await notify.send(
                template="PRICE_ANOMALY_ALERT",
                receivers=await get_finance_managers(),
                params={"count": len(anomalies), "items": anomalies[:20]},
            )


async def check_invoice_segments():
    """检查发票号码段余量"""
    from sqlalchemy import select
    from app.models.mdm.charge import InvoiceNumberSegment
    from app.core.database import AsyncSessionLocal

    async with AsyncSessionLocal() as db:
        rows = (await db.execute(
            select(InvoiceNumberSegment).where(
                InvoiceNumberSegment.status == "ACTIVE",
                InvoiceNumberSegment.deleted == 0,
            )
        )).scalars().all()

        for seg in rows:
            remaining = seg.end_no - seg.current_no
            ratio = remaining / seg.total_count if seg.total_count else 0
            if ratio <= 0.05:
                await notify_service.send(
                    template="INVOICE_SEGMENT_LOW",
                    receivers=await get_finance_managers(),
                    params={
                        "invoice_point": seg.invoice_point,
                        "remaining": remaining,
                        "level": "URGENT",
                    },
                )

## 8. 业务规则与校验

### 8.1 编码规则

| 对象 | 规则 | 示例 |
|---|---|---|
| 收费项目 | `C` + 分类段(2) + 流水(5) | `C0300127` |
| 价表 | `PL` + 流水(3) | `PL001` |
| 调价单 | `PA` + yyyyMM + 流水(4) | `PA2026040007` |
| 优惠方案 | `DP` + 流水(4) | `DP0024` |
| 套餐 | `CM` + 流水(4) | `CM0086` |
| 退费规则 | `RF` + 流水(3) | `RF012` |
| 发票配置 | `IC` + 流水(3) | `IC002` |

**约束：** 编码全局唯一；生成后不可修改。

### 8.2 唯一性规则

| 校验 | 规则 | 处理 |
|---|---|---|
| 收费编码唯一 | `md_charge_item.code` | 阻止，42001 |
| 收费项目名称唯一 | 同名且同单位 | 警告（可继续） |
| 快捷键唯一 | `md_charge_item.hotkey` | 阻止，42003 |
| 价表编码唯一 | `md_price_list.code` | 阻止，42005 |
| 价表内项目唯一 | `price_list_id + charge_item_id` | 阻止，42006 |
| 同类型默认价表唯一 | `price_type + is_default=1` | 阻止，42008 |
| 调价明细不重复 | `object_id + price_list_id` | 阻止，40001 |
| 套餐明细不重复 | `combo_id + charge_item_id` | 阻止，42022 |
| 优惠方案编码唯一 | `md_discount_policy.code` | 阻止 |

### 8.3 价格规则

| 规则 | 说明 |
|---|---|
| 版本化 | 价格变更**永不覆盖**，只新增版本 |
| 生效日期 | 必须 ≥ 今天（补录需管理员权限） |
| 旧价失效 | 新价生效日 -1 天 |
| 最高限价 | `price ≤ max_retail_price`，否则阻止（42010） |
| 最低限价 | `price ≥ min_retail_price`，否则阻止（42011） |
| 成本校验 | `price < cost_price` 告警（不阻止） |
| 取价规则 | 按 `biz_time` 取当时有效价 |
| 加价率 | `markup_rate ≤ 配置上限`（默认 100%） |
| 精度 | 价格保留 4 位小数，金额保留 2 位小数 |

### 8.4 计价规则

| 计价方式 | 计算 | 说明 |
|---|---|---|
| FIXED | 金额 = 单价 | — |
| BY_EYE | 金额 = 单价 × 眼别系数 | 双眼 = 2，单眼 = 1 |
| BY_QTY | 金额 = 单价 × 数量 | — |
| BY_DAY | 金额 = 单价 × 天数 | — |
| BY_HOUR | 金额 = 单价 × 小时数 | — |
| BY_AREA | 金额 = 单价 × 面积 | — |
| BY_PART | 金额 = 单价 × 部位数 | — |
| TIERED | 按数量区间取单价 | 取第一个命中区间 |
| COMBO | 金额 = 套餐价 | 明细不出账 |
| FREE | 金额 = 0 | — |

**附加费：** `EXTRA` 加固定金额；`SURCHARGE` 加比例。

**最终金额计算顺序：**

```
单价 → 数量/眼别/天数 → 小计 → 附加费 → 折扣 → 满减 → 最终金额
```

### 8.5 折扣规则

| 规则 | 说明 |
|---|---|
| 项目可打折 | `allow_discount=1` |
| 折扣率上限 | `discount_rate ≥ max_discount_rate`（如 80 表示最低 8 折后被允许？） |
| 折扣率下限 | `discount_rate ≥ min_discount_rate`（防过度让利） |
| 折扣审批 | 低于阈值需审批 |
| 叠加规则 | `allow_stack` 控制 |
| 取最优 | 多方案时自动取最优（优惠最大） |
| 免费项目 | `pricing_mode=FREE` 不参与折扣 |
| 会员折扣 | 由 M03 会员等级提供，M01 控制折扣率配置 |

> **术语澄清**：`max_discount_rate`（最高折扣率）指**最低可打的折**（如 80 = 最低 8 折），数值越大折扣力度越小；`min_discount_rate`（最低折扣率）指**最高可打的折**？为避免歧义，实现中统一：**折扣率数值 = 实付/原价 × 100**，数值越小折扣越大。`min_discount_rate` 是允许的最小折扣率（折扣力度上限，防过度让利），`max_discount_rate` 是允许的最大折扣率（折扣力度下限，即不能随便少打折）。

### 8.6 优惠方案规则

| 规则 | 说明 |
|---|---|
| 生效期 | `effective_date ≤ today ≤ expire_date` |
| 名额 | `used_quota < total_quota` |
| 每人限次 | 按患者统计使用次数 |
| 每日限次 | 按日统计 |
| 叠加 | `allow_stack=1` 才能叠加 |
| 互斥 | 同项目多方案时取最优 |
| 最低折扣底线 | `discount_rate ≥ min_discount_rate` |
| 自动应用 | `is_auto_apply=1` 无需手动选择 |
| 名额扣减 | 使用后 `used_quota += 1`（原子操作） |

### 8.7 退费规则

| 规则 | 说明 |
|---|---|
| 可退 | `allow_refund=1` |
| 时间窗口 | `refund_window_type` 定义 |
| 退费比例 | `refund_ratio` 限制可退金额 |
| 手续费 | `fee_ratio` 扣除 |
| 已执行 | `allow_executed_refund` 控制 |
| 已发药 | `allow_dispensed_refund` 控制 |
| 审批阈值 | 金额/比例超阈值需审批 |
| 积分回滚 | `rollback_points` 控制 |

**退费金额计算：**

```
可退金额 = 原实收金额 × refund_ratio/100 - 原实收金额 × fee_ratio/100
```

### 8.8 套餐规则

| 规则 | 说明 |
|---|---|
| 套餐价 | `package_price ≤ 原价合计` |
| 明细唯一 | 不能重复收费项目 |
| 按眼别拆分 | 双眼时明细数量 ×2 |
| 有效期 | 购买后 `valid_days` 内有效 |
| 部分退费 | `allow_partial_refund` 控制 |
| 套餐价分摊 | 按明细原价比例分摊套餐价（供 M16 结算） |

### 8.9 关联规则

| 规则 | 说明 |
|---|---|
| 一对象一主收费 | 同一业务对象只能有一个 `rel_type=PRIMARY` 关联 |
| 未关联阻断 | 检查/手术项目未关联收费项目时，不可开单（可配置为警告） |
| 孤儿关联 | 关联对象已删除时标记为孤儿，定期清理 |
| 数量换算 | `qty_factor` 定义对象与收费单位的换算关系 |
| 价格来源 | `FIXED` 用收费项目价；`OBJECT` 用对象价格（药品/耗材） |

### 8.10 验证与并发

| 机制 | 说明 |

### 10.3 与 M16 的核心契约

| 接口 | 用途 | SLA |
|---|---|---|
| `GET /internal/v1/charge/prices/effective` | 取生效价（必须传 biz_time） | P95 ≤ 100ms（缓存）/ ≤300ms（DB） |
| `POST /internal/v1/charge/prices/batch-effective` | 批量取价 | P95 ≤ 200ms |
| `POST /internal/v1/charge/prices/resolve` | 智能取价 | P95 ≤ 300ms |
| `POST /internal/v1/charge/calculate` | 计费试算 | P95 ≤ 200ms |
| `POST /internal/v1/charge/discount/calc` | 优惠试算 | P95 ≤ 300ms |
| `GET /internal/v1/charge/refund-policy/match` | 匹配退费规则 | P95 ≤ 50ms |
| `GET /internal/v1/charge/combos/{code}` | 套餐详情 | P95 ≤ 100ms |

**关键约定：**

1. **必须传 `biz_time`**：M16 结算时传业务发生时间，保证历史单据金额不变。
2. **M16 不缓存价格**：每次结算实时调用，避免价格不一致。
3. **金额以 M01 返回为准**：M16 只负责记录与收付款，不自行计算单价。
4. **版本号兜底**：`GET /internal/v1/charge/version` 供 M16 检测价格变动。

## 11. 异常处理与日志

### 11.1 异常分类

| 类型 | 示例 | 处理 |
|---|---|---|
| 参数异常 | 必填缺失、格式错误 | 40001 + 字段级错误 |
| 业务异常 | 编码重复、超限价、折扣越界 | 对应业务码 + 友好提示 |
| 并发异常 | 乐观锁冲突、编辑锁 | 42027 + 提示刷新 |
| 取价异常 | 价表缺失、价格缺失 | 降级取标准价 + 告警 |
| 依赖异常 | M02 二次验证不可用 | 降级放行 + 审计告警 |
| 系统异常 | DB/Redis 失败 | 50000 + 错误日志 |

**降级策略：**

| 依赖 | 不可用时 |
|---|---|
| Redis | 直连 DB 取价（性能下降，功能可用） |
| M02（二次验证） | 审批降级放行并记录告警（可配置为拒绝） |
| MQ | 事件落库 PENDING，恢复后补投；版本号轮询兜底 |

### 11.2 日志规范

```json
{
  "timestamp": "2026-04-01T10:23:45.123+08:00",
  "level": "INFO",
  "logger": "app.services.mdm.price_service",
  "trace_id": "3f2a1b9c",
  "user_id": 1001,
  "user_name": "张明",
  "action": "PRICE_ADJUST_EFFECT",
  "target": { "adjust_code": "PA2026030007", "item_count": 128 },
  "affected_price_lists": 4,
  "cost_ms": 320,
  "message": "调价单生效完成"
}
```

**日志级别：**
- `INFO`：正常操作（新增/修改/调价/发布）
- `WARNING`：可恢复异常（价格告警、取价降级、缓存失效慢）
- `ERROR`：业务失败（校验不通过、限价超限）
- `CRITICAL`：系统故障（价表缺失、DB/Redis 不可用）

**敏感信息：** 日志不记录成本价明细（仅记录是否超限）。

## 附录 E：计价示例

### E.1 按眼别计价

```
项目：OCT（C0300127），单价 266.00 元/眼
场景：双眼检查

计算：
  眼别 = BOTH → 系数 = 2
  金额 = 266.00 × 1（默认数量）× 2 = 532.00 元
```

### E.2 阶梯价

```
项目：某检查，配置：
  [1, 5] 次 → 280.00
  [6, 10] 次 → 250.00
  [11, ∞] 次 → 220.00

场景：8 次
计算：命中 [6, 10] 区间 → 250.00 × 8 = 2,000.00 元
```

### E.3 附加费

```
项目：FFA 造影检查，标准价 300.00
附加规则：EXTRA 造影剂费 180.00

场景：单眼 FFA
计算：300.00 + 180.00 = 480.00 元
```

### E.4 折扣叠加

```
项目：镜片 680.00，镜架 420.00，加工 120.00（可打折）
会员折扣：95%（金卡）
活动方案：满 1000 减 100

原始合计 = 680 + 420 + 120 = 1,220.00
会员折扣 = 1,220 × 95% = 1,159.00（优惠 61.00）
满减 = 1,159 - 100 = 1,059.00
最终应收 = 1,059.00

（若模式 B：先减后折）
满减 = 1,220 - 100 = 1,120.00
会员折扣 = 1,120 × 95% = 1,064.00
最终应收 = 1,064.00
```

### E.5 退费计算

```
原收费：OCT 双眼 532.00 元，2026-04-01 10:00 收取
退费规则：同日可退，退费比例 100%，手续费 0

场景：2026-04-01 15:00 退费
计算：可退 = 532.00 × 100% - 0 = 532.00 元

场景：2026-04-03 退费（超过同日窗口）
结果：不可退（需主管审批例外）
```

### E.6 价格版本取价

```
价格历史：
  2024-01-01 ~ 2024-12-31  280.00
  2025-01-01 ~ 2025-12-31  300.00
  2026-01-01 ~ 至今        266.00

场景 1：biz_time = 2025-06-15 → 返回 300.00
场景 2：biz_time = 2026-04-01 → 返回 266.00
场景 3：biz_time = 2023-12-01 → 返回 280.00（最早价格兜底）
```
