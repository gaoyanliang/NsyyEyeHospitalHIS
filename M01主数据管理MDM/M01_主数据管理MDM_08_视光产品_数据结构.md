**索引设计**

| 索引名 | 类型 | 字段 | 说明 |
|---|---|---|---|
| pk_optical_spec | PRIMARY | id | 主键 |
| uk_optical_spec | UNIQUE | product_id, sphere, cylinder, add_power, deleted | 度数组合唯一 |
| idx_optical_spec_lookup | NORMAL | product_id, is_available, sphere, cylinder | 验光校验主查询 |
| idx_optical_spec_sphere | NORMAL | sphere, cylinder | 跨产品度数查询 |
| idx_optical_spec_stock | NORMAL | product_id, supply_type, is_available | 现货/定制过滤 |

**约束：**
- `sphere`、`cylinder` 必须是 0.25 的整数倍（应用层 + CHECK 约束）
- `axis` 必须是 1~180 的整数
- `cylinder = 0` 时 `axis` 必须为 NULL
- `add_power` 非空时 `product_kind` 必须为 `LENS` 且 `lens_design = 'PROGRESSIVE'`

**分区策略：** 该表预计 200 万行，按 `product_id` HASH 分区（8 个分区）。

    is_trial_lens: bool = False

    member_price: Optional[Decimal] = Field(None, ge=0)

    is_hot: bool = False

    effective_date: Optional[date] = None
    expire_date: Optional[date] = None

    @model_validator(mode="after")
    def validate_product(self):
        # 医疗器械必须填注册证
        if self.is_medical_device:
            if not self.registration_no:
                raise ValueError("医疗器械必须填写注册证号")
            if not self.device_class:
                raise ValueError("医疗器械必须填写器械类别")
        # OK 镜必为三类器械且定制
        if self.product_kind == "ORTHO_K":
            if not self.is_medical_device:
                raise ValueError("OK镜必须标记为医疗器械")
            if self.device_class != "III":
                raise ValueError("OK镜必须为三类医疗器械")
        # 隐形眼镜需凭处方
        if self.product_kind in ("CONTACT", "RGP"):
            if not self.is_prescription_required:
                raise ValueError("隐形眼镜/RGP 必须标记为凭处方销售")
        # 会员价不能高于零售价
        if self.member_price is not None and self.member_price > self.retail_price:
            raise ValueError("会员价不能高于零售价")
        # 成本价不能高于零售价的两倍（异常提示）
        if self.cost_price is not None and self.retail_price > 0:
            if self.cost_price > self.retail_price:
                raise ValueError("成本价不能高于零售价")
        # 定制产品必须有供货周期
        if self.is_customized and self.lead_time_days is None:
            raise ValueError("定制产品必须填写供货周期")
        # 日期
        if self.effective_date and self.expire_date:
            if self.expire_date <= self.effective_date:
                raise ValueError("失效日期必须晚于生效日期")
        return self
