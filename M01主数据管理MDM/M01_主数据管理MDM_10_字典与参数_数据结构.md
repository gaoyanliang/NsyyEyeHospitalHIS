| cache_ttl | INT | Y | NULL | 缓存秒数（TTL 模式） |
| version | INT | N | 0 | 版本号（变更递增） |
| item_count | INT | N | 0 | 字典项数（冗余） |

| created_at | TIMESTAMP | N | CURRENT_TIMESTAMP | 创建时间 |
| updated_by | BIGINT | Y | NULL | 更新人 |
| updated_at | TIMESTAMP | N | CURRENT_TIMESTAMP（触发器维护） | 更新时间 |
| deleted | BOOLEAN | N | FALSE | 逻辑删除 |

| 索引名 | 类型 | 字段 | 说明 |
|---|---|---|---|

| idx_dict_type_builtin | NORMAL | is_builtin, status | 内置字典 |

    def cast_value(self, raw: Optional[str]):
        """把字符串值转换为 Python 原生类型"""
        if raw is None or raw == "":
            return None
        t = self.param_type
        if t == "BOOLEAN":
            return str(raw).lower() in ("true", "1", "yes")
        if t == "INTEGER":
            return int(raw)
        if t == "DECIMAL":
            return Decimal(raw)
        if t in ("JSON", "ARRAY"):
            import json
            return json.loads(raw)
        return raw

        """当前生效值（已转换类型）"""
        return self.cast_value(self.param_value or self.default_value)
