## 1. 模块概述

### 1.1 模块定位

临床主数据是眼科医院 HIS 的**临床语义基础**，为医生工作站、护理站、检查检验、手术等全部临床业务提供统一的**诊断、检查、检验、标本、设备**定义。

总体设计第 3 章 M01 行明确"手术、检查"为临床域主数据；第 8.2 节强调主数据分发的首要目标。第 5.5 节手术闭环、第 5.6 节检查闭环均以本子模块为基础。

本子模块定位于**临床业务的"词表与资源"**，不含业务执行：

| 职责 | 归属 | 说明 |
|---|---|---|
| 诊断字典（ICD-10） | **M01 临床子模块（本文档）** | 含眼科专科诊断扩展 |
| 检查项目定义 | **M01 临床子模块（本文档）** | OCT/视野/地形图等 |
| 检查结构化报告字段 | **M01 临床子模块（本文档）** | 报告模板骨架 |
| 危急值规则 | **M01 临床子模块（本文档）** | 检查危急值判定 |
| 检验项目与组合 | **M01 临床子模块（本文档）** | 含眼内液、泪液检测 |
| 参考区间 | **M01 临床子模块（本文档）** | 性别/年龄段分段 |
| 标本类型 | **M01 临床子模块（本文档）** | 含房水、玻璃体液 |
| 设备台账 | **M01 临床子模块（本文档）** | 含 DICOM 对接参数 |
| 设备维修保养记录 | **M01 临床子模块（本文档）** | — |
| 手术项目与麻醉 | **M01 手术子模块**（已独立设计） | 不在本文档 |
| 医生书写诊断 | **M07 医生工作站** | 业务执行 |
| 检查申请、执行、报告 | **M12 检查管理** | 业务执行 |
| 检验申请、标本采集、报告 | **M13 检验管理** | 业务执行 |
| PACS 影像存储 | **M12 + PACS** | — |
| 危急值通知与处置 | **M12/M13** | M01 定义规则 |
| 设备排程 | **M12** | M01 定义设备能力 |

> **一句话边界**：M01 回答"**能下哪些诊断、能做哪些检查检验、结果怎么判读、用哪台设备做**"；M07/M12/M13 回答"**这个患者做了哪些、结果是什么**"。

### 1.2 模块目标

- **统一源头**：全院诊断、检查、检验、标本、设备统一由 MDM 定义，禁止各科室自建。
- **国标映射**：诊断映射 ICD-10，检查映射 DICOM/LOINC，检验映射 LOINC（预留）。
- **眼科专科化**：完整覆盖眼科 40+ 检查模态、眼内液/泪液等特殊标本、眼科专科诊断标识。
- **结构化报告**：检查项目预定义结构化字段，支撑 M12 结构化报告与质控。
- **危急值闭环**：危急值规则前置定义，M12/M13 执行时自动触发通知。
- **设备可排程**：设备能力（日最大量、单次时长、可用状态）前置定义，支撑 M12 号源计算。
- **合规可追溯**：所有变更记录前后值与操作人，保留 10 年。

### 1.3 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 病案室/质控科 | 诊断字典维护 | 维护 ICD-10 诊断、专科标识 |
| 检查中心主任 | 检查项目维护 | 维护检查项目、结构化字段、危急值 |
| 检验科主任 | 检验项目维护 | 维护检验项目、组合、参考区间 |
| 设备科 | 设备台账 | 维护设备、检定、维修保养 |
| 临床医生 | 使用诊断/检查 | 查询、开单 |
| 护士 | 标本采集 | 查询标本要求 |
| 信息科 | PACS/接口 | 维护 DICOM 参数、同步监控 |
| 医务科 | 审核 | 审批新增检查检验项目 |

## 3. 临床主数据分类模型

### 3.1 诊断分类体系

#### 3.1.1 诊断类别（`diagnosis_category`）

| 代码 | 名称 | 说明 |
|---|---|---|
| `WESTERN` | 西医诊断 | ICD-10 主体 |
| `TCM` | 中医诊断 | 中医病名/证候 |
| `SYMPTOM` | 症状体征 | 未明确诊断 |
| `PATHOLOGY` | 病理诊断 | 病理科出具 |
| `IMAGING` | 影像诊断 | 影像科出具 |

#### 3.1.2 诊断层级（`diagnosis_level`）

| 代码 | 名称 | 示例 |
|---|---|---|
| `CATEGORY` | 类目（3 位码） | `H25` 老年性白内障 |
| `SUBCATEGORY` | 亚目（4 位码） | `H25.9` 未特指的老年性白内障 |
| `EXTENSION` | 扩展（院内外延） | `H25.900` 老年性白内障 |

#### 3.1.3 眼科专科标识（`eye_specialty_flag`）

多选字段，标记诊断归属的眼科亚专科。

| 代码 | 亚专科 | 典型诊断 |
|---|---|---|
| `CATARACT` | 白内障 | 老年性白内障、并发性白内障 |
| `GLAUCOMA` | 青光眼 | 原发性开角型青光眼、急性闭角型青光眼 |
| `RETINA` | 眼底病 | 糖尿病视网膜病变、视网膜脱离、黄斑变性 |
| `REFRACTIVE` | 屈光不正 | 近视、远视、散光、老视 |
| `STRABISMUS` | 斜视与小儿眼科 | 共同性斜视、弱视 |
| `CORNEA` | 角膜病 | 角膜炎、圆锥角膜、角膜溃疡 |
| `OCULOPLASTY` | 眼整形 | 上睑下垂、眼睑肿物 |
| `OCULAR_TRAUMA` | 眼外伤 | 眼球挫伤、眼球破裂 |
| `LACRIMAL` | 泪道 | 泪囊炎、泪道阻塞 |
| `OCULAR_SURFACE` | 眼表 | 干眼症、翼状胬肉 |
| `ORBIT` | 眼眶 | 眼眶肿瘤、甲状腺相关眼病 |
| `NEURO_OPHTHALMOLOGY` | 神经眼科 | 视神经炎、缺血性视神经病变 |
| `UVEITIS` | 葡萄膜炎 | 前葡萄膜炎、全葡萄膜炎 |
| `OCULAR_ONCOLOGY` | 眼肿瘤 | 视网膜母细胞瘤、脉络膜黑色素瘤 |

| `AUXILIARY` | 辅助设备 | 电脑、打印机 |

#### 3.4.2 设备运行状态（`run_status`）

| 代码 | 名称 | 影响 |
|---|---|---|
| `NORMAL` | 正常 | 可排程 |
| `REPAIRING` | 维修中 | **不可排程** |
| `DISABLED` | 停用 | 不可排程 |
| `SCRAPPED` | 报废 | 不可排程，不可引用 |

#### 3.4.3 检定状态（`calibration_status`）

| 代码 | 判定 | 说明 |
|---|---|---|
| `VALID` | 检定有效 | `next_calibration_date - today > 30` |
| `EXPIRING` | 即将到期 | `0 ≤ next_calibration_date - today ≤ 30` |
| `EXPIRED` | 已过期 | `next_calibration_date < today` |

from typing import Optional, List

from app.schemas.mdm.clinical import (

@router.get("/diagnoses", summary="诊断分页列表")
async def list_diagnoses(
    keyword: Optional[str] = Query(None, max_length=128),
    diagnosis_category: Optional[str] = Query(None),
    chapter_id: Optional[int] = Query(None),
    eye_specialty: Optional[str] = Query(None),
    is_ophthalmic: Optional[bool] = Query(None),
    is_chronic: Optional[bool] = Query(None),
    is_common: Optional[bool] = Query(None),
    status: Optional[str] = Query(None),
    page: int = Query(1, ge=1),
    page_size: int = Query(20, ge=1, le=200),
    db: AsyncSession = Depends(get_db),
    user=Depends(require_permission("mdm:diagnosis:list")),
):
    svc = DiagnosisService(db)
    q = DiagnosisQuery(
        keyword=keyword,
        diagnosis_category=diagnosis_category.split(",") if diagnosis_category else None,
        chapter_id=chapter_id, eye_specialty=eye_specialty,
        is_ophthalmic=is_ophthalmic, is_chronic=is_chronic,
        is_common=is_common,
        status=status.split(",") if status else None,
        page=page, page_size=page_size,
    )
    items, total = await svc.list_diagnoses(q, user)
    return success_response(PageResult(
        items=items, total=total, page=page, page_size=page_size,
        pages=(total + page_size - 1) // page_size))

# app/services/mdm/critical_service.py
"""危急值判定服务（核心）"""
from decimal import Decimal
from typing import Optional, List

from sqlalchemy import select, and_, or_
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.mdm.clinical import ExamItem, ExamCriticalRule, LabItem, LabReferenceRange
from app.schemas.mdm.clinical import CriticalCheckRequest
from app.core.exceptions import BizException


class CriticalService:
    """危急值判定"""

    def __init__(self, db: AsyncSession):
        self.db = db

    async def check(self, req: CriticalCheckRequest) -> dict:
        """判定是否触发危急值"""
        matched = []
        notify_targets = set()
        notify_channels = set()

        # ---------- 检查危急值 ----------
        if req.exam_code:
            exam = await self._get_exam(req.exam_code)
            if exam and exam.has_critical:
                for rule in exam.critical_rules:
                    if rule.deleted or rule.status != "ENABLED":
                        continue
                    value = req.values.get(rule.indicator_name)
                    if value is None and rule.field_code:
                        value = req.values.get(rule.field_code)
                    if value is None:
                        continue

                    if self._match(rule, Decimal(str(value))):
                        matched.append({
                            "rule_code": rule.rule_code,
                            "rule_name": rule.rule_name,
                            "indicator_name": rule.indicator_name,
                            "value": float(value),
                            "operator": rule.operator,
                            "threshold": float(rule.threshold_min) if rule.threshold_min else None,
                            "unit": rule.indicator_unit,
                            "critical_level": rule.critical_level,
                            "handle_sla_minutes": rule.handle_sla_minutes,
                            "handle_requirement": rule.handle_requirement,
                            "source": "EXAM",
                        })
                        if rule.notify_roles:
                            notify_targets.update(rule.notify_roles.split(","))
                        if rule.notify_channels:
                            notify_channels.update(rule.notify_channels.split(","))

        # ---------- 检验危急值 ----------
        if req.lab_code:
            lab = await self._get_lab(req.lab_code)
            if lab:
                value = req.values.get(lab.lab_name) or req.values.get(lab.lab_code)
                if value is not None:
                    v = Decimal(str(value))
                    if lab.critical_min is not None and v < lab.critical_min:
                        matched.append({
                            "rule_code": f"{lab.lab_code}_LOW",
                            "rule_name": f"{lab.lab_name} 危急低值",
                            "indicator_name": lab.lab_name,
                            "value": float(v),
                            "operator": "LT",
                            "threshold": float(lab.critical_min),
                            "unit": lab.result_unit,
                            "critical_level": "CRITICAL",
                            "source": "LAB",
                        })
                        notify_targets.update(["开单医生"])
                        notify_channels.update(["SMS", "INBOX"])
                    elif lab.critical_max is not None and v > lab.critical_max:
                        matched.append({
                            "rule_code": f"{lab.lab_code}_HIGH",
                            "rule_name": f"{lab.lab_name} 危急高值",
                            "indicator_name": lab.lab_name,
                            "value": float(v),
                            "operator": "GT",
                            "threshold": float(lab.critical_max),
                            "unit": lab.result_unit,
                            "critical_level": "CRITICAL",
                            "source": "LAB",
                        })
                        notify_targets.update(["开单医生"])
                        notify_channels.update(["SMS", "INBOX"])

        has_critical = bool(matched)
        msg = None
        if has_critical:
            parts = [
                f"{m['indicator_name']} {m['value']} {m.get('unit') or ''}"
                f"（{m['operator']} {m['threshold']}）"
                for m in matched
            ]
            msg = "触发危急值：" + "；".join(parts)

        return {
            "has_critical": has_critical,
            "matched_rules": matched,
            "notify_targets": sorted(notify_targets),
            "notify_channels": sorted(notify_channels),
            "message": msg,
        }

    @staticmethod
    def _match(rule, value: Decimal) -> bool:
        op = rule.operator
        t_min = rule.threshold_min
        t_max = rule.threshold_max

        if op == "GT":
            return t_min is not None and value > t_min
        if op == "LT":
            return t_min is not None and value < t_min
        if op == "GTE":
            return t_min is not None and value >= t_min
        if op == "LTE":
            return t_min is not None and value <= t_min
        if op == "BETWEEN":
            return (t_min is not None and t_max is not None
                    and t_min <= value <= t_max)
        if op == "OUTSIDE":
            return (t_min is not None and t_max is not None
                    and (value < t_min or value > t_max))
        return False

    async def _get_exam(self, code: str) -> Optional[ExamItem]:
        return (await self.db.execute(
            select(ExamItem).where(
                ExamItem.exam_code == code, ExamItem.deleted == False)
        )).scalar_one_or_none()

    async def _get_lab(self, code: str) -> Optional[LabItem]:
        return (await self.db.execute(
            select(LabItem).where(
                LabItem.lab_code == code, LabItem.deleted == False)
        )).scalar_one_or_none()

"""设备服务（含可用性计算）"""
from datetime import date
from typing import Optional

from sqlalchemy import select, and_
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.mdm.clinical import (
    Device, DeviceExamRel, DeviceLabRel, ExamItem, LabItem,
)
from app.core.exceptions import BizException


class DeviceService:
    def __init__(self, db: AsyncSession):
        self.db = db

    async def get_availability(self, device_code: str,
                                target_date: Optional[date] = None) -> dict:
        """设备在某日的可用性"""
        device = (await self.db.execute(
            select(Device).where(
                Device.device_code == device_code, Device.deleted == False)
        )).scalar_one_or_none()
        if not device:
            raise BizException(ErrorCode.NOT_FOUND, f"设备 {device_code} 不存在")

        warnings = []
        if device.calibration_status() == "EXPIRING":
            warnings.append("该设备检定即将到期")
        elif device.calibration_status() == "EXPIRED":
            warnings.append("该设备检定已过期，应停止使用")

        # 已预约量（M12 提供，此处从缓存或 M12 接口获取）
        booked = await self._get_booked_count(device.id, target_date or date.today())
        daily = device.daily_capacity or 0

        return {
            "device_code": device.device_code,
            "device_name": device.device_name,
            "is_available": device.is_available,
            "run_status": device.run_status,
            "calibration_status": device.calibration_status(),
            "daily_capacity": daily,
            "booked_count": booked,
            "remaining_capacity": max(0, daily - booked),
            "single_duration_minutes": device.single_duration_minutes,
            "work_start": "08:00",
            "work_end": "17:30",
            "warnings": warnings,
        }

    async def list_available(self, exam_code: Optional[str],
                              lab_code: Optional[str],
                              target_date: Optional[date]) -> dict:
        """某项目可用的设备清单"""
        if exam_code:
            stmt = (
                select(Device, DeviceExamRel)
                .join(DeviceExamRel, DeviceExamRel.device_id == Device.id)
                .join(ExamItem, ExamItem.id == DeviceExamRel.exam_id)
                .where(ExamItem.exam_code == exam_code, Device.deleted == False)
            )
        elif lab_code:
            stmt = (
                select(Device, DeviceLabRel)
                .join(DeviceLabRel, DeviceLabRel.device_id == Device.id)
                .join(LabItem, LabItem.id == DeviceLabRel.lab_id)
                .where(LabItem.lab_code == lab_code, Device.deleted == False)
            )
        else:
            raise BizException(40001, "必须指定 exam_code 或 lab_code")

        rows = (await self.db.execute(stmt)).all()
        available, unavailable = [], []
        for device, rel in rows:
            if not device.is_available:
                unavailable.append({
                    "device_code": device.device_code,
                    "device_name": device.device_name,
                    "reason": self._unavailable_reason(device),
                })
                continue
            booked = await self._get_booked_count(
                device.id, target_date or date.today())
            daily = device.daily_capacity or 0
            available.append({
                "device_code": device.device_code,
                "device_name": device.device_name,
                "dept_name": device.dept_name,
                "is_primary": bool(rel.is_primary),
                "remaining_capacity": max(0, daily - booked),
                "single_duration_minutes": device.single_duration_minutes,
            })

        return {
            "exam_code": exam_code,
            "lab_code": lab_code,
            "devices": available,
            "unavailable_devices": unavailable,
        }

    @staticmethod
    def _unavailable_reason(device: Device) -> str:
        if device.status != "ENABLED":
            return "设备已停用"
        if device.run_status == "REPAIRING":
            return "维修中"
        if device.run_status == "SCRAPPED":
            return "已报废"
        if not device.is_schedulable:
            return "未开放排程"
        return "不可用"

    async def _get_booked_count(self, device_id: int, d: date) -> int:
        """从 M12 获取已预约量（失败时降级为 0）"""
        from app.core.redis import redis_client
        try:
            val = await redis_client.get(f"m12:device:booked:{device_id}:{d}")
            return int(val) if val else 0
        except Exception:
            return 0

| 组合价 | `is_combo_price=true` → `combo_price` 必填（45021） |

| 项目去重 | 同一组合内项目不可重复 |

### 8.7 标本规则

| 规则 | 说明 |
|---|---|
| 送检时限 | `need_immediate=true` → `delivery_minutes ≤ 30` |
| 冷藏/避光 | 与保存条件一致性校验 |
| 引用保护 | 被检验项目引用时不可删除（45023） |

### 8.8 设备规则

| 规则 | 说明 |
|---|---|
| AE Title 格式 | `^[A-Z0-9_]{1,16}$`（45027） |
| 排程能力 | `is_schedulable=true` → `single_duration_minutes` 必填（默认 15） |
| 维修中不可排程 | `run_status=REPAIRING` → `is_available=false`（45030） |
| 报废不可引用 | `run_status=SCRAPPED` → 不可被检查项目引用（45029） |
| 报废留痕 | 报废必须填日期、原因、审批人、审批单号 |

### 10.3 与 M12/M13 的核心契约

| 接口 | 用途 | SLA |
|---|---|---|
| `GET /internal/v1/clinical/exams/{code}/full-config` | 检查完整配置（含字段/危急值） | P95 ≤ 150ms |
| `GET /internal/v1/clinical/labs/{code}/full-config` | 检验完整配置 | P95 ≤ 150ms |
| `GET /internal/v1/clinical/lab-combos/{code}/items` | 组合项目明细 | P95 ≤ 100ms |
| `GET /internal/v1/clinical/labs/{code}/range` | 按患者取参考区间 | P95 ≤ 80ms |
| `POST /internal/v1/clinical/critical/check` | **危急值判定** | P95 ≤ 60ms |
| `GET /internal/v1/clinical/devices/{code}/availability` | 设备可用性 | P95 ≤ 100ms |
| `GET /internal/v1/clinical/devices/available` | 可用设备清单 | P95 ≤ 200ms |
| `GET /internal/v1/clinical/version` | 版本号 | P95 ≤ 20ms |

**关键约定：**

1. **M12 开检查申请时必须调用 `exams/{code}/full-config`**，获取准备事项、结构化字段、危急值规则。
2. **M13 出检验报告时必须调用 `critical/check`** 判定危急值。
3. **M13 出报告时必须调用 `labs/{code}/range`** 按患者性别年龄取参考区间。
4. **M12 排程时必须调用 `devices/available`** 获取可用设备与剩余产能。
5. **设备状态变更事件必须订阅**：M12 收到 `mdm.device.status.changed` 后立即将相关检查标记为暂不可约。
