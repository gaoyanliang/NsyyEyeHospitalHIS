## 1. 模块概述

### 1.1 模块定位

数据字典是全院系统的**枚举值总线**，系统参数是全院系统的**运行期配置中心**。二者虽数据结构简单，但被 **M01~M23 全部模块**依赖，是耦合度最高、影响面最广的基础设施。

总体设计第 3 章 M01 行明确"字典"为主数据域之一；第 1.2 节边界约定：**M01 提供 `md_sys_param` 的参数定义，M23 负责运行期读写**。本文档在尊重该边界的前提下，补充字典的完整治理能力。

| 职责 | 归属 | 说明 |
|---|---|---|
| 字典类别定义（`md_dict_type`） | **M01 字典子模块（本文档）** | 60+ 内置类别 |
| 字典项定义（`md_dict_item`） | **M01 字典子模块（本文档）** | 3000+ 字典项 |
| 树形字典（行政区划、科室分类） | **M01 字典子模块（本文档）** | parent_id 自关联 |
| 字典缓存与广播 | **M01 字典子模块（本文档）** | Redis 永久缓存 + 主动失效 |
| 字典引用检查 | **M01 字典子模块（本文档）** | 停用/删除前校验 |
| 系统参数**定义**（`md_sys_param`） | **M01 字典子模块（本文档）** | 参数元数据 |
| 系统参数**运行期读写** | **M23 系统管理** | 运行期配置值 |
| 模块级业务参数（如 `MDM.*`） | **M01 字典子模块（本文档）** | 参数分组=M01 |
| 其他模块业务参数（如 `M16.*`） | 各模块定义，M23 托管 | — |
| 业务表单中的下拉选项 | 各业务模块 | 引用字典 |

> **一句话边界**：M01 回答"**有哪些枚举值、每个参数叫什么名字、什么类型、什么范围、默认值是什么**"；M23 回答"**当前参数值是多少、谁改的、什么时候改的**"。

### 1.2 模块目标

- **统一枚举**：消除各模块自建枚举，全系统共用一套字典。
- **零重启生效**：字典变更后主动失效缓存并广播，业务模块下次读取即生效，无需重启。
- **安全可管**：内置字典受保护，参数值强类型校验，越界修改被拒绝。
- **影响可见**：修改字典/参数前可查看引用范围，避免误改。
- **全量审计**：字典与参数的每次变更均留痕，可回溯到人。
- **多环境一致**：支持导出为初始化脚本，保证开发/测试/生产环境字典一致。

### 1.3 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 信息科 | 字典与参数维护 | 维护字典项、参数值 |
| 系统管理员 | 内置字典管理 | 维护内置类别、系统参数 |
| 各模块负责人 | 业务字典申请 | 申请新增字典类别/字典项 |
| 医务科 | 临床类字典审核 | 审核临床字典变更 |
| 审计 | 变更追溯 | 查看变更历史 |
| 开发人员 | 读取字典 | 通过接口/缓存读取 |

## 2. 业务范围与边界

### 2.1 范围内

| 范围 | 说明 |
|---|---|
| 字典类别 | 编码、名称、所属域、是否内置、是否可编辑、是否树形 |
| 字典项 | 编码、名称、别名、拼音、排序、父级、扩展属性、是否默认 |
| 树形字典 | 行政区划、科室分类、ICD 章节等 |
| 字典别名 | 一个字典项多个别名（用于检索） |
| 字典引用登记 | 哪些表/字段引用了某字典 |
| 字典缓存管理 | 缓存刷新、预热 |
| 系统参数定义 | 参数编码、名称、类型、默认值、范围、生效方式 |
| 系统参数作用范围 | 全院/科室/用户三级 |
| 参数变更历史 | 谁在何时改了什么 |

### 2.2 范围外（由其他模块负责）

| 范围外内容 | 负责方 | 说明 |
|---|---|---|
| 参数运行期取值存储与下发 | M23 系统管理 | M01 只提供定义 |
| 参数热更新的推送通道 | M23 | — |
| 业务表本身 | 各模块 | 字典仅被引用 |
| 用户偏好设置 | M23 / M02 | — |
| 系统配置的备份恢复 | M23 | — |
| 日志与审计存储 | M02 / 日志系统 | M01 产生变更记录 |

### 2.3 字典域划分（`domain_code`）

| 域代码 | 域名称 | 典型字典 | 维护方 |
|---|---|---|---|
| `ORG` | 组织人员域 | `DEPT_TYPE`、`TITLE`、`DUTY`、`STAFF_STATUS` | 人事科 |
| `PAT` | 患者域 | `SEX`、`NATION`、`MARITAL_STATUS`、`ID_TYPE`、`BLOOD_TYPE` | 病案室 |
| `MAT` | 物资域 | `DOSAGE_FORM`、`PHARM_CLASS`、`MATERIAL_CLASS`、`WAREHOUSE_TYPE` | 药剂科/设备科 |
| `CLI` | 临床域 | `EXAM_MODALITY`、`EXAM_CATEGORY`、`LAB_CATEGORY`、`SPECIMEN_TYPE`、`SURGERY_LEVEL` | 医务科 |
| `FEE` | 费用域 | `CHARGE_CLASS`、`CHARGE_UNIT`、`PAYMENT_TYPE`、`DISCOUNT_TYPE` | 物价员 |
| `AUTH` | 权限域 | `ROLE_CATEGORY`、`DATA_SCOPE_TYPE` | 信息科 |
| `DICT` | 字典域 | `YES_NO`、`ENABLE_STATUS`、`AUDIT_STATUS` | 信息科 |
| `OPT` | 视光域 | `OPTICAL_BRAND`、`OPTICAL_KIND`、`LENS_COATING` | 视光中心 |

## 3. 字典与参数模型

### 3.1 字典类别模型

#### 3.1.1 字典类别属性

| 属性 | 说明 |
|---|---|
| `code` | 类别编码，大写蛇形，如 `DEPT_TYPE` |
| `name` | 类别名称，如"科室类型" |
| `domain_code` | 所属域（2.3） |
| `is_builtin` | 是否系统内置（内置不可删除） |
| `is_editable` | 是否允许编辑（内置类别编码不可改，仅可增删字典项） |
| `is_tree` | 是否树形字典（有 `parent_id` 层级） |
| `value_type` | 值类型：`STRING` / `INT` / `JSON` |
| `cache_mode` | 缓存模式：`PERMANENT`（永久）/`TTL`（定时） |
| `version` | 版本号（变更时递增，供客户端判断是否过期） |

### 3.3 系统参数模型

#### 3.3.1 参数类型（`param_type`）

| 类型 | 说明 | 校验 | 控件 |
|---|---|---|---|
| `STRING` | 字符串 | 长度/正则 | 输入框 |
| `INTEGER` | 整数 | 最小/最大值 | 数字框 |
| `DECIMAL` | 小数 | 最小/最大/精度 | 数字框 |
| `BOOLEAN` | 布尔 | true/false | 开关 |
| `DATE` | 日期 | 格式 | 日期选择 |
| `DATETIME` | 日期时间 | 格式 | 日期时间选择 |
| `ENUM` | 枚举 | 选项列表 | 下拉 |
| `JSON` | JSON | JSON 解析 | 代码编辑器 |
| `ARRAY` | 数组 | 元素类型 | 标签输入 |

#### 3.3.2 生效方式（`effective_mode`）

| 模式 | 说明 | 典型场景 |
|---|---|---|
| `IMMEDIATE` | 立即生效 | 校验阈值、开关类 |
| `RESTART` | 重启生效 | 连接池大小、日志级别 |
| `NEXT_LOGIN` | 下次登录生效 | 用户级界面配置 |

#### 3.3.3 作用范围（`scope_type`）

| 范围 | 说明 | 存储 |
|---|---|---|
| `GLOBAL` | 全院 | 单值 |
| `DEPT` | 科室级 | `scope_value=dept_id` |
| `USER` | 用户级 | `scope_value=staff_id` |

**优先级：** `USER > DEPT > GLOBAL`

```python
# app/services/mdm/dict_cache_service.py
"""字典缓存服务（核心）"""
import json
from typing import Optional, List

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.mdm.dictionary import DictType, DictItem
from app.core.exceptions import BizException
from app.core.redis import redis_client


class DictCacheService:
    """字典缓存读取与刷新"""

    CACHE_PREFIX = "mdm:dict:"
    VERSION_KEY = "mdm:dict:version"

    def __init__(self, db: AsyncSession):
        self.db = db

    # ---------- 读取 ----------
    async def get_dict(self, type_code: str, only_enabled: bool = True) -> dict:
        """读取字典（优先缓存）"""
        cache_key = f"{self.CACHE_PREFIX}{type_code}"
        raw = await redis_client.get(cache_key)
        if raw:
            cached = json.loads(raw)
            items = [i for i in cached["items"] if i["status"] == "ENABLED"] \
                if only_enabled else cached["items"]
            return {
                "type_code": cached["type_code"],
                "type_name": cached["type_name"],
                "version": cached["version"],
                "cached": True,
                "items": items,
            }

        # 缓存未命中 → 查库并回填
        dtype = await self._load_type(type_code)
        if not dtype:
            raise BizException(46001, f"字典类别 {type_code} 不存在")

        payload = self._build_payload(dtype)
        await self._write_cache(dtype, payload)

        items = [i for i in payload["items"] if i["status"] == "ENABLED"] \
            if only_enabled else payload["items"]
        return {
            "type_code": payload["type_code"],
            "type_name": payload["type_name"],
            "version": payload["version"],
            "cached": False,
            "items": items,
        }

    async def get_dict_map(self, type_code: str) -> dict:
        """读取为 {item_code: item_name}"""
        data = await self.get_dict(type_code, only_enabled=True)
        return {
            "type_code": type_code,
            "version": data["version"],
            "map": {i["item_code"]: i["item_name"] for i in data["items"]},
        }

    async def get_tree(self, type_code: str) -> dict:
        """读取树形字典"""
        data = await self.get_dict(type_code, only_enabled=True)
        flat = data["items"]

        # 按 parent_id 组装
        by_parent = {}
        for item in flat:
            by_parent.setdefault(item.get("parent_id"), []).append(item)

        def build(parent_id):
            nodes = []
            for it in sorted(by_parent.get(parent_id, []),
                              key=lambda x: x.get("sort_no", 999)):
                node = {
                    "id": it["id"],
                    "item_code": it["item_code"],
                    "item_name": it["item_name"],
                    "item_value": it.get("item_value"),
                    "parent_id": it.get("parent_id"),
                    "level": it.get("level", 1),
                    "sort_no": it.get("sort_no", 999),
                    "is_leaf": it.get("is_leaf", True),
                    "ext_json": it.get("ext_json"),
                    "children": build(it["id"]),
                }
                nodes.append(node)
            return nodes

        return {
            "type_code": type_code,
            "type_name": data["type_name"],
            "is_tree": True,
            "version": data["version"],
            "tree": build(None),
        }

    async def batch_get(self, type_codes: List[str],
                         only_enabled: bool = True,
                         as_map: bool = True) -> dict:
        """批量读取多个字典"""
        dicts, missing = {}, []
        for code in type_codes:
            try:
                data = await self.get_dict(code, only_enabled)
                if as_map:
                    dicts[code] = {
                        "version": data["version"],
                        "map": {i["item_code"]: i["item_name"] for i in data["items"]},
                    }
                else:
                    dicts[code] = data
            except BizException:
                missing.append(code)

        ver = await redis_client.get(self.VERSION_KEY) or "0"
        return {
            "version": f"v{ver}",
            "dicts": dicts,
            "missing": missing,
        }

    # ---------- 刷新 ----------
    async def refresh(self, type_codes: Optional[List[str]],
                       rebuild: bool = False, operator=None) -> dict:
        """刷新缓存"""
        if type_codes:
            types = []
            for code in type_codes:
                dt = await self._load_type(code)
                if dt:
                    types.append(dt)
        else:
            types = (await self.db.execute(
                select(DictType).where(
                    DictType.status == "ENABLED",
                    DictType.deleted == False)
            )).scalars().all()

        affected_keys = 0
        details = []
        for dt in types:
            try:
                if rebuild:
                    await redis_client.delete(f"{self.CACHE_PREFIX}{dt.code}")
                payload = self._build_payload(dt, await self._load_items(dt.id))
                await self._write_cache(dt, payload)
                affected_keys += 1
                details.append({
                    "type_code": dt.code,
                    "status": "SUCCESS",
                    "item_count": len(payload["items"]),
                })
            except Exception as e:
                details.append({
                    "type_code": dt.code,
                    "status": "FAILED",
                    "error": str(e)[:200],
                })

        # 提升全局版本号
        await redis_client.incr(self.VERSION_KEY)

        return {
            "task_type": "REFRESH_TYPE" if type_codes else "REFRESH_ALL",
            "affected_types": len(types),
            "affected_keys": affected_keys,
            "details": details,
        }

    # ---------- 内部 ----------
    async def _load_type(self, code: str) -> Optional[DictType]:
        return (await self.db.execute(
            select(DictType).where(
                DictType.code == code, DictType.deleted == False)
        )).scalar_one_or_none()

    async def _load_items(self, type_id: int) -> List[DictItem]:
        return (await self.db.execute(
            select(DictItem)
            .where(DictItem.type_id == type_id, DictItem.deleted == False)
            .order_by(DictItem.sort_no.asc())
        )).scalars().all()

    def _build_payload(self, dtype: DictType,
                        items: Optional[List[DictItem]] = None) -> dict:
        if items is None:
            items = []   # 由调用方预先加载
        return {
            "type_code": dtype.code,
            "type_name": dtype.name,
            "version": dtype.version,
            "is_tree": bool(dtype.is_tree),
            "items": [
                {
                    "id": i.id,
                    "item_code": i.item_code,
                    "item_name": i.item_name,
                    "item_value": i.item_value,
                    "parent_id": i.parent_id,
                    "level": i.level,
                    "is_leaf": bool(i.is_leaf),
                    "sort_no": i.sort_no,
                    "ext_json": i.ext_json,
                    "is_default": bool(i.is_default),
                    "status": i.status,
                }
                for i in items
            ],
        }

    async def _write_cache(self, dtype: DictType, payload: dict) -> None:
        key = f"{self.CACHE_PREFIX}{dtype.code}"
        ttl = -1 if dtype.cache_mode == "PERMANENT" else (dtype.cache_ttl or 1800)
        await redis_client.set(key, json.dumps(payload, ensure_ascii=False),
                                ex=None if ttl == -1 else ttl)

    async def get_version(self) -> dict:
        ver = await redis_client.get(self.VERSION_KEY) or "0"
        return {"version": f"v{ver}"}
```

```python
# app/services/mdm/param_service.py
"""系统参数服务（含作用域解析）"""
import json
from decimal import Decimal
from typing import Optional, List

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.mdm.dictionary import SysParam, SysParamScope, SysParamHistory
from app.core.exceptions import BizException
from app.core.redis import redis_client


class ParamService:
    def __init__(self, db: AsyncSession):
        self.db = db

    # ---------- 读取与解析 ----------
    async def resolve(self, param_code: str,
                       staff_id: Optional[int] = None,
                       dept_id: Optional[int] = None) -> dict:
        """按优先级解析参数值：USER > DEPT > GLOBAL > DEFAULT"""
        param = await self._get_param(param_code)
        if not param:
            raise BizException(46013, f"参数 {param_code} 不存在")

        value, source = param.default_value, "DEFAULT"

        # GLOBAL
        if param.param_value is not None:
            value, source = param.param_value, "GLOBAL"

        # DEPT（scope_type=DEPT 或参数本身支持 DEPT）
        if dept_id is not None:
            scope = await self._get_scope(param.id, "DEPT", str(dept_id))
            if scope and scope.is_enabled and scope.param_value is not None:
                value, source = scope.param_value, "DEPT"

        # USER 优先级最高
        if staff_id is not None:
            scope = await self._get_scope(param.id, "USER", str(staff_id))
            if scope and scope.is_enabled and scope.param_value is not None:
                value, source = scope.param_value, "USER"

        if param.is_sensitive and not param.is_business_editable:
            raw = "******"
        else:
            raw = value

        return {
            "param_code": param.param_code,
            "param_name": param.param_name,
            "param_type": param.param_type,
            "value": param.cast_value(value),
            "raw_value": raw,
            "source": source,
            "unit": param.unit,
        }

    async def batch_resolve(self, param_codes: List[str],
                             staff_id: Optional[int] = None,
                             dept_id: Optional[int] = None) -> dict:
        """批量解析"""
        params, missing = {}, []
        for code in param_codes:
            try:
                r = await self.resolve(code, staff_id, dept_id)
                params[code] = {
                    "value": r["value"],
                    "source": r["source"],
                    "param_type": r["param_type"],
                }
            except BizException:
                missing.append(code)
        return {"params": params, "missing": missing}

    # ---------- 更新 ----------
    async def update_value(self, param_code: str, payload,
                            operator, ip: Optional[str] = None) -> dict:
        """更新参数值（含校验与审计）"""
        param = await self._get_param(param_code)
        if not param:
            raise BizException(46013, f"参数 {param_code} 不存在")
        if param.is_system and not param.is_business_editable:
            raise BizException(46021, "该参数不允许业务方修改")

        if param.version != payload.version:
            raise BizException(46026, "参数已被他人修改，请刷新后重试")

        # 类型与范围校验
        self._validate_value(param, payload.param_value)

        old_value = param.param_value
        param.param_value = payload.param_value
        param.version += 1

        self.db.add(SysParamHistory(
            param_id=param.id, param_code=param.param_code,
            param_group=param.param_group, change_type="UPDATE",
            scope_type="GLOBAL", old_value=old_value,
            new_value=payload.param_value,
            change_reason=payload.change_reason,
            operator_id=operator.id, operator_name=operator.name,
            operator_ip=ip,
        ))
        await self.db.commit()

        # 失效缓存
        await redis_client.delete(f"mdm:param:{param_code}")

        return {
            "param_code": param.param_code,
            "old_value": old_value,
            "new_value": payload.param_value,
            "effective_mode": param.effective_mode,
            "cache_refreshed": True,
            "version": param.version,
        }

    @staticmethod
    def _validate_value(param: SysParam, raw: Optional[str]) -> None:
        """按类型校验参数值"""
        if raw is None or raw == "":
            return
        t = param.param_type

        if t == "BOOLEAN":
            if str(raw).lower() not in ("true", "false", "1", "0"):
                raise BizException(46016, "参数值必须为 true 或 false")

        elif t == "INTEGER":
            try:
                v = int(raw)
            except ValueError:
                raise BizException(46016, "参数值必须为整数")
            SysParamService._check_range(param, v)

        elif t == "DECIMAL":
            try:
                v = Decimal(raw)
            except Exception:
                raise BizException(46016, "参数值必须为数值")
            SysParamService._check_range(param, v)

        elif t == "JSON":
            try:
                json.loads(raw)
            except json.JSONDecodeError:
                raise BizException(46016, "参数值必须为合法 JSON")

        elif t == "ARRAY":
            try:
                arr = json.loads(raw)
                if not isinstance(arr, list):
                    raise ValueError
            except Exception:
                raise BizException(46016, "参数值必须为 JSON 数组")

        elif t == "ENUM":
            options = [o.get("value") for o in (param.enum_options or [])]
            if raw not in options:
                raise BizException(46016, f"参数值必须是 {options} 之一")

        else:  # STRING
            if param.max_length and len(raw) > param.max_length:
                raise BizException(46017, f"参数值长度不能超过 {param.max_length}")
            if param.value_pattern:
                import re
                if not re.match(param.value_pattern, raw):
                    raise BizException(46018, "参数值不匹配校验规则")

    @staticmethod
    def _check_range(param: SysParam, v) -> None:
        if param.min_value is not None and v < param.min_value:
            raise BizException(
                46017, f"参数值不能小于 {param.min_value}",
                data={"min_value": float(param.min_value),
                      "max_value": float(param.max_value) if param.max_value else None})
        if param.max_value is not None and v > param.max_value:
            raise BizException(
                46017, f"参数值不能大于 {param.max_value}",
                data={"min_value": float(param.min_value) if param.min_value else None,
                      "max_value": float(param.max_value)})

    async def _get_param(self, code: str) -> Optional[SysParam]:
        return (await self.db.execute(
            select(SysParam).where(
                SysParam.param_code == code, SysParam.deleted == False)
        )).scalar_one_or_none()

    async def _get_scope(self, param_id: int, scope_type: str,
                          scope_value: str) -> Optional[SysParamScope]:
        return (await self.db.execute(
            select(SysParamScope).where(
                SysParamScope.param_id == param_id,
                SysParamScope.scope_type == scope_type,
                SysParamScope.scope_value == scope_value,
                SysParamScope.deleted == False)
        )).scalar_one_or_none()
```

```python
    """预热全部字典缓存"""

    """异步刷新字典项引用计数"""
    import asyncio
    return asyncio.run(_refresh_ref_count())


async def _refresh_ref_count():
    """扫描 md_dict_ref 统计各字典项引用情况"""
    from sqlalchemy import select, func
    from app.models.mdm.dictionary import DictItem, DictRef
    from app.core.database import AsyncSessionLocal

    async with AsyncSessionLocal() as db:
        rows = (await db.execute(
            select(DictRef.item_code, DictRef.type_code,
                   func.count().label("cnt"))
            .where(DictRef.item_code.isnot(None), DictRef.is_active == True)
            .group_by(DictRef.item_code, DictRef.type_code)

                DictItem.__table__.update()
                .where(DictItem.type_code == type_code,
                       DictItem.item_code == item_code)
                .values(ref_count=cnt)
            )
        await db.commit()
        return {"updated": len(rows)}
```

```python
"""字典定时任务"""
from apscheduler.schedulers.asyncio import AsyncIOScheduler
from apscheduler.triggers.cron import CronTrigger

scheduler = AsyncIOScheduler(timezone="Asia/Shanghai")

scheduler.add_job(
    audit_dict_cache,
    CronTrigger(hour=7, minute=0),
    id="job_dict_cache_audit",
    name="字典缓存完整性检查",
    replace_existing=True,
)


async def audit_dict_cache():
    """检查缓存完整性，缺失或版本落后的字典自动重建"""
    import json
    from sqlalchemy import select
    from app.models.mdm.dictionary import DictType
    from app.core.database import AsyncSessionLocal
    from app.core.redis import redis_client
    from app.services.mdm.dict_cache_service import DictCacheService

    async with AsyncSessionLocal() as db:
        types = (await db.execute(
            select(DictType).where(
                DictType.status == "ENABLED",
                DictType.deleted == False)
        )).scalars().all()

        svc = DictCacheService(db)
        missing = []
        for dt in types:
            raw = await redis_client.get(f"mdm:dict:{dt.code}")
            if not raw:
                missing.append(dt.code)
                continue
            cached = json.loads(raw)
            if cached.get("version") != dt.version:
                missing.append(dt.code)

        if missing:
            await svc.refresh(missing, rebuild=True)
            # 记录并告警
            from app.services.notify_service import NotifyService
            await NotifyService().send(
                template="DICT_CACHE_REBUILT",
                receivers=await get_it_managers(),
                params={"count": len(missing), "types": missing[:20]},
            )
```

## 8. 业务规则与校验

### 8.1 字典类别规则

| 规则 | 说明 |
|---|---|
| 编码格式 | `^[A-Z][A-Z0-9_]{1,63}$`（大写蛇形），否则 46002 |
| 编码唯一 | 全局唯一，否则 46001 |
| 内置保护 | `is_builtin=true` 不可删除（46003），编码不可改（46004） |
| 可编辑 | `is_editable=false` 时仅可增删字典项，不可改类别属性 |
| 树形层级 | `is_tree=true` → `max_level` 默认 3，超限阻止（46010） |
| 缓存模式 | `TTL` 模式必须设置 `cache_ttl` |
| 版本递增 | 任何字典项变更都会使类别 `version+1` |
| 引用保护 | 有字典项时不可删除（46005） |

### 8.2 字典项规则

| 规则 | 说明 |
|---|---|
| 编码格式 | `^[A-Za-z0-9_\-]{1,64}$` |
| 编码唯一 | 同类别内唯一（46006） |
| 名称 | 1~200 字 |
| 树形父级 | 必须存在（46009），且同类别（46011） |
| 层级计算 | `level = parent.level + 1`，`path = parent.path + id + '/'` |
| 叶子标识 | 有子节点时 `is_leaf=false`（自动维护） |
| 默认项 | 同类别可多个默认，但建议仅一个 |
| 扩展属性 | 必须是合法 JSON（46012） |
| 引用保护 | 被业务引用时不可删除（46007） |
| 停用 | 允许，提示影响（46008 为警告非阻止） |

### 8.3 系统参数规则

| 规则 | 说明 |
|---|---|
| 编码格式 | `^[A-Z][A-Z0-9]*(\.[A-Z][A-Z0-9_]*){1,4}$`（如 `MDM.CODE.AUTO_GENERATE`），否则 46014 |

### 10.3 全院读取契约

| 接口 | 用途 | SLA |
|---|---|---|
| `GET /internal/v1/dict/{type_code}` | 读取字典（含全量项） | P95 ≤ 30ms |
| `GET /internal/v1/dict/{type_code}/map` | 读取为 Map（显示用） | P95 ≤ 30ms |
| `GET /internal/v1/dict/{type_code}/tree` | 读取树形字典 | P95 ≤ 50ms |

| `GET /internal/v1/param/{code}` | 读取参数（含作用域） | P95 ≤ 20ms |
| `POST /internal/v1/param/batch` | 批量读取参数 | P95 ≤ 40ms |
| `GET /internal/v1/dict/version` | 字典版本号 | P95 ≤ 10ms |

**关键约定：**

1. **业务模块首次启动时调用 `dict/batch` 批量拉取所需字典**，本地缓存。
2. **业务模块必须订阅 `mdm.dict.item.changed` 事件**，收到后刷新本地缓存。
3. **禁止业务模块直接查 `md_dict_item` 表**，必须走内部接口。
4. **参数读取必须传 `staff_id`/`dept_id`**，否则无法解析作用域覆盖。
5. **字典版本号可用于判断本地缓存是否过期**。
6. **高频字典（如 YES_NO、SEX）建议业务侧做进程内一级缓存** + Redis 二级缓存。

## 11. 异常处理与日志

### 11.1 异常分类

| 类型 | 示例 | 处理 |
|---|---|---|
| 参数异常 | 编码格式、值类型不符、超范围 | 40001 + 字段级错误 |
| 业务异常 | 编码重复、引用保护、内置保护 | 对应业务码 |
| 并发异常 | 乐观锁冲突、缓存刷新锁 | 46026 + 提示刷新 |
| 缓存异常 | Redis 不可用 | 降级直连 DB |
| 依赖异常 | MQ 不可用 | 事件落库 PENDING |
| 系统异常 | DB 失败 | 50000 + 错误日志 |

**降级策略：**

| 依赖 | 不可用时 |
|---|---|
| **Redis** | **直连 DB 读取**（性能下降但功能可用），并告警 |
| MQ | 事件落库 PENDING，恢复后补投；版本号轮询兜底 |
| 缓存刷新锁 | 跳过锁直接刷新（可能并发，但有幂等保护） |

### 11.2 日志规范

```json
{
  "timestamp": "2026-04-01T10:23:45.123+08:00",
  "level": "INFO",
  "logger": "app.services.mdm.param_service",
  "trace_id": "3f2a1b9c",
  "user_id": 1001,
  "user_name": "信息科张明",
  "action": "PARAM_UPDATE",
  "target": { "param_code": "MDM.EXPORT.MAX_ROWS" },
  "old_value": "50000",
  "new_value": "100000",
  "result": "success",
  "cost_ms": 12,
  "message": "参数值已更新并刷新缓存"
}
```

**日志级别：**
- `INFO`：正常读取、更新成功
- `WARNING`：缓存未命中、字典不存在、已停用
- `ERROR`：校验失败、更新失败
- `CRITICAL`：Redis/DB 不可用
