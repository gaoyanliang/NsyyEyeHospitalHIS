## 1. 模块概述

### 1.1 模块定位

本子模块是 M01 的**收尾补充**，覆盖两块内容：

1. **组织辅助主数据**（M01-01 剩余部分）：病区与床位类型、仓库、职称、职务、执业资质与证书。
2. **患者主索引只读视图**（M01-09）：`md_patient` 同步表 + 只读查询能力，**写入权归 M03**。

| 职责 | 归属 | 说明 |
|---|---|---|
| 病区（`md_ward`） | **M01 本子模块（本文档）** | 住院病区定义 |
| 床位类型（`md_bed_type`） | **M01 本子模块（本文档）** | 普通/加床/监护/日间 |
| 仓库（`md_warehouse`） | **M01 本子模块（本文档）** | 药房/药库/耗材库 |
| 职称（`md_title`） | **M01 本子模块（本文档）** | 正高/副高/中级/初级 |
| 职务（`md_duty`） | **M01 本子模块（本文档）** | 院长/科主任/护士长 |
| 执业资质与证书（`md_staff_cert`） | **M01 本子模块（本文档）** | 医师执业证等 |
| **患者主索引同步表（`md_patient`）** | **M01 只读持有 / M03 写入** | 关键边界 |
| 床位明细（具体床位号） | **M05 住院管理** | — |
| 在院患者 | **M05** | — |
| 库存与出入库 | **M14/M15** | — |
| 职工主数据 | M01 职工子模块 | 本文档只引用 |
| 患者建档、匹配、合并 | **M03 患者服务** | **写入权归 M03** |

> **一句话边界**：M01 回答"**有哪些病区/仓库/职称/职务、职工有哪些证书、患者是谁**"；M03 回答"**患者怎么建档/匹配/合并**"；M05 回答"**患者住哪个床**"。

### 1.2 为什么 M01 持有患者同步表

M01 持有 `md_patient` 的**只读副本**，目的是：

1. **解耦**：M04/M05/M07/M12/M16 等模块可通过统一的 `/api/v1/mdm/patients/*` 查询患者，**不必直连 M03 库**。
2. **性能**：主数据查询走 M01 缓存，避免患者高频查询压垮 M03。
3. **一致性**：由 M03 单向同步，M01 只做只读镜像。

**关键约束：**
- M01 **不提供任何患者写接口**。
- 尝试写返回 `40300 患者主数据由 M03 患者服务模块维护`。
- 同步延迟 >30 分钟时页面显示告警。

### 1.3 关键业务角色

| 角色 | 职责 | 主要操作 |
|---|---|---|
| 人事科 | 职称职务、执业资质 | 维护职称/职务、录入证书 |
| 护理部 | 病区与床位类型 | 维护病区、床位类型 |
| 药剂科 | 药房仓库 | 维护仓库 |
| 设备科 | 耗材库 | 维护仓库 |
| 医务科 | 执业资质审核 | 审核医师证书 |
| 临床/收费 | 患者查询 | 只读查询患者 |
| 信息科 | 同步监控 | 查看同步状态、手动重同步 |

## 3. 组织与患者模型

### 3.1 病区与床位类型模型

#### 3.1.1 病区（`md_ward`）

| 属性 | 说明 |
|---|---|
| 编码 | `W` + 流水 |
| 所属科室 | 必须关联有效科室 |
| 床位数 | 该病区规划床位数 |
| 是否日间病区 | 日间手术（M06）专用 |
| 护士长 | 职工引用 |

**日间病区特殊性：**
- `is_day_ward=true` 时，床位类型必须含"日间观察床"。
- 日间病区不参与住院床位占用率统计（M05 单独统计）。

#### 3.1.2 床位类型（`md_bed_type`）

| 代码 | 名称 | 说明 | 床位费 |
|---|---|---|---|
| `NORMAL` | 普通床 | 标准住院床位 | 有 |
| `EXTRA` | 加床 | 走廊/临时加床 | 有（低价） |
| `ICU` | 监护床 | 重症监护 | 有（高价） |
| `DAY_OBSERVE` | 日间观察床 | 日间手术用 | 有 |
| `OBSERVE` | 留观床 | 急诊留观 | 有 |

**床位费关联：** 每种床位类型关联一个收费项目（M01 收费子模块），M16 按天计费。

### 3.2 仓库模型

#### 3.2.1 仓库类型（`warehouse_type`）

| 代码 | 名称 | 是否零售 | 成本核算 | 说明 |
|---|---|---|---|---|
| `DRUG_STORE` | 药库 | 否 | 是 | 药品总库 |
| `DRUG_PHARMACY` | 西药房 | **是** | 是 | 门诊发药 |
| `TCM_PHARMACY` | 中药房 | 是 | 是 | — |
| `MATERIAL_STORE` | 耗材库 | 否 | 是 | 耗材总库 |
| `OPTICAL_STORE` | 视光成品库 | 是 | 是 | 镜架成品 |
| `OPTICAL_LENS_STORE` | 视光镜片库 | 是 | 是 | 镜片 |
| `HIGH_VALUE_CABINET` | 高值耗材柜 | 否 | 是 | 人工晶体等 |
| `OR_SUB_STORE` | 手术室二级库 | 否 | 是 | 手术室用 |

#### 3.2.2 成本核算方法（`cost_method`）

| 代码 | 名称 | 适用 |
|---|---|---|
| `FIFO` | 先进先出 | 效期敏感（药品） |
| `WEIGHTED_AVG` | 加权平均 | 通用 |
| `SPECIFIC` | 个别计价 | 高值耗材（人工晶体） |

**联动规则：**
- `warehouse_type=HIGH_VALUE_CABINET` → 强制 `is_cost_account=true` + `cost_method=SPECIFIC`。
- `is_retail=true` → 必须 `is_cost_account=true`（零售仓参与成本）。

### 3.3 职称与职务模型

#### 3.3.1 职称（`md_title`）

| 级别 | 代码 | 名称 | 是否医师 | 对应手术权限 |
|---|---|---|---|---|
| 正高 | `SENIOR` | 主任医师 | 是 | 四级 |
| 副高 | `ASSOCIATE_SENIOR` | 副主任医师 | 是 | 三级 |
| 中级 | `INTERMEDIATE` | 主治医师 | 是 | 二级 |
| 初级 | `JUNIOR` | 住院医师 | 是 | 一级 |
| 无 | `NONE` | 医士/无职称 | 是 | 一级 |

**职称系列（`title_series`）：** 医/护/技/药/视光/管理。

**与手术权限的联动：** 职称级别决定 M01 手术子模块的默认手术级别上限（见手术子模块 3.4.1）。

#### 3.3.2 职务（`md_duty`）

| 类别 | 代码 | 名称 | 是否科主任级 |
|---|---|---|---|
| 行政 | `PRESIDENT` | 院长 | 否 |
| 行政 | `VICE_PRESIDENT` | 副院长 | 否 |
| 业务 | `DEPT_HEAD` | 科主任 | **是** |
| 业务 | `DEPUTY_DEPT_HEAD` | 副主任 | 是 |
| 业务 | `HEAD_NURSE` | 护士长 | 是 |
| 业务 | `DEPUTY_HEAD_NURSE` | 副护士长 | 否 |
| 党务 | `PARTY_SECRETARY` | 党支部书记 | 否 |

**科主任级联动：** `is_dept_head=true` 的职务在审批链中可作为 `DEPT_LEADER` 解析来源。

### 3.4 执业资质与证书模型

#### 3.4.1 证书类型（`cert_type`）

| 代码 | 名称 | 是否必需 | 到期影响 |
|---|---|---|---|
| `PHYSICIAN_QUALIFY` | 医师资格证 | 医师必需 | 不可执业 |
| `PHYSICIAN_PRACTICE` | 医师执业证 | 医师必需 | **不可开处方** |
| `NURSE_PRACTICE` | 护士执业证 | 护士必需 | 不可执行护理 |
| `TITLE_CERT` | 职称证 | 否 | 影响手术权限 |
| `LARGE_EQUIPMENT` | 大型设备上岗证 | 操作技师必需 | 不可操作设备 |
| `OPTOMETRIST` | 验光师证 | 视光师必需 | 不可验光 |
| `ORTHO_K_FIT` | OK 镜验配证 | OK 镜验配师必需 | 不可验配 OK 镜 |
| `REFRACTIVE_TRAINING` | 屈光手术培训证 | 屈光医师必需 | 不可做屈光手术 |
| `INFECTION_TRAINING` | 院感培训证 | 否 | — |
| `OTHER` | 其他 | 否 | — |

#### 3.4.2 证书状态

| 状态 | 判定 | 显示 |
|---|---|---|
| `VALID` | 有效期至 > 今天 + 60 天 | 绿 |
| `EXPIRING` | 今天 < 有效期至 ≤ 今天 + 60 天 | 橙 |
| `EXPIRED` | 有效期至 < 今天 | 红 |
| `REVOKED` | 已注销 | 灰 |

**长期有效：** `is_long_term=true` 时 `expire_date` 可为空，状态恒为 `VALID`。

#### 3.4.3 证书到期提醒

| 节点 | 提醒对象 | 方式 |
|---|---|---|
| 60 天前 | HR + 本人 | 站内信 |
| 30 天前 | HR + 本人 + 科室负责人 | 站内信 + 短信 |
| 7 天前 | HR + 本人 + 科室负责人 + 医务科 | 站内信 + 短信 |
| 到期日 | HR + 本人 + 科室负责人 + 医务科 | 站内信 + 短信 |
| 到期后每日 | 医务科 | 站内信 |

| 字段 | 存储 | 展示 | 明文获取 |
|---|---|---|---|

| 地址 | 明文 | 完整 | — |
| 过敏史 | 明文 | 完整（安全需要） | — |

#### 3.5.3 同步机制

```
M03 患者变更
   ↓
M03 发布 mdm.patient.changed 事件（或定时批量推送）
   ↓
M01 接收并写入 md_patient（upsert by empi_id）
   ↓
更新 synced_at / sync_version
   ↓
刷新 M01 患者缓存
```

**同步方式：**

| 方式 | 说明 | 频率 |
|---|---|---|
| 事件驱动 | M03 变更时实时推送 | 实时 |
| 批量同步 | 每日 03:00 全量比对 | 每日 |
| 手动同步 | 管理员触发 | 按需 |

# app/api/v1/mdm/org_support.py
"""组织辅助与患者索引 REST 接口"""
from typing import Optional, List
from fastapi import APIRouter, Depends, Query, Body, Request, HTTPException
from sqlalchemy.ext.asyncio import AsyncSession

from app.core.database import get_db
from app.core.response import success_response, PageResult, error_response
from app.core.security import get_current_user, require_permission
from app.schemas.mdm.org_support import (
    WardCreate, WardUpdate, WardQuery,
    BedTypeCreate, BedTypeUpdate,
    WarehouseCreate, WarehouseUpdate, WarehouseQuery,
    TitleCreate, TitleUpdate, DutyCreate, DutyUpdate,
    StaffCertCreate, StaffCertUpdate, StaffCertQuery,
    PatientQuery, PatientSyncRequest,
)
from app.services.mdm.ward_service import WardService
from app.services.mdm.warehouse_service import WarehouseService
from app.services.mdm.title_service import TitleService
from app.services.mdm.cert_service import CertService
from app.services.mdm.patient_service import PatientService

router = APIRouter(prefix="/api/v1/mdm", tags=["MDM-组织辅助与患者"])
internal_router = APIRouter(prefix="/internal/v1/mdm", tags=["MDM-组织辅助内部接口"])


# ==================== 病区 ====================
@router.get("/wards", summary="病区分页")
async def list_wards(
    keyword: Optional[str] = Query(None),
    dept_id: Optional[int] = Query(None),
    is_day_ward: Optional[bool] = Query(None),
    status: Optional[str] = Query(None),
    page: int = Query(1, ge=1),
    page_size: int = Query(20, ge=1, le=200),
    db: AsyncSession = Depends(get_db),
    user=Depends(require_permission("mdm:ward:list")),
):
    svc = WardService(db)
    q = WardQuery(
        keyword=keyword, dept_id=dept_id, is_day_ward=is_day_ward,
        status=status.split(",") if status else None,
        page=page, page_size=page_size)
    items, total = await svc.list_wards(q)
    return success_response(PageResult(
        items=items, total=total, page=page, page_size=page_size,
        pages=(total + page_size - 1) // page_size))


@router.post("/wards", summary="新增病区")
async def create_ward(
    payload: WardCreate,
    request: Request,
    db: AsyncSession = Depends(get_db),
    user=Depends(require_permission("mdm:ward:update")),
):
    svc = WardService(db)
    data = await svc.create(payload, operator=user, ip=request.client.host)
    return success_response(data)


@router.patch("/wards/{ward_id}/status", summary="启停病区")
async def change_ward_status(
    ward_id: int,
    new_status: str = Body(..., embed=True, alias="status"),
    db: AsyncSession = Depends(get_db),
    user=Depends(require_permission("mdm:ward:update")),
):
    svc = WardService(db)
    data = await svc.change_status(ward_id, new_status, operator=user)
    return success_response(data)


# ==================== 仓库 ====================
@router.get("/warehouses", summary="仓库分页")
async def list_warehouses(
    keyword: Optional[str] = Query(None),
    warehouse_type: Optional[str] = Query(None),
    dept_id: Optional[int] = Query(None),
    is_retail: Optional[bool] = Query(None),
    page: int = Query(1, ge=1),
    page_size: int = Query(20, ge=1, le=200),
    db: AsyncSession = Depends(get_db),
    user=Depends(require_permission("mdm:warehouse:list")),
):
    svc = WarehouseService(db)
    q = WarehouseQuery(
        keyword=keyword,
        warehouse_type=warehouse_type.split(",") if warehouse_type else None,
        dept_id=dept_id, is_retail=is_retail,
        page=page, page_size=page_size)

"""证书服务（含执业校验与到期提醒）"""
from datetime import date, timedelta
from typing import Optional, List

from sqlalchemy import select, and_, func
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.mdm.org_support import StaffCert, Title
from app.models.mdm.staff import Staff
from app.core.exceptions import BizException


class CertService:
    def __init__(self, db: AsyncSession):
        self.db = db

    # ---------- 执业资格校验（M07 核心调用） ----------
    async def check_practice(self, staff_id: int) -> dict:
        """校验医师执业资格"""
        staff = (await self.db.execute(
            select(Staff).where(Staff.id == staff_id, Staff.is_deleted == False)
        )).scalar_one_or_none()
        if not staff:
            raise BizException("0113033", f"职工 {staff_id} 不存在")

        # 查执业证
        cert = (await self.db.execute(
            select(StaffCert).where(
                StaffCert.staff_id == staff_id,
                StaffCert.cert_type == "PHYSICIAN_PRACTICE",
                StaffCert.is_deleted == False,
                StaffCert.status == "ENABLED",
            ).order_by(StaffCert.expire_date.desc().nullslast())
        )).scalars().first()

        if not cert:
            return {
                "staff_id": staff_id,
                "staff_name": staff.name,
                "can_prescribe": False,
                "practice_valid": False,
                "practice_cert_no": None,
                "practice_expire": None,
                "reason": "该医师无医师执业证记录，不可开处方",
            }

        status = cert.compute_status()
        valid = status == "VALID"

        # 同时校验职称是否可开处方
        title = (await self.db.execute(
            select(Title).where(Title.code == staff.title_code)
        )).scalar_one_or_none() if getattr(staff, "title_code", None) else None

        can_prescribe = valid and (title.can_prescribe if title else True)

        reason = None
        if not valid:
            if status == "EXPIRED":
                reason = f"医师执业证已于 {cert.expire_date} 过期，不可开处方"
            elif status == "REVOKED":
                reason = "医师执业证已注销，不可开处方"
            else:
                reason = f"医师执业证状态异常（{status}），不可开处方"
        elif title and not title.can_prescribe:
            reason = f"该职称（{title.name}）无处方权"
            can_prescribe = False

        return {
            "staff_id": staff_id,
            "staff_name": staff.name,
            "can_prescribe": can_prescribe,
            "practice_valid": valid,
            "practice_cert_no": cert.cert_no,
            "practice_expire": cert.expire_date.isoformat() if cert.expire_date else None,
            "reason": reason,
        }

    # ---------- 到期看板 ----------
    async def get_expiring_dashboard(self, days: int = 60) -> dict:
        """证书到期看板"""
        today = date.today()

        stmt = (
            select(StaffCert)
            .where(
                StaffCert.is_deleted == False,
                StaffCert.status == "ENABLED",
                StaffCert.cert_status != "REVOKED",
            )
        )
        certs = (await self.db.execute(stmt)).scalars().all()

        expired, within_7, within_30, within_60 = [], [], [], []
        for c in certs:
            st = c.compute_status()
            d = c.days_to_expire()
            item = {
                "cert_id": c.id,
                "staff_id": c.staff_id,
                "staff_no": c.staff_no,
                "staff_name": c.staff_name,
                "cert_type": c.cert_type,
                "cert_type_name": c.cert_type_name,
                "cert_no": c.cert_no,
                "expire_date": c.expire_date.isoformat() if c.expire_date else None,
                "days_left": d,
                "cert_status": st,
                "impact": self._impact_text(c.cert_type),
            }
            if st == "EXPIRED":
                expired.append(item)
            elif d is not None:
                if d <= 7:
                    within_7.append(item)
                elif d <= 30:
                    within_30.append(item)
                elif d <= 60:
                    within_60.append(item)

        # 统计影响
        restricted = {"cannot_prescribe": 0, "cannot_execute_nursing": 0,
                      "cannot_operate_equipment": 0}
        staff_set = set()
        for it in expired:
            staff_set.add(it["staff_id"])
            if it["cert_type"] == "PHYSICIAN_PRACTICE":
                restricted["cannot_prescribe"] += 1
            elif it["cert_type"] == "NURSE_PRACTICE":
                restricted["cannot_execute_nursing"] += 1
            elif it["cert_type"] == "LARGE_EQUIPMENT":
                restricted["cannot_operate_equipment"] += 1

        return {
            "expired_count": len(expired),
            "within_7_days": len(within_7),
            "within_30_days": len(within_30),
            "within_60_days": len(within_60),
            "expired": expired[:50],
            "expiring_7": within_7[:50],
            "expiring_30": within_30[:50],
            "expiring_60": within_60[:50],
            "impact_summary": {
                "restricted_staff_count": len(staff_set),
                **restricted,
            },
        }

    @staticmethod
    def _impact_text(cert_type: str) -> str:
        return {
            "PHYSICIAN_PRACTICE": "不可开处方",
            "NURSE_PRACTICE": "不可执行护理",
            "LARGE_EQUIPMENT": "不可操作设备",
            "ORTHO_K_FIT": "不可验配OK镜",
            "REFRACTIVE_TRAINING": "不可做屈光手术",
        }.get(cert_type, "")

    # ---------- 新增证书 ----------
    async def create(self, payload, operator) -> dict:
        """新增证书"""
        # 唯一性
        exist = (await self.db.execute(
            select(StaffCert).where(
                StaffCert.staff_id == payload.staff_id,
                StaffCert.cert_type == payload.cert_type,
                StaffCert.cert_no == payload.cert_no,
                StaffCert.is_deleted == False)
        )).scalar_one_or_none()
        if exist:
            raise BizException("0113028", "该职工的此证书编号已存在")

        cert = StaffCert(
            staff_id=payload.staff_id,
            cert_type=payload.cert_type,
            cert_no=payload.cert_no,
            issuing_authority=payload.issuing_authority,
            issue_date=payload.issue_date,
            expire_date=payload.expire_date,
            is_long_term=payload.is_long_term,
            practice_scope=payload.practice_scope,
            practice_location=payload.practice_location,
            attachment_ids=",".join(map(str, payload.attachment_ids or [])),
            is_required_cert=payload.is_required_cert,
            remark=payload.remark,
            created_by=operator.id,
        )
        # 计算状态
        cert.cert_status = cert.compute_status()

        self.db.add(cert)
        await self.db.commit()

        return {
            "id": cert.id,
            "staff_id": cert.staff_id,
            "cert_type": cert.cert_type,
            "cert_no": cert.cert_no,
            "expire_date": cert.expire_date.isoformat() if cert.expire_date else None,
            "cert_status": cert.cert_status,
            "days_to_expire": cert.days_to_expire(),
        }

"""患者只读服务（M03 同步镜像）"""
from datetime import datetime, timedelta
from typing import Optional, List

from sqlalchemy import select, or_, func
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.mdm.org_support import Patient, PatientMergeRef, PatientSyncLog

class PatientService:
    """患者只读服务"""

    CACHE_TTL = 300

    def __init__(self, db: AsyncSession):
        self.db = db

    # ---------- 查询 ----------
    async def list_patients(self, q: PatientQuery) -> tuple:
        stmt = select(Patient).where(Patient.is_deleted == False)

        if q.keyword:
            kw = f"%{q.keyword}%"
            stmt = stmt.where(or_(
                Patient.name.ilike(kw),
                Patient.patient_no.ilike(kw),
                Patient.empi_id.ilike(kw),
                Patient.pinyin_code.ilike(kw),
                Patient.phone.ilike(kw),
            ))
        if q.gender:
            stmt = stmt.where(Patient.gender == q.gender)
        if q.age_min is not None:
            stmt = stmt.where(Patient.age >= q.age_min)
        if q.age_max is not None:
            stmt = stmt.where(Patient.age <= q.age_max)
        if q.patient_type:
            stmt = stmt.where(Patient.patient_type == q.patient_type)

        total = (await self.db.execute(
            select(func.count()).select_from(stmt.subquery())
        )).scalar_one()

        rows = (await self.db.execute(
            stmt.order_by(Patient.id.asc())
            .offset((q.page - 1) * q.page_size)
            .limit(q.page_size)
        )).scalars().all()

        items = [self._to_list_item(p) for p in rows]

        # 同步元信息
        last_sync = (await self.db.execute(
            select(func.max(Patient.synced_at))
        )).scalar()
        stale = False
        if last_sync:
            stale = (datetime.now() - last_sync) > timedelta(minutes=30)

        meta = {
            "data_synced_at": last_sync.isoformat() if last_sync else None,
            "sync_stale": stale,
            "readonly_notice": "本页为只读视图，患者建档/修改请在 M03 患者服务操作",
        }
        return items, total, meta

    async def get_patient(self, empi_id: str) -> dict:
        """患者详情（含合并提示）"""
        cache_key = f"mdm:patient:{empi_id}"
        p = (await self.db.execute(
            select(Patient).where(
                Patient.empi_id == empi_id, Patient.is_deleted == False)
        )).scalar_one_or_none()

        if not p:
            raise BizException("0113033", f"患者 {empi_id} 不存在")

        data = self._to_detail(p)

        # 已合并 → 附带目标
        if p.is_merged and p.merged_to_empi:
            target = (await self.db.execute(
                select(Patient).where(Patient.empi_id == p.merged_to_empi)
            )).scalar_one_or_none()
            if target:
                data["merged_target"] = {
                    "empi_id": target.empi_id,
                    "name": target.name,
                    "patient_no": target.patient_no,
                }
        return data

    async def get_brief(self, empi_id: str) -> dict:
        """患者简要（供业务模块）"""
        p = await self._get_by_empi(empi_id)
        if not p:
            raise BizException("0113033", f"患者 {empi_id} 不存在")

        # 若已合并，返回目标患者

    async def batch_brief(self, empi_ids: List[str]) -> dict:

            select(Patient).where(
                Patient.empi_id.in_(empi_ids), Patient.is_deleted == False)

        found = {

            for p in rows

        return {
            "total": len(empi_ids),
            "found": len(found),
            "patients": found,
            "missing": [e for e in empi_ids if e not in found],
        }

    # ---------- 同步（M03 推送） ----------
    async def sync_from_m03(self, payload) -> dict:
        """接收 M03 推送的患者数据"""
        batch = f"PS{datetime.now().strftime('%Y%m%d%H%M%S')}"
        success, failed = 0, 0
        results = []

        for item in payload.patients:
            empi_id = item.get("empi_id")
            try:
                if payload.action == "DELETE":
                    p = await self._get_by_empi(empi_id)
                    if p:
                        p.is_deleted = True
                    action = "DELETE"
                elif payload.action == "MERGE":
                    action = await self._handle_merge(item)
                else:  # UPSERT
                    action = await self._handle_upsert(item)

                self.db.add(PatientSyncLog(
                    sync_batch=batch,
                    sync_mode=payload.sync_mode,
                    empi_id=empi_id,
                    action=action,
                    sync_status="SUCCESS",
                    source_version=item.get("sync_version"),
                    local_version=item.get("sync_version"),
                ))
                success += 1
                results.append({
                    "empi_id": empi_id, "action": action,
                    "status": "SUCCESS",
                    "local_version": item.get("sync_version")})
            except Exception as e:
                self.db.add(PatientSyncLog(
                    sync_batch=batch,
                    sync_mode=payload.sync_mode,
                    empi_id=empi_id,
                    action=payload.action,
                    sync_status="FAILED",
                    error_msg=str(e)[:1000],
                ))
                failed += 1
                results.append({
                    "empi_id": empi_id, "action": payload.action,
                    "status": "FAILED", "error": str(e)[:200]})

        await self.db.commit()

        # 清缓存
        for r in results:
            if r["status"] == "SUCCESS":
                await redis_client.delete(f"mdm:patient:{r['empi_id']}")

        return {
            "sync_batch": batch,
            "total": len(payload.patients),
            "success": success,
            "failed": failed,
            "results": results,
        }

    async def _handle_upsert(self, item: dict) -> str:
        empi_id = item["empi_id"]
        p = await self._get_by_empi(empi_id)

        if p:
            # 版本比较：仅当 M03 版本更新时才覆盖
            if (item.get("sync_version") or 0) <= p.sync_version:
                return "SKIPPED"
            for field in ("patient_no", "name", "pinyin_code", "pinyin_short",
                           "gender", "birth_date", "age", "id_card_no_mask",
                           "id_card_hash", "id_type", "phone", "address",
                           "patient_type", "member_id", "member_level",
                           "is_vip", "allergy_history"):
                if field in item:
                    setattr(p, field, item[field])
            p.sync_version = item.get("sync_version", p.sync_version + 1)
            p.synced_at = datetime.now()
            return "UPSERT"
        else:
            new_p = Patient(
                empi_id=empi_id,
                patient_no=item["patient_no"],
                name=item["name"],
                pinyin_code=item.get("pinyin_code"),
                pinyin_short=item.get("pinyin_short"),
                gender=item.get("gender"),
                birth_date=item.get("birth_date"),
                age=item.get("age"),
                id_card_no_mask=item.get("id_card_no_mask"),
                id_card_hash=item.get("id_card_hash"),
                id_type=item.get("id_type"),
                phone=item.get("phone"),
                address=item.get("address"),
                patient_type=item.get("patient_type"),
                member_id=item.get("member_id"),
                member_level=item.get("member_level"),
                is_vip=item.get("is_vip", False),
                allergy_history=item.get("allergy_history"),
                sync_version=item.get("sync_version", 1),
                synced_at=datetime.now(),
            )
            self.db.add(new_p)
            return "UPSERT"

    async def _handle_merge(self, item: dict) -> str:
        """处理合并：标记源患者已合并"""
        source_empi = item["empi_id"]
        target_empi = item["merged_to_empi"]

        p = await self._get_by_empi(source_empi)
        if not p:
            raise BizException("0113033", f"源患者 {source_empi} 不存在")

        p.is_merged = True
        p.merged_to_empi = target_empi
        p.merged_at = datetime.now()

        # 记录合并关系
        exist = (await self.db.execute(
            select(PatientMergeRef).where(
                PatientMergeRef.source_empi == source_empi)
        )).scalar_one_or_none()
        if not exist:
            self.db.add(PatientMergeRef(
                source_empi=source_empi,
                source_name=p.name,
                target_empi=target_empi,
                target_name=item.get("target_name"),
                merge_reason=item.get("merge_reason"),
                merged_by=item.get("merged_by"),
                merged_at=datetime.now(),
            ))
        return "MERGE"

    # ---------- 工具 ----------
    async def _get_by_empi(self, empi_id: str) -> Optional[Patient]:
        return (await self.db.execute(
            select(Patient).where(
                Patient.empi_id == empi_id, Patient.is_deleted == False)
        )).scalar_one_or_none()

    @staticmethod
    def _to_list_item(p: Patient) -> dict:
        return {
            "id": p.id,
            "empi_id": p.empi_id,
            "patient_no": p.patient_no,
            "name": p.name,
            "pinyin_code": p.pinyin_code,
            "gender": p.gender,
            "age": p.age,
            "birth_date": p.birth_date.isoformat() if p.birth_date else None,
            "id_card_no_mask": p.id_card_no_mask,
            "phone_mask": Patient.mask_phone(p.phone),
            "patient_type": p.patient_type,
            "member_level": p.member_level,
            "is_vip": bool(p.is_vip),
            "has_allergy": p.has_allergy(),
            "is_merged": bool(p.is_merged),
            "synced_at": p.synced_at.isoformat() if p.synced_at else None,
        }

    def _to_detail(self, p: Patient) -> dict:
        d = self._to_list_item(p)
        d.update({
            "id_type": p.id_type,
            "address": p.address,
            "member_id": p.member_id,
            "allergy_history": p.allergy_history,
            "merged_to_empi": p.merged_to_empi,
            "merged_at": p.merged_at.isoformat() if p.merged_at else None,
            "merged_target": None,
            "sync_version": p.sync_version,
            "status": p.status,
        })
        return d

    """批量重算证书状态"""

    from app.core.database import AsyncSessionLocal

async def _send_remind():
    """按 60/30/7/到期 节点发送提醒"""
    from datetime import date
    from sqlalchemy import select
    from app.models.mdm.org_support import StaffCert
    from app.core.database import AsyncSessionLocal
    from app.services.notify_service import NotifyService

    async with AsyncSessionLocal() as db:

                StaffCert.cert_status != "REVOKED",
            )
        )).scalars().all()

        for c in certs:
            d = (c.expire_date - today).days
            if d < 0:
                if not getattr(c, "remind_expired_sent", False):
                    await notify.send(
                        template="CERT_EXPIRED",
                        receivers=await get_hr_and_staff(c.staff_id),
                        params={"staff": c.staff_name, "cert_type": c.cert_type_name,
                                "cert_no": c.cert_no, "expire": str(c.expire_date)})
                    sent["expired"] += 1
            elif d <= 7 and not c.remind_7_sent:
                await notify.send(
                    template="CERT_EXPIRING_7",
                    receivers=await get_staff_and_leaders(c.staff_id),
                    params={"staff": c.staff_name, "cert_type": c.cert_type_name,
                            "days": d})
                c.remind_7_sent = True
                sent["7"] += 1
            elif d <= 30 and not c.remind_30_sent:
                await notify.send(
                    template="CERT_EXPIRING_30",
                    receivers=await get_staff_and_leaders(c.staff_id),
                    params={"staff": c.staff_name, "cert_type": c.cert_type_name,
                            "days": d})
                c.remind_30_sent = True
                sent["30"] += 1
            elif d <= 60 and not c.remind_60_sent:
                await notify.send(
                    template="CERT_EXPIRING_60",
                    receivers=await get_hr_and_staff(c.staff_id),
                    params={"staff": c.staff_name, "cert_type": c.cert_type_name,
                            "days": d})
                c.remind_60_sent = True
                sent["60"] += 1

        await db.commit()
        return sent

async def _full_sync():
    """全量比对同步"""
    import httpx
    from app.core.database import AsyncSessionLocal
    from app.core.redis import redis_client
    from app.services.mdm.patient_service import PatientService
    from app.schemas.mdm.org_support import PatientSyncRequest

    lock_key = "mdm:lock:patient:sync"
    if not await redis_client.set(lock_key, "1", nx=True, ex=600):
        return {"status": "SKIPPED", "reason": "同步任务已在运行"}

    try:
        total_synced = 0
        page = 1
        async with httpx.AsyncClient(timeout=60) as client:
            while True:
                resp = await client.get(
                    "http://m03.internal/internal/v1/patients/snapshot",
                    params={"page": page, "page_size": 1000})
                data = resp.json().get("data", {})
                patients = data.get("items", [])
                if not patients:
                    break

                async with AsyncSessionLocal() as db:
                    svc = PatientService(db)
                    await svc.sync_from_m03(PatientSyncRequest(
                        sync_mode="BATCH", action="UPSERT", patients=patients))

                total_synced += len(patients)
                page += 1
                if page > data.get("total_pages", 1):
                    break

        return {"status": "SUCCESS", "synced": total_synced}
    finally:
        await redis_client.delete(lock_key)

async def check_patient_sync_stale():
    """患者同步延迟检查"""
    from datetime import datetime, timedelta
    from sqlalchemy import select, func
    from app.models.mdm.org_support import Patient
    from app.core.database import AsyncSessionLocal
    from app.services.notify_service import NotifyService

    async with AsyncSessionLocal() as db:
        last = (await db.execute(
            select(func.max(Patient.synced_at))
        )).scalar()

        if not last:
            return {"status": "NO_DATA"}

        delay = (datetime.now() - last).total_seconds()
        if delay > 1800:  # 30 分钟
            await NotifyService().send(
                template="PATIENT_SYNC_STALE",
                receivers=await get_it_managers(),
                params={
                    "last_sync": last.isoformat(),
                    "delay_minutes": int(delay / 60),
                },
            )
            return {"status": "STALE", "delay_seconds": int(delay)}
        return {"status": "OK", "delay_seconds": int(delay)}

| `mdm.cert.changed` | 证书变更 | staff_id, cert_type, status |
| `mdm.cert.expired` | 证书过期 | staff_id, cert_type |
| `mdm.patient.synced` | 患者同步（由 M03 触发） | empi_id, action |

### 10.3 与 M03 的患者同步契约

| 接口 | 用途 | SLA |
|---|---|---|
| `POST /internal/v1/mdm/patients/sync` | M03 推送患者数据 | P95 ≤ 200ms（单条）/ ≤2s（1000 条） |
| `GET /internal/v1/mdm/patients/{empi_id}/brief` | 业务模块查患者 | P95 ≤ 30ms |
| `POST /internal/v1/mdm/patients/batch-brief` | 批量查患者 | P95 ≤ 100ms |

**关键约定：**

1. **M03 是患者数据唯一写入方**，M01 只接收推送。
2. **M01 拒绝任何患者写请求**（40300）。
3. **M03 推送时必须带 `sync_version`**，M01 据此判断是否覆盖。
4. **同步失败不影响 M03**，M01 记录失败日志并告警。
5. **患者合并由 M03 决定**，M01 只镜像合并关系。

### 10.4 与 M07 的执业校验契约

| 接口 | 用途 | SLA |
|---|---|---|
| `GET /internal/v1/mdm/staff/{staff_id}/practice-check` | 开处方前校验 | P95 ≤ 50ms |

**关键约定：**

1. **M07 开处方前必须调用** `practice-check`，返回 `can_prescribe=false` 时阻断。
2. 结果缓存 10 分钟，证书变更时主动失效。
3. 校验失败必须给出明确原因（证书过期/无证书/职称无处方权）。
