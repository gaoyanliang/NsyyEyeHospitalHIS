## 1. 模块概述

### 1.1 模块定位

视光产品是眼科医院区别于综合医院的核心业务品类，也是 M10 视光业务模块的收入主体。本子模块是全院**镜架、镜片、隐形眼镜、OK 镜（角膜塑形镜）、RGP、护理产品、视光服务**的统一数据源头。

总体设计第 3 章 M01 行明确"视光产品"为主数据域之一；第 5.2 节视光闭环为：**验光→处方→选品→下单→加工→交付→复查**。整个闭环的选品与定价规则，均由本子模块定义。

与普通耗材的关键差异在于：**视光产品具有多维光学参数**，同一"产品"在不同度数组合下是不同的销售单元（SKU），价格、库存、供货周期都可能不同。这是本子模块设计的核心复杂度。

| 职责 | 归属 | 说明 |
|---|---|---|
| 视光产品目录（`md_optical_product`） | **M01 视光子模块（本文档）** | 镜架/镜片/隐形/OK镜等 |
| 光学参数规格矩阵（`md_optical_spec`） | **M01 视光子模块（本文档）** | 球镜×柱镜可供应矩阵 |
| 加工工艺与工序（`md_optical_process`） | **M01 视光子模块（本文档）** | 磨边/割边/装框等 |
| 加工工序模板（`md_process_template`） | **M01 视光子模块（本文档）** | 组合工序套用 |
| 视光产品价格（标准/会员） | **M01 收费子模块** | 本文档定义价格字段，价格版本化归收费 |
| 验光处方、配镜订单、加工单 | **M10 视光业务管理** | 业务执行 |
| 实际库存与出入库 | **M13 库房管理 / M15 物资** | — |
| 屈光手术方案与随访 | **M11 屈光手术管理** | — |
| 会员等级与折扣 | **M03 会员管理** | M01 提供最低折扣率 |

> **一句话边界**：M01 回答"**有哪些视光产品、每个度数段能不能做、多少钱、怎么加工**"；M10 回答"**这个患者配了什么、什么时候交货**"。

### 1.2 模块目标

- **统一源头**：全院视光商品统一由 MDM 定义，M10 销售端只读引用。
- **光学参数化**：以"球镜 × 柱镜 × 轴位"矩阵表达可供应范围，支撑验光逐单校验。
- **定制可预期**：标清常规片与定制片，给出供货周期，避免销售承诺无法兑现。
- **加工标准化**：工序、工时、加工费、质检项标准化，支撑 M10 加工单派工与成本核算。
- **专科适配**：完整覆盖 OK 镜验配参数（BC/RC/AC/PC/降度）、隐形眼镜基弧直径、渐进片通道长度等眼科专属属性。
- **价格合规**：最低折扣率受控，低于底价需审批（M20）。
- **即时生效**：产品变更后主动失效缓存并广播，M10 下次选品即生效。

### 2.3 与 M01 耗材子模块的边界

视光产品与耗材是**两个独立主数据域**，但在数据结构上共用部分逻辑：

| 数据 | 权威源 | 说明 |
|---|---|---|
| 普通耗材（手术耗材、检验试剂） | **M01 耗材子模块**（`mdm_material`） | 与本文档独立 |
| **视光产品** | **M01 视光子模块**（`mdm_optical_product`） | 本文档 |
| 人工晶体（IOL） | **M01 耗材子模块**（`mdm_material_iol`） | 属医用耗材，不属视光商品 |
| 供应商 | **M01 耗材子模块**（`mdm_supplier`） | 共用 |
| 生产厂商 | **M01 耗材子模块**（`mdm_manufacturer`） | 共用 |
| 手术套包 | **M01 耗材子模块**（`mdm_surgery_kit`） | 与视光无关 |

> **关键判定**：**是否进入患者体内 / 是否为医疗器械植入** 是分界标准。人工晶体进入体内 → 耗材域；镜片、镜架、隐形眼镜 → 视光域。OK 镜虽为三类医疗器械接触角膜，但因**高度定制化 + 验配参数**，仍归视光域。

### 3.5 光学参数矩阵模型（核心）

#### 3.5.1 矩阵结构

镜片类产品的可供应范围以**二维矩阵**表达：

```
            柱镜 (CYL)
          0.00  -0.25  -0.50  -0.75  ...  -6.00
球镜  +6.00  ✓     ✓      ✗      ✗          ✗
(SHP) +5.75  ✓     ✓      ✓      ✗          ✗
      ...
      -0.25  ✓     ✓      ✓      ✓          ✓
      -0.50  ✓     ✓      ✓      ✓          ✓
      ...
      -8.00  ✓     ✓      ✓      ✓          ✗   ← 高度数需定制
      ...
     -20.00  ✗     ✗      ✗      ✗          ✗
```

**每个矩阵格（球镜 × 柱镜组合）具备：**

| 属性 | 说明 |
|---|---|
| 是否可供 | 该度数组合能否下单 |
| 供货类型 | 现货 / 定制 |
| 加价金额 | 高度数加价 |
| 供货周期 | 定制片天数 |
| 库存数量 | 只读同步 M13（现货才有意义） |

#### 3.5.2 加价规则模型

高度数、高散光、特殊设计通常加价。支持两种配置方式：

| 方式 | 说明 |
|---|---|
| **矩阵逐格加价** | 每个格子单独设 `surcharge` |
| **规则式加价** | 按条件批量应用，如"球镜绝对值 > 6.00 加价 100 元" |

**规则式加价配置：**

| 字段 | 说明 |
|---|---|
| 规则名称 | 如"高度数加价" |
| 适用维度 | 球镜 / 柱镜 / 轴位 |
| 比较符 | `>` / `>=` / `<` / `<=` / `=` / `BETWEEN` |
| 阈值 | 如 6.00 |
| 加价方式 | 固定金额 / 百分比 |
| 加价数值 | 如 100 或 15 |
| 优先级 | 多条规则命中时的应用顺序（可叠加或取最大） |

#### 3.5.3 矩阵存储策略

| 方案 | 说明 | 采用 |
|---|---|---|
| 逐格存储 | 每格一行 `(product_id, sphere, cylinder)` | **是**（灵活、可按格设加价） |
| 范围存储 | 存 `sphere_min/max, cylinder_min/max` | 否（无法表达不规则缺口） |

单产品矩阵格数上限：球镜 161 档（-20.00~+20.00）× 柱镜 25 档（0~-6.00）= **4,025 格**。
实际常用产品约 300~800 格，全量存储可控。

| `COATING` | 镀膜 | 否 | 加膜 |
| `REINFORCE` | 加固 | 否 | 高散光加固 |
| `ADJUSTING` | 调整 | 是 | 镜架调整 |

| 属性 | 说明 |
|---|---|
| 标准工时 | 分钟 |

#### 3.6.3 工序模板

将常用工序组合固化为模板：

| 模板 | 包含工序 | 适用场景 |
|---|---|---|

### 3.7 价格与折扣模型

| 字段 | 说明 |
|---|---|
| 零售价 | 标准售价 |
| 会员价 | 会员专享价（为空则按折扣策略） |
| 成本价 | 采购成本，用于毛利核算 |
| 最低折扣率 | 低于此折扣需店长审批（M20） |
| 是否参与折扣 | 是否允许使用活动/优惠券 |
| 加价规则 | 见 3.5.2，高度数加价 |

**价格计算优先级：** 加价后零售价 = 基础零售价 + 度数加价；会员价 = max(会员价, 零售价 × 最低折扣率)。

```python
# app/services/mdm/optical_spec_service.py
"""光度矩阵与取价服务（核心）"""
from decimal import Decimal, ROUND_HALF_UP
from typing import Optional, List

from sqlalchemy import select, and_, or_, func
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.mdm.optical import OpticalProduct, OpticalSpec, OpticalSurchargeRule
from app.schemas.mdm.optical import SpecLookupRequest
from app.core.exceptions import BizException, ErrorCode
from app.core.redis import redis_client


class OpticalSpecService:
    """光学参数矩阵服务"""

    def __init__(self, db: AsyncSession):
        self.db = db

    # ---------- 光度校验（M10 核心调用） ----------
    async def lookup(self, req: SpecLookupRequest) -> dict:
        """校验某度数组合是否可供，并返回价格"""
        # 1. 查产品
        product = await self._get_product_by_code(req.product_code)
        if not product:
            raise BizException(44028, "产品不存在或已停用")
        if product.status != "ENABLED" or product.deleted:
            raise BizException(44028, f"产品「{product.product_name}」已停用")
        if product.is_trial_lens:
            raise BizException(44028, "试戴片不可销售")

        # 2. 查询光度格（先精确，再回退轴位无关匹配）
        spec = await self._find_spec(
            product.id, req.sphere, req.cylinder, req.axis, req.add_power)

        # 3. 计算基础价
        base_price = Decimal(str(product.retail_price))
        if req.is_member and product.member_price is not None:
            base_price = Decimal(str(product.member_price))

        # 4. 未找到或不供
        if not spec or not spec.is_available:
            range_info = await self._get_available_range(product.id)
            return {
                "found": bool(spec),
                "product_code": product.product_code,
                "product_name": product.product_name,
                "is_available": False,
                "supply_type": None,
                "base_price": float(base_price),
                "surcharge": None,
                "final_price": None,
                "lead_time_days": None,
                "stock_qty": None,
                "matched_rule": None,
                "message": (
                    f"该度数组合（球镜 {req.sphere:+.2f} / 柱镜 {req.cylinder:+.2f}）"
                    f"超出可供应范围，请更换产品。"
                    f"当前可供范围：球镜 {range_info['sphere_range']}、"
                    f"柱镜 {range_info['cylinder_range']}"
                ),
            }

        # 5. 计算加价
        surcharge, matched_rule = await self._resolve_surcharge(
            product, req.sphere, req.cylinder, req.add_power)

        final_price = (base_price + surcharge).quantize(
            Decimal("0.01"), rounding=ROUND_HALF_UP)

        lead_time = spec.lead_time_days or product.lead_time_days
        msg = None
        if spec.supply_type == "CUSTOM":
            msg = f"该度数需定制，预计 {lead_time or '?'} 天供货"
        elif spec.stock_qty is not None and spec.stock_qty <= 0:
            msg = "该度数暂时缺货，建议改用定制或其他产品"

        return {
            "found": True,
            "product_code": product.product_code,
            "product_name": product.product_name,
            "is_available": True,
            "supply_type": spec.supply_type,
            "base_price": float(base_price),
            "surcharge": float(surcharge),
            "final_price": float(final_price),
            "lead_time_days": lead_time,
            "stock_qty": spec.stock_qty,
            "matched_rule": matched_rule,
            "message": msg,
        }

    async def _find_spec(self, product_id: int, sphere: Decimal,
                          cylinder: Decimal, axis: Optional[int],
                          add_power: Optional[Decimal]) -> Optional[OpticalSpec]:
        """按度数查找光度格"""
        conditions = [
            OpticalSpec.product_id == product_id,
            OpticalSpec.sphere == sphere,
            OpticalSpec.cylinder == cylinder,
            OpticalSpec.deleted == False,
        ]
        # add_power 匹配：先精确匹配，再允许 NULL
        if add_power is not None:
            conditions.append(
                or_(OpticalSpec.add_power == add_power, OpticalSpec.add_power.is_(None))
            )
        else:
            conditions.append(OpticalSpec.add_power.is_(None))

        stmt = select(OpticalSpec).where(and_(*conditions))
        rows = (await self.db.execute(stmt)).scalars().all()
        if not rows:
            return None

        # 若柱镜=0，取任意一条；若柱镜≠0，优先匹配轴位（矩阵通常不细分轴位）
        if cylinder == 0:
            return rows[0]
        # 优先精确轴位
        for r in rows:
            if r.axis == axis:
                return r
        return rows[0]

    async def _resolve_surcharge(self, product: OpticalProduct, sphere: Decimal,
                                  cylinder: Decimal,
                                  add_power: Optional[Decimal]) -> tuple:
        """按加价规则计算加价"""
        stmt = select(OpticalSurchargeRule).where(
            OpticalSurchargeRule.status == "ENABLED",
            OpticalSurchargeRule.deleted == False,
            or_(
                OpticalSurchargeRule.product_id == product.id,
                and_(
                    OpticalSurchargeRule.product_id.is_(None),
                    or_(
                        OpticalSurchargeRule.product_kind.is_(None),
                        OpticalSurchargeRule.product_kind == product.product_kind,
                    ),
                ),
            ),
        ).order_by(OpticalSurchargeRule.priority.asc())

        rules = (await self.db.execute(stmt)).scalars().all()

        matches = []
        for rule in rules:
            value = {"SPHERE": sphere, "CYLINDER": cylinder,
                     "ADD": add_power}.get(rule.dimension)
            if value is None:
                continue
            if not self._match_rule(rule, value):
                continue

            if rule.surcharge_type == "FIXED":
                amount = Decimal(str(rule.surcharge_value))
            else:
                amount = (Decimal(str(product.retail_price))
                          * Decimal(str(rule.surcharge_value)) / 100)

            matches.append({
                "rule_code": rule.rule_code,
                "rule_name": rule.rule_name,
                "amount": amount.quantize(Decimal("0.01")),
                "apply_mode": rule.apply_mode,
            })

        if not matches:
            return Decimal("0"), None

        # 叠加方式：默认取最大，SUM 则累加
        apply_mode = matches[0]["apply_mode"] if matches else "MAX"
        if apply_mode == "SUM":
            total = sum(m["amount"] for m in matches)
        else:
            total = max(m["amount"] for m in matches)

        return total, {
            "rule_code": matches[0]["rule_code"],
            "rule_name": matches[0]["rule_name"],
            "surcharge": float(total),
        }

    @staticmethod
    def _match_rule(rule, value: Decimal) -> bool:
        """判断某维度值是否命中规则"""
        t_min = rule.threshold_min
        t_max = rule.threshold_max
        op = rule.operator

        if op == "GT":
            return value > t_min
        if op == "GTE":
            return value >= t_min
        if op == "LT":
            return value < t_min
        if op == "LTE":
            return value <= t_min
        if op == "EQ":
            return value == t_min
        if op == "BETWEEN":
            return t_min <= value <= t_max
        if op == "ABS_GT":
            return abs(value) > abs(t_min)
        return False

    async def _get_available_range(self, product_id: int) -> dict:
        """获取产品可供范围（用于提示）"""
        stmt = select(
            func.min(OpticalSpec.sphere), func.max(OpticalSpec.sphere),
            func.min(OpticalSpec.cylinder), func.max(OpticalSpec.cylinder),
        ).where(
            OpticalSpec.product_id == product_id,
            OpticalSpec.is_available == True,
            OpticalSpec.deleted == False,
        )
        row = (await self.db.execute(stmt)).one()
        if row[0] is None:
            return {"sphere_range": "无", "cylinder_range": "无"}
        return {
            "sphere_range": f"{row[0]:+.2f} ~ {row[1]:+.2f}",
            "cylinder_range": f"{row[2]:+.2f} ~ {row[3]:+.2f}",
        }

    async def save_matrix(self, product_id: int, specs: List, mode: str,
                           reason: Optional[str], operator) -> dict:
        """保存光度矩阵"""
        product = await self._get_product(product_id)
        if not product:
            raise BizException(ErrorCode.NOT_FOUND, "产品不存在")

        # 校验：至少一个可供
        if not any(s.is_available for s in specs):
            raise BizException(44014, "光度矩阵至少需要一个可供度数")

        # 全量模式：先删旧
        if mode == "FULL":
            await self.db.execute(
                OpticalSpec.__table__.update()
                .where(OpticalSpec.product_id == product_id)
                .values(deleted=True)
            )

        # 写新
        for s in specs:
            obj = OpticalSpec(
                product_id=product_id,
                product_code=product.product_code,
                sphere=s.sphere, cylinder=s.cylinder,
                axis=s.axis, add_power=s.add_power,
                is_available=s.is_available, supply_type=s.supply_type,
                surcharge=s.surcharge, lead_time_days=s.lead_time_days,
                min_order_qty=s.min_order_qty,
            )
            self.db.add(obj)

        product.version += 1
        await self.db.commit()

        # 失效缓存
        await redis_client.delete(f"mdm:optical:spec:{product.product_code}")
        await redis_client.delete(f"mdm:optical:config:{product.product_code}")

        available = sum(1 for s in specs if s.is_available)
        return {
            "product_code": product.product_code,
            "mode": mode,
            "saved_count": len(specs),
            "available_count": available,
            "change_log_id": 0,   # 由 ChangeLogService 填充
            "version": product.version,
        }

    # ---------- 内部工具 ----------
    async def _get_product(self, product_id: int) -> Optional[OpticalProduct]:
        return (await self.db.execute(
            select(OpticalProduct).where(
                OpticalProduct.id == product_id, OpticalProduct.deleted == False)
        )).scalar_one_or_none()

    async def _get_product_by_code(self, code: str) -> Optional[OpticalProduct]:
        return (await self.db.execute(
            select(OpticalProduct).where(
                OpticalProduct.product_code == code,
                OpticalProduct.deleted == False)
        )).scalar_one_or_none()
```

```python
async def check_registration_expire():
    """注册证到期前 30 天告警，到期后自动停用"""
    from datetime import date, timedelta
    from sqlalchemy import select
    from app.models.mdm.optical import OpticalProduct
    from app.core.database import AsyncSessionLocal
    from app.services.notify_service import NotifyService

    async with AsyncSessionLocal() as db:
        today = date.today()
        warn_date = today + timedelta(days=30)

        # 即将到期
        expiring = (await db.execute(
            select(OpticalProduct).where(
                OpticalProduct.is_medical_device == True,
                OpticalProduct.registration_expire.isnot(None),
                OpticalProduct.registration_expire <= warn_date,
                OpticalProduct.registration_expire >= today,
                OpticalProduct.status == "ENABLED",
                OpticalProduct.deleted == False,
            )
        )).scalars().all()

        if expiring:
            notify = NotifyService()
            await notify.send(
                template="OPTICAL_CERT_EXPIRING",
                receivers=await get_optical_managers(),
                params={"count": len(expiring),
                        "products": [p.product_code for p in expiring[:10]]},
            )

        # 已过期 → 停用
        expired = (await db.execute(
            select(OpticalProduct).where(
                OpticalProduct.is_medical_device == True,
                OpticalProduct.registration_expire.isnot(None),
                OpticalProduct.registration_expire < today,
                OpticalProduct.status == "ENABLED",
                OpticalProduct.deleted == False,
            )
        )).scalars().all()

        for p in expired:
            p.status = "DISABLED"
            p.remark = f"[系统] 注册证已于 {p.registration_expire} 到期，自动停用"
        await db.commit()


async def clean_orphan_specs():
    """清理已删除产品的残留光度格"""
    from sqlalchemy import select, delete
```

## 8. 业务规则与校验

### 8.1 编码规则

| 对象 | 规则 | 示例 |
|---|---|---|
| 视光产品 | `OP` + 品类码(2) + 流水(6) | `OPFR000123` |
| 加工工序 | `PRC` + 流水(3) | `PRC001` |
| 工序模板 | `TP` + 流水(4) | `TP0003` |
| 加价规则 | `SC` + 流水(3) | `SC001` |

**约束：** 编码全局唯一；生成后不可修改；品类不可变更（否则编码语义错误）。

### 8.2 唯一性规则

| 校验 | 规则 | 处理 |
|---|---|---|
| 产品编码唯一 | `product_code` | 阻止，44001 |
| 条形码唯一 | `barcode`（非空时） | 阻止，44002 |
| 度数组合唯一 | `(product_id, sphere, cylinder, add_power)` | 阻止，44009 |
| 工序编码唯一 | `process_code` | 阻止 |
| 工序序号唯一 | `process_seq` | 阻止，44023 |
| 主图唯一 | 同产品仅一张 `is_primary=true` | 阻止，44022 |
| 试戴片编号唯一 | `trial_lens_no` | 阻止 |

### 8.3 品类与参数规则

| 品类 | 强制参数 | 规则 |
|---|---|---|
| `FRAME` | 镜架参数 | 必须有 `mdm_optical_frame_spec` 记录（44015） |
| `LENS` | 光度矩阵 | 至少一个可供度数（44008/44014） |
| `CONTACT` | 隐形参数 | 必须有 `contact_spec`（44016）；散光片需柱镜范围 |
| `RGP` | 隐形参数 | 同上，`spec_kind=RGP` |
| `ORTHO_K` | OK镜参数 | 必须有验配参数（44017）；必须三类器械（44006） |
| `CARE`/`SUN`/`ACCESSORY`/`SERVICE` | 无特殊 | — |

### 8.4 光学参数校验

| 规则 | 说明 |
|---|---|
| 步进 | 球镜/柱镜必须为 0.25 整数倍（44010） |
| 轴位 | 1~180 整数；柱镜=0 时必须为空（44011）；柱镜≠0 时必须填（44012） |
| 球镜范围 | −30.00 ~ +30.00 |
| 柱镜范围 | −10.00 ~ 0.00 |
| 附加度数 | 0 ~ +4.00，仅渐进片 |
| OK镜弧参数 | `RC < BC < AC < PC`（44018） |
| 基建 | 6~11 mm |
| 直径（隐形） | 10~18 mm |
| 直径（OK镜） | 8~14 mm |

### 8.5 医疗器械合规规则

| 规则 | 说明 |
|---|---|
| 注册证必填 | `is_medical_device=true` → `registration_no` 必填（44004） |
| 类别必填 | `is_medical_device=true` → `device_class` 必填 |
| 注册证有效期 | 到期自动停用（定时任务） |
| 到期不可售 | `registration_expire < today` → `is_sellable=false` |
| OK镜三类 | `product_kind='ORTHO_K'` → `device_class='III'`（44006） |
| 隐形凭处方 | `CONTACT`/`RGP` → `is_prescription_required=true`（44007） |

### 8.6 价格与折扣规则

| 规则 | 说明 |
|---|---|
| 会员价 ≤ 零售价 | 否则阻止（44020） |
| 成本价 ≤ 零售价 | 否则阻止（44021） |
| 最低折扣率 | 0~100%，低于此折扣需 M20 审批 |
| 底价计算 | `floor_price = 零售价 × min_discount_rate / 100` |
| 加价不计入底价 | 底价仅按基础价计算，加价部分不参与折扣 |
| 加价优先级 | 多条规则命中时按 `apply_mode`（MAX/SUM） |

### 8.7 供货与库存规则

| 规则 | 说明 |
|---|---|
| 定制必填周期 | `supply_type='CUSTOM'` → `lead_time_days` 必填（44013） |
| 现货库存 | `supply_type='STOCK'` 建议有库存，允许超卖但提示 |
| 缺货提示 | `stock_qty <= 0` 时返回缺货提示 |
| 试戴片不销售 | `is_trial_lens=true` → `is_sellable=false` |

### 8.8 加工工序规则

| 规则 | 说明 |
|---|---|
| 序号唯一 | `process_seq` 不可重复（44023） |
| 拖拽重排 | 批量更新序号，事务内完成 |
| 引用保护 | 被订单引用的工序不可删除（44024） |
| 外协必填供应商 | `is_outsourced=true` → `outsourced_supplier_id` 必填（44025） |
| 模板工时汇总 | `total_minutes`、`total_fee` 自动汇总 |

### 8.9 引用与删除规则

| 规则 | 说明 |
|---|---|
| 删除校验 | 被验光处方/配镜订单/库存引用时不可删除（44003） |
| 停用校验 | 停用时提示引用情况 |
| 物理删除 | 仅当从未被引用时允许 |

### 8.10 并发控制

| 机制 | 说明 |
|---|---|
| 乐观锁 | 保存时校验 `version`，不匹配返回 44027 |
| 编辑互斥锁 | `mdm:lock:optical:product:{id}`，30s TTL |
| 矩阵编辑锁 | `mdm:lock:optical:matrix:{id}`，60s TTL（防多人同时改矩阵） |
| 增量保存 | 矩阵支持 `mode=INCR` 仅保存变更格 |
