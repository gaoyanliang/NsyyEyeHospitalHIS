## 1. 模块概述

### 1.1 模块定位

M09-02 负责**麻醉过程中的全部事实记录**：麻醉开始确认、生命体征趋势、麻醉深度、给药记录、麻醉结束与苏醒、麻醉小结。

M09-01 回答"用什么麻醉方式、打算给什么药"，M09-02 回答"**实际给了什么、患者怎么反应、什么时候醒的**"。

### 1.2 为什么独立成子模块

**理由一：麻醉记录与手术记录是两个独立法定文书。**

《病历书写基本规范》第十八条要求麻醉记录单包含：麻醉方法、麻醉药及剂量、生命体征、麻醉过程、麻醉效果、并发症及处理。第十九条要求手术记录包含：手术名称、术者、助手、手术日期、术前诊断、手术过程、麻醉方法、术中情况、术后处理。

两份文书的责任人不同（麻醉医生 vs 主刀医生），签名不同，归档检查项也不同（M06-06 的 D-11 手术记录与 D-12 麻醉记录是分开的两项）。

合在一起的问题：麻醉医生在麻醉深度监测界面看到的字段与手术医生在术野记录界面看到的字段完全不重叠。一个界面上摆 60 个字段，每类人都要跳过另一类的 30 个。

**理由二：麻醉记录的核心是时间序列，手术记录的核心是事件。**

麻醉记录的数据模型本质是"每 5 分钟一组数值"——一台 60 分钟手术产生 12~15 组体征记录，一天 55 台就是 800 组。它的查询模式是"取某时间段的趋势做曲线"。

手术记录的数据模型是"若干关键事件的文字描述"——切开、超声乳化、植入晶体、闭合切口。它的查询模式是"读出这段文字给质控和病历看"。

两者的索引策略、分区策略、缓存策略完全不同。合并会让一张表同时承担两种访问模式。

**理由三：眼科麻醉有完全不同的药物谱与风险点。**

一般外科麻醉以全麻为主（丙泊酚 + 阿片 + 肌松），眼科日间手术 **80% 是局部麻醉**：

| 麻醉方式 | 占比 | 药物 | 执行人 | 主要风险 |
|---|---|---|---|---|
| 表面麻醉 | 45% | 奥布卡因 0.4% / 丙美卡因 0.5% | 主刀 | 角膜上皮损伤 |
| 局部浸润 | 25% | 利多卡因 2% | 主刀 | 麻醉不充分 |
| 球周 / 球后阻滞 | 20% | 利多卡因 + 布比卡因 | 麻醉医生或主刀 | 球后出血、眼心反射、眼球穿孔 |
| 静脉镇静 | 7% | 咪达唑仑 + 芬太尼 | 麻醉医生 | 呼吸抑制 |
| 全身麻醉 | 3% | 丙泊酚 + 喉罩 | 麻醉医生 | 气道管理 |

这个药物谱与风险结构完全独立于一般外科。把眼科的球后阻滞用药、眼心反射监测放在通用麻醉记录里，会被淹没在大量一般外科字段中（如肌松监测 TOF 计数、吸入麻醉 MAC 值），而眼科根本用不到。

**理由四：麻醉药品是受管制物资，必须与 M14-09 逐支对账。**

芬太尼、瑞芬太尼、舒芬太尼属麻醉药品（《麻醉药品和精神药品管理条例》第三类管理）。每一次给药必须：
- 有印鉴卡
- 双人签字
- 空安瓿回收
- 逐支登记

这不是"一个开药动作"，而是一整条受药监管制的业务链。放在麻醉记录里做，可以让"给了多少药"与"登记了多少瓶"在同一界面对账。

**理由五：麻醉记录是质控与科研的数据源。**

麻醉质控指标（《麻醉专业医疗质量控制指标（2021 年版）》）如"非计划二次气管插管率""麻醉相关死亡率"都从麻醉记录取数。

科研课题（如"球后阻滞与球周阻滞的术后眼球运动恢复时间对比"）需要结构化的给药时间、剂量、体征曲线。

如果麻醉记录只是嵌在手术记录里的一段文本，这些指标与课题都做不了。

**一句话边界：** M09-02 回答「这台手术的麻醉，实际发生了什么」。不回答「应该怎么做」（M09-01）、不回答「手术做了什么」（M09-03）、不回答「药品实物在哪」（M14-09）。

### 1.4 概念辨析

| 易混淆概念 | 区别 |
|---|---|
| **麻醉方案 vs 麻醉记录** | 方案是"计划"（M09-01，术前确定，可改版本）；记录是"事实"（M09-02，术中产生，不可改） |
| **计划给药 vs 实际给药** | 方案里说"利多卡因 2% 3ml"，记录里写"2% 利卡因 2.5ml 于 09:12 球后注射"——**剂量可以不一样**，事实优先 |
| **麻醉开始 vs 手术开始** | 麻醉开始在前（球后注射后需等 8~10 分钟起效），手术开始在后（切皮）。麻醉时长 = 麻醉结束 − 麻醉开始；手术时长 = 手术结束 − 手术开始 |
| **麻醉结束 vs 苏醒** | 麻醉结束是麻醉医生停止给药并宣布麻醉终止；苏醒是患者达到 Aldrete 评分可离开手术间。**两者之间可能相差 5~15 分钟** |
| **Aldrete 评分（M09-02）vs M06-05 的 PADSS** | Aldrete 判断"能否离开手术间"，PADSS 判断"能否离开医院"。眼科全麻手术两者都要，局麻只看 PADSS |
| **麻醉记录中的药 vs 麻醉药品** | 麻醉药用一切麻醉过程的药（含局麻药、镇静药）；"麻醉药品"特指芬太尼类管制药品，须 M14-09 登记 |

### 1.5 模块目标

| 指标 | 目标值 | 说明 |
|---|---|---|
| 麻醉记录完整率 | 100% | 每台有麻醉的手术必须有记录 |
| 体征记录间隔达标率 | ≥98% | 全麻/镇静每 5 分钟一组，局麻每 15 分钟一组 |
| 给药记录与 M14-09 对账一致率 | 100% | 麻醉药品数量必须逐支对齐 |
| 麻醉小结签名率 | 100% | 手术结束 24 小时内完成签名 |
| 麻醉小结平均填写时长 | ≤4 分钟 | 自动生成草稿后人工补充 |
| 体征录入响应 | P95 ≤ 120ms | 护士每 5 分钟一次，必须流畅 |
| 趋势图加载（60 分钟） | P95 ≤ 300ms | 从 15 组数据渲染曲线 |
| 麻醉记录单打印 | ≤3 秒 | 单页 A4 含曲线 |

## 2. 业务范围与边界

### 2.1 范围内

1. **麻醉开始确认**：记录精确到秒的开始时刻，签名确认
2. **生命体征记录**：心率、血压（收缩/舒张/平均）、血氧、呼吸频率、体温、呼末二氧化碳
3. **麻醉深度监测**：Ramsay 镇静评分、BIS 值（全麻）、OAA/S 评分
4. **给药记录**：药名、规格、剂量、单位、途径、给药时刻、给药人
5. **术中事件记录**：眼心反射、球后出血、麻醉不充分、恶心呕吐、呼吸抑制等
6. **麻醉结束**：停止给药、拔管（全麻）、麻醉终止时刻
7. **苏醒评估**：Aldrete 评分、离室判定
8. **麻醉小结**：自动生成草稿 + 人工补充 + 签名
9. **麻醉记录单打印**：A4 单页，含生命体征曲线
10. **麻醉药品联动**：给药时向 M14-09 发起登记请求

### 2.4 依赖清单与失败影响

| 编号 | 依赖 | 接口 | 用途 | 超时 | 失败影响 | 降级 |
|---|---|---|---|---|---|---|
| U-01 | M09-01 | `GET /internal/v1/m09/reception/by-schedule/{id}` | 接收记录与麻醉方案 | 2s | **阻断** | 无降级 |
| U-02 | M01-03 | `GET /internal/v1/mdm/drug/{code}/brief` | 药品名称、规格 | 2s | 无法带出药名 | 降级：手工录入药名 |
| U-03 | M01-07 | `GET /internal/v1/surgery/operations/{code}/full-config` | 默认药品与剂量 | 3s | 无法带出默认药 | 降级：手工增药 |
| U-04 | M03-01 | `GET /internal/v1/patient/{id}/brief` | 患者过敏史 | 2s | **阻断** | 无降级 |
| U-05 | M14-09 | `POST /internal/v1/m14/special/register` | 麻醉药品登记 | 3s | 给药已记录但未登记 | 重试队列 |
| U-06 | M01-02 | `GET /internal/v1/mdm/employee/{id}/brief` | 医护信息 | 2s | 显示 ID | 降级：显示 ID |
| U-07 | M02-06 | `POST /internal/v1/audit/record` | 审计 | 1s | 无影响 | 异步补偿 |
| U-08 | M03-05 | `POST /internal/v1/message/send` | 异常通知 | 2s | 无影响 | 异步重试 |

**三条不可降级铁律：**

1. **U-01 不可降级**：没有 M09-01 的接收记录与麻醉方案，就不知道麻醉方式、不知道同意书是否签署，无法开始麻醉记录。
2. **U-04 不可降级**：过敏史是给药的最后一道闸门。M03-01 不可用时**不允许给药**——患者可能有"利多卡因过敏"记录，绕过后可能过敏性休克。
3. **U-05 失败不阻断但必须标记**：麻醉药品登记是法规要求，但"给药"这个动作已经发生（药推进去了），系统阻断毫无意义。正确做法是：本地记录 `narcotic_register_status='PENDING'`，进入重试队列，同时页面显示红色"麻醉药品待登记"，护士长每日核对。

## 3. 业务模型

### 3.1 麻醉记录主模型

一台手术一条麻醉记录（`schedule_id` 唯一）。记录内部有 6 类子数据：

```
m09_anesthesia_record（麻醉记录主表，1:1 台次）
  ├── m09_vital_sign（体征时间序列，1:N，每 5 分钟一条）
  ├── m09_anesthesia_depth（麻醉深度，1:N，每个时点一条）
  ├── m09_drug_admin（给药记录，1:N，每次给药一条）
  ├── m09_intraop_event（术中事件，1:N）
  ├── m09_recovery_score（Aldrete 评分，1:N，每 15 分钟一次）
  └── m09_anesthesia_summary（麻醉小结，1:1）
```

**为什么拆成 6 张表而不是 1 张宽表：**

1. **访问模式完全不同**：体征是"每 5 分钟一行"，一台 60 分钟手术 13 行；给药是"事件驱动"，一台平均 5 行；小结是"一次写入"。宽表会让每个空字段浪费空间。
2. **增长速率差 10 倍**：体征一天 55 台 × 13 = 715 行；给药 55 × 5 = 275 行；小结 55 行。合并后单表 15 年约 390 万行，其中 60% 是小结的 NULL 字段。
3. **导出与打印的正确性**：麻醉记录单需要"体征曲线 + 给药时间点标注在曲线上"。这要求体征与给药能分别按时间排序后合并渲染，而不是从一张表的混合行里挑。

### 3.2 麻醉记录状态机

```
        ANESTHESIA_STARTED（M09-01 触发，创建记录）
                │ confirm_start
                ▼
           IN_PROGRESS ──────────────────┐
                │                        │
                │                        │ 术中异常不能"暂停"
                │ end_anesthesia         │ 只能记录事件后继续
                ▼                        │
            ENDED                        │
                │ score_aldrete          │
                ▼                        │
         RECOVERY_SCORING                │
                │ exit_room              │
                ▼                        │
           COMPLETED ────────────────────┘
                │ write_summary
                ▼
        SUMMARY_SIGNED
```

**6 态：**

| 状态 | 语义 | 可执行操作 |
|---|---|---|
| `IN_PROGRESS` | 麻醉进行中 | 体征、深度、给药、事件、结束 |
| `ENDED` | 麻醉已结束，待苏醒评分 | 体征、Aldrete 评分 |
| `RECOVERY_SCORING` | 苏醒评分中 | 体征、Aldrete 评分、离室 |
| `COMPLETED` | 已离室，待写小结 | 写小结 |
| `SUMMARY_SIGNED` | 小结已签名 | 只读 |
| `CANCELLED` | 麻醉开始后意外终止（如紧急转开胸） | 只读 |

**为什么没有 `PAUSED` 态：** 麻醉不能暂停。如果因为设备故障暂时中断，麻醉医生仍在监护患者，记录仍在进行。中断要作为术中事件记录，不能把记录状态挂起——挂起会让"这段空白时间发生了什么"无法追溯。

### 3.3 生命体征记录模型

**采集方式两种：**

| 方式 | 触发 | 频率 | 覆盖率 |
|---|---|---|---|
| 设备自动采集 | 监护仪对接，每 5 秒推送 | 每 5 秒存原始值，每 5 分钟聚合一行 | 全麻/镇静 100% |
| 人工录入 | 护士读数后手动输入 | 每 5 分钟（全麻）/ 每 15 分钟（局麻） | 局麻 100%，全麻兜底 |

**采集字段 8 项：**

| 字段 | 单位 | 全麻 | 局麻 | 说明 |
|---|---|---|---|---|
| heart_rate | 次/分 | 必 | 必 | |
| systolic_bp | mmHg | 必 | 必 | |
| diastolic_bp | mmHg | 必 | 必 | |
| mean_bp | mmHg | 自动算 | 自动算 | (SBP + 2×DBP) / 3 |
| spo2 | % | 必 | 必 | |
| respiratory_rate | 次/分 | 必 | 选 | 自主呼吸时才有意义 |
| temperature | ℃ | 选 | 选 | 手术超过 60 分钟建议监测 |
| etco2 | mmHg | 必（插管/喉罩） | ❌ | 呼末二氧化碳 |

**间隔达标判定：**

| 麻醉层级 | 要求间隔 | 允许偏差 |
|---|---|---|
| GENERAL / SEDATION | 5 分钟 | ±2 分钟 |
| REGIONAL（球后/球周） | 15 分钟 | ±5 分钟 |
| LOCAL / TOPICAL | 15 分钟 | ±5 分钟 |

"体征记录间隔达标率"= 相邻两组体征时间差在允许范围内的组数 / 应记录组数。

### 3.4 给药记录模型

**7 个要素：**

| 要素 | 说明 | 来源 |
|---|---|---|
| 药品（drug_code / drug_name / spec） | | M01-03 |
| 剂量（dose + dose_unit） | 如 `2.5` + `ml` | 录入 |
| 途径（route_code） | 球后注射 / 静脉 / 滴眼 | 录入 |
| 给药时刻（administered_at） | 精确到秒 | 系统时钟 |
| 给药人（administered_by） | 麻醉医生或主刀 | 当前用户 |
| 与方案的关系 | 是否默认药品、是否超量 | 对比 M09-01 方案 |
| 特殊标记 | 麻醉药品 / 局部麻醉药 / 抗胆碱药 | M01-03 分类快照 |

**给药记录的 5 种偏差类型（自动检测）：**

| 偏差类型 | 判定 | 处理 |
|---|---|---|
| 非默认药品 | 药不在 M09-01 方案中 | 需填"加药原因"（≥5 字） |
| 剂量超计划 | 实际剂量 > 计划剂量 × 1.2 | 标记 `dose_exceed`，需主任确认（配置项） |
| 剂量偏小 | 实际剂量 < 计划剂量 × 0.8 | 标记 `dose_under`，需填原因 |
| 途径不符 | 实际途径 ≠ 方案途径 | 需填原因 |
| 重复给药 | 同药在 5 分钟内重复 | 弹窗二次确认（防误点） |

**为什么剂量偏小也要标记：** 方案 3ml 实际只给 2ml，可能因为"患者诉疼痛已停止"或"计划改变"。不标记会让术后统计"平均用药量"偏离实际。

### 3.5 麻醉深度评估模型

**三种方法对应三种麻醉：**

| 方法 | 适用 | 取值 | 频率 |
|---|---|---|---|
| **Ramsay 镇静评分** | 镇静 / 局麻辅以镇静 | 1~6 分 | 每 10 分钟 |
| **OAA/S 评分**（Observer's Assessment of Alertness/Sedation） | 镇静 | 1~5 分 | 每 10 分钟 |
| **BIS 值**（脑电双频指数） | 全麻 | 0~100 | 每 5 分钟（设备自动） |

**Ramsay 镇静评分标准：**

| 分值 | 状态 |
|---|---|
| 1 | 焦虑、躁动不安 |
| 2 | 合作、定向力良好、安静 |
| 3 | 对指令有反应 |
| 4 | 对轻扣眉间反应敏捷 |
| 5 | 对轻扣眉间反应迟钝 |
| 6 | 对轻扣眉间无反应 |

**目标区间：** 眼科球后阻滞辅以镇静的患者，理想 Ramsay 2~3 分（安静但可唤醒，能配合"向上看"指令）。Ramsay ≥4 会失去配合能力，增加眼球穿孔风险。

**BIS 目标区间：** 全麻维持期 40~60。BIS <40 说明麻醉过深（术后认知功能障碍风险），>60 说明麻醉过浅（可能出现术中知晓）。

**为什么眼科特别强调"可配合"：** 白内障手术患者需要在术中按医生指令转动眼球。镇静过深会导致眼球上翻（Bell 现象），术野暴露困难，甚至需要临时改全麻。

### 3.6 术中事件模型

**9 类事件：**

| 事件类型 | 严重度 | 典型场景 | 必填字段 |
|---|---|---|---|
| `OCULOCARDIAC_REFLEX` 眼心反射 | HIGH | 球后阻滞或牵拉眼外肌时心率骤降 | 心率最低值、处理措施 |
| `RETROBULBAR_HEMORRHAGE` 球后出血 | HIGH | 球后注射后眼球突出、结膜下血肿 | 出血量、是否改期 |
| `GLOBE_PERFORATION` 眼球穿孔 | CRITICAL | 球后针误入眼球 | 处理、是否转住院 |
| `INADEQUATE_ANESTHESIA` 麻醉不充分 | MEDIUM | 患者术中有痛感 | 补药量与时机 |
| `NAUSEA_VOMITING` 恶心呕吐 | MEDIUM | 镇静或全麻后 | 处理措施 |
| `RESPIRATORY_DEPRESSION` 呼吸抑制 | HIGH | 镇静过量 SpO2 <90% | 最低 SpO2、处理措施 |
| `BRADYCARDIA` 心动过缓 | MEDIUM | HR <50 | 最低心率、处理措施 |
| `HYPOTENSION` 低血压 | MEDIUM | SBP <90 或较基线降 >30% | 最低血压、处理措施 |
| `OTHER` 其他 | — | — | 描述 |

**眼心反射的处理必须记录具体动作**（球后阻滞后常见，发生率约 1.5%）：

- 停止操作
- 静脉注射阿托品 0.5mg
- 吸氧
- 观察心率恢复时间

不记录具体动作，事后无法判断"当时处理是否及时恰当"。

### 3.7 麻醉结束与苏醒模型

**三个时刻：**

| 时刻 | 定义 | 用途 |
|---|---|---|
| `anesthesia_start_at` | 第一次给麻醉药（来自 M09-01） | 麻醉时长起点 |
| `anesthesia_end_at` | 停止给药 + 手术结束（由麻醉医生确认） | 麻醉时长终点；M16 计费依据 |
| `exit_room_at` | Aldrete ≥9 分，可离开手术间 | 手术间占用终点 |

**麻醉时长 = anesthesia_end_at − anesthesia_start_at**
**苏醒时长 = exit_room_at − anesthesia_end_at**

**Aldrete 评分 5 项（离室标准）：**

| 项目 | 2 分 | 1 分 | 0 分 |
|---|---|---|---|
| 活动（自主或指令） | 四肢活动自如 | 两个肢体活动 | 不能活动 |
| 呼吸 | 深呼吸并咳嗽 | 呼吸困难/浅表 | 无呼吸 |
| 循环（血压） | 较麻醉前 ±20% | ±20~50% | ±50% 以上 |
| 意识 | 完全清醒 | 可唤醒 | 无反应 |
| 血氧（SpO2） | 吸空气 ≥92% | 吸氧 >90% | 吸氧 <90% |

**满分 10 分，≥9 分可离室。**

**为什么眼科全麻还要评 Aldrete：** 全麻患者从"手术结束"到"能安全搬动"需要 5~15 分钟。若直接送回病房，搬运过程中可能出现气道梗阻。Aldrete 是手术间到病房的安全交接依据。

**局麻为什么不评 Aldrete：** 局麻患者全程清醒，离室直接由 M06-05 的 PADSS 判定。若局麻也强求 Aldrete，护士会随意填 10 分，评分失去意义。

### 3.8 麻醉小结模型

**自动生成草稿的 6 段内容：**

| 段落 | 内容 | 来源 |
|---|---|---|
| 一、麻醉方法 | 麻醉方式、给药途径 | M09-01 方案 + 实际 |
| 二、麻醉过程 | 麻醉起效时间、术中配合度、术中事件 | 事件表汇总 |
| 三、用药情况 | 药品、剂量、总用量 | 给药记录汇总 |
| 四、生命体征 | 最高/最低心率、血压、血氧 | 体征表聚合 |
| 五、麻醉效果 | 是否满意、有无麻醉不充分 | 事件表 + 人工 |
| 六、并发症与处理 | 术中事件 + 处理 + 转归 | 事件表 |

**人工必须补充的 3 项：**

1. **麻醉效果评价**：满意 / 基本满意 / 不满意（含原因）
2. **术后随访建议**：无 / 常规 / 关注眼压 / 关注心率
3. **签名**

**为什么自动生成草稿：** 麻醉医生一天做 8~12 台手术，每台小结从零写要 3~5 分钟，一天 40 分钟。系统能填的部分（用药、体征极值、事件）自动填，麻醉医生只需 3 项判断与签名，压缩到 ≤4 分钟。

### 3.9 麻醉药品联动模型

**触发条件：** 给药的药品 `is_narcotic = TRUE`（芬太尼、瑞芬太尼、舒芬太尼）

**联动流程：**

```
给药记录保存
    │
    ├─> 本地事务提交（保证给药记录不丢）
    │
    └─> 异步调 M14-09 POST /internal/v1/m14/special/register
            │
            ├─ 成功 → narcotic_register_status = 'SUCCESS'，记 registered_deposit_no
            │
            └─ 失败 → narcotic_register_status = 'PENDING'，进 Celery 重试队列
                      重试 5 次（10/30/60/120/300 秒）
                      全部失败 → 'FAILED'，页面红色告警，护士长每日核对
```

**对账规则（每日 04:00 定时）：**

```
SUM(m09_drug_admin.dose) WHERE is_narcotic AND status='SUCCESS'
    vs
M14-09 当日麻醉药品出库数量
```

不等则告警麻醉科主任 + 药房主任。

**为什么给药与登记必须分两步：** 给药是临床动作，登记是管理动作。如果强制"登记成功才能保存给药记录"，M14-09 一故障麻醉医生就无法记录给了药——但药已经推进去了，记录必须落下。**临床事实永远优先于管理流程。**

### 3.10 全流程时序

| 时刻 | 角色 | 事件 | 系统动作 |
|---|---|---|---|
| T+0 | 麻醉医生 | 从 M09-01 点"开始麻醉" | 创建麻醉记录，状态 `IN_PROGRESS` |
| T+0 | 麻醉医生 | 确认麻醉开始 | 记录 `confirmed_at`，开始体征计时 |
| T+5 | 麻醉医生/护士 | 录入体征 | 写 `m09_vital_sign` |
| T+8 | 麻醉医生 | 球后注射利多卡因 3ml | 写 `m09_drug_admin` |
| T+9 | — | 心率骤降至 42 | 系统自动检测（<50）→ 弹窗建议记录眼心反射 |
| T+10 | 麻醉医生 | 记录眼心反射 + 阿托品 0.5mg | 写 `m09_intraop_event` + `m09_drug_admin` |
| T+12 | 麻醉医生 | 评估 Ramsay 2 分 | 写 `m09_anesthesia_depth` |
| T+45 | 主刀 | 手术结束 | 通知麻醉医生 |
| T+46 | 麻醉医生 | 停止给药 + 确认麻醉结束 | 状态 `ENDED` |
| T+58 | 麻醉医生 | Aldrete 评分 10 分 | 状态 `RECOVERY_SCORING` |
| T+58 | 麻醉医生 | 确认离室 | 状态 `COMPLETED`，回写 M06-05 |
| 术后 1h | 麻醉医生 | 写麻醉小结并签名 | 状态 `SUMMARY_SIGNED` |

**为什么把体征曲线放主界面而不是单独的"监护"页面：**

麻醉医生在术中需要同时看三件事：生命体征趋势、给了什么药、发生了什么事件。这三件事有强关联——心率骤降发生在球后注射后 30 秒，如果分三个页面看，医生要来回切换才能建立因果链。

一屏内并排正是为了让因果关系可视化。

**为什么用曲线而不用表格：** 表格看单个数值，曲线看趋势。麻醉医生真正关心的是"心率在往下走还是在往上走"——表格需要 13 行数据心算，曲线一眼可见。

**字段说明：**

| 区域 | 字段 | 必填 | 说明 |
|---|---|---|---|
| 一~四 | 自动生成 | — | 只读，来自结构化数据 |
| 五、麻醉效果 | 评价等级 | ★ | 满意/基本满意/不满意 |
| | 说明 | 不满意必填 | ≥10 字 |
| 六、并发症 | 自动生成 | — | 可追加 |
| 术后随访建议 | 选项 | ★ | 4 选 1 |
| 签名 | 手写/指纹 | ★ | |

**交互说明：**

| 操作 | 触发 | 结果 |
|---|---|---|
| 打开页面 | 进入 | 自动生成一~四、六段 |
| 修改自动内容 | 双击段落 | 进入可编辑态，修改留痕 `is_manual_edited=true` |

**校验规则：**

| 编号 | 规则 | 说明 |
|---|---|---|
| V-50 | 未选麻醉效果评价 | 阻断提交 |
| V-51 | 不满意未填说明 | 阻断 |
| V-52 | 未选随访建议 | 阻断 |
| V-53 | 未签名 | 阻断 |
| V-54 | 超过 24 小时未签名 | 每日 09:00 提醒 |

**为什么把"麻醉效果"与"随访建议"留给人工而其他自动生成：**

- 麻醉效果是**主观医学判断**。系统能算"用时 45 分钟、用了 5 种药、发生 1 次事件"，但"这次麻醉是否满意"只有麻醉医生能判。自动填"满意"会让签名变成橡皮图章。
- 随访建议是**临床决策**。系统能知道患者有青光眼，但不能决定"是否需要关注眼压"——这取决于术中是否用了散瞳药、血压波动如何等综合判断。

细节性事实自动填，判断性内容必须人工。这条原则贯穿整个 M06/M09。

### 6.2 错误码规范

"""
M09-02 麻醉记录与用药 —— 服务层。
"""
from __future__ import annotations

import logging
import uuid

from decimal import Decimal

from sqlalchemy import and_, func, select, text

from app.clients.m03 import MpiClient
from app.clients.m06 import M06Client

from app.clients.m14 import M14SpecialDrugClient
from app.core.exceptions import BizException
from app.models.m09_02 import (
    M09AldreteScore, M09AnesthesiaDepth, M09AnesthesiaEvent, M09AnesthesiaRecord,
    M09AnesthesiaSummary, M09DrugAdmin, M09VitalSign,
)
from app.services.m09_02_rules import (
    ALDRETE_MIN_TOTAL, DEPTH_TARGET_RANGE, NARCOTIC_DRUG_PREFIXES,
    VITAL_SAFE_RANGE, evaluate_aldrete, suggest_events_from_vitals,
)

logger = logging.getLogger("m09.anesthesia")

CENT = Decimal("0.01")


def _money(v) -> Decimal:
    return Decimal(str(v)).quantize(CENT, rounding="ROUND_HALF_UP")


class AnesthesiaService:
    """M09-02 麻醉记录服务。"""

    # ==================== 麻醉开始 ====================

    @classmethod
    async def start(cls, db: AsyncSession, body, user) -> Dict[str, Any]:
        """确认麻醉开始，创建麻醉记录。

        ① 幂等：按 schedule_id 查已有记录
        ② 拉取 M09-01 接收记录与方案
        ③ 校验方案已确认、同意书已签署
        ④ 校验患者过敏史（阻断）
        ⑤ 建记录
        ⑥ 回写 M06-04 on-anesthesia-start
        """
        # ① 幂等
        exists = (await db.execute(
            select(M09AnesthesiaRecord).where(
                M09AnesthesiaRecord.schedule_id == body.schedule_id,
                M09AnesthesiaRecord.is_deleted.is_(False),
            )
        )).scalar_one_or_none()
        if exists is not None:
            return cls._record_dict(exists, is_duplicate=True)

        # ② 拉取 M09-01
        reception = await M09ReceptionClient.get_by_schedule(body.schedule_id)
        if reception is None:
            raise BizException("0902002", "台次不存在或未接收")

        # ③ 校验方案与同意书
        plan = reception.get("plan") or {}
        if plan.get("status") != "CONFIRMED":
            raise BizException("0902003", "麻醉方案未确认")
        consent = reception.get("consent") or {}
        if consent.get("status") != "SIGNED":
            raise BizException("0902004", "麻醉知情同意未签署")

        # ④ 过敏史校验（不可降级）
        try:
            patient = await MpiClient.get_brief(reception["patient_id"])
        except Exception:
            logger.error("MPI unavailable, block anesthesia start, schedule=%s", body.schedule_id)
            raise BizException("0902030", "患者过敏史服务不可用，暂停麻醉")

        # ⑤ 建记录
        record = M09AnesthesiaRecord(
            record_no=cls._next_record_no(reception["or_code"], reception["seq_no"], body.schedule_id),
            schedule_id=body.schedule_id,
            reception_id=reception["reception_id"],
            apply_id=reception.get("apply_id"),
            patient_id=reception["patient_id"],
            patient_name=reception["patient_name"],
            operation_code=reception["operation_code"],
            operation_name=reception["operation_name"],
            eye_side=reception.get("eye_side"),
            or_code=reception["or_code"],
            seq_no=reception["seq_no"],
            anesthesia_code=plan["anesthesia_code"],
            anesthesia_name=plan["anesthesia_name"],
            anesthesia_type=plan["anesthesia_type"],
            anesthesia_level=plan.get("anesthesia_level"),
            anesthesia_doctor_id=reception.get("anesthesia_doctor_id"),
            anesthesia_doctor_name=reception.get("anesthesia_doctor_name"),
            surgeon_id=reception.get("surgeon_id"),
            surgeon_name=reception.get("surgeon_name"),
            anesthesia_start_at=body.anesthesia_start_at or datetime.now(),
            plan_id=plan.get("plan_id"),
            plan_snapshot=plan,
            allergy_snapshot={
                "drug_allergies": patient.get("drug_allergies", []),
                "local_anesthetic_allergy": patient.get("local_anesthetic_allergy", False),
            },
            status="IN_PROGRESS",
            confirmed_at=datetime.now(),
            confirmed_by=user["employee_id"],
            created_by=user["employee_id"],
            trace_id=uuid.uuid4().hex[:16],
        )
        db.add(record)
        try:
            await db.flush()
        except IntegrityError:
            # 并发下另一请求已插入
            await db.rollback()
            existing = (await db.execute(
                select(M09AnesthesiaRecord).where(M09AnesthesiaRecord.schedule_id == body.schedule_id)
            )).scalar_one_or_none()
            return cls._record_dict(existing, is_duplicate=True)

        await db.commit()

        # ⑥ 回写 M06-04
        writeback = await M06Client.on_anesthesia_start(body.schedule_id, record.anesthesia_start_at)

        logger.info("anesthesia started", extra={
            "module": "M09-02", "action": "start", "record_id": record.id,
            "schedule_id": body.schedule_id, "operator": user["employee_id"],
        })
        result = cls._record_dict(record, is_duplicate=False)
        result["m06_writeback"] = writeback
        return result

    # ==================== 生命体征 ====================

    @classmethod
    async def record_vitals(cls, db: AsyncSession, record_id: int, body, user) -> Dict[str, Any]:
        """录入体征。

        ① 校验记录状态
        ② 校验数值安全范围
        ③ 校验收缩压>舒张压
        ④ 校验全麻必须呼末CO2
        ⑤ 计算平均压与序号
        ⑥ 检测异常项并建议事件
        """
        record = await cls._get_record(db, record_id)
        if record.status not in ("IN_PROGRESS", "ENDED", "RECOVERY_SCORING"):
            raise BizException("0902006", "麻醉记录状态不允许录入体征")

        # ② 安全范围
        for field, (lo, hi) in VITAL_SAFE_RANGE.items():
            val = getattr(body, field, None)
            if val is None:
                continue
            if not (lo <= float(val) <= hi):
                raise BizException("0902007", "体征数值超出安全范围：%s=%s" % (field, val))

        # ③ 血压
        if body.sbp <= body.dbp:
            raise BizException("0902008", "收缩压必须大于舒张压")

        # ④ 全麻必填呼末CO2
        if record.anesthesia_type in ("GENERAL", "COMBINED") and body.etco2 is None:
            raise BizException("0902009", "全麻必须记录呼末二氧化碳")

        # ⑤ 计算
        mean_bp = int(round((body.sbp + 2 * body.dbp) / 3))
        seq_no = (await db.execute(
            select(func.coalesce(func.max(M09VitalSign.seq_no), 0)).where(
                M09VitalSign.record_id == record_id,
            )
        )).scalar_one() + 1

        last = (await db.execute(
            select(M09VitalSign).where(M09VitalSign.record_id == record_id)
            .order_by(M09VitalSign.recorded_at.desc()).limit(1)
        )).scalar_one_or_none()
        interval = (
            int((body.recorded_at - last.recorded_at).total_seconds() // 60)
            if last is not None else 0
        )
        required = cls._vital_interval(record.anesthesia_type)

        vital = M09VitalSign(
            record_id=record_id,
            schedule_id=record.schedule_id,
            seq_no=seq_no,
            recorded_at=body.recorded_at or datetime.now(),
            heart_rate=body.heart_rate,
            systolic_bp=body.sbp,
            diastolic_bp=body.dbp,
            mean_bp=mean_bp,
            spo2=body.spo2,
            respiratory_rate=body.respiratory_rate,
            temperature=body.temperature,
            etco2=body.etco2,
            source=body.source,
            interval_minutes=interval if last is not None else None,
            is_interval_ok=(interval <= required + 2) if last is not None else True,
            recorded_by=user["employee_id"],
            recorded_by_name=user.get("employee_name"),
        )
        db.add(vital)

        # ⑥ 异常检测
        abnormal_items = cls._detect_abnormal(vital)
        suggested_events = suggest_events_from_vitals(vital)
        vital.abnormal_items = abnormal_items
        await db.commit()

        return {
            "vital_id": vital.id,
            "record_id": record_id,
            "recorded_at": vital.recorded_at.isoformat(),
            "mean_bp": mean_bp,
            "seq_no": seq_no,
            "interval_minutes": interval,
            "is_interval_ok": vital.is_interval_ok,
            "abnormal_items": abnormal_items,
            "suggested_events": suggested_events,
            "next_due_at": (vital.recorded_at + timedelta(minutes=required)).isoformat(),
        }

    # ==================== 给药 ====================

    @classmethod
    async def add_drug(cls, db: AsyncSession, record_id: int, body, user) -> Dict[str, Any]:
        """新增给药记录。

        ① 校验记录状态
        ② 拉取患者过敏史（不可降级）
        ③ 校验局麻药过敏 / 青光眼禁忌
        ④ 判定偏差类型
        ⑤ 校验偏差原因
        ⑥ 写记录
        ⑦ 麻醉药品 → 异步登记 M14-09
        """
        record = await cls._get_record(db, record_id)
        if record.status not in ("IN_PROGRESS", "ENDED"):
            raise BizException("0902006", "麻醉记录状态不允许给药")

        if body.administered_at > datetime.now() + timedelta(minutes=1):
            raise BizException("0902037", "给药时刻不能晚于当前时间")

        # ② 患者信息
        try:
            patient = await MpiClient.get_brief(record.patient_id)
        except Exception:
            raise BizException("0902030", "患者过敏史服务不可用，暂停给药")

        drug = await cls._get_drug_brief(body.drug_code)
        if drug is None:
            raise BizException("0902011", "药品不存在或已停用")

        # ③ 禁忌校验
        if drug.get("is_local_anesthetic") and patient.get("local_anesthetic_allergy"):
            raise BizException("0902022", "患者对局麻药过敏，禁止使用")
        if drug.get("is_anticholinergic") and patient.get("glaucoma"):
            raise BizException("0902023", "患者有青光眼，禁用抗胆碱药")

        # ④ 偏差判定
        plan = record.plan_snapshot or {}
        plan_drugs = {d["drug_code"]: d for d in plan.get("drugs", [])}
        deviation_type, is_from_plan = cls._judge_deviation(body, plan_drugs)
        if deviation_type not in (None, "NONE") and not body.deviation_reason:
            raise BizException("0902012", "给药与方案有偏差，必须填写原因")

        # ⑤ 超量标记
        exceed = False
        if body.drug_code in plan_drugs:
            plan_dose = Decimal(str(plan_drugs[body.drug_code]["planned_dose"]))
            if body.dose > plan_dose * Decimal("1.2"):
                exceed = True

        # ⑥ 写记录
        is_narcotic = (drug.get("drug_category") or "").upper() in NARCOTIC_DRUG_PREFIXES or drug.get("is_narcotic", False)
        admin = M09DrugAdmin(
            record_id=record_id,
            schedule_id=record.schedule_id,
            seq_no=await cls._next_drug_seq(db, record_id),
            drug_code=body.drug_code,
            drug_name=drug["drug_name"],
            spec=drug.get("spec"),
            dose=body.dose,
            dose_unit=body.dose_unit,
            route_code=body.route_code,
            administered_at=body.administered_at or datetime.now(),
            administered_by=user["employee_id"],
            administered_by_name=user.get("employee_name"),
            is_from_plan=is_from_plan,
            deviation_type=deviation_type,
            deviation_reason=body.deviation_reason,
            dose_exceed=exceed,
            is_narcotic=is_narcotic,
            is_local_anesthetic=drug.get("is_local_anesthetic", False),
            is_anticholinergic=drug.get("is_anticholinergic", False),
            narcotic_register_status="PENDING" if is_narcotic else None,
            remark=body.remark,
        )
        db.add(admin)
        await db.commit()

        # ⑦ 麻醉药品登记
        if is_narcotic:
            from app.tasks.m09_02 import register_narcotic_task
            register_narcotic_task.delay(admin.id)

        total = (await db.execute(
            select(func.coalesce(func.sum(M09DrugAdmin.dose), 0)).where(
                M09DrugAdmin.record_id == record_id,
                M09DrugAdmin.drug_code == body.drug_code,
                M09DrugAdmin.is_voided.is_(False),
            )
        )).scalar_one()

        return {
            "drug_id": admin.id,
            "record_id": record_id,
            "drug_code": admin.drug_code,
            "drug_name": admin.drug_name,
            "spec": admin.spec,
            "dose": float(admin.dose),
            "dose_unit": admin.dose_unit,
            "route_code": admin.route_code,
            "administered_at": admin.administered_at.isoformat(),
            "is_from_plan": is_from_plan,
            "is_narcotic": is_narcotic,
            "narcotic_register_status": admin.narcotic_register_status,
            "deviation_type": deviation_type,
            "deviation_reason": admin.deviation_reason,
            "dose_exceed": exceed,
            "total_dose_same_drug": float(total),
        }

    @classmethod
    async def end(cls, db: AsyncSession, record_id: int, body, user) -> Dict[str, Any]:
        """确认麻醉结束。"""
        record = await cls._get_record(db, record_id)
        if record.status != "IN_PROGRESS":
            raise BizException("0902006", "当前状态不允许结束麻醉")

        if body.anesthesia_end_at <= record.anesthesia_start_at:
            raise BizException("0902014", "麻醉结束时刻必须晚于开始时刻")

        if record.anesthesia_type in ("GENERAL", "COMBINED") and body.extubation is None:
            raise BizException("0902016", "全麻必须记录是否拔管")

        record.anesthesia_end_at = body.anesthesia_end_at
        record.anesthesia_duration_minutes = int(
            (body.anesthesia_end_at - record.anesthesia_start_at).total_seconds() // 60
        )
        record.extubation = body.extubation
        record.extubation_at = body.extubation_at
        record.end_note = body.note
        record.ended_by = user["employee_id"]
        record.ended_at = datetime.now()
        record.status = "ENDED"
        await db.commit()

        last_vital = (await db.execute(
            select(M09VitalSign).where(M09VitalSign.record_id == record_id)
            .order_by(M09VitalSign.recorded_at.desc()).limit(1)
        )).scalar_one_or_none()
        gap = (
            int((body.anesthesia_end_at - last_vital.recorded_at).total_seconds() // 60)
            if last_vital else 9999
        )
        warnings = []
        if gap > 15:
            warnings.append({"code": "VITAL_GAP", "message": "体征最后一次记录距结束 %d 分钟" % gap})

        drugs = (await db.execute(
            select(M09DrugAdmin).where(
                M09DrugAdmin.record_id == record_id,
                M09DrugAdmin.is_voided.is_(False),
            )
        )).scalars().all()

        return {
            "record_id": record_id,
            "status": record.status,
            "anesthesia_start_at": record.anesthesia_start_at.isoformat(),
            "anesthesia_end_at": record.anesthesia_end_at.isoformat(),
            "anesthesia_duration_minutes": record.anesthesia_duration_minutes,
            "extubation": record.extubation,
            "extubation_at": record.extubation_at.isoformat() if record.extubation_at else None,
            "vital_last_at": last_vital.recorded_at.isoformat() if last_vital else None,
            "vital_gap_minutes": gap,
            "warnings": warnings,
            "drug_summary": cls._summarize_drugs(drugs),
            "event_count": (await db.execute(
                select(func.count()).select_from(M09AnesthesiaEvent).where(
                    M09AnesthesiaEvent.record_id == record_id
                )
            )).scalar_one(),
            "next_step": "ALDRETE_SCORING",
        }

        if record.status not in ("ENDED", "RECOVERY_SCORING"):

            consciousness=body.consciousness,

            total_score=total,

        )
        db.add(score)
        record.status = "RECOVERY_SCORING"
        await db.commit()

            "zero_items": zero_items,

            "next_due_at": None if score.can_exit_room else (score.scored_at + timedelta(minutes=15)).isoformat(),
            "note": "达到离室标准" if score.can_exit_room else "未达标，%d 分钟后复评" % 15,

    # ==================== 麻醉小结 ====================

    @classmethod
    async def build_summary_draft(cls, db: AsyncSession, record_id: int, user) -> Dict[str, Any]:
        """生成麻醉小结草稿（6 段自动生成）。"""
        record = await cls._get_record(db, record_id)
        vitals = (await db.execute(
            select(M09VitalSign).where(M09VitalSign.record_id == record_id)
            .order_by(M09VitalSign.recorded_at)
        )).scalars().all()
        drugs = (await db.execute(
            select(M09DrugAdmin).where(
                M09DrugAdmin.record_id == record_id,
                M09DrugAdmin.is_voided.is_(False),
            ).order_by(M09DrugAdmin.administered_at)
        )).scalars().all()
        events = (await db.execute(
            select(M09AnesthesiaEvent).where(M09AnesthesiaEvent.record_id == record_id)
            .order_by(M09AnesthesiaEvent.occurred_at)
        )).scalars().all()

        # 一、麻醉方法
        method_parts = [record.anesthesia_name]
        block_drugs = [d for d in drugs if d.route_code in ("RETROBULBAR", "PERIBULBAR", "SUBCONJUNCTIVAL", "SUB_TENON")]
        iv_drugs = [d for d in drugs if d.route_code in ("IV", "IM")]
        if block_drugs:
            method_parts.append("（%s）" % " + ".join(
                "%s %s%s" % (d.drug_name, d.dose, d.dose_unit) for d in block_drugs
            ))
        if iv_drugs:
            method_parts.append(" + 静脉给药（%s）" % " + ".join(
                "%s %s%s" % (d.drug_name, d.dose, d.dose_unit) for d in iv_drugs
            ))

        # 二、麻醉过程
        first_iv = iv_drugs[0].administered_at if iv_drugs else None
        onset_min = (
            int((first_iv - record.anesthesia_start_at).total_seconds() // 60)
            if first_iv else None
        )
        process_text = "麻醉起始 %s。" % record.anesthesia_start_at.strftime("%H:%M")
        if block_drugs:
            process_text += " %s 行%s。" % (block_drugs[0].administered_at.strftime("%H:%M"), "球后阻滞" if block_drugs[0].route_code == "RETROBULBAR" else "局部阻滞")
        if onset_min is not None:
            process_text += " 起效时间约 %d 分钟。" % max(onset_min, 1)

        # 三、用药情况
        drug_text = " │ ".join(
            "%s %s%s" % (d.drug_name, d.dose, d.dose_unit) for d in drugs
        )

        # 四、生命体征
        hr_min = min((v.heart_rate for v in vitals if v.heart_rate), default=None)
        hr_max = max((v.heart_rate for v in vitals if v.heart_rate), default=None)
        sbp_min = min((v.systolic_bp for v in vitals if v.systolic_bp), default=None)
        sbp_max = max((v.systolic_bp for v in vitals if v.systolic_bp), default=None)
        dbp_min = min((v.diastolic_bp for v in vitals if v.diastolic_bp), default=None)
        dbp_max = max((v.diastolic_bp for v in vitals if v.diastolic_bp), default=None)
        spo2_min = min((v.spo2 for v in vitals if v.spo2), default=None)
        spo2_max = max((v.spo2 for v in vitals if v.spo2), default=None)

        hr_min_time = next(
            (v.recorded_at.strftime("%H:%M") for v in vitals if v.heart_rate == hr_min), ""
        ) if hr_min is not None else ""

        vital_text = (
            "心率 %s~%s 次/分%s；收缩压 %s~%s mmHg；舒张压 %s~%s mmHg；血氧 %s~%s%%"
            % (
                hr_min, hr_max, ("（最低 %s 于 %s）" % (hr_min, hr_min_time)) if hr_min_time else "",
                sbp_min, sbp_max, dbp_min, dbp_max, spo2_min, spo2_max,
            )
        )

        # 六、并发症与处理
        if events:
            event_text = "\n".join(
                "%s %s，%s。" % (
                    e.occurred_at.strftime("%H:%M"),
                    e.event_type_name or e.event_type,
                    e.description,
                )
                for e in events
            )
        else:
            event_text = "术中无特殊并发症。"

        draft = {
            "record_id": record_id,
            "record_no": record.record_no,
            "patient_summary": {
                "patient_name": record.patient_name,
                "gender": record.gender,
                "age": record.age,
                "operation_name": record.operation_name,
                "eye_side": record.eye_side,
            },
            "anesthesia_summary": {
                "anesthesia_name": record.anesthesia_name,
                "anesthesia_type": record.anesthesia_type,
                "anesthesia_doctor_name": record.anesthesia_doctor_name,
                "surgeon_name": record.surgeon_name,
                "or_code": record.or_code,
                "anesthesia_start_at": record.anesthesia_start_at.isoformat(),
                "anesthesia_end_at": record.anesthesia_end_at.isoformat() if record.anesthesia_end_at else None,
                "anesthesia_duration_minutes": record.anesthesia_duration_minutes,
            },
            "sections": {
                "method": "".join(method_parts),
                "process": process_text,
                "drugs": drug_text,
                "vitals": vital_text,
                "effect": None,
                "complications": event_text,
            },
            "vital_stats": {
                "hr_min": hr_min, "hr_max": hr_max,
                "sbp_min": sbp_min, "sbp_max": sbp_max,
                "dbp_min": dbp_min, "dbp_max": dbp_max,
                "spo2_min": spo2_min, "spo2_max": spo2_max,
                "count": len(vitals),
            },
            "drug_count": len(drugs),
            "event_count": len(events),
            "required_manual": ["effect_evaluation", "followup_suggestion", "signature"],
        }
        return draft

    @classmethod
    async def sign_summary(cls, db: AsyncSession, record_id: int, body, user) -> Dict[str, Any]:
        """签名提交麻醉小结。"""
        record = await cls._get_record(db, record_id)
        if record.status != "COMPLETED":
            raise BizException("0902006", "当前状态不允许签名小结")

        existing = (await db.execute(
            select(M09AnesthesiaSummary).where(M09AnesthesiaSummary.record_id == record_id)
        )).scalar_one_or_none()
        if existing is not None and existing.signed_at is not None:
            raise BizException("0902020", "小结已签名，不可重复提交")

        if body.effect_evaluation == "UNSATISFIED" and (
            not body.effect_note or len(body.effect_note.strip()) < 10
        ):
            raise BizException("0902018", "不满意评价必须填写说明（≥10 字）")
        if not body.signature_image:
            raise BizException("0902019", "未签名不可提交")

### 6.7 专题：为什么体征、给药、事件是同一条时间轴上的三件事

一台白内障手术的麻醉"故事"是这样的：

> 09:00 开始麻醉 → 09:08 球后注射利多卡因 → **09:09 心率骤降到 42**（眼心反射）→ 09:10 静注阿托品 → 09:11 心率恢复到 68 → 09:12 Ramsay 2 分 → 09:20 体征平稳 → 09:46 手术结束

如果这三类数据分散在三个页面：

- 麻醉医生看到心率 42 的曲线，要切到"给药"页才能确认"是球后注射后 40 秒"
- 要再切到"事件"页才能看到"上一次眼心反射是怎么处理的"

**三次页面切换，每次 2~3 秒，中间还要记住上一个数字。** 而在紧急情况下（心率骤降），麻醉医生的注意力应该全在患者身上，不是在看界面。

所以 M09-02 的核心设计决策是：**所有术中数据以时间为唯一排序轴**。

在工作站（P01）上，三类数据同时呈现：
- 曲线区：体征时间序列
- 右侧栏：给药按时间倒序 + 事件按时间倒序
- 曲线上的标记点：给药时刻用小三角标注，事件时刻用红点标注

这样麻醉医生看到心率骤降的点位时，向上 30 秒就有一个三角标（球后注射），向下 60 秒有一个红点（眼心反射记录）——因果链在一屏内可见。

**这条设计对数据结构的影响：**

所有子表都必须有 `recorded_at` / `administered_at` / `occurred_at` 这类时间字段，且**都是精确到秒的 TIMESTAMP 而非 DATE**。这与 M06-05 的留观记录不同——留观的体征是 15 分钟粒度，日期级足够；麻醉是秒级操作，日期级完全不够。

**这条设计对接口的影响：**

`API-04 GET /anesthesia/workbench/{schedule_id}` 是聚合接口，一次返回三类数据的合并时间轴。如果让前端发三个请求，就会有三次网络往返与三个时间点的数据（可能出现"给药 09:10 已到达但事件 09:09 还没到"的不一致）。

**四条关键设计说明：**

1. **巡回护士有 execute 无 sign**：护士协助录入体征是护理操作；麻醉小结签名是麻醉医生的法定责任，不可代签。

2. **主刀医生只有 query**：术中主刀关心的是手术本身，麻醉记录由麻醉医生负责。主刀可查看便于术后复盘，但不应有录入权限（否则会出现"主刀代填麻醉记录"的违规情况）。

3. **IT 管理员无 query**：麻醉记录含患者过敏史、既往病史、用药史、生命体征，属高度敏感医疗数据。运维需排查时由医务科授权临时账号（2 小时有效）。

4. **系统管理员无任何权限**：最小权限原则。系统管理员负责部署与备份，不应看到任何患者医疗信息。

### 9.3 数据权限

```python
def apply_m09_scope(stmt, Model, user):
    """M09-02 数据权限注入。"""
    role_codes = set(user.get("role_codes", []))

    # 全院级：麻醉科主任、医务科、质控科、病案室、手术室护士长
    if role_codes & {"ANESTHESIA_DIRECTOR", "MEDICAL_AFFAIRS", "QC_STAFF",
                     "RECORDS_ROOM", "OR_HEAD_NURSE"}:
        return stmt

    # 本人级：麻醉医生只能看自己参与的记录
    if "ANESTHESIA_DOCTOR" in role_codes:
        return stmt.where(
            or_(
                Model.anesthesia_doctor_id == user["employee_id"],
                Model.anesthesia_start_at >= func.current_date() - timedelta(days=7),
            )
        )

    # 巡回护士：只能看当日全部
    if "CIRCULATING_NURSE" in role_codes:
        return stmt.where(Model.anesthesia_start_at >= func.current_date())

    # 主刀：只能看自己主刀的手术的麻醉记录
    if "SURGEON" in role_codes:
        return stmt.where(Model.surgeon_id == user["employee_id"])

    return stmt.where(text("1 = 0"))
```
