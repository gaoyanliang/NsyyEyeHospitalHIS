## 1. 模块概述

### 1.1 模块定位

M09-06 回答一个问题：**「这个月手术室到底做得怎么样？瓶颈在哪？」**

### 1.2 为什么独立成子模块

**理由一：统计口径是「制度」，不是「计算」。**

同一个「手术间利用率」有至少四种算法：

| 算法 | 公式 | 本院实测值 |
|---|---|---|
| A 按台次时长 | Σ实际手术时长 / Σ可用时长 | 72% |
| B 按占用时长（含清台） | Σ(缝合−切皮) / Σ可用时长 | 58% |
| C 按进间到离间 | Σ(离间−进间) / Σ可用时长 | 81% |
| D 按麻醉开始到离院 | Σ(离院−麻醉开始) / Σ可用时长 | **94%** |

差异高达 **36 个百分点**。若无统一口径，手术室主任报 94%、院领导算 72%、财务算 58%，三方各执一词，管理决策无从谈起。M09-06 把口径显式定义为**可配置、可版本化、可追溯**的规则（`m09_metric_config`），每次口径变更都有版本号与生效日期。

**理由二：统计的业务语义与技术实现完全不同。**

业务方问的是「为什么取消率从 4% 涨到 9%」；技术要做的是「从 6 张表 JOIN 50 万行、按 5 个维度分组、算 12 个派生指标、再与上期对比」。这两件事混在同一次代码里，会让 M09-01~05 的 Service 层掺入 30% 的只读统计逻辑，且每次改指标都要动业务代码。

**理由三：统计结果是「给外面看的」，属对外承诺。**

- **等级评审**：《三级医院评审标准（2022 年版）》把「手术室利用效率」「手术安全核查合格率」「麻醉相关死亡率」列为核心指标
- **医保**：DRG/DIP 付费需要按手术级别与术式分类的台次与费用数据
- **院务会月报**：院长每月看一次，错了会被当场质问

统计错一期，可能导致评审扣分、拨付金额变化、管理判断失误。

**理由四：技术形态与业务接口相反。**

业务接口是「点操作」——P95 ≤ 200ms，读当前状态，走主键或小范围索引。统计接口是「范围聚合」——扫描时间区间 + 多维分组，走预聚合宽表或大范围索引。放在一起要么业务接口被统计拖慢，要么统计为了让业务快而写不出。

### 1.4 概念辨析

**辨析一：运营统计 ≠ 质控统计。**

| 维度 | 运营统计（M09-06） | 质控统计（属 M09-04/05 与医务科） |
|---|---|---|
| 关注 | 效率、产能、准时、成本 | 安全、合规、并发症、差错 |
| 主要用户 | 手术室主任、护士长、院领导 | 医务科、质控科 |
| 核心指标 | 手术间利用率、周转时间、准点率 | 核实合格率、危急事件率、遗留物率 |
| 数据时效 | 日/月为主，允许 T+1 | 事件驱动，实时 |
| 出错后果 | 管理判断偏差、资源错配 | 医疗事故、法律追责 |

两者都在 M09-06 的报表中呈现，但 M09-06 只做「聚合计算」，**不做质控判定**。质控结论由医务科依据原始记录自行判定。

**辨析二：台次 ≠ 患者。**

- 一个患者可能一天做两台手术（双眼分别手术，罕见但存在）
- 一台次可能因术中转住院而延长为 4 小时
- 统计「手术量」时，院方关心的是**台次**（人力物力消耗），医保关心的是**人次**

M09-06 的所有指标都明确标注口径是按台次还是按患者。

**辨析三：计划值 ≠ 实际值。**

| 概念 | 来源 | 用途 |
|---|---|---|
| 计划手术开始 `planned_start_at` | M06-03 排程 | 排班、患者告知 |
| 计划手术结束 `planned_end_at` | M06-03（含术式标准时长） | 排程容量计算 |
| 实际进间 `or_in_at` | M09-01 | **手术间占用起点** |
| 实际切皮 `incision_at` | M09-03 | 净手术时长起点 |
| 实际缝合 `suture_at` | M09-03 | 净手术时长终点 |
| 实际离间 `or_out_at` | M09-02 | 手术间占用终点 |
| 计划离院 `expected_leave_at` | M06-05 | 患者预期出院 |
| 实际离院 `actual_leave_at` | M06-05 | 患者实际出院 |

**准点率用哪一对值，是口径问题。** 本院默认 `planned_start_at` vs `incision_at`（切皮才算真正开始），但允许配置为 `planned_start_at` vs `or_in_at`（进间即算开始，更宽容）。

**辨析四：延期 ≠ 取消。**

- **取消**（`CANCELLED`）：手术没做。患者在管理系统中的状态是「这台手术不做了」
- **延期**（`POSTPONED`）：手术做了但换了一天/换了个时段。M06-03 用 `RESCHEDULED` 状态链表达
- **术中转住院**（`TRANSFER_INPATIENT`）：手术做了但患者转住院。既不是取消也不是延期

统计「手术失约率」时，这三者必须分开——把它们合并会把「及时发现问题转住院」这一正确决策错误地归为失误。

### 1.5 模块目标

| 指标 | 定义 | 目标值 | 当前典型值 |
|---|---|---|---|
| 手术间利用率 | 按口径 A（实际手术时长/可用时长） | ≥ 75% | 58~72% |
| 台次周转时间 | 上一台离间到下一台进间的中位数 | ≤ 25 分钟 | 30~42 分钟 |
| 首台准点率 | 08:30 前切皮的首台占比 | ≥ 90% | 62~78% |
| 台次准点率 | 偏差 ≤ 10 分钟的台次占比 | ≥ 85% | 60~72% |
| 报表生成及时率 | 次日 03:00 前完成的日统计占比 | 100% | — |
| 报表数字可解释率 | 每个数字可下钻到明细台次的占比 | 100% | — |
| 实时看板刷新延迟 | 手术进行中状态变化到看板可见 | ≤ 60 秒 | — |
| 指标口径覆盖率 | 有版本化口径定义的指标占比 | 100% | — |

## 2. 业务范围与边界

### 2.1 范围内

1. **实时运营看板**：今日手术间状态、进行中台次、待开台、超时、异常告警
2. **周期统计报表**：日/周/月/季/年，5 维度 × 36 指标
3. **专题瓶颈分析**：取消原因、周转时间、准点偏移、麻醉恢复、器械耗用、并发症
4. **运营目标管理**：院级目标设定、科室分解、达成追踪、预警
5. **指标口径配置**：指标定义、计算公式、口径版本、生效日期、审批
6. **对外上报**：推 M22 报表中心、导出等级评审数据包、导出医保 DRG 数据
7. **术中事件统计**：按事件类型、严重度、科室、医生分布

## 3. 业务模型

### 3.1 指标体系：三层模型

```
┌──────────────────────────────────────────────────────────────────────────┐
│                        三层指标模型                                       │
└──────────────────────────────────────────────────────────────────────────┘

  L1 原子指标（18 项）—— 从业务表直接聚合，不可再分解
  ┌────────────────────────────────────────────────────────────────────┐
  │ A-01 台次总数         COUNT(台次)                                   │
  │ A-02 完成台次         COUNT(状态=COMPLETED)                         │
  │ A-03 取消台次         COUNT(状态=CANCELLED)                         │
  │ A-04 首台台次         COUNT(当日房间首台)                            │
  │ A-05 准点台次         COUNT(偏差 ≤ 阈值)                            │
  │ A-06 手术间可用分钟   SUM(可用时段时长)                              │
  │ A-07 手术间占用分钟   SUM(离间 − 进间)                              │
  │ A-08 净手术分钟       SUM(缝合 − 切皮)                              │
  │ A-09 周转分钟合计     SUM(下一台进间 − 上一台离间)                  │
  │ A-10 周转次数         COUNT(周转对)                                 │
  │ A-11 麻醉台次         COUNT(有麻醉记录)                             │
  │ A-12 麻醉分钟         SUM(麻醉结束 − 麻醉开始)                      │
  │ A-13 器械清点台次     COUNT(有清点单)                               │
  │ A-14 器械不符次数     COUNT(清点不符发生)                            │
  │ A-15 植入物件数       COUNT(植入明细)                               │
  │ A-16 植入金额         SUM(植入物金额)                               │
  │ A-17 术中事件数       COUNT(事件)                                   │
  │ A-18 术中危急事件数   COUNT(事件严重度=CRITICAL)                     │
  └────────────────────────────────────────────────────────────────────┘
                              │
                              ▼
  L2 派生指标（14 项）—— 原子指标的四则运算
  ┌────────────────────────────────────────────────────────────────────┐
  │ D-01 手术间利用率     = A-07 / A-06                                 │
  │ D-02 净手术效率       = A-08 / A-07                                 │
  │ D-03 平均周转时间     = A-09 / A-10                                 │
  │ D-04 首台准点率       = 首台准点 / A-04                             │
  │ D-05 台次准点率       = A-05 / A-02                                 │
  │ D-06 取消率           = A-03 / (A-02 + A-03)                        │
  │ D-07 日均台次         = A-01 / 有效工作日                           │
  │ D-08 日均手术间台次   = A-01 / (房间数 × 有效工作日)                 │
  │ D-09 麻醉占比         = A-11 / A-02                                 │
  │ D-10 平均麻醉时长     = A-12 / A-11                                 │
  │ D-11 清点覆盖率       = A-13 / A-02                                 │
  │ D-12 清点不符率       = A-14 / A-13                                 │
  │ D-13 件均植入金额     = A-16 / A-15                                 │
  │ D-14 术中事件率       = A-18 / A-02                                 │
  └────────────────────────────────────────────────────────────────────┘
                              │
                              ▼
  L3 复合指标（4 项）—— 派生指标加权
  ┌────────────────────────────────────────────────────────────────────┐
  │ C-01 运营效率得分 = D-01×0.3 + D-02×0.3 + (100−D-03×2)×0.2          │
  │                    + D-05×0.2                                       │
  │ C-02 安全得分     = (100−D-12×100)×0.5 + (100−D-14×500)×0.5         │
  │ C-03 产能得分     = D-07×0.6 + D-08×0.4                             │
  │ C-04 综合得分     = C-01×0.4 + C-02×0.3 + C-03×0.3                  │
  └────────────────────────────────────────────────────────────────────┘
```

**为什么分三层：**

1. **原子可复用。** 一个「台次总数」被 6 个派生指标使用。若每个指标各写一条 SQL，改口径时要改 6 处
2. **口径可追溯。** 任一派生指标的异常都能回到原子指标核对（「利用率异常低是不是占用分钟算错了」）
3. **性能可控。** 原子指标可一次性预聚合成宽表，派生指标在宽表上做四则运算（微秒级）

### 3.2 统计维度与粒度

**五个维度：**

| 维度 | 取值来源 | 示例 |
|---|---|---|
| DIM_HOSPITAL | 全院 | 全院 |
| DIM_DEPT | `m06_or_schedule.dept_id` | 白内障科、眼底病科、青光眼科 |
| DIM_DOCTOR | `m06_or_schedule.surgeon_id` | 张明（主任医师） |
| DIM_ROOM | `m06_or_schedule.room_code` | OR-01、OR-02、OR-03、OR-04 |
| DIM_PROCEDURE | `m06_or_schedule.operation_code` | 白内障超声乳化摘除+人工晶体植入术 |

**五种粒度：**

| 粒度 | 数据来源 | 用途 |
|---|---|---|
| DAILY | 日统计任务 02:00 | 日报、走势图 |
| WEEKLY | 从 DAILY 汇总 | 周报 |
| MONTHLY | 月统计任务 1 日 02:30 | 月报、院务会 |
| QUARTERLY | 从 MONTHLY 汇总 | 季度分析 |
| YEARLY | 从 MONTHLY 汇总 | 年度评审、医保结算 |

**为什么周/季/年从日/月汇总而非各算一遍：** 一致性。若各算一遍，可能出现「12 个月之和 ≠ 年合计」（因为按月统计时点不同导致的边界差异）。从源头汇总保证恒等。

### 3.3 统计口径五要素

每个指标必须显式定义五件事：

| 要素 | 说明 | 示例（手术间利用率） |
|---|---|---|
| **分子** | 计算式 | `SUM(or_out_at − or_in_at)` |
| **分母** | 计算式 | `SUM(可用时段时长)` |
| **排除规则** | 哪些记录不计入 | 排除设备维修、排除教学演示台次 |
| **时间口径** | 按哪个时刻归入统计区间 | 按**台次日期**（`schedule_date`），不按记录创建日 |
| **维度** | 可拆分的维度 | 全院 / 科室 / 医生 / 手术间 / 术式 |

**时间口径的重要性：**

真实场景——10 月 31 日 22:40 进间、11 月 1 日 00:20 离间的急诊手术，算哪个月？

| 口径 | 影响 |
|---|---|
| 按台次日期（10-31） | 归 10 月。优点：与排程台账一致，月报表可对得上台数 |
| 按离间日期（11-01） | 归 11 月。缺点：10 月 31 日那天显示 0 台，与现场记忆不符 |
| 按结束但落在区间内的部分时长 | 拆分。缺点：一台手术拆两个月，台数怎么算？ |

**本院统一采用「按台次日期」**，并在报表中明确标注。跨月台次在 `m09_oper_metric` 中通过 `cross_month_flag` 标记，便于人工核查。

### 3.4 指标口径版本化

```
  V1（2026-01-01 生效）
    ├── D-06 取消率 = A-03 / (A-02 + A-03)
    └── D-05 台次准点率 = A-05 / A-02，阈值 10 分钟
                │
                │ 2026-07-01 变更（取消率排除术中转住院）
                ▼
  V2（2026-07-01 生效）
    ├── D-06 取消率 = A-03 / (A-02 + A-03)，A-03 排除 TRANSFER_INPATIENT
    └── 其余同 V1
                │
                │ 2026-11-01 变更（准点阈值从 10 分钟收紧到 8 分钟）
                ▼
  V3（2026-11-01 生效）
    ├── D-05 台次准点率 = A-05 / A-02，阈值 8 分钟
    └── 其余同 V2
```

**为什么必须版本化：**

1. **历史不可重算。** 2026 年 3 月的报表是按 V1 算的（取消率 4.2%）。若 7 月改成 V2 后重算，3 月变成 3.8%。报表数字变了，但没有任何人的工作发生变化——这会让管理者怀疑整个系统
2. **跨版本对比需标注。** 报表页显示「6 月 vs 7 月取消率」时，若口径不同必须加脚注「6 月按 V1，7 月按 V2」
3. **口径变更是管理决策。** 双人复核（手术室主任提出 + 医务科批准）+ 生效日期延后（≥24 小时），与 M09-01 的危急阈值变更同一套机制

### 3.5 台次生命周期与统计窗口

```
  计划               实际                         统计可用时刻
  ────               ────                         ────────────
  planned_start_at   or_in_at ──► incision_at ──► suture_at ──► or_out_at
      │                 │            │              │            │
      │                 │            │              │            │
      │          ┌──────┴────────────┴──────────────┴────────────┐
      │          │  手术间占用 = or_out_at − or_in_at            │
      │          └───────────────────────────────────────────────┘
      │                       ┌──────────────────────┐
      │                       │ 净手术 = suture − 切皮 │
      │                       └──────────────────────┘
      │
      ├──► 准点判定：incision_at − planned_start_at（默认口径）
      │
      └──► 周转时间：下一台取 or_in_at，本台取 or_out_at

  ┌─────────────────────────────────────────────────────────────────┐
  │ 统计可用性判定（R-02）：                                         │
  │  · 手术进行中（or_out_at 为 NULL）→ 不纳入占用时长统计           │
  │  · 手术已完成但缺 or_in_at → 纳入台数，不纳入时长，标记 INCOMPLETE│
  │  · 取消台次 → 纳入取消率分子，不纳入时长                         │
  └─────────────────────────────────────────────────────────────────┘
```

**为什么手术进行中的台次不统计时长：** 若统计，下午 3 点看板显示「今日利用率 45%」（因为还有 6 台在台上），到晚上变 78%。管理者在 15:00 看到 45% 会误判「今天很闲」，实际是数据还没产生。**看板必须区分「已完成」与「进行中」两套数字**。

### 3.6 预聚合宽表模型

```
┌──────────────────────────────────────────────────────────────────────────┐
│                     m09_oper_metric 预聚合宽表                            │
└──────────────────────────────────────────────────────────────────────────┘

  行键 = (stat_date, granularity, dimension_type, dimension_value)
  ─────────────────────────────────────────────────────────────────────────
  例：
  (2026-10-23, DAILY,  DIM_HOSPITAL,  'ALL')          全院当日
  (2026-10-23, DAILY,  DIM_DEPT,      'DEPT_0102')    白内障科当日
  (2026-10-23, DAILY,  DIM_DOCTOR,    'EMP_10023')    张明医生当日
  (2026-10-23, DAILY,  DIM_ROOM,      'OR-01')        OR-01 当日
  (2026-10-23, DAILY,  DIM_PROCEDURE, 'OP_CAT_IOL')   白内障术式当日
  (2026-10,    MONTHLY,DIM_HOSPITAL,  'ALL')          全院当月
  ...

  列 = 18 原子指标 + 14 派生指标 + 4 复合指标 = 36 个数值列
       + metric_version（口径版本）
       + source_row_count（源行数，用于对账）
       + computed_at / computed_by（生成信息）
```

**为什么用宽表而非实时计算：**

| 方案 | 30 天报表 P95 | 1 年报表 P95 | 复杂度 |
|---|---|---|---|
| 实时 6 表 JOIN 计算 | 约 2.8 秒 | 约 22 秒 | 每条 SQL 100+ 行 |
| 预聚合宽表 | **48 毫秒** | **120 毫秒** | 每日一条 ETL |

**58 倍差距。** 且实时计算无法支持「按任意维度排序 36 个指标」这种交互式分析——用户点一下排序就要跑一次全量计算。

**宽表的代价与应对：**

- 代价一：T+1 延迟。今日数据 02:00 才生成
- 应对：**实时看板（L1）不走宽表**，直接查业务表算今日 12 项指标（当日数据量小，可接受），宽表只服务周期报表（L2/L3）
- 代价二：宽表与业务表可能不一致
- 应对：**每日对账**（R-30）——重算台次总数与宽表比对，不一致则告警并重算

### 3.7 时效模型

```
  当日 00:00 ~ 23:59   业务发生
        │
        ▼
  次日 00:30          M06-06 完整性检查（不涉及 M09-06）
  次日 01:00          M16-09 全院日结（数据库压力最大）
        │
        ▼
  次日 02:00          ★ M09-06 日统计任务（5 维度 × 18 原子指标）
  次日 02:20          目标达成检查，发预警
        │
        ▼
  次日 03:00          日统计完成截止（SLA）
        │
        ▼
  次日 06:00          日报推送 M22
  次日 06:20          月报（仅每月 1 日）
```

**为什么 02:00：** 01:00 是全院日结（M16-09），数据库压力最大。错开 1 小时，避免统计任务与日结事务互相等锁。

**为什么 SLA 是 03:00 而非 06:00：** 若 02:00 任务失败，还有 1 小时重试窗口。若 SLA 设为 06:00，失败后没有重试余地，早 8 点院领导看报表时会发现空白。

**为什么日报推 M22 在 06:00：** 让数据稳定 4 小时（期间可能有补录、修正），避免「06:00 推了一次，08:00 又因为补录重推」造成 M22 端反复更新。

### 3.8 告警与目标模型

**目标两级分解：**

```
  院级目标（年度，医务科设定）
    D-01 手术间利用率 ≥ 75%
    D-05 台次准点率   ≥ 85%
    D-06 取消率       ≤ 5%
         │
         │  按历史台次占比加权分解
         ▼
  科室目标（季度）
    白内障科：利用率 ≥ 78%（该科台次占比 42%，术式成熟）
    眼底病科：利用率 ≥ 68%（术式复杂，正常偏低）
    青光眼科：利用率 ≥ 72%

  医生层面：只展示，不分解目标
```

**为什么医生层面不分解：**

1. 48 位主刀逐一设 36 项指标的目标，管理成本极高（每季度 48×36 = 1,728 个数字要核）
2. 术式差异极大（注药 10 分钟 vs 玻切 120 分钟），简单分解不公平
3. 医生绩效应由科室内部管理，系统只提供数据

**四级预警：**

| 级别 | 触发条件 | 通知对象 | 响应要求 |
|---|---|---|---|
| INFO | 达到目标的 90% | 手术室主任 | 关注 |
| WARN | 达到目标的 80% | 科主任 | 一周内说明 |
| HIGH | 达到目标的 70% | 医务科 | 当月整改 |
| CRITICAL | 低于目标 70% 或连续 3 月未达标 | 分管院长 | 专项分析 |

**为什么用「目标的 80%」而非绝对阈值：** 不同指标量级差异极大（D-06 取消率目标 5%，D-05 准点率目标 85%）。若用绝对值设阈值（如「取消率 > 3% 告警」），改目标线后阈值就要改。用相对比例（目标的 80%）可与目标解耦。

### 3.9 数据质量与对账

**四类数据质量问题：**

| 问题 | 现象 | 影响 | 处理 |
|---|---|---|---|
| **数据缺失** | 台次已完成但 `or_in_at`/`or_out_at` 为 NULL | 时长类指标偏低 | 标记 `INCOMPLETE`，纳入「数据完整率」指标 |
| **时序颠倒** | `or_out_at < or_in_at` | 出现负时长 | 该台次不计入时长统计，告警 |
| **跨月台次** | 10-31 进间、11-01 离间 | 月末/月初数字异常 | 按台次日期归属，标记 `cross_month_flag` |
| **补录滞后** | 昨日台次今日补录 | 已生成的日统计数字偏小 | 每日对账发现不一致则重算 |

**对账机制（R-30）：**

```
每日 03:00（日统计完成后）
  ├── 重算 5 维度的 A-01 台次总数
  ├── 与 m09_oper_metric 中对应行比对
  ├── 不一致 → 手动重算该维度该日 → 记 diff 日志 → 告警
  └── 一致 → 记 source_row_count（供事后核查）
```

**为什么对账要重算而不是比对数据库计数：** 比对 `COUNT(*)` 只能发现「宽表少了行」，发现不了「宽表的值算错了」。重算并比数值才能发现逻辑错误。

### 3.10 指标可解释性

**每一个数字都必须能下钻到明细台次。**

```
报表：白内障科 2026-10 手术间利用率 72.3%
   │
   └─► 点击下钻 ─► 列出该科室 10 月的全部台次
                    每行含：台次号、日期、手术间、进间、离间、占用分钟、
                            计划时长、是否纳入统计（排除原因）
                    合计：占用 8,420 分钟 / 可用 11,640 分钟 = 72.3%
```

**为什么必须可下钻：**

真实场景——手术室主任看到「眼底病科利用率 58%」，第一反应是「不可能，我们天天加班」。若无下钻，他只能怀疑系统；有下钻，他看到「本月 23 台因设备维修未排程，可用时长按 22 天算而非 26 天」——问题立刻定位到「设备维修台账没录入」。

**下钻的三个要求：**

1. **明细行必须含「是否纳入统计」标志与排除原因**
2. **明细合计必须与报表数字完全相等**（不能有「其他调整项」）
3. **明细可按任意列排序**（按时长降序找最长的台次）

| 分布 | 分档柱状图 | 按阈值分档，标出长尾 |

| 改进建议 | 规则推导 | 基于归因占比 ≥15% 的项生成 |

**交互说明：**

| 操作 | 触发 | 结果 |
|---|---|---|
| 切换专题 | 下拉选择 | 重新加载 |
| 点击归因行 | 单击 | 下钻到该类台次明细 |
| 点击建议 | 单击 | 跳转对应模块的问题页 |
| 导出专题报告 | 点击 | 生成含图表 PDF |

**校验规则：**

| 编号 | 规则 | 说明 |
|---|---|---|
| V-16 | 归因占比合计必须 = 100% | 差额归入「其他」 |
| V-17 | 改进建议仅当事项占比 ≥15% 时生成 | 低于 15% 的项不足以为管理决策依据 |
| V-18 | 「其他」占比 > 20% 时提示补充归因规则 | 说明现有归因维度覆盖不足 |

**为什么改进建议用规则不用 AI：**

生成式 AI 能写出流畅的管理建议，但可能空洞或错误（如建议「加强培训」而不指出培训谁、培训什么）。规则式建议的每一条都**可追溯到一个具体数据**（「上一台超时占 40.9%」），管理者能验证、能反驳、能落地。**不可验证的建议比没有建议更糟**——它会消耗管理者的信任。

**长尾归因的判定规则（T-01 周转时间）：**

```
对每一对相邻台次（前一台离间 → 后一台进间），判定周转 > 目标的归因：

  ① 上一台超时：前一台的（缝合 − 计划结束）> 15 分钟  → 归因「上一台超时」
  ② 器械包未就绪：后一台的 M15 器械包齐备时刻 > 前一台离间 + 5 分钟
                    → 归因「器械包未就绪」
  ③ 患者未到：后一台的 M06-04 报到时刻 > 前一台离间 + 10 分钟
                → 归因「患者未到」
  ④ 麻醉医生未到：后一台的 M09-01 麻醉医生到场时刻 > 前二台离间 + 15 分钟
                   → 归因「麻醉医生未到」
  ⑤ 器械清点不符：前一台的 M09-04 存在 MISMATCH 记录
                    → 归因「器械清点不符处置」
  ⑥ 以上均不满足 → 归因「其他」

多重命中时按 ①②③④⑤ 优先级取第一个。
```

**为什么按优先级取第一个：** 一个长周转可能同时满足「上一台超时」与「患者未到」——因为上一台超时导致患者来了还得等。此时责任主体是「上一台超时」，标为「患者未到」会误导改进方向。

```python
    @classmethod
    async def create_version(
        cls,
        body: MetricVersionCreateIn,
        user: Dict[str, Any],
    ) -> MetricVersionOut:
        """新建口径版本。"""
        async with get_session() as db:
            # ① 取基准版本
            base = (
                await db.execute(
                    select(M09MetricVersion)
                    .where(M09MetricVersion.status == "EFFECTIVE")
                    .order_by(M09MetricVersion.effective_at.desc())
                    .limit(1)
                )
            ).scalar_one_or_none()
            if base is None:
                raise BizException("0906005", "无生效中的口径版本")

            # ② 校验生效时间 ≥ 申请后 24 小时
            now = datetime.now()
            earliest = now + timedelta(hours=24)
            if body.effective_at < earliest:
                raise BizException(
                    "0906012",
                    "生效时间须晚于申请时刻 24 小时，最早为 %s"
                    % earliest.strftime("%Y-%m-%d %H:%M"),
                )

            # ③ 校验变更原因
            if len((body.change_reason or "").strip()) < 20:
                raise BizException("0906011", "口径变更原因不得少于 20 字")

            # ④ 复制基准版本的指标定义
            base_metrics = (
                await db.execute(
                    select(M09MetricConfig).where(
                        M09MetricConfig.version_id == base.id,
                        M09MetricConfig.is_deleted.is_(False),
                    )
                )
            ).scalars().all()

            # ⑤ 建新版本
            version = M09MetricVersion(
                version_label=body.version_label,
                status="DRAFT",
                effective_at=body.effective_at,
                change_reason=body.change_reason,
                base_version_id=base.id,
                created_by=user["employee_id"],
            )
            db.add(version)
            await db.flush()

            # ⑥ 复制指标并应用变更
            changed: List[str] = []
            patch = {m.metric_code: m for m in body.metrics}
            for m in base_metrics:
                cfg = M09MetricConfig(
                    version_id=version.id,
                    metric_code=m.metric_code,
                    metric_name=m.metric_name,
                    metric_type=m.metric_type,
                    metric_group=m.metric_group,
                    formula=m.formula,
                    numerator_code=m.numerator_code,
                    denominator_code=m.decoder_code
                    if hasattr(m, "decoder_code")
                    else m.denominator_code,
                    exclude_rules=m.exclude_rules,
                    time_basis=m.time_basis,
                    threshold_value=m.threshold_value,
                    unit=m.unit,
                    sort_no=m.sort_no,
                    description=m.description,
                )
                if m.metric_code in patch:
                    p = patch[m.metric_code]
                    if p.threshold is not None:
                        cfg.threshold_value = p.threshold
                    if p.formula is not None:
                        cfg.formula = p.formula
                    if p.exclude_rules is not None:
                        cfg.exclude_rules = p.exclude_rules
                    changed.append(m.metric_code)
                db.add(cfg)

            await db.commit()

            # ⑦ 清缓存
            await cls._clear_cache()

            return MetricVersionOut(
                version_id=version.id,
                version_label=version.version_label,
                status=version.status,
                effective_at=version.effective_at.isoformat(),
                earliest_allowed_effective_at=earliest.isoformat(),
                changed_metrics=changed,
                next_action="测试计算后提交审批",
            )

            row = (
                await db.execute(
                    select(M09OperMetric).where(
                        M09OperMetric.dimension_type == dimension_type,
                        M09OperMetric.dimension_value == dimension_value,
                        M09OperMetric.stat_date >= d1,
                        M09OperMetric.stat_date <= d2,
                        M09OperMetric.granularity == "DAILY",
                    )
                )
            ).first()

            if row is None:
                raise BizException("0906003", "统计结果尚未生成")

            version = (
                await db.execute(
                    select(M09MetricVersion)
                    .where(M09MetricVersion.status == "EFFECTIVE")
                    .order_by(M09MetricVersion.effective_at.desc())
                    .limit(1)
                )
            ).scalar_one_or_none()

            values = {
                "A-01": float(row[0].a01_schedule_count or 0),
            }
            return {
                "metric_code": code,
                "value": values.get(code),
                "metric_version": version.version_label if version else None,
                "date_from": date_from,
                "date_to": date_to,
            }

                raise BizException("0906025", "口径版本未批准")
            return {"id": row.id, "version_label": row.version_label}

        row = (

                    M09MetricVersion.status == "EFFECTIVE",
                    M09MetricVersion.effective_at <= datetime.now(),
                )

        if row is None:

    @classmethod
    async def _today_metrics(
        cls,
        db: AsyncSession,
        day: date,
        user: Dict[str, Any],
    ) -> List[Dict[str, Any]]:
        """今日 8 项指标（已完成台次口径）。"""
        row = (
            await db.execute(
                text(
                    """
                    WITH done AS (
                        SELECT s.schedule_id,
                               s.room_code,
                               s.planned_start_at,
                               r.or_in_at,
                               r.or_out_at,
                               sr.incision_at,
                               sr.suture_at
                        FROM m06_or_schedule s
                        LEFT JOIN m09_or_reception r
                               ON r.schedule_id = s.schedule_id
                              AND r.is_deleted = FALSE
                        LEFT JOIN m09_surgery_record sr
                               ON sr.schedule_id = s.schedule_id
                              AND sr.is_deleted = FALSE
                        WHERE s.schedule_date = :d
                          AND s.status = 'COMPLETED'
                          AND s.is_deleted = FALSE
                    )
                    SELECT COUNT(*) AS done_count,
                           SUM(
                               EXTRACT(EPOCH FROM (or_out_at - or_in_at)) / 60
                           ) AS occupied_minutes,
                           AVG(
                               EXTRACT(EPOCH FROM (incision_at - planned_start_at)) / 60
                           ) AS avg_start_offset
                    FROM done
                    WHERE or_in_at IS NOT NULL
                      AND or_out_at IS NOT NULL
                      AND or_out_at > or_in_at
                    """
                ).bindparams(d=day)
            )
        ).mappings().first()

        occupied = Decimal(str(row["occupied_minutes"] or 0))

        # 可用分钟 = 可用手术间数 × 每间可用时长
        avail = (
            await db.execute(
                text(
                    """
                    SELECT COUNT(DISTINCT room_code) AS room_count
                    FROM m06_or_schedule
                    WHERE schedule_date = :d
                      AND status <> 'CANCELLED'
                      AND is_deleted = FALSE
                    """
                ).bindparams(d=day)
            )
        ).scalar_one()

        minutes_per_room = Decimal(str(cfg.get("M09.OPER.DAILY_AVAILABLE_MINUTES", 480)))
        room_count = Decimal(str(avail or 0))
        available = room_count * minutes_per_room

        util = safe_div(occupied, available)

        # 清点覆盖
        cnt_row = (
            await db.execute(
                text(
                    """
                    SELECT COUNT(*) AS total,
                           COUNT(*) FILTER (
                               WHERE matched = FALSE
                           ) AS mismatched
                    FROM m09_instrument_count
                    WHERE count_date = :d
                      AND is_deleted = FALSE
                    """
                ).bindparams(d=day)

        ).mappings().first()

                    """
                ).bindparams(d=day)
            )
        ).mappings().first()

        # 术中事件
        evt_row = (
            await db.execute(
                text(
                    """
                    SELECT COUNT(*) AS evt_count,
                           COUNT(*) FILTER (
                               WHERE severity = 'CRITICAL'
                           ) AS critical_count
                    FROM m09_surgery_event
                    WHERE occurred_at::date = :d
                      AND is_deleted = FALSE
                    """
                ).bindparams(d=day)
            )
        ).mappings().first()

        done_count = int(row["done_count"] or 0)
        total = int((await OperDashboardService._count_schedules(db, day, user))["total_schedules"])
        done_ratio = safe_div(done_count, total) or Decimal("0")

        ins_covered = int(cnt_row["total"] or 0)
        ins_mismatch = int(cnt_row["mismatched"] or 0)

        return [
            cls._metric_card("D-01", "手术间利用率", pct(util * 100) if util else None, "%",
                             cfg.get("M09.OPER.TARGET_UTILIZATION", 75), "GTE"),
            cls._metric_card("D-03", "平均周转时间", Decimal("0"), "分钟",
                             cfg.get("M09.OPER.TURNOVER_TARGET_MINUTES", 25), "LTE"),
            cls._metric_card("D-04", "首台准点率", Decimal("0"), "%",
                             cfg.get("M09.OPER.FIRST_CASE_TARGET", 90), "GTE"),
            cls._metric_card("D-05", "台次准点率", Decimal("0"), "%",
                             cfg.get("M09.OPER.PUNCTUAL_TARGET", 85), "GTE"),
            cls._metric_card("D-11", "清点覆盖率",
                             pct(safe_div(ins_covered, done_count) * 100)
                             if done_count else None,
                             "%", 100, "GTE"),
            cls._metric_card("A-14", "清点不符次数", Decimal(ins_mismatch), "次",
                             0, "LTE"),
            cls._metric_card("A-15", "植入物件数",
                             Decimal(int(imp_row["item_count"] or 0)), "枚", None, "NONE"),
            cls._metric_card("A-17", "术中事件数",
                             Decimal(int(evt_row["evt_count"] or 0)), "例", None, "NONE"),
        ]

    @classmethod
    async def _build_alerts(
        cls,
        db: AsyncSession,
        day: date,
        counters: Dict[str, int],
        metrics: List[Dict[str, Any]],
    ) -> List[Dict[str, Any]]:
        """构建告警。"""
        alerts: List[Dict[str, Any]] = []
        cfg = await OperConfigService.get_map()

        # ① 待清台超时
        stale = (
            await db.execute(
                text(
                    """
                    SELECT s.room_code,
                           s.schedule_no,
                           sr.suture_at,
                           a.anesthesia_end_at
                    FROM m06_or_schedule s
                    JOIN m09_surgery_record sr
                      ON sr.schedule_id = s.schedule_id
                     AND sr.is_deleted = FALSE
                    LEFT JOIN m09_anesthesia_record a
                           ON a.schedule_id = s.schedule_id
                          AND a.is_deleted = FALSE
                    WHERE s.schedule_date = :d
                      AND s.status = 'CHECKED_IN'
                      AND sr.suture_at IS NOT NULL
                      AND sr.suture_at > NOW() - INTERVAL '2 hours'
                      AND s.is_deleted = FALSE
                    """
                ).bindparams(d=day)
            )
        ).mappings().all()

        turnover_target = int(cfg.get("M09.OPER.TURNOVER_TARGET_MINUTES", 25))
        for s in stale:
            base = s["suture_at"]
            elapsed = int((datetime.now() - base).total_seconds() / 60)
            if elapsed >= turnover_target:
                alerts.append({
                    "alert_id": "AL%s_%s" % (day.strftime("%Y%m%d"), s["schedule_no"]),
                    "level": "HIGH" if elapsed < turnover_target * 2 else "CRITICAL",
                    "code": "TURNOVER_OVERTIME",
                    "room_code": s["room_code"],
                    "message": "%s 待清台已 %d 分钟，超过目标 %d 分钟"
                               % (s["room_code"], elapsed, turnover_target),
                    "occurred_at": datetime.now().isoformat(),
                })

        # ② 指标未达标
        for m in metrics:
            if m.get("status") == "FAR_BELOW":
                alerts.append({
                    "alert_id": "AL_%s_%s" % (day.strftime("%Y%m%d"), m["code"]),
                    "level": "HIGH",
                    "code": "METRIC_FAR_BELOW",
                    "room_code": None,
                    "message": "%s 为 %s%s，目标 %s%s，严重未达标"
                               % (m["name"], m["value"], m["unit"],
                                  m["target"], m["unit"]),
                    "occurred_at": datetime.now().isoformat(),
                })

        alerts.sort(key=lambda x: {"CRITICAL": 0, "HIGH": 1, "MEDIUM": 2, "LOW": 3}[x["level"]])
        return alerts

    @classmethod
    def _room_card(
        cls,
        room_row: Dict[str, Any],
        current: Optional[Dict[str, Any]],
        nxt: Optional[Dict[str, Any]],
    ) -> Dict[str, Any]:
        """房间卡片。"""
        status = "IDLE"
        if room_row["in_surgery"]:
            status = "IN_SURGERY"
        elif room_row["completed"]:
            status = "IDLE"

        elapsed = None
        if current and current.get("or_in_at"):
            elapsed = int(
                (datetime.now() - current["or_in_at"]).total_seconds() / 60
            )

        return {
            "room_code": room_row["room_code"],
            "room_name": room_row["room_name"],
            "status": status,
            "completed": int(room_row["completed"] or 0),
            "total": int(room_row["total"] or 0),
            "cancelled": int(room_row["cancelled"] or 0),
            "current": {
                "schedule_no": current["schedule_no"],
                "patient_name": current["patient_name"],
                "operation_name": current["operation_name"],
                "surgeon_name": current["surgeon_name"],
                "or_in_at": current["or_in_at"].isoformat()
                             if current.get("or_in_at") else None,
                "incision_at": current["incision_at"].isoformat()
                               if current.get("incision_at") else None,
                "suture_at": current["suture_at"].isoformat()
                             if current.get("suture_at") else None,
                "elapsed_minutes": elapsed,
            } if current else None,
            "next": {
                "schedule_no": nxt["schedule_no"],
                "patient_name": nxt["patient_name"],
                "planned_start_at": nxt["planned_start_at"].isoformat(),
            } if nxt else None,
        }

    @classmethod
    def _metric_card(
        cls,
        code: str,
        name: str,
        value: Optional[Decimal],
        unit: str,
        target: Optional[Any],
        operator: str,
    ) -> Dict[str, Any]:
        """指标卡片：算偏差与状态。"""
        if value is None or target is None:
            return {
                "code": code, "name": name, "value": float(value) if value else None,
                "unit": unit, "target": target, "target_operator": operator,
                "deviation": None, "deviation_unit": unit, "status": "NO_TARGET",
            }

        t = Decimal(str(target))
        if operator == "GTE":
            deviation = pct(value - t)
            if value >= t:
                status = "MEET"
            elif value >= t * Decimal("0.85"):
                status = "BELOW"
            else:
                status = "FAR_BELOW"
        elif operator == "LTE":
            deviation = pct(t - value)
            if value <= t:
                status = "MEET"
            elif value <= t * Decimal("1.15"):
                status = "BELOW"
            else:
                status = "FAR_BELOW"
        else:
            deviation = None
            status = "NO_TARGET"

        deviation_unit = "pp" if unit == "%" else unit
        return {
            "code": code,
            "name": name,
            "value": float(value),
            "unit": unit,
            "target": float(t),
            "target_operator": operator,
            "deviation": float(deviation) if deviation is not None else None,
            "deviation_unit": deviation_unit,
            "status": status,
        }


class OperReportService:
    """周期报表服务（查预聚合宽表）。"""

    @classmethod
    async def get_report(
        cls,
        granularity: str,
        date_from: str,
        date_to: str,
        dimension: str,
        compare: str,
        metric_codes: Optional[str],
        metric_version: Optional[int],
        page: int,
        page_size: int,
        user: Dict[str, Any],
    ) -> ReportOut:
        """周期报表。"""
        d1 = date.fromisoformat(date_from)
        d2 = date.fromisoformat(date_to)
        cls._check_span(granularity, d1, d2)
        cls._check_dimension(dimension)

        codes = [c.strip() for c in metric_codes.split(",")] if metric_codes else None

        async with get_session() as db:
            version = await OperMetricService._resolve_version(db, metric_version)

            # ① 概览（全院）
            rows = (
                await db.execute(
                    text(
                        """
                        SELECT dimension_value,
                               SUM(a01_schedule_count) AS a01,
                               SUM(a02_completed) AS a02,
                               SUM(a03_cancelled) AS a03,
                               SUM(a06_available_minutes) AS a06,
                               SUM(a07_occupied_minutes) AS a07,
                               SUM(a09_turnover_minutes) AS a09,
                               SUM(a10_turnover_count) AS a10,
                               SUM(a11_anesthesia_count) AS a11,
                               SUM(a13_count_cases) AS a13,
                               SUM(a14_mismatch_count) AS a14,
                               SUM(a15_implant_items) AS a15,
                               SUM(a16_implant_amount) AS a16,
                               SUM(a17_event_count) AS a17,
                               SUM(a18_critical_events) AS a18
                        FROM m09_oper_metric
                        WHERE stat_date BETWEEN :d1 AND :d2
                          AND granularity = 'DAILY'
                          AND dimension_type = :dim
                          AND is_deleted = FALSE
                        GROUP BY dimension_value
                        ORDER BY dimension_value
                        """
                    ).bindparams(d1=d1, d2=d2, dim=dimension)
                )
            ).mappings().all()

            overview: List[Dict[str, Any]] = []
            totals = {
                "a01": sum(int(r["a01"] or 0) for r in rows),
                "a02": sum(int(r["a02"] or 0) for r in rows),
                "a03": sum(int(r["a03"] or 0) for r in rows),
                "a06": Decimal(str(sum(Decimal(str(r["a06"] or 0)) for r in rows))),
                "a07": Decimal(str(sum(Decimal(str(r["a07"] or 0)) for r in rows))),
                "a09": Decimal(str(sum(Decimal(str(r["a09"] or 0)) for r in rows))),
                "a10": sum(int(r["a10"] or 0) for r in rows),
            }

            d01 = safe_div(totals["a07"], totals["a06"])
            d03 = safe_div(totals["a09"], totals["a10"])
            d05 = safe_div(
                sum(int(r["a02"] or 0) for r in rows),
                totals["a02"],
            )
            d06 = safe_div(totals["a03"], totals["a02"] + totals["a03"])

            overview.append({
                "metric_code": "D-01", "name": "手术间利用率",
                "value": float(pct(d01 * 100)) if d01 else None,
                "unit": "%", "prev_value": None, "delta": None, "delta_kind": "PP",
            })
            overview.append({
                "metric_code": "D-03", "name": "平均周转时间",
                "value": float(pct(d03)) if d03 else None,
                "unit": "分钟", "prev_value": None, "delta": None, "delta_kind": "ABS",
            })
            overview.append({
                "metric_code": "D-06", "name": "取消率",
                "value": float(pct(d06 * 100)) if d06 else None,
                "unit": "%", "prev_value": None, "delta": None, "delta_kind": "PP",
            })

            # ② 明细行
            items: List[Dict[str, Any]] = []
            for r in rows:
                a01 = int(r["a01"] or 0)
                a02 = int(r["a02"] or 0)
                a03 = int(r["a03"] or 0)
                a06 = Decimal(str(r["a06"] or 0))
                a07 = Decimal(str(r["a07"] or 0))
                a09 = Decimal(str(r["a09"] or 0))
                a10 = int(r["a10"] or 0)

                mv: Dict[str, Any] = {
                    "A-01": a01, "A-02": a02, "A-03": a03,
                    "A-06": float(a06), "A-07": float(a07),
                }
                u = safe_div(a07, a06)
                if u is not None:
                    mv["D-01"] = float(pct(u * 100))
                t = safe_div(a09, a10)
                if t is not None:
                    mv["D-03"] = float(pct(t))
                c = safe_div(a03, a02 + a03)
                if c is not None:
                    mv["D-06"] = float(pct(c * 100))

                if codes:
                    mv = {k: v for k, v in mv.items() if k in codes}

                items.append({
                    "dimension_value": r["dimension_value"],
                    "dimension_name": await cls._dim_name(db, dimension, r["dimension_value"]),
                    "metrics": mv,
                })

            total = len(items)
            start = (page - 1) * page_size
            return ReportOut(
                granularity=granularity,
                date_from=date_from,
                date_to=date_to,
                dimension=dimension,
                metric_version=version["version_label"],
                metric_version_note=await cls._version_note(db, version["id"]),
                compare={"type": compare},
                overview=overview,
                rows=items[start:start + page_size],
                total=total,
                page=page,
                page_size=page_size,
                pages=(total + page_size - 1) // page_size if page_size else 1,
            )

        granularity: str,
        date_from: str,
        date_to: str,
        dimension: str,
        user: Dict[str, Any],
    ) -> ReportTrendOut:

        codes = [c.strip() for c in metric_codes.split(",")][:5]

        d2 = date.fromisoformat(date_to)
        cls._check_span(granularity, d1, d2)

        async with get_session() as db:

            cur = d1

                        select(M09OperMetric).where(

                            M09OperMetric.dimension_value == "ALL",

                ).scalar_one_or_none()
                if row is not None:
                    pt = {"date": cur.isoformat()}
                    for c in codes:
                        pt[c] = cls._trend_value(row, c)
                    points.append(pt)
                cur += timedelta(days=1)

            return ReportTrendOut(
                metric_codes=codes,
                granularity=granularity,
                date_from=date_from,
                date_to=date_to,
                dimension=dimension,
                points=points,
            )

    @classmethod
    def _check_span(cls, granularity: str, d1: date, d2: date) -> None:
        """校验日期跨度。"""
        if d1 > d2:
            raise BizException("0906002", "起始日期不得晚于结束日期")
        limit = SPAN_LIMIT.get(granularity, 92)
        if (d2 - d1).days + 1 > limit:
            raise BizException(
                "0906002",
                "%s 粒度查询跨度不得超过 %d 天" % (granularity, limit),
            )

    @classmethod
    def _check_dimension(cls, dimension: str) -> None:
        """校验维度。"""
        if dimension not in DIMENSIONS:
            raise BizException("0906006", "维度不在支持范围内")

    @classmethod
    async def _dim_name(
        cls,
        db: AsyncSession,
        dimension: str,
        value: str,
    ) -> str:
        """维度值 → 名称。"""
        if dimension == "DIM_HOSPITAL":
            return "全院"
        if dimension == "DIM_DEPT":
            return value
        if dimension == "DIM_DOCTOR":
            return value
        return value

    @classmethod
    async def _version_note(cls, db: AsyncSession, version_id: int) -> str:
        """口径版本说明（强制显示）。"""
        row = (
            await db.execute(
                select(M09MetricVersion).where(M09MetricVersion.id == version_id)
            )
        ).scalar_one_or_none()
        if row is None:
            return ""
        return row.change_reason or ""

    @classmethod
    def _trend_value(cls, row: M09OperMetric, code: str) -> Optional[float]:
        """取指标值。"""
        mapping = {
            "D-01": "d01_utilization_rate",
            "D-03": "d03_avg_turnover",
            "D-05": "d05_punctual_rate",
            "D-06": "d06_cancel_rate",
            "A-01": "a01_schedule_count",
        }
        attr = mapping.get(code)
        if attr is None:
            return None
        val = getattr(row, attr, None)
        return float(val) if val is not None else None


class OperDrillService:

    @classmethod
    async def get_cases(
        cls,
        metric_code: str,
        date_from: str,
        date_to: str,
        dimension_type: str,
        dimension_value: str,
        include_excluded: bool,
        page: int,
        page_size: int,
        user: Dict[str, Any],
    ) -> Dict[str, Any]:
        """明细台次列表（含纳入/排除标志与原因）。"""
        d1 = date.fromisoformat(date_from)
        d2 = date.fromisoformat(date_to)

        where_extra = ""
        params: Dict[str, Any] = {"d1": d1, "d2": d2}
        if dimension_type == "DIM_DEPT":
            where_extra += " AND s.dept_id = :dval"
            params["dval"] = dimension_value
        elif dimension_type == "DIM_DOCTOR":
            where_extra += " AND s.surgeon_id = :dval"
            params["dval"] = dimension_value
        elif dimension_type == "DIM_ROOM":
            where_extra += " AND s.room_code = :dval"
            params["dval"] = dimension_value
        elif dimension_type == "DIM_PROCEDURE":
            where_extra += " AND s.operation_code = :dval"
            params["dval"] = dimension_value

        async with get_session() as db:
            sql = (
                """
                SELECT s.schedule_no,
                       s.schedule_date,
                       s.room_code,
                       s.patient_name,
                       s.operation_name,
                       s.surgeon_name,
                       s.status,
                       r.or_in_at,
                       r.or_out_at,
                       sr.incision_at,
                       sr.suture_at,
                       CASE
                         WHEN s.status = 'CANCELLED' THEN NULL
                         WHEN r.or_in_at IS NULL THEN NULL
                         WHEN r.or_out_at IS NULL THEN NULL
                         WHEN r.or_out_at <= r.or_in_at THEN NULL
                         ELSE EXTRACT(EPOCH FROM (r.or_out_at - r.or_in_at)) / 60
                       END AS occupied_minutes,
                       CASE
                         WHEN s.status = 'CANCELLED' THEN '取消台次'
                         WHEN r.or_in_at IS NULL THEN '缺进间时刻'
                         WHEN r.or_out_at IS NULL THEN '缺离间时刻'
                         WHEN r.or_out_at <= r.or_in_at THEN '时序颠倒'
                         ELSE NULL
                       END AS exclude_reason
                FROM m06_or_schedule s
                LEFT JOIN m09_or_reception r
                       ON r.schedule_id = s.schedule_id
                      AND r.is_deleted = FALSE
                LEFT JOIN m09_surgery_record sr
                       ON sr.schedule_id = s.schedule_id
                      AND sr.is_deleted = FALSE
                WHERE s.schedule_date BETWEEN :d1 AND :d2
                  AND s.is_deleted = FALSE
                """
                + where_extra
                + " ORDER BY s.schedule_date, s.room_code, s.seq_no"
            )
            rows = (await db.execute(text(sql).bindparams(**params))).mappings().all()

        cases: List[Dict[str, Any]] = []
        for r in rows:
            excluded = r["exclude_reason"] is not None
            if excluded and not include_excluded:
                continue
            cases.append({
                "schedule_no": r["schedule_no"],
                "schedule_date": r["schedule_date"].isoformat(),
                "room_code": r["room_code"],
                "patient_name": r["patient_name"],
                "operation_name": r["operation_name"],
                "surgeon_name": r["surgeon_name"],
                "status": r["status"],
                "or_in_at": r["or_in_at"].isoformat() if r["or_in_at"] else None,
                "or_out_at": r["or_out_at"].isoformat() if r["or_out_at"] else None,
                "incision_at": r["incision_at"].isoformat() if r["incision_at"] else None,
                "suture_at": r["suture_at"].isoformat() if r["suture_at"] else None,
                "occupied_minutes": float(pct(r["occupied_minutes"]))
                                    if r["occupied_minutes"] is not None else None,
                "included": not excluded,
                "exclude_reason": r["exclude_reason"],
            })

        total = len(cases)
        start = (page - 1) * page_size
        return {
            "metric_code": metric_code,
            "date_from": date_from,
            "date_to": date_to,
            "items": cases[start:start + page_size],
            "total": total,
            "page": page,
            "page_size": page_size,
            "pages": (total + page_size - 1) // page_size if page_size else 1,
            "included_total": sum(1 for c in cases if c["included"]),
            "excluded_total": sum(1 for c in cases if not c["included"]),
        }

    # ---------- 内部辅助 ----------

    @classmethod
    async def _availability(
        cls,
        db: AsyncSession,
        d1: date,
        d2: date,
        dimension_type: str,
        dimension_value: str,
    ) -> List[Dict[str, Any]]:
        """按手术间列出可用时长与异常说明。"""
        cfg = await OperConfigService.get_map()
        per_day = int(cfg.get("M09.OPER.DAILY_AVAILABLE_MINUTES", 480))

        rows = (
            await db.execute(
                text(
                    """
                    SELECT room_code,
                           COUNT(*) AS work_days
                    FROM m06_or_schedule
                    WHERE schedule_date BETWEEN :d1 AND :d2
                      AND status <> 'CANCELLED'
                      AND is_deleted = FALSE
                    GROUP BY room_code
                    ORDER BY room_code
                    """
                ).bindparams(d1=d1, d2=d2)
            )
        ).mappings().all()

        result: List[Dict[str, Any]] = []
        for r in rows:
            note = None
            if r["work_days"] < int((d2 - d1).days * 0.7):
                note = "该手术间本期间排程天数偏少（含设备维修或未启用）"
            result.append({
                "room_code": r["room_code"],
                "work_days": int(r["work_days"]),
                "minutes_per_day": per_day,
                "total_minutes": int(r["work_days"]) * per_day,
                "note": note,
            })
        return result

    @classmethod
    async def _occupied_minutes(
        cls,
        db: AsyncSession,
        d1: date,
        d2: date,
        dimension_type: str,
        dimension_value: str,
    ) -> Decimal:
        """占用分钟合计（排除无效记录）。"""
        row = (
            await db.execute(
                text(
                    """
                    SELECT COALESCE(
                        SUM(EXTRACT(EPOCH FROM (r.or_out_at - r.or_in_at)) / 60),
                        0
                    ) AS minutes
                    FROM m06_or_schedule s
                    JOIN m09_or_reception r
                      ON r.schedule_id = s.schedule_id
                     AND r.is_deleted = FALSE
                    WHERE s.schedule_date BETWEEN :d1 AND :d2
                      AND s.status <> 'CANCELLED'
                      AND s.is_deleted = FALSE
                      AND r.or_in_at IS NOT NULL
                      AND r.or_out_at IS NOT NULL
                      AND r.or_out_at > r.or_in_at
                    """
                ).bindparams(d1=d1, d2=d2)
            )
        ).scalar_one()
        return Decimal(str(row or 0))

    @classmethod
    async def _case_stats(
        cls,
        db: AsyncSession,
        d1: date,
        d2: date,
        dimension_type: str,
        dimension_value: str,
    ) -> Tuple[int, int, int]:
        """台次统计（总数/纳入/排除）。"""
        row = (
            await db.execute(
                text(
                    """
                    SELECT COUNT(*) AS total,
                           COUNT(*) FILTER (
                               WHERE r.or_in_at IS NOT NULL
                                 AND r.or_out_at IS NOT NULL
                                 AND r.or_out_at > r.or_in_at
                                 AND s.status <> 'CANCELLED'
                           ) AS included
                    FROM m06_or_schedule s
                    LEFT JOIN m09_or_reception r
                           ON r.schedule_id = s.schedule_id
                          AND r.is_deleted = FALSE
                    WHERE s.schedule_date BETWEEN :d1 AND :d2
                      AND s.is_deleted = FALSE
                    """
                ).bindparams(d1=d1, d2=d2)
            )
        ).mappings().first()
        total = int(row["total"] or 0)
        included = int(row["included"] or 0)
        return total, included, total - included


class OperTopicService:
    """专题瓶颈分析服务。"""

    MIN_SUGGEST_RATIO = Decimal("0.15")
    OTHER_LIMIT_RATIO = Decimal("0.20")

    TURNOVER_ATTR_ORDER = [
        "PREV_OVERTIME", "KIT_NOT_READY", "PATIENT_LATE",
        "ANESTHETIST_LATE", "COUNT_MISMATCH", "OTHER",
    ]

    @classmethod
    async def get_topic(
        cls,
        topic_code: str,
        date_from: str,

        dimension: str,
        dimension_value: str,
        user: Dict[str, Any],
    ) -> TopicOut:
        """专题分析（6 类）。"""
        d1 = date.fromisoformat(date_from)
        d2 = date.fromisoformat(date_to)

        async with get_session() as db:
            if topic_code == "T-01":
                return await cls._turnover(db, d1, d2, dimension, dimension_value)
            if topic_code == "T-02":
                return await cls._punctuality(db, d1, d2, dimension, dimension_value)
            if topic_code == "T-03":
                return await cls._cancellation(db, d1, d2, dimension, dimension_value)
            if topic_code == "T-04":
                return await cls._anesthesia(db, d1, d2, dimension, dimension_value)
            if topic_code == "T-05":
                return await cls._instrument(db, d1, d2, dimension, dimension_value)
            if topic_code == "T-06":
                return await cls._complication(db, d1, d2, dimension, dimension_value)
            raise BizException("0906004", "专题编码不存在")

    # ---------- T-01 周转时间 ----------

    @classmethod
    async def _turnover(
        cls,
        db: AsyncSession,
        d1: date,
        d2: date,
        dimension: str,
        dimension_value: str,
    ) -> TopicOut:
        """周转专题：分布 + 长尾归因。"""
        cfg = await OperConfigService.get_map()
        target = Decimal(str(cfg.get("M09.OPER.TURNOVER_TARGET_MINUTES", 25)))

        pairs = await cls._turnover_pairs(db, d1, d2, dimension, dimension_value)

        # 分档统计
        buckets = {
            "<=15": 0, "15-20": 0, "20-25": 0, "25-30": 0, "30-45": 0, ">45": 0,
        }
        values: List[Decimal] = []
        for p in pairs:
            v = p["turnover_minutes"]
            values.append(v)
            if v <= 15:
                buckets["<=15"] += 1
            elif v <= 20:
                buckets["15-20"] += 1
            elif v <= 25:
                buckets["20-25"] += 1
            elif v <= 30:
                buckets["25-30"] += 1
            elif v <= 45:
                buckets["30-45"] += 1
            else:
                buckets[">45"] += 1

        total = len(values)
        avg = pct(sum(values) / total) if total else None
        p90 = pct(sorted(values)[int(total * 0.9)]) if total else None

        # 长尾归因
        long_tail = [p for p in pairs if p["turnover_minutes"] > target]
        attribution: Dict[str, List[Decimal]] = {k: [] for k in cls.TURNOVER_ATTR_ORDER}
        for p in long_tail:
            attr = await cls._turnover_attribution(db, p)
            attribution[attr].append(p["turnover_minutes"])

        attr_rows: List[Dict[str, Any]] = []
        for key in cls.TURNOVER_ATTR_ORDER:
            vals = attribution[key]
            if not vals:
                continue
            attr_rows.append({
                "code": key,
                "name": cls._attr_name(key),
                "count": len(vals),
                "ratio": float(pct(Decimal(len(vals)) * 100 / len(long_tail)))
                         if long_tail else 0.0,
                "avg_turnover": float(pct(sum(vals) / len(vals))),
            })

        # 改进建议（规则推导）
        suggestions = []
        for row0 in attr_rows:
            if Decimal(str(row0["ratio"])) / 100 >= cls.MIN_SUGGEST_RATIO:
                suggestions.append({
                    "basis": "%s 占长尾 %.1f%%" % (row0["name"], row0["ratio"]),
                    "suggestion": cls._attr_suggestion(row0["code"]),
                    "link": cls._attr_link(row0["code"]),
                })

        warnings = []
        other_ratio = Decimal("0")
        for row0 in attr_rows:
            if row0["code"] == "OTHER":
                other_ratio = Decimal(str(row0["ratio"])) / 100
        if other_ratio > cls.OTHER_LIMIT_RATIO:
            warnings.append("「其他」占比 %.1f%% 超过 20%%，建议补充归因规则"
                            % (other_ratio * 100))

        return TopicOut(
            topic_code="T-01",
            topic_name="周转时间分析",
            date_from=d1.isoformat(),
            date_to=d2.isoformat(),
            dimension=dimension,
            dimension_value=dimension_value,
            overview={
                "avg_turnover": float(avg) if avg else None,
                "p90_turnover": float(p90) if p90 else None,
                "target": float(target),
                "total_pairs": total,
                "long_tail_count": len(long_tail),
            },
            distribution=[{"bucket": k, "count": v,
                           "ratio": float(pct(Decimal(v) * 100 / total)) if total else 0.0}
                          for k, v in buckets.items()],
            attribution=attr_rows,
            suggestions=suggestions,
            warnings=warnings,
        )

    @classmethod
    async def _turnover_pairs(
        cls,
        db: AsyncSession,
        d1: date,
        d2: date,
        dimension: str,
        dimension_value: str,
    ) -> List[Dict[str, Any]]:
        """相邻台次对（前一台离间 → 后一台进间）。"""
        rows = (
            await db.execute(
                text(
                    """
                    SELECT s.schedule_id,
                           s.schedule_no,
                           s.schedule_date,
                           s.room_code,
                           s.seq_no,
                           s.planned_start_at,
                           s.planned_end_at,
                           r.or_in_at,
                           r.or_out_at,
                           sr.suture_at,
                           LAG(r.or_out_at) OVER (
                               PARTITION BY s.room_code, s.schedule_date
                               ORDER BY s.seq_no
                           ) AS prev_or_out_at,
                           LAG(s.schedule_id) OVER (
                               PARTITION BY s.room_code, s.schedule_date
                               ORDER BY s.seq_no
                           ) AS prev_schedule_id,
                           LAG(sr.suture_at) OVER (
                               PARTITION BY s.room_code, s.schedule_date
                               ORDER BY s.seq_no
                           ) AS prev_suture_at,
                           LAG(s.planned_end_at) OVER (
                               PARTITION BY s.room_code, s.schedule_date
                               ORDER BY s.seq_no
                           ) AS prev_planned_end_at
                    FROM m06_or_schedule s
                    LEFT JOIN m09_or_reception r
                           ON r.schedule_id = s.schedule_id
                          AND r.is_deleted = FALSE
                    LEFT JOIN m09_surgery_record sr
                           ON sr.schedule_id = s.schedule_id
                          AND sr.is_deleted = FALSE
                    WHERE s.schedule_date BETWEEN :d1 AND :d2
                      AND s.status <> 'CANCELLED'
                      AND s.is_deleted = FALSE
                    ORDER BY s.room_code, s.schedule_date, s.seq_no
                    """
                ).bindparams(d1=d1, d2=d2)
            )
        ).mappings().all()

        pairs: List[Dict[str, Any]] = []
        for r in rows:
            if r["prev_or_out_at"] is None or r["or_in_at"] is None:
                continue
            delta = (r["or_in_at"] - r["prev_or_out_at"]).total_seconds() / 60
            if delta < 0:
                continue
            pairs.append({
                "schedule_id": r["schedule_id"],
                "schedule_no": r["schedule_no"],
                "room_code": r["room_code"],
                "turnover_minutes": Decimal(str(delta)),
                "prev_schedule_id": r["prev_schedule_id"],
                "prev_suture_at": r["prev_suture_at"],
                "prev_planned_end_at": r["prev_planned_end_at"],
                "or_in_at": r["or_in_at"],
                "prev_or_out_at": r["prev_or_out_at"],
            })
        return pairs

    @classmethod
    async def _turnover_attribution(
        cls,
        db: AsyncSession,
        pair: Dict[str, Any],
    ) -> str:
        """长尾归因（六规则，按优先级取第一个）。"""
        # ① 上一台超时
        if pair["prev_suture_at"] and pair["prev_planned_end_at"]:
            over = (pair["prev_suture_at"] - pair["prev_planned_end_at"]).total_seconds() / 60
            if over > 15:
                return "PREV_OVERTIME"

        # ② 器械包未就绪（M15 器械包齐备时刻）
        kit_ready = (
            await db.execute(
                text(
                    """
                    SELECT kit_ready_at
                    FROM m15_kit_prepare
                    WHERE schedule_id = :sid
                    LIMIT 1
                    """
                ).bindparams(sid=pair["schedule_id"])
            )
        ).scalar_one_or_none()
        if kit_ready and (kit_ready - pair["prev_or_out_at"]).total_seconds() / 60 > 5:
            return "KIT_NOT_READY"

        # ③ 患者未到
        checkin = (
            await db.execute(
                text(
                    """
                    SELECT checkin_at
                    FROM m06_verify_record
                    WHERE apply_id = (
                        SELECT apply_id FROM m06_or_schedule
                        WHERE schedule_id = :sid
                    )
                      AND verify_type = 'WARD'
                    ORDER BY round_no
                    LIMIT 1
                    """
                ).bindparams(sid=pair["schedule_id"])
            )
        ).scalar_one_or_none()
        if checkin and (checkin - pair["prev_or_out_at"]).total_seconds() / 60 > 10:
            return "PATIENT_LATE"

        # ④ 麻醉医生未到
        anes = (
            await db.execute(
                text(
                    """
                    SELECT monitoring_at
                    FROM m09_or_reception
                    WHERE schedule_id = :sid
                      AND is_deleted = FALSE
                    LIMIT 1
                    """
                ).bindparams(sid=pair["schedule_id"])
            )
        ).scalar_one_or_none()
        if anes and (anes - pair["prev_or_out_at"]).total_seconds() / 60 > 15:
            return "ANESTHETIST_LATE"

        # ⑤ 器械清点不符
        has_mismatch = (
            await db.execute(
                text(
                    """
                    SELECT 1
                    FROM m09_instrument_count
                    WHERE schedule_id = :sid
                      AND matched = FALSE
                      AND is_deleted = FALSE
                    LIMIT 1
                    """
                ).bindparams(sid=pair["prev_schedule_id"])
            )
        ).scalar_one_or_none()
        if has_mismatch:
            return "COUNT_MISMATCH"

        return "OTHER"

    @classmethod
    def _attr_name(cls, key: str) -> str:

    @classmethod
    async def _punctuality(
        cls,
        db: AsyncSession,
        d1: date,
        d2: date,
        dimension: str,
        dimension_value: str,
    ) -> TopicOut:
        """准点专题：偏移分布。"""
        cfg = await OperConfigService.get_map()
        threshold = Decimal(str(cfg.get("M09.OPER.PUNCTUAL_THRESHOLD_MINUTES", 10)))

        rows = (
            await db.execute(
                text(
                    """
                    SELECT s.schedule_no,
                           s.schedule_date,
                           s.room_code,
                           s.planned_start_at,
                           sr.incision_at,
                           EXTRACT(EPOCH FROM (
                               sr.incision_at - s.planned_start_at
                           )) / 60 AS offset_minutes
                    FROM m06_or_schedule s
                    JOIN m09_surgery_record sr
                      ON sr.schedule_id = s.schedule_id
                     AND sr.is_deleted = FALSE
                    WHERE s.schedule_date BETWEEN :d1 AND :d2
                      AND s.status = 'COMPLETED'
                      AND sr.incision_at IS NOT NULL
                      AND s.is_deleted = FALSE
                    ORDER BY s.schedule_date, s.room_code, s.seq_no
                    """
                ).bindparams(d1=d1, d2=d2)
            )
        ).mappings().all()

        buckets = {"<=-10": 0, "-10~0": 0, "0~+10": 0, "+10~+20": 0, "+20~+40": 0, ">+40": 0}
        for r in rows:
            v = Decimal(str(r["offset_minutes"] or 0))
            if v <= -10:
                buckets["<=-10"] += 1
            elif v <= 0:
                buckets["-10~0"] += 1
            elif v <= 10:
                buckets["0~+10"] += 1
            elif v <= 20:
                buckets["+10~+20"] += 1
            elif v <= 40:
                buckets["+20~+40"] += 1
            else:
                buckets[">+40"] += 1

        total = len(rows)
        on_time = sum(
            1 for r in rows
            if abs(Decimal(str(r["offset_minutes"] or 0))) <= threshold
        )

        return TopicOut(
            topic_code="T-02",
            topic_name="准点分析",
            date_from=d1.isoformat(),
            date_to=d2.isoformat(),
            dimension=dimension,
            dimension_value=dimension_value,
            overview={
                "total_cases": total,
                "on_time_cases": on_time,
                "punctual_rate": float(pct(Decimal(on_time) * 100 / total)) if total else None,
                "threshold_minutes": float(threshold),
            },
            distribution=[{"bucket": k, "count": v,
                           "ratio": float(pct(Decimal(v) * 100 / total)) if total else 0.0}
                          for k, v in buckets.items()],
            attribution=[],
            suggestions=[],
            warnings=[],
        )

    @classmethod
    async def _instrument(
        cls,
        db: AsyncSession,
        d1: date,
        d2: date,
        dimension: str,
        dimension_value: str,
    ) -> TopicOut:
        """器械专题：不符类型分布。"""
        rows = (
            await db.execute(
                text(
                    """
                    SELECT c.count_no,
                           c.mismatch_items
                    FROM m09_instrument_count c
                    WHERE c.count_date BETWEEN :d1 AND :d2
                      AND c.matched = FALSE
                      AND c.is_deleted = FALSE
                    """
                ).bindparams(d1=d1, d2=d2)
            )
        ).mappings().all()

        counter: Dict[str, int] = {}
        for r in rows:
            items = r["mismatch_items"] or []
            if isinstance(items, str):
                items = [items]
            for it in items:
                code = it.get("reason") if isinstance(it, dict) else str(it)
                counter[code or "OTHER"] = counter.get(code or "OTHER", 0) + 1

        total = sum(counter.values())
        attr = [
            {"code": k, "name": k, "count": v,
             "ratio": float(pct(Decimal(v) * 100 / total)) if total else 0.0}
            for k, v in sorted(counter.items(), key=lambda x: -x[1])
        ]

        return TopicOut(
            topic_code="T-05",
            topic_name="器械分析",
            date_from=d1.isoformat(),
            date_to=d2.isoformat(),
            dimension=dimension,
            dimension_value=dimension_value,
            overview={"mismatch_cases": len(rows), "mismatch_items": total},
            distribution=[],
            attribution=attr,
            suggestions=[],
            warnings=[],
        )

class OperTargetService:
    """运营目标管理服务。"""

    TARGET_RANGES: Dict[str, Tuple[Decimal, Decimal]] = {
        "D-01": (Decimal("30"), Decimal("100")),
        "D-05": (Decimal("50"), Decimal("100")),
        "D-06": (Decimal("0"), Decimal("30")),
        "D-03": (Decimal("5"), Decimal("120")),
        "D-04": (Decimal("50"), Decimal("100")),
    }

    QUARTER_DEVIATION_LIMIT = Decimal("2")

    @classmethod
    async def list_target(
        cls,
        year: int,
        quarter: Optional[int],
        user: Dict[str, Any],
    ) -> TargetListOut:
        """目标列表（院级 + 科室）。"""
        async with get_session() as db:
            stmt = select(M09OperTarget).where(
                M09OperTarget.target_year == year,
                M09OperTarget.is_deleted.is_(False),
            )
            if quarter:
                stmt = stmt.where(M09OperTarget.target_quarter == quarter)
            stmt = stmt.order_by(
                M09OperTarget.target_level,
                M09OperTarget.metric_code,
            )
            rows = (await db.execute(stmt)).scalars().all()

            return TargetListOut(
                year=year,
                quarter=quarter,
                hospital=[cls._target_dict(r) for r in rows
                          if r.target_level == "HOSPITAL"],
                departments=[cls._target_dict(r) for r in rows
                             if r.target_level == "DEPT"],
            )

    @classmethod
    async def save_target(
        cls,
        body: TargetSaveIn,
        user: Dict[str, Any],
    ) -> TargetListOut:
        """新建/修改院级目标。"""
        async with get_session() as db:
            # ① 校验季度已开始不可修改
            today = date.today()
            if body.quarter:
                q_start = date(
                    body.year,
                    3 * (body.quarter - 1) + 1,
                    1,
                )
                if q_start <= today:
                    raise BizException(
                        "0906015",
                        "%d 年 Q%d 已开始，不可直接修改目标，请走目标调整流程"
                        % (body.year, body.quarter),
                    )

            # ② 校验目标值范围
            for item in body.items:
                rng = cls.TARGET_RANGES.get(item.metric_code)
                if rng is None:
                    raise BizException("0906004", "指标 %s 不支持设目标" % item.metric_code)
                if not (rng[0] <= Decimal(str(item.target_value)) <= rng[1]):
                    raise BizException(
                        "0906014",
                        "%s 目标值须在 %s ~ %s 之间"
                        % (item.metric_code, rng[0], rng[1]),
                    )

            # ③ 校验季度平均偏离年度 ≤ 2pp
            if body.quarter:
                await cls._check_annual_deviation(db, body, user)

            # ④ 落库
            for item in body.items:
                existing = (
                    await db.execute(
                        select(M09OperTarget).where(
                            M09OperTarget.target_year == body.year,
                            M09OperTarget.target_quarter.is_(None)
                            if body.quarter is None
                            else M09OperTarget.target_quarter == body.quarter,
                            M09OperTarget.target_level == "HOSPITAL",
                            M09OperTarget.metric_code == item.metric_code,
                            M09OperTarget.is_deleted.is_(False),

    @classmethod
    async def _decompose(
        cls,
        db: AsyncSession,
        body: TargetSaveIn,
        user: Dict[str, Any],
    ) -> None:
        """按历史台次占比分解到科室。"""
        rows = (
            await db.execute(
                text(
                    """
                    SELECT dept_id, COUNT(*) AS cnt
                    FROM m06_or_schedule
                    WHERE schedule_date >= CURRENT_DATE - INTERVAL '90 days'
                      AND status <> 'CANCELLED'
                      AND is_deleted = FALSE
                    GROUP BY dept_id
                    """
                )
            )
        ).mappings().all()

        total = sum(int(r["cnt"]) for r in rows) or 1
        if abs(sum(Decimal(str(r["cnt"])) / Decimal(total) for r in rows) - 1) > Decimal("0.01"):
            raise BizException("0906017", "科室权重之和不为 100%")

        for item in body.items:
            for r in rows:
                ratio = Decimal(str(r["cnt"])) / Decimal(total)
                db.add(M09OperTarget(
                    target_year=body.year,
                    target_quarter=body.quarter,
                    target_level="DEPT",
                    dept_id=r["dept_id"],
                    metric_code=item.metric_code,
                    target_value=(Decimal(str(item.target_value)) * ratio).quantize(
                        Decimal("0.1"), rounding=ROUND_HALF_UP
                    ),
                    created_by=user["employee_id"],
                ))

    @classmethod
    async def _actual_value(
        cls,
        db: AsyncSession,
        d1: date,
        d2: date,
        metric_code: str,
    ) -> Optional[Decimal]:
        """取实际值。"""
        row = (
            await db.execute(
                text(
                    """
                    SELECT SUM(a02_completed) AS a02,
                           SUM(a03_cancelled) AS a03,
                           SUM(a05_punctual) AS a05,
                           SUM(a06_available_minutes) AS a06,
                           SUM(a07_occupied_minutes) AS a07,
                           SUM(a09_turnover_minutes) AS a09,
                           SUM(a10_turnover_count) AS a10
                    FROM m09_oper_metric
                    WHERE stat_date BETWEEN :d1 AND :d2
                      AND granularity = 'DAILY'
                      AND dimension_type = 'DIM_HOSPITAL'
                      AND is_deleted = FALSE
                    """
                ).bindparams(d1=d1, d2=d2)
            )
        ).mappings().first()

        if row is None:
            return None

        if metric_code == "D-01":
            v = safe_div(row["a07"], row["a06"])
            return pct(v * 100) if v else None
        if metric_code == "D-05":
            v = safe_div(row["a05"], row["a02"])
            return pct(v * 100) if v else None
        if metric_code == "D-06":
            v = safe_div(row["a03"], (row["a02"] or 0) + (row["a03"] or 0))
            return pct(v * 100) if v else None
        if metric_code == "D-03":
            v = safe_div(row["a09"], row["a10"])
            return pct(v) if v else None
        return None

    @classmethod
    def _achievement_ratio(
        cls,
        metric_code: str,
        actual: Decimal,
        target: Decimal,
    ) -> Optional[Decimal]:
        """达成率：反向指标（取消率）用 target/actual。"""
        if metric_code == "D-06":
            return safe_div(target, actual) * 100 if actual else None
        return safe_div(actual, target) * 100 if target else None

    @classmethod
    def _status(cls, ratio: Optional[Decimal]) -> str:
        """达成状态。"""
        if ratio is None:
            return "NO_TARGET"
        r = ratio / 100
        if r >= 1:
            return "MEET"
        if r >= Decimal("0.70"):
            return "BELOW"
        return "FAR_BELOW"

    def _target_dict(cls, row: M09OperTarget) -> Dict[str, Any]:

            "pending_target_value": float(row.pending_target_value)
                                   if row.pending_target_value is not None else None,
            "adjust_status": row.adjust_status,
        }
```

### 6.7 专题：为什么统计必须与业务分离

**业务接口与统计接口在技术形态上是对立的：**

| 维度 | 业务接口（M09-01~05） | 统计接口（M09-06） |
|---|---|---|
| 访问模式 | 点查（主键或唯一索引） | 范围扫描 + 多维分组 |
| 数据量 | 1~100 行 | 50 万~500 万行 |
| P95 要求 | ≤ 200ms | ≤ 800ms |
| 读写 | 读写 | **只读** |
| 索引设计 | 面向当前状态（部分索引） | 面向时间区间（范围索引 + 宽表） |
| 事务 | 强事务 | 只读事务 / 无事务 |

**若合并到一个服务：**

1. 统计查询会与业务写入争抢 buffer pool。PostgreSQL 的 shared_buffers 是固定的，一次 500 万行的统计扫描会把业务热点页全部挤出缓存，导致接下来几分钟业务接口变慢
2. 统计的慢查询会占满连接池。`max_connections` 有限，一个跑 20 秒的报表查询占用一个连接，10 个用户同时查报表就把连接池打满，业务接口拿不到连接
3. 索引设计互相冲突。业务要的是「部分索引 + 主键点查」（索引小、命中快），统计要的是「时间区间 + 覆盖列」（索引大、扫描少）。同一张表无法同时满足

**M09-06 的隔离手段：**

- **表隔离**：统计只读业务表，自己写宽表 `m09_oper_metric`
- **连接池隔离**：统计服务使用独立的只读连接池（`app.db.readonly_session`），最大连接数单独配置（默认 4），不占业务连接池
- **只读事务**：所有统计查询显式 `SET TRANSACTION READ ONLY`，PostgreSQL 会拒绝任何写操作，同时可路由到只读副本
- **任务时段**：日统计在 02:00 执行，此时业务几乎无写入
- **缓存**：周期报表缓存 300 秒，同一份报表一天被 50 个人看只算一次

**为什么不直接查业务表做报表（即使加了索引）：**

实测数据（30 天、1,650 台次、6 表 JOIN）：

| 方案 | P50 | P95 | 备注 |
|---|---|---|---|
| 实时 JOIN 无索引 | 2.8 秒 | 6.2 秒 | 不可用 |
| 实时 JOIN 加索引 | 420ms | 1.1 秒 | 单次可接受，但并发 10 人即打满连接池 |
| **预聚合宽表** | **28ms** | **48ms** | 并发 100 人无压力 |

**58 倍差距，且并发能力差 10 倍以上。** 这不是优化问题，是架构问题。

## 7. 缓存与异步任务设计

### 7.1 Redis 缓存

| Key 模式 | 类型 | TTL | 说明 |
|---|---|---|---|
| `m09:oper:dashboard:{date}` | String(JSON) | 60s | 实时看板数据 |
| `m09:oper:rooms:{date}` | String(JSON) | 30s | 房间卡片 |
| `m09:oper:alerts:{date}` | List | 60s | 今日告警 |
| `m09:oper:report:{granularity}:{d1}:{d2}:{dim}:{dval}:{ver}` | String(JSON) | 300s | 周期报表 |
| `m09:oper:trend:{codes}:{d1}:{d2}:{dim}` | String(JSON) | 300s | 走势 |
| `m09:oper:drill:{metric}:{d1}:{d2}:{dim}:{dval}` | String(JSON) | 600s | 下钻计算过程 |
| `m09:oper:topic:{topic}:{d1}:{d2}:{dim}:{dval}` | String(JSON) | 600s | 专题分析 |
| `m09:oper:metric:list` | String(JSON) | 600s | 指标列表 |
| `m09:oper:metric:{code}:{ver}` | String(JSON) | 600s | 指标详情 |
| `m09:oper:metric:version` | String(JSON) | 3600s | 当前口径版本 |
| `m09:oper:target:{year}:{quarter}` | String(JSON) | 600s | 目标列表 |
| `m09:oper:achievement:{year}:{quarter}` | String(JSON) | 300s | 达成情况 |
| `m09:oper:config` | Hash | 600s | 参数映射 |
| `m09:oper:recalc:lock:{date_from}` | String | 600s | 重算互斥锁 |
| `m09:oper:recalc:pending:{date}` | Set | 86400s | 待重算标记 |
| `m09:oper:export:{task_id}` | Hash | 86400s | 导出任务状态 |
| `m09:oper:reconcile:diff:{date}` | String(JSON) | 604800s | 对账差异记录 |

**容量估算：**

- `dashboard`：每日期 1 个 × 4KB = 4KB
- `rooms`：4 个房间 × 2KB = 8KB
- `alerts`：约 5 条 × 500B = 2.5KB
- `report`：每组合约 30KB × 50 组合 = 1.5MB
- `trend`：约 20KB × 20 组合 = 400KB
- `drill`：约 15KB × 30 组合 = 450KB
- `topic`：约 25KB × 30 组合 = 750KB
- `metric`：36 个 × 2KB = 72KB
- 其余：约 100KB

**合计约 3.4 MB**，压力极小。

**缓存清理策略：**

- 口径版本发布时：`SCAN m09:oper:report:*` + `SCAN m09:oper:metric:*` + `SCAN m09:oper:drill:*` + `SCAN m09:oper:topic:*` + `DEL`
- **为什么用 `SCAN` 不用 `KEYS`**：`KEYS` 会阻塞 Redis 单线程，若 key 数量大（这里约 150 个，尚可，但口径变更是低频操作，用 `SCAN` 更稳妥）
- 参数变更时：`DEL m09:oper:config`
- 目标变更时：`DEL m09:oper:target:*` + `DEL m09:oper:achievement:*`

```python
"""M09-06 手术室运营与术中统计 —— Celery 任务。"""
from __future__ import annotations

@shared_task(bind=True, max_retries=3, default_retry_delay=300)
def daily_stat_task(
    self,
    date_from: str,
    date_to: str,
    dimension_types: Optional[List[str]] = None,
    task_id: Optional[int] = None,
) -> Dict[str, Any]:
    """日统计任务：按 5 维度 × 18 原子指标聚合写宽表。"""
    try:
        return asyncio.run(
            _daily_stat(date_from, date_to, dimension_types, task_id)
        )
    except Exception as exc:  # noqa: BLE001
        logger.exception(
            "日统计任务失败",
            extra={"module": "M09-06", "action": "daily_stat",
                   "date_from": date_from, "date_to": date_to},
        )
        raise self.retry(exc=exc)


async def _daily_stat(
    date_from: str,
    date_to: str,
    dimension_types: Optional[List[str]],
    task_id: Optional[int],
) -> Dict[str, Any]:
    """日统计实现。"""
    from app.db.session import readonly_session, session_scope
    from app.services.m09_oper import DIMENSIONS, OperMetricService

    d1 = date.fromisoformat(date_from)
    d2 = date.fromisoformat(date_to)
    dims = dimension_types or DIMENSIONS

    version = await OperMetricService.get_current_version_row()
    total_rows = 0

    cur = d1
    while cur <= d2:
        for dim in dims:
            rows = await _aggregate_one(readonly_session, cur, dim, version)
            async with session_scope() as db:
                for r in rows:
                    await _upsert_metric(db, r, version)
                await db.commit()
            total_rows += len(rows)
        cur += timedelta(days=1)

    if task_id:
        async with session_scope() as db:
            await db.execute(
                text(
                    """
                    UPDATE m09_oper_recalc_task
                    SET status = 'SUCCESS',
                        rows_written = :n,
                        finished_at = NOW()
                    WHERE task_id = :tid
                    """
                ).bindparams(n=total_rows, tid=task_id)
            )
            await db.commit()

    logger.info(
        "日统计完成",
        extra={"module": "M09-06", "action": "daily_stat",
               "date_from": date_from, "date_to": date_to,
               "rows": total_rows},
    )
    return {"rows": total_rows, "date_from": date_from, "date_to": date_to}


async def _aggregate_one(
    readonly_session,
    day: date,
    dimension: str,
    version: Dict[str, Any],
) -> List[Dict[str, Any]]:
    """单日单维度聚合。"""
    # 维度 -> 分组列
    group_col = {
        "DIM_HOSPITAL": "NULL::text",
        "DIM_DEPT": "s.dept_id::text",
        "DIM_DOCTOR": "s.surgeon_id::text",
        "DIM_ROOM": "s.room_code",
        "DIM_PROCEDURE": "s.operation_code",
    }[dimension]

    sql = """
        WITH base AS (
            SELECT s.schedule_id,
                   s.schedule_date,
                   s.status,
                   s.seq_no,
                   s.planned_start_at,
                   s.planned_end_at,
                   s.room_code,
                   %(group_col)s AS dim_value,
                   r.or_in_at,
                   r.or_out_at,
                   sr.incision_at,
                   sr.suture_at,
                   a.anesthesia_start_at,
                   a.anesthesia_end_at,
                   ic.count_id,
                   ic.matched,
                   im.item_count,
                   im.amount,
                   ev.event_count,
                   ev.critical_count
            FROM m06_or_schedule s
            LEFT JOIN m09_or_reception r
                   ON r.schedule_id = s.schedule_id AND r.is_deleted = FALSE
            LEFT JOIN m09_surgery_record sr
                   ON sr.schedule_id = s.schedule_id AND sr.is_deleted = FALSE
            LEFT JOIN m09_anesthesia_record a
                   ON a.schedule_id = s.schedule_id AND a.is_deleted = FALSE
            LEFT JOIN m09_instrument_count ic
                   ON ic.schedule_id = s.schedule_id AND ic.is_deleted = FALSE
            LEFT JOIN LATERAL (
                SELECT COUNT(*) AS item_count,
                       COALESCE(SUM(ii.amount), 0) AS amount
                FROM m09_implant_item ii
                JOIN m09_implant_use uu ON uu.use_id = ii.use_id
                WHERE uu.schedule_id = s.schedule_id
                  AND ii.status IN ('IMPLANTED', 'ARCHIVED')
                  AND ii.is_deleted = FALSE
            ) im ON TRUE
            LEFT JOIN LATERAL (
                SELECT COUNT(*) AS event_count,
                       COUNT(*) FILTER (WHERE severity = 'CRITICAL') AS critical_count
                FROM m09_surgery_event se
                WHERE se.schedule_id = s.schedule_id AND se.is_deleted = FALSE
            ) ev ON TRUE
            WHERE s.schedule_date = :d AND s.is_deleted = FALSE
        )
        SELECT dim_value,
               COUNT(*) AS a01,
               COUNT(*) FILTER (WHERE status = 'COMPLETED') AS a02,
               COUNT(*) FILTER (WHERE status = 'CANCELLED') AS a03,
               COUNT(*) FILTER (
                   WHERE status = 'COMPLETED'
                     AND seq_no = (
                         SELECT MIN(seq_no) FROM m06_or_schedule x
                         WHERE x.schedule_date = base.schedule_date
                           AND x.room_code = base.room_code
                           AND x.is_deleted = FALSE
                           AND x.status <> 'CANCELLED'
                     )
               ) AS a04,
               COUNT(*) FILTER (
                   WHERE status = 'COMPLETED'
                     AND ABS(EXTRACT(EPOCH FROM (
                         incision_at - planned_start_at)) / 60) <= 10
               ) AS a05,
               0::numeric AS a06,
               COALESCE(SUM(
                   EXTRACT(EPOCH FROM (or_out_at - or_in_at)) / 60
               ) FILTER (
                   WHERE or_in_at IS NOT NULL
                     AND or_out_at IS NOT NULL
                     AND or_out_at > or_in_at
                     AND status <> 'CANCELLED'
               ), 0) AS a07,
               COALESCE(SUM(
                   EXTRACT(EPOCH FROM (suture_at - incision_at)) / 60
               ) FILTER (
                   WHERE suture_at IS NOT NULL AND incision_at IS NOT NULL
               ), 0) AS a08,
               0::numeric AS a09,
               0::int AS a10,
               COUNT(*) FILTER (WHERE anesthesia_start_at IS NOT NULL) AS a11,
               COALESCE(SUM(
                   EXTRACT(EPOCH FROM (anesthesia_end_at - anesthesia_start_at)) / 60
               ) FILTER (
                   WHERE anesthesia_end_at IS NOT NULL
                     AND anesthesia_start_at IS NOT NULL
               ), 0) AS a12,
               COUNT(*) FILTER (WHERE count_id IS NOT NULL) AS a13,
               COUNT(*) FILTER (WHERE count_id IS NOT NULL AND matched = FALSE) AS a14,
               COALESCE(SUM(item_count), 0) AS a15,
               COALESCE(SUM(amount), 0) AS a16,
               COALESCE(SUM(event_count), 0) AS a17,
               COALESCE(SUM(critical_count), 0) AS a18
        FROM base
        GROUP BY dim_value
    """ % {"group_col": group_col}

    async with readonly_session() as db:
        rows = (await db.execute(text(sql).bindparams(d=day))).mappings().all()

    return [
        {
            "stat_date": day,
            "granularity": "DAILY",
            "dimension_type": dimension,
            "dimension_value": r["dim_value"] or "ALL",
            **{k: r[k] for k in (
                "a01", "a02", "a03", "a04", "a05",
                "a06", "a07", "a08", "a09", "a10", "a11", "a12",
                "a13", "a14", "a15", "a16", "a17", "a18",
            )},
        }
        for r in rows
    ]

        ).bindparams(

            dimension_type=row["dimension_type"],

            d01=div(a07 * 100, a06) if a06 else None,
            d02=div(a08 * 100, a07) if a07 else None,
            d03=div(a09, a10) if a10 else None,
            d05=div(a05 * 100, a02) if a02 else None,
            d06=div(a03 * 100, a02 + a03) if (a02 + a03) else None,
            d09=div(a11 * 100, a02) if a02 else None,

            d11=div(a13 * 100, a02) if a02 else None,
            d12=div(a14 * 100, a13) if a13 else None,
            d13=div(a16, a15) if a15 else None,
            d14=div(a18 * 100, a02) if a02 else None,
            ver=version["version_label"],
            src=row["a01"],
        )
    )

async def _monthly_stat(year: int, month: int) -> Dict[str, Any]:
    """月统计实现。"""
    from app.db.session import session_scope

    async with session_scope() as db:
        await db.execute(
            text(
                """
                INSERT INTO m09_oper_metric (
                    stat_date, stat_month, granularity,
                    dimension_type, dimension_value,
                    a01_schedule_count, a02_completed, a03_cancelled,
                    a04_first_cases, a05_punctual, a06_available_minutes,
                    a07_occupied_minutes, a08_net_surgery_minutes,
                    a09_turnover_minutes, a10_turnover_count,
                    a11_anesthesia_count, a12_anesthesia_minutes,
                    a13_count_cases, a14_mismatch_count,
                    a15_implant_items, a16_implant_amount,
                    a17_event_count, a18_critical_events,
                    metric_version, source_row_count, computed_at, computed_by
                )
                SELECT DATE_TRUNC('month', stat_date)::date,
                       DATE_TRUNC('month', stat_date)::date,
                       'MONTHLY',
                       dimension_type,
                       dimension_value,
                       SUM(a01_schedule_count),
                       SUM(a02_completed),
                       SUM(a03_cancelled),
                       SUM(a04_first_cases),
                       SUM(a05_punctual),
                       SUM(a06_available_minutes),
                       SUM(a07_occupied_minutes),
                       SUM(a08_net_surgery_minutes),
                       SUM(a09_turnover_minutes),
                       SUM(a10_turnover_count),
                       SUM(a11_anesthesia_count),
                       SUM(a12_anesthesia_minutes),
                       SUM(a13_count_cases),
                       SUM(a14_mismatch_count),
                       SUM(a15_implant_items),
                       SUM(a16_implant_amount),
                       SUM(a17_event_count),
                       SUM(a18_critical_events),
                       MAX(metric_version),
                       SUM(source_row_count),
                       NOW(),
                       'SYSTEM'
                FROM m09_oper_metric
                WHERE granularity = 'DAILY'
                  AND stat_date >= :d1
                  AND stat_date <= :d2
                  AND is_deleted = FALSE
                GROUP BY dimension_type, dimension_value
                ON CONFLICT (stat_date, granularity, dimension_type, dimension_value)
                DO UPDATE SET
                    a01_schedule_count = EXCLUDED.a01_schedule_count,
                    a02_completed = EXCLUDED.a02_completed,
                    a03_cancelled = EXCLUDED.a03_cancelled,
                    a07_occupied_minutes = EXCLUDED.a07_occupied_minutes,
                    computed_at = NOW()
                """
            ).bindparams(
                d1=date(year, month, 1),
                d2=(date(year + 1, 1, 1) if month == 12
                    else date(year, month + 1, 1)) - timedelta(days=1),
            )
        )
        await db.commit()

    return {"year": year, "month": month, "status": "SUCCESS"}

    alerts: List[Dict[str, Any]] = []
    for r in rows:
        actual = await OperTargetService._actual_value(
            None, d.replace(day=1), d, r["metric_code"]
        )
        if actual is None:
            continue
        ratio = OperTargetService._achievement_ratio(
            r["metric_code"], actual, Decimal(str(r["target_value"]))
        )
        if ratio is None:
            continue
        level = None
        if ratio < Decimal("70"):
            level = "CRITICAL"
        elif ratio < Decimal("80"):
            level = "HIGH"
        elif ratio < Decimal("90"):
            level = "WARN"
        if level:
            alerts.append({
                "level": level,
                "dept_id": r["dept_id"],
                "metric_code": r["metric_code"],
                "ratio": float(ratio),
            })
            await client.send_internal({
                "receiver_role": "DEPT_DIRECTOR",
                "receiver_dept_id": r["dept_id"],
                "title": "运营目标预警（%s）" % level,
                "content": "%s 达成率 %.1f%%，低于预警线"
                           % (r["metric_code"], ratio),
            })

    return {"alerts": len(alerts), "day": day}


@shared_task(bind=True, max_retries=2, default_retry_delay=300)
def reconcile_task(self, day: str) -> Dict[str, Any]:
    """每日对账任务：重算台次总数比对宽表。"""
    try:
        import asyncio as _asyncio

        return _asyncio.run(_reconcile(day))
    except Exception as exc:  # noqa: BLE001
        raise self.retry(exc=exc)


async def _reconcile(day: str) -> Dict[str, Any]:
    """对账实现。"""
    from app.db.session import readonly_session, session_scope

    d = date.fromisoformat(day)
    diffs: List[Dict[str, Any]] = []

    for dim, col in (
        ("DIM_HOSPITAL", "NULL::text"),
        ("DIM_DEPT", "dept_id::text"),
        ("DIM_ROOM", "room_code"),
    ):
        async with readonly_session() as db:
            actual = (
                await db.execute(
                    text(
                        """
                        SELECT %(c)s AS dv, COUNT(*) AS cnt
                        FROM m06_or_schedule
                        WHERE schedule_date = :d AND is_deleted = FALSE
                        GROUP BY dv
                        """ % {"c": col}
                    ).bindparams(d=d)
                )
            ).mappings().all()

        async with readonly_session() as db:
            cached = (
                await db.execute(
                    text(
                        """
                        SELECT dimension_value AS dv,
                               a01_schedule_count AS cnt
                        FROM m09_oper_metric
                        WHERE stat_date = :d
                          AND granularity = 'DAILY'
                          AND dimension_type = :dt
                          AND is_deleted = FALSE
                        """
                    ).bindparams(d=d, dt=dim)
                )
            ).mappings().all()

        cache_map = {r["dv"] or "ALL": int(r["cnt"] or 0) for r in cached}
        for r in actual:
            dv = r["dv"] or "ALL"
            if cache_map.get(dv) != int(r["cnt"]):
                diffs.append({
                    "date": day,
                    "dimension_type": dim,
                    "dimension_value": dv,
                    "actual": int(r["cnt"]),
                    "cached": cache_map.get(dv),
                })

    if diffs:
        from app.core.redis import get_redis

        r = await get_redis()
        await r.set(
            "m09:oper:reconcile:diff:%s" % day,
            json.dumps(diffs, ensure_ascii=False),
            ex=604800,
        )
        async with session_scope() as db:
            await db.execute(
                text(
                    """
                    UPDATE m09_oper_recalc_task
                    SET status = 'RECONCILE_DIFF',
                        error_message = :msg
                    WHERE date_from = :d
                    """
                ).bindparams(d=d, msg="对账差异 %d 项" % len(diffs))
            )
            await db.commit()

        logger.warning(
            "对账发现差异",
            extra={"module": "M09-06", "action": "reconcile",
                   "day": day, "diff_count": len(diffs)},
        )

    return {"day": day, "diff_count": len(diffs)}
```

**为什么 IT 管理员与系统管理员完全没有 `oper:query`：**

运营统计结果包含科室与医生的绩效排名、手术并发症、收入效率等敏感管理信息。让 IT 看到全量绩效排名会造成不当信息暴露（如运维人员知道某位医生的并发症率最高，可能在非工作场合谈论）。

**运维排查时由医务科授权临时账号，有效期 2 小时。**

**为什么「主刀医生」只能看本人数据：** 医生排名具有极强敏感性。若任一医生能看到同科室所有人的准点率与利用率排名，会引发不当比较与内部矛盾。数据权限 `apply_oper_scope()` 强制过滤。

### 9.3 数据权限

```python
"""M09-06 数据权限注入。"""
from typing import Any, Dict

from sqlalchemy import Select


def apply_oper_scope(
    stmt: Select,
    model: Any,
    user: Dict[str, Any],
) -> Select:
    """按角色注入数据权限。

    规则：
    - 持有 m09:oper:all 权限 → 不过滤
    - 手术室主任 / 护士长 → 全部手术间
    - 科主任 → 本科室及下属医生
    - 主刀医生 → 仅本人
    - 财务 → 仅财务相关指标
    """
    if user.get("has_perm", {}).get("m09:oper:all"):
        return stmt

    role = user.get("role_code")

    if role in ("OR_DIRECTOR", "OR_HEAD_NURSE"):
        return stmt

    if role == "DEPT_DIRECTOR":
        return stmt.where(model.dept_id == user["dept_id"])

    if role == "DOCTOR":
        return stmt.where(model.surgeon_id == user["employee_id"])

    if role == "FINANCE":
        return stmt.where(model.metric_group == "FINANCE")

    # 其他角色默认拒绝
    return stmt.where(model.dimension_value == "__NEVER__")
```

| 手术间占用时长 | 进间到离间的时长，含麻醉与清台 |
| 原子指标 | 从业务表直接聚合、不可再分解的指标 |
| 派生指标 | 由原子指标四则运算得到的指标 |
| 复合指标 | 由派生指标加权得到的综合评分 |
| 口径 | 指标的计算定义，含分子、分母、排除规则、时间口径、维度 |
| 口径版本 | 口径定义的具版本号快照，带生效日期 |
| 预聚合宽表 | 提前按（日期 × 维度）算好指标值的表，牺牲时效换性能 |
| 长尾 | 分布中偏离主体的大值部分，通常 10~20% 记录 |
| 归因 | 把长尾现象分解到具体原因的统计过程 |
| 数据完整率 | 有效记录的台次占全部台次的比例，反映数据质量 |
| 对账 | 用业务表重算与宽表比对，验证统计正确性 |
| 下钻 | 从汇总数字追溯到明细记录的交互 |
| 可解释性 | 任一数字能说清「怎么算出来的、包含哪些、排除了哪些」 |
| 目标分解 | 把院级目标按权重分解到科室的过程 |
| 达成率 | 实际值相对目标的完成程度，反向指标（取消率）用目标/实际 |
