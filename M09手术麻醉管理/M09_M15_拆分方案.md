## 二、M09 手术麻醉管理（6 个子模块）

### 2.1 定位

**M09 回答「这台手术是怎么做的」——术中那 40 分钟里，谁做了什么、用了什么、切了多少、出了多少血、植入了什么。**

M09 不做：排班（M06-03）、术前准备（M06-02）、四方核对（M06-04）、术后复苏（M06-05）、结算（M16）。这些全部由 M06 承担，M09 从「Time-Out 完成」开始，到「患者离开手术间」结束。

**边界示意图：**

```
        M06-04 Time-Out 完成
              │
              ▼  POST /m09/surgery/on-timeout-completed
    ┌─────────────────────────────────────────┐
    │  M09 术中段（本模块）                     │
    │                                          │
    │  ① 手术记录   切皮→操作→缝合→关腹         │
    │  ② 麻醉记录   诱导→维持→苏醒（5min 一次）  │
    │  ③ 器械清点   术前/关前/关后三次           │
    │  ④ 耗材消耗   扫码使用                    │
    │  ⑤ 植入物绑定 晶体扫码 + 度数核对          │
    │  ⑥ 标本留取   送 M13                      │
    │                                          │
    └─────────────────────────────────────────┘
              │
              ▼  回写 M06-04（交接二）/ M06-06（手术记录）
        患者离开手术间
```

### 2.2 六子模块

| 编号 | 子模块 | 一句话职责 | 为什么独立 |
|---|---|---|---|
| **M09-01** | 手术室接收与麻醉前评估 | 患者进手术间、麻醉医生术前评估、麻醉方案确定 | 麻醉评估是**独立法律责任**，麻醉医生签字后才可开始 |
| **M09-02** | 麻醉记录与用药 | 诱导、维持、苏醒全程记录，5 分钟一次生命体征 | **麻醉记录是独立的法定医疗文书**，与手术记录并列 |
| **M09-03** | 手术记录与术中事件 | 切皮到缝合的操作记录、术中事件、出血量、标本 | **手术记录是主刀的法定文书**，责任主体与麻醉完全不同 |
| **M09-04** | 器械清点与安全核查 | 术前/关前/关后三次器械纱布清点、双人签字 | **《手术安全核查制度》硬性要求**，遗留器械是重大医疗事故 |
| **M09-05** | 植入物使用与扫码绑定 | 晶体/引流阀/硅油扫码、度数核对、上报 M15 | 眼科**人工晶体度数错误是最常见的可预防事故**，需三重核对 |
| **M09-06** | 手术室运营与术中统计 | 手术间周转、术中时长、取消原因、麻醉工作量 | 统计口径与 M06-07 完全不同（M06 看日间占比，M09 看台间效率） |

### 2.3 为什么麻醉与手术必须拆成两个子模块

| 维度 | 手术记录（M09-03） | 麻醉记录（M09-02） |
|---|---|---|
| 责任主体 | 主刀医生 | 麻醉医生 |
| 起止时刻 | 切皮 → 缝合 | 诱导 → 苏醒（**比手术长**） |
| 记录频率 | 事件驱动（做了什么记什么） | **时间驱动（5 分钟一次生命体征）** |
| 数据形态 | 文本 + 结构化术式步骤 | **时序曲线（血压/心率/SpO2/麻醉深度）** |
| 法规要求 | 《病历书写基本规范》手术记录 24 小时内完成 | **麻醉记录单**是独立文书，需单独签署 |
| 失职后果 | 手术记录缺失无法证明操作合规 | **麻醉记录缺失等于无麻醉监护证据** |

**一条手术可以没有麻醉（表面麻醉），但麻醉记录必须有独立的表、独立的签字、独立的时间轴。** 合并会导致：麻醉医生签的字躺在主刀的表里，医疗纠纷时责任主体不清。

| 约束 | 影响 |

## 三、M15 物资耗材管理（7 个子模块）

### 3.1 定位

**M15 回答「物资在哪、有多少、怎么来的、给谁用了」。** 与 M14 药房药库平行：M14 管药品，M15 管耗材与植入物。

**M14 与 M15 的平行结构：**

| 能力 | M14 药房药库 | M15 物资耗材 |
|---|---|---|
| 基础与台账 | M14-01 药房药库基础与库存台账 | **M15-01 物资仓库与库存台账** |
| 分配与效期 | M14-02 分配与效期管理 | **M15-02 耗材库存分配与 UDI 管理** |
| 采购入库 | M14-03 采购与入库 | **M15-03 采购与入库** |
| 出库调拨 | M14-04 出库与调拨 | **M15-04 出库与二级库** |
| 盘点 | M14-05 盘点与库存调整 | **M15-05 盘点与库存调整** |
| 消耗 | M14-07 门诊发药 | **M15-06 手术室二级库与消耗** |
| 追溯 | M14-09 特殊管理药品 | **M15-07 植入物追溯与召回** |

**为什么不复用 M14 引擎**（用户决策）：
- 医疗器械与药品的监管体系不同（《医疗器械监督管理条例》 vs 《药品管理法》）
- 耗材需要 UDI-DI、序列号一物一码、无菌有效期，与药品的批次管理不同
- 植入物追溯是「患者↔耗材」双向查询，药品没有对应需求
- **两套引擎会有重复（约 4 张表结构相似），但各自更简单清晰**——一套「既能管药又能管耗材」的引擎在实际项目中往往两种都管不好

### 3.2 七子模块

| 编号 | 子模块 | 一句话职责 | 为什么独立 |
|---|---|---|---|
| **M15-01** | 物资仓库与库存台账 | 仓库、库位、批次、库存量、库存流水 | **库存唯一真相源**，与 M14-01 同构但不是同一张表 |
| **M15-02** | 耗材库存分配与 UDI 管理 | FEFO 分配、UDI-DI 解析、序列号实例 | 耗材特有：UDI、序列号一物一码、无菌有效期 |
| **M15-03** | 采购与入库 | 采购申请、订单、验收、入库 | 与 M14-03 同构；耗材需验注册证与灭菌有效期 |
| **M15-04** | 出库与二级库 | 出库单、调拨、手术室二级库补货 | **二级库是耗材特有**：手术室常备库、备台、术前领用 |
| **M15-05** | 盘点与库存调整 | 盘点、差异审批、调整 | 与 M14-05 同构 |
| **M15-06** | 手术室二级库与消耗 | 备台、术中扫码消耗、术后退料、消耗上报 M16 | **消耗发生在手术台边**，与出库是两件事 |
| **M15-07** | 植入物追溯与召回 | 植入物使用登记、患者↔耗材双向追溯、召回影响分析 | **法规强制**：《医疗器械监督管理条例》要求植入物可追溯 |

### 3.3 为什么「出库」与「消耗」必须分开（M15-04 vs M15-06）

| 动作 | 时点 | 库存变化 | 责任 |
|---|---|---|---|
| **出库** | 手术前一晚备台 | 药库 → 手术室二级库 | 库管员 |
| **消耗** | 术中实际使用 | 手术室二级库 → 已用 | 器械护士 |
| **退料** | 术后未用 | 手术室二级库 ← 未用部分 | 器械护士 |
| **报损** | 发现破损 | 手术室二级库 → 报废 | 护士长 |

**若合并**：备台 50 项、实际用 38 项、退回 12 项，一张表说不清「备了没用」与「备了坏了」的区别。**M06-06 的「材料退回率 ≥90%」指标直接依赖这个区分**——它统计的是「备台未用退回」的比例。

### 3.6 眼科耗材特殊性（必须写入设计）

| 特性 | 设计要求 |
|---|---|
| **人工晶体 SKU 数千** | 按品牌 × 型号 × 球镜 × 柱镜组合；选型需 `by-power` 查询（M01-04 已提供） |

| **飞秒激光耗材** | 单价过万，与设备绑定使用 |
| **植入物注册证** | 每批次需有效注册证，过期不可用 |
