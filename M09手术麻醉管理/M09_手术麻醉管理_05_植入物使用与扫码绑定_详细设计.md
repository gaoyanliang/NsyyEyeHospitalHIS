## 1. 模块概述

### 1.1 模块定位

M09-05 回答一个问题：**「这颗晶体，是假的吗？是不是说好的那一颗？它在哪只眼睛里？」**

```
┌──────────────────────────────────────────────────────────────────────────────────────┐
│                    M09-05 在眼科手术全流程中的位置                                    │
└──────────────────────────────────────────────────────────────────────────────────────┘

  M06-03 排程            M09-01 接收          M09-02 麻醉        M09-05 ★植入物★
  ┌─────────────┐      ┌─────────────┐     ┌────────────┐     ┌──────────────────┐
  │ 预定晶体型号 │ ───► │ 核对晶体型号 │ ──► │ 麻醉实施   │ ──► │ ① 手术间拆包扫码  │
  │（M06-01 申请）│      │（与申请一致） │     │            │     │ ② 读 UDI 校验真伪 │
  └─────────────┘      └─────────────┘     └────────────┘     │ ③ 三方共读型号度数│
                                                              │ ④ 术中记录植入    │
                                                              │ ⑤ 术后扫码归档    │
                                                              └────────┬─────────┘
                                                                       │
                                        ┌──────────────────────────────┼──────────────────────┐
                                        ▼                              ▼                      ▼
                              ┌───────────────────┐          ┌──────────────────┐   ┌──────────────────┐
                              │ 患者病历（M18）    │          │ M15 植入物登记    │   │ 厂商质保/召回     │
                              │ 植入物条码存档     │          │ 使用登记与追溯    │   │（扫码查询）       │
                              └───────────────────┘          └──────────────────┘   └──────────────────┘
```

**一句话：M09-05 是手术室里的「植入物验证台」——在人工晶体进入患者眼睛前，用 30 秒完成真伪校验、型号核对、四方确认。**

### 1.2 为什么独立成子模块

**理由一：人工晶体是眼科唯一的高值植入物，风险等级与器械完全不同。**

一台白内障手术的晶体费用占手术总费用的 **55%~75%**（单焦点 800~2,500 元，多焦点 6,000~15,000 元，散光矫正 8,000~18,000 元）。而一颗用错的晶体：

| 错用类型 | 后果 | 责任 |
|---|---|---|
| **型号度数错**（该 21.0D 用了 21.5D） | 术后屈光误差 0.5D 左右，需二次手术更换 | 医疗事故，医院全责 |
| **晶体类型错**（该多焦点用了单焦点） | 患者付了 12,000 元得到 2,000 元的晶体 | 医疗纠纷 + 欺诈指控 |
| **左右眼错** | 与术眼标记不符，属于严重错误事件 | 医疗事故 |
| **假货 / 山寨货** | 感染、移位、需取出，且涉刑 | 刑事 + 行政责任 |
| **过期晶体** | 材料老化，术后混浊率升高 | 医疗事故 |
| **重复使用**（一次性被复用） | 感染风险极高 | 严重违规 |

器械用错可以换，纱布多一块可以取出，**晶体装进去就是永久的**。它的风险等级、价值量级、追溯要求都与器械清点（M09-04）完全不同。

**理由二：植入物有独立的法规追溯链，不能与器械清点合并。**

《医疗器械监督管理条例》与《医疗器械唯一标识系统规则》要求：

- **UDI（唯一器械标识）**：国家药监局赋予每个医疗器械唯一编码，一物一码
- **植入物必须可追溯到患者**：能回答「这个患者体内植入的是哪个批号、哪个序列号、哪家厂商、什么时候生产」
- **发生召回时必须能定位所有患者**：厂商发布召回，医院需在 **24 小时内**找出所有用过该批次的患者并通知

器械清点解决「数量对不对」，植入物追溯解决「是哪一件、给了谁、是真是假」。**两者是并行的两套台账，不是同一张表的两个字段。**

**理由三：扫码动作的时间窗口与器械清点不同。**

| 环节 | 器械清点（M09-04） | 植入物扫码（M09-05） |
|---|---|---|
| 时机 | 术前 / 关腔前 / 关腔后 / 缝合后（4 次） | **开内包装后、植入前**（1 次核心）+ 术后归档 |
| 动作 | 分类计数 | 逐件扫码 UDI |
| 依据 | 器械卡 | 厂商包装 UDI 码 + 系统预订单 |
| 阻断力 | 数量不符 → 不得关腔 | 型号不符 / 真伪存疑 → **不得植入** |
| 参与人 | 器械护士 + 巡回护士 | **主刀 + 巡回护士 + 患者（或家属）三方共读** |

时间窗口不同、阻断逻辑不同、参与角色不同——合在一起会让 M09-04 的四次清点流程中掺入不属于它的扫码校验。

**理由四：植入物使用登记是 M15 追溯的数据源头。**

按 m02290 决策 3：**扫码动作归 M09（本子模块），使用登记记录归 M15**。

本子模块是「手术室里的扫码验证台」——它在术中产生数据（患者、眼别、术者、UDI、时间、术中情况）。M15 是「全院的植入物台账」——它维护采购、入库、灭菌、发放、使用登记、召回响应。

M09-05 通过 `POST /internal/v1/m15/implant/register`（或事件 `m09.implant.used`）将扫码结果交付给 M15，M15 据此建立完整追溯链。**M09-05 是 M15 追溯体系最关键的入口——没有术中扫码，追溯链从源头就断了。**

**理由五：眼科的其他植入物也需要同时管理。**

除人工晶体（IOL）外，眼科还有：

| 植入物 | 典型术式 | 年用量（本院） | 价值 |
|---|---|---|---|
| **人工晶体 IOL** | 白内障超声乳化 | 4,000~5,000 枚 | 800~18,000 元 |
| **青光眼引流阀** | 难治性青光眼 | 30~50 套 | 3,000~6,000 元 |
| **青光眼引流钉 / 微型支架** | MIGS | 50~100 支 | 5,000~13,000 元 |
| **玻璃体填充物**（硅油 / 气体） | 玻璃体切割 | 200~300 例 | 800~1,500 元 |
| **巩膜扣带 / 环扎带** | 视网膜脱离 | 80~120 条 | 600~1,200 元 |
| **泪道引流管 / 支架** | 泪道阻塞 | 300~500 套 | 500~2,000 元 |
| **眼眶修复材料**（钛板 / PEEK） | 眼眶骨折 | 20~40 块 | 3,000~12,000 元 |
| **角膜基质环** | 圆锥角膜 | 5~10 枚 | 6,000~9,000 元 |

八类植入物、年约 5,000 件，全部需要在术中完成「扫码—校验—记录」。这是一条独立的业务线。

- UDI 与批次的权威：**M15**（入库时登记）
- 「这个患者植入了什么」的权威：**M15**（使用登记记录）

- 病历中的展示与归档：**M18**（从 M15 取数）

### 1.4 概念辨析

| 概念 | 含义 | 易混淆点 |
|---|---|---|
| **UDI（唯一器械标识）** | 国家药监局赋予医疗器械的唯一编码，含 DI + PI | 不等于「商品条码」——UDI 对应具体生产批次与序列号 |
| **DI（器械标识）** | UDI 的静态部分：厂商、型号、规格 | 同一型号的所有产品 DI 相同 |
| **PI（生产标识）** | UDI 的动态部分：批号、序列号、生产日期、有效期 | DI + PI 才能唯一确定一件产品 |
| **GS1 / HIBC 码制** | UDI 的两种主要编码标准 | 眼科晶体多用 GS1-128 或 DataMatrix |
| **植入物使用登记** | 记录「谁、在哪台手术、植入了哪一件」 | 归 M15，M09-05 是入口 |
| **扫码验证** | 扫 UDI 后与系统预订单比对 | 不等于「扫一下」——要查真伪、过期、重复、型号、眼别 |
| **三方共读** | 主刀 + 护士 + 患者（家属）读出晶体度数 | 这是晶体错误最后一道人工防线 |
| **预订单** | M06-01 申请时确认的晶体型号与度数 | 术中扫码的比对基准 |
| **植入物 vs 耗材** | 植入物留在体内 >30 天；耗材一次性用完即弃 | 硅油、气体虽会被取出，仍按植入物管（>30 天） |
| **二次植入** | 同一术眼再次植入（晶体置换） | 必须记录「前一枚的去向」 |

| 国家药监局 UDI 库 | 真伪校验 | 5s | **告警不阻断** | 本地 UDI 缓存命中优先；未命中记 `authenticity=UNCHECKED` |
| M09-03 手术记录 | 回写植入物段 | — | 补偿重试 | 本地先落库 |

**三条不可降级铁律：**

1. **台次与预订单不可降级**——没有基准就无法判定型号是否正确
2. **型号 / 度数 / 眼别不符必须阻断**——这是本子模块存在的意义，若允许"确认后继续"，扫码就变成了走过场
3. **重复使用必须阻断**——一次性植入物复用是严重违规，任何情况下都不允许

## 3. 业务模型

### 3.1 植入物使用主模型

**三层结构：**

```
植入物使用单（m09_implant_use）  — 一台次一条，可含多枚植入物
  └─ 植入明细（m09_implant_item）— 一件植入物一条（1~8 条）
       └─ 扫码记录（m09_implant_scan）— 每次扫码一条（可能多次重扫）
```

**为什么三层而不是两层：**

- 「这台手术用了 2 枚晶体（左眼 + 右眼）」→ 需要主单承载台次级信息
- 「每枚晶体有自己的 UDI、批号、度数、植入时刻」→ 需要明细
- 「护士可能扫错码、重复扫、扫了又撤销」→ 需要扫码日志，才能回答「当时是什么情况」

**为什么主单不直接存明细数组（JSONB）：**

1. 明细要参与**跨明细校验**（两枚晶体不能同一 UDI）
2. 明细要参与**按 UDI / 批号 / 型号的全局检索**（召回响应）
3. 明细要参与**统计**（度数分布、型号分布）

JSONB 无法满足这三条。

### 3.2 植入物使用状态机

```
                    ┌──────────┐
                    │ PENDING  │  待扫码（台次已创建）
                    └────┬─────┘
                         │ ① 扫码
                         ▼
                    ┌──────────┐
              ┌─────│ SCANNED  │  已扫码，待校验
              │     └────┬─────┘
              │          │ ② 校验通过
      校验失败  │          ▼
              │     ┌──────────┐
              └────►│VERIFIED  │  校验通过，待共读确认
                    └────┬─────┘
                         │ ③ 三方共读确认
                         ▼
                    ┌──────────┐
                    │CONFIRMED │  已确认，待植入
                    └────┬─────┘
                         │ ④ 记录植入
                         ▼
                    ┌──────────┐
                    │IMPLANTED │  已植入
                    └────┬─────┘
                         │ ⑤ 术后归档（标签贴病历 + 回写）
                         ▼
                    ┌──────────┐
                    │ ARCHIVED │  已归档（终态）
                    └──────────┘

  旁支：
    ┌──────────┐
    │ ABORTED  │  中止（扫码后未植入，如：晶体破损 / 术式变更 / 度数不符退货）
    └──────────┘
```

**七个状态：**

| 状态 | 名称 | 进入条件 | 允许操作 |
|---|---|---|---|
| `PENDING` | 待扫码 | 台次创建 / M06-03 事件 | 扫码 |
| `SCANNED` | 已扫码 | 扫码成功解析 | 重新扫码、撤销、校验 |
| `VERIFIED` | 校验通过 | 全部校验项通过 | 三方共读确认、撤销 |
| `CONFIRMED` | 已确认 | 三方共读完成 | 记录植入、撤销（需护士长） |
| `IMPLANTED` | 已植入 | 记录植入时刻与位置 | 归档 |
| `ARCHIVED` | 已归档 | 术后归档完成 | 只读（终态） |
| `ABORTED` | 已中止 | 扫码后不植入 | 只读（终态） |

**关键设计：`SCANNED` 与 `VERIFIED` 分开。**

扫码成功 ≠ 校验通过。扫码只解析出 UDI，校验要查五件事：真伪、有效期、重复使用、型号匹配、眼别匹配。若合并成一个状态，护士扫完码就以为"搞定了"，实际校验失败却没人看见。

**关键设计：`CONFIRMED` 与 `IMPLANTED` 分开。**

「确认要植入」与「已经植入」是两件事。三方共读完成后晶体可能还未拆解；植入时刻才是记录真正发生的时间。若合并，事后无法区分「确认了没植入」与「植入了」。

### 3.3 UDI 扫码解析模型

**UDI 结构（GS1 标准）：**

```
完整 UDI = DI（器械标识，静态） + PI（生产标识，动态）

  (01)06912345678901          ← DI：厂商(0691234) + 型号(56789) + 校验位(01)
  (17)260630                  ← PI：有效期 2026-06-30
  (10)LOT20260315             ← PI：批号
  (21)SN0001234               ← PI：序列号
  (240)21.0                   ← 附加：度数 21.0D（厂商扩展）
```

| 数据项 | AI（应用标识符） | 是否必需 | 说明 |
|---|---|---|---|
| DI | (01) | ✅ | 14 位固定 |
| 生产日期 | (11) | 部分 | 与有效期二选一 |
| 有效期 | (17) | ✅ | YYMMDD |
| 批号 | (10) | ✅ | 植入物必须可追溯到批 |
| 序列号 | (21) | 部分 | 一物一码的植入物必需 |
| 附加信息 | (240) 等 | 视厂商 | 度数、型号等 |

**码制支持：**

| 码制 | 标识 | 典型厂商 | 解析库 |
|---|---|---|---|
| GS1-128 | 起始符 `]C1` | 爱尔康、博士伦 | `python-barcode` + GS1 解析器 |
| GS1 DataMatrix | 起始符 `]d2` | 蔡司、强生 | `pylibdmtx` |
| HIBC | `+` 开头 | 部分进口晶体 | 自定义解析 |
| 厂商私有 QR | 无固定格式 | 国产厂商 | 按厂商配置正则 |

**解析失败处理：**

| 情况 | 处理 |
|---|---|
| 格式不识别 | 报 `"0905010"`，提示手动录入 |
| 缺必需字段（DI / 批号 / 有效期） | 报 `"0905011"`，列出缺失项 |
| 校验位错误 | 报 `"0905012"`，判定为「疑似伪码」 |
| 重复扫码（同 UDI 已在本单） | 幂等返回，不报错 |

### 3.4 五道校验模型

**这是本子模块的核心。** 扫码成功只是第一步，必须通过五道校验才能进入 `VERIFIED`。

| 编号 | 校验项 | 检查内容 | 失败处理 | 严重度 |
|---|---|---|---|---|
| **V-01** | 真伪校验 | DI 是否在国家药监局 UDI 库中；厂商是否在合格供应商名录 | 阻断 `"0905020"` | 🔴 BLOCK |
| **V-02** | 有效期校验 | PI 有效期 ≥ 手术日期 | 阻断 `"0905021"` | 🔴 BLOCK |
| **V-03** | 重复使用校验 | 该 UDI（或序列号）是否已被任一台次使用 | 阻断 `"0905022"` | 🔴 BLOCK |
| **V-04** | 型号匹配校验 | 扫码型号 vs 预订单型号 | 阻断 `"0905023"` | 🔴 BLOCK |
| **V-05** | 眼别匹配校验 | 扫码记录眼别 vs 台次术眼 vs M06-04 Time-Out 核对眼别 | 阻断 `"0905024"` | 🔴 BLOCK |

**为什么全部是 BLOCK 而不是 WARN：**

型号错、眼别错、过期、假货、重复使用——每一项单独致残/致命风险都已足够。若允许"警告后继续"，护士在手术室里被时间压力催促时必然选择"继续"，扫码就成了装饰。

**唯一的例外：M15 库存校验与药监局 UDI 校验属于外部依赖，允许降级为 `UNCHECKED` 并留痕**——因为网络不通时不能把手术停掉，但必须在记录里标明"未完成真伪校验"，事后 24 小时内补做。

### 3.5 三方共读模型

**为什么需要三方共读：**

晶体度数错误的典型场景：

```
术前：M11 计算 + 医生选择 → 预订单写 21.5D
库房：发出 21.5D（正确）
术中：护士拆包（正确），扫码（正确），但主刀记错，"我记得是 21.0D"
植入：21.5D 进眼 → 术后验光 -0.5D 误差 → 二次手术
```

系统的所有电子校验都是正确的，唯一出错的是**人的记忆**。三方共读的设计就是让三方在同一时刻用同一个数字互相校正：

1. **主刀说出**：「我要植入的是 21.5 度，非球面，左眼」
2. **巡回护士读出包装**：「标签显示 21.5D，SN 0001234，左眼，效期 2026-06-30」
3. **患者（或家属）确认**：「是左眼，是医生说的那个 21.5 度」

三方一致才允许进入 `CONFIRMED`。

**为什么必须有患者参与：**

这是唯一能从「术前约定」角度校验的人。患者说"医生说做的是左眼 21.5 度"就是最终的需求基准。而且一旦出事，患者是唯一能证明"当时医生说的是什么"的证人。

**共读记录字段：**

| 字段 | 说明 |
|---|---|
| `surgeon_stated_text` | 主刀口述内容（可语音转文字） |
| `nurse_read_text` | 护士读出的包装标签 |
| `patient_confirmed` | 患者是否确认（TRUE / FALSE / UNABLE） |
| `patient_confirm_way` | 确认方式：口头 / 点头 / 家属代确认 |
| `read_at` | 共读时刻 |
| `read_duration_seconds` | 共读耗时 |

`patient_confirmed = UNABLE`（患者无法确认，如全麻、意识障碍）时必须记录 `surrogate`（家属姓名关系）。

### 3.6 植入过程记录模型

**植入时刻与位置：**

| 字段 | 说明 |
|---|---|
| `implanted_at` | 植入时刻（精确到秒） |
| `eye_side` | 植入眼别 |
| `implant_position` | 植入位置：囊袋内 / 睫状沟 / 前房 / 玻璃体腔 / 巩膜面 |
| `implant_depth` | 植入深度（部分植入物如引流阀） |
| `intraop_complication` | 术中并发症（后囊破裂 / 悬韧带断裂 / 玻璃体脱出） |
| `implant_status` | 术中状态：在位 / 偏心 / 需调整 |

**为什么记录"位置"：**

同一枚晶体放入「囊袋内」与「睫状沟」是不同的临床场景——后者多为悬韧带损伤的补救。术后出现移位，能立刻判断是「原位置就有问题」还是「术后新发」。这是术后并发症归因的关键证据。

**为什么记录"术中并发症"：**

术中后囊膜破裂是晶体移位与前房植入的常见原因。手术记录（M09-03）已有并发症字段，但 M09-05 需要独立记录——因为晶体植入决策与并发症发生时序强相关。

### 3.7 术后归档模型

**扫码归档三动作：**

1. **贴病历标签**：厂商包装上的 UDI 标签撕下贴入纸质病历；电子病历同步生成植入物条码图像
2. **回写 M15**：使用登记（追溯链核心）
3. **回写 M18**：病历植入物段落

**归档状态机：**

```
IMPLANTED ──┬──► 贴标签完成
            ├──► 回写 M15 成功
            ├──► 回写 M18 成功
            └──► 三个都完成 ──► ARCHIVED
```

三者任一失败时状态保持 `IMPLANTED`，进入补偿队列重试。**不允许因为某个系统故障就跳过归档**——植入物的追溯链一旦断掉，召回时就会出现"这个患者用了什么查不到"。

### 3.8 召回响应模型

**召回场景：**

```
厂商通知：批号 LOT20260315 的人工晶体存在某批次光学质量问题
       ↓
设备科在 M09-05 输入批号
       ↓
检索：所有使用该批号的手术记录
       ↓
输出：患者姓名、联系方式、手术日期、术者、眼别、UDI
       ↓
24 小时内通知全部患者（M03-05 消息 + 人工电话）
```

**检索维度：**

| 维度 | 用途 |
|---|---|
| 批号 | 主检索条件（厂商召回按批） |
| DI（型号） | 型号级召回 |
| UDI / 序列号 | 单件召回 |
| 厂商 | 厂商级召回 |
| 患者 ID | 反向查患者用过的所有植入物 |

**性能要求：按批号检索 5 年数据 ≤ 2 秒。** 这是召回响应的核心 SLA——24 小时内找回患者的前提是 2 小时内能出名单。

**为什么召回检索性能要求 ≤2 秒：**

召回 24 小时内通知患者，是指从收到厂商通知算起。若检索要 30 分钟，那一天只能处理几十个召回。而且真实场景中一次召回可能涉及多个批次（厂商同时召回多个生产日期），需要反复检索。2 秒意味着可以快速迭代查询条件。

"""M09-05 植入物使用与扫码绑定 —— Service 层。"""
from __future__ import annotations

import hashlib

from datetime import date, datetime, timedelta

from app.clients import (
    BillingClient, EmrClient, LabClient, MdmClient, MpiClient,
    MsgClient, SmsClient, SurgeryClient, SurgeryScheduleClient,
)
from app.core.exceptions import BizException
from app.models.m09_implant import (
    M09ImplantConfig, M09ImplantItem, M09ImplantReadback,
    M09ImplantScan, M09ImplantUse,
)
from app.services.base import BaseService

logger = logging.getLogger("m09.implant")

CENT = Decimal("0.01")


def money(value: Any) -> Decimal:
    """金额统一舍入到 2 位小数。"""
    if value is None:
        return Decimal("0.00")
    return Decimal(str(value)).quantize(CENT, rounding="ROUND_HALF_UP")


# ============================================================================
# UDI 解析器
# ============================================================================

class UdiParser:
    """UDI 码解析（GS1-128 / GS1 DataMatrix / HIBC / 私有 QR）。"""

    # GS1 应用标识符 → 字段名
    _AI_MAP = {
        "01": "di",
        "11": "production_date",
        "17": "expiry_date",
        "10": "lot_no",
        "21": "serial_no",
        "240": "extra_model",
        "30": "quantity",
    }
    # 定长 AI（长度固定，无需分隔符）
    _FIXED_LEN = {"01": 14, "11": 6, "17": 6, "30": 6}
    # 变长 AI（遇到下一 AI 或 FNC1 结束）
    _VAR_LEN = {"10", "21", "240"}
    # 私有扩展：度数（厂商自定义）
    _DIOPTER_AI = "240"

    @classmethod
    def parse(cls, raw: str, barcode_type: str) -> Dict[str, Any]:
        """解析原始码，返回字段字典。

        :raises BizException: 格式不识别 / 缺必需字段 / 校验位错误
        """
        raw = (raw or "").strip()
        if not raw:
            raise BizException("0905009", "扫码内容为空")

        if barcode_type in ("GS1_128", "GS1_DM", "GS1_DATAMATRIX"):
            return cls._parse_gs1(raw, barcode_type)
        if barcode_type == "HIBC":
            return cls._parse_hibc(raw)
        if barcode_type == "QR":
            return cls._parse_private_qr(raw)
        raise BizException("0905010", "UDI 格式无法识别：%s" % barcode_type)

    @classmethod
    def _parse_gs1(cls, raw: str, barcode_type: str) -> Dict[str, Any]:
        """解析 GS1 格式。"""
        # 去掉 FNC1 分隔符（GS = \x1d）
        text = raw.replace("\x1d", "|")
        fields: Dict[str, Any] = {}
        i = 0
        n = len(text)
        while i < n:
            ai = text[i:i + 2]
            if ai == "|":
                i += 1
                continue
            if ai in ("24", "30") and i + 2 < n and text[i + 2].isdigit():
                ai = text[i:i + 3]
            i += len(ai)
            if ai in cls._FIXED_LEN:
                length = cls._FIXED_LEN[ai]
                value = text[i:i + length]
                i += length
            elif ai in cls._VAR_LEN or len(ai) == 3:
                j = text.find("|", i)
                if j == -1:
                    j = n
                value = text[i:j]
                i = j
            else:
                break
            name = cls._AI_MAP.get(ai)
            if name:
                fields[name] = value

        if "di" not in fields:
            raise BizException("0905011", "UDI 缺少器械标识 DI")

        # DI 校验位（GS1 Mod-10）
        if not cls._check_gs1_di(fields["di"]):
            raise BizException("0905012", "UDI 校验位错误，疑似伪码")

        if not fields.get("lot_no") and not fields.get("serial_no"):
            raise BizException("0905011", "UDI 缺少批号或序列号")

        if not fields.get("expiry_date") and not fields.get("production_date"):
            raise BizException("0905011", "UDI 缺少有效期或生产日期")

        if fields.get("expiry_date"):
            fields["expiry_date"] = cls._yymmdd(fields["expiry_date"])
        if fields.get("production_date"):
            fields["production_date"] = cls._yymmdd(fields["production_date"])

        fields["diopter"] = cls._extract_diopter(fields.get("extra_model"))
        fields["barcode_type"] = barcode_type
        return fields

    @classmethod
    def _parse_hibc(cls, raw: str) -> Dict[str, Any]:
        """解析 HIBC 格式（`+` 开头，`/` 分隔）。"""
        parts = raw.lstrip("+").split("/")
        if len(parts) < 3:
            raise BizException("0905010", "HIBC 格式不完整")
        fields = {
            "di": parts[0],
            "lot_no": parts[1] if len(parts) > 1 else None,
            "serial_no": parts[2] if len(parts) > 2 else None,
            "barcode_type": "HIBC",
        }
        if len(parts) > 3 and re.match(r"^\d{6}$", parts[3]):
            fields["expiry_date"] = cls._yymmdd(parts[3])
        fields["diopter"] = cls._extract_diopter(parts[-1])
        return fields

    @classmethod
    def _parse_private_qr(cls, raw: str) -> Dict[str, Any]:
        """解析厂商私有 QR（JSON 或 key=value 格式）。"""
        try:
            obj = json.loads(raw)
            fields = {
                "di": obj.get("di") or obj.get("udi_di"),
                "lot_no": obj.get("lot") or obj.get("lot_no"),
                "serial_no": obj.get("sn") or obj.get("serial_no"),
                "expiry_date": obj.get("exp") or obj.get("expiry"),
                "diopter": obj.get("power") or obj.get("diopter"),
                "barcode_type": "QR",
            }
        except (ValueError, AttributeError):
            pairs = dict(
                item.split("=", 1) for item in raw.split(";") if "=" in item
            )
            fields = {
                "di": pairs.get("di"),
                "lot_no": pairs.get("lot"),
                "serial_no": pairs.get("sn"),
                "expiry_date": pairs.get("exp"),
                "diopter": pairs.get("power"),
                "barcode_type": "QR",
            }
        if not fields.get("di"):
            raise BizException("0905011", "UDI 缺少器械标识 DI")
        return fields

    @staticmethod
    def _check_gs1_di(di: str) -> bool:
        """GS1 Mod-10 校验位。"""
        if not re.match(r"^\d{14}$", di):
            return False
        digits = [int(c) for c in di]
        check = digits[-1]
        total = 0
        for idx, d in enumerate(reversed(digits[:-1])):
            total += d * (3 if idx % 2 == 0 else 1)
        return (10 - total % 10) % 10 == check

    @staticmethod
    def _yymmdd(value: str) -> str:
        """YYMMDD → YYYY-MM-DD。"""
        if not re.match(r"^\d{6}$", value):
            return value
        yy = int(value[:2])
        year = 2000 + yy if yy < 70 else 1900 + yy
        return "%04d-%s-%s" % (year, value[2:4], value[4:6])

    @staticmethod
    def _extract_diopter(value: Optional[str]) -> Optional[float]:
        """从附加信息提取度数（如 '21.5' / 'D21.5' / '21.5D'）。"""
        if not value:
            return None
        m = re.search(r"(\d{1,2}(?:\.\d{1,2})?)\s*D?", value.upper())
        if not m:
            return None
        try:
            return float(m.group(1))
        except ValueError:
            return None

class ImplantUseService(BaseService):
    """植入物使用单的创建、查询、植入记录。"""

    @classmethod
    async def workbench(
        cls, db: AsyncSession, schedule_id: int, user: Dict[str, Any],
    ) -> Dict[str, Any]:
        """植入物工作台。"""
        schedule = await SurgeryScheduleClient.get_schedule(db, schedule_id)
        if not schedule:
            raise BizException("0905001", "台次不存在或已结束")

        use = await cls._get_or_create_use(db, schedule, user)
        preorder = await SurgeryClient.get_implant_preorder(db, schedule_id)
        items = await cls._list_items(db, use["id"])

        pending = [x for x in preorder.get("items", [])
                   if x["eye_side"] not in {i["eye_side"] for i in items
                                            if i["status"] != "ABORTED"}]

        alerts: List[Dict[str, Any]] = []
        if pending and schedule.get("status") in ("IN_SURGERY", "RECOVERING"):
            alerts.append({
                "level": "HIGH",
                "code": "IMPLANT_PENDING",
                "message": "还有 %d 枚植入物未扫码，患者仍在手术间" % len(pending),
            })

        return {
            "schedule": schedule,
            "use": use,
            "preorder": preorder,
            "items": items,
            "pending": pending,
            "alerts": alerts,
        }

    @classmethod
    async def _get_or_create_use(
        cls, db: AsyncSession, schedule: Dict[str, Any], user: Dict[str, Any],
    ) -> Dict[str, Any]:
        """获取或创建使用单（幂等）。"""
        stmt = select(M09ImplantUse).where(
            M09ImplantUse.schedule_id == schedule["id"],
            M09ImplantUse.is_deleted.is_(False),

        row = (await db.execute(stmt)).scalar_one_or_none()
        if row:
            return cls._use_dict(row)

        use = M09ImplantUse(
            use_no=await cls._next_use_no(db),
            schedule_id=schedule["id"],
            schedule_no=schedule.get("schedule_no"),
            use_date=schedule["schedule_date"],
            patient_id=schedule["patient_id"],
            patient_name=schedule["patient_name"],
            gender=schedule.get("gender"),
            age=schedule.get("age"),
            adm_no=schedule.get("adm_no"),
            operation_code=schedule.get("operation_code"),
            operation_name=schedule.get("operation_name"),
            eye_side=schedule.get("eye_side"),
            or_code=schedule.get("room_code"),
            seq_no=schedule.get("seq_no", 1),
            dept_id=schedule.get("dept_id"),
            surgeon_id=schedule.get("surgeon_id"),
            surgeon_name=schedule.get("surgeon_name"),
            instrument_nurse_id=schedule.get("instrument_nurse_id"),
            instrument_nurse_name=schedule.get("instrument_nurse_name"),
            circulating_nurse_id=schedule.get("circulating_nurse_id"),

            status="PENDING",
            total_items=0,
            scanned_items=0,
            implanted_items=0,
            archived_items=0,
            created_by=user.get("employee_id"),
        )
        db.add(use)
        await db.commit()
        await db.refresh(use)
        return cls._use_dict(use)

    @classmethod
    async def record_implant(
        cls, db: AsyncSession, item_id: int, body: Any, user: Dict[str, Any],
    ) -> Dict[str, Any]:
        """记录植入。"""
        item = await cls._get_item_for_update(db, item_id)
        if item.status != "CONFIRMED":
            raise BizException("0905003",
                               "植入物状态为 %s，不可记录植入" % item.status)

        schedule = await SurgeryScheduleClient.get_schedule(db, item.schedule_id)
        incise_at = schedule.get("actual_incise_at")
        suture_at = schedule.get("actual_suture_at")
        if incise_at and body.implanted_at < incise_at:
            raise BizException("0905040", "植入时刻早于切皮时刻")
        if suture_at and body.implanted_at > suture_at:
            raise BizException("0905040", "植入时刻晚于缝合时刻")

        if body.eye_side != item.eye_side:
            raise BizException(
                "0905041",
                "植入眼别 %s 与共读眼别 %s 不一致" % (body.eye_side, item.eye_side),
            )

        if body.intraop_complication and not (body.remark or "").strip():
            raise BizException("0905042", "勾选术中并发症必须填写备注")

        item.implanted_at = body.implanted_at
        item.eye_side = body.eye_side
        item.implant_position = body.implant_position
        item.implant_depth_mm = body.implant_depth_mm
        item.intraop_complication = body.intraop_complication or []
        item.implant_status = body.implant_status
        item.remark = body.remark
        item.status = "IMPLANTED"
        item.updated_at = datetime.now()
        item.updated_by = user.get("employee_id")

        await cls._recount_use(db, item.use_id)

        # 触发异步回写
        from app.tasks.m09_implant import (
            writeback_emr_task, writeback_m15_task,
        )
        writeback_m15_task.delay(item.id)
        writeback_emr_task.delay(item.id)

        await db.commit()

        return {
            "item_id": item.id,
            "status": item.status,
            "implanted_at": item.implanted_at.isoformat(),
            "archive": {
                "label_done": item.label_archived,
                "m15_done": item.m15_written,
                "m18_done": item.m18_written,
                "progress": "%d/3" % sum(
                    [item.label_archived, item.m15_written, item.m18_written]
                ),
            },
            "writeback_tasks": [
                "m09_implant_writeback_m15", "m09_implant_writeback_m18",
            ],
        }

    @classmethod
    async def internal_status(
        cls, db: AsyncSession, schedule_id: int,
    ) -> Dict[str, Any]:
        """植入完成状态（M06-05 离院校验）。"""
        stmt = select(M09ImplantUse).where(
            M09ImplantUse.schedule_id == schedule_id,
            M09ImplantUse.is_deleted.is_(False),
        )
        use = (await db.execute(stmt)).scalar_one_or_none()
        if not use:
            return {
                "schedule_id": schedule_id,
                "exists": False,
                "allow_discharge": True,
                "block_reason": None,
            }

        items = await cls._list_items(db, use.id)
        unarchived = [x for x in items
                      if x["status"] == "IMPLANTED" and x["archive_progress"] != "3/3"]

        allow = True
        block_reason = None
        if use.status in ("SCANNED", "VERIFIED", "CONFIRMED"):
            allow = False
            block_reason = "存在未完成植入流程的植入物"
        elif unarchived:
            allow = False
            block_reason = "%d 枚植入物归档未完成" % len(unarchived)

        return {
            "schedule_id": schedule_id,
            "exists": True,
            "use_id": use.id,
            "use_no": use.use_no,
            "status": use.status,
            "total_items": use.total_items,
            "implanted_items": use.implanted_items,
            "archived_items": use.archived_items,
            "allow_discharge": allow,
            "block_reason": block_reason,
        }

class ImplantScanService(BaseService):
    """UDI 扫码与解析。"""

    @classmethod
    async def scan(
        cls, db: AsyncSession, use_id: int, body: Any, user: Dict[str, Any],
    ) -> Dict[str, Any]:
        """扫码解析。"""
        use = await cls._get_use_for_update(db, use_id)

        if use.status not in ("PENDING", "SCANNED", "VERIFIED", "CONFIRMED"):
            raise BizException("0905003",
                               "使用单状态为 %s，不允许扫码" % use.status)

        items = await cls._count_items(db, use_id)
        if items >= ImplantUseService.MAX_ITEMS_PER_SCHEDULE:
            raise BizException("0905005",
                               "单台次植入物不得超过 %d 枚"
                               % ImplantUseService.MAX_ITEMS_PER_SCHEDULE)

        parsed = UdiParser.parse(body.raw_code, body.barcode_type)

        # 同单内重复
        dup = await cls._find_duplicate_in_use(db, use_id, parsed)
        if dup:
            raise BizException("0905014", "该 UDI 已在本台次扫码（明细 %d）" % dup)

        # 其他人已使用
        used = await cls._find_used_elsewhere(db, parsed)
        if used:
            raise BizException(
                "0905015",
                "该 UDI 已被占用：台次 %s" % used,
            )

        item = M09ImplantItem(
            use_id=use_id,
            seq_no=items + 1,
            eye_side=body.eye_side,
            status="SCANNED",
            raw_code=body.raw_code,
            barcode_type=parsed.get("barcode_type"),
            di=parsed.get("di"),
            lot_no=parsed.get("lot_no"),
            serial_no=parsed.get("serial_no"),
            expiry_date=cls._to_date(parsed.get("expiry_date")),
            production_date=cls._to_date(parsed.get("production_date")),
            diopter=parsed.get("diopter"),
            manufacturer_name=parsed.get("manufacturer_name"),
            model=parsed.get("model"),
            spec=parsed.get("spec"),
            scanned_at=datetime.now(),
            scanned_by=user.get("employee_id"),
            created_by=user.get("employee_id"),
        )
        db.add(item)

        # 扫码日志
        db.add(M09ImplantScan(
            use_id=use_id,
            item_id=None,
            raw_code=body.raw_code,
            barcode_type=body.barcode_type,
            parse_success=True,
            parsed_json=parsed,
            scanned_at=datetime.now(),
            scanned_by=user.get("employee_id"),
            ip=user.get("client_ip"),
        ))

        use.status = "SCANNED"
        use.scanned_items = items + 1
        await db.flush()

        # 补写日志的 item_id
        stmt = select(M09ImplantScan).where(
            M09ImplantScan.use_id == use_id,
            M09ImplantScan.item_id.is_(None),
        ).order_by(M09ImplantScan.id.desc()).limit(1)
        log = (await db.execute(stmt)).scalar_one_or_none()
        if log:
            log.item_id = item.id

        await db.commit()
        await db.refresh(item)

        return {
            "item_id": item.id,
            "use_id": use_id,
            "eye_side": item.eye_side,
            "status": item.status,
            "parsed": {
                "di": item.di,
                "manufacturer_name": item.manufacturer_name,
                "model": item.model,
                "spec": item.spec,
                "lot_no": item.lot_no,
                "serial_no": item.serial_no,
                "expiry_date": (
                    item.expiry_date.isoformat() if item.expiry_date else None
                ),
                "days_remaining": cls._days_remaining(item.expiry_date),
                "diopter": float(item.diopter) if item.diopter else None,
                "barcode_type": item.barcode_type,
            },
            "next_action": "VERIFY",
        }

    @classmethod
    def _to_date(cls, value: Optional[str]) -> Optional[date]:
        """字符串日期转 date。"""
        if not value:
            return None
        try:
            return date.fromisoformat(value)
        except ValueError:
            return None

    @classmethod
    def _days_remaining(cls, expiry: Optional[date]) -> Optional[int]:
        """剩余天数。"""
        if not expiry:
            return None
        return (expiry - date.today()).days

    @classmethod
    async def _find_duplicate_in_use(
        cls, db: AsyncSession, use_id: int, parsed: Dict[str, Any],
    ) -> Optional[int]:
        """同单内是否已有同一 UDI。"""
        conditions = [M09ImplantItem.use_id == use_id,
                      M09ImplantItem.is_deleted.is_(False),
                      M09ImplantItem.status != "ABORTED"]
        if parsed.get("serial_no"):
            conditions.append(M09ImplantItem.serial_no == parsed["serial_no"])
        else:
            conditions.append(M09ImplantItem.di == parsed.get("di"))
            conditions.append(M09ImplantItem.lot_no == parsed.get("lot_no"))
        stmt = select(M09ImplantItem.id).where(and_(*conditions)).limit(1)
        row = (await db.execute(stmt)).scalar_one_or_none()
        return row

    @classmethod
    async def _find_used_elsewhere(
        cls, db: AsyncSession, parsed: Dict[str, Any],
    ) -> Optional[str]:
        """是否已被其他台次使用。"""
        conditions = [M09ImplantItem.is_deleted.is_(False),
                      M09ImplantItem.status == "IMPLANTED"]
        if parsed.get("serial_no"):
            conditions.append(M09ImplantItem.serial_no == parsed["serial_no"])
        else:
            conditions.append(M09ImplantItem.di == parsed.get("di"))
            conditions.append(M09ImplantItem.lot_no == parsed.get("lot_no"))
        stmt = (
            select(M09ImplantUse.schedule_no)
            .join(M09ImplantItem, M09ImplantItem.use_id == M09ImplantUse.id)
            .where(and_(*conditions))
            .limit(1)
        )
        row = (await db.execute(stmt)).scalar_one_or_none()
        return row

class ImplantVerifyService(BaseService):
    """五道校验（真伪 / 有效期 / 重复 / 型号 / 眼别）。"""

    @classmethod
    async def verify(
        cls, db: AsyncSession, item_id: int, body: Any, user: Dict[str, Any],
    ) -> Dict[str, Any]:
        """执行五道校验。"""
        item = await cls._get_item_for_update(db, item_id)
        if item.status != "SCANNED":
            raise BizException("0905003",
                               "植入物状态为 %s，不可校验" % item.status)

        checks: List[Dict[str, Any]] = []
        failed: List[str] = []

        # ① 真伪校验
        auth = await cls._check_authenticity(db, item, body.skip_external)
        checks.append(auth)
        if not auth["passed"] and auth["blocking"]:
            failed.append(auth["code"])

        # ② 有效期校验
        expiry = cls._check_expiry(item)
        checks.append(expiry)
        if not expiry["passed"]:
            failed.append(expiry["code"])

        # ③ 重复使用校验
        dup = await cls._check_reuse(db, item)
        checks.append(dup)
        if not dup["passed"]:
            failed.append(dup["code"])

        # ④ 型号匹配校验
        model = await cls._check_model(db, item)
        checks.append(model)
        if not model["passed"]:
            failed.append(model["code"])

        # ⑤ 眼别匹配校验
        eye = await cls._check_eye_side(db, item)
        checks.append(eye)
        if not eye["passed"]:
            failed.append(eye["code"])

        # 附加校验（不阻断）
        extras: List[Dict[str, Any]] = []
        extras.append(await cls._check_m15_stock(db, item))
        extras.append(await cls._check_theoretical_diopter(db, item))

        # 记录校验结果
        item.verify_checks = checks
        item.verify_extras = extras
        item.verify_at = datetime.now()
        item.verify_by = user.get("employee_id")

        if failed:
            item.verify_failed_codes = failed
            item.status = "SCANNED"
            await db.commit()
            raise BizException(failed[0], checks[-1].get("detail", "校验未通过"),
                               data={"item_id": item.id,
                                     "status": item.status,
                                     "checks": checks,
                                     "failed_codes": failed})

        item.status = "VERIFIED"
        item.verify_failed_codes = []
        await db.commit()

        return {
            "item_id": item.id,
            "status": item.status,
            "checks": checks,
            "extras": extras,
            "all_passed": True,
            "next_action": "READBACK",
        }

    @classmethod
    async def _check_authenticity(
        cls, db: AsyncSession, item: Any, skip_external: bool,
    ) -> Dict[str, Any]:
        """V-01 真伪校验。"""
        if skip_external:
            item.authenticity = "UNCHECKED"
            return {
                "code": "V-01",
                "name": "真伪校验",
                "passed": True,
                "blocking": False,
                "detail": "已跳过外部校验，记未校验",
            }
        try:
            result = await SurgeryClient.check_udi(db, item.di)
        except Exception:  # 外部依赖超时
            item.authenticity = "UNCHECKED"
            logger.warning("UDI 库校验超时 di=%s", item.di)
            return {
                "code": "V-01",
                "name": "真伪校验",
                "passed": True,
                "blocking": False,
                "detail": "UDI 库服务不可用，记未校验（24h 内补做）",
            }
        if not result.get("found"):
            item.authenticity = "FAKE"
            return {
                "code": "V-01",
                "name": "真伪校验",
                "passed": False,
                "blocking": True,
                "detail": "DI %s 不在国家药监局 UDI 库中" % item.di,
            }
        if not result.get("manufacturer_qualified", True):
            item.authenticity = "UNQUALIFIED"
            return {
                "code": "V-01",
                "name": "真伪校验",
                "passed": False,
                "blocking": True,
                "detail": "厂商「%s」不在合格供应商名录" % result.get("manufacturer_name"),
            }
        item.authenticity = "VERIFIED"
        item.manufacturer_name = result.get("manufacturer_name")
        item.model = result.get("model") or item.model
        item.spec = result.get("spec") or item.spec
        return {
            "code": "V-01",
            "name": "真伪校验",
            "passed": True,
            "blocking": True,
            "detail": "DI %s 在国家药监局 UDI 库中；厂商在合格供应商名录" % item.di,
        }

    @classmethod
    def _check_expiry(cls, item: Any) -> Dict[str, Any]:
        """V-02 有效期校验。"""
        if not item.expiry_date:
            return {
                "code": "V-02",
                "name": "有效期校验",
                "passed": False,
                "blocking": True,
                "detail": "UDI 缺少有效期，无法判定",
            }
        today = date.today()
        if item.expiry_date < today:
            return {
                "code": "V-02",
                "name": "有效期校验",
                "passed": False,
                "blocking": True,
                "detail": "有效期 %s，已过期 %d 天"
                          % (item.expiry_date.isoformat(),
                             (today - item.expiry_date).days),
            }
        return {
            "code": "V-02",
            "name": "有效期校验",
            "passed": True,
            "blocking": True,
            "detail": "有效期 %s，剩余 %d 天"
                      % (item.expiry_date.isoformat(),
                         (item.expiry_date - today).days),
        }

    @classmethod
    async def _check_reuse(cls, db: AsyncSession, item: Any) -> Dict[str, Any]:
        """V-03 重复使用校验。"""
        conditions = [M09ImplantItem.is_deleted.is_(False),
                      M09ImplantItem.status == "IMPLANTED",
                      M09ImplantItem.id != item.id]
        if item.serial_no:
            conditions.append(M09ImplantItem.serial_no == item.serial_no)
        else:
            conditions.append(M09ImplantItem.di == item.di)
            conditions.append(M09ImplantItem.lot_no == item.lot_no)
        stmt = select(func.count(M09ImplantItem.id)).where(and_(*conditions))
        count = (await db.execute(stmt)).scalar() or 0
        if count > 0:
            return {
                "code": "V-03",
                "name": "重复使用校验",
                "passed": False,
                "blocking": True,
                "detail": "该序列号已被使用 %d 次" % count,
            }
        return {
            "code": "V-03",
            "name": "重复使用校验",
            "passed": True,
            "blocking": True,
            "detail": "序列号 %s 未被使用" % (item.serial_no or item.lot_no),
        }

    @classmethod
    async def _check_model(cls, db: AsyncSession, item: Any) -> Dict[str, Any]:
        """V-04 型号与度数匹配校验。"""
        preorder = await SurgeryClient.get_implant_preorder(db, item.schedule_id)
        expected = None
        for x in preorder.get("items", []):
            if x["eye_side"] == item.eye_side:
                expected = x
                break
        if not expected:
            return {
                "code": "V-04",
                "name": "型号匹配校验",
                "passed": False,
                "blocking": True,
                "detail": "预订单中无 %s 眼别的植入物" % item.eye_side,
            }

        diffs: List[str] = []
        if (expected.get("model") or "") != (item.model or ""):
            diffs.append("型号「%s」≠「%s」"
                         % (item.model, expected.get("model")))
        if expected.get("diopter") is not None:
            exp_d = Decimal(str(expected["diopter"]))
            act_d = Decimal(str(item.diopter)) if item.diopter else None
            if act_d is None or abs(exp_d - act_d) > Decimal("0.01"):
                diffs.append("度数 %sD ≠ %sD"
                             % (item.diopter, expected.get("diopter")))

        if diffs:
            return {
                "code": "V-04",
                "name": "型号匹配校验",
                "passed": False,
                "blocking": True,
                "detail": "；".join(diffs),
            }
        return {
            "code": "V-04",
            "name": "型号匹配校验",
            "passed": True,
            "blocking": True,
            "detail": "预订单 %sD %s，扫码一致"
                      % (expected.get("diopter"), expected.get("model")),
        }

    @classmethod
    async def _check_eye_side(cls, db: AsyncSession, item: Any) -> Dict[str, Any]:
        """V-05 眼别匹配校验。"""
        schedule = await SurgeryScheduleClient.get_schedule(db, item.schedule_id)
        schedule_eye = (schedule or {}).get("eye_side") or "NA"
        if schedule_eye == "NA":

class ImplantReadbackService(BaseService):
    """三方共读确认。"""

    MIN_DURATION_SECONDS = 5

    @classmethod
    async def submit(
        cls, db: AsyncSession, item_id: int, body: Any, user: Dict[str, Any],
    ) -> Dict[str, Any]:
        """提交三方共读。"""
        item = await cls._get_item_for_update(db, item_id)
        if item.status != "VERIFIED":
            raise BizException("0905026",
                               "植入物状态为 %s，必须先通过校验" % item.status)

        existing = await cls._get_readback(db, item_id)
        if existing:
            raise BizException("0905034", "共读记录已存在，不可重复提交")

        if not (body.surgeon_stated_text or "").strip():
            raise BizException("0905030", "主刀口述内容不能为空")
        if not (body.nurse_read_text or "").strip():
            raise BizException("0905030", "护士读出内容不能为空")
        if body.patient_confirmed not in ("CONSISTENT", "INCONSISTENT", "UNABLE"):
            raise BizException("0905031", "请选择患者确认结果")
        if body.patient_confirm_way == "SURROGATE":
            if not (body.surrogate_name or "").strip() or not (
                body.surrogate_relation or ""
            ).strip():
                raise BizException("0905032", "家属代确认须填写姓名与关系")
        if body.patient_confirmed == "INCONSISTENT":
            if not (body.inconsistent_reason or "").strip():
                raise BizException("0905033", "共读不一致必须填写原因")

        consistency = cls._judge_consistency(
            item, body.surgeon_stated_text, body.nurse_read_text,
            body.patient_confirmed,
        )
        suspicious = body.duration_seconds < cls.MIN_DURATION_SECONDS
        if suspicious:
            logger.warning(
                "共读耗时过短 item=%s duration=%ss",
                item_id, body.duration_seconds,
            )

        readback = M09ImplantReadback(
            item_id=item_id,
            use_id=item.use_id,
            surgeon_stated_text=body.surgeon_stated_text,
            nurse_read_text=body.nurse_read_text,
            patient_confirmed=body.patient_confirmed,
            patient_confirm_way=body.patient_confirm_way,
            surrogate_name=body.surrogate_name,
            surrogate_relation=body.surrogate_relation,
            inconsistent_reason=body.inconsistent_reason,
            consistency=consistency,
            duration_seconds=body.duration_seconds,
            is_suspicious_fast=suspicious,
            read_at=datetime.now(),
            read_by=user.get("employee_id"),
        )
        db.add(readback)

        if body.patient_confirmed == "INCONSISTENT":
            item.status = "SCANNED"
            item.verify_failed_codes = ["0905033"]
        else:
            item.status = "CONFIRMED"

        item.updated_at = datetime.now()
        item.updated_by = user.get("employee_id")
        await db.commit()
        await db.refresh(readback)

        return {
            "item_id": item_id,
            "status": item.status,
            "readback_id": readback.id,
            "consistency": consistency,
            "read_at": readback.read_at.isoformat(),
            "is_suspicious_fast": suspicious,
            "next_action": (
                "IMPLANT" if item.status == "CONFIRMED" else "RESCAN"
            ),
        }

    @classmethod
    def _judge_consistency(
        cls, item: Any, surgeon_text: str, nurse_text: str,
        patient_confirmed: str,
    ) -> Dict[str, bool]:
        """一致性自动比对（提取数字与关键字段）。"""

        def extract_numbers(value: str) -> set:
            return set(re.findall(r"\d+(?:\.\d+)?", value or ""))

        def extract_eye(value: str) -> Optional[str]:
            text = value or ""
            if "左" in text or "OS" in text.upper():
                if "右" not in text:
                    return "OS"
            if "右" in text or "OD" in text.upper():
                if "左" not in text:
                    return "OD"
            return None

        item_eye = item.eye_side
        item_diopter = (
            str(item.diopter).rstrip("0").rstrip(".")
            if item.diopter is not None else None
        )

        numbers = extract_numbers(
            "%s %s" % (surgeon_text or "", nurse_text or "")
        )
        surgeon_eye = extract_eye(surgeon_text) or item_eye
        nurse_eye = extract_eye(nurse_text) or item_eye

        return {
            "surgeon_vs_packaging": (
                (item_diopter is None or item_diopter in numbers)
                and surgeon_eye == item_eye
            ),
            "nurse_vs_system": (
                (item_diopter is None or item_diopter in numbers)
                and nurse_eye == item_eye
            ),
            "patient_confirmed": patient_confirmed == "CONSISTENT",
        }

### 6.7 专题：为什么"扫码动作"与"使用登记"要分属两个模块

这是本子模块最容易被质疑的设计——既然都是记录植入物，为什么不放在一起？

**如果都在 M09 会怎样：**

M09 需要维护全院植入物的库存、批次、供应商、采购、召回——这与手术室业务毫无关系。而且 M05 住院手术、M11 屈光手术（ICL）也需要登记植入物，它们不在 M09。

**如果都在 M15 会怎样：**

M15 需要理解 UDI 解析、五道校验、三方共读、术眼匹配——这些都是手术事业务，M15 是物资部门，不掌握这些知识。而且 M15 的人不会在手术间里扫码。

**当前设计的三个好处：**

1. **M09-05 是「术中那一刻」的记录，与手术时间轴绑定**——植入时刻必须在切皮与缝合之间，这个约束只有 M09 能表达
2. **M15 是「植入物台账」，与物资生命周期绑定**——入库、出库、灭菌、使用、召回，是完整链条
3. **数据只写一次、只读多次**——M09-05 产生，M15 消费，M18 展示。没有人复制粘贴

**接口契约：**

```
M09-05 记录植入 ──异步──► POST /internal/v1/m15/implant/register
                             {udi, di, lot_no, serial_no, patient_id,
                              schedule_id, eye_side, implanted_at,
                              surgeon_id, implant_position}
                          ◄── {register_no, registered: true}

                      失败时 ──► 重试队列（退避 10/30/60/120/300 秒）
                              5 次后标 FAILED，告警设备科 + 手术室护士长
```

**关键设计：回写 M15 失败不阻断手术。**

真实场景：M15 服务升级窗口 10 分钟，期间植入的晶体回写失败。若阻断，手术无法进行。当前设计是本地先落库、异步重试——只要 M09-05 有记录，追溯链就不断。理论上 5 次重试约 9 分钟后仍未成功，人工介入。

**设计要点：**

1. **主刀医生只有 `query`**：扫码、校验、共读是护士执行的。主刀在三方共读中「口述」由巡回护士代为录入——若主刀自己也能执行，三方共读就变成两方，失去制衡。
2. **系统管理员只有 `config`**：植入物记录含患者姓名、诊断、植入部位、晶体型号与价格，属敏感医疗财务数据。运维排查需护士长或设备科授权临时账号（2 小时）。
3. **设备科有 `recall` 无 `execute`**：召回是设备科职责，但扫码植入必须在场护士完成。
4. **医务科有 `recall` 无 `execute`**：不良事件上报与召回跟进是医务科职责。

        extra={
            "module": "M09-05",
            "action": "SCAN",
            "item_id": item_id,
            "success": success,
        },
    )


def log_verify(item_id: int, failed: list, elapsed_ms: int) -> None:
    """校验日志。"""
    level = logging.INFO if not failed else logging.WARNING
    logger.log(
        level,
        "植入物校验 item=%s failed=%s elapsed=%sms",
        item_id, failed, elapsed_ms,
        extra={
            "module": "M09-05",
            "action": "VERIFY",
            "item_id": item_id,
            "failed_codes": failed,
            "elapsed_ms": elapsed_ms,
        },
    )


def log_implant(item_id: int, patient_id: int, udi: str, eye_side: str) -> None:
    """植入日志（敏感：含患者与植入物信息）。"""
    logger.info(
        "植入完成 item=%s patient=%s udi=%s eye=%s",
        item_id, patient_id, udi, eye_side,
        extra={
            "module": "M09-05",
            "action": "IMPLANT",
            "item_id": item_id,
            "patient_id": patient_id,
        },
    )


def log_recall(recall_no: str, recall_type: str, total: int, elapsed_ms: int) -> None:
    """召回检索日志。"""
    logger.warning(
        "召回检索 recall=%s type=%s total=%s elapsed=%sms",

        extra={
            "module": "M09-05",

            "recall_no": recall_no,
            "total_patients": total,
        },
    )
